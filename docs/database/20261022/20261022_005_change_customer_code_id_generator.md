# 거래처 코드 eGov ID Generator 초기화 변경 이력

- 날짜: 2026-10-22
- 변경 번호: `20261022_005`
- 대상: 기존 전자정부 ID Generator 관리 테이블 `public.ids`의 `tb_customer_info` 카운터 행.
- 변경 내용: 기존 `customer_code` 중 1~6자리 숫자 코드의 최댓값보다 큰 값으로 카운터를 초기화한다. 해당 키가 이미 있으면 기존 `next_id`와 비교해 더 큰 값만 보존한다. 신규 코드는 전자정부 ID Generator가 6자리로 생성한다.
- 영향 범위: 거래처 등록 시 코드 미입력인 경우 사용할 기존 ID 카운터 행만 초기화한다. 신규 테이블/시퀀스와 거래처 컬럼 변경은 없다. 수동 입력 코드, 거래처 데이터, 기존 unique 제약 및 `customer_id` 기본 시퀀스는 변경하지 않는다.
- MCP 근거: `s-erp-postgresql-readonly-tenant-1110011111`에서 `tb_customer_info`, `ids` 컬럼 및 제약 메타데이터를 확인했다. 업무 데이터 행과 ID 카운터 행은 조회하지 않았다.
- 적용 상태: 스크립트 작성만 완료. 실제 DB에는 적용하지 않았다.
