## 변경 내용
| 대상 | 변경 |
|---|---|
| `tb_hr_order_hd` | 신규. 인사명령 1건(명령일·유형·출처·비고·처리자·처리일시) |

## 영향 범위
- 신규 테이블·메뉴만 추가하며 기존 데이터는 바뀌지 않는다. 서버가 이력을 기록하므로 **스크립트를 적용한 뒤** 백엔드를 배포한다(적용 전에는 사원 저장이 이력 기록에서 실패할 수 있다).
- 이미 있는 사원의 과거 이력은 만들지 않는다.

## 롤백
롤백 스크립트로 메뉴와 두 테이블을 제거한다(이력 데이터 삭제).
