# 20261026_008 수주 헤더/상세 스키마 변경 이력

- 날짜: 2026-10-26
- 변경 내용: S-ERP 테넌트 모델에 맞춘 수주 헤더 및 상세 테이블 생성 DDL을
  신규 환경용으로 추가한다.
- 대상 테이블: `public.tb_sales_order_hd`, `public.tb_sales_order_dt`
- 영향 범위: 헤더/상세 내부 ID, tenant별 수주번호, 거래처/품목 복합 FK,
  상세 라인 식별 및 주문 금액/납기/출하 필드.
- 전제: `public.tb_tenant`, `public.tb_customer_info`,
  `public.tb_material_info`와 마스터별 `(id, tenant_id)` 유니크 키가 준비되어
  있어야 한다. 견적 테이블은 현 DB에 없어 `quot_no` FK를 생성하지 않는다.
- 적용 상태: SQL 파일만 작성했으며 실제 데이터베이스에 적용하지 않았다.
- DB 확인 근거: `s-erp-postgresql-readonly` MCP에서 테이블 목록 및 거래처/
  품목 컬럼·제약 metadata를 읽기 전용으로 확인했다. 업무 데이터 행은 조회하지
  않았다.
- 롤백: 두 테이블 중 하나라도 데이터가 있으면 중단한다. 빈 신규 테이블만
  상세→헤더 순으로 삭제하며 `CASCADE`를 사용하지 않는다.
- 롤백 여부: 실행하지 않음. 데이터베이스 변경을 적용하지 않았다.

같은 작업 번호의 생성 스크립트와 롤백 스크립트는 이 디렉터리에 보관한다.
