## 실행 안전

psql 호출 시 승인된 테넌트를 명시적으로 전달해야 한다. 스크립트는 해당 테넌트가 존재하지 않으면 실패하며 기본 테넌트를 추정하거나 선택하지 않는다. 기존 item code 충돌은 `ON CONFLICT DO NOTHING`으로 보존한다. 실행과 검증은 운영자가 승인한 절차로 수행하며 이 작업에서는 실행하지 않았다.

## 근거와 제한

읽기 전용 PostgreSQL MCP의 테이블 목록, 관련 테이블 메타데이터와 제안 그룹 코드의 존재 여부 집계로 공통코드 구조 및 현재 그룹 부재를 확인했다. 수주 헤더 상태 CHECK는 기존 한글 코드값을 허용하며 상세 진행상태 기본값은 `대기`다. 테넌트별 데이터 행이나 민감정보는 결과물에 기록하지 않았다.
