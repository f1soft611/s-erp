# 20261102_001 메뉴 즐겨찾기 스키마 변경 이력

- 변경일: 2026-11-02
- 변경 내용: 사용자별 즐겨찾기 폴더와 메뉴 바로가기 저장 테이블 정의
- 적용 대상: `tb_user_menu_favorite_folder`, `tb_user_menu_favorite`
- 영향 범위: 신규 API에서 인증 사용자·tenant 소유 범위로 폴더와 메뉴 위치를 저장하고 조회한다. 메뉴 삭제 시 즐겨찾기 참조는 cascade 삭제하며, 폴더는 연결된 메뉴가 있으면 삭제가 제한된다.
- 제약: 메뉴 즐겨찾기는 사용자별 메뉴당 한 행이며, 폴더 참조는 동일 사용자·tenant 소유만 허용한다. 폴더명은 공백 제거 후 1~40자다.
- 롤백 여부: 대응 롤백 스크립트 제공. 두 테이블의 데이터가 비어 있을 때만 삭제를 허용한다.
- 적용 상태: 이 작업에서는 실제 DB에 DDL을 적용하지 않았다. 스크립트는 수동 검토 및 추후 적용용이다.
- 확인 근거: `s-erp-postgresql-readonly` MCP로 `tb_menu`, `tb_user`, `tb_tenant` 컬럼과 PK/FK/UNIQUE 제약을 확인했다. 행 데이터는 조회하지 않았다.
