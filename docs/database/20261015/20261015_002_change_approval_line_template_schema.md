# 20261015_002 전자결재 결재선 템플릿 스키마 변경 이력

- 변경 일자: 2026-10-15
- 변경 내용: 사용자별 전자결재 결재선 템플릿 마스터/참여자 상세 테이블 생성
- 적용 대상 테이블: `tb_electronic_approval_line_template`, `tb_electronic_approval_line_template_info`
- 영향 범위: 결재선 템플릿의 사용자/테넌트별 저장, 문서번호 코드별 목록, 단계·참여자·참조 순서 보존
- 소유권: 마스터에 인증 사용자 ID와 tenant ID를 저장하고 모든 API에서 양쪽을 조건으로 사용
- 문서 구분 코드: 기안 `001`, 업무 `008`, 지출 `004`, 근태 `031`
- 무결성: 지원 코드/참여 유형/양수 순서 CHECK, 사용자·위치·이름 UNIQUE, tenant 복합 FK, 상세 cascade 삭제
- 참조 사용자: 저장 및 불러오기 시 서비스에서 같은 tenant의 활성 사용자임을 검증
- DB 확인 근거: PostgreSQL MCP에서 `tb_electronic_approval_line_info`, `tb_user`, `tb_login_account`의 현재 컬럼 메타데이터를 확인했다. 기존 결재선 행은 문서/처리상태에 귀속되므로 템플릿 용도로 재사용하지 않는다.
- 롤백: `20261015_002_rollback.sql`에서 상세 테이블을 먼저 제거한 뒤 마스터를 제거한다.
- 적용 상태: 마이그레이션 초안이며 실제 DB 적용 전 검토 및 배포 절차가 필요하다.
