# 20261030_005 공통 알림·쪽지함 스키마 변경 이력

- 날짜: 2026-10-30
- 변경: 수신자별 공통 알림, 1:1 쪽지 대화, 메시지 및 조회 인덱스 추가
- 대상 테이블: `tb_notification`, `tb_direct_message_thread`, `tb_direct_message`
- 영향 범위: 앱 API에서 사용하는 알림/쪽지 저장 구조. 실제 DB에는 세 테이블이 이미 존재하며 이번 작업은 스키마를 변경하지 않는다.
- 영향도: 로그인 사용자/tenant 조회 경계, 신규 메시지의 알림 생성, 쪽지별 읽음 상태를 사용한다.
- 롤백: `20261030_005_rollback.sql`에서 메시지 → 대화 → 알림 순서로 삭제 가능하다. 데이터가 생성된 뒤 롤백하면 해당 알림/쪽지 데이터가 제거되므로 사전 백업과 업무 승인 후 진행한다.
- DB MCP 근거: `s-erp-postgresql-readonly`의 public 테이블 목록, 세 테이블의 컬럼, FK/CHECK/UNIQUE 제약 및 인덱스 메타데이터를 조회했다. 실제 정의는 `20261030_005` DDL 초안과 일치한다. 행 데이터는 조회하지 않았다.
- 적용 상태: 이 작업에서는 실제 DB에 쓰기/적용하지 않았다. 세 테이블이 이미 존재하므로 migration/rollback 초안은 현재 DB에 실행하지 않는다.
- 작성 근거: 1:1 쪽지와 공통 알림은 별도 데이터/읽음 상태로 저장하고, 메시지 도착/댓글 멘션만 공통 알림으로 연결한다.
