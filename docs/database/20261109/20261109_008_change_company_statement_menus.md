# 회사정보·거래명세서 메뉴 변경 이력

- 날짜: 2026-11-09
- 대상: `tb_menu`, `tb_menu_permission`, `tb_role_menu_permission`.
- 내용: 기준정보 관리 아래 회사정보 관리, 출하관리 아래 거래명세서등록·현황을 추가한다.
- 영향: 승인된 테넌트의 기존 거래처·출하 메뉴 역할 권한을 대응 메뉴에 복사한다. 충돌 시 전체 트랜잭션을 중단한다.
- 롤백: 기존 메뉴와 권한을 재사용할 수 있으므로 자동 삭제하지 않는다. 적용 전 백업으로 DBA가 복원한다.
- 실제 DB 적용은 수행하지 않았다.
