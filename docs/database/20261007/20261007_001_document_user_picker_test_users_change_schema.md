# 20261007_001 문서작성 사용자 선택 테스트 데이터 변경 이력

- 변경일: 2026-10-07
- 변경 유형: 선택기 테스트용 시드 데이터 추가 (테이블 구조 변경 없음)
- 대상 테이블: `tb_user`
- 변경 내용: 예약된 `.invalid` 이메일과 표시용 테스트 이름을 가진 활성 사용자 프로필 10개를 추가하는 멱등 SQL 제공
- 계정 연결: 기존 활성 `tb_login_account` 행의 `tenant_id`/`login_id`를 재사용하며 로그인 계정이나 비밀번호는 생성하지 않음
- 조직 참조: 기존 활성 기준 사용자의 `department_id`, `level_id`를 재사용
- 영향 범위: 해당 기준 사용자의 테넌트에서 조회되는 문서작성 결재선/참조 사용자 선택 후보
- 롤백 여부: 제공된 `20261007_001_rollback.sql`은 지정된 테스트 이름/이메일을 모두 만족하는 행만 기준 테넌트에서 제거
- DB 반영 여부: 이 변경 기록은 SQL 산출물 설명이며 실제 DB에는 적용하지 않음
- DB MCP 확인: `tb_user`, `tb_login_account`, `tb_department`의 테이블/컬럼 설명은 확인함. 제한된 사용자 집계 조회는 `Database request failed`로 실패하여 초기 로그인 스키마 SQL과 사용자 선택 Mapper 조회문을 대체 계약 근거로 사용함
