# 납품처 관리 메뉴 seed

- 작성일: 2026-11-23. 단일 테넌트 대상 메뉴 데이터 변경이며 실제 DB에는 적용하지 않았다.
- 영업관리의 기준정보 그룹과 납품처 관리 메뉴 및 메뉴 가능 권한을 등록한다.
- 실행자가 대상 테넌트를 명시하고 스키마 적용 뒤 실행한다. 역할별 권한은 자동 부여하지 않으므로 관리자가 별도로 배정해야 메뉴가 표시된다.
- 롤백은 납품처 메뉴에 역할 권한이나 하위 메뉴가 있으면 중단한다. 기존 그룹일 수 있으므로 기준정보 그룹은 보존한다.
- 기본 PostgreSQL MCP의 메뉴 및 권한 테이블 메타데이터를 근거로 작성했으며 실제 seed 실행과 통합 검증은 수행하지 않았다.
