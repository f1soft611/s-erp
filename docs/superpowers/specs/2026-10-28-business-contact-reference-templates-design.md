# 업무연락 자주 쓰는 참조자 설정 설계

## 배경

문서작성 모달의 `업무연락`은 결재/합의 없이 참조자만 지정한다. 현재 참조자 입력은 있으나 자주 쓰는 참조자 구성을 저장하거나 불러오는 진입점이 없다. 반면 기안서에는 결재선과 참조자를 함께 편집하고 템플릿으로 관리하는 `결재선 설정` 모달이 이미 있다.

## 목표

- 업무연락에서 자주 쓰는 참조자 구성을 저장하고 다시 적용할 수 있게 한다.
- 기존 템플릿 저장/조회/이름 변경/삭제 기능과 적용·취소 상태 흐름을 재사용한다.
- 업무연락 UI에 결재/합의 편집 기능이 있는 것처럼 보이지 않도록 한다.
- 기존 기안서 결재선 설정 동작을 유지한다.

## 승인된 설계

### 진입점과 모달

- 업무연락의 참조 필드 오른쪽에 `자주 쓰는 참조자` 버튼을 둔다.
- 버튼을 누르면 기존 설정 모달을 재사용하되 업무연락 전용 참조자 모드로 연다.
- 모달 제목과 템플릿 저장/관리 문구는 참조자 의미에 맞게 표시한다.
- 참조자 모드에서는 참조자 선택과 자주 쓰는 참조자 템플릿의 저장, 불러오기, 이름 변경, 삭제만 노출한다. 결재/합의 단계 편집 UI는 숨긴다.
- 기안서에서 여는 모달의 기존 제목, 설명, 단계 UI와 동작은 변경하지 않는다.

### 상태와 상호작용

- 모달에서 템플릿을 적용하거나 참조자를 편집해도 작성 화면에는 즉시 반영하지 않는다.
- `적용`을 눌렀을 때만 임시 참조자 구성을 작성 화면에 전달한다.
- `취소` 또는 닫기는 모달을 연 시점의 작성 화면 참조자를 보존한다.
- 템플릿 CRUD는 기존 로그인 사용자/문서 코드 범위와 API 계약을 재사용한다.
- 업무연락은 기존 문서 코드 `008`에 저장된 템플릿을 사용한다.

### 기존 템플릿 호환성

- 업무연락 템플릿은 참조자만 포함해야 한다.
- 업무연락 모드에서 결재 또는 합의 참여자가 포함된 기존 템플릿은 참조자 목록으로 변환하거나 일부만 적용하지 않는다. 잘못된 템플릿의 적용을 거부하고 사용자가 알 수 있는 안내를 표시한다.
- 서버 저장 데이터 구조와 기존 템플릿 API는 변경하지 않는다.

### 반응형 배치

- 넓은 화면에서는 버튼을 참조 입력 영역 오른쪽에 배치한다.
- 좁은 화면에서는 입력을 압축하지 않도록 버튼을 다음 줄로 배치할 수 있게 구성한다.
- 모달과 입력 영역은 375px, 768px, 1280px 화면에서 잘림이나 의도하지 않은 가로 스크롤 없이 사용할 수 있어야 한다.

## 접근 방식과 선택 이유

1. **기존 모달에 참조자 전용 모드를 추가 (선택):** 템플릿 관리와 적용/취소 흐름을 재사용하면서 업무연락에서 불필요한 결재 UI를 감춘다.
2. **별도 팝오버/드롭다운 구현:** 진입은 간결하지만 템플릿 관리 및 오류 상태를 별도 구현하게 되어 기존 흐름과 중복된다.
3. **결재선 설정 모달을 그대로 재사용:** 개발 변경은 작지만 참조자만 필요한 업무연락 화면에서 결재선 편집이 가능한 것처럼 보인다.

## 검증 기준

- 업무연락의 참조 필드 옆 버튼으로 참조자 모드가 열린다.
- 참조자 모드에서 결재/합의 단계 편집 UI가 표시되지 않는다.
- 저장, 목록, 적용, 이름 변경, 삭제가 문서 코드 `008`의 기존 사용자별 템플릿 계약을 사용한다.
- 유효한 참조 전용 템플릿은 적용할 수 있고, 결재/합의가 섞인 템플릿은 부분 적용 없이 명시적으로 거부한다.
- 모달 `적용` 전까지 작성 화면 참조자는 변하지 않으며, 취소/닫기 시 기존 참조자를 유지한다.
- 기안서의 결재선 설정 및 기존 자주 쓰는 결재선 기능에 회귀가 없다.
- 375px, 768px, 1280px 실제 브라우저 화면에서 버튼, 입력, 모달이 겹치거나 잘리지 않는다.

## 범위 제외

- 새 템플릿 API 또는 데이터베이스 스키마 추가
- 조직 공용 또는 타 사용자 템플릿 공유
- 참조자 모드 외 기안서 결재선 설정 UI/흐름 변경
- 기존 잘못된 템플릿을 자동 수정하거나 자동 변환
