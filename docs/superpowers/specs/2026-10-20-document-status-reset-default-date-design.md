# 문서현황 초기화 시 결재신청일 기본값 복원 설계

## 목적

문서현황에서 검색조건을 초기화할 때 결재신청일을 비우지 않고, 최초 진입과 같은 최근 1개월 기본 기간으로 복원한다.

## 승인된 동작

- 초기화 시 빠른 검색어와 결재신청일 외 상세검색 조건을 비운다.
- 결재신청일은 초기화 시점 기준 최근 1개월부터 오늘까지의 기본 범위로 설정한다.
- 이 조건을 즉시 적용해 목록을 다시 조회한다.
- 세션에는 빈 검색어, 기본 결재신청일 범위, 비어 있는 나머지 상세조건을 저장한다. 페이지 재진입 시에도 같은 기본 날짜 범위가 복원된다.
- 최초 방문의 날짜 기본값과 검색조건 초기화 동작은 동일한 기본 범위 계산 규칙을 사용한다.

## 구현 범위

- 문서현황의 초기화 상태 계산 및 적용
- 초기화 직후 UI/API 조회조건 및 재진입 세션 복원 회귀 테스트
- 문서현황 작업지시서, 상세사양서, F1-Grid 문서 및 결과 문서 갱신
- 백엔드, API, DB 변경 없음

## 검증 기준

- 초기화 후 결재신청일 입력에 최근 1개월 기본 범위가 표시된다.
- 초기화 직후 API 목록 요청에도 해당 기본 날짜 범위가 포함된다.
- 다른 검색조건과 빠른 검색어는 제거된다.
- 초기화 후 페이지를 나갔다 다시 열어도 기본 결재신청일 범위가 유지되고 같은 조건으로 조회된다.
- 새 세션 최초 진입의 기존 날짜 기본값 동작에 회귀가 없다.
