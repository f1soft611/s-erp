# 공지 작성 모달 다크 입력면 대비 설계

## 문제

공지 작성 모달의 다크 테마에서 구분과 제목 입력면이 본문 편집 영역과 같은 `#0f172a`를 사용해 입력 필드의 경계가 약하다. 라이트 테마에서는 입력면이 흰색이고 주변 본문 배경은 별도 색상이라 구분이 더 뚜렷하다.

## 대안

1. 다크 테마에서 구분·제목 입력면만 `#1e293b`로 밝힌다. 본문 편집 영역과 라이트 테마는 유지한다.
2. 배경색은 유지하고 구분·제목 필드에 테두리만 추가한다. 기존 모달의 무테두리 입력 스타일과 달라질 수 있다.
3. 편집기와 첨부 영역을 포함해 모든 입력 표면을 함께 밝힌다. 요청 범위를 넘어 다른 편집 표면의 대비도 바뀐다.

## 승인 설계

대안 1을 적용한다. `NoticeComposerDialog`에 구분·제목 필드 전용 배경색을 두고, 다크 테마에서는 공통 모달 셸의 슬레이트 표면색 `#1e293b`를 사용한다. 라이트 테마는 현재 흰색을 유지하며, 본문 편집기와 첨부 등 다른 입력 표면은 변경하지 않는다.

## 검증 기준

- 다크 테마에서 구분 및 제목 입력면 배경은 `#1e293b`이고 본문 입력면은 기존 `#0f172a`를 유지한다.
- 라이트 테마의 구분·제목 입력면은 기존 흰색을 유지한다.
- 기존 공지 모달 테마 테스트와 프론트엔드 빌드가 통과한다.
- 브라우저에서 다크 모달을 확인해 두 필드가 주변 편집기보다 은은하게 구분되는지 검증한다.

## 제외 범위

- 모달 레이아웃, 테두리, 타이포그래피, 저장 동작 및 API 변경
- 본문 편집기와 첨부 영역의 배경색 변경
