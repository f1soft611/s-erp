# 문서작성 합의 행 라벨 정렬 및 배경 제거 설계

## 상태

승인됨 — 2026-10-07

## 목적

문서작성 모달에서 합의자를 선택한 뒤 표시되는 합의 행의 라벨을 칩 묶음 세로 가운데에 맞추고, 합의자 표시의 배경색을 제거한다.

## 설계

- `DocumentApprovalFields`의 합의 표시 행에만 `alignItems: 'center'`를 적용한다. `참조` 라벨과 입력 행의 기존 가운데 정렬을 기준으로 하되 다른 행의 정렬은 바꾸지 않는다.
- 합의자 칩에서 테마별 `bgcolor` 지정을 제거한다. 기존 테두리, 모서리, 간격, 텍스트 색상, 크기 및 삭제 동작은 유지한다.
- 합의 표시 행의 표시 조건, 전역 순번, 이름 말줄임, 접근성 레이블, 후보 선택/삭제 동작은 변경하지 않는다.

## 대안

1. **합의 행에 한정해 정렬 및 배경만 조정 (선택):** 요구사항에 직접 대응하고 나머지 행과 칩 스타일을 유지한다.
2. 모든 라벨 행의 기본 정렬을 가운데로 변경: 다른 행까지 영향이 퍼질 수 있어 제외한다.
3. 합의 칩의 테두리와 모서리 등 전체 장식을 함께 제거: 요청하지 않은 스타일 변경이므로 제외한다.

## 검증 기준

- 합의 참여자가 있을 때 `합의` 라벨이 합의자 표시 목록의 세로 가운데에 정렬된다.
- 합의자 표시에는 테마별 회색 배경색이 적용되지 않는다.
- 합의 칩의 기존 테두리/모서리/간격과 참여자 선택, 삭제, 순번 표시가 유지된다.
- 합의 참여자가 없는 상태와 `참조` 행의 표시 동작은 바뀌지 않는다.
- 관련 자동 검증과 브라우저에서 데스크톱 및 좁은 화면 레이아웃을 확인한다.
