# S-ERP 메뉴 즐겨찾기 설계

## 목표

사용자가 자주 사용하는 권한 메뉴를 즐겨찾기에 저장하고, 루트 또는 사용자가 만든 폴더에서 다시 빠르게 열 수 있게 한다. 즐겨찾기 저장소는 개인별로 분리하며, 기존 모듈·권한 메뉴와 최근 사용 메뉴의 의미 및 동작은 유지한다.

## 현재 구조와 근거

- 대시보드는 로그인 사용자의 메뉴를 `GET /api/v1/menus/my`에서 조회하고, 프런트엔드 `buildModuleDescriptors`가 모듈과 메뉴 트리를 구성한다.
- 메뉴 응답은 `menuId`, 이름, 경로, 권한 및 자식 메뉴를 제공한다. 현재 사용자에게 허용된 메뉴만 메뉴 트리에 노출된다.
- 좌측 모듈 레일은 DB 모듈에서 만들어지며, 선택한 모듈의 트리와 최근 사용 메뉴는 사이드바 메뉴 패널에 표시된다.
- 최근 사용 메뉴는 `sessionStorage`에 유지되는 임시 빠른 이동 기록이며, 사용자가 폴더와 항목을 관리하는 즐겨찾기와 별도다.
- 현재 DB의 `tb_menu`는 메뉴 ID, tenant, module, 상위 메뉴, URL, 사용 여부 등의 필드를 갖는다. 사용자 즐겨찾기·폴더 테이블은 현재 테이블 목록에 없다.
- `tb_user`는 테넌트별 사용자 식별자를 제공한다. 개인 즐겨찾기는 인증된 사용자와 tenant를 기준으로 분리해야 한다.

## 승인된 범위

### 포함

- 사용자별 즐겨찾기 폴더와 메뉴 바로가기 저장
- 루트와 1단계 폴더에 메뉴 배치
- 일반 모듈의 leaf 메뉴에서 즐겨찾기 추가 및 폴더 지정
- 즐겨찾기 가상 모듈과 루트/폴더/메뉴 트리
- 컨텍스트 메뉴를 통한 폴더 생성·이름 변경·삭제, 메뉴 이동·즐겨찾기 해제
- 마우스 우클릭 외에 터치/키보드 사용자를 위한 동일 기능의 더보기 액션
- 인증·tenant·메뉴 권한 검증, DB migration 및 날짜별 변경/롤백 문서
- 자동화 테스트, 반응형 브라우저 검증 및 결과 스크린샷

### 제외

- 실제 `tb_module` 행 생성 및 일반 모듈 권한 체계 변경
- 같은 메뉴를 여러 위치에 중복 등록하는 동작
- 중첩 폴더, 드래그 정렬, 공유 즐겨찾기
- 즐겨찾기 전용 관리 페이지
- 기존 최근 사용 메뉴 기능 대체

## 사용자 흐름

1. 일반 모듈의 이동 가능한 leaf 메뉴에서 컨텍스트 메뉴를 열어 루트 또는 폴더를 지정하고 즐겨찾기에 추가한다.
2. 사용자는 좌측 모듈 레일의 즐겨찾기 버튼을 선택해 저장된 루트/폴더/메뉴 트리를 본다. 즐겨찾기 메뉴가 하나 이상 있을 때만 이 가상 모듈을 표시한다.
3. 메뉴를 선택하면 원래 메뉴 URL로 이동하고, 기존 대시보드 라우팅과 선택 표시를 따른다.
4. 즐겨찾기 루트/폴더/메뉴 항목의 컨텍스트 메뉴에서 폴더와 항목을 관리한다. 포인터 우클릭 및 더보기 버튼은 같은 작업을 제공한다.
5. 메뉴를 루트나 다른 폴더로 옮기면 기존 위치의 즐겨찾기를 이동하며 복제하지 않는다.
6. 마지막 즐겨찾기 메뉴를 해제해 메뉴가 0개가 되면 가상 모듈 버튼을 숨긴다. 저장된 폴더는 유지한다. 이후 일반 메뉴에서 즐겨찾기 위치 선택/관리 창을 열어 폴더를 다시 사용하거나 관리할 수 있다.

## 데이터 및 권한 원칙

- 저장 단위는 인증 사용자 및 tenant다. 클라이언트가 보낸 사용자 ID나 tenant ID를 신뢰하지 않는다.
- 메뉴 바로가기는 안정적인 `tb_menu.menu_id`를 참조하고 경로/메뉴명은 권한 메뉴 트리의 현재 데이터를 사용한다. 링크 URL이나 메뉴명을 즐겨찾기 저장소에서 권한 우회용으로 신뢰하지 않는다.
- 메뉴 하나는 루트 또는 한 폴더에만 등록한다. 서버/DB에서 사용자·tenant·menu 기준 중복을 막는다.
- 폴더는 사용자별 1단계 구조로 관리하고 메뉴 바로가기를 자식으로 둘 수 있다. 이름은 양 끝 공백을 제거한 뒤 1~40자로 제한한다.
- 폴더 삭제는 비어 있을 때만 허용한다. 항목이 들어 있는 폴더는 먼저 메뉴를 이동하거나 해제해야 삭제할 수 있다.
- 추가/이동 시 메뉴가 현재 tenant에 속하고 활성 상태이며 사용자가 조회할 권한을 가진 leaf인지 서버가 다시 확인한다.
- 메뉴가 비활성화되거나 사용자 권한에서 빠진 경우 즐겨찾기 응답과 이동 대상에서 숨기되 저장 레코드는 자동 삭제하지 않는다. 권한이 회복되면 다시 나타난다.
- 실제 테이블/컬럼/FK/인덱스와 엔드포인트는 날짜별 상세 사양에서 기존 인증, MyBatis 및 DB metadata에 맞춰 확정한다. 실제 DB에는 읽기 전용 MCP 조회 외 변경을 수행하지 않는다.

## 화면 및 상호작용

### 가상 즐겨찾기 모듈

- 실제 모듈 목록과 별개의 프런트엔드 가상 항목이다. `tb_module`의 관리·권한·정렬 데이터에는 포함하지 않는다.
- 즐겨찾기 메뉴가 하나 이상일 때 일반 모듈 레일에 표시한다. 즐겨찾기 데이터 로딩 중이나 조회 실패 시 가상 모듈을 성공 상태처럼 추정해 노출하지 않는다.
- 선택하면 메뉴 패널이 루트, 폴더 및 접근 가능한 메뉴 항목을 계층형으로 표시한다.
- 기존 모듈 메뉴의 현재 경로 선택, breadcrumb, 권한 및 페이지 이동 로직을 재사용한다.
- 기존 최근 사용 목록은 별도 영역에 그대로 둔다.

### 컨텍스트 메뉴

- 일반 모듈의 leaf 메뉴: 즐겨찾기 추가, 저장 위치(루트/폴더) 지정.
- 일반 메뉴의 즐겨찾기 위치 선택 창: 루트/폴더 지정, 폴더 생성, 빈 폴더 이름 변경/삭제. 즐겨찾기 메뉴가 0개여서 가상 모듈이 숨겨져도 저장된 폴더를 관리할 수 있게 한다.
- 즐겨찾기 루트: 새 폴더 생성.
- 폴더: 이름 변경, 빈 폴더 삭제, 메뉴 이동.
- 즐겨찾기 메뉴: 원래 메뉴 열기, 루트/다른 폴더로 이동, 즐겨찾기 해제.
- 일반 모듈 그룹 노드, URL이 없는 노드 및 권한 없는 메뉴에는 추가 동작을 제공하지 않는다.
- 브라우저 기본 컨텍스트 메뉴를 막는 경우에도 같은 항목의 접근 가능한 더보기 버튼과 키보드 접근 경로를 제공한다.
- 이동/해제/삭제 실패 시 서버 응답을 사용자에게 알리고, 낙관적 화면 변경이 있었다면 이전 상태로 복원한다.
- 폴더명 오류, 빈 폴더 삭제 제한, 조회 실패, 빈 즐겨찾기 상태를 구분해 안내한다.

## 대안과 선택

1. **사용자별 DB 저장 + 즐겨찾기 가상 모듈 — 선택.** 여러 기기/세션에서 개인 구성을 유지하며 기존 실제 모듈 및 역할 권한을 변경하지 않는다. DB/API 변경은 필요하다.
2. **브라우저 localStorage/sessionStorage.** 서버 변경은 없지만 기기별로 구성이 갈리고, 권한 확인 및 계정 전환 시 데이터 정합성을 보장하기 어렵다.
3. **실제 `tb_module`에 즐겨찾기 모듈 추가.** 기존 모듈·메뉴 관리와 역할 권한 구조를 오염시키고 개인별 폴더/메뉴 구조와 맞지 않아 선택하지 않는다.

## 검증 기준

- 즐겨찾기가 하나도 없을 때 가상 모듈이 보이지 않고, 첫 메뉴 저장 후 나타난다.
- 메뉴 중복 등록은 거부되며 루트/폴더 간 이동 후에도 항목은 한 위치에만 존재한다.
- 폴더 생성/이름 변경/빈 폴더 삭제 및 내용이 있는 폴더 삭제 제한이 정상 동작한다.
- 다른 tenant, 비활성 메뉴, 권한 없는 메뉴, 그룹 메뉴 및 URL 없는 메뉴의 추가/이동이 거부된다.
- 권한 제거 시 해당 바로가기는 숨겨지고, 권한 복구 후 다시 나타난다.
- 실제 메뉴 이동은 기존 경로 및 메뉴 선택 상태와 일치한다.
- 우클릭 메뉴와 터치/키보드 더보기 액션이 같은 기능을 제공한다.
- 375px, 768px, 1280px 브라우저 화면에서 메뉴와 컨텍스트 메뉴가 잘리거나 가로 넘침을 만들지 않는다.
- API/DB 변경 테스트, 프런트엔드 테스트와 빌드, 브라우저 스크린샷 및 결과 문서가 제공된다.

## 다음 단계

사용자는 위 설계를 승인했다. 다음 순서로 진행한다.

1. `docs/directions/20261102`에 날짜별 작업지시서를 작성한다.
2. 작업지시서를 바탕으로 `docs/plan/20261102`에 계획서를 작성한다.
3. 계획서를 바탕으로 `docs/spec/20261102`에 상세 사양서를 작성한다.
4. 문서 간 범위와 계약을 자체 검토하고 사용자에게 문서 검토를 요청한다.
5. 사용자의 문서 검토 후 승인된 사양으로 구현 계획과 코드를 진행한다.
