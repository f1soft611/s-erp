# 자주 쓰는 결재선 행 액션 정렬 설계

## 목적

문서작성 페이지의 자주 쓰는 결재선 관리 팝업에서 각 행의 `적용`/`삭제` 버튼 그룹이 액션 열 중앙에 오도록 정렬한다.

## 검토한 접근

1. 해당 팝업의 버튼 그룹 컨테이너가 액션 셀 전체 폭을 사용하고 내부 버튼을 중앙 정렬한다.
2. 액션 열 폭을 늘려 버튼 그룹을 왼쪽으로 이동한다.
3. 공통 F1-Grid의 셀 렌더링 정렬을 변경한다.

첫 번째 방법을 선택한다. 팝업 한 곳에만 적용되어 영향 범위가 작고, 열 너비와 기존 버튼 배치·동작을 보존하면서 중앙 정렬을 명시할 수 있다. 두 번째 방법은 불필요하게 표 공간을 사용하고, 세 번째 방법은 다른 화면까지 영향을 준다.

## 동작 및 범위

- 자주 쓰는 결재선 관리 팝업 행의 `적용`/`삭제` 버튼만 중앙 배치한다.
- 기존 액션 열 너비, 고정 위치, 버튼 순서, 크기, 비활성화와 클릭 동작은 유지한다.
- 공통 F1-Grid 동작, 결재선 데이터, 팝업 하단의 `저장`/`닫기` 버튼은 변경하지 않는다.
- 좁은 화면에서도 버튼이 잘리거나 가로 넘침을 만들지 않도록 브라우저에서 확인한다.

## 검증

- 설정 다이얼로그의 관련 테스트를 실행하고 액션 버튼 역할과 동작이 유지되는지 확인한다.
- 실제 브라우저에서 액션 그룹이 액션 셀 가운데에 표시되는지 확인한다.
- 프론트엔드 빌드 및 `git diff --check`를 실행한다.
