# 자주 쓰는 결재선 행 액션 정렬 설계

## 목적

문서작성 페이지의 자주 쓰는 결재선 관리 팝업에서 각 행의 `적용`/`삭제` 버튼 그룹이 액션 열 중앙에 오도록 정렬한다.

## 원인 및 확인

액션 셀은 이미 가운데 정렬되어 있지만 MUI 버튼의 기본 최소 너비가 각각 64px이므로 버튼 두 개가 차지하는 128px이 액션 열 너비 110px보다 크다. 실제 브라우저에서 기본 버튼 그룹이 셀 밖으로 넘치는 것을 확인했다. 따라서 그룹 컨테이너만 중앙 정렬하는 것으로는 버튼이 셀 안에 모여 보이지 않는다.

## 검토한 접근

1. 기존 액션 열 폭을 유지하고 버튼별 최소 너비와 좌우 패딩을 줄인 뒤 버튼 그룹을 셀 중앙에 배치한다.
2. 기본 버튼 크기를 유지하도록 액션 열 폭을 늘린다.
3. 공통 F1-Grid의 셀 렌더링 정렬을 변경한다.

첫 번째 방법을 선택한다. 팝업 한 곳에만 적용되어 영향 범위가 작고, 110px 열 안에 버튼을 정돈해 배치할 수 있다. 두 번째 방법은 표 공간을 추가로 사용하고, 세 번째 방법은 다른 화면까지 영향을 준다.

## 동작 및 범위

- 자주 쓰는 결재선 관리 팝업 행의 `적용`/`삭제` 버튼만 중앙 배치한다.
- 각 버튼의 MUI 기본 최소 너비를 해제하고 좌우 패딩을 줄인다. 버튼 높이, 순서, 색상, 비활성화와 클릭 동작은 유지한다.
- 액션 열 너비 110px 및 우측 고정 상태를 유지한다.
- 공통 F1-Grid 동작, 결재선 데이터, 팝업 하단의 `저장`/`닫기` 버튼은 변경하지 않는다.
- 좁은 화면에서도 버튼이 잘리거나 가로 넘침을 만들지 않도록 브라우저에서 확인한다.

## 검증

- 설정 다이얼로그의 관련 테스트에서 버튼 너비/좌우 패딩 및 그룹 중앙 정렬을 확인하고 액션 버튼 동작이 유지되는지 확인한다.
- 실제 브라우저에서 두 버튼이 액션 셀 안에 들어오고 그룹이 셀 가운데에 표시되는지 확인한다.
- 프론트엔드 빌드 및 `git diff --check`를 실행한다.
