# 문서 결재선 순번 배지 통일 설계

## 목표

문서 작성 모달과 문서 상세 결재선에서 결재 및 합의 단계 순번을 같은 크기와 정렬로 표시한다. 사용자가 확인한 기준은 24px 원형 테두리 배지이며, 숫자는 배지 중앙에 놓인다.

## 승인된 표시 규칙

- 상세 화면의 승인 순번과 합의 단계 순번 배지를 모두 24px 원형으로 통일한다.
- 작성 모달의 결재자 순번과 합의자 순번도 같은 24px 원형 테두리 배지를 사용한다.
- 숫자는 배지 안에서 가로·세로 가운데 정렬한다.
- 작성 모달 결재자 카드 하단은 순번 배지와 이름을 한 묶음으로 가운데 정렬한다. 합의자 칩의 기존 항목 배치는 유지한다.
- 작성 모달의 순번은 기존 단계 번호를 사용한다. 상세 화면의 합의 단계별 묶음 및 승인 참여자 표시 구조도 변경하지 않는다.

## 구현 접근

배지 UI를 결재선 기능의 공통 컴포넌트로 추출해 상세 화면과 작성 화면에서 재사용한다. 현재 구현은 작성 모달의 번호가 15px 채움 원형이고 상세 화면에서는 승인 번호가 24px, 합의 단계 번호가 28px 원형 테두리로 각각 달라 공통 컴포넌트로 정리해야 표시 규칙의 재분기를 막을 수 있다.

각 화면에 같은 스타일을 별도로 복사하는 방식도 가능하지만 이후 화면별 수정으로 다시 불일치할 수 있다. 승인자는 기존 상세 승인 배지 크기인 24px을 기준으로 선택했고, 합의 배지도 같은 크기로 맞춘다.

## 변경 범위

- 공통 순번 배지 컴포넌트 추가
- 작성 모달 결재·합의 순번 표시 및 결재자 하단 정렬
- 상세 화면 결재·합의 순번 표시
- 작성/상세 결재선 표현에 대한 직접 관련 테스트와 문서

순번 산정, 합의 그룹 정책, 결재 처리, API, DB 및 그 밖의 상세 화면 동작은 변경하지 않는다. 기존 상세 결재선 파일의 작업 중인 변경은 보존한다.

## 검증

- 회귀 테스트에서 작성 화면 결재·합의 배지의 지름과 중앙 배치, 결재자 순번/이름 그룹의 중앙 정렬을 확인한다.
- 상세 화면에서 승인 및 합의 단계 배지의 공통 크기와 중앙 정렬을 확인한다.
- 관련 `document-write-page.test.tsx` 테스트 및 프론트엔드 빌드를 실행한다.
- 실제 브라우저에서 375px, 768px, 1280px 화면의 모달 및 상세 결재선을 확인하고 의도하지 않은 가로 넘침이 없는지 검증한다.
- 결과 문서는 `docs/result/20261015/document-approval-sequence-badge/`에 저장하며 개인정보가 드러나지 않는 화면 캡처를 사용한다.
