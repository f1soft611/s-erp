# 전자결재 합의·참조 부서명 누락 시 정렬 설계

## 목적

전자결재 상세에서 합의자 또는 참조자의 부서명이 없을 때 카드 내용이 위쪽으로 치우치지 않도록 한다. 부서 정보가 있는 기존 카드 배치와 결재 처리 동작은 유지한다.

## 범위

- 대상 화면: 전자결재 상세 결재선의 합의자 및 참조 카드
- 대상 필드: `participantDepartmentName`
- 변경 대상: 상세 결재선 UI와 해당 UI 회귀 테스트, 관련 작업 결과 문서
- 제외: 백엔드/API/데이터 변경, 카드의 너비·순서·반응형 흐름, 승인 상태 및 댓글 기능

## 표시 규칙

- 부서명이 유효한 문자열이면 기존 프로필·이름 첫 행과 부서·상태(합의) 또는 부서(참조) 둘째 행을 유지한다.
- 부서명이 `null`, 빈 문자열 또는 공백만 있는 문자열이면 부서 행을 표시하지 않는다.
- 부서명이 없는 합의 카드는 프로필·이름·상태를 한 줄에 표시하고, 해당 내용 행을 카드 높이의 세로 중앙에 정렬한다.
- 부서명이 없는 참조 카드는 프로필·이름을 한 줄에 표시하고, 해당 내용 행을 카드 높이의 세로 중앙에 정렬한다.
- 이름은 기존 말줄임 규칙과 접근성 이름을 유지하고, 상태 텍스트·배지와 프로필 대체 이미지는 계속 표시한다.
- 유효한 부서명이 있는 경우의 레이아웃과 모든 데이터 계약 및 결재 동작은 변경하지 않는다.

## 구현 및 검증

- 기존 테스트 파일에서 합의와 참조 각각 부서명이 없는 참여자를 fixture로 추가한다.
- 회귀 테스트에서 부서 행 비표시, 카드의 단일 콘텐츠 행 및 세로 중앙 정렬 스타일을 확인한다. 기존 부서명이 있는 카드 테스트도 그대로 통과해야 한다.
- 구현은 `DocumentApprovalDetailFeed.tsx`의 카드 렌더링에 한정한다.
- `document-write-page.test.tsx` 관련 테스트를 실행하고, `frontend` build 및 실제 브라우저에서 기존 375px·768px·1280px viewport에 대해 확인한다.
- 변경 결과를 `docs/result/20261014/approval-line-detail-refinement/`의 결과 문서에 추가한다.
