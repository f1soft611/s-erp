# 수주등록 기본정보 레이아웃 개선 설계

## 배경

현재 수주등록 화면의 기본정보 입력은 하나의 그리드로 구성되어 있어
거래처 선택 버튼과 입력 필드의 높이가 맞지 않고, 필드가 행 단위로 정돈되어
보이지 않는다. 사용자는 기본정보 필드의 배치/정렬을 가장 큰 문제로
지적했으며, 기존 카드 안에서 정렬을 개선하는 B안을 선택했다.

## 설계

- `수주 기본정보` 카드와 기존 필드 및 필드 순서를 유지한다.
- 데스크톱 첫 행은 수주번호, 수주일자, 거래처, 견적번호로 구성한다.
- 두 번째 행은 납기일자, 납품장소, 배송방법, 수주상태로 구성한다.
- 비고는 카드 전체 너비를 사용한다.
- 화면 폭이 줄어들면 기존 반응형 패턴에 따라 열 수를 줄여 375px, 768px,
  1280px에서 입력 요소가 겹치거나 잘리지 않도록 한다.
- 거래처 선택 버튼은 입력 필드에 인접한 picker 버튼만 대상으로 하며, 높이를
  입력 필드와 동일하게 맞춘다.
- 저장, 계산, picker 데이터, 상세 그리드 등 페이지 동작은 변경하지 않는다.

## 범위 및 검증

변경은 수주등록 화면의 프론트엔드 레이아웃에 한정한다. 기존 수주등록
페이지 테스트와 프론트엔드 빌드를 실행하고, 375px/768px/1280px 실제
브라우저에서 확인한다. 결과 문서에 수정 내용과 각 뷰포트 스크린샷을
기록한다.
