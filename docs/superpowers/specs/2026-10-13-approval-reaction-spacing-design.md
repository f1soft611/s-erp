# 전자결재 상세 반응 영역 간격 정합화 설계

## 문제

전자결재 상세의 첨부·반응·댓글은 `Stack spacing={2}`의 직접 자식으로 각각 렌더링된다. 이 때문에 반응바 위와 아래에 16px 간격이 각각 들어가 공지사항의 상세 피드와 간격이 달라진다.

## 결정

전자결재 상세에서 첨부, 첨부 뒤 구분선, 반응바, 댓글 섹션을 하나의 자식 영역으로 묶어 외부 Stack이 영역 내부 항목 사이에 간격을 삽입하지 않게 한다. 첨부/반응 구분선의 상·하 여백은 공지사항과 같은 `my: 1.5`로 맞춘다. 내부 항목 순서와 기존 구분선 정책은 유지한다. 특히 첨부가 있으면 첨부와 반응바 사이 구분선을 유지하고, 반응바와 댓글 사이에는 구분선을 두지 않는다.

공지사항의 기존 레이아웃·간격과 대조하는 회귀 검증을 추가하고, 전자결재 상세의 DOM에서 그룹 내부 자식에 Stack 간격이 생기지 않는지 확인한다.

## 범위

- `DocumentApprovalDetailFeed`의 첨부·반응·댓글 영역 레이아웃 및 관련 테스트
- 날짜별 상세 사양·작업 계획·결과 문서의 해당 동작 설명 갱신
- API, 데이터, 결재선, 댓글 동작과 전체 상세 화면의 다른 섹션 간격은 변경하지 않음
