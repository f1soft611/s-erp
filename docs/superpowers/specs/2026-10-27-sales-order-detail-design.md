# 수주현황 상세 패널 디자인 사양

## 승인된 방향

수주번호를 클릭해 여는 기존 상세 패널의 데이터와 동작은 유지하면서, 메인정보와 수주 품목 테이블의 정보 위계 및 가독성을 개선한다. 선택한 방향은 **요약 헤더 + 그룹형 기본정보 + 정돈된 품목 표**다.

## 목표와 범위

- 상태, 거래처, 총액 등 수주의 핵심 정보를 패널 상단에서 빠르게 파악할 수 있게 한다.
- 기본정보를 성격별 그룹과 반응형 그리드로 정돈한다.
- 품목 코드·명, 수량·금액, 납기·행상태를 구별하기 쉬운 표로 만든다.
- 기존 필드, 조회 API, 권한, 편집/상세보기 메뉴, 패널 열기·닫기 동작은 변경하지 않는다.
- 새 데이터, 계산 규칙, 메뉴, 화면 흐름은 추가하지 않는다.

## 화면 구성

### 1. 작성자와 액션

작성자 아바타·이름·등록일, 현재 수주 상태, 더보기 메뉴를 기존 위치와 기능대로 유지한다. 좁은 화면에서는 콘텐츠가 겹치지 않도록 줄바꿈을 허용한다.

### 2. 핵심 요약 헤더

작성자 영역 아래에 강조된 요약 영역을 둔다.

- 수주번호는 기존 패널 부제목, 수주상태는 기존 상태 Chip으로 식별한다. 새 요약 영역에 같은 값을 중복 표시하지 않는다.
- 거래처명을 주요 텍스트로 두고, 수주일자와 납기일자를 보조 정보로 표시한다.
- 총 합계를 요약 영역에서 가장 눈에 띄는 수치로 표시한다.
- 거래처·날짜·합계 값은 현재 `SalesOrderItem` 응답에 있는 필드만 사용한다.

### 3. 수주 기본정보

기본정보는 하나의 평면 박스에서 다음 두 그룹으로 재배치한다.

- **수주 정보:** 견적번호, 배송방법
- **납품 정보:** 납품장소, 비고

각 항목은 라벨과 값을 분리하고 값의 줄바꿈을 허용한다. 거래처와 날짜는 요약 영역에, 총 합계는 요약 영역에, 품목 수는 품목 섹션 제목에 한 번만 표시한다. 납품장소처럼 긴 값은 그리드에서 더 넓은 공간을 사용한다. 값이 비어 있으면 기존처럼 `-`로 표시한다.

### 4. 수주 품목 표

- 섹션 제목에 품목 건수를 표시한다.
- 품목명은 주요 텍스트, 품목코드는 보조 텍스트로 표현해 식별 우선순위를 명확히 한다.
- 수량·단가·합계는 우측 정렬하고 숫자 자릿수와 기존 `ko-KR` 포맷을 유지한다.
- 헤더 대비, 행 구분, 셀 여백을 개선하되 기존 행 순서와 전체 필드(행, 품목코드, 품목명, 수량, 단가, 합계, 납기, 행상태)는 유지한다.
- 합계 열은 읽기 쉽게 강조하되 오류/성공 상태를 오인하게 하는 색 사용은 피한다.
- 데이터가 없을 때는 기존 데이터 계약을 바꾸지 않고 빈 목록을 명확히 표시한다.

## 반응형 및 접근성

- 1280px 이상에서는 요약 정보와 기본정보를 넓게 배치하고 표를 한 화면에서 비교하기 쉽게 한다.
- 768px에서는 기본정보 열 수와 요약 요소의 줄바꿈을 조정한다.
- 375px에서는 기본정보를 좁은 그리드로 재배치하고, 넓은 품목 표만 내부 가로 스크롤을 사용한다. 패널이나 페이지 전체 가로 넘침은 허용하지 않는다.
- 현재의 패널 이름, 닫기 접근성 이름, 로딩 상태, 표 접근성 이름을 보존한다. 상태나 값의 의미를 색만으로 전달하지 않는다.
- 기존 테마 토큰과 Material UI 패턴을 사용하며 전역 스타일이나 공통 패널 디자인은 변경하지 않는다.

## 데이터·동작·오류 처리

- 변경 대상은 수주현황의 `SalesOrderStatusDetailPanel` 시각 구조와 이에 필요한 기존 스타일 범위로 제한한다.
- API, 타입, 필드 의미, 상세/수정 권한 및 액션은 변경하지 않는다.
- 로딩 문구, 오류 Alert, 닫기 동작, 더보기 액션은 현재대로 유지한다.

## 검증 기준

- 상세 패널에서 핵심 요약, 두 기본정보 그룹, 품목 건수와 각 열이 기존 데이터로 렌더링된다.
- 긴 거래처/품목명과 빈 선택값이 레이아웃을 깨뜨리지 않는다.
- 375px, 768px, 1280px에서 패널 내부 표 가로 스크롤 외 페이지 전체 가로 넘침이 없다.
- 로딩, 오류, 상세보기, 수정, 닫기 흐름은 기존 동작을 유지한다.
- 변경 후 관련 테스트와 프론트엔드 빌드를 실행하고, 실제 브라우저에서 모바일·데스크톱 화면을 확인한다.

## 범위 밖

- 수주등록 화면, 수주 목록 그리드, API/백엔드, 신규 필드와 비즈니스 규칙
- 품목 행을 카드형으로 바꾸는 대안
- 공통 `PostDetailPanel` 또는 전체 테마의 변경
