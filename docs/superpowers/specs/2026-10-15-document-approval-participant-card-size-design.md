# 전자결재 합의·참조 참여자 카드 크기 통일 설계

## 목표

전자결재 상세 결재선의 합의·참조 사용자 카드를 현재 참조 카드 크기 기준으로 통일한다. 두 카드 모두 이름과 부서를 두 줄로 표시하고, 부서 정보가 비어 있으면 `부서없음`을 표시해 카드 높이와 프로필 이미지 크기가 항상 같게 보이도록 한다.

## 승인된 설계

- 참조 카드의 크기 기준을 합의 카드에도 적용한다.
- 두 카드의 폭 동작은 같은 `flex: 0 1 240px`, `minWidth: min(100%, 190px)`, `maxWidth: 100%` 규칙을 쓴다.
- 프로필 이미지는 두 카드 모두 `36 × 36px`로 표시한다.
- 두 카드의 바깥 높이를 `66px`로 동일하게 고정한다. 이는 참조 카드에 이름·부서 두 줄과 기존 `8px` 내부 여백을 적용한 기준이다.
- 이름은 첫째 줄, 부서는 둘째 줄에 표시한다. 합의 상태 표시는 기존과 같이 유지하고 둘째 줄의 부서 정보 옆에 둔다.
- 부서명 값이 없거나 공백뿐이면 합의·참조 모두 `부서없음`으로 표시한다.
- 작은 화면에서는 기존 결재선 콘텐츠 열 너비에 맞춰 카드가 줄어들고 줄바꿈하되, 화면 전체 가로 넘침을 만들지 않는다.

## 대안 및 선택 근거

- 합의 카드 크기를 참조 카드에 맞추는 선택은 사용자가 요청했다.
- 아바타와 최소 높이만 맞추는 방식은 내용에 따라 카드 높이가 달라질 수 있어 제외한다.
- 합의·참조의 정보 차이를 고려해 카드 렌더링 전체를 공통 컴포넌트로 합치지 않는다. 기하 규칙만 일치시키고 기존 표시 책임을 유지한다.

## 범위와 영향

- 상세 결재선의 합의·참조 참여자 카드 표시와 이에 대한 프론트엔드 회귀 테스트, 날짜별 작업 문서 및 결과 문서를 갱신한다.
- 결재 순서, 상태/처리 동작, 편집 결재선, API, 백엔드 및 DB는 변경하지 않는다.

## 검증 기준

1. 상세 결재선 회귀 테스트에서 합의·참조 카드의 동일한 폭 규칙, `66px` 높이, `36 × 36px` 아바타를 확인한다.
2. 부서가 누락되거나 공백인 합의자와 참조자 모두 `부서없음`을 표시하는지 확인한다.
3. 기존 이름, 부서, 합의 상태, 순서 및 프로필 이미지 대체 표시 회귀 검증을 유지한다.
4. 관련 테스트와 프론트엔드 빌드를 실행하고 `git diff --check`를 확인한다.
5. 실제 브라우저에서 375px, 768px, 1280px 폭으로 카드 줄바꿈, 텍스트 표시, 높이/아바타 정합 및 페이지 전체 가로 넘침을 검증하고 결과 문서에 비식별 스크린샷을 포함한다.
