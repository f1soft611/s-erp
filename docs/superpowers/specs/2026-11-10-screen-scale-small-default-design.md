# 화면 크기 기본값을 작게로 변경

## 목표

화면 크기 설정이 저장되지 않은 경우의 초기 배율을 `보통(1)`에서 `작게(0.9)`로 변경한다.

## 설계

`AppSettingsContext`의 기본 배율 상수만 `0.9`로 바꾼다. 저장된 화면 크기 값의 초기화와 변경 동작은 그대로 두어, 이미 선택한 사용자 설정은 계속 복원한다. 메뉴, 배율 단계, 화면 레이아웃, 테마에는 변경을 가하지 않는다.

## 검증

화면 크기 설정 테스트에서 저장값이 없을 때 `0.9`가 적용되는지, 저장된 값이 있을 때 해당 값이 우선되는지 확인한다. 이후 프론트엔드 테스트와 빌드를 실행한다.
