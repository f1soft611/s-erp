# F1-Grid 문서 사이드 메뉴 아코디언 설계

## 목표

긴 문서 메뉴를 빠르게 훑고 현재 위치를 쉽게 찾을 수 있도록, 기존 기능 그룹형 사이드 메뉴를 단일 열림 아코디언으로 개선한다. 문서 분류, 검색 대상, API 참조, 문서 본문과 우측 목차는 유지한다.

## 동작

- 선택된 문서가 속한 그룹만 펼치고, 다른 그룹은 접는다.
- 현재 문서 그룹은 항상 펼쳐 둔다. 문서 항목을 선택하면 활성 그룹이 해당 문서의 그룹으로 바뀐다.
- 접힌 그룹 제목을 선택하면 해당 그룹의 첫 문서로 이동하고 그 그룹만 펼친다. 현재 그룹 제목을 선택해도 그 그룹의 첫 문서로 이동한다.
- 초기 문서가 `overview`이면 `시작하기` 그룹을 펼친다.
- 검색어가 있을 때는 검색 결과가 있는 모든 그룹을 표시하고, 일치 문서를 결과에서 숨기지 않는다. 검색 결과를 선택하면 검색을 지우지 않고 기존 선택 동작을 유지한다.
- 모바일에서도 그룹의 펼침/접힘 규칙을 동일하게 적용한다.
- 검색 결과, API 검색 결과, 메뉴 항목 및 그룹 버튼에는 기존 접근성 레이블과 키보드 상호작용을 보존한다.

## 화면 구성

그룹 제목을 버튼으로 제공하고 펼침 상태를 `aria-expanded`로 노출한다. 그룹 제목 버튼은 그 그룹의 첫 문서로 이동하는 탐색 동작을 수행해 선택 문서와 열린 그룹을 일치시킨다. 펼쳐진 그룹 아래에는 현재 포함 문서만 기존 순서대로 표시한다. 현재 선택된 문서는 기존 활성 표시를 유지한다. 검색 중에는 그룹 버튼 대신 결과가 포함된 그룹명과 매칭 문서 목록을 표시해 필터 결과를 한눈에 비교할 수 있게 한다.

## 영향 범위

프론트엔드 문서 포털의 사이드 메뉴 상태/렌더링, 관련 스타일과 테스트, F1-Grid 문서 포털 설명 및 작업 결과 문서에 한정한다. 기존 라우트, 검색 의미, API 데이터, Playground, 본문/목차, F1-Grid 런타임, 백엔드와 데이터베이스는 변경하지 않는다.

## 검증

- 관련 테스트에서 초기 활성 그룹, 그룹 전환, 현재 그룹 고정 펼침, 검색 중 결과 전체 노출, 기존 검색/API 이동을 확인한다.
- 프론트엔드 빌드를 실행한다.
- 브라우저에서 데스크톱 및 모바일 폭의 그룹 전환, 검색, 현재 문서 표시를 확인한다.
