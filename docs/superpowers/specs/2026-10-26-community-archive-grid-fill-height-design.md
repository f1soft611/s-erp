# 자료실 그리드 잔여 높이 채우기 설계

## 배경

자료실 화면의 페이지와 그리드 영역은 `flex: 1`을 사용하지만, 그리드 영역 컨테이너가 flex 컨테이너가 아니어서 내부 자료실 트리에 부모의 남은 높이가 전달되지 않을 수 있다. 그 결과 그리드가 화면 아래까지 늘어나지 않고 콘텐츠 높이에 머문다.

## 검토한 접근

1. **권장 — 기존 세로 flex 흐름을 그리드 영역까지 연결.** 페이지의 마지막 영역을 세로 flex 컨테이너로 만들어 자료실 트리의 `height="100%"`가 화면의 남은 높이를 사용하게 한다. 반응형 크기 변화에 대응하고 수정 범위가 작다.
2. 뷰포트 높이 기반 `calc()`를 지정한다. 간단하지만 헤더·검색·경로의 실제 높이와 반응형 줄바꿈에 취약하다.
3. 그리드의 `minHeight`를 높인다. 최소 크기만 바꾸므로 다양한 화면 높이를 채우지 못한다.

## 승인된 설계

- 헤더, 검색 영역, 안내 메시지와 폴더 경로는 기존 위치와 동작을 유지한다.
- 마지막 그리드 영역을 세로 flex 컨테이너로 구성해 `ArchiveFileGrid`와 F1Tree가 가용한 잔여 높이를 차지하게 한다.
- 기존 최소 그리드 높이, 로딩/오류/빈 결과 상태, 자료실 검색·파일 동작은 유지한다.
- 현재 워크트리에 이미 있는 자료실 로딩 변경과 통합하며 덮어쓰거나 되돌리지 않는다.
- API, 공통 F1-Grid/F1Tree 구현 및 백엔드는 수정하지 않는다.

## 검증

- 자료실 관련 페이지 테스트와 프런트엔드 빌드를 실행한다.
- 실제 브라우저에서 375px, 768px, 1280px 너비로 헤더·검색·경로 아래 그리드가 남은 화면 높이를 차지하고 가로 넘침이 없는지 확인한다.
- 결과 문서에 변경 원인, 해결 및 브라우저 검증 결과를 기록한다.
