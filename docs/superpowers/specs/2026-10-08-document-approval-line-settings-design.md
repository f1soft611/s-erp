# 문서작성 결재선 설정 설계

## 배경

문서작성 모달의 `합의 추가` 버튼 옆에 `결재선 설정`을 제공한다. 사용자는 작성 중인 결재선과 참조선을 확인하고 순서와 참여자를 변경한 뒤 작성 화면에 적용할 수 있어야 한다. 반복 사용을 위한 결재선 저장/불러오기도 필요하지만, 즐겨찾기 저장 테이블과 명명 규칙이 아직 정해지지 않아 이번 작업에서는 실제 저장을 제공하지 않는다.

현재 문서작성 상태는 `DocumentApprovalStage[]`와 참조 사용자 ID 배열로 관리된다. 기안자 단계는 고정 결재자로 시작하고, 각 결재 단계는 한 명, 합의 단계는 여러 명을 담는 하나의 단계다. 작성 모달을 벗어나 실제 저장/상신하는 API는 아직 없다.

## 접근 방식

1. **별도 설정 창과 임시 편집 상태 (선택)** — 설정 창이 열릴 때 현재 결재선과 참조선을 복사한다. 적용 시에만 작성 상태에 반영하고, 취소/닫기는 원본을 유지한다.
2. 작성 창에서 상태를 즉시 변경 — 별도 편집 창은 없지만 취소를 지원하기 어렵고 수정 도중 변경 사항이 작성 화면에 노출된다.
3. 즐겨찾기 API와 DB를 함께 구현 — 완결된 저장 흐름이 가능하지만 현재 미정인 테이블 계약과 범위를 추측하게 된다.

첫 번째 접근을 사용한다. 즐겨찾기 영속 저장이나 브라우저 로컬 저장을 가장한 임시 동작은 넣지 않는다.

## 사용자 흐름과 동작

1. 작성 모달의 `합의 추가` 옆 `결재선 설정`을 누른다.
2. 설정 창은 작성 중인 결재 단계와 참조자를 불러와 독립된 편집 상태로 보여준다.
3. 기안자 단계를 제외한 결재 및 합의 단계를 드래그하거나 위/아래 이동 액션으로 재정렬한다. 합의자 그룹은 하나의 단계로 이동한다.
4. 결재 참여자는 사용자 추가/삭제로 변경한다. 결재 단계는 사용자 한 명을 유지하고, 합의 단계는 여러 명을 유지한다. 합의 단계의 마지막 사용자를 삭제하면 단계도 제거한다.
5. 참조자는 별도 다중 사용자 선택으로 추가/삭제한다. 현재 문서작성 화면의 결재/참조 중복 제한과 사용자 후보 규칙을 유지한다.
6. `적용`은 편집 중인 결재선과 참조선을 작성 상태에 함께 반영한다. `취소` 또는 닫기는 변경을 폐기한다.

기안자 단계는 설정 창에서도 이동, 교체 또는 삭제할 수 없다. 결재와 합의의 역할 전환은 범위에 포함하지 않는다.

## 즐겨찾기 저장/불러오기

- `자주 쓰는 결재선 저장`과 `자주 쓰는 결재선 불러오기` UI를 제공한다.
- 테이블/API 및 테이블 명명 규칙이 확정될 때까지 두 액션은 비활성화한다.
- 비활성화 이유를 화면에서 확인할 수 있도록 “저장 테이블/API 준비 후 제공” 안내를 표시한다.
- 이번에는 API 엔드포인트, 데이터 모델, DB 테이블/SQL, 로컬 저장, 가짜 저장 성공 상태를 추가하지 않는다.
- 향후 구현은 사용자별 결재선과 참조선 목록의 저장/조회 서비스를 연결하는 변경으로 분리한다. 구체 계약은 해당 스키마 및 API 결정 후 작성한다.

## 상태와 오류 처리

- 설정 창을 열 때 원본 상태를 복사하고 창을 닫을 때 편집 상태를 폐기한다. `적용`에서만 원본 상태를 갱신한다.
- 사용자 후보는 현재 문서작성 모달에서 로드한 사용자 옵션을 재사용한다. 후보 로드가 이미 실패한 상태라면 기존 오류를 표시하고 선택 변경을 진행할 수 없게 한다.
- 현재 기능은 서버 요청을 추가하지 않는다. 적용은 로컬 작성 상태 갱신이므로 네트워크 오류 흐름을 새로 만들지 않는다.
- 편집 상태가 비어 있는 결재/합의 단계를 만들지 않도록 참여자를 추가/삭제할 때 단계를 함께 정규화한다.

## 화면 및 접근성

- 기존 `CommonDialog` 스타일을 따르는 별도 결재선 설정 창을 사용한다.
- 단계 행은 드래그 핸들과 역할/사용자/삭제 액션을 구분해 보여준다.
- 포인터 드래그 외에도 키보드로 사용할 수 있는 위/아래 이동 버튼을 제공한다. 고정 기안자는 이동 버튼을 제공하지 않는다.
- 참조 입력은 결재 단계 편집과 구별되는 영역에 둔다.
- 즐겨찾기 비활성 상태는 버튼의 disabled 표현과 함께 원인을 텍스트로 제공한다.
- 좁은 화면에서는 창 안 콘텐츠가 세로로 흐르고, 페이지 너비를 늘리는 수평 넘침을 만들지 않는다.

## 검증

- 설정 창이 현재 결재선 및 참조자를 정확히 복사해 표시한다.
- 취소/닫기는 변경을 폐기하고, 적용은 결재선과 참조선을 함께 반영한다.
- 기안자는 고정되며 결재/합의 단계는 그룹 단위로 포인터 드래그와 위/아래 버튼 재정렬이 가능하다.
- 결재 사용자 추가/삭제, 합의 사용자 추가/삭제, 빈 합의 단계 정리 및 참조자 변경이 동작한다.
- 즐겨찾기 액션은 비활성화되어 있고 저장을 가장한 상태 변경이 없다.
- 문서작성 관련 테스트 및 프론트엔드 빌드를 수행한다. 브라우저에서 375px, 768px, 1280px 폭의 설정 창 레이아웃을 확인하고 결과 문서에 캡처를 남긴다.

## 범위 제외

- 결재선 즐겨찾기 테이블, SQL 마이그레이션, 서버/API 영속 처리
- 문서 저장, 임시 저장, 상신 및 실제 결재 처리
- 결재/합의 역할 전환
- 기안자 단계 변경
