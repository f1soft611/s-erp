# 전자결재 상세 합의·참조 한 줄 배치 설계

## 목표

전자결재 상세 결재선의 합의·참조 제목을 참여자 목록과 같은 행에 배치하고, 두 영역의 제목 열과 기본 높이를 동일하게 맞춘다. 결재 데이터와 처리 동작은 변경하지 않는다.

## 승인된 레이아웃

- 합의와 참조 각각을 제목 열과 참여자 콘텐츠 열로 이루어진 한 행으로 표시한다.
- 두 제목 열은 동일한 폭을 사용하고, 두 행의 기본 높이를 동일하게 맞춘다.
- 참여자 카드, 표시 정보, 합의 단계 순번, 순서는 기존 상세 결재선 동작을 유지한다.
- 좁은 화면에서는 제목을 고정된 첫 열에 유지하고 참여자 목록은 가용 폭에 따라 줄바꿈한다. 화면 전체에 가로 스크롤을 추가하지 않는다.

## 대안 및 선택 근거

- 제목을 카드 흐름 안의 라벨로 두는 방식은 공간을 덜 쓰지만 줄바꿈 시 제목이 참여자와 함께 이동할 수 있다.
- 사용자는 제목을 고정된 왼쪽 열에 배치하는 방식을 선택했다. 이는 두 영역의 제목 위치와 크기를 일관되게 유지하면서 현재 카드 표현을 보존한다.

## 범위와 영향

- 프론트엔드 상세 결재선의 합의·참조 레이아웃과 관련 회귀 테스트만 변경한다.
- 승인 카드, 결재 순서/상태, 결재 처리, API, 서버, DB는 변경하지 않는다.

## 검증 기준

- 데스크톱에서 제목과 참여자 목록이 한 행에 배치되고 합의·참조 제목 열과 기본 행 높이가 동일하다.
- 좁은 폭에서는 참여자만 줄바꿈하고 제목과 콘텐츠가 겹치거나 잘리지 않는다.
- 375px, 768px, 1280px 브라우저 폭에서 페이지 전체의 불필요한 가로 넘침이 없다.
- 관련 프론트엔드 테스트 및 빌드가 통과한다.
