# 결재상태와 구분선 사이 간격 조정 설계

## 목표

공통 문서 결재 툴바에서 결재상태와 세로 구분선 사이 간격을 현재 8px에서 12px로 넓힌다.

## 승인된 변경

- 현재 간격은 툴바의 기본 열 간격 4px와 상태 Chip의 오른쪽 여백 4px를 합산한 8px다.
- 결재상태 Chip의 오른쪽 여백만 8px로 바꿔 대상 구간을 총 12px로 만든다.
- 기본 열 간격은 그대로 두며 구분선-상단 고정 아이콘, 문서구분 Chip 및 다른 컨트롤의 간격은 바꾸지 않는다.
- 공통 피드/상세 툴바에서 결재상태를 표시하는 기존 컴포넌트 경로에 적용한다.

## 대안 및 선택 근거

- 전체 툴바의 기본 간격을 늘리는 방식은 다른 컨트롤 사이까지 영향을 주므로 제외한다.
- 상태 Chip 여백을 더 크게 설정해 총 16px로 만드는 방식보다, 사용자가 선택한 총 12px가 기존 간격과의 차이를 유지하면서 간결하다.

## 범위와 검증

- 결재상태 Chip의 여백과 그 기대값을 검사하는 기존 회귀 테스트, 관련 상세 사양 및 작업 결과만 갱신한다.
- 툴바 순서, 상태 표시, 권한, 동작, 반응형 배치, API 및 데이터 구조는 변경하지 않는다.
- 관련 툴바 테스트와 문서 결재 상세 테스트를 실행하고 프론트엔드 빌드 및 diff 검사를 수행한다.
