# 문서작성 놓치지 마세요 패널 스타일 보완 설계

## 목적

문서작성 페이지 우측 `놓치지 마세요` 카드에서 알림 유형과 문서 제목이 가운데로 모여 보이는 문제를 개선하고, 공백 없는 긴 제목이 카드 폭을 벗어나지 않도록 한다. 기존 목록과 선택 동작은 유지한다.

## 현재 상태와 원인

`ApprovalNoticePanel`은 MUI `Button` 안에 유형명과 제목을 배치한다. 버튼에 `display: grid`와 `justifyItems: start`를 지정했지만, MUI 버튼의 기본 정렬 규칙이 남아 자식이 가운데로 보인다. 카드 자체의 시각적 계층도 배경색 외에는 약해, 첨부 화면에서 항목들이 평평하고 불균형하게 보인다.

## 승인된 디자인

- 알림 항목의 버튼을 전체 너비 세로 레이아웃으로 구성하고 `alignItems: flex-start`, `justifyContent: flex-start`, `textAlign: left`를 함께 적용해 좌측 정렬을 명시한다.
- 현재 패널과 어울리는 중립 스타일을 유지한다. 옅은 테마 배경, 얇은 구분선, 둥근 모서리, 일관된 내부 여백으로 카드 경계를 정리하며 강한 색상 포인트나 아이콘은 추가하지 않는다.
- 알림 유형은 굵고 선명한 본문 텍스트로, 문서 제목은 보조 텍스트 색상과 읽기 쉬운 행간으로 구분한다.
- 제목에 전체 너비와 `overflow-wrap: anywhere`에 해당하는 스타일을 적용한다. 일반 제목은 자연스럽게 줄바꿈되고 공백 없는 긴 문자열도 카드 안에서 줄바꿈되어 가로 넘침을 만들지 않는다.
- 기존 테마 색상 토큰을 사용하고, 키보드 포커스와 버튼 상호작용이 기존 MUI 동작을 유지하도록 한다.

## 유지 범위와 제외

- 최대 3개 알림 표시, 알림 문구, 항목 클릭 시 선택 동작, 알림이 없는 경우의 안내 문구는 변경하지 않는다.
- API, 데이터 구조, 상태 로직, 다른 우측 패널과 문서작성 화면의 전체 레이아웃은 변경하지 않는다.
- 제목 말줄임, 아이콘 추가, 상태별 강한 컬러 코딩은 적용하지 않는다.

## 구현 및 검증 기준

- 변경은 `ApprovalNoticePanel`의 스타일에 한정한다.
- 짧은 제목 및 공백 없는 긴 제목의 정렬이 모두 왼쪽이고, 텍스트가 카드 너비 안에서 줄바꿈되는지 확인한다.
- 375px, 768px, 1280px 브라우저 폭에서 우측 패널 또는 알림 항목의 의도하지 않은 가로 넘침이 없는지 확인한다.
- 기존 알림 선택 및 빈 상태 테스트를 유지하고, 관련 테스트와 프런트엔드 빌드를 실행한다.
- 회귀 검증 결과와 접근 가능한 브라우저 스크린샷을 날짜별 결과 폴더에 기록한다.
