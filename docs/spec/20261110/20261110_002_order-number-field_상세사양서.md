# 수주번호 필드 표시 사양

근거: [계획서](../../plan/20261110/20261110_002_order-number-field_계획서.md).

- 대상: `SalesOrderCreatePage`의 수주번호 TextField. 해당 폼을 공유하는 조회·수정에도 적용한다.
- 수주번호·견적번호·수주상태는 동일한 공통 글꼴 크기와 입력 외곽 높이를 사용한다. 화면 크기별 수주번호 전용 글꼴 지정은 하지 않는다.
- 수주번호 값, 저장 전 자동 채번 안내, 읽기 전용 속성, 저장과 API 계약은 변경하지 않는다.
- 브라우저에서 세 입력의 computed `fontSize`, `fontFamily`, 외곽 높이(차이 1px 이내)를 375/768/1280px에서 비교한다.
- 합성 데이터만 사용하며 기본정보 스크린샷을 기록한다. 백엔드·DB 변경 없음.
