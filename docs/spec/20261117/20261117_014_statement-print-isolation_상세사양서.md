# 거래명세표 인쇄 영향 범위 및 공용 금액 변환 상세사양서

- 작업번호: 20261117_014

## 동작 사양

- `StatementPrint`는 `frontend/src/shared/utils/amountInKorean.ts`의 함수를 가져와 거래명세표 합계 한글 표기에 사용한다.
- `statementPrint.ts`에는 금액 페이지 계산 등 기존 역할만 남기고 한글 변환 함수를 중복 정의하지 않는다.
- 사용자가 미리보기에서 인쇄를 실행할 때 `body.statement-printing` 클래스를 설정한 상태로 `window.print()`를 호출한다.
- `window.print()`가 반환되거나 예외를 던지면 `finally`에서 클래스를 제거한다. 기존에 같은 클래스가 이미 있었다면 호출자가 소유한 클래스를 유지한다.
- `@media print`의 전역 형제 숨김 규칙과 출력 호스트 표시는 `body.statement-printing`이 있을 때에만 적용한다. 미리보기 화면이나 다른 화면의 인쇄에는 적용하지 않는다.

## 회귀 검증

- 거래명세표 미리보기의 한글 금액이 기존 변환 결과와 일치한다.
- `window.print()` 호출 중 클래스가 설정되고 호출 종료 뒤 제거된다.
- 기존 공용 함수의 단위 테스트로 0, 음수, 안전하지 않은/소수 입력 규칙을 유지한다.
- 브라우저 PDF에서 A4 인쇄 내용이 포함되고 출력 외 화면 콘텐츠가 섞이지 않는지 확인한다.
