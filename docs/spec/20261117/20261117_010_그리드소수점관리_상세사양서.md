# 그리드 소수점 관리 상세사양서

- 작업번호: 20261117_010

## 정책 등록 규칙
- 정책 관리 > 정책 추가: 값 유형 `NUMBER`, 코드 `GRID_DECIMAL_{tb_module.module_code 대문자}` (예: `GRID_DECIMAL_SALES`), 최소 0 / 최대 6 권장.
- 예: 수주 2, 구매 4, 생산 1.

## API
- `GET /api/v1/system/policies/grid-decimals` (로그인 사용자, 테넌트 범위)
- 응답: `{ item: { "SALES": 2, "PURCHASE": 4 } }`
- 값이 0 미만이거나 6 초과, 숫자가 아닌 정책은 무시한다.
- 쿼리: `selectGridDecimalPolicies` (`tenant_id = #{tenantId}`, `value_type='NUMBER'`, `policy_code LIKE 'GRID\_DECIMAL\_%'`).

## 프런트
- `shared/services/gridDecimalPolicy.service.ts`: 1회 조회·캐시, 실패 시 `{}`.
- `shared/hooks/useModuleDecimals.ts`: `useModuleDecimals('SALES', 2)`; 정책이 없으면 폴백.
- 컬럼 생성 함수는 `decimalPlaces` 옵션을 받아 수량/단가 컬럼에 적용(금액 컬럼은 2자리 유지).

- `20261117_009_seed_grid_decimal_policies.sql`을 적용하면 tb_module 사용 모듈마다 `GRID_DECIMAL_{모듈코드}` 정책(기본 2, 0~6)이 정책 관리 목록에 생성된다. 적용 전에는 정책 추가로 직접 등록해야 한다.
