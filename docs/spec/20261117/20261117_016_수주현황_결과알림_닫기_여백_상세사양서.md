## 동작 계약

- 조회 성공 후 결과 알림이 표시될 때의 기존 간격은 유지한다.
- 사용자가 결과 알림을 닫으면 알림은 숨기되 그리드 콘텐츠 컨테이너는 기존 기본 상단 여백 `pt: 1`(MUI spacing 8px)을 적용한다.
- 이후 신규 조회, 목록 재시도 또는 저장/삭제 후 목록 갱신에서는 닫힘 상태를 초기화하고 조회 성공 후 결과 알림을 다시 표시한다.
- 변경은 `SalesOrderStatusPage`에서 결과 알림 닫힘 여부와 그리드 간격을 동기화하는 데 한정한다. 공용 메시지의 새 콜백은 선택 사항이며, 다른 사용 화면의 표시/닫기 동작은 그대로 둔다.
- API, 결과 수, 검색 조건, 그리드 컬럼/행 동작은 변경하지 않는다.

## 회귀 검증

- 결과 알림 표시 중 그리드 간격이 기존 `pt: 0`인지 확인한다.
- 결과 알림을 닫은 뒤 알림이 사라지고 그리드 간격이 `pt: 1`인지 확인한다.
- 다시 조회하면 결과 알림이 다시 표시되고 그리드 간격이 `pt: 0`으로 복귀하는지 확인한다.
