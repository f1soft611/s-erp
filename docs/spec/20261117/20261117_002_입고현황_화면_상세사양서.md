# 20261117_002 입고현황 화면 상세 사양서

기준: [작업지시서](../../directions/20261117/20261117_002_입고현황_화면_작업지시서.md), [계획서](../../plan/20261117/20261117_002_입고현황_화면_계획서.md), [입고등록 사양서](20261117_001_입고등록_화면_상세사양서.md)
DB(테이블)와 수정·취소 API는 입고등록 사양서에 있다. 이 문서는 목록과 현황 화면만 정의한다.

## 1. 메뉴
- `입고현황`: `MATERIALS_RECEIPT_STATUS`, `/materials/receipt/receipt-status`, 입고관리 그룹 아래, 정렬 40(입고등록 바로 다음). 권한 READ, EXCEL. 역할 권한은 가입고현황(`MATERIALS_ARRIVAL_STATUS`)을 복사한다. 스크립트 `20261117_003`.

## 2. API (`/api/v1/materials/material-receipt-status`)

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/` | 입고 품목 행 단위 목록 |

### 2.1 검색 조건
- `receiptDtFrom`, `receiptDtTo`: 입고일 기간(필수, 시작·종료 모두. 기본 최근 1개월~오늘).
- `receiptNo`, `supplierKeyword`(구매처명·코드), `arrivalNo`, `orderNo`, `materialKeyword`(품목코드·명·규격), `keyword`(빠른 검색).
- `status`: `ACTIVE`(정상), `CANCELED`(취소), `ALL`(전체). 값이 없으면 서버는 `ACTIVE`로 본다. 화면 기본값도 정상이다.

### 2.2 응답 행
입고 헤더·행 정보와 `status`(ACTIVE/CANCELED): `materialReceiptId`, `receiptNo`, `receiptDt`, `supplierName`, `receiverName`, `taxType`, `taxTypeName`, `vatIncludedAt`, 헤더 `headerSupplyAmt/headerVatAmt/headerTotalAmt/headerRemark`, 행 `materialReceiptDetailId`, `lineNo`, `arrivalNo`, `arrivalLinked`(연결된 가입고 행이 남아 있고 그 가입고가 정상이면 true), `materialArrivalId`(링크용), `orderNo`, `materialCode/Name/Spec`, `unit`, `receiptQty`, `unitPrice`, `supplyAmt/vatAmt/totalAmt`, `warehouseName`, `manufactureDt`, `expireDt`, `lotNo`, `remark`, `createdByName`.
정렬은 입고일·입고번호 내림차순, 행번호 오름차순.

## 3. 화면 (`frontend/src/pages/materials/receipt/status`)

- 구성: `MaterialReceiptStatusPage`, `components`(상세 패널, 에디터 다이얼로그), `data`(컬럼), `hooks`, `services`, `types`. 가입고현황과 같은 구조다.
- 목록 컬럼(같은 입고는 헤더 셀 병합): 입고번호(링크), 입고일, 구매처, 상태, 행, 가입고번호(링크: 가입고현황 상세로 이동, 연결이 끊긴 취소 이력은 일반 텍스트), 발주번호, 품목코드, 품목명, 규격, 단위, 입고수량, 입고단가, 공급가·세액·합계, 입고창고, 제조일, 소비기한, 비고, 등록자.
- 상태 검색: 정상(기본) / 취소 / 전체. 기본 조회에서는 취소건이 나오지 않는다. 필수 조건이 아니라 칩에서 해제하거나 바꿀 수 있다.
- 입고번호 클릭 → 상세 패널(요약: 건수·공급가·세액·합계, 헤더 정보, 가입고번호 링크) → [더보기] 메뉴에서 조회/수정.
- 수정 다이얼로그는 입고등록 화면을 `embedded`로 쓴다: 취소된 입고는 조회만, 정상은 수정(수정 권한은 입고등록 메뉴 UPDATE), 푸터에 [입고 취소]. 취소·행 빼기 확인창에는 무검사 안내를 포함한다(입고등록 사양 5절).
- 엑셀은 EXCEL 권한이 있을 때만 보인다.
- 375/768/1280/1920px에서 가로 스크롤·잘림을 확인한다.

## 4. 검증 항목
- 기본 조회는 정상만, 취소·전체 선택 시 해당 건이 조회됨. 입고일 기간 필수 검증.
- 번호 링크 → 상세 → 수정 저장·행 빼기·취소가 목록과 헤더 금액에 반영됨.
- 취소된 입고는 수정·취소 버튼이 없고 조회만 됨. 가입고번호 링크 동작.

## 5. 확정한 사항 (2026-11-17 사용자 확인)
- 취소건 조회는 정상(기본)/취소/전체 3종이며 모든 현황에 적용한다. 기존 현황 화면 정비는 입고 작업 종료 후 별도 작업이다.
