## 1. 견적 기본정보 레이아웃

- 기존 필드 순서를 유지한다: 견적번호, 견적작성일, 거래처, 견적제출일, 참조, Incoterms, 결제조건, 견적유효기간, 화폐단위, 비고.
- 그리드는 xs 1열, sm 2열, lg 4열이며, 가로 간격 16px, 세로 간격 8px을 사용한다.
- 그리드 자식 MUI form control의 기본 여백을 제거한다. 거래처 picker의 기본 상단 간격도 이 그리드 안에서만 제거하고, 40px 높이 입력/선택 버튼을 정렬한다.
- 1200px 이상에서 첫 행은 견적번호·견적작성일·거래처·견적제출일, 다음 행은 참조·Incoterms·결제조건·견적유효기간, 마지막 행은 화폐단위와 전체 너비 비고로 구성한다. 좁은 화면은 동일 DOM 순서로 열을 줄인다.

## 2. 날짜 입력

- 견적작성일 및 견적제출일은 공통 `DateEditor`의 outlined 변형을 사용한다.
- 내부 날짜 문자열과 API 계약은 `YYYY-MM-DD` 그대로다. 달력 선택과 `DateEditor`의 기존 축약 입력 정규화 동작을 제공한다.
- 견적작성일은 시스템 업무일 기본값 및 필수 조건을 유지한다. 빈 견적제출일은 허용한다.
- blur 또는 저장 시 정규화할 수 없는 비어 있지 않은 날짜는 오류로 표시하고 저장을 막는다. 빈 견적작성일도 필수 검증 오류를 표시한다.

## 3. 견적 상세 품목 입력

| 필드 | 마스터 선택 | 직접 입력 행 | 필수 |
|---|---|---|---:|
| 품목코드 | 선택된 품목의 코드 스냅샷 표시 | 입력 불가, 빈 값 | 아니오 |
| 품목명 | 선택된 품목명 표시 | 편집 가능 | 예 |
| 규격 | 선택된 품목 규격 표시 | 입력 불가, 빈 값 | 아니오 |
| 단위 | 선택된 품목 단위 표시 | 입력 불가, 빈 값 | 아니오 |
| 견적수량 | 편집 가능 | 편집 가능 | 예, 0 초과 |
| 견적단가 | 편집 가능 | 편집 가능 | 예, 0 이상 |
| 견적금액 | 계산 결과 | 계산 결과 | 계산 |
| 비고 | 편집 가능 | 편집 가능 | 아니오 |

- 품목코드 셀은 F1-Grid `code` 유형의 선택 셀로 동작한다. 사용자가 셀을 선택하면 해당 행의 품목 선택기를 열고, 코드를 타이핑해 임의 입력할 수 없다.
- 기존 상세 행 선택 후 `품목 선택` 툴바 버튼도 제공하며 같은 품목 선택 결과를 적용한다.
- 마스터 선택은 `materialId`, 코드, 이름, 규격, 단위 스냅샷을 함께 설정한다.
- 직접 입력은 마스터를 선택하지 않은 행에서 품목명만 허용한다. 직접 품목은 견적 상세 값으로만 저장하며 마스터 insert/update 요청을 발생시키지 않는다.
- 마스터 연결 행의 품목명을 사용자가 변경하면 `materialId` 및 기존 마스터 스냅샷 값을 제거해 수기 입력 상태로 바꾼다. 품목코드/규격/단위는 편집 불가다.
- 품목명, 수량, 단가 검증 및 기존 금액 재계산/소수점 정책은 그대로 유지한다. API 요청 필드와 서버 계약은 변경하지 않는다.
