# 수주현황 컬럼 조정 상세사양서

## 대상

`frontend/src/pages/sales/order/status/data/salesOrderStatusColumns.tsx`

## 변경

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| `status` (수주상태) | 그리드 표시 | `hidden: true` (그리드 숨김, 상세검색 조건 유지) |
| `lineStatus` | 뒤쪽 "행상태" | 견적번호 다음 "업무상태", 검색 라벨 "업무상태" |

최종 컬럼 순서: No, 수주번호, 수주일자, 거래처코드, 거래처명, 견적번호, 업무상태, 수주상태(숨김), 납품장소, 배송방법, 행, 품목코드, 품목명, 단위, 주문수량, 단가, 공급가, 부가세, 합계, 납기일자, 출하수량, 비고.

## 검증 기준

- 그리드 헤더에 "수주상태"가 보이지 않고 "업무상태"가 견적번호 바로 다음에 표시된다.
- 상세검색에서 수주상태·업무상태 조건이 모두 동작한다(`status`, `lineStatus` 파라미터 불변).
- `lineStatus`는 행 단위 값이므로 병합하지 않는다.
- 375/768/1280px에서 그리드 내부 스크롤로 표시되며 페이지 가로 스크롤이 없다.
- 기존 수주현황 테스트가 모두 통과한다.
