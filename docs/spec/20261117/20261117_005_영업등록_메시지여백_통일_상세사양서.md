## 일반 등록 페이지

- 수주등록과 동일하게 본문은 오류가 없으면 좌우 `xs: 8px / sm: 16px`, 위 8px, 아래 16px을 사용한다. 성공 메시지는 본문 직계 `Alert`와 16px gap을 유지한다.
- 기준은 수주등록 신규 화면에서 품목 상세 미입력 시 표시하는 입력 검증 오류다. 오류 여부와 무관하게 본문 패딩을 유지하며 오류도 본문 직계 `Alert`로 표시한다.
- 오류 상자는 기본정보와 좌우 경계를 맞추고 본문 상단에서 8px, 기본정보까지 16px 간격을 유지한다. 성공 메시지도 같은 위치를 사용한다.
- 수주등록 서버 오류, 견적서작성, 출하등록, 출하계획등록, 거래명세서등록의 상단 오류·성공 메시지는 같은 구조로 배치한다. 화면별 메시지 내용, 닫기 및 오류 발생 조건은 유지한다.
- embedded 본문은 수주등록처럼 패딩 0을 유지한다. 메시지 전용 외부 패딩은 추가하지 않는다.

## 검증

- 수주등록의 실제 신규 입력 검증 오류와 각 화면의 성공·서버 오류, 출하계획의 실제 수량 초과 검증 오류를 합성 데이터로 재현한다.
- 375/768/1280px에서 실제 메시지의 region 기준 좌우 위치, 위 여백, 아래 기본정보까지의 간격을 각 성공·오류 상태별로 비교한다.
- 관련 회귀 테스트, 빌드, lint, 스크린샷을 기록한다.
