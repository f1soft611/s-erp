# 공통코드 모듈 구분 상세사양서

## 데이터
| 항목 | 내용 |
| --- | --- |
| 컬럼 | `tb_common_code_group.module_cd` varchar(50) NULL |
| 값 | 시스템 모듈관리 `tb_module.module_code`(테넌트 내 유일). NULL/빈값 = 공통 |
| 검증 | 같은 테넌트의 `tb_module`에 없는 코드는 `IllegalArgumentException`(400). FK는 두지 않음 |

## API
- `GET /api/v1/co/master/common-code/groups?moduleCd=<module_code>` : 해당 모듈 그룹만 조회(다른 조건과 AND). 응답 행에 `moduleCd` 포함.
- `POST/PUT /groups`, `POST /save-batch`의 그룹 행에 `moduleCd` 포함. 빈값은 NULL(공통)로 저장.
- 모듈 목록은 기존 `GET /api/v1/system/modules`를 재사용(신규 API 없음).

## 화면
- 그룹 트리에 `모듈` 선택 컬럼(옵션: 공통 + 사용 중 모듈). 옵션은 모듈관리 데이터에서 로드하며 로드 실패 시 `공통`만 표시.
- 상세검색에 `모듈` 조건 추가, 조회 시 `moduleCd` 쿼리 전달.

## 검증 기준
매퍼 module_cd 읽기/필터/저장 및 tb_module 존재 조회, 프론트 매핑(빈값=공통), 모듈 옵션이 `/system/modules`에서 생성, 필터 쿼리 전달.
