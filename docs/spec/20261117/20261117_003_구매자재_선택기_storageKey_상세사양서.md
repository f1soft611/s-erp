## 2. 동작
- 열 순서·너비·숨김·고정 설정은 `storageKey` 기준으로 브라우저에 저장되고 선택기를 다시 열면 복원된다.
- 선택기마다 키가 달라 한 선택기의 설정이 다른 선택기에 영향을 주지 않는다.
- API, 검색, 선택, 저장 요청, 권한 동작은 바꾸지 않는다.

## 3. 문서
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`의 `storageKey` 설명에 "다이얼로그 선택기·팝업 안의 그리드도 대상이며 누락은 `tests/f1-grid-storage-keys.test.ts`가 검출한다"를 추가한다.
