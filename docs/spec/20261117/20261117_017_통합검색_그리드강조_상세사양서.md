# 통합검색어 그리드 강조 상세사양서

- 작업번호: 20261117_017
- 근거: [계획서](../../plan/20261117/20261117_017_통합검색_그리드강조_계획서.md)

## API
| 위치 | 이름 | 설명 |
| --- | --- | --- |
| `F1GridProps` | `highlightKeyword?: string` | 조회에 적용된 통합검색어. 앞뒤 공백은 제거한다. |
| `F1GridColumn` | `highlightSearch?: boolean` | true인 컬럼에서 검색어와 일치하는 글자를 빨간색(`error.main`)으로 표시한다. |
| `F1GridCellRenderContext` | `highlightKeyword?: string` | `highlightSearch` 컬럼의 `renderCell`에만 전달된다. |
| 컴포넌트 | `F1GridHighlightText` | `renderCell` 안에서 `text`, `keyword`로 같은 강조를 적용한다. |

## 동작
- 대소문자 무시, 부분 일치, 모든 일치 구간 강조. 특수문자는 문자 그대로 비교한다.
- 읽기 모드 기본 텍스트 셀에 자동 적용, 편집 중 셀은 제외한다.
- 서버 검색 컬럼과 일치시킨다. 예: 수주현황은 수주번호·거래처코드/명·품목코드/명·견적번호.
