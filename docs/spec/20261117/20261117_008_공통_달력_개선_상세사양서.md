## 1. 컴포넌트 (`frontend/src/shared/components/calendar/`)

| 컴포넌트 | 용도 | 값 형식 |
| --- | --- | --- |
| `DatePanel` | 날짜 한 개 선택 | `YYYY-MM-DD` |
| `DateRangePanel` | 시작~종료 선택 | `from`, `to` (`YYYY-MM-DD`) |
| `MonthPanel` | 월 선택 | `YYYYMM` |

모든 문구는 한국어다. 요일은 일·월·화·수·목·금·토(주 시작 일요일), 월은 `1월`~`12월`.

### 1.1 날짜 격자 (`DatePanel`, `DateRangePanel` 공통)
- 헤더: `‹`(이전 달) / 연도 드롭다운 / 월 드롭다운 / `›`(다음 달). 연도 드롭다운은 표시 연도 기준 −50~+20년, 월 드롭다운은 `1`~`12`(월 표기 `N월`).
- 본문: 6주×7일 고정 격자. 이전·다음 달 날짜도 표시하되 흐리게, 누르면 그 날짜를 선택하고 표시 월도 그 달로 바뀐다.
- 색: 일요일 빨강, 토요일 파랑(다른 달 날짜는 흐린 같은 색), 선택 날짜는 진한 파랑 배경·흰 글자, 오늘은 주황 점.
- 접근성: 격자 `role="grid"`, 주 `role="row"`, 날짜 `role="gridcell"`인 버튼, 이름은 ISO 날짜(`2026-11-17`), 오늘은 `aria-current="date"`, 선택은 `aria-selected="true"`. 키보드: 날짜 버튼 Tab 이동, Enter/Space 선택.
- 하단: 좌 `오늘`(서버 날짜가 아니라 입력 화면의 현재 날짜. 단 `todayValue`를 받으면 그 값, 영업 화면처럼 서버 날짜를 쓰는 곳에서 넘길 수 있다), 우 `삭제`(값을 비움).
  - 이 화면들의 "오늘"은 달력을 편의로 이동·선택하는 용도이며 기본값 규칙(서버 날짜)과 무관하다. `todayValue`가 없으면 브라우저 날짜를 쓴다.

### 1.2 `DatePanel`
- props: `value`, `onChange(value: string)`, `onClear()`, `todayValue?`, `initialMonth?`.
- 날짜를 누르면 `onChange(ISO)`. `오늘`은 오늘 날짜를 선택, `삭제`는 `onClear`. 값이 없으면 표시 월은 오늘이 속한 달.

### 1.3 `DateRangePanel`
- props: `from`, `to`, `onChange(from, to, done: boolean)`, `onClear()`, `todayValue?`.
- 동작:
  1. 팝업을 열었을 때 단계는 `start`. 첫 클릭 날짜 `d`는 `onChange(d, d, false)`를 호출하고 단계는 `end`로 바뀐다.
  2. 단계 `end`에서 마우스를 올린 날짜(`hover`)까지 연한 파랑으로 미리 칠한다.
  3. 두 번째 클릭 날짜 `e`는 `d`보다 앞이면 서로 바꿔 `onChange(min, max, true)`를 호출하고 팝업은 닫힌다(`done`).
  4. `오늘`은 오늘 하루 범위로 `onChange(today, today, true)`, `삭제`는 `onClear`.
- 칠하기: 시작·종료는 진한 파랑, 사이는 연한 파랑 배경이고 행 경계에서 모서리를 둥글게 하지 않아도 된다. 기존 `from`/`to` 값이 있는 채로 열면 그 범위를 칠한다.

### 1.4 `MonthPanel`
- props: `value`, `onChange(value: string)`, `onClear()`, `todayValue?`.
- 헤더 `‹` / 연도 드롭다운 / `›`(연 단위 이동). 본문 `1월`~`12월` 버튼 3×4, 선택 월 진한 파랑, 이번 달 주황 점. 하단 좌 `이번 달`, 우 `삭제`.
- 월을 누르면 `onChange('YYYYMM')`.

## 2. 연동

### 2.1 `DateEditor`
- 기존 props(`value`, `onChange`, `disabled`, `variant`, `label`, 오류 등)와 입력 동작은 그대로다. 달력 열기 버튼 이름 `${label} 달력 열기`도 그대로다.
- 신규 선택 prop `renderCalendar?: (api: { close: () => void; value: string }) => ReactNode`. 없으면 `DatePanel`을 쓰고 날짜를 고르면 `onChange(ISO)` 후 닫는다. `disabled`이면 팝업을 열지 않는다(기존).
- 팝업은 `Popover`이며 폭은 `min(100vw - 32px, 296px)`.

### 2.2 `PageSearchArea` 날짜 필드(from~to) — 단일 달력 유지(범위 달력 보류)
- **결정(2026-11-17)**: 범위 달력은 화면에 연결하지 않는다. 시작일·종료일 두 `DateEditor`는 각각 기본 `DatePanel`을 쓰고 자기 값만 바꾼다. 종료일 달력은 종료일을 선택 상태로 보여 준다.
- 아래 범위 달력 연동 설명은 보강 시의 설계 메모이며 현재 구현이 아니다.
- (보류 설계) 시작일·종료일 두 `DateEditor`가 각각 `renderCalendar`로 같은 `DateRangePanel`을 연다. `onChange(from, to, done)`는 기존 `updateDateValue`로 두 값을 갱신하고 `done`이면 팝업을 닫는다. 입력 정규화·필수·오류 표시는 기존 그대로다.
- 첫 클릭으로 시작=종료=그 날이 반영된다(이전 동작은 시작만 바뀌고 종료 유지). 종료만 바꾸려면 종료일 입력에 직접 입력하거나 달력에서 시작을 다시 고른 뒤 종료를 고른다.

### 2.3 `MonthEditor`
- `DateCalendar` 대신 `MonthPanel`을 쓴다. 월을 고르면 값을 반영하고 닫는다. 입력 규칙은 그대로다.

### 2.4 `DateTimeEditor`·`TimeEditor`
- 모양은 유지하고 `LocalizationProvider`에 한국어 로케일을 적용해 표시를 한글로 맞춘다.

## 3. 검증 항목
- 격자: 2026-11(일요일 시작) 첫 주가 10/25~10/31이 아니라 11/1(일)부터이며 6주 42칸, 월말·윤년(2028-02)·월 시작 요일이 다른 달, 이전/다음 달 날짜 선택 시 표시 월 이동.
- `DatePanel`: 날짜 선택, 오늘·삭제, 드롭다운 연·월 변경, 화살표 이동, 선택·오늘 표시 속성.
- `DateRangePanel`: 첫 클릭=하루 범위(done=false), 두 번째 클릭 완성(done=true), 역순 교체, 호버 미리보기, 기존 범위 칠하기, 오늘·삭제.
- `DateEditor`: 입력·정규화 회귀, 달력 선택, `disabled`에서 팝업 불가, `renderCalendar` 사용.
- `PageSearchArea`: 시작일 달력에서 두 번 클릭해 범위 반영·닫힘, 첫 클릭 후 닫아도 하루 범위 유지, 필수 오류·기존 테스트.
- `MonthEditor`: 월 선택(`1월` 버튼), 연도 이동, 삭제.
- 회귀: `f1-grid`, `page-search-area-detail`, 영업 폼(수주·출하·명세서·견적), 공지 작성, 날짜 셀 편집 테스트. 실제 브라우저 375/768/1280px(영업 수주등록 폼·공지 작성·검색 날짜·마감월).

## 4. 영업 담당자 전달 사항
공통 `DateEditor`의 달력 팝업이 새 컴포넌트로 바뀐다(한국어, 연·월 드롭다운). 입력 규칙·`disabled`·props는 같다. 영업 화면 코드 변경은 없다.
