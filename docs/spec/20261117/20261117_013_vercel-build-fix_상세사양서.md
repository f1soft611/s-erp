## 원인

최근 소수점 정책 변경에서 기존 `F1GridColumn.options` 선언이 소수점 옵션으로 대체되었으나 선택 편집기·폼·검색·표시 및 업무 컬럼은 계속 이를 사용한다. 같은 변경에서 견적 금액 컬럼 너비와 공통코드 패널 prop·헤더가 누락되었고, 샘플 그룹은 새 필수 필드에 맞춰지지 않았다.

## 변경 계약

- `F1GridColumn<T>.options?: F1GridOption[]`를 소수점 옵션과 함께 제공한다. `F1GridOption`은 기존 `value: string | number | boolean`, `label: string` 그대로다.
- 견적현황 `amountColumn`은 전달된 너비 또는 기본 130을 반환 컬럼에 반영한다. `decimalPlaces`를 강제하지 않아 기존 모듈 정책을 유지한다.
- 공통코드 패널은 기존 선택적 문자열 `searchQuery`를 받는다. 그룹 설명 컬럼의 헤더는 `그룹 설명`이다.
- 샘플 그룹 `moduleCd`는 빈 문자열(공통)이다. 서버 요청·응답, DB 및 권한은 변경하지 않는다.

## 검증

- 수정 전 `npm run build` 실패를 확인하고 수정 후 TypeScript와 Vite 모두 성공해야 한다.
- 견적현황 금액 컬럼 너비 복원은 diff로 확인하고 기존 견적현황 테스트로 화면 흐름을 회귀 검증한다.
- F1Grid 선택 편집·폼·검색, 견적현황 및 공통코드 관련 기존 테스트를 실행한다.
- 레이아웃/CSS/렌더러는 바꾸지 않는다. 브라우저 확인 여부와 증빙은 결과 문서에 실제 수행한 범위만 기록한다.
