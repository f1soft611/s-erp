# 20261117_009 구매자재 현황 통합검색어 강조 적용 상세 사양서

기준: [작업지시서](../../directions/20261117/20261117_009_구매자재_통합검색어_강조_작업지시서.md), [계획서](../../plan/20261117/20261117_009_구매자재_통합검색어_강조_계획서.md)
DB·API 변경 없음. 근거 사양: [F1-GRID.md](../../../frontend/src/pages/f1-grid-docs/F1-GRID.md) "통합검색어 강조 (2026-11-17)".

## 1. 공통 규칙
- `F1Grid`의 `highlightKeyword`에는 마지막 조회에 적용된 통합검색어(`appliedFilters?.keyword`)를 넘긴다. 앞뒤 공백은 그리드가 제거한다.
- 강조는 대소문자를 구분하지 않는 부분 일치이며 모든 일치 구간을 `error.main` 색으로 표시한다.
- `highlightSearch: true` 컬럼은 서버 통합검색 SQL이 검색하는 컬럼만이다.
- 기본 텍스트 셀은 자동 적용되고 `renderCell` 컬럼은 context의 `highlightKeyword`를 `F1GridHighlightText`에 넘겨 직접 적용한다. 값은 `string`으로 넘기고(null은 빈 문자열) 링크의 `aria-label`은 바꾸지 않는다.

## 2. 화면별 지정

| 화면 | 그리드 | `highlightSearch` 컬럼 |
| --- | --- | --- |
| 구매요청현황 | 요청 목록 | `requestNo`(링크), `requesterName`, `materialCode`, `materialName` |
| 구매발주현황 | 발주 목록 | `orderNo`(링크), `supplierName`, `ordererName`, `materialCode`, `materialName` |
| 가입고현황 | 가입고 목록 | `arrivalNo`(링크), `supplierName`, `receiverName`, `materialCode`, `materialName` |
| 입고현황 | 입고 목록 | `receiptNo`(링크), `supplierName`, `receiverName`, `materialCode`, `materialName` |
| 자재수입검사현황 | 검사 목록 | `inspectionNo`(링크), `arrivalNo`(링크), `supplierName`, `inspectorName`, `materialCode`, `materialName` |
| 매입마감처리 | 입고 행 | `materialCode`, `materialName` |

- 입고현황·자재수입검사현황의 `arrivalNo`처럼 서버 통합검색이 검색하는 번호는 입고현황에서는 검색하지 않는다(입고현황은 가입고번호를 통합검색하지 않고 상세검색 `arrivalNo`만 쓴다). 따라서 입고현황의 `arrivalNo`는 강조하지 않는다.
- 같은 이유로 `orderNo`, `inspectionNo`(입고현황) 등 통합검색에 없는 컬럼은 지정하지 않는다.
- 매입마감처리의 구매처 요약 그리드는 강조하지 않는다.

## 3. 컬럼 정의 변경 방식
- 각 `create…Columns` 함수의 링크 `renderCell`에서 `({ row, highlightKeyword })`를 받아 `highlightKeyword ? <F1GridHighlightText text={…} keyword={highlightKeyword} /> : 원래 값`으로 렌더한다.
- 일반 텍스트 컬럼은 `highlightSearch: true`만 추가한다.
- 페이지는 `<F1Grid … highlightKeyword={search.appliedFilters?.keyword} />`로 전달한다. 매입마감처리는 `search.appliedFilters?.keyword`를 입고 행 그리드에 전달한다.

## 4. 검증 항목
- 각 화면: 조회 전에는 강조 없음, 통합검색어를 적용해 조회하면 지정 컬럼에서 일치 글자만 강조(`data-f1-grid-highlight`), 지정하지 않은 컬럼은 강조 없음, 입력 중 변경은 조회 전까지 반영 안 됨.
- 링크 컬럼: 강조되어도 클릭하면 기존 동작(상세 열기·이동)이 동작하고 접근성 이름이 같다.
- 검색어를 비우고 조회하면 강조가 사라진다.
- 기존 구매 화면 테스트와 `f1-grid-highlight-keyword`, `f1-grid-docs`가 통과한다.
- 실제 브라우저(1920/1280/768/375px)에서 빨간 글자와 가로 넘침 없음 확인.

## 5. 유지 보수 메모
- 서버 통합검색 SQL의 검색 컬럼이 바뀌면 이 표와 컬럼의 `highlightSearch`를 같이 바꾼다.
