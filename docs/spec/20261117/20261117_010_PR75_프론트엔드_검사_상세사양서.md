# PR #75 프론트엔드 검사 실패 수정 상세사양서

## 범위

- 대상: `frontend/tests/sales-delivery-plan-page.test.tsx`의 PR 추가 AUTO 출하계획 테스트 2건.
- 원인: 수주 선택 후 계획번호가 먼저 갱신될 수 있으며, source-picker 다이얼로그의 종료 전환 중에는 상세 그리드가 접근성 역할 조회에 아직 노출되지 않을 수 있다.
- 동작 변경: 없음. 테스트가 그리드의 접근 가능 상태를 기다린 뒤 기존 편집·저장 검증을 수행한다. 전체 스위트 부하에서 split 시나리오가 기본 테스트 제한시간을 넘는 재현을 고려해 해당 테스트에만 15초 timeout을 지정한다.

## 검증

- CI와 같은 `--pool=threads --maxWorkers=2`를 사용해 대상 테스트 파일을 실행한다.
- PR head의 lockfile 의존성(Vitest 4.1.12)으로 대상 및 관련 수주 입력 테스트 파일을 실행한다.
- base 재현 테스트의 실패는 기존 동작으로 분류하고 수정하지 않는다.
- 사용자 요청 범위를 벗어난 실패 또는 원인이 확정되지 않은 실패는 결과와 사용자 확인 대상으로 남긴다.
