# 거래명세서 발행 상세사양서

- 작업번호: 20261117_011

## 정책
- 코드 `STATEMENT_ISSUE_MODE`, 유형 SELECT, 값 `AUTO`(자동 발행) / `MANUAL`(직접 발행), 기본 MANUAL. 정책 관리 화면에서 변경.

## 동작
- 출하등록(`POST` 출하) 성공 직전에 정책이 AUTO이면 명세일=출하일, 비고 "출하등록 자동 발행"으로 `SalesStatementServiceImpl.create` 호출.
- 발행 실패(중복 등) 예외는 그대로 전파되어 출하 저장이 롤백된다.
- 출하수정/삭제는 기존 동작 유지.
