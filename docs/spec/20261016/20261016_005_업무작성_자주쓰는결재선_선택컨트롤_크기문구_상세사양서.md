## 2. 화면 요구사항

- 자주 쓰는 결재선 select의 outlined input 외곽 높이는 38px로 한다. 이는 결재자 및 참조 `UserSelectEditor`의 38px 최소 높이와 일치한다.
- select의 `TextField`는 `margin="none"`으로 설정해 기본 FormControl 수직 여백이 행 높이를 늘리지 않게 한다.
- select의 표시값은 컨트롤 안에서 수직 중앙 정렬한다.
- select와 `설정` 버튼의 공통 행은 stretch 정렬하여 두 컨트롤의 외곽 높이를 동일하게 한다. 버튼은 medium variant를 유지하고 해당 행에서 38px로 표시한다.
- 미선택 기본 문구는 `자주 쓰는 결재선 선택`으로 표시한다.
- 미선택 기본 문구는 `UserSelectEditor` 입력 라벨과 같은 0.82rem 글꼴 크기 및 600 굵기로 표시한다. 선택된 템플릿명과 메뉴 옵션의 기존 글꼴은 유지한다.
- 접근성 이름 `자주 쓰는 결재선`, 선택값, 메뉴 옵션 및 API 동작은 유지한다.

## 3. 범위 및 비범위

- 변경 범위: `DocumentApprovalSettingsDialog`의 자주 쓰는 결재선 select 스타일과 미선택 문구, 직접 연관된 테스트 및 관련 결과/사양 문서.
- 비범위: 결재자 선택기, `결재 추가`/`합의 추가` 버튼 크기 변경, `설정` 버튼 variant 변경, 공통 MUI 테마 변경, 템플릿 API/상태 흐름 수정.

## 4. 검증 기준

- 빈 목록에서 select의 표시 문구가 `자주 쓰는 결재선 선택`이고, 해당 문구의 글꼴 크기/굵기가 각각 0.82rem/600이다.
- select의 outlined root에 38px 최소 높이가 적용되고 선택 텍스트가 수직 중앙에 표시된다.
- favorite selector 행은 stretch 정렬이며 `설정` 버튼의 외곽 높이가 select와 동일하다. 다른 버튼 크기와 variant는 변경하지 않는다.
- 설정 창 기존 전체 테스트와 프론트엔드 빌드가 통과한다.
- 브라우저 화면을 검증할 수 없는 경우 결과 보고서에 미수행 사유를 기록하고 시각 검증 완료를 주장하지 않는다.
