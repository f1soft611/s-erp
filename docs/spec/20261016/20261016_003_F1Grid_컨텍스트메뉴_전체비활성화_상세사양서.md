# F1-Grid 컨텍스트 메뉴 전체 비활성화 상세 사양서

## 1. 목적

F1Grid와 F1Tree의 바디 우클릭 컨텍스트 메뉴를 화면별로 모두 비활성화할 수 있는 공개 옵션을 제공한다. 행/엑셀 등 기존 메뉴 항목 단위 설정과 별도로 메뉴 표시 전체를 제어한다.

## 2. 적용 범위

- 프론트엔드 공통 F1-Grid 컴포넌트의 공개 props 및 이벤트 처리
- `F1Grid`, `F1Tree`의 바디 우클릭 컨텍스트 메뉴
- F1-Grid API Reference, 문서 포털 예제, 독립 개발 문서
- Vitest 회귀 테스트와 결과 문서/브라우저 캡처

## 3. 공개 API

| Prop | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `disableContextMenu` | `boolean` | `false` | 바디 우클릭으로 표시하는 F1-Grid 및 브라우저 기본 컨텍스트 메뉴를 표시하지 않는다. 우클릭 대상 셀/행 선택은 유지한다. |

`disableContextMenu`는 `F1GridProps`에 선언한다. `F1TreeProps`는 `F1GridProps`를 상속하므로 동일 옵션을 별도 선언 없이 지원한다.

## 4. 동작 요구사항

### 4.1 기본값

- 옵션을 생략하거나 `false`이면 현재 F1Grid/F1Tree 컨텍스트 메뉴의 항목 구성과 동작을 그대로 유지한다.
- 기존 `canExportExcel`, `allowAddRootInContextMenu`, `allowAddRowInContextMenu`, `allowDuplicateRowInContextMenu`, `allowDeleteRowInContextMenu`, `deleteMenuDisabled`와 상호 호환되어야 한다.

### 4.2 비활성화

- `true`이면 F1Grid/F1Tree 바디 영역 우클릭 시 F1-Grid 앱 메뉴와 브라우저 기본 메뉴 모두 표시하지 않는다.
- 기존 `contextmenu` 이벤트의 기본 동작 차단은 유지한다.
- 기존 타겟 해석 로직으로 식별한 우클릭 셀/행의 선택 동작은 유지한다.
- 옵션이 `false`에서 `true`로 변경될 때 이미 열린 컨텍스트 메뉴와 예약된 재오픈 동작을 닫는다.

### 4.3 비범위 및 호환성

- 헤더 클릭으로 여는 정렬/필터/고정/숨김 메뉴는 영향을 받지 않는다.
- F1-Grid 이외 브라우저/화면의 컨텍스트 메뉴는 영향을 받지 않는다.
- 브라우저 기본 메뉴만 따로 허용하는 옵션은 추가하지 않는다.
- 기존 개별 메뉴 항목의 표시, 순서, 비활성 조건은 변경하지 않는다.

## 5. 구현 기준

- `frontend/src/shared/components/f1-grid/types/grid.types.ts`에 optional boolean을 추가한다.
- `F1Grid` 기본값은 `false`다.
- 공통 바디 `onContextMenu` 처리에서 이벤트 기본 동작 차단, 그리드 내부 판정, 대상 셀/행 선택은 그대로 실행하고, 옵션이 켜져 있으면 app menu 상태를 설정하지 않는다.
- 옵션 활성화 효과는 기존 `closeContextMenu()`를 재사용해 열린 메뉴와 재오픈 타이머를 정리한다.
- `F1Tree`는 공유 props 전달로 동일 동작을 제공하고 트리 전용 메뉴 동작을 별도 구현하지 않는다.

## 6. 검증 기준

1. 옵션 기본값에서 기존 body 메뉴 및 헤더 메뉴 테스트가 통과한다.
2. `disableContextMenu`가 활성화된 F1Grid와 F1Tree에서 바디 우클릭 후 앱 메뉴가 없고 `contextmenu` 이벤트가 기본 차단된다.
3. 비활성화 상태에서도 우클릭한 대상 셀/행은 선택된다.
4. 메뉴가 열린 뒤 옵션이 켜지면 메뉴가 닫히며 이후 우클릭으로 재오픈되지 않는다.
5. API 테스트 계약, 문서 포털 Playground 및 `F1-GRID.md` 설명이 공개 타입과 일치한다.
6. 관련 테스트와 프론트엔드 빌드를 실행한다. 기준선에서 사전 확인된 F1Tree 메뉴 테스트 실패 두 건은 이 기능의 변경 범위와 분리해 결과 문서에 기록하고, 본 변경으로 새 실패가 추가되지 않았는지 확인한다.
7. 브라우저에서 비활성화/기본 동작 전환, 대상 선택, 헤더 메뉴 유지 여부를 확인하고 캡처한다.
