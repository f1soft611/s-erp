## 2. 화면 요구사항

- 선택 상자와 `설정` 버튼은 같은 수평 행에 유지한다.
- 두 컨트롤은 행의 세로 중앙을 기준으로 정렬한다.
- 선택 상자는 기존과 같이 남는 너비를 사용하고 좁은 화면에서 축소될 수 있다.
- 기존 간격, 크기, 접근성 이름, 로딩/오류 표시, 선택 동작, 관리 모달 열기 동작을 변경하지 않는다.
- 공통 다이얼로그 및 다른 화면의 스타일은 변경하지 않는다.

## 3. 구현 범위

- 결재선 설정 컴포넌트의 선택 상자/설정 버튼 행만 정렬한다.
- 관련 설정 창 테스트에 행의 세로 중앙 정렬 검증을 추가한다.
- 테스트 및 빌드 결과와 브라우저 확인 가능 여부를 기존 결과 보고서에 기록한다.

## 4. 검증 기준

- 정렬 회귀 테스트는 현재 `flex-start` 설정에서 실패하고 `center` 변경 후 통과한다.
- 결재선 설정 창 전체 테스트와 프론트엔드 빌드가 통과한다.
- 가능한 경우 375px, 768px, 1280px 브라우저에서 두 컨트롤이 중앙 정렬되고 가로 넘침이 없는지 확인한다.
- 인증된 업무작성 화면에 접근하지 못하면 브라우저 시각 검증을 완료한 것으로 기록하지 않는다.
