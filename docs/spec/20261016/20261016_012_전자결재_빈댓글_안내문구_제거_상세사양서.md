# 20261016_012 전자결재 빈 댓글 안내문구 제거 상세 사양서

## 1. 개요

문서작성 전자결재 상세 댓글에서 USER 댓글과 SYSTEM 메시지가 모두 없을 때 표시되는 `등록된 댓글이 없습니다.` 문구를 제거한다.

## 2. 기준 문서

- 작업지시서: [20261016_012 전자결재 빈 댓글 안내문구 제거 작업지시서](../../directions/20261016/20261016_012_전자결재_빈댓글_안내문구_제거_작업지시서.md)
- 계획서: [20261016_012 전자결재 빈 댓글 안내문구 제거 계획서](../../plan/20261016/20261016_012_전자결재_빈댓글_안내문구_제거_계획서.md)
- 승인 설계: [빈 댓글 안내 상태 설계](../../superpowers/specs/2026-10-16-document-approval-empty-comments-design.md)

## 3. 동작 요구사항

- 빈 댓글 상태는 USER 댓글 목록과 SYSTEM 메시지 목록이 모두 비어 있는 상태다.
- 이 상태에서 빈 안내 문구를 렌더링하지 않는다.
- 댓글 입력창과 등록 기능은 계속 표시한다.
- 초기 조회 로딩 spinner, API 오류 안내 및 재시도, 이전 댓글 보기, 비어 있지 않은 댓글/시스템 메시지 렌더링은 변경하지 않는다.
- 문서 피드 및 상세 댓글 페이지 API 계약은 변경하지 않는다.

## 4. 변경 범위

- 대상 컴포넌트: `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`
- 회귀 테스트: `frontend/tests/document-write-page.test.tsx`
- 결과 문서: `docs/result/20261016/approval-empty-comment-state/`
- 백엔드 및 DB 변경 없음.

## 5. 검증 기준

1. USER 댓글과 SYSTEM 메시지가 모두 없는 상세 댓글에서 `등록된 댓글이 없습니다.` 텍스트가 없다.
2. 같은 상태에서 `댓글 입력` 입력 요소와 `등록` 버튼을 사용할 수 있다.
3. 기존의 로딩·오류/재시도·USER/SYSTEM 렌더링 회귀 테스트가 유지된다.
4. 관련 프런트엔드 테스트, production build, `git diff --check` 결과를 기록한다.
5. 브라우저에서 빈 상태를 재현할 수 없다면 그 이유와 테스트 기반 검증 범위를 결과 문서에 기록한다.
