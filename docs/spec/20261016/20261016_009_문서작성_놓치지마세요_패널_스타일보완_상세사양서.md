# 문서작성 놓치지 마세요 패널 스타일 보완 상세 사양서

**문서 번호:** 20261016_009

## 목적

문서작성 페이지 우측 `놓치지 마세요` 패널에서 알림 유형과 문서 제목이 가운데에 모여 보이는 현상을 개선한다. 긴 제목, 특히 공백 없는 문자열이 카드 폭을 밀어내지 않고 읽히도록 한다.

## 대상과 현재 동작

- 대상 화면: `/groupware/doc/write`
- 대상 컴포넌트: `frontend/src/pages/groupware/documents/write/components/ApprovalNoticePanel.tsx`
- 현재 각 알림은 MUI `Button` 안에 유형명과 제목을 표시한다.
- 현재 버튼은 grid 정렬과 `action.hover` 배경을 사용하고, 제목에는 `overflowWrap: 'anywhere'`를 적용했으나 콘텐츠 너비 및 버튼 정렬이 충분히 고정되지 않아 첨부 화면처럼 중심 정렬로 보이고 긴 제목의 시각적 흐름이 어색하다.

## 기능 및 스타일 계약

1. 제목과 유형 라벨은 모두 카드의 왼쪽 가장자리에 맞춘다.
2. 버튼은 전체 너비의 세로 flex 레이아웃을 사용하고 `alignItems: flex-start`, `justifyContent: flex-start`, `textAlign: left`를 적용한다.
3. 각 알림은 현재 디자인과 조화되는 중립 톤의 옅은 테마 배경, 1px 테마 구분선, 둥근 모서리와 일관된 내부 여백을 사용한다.
4. 유형명은 굵은 본문 텍스트, 제목은 보조색 caption으로 구별한다.
5. 제목은 버튼 안에서 전체 너비를 사용하고 `overflowWrap: anywhere`로 공백 없는 긴 문자열도 줄바꿈한다.
6. 스타일은 theme palette 토큰을 사용한다. 강한 경고색, 아이콘 또는 제목 말줄임은 추가하지 않는다.

## 유지할 동작

- 최대 3건 표시, 알림별 문구, 클릭 시 `onSelect(item.id)` 호출을 유지한다.
- 알림이 없을 때 `새로운 결재 알림이 없습니다.` 안내를 유지한다.
- 데이터 타입, API 호출, 우측 패널의 배치 및 다른 요약 카드에는 변경을 가하지 않는다.

## 검증 기준

- 전용 테스트에서 버튼의 flex 세로 배치, 왼쪽 정렬, 전체 너비와 제목의 전체 너비/`overflowWrap: anywhere`를 확인한다.
- 항목 클릭이 선택한 문서 ID를 전달하고, 빈 상태 안내가 렌더링되는지 확인한다.
- `npx vitest run tests/approval-notice-panel.test.tsx tests/document-write-page.test.tsx`와 `npm run build`를 실행한다.
- 브라우저에서 375px, 768px, 1280px 폭을 확인해 긴 제목의 줄바꿈 및 가로 넘침 여부를 검증한다. 실제 페이지에 접근할 수 없으면 결과 문서에 제한을 구분해 기록한다.
- 결과와 캡처는 `docs/result/20261016/document-approval-notice-style/`에 보관한다.
