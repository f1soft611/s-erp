# 20260923_002 최근 사용 메뉴 세션 유지 상세 사양서

## 1. 화면 범위

- 대상 경로: 대시보드 전체, 모듈 사이드바
- 적용 위치: `DashboardPage`, `DashboardSidebar`, `DashboardMenuTree`
- 목적: 세션 동안 최근 사용 메뉴를 표시하고, 모듈 사이드바 하단에 간결한 사용자 프로필을 유지한다.

## 2. 상태 모델

```ts
type RecentMenuEntry = {
  menuId: string;
  moduleId: string;
  label: string;
  path: string;
  visitedAt: number;
};
```

- 저장 위치: `sessionStorage`
- 키 이름: `s-erp:recent-menu-history`
- 구조: 최근 방문 시간 기준으로 정렬한다.
- 최대 보관 개수: 5~8개

## 3. 동작 요구사항

### 3.1 최근 메뉴 저장

- 사용자가 메뉴를 선택하면 해당 메뉴의 moduleId, menuId, label, path, visitedAt을 기록한다.
- 동일 menuId가 이미 있으면 기존 기록을 제거하고 가장 최근 시점으로 갱신한다.
- 배열 길이가 제한값을 초과하면 가장 오래된 항목을 제거한다.
- 세션 종료/브라우저 종료 시 기록은 사라진다.

### 3.2 최근 메뉴 복귀

- 사이드바 하단에 최근 메뉴 버튼 리스트를 표시한다.
- 각 항목을 클릭하면 해당 메뉴로 이동한다.
- 이동 시 기존 선택 상태와 라우팅 흐름을 유지한다.
- 최근 메뉴는 빠른 이동 경로로만 처리하며, 전체 페이지 상태 복원은 수행하지 않는다.

### 3.3 사용자 프로필

- 프로필은 모듈 사이드바 하단에 위치한다.
- 사용자 이름/이메일 전체를 메인으로 보여주지 않고, 사진과 최소한의 텍스트만 노출한다.
- 추가 정보는 팝오버 또는 액션 버튼으로 분리한다.
- 메뉴 우선 UX를 유지한다.

## 4. UI 사양

### 4.1 사이드바 레이아웃

- 기존 메뉴 트리는 그대로 유지한다.
- 최근 메뉴 영역과 프로필 영역은 하단에 추가된다.
- 하단 영역은 사이드바 높이와 균형을 맞춰 과도하게 길어지지 않도록 한다.
- 모바일에서도 동일 구조를 유지하되, 수평 여백과 간격을 정리한다.

### 4.2 최근 메뉴 리스트

- 섹션 헤더: `최근 사용`
- 항목 표시 방식: 아이콘 또는 점 표시 + 메뉴명
- 최대 보관 개수: 5개 기본, 공간이 남으면 8개까지 확장 가능
- 선택 상태는 기존 메뉴 선택 표시와 별개로 유지한다.

### 4.3 프로필 카드

- 구성: avatar + 사용자명 + 상태 표시(선택 사항)
- 텍스트는 짧게 유지한다.
- 이메일 전체 표시를 줄이고, 사진을 중심으로 배치한다.
- hover 또는 click 시 간단한 프로필 액션 메뉴를 제공할 수 있다.

## 5. 구현 경계

- 최근 메뉴 저장 로직은 `DashboardPage` 또는 사이드바 하위 훅에서 처리한다.
- `DashboardMenuTree`는 사용자 프로필 영역과 최근 사용 메뉴 영역을 렌더링하는 역할만 수행한다.
- 기존 `selectedMenuId`, `expandedItemIds`, `onMenuSelect` 흐름은 재사용한다.
- 메뉴 트리의 스타일/선택 효과는 유지한다.

## 6. 예외 처리

- `sessionStorage`가 비활성화되거나 접근 불가할 경우: 최근 메뉴는 표시하지 않고 현재 메뉴 선택만 유지한다.
- 저장된 메뉴가 현재 구조에 없는 경우: 해당 항목은 목록에서 제외한다.
- 잘못된 JSON 형식의 저장값은 초기화하고 기본 상태로 복귀한다.

## 7. 검증 기준

1. 메뉴 이동 시 최근 메뉴 기록이 저장된다.
2. 동일 메뉴 재방문 시 기록이 최신화된다.
3. 최근 5~8개의 항목만 노출된다.
4. 최근 메뉴 클릭 시 이동이 정상 동작한다.
5. sidebar 하단에 프로필이 유지된다.
6. 프로필이 간결한 사진 중심 구조로 노출된다.
7. 메뉴 트리 선택 UX는 유지된다.
8. 375px, 768px, 1280px에서 레이아웃이 자연스럽게 보인다.

## 8. 완료 조건

- 최근 사용 메뉴 세션 유지 기능이 동작한다.
- 모듈 사이드바 하단 프로필이 유지된다.
- 메뉴 우선 UX를 유지한 채 보조 영역만 추가되었다.
- 요구사항과 구현 문서가 일치한다.
- 관련 결과 문서와 브라우저 확인이 남는다.
