# 20260923_003 공지사항 전체 우측 오버레이 상세 패널 상세 사양서

## 1. 레이아웃 사양

- 선택 전: 기존 공지 목록과 요약 패널을 표시한다.
- 선택 후: 목록은 기존 위치에 유지하고, `Drawer anchor="right"`가 앱 콘텐츠 위에 오버레이된다.
- 데스크톱 Drawer Paper 폭: `min(960px, 72vw)`에 해당하는 CSS `width: min(960px, 72vw)`.
- 모바일 Drawer Paper 폭: `100vw`.
- Drawer 높이: `100dvh`; 브라우저 fallback으로 `100vh`를 함께 지정한다.
- Drawer는 기본 백드롭을 사용하고, 백드롭 클릭·Escape·헤더 닫기 버튼으로 닫힌다.
- 목록 페이지의 전체 가로 스크롤은 없어야 한다.

## 2. 패널 구조

```text
Drawer
└── PostDetailPanel
    ├── 고정 헤더
    │   ├── 상세 제목/게시글 제목 영역
    │   └── 상세 닫기 버튼
    └── 독립 스크롤 콘텐츠
        └── NoticeFeedList(items=[selectedNotice])
```

- `PostDetailPanel`은 공지 API를 직접 호출하지 않는다.
- `NoticeFeedList`가 기존 피드 카드의 본문, 이미지, 첨부, 댓글, 반응, 게시글 관리 기능을 계속 제공한다.
- 헤더는 콘텐츠 스크롤과 분리되어 항상 보인다.
- 콘텐츠 영역은 `min-height: 0`, `overflow-y: auto`, `overflow-x: hidden`을 사용한다.

## 3. 상태 및 상호작용

- `selectedNoticeId`가 null이면 Drawer는 닫힌다.
- 리스트/상단 고정 항목 클릭 시 `selectedNoticeId`를 갱신하고 기존 상세 API를 호출한다.
- 다른 항목 클릭 시 Drawer를 유지한 채 선택 게시글과 콘텐츠를 교체한다.
- 상세 닫기, 백드롭, Escape 시 `selectedNoticeId`를 null로 설정한다.
- 상세 API 실패 시 Drawer는 닫지 않고 오류 알림과 기존 콘텐츠 상태를 유지한다.
- 목록의 스크롤 위치와 선택 상태는 상세를 닫았다 다시 열 때까지 불필요하게 초기화하지 않는다.

## 4. 콘텐츠 기능 계약

다음 기능은 오버레이 전환 전후 동일해야 한다.

- 본문 텍스트 및 HTML 에디터 콘텐츠
- 본문 이미지 뷰어
- 첨부파일 목록 및 다운로드
- 좋아요·북마크
- 댓글 입력·답글·이전 댓글 로드
- 댓글 수정·삭제·댓글 첨부파일
- 게시글 작성자 본인의 더보기·수정·삭제
- 비작성자 게시글의 게시글 관리 메뉴 비노출

## 5. 반응형 기준

| 뷰포트 | 패널 폭                              | 검증 기준                                             |
| ------ | ------------------------------------ | ----------------------------------------------------- |
| 1280px | `min(960px, 72vw)`                   | 목록이 배경에 남고 넓은 본문·댓글 영역을 제공         |
| 768px  | `100vw` 또는 breakpoint 기준 전체 폭 | 헤더와 본문이 겹치지 않음                             |
| 375px  | `100vw`                              | 가로 스크롤 없음, 닫기 버튼과 입력 영역이 잘리지 않음 |

## 6. API 및 오류

API 계약은 기존 공지 상세 조회를 그대로 사용한다.

- `GET /api/v1/groupware/boards/notice/posts/{postId}`
- 성공: 선택 게시글을 병합하고 Drawer 콘텐츠를 갱신한다.
- `401/403`: 기존 인증·권한 오류 처리와 알림을 유지한다.
- `404`: 상세 오류를 표시하고 닫기 또는 다른 게시글 선택을 허용한다.
- 네트워크 오류: 목록을 유지하고 Drawer 내부 또는 전역 알림으로 실패를 표시한다.

## 7. 테스트 기준

1. 선택 전 Drawer가 닫혀 있다.
2. 리스트형 항목 클릭 시 우측 Drawer가 열린다.
3. 상단 고정 항목 클릭 시 우측 Drawer가 열린다.
4. Drawer 폭이 데스크톱에서 기존 우측 컬럼보다 넓다.
5. Drawer 높이가 viewport 전체를 사용한다.
6. 목록이 배경에 유지된다.
7. 다른 게시글 선택 시 Drawer가 유지되고 대상만 교체된다.
8. 닫기 버튼·백드롭·Escape가 모두 선택 상태를 해제한다.
9. 본문·첨부·댓글·게시글 관리 기능이 유지된다.
10. 375px·768px·1280px에서 가로 스크롤·겹침·잘림이 없다.

## 8. DB 영향

백엔드·DB 변경 없음. SQL 및 롤백 문서는 작성하지 않는다.
