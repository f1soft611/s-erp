# 환경설정 공통 소수점 정책 적용 상세사양서

- 계획서: [20261126_005](../../plan/20261126/20261126_005_환경설정_공통_소수점_정책_적용_계획서.md)
- 공통 규칙: [공통 소수점 계약 가드레일 사양](20261126_001_공통_소수점_계약_가드레일_상세사양서.md)

## 계약

| 문서 | 필드 | 화면 컬럼 | 설정 |
| --- | --- | --- | --- |
| `settings.module` | `sortOrder` | 모듈 관리 정렬 순서 | `type: number` (정책 따름) |
| `settings.module` | `menuCount` | 모듈 관리 메뉴 수 | `type: number` |
| `settings.menu` | `order` | 메뉴 관리 정렬 | `type: number` |
| `settings.role` | `menuCount` | 역할 관리 사용자 수 | `type: number` |

- 환경설정 정책(`GRID_DECIMAL_SETTINGS`)의 number는 0자리이므로 정렬·개수는 정수로 입력·표시한다. 컬럼 예외는 없다.
- 순번(`rownumber`)은 대상이 아니다.

## 화면 동작

- 컬럼은 `decimalColumnOptions(getDecimalColumnContract(문서), 필드)`로 `type`과 예외를 얻는다. 화면에 `decimalPlaces` 등 소수점 옵션을 직접 쓰지 않는다.
- F1-Grid 공통 동작: 컬럼의 소수 자릿수(정책 포함)가 0이면 셀 직접 편집에서 `.`와 `,` 키 입력을 막는다. `exactDecimal`은 필요 없고 값은 숫자 그대로이므로 저장 요청 변환은 바꾸지 않는다.
- 자릿수가 1 이상인 컬럼은 소수점 입력을 막지 않는다. 붙여넣기와 행 폼 입력의 정규화는 기존 사양을 따른다.

## 서버

- 변경 없음. 서버는 정렬 순서와 개수를 정수로 저장·집계하며 소수점 규칙으로 계산하지 않는다. 서버 가드는 이 문서들을 "화면 전용 문서" 허용 목록으로 둔다.

## 검증

- F1-Grid 공통 테스트: 0자리 숫자 편집에서 `.`·`,` 입력이 막히고 정수 입력이 확정되며, 자릿수가 있으면 막지 않는다.
- 모듈 관리 화면 테스트: 환경설정 정책(number 0자리)에서 정렬 순서 입력의 `.`·`,`가 막힌다.
- 가드 테스트가 환경설정 폴더를 검사하고, 서버 가드는 환경설정 문서를 화면 전용 문서로 허용한다.
