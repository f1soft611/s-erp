# 문서관리 부서 표시·참조자 표시 개선 상세사양서

- 작성일: 2026-11-26
- 계획서: [20261126_010](../../plan/20261126/20261126_010_문서관리_부서표시_참조자표시_개선_계획서.md)

## 1. 부서명 조회 (백엔드)

- 대상: `DocumentApproval_SQL_postgresql.xml` `selectApprovalLines`
- `LEFT JOIN public.tb_department d ON d.tenant_id = u.tenant_id AND d.department_id = u.department_id`
- 응답 `participantDepartmentName` = `COALESCE(NULLIF(TRIM(d.department_nm), ''), NULLIF(TRIM(line.participant_department_name), ''))`
- 둘 다 없으면 null(화면은 `부서없음`). API 필드명·응답 구조는 변경하지 않는다.

## 2. 작성 화면 참조자

- 칩은 입력창 한 줄에 맞춰 앞 3명만 표시하고 나머지는 `+N명`. 입력창 높이는 40px을 유지하고 겹치지 않는다.
- 칩 라벨은 `이름`, 보조로 부서가 있으면 툴팁에 `직급 부서`.
- `+N명` 또는 `참조 N명 보기`를 누르면 다이얼로그: 검색(이름·부서), 부서별 그룹 헤더(`부서명 (n)`), 항목별 삭제, 전체 삭제.
- 선택 순서는 기존대로 보존한다. 부서 없는 사용자는 `부서없음` 그룹 맨 끝.
- 제한 수·접힘은 참조 필드에만 적용하며 `UserSelectEditor`의 기본 동작(다른 화면)은 변하지 않는다.

## 3. 문서 상세 참조자

- 별도 요약 줄은 두지 않는다(사용자 지시). 인원수는 `전체 N명 보기` 버튼 라벨로만 알린다.
- 기본은 접힘 상태로 앞 5명만 칩 형태로 표시하고 `전체 N명 보기`로 펼친다.
- 펼침: 부서별 그룹, 최대 높이 320px 내부 스크롤.
- 5명 이하이면 접힘 없이 모두 표시한다.

## 4. 검증 기준

- 100명 선택/상세 데이터에서 DOM 칩 수가 제한 수 이하이고 레이아웃이 겹치지 않는다.
- 부서가 비어 있는 복사본이어도 현재 부서가 표시된다.
