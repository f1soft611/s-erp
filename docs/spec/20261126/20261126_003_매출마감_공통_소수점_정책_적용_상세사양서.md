## 컬럼과 계약 연결

| 매출마감 컬럼 | 따르는 계약 컬럼 |
| --- | --- |
| 수량 `quantity` | `sales.delivery.deliveryQty` |
| 매출금액 `salesAmount` | `sales.delivery.supplyAmt` |
| 부가세 `vatAmount` | `sales.delivery.vatAmt` |
| 합계 `totalAmount` | `sales.delivery.totalAmt` |

- 컬럼은 `decimalColumnOptions(getDecimalColumnContract('sales.delivery'), 필드)`로 `type`과 예외를 얻고, `exactDecimal: true`로 정확한 소수 문자열을 표시한다.
- 정책은 F1-Grid가 모듈 정책으로 적용한다. 계약 컬럼에 `places`/`rounding`/`trailingZeros`가 있으면 그 항목만 정책보다 우선한다.
- 화면에는 `type: 'number'`/`'currency'`나 소수점 옵션을 직접 쓰지 않는다.

## 서버

- 변경 없음. 매출마감은 계산·저장 없이 읽기와 마감 표시만 하므로 서버 계약 필드를 추가하지 않는다.
- 거래명세서 발행은 기존 명세서 서비스가 처리하며 이번 범위가 아니다.

## 검증

- `createRevenueClosingColumns()`가 기본 계약에서 예외 없는 컬럼을, 예외를 넣은 계약에서 해당 필드의 예외를 반환하는지 확인한다.
- 가드 테스트가 매출마감 폴더의 직접 설정을 차단한다.
