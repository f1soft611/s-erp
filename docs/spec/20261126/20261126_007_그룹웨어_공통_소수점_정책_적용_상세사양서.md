- 공통 규칙: [공통 소수점 계약 가드레일 사양](20261126_001_공통_소수점_계약_가드레일_상세사양서.md)

## 계약 (예외 없음, 화면 전용)

| 문서 | 필드 | 화면 | 구분 |
| --- | --- | --- | --- |
| `groupware.archivePost` | `attachmentCount` | 자료실 게시글 목록 첨부 수 | 수량 `number` |
| `groupware.file` | `fileSize` | 자료실 파일 목록 크기, 문서 첨부 목록 크기 | `decimal` |

## 첨부 수

- 컬럼은 `decimalColumnOptions(getDecimalColumnContract('groupware.archivePost'), 'attachmentCount')`로 타입과 예외를 얻고, 값은 `getValue`(`attachmentCount ?? 0`)로 넘긴다. 그룹웨어 number 정책이 0자리이므로 `3`으로 표시한다.

## 파일 크기

- 저장값은 바이트다. 1024바이트 미만은 정수 바이트(`512 B`)로 표시한다.
- 1024바이트 이상은 KB/MB/GB/TB로 환산하고, 환산한 숫자를 `groupware.file.fileSize`의 정책 규칙(자릿수·반올림·0 표시)으로 표시한다. 예: 정책 2자리 FIXED이면 `1,500` 바이트는 `1.46 KB`, `1,572,864` 바이트는 `1.50 MB`.
- 정책 규칙이 없으면 소수 자릿수를 정하지 않고 바이트(`1,500 B`)로 표시한다.
- 구현: `shared/utils/formatFileSize.ts`(`formatFileSize`, `resolveFileSizeRule`). 자료실 파일 목록과 문서 첨부 목록이 같은 함수를 쓴다.

## 서버

- 변경 없음. 두 문서는 서버 가드의 화면 전용 문서 허용 목록에 둔다.

## 검증

- 첨부 수: 컬럼이 계약을 따름(직접 옵션 없음), 계약 예외가 전달됨, 0자리 정책에서 `3`으로 표시됨.
- 파일 크기: 단위 환산, 정책 자릿수·반올림·0 표시, 정책 없을 때 고정 자릿수 없음, 계약 예외 반영.
- 가드 테스트가 그룹웨어 폴더를 검사하고 자료실·문서 기존 테스트가 통과한다.
