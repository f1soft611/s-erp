## 화면

- 위치: 그룹웨어 > 커뮤니티 > 협업공간 (page key `workspace`)
- 구성: 헤더 + 좌측 방 목록 + 우측 도구 모음(보기 전환, 컬럼 설정, "내가 쓴 글", 검색어, 새 글) + 칸반 또는 피드
- 기준 화면: 공지(피드·댓글), 자료실(페이지 헤더·권한 처리). 헤더·여백·버튼 위치·메시지 영역을 맞춘다.

## 데이터 (프론트 계약안, 백엔드 사양에서 재확정)

| 타입 | 필드 |
|---|---|
| 방 | id, name, defaultView(kanban/feed), columns[{id,name}], groups[{id,name,members[{kind:'user',userId}],level}] |
| 글 | id, roomId, title, body(일반 텍스트), authorId, createdAt, columnId(없으면 null), attachments[{name,size,type}], comments |
| 댓글 | id, authorId, body, createdAt, replies |
| 개인 설정 | hiddenColumnIds, collapsedColumnIds, columnOrder, onlyMine, keyword |

## 권한

- 수준: 읽기 < 저장(글·댓글·카드 이동) < 방 설정(누적). 사용자가 속한 그룹 중 최고 수준을 쓴다.
- 읽기 권한이 없는 방은 목록에 나오지 않는다. 권한이 없는 동작은 숨기거나 비활성화하고 이유를 알린다.
- 1차 구성원은 개별 사용자뿐이다. 개발용 "사용자 전환"으로 확인한다.

## 동작 규칙

- 칸반: 컬럼 숨김·접기·순서는 사용자별 저장. 숨긴 컬럼에는 놓을 수 없다. 새 컬럼은 보이며 맨 뒤에 붙고, 삭제된 컬럼의 개인 설정은 무시한다.
- 카드 이동: 드래그와 카드 "이동" 메뉴. 이동 결과는 모든 사용자에게 같다.
- 방 설정: 컬럼 추가·이름 변경·순서 변경·삭제(카드가 있으면 불가). 컬럼이 없으면 피드 전용. 방 설정 권한 그룹은 최소 1개.
- 글: 제목 필수, 본문 일반 텍스트, 첨부는 파일명·크기·형식만 저장(내려받기 없음).
- 댓글: 공지 댓글 트리와 같은 중첩 방식.
- 저장소: localStorage 키 `s-erp:workspace:data`, 개인 설정 `s-erp:workspace:<userId>:prefs:<roomId>`. 깨진 값이나 접근 실패 시 샘플 데이터로 동작한다.

## 검증 기준

- 권한 판정, 개인 설정 보정, 서비스 규칙(권한 거부, 컬럼 삭제 거부, 마지막 관리자 그룹 거부, 깨진 저장소)이 단위 테스트로 확인된다.
- 페이지 테스트: 화면 렌더, 보기 전환, 이동, 읽기 전용 사용자의 버튼 부재, 읽을 방이 없을 때의 안내.
- 저장·변경 흐름은 진행 표시, 성공 알림, 실패 표시, 변경 취소 확인을 갖춘다.
- 실제 브라우저에서 375/768/1280px 확인.
