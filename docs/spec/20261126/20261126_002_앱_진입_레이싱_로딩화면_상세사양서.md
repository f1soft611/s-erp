## 화면 사양

- 컨테이너: `position: fixed; inset: 0; z-index: 2147483000`, 단색 배경(라이트 `#f4f7fb`, 다크 `#0f172a`).
- 내용 폭 최대 480px, 가운데 정렬. 로고 `F1`(핑크 `#ee1c6e`) + `SOFT`, 부제 `ENTERPRISE RESOURCE PLANNING`, 레이싱카 SVG(폭 190px), 진행바(폭 최대 320px), 문구 `시스템을 준비하고 있습니다...`.
- 모션: 바퀴 회전, 속도선, 바닥 점선 스크롤, 먼지, 진행바 반복. `prefers-reduced-motion: reduce`이면 정지.
- 외부 폰트나 이미지에 의존하지 않는다(시스템 폰트 폴백). 번들 로딩 전에 표시되어야 하기 때문이다.
- 접근성: `role="status"`, `aria-label="시스템을 준비하고 있습니다"`.

## 동작 사양

1. 표시 지연: CSS `animation: boot-in .2s ease .3s both`로 300ms 동안 투명하게 유지한 뒤 나타난다.
2. 해제: `dismissBootSplash()`는 요소의 계산된 opacity가 0.05 미만이면(아직 안 보임) 즉시 제거한다. 보이는 중이면 `is-leaving` 클래스로 200ms 페이드아웃 후 제거한다. 이미 제거됐거나 없으면 아무 동작도 하지 않는다.
3. 준비 신호: `BootSplashReady`가 커밋될 때 해제를 호출한다.
4. 안전 해제: `main.tsx`가 15초 뒤 해제를 호출한다.
5. 테마: 인라인 스크립트가 `localStorage['erp-theme']`를 읽고 값이 `dark`이면 `html`에 `data-boot-theme="dark"`를 붙인다. 읽기 실패 시 라이트.
