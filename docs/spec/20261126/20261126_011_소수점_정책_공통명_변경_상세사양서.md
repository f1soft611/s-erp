# 소수점 정책 공통명 변경 상세사양서

- 작성일: 2026-11-26
- 계획서: [소수점 정책 공통명 변경](../../plan/20261126/20261126_011_소수점_정책_공통명_변경_계획서.md)

## 변경 내용

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 클래스 | `egovframework.let.sales.common.SalesDecimalPolicy` | `egovframework.com.cmm.DecimalPolicy` |
| 영업 진입 | `SalesDecimalPolicy.from(정책, 컬럼)` | `DecimalPolicy.forModule("SALES", 정책, 컬럼)` |
| 모듈 진입 | `SalesDecimalPolicy.forModule(모듈, 정책, 컬럼)` | `DecimalPolicy.forModule(모듈, 정책, 컬럼)` |
| 정책 단위 테스트 | `sales.common.SalesDecimalColumnPolicyTest` | `com.cmm.DecimalPolicyTest` |

- 메서드 시그니처·검증 규칙·예외 메시지·`MAX_INTEGER`·`Rule` 계산은 그대로 둔다.
- `from(policies)` 형태(컬럼 계약 없음)를 쓰던 호출은 `forModule("SALES", policies, Collections.<String, Object>emptyMap())`와 같다.
- 정책 키(`GRID_DECIMAL_{모듈코드}`)와 DB 정책 값은 바뀌지 않는다.

## 검증

- `mvn test` 전체 통과(기존 테스트가 이름만 바뀐 상태로 같은 결과여야 한다).
- `javac --release 8`로 `DecimalPolicy`와 변경한 서비스 구현의 Java 8 API 호환을 확인한다.
- `SalesDecimalPolicy` 문자열 검색 시 현재 지침·소스에 남은 곳이 없고, 남는 곳은 과거 날짜별 문서뿐이다.
