# 20260826_001 모듈별 메뉴 레이아웃 개선 사양

## 1. 목표

메인 화면이 단순 사이드바형 리스트 구조로 느껴지지 않도록, ERP처럼 모듈과 메뉴를 분리하여 업무 중심의 레이아웃을 구성한다.

## 2. 화면 구조

### 2.1 좌측 영역

- S-ERP 로고 및 enterprise portal 배지 표시
- 각 모듈을 버튼 형태로 목록화
- 선택된 모듈은 강조 배경과 텍스트 색상 변경

### 2.2 중간 영역

- 선택된 모듈 이름 표시
- 해당 모듈의 하위 메뉴 버튼 배열
- 선택된 메뉴는 컨테이너 버튼 강조 스타일 적용

### 2.3 메인 영역

- 현재 선택된 모듈/메뉴 조합에 맞는 타이틀
- 사용자에게 보여줄 업무 요약 카드 4개
- 현재 현황 리스트 및 추가 요약 카드
- 상단 AppBar를 통해 검색/알림/로그아웃 액션 노출

## 3. 동작 규칙

- 기본 진입 시 `groupware` 모듈 선택
- 모듈 버튼 클릭 시 하위 메뉴를 즉시 재렌더링
- 메뉴 클릭 시 `currentMenu`와 `content`를 재계산
- 선택 상태와 hover/focus 상태를 시각적으로 구분

## 4. 데이터 규칙

```ts
interface ModuleItem {
  id: string;
  name: string;
  icon: React.ReactNode;
  menus: MenuItem[];
}

interface MenuItem {
  id: string;
  name: string;
  pageKey: string;
}
```

- `moduleItems` 배열로 모듈 정의
- `pageContentMap`으로 메뉴별 상세 화면 데이터 구성
- `defaultPage`로 데이터가 없을 때 안전하게 보완

## 5. 검증 기준

- 모듈 선택 시 하위 메뉴가 갱신된다.
- 메뉴 선택 시 메인 콘텐츠가 바뀐다.
- 정보 밀도가 높아졌는지 사용자가 이해할 수 있다.
- 실제 브라우저에서 도입 전보다 ERP 구조에 가까워졌음을 확인한다.

## 6. 비범위

- 서버 API 신규 구축
- DB 스키마 변경
- 비즈니스 로직 연동
- 과도한 페이지 구조 확장
