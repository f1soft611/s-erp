# 양쪽 그리드 내부 여백 통일 상세사양

## 근거와 범위
- 사용자 요청(2026-11-24): 공통코드 관리와 납품처 관리의 좌우 그리드와 뒤쪽 카드 사이 여백을 맞춘다.
- 사용자 승인: 카드 내부 좌우와 아래를 16px로 맞추고 제목과 그리드 좌우 시작점을 정렬한다. 그리드는 기존처럼 남는 영역을 채운다.
- 기존 외곽 16px 및 납품처 카드 테두리는 [영업관리 본문 여백 사양](20261124_001_영업관리_본문여백_통일_상세사양서.md)을 유지한다.

## 상세 기준
- 공통코드 그룹·상세, 납품처의 거래처·납품처 총 네 카드에 동일하게 적용한다.
- 375/768/1280px에서 각 카드 콘텐츠의 좌우 및 하단 패딩은 16px이다. 상단 패딩과 제목의 위아래 간격은 기존대로 둔다.
- 각 카드 제목 줄의 좌우 시작·끝 경계는 그리드 경계와 같다. 제목 줄에 추가 좌우 패딩을 두지 않는다.
- 그리드는 계속 flex 영역을 채우고 기존 높이 설정·분할·선택·저장 및 모바일 세로 배치를 유지한다. 추가 패딩에 따라 사용 가능한 높이가 줄어들 수 있다.
- 공통 F1-Grid 자체 및 다른 화면은 수정하지 않는다.

## 검증
- 두 화면 각각의 좌우 카드에서 내부 좌우·하단 패딩 및 제목 정렬을 테스트한다.
- 375/768/1280px 실제 브라우저에서 네 카드의 패딩·정렬, 분할 배치, 가로 넘침과 스크린샷을 확인한다.
