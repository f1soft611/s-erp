# 타 업무 본문 여백 통일 상세사양

## 근거와 범위
- 사용자 요청(2026-11-24): 영업관리와 동일하게 적용하되 구매, 품질, 인사 모듈은 제외한다.
- 기준: [영업관리 본문 여백 상세사양](20261124_001_영업관리_본문여백_통일_상세사양서.md).
- 대상: 공통관리, 생산, 그룹웨어, 환경설정의 기존 업무 페이지. 공통관리의 품목 및 단가 기준정보는 구매 업무 화면이 아니므로 포함한다.
- 제외: 구매자재(`materials`), 품질(`quality`), 인사(`hr`), 이미 완료한 영업(`sales`), 로그인·오류·독립 알림/쪽지 창 및 F1-Grid 문서·테스트 도구.

## 동작
- 각 페이지의 주요 본문 외곽을 모든 화면 크기에서 상하좌우 16px로 맞춘다. 헤더, 검색 영역 내부, 상세 패널·다이얼로그 및 embedded 내용은 기존 동작을 유지한다.
- 화면 본문 외부의 오류·결과 알림 영역은 크기와 여백을 영업관리와 같은 공통 규격으로 통일하고 본문 좌우 경계와 맞춘다. 결과 알림이 닫힌 뒤 본문 위 16px을 유지하며 메시지가 보일 때 인접 본문 패딩과 중복되지 않게 한다.
- 등록 화면의 그리드와 같은 카드 내부의 다른 콘텐츠 좌우 간격은 16px로 정렬한다. 그리드 자체 동작, 데이터·권한·저장 및 기존 레이아웃 구조는 변경하지 않는다.
- 모듈관리와 메뉴관리 그리드 위의 빈 흰색 카드 영역은 없애고 다른 현황 화면처럼 본문 외곽 16px 다음에 바로 그리드가 시작된다.
- 사용자 요청에 포함되지 않은 공통 컴포넌트 소비 화면은 기존 기본 스타일을 유지한다.

## 검증
- 해당 페이지 회귀 테스트에 외곽 여백, 현황 알림 표시·닫힘·재조회, 임베디드 예외를 연결한다.
- 375/768/1280px 브라우저에서 실제 렌더링과 가로 넘침을 확인하고 스크린샷을 결과 폴더에 남긴다. 차단된 화면과 미검증 항목은 명시한다.
