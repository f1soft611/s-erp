# 영업관리 본문 여백 통일 상세사양

## 근거와 범위
- 사용자 요청(2026-11-24): 영업관리 페이지의 위아래·좌우 여백을 16px로 통일하고 현황의 검색결과 메시지 닫힘 상태도 확인한다.
- 기존 기준: 수주등록과 수주현황, `docs/directions/20261117/20261117_005_영업등록_메시지여백_통일_작업지시서.md`, `docs/directions/20261117/20261117_016_수주현황_결과알림_닫기_여백_작업지시서.md`.
- 영업관리 등록, 현황, 납품처, 매출마감의 메인 본문 외곽을 모든 뷰포트에서 16px로 한다. 헤더 및 검색 도구 내부 요소 간격, 상세 패널·다이얼로그 내부 간격은 범위 밖이다.
- embedded 등록 폼은 기존처럼 외곽 패딩 0을 유지한다.
- 후속 요청: 납품처 관리의 거래처·납품처 좌우 영역은 수주등록 기본정보와 동일한 MUI `outlined` 외곽 테두리를 사용한다. 기존 그리드 테두리와 분할 동작은 유지한다.
- 후속 화면 피드백: 수주·견적·출하·출하계획·거래명세서 등록의 상세 그리드가 다른 카드 내용과 같은 좌우 16px을 사용한다. 기본정보와 상세 제목·합계의 카드 내부 좌우 여백도 모바일을 포함해 16px로 맞춘다.

## 현황 메시지
- 결과 메시지가 보이면 메시지의 외곽 간격과 본문 사이에 중복 상단 패딩을 두지 않는다.
- 메시지를 닫으면 본문 상단 여백이 16px로 복구된다. 새 조회 시 기존 안내 재표시 동작을 유지한다.
- 메시지와 그리드 좌우 경계는 16px로 정렬한다. 다른 업무의 공통 메시지 기본값은 변경하지 않는다.

## 검증
- 페이지별 본문 4방향 여백과 embedded 예외를 테스트한다.
- 납품처 좌우 영역의 외곽 테두리를 각각 확인한다.
- 등록 상세 그리드와 카드 내 제목·기본정보의 좌우 경계를 비교한다.
- 현황 결과 메시지 표시·닫힘·재조회, 오류 메시지와 그리드 정렬을 테스트한다.
- 375/768/1280px 브라우저 비교 및 스크린샷을 수행한다. 인증 등으로 막히면 미검증 사실을 결과에 기록한다.
