# 대시보드 하위 리프 메뉴 준비 중 페이지 표시 상세 사양서

## 1. 범위와 용어

- 리프 메뉴: `children`이 없거나 빈 배열인 `MenuTreeNode`.
- 부모 메뉴: 하나 이상의 `children`을 가진 `MenuTreeNode`.
- 구현 화면: `DashboardContent`에서 모듈 ID와 `pageKey` 조합으로 전용 페이지를 렌더링하는 메뉴.
- 준비 중 화면: 구현 화면이 없는 리프 메뉴에 표시하는 기존 `ComingSoonPage` 기반 콘텐츠.

## 2. 메뉴 트리 UI 동작

| 메뉴 유형           | 클릭 결과             | 콘텐츠 영역            |
| ------------------- | --------------------- | ---------------------- |
| 부모 메뉴           | 트리 펼침 또는 닫힘   | 기존 선택 콘텐츠 유지  |
| 구현 화면 리프 메뉴 | 해당 메뉴 경로로 이동 | 기존 전용 화면 표시    |
| 미구현 리프 메뉴    | 해당 메뉴 경로로 이동 | 공통 준비 중 화면 표시 |

- `DashboardMenuTree`는 부모 메뉴에 `onMenuSelect`를 호출하지 않는다.
- 리프 메뉴의 선택 스타일은 URL에서 해석된 현재 메뉴 ID를 기준으로 표시한다.
- URL 직접 진입에서도 위와 동일하게 리프 메뉴를 선택한다.

## 3. 선택 및 라우팅 계약

1. `findMenuPath(selectedModule.tree, routeMenuId)`로 URL의 메뉴 노드와 상위 경로를 찾는다.
2. 찾은 노드에 자식이 없으면 `pageKey` 유무와 무관하게 현재 선택 메뉴로 채택한다.
3. 노드에 자식이 있거나 찾지 못하면 기존 접근 가능 첫 메뉴 fallback을 적용한다.
4. 메뉴 경로가 명시돼 있으면 그 경로를 사용하고, 없으면 기존 `getMenuRoutePath`의 모듈 경로와 메뉴 ID 조합을 사용한다.
5. breadcrumb에는 모듈명, 상위 메뉴명, 현재 리프 메뉴명을 순서대로 표시한다.

## 4. 콘텐츠 렌더링 계약

1. 현재 메뉴가 기존 구현 화면의 조건과 일치하면 기존 페이지 컴포넌트를 렌더링한다.
2. 현재 메뉴가 리프 메뉴이며 기존 구현 화면 조건과 일치하지 않으면 `PageHeader`와 `ComingSoonPage`를 렌더링한다.
3. `ComingSoonPage`의 본문은 `{현재 메뉴명} 메뉴는 추후 서비스될 예정입니다.` 형식을 사용한다.
4. 부모 메뉴 또는 유효하지 않은 경로는 준비 중 화면으로 전환하지 않으며 기존 fallback 콘텐츠를 유지한다.

## 5. API, 권한, 예외 처리

- API 계약: 변경 없음. 기존 `fetchMyMenus()`와 메뉴 응답의 `id`, `name`, `path`, `pageKey`, `children` 소비 방식을 유지한다.
- 권한: 변경 없음. 서버가 반환한 접근 가능 메뉴만 대시보드 트리에 존재한다.
- 네트워크 오류: 기존 메뉴 조회 재시도와 오류 화면 동작을 변경하지 않는다.
- 유효하지 않은 URL: 기존 Not Found 또는 fallback 라우팅 규칙을 변경하지 않는다.

## 6. 반응형 및 접근성

- 기존 사이드바의 모바일 메뉴 열기·닫기 동작을 유지한다.
- 준비 중 콘텐츠는 375px, 768px, 1280px 뷰포트에서 제목과 본문이 겹치거나 잘리지 않아야 한다.
- 리프 메뉴는 키보드 및 포인터로 선택할 수 있어야 하며, 선택 상태는 기존 트리의 스타일과 접근성 속성을 유지한다.

## 7. 검증 기준

- `pageKey`가 없는 리프 메뉴 클릭 및 직접 URL 진입에서 준비 중 문구와 메뉴명이 표시된다.
- 기존 구현 화면 리프 메뉴는 종전 전용 페이지를 렌더링한다.
- 부모 메뉴 클릭은 트리 상태만 변경하고 URL 및 콘텐츠를 변경하지 않는다.
- 메뉴 응답, 권한, API 요청, DB 스키마에 대한 변경이 없음을 확인한다.
- 관련 Vitest, 전체 Vitest, TypeScript/Vite 빌드와 실제 브라우저 모바일·데스크톱 캡처를 완료한다.
