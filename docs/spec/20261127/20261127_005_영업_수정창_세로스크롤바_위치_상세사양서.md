## 1. 공통 대화상자

| 항목 | 값 |
| --- | --- |
| prop | `disableBodyGutters?: boolean`(기본 false) |
| false(기존) | `DialogContent` `px: { xs: 2, sm: 3 }`, `py: 2` |
| true | `DialogContent` `px: 0`, `py: 0`. 자식 스크롤 영역이 `COMMON_DIALOG_BODY_PADDING`을 직접 적용 |
| export | `COMMON_DIALOG_BODY_PADDING = { px: { xs: 2, sm: 3 }, py: 2 }` |

## 2. 화면

| 수정 창 | 스크롤 영역 | embedded 여백(변경 후) | 메뉴 화면 여백 |
| --- | --- | --- | --- |
| 견적 | `견적 입력 내용` | `COMMON_DIALOG_BODY_PADDING` | `px/pt/pb: 2`(유지) |
| 수주 | 수주 입력 영역 | 같음 | 유지 |
| 출하 | `출하 입력 내용` | 같음 | 유지 |
| 거래명세서 | `거래명세서 입력 내용` | 같음 | 유지 |
| 출하계획(현황 화면 내 창) | 창 내부 스크롤 상자 | 같음 | 해당 없음 |

결과: 스크롤 영역이 창 전체 폭을 차지해 세로 스크롤바가 창 오른쪽 끝에 생기고, 내용 위치는 변경 전과 같다(여백이 `DialogContent`에서 스크롤 영역 안쪽으로 이동).
