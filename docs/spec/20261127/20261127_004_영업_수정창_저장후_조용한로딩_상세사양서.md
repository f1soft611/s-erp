## 1. 동작

| 상황 | 목록 그리드 로딩(`aria-busy`) | 기존 행 | 잠기는 것 |
| --- | --- | --- | --- |
| 조회 버튼·상세검색·다시 시도 | 표시 | 응답 후 교체 | 검색 영역 |
| 수정 창 저장 중 | 표시 안 함 | 유지 | 수정 창 저장·취소 버튼, 수정 창 입력 |
| 수정 창 저장·삭제 성공 후 재조회 | 표시 안 함 | 응답 후 교체 | 없음 |
| 재조회 실패 | 표시 안 함 | 유지 | 현황 메시지 영역에 오류 |

## 2. 화면별

- 거래명세서현황: `useSalesStatementStatus`에 `quietRefresh: number | null`. `refreshQuietly()`는 다음 refresh 번호를 `quietRefresh`에 기록한 뒤 `refresh`를 올린다. 목록 요청 시작 블록에서 `quietRefresh !== refresh`일 때만 `setLoading(true)`.
- 출하계획현황: `saving` 상태 추가. `runSearch(next, { quiet = false } = {})`에서 quiet이면 `setLoading(true)`/`setLoading(false)`를 하지 않는다. 저장 버튼 `disabled={saving || !policyReady}`, 취소 `disabled={saving}`, 그리드 `editable={... && !saving && ...}`, `closeDialog`는 `saving`이면 무시.
