## 1. 공통 동작

| 요소 | 위치 | 사양 |
| --- | --- | --- |
| 오류 분류 | `shared/hooks/useInitialLoadState.ts` `toPageLoadError(cause)` | `ApiNetworkError` → `network`, `ApiResponseError` 401 → `authentication`, 403 → `forbidden`, 그 외 → `server` |
| 상태 훅 | `useInitialLoadState({ networkOnly })` | `start()` 로딩 시작, `succeed()` 오류 해제(이후 실패는 무시), `fail(cause)` 오류 설정. 취소(`AbortError`)는 무시. `networkOnly: true`면 `network`일 때만 오류를 설정하고 나머지는 화면 내 메시지에 맡긴다 |
| 연결 실패 판별 | `shared/services/apiErrors.ts` `isApiNetworkError(cause)` | `ApiNetworkError` 인스턴스면 true. 화면은 이 값이 true이면 자체 `setError`를 호출하지 않는다 |
| 정책 상태 | `usePolicyDecimalStatus()` | 정책 조회 실패 시 `status: 'error'`, 원인이 연결 실패면 `network: true` |
| 정책 오류 안내 | `SalesDecimalPolicyError({ status, network })` | `status === 'error'`이고 `network`가 아닐 때만 안내를 표시한다 |
| 오류 화면 | `shared/components/PageLoadBoundary.tsx` | `error`가 있으면 본문 대신 `role="alert"` 영역에 문구와 `<label> 다시 불러오기` 버튼을 표시. 로딩 중에는 버튼 비활성. network 문구: "서버에 연결하지 못했습니다. 네트워크 상태를 확인한 뒤 다시 시도해 주세요." |

## 2. 화면별 적용

"정책 포함"은 오류 화면 `error`에 `policyState.network ? 'network'`를 함께 연결했다는 뜻이다. 이 화면들의 다시 시도는 정책이 연결 실패였을 때 `resetGridDecimalPolicyCache()`를 먼저 호출한다.

| 화면 | page key | 오류 화면 label | 상태 관리 | 정책 포함 | 다시 시도 동작 |
| --- | --- | --- | --- | --- | --- |
| 견적등록 | `quotation-create` | 견적등록 공통코드 / 견적등록 | `useInitialLoadState({ networkOnly })` 2개(공통코드, 견적 상세) | 견적등록만 | 공통코드 재조회 / 견적 상세 재조회 |
| 수주등록 | `create` | 수주등록 | `useInitialLoadState({ networkOnly })` | 예 | `loadRetry` 증가로 재조회 |
| 출하계획등록 | `delivery-plan-create` | 출하계획등록 | 정책 상태만 사용 | 예(정책만) | `resetGridDecimalPolicyCache()` |
| 출하계획현황 | `delivery-plan-status` | 출하계획현황 | `useInitialLoadState({ networkOnly })` | 예 | 현재 조건으로 `runSearch` |
| 출하등록 | `delivery-create` | 출하등록 | 화면 자체 `loadError`·`loading` | 예 | 저장된 출하가 있으면 `load(savedId)`, 없으면 기준일 재조회 |
| 출하현황 | `delivery-status` | 출하현황 | 화면 자체 `initialError`(첫 성공 전만) | 아니오 | `refresh` 증가로 재조회 |
| 거래명세서등록 | `statement-create` | 거래명세서등록 | `useInitialLoadState({ networkOnly })`(훅) | 예 | `retryLoad` |
| 거래명세서현황 | `statement-status` | 거래명세서현황 | `useInitialLoadState({ networkOnly })`(훅) | 아니오 | `refresh` 증가로 재조회 |
| 매출마감 | `revenue-closing` | 매출마감 | `useInitialLoadState({ networkOnly })` | 아니오 | 현재 검색 조건 재적용 |
| 납품처관리 | `destinations` | 납품처관리 | `useInitialLoadState({ networkOnly })`(훅) | 아니오 | `refresh` |

정책 Provider(`GridDecimalModuleProvider`)는 `DashboardPage`에서 모듈 단위로 감싼다. 화면 테스트도 같은 Provider와 데이터 라우터(`useBlocker`) 안에서 렌더링해야 실제와 같은 조건이 된다.
