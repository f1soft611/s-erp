## 2. 화면 구조

- `자주 쓰는 결재선` 제목 아래 동일 행에 select와 `설정` 버튼을 둔다.
- select는 남은 폭을 사용하고, 설정 버튼은 우측에 둔다. 좁은 화면에서 select는 줄어들 수 있으며 전체 화면 가로 넘침을 만들지 않는다.
- select 외곽 높이는 `결재선 사용자 선택` 및 `참조자 선택` 입력과 같은 38px로 하고 표시값을 수직 중앙 정렬한다. 같은 행의 설정 버튼은 stretch 정렬로 select와 외곽 높이를 맞추되 medium variant를 유지한다.
- 미선택 문구 `자주 쓰는 결재선 선택`은 사용자 선택기 입력 라벨과 같은 0.82rem 글꼴 크기 및 600 굵기를 사용한다. 선택된 템플릿명과 메뉴 옵션의 글꼴은 기존 스타일을 유지한다.
- select 접근성 이름은 `자주 쓰는 결재선`으로 한다. 초기/미선택 항목은 `자주 쓰는 결재선 선택`으로 표시한다.
- `설정`은 기존 F1-Grid 템플릿 관리 모달을 연다.
- `자주 쓰는 결재선 저장` 버튼은 결재선 설정 `CommonDialog.footerStart`에 배치한다. `취소`와 `적용`은 기존 footer actions 오른쪽에 유지한다.
- 저장 시작 버튼은 기존 결재선 이름 입력 모달을 연다.

## 3. 템플릿 목록 및 선택

1. 결재선 설정 창이 열릴 때 현재 문서 코드로 템플릿 요약 목록을 조회한다.
2. 조회 중에는 select를 비활성화하고 진행 상태를 알린다. 조회 성공 시 템플릿 이름을 옵션으로 표시한다. 목록이 비어 있으면 안내 항목만 표시한다.
3. 요약 목록을 선택하면 기존 상세 조회 API를 호출한다. 요청 중에는 select를 비활성화한다.
4. 상세 응답의 문서 코드 및 참여자 유효성 검증을 통과한 경우에만 임시 결재선과 참조자를 함께 교체한다. 성공한 항목을 select의 선택값으로 유지한다.
5. 템플릿 적용은 결재선 설정 창 내부 임시 상태만 변경한다. 작성 화면은 기존 결재선 설정의 `적용` 버튼 이후 변경된다. 취소/닫기는 기존 동작대로 임시 변경을 폐기한다.
6. 사용자가 직접 결재선을 수정해도 select 값은 자동으로 변경하지 않는다.

## 4. 설정 모달 및 저장 흐름

- 설정 버튼을 눌러 기존 관리 모달을 연다. 관리 모달의 목록 조회/행별 적용·삭제/이름 인라인 편집 및 저장/확인 흐름은 그대로 둔다.
- 관리 모달이 닫히면 요약 목록을 새로 조회한다. 이름 변경 시 선택 ID를 유지하고 표시 이름을 갱신한다. 선택 항목이 삭제된 경우 선택을 초기화하되 이미 반영된 임시 결재선은 유지한다.
- footer 왼쪽의 저장 시작 버튼은 기존 이름 입력 모달 및 생성 API를 사용한다.
- 생성 성공 후 요약 목록을 갱신하고 새 템플릿을 선택값으로 설정한다. 목록 갱신이 실패하더라도 생성 API가 반환한 요약 항목을 옵션에 반영하고, 저장 성공과 목록 갱신 실패를 구분해 알린다.

## 5. 오류 처리

- 최초 요약 목록 조회 및 관리 모달 종료 후 목록 갱신 실패는 오류와 재시도 동작을 제공한다. 실패를 빈 목록으로 표시하지 않으며 임시 결재선을 유지한다.
- 상세 조회 실패, 문서 코드 불일치 또는 참여자 검증 실패 시 기존 임시 결재선/참조자를 유지하고 오류를 표시한다. 사용자가 선택한 select 항목은 남긴다.
- 템플릿 생성 실패 시 기존 임시 결재선과 기존 선택값을 유지하고 오류를 표시한다.
- 조회/적용 중 반복 요청을 방지하며 진행 상태를 접근성 트리에 노출한다.

## 6. 검증 기준

- 설정 창을 열 때 올바른 문서 코드로 목록 API가 호출되고, 로딩 완료 후 select 옵션이 나타난다.
- select 변경은 상세 API를 호출하고 성공하면 결재선/참조자 임시 상태를 갱신하며 작성 화면 적용은 별도 확인한다.
- 상세 로딩/실패에서 선택값과 기존 임시 데이터의 동작이 명세와 일치한다.
- 설정 버튼으로 기존 관리 모달을 열 수 있고 종료 후 이름 변경·추가·삭제가 목록에 반영된다.
- footer 저장 시작 버튼의 위치와 이름 입력 저장 흐름, 생성 후 새 항목 선택, 재조회 실패 시 저장 성공의 명시가 검증된다.
- 기존 F1-Grid 관리, 이름 검증/부분 실패, 취소/적용 경계 테스트가 유지된다.
- 375px, 768px, 1280px에서 겹침 및 페이지 가로 넘침이 없다.

## 7. 비범위

- 템플릿 선택 시 작성 화면 결재선을 자동 반영하거나 자동 저장하는 동작
- 저장한 결재선 구성의 새 기능 또는 공유 기능
