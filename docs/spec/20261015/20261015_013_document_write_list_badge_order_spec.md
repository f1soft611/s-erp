# 문서작성 리스트 배지 순서 상세 사양서

**문서 번호:** 20261015_013

## 목적

문서작성 페이지의 리스트형 문서 행에서 결재상태와 문서구분의 표시 순서를 바꾼다.

## 대상 및 현재 동작

- `frontend/src/pages/groupware/documents/write/DocumentWritePage.tsx`가 공용 `ListView`로 문서 목록을 렌더링한다.
- 문서 종류는 `categoryLabel`, 결재상태는 `statusLabel`에 매핑된다.
- 공용 `ListView`는 공지사항 페이지에서도 쓰이며 현재 카테고리 → 상태 순서로 두 배지를 렌더링한다.

## 기능 요구사항

1. 문서작성 페이지 리스트형 목록은 결재상태 → 문서구분 순으로 표시한다.
2. 순서는 DOM 순서와 시각적 순서에서 동일해야 한다.
3. 공용 `ListView`에서 순서 속성을 전달하지 않은 기존 사용처는 카테고리 → 상태 순서를 유지한다.
4. 기존 배지 색상, 크기, 라벨, 조건부 렌더링, 행 클릭 동작 및 데이터 매핑을 변경하지 않는다.
5. 피드형 문서 표시, 상세 결재 툴바, 공지사항 표시를 변경하지 않는다.

## 구현 계약

- `ListView`에는 두 가지 배지 순서를 표현하는 타입 안전한 선택적 속성을 추가한다.
- 기본값은 기존 카테고리 우선 순서다.
- `DocumentWritePage`의 리스트형 문서 목록에서만 결재상태 우선 값을 지정한다.
- 배지 중 하나가 없는 경우 존재하는 배지만 표시하며 빈 자리표시자를 추가하지 않는다.

## 검증 기준

- `common-view-mode.test.tsx`: 순서 속성이 없을 때 카테고리 배지가 상태 배지보다 먼저 나타난다.
- `document-write-page.test.tsx`: 리스트 문서 행의 결재상태 배지가 문서구분 배지보다 먼저 나타난다.
- 위 테스트 파일을 통과하고 `npm run build`가 성공한다.
- Problems 검사 및 `git diff --check`에 변경 관련 오류가 없다.
- 실행 중인 앱에서 375px, 768px, 1280px 뷰포트의 리스트를 확인하고 캡처를 결과 폴더에 저장한다.

## 제외 범위

- 전역 `ListView` 기본 순서 변경.
- 공지사항 리스트의 배지 순서 변경.
- 배지 시각 스타일, 데이터 계약, API, 승인 처리, 행 클릭 동작 수정.
