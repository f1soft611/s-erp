# 20261015_002 문서 작성 결재선 순번 표시 통일 상세사양서

## 1. 목적 및 기준

문서 작성 모달과 문서 상세 결재선의 결재·합의 순번 원형 배지 크기와 표현을 통일한다. 순번 값과 결재 업무 흐름은 변경하지 않는다.

- 작업지시서: [20261015_002 작업지시서](../../directions/20261015/20261015_002_문서작성_결재선_순번_표시_통일_작업지시서.md)
- 계획서: [20261015_002 계획서](../../plan/20261015/20261015_002_문서작성_결재선_순번_표시_통일_계획서.md)
- 승인 설계: [문서 결재선 순번 배지 통일 설계](../../superpowers/specs/2026-10-15-document-approval-sequence-badge-design.md)

## 2. 현재 동작과 변경점

| 화면 | 현재 순번 표시 | 목표 |
|---|---|---|
| 작성 모달 결재자 | 15px 채움 원형 배지와 이름이 왼쪽 정렬된 하단 행 | 24px 원형 테두리 배지, 순번·이름을 한 묶음으로 가운데 정렬 |
| 작성 모달 합의자 | 15px 채움 원형 배지 | 24px 원형 테두리 배지, 숫자는 원 중앙 |
| 상세 승인자 | 24px 원형 테두리 배지, 이름과 가운데 정렬된 행 | 공통 24px 원형 테두리 배지 사용 |
| 상세 합의 단계 | 28px 원형 테두리 배지 | 공통 24px 원형 테두리 배지 사용 |

작성 모달은 현재 선택한 결재선 단계 순번을 유지한다. 상세 합의는 기존대로 단계별 그룹에서 순번을 한 번 표시한다. 참여자 구성 및 정렬 순서는 그대로 유지한다.

## 3. 공통 배지 사양

- 결재선 기능 내부의 공통 `ApprovalSequenceBadge` 컴포넌트를 작성 모달과 상세 화면에서 사용한다.
- 실제 콘텐츠 상자 크기는 가로 24px, 세로 24px이며 원형 테두리(`borderRadius: 50%`)로 표시한다.
- 기존 상세 승인 배지와 같은 1px 테두리, `text.secondary` 테두리색, `1rem` 굵은 숫자를 적용한다.
- 배지 내부는 grid/center 정렬로 숫자를 가로·세로 중앙에 놓는다.
- 배지가 flex item으로 사용될 때 24px 크기가 축소되지 않도록 한다.
- 작성 모달에서 기존의 채움 배경과 전경색은 제거해 상세의 테두리 배지 표현에 맞춘다.
- 모달의 접근성 이름 `참여 순번 {order}`은 유지한다. 상세 화면의 기존 그룹/순번 테스트 식별자는 유지한다.

## 4. 화면별 배치

### 4.1 문서 작성 모달

- 결재 카드 하단은 24px 순번과 결재자 이름을 가로로 배치하고 컨테이너 기준으로 가운데 정렬한다.
- 결재자 이름의 말줄임과 title은 유지하며, 순번이 좁은 카드에서 축소되지 않도록 한다.
- 합의자 칩은 기존 배치와 순번 반복 방식을 유지하고 배지 외형만 공통 스타일로 변경한다.
- 결재선 추가, 참여자 제거, 빈 결재 슬롯, 다음 결재선 번호, 선택 및 저장 흐름은 변경하지 않는다.

### 4.2 문서 상세

- 승인 순번 배지는 기존 데이터(test ID, stageOrder)와 이름의 중앙 정렬을 유지하고 공통 컴포넌트를 적용한다.
- 합의는 현재 단계별 그룹 헤더를 유지하고 단계 순번 원형만 24px 공통 배지로 변경한다.
- 합의 참여자 그룹, 연결선, 상태·프로필·도장, 참조자 표시, 상세 화면 액션은 변경하지 않는다.

## 5. 범위 제외 및 호환성

- 순번 산정 로직, 승인/합의 단계 저장 형식, 상세 API 응답, 백엔드, DB, 권한, 결재 처리 규칙 변경
- 합의 그룹 표시 횟수나 참여자별 번호 정책 변경
- 결재선 편집 및 삭제 동작 변경
- 다른 그룹웨어 화면의 번호 배지 변경

변경 파일은 `frontend/src/pages/groupware/documents/write/components/`와 직접 관련된 `frontend/tests/document-write-page.test.tsx`, 날짜별 문서 및 결과 경로에 한정한다.

## 6. 검증 기준

### 회귀 테스트

`frontend/tests/document-write-page.test.tsx`에서 아래 사항을 확인한다.

1. 작성 모달의 결재·합의 배지가 모두 24px이고 원형 테두리이며 숫자가 가운데 위치한다.
2. 작성 모달 결재자 배지와 이름 묶음의 컨테이너가 가운데 정렬된다.
3. 결재자 이름의 title/말줄임, 배지의 `참여 순번 {order}`, 기존 결재선 순번 및 합의 단계 번호가 보존된다.
4. 상세 승인·합의 배지가 모두 24px 공통 원형이며 상세 승인자의 기존 중앙 정렬 테스트가 계속 통과한다.
5. 상세 합의 단계 배지는 단계 그룹마다 한 번만 노출되고 참여자/상태/프로필 테스트가 유지된다.

### 실행 명령

`frontend` 디렉터리에서 실행한다.

```powershell
npm run test -- tests/document-write-page.test.tsx
npm run build
```

### 실제 브라우저

- 기존 S-ERP 개발 서버 `http://127.0.0.1:4173`을 확인해 재사용한다.
- 문서 작성 모달과 상세 결재선에서 1280px, 768px, 375px 폭으로 크기·중앙 정렬을 확인한다.
- 375px에서 페이지 전체에 의도하지 않은 가로 넘침이 없어야 한다.
- 최종 결과 문서에 각 화면의 확인 결과 및 개인정보가 포함되지 않은 스크린샷을 남긴다.
