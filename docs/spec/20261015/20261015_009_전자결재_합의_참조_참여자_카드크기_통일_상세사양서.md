## 2. 참여자 카드 규격

### 2.1 합의·참조 공통 치수

- 폭 동작은 `flex: 0 1 240px`, `minWidth: min(100%, 190px)`, `maxWidth: 100%`를 사용한다.
- 카드 외곽 높이는 `66px`로 고정하고 `box-sizing: border-box`를 적용한다.
- 내부 여백은 `8px`로 동일하게 유지한다.
- 프로필 이미지는 가로·세로 각각 `36px`로 고정하고 축소하지 않는다.
- 두 카드 모두 이름을 첫째 줄에, 부서를 둘째 줄에 표시한다. 이름과 부서 텍스트는 기존처럼 넘칠 경우 한 줄 말줄임을 허용한다.
- 부서 값이 `null`, 빈 문자열 또는 공백만 있는 문자열이면 사용자에게 `부서없음`으로 표시한다.

### 2.2 합의 카드 표시

- 단계 순번, 합의 참여자 순서, 사용자 이름 및 기존 합의 상태 라벨/색상을 유지한다.
- 상태 배지는 둘째 줄의 부서명 옆에 유지한다.
- 부서가 없을 때도 둘째 줄을 표시하고 `부서없음`과 상태 배지를 함께 표시한다.
- 이름 텍스트의 기존 프로필 이미지 대체 방식과 상세 결재선 단계 구조는 변경하지 않는다.

### 2.3 참조 카드 표시

- 참조 참여자 순서와 프로필 이미지/이름 표시를 유지한다.
- 부서 정보가 없거나 공백일 때 `부서없음`을 두 번째 줄에 표시한다.
- 합의에만 있는 상태 배지나 단계 순번을 참조 카드에 추가하지 않는다.

## 3. 반응형 및 비범위

- 참여자 콘텐츠 열 너비에 맞춰 카드가 유동적으로 줄어들고, 여러 카드가 콘텐츠 열 안에서 줄바꿈한다.
- 제목 열과 기존 결재선 행 규칙은 변경하지 않는다.
- 결재 처리, 상태 전이, API, 서버, DB, 문서작성 편집 결재선은 변경하지 않는다.

## 4. 검증 기준

1. 상세 결재선 회귀 테스트에서 합의 및 참조 카드가 같은 폭 규칙, 높이 `66px`, 내부 여백 `8px`, 아바타 `36 × 36px`를 사용하는지 확인한다.
2. 부서 없는 합의자와 공백 부서인 합의자/참조자 모두 `부서없음`을 표시하는지 확인한다.
3. 합의 상태 및 단계 순서, 참조 정보, 프로필 이미지 표시/fallback, 기존 행 구조 회귀 검증을 유지한다.
4. 집중 테스트, `npm run build`, `git diff --check`를 실행한다.
5. 실제 브라우저의 375px, 768px, 1280px 폭에서 카드 높이와 아바타 정합, 카드 내부 텍스트 줄, 목록 줄바꿈, 페이지 전체 가로 넘침을 확인한다. 접근이 막히면 사유와 미수행 항목을 결과 문서에 기록한다.
