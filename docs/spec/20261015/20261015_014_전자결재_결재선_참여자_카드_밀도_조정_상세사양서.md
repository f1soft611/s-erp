## 2. 카드 규격

### 2.1 공통 사용자 이름

- 읽기 전용 상세 결재선에서 결재·합의·참조 사용자 이름은 모두 14px(`0.875rem`)로 표시한다.
- 결재 카드의 가로/세로 치수, 아바타, grid row, 도장/상태 아이콘 및 순번 배지는 바꾸지 않는다.

### 2.2 합의 및 참조 카드 geometry

- 참여자 콘텐츠 flex row에서 각 카드는 `flex: 1 1 240px`를 사용한다.
- `minWidth: min(100%, 190px)`, `maxWidth: 100%`, 콘텐츠 열의 내부 줄바꿈은 유지한다.
- 바깥 높이는 `56px`, `boxSizing: border-box`를 사용한다.
- padding은 좌우 8px, 위아래 6px이다(`px: 1`, `py: 0.75`).
- 아바타는 각 변 32px이며 줄어들지 않는다.
- 카드 안의 이름/부서는 각각 한 줄로 렌더링하며, 잘릴 때 기존 말줄임/툴팁 동작을 유지한다.
- 합의·참조 부서 텍스트는 14px, line-height 18px이다.
- 합의 상태 라벨은 둘째 줄의 부서 옆에 남고 14px, line-height 18px을 사용한다.
- 부서가 null/빈 문자열/공백뿐이면 `부서없음`을 그대로 표시한다.

## 3. 동작 보존 및 범위

- 합의 단계/순번/참여자 순서/상태 라벨과 색상, 참조 순서 및 아바타 fallback은 변하지 않는다.
- 상위 합의/참조 행 grid, 제목 열 너비, 참여자 콘텐츠 영역 wrapping은 변경하지 않는다.
- 결재 처리, API, 백엔드, DB, 문서 작성 편집 결재선은 변경하지 않는다.

## 4. 검증 기준

1. 상세 테스트에서 합의·참조 카드의 `flex: 1 1 240px`, 최소/최대 너비, 높이 56px, box sizing, 세로 padding 6px, 아바타 32px을 확인한다.
2. 결재/합의/참조 사용자명 및 합의/참조 부서 텍스트가 14px이고 합의 상태 라벨이 14px/18px인지 확인한다.
3. 기존 합의/참조 `부서없음`, 상태 라벨, 순번, 순서 및 이미지 fallback assertion을 유지한다.
4. 집중 Vitest, 대상 파일 Oxlint, 프론트 빌드, Problems, `git diff --check`가 수행된다.
5. 브라우저에서 375px, 768px, 1280px의 줄 폭 분배, 카드 치수, 텍스트 겹침/잘림, 전체 가로 넘침을 점검한다. 캡처는 비식별 화면에서만 생성하고 접근이 불가하면 사유를 기록한다.
