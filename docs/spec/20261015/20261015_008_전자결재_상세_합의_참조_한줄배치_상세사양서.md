# 20261015_008 전자결재 상세 합의·참조 한 줄 배치 상세사양서

## 1. 목적 및 기준

전자결재 상세 결재선에서 합의 및 참조 제목을 참여자 목록과 같은 행에 배치하고, 두 영역의 제목 너비와 기본 높이를 동일하게 한다. 참여자 데이터와 결재 처리 동작은 변경하지 않는다.

## 2. 화면 레이아웃

### 2.1 공통 행 구조

- 합의와 참조 영역은 각각 제목 열과 참여자 콘텐츠 열을 가진 CSS grid 행으로 표시한다.
- 제목 열 너비는 `64px`, 콘텐츠 열은 `minmax(0, 1fr)`로 동일하게 구성한다.
- 두 행의 최소 높이는 `72px`로 같게 설정한다. 실제 내용이 늘어나는 경우 행은 콘텐츠에 맞춰 확장될 수 있다.
- 제목과 콘텐츠는 각 영역의 같은 행 안에 놓이며, 기존 제목 텍스트와 강조 스타일을 유지한다.
- 참여자 수가 많거나 뷰포트가 좁으면 참여자 콘텐츠 내부에서만 자동 줄바꿈한다. 제목은 첫 번째 열에 남고 페이지 전체 가로 스크롤은 추가하지 않는다.

### 2.2 합의 콘텐츠

- 합의 그룹의 기존 `stageOrder` 순서와 단계별 외곽 카드, 순번 배지, 참여자 순서 및 상태를 유지한다.
- 합의 참여자 카드와 프로필/부서/상태 표시를 변경하지 않는다.
- 합의 단계가 여러 개인 경우 참여자 콘텐츠 열 안에서 기존 순서대로 세로 배치한다.

### 2.3 참조 콘텐츠

- 참조 참여자 순서, 프로필/이름/부서 표시 및 기존 카드 스타일을 유지한다.
- 참조 참여자 카드는 콘텐츠 열의 가용 폭에 따라 자동 줄바꿈한다.
- 참조 참여자가 없으면 기존 조건에 따라 참조 영역을 표시하지 않는다.

## 3. 범위와 비범위

- 수정 대상은 `DocumentApprovalDetailFeed.tsx`의 상세 합의/참조 레이아웃과 해당 동작을 검증하는 `document-write-page.test.tsx`에 한정한다.
- 승인 카드, 결재 순서/상태, 합의 처리 규칙, API, 백엔드, DB는 변경하지 않는다.
- 문서작성 화면의 편집 결재선 레이아웃은 이번 범위가 아니다.

## 4. 검증 기준

1. 기존 읽기 전용 상세 테스트에서 합의/참조 제목과 콘텐츠가 각 행의 형제 요소로 배치되는지 확인한다.
2. 두 그룹이 모두 `64px minmax(0, 1fr)` grid 열과 `72px` 최소 높이를 적용하는지 확인한다.
3. 기존 합의 순번, 참여자 순서, 상태, 프로필 대체 표시 및 참조 부서 표시 회귀 검증을 유지한다.
4. 변경 전 전체 `document-write-page.test.tsx` 기준 실행은 21개 실패/62개 통과였으며, 사용자가 지정한 검증 범위에 따라 변경 후에는 읽기 전용 상세 결재선 집중 테스트를 실행한다. 초기 `npm run build` 오류와 후속 성공 재실행을 이번 범위 밖의 변경과 구분해 기록한다.
5. 빌드 가능 시 375px, 768px, 1280px 브라우저 폭에서 제목/콘텐츠 겹침, 참여자 콘텐츠 줄바꿈 및 페이지 전체 가로 넘침 여부를 확인한다. 빌드 오류로 브라우저 확인이 차단된 경우 미수행과 원인을 결과 문서에 명시한다.
