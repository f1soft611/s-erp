# 20261015_017 문서작성 첨부파일 상태 뱃지 표시 상세 사양서

## 목적과 승인 근거

파일 업로드 상태를 파일 행에 통합해 한눈에 알아볼 수 있게 한다. 승인된 시안은 [첨부파일 상태 뱃지 디자인](../../superpowers/specs/2026-10-15-document-attachment-status-badge-design.md)에 기록되어 있다.

## UI 상태 계약

| 상태 | 뱃지 문구 | 뱃지 색상 | 추가 동작 |
|---|---|---|---|
| `uploaded` | 완료 | 초록 | 삭제 |
| `pending` | 대기 | 중립 | 삭제 |
| `failed` | 실패 | 빨강 | 재시도, 삭제 |
| `unknown` | 확인 필요 | 황색 | 상태 확인, 삭제 제한(기존 정책 유지) |

- 상태 뱃지는 파일 행 안에서 파일명 뒤, 삭제 버튼 앞에 보인다.
- 기존 상태 보조 문구(`업로드 완료`, `저장 후 업로드`, 오류 문자열)는 첨부 행 아래에서 렌더링하지 않는다.
- 재시도/상태 확인 버튼은 기존 레이블과 핸들러를 보존하고 파일 행에서 사용할 수 있게 둔다.
- 저장 실패 등 현재 모달의 오류 안내는 그대로 유지한다.
- 파일명만 flex shrink가 가능하고 상태 뱃지, 보조 동작, 삭제 버튼은 폭을 유지한다.

## 영향 파일

- `frontend/src/shared/components/feed/AttachmentList.tsx`: 선택적 상태 뱃지 슬롯을 삭제 액션 앞에 표시
- `frontend/src/pages/groupware/documents/write/components/DocumentComposerDialog.tsx`: 상태별 MUI 뱃지, 재시도/확인 액션을 행에 배치하고 아래 텍스트 제거
- `frontend/tests/document-write-page.test.tsx`: 완료/대기 뱃지, 아래 텍스트 제거, 실패/확인 동작 검증

## 회귀 및 완료 조건

- 기존 파일과 신규 파일의 `uploaded`/`pending` 상태가 행 안 뱃지로 구분된다.
- 실패/unknown 뱃지로 상태를 표시하면서 해당 행의 재시도/상태 확인 버튼은 동작한다.
- 아래 상태 문구는 표시되지 않으며 오류·삭제 정책과 기존 파일/신규 업로드 동작은 보존된다.
- 파일명/뱃지/삭제 버튼 행 구조가 최소 너비에서도 줄바꿈이나 가로 넘침을 유발하지 않도록 스타일을 둔다.
- 집중 테스트, 빌드 및 문제 진단이 통과한다. 인증 브라우저 접근이 안 되면 결과 문서에 명시한다.
