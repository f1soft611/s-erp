## 동작 사양

- `disableFiltering`이 `false`이면 `필터 해제` 항목을 표시하고, `disableSorting`이 `false`이면 `정렬 해제` 항목을 표시한다.
- 두 항목 중 적어도 하나가 표시될 경우, 필터/정렬 항목 그룹 앞의 구분선을 표시한다.
- 두 항목이 모두 숨겨질 경우, 그룹 앞의 구분선은 생략한다.
- `설정을 기본값으로 복원` 항목 바로 앞의 기존 구분선은 항상 표시한다.
- `컬럼 길이 자동 조정` 및 행 작업 그룹을 나누는 나머지 구분선은 변경하지 않는다.
- 필터/정렬 상태가 비어 있어 항목이 비활성화된 경우에도 항목 자체가 노출되므로 구분선은 표시한다. 구분선 조건은 `disableFiltering`/`disableSorting` 노출 정책에만 기반한다.

## 테스트 기준

1. 기본 F1Grid에서 필터 해제/정렬 해제 항목이 모두 노출되고 메뉴 구분선 수 및 순서가 기존과 같다.
2. `disableFiltering`과 `disableSorting`이 모두 `true`일 때 두 항목이 없고, 필터/정렬 그룹 앞 구분선도 없어져 설정 복원 앞에만 구분선이 남는다.
3. 두 prop 중 하나만 `true`일 때 해당 항목만 숨겨지고, 남은 해제 항목 그룹의 앞/뒤 구분선은 보존된다.
4. 상태가 비어 있는 해제 항목은 비활성화 표시를 유지하며, 항목이 보이는 동안 구분선은 유지된다.
