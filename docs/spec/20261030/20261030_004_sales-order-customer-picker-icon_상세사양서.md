## 화면 동작

- 수주등록 기본정보 거래처 컨트롤은 기존 `CustomerPicker`의 읽기 전용
  코드·명 필드를 유지한다.
- 필드 끝의 돋보기 아이콘을 클릭하면 기존 제목 `거래처 선택`의
  `MasterPickerDialog`를 연다. 별도의 텍스트 `선택` 버튼은 표시하지 않는다.
- 도움폼의 검색어 입력, Enter/검색 버튼, 로딩/결과 없음/오류, 거래처 선택
  동작은 수정하지 않는다.
- 선택하면 `MasterPickerOption`의 거래처 ID/코드/명이 기존 상태에 반영되고,
  필드에 `코드 · 이름`을 표시한다.

## 상태와 호환성

- 미선택 시 필드 값은 빈 문자열이며 필수 검증 및 기존 helper/error 표시를
  유지한다.
- 편집 불가 상태에서는 돋보기 아이콘을 비활성화한다. 현재 선택값 표시와
  저장/조회 데이터 구조는 바꾸지 않는다.
- 공통 피커의 기본 트리거 모드는 기존 버튼으로 유지한다. 수주등록의 거래처
  피커만 아이콘 모드를 지정한다.
- 모바일/태블릿/데스크톱 그리드 폭과 입력 필드 높이/정렬을 유지하며 페이지
  수평 넘침을 추가하지 않는다.

## 검증 기준

- 아이콘 클릭으로 기존 거래처 도움폼이 열리고 거래처 선택 후 코드·명이
  필드에 표시된다.
- 돋보기는 disabled 상태에서 비활성이고, 별도 텍스트 `선택` 버튼은 없다.
- 기존 공통 피커 기본 버튼 모드, 검색/선택, 오류/빈 결과 동작이 회귀하지
  않는다.
- `tests/master-picker.test.tsx`,
  `tests/sales-order-create-page.test.tsx`, 프론트엔드 build/lint를 통과한다.
- 실제 브라우저에서 375px, 768px, 1280px 화면 및 도움폼 플로우를 확인한다.
- 검증 및 합성 데이터 스크린샷은
  `docs/result/20261030/sales-order-customer-picker/`에 기록한다.

조회 동작, 백엔드 및 DB 스키마는 변경하지 않는다.
