## 재현 및 원인

1. 품목·거래처별 단가관리에서 단가 등록/수정 행 폼을 연다.
2. 품목 도움창에서 검색한 후 항목을 선택하거나 도움창을 닫는다.
3. 거래처 도움창을 열면 제목은 거래처지만 기존 품목 검색어/목록이 남는다.

`ItemPartnerPriceGrid`는 동일 위치의 `MasterPickerDialog`에 종류별 props만 바꾼다. 도움창의 `keyword/results/hasSearched/error/loading`은 내부 state이므로 종류를 바꿔도 초기화되지 않는다.

## 수정 계약

- 단가 화면에서 도움창 key를 `material`, `customer`, `closed`로 구분한다.
- 열 때마다 검색어, 결과, 오류, 검색 중 상태는 초기 상태로 시작한다.
- 검색 전에는 기존의 “검색어를 입력한 뒤 검색해 주세요.” 안내를 보여준다. 자동 검색은 추가하지 않는다.
- 이전 도움창의 늦은 응답은 새 도움창의 검색 결과/로딩/오류를 바꾸지 않는다.
- 품목 선택은 품목 ID/코드/명만, 거래처 선택은 거래처 ID/코드/명만 기존 `applyPatch`로 반영한다. 다른 폼 입력값은 유지한다.
- 공통 도움창, API/DB 계약, 권한, 저장 흐름, 레이아웃/CSS는 변경하지 않는다.

## 검증

- 품목 검색/선택 → 거래처 도움창 초기 상태 → 거래처 검색/선택 → 품목 도움창 초기 상태.
- 검색 후 닫기 → 같은 종류 재열기에도 이전 검색 상태를 표시하지 않음.
- 품목 검색 중 닫기 → 거래처 검색 완료 → 이전 품목 응답 완료 시 거래처 결과 유지.
- 오류 후 전환 시 이전 오류가 남지 않음.
- 실제 브라우저 375/768/1280px에서 위 흐름과 도움창 내부 표시, 페이지 가로 넘침을 확인한다.
- 합성 데이터만 사용하며 인증 정보나 실제 업무 데이터는 출력/스크린샷에 기록하지 않는다.
