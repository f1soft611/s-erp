# 상세 사양서

## 화면 동작

- 사용자가 셀을 편집하기 위해 에디터에 포커스하면 현재 입력값의 전체 범위가 선택된 상태로 시작한다.
- 날짜/시간 값은 셀 높이와 관계없이 그리드 기본 폰트 크기를 유지한다.
- 에디터는 기존 텍스트 입력, 숫자 입력, 선택/자동완성 입력 흐름과 호환되어야 한다.

## 로직 규칙

- 공통 `F1GridColumn` 옵션에 `selectOnFocus?: boolean`를 추가한다.
- 기본값은 `true`이며, 해당 옵션을 비활성화할 때만 선택을 유지하지 않는다.
- 각 에디터는 `font: inherit` 및 `fontSize: inherit`를 적용해 셀 기준 폰트를 상속한다.
- `DateTimePicker`/`TextField` 등 MUI 컴포넌트는 포커스 이벤트 타깃이 래퍼일 수 있으므로 실제 입력 요소를 안전하게 찾는다.

## 테스트 기준

- 포커스 시 입력 값 전체 선택이 발생한다.
- F1-Grid 단일 테스트 파일이 통과한다.
