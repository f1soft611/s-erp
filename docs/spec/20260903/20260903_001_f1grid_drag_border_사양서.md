# 상세 사양서

## 화면 동작

- 사용자가 셀을 드래그하면 선택 범위가 계산되고 하나의 외곽 사각형 오버레이가 표시된다.
- 오버레이는 첫 셀과 마지막 셀의 실제 화면 경계 안쪽에 그려진다.
- 셀 높이 또는 너비를 넘어서는 드래그 테두리는 생성하지 않는다.

## 로직 규칙

- 오버레이 좌표는 선택 범위의 실제 `getBoundingClientRect()` 기반 경계값을 사용한다.
- 오버레이는 셀 경계 바깥으로 2px 이상 확장하지 않는다.
- 복사 경로와 드래그 경로 모두 같은 계산 규칙을 사용한다.

## 에러 처리

- 선택 범위가 단일 셀이면 오버레이는 비활성화한다.
- 셀 참조를 찾지 못하면 이전 오버레이를 제거한다.

## 테스트 기준

- 범위 오버레이의 좌측/상단/우측/하단이 선택 영역을 벗어나지 않는다.
- 관련 F1-Grid 테스트 파일이 통과한다.
