# F1-Grid 문서 포털 자간 통일 상세 사양서

## 1. 화면 요구사항

### 목적

- 문서 포털에서 제목, 라벨, 네비게이션 문자열의 간격이 일정하게 보이도록 한다.
- 자간 값이 부자연스럽게 높거나 낮아지지 않도록 기준값을 명확히 적용한다.

### 적용 범위

- 문서 포털 헤더 title: `F1-Grid`
- 문서 라벨: `DOCUMENTATION`
- 문서 본문 주요 제목 및 하위 제목

## 2. 스타일 제약

- `letter-spacing` 값은 페이지 전반에서 통일된 기준을 사용한다.
- 기존 레이아웃 구조, 여백, 사이드바 동작, 모바일 반응형 레이아웃은 그대로 유지한다.
- 다른 화면의 전역 CSS와는 무관하게 문서 포털에만 적용한다.

## 3. 구현 기준

- `frontend/src/pages/f1-grid-docs/F1GridDocsPage.css`에 공통 자간 값을 지정한다.
- 대문자 라벨과 메인 제목이 동일한 간격 기준을 공유하도록 한다.
- 값은 텍스트 가독성을 해치지 않는 범위에서 조정한다.

## 4. 검증 기준

- 대표 텍스트가 하나의 자간 값으로 렌더링되는지 테스트로 검증한다.
- 기존 F1-Grid 문서 포털 테스트가 모두 통과한다.
- 빌드 오류가 없음을 확인한다.
