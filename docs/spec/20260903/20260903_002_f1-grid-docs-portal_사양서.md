# F1-Grid 개발자 문서 포털 상세 사양서

## 1. 화면 UI

### 공개 진입

- 경로: `/f1-grid-docs`
- 인증: 불필요
- 기본 문서: `overview`

### 레이아웃

- 상단 헤더: F1-Grid 로고/제목, 문서 검색 또는 메뉴 토글
- 왼쪽 사이드바: 문서 카테고리와 선택 상태
- 본문: breadcrumb, 제목, 설명, 문서 블록, 코드, Playground
- 모바일: 사이드바를 토글 패널로 전환

### 문서 상세 블록

- `prose`: 설명과 목록
- `code`: 복사 가능한 TypeScript 예제
- `api`: 타입/속성 표
- `playground`: 옵션 패널과 실제 F1-Grid
- `related`: 관련 문서 링크

## 2. 문서 데이터 계약

```ts
type F1GridDoc = {
  id: string;
  title: string;
  category: 'guide' | 'feature' | 'reference';
  description: string;
  sections: DocSection[];
  playground?: PlaygroundConfig;
};
```

문서 데이터는 정적 프론트엔드 모듈로 제공하며 서버 API를 사용하지 않는다.

## 3. Playground 계약

- `row-height`: 행 높이/줄바꿈/행 리사이즈
- `editing`: 셀 편집 및 검증
- `selection`: 행/셀 범위 선택과 복사
- `layout`: 컬럼 숨김, 고정, 리사이즈
- `row-merge`: 연속 동일 값 병합
- `tree`: 트리 펼침과 체크박스

옵션 변경은 React state를 통해 해당 예제의 F1-Grid props와 샘플 데이터에 반영한다. 임의의 사용자 코드를 실행하지 않는다.

## 4. 상호작용 및 예외

- 사이드바 문서 선택: URL query 또는 내부 state 중 기존 라우팅 패턴과 충돌이 적은 방식으로 구현한다.
- 코드 복사 성공: 버튼 상태를 일시적으로 `복사됨`으로 표시한다.
- 코드 복사 실패: 오류 상태를 표시하고 코드 선택/복사를 안내한다.
- 존재하지 않는 문서 ID: Overview로 이동하거나 404 안내를 표시한다.
- 모바일 메뉴 전환 시 본문 위에 겹치지 않도록 닫기 동작을 제공한다.

## 5. 내부 메뉴 연결

기존 대시보드 메뉴에서 `F1-Grid 문서` 항목을 선택하면 문서 포털 화면을 표시한다. 기존 관리자 인증과 대시보드 레이아웃은 유지한다. 내부 메뉴에서는 공개 URL로 외부 이동하지 않고 앱 내부 컴포넌트를 재사용한다.

## 6. 권한 및 보안

- 공개 URL: 샘플 데이터와 정적 문서만 제공
- 내부 URL: 기존 대시보드 인증 정책을 따른다.
- 운영 API, 사용자 데이터, 토큰을 문서 포털에서 사용하지 않는다.

## 7. 검증 기준

- `F1GridDocsPage`가 공개 URL에서 렌더링된다.
- 문서 선택으로 제목/본문/예제가 변경된다.
- 옵션 변경이 예제 결과에 반영된다.
- 코드 복사 성공 상태가 표시된다.
- 375px, 768px, 1280px에서 레이아웃이 깨지지 않는다.
- 기존 F1-Grid 회귀 테스트와 전체 빌드가 통과한다.
