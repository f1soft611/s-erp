# 20260921_005 공지사항 제목·본문 조회수 진입 상세 사양서

## 1. 화면 및 컴포넌트

- 화면: `/groupware/community/notice`
- 대상: `NoticeFeedList`
- 상세 조회 조정: `CommunityNoticePage.handleToggleNoticeExpand`
- 적용 대상: `더보기` 버튼이 없거나 본문이 짧은 공지, 긴 공지 포함

## 2. 사용자 동작

| 사용자 동작            | 처리                     |
| ---------------------- | ------------------------ | ---------------------------- |
| 사용자 동작            | `더보기` 있음            | `더보기` 없음                |
| ---                    | ---                      | ---                          |
| `더보기` 클릭          | 상세 조회 및 조회수 처리 | 해당 버튼 없음               |
| 제목 클릭              | 조회수 처리 없음         | 상세 조회 및 조회수 처리     |
| 본문 텍스트 클릭       | 조회수 처리 없음         | 상세 조회 및 조회수 처리     |
| 이미지 클릭            | 이미지 뷰어만 실행       | 이미지 뷰어와 상세 조회 실행 |
| 첨부파일 다운로드 클릭 | 다운로드만 실행          | 다운로드와 상세 조회 실행    |
| 댓글 입력·버튼 클릭    | 댓글 동작만 실행         | 댓글 동작과 상세 조회 실행   |
| 목록 로딩              | 조회수 증가 없음         | 조회수 증가 없음             |
| 공지 메뉴 클릭         | 메뉴만 실행              | 메뉴만 실행                  |

## 3. 클릭 영역

- 제목: `Typography`에 `role="button"`, `tabIndex={0}`, 키보드 `Enter`/`Space` 접근성을 제공한다.
- 본문: Rich HTML은 본문 컨테이너, 일반 텍스트는 본문 `Typography`에 클릭 핸들러를 연결한다.
- `더보기`가 없는 공지의 이미지·첨부파일·댓글은 기존 동작을 실행하면서 공지 상세 조회 콜백을 한 번 호출한다.
- `더보기`가 있는 공지의 제목·본문·이미지·첨부파일·댓글은 조회 콜백을 호출하지 않는다.
- 이미 확장된 공지에서 제목·본문을 다시 클릭하면 기존 접기 동작을 유지하거나 요청 없이 닫는다.
- 요청 중인 공지는 동일 공지에 대한 중복 요청을 막는다.
- 클릭 가능한 영역의 시각 스타일은 기존 피드 스타일을 유지하고, 포커스 시 접근 가능한 outline을 제공한다.

## 4. API 계약

기존 계약을 재사용한다.

```text
GET /api/v1/groupware/boards/notice/posts/{postId}
Authorization: Bearer <token>
```

- 성공: 기존 `ResultVO.item`을 피드 항목에 병합하고 `viewCount`를 서버 응답값으로 표시
- 인증 실패·조회 실패: 기존 오류 처리와 피드 표시를 유지하고 사용자에게 오류 메시지 표시
- 클라이언트는 조회수를 직접 증가시키지 않는다.

## 5. 이벤트 전파 규칙

- `더보기`가 없는 공지의 본문 내부 `img` 클릭은 이미지 뷰어 이벤트와 상세 조회 콜백을 함께 실행한다.
- `더보기`가 없는 공지의 첨부파일·댓글 버튼·입력 이벤트는 기존 동작과 상세 조회 콜백을 함께 실행한다.
- `더보기`가 있는 공지는 기존 동작만 실행한다.
- 메뉴와 카드 여백은 상세 조회 이벤트에서 제외한다.
- 제목·본문 외 카드 여백은 조회 진입점으로 사용하지 않는다.

## 6. 권한 및 보안

- 기존 인증된 공지 API 권한을 유지한다.
- 사용자 식별과 조회수 증가는 서버 인증 컨텍스트와 기존 조회 이력 테이블에 맡긴다.
- 클라이언트 요청에서 사용자 ID나 조회수를 전달하지 않는다.

## 7. 회귀 검증

1. `더보기` 없는 공지 제목 클릭이 상세 조회 콜백을 호출한다.
2. `더보기` 없는 공지 본문 클릭이 상세 조회 콜백을 호출한다.
3. 긴 공지의 `더보기` 동작이 유지된다.
4. 제목 키보드 `Enter`/`Space`가 클릭과 동일하게 동작한다.
5. `더보기` 없는 공지의 이미지 클릭이 이미지 뷰어와 상세 조회 콜백을 모두 실행한다.
6. `더보기` 없는 공지의 댓글·첨부파일 클릭이 기존 동작과 상세 조회 콜백을 모두 실행한다.
7. `더보기` 있는 공지의 제목·본문·이미지·첨부파일·댓글 클릭은 상세 조회 콜백을 호출하지 않는다.
8. 메뉴·카드 여백은 상세 조회 콜백을 호출하지 않는다.
9. 상세 응답의 `viewCount`가 피드 메타에 반영된다.
10. 관련 테스트와 프론트 빌드가 통과한다.
