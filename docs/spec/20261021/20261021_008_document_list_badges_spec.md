# 문서 리스트 표시 단순화 상세 사양

- [작업지시서](../../directions/20261021/20261021_008_document_list_badges_work_instruction.md)
- [계획서](../../plan/20261021/20261021_008_document_list_badges_plan.md)

007 사양의 리스트 도구막대 요구만 본 사양으로 대체한다.

리스트형은 기존 제목·작성자·날짜를 유지하고 부가 배지는 **결재상태 → 업무구분** 순서로 표시한다. 업무구분은 기존 기안/업무/지출/근태 표시를 뜻하며 새 데이터 필드를 추가하지 않는다.

행에는 세로 구분선, 고정/해제 버튼, 더보기, 직접 수정/삭제 메뉴를 표시하지 않는다. 작성자 여부 및 상태와 무관하게 동일하다. 문서 선택 시 기존 상세를 열며 상세 내 액션은 유지한다.

별도 상단고정 영역, 일반 리스트/피드의 고정 데이터 포함, 순서/건수/페이지 크기는 바꾸지 않는다. 피드/상세의 공용 도구막대와 핀 색상·확인·더보기 권한은 유지한다.

새 API/DB 변경은 없고 오류 처리 및 로딩/빈 목록/후속 페이지 동작은 기존 경로를 유지한다.
