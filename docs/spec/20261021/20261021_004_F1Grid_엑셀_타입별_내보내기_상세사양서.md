## 적용 범위

공통 F1-Grid의 기존 `.xlsx` 다운로드에서 값 저장 방식을 컬럼 `type`에 맞춘다. 화면에 보이는 컬럼과 행, 정렬·필터·숨김·순서 반영, 파일명, 컨텍스트 메뉴 및 다운로드 흐름은 바꾸지 않는다. 원본 행이나 편집·검색·정렬·클립보드 값을 수정하지 않는다.

## 셀 타입 계약

| 컬럼 타입 | Excel 값 타입 | 값 처리 |
| --- | --- | --- |
| `number`, `decimal`, `currency` | Number | 유한 숫자 또는 십진 숫자 문자열을 숫자로 기록한다. |
| `date` | Date | 유효한 `Date`, ISO 날짜/timestamp, `yyyymmdd`를 date-only `Date`로 기록한다. 문자열의 날짜 부분을 유지한다. |
| `datetime` | Date | 유효한 `Date` 또는 실제 달력 날짜와 JavaScript가 파싱할 수 있는 timestamp를 날짜·시간 값으로 기록한다. |
| `time` | Number | `HH:mm` 또는 `HH:mm:ss`를 Excel 1일 분수 값으로 기록한다. |
| `checkbox` | Boolean | Boolean, 숫자 `0`/`1`, `true`/`false`, `y`/`n`, `yes`/`no`, `on`/`off` 문자열을 Boolean으로 기록한다. |
| `rownumber` | Number | 원시 값이 유한 숫자이거나 십진 숫자 문자열이면 Number로 기록한다. |
| 기타 타입 | String | 기존 `getCellDisplayValue` 결과를 사용한다. select/autocomplete/user 선택지는 기존 label 매핑을 유지한다. |

`null`, `undefined`, `''`는 빈 Excel 셀이다. 위 타입으로 안전하게 변환할 수 없는 비어 있지 않은 값은 변환하거나 버리지 않고 원문 문자열로 저장한다. 숫자 문자열은 부호, 소수점, 선택적 지수부를 가진 십진 표현만 허용하며 쉼표 등 표시용 그룹 구분자는 원본 데이터로 간주한다.

## Excel 표시 서식

- 숫자 셀은 그룹 구분자를 적용한다. 유효한 `decimalPlaces`가 설정되면 해당 자릿수를 최소·최대 소수 자릿수로 사용한다. 일반 숫자는 지정하지 않은 경우 화면과 같이 최대 다섯 자리까지 선택적으로 표시한다.
- 숫자 `format: 'currency'`는 기존 화면 계약대로 KRW 통화 표시 서식을 적용하고 기본 소수 자릿수는 0이다. 통화에 `decimalPlaces`가 지정되면 해당 자릿수를 사용한다. 다른 `format`은 현재 숫자 표시 동작과 일치하는 그룹/소수 서식을 쓴다.
- 통화/숫자 서식은 `numFmt`만 지정하고, 셀 값은 Number로 유지한다.
- `date`는 컬럼의 `format`을 Excel number format으로 바꿔 적용한다. 미지정 또는 빈 형식은 `yyyy-mm-dd`다. 기존 지원 토큰(`yyyy`/`YYYY`, `yy`/`YY`, `mm`/`MM`, `m`/`M`, `dd`/`DD`, `d`/`D`)을 적용하고 대괄호 안의 문구와 토큰 사이의 일반 문자 리터럴은 Excel 서식 문자열로 인용한다.
- `datetime`은 `yyyy-mm-dd hh:mm:ss`, `time`은 입력에 초가 있으면 `hh:mm:ss`, 없으면 `hh:mm` 형식을 사용한다.

## 날짜 변환 및 호환성

1. date-only 문자열과 timestamp 문자열은 기존 그리드 date 표시와 동일하게 날짜 부분을 검증한다. offset이 포함되어도 문자열에 명시된 연/월/일을 유지한다.
2. 유효한 `Date` 객체는 로컬 달력의 연/월/일을 기준으로 자정 Date로 내보낸다.
3. 잘못된 날짜와 빈 값은 기존 date 표시 계약을 유지한다. 잘못된 비어 있지 않은 값은 원문 문자열로, 빈 값은 빈 셀로 내보낸다.
4. 공통 date parser를 화면 표시 함수와 export가 함께 사용해 두 경로의 유효성 판단을 일치시킨다.
5. datetime timestamp는 실제 날짜·시간 셀로 저장한다. date 부분이 잘못되었거나 JavaScript가 파싱하지 못하는 값은 원문 문자열로 보존한다.

## 테스트 및 완료 기준

- ExcelJS가 만든 buffer를 새 Workbook으로 재로딩해 값의 타입 및 `numFmt`를 확인한다. ExcelJS는 시간 표시 서식이 적용된 숫자 serial을 다시 읽을 때 epoch 날짜를 가진 `Date`로 반환할 수 있으므로 UTC 시/분/초와 `numFmt`를 검증한다.
- 숫자/통화/소수, date/date format, datetime, time, checkbox, rownumber, select label, 빈 값, 각 typed 타입의 잘못된 값, date-only timezone 경계 사례를 검증한다.
- `f1-grid-excel-export.test.ts`, `f1-grid-date-format.test.tsx`, `f1-grid-docs.test.tsx` 및 프론트엔드 빌드가 통과한다. 기준 실행에서 이미 확인된 넓은 Grid/context-menu 테스트 실패는 결과 보고서에 분리 기록하며 이번 범위에서 수정하지 않는다.
- [F1-GRID.md](../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)를 갱신한다.
- 결과 보고서와 export 화면 스크린샷을 `docs/result/20261021/f1-grid-excel-export-types/`에 저장한다.
