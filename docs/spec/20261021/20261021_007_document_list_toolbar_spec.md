## 화면 및 권한

리스트 도구막대는 결재상태, 문서구분, 높이 20px의 중앙 정렬 세로선, 고정핀, 더보기 순서다. 핀/더보기 버튼은 행 선택 버튼의 자식이 아니며 메뉴/핀 조작으로 상세가 열리지 않는다. 좁은 화면에서는 도구막대를 행 하단 별도 줄에 우측 정렬한다. 기본 ListView 소비자는 기존 렌더링을 유지한다.

피드/상세도 동일한 공용 툴바의 중앙 구분선을 사용한다. 칩 높이는 기존 리스트 22px, 피드/상세 28px을 유지한다.

더보기는 서버의 isDrafter가 true이고 문서 상태가 DRAFT 또는 REVISION_REQUESTED일 때만 표시한다. DRAFT에는 문서 수정과 삭제, REVISION_REQUESTED에는 수정 후 재상신만 제공한다. 타인 문서 및 그 외 상태에는 버튼을 표시하지 않는다.

수정 선택 시 해당 상세를 조회하고 기존 Composer를 연다. 조회 실패는 알림으로 표시하고 Composer를 열지 않는다. 삭제는 기존 삭제 문구로 확인 후 기존 API를 호출한다. 실패 시 확인창에 오류를 표시하고 다시 시도할 수 있다. 삭제 중 중복 요청/닫기는 막는다. 성공 시 기존 quiet refresh를 수행한다.

## 데이터

일반 문서 목록/페이지 응답에 isDrafter boolean을 추가한다. SQL에서 현재 인증 사용자의 drafterId와 문서 drafter_id를 비교한다. 식별자/개인정보를 추가 노출하지 않으며 서버 수정/삭제 권한 검사는 유지한다. 과거 응답에 필드가 없으면 허용 메뉴를 만들지 않는다.

고정/페이징/정렬/필터 계약과 DB 스키마는 변경하지 않는다.
