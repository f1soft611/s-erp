## 2. 동작 계약

- 자료실 `ArchiveFileGrid`에서만 `allowAddRootInContextMenu`를 `false`로 지정한다. 우클릭 메뉴의 `루트 추가` 항목은 나타나지 않는다.
- 자료실 `ArchiveFileGrid`에서 `canExportExcel`을 활성화한다. 우클릭 메뉴의 `엑셀 내보내기`는 공통 `exportGridRowsToExcel` 흐름을 사용해 현재 표시 행과 표시 컬럼을 내려받는다.
- `allowAddRowInContextMenu`, `allowDeleteRowInContextMenu`, `allowDuplicateRowInContextMenu`는 계속 비활성이다.
- 공통 컴포넌트 기본값 및 타 화면 메뉴 동작은 바꾸지 않는다.
- F1Grid 컨텍스트 메뉴는 구분선을 실제 비어 있지 않은 액션 그룹 사이에만 그린다. 자료실처럼 행 작업과 정렬/필터 그룹이 모두 없을 때는 일반 액션과 기본 설정 복원 사이의 구분선 하나만 남긴다.

## 3. 검증 기준

- 자료실 그리드 우클릭 시 `루트 추가`가 없고 `엑셀 내보내기`가 보인다.
- Excel 메뉴 활성화에 따라 기존 exporter 다운로드 호출이 유지된다.
- 루트/행 추가, 복제, 삭제 동작이 모두 숨겨지고 정렬/필터도 비활성화된 트리의 컨텍스트 메뉴는 구분선을 하나만 표시한다.
- 자료실 테스트, 공통 컨텍스트 메뉴 회귀 테스트, production build가 통과한다.
