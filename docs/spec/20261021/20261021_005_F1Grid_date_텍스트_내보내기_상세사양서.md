## 적용 범위

공통 F1-Grid `.xlsx` export에서 `type: 'date'` 셀의 저장값을 Grid 표시 문자열로 변경하고, 헤더/데이터 셀의 수평 정렬을 Grid 설정에 맞춘다. 컬럼/행 포함 규칙, 파일명, 내보내기 메뉴, 다운로드 방식 및 다른 컬럼 타입의 값/서식은 유지한다.

## 셀 계약

| 입력 | Excel 셀 값 | 수평 정렬 |
| --- | --- | --- |
| 유효한 date 값 | `getCellDisplayValue(column, value)`가 반환하는 문자열 | `align` 또는 Grid 기본 정렬 |
| 유효하지 않은 비어 있지 않은 date 값 | Grid formatter가 반환하는 원문 문자열 | `align` 또는 Grid 기본 정렬 |
| `null`, `undefined`, 빈 문자열 | 빈 셀 | `align` 또는 Grid 기본 정렬 |
| `datetime`, `time`, 숫자, Boolean, 기타 | 기존 타입별 값/서식 | `align` 또는 Grid 기본 정렬 |

헤더 정렬은 `headerAlign` 값을 사용하고 미지정 시 Grid처럼 가운데 정렬한다. 데이터 셀은 `align` 값을 사용하고 미지정 시 `number`/`rownumber`는 오른쪽, 나머지는 왼쪽 정렬한다. 명시한 정렬 값은 타입 기본값보다 우선한다.

date 문자열은 Excel 날짜 serial로 저장하지 않는다. Grid에서 구성한 날짜 표시 형식과 정확히 맞추는 것을 우선하므로 Excel 날짜 연산/정렬은 date 타입 export 범위에서 제공하지 않는다. 날짜 표시 포맷 해석은 기존 `getCellDisplayValue` 구현을 재사용하며 별도 토큰 변환기를 만들지 않는다.

## 검증 기준

- Export XLSX를 ExcelJS로 재로딩해 date 값이 지정된 Grid 형식(예: `yyyy년 m월 d일`)의 문자열인지 확인한다.
- 헤더 기본 가운데/본문 타입 기본값과 명시적 `headerAlign`/`align` 매핑을 검증한다.
- 빈 date 셀과 invalid date 문자열도 값 보존 정책을 유지하면서 컬럼 정렬을 따르는지 확인한다.
- datetime 값은 Date, time은 현재 time serial/서식, 숫자와 Boolean은 기존 타입을 유지하는지 회귀 검증한다.
- export, date format, F1-GRID docs 테스트와 frontend build를 실행한다.
