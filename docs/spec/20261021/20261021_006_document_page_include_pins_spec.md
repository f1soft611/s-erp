## 계약

- 일반 문서 페이지와 피드 페이지는 읽기 가능한 고정/미고정 문서를 모두 조회한다.
- `totalRowCount`도 동일 조건의 전체 문서를 세며 고정 여부로 감소하지 않는다.
- 상단 고정 영역은 현재 사용자의 별도 고정 조회를 유지한다. 일반 페이지와 중복 표시는 정상이다.
- 일반 조회 정렬은 `updated_at DESC, electronic_approval_id DESC`, 기본 페이지 크기는 20, offset/limit 계약은 유지한다.
- 피드 조회는 같은 일반 페이지 결과의 상세를 조립하며 고정 문서를 앞에 삽입하거나 제외하지 않는다.
- tenant/삭제/읽기 권한/scope/업무구분/선택 문서 필터는 변경하지 않는다.
- 개인 고정 상태 및 프론트엔드의 핀 색상/확인 흐름은 기존 005 구현을 유지한다.

## 검증 기준

- 실제 MyBatis가 조립한 페이지/count SQL에 pin 테이블 제외 조건이 없다.
- 권한 및 필터 SQL, 정렬, 페이지 제한이 유지된다.
- 별도 고정 조회의 사용자/tenant 조건은 기존 테스트로 유지 여부를 검사한다.
- 매퍼, 서비스, 컨트롤러 테스트가 통과한다.
- 실행 서버 미반영이면 재시작 필요성을 결과에 명시하며 코드 테스트와 실제 서버 검증을 구분한다.
