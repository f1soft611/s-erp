## 표시 및 조작

- 별도 조회한 고정 문서가 있으면 피드형과 리스트형의 도구막대 아래에 동일한 `상단 고정 문서` 영역을 표시한다.
- 고정 영역의 문서 제목 선택은 기존 상세 오버레이를 연다. 고정 영역에는 직접 해제 버튼을 제공하지 않는다.
- 고정 문서가 없거나 초기 로딩 중이면 고정 영역을 표시하지 않는다. 파일형의 기존 분기는 유지한다.
- 피드 및 리스트 본문은 일반 조회 API 순서 그대로 유지한다. 별도 고정 조회 결과를 본문에 삽입하거나 일반 결과의 고정 문서를 제외/우선 정렬하지 않는다.
- 고정 문서가 일반 조회 범위에도 포함되면 두 영역에 모두 표시한다. 일반 조회의 다음 페이지에 있는 고정 문서는 해당 페이지를 불러올 때 본문에 나타나며 실제 고정 상태를 표시한다.
- 피드 및 상세의 핀 아이콘은 고정 시 `primary`, 미고정 시 `inherit`이다. 접근성 이름은 기존 고정/해제 이름을 유지한다.
- 피드 및 상세의 고정/해제는 기존 확인창, pending 비활성화, 성공 후 quiet refresh, 실패 알림을 유지한다.
- 일반 리스트의 고정 문서는 해제 버튼과 primary 핀을 제공하고, 미고정 문서는 고정 버튼과 기본색 핀을 제공한다. 페이지네이션 및 필터 조건은 유지한다.

## 회귀 검증

- 두 보기에서 별도 조회한 고정 영역과 제목이 보이고 직접 해제 버튼은 없다.
- 고정 영역 선택 시 상세가 열리고 해제 핀이 강조색으로 표시된다.
- 피드 카드의 고정 핀 강조색과 미고정 핀 기본색을 검사한다.
- 기존 고정/해제 확인 취소 및 확인 API 호출 테스트를 유지한다.
- 375/768/1280px에서 영역 표시, 버튼 겹침 및 페이지 가로 넘침을 확인한다.

기존 004 사양의 고정 패널 직접 해제 유지 항목은 이번 사양으로 대체한다. API/DB 계약은 변경하지 않는다.
