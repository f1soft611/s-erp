# 문서 피드 취소 액션 상세 사양

- [작업지시서](../../directions/20261021/20261021_009_document_feed_cancellation_work_instruction.md)
- [계획서](../../plan/20261021/20261021_009_document_feed_cancellation_plan.md)

기존 20261014 취소 사양의 상세 전용 제한을 변경한다. 피드와 상세 모두 같은 조건으로 버튼을 표시한다.

- 상신 취소: 본인 기안 문서이며 PENDING 상태.
- 승인 취소: PENDING/IN_PROGRESS 문서에서 본인의 2단계 이상 결재/합의선이 APPROVED이고, 후속 단계에 처리 완료 결재/합의선이 없는 경우. 기존 계산을 유지한다.
- 실행 전 기존 확인창을 표시한다. 닫기 시 API를 호출하지 않는다. 처리 중 재요청 및 닫기를 막는다.
- 기존 취소 API와 서버 권한/상태 검증은 유지한다. 실패는 확인창에 오류를 표시하고 재시도를 허용한다.
- 성공 시 기존 알림, 부모 목록 갱신, 댓글 재조회 경로를 사용한다.

승인/반려/보완요청, 핀/더보기, 리스트의 상태·업무구분만 표시, 정렬/페이징은 변경하지 않는다. 백엔드/DB 변경은 없다.
