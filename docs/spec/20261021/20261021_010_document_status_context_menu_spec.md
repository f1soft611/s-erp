## 화면 동작

| 입력 | 동작 |
|---|---|
| 문서현황 데이터 셀 왼쪽 클릭 | 기존 행 선택 및 상세 열기 |
| 체크박스 선택 | 기존 상세 열기 동작 유지 |
| 데이터 셀 오른쪽 클릭 | 메뉴 표시, 셀 포커스 이동, 행 선택 변경 없음, 상세 열기 없음 |
| 이미 선택한 행과 다른 행 우클릭 | 기존 행 선택 유지, 우클릭 대상의 메뉴만 표시 |
| 빈 영역 우클릭 | 일반 메뉴 표시, 상세 열기 없음 |
| 헤더 우클릭 | 기존대로 본문 메뉴 표시 안 함 |

## 메뉴

- 표시: 엑셀 내보내기, 컬럼 길이 자동 조정, 정렬 해제, 설정을 기본값으로 복원.
- 숨김: 행 추가, 위에 행 삽입, 아래에 행 삽입, 행 복사, 행 삭제.
- 기존대로 숨김: 필터 해제.
- 엑셀 내보내기는 기존 F1Grid 내보내기 기능을 사용하며 현재 그리드 데이터를 기존 타입별 변환 규칙으로 내보낸다.
- 정렬 해제의 기존 활성/비활성 조건과 메뉴 닫기 동작을 유지한다.

## 공통 컴포넌트 계약

- `F1GridProps.selectRowOnContextMenu?: boolean`, 기본값 `true`.
- false는 우클릭에 따른 행 선택 상태 변경만 막는다. 셀 포커스 및 셀 범위 표시는 유지하고 좌클릭 드래그는 시작하지 않는다.
- 기본값 true인 기존 화면 및 F1Tree의 우클릭 행 선택은 유지한다.
- 행 변경 메뉴는 기존 `allowAddRowInContextMenu`, `allowDuplicateRowInContextMenu`, `allowDeleteRowInContextMenu`로 숨기므로 신규 메뉴 API를 만들지 않는다.
- 상세 피드, 서버 조회, 데이터/권한/오류 처리 계약은 변경하지 않는다.

## 검증 기준

1. 실제 버튼 순서를 반영한 우클릭 이벤트 후 문서현황 상세 overlay가 없고 메뉴가 보인다.
2. 행 변경 메뉴와 필터 해제 메뉴가 DOM에 없고 엑셀 내보내기가 실행 가능하다.
3. 이후 좌클릭 및 체크박스 상세 동작은 유지된다.
4. 공통 옵션 false에서 기존 선택 유지, true에서 우클릭 선택 유지.
5. 관련 Vitest, TypeScript/Vite 빌드 및 실제 브라우저 375px·768px·1280px 검증.
6. 결과 스크린샷은 합성 데이터만 사용하고 실제 문서/계정 정보를 저장하지 않는다.
