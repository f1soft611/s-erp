# 납품 그리드 정렬 통일 상세사양서

## 컬럼 정렬 계약

| 구분 | 납품 화면 컬럼 | 정렬 |
|---|---|---|
| 문서/분류/일자 | 납품번호, 계획번호, 수주번호, 날짜, 납품구분 | 가운데 |
| 코드 및 명칭 | 거래처코드/명, 품목코드/명 | 가운데 |
| 기타 설명 텍스트 | 납품장소, 배송방법, 비고 | 왼쪽 |
| 숫자 | 수량, 단가, 공급가, VAT, 합계, 잔량/초과수량 | 오른쪽 |
| 행 식별 | No, 행, 단위 | 기존 가운데 정렬 유지 |

대상은 납품등록 상세 그리드, 등록 중 열리는 계획 선택 그리드, 납품현황 그리드다. 등록 그리드에서 문자 필드는 왼쪽으로, 코드와 명칭은 가운데로, 숫자 필드는 오른쪽으로 정렬한다. 숫자 포맷이나 컬럼 헤더 정렬 설정은 바꾸지 않는다.

## 구현 및 검증

- 정렬은 해당 페이지의 `F1GridColumn.align`으로 선언하며 공통 그리드 동작은 수정하지 않는다.
- 사용자 정의 렌더링 컬럼도 셀 정렬을 유지한다.
- 단위테스트에서 등록/현황 그리드 주요 컬럼의 실제 셀 정렬을 검증하고 375/768/1280px 브라우저 렌더링에서 기존 내부 스크롤/레이아웃이 유지되는지 확인한다.
