# 납품계획번호 채번 규칙 정렬 상세사양서

## 번호 계약

- 납품계획번호 형식은 `DP-YYYYMMDD-NNNN`이다. `DP`는 계획 문서를 구분하며 수주 `SO`, 납품 `SD`의 접두사와 혼동하지 않는다.
- 날짜는 채번 시점의 현재 날짜를 `yyyyMMdd`로 사용한다.
- 순번은 `SALES_DELIVERY_PLAN_NO` generator에서 tenant ID와 날짜를 범위로 하며, `%04d`는 최소 네 자리로 출력한다. 네 자리를 초과하는 순번은 자릿수를 자르지 않는다.
- 숫자 출력은 기본 JVM 로케일과 무관하게 ASCII로 고정한다.
- 생성 결과가 스키마 제한인 30자를 초과하면 HTTP 500 오류로 반환하고 계획 헤더를 저장하지 않는다.

## 검증

- 순번 1은 `DP-<오늘 날짜>-0001` 형식으로 계획 헤더에 전달한다.
- 길이가 30자를 초과하는 순번은 헤더 저장 전에 거부한다.
- MANUAL/AUTO 운영 모드, 수주·계획 상세 동기화 및 초과납품 정책은 변경하지 않는다.
