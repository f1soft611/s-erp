# 상세 사양서: F1-GRID 빈 데이터, 컴팩트 행 높이, 에디터 정렬 보정

## 화면 동작

- 빈 데이터 상태에서는 그리드 본문에 `데이터가 없습니다` 메시지를 표시한다.
- 기본 row height는 기존 40px보다 더 compact한 값으로 조정하되, 편집 중인 셀과 선택된 셀의 border/outline가 정상적으로 유지되어야 한다.
- `date`, `time`, `datetime` 에디터는 입력 텍스트가 수직 중앙에 정렬되어 보여야 한다.
- 빈 상태에서도 기존 헤더/스크롤/테두리 레이아웃은 유지한다.

## 검증 기준

- `npm run test -- tests/f1-grid.test.tsx` 통과
- 빈 데이터 그리드 렌더링 시 메시지 노출 확인
- `date`/`time` 타입 편집 시 텍스트 정렬이 하단이 아닌 가운데/상단 기준으로 유지되는지 확인
