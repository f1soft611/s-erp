# 상세 사양서

## 훅 동작

- 훅은 `UserPromptSubmit` 이벤트에 대해 기존 문서 우선 절차를 계속 주입한다.
- 추가 컨텍스트는 작업에 적용 가능한 스킬 또는 절차 안내가 있으면 구현·응답 전에 이를 확인하고 적용하도록 요구한다.
- 스킬을 불러오는 수단은 현재 실행 환경에서 제공하는 스킬 로더, 도구 또는 문서로 표현하며 특정 제품, 모델, 도구 이름을 요구하지 않는다.
- 여러 스킬이 적용되면 문제 해결 절차 성격의 스킬을 먼저 적용하고, 이후 구현 영역 스킬을 적용한다.
- 사용자 요구사항과 저장소 지침이 스킬 지침보다 우선함을 명시한다.

## 범위 제한

- `.github/hooks/force-doc-workflow.js`의 `additionalContext` 문자열만 변경한다.
- 훅 이벤트 이름과 JSON 출력 구조는 변경하지 않는다.

## 검증 기준

- `node --check .github/hooks/force-doc-workflow.js`가 성공한다.
- 스크립트 실행 결과의 `additionalContext`에 문서 절차 및 모델 독립 스킬 절차가 포함된다.
