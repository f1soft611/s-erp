# 상세 사양서: F1 Grid/F1 Tree 핀 고정 컬럼 정렬 보정

## 레이아웃 계약

- F1Grid는 컨테이너 폭을 기준으로 모든 `flex` 컬럼의 비율을 픽셀 폭으로 계산한다.
- 계산된 단일 CSS Grid 트랙 문자열을 헤더와 본문이 함께 사용한다.
- 좌측 또는 우측으로 고정된 컬럼은 설정 또는 리사이즈 폭을 고정 CSS Grid 트랙으로 사용한다.
- 고정 컬럼의 좌우 sticky 오프셋은 같은 고정 폭을 누적해 계산한다.
- 좌측 고정 컬럼은 일반 컬럼보다 앞에, 우측 고정 컬럼은 일반 컬럼보다 뒤에 배치한다.
- 이 계약은 `F1Tree`가 위임하는 `F1Grid`에도 동일하게 적용되며, 페이지 컴포넌트에는 별도 스타일 또는 정렬 보정을 추가하지 않는다.

## 검증 기준

- `flex` 좌측 고정 컬럼 뒤의 좌측 고정 컬럼은 앞 컬럼의 고정 트랙 폭만큼 `left` 오프셋을 가진다.
- `flex` 컬럼이 존재하는 가로 스크롤 그리드에서도 헤더와 본문의 모든 컬럼 경계가 일치한다.
- 중간에 선언된 좌측 고정 컬럼도 고정 영역의 선두로 이동하며, 헤더와 본문은 같은 고정 영역 순서를 사용한다.
- F1Tree에서도 핀 고정 `flex` 컬럼의 헤더 트랙이 고정 폭으로 렌더링된다.
