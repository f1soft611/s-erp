# 상세 사양서

## 산출물

- 대상 파일: `docs/guide/project-structure.md`
- 형식: Markdown
- 대상 독자: S-ERP 저장소를 처음 확인하는 개발자

## 포함 내용

1. 루트 기준의 `frontend`, `backend`, `docs` 역할
2. 프론트엔드의 React, TypeScript, Vite 구성과 주요 소스 위치
3. 백엔드의 Java, Spring Boot, eGovFrame 구성과 주요 소스 위치
4. 작업 문서와 데이터베이스 이력의 날짜별 관리 위치
5. 프론트엔드 및 백엔드의 기본 검증 명령
6. 작업지시서부터 결과 문서까지의 작업 순서

## 제외 내용

- 세부 화면·API·테이블 명세
- 코드, 설정, 데이터베이스 스키마 변경

## 검증 기준

- 문서의 모든 상대 경로가 저장소에 존재한다.
- `frontend/package.json`과 `backend/pom.xml`에 기반한 명령만 기재한다.
