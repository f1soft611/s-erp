## 병합 셀 경계선

- `mergeInfo.isStart`가 참인 병합 시작 셀은 `gridRow` span 전체의 하단에 `divider` 색상 보더를 표시한다.
- 병합되지 않은 일반 셀은 기존과 같이 그리드의 마지막 행에서만 하단 보더를 표시한다.
- 선택, 포커스, 편집 상태가 보더 색상을 투명하게 처리하는 기존 동작은 유지한다.

## 컬럼 필터 위치

- 컬럼 메뉴를 여는 버튼을 클릭하면 해당 버튼 DOM 노드를 컬럼별 메뉴 앵커로 저장한다.
- 필터 항목을 클릭하면 이 헤더 메뉴 버튼을 필터 메뉴의 `anchorEl`로 사용한다.
- 필터 창의 기준점은 앵커 버튼의 왼쪽 하단이다.
- 부모 컬럼 메뉴가 닫혀도 필터 앵커는 DOM에 남아 있어 위치를 유지한다.

## 회귀 검증

- 두 행 이상 병합된 시작 셀의 `borderBottom`이 `1`인지 확인한다.
- 필터 메뉴를 연 후 `MuiMenu-paper`가 선택 컬럼의 메뉴 버튼 앵커를 기준으로 표시되는지 확인한다.
- F1 Grid 테스트 페이지에서 병합 셀의 마지막 행 선과 필터 팝업을 브라우저 스크린샷으로 확인한다.
