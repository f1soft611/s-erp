## 동작

- `F1Tree`는 `F1Grid`의 `disableFiltering`, `disableSorting` props를 강제로 설정하지 않는다.
- 메뉴 관리 트리는 기본 공용 정책에 따라 컬럼 필터와 정렬을 제공한다.
- 필터가 하나 이상 활성화된 상태에서 우클릭하면 `필터 해제`를 선택할 수 있으며, 선택 시 모든 필터 조건이 해제된다.
- 정렬이 하나 이상 활성화된 상태에서 우클릭하면 `정렬 해제`를 선택할 수 있으며, 선택 시 모든 정렬 조건이 해제된다.
- 필터 또는 정렬 해제는 행의 원본 데이터, 변경 추적, 펼침/접기 상태를 변경하지 않는다.

## 회귀 검증

- 메뉴 관리 트리에서 컬럼 필터를 적용하면 우클릭 `필터 해제`가 활성화되고, 선택 후 필터 대상 외 행이 다시 표시된다.
- 메뉴 관리 트리에서 컬럼 정렬을 적용하면 우클릭 `정렬 해제`가 활성화되고, 선택 후 원본 입력 순서로 복원된다.
- 모듈 관리 및 권한 관리의 기존 공용 `F1Grid` 우클릭 동작은 변경하지 않는다.
