# 상세 사양서

## 대상 파일

- `AGENTS.md`
- `.github/instructions/database-mcp.instructions.md`

## 루트 규칙

- DB, SQL, 테이블, 컬럼, 데이터 정합성, 백엔드 API 데이터 계약과 관련된 작업은 구현 전에 `s-erp-postgresql-readonly` MCP로 현재 계약을 확인한다.
- 기본 조회 순서는 `list_tables`, `describe_table`, 필요 시 제한된 `query_readonly`다.
- MCP는 읽기 전용 근거 확인용이며, 스키마 변경은 기존 날짜별 SQL, 변경 이력, 롤백 스크립트 규칙을 따른다.
- MCP 연결 실패 시 원인과 대체 근거를 결과 문서에 기록한다.

## 전용 지침

- 설명에는 DB, SQL, PostgreSQL, 테이블, 컬럼, MyBatis, Mapper, JPA, Entity, Migration, API 데이터 계약 키워드를 포함한다.
- `applyTo`는 `backend/**/*.java`, `backend/**/*Mapper*.xml`, `backend/**/*.sql`, `docs/database/**/*.md`, `docs/database/**/*.sql`, `backend/DATABASE/**/*.md`, `backend/DATABASE/**/*.sql`을 포함한다.
- 지침은 MCP 사용 전제조건, 도구 순서, 읽기 전용 제한, 민감정보 기록 금지, 연결 실패 대체 절차를 포함한다.

## 검증 기준

- 전용 지침의 YAML frontmatter에 설명과 제한된 `applyTo` 범위가 있다.
- 루트 및 전용 지침에서 서버 이름과 도구 이름이 일치한다.
- 결과 문서에 변경 파일, 적용 조건, 검증 결과가 기록된다.
