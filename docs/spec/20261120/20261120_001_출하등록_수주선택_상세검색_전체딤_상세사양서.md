# 출하등록 수주 선택 상세검색 전체 딤 상세사양서

## 1. 목적 및 기준 화면

수주 선택 다이얼로그의 상세검색 시각 효과를 출하현황 상세검색과 동일하게 한다. 기준 구현은 `PageSearchArea`의 페이지 모드 backdrop이며 색상은 `rgba(15, 23, 42, 0.12)`다.

## 2. 동작 사양

- 상세검색 토글을 열면 수주 선택 CommonDialog 전체(제목, 검색/그리드 본문, 하단 액션)를 기준 색상으로 딤 처리한다.
- 상세검색 패널과 검색 토글 영역은 오버레이 위에 표시해 선명하고 조작 가능하게 유지한다.
- 통합검색 입력은 오버레이가 투과되지 않도록 현황 페이지와 동일하게 `background.paper` 배경을 유지한다.
- 오버레이는 CommonDialog 안에만 위치한다. 모달 바깥 앱 화면에는 상세검색용 오버레이를 추가하지 않는다.
- 그리드는 기존처럼 상세검색이 열린 동안 `inert` 상태를 유지하고, 닫거나 검색 적용 후 활성화한다.
- `PageSearchArea`의 공통 페이지 모드와 기본 현황 화면 동작은 수정하지 않는다.

## 3. 구현 범위

- `SourceOrderPicker`에서 상세검색 열림 상태에 따라 `CommonDialog.overlay`에 `position: absolute; inset: 0; z-index: 12` 및 기준 색상의 스크림을 전달한다.
- 기존 검색영역의 stacking order가 스크림보다 위에 있도록 유지한다.
- 통합검색 입력의 outlined root는 `theme.palette.background.paper`를 배경으로 사용해 검색창이 스크림에 비치지 않게 한다.
- 프론트엔드 회귀 테스트는 오버레이가 `DialogContent` 외부의 다이얼로그 자식인지, 색상이 기준과 일치하는지, 통합검색 배경이 불투명한지 확인한다.
