# 20261120_007 사원 선택 도움창 다중 선택 상세사양서

기준: [계획서](../../plan/20261120/20261120_007_hr-employee-picker-multiple_계획서.md)

## 1. 속성
- 공통: `open`, `onClose`, `title`.
- 단일(기본, `selectionMode` 생략 또는 `'single'`): `onChange(option)`, `onClear?` — 기존과 같다(더블클릭/Enter로 적용, 닫힘).
- 다중(`selectionMode: 'multiple'`): `onApply(options: EmployeePickerOption[])`(필수), `selected?: EmployeePickerOption[]`(열 때의 초기 선택), `maxSelect?: number`(1 이상, 기본 제한 없음).

## 2. 다중 동작
- 사원 표 맨 앞 "선택" 열의 체크박스로 고른다(접근성 이름 "<사원명> 선택"). 행 더블클릭은 아무 동작도 하지 않는다.
- 선택은 **사원 ID로 유지**한다. 부서를 바꾸거나 검색해 다른 목록이 떠도 이미 고른 사원은 선택 상태로 남고, 보이지 않는 사원도 적용에 포함된다.
- 안내 줄(표 위): 평소 "체크박스로 사원을 고른 뒤 적용하세요. 부서·검색을 바꿔도 선택은 유지됩니다."와 버튼 "현재 목록 전체 선택", "선택 해제". `maxSelect`를 넘기려 하면 같은 줄이 "최대 N명까지 선택할 수 있습니다."(오류 색)로 바뀐다(별도 영역을 늘리지 않아 도움창 크기가 변하지 않는다). 전체 선택은 한도까지만 채운다.
- 푸터: 왼쪽 "선택 N명", 오른쪽 "취소", "적용(N명)". 적용은 선택 순서대로 `onApply`를 호출하고 닫는다. 0명이어도 적용할 수 있다(선택 비우기). 취소·닫기는 `onApply`를 호출하지 않는다.
- 열 때마다 `selected`로 초기화한다. `selected`가 `maxSelect`보다 많으면 앞에서부터 `maxSelect`명만 쓴다.
- 받는 값은 단일과 같은 `EmployeePickerOption`(부서ID·부서명·사원ID·직위코드·직위명·사번·사원명) 배열이다.

## 3. 검증
- 단일: 기존 테스트 그대로(더블클릭 선택, 선택 해제, 빈 목록 등).
- 다중: 체크 후 적용 시 배열 전달, 더블클릭은 적용하지 않음, 부서 이동 후에도 선택 유지, 초기 선택, `maxSelect` 초과 안내와 전체 선택 한도, 취소는 미호출, 0명 적용.
