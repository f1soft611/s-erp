## 2. 기능 개요

공지사항 화면은 그룹웨어 하위 커뮤니티의 첫 화면으로, 사용자에게 최신 공지와 중요 공지를 한눈에 보여주는 피드형 레이아웃을 제공한다. 기존의 공통 `PageHeader`와 대시보드 레이아웃은 그대로 유지하고, 본문 영역만 커뮤니티 공지 페이지의 디자인으로 교체한다.

## 3. 사용자 시나리오

### 3.1 진입

- 사용자가 `그룹웨어 > 커뮤니티 > 공지사항` 메뉴를 선택한다.
- 브라우저 경로는 `/groupware/community/notice`로 진입한다.
- 기존 대시보드 구조 안에서 공지사항 전용 콘텐츠가 렌더링된다.

### 3.2 목록 확인

- 상단에는 검색 영역과 새 공지 작성 버튼이 표시된다.
- 공지 목록은 최신순 피드형 카드로 노출된다.
- 중요 공지에는 강조 배지와 우선 표시가 적용된다.
- 사용자에게는 제목, 작성자, 작성일, 조회수, 요약 내용이 함께 보인다.

### 3.3 요약 정보

- 우측 또는 하단의 요약 패널에 공지 통계가 표시된다.
- 전체 공지 수, 이번 주 공지, 중요 공지 수와 같은 간단한 값이 노출된다.
- 검색/필터 상태는 UI에서 직관적으로 확인 가능하다.

## 4. 화면 구성

### 4.1 공통 영역

- `PageHeader` 사용
- breadcrumb: `그룹웨어 > 커뮤니티 > 공지사항`
- 설명 문구: `최근 공지 내용을 빠르게 확인합니다.`

### 4.2 본문 영역

- 검색 필드, 필터 칩, 새 공지 작성 버튼을 상단에 배치
- 카드형 피드 목록을 메인 영역으로 구성
- 우측 요약 영역은 공지 통계와 최근 이슈를 정리
- 메인 영역/요약 영역은 모바일에서는 단일 컬럼으로 전환

### 4.3 카드 구성

- 상단 배지: 중요, 운영, 보안, 알림 등
- 제목: 공지 제목
- 작성자/작성일/조회수 메타 정보
- 요약 문구: `reading` 가능한 짧은 설명
- 하단 표시: 첨부 파일 수, 카테고리, 상태 배지

## 5. 비기능 요구사항

- 다크/라이트 테마에서 대비와 가독성이 유지되어야 한다.
- `Container`와 `Grid`를 사용해 폭이 좁아도 자연스럽게 줄어들어야 한다.
- 텍스트가 잘려 보이지 않도록 반응형 폰트와 줄바꿈을 적절히 사용한다.
- 공통 스타일은 MUI `theme.palette`와 `background.paper`를 활용한다.

## 6. 검증 기준

- `/groupware/community/notice` 페이지가 정상 로드된다.
- 공지사항 페이지에는 `새 공지 작성` 버튼이 표시된다.
- 중요 공지와 검색 영역이 렌더링된다.
- 라이트/다크 테마에서 로컬 스타일이 안정적으로 적용된다.
- 좁은 폭 화면에서도 레이아웃이 카드형으로 자연스럽게 보인다.

## 7. 구현 제한

- 상세 페이지 전환, 에디터 연동, 실제 데이터 API 연결은 이 단계에서 포함하지 않는다.
- 공지 작성/수정/삭제 기능은 별도 단계로 분리한다.
- 게시판/자료실은 별도 화면으로 확장한다.
