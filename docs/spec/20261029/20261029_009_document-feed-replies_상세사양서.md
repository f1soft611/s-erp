# 문서작성 피드 답글 기본 접힘 상세 사양서

기준: [계획서](../../plan/20261029/20261029_009_document-feed-replies_계획서.md)

- 적용 화면: `/groupware/doc/write` 피드형 카드(고정 문서 포함) 및 동일 컴포넌트를 사용하는 문서 상세 패널.
- 댓글 본문, 시스템 이력, 이전 댓글 버튼, 댓글 입력창은 기존처럼 표시한다.
- 최초 렌더링 시 답글은 숨기며 기존 `답글 N개` 버튼의 `aria-expanded`는 false이다.
- 버튼 클릭 시 해당 댓글의 답글이 표시되고 `aria-expanded=true`가 된다. 다시 클릭하면 접힌다.
- 기존 `CommentThread`의 기본 접힘 및 토글 동작을 재사용하며 새 상태나 API를 추가하지 않는다.
- 추가 요청에 따라 문서 상세 패널에서도 답글을 기본 접힘으로 표시한다. 공지사항은 변경하지 않는다.
- 댓글 등록·답글 작성·수정·삭제, 이전 페이지 조회, 권한 및 오류 처리 계약은 유지한다.
- 375/768/1280px에서 댓글/입력창 유지, 답글 최초 접힘, 열기/닫기, 가로 넘침을 확인한다.
- 프론트엔드 표시 옵션만 수정하므로 백엔드/DB 변경 및 MCP 조회는 적용 대상이 아니다.
