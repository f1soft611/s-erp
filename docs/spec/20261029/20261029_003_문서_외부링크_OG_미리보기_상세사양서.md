# 문서 외부 링크 OG 미리보기 상세 사양서

## 목표와 범위

문서 작성/조회 본문, 댓글 및 답글에서 외부 웹 URL의 OG 미리보기를 제공한다. 기존 시스템 문서 공유 링크는 현재의 암호화 토큰, 권한 확인, 내부 문서 카드 및 우측 상세 열기를 유지한다. 외부 링크 카드와 내부 문서 카드는 라벨과 클릭 동작으로 구분하며, 미리보기 데이터는 저장하지 않는다.

## 링크 분류와 화면 동작

- 현재 origin의 문서 URL 중 `share` 토큰 및 지원 중인 legacy `documentId` 링크는 기존 내부 문서 미리보기로 분류한다. 기존 내부 링크 조회 API만 사용한다.
- 절대 URL 중 `http` 또는 `https`이며 현재 origin이 아닌 URL만 외부 링크 미리보기를 요청한다. `javascript:`, `data:`, 상대 URL, malformed URL 및 현재 origin의 비문서 URL은 외부 미리보기에서 제외한다.
- 앵커는 `href` 값만 대상으로 한다. 앵커 내부 표시 문자열은 별도 URL로 중복 검색하지 않는다. 앵커 바깥의 본문 URL 텍스트도 지원한다.
- 본문 단위로 같은 목적지 URL은 하나의 카드만 표시한다. 본문 변경/컴포넌트 해제 시 이전 조회 결과를 버리고 최신 결과만 표시한다.
- 내부 카드는 기존 `문서` 미리보기 UI와 상세 패널 동작을 유지한다. 외부 카드는 `웹 링크`로 명확히 표시하고 OG 이미지(있을 때), 사이트명, 제목, 설명을 제공한다. 외부 카드 클릭은 원문 URL을 `target=_blank`, `rel=noopener noreferrer`로 연다.
- 이미지는 지연 로드하고 `referrerPolicy=no-referrer`를 사용한다. 외부 조회 실패 시 일반 오류 상태를 표시하되 원문 링크는 계속 이용할 수 있어야 한다.

## API 계약

- `POST /api/v1/groupware/approvals/link-preview`
- 인증된 로그인 사용자만 요청할 수 있다. 권한 외에 문서/DB 조회는 하지 않는다.
- Request JSON: `{ "url": "<absolute HTTP(S) URL>" }`
- Success: 기존 응답 계약의 `item`에 `{ "siteName": string, "title": string, "description": string, "imageUrl": string | null }`.
- URL을 응답에 그대로 반향하지 않는다. 프론트엔드는 원문 href를 카드 링크로 유지한다.
- 잘못된/금지된 입력은 클라이언트 오류, 인증 실패는 기존 인증 응답, 원격 사이트 오류·비 HTML·초과 크기·시간 초과는 메타데이터 없음/서비스 오류로 처리한다. 응답이나 로그에 HTML, 예외 메시지, 전체 요청 URL을 포함하지 않는다.

## 안전한 외부 조회

- URL 길이는 2048자 이하로 제한한다. scheme은 HTTP/HTTPS, 포트는 명시되지 않은 기본 포트(HTTP 80/HTTPS 443)만 허용한다. user-info, fragment, 잘못된 host 형식은 거부한다.
- `localhost`, 사설망, loopback, link-local, multicast, unspecified, 예약 및 문서용 IPv4/IPv6 주소와 IPv4-mapped IPv6 주소는 차단한다. DNS 응답에 차단 주소가 하나라도 섞이면 전체 요청을 거부한다.
- DNS로 확인한 공인 주소를 해당 연결의 resolver에 고정한다. 프록시와 자동 리다이렉트를 사용하지 않는다. 리다이렉트는 최대 3회이며, 매번 목적지 scheme/host/port/DNS/IP를 처음부터 검증한다.
- 연결 및 읽기 제한은 각각 3초, 응답 본문은 최대 1 MiB, 압축은 요청하지 않는다. Content-Type이 `text/html` 또는 `application/xhtml+xml`이 아니면 거부한다.
- Jsoup은 HTML을 파싱하는 용도로만 사용한다. 페이지의 JavaScript를 실행하지 않는다. OG 제목/설명/사이트명은 태그 제거 후 공백을 정규화하고 최대 길이를 각각 제한한다. 제목이 없으면 HTML `<title>`과 host 순으로 대체한다.
- `og:image`는 페이지 URL 기준으로 절대 URL로 해석하고 scheme/host/DNS 공인 주소 정책을 확인한다. HTML 안의 이미지를 서버에서 추가 다운로드하지 않는다.
- 공유 링크의 토큰 발급/해석/권한 정책, 댓글 및 본문 저장 계약, DB 스키마는 변경하지 않는다. 외부 URL은 제3자 미리보기 서비스로 전송하지 않는다.

## 검증 기준

- Backend: parser fallback/정규화/길이 제한, URL scheme/authority/port/IP 범위, DNS 혼합 응답, redirect 재검증 및 최대 횟수, timeout/body limit/content type, 공인 주소 mock 응답에서의 OG DTO, 인증 컨트롤러 계약을 검증한다.
- Frontend: 내부 링크가 외부 API를 호출하지 않음, 외부 링크 추출과 중복 제거, anchor 표시 문자열 무시, 위험 scheme/current origin 제외, 성공/로딩/오류/원문 열기, 편집 후 오래된 응답 무시를 검증한다.
- 관련 frontend 테스트/build/lint와 backend 테스트를 실행한다. 실제 브라우저 375px, 768px, 1280px에서 내부/외부 링크를 함께 표시해 폭 넘침, 카드 구분, 클릭 동작을 확인한다.

## DB 근거

읽기 전용 DB MCP `list_tables`로 현재 공개 스키마의 테이블 목록을 확인했다. 이 기능은 외부 페이지 메타데이터만 조회하고 기존 내부 문서 조회 계약을 변경하지 않으므로 추가 테이블/컬럼/SQL이 필요하지 않다. 데이터 행은 조회하지 않았다.
