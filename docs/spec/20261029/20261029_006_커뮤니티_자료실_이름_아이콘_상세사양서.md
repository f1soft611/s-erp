## 표시 계약

| 항목 | 스타일 | 기존 동작 |
|---|---|---|
| 폴더 이름 | `text.primary`, bold | 클릭하면 기존처럼 해당 폴더의 파일 목록 조회 |
| 폴더 아이콘 | `text.secondary` 회색톤 | 활성/비활성 공통; 비활성 상태 chip은 유지 |
| 파일 이름 | `text.primary`, 일반 굵기 | 클릭하면 기존 인증 다운로드 실행 |
| 확장자 아이콘 | shared `getAttachmentIconMeta`의 아이콘 및 배경/전경색 | 비상호작용 표시 |
| 분류 폴더 아이콘/상태 | 현행 유지 | 기존 탐색/비활성 표시 유지 |

아이콘은 공지 첨부 목록이 사용하는 확장자별 메타데이터를 재사용한다. 이 변경은 자료실 `ArchiveFileGrid`의 표시 계층에 한정하며 API, 데이터, 권한, 검색, 파일 작업 계약을 바꾸지 않는다.

## 검증

- 자료실 테스트에서 파일/폴더 이름 색상과 폴더 이름 굵기를 검증한다.
- 폴더 클릭의 기존 folderCode 조회와 파일 클릭의 다운로드 호출을 확인한다.
- PDF 아이콘이 shared attachment helper가 제공하는 아이콘과 색상을 사용함을 검증한다.
- 자료실 대상 Vitest/oxlint 및 실제 브라우저의 375px, 768px, 1280px 화면을 확인한다.
