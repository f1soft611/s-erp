# 댓글 수정 권한 및 이미지 첨부 구분선 상세사양서

## 목표와 범위

문서 및 공지 댓글에서 수정/삭제 가능한 사용자를 댓글 작성자로 한정한다. 댓글 수정 화면의 기존 이미지 미리보기는 유지하고 미리보기와 파일명 사이에 시각적 구분선과 간격을 제공한다.

## 권한 동작

- 공통 댓글 UI에서 `isEditable === true`인 댓글에만 더보기 버튼과 수정/삭제 메뉴를 표시한다.
- `isEditable`이 false이거나 설정되지 않은 댓글에는 편집 메뉴를 표시하지 않는다.
- 공지 댓글은 `writerId`와 현재 인증 정보의 `userId`를 문자열로 비교한다. 둘 다 존재하고 일치할 때만 편집 가능하다.
- 이미 소유자 기준으로 `isEditable`을 설정하는 문서 댓글 adapter 동작을 유지한다.
- 서버 작성자 제한은 그대로 유지하며 클라이언트 표시는 서버 권한 검사를 대체하지 않는다.

## 이미지 첨부 표시

- 댓글 수정 시 기존 이미지 첨부 미리보기와 파일명은 모두 계속 표시한다.
- 이미지 미리보기와 파일명 영역 사이에 세로 구분선을 표시하고 양쪽에 시각적 간격을 둔다.
- 미리보기 크기, 첨부 삭제/다운로드 동작, 비이미지 첨부 레이아웃은 변경하지 않는다.
- hover 미리보기 동작은 추가하지 않는다.

## 검증 기준

- `isEditable: false`인 댓글에는 `댓글 메뉴 {작성자}` 버튼과 수정/삭제 메뉴가 없다.
- `isEditable: true`인 댓글은 기존 수정/삭제 흐름을 사용할 수 있다.
- 로그인 사용자와 같은 `writerId`인 공지 댓글만 편집 가능하다. 타인 작성자, 작성자 ID 누락, 비로그인 상태에서는 편집 불가다.
- 이미지 `previewUrl`이 있는 첨부는 수정 화면에서 계속 미리보이고, DOM상 미리보기와 파일명 영역 사이에 구분 요소가 있다.
- 백엔드, API 계약, DB schema 변경은 없다.
