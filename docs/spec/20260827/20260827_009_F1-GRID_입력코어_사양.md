# 20260827_009 F1-GRID 입력 코어 사양

## 1. 목적

`F1Grid`는 ERP 화면의 빠른 데이터 입력과 다중 행 작업을 위한 재사용 React Grid 컴포넌트다. 첫 적용 화면은 환경설정 > 시스템 관리 > 메뉴관리의 목록 영역이다.

## 2. 범위

### 포함

- 제네릭 행과 설정형 컬럼
- 단일, Ctrl 다중, Shift 범위, 체크박스 전체 선택
- 셀 포커스와 인라인 편집
- 행 추가, 선택 행 삭제, 삭제 행 복원, 선택 행 복제
- `normal`, `inserted`, `updated`, `deleted` 상태와 변경분 추출
- 방향키, Tab, Shift+Tab, Enter, Shift+Enter, F2, Escape, Insert, Delete, Ctrl+D
- Menu Management의 코드, 메뉴명, 상위 메뉴, 정렬, 사용 여부 편집

### 제외

클립보드, Validation, 정렬, 필터, 집계, 컬럼 관리, 사용자 레이아웃 저장, 서버 조회, 페이지네이션, 가상 스크롤, Excel export는 이번 구현에 포함하지 않는다.

## 3. Public API

```ts
type F1GridRowState = 'normal' | 'inserted' | 'updated' | 'deleted';

interface F1GridColumn<T extends object> {
  field: keyof T;
  headerName: string;
  width?: number;
  editable?: boolean | ((row: T) => boolean);
  type?: 'text' | 'number' | 'checkbox' | 'date' | 'select';
  options?: Array<{ value: string | number | boolean; label: string }>;
  align?: 'left' | 'center' | 'right';
  mergeRows?: boolean;
}

interface F1GridRef<T extends object> {
  getSelectedRows(): T[];
  getSelectedRowIds(): Array<string | number>;
  clearSelection(): void;
  addRow(row?: Partial<T>): void;
  deleteSelectedRows(): void;
  restoreDeletedRows(): void;
  duplicateSelectedRows(): void;
  getRows(): T[];
  getChanges(): {
    insertedRows: T[];
    updatedRows: T[];
    deletedRows: T[];
  };
  startEdit(rowId: string | number, field: keyof T): void;
  stopEdit(): void;
}
```

`F1Grid`는 `rows`, `columns`, `rowKey`, `ariaLabel`을 필수 props로 받는다. 행 상태는 소비자 행 타입을 변경하지 않는 내부 메타데이터로 관리한다.

`columnLine` prop을 지정하면 헤더와 본문 컬럼 사이에 세로 구분선을 표시한다. 기본값은 `false`다.

## 4. 편집 및 키보드 동작

- 더블클릭, Enter, F2는 편집 가능한 현재 셀의 편집을 시작한다.
- Enter는 값을 반영하고 같은 열의 다음 행으로, Shift+Enter는 이전 행으로 이동한다.
- Tab과 Shift+Tab은 값을 반영하고 이전 또는 다음 편집 가능한 셀로 이동한다.
- Escape는 편집 값을 취소한다.
- 방향키는 현재 셀 포커스를 이동한다.
- Insert는 빈 신규 행을 추가한다.
- Delete는 선택 행을 deleted 상태로 표시해 렌더링에서 숨긴다.
- Ctrl+D는 선택 행을 복제한 inserted 행을 만든다.
- `mergeRows: true`인 컬럼은 연속된 동일 값을 하나의 표시 값으로 병합한다. 병합은 표시 계층에서만 처리하며 행 데이터와 변경 상태에는 영향을 주지 않는다.
- 병합 그룹의 비선두 셀도 더블클릭하면 해당 행의 실제 값을 편집할 수 있으며, 값 변경 시 기존 행 상태 규칙을 따른다.

## 5. 상태 전이

| 동작      | 기존 normal 행 | inserted 행                 |
| --------- | -------------- | --------------------------- |
| 편집 저장 | updated        | inserted 유지               |
| 삭제      | deleted        | deleted                     |
| 복원      | normal         | inserted                    |
| 복제      | 원본 유지      | 원본 유지, 복제 행 inserted |

삭제 행은 화면 목록에서는 숨기지만 `getChanges().deletedRows`에는 포함한다. `restoreDeletedRows()`는 모든 deleted 행을 원래 상태로 복원한다.

## 6. 메뉴관리 적용

목록 영역의 기존 MUI `Table`은 `F1Grid<MenuManagementRow>`로 대체한다. 기존 우측 기본정보 패널과 `getMenuRows()` 서비스는 변경하지 않는다. 툴바의 새 메뉴, 삭제, 복제는 Grid ref 명령을 호출하며, 상태 요약은 inserted/updated/deleted 건수를 표시한다.

## 7. 검증 기준

- 메뉴관리 화면에 `F1-GRID`, 기존 메뉴 코드, 새 메뉴, 삭제, 복제 컨트롤이 표시된다.
- 체크박스와 Ctrl/Shift 조작으로 예상한 행만 선택된다.
- text, number, checkbox 편집은 값을 저장하고 기존 행을 updated로 표시한다.
- Insert/Delete/Ctrl+D 동작이 각각 inserted/deleted/inserted 행을 생성한다.
- `getChanges()`가 상태별 행을 정확히 분리한다.
- `mergeRows`가 연속된 동일 값만 병합하고, 비연속 동일 값은 병합하지 않는다.
- 병합 그룹의 비선두 셀을 편집해 해당 행만 `updated`로 표시한다.
- `npm run build` 및 Git Bash의 `npm run test`가 통과한다.
