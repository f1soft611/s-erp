# 20260827_007 권한/메뉴 관리 목업 화면 사양

## 1. 화면 목적

환경설정 > 시스템 관리 하위 메뉴에서 다음 두 관리 화면을 확인하고, 기본 CRUD 흐름을 이해할 수 있도록 구성한다.

- 권한관리: 역할별 접근 권한 설정
- 메뉴관리: 메뉴 구조/설명/사용 여부 관리

## 2. 데이터 모델

### 2.1 역할 데이터

```ts
type RolePermissionRow = {
  id: string;
  name: string;
  description: string;
  group: string;
  menuCount: number;
  active: boolean;
  permissions: {
    read: boolean;
    create: boolean;
    update: boolean;
    delete: boolean;
  };
};
```

### 2.2 메뉴 데이터

```ts
type MenuManagementRow = {
  id: string;
  code: string;
  name: string;
  parent: string;
  order: number;
  enabled: boolean;
  description: string;
  permissionGroup: string;
};
```

## 3. 권한관리 UI 요구사항

1. 상단 요약 카드 4개 유지
2. 역할 목록 테이블 왼쪽에 배치
3. 우측 상세 패널에는 선택 역할 이름, 설명, 권한 체크박스 표시
4. 기본 역할 3개 이상 표시: `ADMIN`, `MANAGER`, `USER`
5. 권한 항목: 읽기, 생성, 수정, 삭제
6. 선택된 역할을 변경하면 상세 패널 내용 갱신

## 4. 메뉴관리 UI 요구사항

1. 목록 테이블 상단에 새 메뉴 버튼 배치
2. 각 행은 코드, 메뉴명, 상위메뉴, 정렬, 사용 여부, 설명, 권한 그룹 표시
3. 선택된 메뉴 상세 패널에 기본 값 입력 가능
4. 샘플 메뉴 예시: `대시보드`, `기준정보`, `시스템 관리`, `권한관리`, `메뉴관리`
5. 선택된 메뉴를 편집할 수 있는 폼 필드 포함

## 5. 화면 분기 로직

- `DashboardContent`는 `content.kind` 값이 `roles` 또는 `menus`일 때 관리 컴포넌트를 렌더링한다.
- 기존 요약형 대시보드 화면은 `kind` 미설정 상태로 유지한다.

## 6. 비기능 요구사항

- React 19 + MUI 기반으로 구성
- 샘플 데이터는 정적 배열로 유지
- 페이지 이동 및 모듈 선택은 기존 로직을 재사용
- 추가 패키지 설치 없이 구현

## 7. 검증 기준

- 권한관리 페이지에서 `역할 목록`, `권한 매핑`, `조회`, `생성`, `수정`, `삭제` 텍스트가 보인다.
- 메뉴관리 페이지에서 `메뉴 관리`, `상위 메뉴`, `사용 여부`, `정렬 순서` 텍스트가 보인다.
- 각각 테이블과 상세 패널이 존재한다.
- `npm run build`, `npm run test` 통과
