## 변경 동작

- F1-Grid의 기본 텍스트 편집기에서 값이 `null` 또는 `undefined`인 셀은 화면에 빈 문자열로 보인다. 이를 변경하지 않고 편집 확정하면 빈 문자열로 변환하지 않고 기존 nullable 값을 유지한다. 실제로 문자열을 입력하거나 비어 있지 않은 문자열을 지우는 동작은 계속 변경으로 추적한다.
- 납품처 저장 요청 중에는 저장 버튼의 기존 진행 표시와 비활성화를 사용한다. 저장 성공 직후 그리드의 변경 행을 확정해 수정값을 유지하고 공통 성공 토스트를 표시한다. 거래처·납품처 목록을 재조회하는 동안 현재 목록과 우측 그리드 데이터를 유지하며 그리드 로딩 오버레이를 표시하지 않는다. 재조회 응답을 받으면 서버값으로 갱신하고, 저장·재조회 오류는 기존 화면 메시지로 표시한다. 저장 실패 시 성공 토스트를 표시하지 않는다.
- 거래처 선택 전에도 납품처 관리 우측에 빈 F1Grid를 렌더링한다. 거래처 선택 전에는 새 행 추가·행 폼 편집을 할 수 없으며, 선택 후 기존 권한에 따라 동작한다.

## 영향 범위 및 비목표

- 변경 영역은 공통 F1-Grid의 텍스트 셀 무변경 확정과 영업관리 납품처 관리 화면·상태 훅으로 한정한다.
- API 계약, 저장 데이터, 권한, 거래처 조회·선택 흐름과 일반 검색/거래처 변경 시의 조회 로딩 표시는 변경하지 않는다.
- 삭제 요청 로딩 방식 및 다른 화면의 저장·조회 동작은 변경하지 않는다.

## 검증

- 원본 값이 `null`/`undefined`인 기본 텍스트 셀에서 빈 값 확정 시 행 변경과 dirty 표시가 없어야 한다. 값 입력과 기존 값 삭제는 계속 변경으로 표시해야 한다.
- 납품처 관리 진입 직후 고객 목록과 우측 그리드가 모두 표시되고, 거래처 미선택 상태에서는 추가·편집이 불가능해야 한다.
- 저장 재조회 응답을 지연해도 기존 우측 그리드 행과 거래처 목록이 유지되고 로딩 오버레이가 나타나지 않아야 한다. 새로 저장한 수정값이 이전 값으로 되돌아가지 않고, 응답 후 서버 데이터가 표시되어야 한다.
- 저장 성공 시 공통 성공 토스트가 표시되고 저장 실패 시에는 성공 토스트 없이 오류 메시지가 표시되어야 한다.
- 저장 실패 및 재조회 실패는 기존 오류 영역에 표시되어야 한다.
