# 비밀번호 변경 필요 응답 처리 상세사양

기준: [계획서](../../plan/20261123/20261123_002_비밀번호변경_응답처리_계획서.md), 사용자 승인 설계.

## 계약

- 서버의 실제 403 응답은 `resultCode: "PASSWORD_CHANGE_REQUIRED"`와 `resultMessage`를 사용한다. 기존 [계정관리 사양](../20261120/20261120_001_hr-account_상세사양서.md)의 `code` 표기를 실제 계약에 맞춘다.
- JSON API, `apiGetBlob`, `apiDownload`, `apiGetEventStream`은 해당 응답을 받으면 공통으로 로그인 세션을 비밀번호 변경 필요 상태로 표시하고 요청을 오류로 종료한다. 라우터의 기존 강제 변경 화면 전환을 사용한다.
- 변경 필요 응답이 아닌 403은 세션 상태를 변경하지 않는다. 일반 오류와 정상 Blob, 다운로드, 스트림의 기존 반환·메시지 동작을 보존한다. 스트림의 정상 응답 본문은 소비하지 않는다.
- 인증 정책, 서버 응답 형식, 경로와 권한을 변경하지 않는다. 외부 연동 클라이언트는 이 저장소에서 수정하거나 검증했다고 가정하지 않는다.

## 검증

- 네 경로에서 변경 필요 응답과 다른 403을 각각 확인한다. Blob·다운로드·스트림의 정상 흐름과 JSON의 기존 응답 처리도 확인한다.
- 기존 비밀번호 변경 화면 관련 회귀 테스트와 네트워크 오류 테스트, 프론트 typecheck/build/lint를 수행한다.
- DB 스키마나 실제 계정 데이터는 변경하지 않는다.
