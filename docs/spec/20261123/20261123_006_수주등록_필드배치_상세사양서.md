- 기존 기준: 수주등록 화면 및 이를 공유하는 수주현황 상세.

## 배치

1200px 이상에서 첫 행은 수주번호, 수주일자, 납기일자, 수주상태; 둘째 행은 거래처, 납품처, 매출처; 셋째 행은 견적번호, 배송방법; 넷째 행은 전체 폭 비고다. 세 picker의 폭은 수주번호의 폭과 동일하다.

600px 미만에서는 한 열, 600px 이상 1200px 미만에서는 두 열로 각 행 그룹 내 필드를 순서대로 배치한다. picker는 상위 그리드와 동일한 열 수 및 간격을 사용한다. 비고는 전체 폭이다.

## 유지 및 검증

요청한 납품일자는 기존 명칭인 납기일자를 유지한다. 필드 값, 검증, picker 및 저장과 API 계약은 변경하지 않는다. 등록과 현황 상세의 공유 컴포넌트를 유지한다.

Vitest로 필드 순서를 검증하고 기존 입력/저장 회귀 테스트를 실행한다. 실제 브라우저 375/768/1280px에서 겹침과 가로 넘침을 확인하고 1280px에서 행 배치와 네 필드의 동일한 폭을 비교한다. 결과 문서에 스크린샷과 검증 결과를 기록한다.
