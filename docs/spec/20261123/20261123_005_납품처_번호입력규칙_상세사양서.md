# 납품처 번호 입력 규칙 상세사양서

기준: [계획서](../../plan/20261123/20261123_005_납품처_번호입력규칙_계획서.md), 거래처 관리 `createCustomerColumns`.

- 사업자번호 입력은 숫자 10자리까지 허용하고 `123-45-67890` 형태로 표시한다. 값이 있으면 10자리여야 하며 빈 값은 허용한다.
- 이동전화번호·전화번호·팩스번호 입력은 기존 `korean-phone` 형식으로 숫자만 받고 자동 하이픈을 적용한다. 02 지역번호는 9~10자리, 그 외 번호는 10~11자리를 허용하며 빈 값은 허용한다.
- 셀 편집, 행 폼, 붙여넣기 및 저장 검증은 공통 F1-Grid 입력 처리에 위임한다. 기존 거래처 관리의 사업자번호 필수 및 중복 검사는 납품처에 추가하지 않는다.
- 저장 API, 권한, 기존 행 데이터의 자동 변환은 변경하지 않는다.
- 회귀 검증은 행 폼 자동 서식·부적합 자리수 오류·빈 값, 셀 직접 편집 서식을 확인한다.
