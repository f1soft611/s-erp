# 즐겨찾기 폴더·메뉴 구분 상세사양서

기준: [작업지시서](../../directions/20261103/20261103_004_favorites-item-distinction_작업지시서.md), [계획서](../../plan/20261103/20261103_004_favorites-item-distinction_계획서.md).

## 화면

| 대상 | 표시 |
|---|---|
| 폴더 | 속이 채워지지 않은 FolderOutlined 윤곽선 아이콘, 기존 상속 색상, 일반 굵기의 이름(400), `폴더` 보조 표시. 컬러 배경/테두리 없음 |
| 루트/폴더 안 메뉴 | 문서 윤곽 아이콘, text.secondary 아이콘 색상, 일반 굵기의 이름, 기존 TreeItem 선택/hover |
| 빈 폴더 | 일반 폴더와 같은 스타일, 펼치면 기존 빈 폴더 안내 유지 |

- 폴더 전용 컬러 아이콘/배경/테두리/hover 강조를 사용하지 않는다. 메뉴와 동일한 기본 TreeItem 선택/hover를 유지한다.
- light/dark 테마에서 폴더 아이콘은 별도 색상 지정 없이 기존 행의 색상을 상속한다. 문서 아이콘은 text.secondary를 유지한다. 폴더 이름 굵은 강조는 제거한다.
- 폴더·메뉴 이름/행은 기존 일반 메뉴와 동일하게 light `#475569`, dark `#dbeafe`를 유지한다. 폴더 아이콘의 채움만 제거하고 색상은 변경하지 않는다.
- 헤더 높이는 기존 메뉴와 같은 `var(--dashboard-header-height)`(앱 58px), px 2, border-box, 중앙 정렬을 사용한다. subtitle2 제목 크기/굵기 800/letterSpacing 0.08em과 기존 헤더 배경을 맞춘다. 별 아이콘·즐겨찾기 제목·새 폴더 버튼은 유지한다.
- 본문 패널 배경과 트리 바깥 여백 12px은 기존 메뉴 패널과 맞춘다. 행 minHeight 36px, 하단 여백 2px, 글자 크기 0.875rem, 투명 좌측 테두리 3px도 기존 메뉴와 동일하게 한다. 폴더/메뉴 이름 굵기는 400을 유지한다.
- 좁은 목록과 긴 이름은 한 줄 말줄임 처리한다. 아이콘, `폴더`, 더보기는 축소되지 않는다. 기존 트리 들여쓰기는 유지한다.
- TreeItem 접근성 이름은 `폴더: 표시명`, `메뉴: 표시명`이다. 아이콘은 장식 요소이고 보조 표시로 색 이외의 단서를 제공한다.

## 보존 동작

- 폴더 행은 기존 방식으로 펼치고 접는다. 메뉴 이름/문서 아이콘은 기존 `onMenuSelect(moduleId, menuId)`를 호출한다.
- 메뉴와 폴더 더보기의 접근성 이름, 우클릭 메뉴, 생성/이름 변경/삭제/이동/해제 및 오류 처리는 유지한다.
- 메뉴 사용자 지정 이름과 원래 이름 fallback을 유지한다.
- 서버 데이터, API, DB, 권한, 순서 및 폴더 깊이는 변경하지 않는다. DB MCP 확인은 해당하지 않는다.

## 검증

- 같은 이름의 폴더와 메뉴를 접근성 이름과 아이콘/폴더 표시로 식별할 수 있다.
- 루트 메뉴와 펼친 폴더 안 메뉴에 문서 아이콘이 보이고 각각 원래 메뉴 선택 callback을 호출한다.
- 폴더 더보기에서 이름 변경 작업을 열고 메뉴 선택 callback은 호출하지 않는다.
- 빈 폴더를 펼쳤을 때 기존 안내가 보인다.
- 실제 브라우저 375/768/1280px, light/dark에서 폴더 전용 배경/테두리가 없고 아이콘이 기존 행 색상을 상속하며 폴더 이름은 일반 굵기인지 확인한다. 가로 넘침/더보기 겹침이 없고 긴 이름은 말줄임으로 표시한다.
- 관련 테스트, build, 변경 파일 lint를 통과하고 결과 문서/스크린샷을 남긴다.
