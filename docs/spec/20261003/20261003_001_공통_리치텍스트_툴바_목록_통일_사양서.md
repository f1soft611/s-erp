## Toolbar 계약

왼쪽부터 다음 순서로 한 줄 toolbar를 표시한다.

1. `문단` selector: 본문, 제목 1, 제목 2, 부제목
2. 굵게, 기울임, 밑줄, 취소선
3. 글자색 swatch (`A` icon)
4. 표 삽입
5. 링크 추가/수정/제거
6. 번호 목록, 글머리 목록

Font family/font size picker와 blockquote/undo/redo button은 노출하지 않는다. 기존 FontFamily, FontSize, Color, TextStyle schema extensions는 저장 JSON/HTML과 Excel paste의 호환을 위해 유지한다.

Paragraph selector는 현재 selection의 paragraph/heading type을 표시하고 선택 시 `setParagraph` 또는 `setHeading(level)`를 실행한다. `본문`은 paragraph 기본값(16px, normal), `제목 1`은 h1(24px, bold), `제목 2`는 h2(20px, bold), `부제목`은 h3(18px, semibold)로 렌더링한다. 표 삽입은 cursor 위치에 header row 없는 3×3 table을 삽입한다.

Color control은 기본색 복귀 action, 12개의 고정 preset swatch, 최근 선택 색상을 최대 6개까지 표시하는 compact popover로 연다. 최근색은 선택할 때마다 중복 제거 후 맨 앞에 추가하며 6개를 초과하면 가장 오래된 색을 제거한다. 선택한 swatch는 `setColor`로 적용하고 접근 가능한 이름/selected state를 노출한다. OS native color picker는 사용하지 않는다.

Link button은 표시 텍스트와 URL을 입력하는 accessible popover를 연다. 편집 중인 링크가 있으면 두 값을 채운다. 텍스트 선택이 있으면 확인 시 그 텍스트를 링크로 교체/갱신하고, 선택이 없으면 표시 텍스트를 삽입해 링크로 만든다. 취소는 편집 내용을 적용하지 않는다. URL은 기존 허용 protocol/도메인 정규화 검증을 통과해야 하며, 기존 링크 제거 action도 유지한다. StarterKit 내 Link extension을 configure해 `openOnClick:false`를 유지하고 별도 extension을 중복 등록하지 않는다.

## 시각/스크롤 계약

- Notice와 drafting-form은 동일한 `RichTextEditorToolbar` component를 사용한다.
- Call sites는 trigger/panel style override를 제공하지 않는다. Toolbar trigger와 각 command icon은 32px 정사각형, 개별 border 없음으로 표시한다. Notice 첨부 버튼은 toolbar 바깥 action으로 기존 outlined style을 유지한다.
- Toolbar panel만 얇은 border와 중립 surface를 가진다. Formatting command가 활성화되면 theme의 selected 배경을 표시하고, editor transaction/selection 변경 즉시 active state와 paragraph label을 갱신한다. Narrow viewport에서는 내부 horizontal scrolling/scrollbar 및 vertical wheel 이동을 유지한다.
- Toolbar buttons는 접근 가능한 이름과 정확한 `aria-pressed` state를 갖는다. Controls는 keyboard accessible하다.

## 호환성과 비목표

- Notice/draft upload adapter, 저장 payload, image metadata/ownership, modal fields/actions는 변경하지 않는다.
- Inline typography schema와 paste sanitizer는 유지한다. 기존 template/notice content에서 저장된 font/color marks를 잃지 않는다.
- 새 font-family/font-size editing UI, table dimension dialog, file/image upload 정책 변경은 범위 밖이다.

## 테스트

- shared toolbar: control 목록/순서, typography picker 부재, paragraph/underline/color/table/link/list commands.
- consumer integration: 공지/기안양식 공통 control 목록, 각 저장 payload와 domain image adapter.
- frontend focused suite와 `npm --prefix frontend run build`.
- screenshot artifact는 저장하지 않는다.
