# 출하계획·수주 도움창 상세사양

- 출하계획등록 수주 도움창의 검색 폼은 출하등록 출하계획 도움창과 동일하게 40px 높이 입력란 및 검색 버튼을 사용하고, 입력란은 남은 폭을 차지하며 버튼은 최소 88px 폭을 유지한다.
- 두 도움창의 번호 셀은 번호만 표시하는 클릭 가능한 버튼이다. 기존처럼 번호를 클릭하면 해당 수주의 모든 상세 행을 가져온다.
- 두 목록은 `selectionMode="row"`와 단일 선택 기본값을 적용한다. 번호 이외의 셀 클릭은 행을 강조하되 도움창을 닫지 않는다.
- 검색, AUTO/MANUAL 정책, 기존 권한, 오류 및 선택 데이터 계약은 변경하지 않는다.
- 출하계획현황 상세보기와 수정은 출하계획등록과 같은 기본정보·상세 F1Grid 컴포넌트를 사용한다. 상세보기는 읽기 전용이고 수정은 등록 화면처럼 계획일·수량과 분할 행을 편집한다.
- 등록 화면과 같은 계획수량·일자·합계 검증을 적용한다. 분할 신규 행의 상세 ID는 null로 전송하고 기존 행의 ID는 유지한다. 삭제된 행은 요청에서 제외한다. 검증 또는 서버 거절 시 대화상자와 입력을 보존한다.
- 재발 방지 규칙에는 동일 업무의 등록·현황 상세·수정에서 폼과 그리드를 공유하고 차이가 필요하면 사양에 근거를 기록하도록 명시한다.
