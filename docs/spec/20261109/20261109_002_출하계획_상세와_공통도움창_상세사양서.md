# 출하계획 상세와 공통 도움창 상세사양서

## 출하 선택 입력

- 출하등록 연결 수주번호에는 기존 계획 선택 대화상자를 여는 필드 내부 돋보기 아이콘을 제공한다. 직출하, 저장 후 잠금 및 권한에 따른 기존 비활성화 동작을 유지한다.
- 출하계획등록 수주번호에도 동일한 내부 돋보기 아이콘을 사용하며 AUTO와 MANUAL의 기존 선택·저장 제한을 유지한다.

## 출하계획현황 상세

- 출하현황처럼 계획번호 자체를 클릭해 상세를 연다. 별도의 상세 보기 버튼은 목록에 표시하지 않는다.
- 출하현황과 같은 우측 상세 패널, 작성자, 거래처 요약, 기본정보, 품목 목록, 더보기 메뉴를 사용한다.
- 더보기에서 상세보기와 권한에 따른 수정을 제공한다. 상세보기는 읽기 전용 대화상자이고 수정 대화상자에서는 기존 계획 상세의 일자·수량을 수정한다. 저장 실패 시 입력값을 보존한다.
- 기존 계획 ID, 데이터, 수량 제한, 조회 및 수정 권한을 유지한다.

## 공통 도움창

- 품목 검색의 기존 API 응답에서 `materialSpec`, `materialSpec2`, `unit`, `materialModelName`을 표시한다.
- 거래처 검색의 기존 API 응답에서 `businessNo`, `presidentName`을 표시한다.
- 값이 없으면 해당 값을 생략한다. 코드·이름·ID와 선택 콜백은 기존과 호환되며 검색 및 다른 도움창 유형은 유지한다.
- 새 테이블, 컬럼, API 또는 마이그레이션은 만들지 않는다.

## 검증

- 공통 도움창 사용처와 기존 선택 회귀, 권한별 계획 상세·편집, AUTO/MANUAL 및 오류 보존을 검증한다.
- 375/768/1280px에서 실제 브라우저 레이아웃과 합성 데이터 화면을 확인한다.
