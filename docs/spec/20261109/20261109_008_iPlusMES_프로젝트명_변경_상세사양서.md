# iPlusMES 프로젝트명 변경 상세사양서

## 승인된 변경 방향

사용자가 `S-ERP >> iPlusMES` 변경 진행을 승인했다. 현재 제품 브랜드를 나타내는 사용자 노출 문구와 활성 운영 안내만 변경하고, 실행 계약 및 역사적 기록은 유지한다.

## 변경 대상

- 프론트엔드 `index.html` 문서 제목
- 로그인 화면, 대시보드 좌측 브랜드, Not Found 화면의 제품명
- 웹 푸시 알림 제목, 대시보드 미리보기 페이지의 제목/브랜드
- 백엔드 정적 기본 화면의 제목/본문
- Maven 메타데이터의 사람이 읽는 `<name>`만 변경하고 artifactId/finalName은 유지
- 프로젝트 루트 README, 백엔드 README 및 현재 브랜드를 설명하는 개발 가이드
- 위의 이름을 검증하는 테스트 및 브라우저 스크립트

## 보존 대상

- `s-erp-auth`, `s-erp:page:*`, `s-erp:*` 등의 저장소 키·브라우저 이벤트명
- `s-erp-backend`와 같은 빌드 아티팩트명, 저장소 경로 및 URL
- `s-erp-postgresql-readonly` 등 MCP/도구 ID, API·환경 설정 식별자
- 과거 계획·사양·작업지시서·결과물의 당시 명칭
- 제품명 문구가 아닌 테스트 데이터 및 내부 코드 식별자

## 동작 및 호환성

제품명 텍스트 변경만 수행한다. 라우팅, 인증, 알림 페이로드, 저장 키, 서비스 워커 이벤트 처리, 데이터베이스 및 API 계약에는 동작 변경이 없다.

## 검증 기준

- 제품명 표기에 대한 관련 Vitest 테스트를 실행한다.
- `npm run build`와 `npm run test`가 성공한다.
- 브라우저에서 로그인 및 대시보드 브랜드를 확인하고 결과 스크린샷을 저장한다.
- 잔여 `S-ERP` 항목을 검색해 위 보존 대상과 부합하는지 확인한다.
