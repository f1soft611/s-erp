# 출하계획 분할 버튼 정렬 상세사양

- 분할 버튼만 있는 행과 분할·삭제 버튼이 모두 있는 행의 버튼 그룹을 셀 가운데 정렬한다.
- 삭제 버튼의 과도한 기본 최소 너비를 제거해 두 버튼을 가깝게 배치한다. 삭제 버튼의 접근 가능한 이름과 권한·비활성 조건을 유지한다.
- 분할 시 최신 활성 행의 선택된 원본 바로 뒤에 새 행을 삽입하고 계획수량 셀 편집을 시작한다. 새 행의 초기 수량은 0, 계획일은 빈 값으로 유지하고 기존 행 값은 자동 변경하지 않는다.
- 저장·재조회 시 같은 수주 상세의 행을 한 그룹으로 표시한다. 서버의 행 번호는 변경하지 않고, 그룹 순서는 최초 조회 순서, 그룹 내부 순서는 서버 조회 순서로 유지한다.
- 등록과 현황 수정 모두 같은 공통 그리드를 사용한다. 삭제, 검증, 권한 및 서버 계약은 변경하지 않는다.
