# 출하계획 F1Grid 편집 상세사양

- 출하계획등록과 현황 수정은 동일한 `DeliveryPlanForm`과 F1Grid 컬럼 정의를 사용한다.
- 계획일은 F1Grid `date`, 계획수량은 `decimal` 셀 편집기를 사용한다. 더블클릭·키보드 확정·편집 취소 등은 수주·출하와 같은 F1Grid 기본 동작을 따른다.
- 상세보기·권한 없음·저장 중에는 셀 편집과 분할을 막는다.
- 출하 화면과 동일하게 F1Grid 기본 행 높이(32px, 표시 배율 적용)를 쓰고 기본정보는 열 간격 16px·행 간격 8px, 상세 도구영역은 하단 8px 여백을 사용한다. 대화상자 내부는 출하 상세의 flex 및 스크롤 구조를 따른다.
- 계획 상세 조회는 테넌트가 일치하는 작성자의 `createdByName`, `createdByProfileImage`, `createdAt`을 제공한다. 작성자 정보가 없으면 기존 ID 및 기본 아바타를 표시한다. 목록 및 갱신 잠금 조회는 사진을 조회하지 않는다.
- 상세 패널은 수주·출하와 같은 작성자 영역, 거래처 요약, 정보 그룹과 품목 제목·건수·표 형식을 사용한다. 계획의 수량 및 초과출하 정보는 유지한다.
- 셀 변경은 저장 요청, 합계와 분할에 반영하며, 저장 실패 시 편집 내용이 유지된다. 저장 직전 편집 중인 값도 누락되지 않는다.
- 분할·삭제, 계획일·수량 검증, AUTO/MANUAL 정책 및 API 계약은 유지한다.
