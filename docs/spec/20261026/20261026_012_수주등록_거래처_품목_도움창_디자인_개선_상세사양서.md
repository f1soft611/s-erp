## 1. 공통 도움폼

거래처 및 품목은 `MasterPicker` 공통 선택 컴포넌트를 통해 같은 도움창을
사용한다. 도움창 컨테이너는 `CommonDialog`를 사용하고 제목은 선택 대상에
따라 거래처/품목 선택으로 표시한다. 모바일에서는 공통 다이얼로그의 모바일
전체화면 동작을 사용한다.

## 2. 컨트롤 표현 및 크기

- 선택 필드와 인접 선택 버튼 높이는 각각 40px이다.
- 다이얼로그 검색 입력과 검색 버튼 높이는 각각 40px이다.
- 검색 입력의 기본 세로 여백을 제거하고 입력 테두리와 버튼을 가운데
  정렬해 실제 화면의 기준선을 맞춘다.
- 버튼은 둥근 모서리와 검색 아이콘을 포함한다.
- 검색 결과는 코드와 이름을 구분해 표시하고 결과 선택 가능 상태를 유지한다.
- 좁은 화면에서는 필드와 버튼의 너비가 화면에 맞고 내용이 겹치지 않는다.

## 3. 동작/오류 처리 유지

- 검색 함수, 검색어 전달, Enter 검색, 선택 반환 타입은 변경하지 않는다.
- 로딩, 빈 결과, 검색 오류는 각각 구분해서 표시한다.
- 오래된 비동기 검색 결과가 최신 결과를 덮어쓰지 않도록 기존 요청 식별
  동작을 유지한다.
- 닫기 동작은 공통 다이얼로그의 닫기 컨트롤에서 제공하며, 선택하지 않고
  닫으면 선택 값은 변경되지 않는다.

## 4. 검증 기준

- picker 테스트에서 기본 필드/버튼 및 도움창 검색 필드/버튼 높이 40px,
  공통 다이얼로그 제목, 검색/선택, 로딩/빈 결과/오류 상태를 확인한다.
- 관련 picker 및 수주등록 테스트와 프로덕션 빌드를 실행한다.
- 실제 브라우저에서 375px, 768px, 1280px를 확인하고 스크린샷을 결과
  문서에 포함한다.
