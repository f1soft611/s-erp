## 렌더 계약

- 병합 열이 없는 일반 그리드에서 한 행의 값을 변경하고 Enter/Tab/다른 셀 클릭으로 확정하면 무관한 행 본문은 실행하지 않는다.
- 다른 행으로 포커스를 이동한 경우 그 행은 실제 표시 영향이 있으므로 갱신할 수 있다.
- dirty 정보는 현재 행의 각 컬럼에 대한 표시 boolean을 비교한다. 다른 행의 dirty 맵 참조 변경만으로 본문을 실행하지 않는다.
- 일반 행의 전체 목록 변경은 자신의 row 참조, rowIndex, 마지막 행 여부에 따른 갱신으로 처리한다. 행 개수 변화는 보수적으로 갱신한다.
- 병합 열이 하나라도 있으면 기존 전체 목록/병합 정보/전역 편집 상태 비교를 유지한다.
- 값이 다른 행에서 바뀌어도 생략된 행의 이벤트는 최신 부모 콜백을 실행해야 한다.
- 정렬로 행 인덱스가 바뀌거나 필터로 마지막 행이 바뀌면 셀/폼 버튼 경계를 최신 상태로 표시한다.
- 수정값 복구 시 dirty 표시 제거, getChanges 결과, 편집 취소 및 키보드 이동은 유지한다.

## 검증

- 합성 100행 × 2열, 고정열/열 가상화 조건에서 비수정 행의 cellAdornment 방문 0회와 비수정 renderer 0회를 검사한다.
- dirty 복구, 마지막 행 변경, 정렬/필터 및 병합 회귀 테스트를 확인한다.
- React Profiler actualDuration을 같은 합성 조건으로 전후 비교한다. 개발 빌드 측정이며 운영 지연이나 서버 성능으로 일반화하지 않는다.
- 375/768/1280px에서 편집 확정과 페이지 전체 가로 넘침을 확인하고 합성 데이터 스크린샷을 남긴다.
- API/DB/스키마 변경은 없다.
