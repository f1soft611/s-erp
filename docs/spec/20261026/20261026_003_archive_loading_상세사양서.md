## 설계 및 사용자 흐름

- 권장안: 기존 F1-Grid 스피너를 재사용하고 조회 전용 배너를 제거한다. 대안인 배너 높이 예약은 불필요한 공간을 남기므로 채택하지 않는다.
- 헤더, 검색 영역, 자료실 경로, 그리드 컨테이너는 처음부터 같은 구조를 유지한다.
- 날짜 기본값 초기화, 분류 조회, 파일 목록 조회 중 하나라도 진행 중이면 기존 F1Tree loading을 활성화한다.
- 날짜 초기화가 아직 완료되지 않았더라도 기본값 오류로 종료된 경우 영구 스피너를 표시하지 않는다.
- 날짜 요약의 초기 임시값은 `—`이다. 로딩을 설명하는 별도 문구는 표시하지 않는다.
- 분류 조회 중 정보 Alert는 표시하지 않는다. 조회 중 `조건에 맞는 파일이 없습니다.` Alert도 표시하지 않는다.
- 조회가 완료되고 파일이 없으면 기존 빈 결과 Alert를 표시한다.
- 업로드/수정/삭제 진행 안내, 조회 실패 Alert와 재시도, 권한 안내는 유지한다.

## 영향 범위

- 자료실 페이지의 조회 로딩 표시만 변경한다.
- 공통 F1-Grid/F1Tree 구현 및 다른 화면의 로딩 UX는 변경하지 않는다.
- API, 필드, DB 변경이 없으므로 DB MCP 확인 및 SQL 생성 대상이 아니다.

## 검증 기준

1. 날짜 기본값을 지연하면 그리드 스피너만 표시되고 목록 요청은 초기화 후 시작한다.
2. 분류 조회만 지연해도 그리드 스피너가 유지된다.
3. 파일 목록을 지연하면 그리드 스피너가 유지된다.
4. 모든 조회 완료 후 스피너가 사라지고 파일/폴더 또는 기존 빈 결과 안내가 표시된다.
5. 날짜/분류/목록 오류 및 재시도는 정상 표시된다.
6. 375/768/1280px에서 지연된 정상 목록 조회 전후 그리드 상단 좌표와 높이가 유지된다. 빈 결과/오류/변경 작업의 명시적 안내는 기존 동작을 유지한다.
