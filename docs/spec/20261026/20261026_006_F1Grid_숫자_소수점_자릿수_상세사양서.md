# F1-Grid 숫자 소수점 자릿수 상세 사양서

## 1. 개요

F1-Grid 컬럼에 이미 정의된 `decimalPlaces` 옵션을 이용해 숫자 표시 정밀도를 제어한다. 옵션이 없는 일반 숫자 컬럼의 화면 및 엑셀 기본 표시 정밀도는 최대 소수점 이하 5자리로 변경한다.

## 2. 컬럼 API

새 속성은 추가하지 않는다. 기존 `F1GridColumn` 정의를 사용한다.

```ts
{
  field: 'quantity',
  headerName: '수량',
  type: 'number',
}
```

기본 숫자 서식은 최대 5자리까지 선택적으로 표시한다. 자릿수를 고정하려면 기존 `decimalPlaces`를 지정한다.

```ts
{
  field: 'unitPrice',
  headerName: '단가',
  type: 'number',
  decimalPlaces: 2,
}
```

## 3. 표시 규칙

| 컬럼 설정 | 최소 소수 자릿수 | 최대 소수 자릿수 | 동작 |
| --- | ---: | ---: | --- |
| `type: 'number'` 또는 `type: 'decimal'`, `decimalPlaces` 미지정 | 0 | 5 | 소수부 끝의 0과 불필요한 소수점은 생략 |
| `decimalPlaces: N` 유효한 정수 지정 | N | N | 지정 자릿수를 고정 표시 |
| `format: 'currency'`, `decimalPlaces` 미지정 | 0 | 0 | 기존 KRW 기본 표시 유지 |
| `format: 'currency'`, `decimalPlaces: N` 지정 | N | N | 기존대로 지정 자릿수 고정 표시 |

기본 숫자 예시:

| 값 | 화면 표시 |
| ---: | --- |
| `1` | `1` |
| `1.2` | `1.2` |
| `1.2345` | `1.2345` |
| `1.234567` | `1.23457` |

명시 자릿수 예시:

| 설정 | 값 | 화면 표시 |
| --- | ---: | --- |
| `decimalPlaces: 2` | `1.2` | `1.20` |
| `decimalPlaces: 0` | `1.8` | `2` |

숫자 표시는 기존 `ko-KR` 로캘 그룹 구분을 유지한다. 반올림은 `Intl.NumberFormat`의 기존 반올림 동작을 따른다.

## 4. 엑셀 내보내기

- `number`/`decimal` 컬럼의 미지정 기본 숫자 서식은 `#,##0.#####`로 설정한다.
- 이 서식은 최대 5자리까지 표시하며 끝자리 0과 불필요한 소수점은 숨긴다.
- 명시된 `decimalPlaces`는 기존처럼 해당 개수의 `0` 자리표시자를 사용해 고정 표시한다. 예: `decimalPlaces: 2`는 `#,##0.00`.
- `format: 'currency'`는 기존 기본 `₩#,##0` 표시와 명시 정밀도 동작을 유지한다.
- 엑셀 셀의 숫자 원본 값은 변경하지 않고 숫자 형식 서식으로 표시 정밀도를 제어한다.

## 5. 편집 및 데이터 보존

- `decimalPlaces` 지정 시 현재 편집 입력 정규화 동작을 그대로 유지한다.
- 기본 표시 정밀도를 5자리로 변경해도 미지정 편집 입력의 제한을 새로 추가하지 않는다.
- 셀의 원본 값과 변경 추적/저장 흐름은 변경하지 않는다.

## 6. 검증 기준

1. 기본 숫자 컬럼은 정수에서 소수점을 표시하지 않는다.
2. 기본 숫자 컬럼은 소수부 끝의 0을 제거하고 최대 5자리까지 반올림 표시한다.
3. `number`와 `decimal` 유형 모두 같은 기본 정밀도 규칙을 따른다.
4. 명시한 `decimalPlaces`는 화면과 엑셀에서 기존처럼 고정 자릿수를 유지한다.
5. KRW 통화 기본값 및 기존 통화 표시가 변하지 않는다.
6. 엑셀 기본 숫자 셀의 `numFmt`가 `#,##0.#####`이다.
7. 포커스 프론트엔드 테스트와 프로덕션 빌드가 통과한다.
