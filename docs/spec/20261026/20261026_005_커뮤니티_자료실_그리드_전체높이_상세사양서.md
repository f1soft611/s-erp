## 동작 및 레이아웃

- 자료실 페이지의 헤더, 검색 영역, 안내 메시지 및 경로는 기존 순서와 높이 흐름을 유지한다.
- 그리드 영역은 세로 flex 컨테이너가 되어 `ArchiveFileGrid`가 부모의 남은 높이를 차지한다.
- `ArchiveFileGrid`가 전달하는 `height="100%"`는 가용 그리드 높이를 사용한다.
- 뷰포트 높이 기반 `calc()`는 사용하지 않는다.
- 기존 최소 그리드 높이와 페이지 내부 여백을 유지한다.

## 비기능 및 범위

- 자료실 파일/폴더 데이터, 검색, 권한, 파일 작업, 조회 API는 변경하지 않는다.
- 공통 F1-Grid/F1Tree 및 백엔드/DB는 변경하지 않는다.
- 현재 워크트리에서 진행 중인 자료실 로딩 관련 변경을 보존한다.
- 폭 375px, 768px, 1280px에서 가로 넘침 없이 동작해야 한다.

## 검증 기준

1. 관련 자료실 페이지 테스트가 통과한다.
2. `npm run build`가 통과한다.
3. 브라우저에서 세 뷰포트 폭 모두 그리드가 경로 아래 남은 세로 공간을 차지하는지 확인한다.
4. 결과 문서에 검증 결과와 스크린샷을 기록한다.
