# 20261026_007 그룹웨어 문서현황·자료실 브로드크럼 경로 수정 상세사양서

## 1. 표시 규격

| 페이지 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 문서현황 | 선택한 모듈명 | 문서관리 | 현재 메뉴명 |
| 자료실 | 선택한 모듈명 | 커뮤니티 | 현재 메뉴명 |

`PageHeader`가 항목을 입력 순서대로 표시하므로 페이지가 부모 메뉴명을 포함한 세 항목을 전달한다. 현재 메뉴명은 기존처럼 `currentMenuName`을 사용한다.

## 2. 동작 범위

- 문서현황과 자료실 두 화면만 변경한다.
- 메뉴 계층에 해당하는 고정 상위 메뉴명만 추가한다. 이동 링크나 별도 라우팅은 추가하지 않는다.
- 헤더 설명 접기, 액션 버튼, 페이지 검색 및 데이터 동작은 변경하지 않는다.

## 3. 회귀 검증

- 각 페이지 통합 테스트에서 전체 브로드크럼 문자열이 DOM에 존재하는지 확인한다.
- 테스트는 변경 전 각 페이지가 두 항목만 전달하므로 실패해야 한다.
- 관련 Vitest를 실행하고 TypeScript/Vite 빌드로 전체 컴파일을 검증한다.
- 브라우저에서 두 화면의 세 단계 경로를 확인하고 결과 문서에 캡처를 연결한다.
