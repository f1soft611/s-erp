# 문서 공통 UI 테스트 복구 상세사양서

- [계획서](../../plan/20261118/20261118_007_document-component-tests_계획서.md)
- [최신 결재 액션 메뉴 사양](../20261111/20261111_001_문서결재액션_더보기메뉴_상세사양서.md)은 툴바의 인라인 승인 액션을 제공하지 않는다. 상태·문서구분·구분선·고정·더보기의 순서와 간격을 보존한다.
- [공유 링크 미리보기 사양](../20261029/20261029_004_문서_공지_공유링크_상호미리보기_상세사양서.md)은 앵커의 href만 추출하고 외부 URL도 카드로 표시한다. 내부 링크의 목적지를 외부 URL로 변경하면 전체 preview 컨테이너가 아닌 이전 내부 카드가 사라져야 한다.
- 클립보드 사례는 메뉴가 사용하는 멘션 사용자 선행 조회를 빈 성공 fixture로 제공한다. 기존 실패의 추가 오류 알림은 누락된 멘션 조회 응답에 의한 것이며, 실제 공유 성공/실패 알림은 각각 1회인지 계속 검증한다.
- 외부 미리보기 API는 합성 메타데이터로 mock한다. 실제 외부 요청이나 업무 데이터를 사용하지 않는다.
- `DraftFormTemplateDialog`의 미저장 변경 확인창은 현재 `취소`/`계속`을 사용한다. 계속 선택 후 임시 이미지 삭제 요청과 onClose 호출을 유지한다.

테스트 계약 복구만 수행한다. 운영 문구·API 응답 계약·권한 정책·UI·DB 변경과 신규 스크린샷은 해당 없음이다.
