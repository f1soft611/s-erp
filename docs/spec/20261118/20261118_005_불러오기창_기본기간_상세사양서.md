# 20261118_005 구매자재·품질 불러오기 창 기본 조회 기간 상세 사양서

기준: [작업지시서](../../directions/20261118/20261118_005_불러오기창_기본기간_작업지시서.md), [계획서](../../plan/20261118/20261118_005_불러오기창_기본기간_계획서.md)

## API
- `GET /api/v1/materials/purchase-request-confirms/candidates?keyword&fromDt&toDt`: 구매요청 `request_dt` 기간(포함) 필터.
- `GET /api/v1/materials/purchase-request-confirms?keyword&status&fromDt&toDt`: 확정 `confirm_dt` 기간(포함) 필터.
- 날짜 형식 `YYYY-MM-DD`, 한쪽만 있어도 허용, 시작일>종료일이면 400 `시작일이 종료일보다 늦습니다.`
- 확정 품목(`/purchase-orders/candidates`), 발주 품목, 수입검사 합격분, 가입고 후보 API는 기존 `fromDt`/`toDt`를 그대로 쓴다.

## 화면
| 창 | 조건 이름 | 기준 |
| --- | --- | --- |
| 구매요청 선택 | 요청일 시작·종료 | 구매요청 요청일 |
| 구매요청확정 선택 | 확정일 시작·종료 | 확정일 |
| 확정 품목 선택 | 확정일 시작·종료 | 확정일 |
| 발주 품목 선택 | 발주일 시작·종료 | 발주일 |
| 수입검사 합격분 선택 | 검사일 시작·종료 | 검사일 |
| 검사 대기 가입고 선택 | 가입고일 시작·종료 | 가입고일 |

- 검색 줄: 기간 두 칸(168px, 공통 달력, 필수 표시 없음) → (확정 목록은 상태 선택 다음) → 검색어 → 검색 버튼. 좁으면 줄바꿈.
- 처음 열릴 때 `usePickerDateRange(open)`이 서버 날짜로 종료일=오늘, 시작일=오늘−`PICKER_DEFAULT_RANGE_MONTHS`개월을 채우고 `ready`가 되면 첫 조회한다. 서버 날짜 실패 시 비운 채 조회(브라우저 날짜 대체 없음).
- 시작일>종료일이면 조회하지 않고 `○○일 시작일은 종료일보다 늦을 수 없습니다.`를 표시한다.

## 검증 기준
- 훅: 열릴 때 기본 기간 채움·한 번만 호출, 실패 시 비움. 6개 창: 기본 기간 표시, 첫 조회 1회에 `fromDt`/`toDt` 포함.
- 백엔드: 두 API가 기간을 질의에 전달하고 역순을 400으로 거부.
