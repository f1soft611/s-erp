## 1. DB (`tb_item_partner_price`)
| 변경 | 내용 |
| --- | --- |
| `customer_id` | NOT NULL 해제. NULL = 품목 기본단가 |
| `tax_type` | 신규 varchar, NOT NULL, 기본 `TAXABLE`(발주 `tax_type`과 같은 공통코드 `PURCHASE_TAX_TYPE`). 기존 행은 `TAXABLE` |
| `vat_included_at` | 신규 char(1), NOT NULL, 기본 `N`. 기존 행은 `N` |
| `foreign_unit_price` | 신규 numeric, NULL 허용 |
| `currency` | NOT NULL·기본 `KRW` 해제(NULL 허용). 외화단가의 통화(공통코드 `CURRENCY`). 기존 `KRW`는 NULL로 정리 |
| 인덱스 | `customer_id IS NULL` 행용 부분 유니크 `(tenant_id, material_id, trade_type, start_dt)` 추가(기존 유니크는 NULL을 중복 판정하지 못함) |

- 스크립트: `docs/database/20261118`, `backend/DATABASE/20261118` 동일 파일(추가 SQL·롤백·변경 이력 md), `db-schema.md` 갱신. 롤백은 `currency` NULL을 `KRW`로 복원하고 신규 컬럼·인덱스를 제거하며, 기본단가 행이 있으면 삭제 전 확인이 필요함을 명시한다.

## 2. 저장 규칙 (서버)
- 필수: 품목, 구분(매입/매출), 적용일(`start_dt`), 원화단가(`unit_price` ≥ 0). 거래처는 선택(비우면 기본단가).
- 외화단가를 입력하면 통화가 필수이고, 통화 없이 외화단가를 넣으면 400. 외화단가가 없으면 통화는 비운다.
- `end_dt`는 `start_dt` 이상. 같은 (품목, 거래처 또는 기본, 구분) 안에서 기간이 겹치면 409 또는 400(기존 오류 코드 규칙 따름).
- 신규 행 저장 시 직전 행(같은 키, `end_dt`가 NULL이고 `start_dt` < 새 `start_dt`)의 `end_dt`를 새 `start_dt`의 전날로 자동 설정한다. 직전 행이 과거(이미 종료)이면 건드리지 않는다.
- 수정·삭제 제한(서버 날짜 기준): 종료일이 오늘 이전이면 수정·삭제 불가(409). 현재 적용 중(시작일 ≤ 오늘 ≤ 종료일/무기한) 행은 `start_dt` 변경 불가, 나머지 정정 허용. 예정 행은 자유.
- 자동 종료로 인한 직전 행 변경도 과거 행이 아닌 경우에만 수행한다.

## 3. 조회
- 목록 API에 `includeHistory`(기본 false) 추가. false면 `end_dt IS NULL OR end_dt >= 오늘`, true면 전체.
- 응답에 `taxType`, `vatIncludedAt`, `foreignUnitPrice`, `currency`, 거래처 미지정 시 `customerId` NULL, 행 상태(`past`/`current`/`future`)를 포함한다.
- 단위는 품목 마스터 단위를 조회해 표시만 한다(저장하지 않음).

## 4. 단가 조회 폴백 (`selectDefaultUnitPrice`)
- 거래처 일치 행이 유효하면 그 행, 없으면 `customer_id IS NULL` 기본단가 행. 정렬은 `ORDER BY (customer_id IS NULL), start_dt DESC, price_id DESC`.
- 반환: 기존 `unitPrice`, `currency` 유지. 구매확정 호출부 동작은 같고 기본단가를 새로 찾을 수 있다는 차이만 있다.

## 5. 프론트
- 컬럼: 품목, 거래처(비우면 "(기본)" 표시), 구분, 원화단가, 부가세구분(공통코드), 부가세포함(Y/N), 외화단가, 통화(공통코드), 적용일, 종료일, MOQ, 사용여부, 단위(조회 전용).
- 조회조건 "이력 포함"(현재·예정만 / 이력 포함). 과거 행은 회색, 편집·삭제 불가. 현재 행은 적용일 편집 불가.
- 외화단가 입력 시 통화 필수 검증 메시지, 저장 오류는 상단 메시지(`usePageMessages`)로 표시.
- 엑셀 가져오기·내보내기 양식에 신규 컬럼 반영, 거래처 빈 값은 기본단가로 처리.
- 수량·단가 소수점은 모듈 정책(COMMON)을 따른다. 컬럼에 고정 자릿수를 두지 않는다.
