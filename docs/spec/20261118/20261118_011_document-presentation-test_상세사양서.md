## 원인과 변경

- 표시 전용 테스트가 전체 페이지·API 준비와 결재·합의 선택 과정을 중복 수행해 대부분의 실행 시간을 사용한다. 단독 계측에서도 약 4초로 기본 제한에 근접했고 파일/전체 실행에서는 초과했다.
- 순수 표시 단언을 실제 DocumentApprovalFields 컴포넌트로 이동한다. 고정 결재 1명, 긴 이름 결재 1명, 합의 1명의 동일 상태를 props로 구성한다.
- 이전 표시·접근성·삭제 노출·말줄임 단언을 모두 유지한다. 운영 컴포넌트, 저장 payload, 선택/추가 기능은 변경하지 않는다.
- 문서작성의 별도 통합 케이스가 선택·추가·삭제·후보 제외 동작을 계속 검증한다. 이번 이동 자체는 그 통합 흐름의 검증이라고 표현하지 않는다.
- timeout 상향, source skip, 테스트 제외, 자동 재시도는 추가하지 않는다.
- 후속 파일 실행에서 확인한 첨부 테스트 두 개는 기존 문서작성 dialog로 DOM 조회 범위를 한정한다. 공통 준비 대기는 같은 기안자 값 조건을 공개 라벨로 확인한다. 준비 조회 비용 계측과 변경 후 전체 파일 결과를 구별해 기록한다.

## 완료 기준

- 문서작성 156개 + 기존 fields-theme 3개 + 이동한 표시 1개 = 160개를 전부 실행한다.
- 운영 무변경, 전체 케이스 수 보존, 표시 단언 보존을 diff로 확인한다.
- 임시 계측은 소유 검증 worktree에서도 제거한다.
- UI 변경이 없는 테스트/문서 작업으로 신규 스크린샷은 해당 없음이다.
