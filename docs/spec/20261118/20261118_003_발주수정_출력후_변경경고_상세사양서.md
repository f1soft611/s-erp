# 20261118_003 출력된 발주서 변경 시 경고 상세 사양서

기준: [작업지시서](../../directions/20261118/20261118_003_발주수정_출력후_변경경고_작업지시서.md), [계획서](../../plan/20261118/20261118_003_발주수정_출력후_변경경고_계획서.md)

## 화면 (`PurchaseOrderCreatePage`, 발주현황 수정 창과 공통)
- 조건: 저장된 발주(`loaded`)의 `printAt === 'Y'`이고 수정 가능한 상태(`editable`, 입고대기마감·조회·취소 상태 제외).
- 경고(warning Alert): `이미 출력된 발주서입니다. 내용을 바꾸면 출력본과 달라집니다. 저장은 가능합니다.` — 상태 안내이므로 계속 표시한다.
- 저장 확인: 저장 직전(검증 통과 후)에 공통 확인창을 띄운다. 본문: `이미 출력된 발주서입니다. 저장하면 출력본과 내용이 달라집니다. 저장하시겠습니까?` 확인 시 저장, 취소 시 저장하지 않고 입력을 유지한다.
- 입고대기마감 저장(`closeEditable`)은 이 경고·확인이 없다. 미출력(`printAt != 'Y'`) 발주도 없다.
- 저장 후 출력 표시(`printAt`)는 서버 응답 그대로 유지한다.

## 검증 기준
- 출력된 발주: 경고가 보이고, 저장 → 확인창, 취소 → PUT 호출 없음, 확인 → PUT 1회.
- 미출력 발주: 경고·확인창 없이 저장.
- 입고대기마감 모드: 출력된 발주여도 경고·확인창 없이 저장.
