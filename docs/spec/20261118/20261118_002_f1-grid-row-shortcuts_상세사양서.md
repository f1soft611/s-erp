# F1-Grid 행 단축키 상세사양서

| 키 | 행 동작 | 허용 설정 |
| --- | --- | --- |
| `Delete` | 선택한 행 삭제 | `allowDeleteRowInContextMenu` |
| `Insert` | 행 추가 | `allowAddRowInContextMenu` |
| `Ctrl+D` | 선택한 행 복제 | `allowDuplicateRowInContextMenu` |

행 동작은 해당 설정이 `false`이면 실행하지 않는다. 품목관리는 행 삭제·복제를 꺼 두고 행 추가 설정에는 기존 생성 권한과 화면 상태를 전달하므로 컴포넌트 설정을 바꾸지 않는다. `disableContextMenu`는 전체 메뉴 표시만 제어하며 키보드 동작의 일괄 차단으로 해석하지 않는다.

선택 행 삭제가 차단된 경우 일반 셀의 값도 지우지 않는다. 선택 행이 없는 편집 가능한 셀의 값 지우기, 이미지 셀의 기존 삭제 규칙, 편집 중 `Backspace`, 포커스 이동은 유지한다. 그리드 ref의 명시적 호출과 서버 권한은 변경하지 않는다.

활성·비활성 단축키를 그리드 테스트로 확인하고 기존 이미지 삭제 테스트를 회귀 검증한다. 브라우저에서는 셀 선택 후 단축키를 눌러 설정에 따라 행이 유지되거나 변경되는지 확인한다.
