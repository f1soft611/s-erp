# 20261118_006 구매자재·품질 수량·단가 소수점 정책 적용 상세 사양서

기준: [작업지시서](../../directions/20261118/20261118_006_구매자재_수량단가_소수점정책_작업지시서.md), [계획서](../../plan/20261118/20261118_006_구매자재_수량단가_소수점정책_계획서.md)

## 대상 컬럼
| 구분 | 필드 | 처리 |
| --- | --- | --- |
| 수량 | `orderQty`, `arrivedQty`, `remainQty`, `arrivalQty`, `receiptQty`, `receivedQty`, `receivableQty`, `requestQty`, `confirmQty`, `orderedQty`, `stockQty`, `passQty`, `failQty`, `inspectQty`, `inspectedQty`, `otherInspectedQty`, `waitQty`, `maxQty` | `decimalPlaces` 제거(정책 적용) |
| 단가 | `unitPrice` | `decimalPlaces` 제거(정책 적용) |
| 금액 | `supplyAmt`, `vatAmt`, `totalAmt`, `amount` | 2자리 고정 유지 |
| 건수·비율 | `receiptCount`, `monthClosedCount`, `openCount`(0자리), `passRate`(1자리) | 유지 |

## 구현
- 현황 컬럼 도우미: `quantityColumn`(수량·단가, 자릿수 미지정)과 `amountColumn`(금액, 2자리)로 분리(가입고·입고·발주 현황). 구매요청·수입검사 현황의 수량 도우미는 자릿수를 지정하지 않는다.
- 입고마감 화면의 `amount()` 도우미로 만든 `receiptQty`는 `decimalPlaces: undefined`로 정책을 따른다.
- 등록 화면·불러오기 창·검사 화면은 컬럼의 `decimalPlaces: 2`만 제거한다.

## 검증 기준
- 구매자재·품질 관련 단위 테스트 통과, `tsc` 통과.
- 실서버: 발주현황(발주수량·발주단가·입고잔량), 수입검사현황(합격량·불합격량), 입고현황(입고수량·입고단가)이 정책(2자리·항상 표시)으로 표시된다.
