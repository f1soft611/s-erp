# CI 플랫폼·준비 계약 상세사양서

- [계획서](../../plan/20261118/20261118_018_ci-contract-stability_계획서.md)는 기존 [작업지시서](../../directions/20261118/20261118_001_repository-remediation_작업지시서.md)의 테스트 복구 후속이다.
- 운영 로컬 달력의 주 시작 정책을 Asia/Seoul 고정으로 바꾸지 않는다. 테스트만 달력 좌표를 직접 생성해 UTC/KST에서 같은 계약을 검증한다.
- createdAt fixture는 로컬 숫자 Date를 ISO 문자열로 직렬화해 기존 정상 문자열 파싱 검증을 보존한다. 현재 시각 인수는 Date를 유지한다.
- editor는 초기 댓글보다 늦게 준비되거나 초기 전환 중 잠시 없을 수 있다. 등록 입력의 실제 준비를 findByRole로 기다리며 별도 sleep이나 timeout override는 추가하지 않는다.
- 사용자 별도 컬럼 위치 수정은 보존하고 기대 배열을 갱신한다. 행·진행상태·품목코드의 상대 순서를 명시적으로 계속 검사한다. 실제 horizontal scroll로 이동된 컬럼을 viewport에 넣은 뒤 표시를 기다리며 가상화 자체를 끄지 않는다.
- API/DTO/DB·화면·권한·의존성을 바꾸지 않으며 새로운 스크린샷 대상이 아니다.
- 원격 CI와 로컬 검증의 결과·소스 입력을 분리한다. 중단한 로컬 실행은 전체 결과나 통과 모수로 기록하지 않는다.
