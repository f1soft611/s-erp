# 20261118_002 발주 수정 시 가입고 행 잠금 상세 사양서

기준: [작업지시서](../../directions/20261118/20261118_002_발주수정_가입고행_잠금_작업지시서.md), [계획서](../../plan/20261118/20261118_002_발주수정_가입고행_잠금_계획서.md)

## 1. API
### `GET /api/v1/materials/purchase-orders/{id}` (응답 확장)
- 각 상세 행에 `arrivedQty` 추가(decimal, 가입고가 없으면 0). 계산: 유효 가입고 합 − 유효 수입검사 불합격 합.

### `PUT /api/v1/materials/purchase-orders/{id}` (검증 추가, 409)
| 조건 | 응답 |
| --- | --- |
| 가입고가 있는 행이 요청에 없음(삭제) | 409 `가입고가 있는 행은 삭제할 수 없습니다.` (기존) |
| 가입고가 있는 행의 수량·단가·납기·창고·검사대상·공급가·세액·합계 중 하나라도 저장값과 다름 | 409 `가입고가 있는 행(N행)은 수량·단가·납기·창고·검사대상을 바꿀 수 없습니다. 가입고를 먼저 취소해 주세요.` |
| 가입고가 하나라도 있는데 발주일·부가세구분·부가세 포함 여부가 저장값과 다름 | 409 `가입고가 있는 발주는 발주일·부가세 설정을 바꿀 수 없습니다. 비고만 수정할 수 있습니다.` |
- 허용: 가입고가 없는 행의 모든 수정, 가입고가 있는 행의 행 비고, 헤더 비고, 잠긴 행을 그대로 포함한 저장.
- 수량 비교는 `compareTo`(2.0 = 2.00), null 안전. 취소·마감 API는 변경 없음.

## 2. 화면 (발주 등록·수정, 발주현황 수정 창 공통)
- 행: `arrivedQty > 0`이면 발주수량·발주단가·납기일·입고창고·검사대상·세액을 편집할 수 없다(컬럼 `editable`을 행 함수로). 비고는 편집 가능.
- 저장된 발주에서 `가입고수량` 컬럼(읽기 전용)을 `잔량` 뒤에 표시한다.
- 헤더: 가입고가 있으면 발주일, 부가세구분, 부가세 포함 스위치를 비활성화한다(비고는 활성).
- 안내(info): `가입고가 있는 행 N건은 수량·단가·납기·창고·검사대상을 바꿀 수 없습니다. 발주일·부가세 설정도 바꿀 수 없고 비고만 수정할 수 있습니다. 가입고를 취소하면 수정할 수 있습니다.` (수정 가능한 상태에서만)
- 선택 행 빼기: 가입고가 있는 행은 빼지 않고 `가입고가 있는 행은 뺄 수 없습니다. 가입고를 먼저 취소해 주세요.`를 표시한다. 나머지 선택 행은 뺀다.
- 가입고가 없으면 잠금·안내가 없다.

## 3. 검증 기준
- 백엔드: 행 값 변경 거부(수량 증가·감소, 단가, 납기, 창고, 검사대상), 헤더 변경 거부(발주일, 부가세구분, 포함 여부), 허용(미가입고 행 수정, 행·헤더 비고, 가입고 없는 발주의 헤더 변경), 상세 `arrivedQty`.
- 프론트: `detailToRow` 매핑, 컬럼 `editable` 함수, 수정 창의 잠금·안내·행 빼기 거부, 잠금 없음 회귀.
- 실서버: 가입고가 있는 발주(PO-20261117-0018 등)에서 수정 시도 409 확인, 화면 잠금 확인.
