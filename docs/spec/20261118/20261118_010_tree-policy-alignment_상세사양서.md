## 결정과 동작

- 9월 9일 호출자 정책 사양보다 최신인 10월 공통 Tree 계약을 적용한다. 사양 006에서 최신 사양을 누락해 운영 회귀로 판정했던 부분을 정정한다.
- F1Tree의 정렬·필터 강제 비활성화를 유지한다. 명시적 false props도 계층 보호 정책을 해제하지 않는다.
- 헤더에 오름차순·내림차순·필터 메뉴가 없으며 본문 우클릭에 정렬 해제·필터 해제 항목도 없다.
- 부모 Zulu와 자식 Beta·Alpha가 `getRowOrder` 순서로 유지되는지 확인한다. 메뉴를 열어도 계층과 형제 순서는 바뀌지 않는다.
- 일반 F1Grid의 정렬·필터 및 해제 동작은 기존 회귀로 계속 검증한다.
- 운영 코드, 원본 행, 변경 추적, API, DB, 펼침/접기 동작은 변경하지 않는다.

## 검증

- 기존 전체 실행의 두 메뉴 탐색 실패는 당시 결과로 보존한다.
- context-menu, tree, tree-projection 테스트 전체를 제외 없이 실행한다.
- 운영 코드 무변경 hash와 git diff를 확인한다. 화면 변경이 없어 새 브라우저 스크린샷은 해당 없음이다.
- 시간 제한을 상향하거나 테스트를 skip하지 않는다.
