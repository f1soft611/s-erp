# 공지 이전 댓글 초기 커서 상세사양서

[작업지시서](../../directions/20261118/20261118_044_notice-initial-cursor_작업지시서.md)와 [계획서](../../plan/20261118/20261118_044_notice-initial-cursor_계획서.md)에 따른 기존 커서 계약 복구다.

## 설계 선택

1. **미초기화 이벤트 fallback에 서버 커서 사용:** 권장안이다. 기존 effect 이후의 의미를 첫 상호작용에서도 사용하며, 소유 map entry가 있는 경우의 동작은 바꾸지 않는다.
2. 버튼을 effect 이후에만 활성화: 초기 UI/접근성을 변경하고 경합을 버튼 숨김으로 우회하므로 선택하지 않는다.
3. 댓글 관련 모든 state/effect를 재구성: 병합/CRUD/서버 reset의 영향 범위가 커지므로 별도 lint 단위로 남긴다.

| 상태 | 요청 커서 |
| --- | --- |
| own entry 없음 + 서버 커서 7 | 첫 commit에서도 7 |
| own entry 없음 + 서버 커서 없음 | 기존처럼 첫 표시 댓글 |
| own entry에 로컬 커서 4 | 서버 메타데이터와 무관하게 기존 4 유지 |
| own entry가 undefined | 기존처럼 첫 표시 댓글; 서버 prop을 임의 복원하지 않음 |
| 로딩 중/더 이전 없음 | 기존 중복 요청/완료 방지 그대로 |

수정은 이벤트 내 순수 값 선택뿐이다. 상태 초기값, effect, ref, 댓글 추가/수정/삭제/병합, 이전 댓글 완료 조건, DOM/JSX/CSS와 공개 props를 변경하지 않는다. API 인자 수·필드·경로·응답/DB 계약을 바꾸지 않아 DB MCP·SQL 대상이 아니다. 서버 저장이나 신규 댓글 조회 정책을 추가하지 않는다.

검증은 실제 callback 인자를 관찰한다. 첫 commit 테스트는 의도적으로 passive effect 전의 사용자 이벤트를 고정하며, 일반 native 브라우저 흐름과 동일한 시점 검증이라고 확대하지 않는다. 브라우저는 실제 컴포넌트의 일반 댓글 흐름/반응형 보존을 보완한다.
