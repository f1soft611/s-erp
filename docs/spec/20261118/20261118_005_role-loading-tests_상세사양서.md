## 현재 검증 계약

- `loading` 중 그리드 root는 `aria-busy="true"`이고, 직접 자식 `f1-grid-loading-overlay`가 `position: absolute`, `inset: 0`으로 지정 높이의 그리드를 채운다.
- 오버레이는 입력을 차단하고 공통 로딩 스피너를 표시한다. 헤더 구조는 남는다.
- 실제 역할 목록 요청을 보류한 상태에서 헤더와 busy/overlay를 확인하고, 요청을 완료한 뒤 실제 역할 행·overlay 제거·busy 해제를 기다린다.
- 저장과 저장 후 조용한 재조회는 기존 행과 편집 잠금을 보존하고 전체 로딩 오버레이를 띄우지 않는다. 존재하지 않는 과거 스켈레톤 식별자를 조회하는 부정 단언으로 대체하지 않는다.
- 검색 영역의 과거 `검색 조건` 제목을 강제하지 않는다. 실제 `역할 검색` 입력의 placeholder와 권한 그리드를 검증한다.
- 5개 스켈레톤 행과 과거 내부 gap/minHeight 값은 현재 전체 로딩 상태의 공개 계약이 아니다. 초기 스켈레톤 구현을 제거한 `7cb277e8` 이후의 현재 스피너 계약과 구별한다.

테스트·설명만 변경하므로 UI 스크린샷, DB MCP, SQL 스크립트는 해당 없음이다. 실패를 skip하거나 저장/오류/매핑 단언과 시간 제한을 변경하지 않는다.
