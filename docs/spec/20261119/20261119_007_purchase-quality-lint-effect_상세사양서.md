# 20261119_007 구매·품질 잔여 lint 정리 상세사양서

기준: [계획서](../../plan/20261119/20261119_007_purchase-quality-lint-effect_계획서.md)

## 동작 보존 기준
- **검색 초기화**: 기본값이 로드되고 세션이 비어 있을 때 한 번 기본 검색 조건을 적용하고 세션에 저장한다. 세션이 있으면 기본값을 적용하지 않는다. 초기화 버튼은 기본값으로 되돌린다.
- **목록**: filters가 null이면 요청하지 않는다. 필터가 바뀌면 이전 응답을 무시하고 일반 로딩(초기 로딩 상태 시작, hasLoaded=false, 오류 비움). `refreshQuietly`는 목록과 로딩 표시를 유지한 채 재조회(quiet 이후 조건 변경은 일반 로딩, filters가 null인 동안의 quiet 요청은 재개 시 quiet 유지).
- **상세**: selectedId가 null이면 요청 없음. 같은 ID 재선택은 요청하지 않는다. ID·새로고침 토큰이 바뀌면 로딩 시작·오류 비움, 늦은 응답은 무시. 닫기는 선택·항목·오류·편집 모드를 비운다.
- **등록 화면 상세 로드**: 수정 대상 ID가 있으면 불러오기 중 로딩 표시, 성공 시 폼 값 채움, 실패 시 오류 표시, 늦은 응답 무시.

## 구현 규칙
- effect 본문에서 동기 `setState`를 하지 않는다. 시작 상태는 렌더 중 이전 요청 값과 비교해 보정하고(입고현황 훅과 동일 형태), effect는 요청 호출과 응답 처리(비동기 콜백)만 한다.
- 훅 공개 반환 값(이름·형태)과 세션 키·버전은 바꾸지 않는다.
