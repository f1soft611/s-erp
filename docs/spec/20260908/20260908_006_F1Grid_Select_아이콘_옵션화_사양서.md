## 1. 공통 컬럼 API

`F1GridColumn<T>`에 아래 선택 속성을 추가한다.

```typescript
selectOptionIcon?: (option: F1GridOption) => ReactNode;
```

- `option`은 현재 선택된 항목 또는 드롭다운 목록의 `value`, `label`을 가진 객체다.
- 반환값이 `null`, `undefined`, `false` 등 렌더링할 수 없는 값이면 해당 항목에는 아이콘 영역을 만들지 않는다.
- 속성을 지정하지 않으면 Select 에디터는 아이콘을 전혀 표시하지 않는다.
- 새 속성은 선택 사항이므로 기존 Select 컬럼의 선언과 런타임 동작(아이콘 제외)은 호환된다.

## 2. Select 편집 UI

### 기본 동작

- 선택된 값 영역은 현재 옵션의 레이블만 표시한다.
- 드롭다운 메뉴의 각 항목은 레이블만 표시한다.
- 값 비교는 기존과 동일하게 문자열 정규화로 수행하며, `onChange`는 원래 옵션의 `value`를 반환한다.

### 명시적 아이콘 동작

- `selectOptionIcon`이 선언된 컬럼만 선택값과 드롭다운 각 옵션을 렌더러에 전달한다.
- 렌더러가 아이콘을 반환하면 아이콘과 레이블을 수평 정렬한다.
- 렌더러가 빈 값을 반환하면 해당 옵션은 아이콘 없이 레이블만 표시한다.
- 공통 `SelectEditor`는 특정 아이콘 이름과 MUI 아이콘을 매핑하거나 fallback 아이콘을 제공하지 않는다.

## 3. 모듈관리 적용

- `ModuleManagementPanel`의 `iconName` 컬럼은 `MODULE_ICON_OPTIONS`의 값과 일치하는 아이콘을 `selectOptionIcon`으로 반환한다.
- 대상 아이콘은 기존 목록의 `Settings`, `Folder`, `Dashboard`, `Inventory`, `People`, `Business`, `AdminPanelSettings`, `ListAlt`, `FileText`, `ClipboardCheck`, `CheckCircle`, `Notifications`, `Assignment`, `Security`, `CalendarMonth`, `ShoppingCart`이다.
- 이 목록에 없는 값 또는 빈 값은 아이콘을 반환하지 않으며, 레이블 또는 현재 값만 보인다.
- 다른 Select 컬럼에는 `selectOptionIcon`을 선언하지 않는다.

## 4. UI 및 반응형 기준

- 아이콘이 있는 행은 아이콘과 레이블이 수직 중앙 정렬되고 기존 Select 높이를 변경하지 않아야 한다.
- 아이콘이 없는 행에는 아이콘 자리용 공백이나 fallback 아이콘이 남지 않아야 한다.
- 375px와 1280px에서 모듈관리 Select 편집 상태의 레이블과 아이콘이 겹치거나 잘리지 않아야 한다. 그리드의 기존 내부 가로 스크롤 정책은 유지한다.

## 5. 오류 처리 및 권한

- API 호출, 저장 흐름, 권한 판정은 변경하지 않는다.
- 미등록 아이콘 값은 오류가 아니라 레이블 전용 출력으로 처리한다.

## 6. 검증 기준

1. `selectOptionIcon`이 없는 Select의 선택값과 드롭다운 항목이 레이블만 렌더링한다.
2. `selectOptionIcon`이 반환한 아이콘이 선택값과 드롭다운 항목에 렌더링된다.
3. 렌더러가 빈 값을 반환한 항목에는 아이콘 영역이 없다.
4. 모듈관리 `iconName` 컬럼만 아이콘 렌더러를 선언한다.
5. 기존 선택값 변경 이벤트와 F1-Grid 편집 동작이 유지된다.
6. 관련 Vitest, 프론트엔드 빌드, 375px/1280px 브라우저 캡처를 완료한다.
