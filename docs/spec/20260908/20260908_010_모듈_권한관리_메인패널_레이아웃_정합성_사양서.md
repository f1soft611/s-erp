# 상세 사양서

## 1. 적용 대상

- 모듈관리: `frontend/src/pages/settings/system/modules/components/ModuleManagementPanel.tsx`
- 권한관리: `frontend/src/pages/settings/system/roles/components/RoleManagementPanel.tsx`
- 레이아웃 기준: `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx`

## 2. 공통 외곽 레이아웃 계약

메뉴관리 패널의 외곽 레이아웃을 다음 기준으로 사용한다.

```text
Outer Box
  p: { xs: 1.5, sm: 1 }
  minWidth: 0
  flex: 1
  display: flex
  flexDirection: column
  height: 100%
  overflow: hidden
    Card
      borderRadius: 1
      border: 1px solid rgba(148,163,184,0.18)
      boxShadow: none
      display: flex
      flexDirection: column
      flex: 1
      height: 100%
      overflow: hidden
        CardContent
          p: 2.5
          display: flex
          flexDirection: column
          flex: 1
          height: 100%
          overflow: hidden
```

모듈관리와 권한관리 모두 부모 높이를 따라가도록 `flex`와 `height`를 적용하고, 기존 2열 grid의 높이 계산을 유지한다.

## 3. 모듈관리 패널 사양

### 3.1 구조

```text
ModuleManagementPanel
  Outer Box
    Card
      CardContent
        제목 영역
        F1Grid 영역
```

### 3.2 동작

- 기존 `ModuleManagementPanel`의 props, ref handle, 저장/삭제/엑셀, 로딩 prop을 변경하지 않는다.
- 기존 제목과 F1Grid는 같은 CardContent 안에 둔다.
- F1Grid 영역은 `flex: 1`, `height: 100%`로 유지한다.
- 카드 외곽 스타일은 메뉴관리 기준의 `borderRadius: 1`, 테두리, `boxShadow: none`, `overflow: hidden`을 사용한다.

## 4. 권한관리 패널 사양

### 4.1 구조

```text
RoleManagementPanel
  Outer Box: 메뉴관리 기준의 외곽 Box
    Inner Grid Box
      Card: 권한 목록
        CardContent
          제목 영역
          권한 F1Grid
      Card: 권한별 사용자 매핑
        CardContent
          제목/선택 역할 영역
          사용자 F1Grid 또는 오류/빈 상태
```

### 4.2 반응형

- Inner Grid Box의 기존 `gridTemplateColumns: { xs: '1fr', lg: '1.2fr 1fr' }`를 유지한다.
- `gap: 2`는 유지한다.
- Outer Box의 기준 패딩은 메뉴관리 패널과 동일하게 적용한다.
- 권한관리의 내부 카드에는 메뉴관리 기준 카드 스타일을 적용한다.
- 각 CardContent는 `p: 2.5`, 세로 flex, `flex: 1`을 유지하고, 필요한 경우 `height: 100%`, `overflow: hidden`을 적용한다.
- 사용자 매핑 카드의 선택 역할 텍스트는 기존 `nowrap`, ellipsis 동작을 유지한다.

## 5. 비기능 요구사항

- 375px, 768px, 1280px viewport에서 콘텐츠가 겹치거나 잘리지 않아야 한다.
- 페이지 전체에 불필요한 가로 스크롤을 추가하지 않는다.
- F1Grid/F1Tree의 행 높이, 컬럼, 로딩 스켈레톤, 편집 상태에 영향을 주지 않는다.
- API endpoint, request/response, 권한 정책, 상태 관리 및 이벤트 계약을 변경하지 않는다.

## 6. API 및 DB 계약

- API 변경 없음.
- Request/Response 필드 변경 없음.
- DB 변경 없음. 기존 스키마 영향 검토 완료.

## 7. 검증 기준

1. 모듈관리와 권한관리의 메인 패널이 메뉴관리와 동일한 외곽 여백 및 카드 경계 기준으로 표시된다.
2. 모듈관리 단일 F1Grid가 카드 내부 높이를 정상적으로 채운다.
3. 권한관리의 권한 목록/사용자 매핑 카드가 데스크톱에서 2열, 좁은 화면에서 1열로 표시된다.
4. 세 화면에서 기존 로딩, 조회, 편집, 저장, 삭제, 엑셀, 오류 표시 동작이 유지된다.
5. `npm run build`가 통과한다.
6. 관련 Vitest가 통과한다.
7. 실제 브라우저에서 375px, 768px, 1280px 뷰포트의 스크린샷을 확인하고 결과 문서에 기록한다.
