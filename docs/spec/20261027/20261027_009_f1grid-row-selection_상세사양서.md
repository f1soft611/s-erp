# F1-Grid 행 선택 상세 사양

근거: [작업지시서](../../directions/20261027/20261027_009_f1grid-row-selection_작업지시서.md), [계획서](../../plan/20261027/20261027_009_f1grid-row-selection_계획서.md).

## 공통 인터페이스

`F1GridProps.selectionMode?: 'cell' | 'row'`를 제공한다. 미지정 시 `cell`이다. 체크박스 표시 여부인 `showCheckbox`, 편집 가능 여부인 컬럼 `editable`, 우클릭 선택 정책인 `selectRowOnContextMenu`와 독립적이다. F1Tree는 기존 props 상속으로 같은 옵션을 사용할 수 있다.

## 동작

| 구분 | cell (기존 기본값) | row |
|---|---|---|
| 클릭 표시 | 기존 활성 셀 테두리 | 선택 행 전체 반투명 테마 강조, 비편집 활성 셀 테두리 없음 |
| 셀 범위 드래그 | 기존 범위/overlay | 비활성화, 다른 행에 hover해도 선택을 바꾸지 않음 |
| Ctrl/Command 클릭 | 기존 동작 유지 | 클릭 행 추가/해제 |
| Shift 클릭 | 기존 동작 유지 | 마지막 일반 클릭 행부터 현재 표시 순서의 연속 행 선택 |
| 위/아래 키 | 기존 포커스 이동 | 포커스와 행 선택 이동, Shift로 범위 확장 |
| 좌/우 키 | 기존 포커스 이동 | 같은 행의 내부 포커스만 이동, 다중 행 선택 유지 |
| Tab/편집 | 기존 계약 | 기존 이동/편집 계약 유지, 행 이동 시 선택도 이동 |
| Ctrl+C | 기존 셀 범위 복사 | 선택된 표시 행의 모든 표시 컬럼을 표시 순서로 TSV 복사 |
| checkbox/ref/초기 선택 | 기존 계약 | 같은 rowSelection을 강조·콜백·ref·복사에 사용 |
| 우클릭 | 기존 정책 | `selectRowOnContextMenu=false`이면 선택 행 표시를 변경하지 않음 |

행 강조는 GridRow의 실제 높이에 맞춘 별도 overlay로 표시한다. 병합 셀 그룹 전체를 선택한 것처럼 칠하지 않으며 병합 그룹의 두 번째 상세 행을 클릭해도 그 행만 강조한다. 고정 열과 가로 스크롤에도 같은 높이/범위를 사용한다. overlay는 pointer 이벤트를 차단하지 않는다. editor가 열릴 때의 편집 테두리/검증 오류는 유지한다.

기존 선택 상태를 중복 저장하지 않는다. `onSelectionChange`, `getSelectedRowIds`, `getSelectedRows`, `setSelectedRowIds`, `clearSelection`을 그대로 사용한다. 모드를 바꾸면 기존 셀 범위/복사 overlay와 drag 상태를 해제해 이전 모드의 표시가 남지 않게 한다. 행 선택 자체는 유지한다.

## 적용

수주현황과 문서현황 Grid에 옵션을 명시한다. 그 외 관리/작성/조회 화면의 기본 동작은 변경하지 않는다. 현황의 checkbox 표시, 선택 콜백, 읽기 권한, 엑셀 내보내기, 행 메뉴와 기존 컬럼/병합/스크롤 설정을 유지한다.

## 검증

회귀 테스트로 기본값 호환, 행/다중 선택, 위아래 이동, 동일 행 좌우 이동, 전체 행 복사, ref/checkbox 해제, 병합 두 번째 행 선택, 우클릭 정책, 모드 전환을 확인한다. 기존 셀 범위·병합·고정 열·렌더 성능 테스트를 실행한다. 실제 Chromium에서 375/768/1280px로 행 강조의 정렬, 가로 스크롤 시 고정 열 일치, 복사·키보드, 페이지 가로 넘침을 확인한다.

백엔드/DB/API 계약 변경은 없다.
