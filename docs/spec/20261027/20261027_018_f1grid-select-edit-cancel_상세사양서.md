## 동작 계약

1. `select` 셀을 편집하고 목록을 여는 조작은 셀 범위 드래그를 시작하지 않는다.
2. 목록을 연 상태에서 다른 셀로 이동하거나 해당 셀을 클릭해도 선택 범위가 확장되지 않는다.
3. 다른 셀 클릭 시 `select` 에디터를 취소하고 원래 값을 보존한다.
4. 메뉴 옵션을 선택하면 선택값이 한 번 반영되고 에디터가 종료된다.
5. 비선택 닫기, 텍스트/숫자 등 다른 에디터 외부 클릭, 일반 셀 범위 드래그는 기존 동작을 보존한다.

## 회귀 검증

- 메뉴 열기 동작에서 드래그 상태가 활성화되지 않는지 확인한다.
- 열린 메뉴에서 다른 셀로 이동/클릭한 뒤 에디터 종료, 원본 값 보존, 미변경 행 및 드래그 범위 부재를 확인한다.
- 정상 옵션 선택과 셀 범위 드래그 테스트를 재실행한다.
- 실제 브라우저에서 합성 Grid를 확인하고 스크린샷을 `docs/result/20261027/f1grid-select-edit-cancel/screenshots`에 저장한다.
- 백엔드/API/DB 계약 및 스키마는 변경하지 않는다.
