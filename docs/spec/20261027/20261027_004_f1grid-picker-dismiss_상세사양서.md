# F1-Grid 선택 에디터 종료 상세 사양서

## 근거

- [계획서](../../plan/20261027/20261027_004_f1grid-picker-dismiss_계획서.md)

## 동작 계약

1. `type: 'code'` 버튼 또는 `type: 'select'` 에디터를 열고 다른 셀/그리드 밖을 클릭하면 편집이 종료된다.
2. select 목록이 열린 상태에서 항목을 선택하지 않고 backdrop을 클릭하거나 Escape로 목록을 닫으면 셀 편집도 종료된다.
3. 미선택 종료 시 원래 값과 타입, dirty 상태를 보존한다. code의 값 변경은 기존 picker 패치 경로로만 수행한다.
4. 코드 선택 버튼 클릭은 기존 `onOpenCodePicker`를 호출하고 반환/비동기 패치 계약을 유지한다.
5. select 항목 클릭은 해당 옵션의 원래 타입 값을 한 번 반영하고 에디터를 종료한다. 닫기 이벤트가 이전 값으로 선택을 덮어쓰면 안 된다.
6. 목록 안 상호작용 보호와 기존 user/autocomplete 에디터 동작, 열 너비/행 높이/스타일은 바꾸지 않는다.
7. 옵션 선택 후 목록 닫기 이벤트가 이어져도 editor plugin의 `endEdit`는 선택 확정 경로에서 한 번만 호출한다.

## 검증

- 다른 셀 및 외부 영역 클릭 후 코드 선택 버튼/combobox가 제거되는지 검사한다.
- select backdrop 클릭 및 Escape 닫기에서 combobox 제거와 변경 행 0건을 확인한다.
- code 숫자값 및 select 숫자 옵션의 타입 보존을 검사한다.
- 정상 옵션 선택 및 picker 패치가 보존되는지 확인한다.
- 실제 브라우저 375/768/1280px에서 동일 동작과 페이지 가로 넘침을 확인한다.
- 스크린샷은 `docs/result/20261027/f1grid-picker-dismiss/screenshots`에 합성 데이터만 저장한다.
- 백엔드/API/DB 계약 및 스키마는 변경하지 않는다.
