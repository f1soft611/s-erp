# F1-Grid Excel 정수 숫자 표시 상세 사양

## 원인

일반 숫자 컬럼의 기본 Excel 서식 `#,##0.#####`는 Excel에서 값이 정수여도 소수점 구분자만 표시할 수 있다. 확인된 Excel 결과는 값 `4`, 서식 `#,##0.#####`에서 셀 표시가 `4.`였다.

## 동작 계약

- 입력이 finite Number로 정규화되고 정수인 `number`/`decimal` 셀은 `#,##0` 서식을 쓴다.
- 그 외 기본 일반 숫자 셀은 기존 `#,##0.#####` 서식을 유지한다.
- `decimalPlaces`가 유효하게 명시된 경우 기존 고정 자릿수 형식을 유지한다. `decimalPlaces: 0`은 `#,##0`이다.
- `currency`는 기존 기본 KRW 0자리 및 명시 자릿수 형식을 유지한다.
- 셀의 numeric 값, 숫자 그룹화, 데이터 원본 및 나머지 typed export 동작은 변경하지 않는다.

## 검증

- 실제 `.xlsx` 생성/재로딩 테스트에서 정수 Number와 정수 숫자 문자열의 값/서식, 소수값의 기존 선택 소수 서식, 명시 소수 자릿수를 검증한다.
- Windows Excel에서 정수 값 `4`의 NumberFormat `#,##0`과 표시 문자열 `4`를 확인한다.
- 전용 Excel export 테스트와 프론트엔드 빌드를 실행한다.
