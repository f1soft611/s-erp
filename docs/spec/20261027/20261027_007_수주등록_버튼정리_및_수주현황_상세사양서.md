## 1. 수주등록 버튼 정리

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 상세 행 추가 | 상단 액션바(쓰기 그룹) | 수주 상세 그리드 헤더, `품목 선택` 왼쪽. 저장 권한(`canWrite`) 있을 때 표시, 편집 불가 시 비활성 |
| 선택 행 삭제 | 상단 액션바 | 제거. 우클릭 메뉴 `행 삭제` 사용 |
| 우클릭 행 복사 | 비활성(`createDuplicate` 없음) | 활성. 편집 가능 시에만 메뉴 사용 |

상단 액션바는 `신규`, `저장`, `삭제`만 남는다.

### 행 복사 규칙 (`duplicateSalesOrderDetailRow`)

- 새 `rowId` 발급, 원본 바로 아래 삽입(F1-Grid 기본 동작)
- 유지: 품목(ID/코드/명), 주문수량, 단가, 공급가, 부가세, 합계, 상세납기
- 초기화: `salesOrderDetailId` 제거, `shippedQty = 0`, `lineStatus = '대기'`

## 2. 수주현황 API

`GET /api/v1/sales/order-status` (`SalesOrderStatusApiController`, 태그 `SalesOrderStatusApiController`)

### 요청 파라미터 (`SalesOrderStatusSearchVO`, 모두 선택)

| 파라미터 | 설명 | 조건 |
|---|---|---|
| keyword | 빠른 검색 | 수주번호/거래처코드·명/품목코드·명/견적번호 부분일치(대소문자 무시) |
| orderNo | 수주번호 | 부분일치 |
| orderDtFrom / orderDtTo | 수주일자 범위 | `h.order_dt` 이상/이하 |
| customerKeyword | 거래처 | 거래처코드·명 부분일치 |
| quotNo | 견적번호 | 부분일치 |
| status | 수주상태 | 일치 |
| deliveryDtFrom / deliveryDtTo | 상세 납기일자 범위 | `COALESCE(d.delivery_dt, h.delivery_dt)` |
| materialKeyword | 품목 | 품목코드·명 부분일치 |
| lineStatus | 행상태 | 일치 |

- 테넌트는 인증 사용자 기준으로만 적용(요청 값 무시), `h.use_at = 'Y'`
- 날짜 문자열은 `CAST(? AS date)`로 비교, 빈 문자열은 서비스에서 null 처리
- 정렬: `h.order_dt DESC, h.order_no DESC, d.line_no`

### 응답

`result.resultList: SalesOrderStatusVO[]`, `result.resultCnt`

| 필드 | 원천 |
|---|---|
| salesOrderId, salesOrderDetailId | hd/dt PK |
| orderNo, orderDt, quotNo, status | hd |
| customerCode, customerName | tb_customer_info |
| headerDeliveryDt, deliveryPlace, deliveryMethod, remark | hd |
| lineNo, materialCode, materialName, unit | dt + tb_material_info |
| orderQty, unitPrice, supplyAmt, vatAmt, totalAmt | dt |
| deliveryDt, shippedQty, lineStatus | dt (`deliveryDt`는 상세 → 헤더 대체) |

## 3. 수주현황 화면

- 경로/키: `/sales/order/status`, `DashboardContent`에서 `sales` 모듈 `status` 키로 렌더
- 권한: `read` → 조회 버튼, `excel` → 그리드 엑셀 내보내기
- 상단: PageSearchArea(빠른 검색 + 상세검색), 상세검색 필드는 컬럼 `search` 옵션에서 생성
  - 수주일자 기본값: 시스템일자 기준 1개월 전 ~ 오늘
- 그리드: F1-Grid 읽기 전용, 행 추가/복사/삭제 메뉴 비활성, `selectRowOnContextMenu={false}`
- 컬럼(헤더 + 상세 결합)
  - 수주번호, 수주일자, 거래처코드, 거래처명, 견적번호, 수주상태, 납품장소, 배송방법
  - 행, 품목코드, 품목명, 단위, 주문수량, 단가, 공급가, 부가세, 합계, 납기일자, 출하수량, 행상태, 비고
- 로딩/오류: 조회 중 로딩, 실패 시 Alert 메시지, 결과 없음은 그리드 빈 상태

## 4. 검증 기준

- 수주등록: 상단에 상세 행 추가/선택 행 삭제 없음, 그리드 헤더 버튼으로 행 추가, 우클릭 `행 복사`로 동일 품목 행 추가
- 수주현황: 진입 시 기본 조건 조회, 상세검색 값이 API 파라미터로 전달, 결합 컬럼 표시
- 백엔드: 테넌트 범위, 파라미터 바인딩, OpenAPI 어노테이션/스키마 검증
