# 고정 병합 셀 클릭 상세 사양서

- 계획: [016](../../plan/20261027/20261027_016_f1grid-pinned-merge-click_계획서.md)

## 적용 조건

`pinOffset`이 있고 `mergeInfo.isStart === true`, `mergeInfo.span > 1`이며 사용자 정의 `renderCell`을 표시하는 비편집 셀에만 적용한다. 체크박스 타입은 기존 전용 렌더러를 유지한다.

## 이벤트 및 표시

- 고정 병합 시작 셀은 일반 고정 셀(z-index 2)보다 위(z-index 3)에 표시한다.
- 병합 셀 전체가 후속 행의 선택을 막지 않도록 컨테이너의 포인터를 통과시킨다.
- 첫 행 높이의 가상 요소는 시작 행의 빈 공간 클릭과 드래그 시작을 받는다.
- 사용자 정의 콘텐츠는 레이아웃 박스를 추가하지 않는 래퍼에서 포인터를 다시 받는다. 수주번호 링크의 기존 콜백과 이벤트 전파 정책은 유지한다.
- 후속 행의 빈 공간은 기존 투명 병합 셀이 받아 실제 상세 행을 선택한다.
- 왼쪽/오른쪽 고정, 고정 해제, 수평 스크롤, 행 강조 overlay, 컬럼 경계와 배경을 유지한다.
- 새로운 공개 옵션, 데이터 필드, API, DB 변경은 없다.

## 검증

Chromium에서 실제 수주현황 컬럼을 합성 데이터로 렌더링한다. 2행/3행 병합 링크 중앙 클릭이 정확히 한 번 해당 수주를 열어야 한다. 각 상세 행의 빈 공간 클릭은 해당 행만 선택해야 한다. 375/768/1280px에서 고정 방향별 스크롤 후 링크 클릭과 화면 바깥 가로 넘침을 확인한다. 기존 Vitest 병합/고정 열/행 선택/수주현황 회귀 테스트, 빌드와 lint도 수행한다.
