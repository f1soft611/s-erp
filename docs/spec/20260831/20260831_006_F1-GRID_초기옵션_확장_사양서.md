# 20260831_006 F1-GRID 초기 옵션 확장 사양서

## 1. 목적

공통 그리드 사용자가 런타임 메뉴 조작 없이 화면 진입 즉시 필요한 컬럼을 고정하고, 트리 그리드를 전체 펼침 상태로 시작할 수 있게 한다.

## 2. 컬럼 초기 고정

`F1GridColumn<T>`는 다음 옵션을 지원한다.

```ts
pinned?: 'left' | 'right';
```

- `pinned: 'left'`인 컬럼은 최초 렌더링 시 왼쪽 고정 그룹으로 이동한다.
- `pinned: 'right'`인 컬럼은 최초 렌더링 시 오른쪽 고정 그룹으로 이동한다.
- 고정 offset은 기존 컬럼 고정 로직과 동일하게 선택 checkbox 컬럼 너비를 포함해 계산한다.
- 최초 고정 후 사용자는 기존 컬럼 헤더 메뉴에서 왼쪽/오른쪽 고정 또는 고정 해제를 수행할 수 있다.
- `hidden: true` 컬럼은 기존 숨김 처리에 따라 최초 표시 대상에서 제외된다.

## 3. 트리 초기 전체 펼침

`F1Tree<T>`는 다음 옵션을 지원한다.

```tsx
defaultExpandAll?: boolean;
```

- `defaultExpandAll`이 `true`이면 최초 렌더링 시 자식이 있는 모든 부모 row id를 펼침 상태로 등록한다.
- `defaultExpandAll`은 기존 `defaultExpanded`보다 우선한다.
- 기존 `defaultExpanded="all"`, `defaultExpanded="root"`, `defaultExpanded={[id]}` 동작은 유지한다.
- 이후 사용자의 펼침/접힘 조작과 `expandAll`, `collapseAll` ref 명령은 기존과 동일하게 동작한다.

## 4. 사용 예시

```tsx
const columns: F1GridColumn<ItemRow>[] = [
  { field: 'itemCode', headerName: '품목코드', pinned: 'left' },
  { field: 'amount', headerName: '금액', pinned: 'right' },
];

<F1Tree
  rows={rows}
  columns={columns}
  rowKey="id"
  parentKey="parentId"
  treeColumn="name"
  defaultExpandAll
/>;
```

## 5. 제외 범위

- 사용자별 레이아웃 저장 API
- 컬럼 순서 drag and drop
- 트리 노드 lazy loading
- 펼침 상태 외부 제어 컴포넌트 전환
