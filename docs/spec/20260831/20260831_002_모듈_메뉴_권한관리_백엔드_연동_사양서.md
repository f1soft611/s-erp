## 2. 시드 데이터 (테넌트: T1358606250, 에프원소프트)

- 모듈: `GROUPWARE`(그룹웨어, 아이콘 Groups), `SETTINGS`(환경설정, 아이콘 Settings)
- 메뉴(GROUPWARE): `overview`(종합현황), `documents`(문서관리) — 모듈 직속 메뉴
- 메뉴(SETTINGS): `system`(시스템 관리, 상위 없음) → 하위 `roles`(권한관리), `menus`(메뉴관리), `f1-grid-test`(F1 Grid 테스트)
- 경로는 기존 `adminUserMenus.json`과 동일하게 유지: `/groupware/overview`, `/groupware/documents`, `/settings/system`, `/settings/system/roles`, `/settings/system/menus`, `/settings/system/f1-grid-test`

## 3. 백엔드 API

공통 응답: `ResultVO` (`resultCode`, `resultMessage`, `result`), 인증 필요(JWT), 관리(등록/수정/삭제) API는 `roleCode`가 `PLATFORM_ADMIN` 또는 `TENANT_ADMIN`이 아니면 `403 AUTH_ERROR` 반환.

### 3-1. 모듈 API — `egovframework.let.system.modules`

| Method | URL                         | 설명                              |
| ------ | --------------------------- | --------------------------------- |
| GET    | /api/v1/system/modules      | 모듈 목록 조회(테넌트 기준)       |
| POST   | /api/v1/system/modules      | 모듈 등록                         |
| PUT    | /api/v1/system/modules/{id} | 모듈 수정                         |
| DELETE | /api/v1/system/modules/{id} | 모듈 삭제(하위 메뉴 존재 시 거부) |

### 3-2. 메뉴 API — `egovframework.let.system.menus`

| Method | URL                       | 설명                                                                   |
| ------ | ------------------------- | ---------------------------------------------------------------------- |
| GET    | /api/v1/system/menus      | 메뉴 목록 조회(테넌트 기준, 평면 리스트)                               |
| POST   | /api/v1/system/menus      | 메뉴 등록                                                              |
| PUT    | /api/v1/system/menus/{id} | 메뉴 수정                                                              |
| DELETE | /api/v1/system/menus/{id} | 메뉴 삭제(하위 메뉴 존재 시 거부)                                      |
| GET    | /api/v1/menus/my          | 로그인 사용자 기준 모듈-메뉴 트리 + 권한(대시보드용, 관리자 제한 없음) |

`GET /api/v1/menus/my` 응답 `result` 형태:

```json
{
  "user": { "userId": "admin", "roles": ["PLATFORM_ADMIN"] },
  "menus": [
    {
      "menuId": 1,
      "parentMenuId": null,
      "name": "그룹웨어",
      "icon": "Groups",
      "path": "/groupware",
      "children": [
        {
          "menuId": 2,
          "parentMenuId": 1,
          "name": "종합현황",
          "path": "/groupware/overview",
          "permissions": {
            "read": true,
            "create": true,
            "update": true,
            "delete": true
          }
        }
      ]
    }
  ]
}
```

- 권한 규칙: `PLATFORM_ADMIN`/`TENANT_ADMIN` → 모든 리프 메뉴 `read/create/update/delete = true`, `TENANT_USER` → `read = true`, 나머지 `false`. 모듈/그룹 노드(자식이 있는 노드)는 permissions 없이 children만 내려준다(기존 계약과 동일).

### 3-3. 역할 API — `egovframework.let.system.roles`

| Method | URL                       | 설명                        |
| ------ | ------------------------- | --------------------------- |
| GET    | /api/v1/system/roles      | 역할 목록 조회(테넌트 기준) |
| POST   | /api/v1/system/roles      | 역할 등록                   |
| PUT    | /api/v1/system/roles/{id} | 역할 수정                   |

삭제 API는 이번 범위에서 제외한다.

## 4. VO 필드(요청/응답)

- `SystemModuleSaveRequestVO`: tenantCode, moduleCode, moduleNm, iconNm, moduleUrl, sortOrder, useAt
- `SystemModuleVO`(응답): moduleId, tenantId, moduleCode, moduleNm, iconNm, moduleUrl, sortOrder, useAt, createdAt, updatedAt
- `SystemMenuSaveRequestVO`: tenantCode, moduleId(또는 moduleCode), parentMenuId, menuCode, menuNm, menuUrl, iconNm, sortOrder, useAt
- `SystemMenuVO`(응답): menuId, tenantId, moduleId, parentMenuId, menuCode, menuNm, menuUrl, iconNm, sortOrder, useAt, hasChildren, createdAt, updatedAt
- `SystemRoleSaveRequestVO`: tenantCode, roleCode, roleNm, roleDc, useAt
- `SystemRoleVO`(응답): roleId, tenantId, roleCode, roleNm, roleDc, useAt, isSystemRole, createdAt, updatedAt (`PLATFORM_ADMIN`은 비활성화 불가 정책 유지)

## 5. 프론트엔드 연동

- `frontend/src/shared/services/apiClient.ts` 신설: `getStoredAuth()`의 accessToken을 `Authorization: Bearer` 헤더로 부착하는 공통 `apiGet/apiPost/apiPut` 헬퍼
- `dashboard/services/menuService.ts`: 로컬 JSON import 제거, 앱 시작 시 `/api/v1/menus/my` 호출 결과로 `moduleDescriptors` 구성(비동기 로딩 상태는 최소 처리)
- `settings/system/menus/services/menuManagement.service.ts`: `/api/v1/system/menus` 연동, `MenuManagementRow`는 API 응답 필드로 매핑
- `settings/system/roles/services/roleManagement.service.ts`: `/api/v1/system/roles` 연동, `RoleManagementRow`는 API 응답 필드로 매핑(권한 상세 편집 UI는 이번 범위에서 read-only 표시 유지, 저장 대상은 역할 기본 정보만)
