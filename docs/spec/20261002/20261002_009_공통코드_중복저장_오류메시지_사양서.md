## 2. 오류 응답 계약

공통코드 저장에서 서비스가 `IllegalArgumentException`으로 검증 오류를 반환하면 API는 다음을 유지한다.

- HTTP 상태: `400 Bad Request`
- `resultCode`: `ResponseCode.INPUT_CHECK_ERROR`의 기존 값
- `result.message`: 상세 검증 메시지
- `resultMessage`: 동일한 상세 검증 메시지

중복 메시지는 기존 서비스 문구를 그대로 사용한다.

- 그룹 코드: `이미 사용 중인 그룹 코드입니다.`
- 상세 코드: `이미 사용 중인 상세 코드입니다.`

## 3. 검증 기준

컨트롤러 테스트에서 상세코드 중복 예외를 모의하여 HTTP 400, 기존 입력 오류 코드, 최상위 `resultMessage`, `result.message`를 확인한다. UI와 DB 스키마/API 경로는 변경하지 않는다.
