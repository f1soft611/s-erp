# 20261002_005 기안양식 분류 안내 초기 노출 보완 사양서

## 대상 흐름

기안양식관리 페이지 진입 시 분류 옵션을 비동기로 조회하고, 결과에 따라 분류 미설정 안내를 표시하는 흐름.

## 표시 규칙

- `optionsLoading`이 참인 동안 기존 분류 미설정 안내를 표시하지 않는다.
- 옵션 조회 완료 후 분류 항목이 없고 안내를 닫지 않은 경우에만 기존 안내를 표시한다.
- 옵션이 하나 이상 있거나 사용자가 안내를 닫은 경우 안내를 표시하지 않는다.
- 옵션 오류 및 기타 페이지 오류 처리 방식은 변경하지 않는다.

## 검증

- 옵션 조회가 보류 중일 때 안내가 표시되지 않는다.
- 빈 분류 목록으로 조회가 끝난 뒤 기존 안내가 표시된다.
