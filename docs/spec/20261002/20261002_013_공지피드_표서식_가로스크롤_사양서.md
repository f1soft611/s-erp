## 처리 계약

1. 공통 `sanitizeHtml(value)` 기본 동작은 현재와 동일하게 유지한다.
2. 공지 전용 호출은 opt-in 옵션으로 `span`과 다음 inline style만 보존한다: `font-family`, `font-size`, `font-style`, `font-weight`, `color`, `line-height`, `text-decoration`.
3. 모든 모드에서 script/style/iframe 등 실행 가능 태그, event handler, 위험 URL 및 unsafe CSS 값은 제거한다.
4. 공지 저장 시 `sanitizeNoticeBodyHtml`을 사용해 허용된 서식을 기존 HTML 본문 값에 남긴다. 저장 HTML에 layout wrapper를 추가하지 않는다.
5. 피드 표시용 `prepareNoticeFeedHtml`은 sanitized HTML의 wrapper 없는 각 표를 `<div class="tableWrapper">`로 감싼다. 이미 wrapper 안에 든 표에는 중복 wrapper를 추가하지 않는다.
6. feed preview는 기존 `noticeContentStyles`를 재사용한다. `.tableWrapper`는 `width/max-width:100%`, `overflow-x:auto`를 유지하고 표 외부의 feed/card에는 가로 overflow를 추가하지 않는다.
7. 접힘/펼침 모두 같은 feed HTML 변환을 사용한다. 기존 미리보기 높이, 마스크, 이미지 동작, 클릭 동작을 변경하지 않는다.
8. API field, notice JSON payload contract, DB schema, attachments 및 comment sanitizer는 변경하지 않는다.

## 테스트 및 완료 검증

- shared sanitizer: 기본 호출은 기존 출력 유지, opt-in 텍스트 서식은 보존, unsafe style/tag는 제거.
- notice HTML utility: 서식 allowlist, 저장 결과의 wrapper 부재, 피드 wrapper 생성/중복 방지.
- feed DOM: 접힘/펼침 모두 font-family/font-size inline style 및 `.tableWrapper` 보존.
- 브라우저: 1280px/375px에서 feed/card 폭은 유지되고 긴 표 wrapper의 scrollWidth가 clientWidth를 초과하며 수평 스크롤 가능.
- focused notice tests 및 `npm --prefix frontend run build` 통과.
- 결과 문서와 캡처 경로: `docs/result/20261002/notice-feed-table-rendering/`.
