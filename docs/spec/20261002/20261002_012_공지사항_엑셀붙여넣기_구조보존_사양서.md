## 입력 처리 계약

1. HTML에 표가 있으면 HTML 표를 우선 정규화해 Tiptap에 전달한다.
2. 표 HTML은 table → 직접 소속 row → 직접 소속 cell 계층을 유지한다. 중첩 표의 row/cell은 바깥 표 행·열로 중복 계산하지 않는다.
3. `td`/`th` 순서, 빈 셀, 셀 없는 빈 행, 유효한 양의 `rowspan`/`colspan`, 셀의 `width`/`height`와 행 높이를 보존한다. 셀 없는 행은 `<tr></tr>`로 유지하고 placeholder 셀을 추가하지 않는다. 빈 행 삭제는 후속 행을 옆으로 밀고, placeholder 셀은 기존 rowspan 아래에 불필요한 끝 열을 만들 수 있다.
4. 원본 `<colgroup>`의 px/pt/pc/in/cm/mm 절대 너비를 px 정수로 정규화해 각 셀 `colwidth`에 기록한다. 병합 셀에는 병합한 각 열의 너비 배열을 제공하고, 세로 병합 중인 앞 열은 다음 행의 열 인덱스 계산에서 건너뛴다. 원본 열 너비가 유효하면 셀 전체 `width` 값은 중복 적용하지 않는다.
5. 셀 콘텐츠의 텍스트 순서를 보존한다. `<br>` 및 paragraph/block 경계는 줄바꿈 경계로 유지하며 셀 전체 텍스트를 공백으로 평탄화하지 않는다.
6. 허용 CSS 스타일(`width`, `height`, `font-family`, `font-size`, `font-weight`, `font-style`, `color`, 배경, 테두리, 정렬, `line-height`)만 셀/인라인 텍스트에 제한적으로 보존한다. `strong`, `em`, `s` 등 에디터가 지원하는 의미 구조도 유지한다. 임의 class, 원본 stylesheet, 실행 가능한 HTML/속성은 제거한다.
7. HTML에 표가 없거나 쓸 수 있는 표 구조가 없으면 기존 `text/plain` 줄바꿈/탭 정규화를 사용한다.
8. 표 데이터와 이미지 파일이 함께 있으면 기존 정책대로 표 HTML 붙여넣기를 우선한다. 표가 아닌 이미지 클립보드는 기존 업로드 경로를 유지한다.

## 표시 계약

- 표는 shared `richTextContentStyles`의 `max-content` 레이아웃을 사용한다. 공지 feed와 그룹웨어 문서작성에서도 동일한 본문 표시 style을 소비한다.
- Tiptap `cellMinWidth`는 16px로 둔다. 유효한 Excel colgroup 폭이 있으면 각 열에 명시 `width`를 적용하고, 없으면 안전하게 최소 너비 fallback을 사용한다.
- 표가 편집기 가용 폭보다 넓으면 편집기 내부 가로 스크롤을 사용한다.
- 이번 변경은 모달 폭/높이, 편집 영역 overflow 정책, 툴바 또는 저장 계약을 바꾸지 않는다.

## 보안 및 호환성

- `script`, `style`, `iframe`, `svg`, `object`, `embed`, 폼 및 비허용 속성은 기존 정책대로 제거한다.
- 인라인 폰트 크기/가족/색상은 Tiptap 공식 `TextStyle`, `FontFamily`, `FontSize`, `Color` 확장으로 파싱/직렬화한다. CSS 값은 allowlist와 안전성 검사를 통과해야 한다.
- 셀 안에서 허용된 줄바꿈 외 외부 포맷/스타일은 유지하지 않는다.
- notice 저장 payload, 이미지 API, 일반 텍스트 편집 및 첨부 파일 동작은 변경하지 않는다.

## 테스트 및 완료 검증

1. Utility 테스트: 여러 행/열, 빈 셀, `rowspan`, `colspan`, colgroup px/pt 폭, `<br>`, 문단 경계, 셀 width/height, font-size/family/color, 하위 표 경계, unsafe markup 제거.
2. Modal 테스트: 실제 paste 이벤트로 복합 HTML table을 전달하고 셀 위치, 줄바꿈, inline font styles, 병합 셀 colwidth 배열, 생성된 col/table width와 rowspan 아래 푸터의 여분 셀 부재를 확인.
3. 회귀 테스트: 일반 텍스트 및 이미지 clipboard 처리, 기존 허용 스타일 테스트.
4. 빌드: `npm --prefix frontend run build`.
5. 브라우저: 공유된 `http://127.0.0.1:4173/groupware/community/notice` 페이지의 공지 작성 모달에서 복합 표를 실제 붙여넣고 행 수/셀 위치/줄바꿈/내부 가로 스크롤 확인.
6. 결과 문서 및 화면 캡처를 `docs/result/20261002/notice-excel-paste-structure/` 아래에 저장한다.
