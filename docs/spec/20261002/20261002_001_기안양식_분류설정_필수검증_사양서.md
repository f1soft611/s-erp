# 20261002_001 기안양식 분류 설정 필수 검증 사양서

## 대상 흐름

기안양식관리 페이지의 `분류 설정` 버튼으로 연 `CommonCodeItemHelpDialog`에서 신규 또는 수정된 분류를 저장하는 흐름.

## 저장 전 검증

- 기존 F1-Grid 컬럼 정의의 `required: true`를 그대로 사용한다. 필수 컬럼은 상세코드(`itemCode`)와 상세코드명(`itemNm`)이다.
- 저장 버튼을 누르면 모달의 `F1GridRef.validate()`를 먼저 실행한다.
- 검증 실패 시 F1-Grid 셀 오류를 표시하고 `필수 입력 항목을 확인해 주세요.` 안내를 모달 안에 표시한다.
- 검증 실패 시 create/update API, 목록 재조회, 성공 알림을 실행하지 않는다.

## 오류 표시 범위

- API 저장 실패 메시지는 모달의 기존 오류 영역에 표시한다.
- 모달 저장 실패를 페이지의 `PageMessageArea`로 전달하지 않는다.
- 성공 토스트, 저장 진행 표시, 저장 후 목록 재조회는 기존 동작을 유지한다.

## 비범위

필수 컬럼 정의, 서버 입력 검증/API 계약, F1-Grid 공통 검증 구현, 메인 양식 그리드 저장 동작은 변경하지 않는다.

## 회귀 검증

- 빈 신규 행 저장 시 API 요청 없이 모달 필수 안내가 보인다.
- 서버 저장 실패 시 오류는 모달 안에만 보이고 부모 오류 콜백은 호출되지 않는다.
- 유효한 신규/수정 저장은 기존대로 성공하고 재조회된다.
