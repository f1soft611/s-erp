# 20261002_014 공지 작성 저장 진행 표시 상세 사양서

## 대상

공지 작성/수정 모달의 하단 저장/취소 액션과 `onSubmit` 비동기 흐름.

## 처리 계약

- 필수 구분 검증이 통과한 다음에만 `saving=true`로 전환한다.
- `saving=true` 동안 중복 `handleSubmit`은 즉시 무시한다.
- 저장 버튼은 `CircularProgress` 16px과 `저장 중…` 문구를 표시하고 disabled가 된다.
- 저장 요청이 종료되면 버튼 문구는 `저장`으로 복구된다.
- 취소 버튼 및 다이얼로그 닫기 요청도 저장 완료 전까지 비활성 또는 무시한다.
- 성공 시 현재 동작대로 모달을 닫는다. 실패 시 기존처럼 모달을 유지하고 `saving=false`로 복구한다.
- `onSubmit`이 없는 사용 흐름에서는 비동기 저장 표시 상태를 만들지 않고 기존 닫기 동작을 유지한다.
- 저장 payload와 API 요청/응답 계약은 변경하지 않는다.

## 테스트

- Deferred promise 중 spinner와 `저장 중…` 문구가 표시되고 저장 버튼이 disabled인지 확인한다.
- 요청 대기 중 저장 버튼 재클릭을 포함해 `onSubmit` 호출이 1회인지 확인한다.
- resolve 시 모달 닫힘, reject 시 모달 유지 및 spinner 제거/`저장` 문구/버튼 활성 복구를 확인한다.
- 구분 필수 검증 실패에는 submit 및 spinner가 없는지 기존 테스트로 확인한다.
