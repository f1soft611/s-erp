# 20261002_006 분류 설정 모달 공통 셸 적용 상세 사양서

## 1. 대상

- 기안양식관리의 분류 설정 모달: `frontend/src/shared/components/common-code/CommonCodeItemHelpDialog.tsx`
- 공통 셸: `frontend/src/shared/components/CommonDialog.tsx`
- F1-Grid 행 폼 divider 회귀: `frontend/src/shared/components/f1-grid/form/F1GridFormModal.tsx`

## 2. 공통 셸 적용

- 분류 설정 모달은 제목 `기안양식 분류 설정`, 닫기 callback `requestClose`, `size="lg"`, `bodyMode="fill"`, `paperHeight="60vh"`, `fullScreenOnMobile`을 사용한다.
- 공통 Dialog의 header/description/footer 구조를 사용한다. 모달에 description이 없으면 설명 영역은 표시하지 않는다.
- `paperHeight`는 optional `CSSProperties['height']`다. `bodyMode="fill"`의 기본 높이는 기존 90vh를 유지하며, 명시 시 일반 paper의 높이만 지정값으로 대체한다. full-screen paper에서는 full-screen 레이아웃이 우선한다.
- 분류용 F1Grid의 `Stack`, add button, grid, alert는 CommonDialog children에 그대로 둔다.
- 저장/취소 버튼은 `actions` slot으로 이동한다. 저장 spinner/disabled, read-only 사용자의 저장 버튼 숨김, 취소 중 `requestClose`, close confirm 동작은 유지한다.

## 3. Divider 규칙

- Header 하단에는 CommonDialog가 색상 prop 없이 MUI 기본 `Divider`를 하나 렌더링한다.
- DialogContent에는 `dividers` 속성을 설정하지 않는다. 본문 하단에 추가 선을 그리지 않는다.
- `DialogActions`는 CommonDialog footer 하나만 사용한다. footer 앞의 기본 `Divider`가 경계선을 표시하며 `DialogActions`에는 border를 직접 지정하지 않는다.
- F1-Grid 행 폼과 분류 설정은 같은 기본 `Divider` 스타일을 사용하고 호출부에서 색상/두께를 덮어쓰지 않는다.

## 4. 동작 보존

- 분류 항목 추가, 인라인 편집, duplicate, 유효성 검사, 저장 API 호출, 성공 notification, error 표시는 변경하지 않는다.
- 변경사항이 있을 때 취소/닫기를 누르면 기존 `UnsavedChangesConfirmDialog`를 보여준다.
- 확인 대화상자 자체는 공통 셸로 이전하지 않는다.
- API 계약, DB 구조와 권한 조건은 변경하지 않는다.
