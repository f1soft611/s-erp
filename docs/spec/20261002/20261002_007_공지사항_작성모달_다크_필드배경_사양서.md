# 20261002_007 공지사항 작성 모달 다크 필드 배경 상세 사양서

## 1. 대상

- 화면: `/groupware/community/notice`
- 컴포넌트: `frontend/src/pages/groupware/community/notice/components/NoticeComposerDialog.tsx`
- 대상 입력: `구분`, `제목`
- 적용 상태: 다크 및 라이트 테마

## 2. 색상 계약

| 영역        | 다크 테마      | 라이트 테마    |
| ----------- | -------------- | -------------- |
| 구분 입력면 | `#1e293b`      | 기존 `#ffffff` |
| 제목 입력면 | `#1e293b`      | 기존 `#ffffff` |
| 본문 편집면 | 기존 `#0f172a` | 기존 `#ffffff` |

- 필드용 색상은 컴포넌트 내부 토큰으로 분리해 구분·제목 `TextField`에만 사용한다.
- 두 필드의 `OutlinedInput` 및 `InputBase` 배경이 동일한 계약을 따른다.
- 입력 테두리, 모서리, 라벨, 글자, placeholder, 높이와 간격은 변경하지 않는다.

## 3. 동작 및 API

- 입력, 선택, 검증, 저장 payload, API 및 권한 동작은 변경하지 않는다.
- 첨부 목록, 툴바, 본문 편집기, 모달 셸 스타일은 변경하지 않는다.
- 다크·라이트 테마 판정은 기존 `resolvedDark` 값을 따른다.

## 4. 검증 기준

1. 다크 테마에서 구분과 제목 입력 루트의 계산 배경색은 `rgb(30, 41, 59)`다.
2. 라이트 테마에서 구분과 제목 입력 루트의 계산 배경색은 `rgb(255, 255, 255)`다.
3. 기존 공지 작성 모달 테마 테스트와 프론트엔드 빌드가 통과한다.
4. 다크 모드 375px, 768px, 1280px 브라우저 캡처에서 필드 배경 외 레이아웃 회귀가 없다.

## 5. 제외 범위

- 공통 모달 셸, 본문 편집기, 첨부 및 툴바 배경 수정
- API, 저장 데이터, 입력 동작 및 접근성 라벨 변경
