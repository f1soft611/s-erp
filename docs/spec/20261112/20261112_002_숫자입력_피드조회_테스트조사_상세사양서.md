# 숫자 입력·피드 조회·테스트 지연 상세 사양

## 숫자 입력

- `decimalPlaces: 0`에서 첫 소수점과 그 뒤를 버린다. `12.34 → 12`, `-12.34 → -12`, `1,234.56 → 1234`.
- 빈 입력과 부호 입력, 소수점이 없는 정수 정규화는 기존 동작을 유지한다.
- 키보드 연속 입력 중에는 원문을 임시 표시하되 저장값은 정규화한다. 포커스를 잃거나 셀 편집을 확정하면 정수값을 표시한다. 외부 값이 바뀌면 이전 입력 원문을 표시하지 않는다.
- 양수 소수 자릿수와 옵션 미지정 시 동작은 변경하지 않는다. 그리드 셀과 행 폼이 동일한 정규화 함수를 사용한다.

## 문서 목록 조회 실패

- 필터, 보기, 범위 등 조건 변경을 포함한 일반 조회가 실패하면 이전 조건의 목록·피드·고정 문서를 비우고 오류를 표시한다.
- 같은 조건의 조용한 재조회가 실패하면 기존 결과를 유지하되 오류를 표시한다. 최초 로드 실패는 기존 공통 오류 경계를 유지한다.
- 성공한 조회만 결과를 교체하며 오래된 요청의 결과는 적용하지 않는다.

## 테스트 지연 조사

- 테스트 대상 파일의 단독 실행과 선택된 테스트의 실행 시간을 비교하고, 타임아웃과 일회성 목 응답이 다음 테스트에 남는지를 점검한다.
- 타임아웃 상향으로 문제를 숨기지 않는다. 실행 환경의 부하로 원인을 확정할 수 없으면 근거와 미확인 사항을 기록한다.
