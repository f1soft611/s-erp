# F1-Grid 집계 상세사양

계획: [20261112_004](../../plan/20261112/20261112_004_f1-grid-summary_계획서.md)

## 공통 기능

- `features`에 `{ ftype: 'summary', dock: 'top' | 'bottom' }`을 지정한다. 미지정 시 기존 화면은 변하지 않는다.
- 컬럼 `summaryType`은 `sum`, `average`, `min`, `max`를 지원한다. 지정하지 않은 컬럼은 빈 셀로 둔다.
- 숫자 또는 공백이 아닌 숫자 문자열 중 유한한 값만 집계한다. 유효한 값이 없으면 빈 셀이다.
- 삭제된 행을 제외한 현재 필터 결과 전체를 집계한다. 가상화된 렌더 행에 한정하지 않는다. 서버 데이터 소스는 현재 로드된 행만 집계한다.
- 집계는 편집 확정, 추가, 삭제, 필터 변경에 따라 갱신된다. 컬럼 표시 형식과 정렬을 따른다.
- 행은 읽기 전용이며 열 크기, 순서, 고정 위치, 가로 스크롤 및 모바일 행 폼 열과 정렬된다.

## 수주등록

- 기존 수주 상세 그리드를 기준으로 참조 소스의 상단 집계 방식을 적용한다.
- 주문수량, 공급가, 부가세, 라인합계에 합계를 표시한다. 단가와 출하수량은 참조 수주 상세 합계 대상이 아니므로 제외한다.
- 수주현황 상세가 같은 컴포넌트를 공유하므로 보기·수정 모드도 동일하게 적용된다.

## 검증

- 상단/하단 위치와 네 집계 방식, 빈 값, 필터·편집·삭제 갱신 및 컬럼 고정을 테스트한다.
- 수주 상세 합계와 기존 수주 등록 동작, 빌드, lint를 검증하고 375/768/1280px 브라우저 화면을 확인한다.
