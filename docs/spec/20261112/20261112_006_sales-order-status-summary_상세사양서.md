# 수주현황 집계 적용 상세사양

계획: [20261112_006](../../plan/20261112/20261112_006_sales-order-status-summary_계획서.md)

- 수주현황 목록의 기존 `dock: 'bottom'` 집계 행에 주문수량(`orderQty`), 공급가(`supplyAmt`), 부가세(`vatAmt`), 합계(`totalAmt`)의 합을 표시한다.
- 단가와 출하수량 등 다른 컬럼은 집계하지 않는다.
- F1-Grid의 기존 필터·숫자 형식·가로 스크롤 동작을 유지한다.
- 집계 설정이 있는 그리드의 엑셀에 동일한 필터 결과와 표시 컬럼 기준의 집계 행을 추가한다. `top`은 헤더 바로 아래, `bottom`은 데이터 아래다.
- 합계·평균·최솟값·최댓값은 화면과 같은 계산을 사용하고, 숫자 셀과 컬럼의 숫자 서식으로 저장한다. 유효한 값이 없거나 집계가 없는 컬럼은 빈 셀이다.
- 집계 기능이 없으면 기존 엑셀 내보내기를 유지한다. 엑셀은 현재 계산값이며 수식이 아니다.
- 다중 행의 네 집계 값과 단가의 빈 집계, 화면 크기별 표시 및 엑셀 파일 값을 확인한다.
