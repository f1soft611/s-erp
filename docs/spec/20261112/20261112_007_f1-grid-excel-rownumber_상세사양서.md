# F1-Grid 엑셀 행번호 상세사양

계획: [20261112_007](../../plan/20261112/20261112_007_f1-grid-excel-rownumber_계획서.md)

- `rownumber` 데이터 셀은 필터와 정렬이 반영된 내보내기 행 순서로 1부터 기록한다. 원본 필드와 `getValue`의 결과는 사용하지 않는다.
- 행번호는 정수 숫자 셀과 기존 서식 `0`, 기존 컬럼 정렬을 사용한다. 상단·하단 집계 행은 데이터 행 번호에 포함하지 않는다.
- 원본 데이터, 다른 컬럼과 숨김 컬럼 동작은 변경하지 않는다. 서버 데이터는 기존 내보내기와 같이 현재 로드 행을 기준으로 한다.
- 이전 엑셀 사양의 `rownumber` 원시값 출력 규칙을 이 사양으로 대체한다.
- ExcelJS 재로드 테스트와 실제 브라우저 필터 후 다운로드에서 화면 순번과 파일 값을 비교한다.
