# F1-Grid 집계 컬럼 경계선 정렬 상세사양

계획: [20261112_005](../../plan/20261112/20261112_005_f1-grid-summary-lines_계획서.md)

- 집계 행의 데이터 열 경계는 본문과 동일하게 `columnLine`이 켜진 경우 첫 데이터 열을 제외하고 각 열의 왼쪽에 표시한다.
- `columnLine`이 꺼진 경우 본문의 데이터 열처럼 집계 데이터 셀에는 세로 경계를 표시하지 않는다.
- 행 선택 열과 모바일 행 폼 열의 위치는 기존 그리드 열 트랙을 유지한다.
- 상단·하단 위치, 가로 스크롤, 열 고정 및 열 너비 변경과 관계없이 집계 셀의 경계 위치는 같은 컬럼의 헤더·본문과 일치한다.
- 집계 값과 기타 동작은 변경하지 않는다.

## 검증

- 세로선의 방향·위치와 `columnLine` 비활성화를 테스트한다.
- 수주등록의 각 집계 셀 경계를 실제 브라우저에서 헤더·본문과 비교하고 375/768/1280px 스크린샷을 기록한다.
