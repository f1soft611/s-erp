# 20260828_001 F1-GRID 소스 분리 사양

## 1. 공개 경로와 호환성

기존 `shared/components/f1-grid/F1Grid` import는 계속 동작해야 한다. 실제 구현은 `core/ERPGrid.tsx`에 두고 `F1Grid`는 동일 컴포넌트를 재-export한다. 신규 소비자는 `core/ERPGrid`를 사용할 수 있다.

## 2. 모듈 책임

```text
shared/components/f1-grid/
  core/ERPGrid.tsx       조합, 상태 orchestration, imperative ref
  core/GridHeader.tsx    헤더와 전체 선택
  core/GridBody.tsx      visible rows 렌더링
  core/GridRow.tsx       행 렌더링
  core/GridCell.tsx      셀, 편집기, merge 표시
  core/GridFooter.tsx    선택/변경 요약 슬롯
  editing/               editor dispatcher와 타입별 editor
  selection/             단일/Ctrl/Shift/전체 선택 순수 로직
  keyboard/              셀 좌표와 다음 편집 셀 계산
  types/                 공개 타입
  utils/                 표시값, editable, row key, merge 계산
```

행 상태 순수 함수는 기존 `f1Grid.state.ts`를 유지하되 중복 ID와 외부 rows 재기반화 계약을 추가한다.

## 3. 키보드와 포커스

- Arrow 키는 활성 셀 좌표와 DOM focus를 함께 이동한다.
- Enter/Shift+Enter는 같은 열에서 다음/이전 visible row로 이동한다.
- Tab/Shift+Tab은 현재 행에서 다음 편집 가능 셀을 찾고, 경계를 넘으면 다음/이전 visible row의 편집 가능 셀로 이동한다.
- 편집 가능 셀이 없으면 포커스 이동을 수행하지 않는다.
- Escape는 draft를 취소하고 현재 셀 포커스를 유지한다.

## 4. 상태와 외부 rows

- 최초 rows는 normal baseline으로 초기화한다.
- 외부 rows가 변경되고 내부 변경분이 없으면 내부 data를 새 rows로 재기반화한다.
- 내부 변경분이 있으면 외부 rows를 자동으로 덮어쓰지 않는다. 저장/충돌 UI는 후속 dirty 작업에서 제공한다.
- 신규/복제 ID가 기존 ID와 충돌하면 상태와 rows를 변경하지 않는다.
