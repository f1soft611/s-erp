## 1. 레이아웃 사양

### 1.1 대시보드 콘텐츠 영역

`DashboardSidebar` 다음의 `DashboardPage` 콘텐츠 flex item은 다음 속성을 가진다.

```tsx
<Box sx={{ flex: 1, minWidth: 0, display: 'flex', flexDirection: 'column' }}>
```

`minWidth: 0`은 flex item의 자동 최소 크기를 해제한다. 따라서 내부의 max-content 기반 그리드가 넓어도 콘텐츠 영역은 남은 가용 폭으로 축소된다.

앱 바의 제목 및 제어 영역은 좁은 중앙 콘텐츠 폭에서 줄바꿈할 수 있어야 한다. 900px 미만 구간에서는 좌우 패딩과 테마/화면 크기 선택 컨트롤의 최소 폭을 줄여 문서 전체 폭을 확장하지 않는다.

### 1.2 F1-GRID 스크롤 소유

`F1Grid`의 `role="grid"` 루트는 다음 제약을 가진다.

```tsx
sx={{
  width: '100%',
  minWidth: 0,
  maxWidth: '100%',
  overflowX: 'auto',
}}
```

- 그리드 루트의 폭은 부모 콘텐츠 폭을 넘지 않는다.
- `GridHeader` 및 `GridBody`의 `minWidth: 'max-content'`는 유지한다.
- 컬럼 합계 폭이 그리드 루트의 폭을 초과하면 그리드 루트에서만 가로 스크롤 바를 제공한다.

## 2. 검증 사양

1. F1Grid 렌더링 테스트는 grid 루트의 `min-width: 0`, `max-width: 100%`, `overflow-x: auto`를 검증한다.
2. Playwright 좁은 뷰포트 검증은 768px 뷰포트에서 `document.documentElement.scrollWidth <= window.innerWidth`를 확인한다.
3. Playwright 좁은 뷰포트 검증은 F1-GRID의 `scrollWidth > clientWidth` 및 계산된 `overflow-x: auto`를 확인한다.
4. F1-GRID 기존 동작 테스트와 프런트엔드 빌드를 함께 실행한다.
