# F1-GRID 행 높이 조절 사양

## 공개 옵션

- `rowHeight`: 기본 높이, 기본값 40px
- `minRowHeight`: 최소 높이, 기본값 40px
- `maxRowHeight`: 최대 높이, 기본값 300px
- `resizableRows`: resize 핸들 활성화, 기본값 true
- 컬럼 `wrapText`: 행 높이가 기본값보다 클 때 줄바꿈 허용

## 동작

기본 셀은 한 줄 말줄임과 전체값 `title`을 제공한다. 행 하단 핸들을 드래그하거나 ArrowUp/ArrowDown으로 4px씩 조절한다. 모든 값은 최소/최대 범위로 보정하며 높이는 행 ID별로 독립 관리되고 저장하지 않는다.

## 완료 기준

행별 높이 격리, 포인터/키보드 조절, 경계값 보정, 말줄임/줄바꿈 정책과 기존 F1-GRID 회귀 테스트가 검증되어야 한다.
