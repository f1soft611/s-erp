# 20260828_003 F1-GRID 클립보드, 검증 및 에디터 확장 사양

## 1. 목적

`F1Grid`에 ERP 입력 업무용 Excel TSV 클립보드 연동, 컬럼 기반 셀 검증, 확장 에디터와 보강 키보드 조작을 추가한다. 시스템 관리 하위의 전용 테스트 메뉴에서 모든 기능을 직접 조작하고 변경 행 상태를 확인할 수 있어야 한다.

## 2. 범위

### 포함

- 선택 시작 셀 또는 선택 행을 TSV 텍스트로 복사하는 `Ctrl+C`
- TSV 클립보드 데이터를 활성 셀 기준으로 붙여넣고, 범위를 벗어나는 행은 신규 행으로 추가하는 `Ctrl+V`
- 붙여넣기와 일반 수정에서 `updated` 및 `inserted` 상태를 기존 `GridState` 규칙에 따라 반영
- 컬럼 `required`, `min`, `max`, `validate(value, row)` 검증 및 셀별 오류 메시지 표시
- `F1GridRef.validate(): boolean` 공개 API
- `autocomplete`, `code`, `currency`, `decimal`, `datetime`, `time` 에디터 타입
- 코드 선택 결과의 `Partial<T>` 행 패치 반영. 데모 품목 선택 결과는 `itemCode`와 `itemName`을 함께 반영
- Insert, Delete/Backspace, Ctrl+D, Home, End 키보드 동작 보강
- 시스템 관리 하위 F1 Grid 테스트 메뉴와 상호작용 가능한 샘플 데이터

### 제외

- 브라우저가 제공하지 않는 클립보드 권한 우회
- 실제 품목 마스터 API 또는 공통 코드 팝업 API 연동
- Excel 파일 생성/다운로드, 정렬, 필터, 저장 API, 서버사이드 조회

## 3. 공개 계약

```ts
type F1GridEditorType =
  | 'text'
  | 'number'
  | 'decimal'
  | 'currency'
  | 'date'
  | 'datetime'
  | 'time'
  | 'checkbox'
  | 'select'
  | 'autocomplete'
  | 'code';

type F1GridColumn<T extends object> = {
  required?: boolean;
  min?: number;
  max?: number;
  validate?: (value: T[keyof T], row: T) => string | boolean;
  options?: F1GridOption[];
  onOpenCodePicker?: (row: T) => Partial<T> | undefined;
};

type F1GridRef<T extends object> = {
  validate(): boolean;
  // Existing commands remain unchanged.
};
```

`onOpenCodePicker`는 Grid가 API 또는 페이지 팝업 구현에 의존하지 않도록 소비자 레이어에서 제공한다. 반환된 패치는 현재 행에 한 번에 병합하며, 변경된 기존 행은 `updated`, 신규 행은 `inserted` 상태를 유지한다.

## 4. 클립보드 동작

- `Ctrl+C`는 선택한 행이 있으면 선택 행 전체의 표시 순서 컬럼값을 탭으로 구분하고 줄바꿈으로 결합한다. 선택 행이 없으면 현재 포커스 셀 한 개를 복사한다.
- `Ctrl+V`는 `ClipboardEvent.clipboardData`의 `text/plain`을 읽고, 줄바꿈과 탭으로 2차원 표로 파싱한다.
- 붙여넣기는 현재 포커스 셀을 좌상단으로 하며, 편집 가능 컬럼에만 값을 반영한다. 읽기 전용 열과 체크박스가 아닌 변환 불가 값은 건너뛴다.
- 데이터 행 수가 표시 행의 끝을 넘으면 `createRow`로 행을 만들고, 생성할 수 없는 경우 그 범위를 무시한다.
- 일반 숫자, decimal, currency는 숫자값으로 정규화한다. checkbox는 `true`, `1`, `Y`를 참으로, 그 외 값을 거짓으로 정규화한다.

## 5. 검증과 오류 표시

- `required`는 `null`, `undefined`, 빈 문자열, 공백 문자열을 오류로 처리한다.
- `min`과 `max`는 숫자 변환 가능한 값에 적용한다.
- `validate`가 문자열을 반환하면 그 문자열을 오류 메시지로 사용하고, `false`면 기본 오류 메시지를 사용한다.
- 셀 값 수정 또는 붙여넣기 후 해당 셀 오류를 즉시 갱신한다.
- `validate()`는 삭제 행을 제외한 모든 행과 컬럼을 검사하고, 오류가 하나라도 있으면 `false`를 반환한다.
- 오류 셀은 테마의 error 색상 테두리/배경으로 구분하고, 마우스 호버 시 오류 메시지 툴팁을 표시한다.

## 6. 에디터와 키보드

- `autocomplete`은 `options`를 입력값으로 필터링하고 선택값을 저장한다.
- `code`는 코드 선택 콜백을 실행하고 반환한 행 패치를 반영한다.
- `currency`와 `decimal`은 숫자 입력을 사용하며, 비편집 상태는 각각 통화 및 소수 표시 형식을 적용한다.
- `datetime`과 `time`은 각각 `datetime-local`, `time` 입력을 사용한다.
- `Insert`는 `createRow`가 제공된 경우 신규 행을 추가한다.
- 선택 행이 있으면 `Delete`와 `Backspace`는 선택 행을 삭제한다. 선택 행이 없으면 현재 편집 가능 셀의 값을 비운다.
- `Ctrl+D`는 선택 행을 복제한다.
- `Home`과 `End`는 현재 행의 첫 번째 또는 마지막 편집 가능 셀로 포커스를 이동한다.

## 7. 테스트 메뉴

- 시스템 관리 메뉴에서 접근 가능한 F1 Grid 테스트 페이지를 추가한다.
- 품목 코드, 품목명, 수량, 단가, 공급가, 납기 일시, 작업 시각, 상태를 포함한 편집 가능 샘플 Grid를 제공한다.
- 품목 코드 셀의 picker는 테스트 다이얼로그로 열리며, 선택 시 `itemCode`와 `itemName`을 같이 설정한다.
- 검증 실행 명령은 `grid.validate()`를 호출하여 성공 또는 오류 건수를 화면에 표시한다.

## 8. 검증 기준

- TSV 복사 문자열이 선택 행과 컬럼 순서를 보존한다.
- TSV 붙여넣기가 기존 행을 `updated`, 추가 행을 `inserted`로 표시한다.
- required, min, max, custom validation 오류가 셀에 표시되고 `validate()`가 false를 반환한다.
- autocomplete, code picker, currency, decimal, datetime, time이 타입별 편집값을 저장한다.
- 코드 picker 선택이 `itemCode`와 `itemName`을 한 행 변경으로 반영한다.
- Insert, Delete/Backspace, Ctrl+D, Home, End의 지정 동작을 테스트한다.
- 테스트 메뉴가 라우트와 메뉴에서 접근되고 샘플 Grid를 렌더링한다.
- 관련 Vitest, 전체 프론트엔드 테스트, TypeScript/Vite build를 실행한다.
