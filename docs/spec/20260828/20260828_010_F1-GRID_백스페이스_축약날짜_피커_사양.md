# 20260828_010 F1-GRID 백스페이스 및 날짜/시간 피커 사양

## 동작 사양

- `Backspace`는 F1-Grid 전역 키보드 명령에서 제외한다. 편집기 내부에서는 입력값 삭제 키로 동작해야 한다.
- `Delete` 및 명시적인 행 삭제 API/툴바 동작은 유지한다.
- date 입력은 현재 날짜를 기준으로 `DD`, `MMDD`, `YYMMDD`, `YYYYMMDD`를 각각 `YYYY-MM-DD`로 변환한다.
- 표준 `YYYY-MM-DD` 입력과 MUI DatePicker 선택 결과는 기존 문자열 계약을 유지한다.
- 시간 피커 버튼 클릭은 MUI 시간 선택 UI를 열고 선택 결과를 `HH:mm`으로 유지한다.
- 잘못된 날짜는 정규화하지 않는다.

## 제외

- autocomplete 타입 및 옵션 매칭 동작 변경
- 서버 API, 데이터베이스, 타임존 정책 변경

## 검증 기준

- Backspace 회귀 테스트 통과
- 날짜 축약 포맷 테스트 통과
- 시간 피커 클릭 테스트 통과
- 전체 테스트와 빌드 통과
