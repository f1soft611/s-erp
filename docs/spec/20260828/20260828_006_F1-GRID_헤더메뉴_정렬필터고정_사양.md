# 20260828_006 F1-GRID 헤더 메뉴 정렬/필터/고정 상세 사양서

## 1. 헤더 구분선

- `GridHeader.tsx`의 헤더 셀에 `columnLine` prop과 무관하게 `borderRight: 1px solid divider`를 항상 적용한다.
- 본문 셀(`GridCell.tsx`)의 `columnLine` 기반 구분선 동작은 변경하지 않는다.

## 2. 타입 추가 (`types/grid.types.ts`)

```typescript
export type F1GridSortDirection = 'asc' | 'desc';

export type F1GridSort<T> = {
  field: keyof T;
  direction: F1GridSortDirection;
};

export type F1GridFilterOperator =
  | 'equals'
  | 'notEquals'
  | 'contains'
  | 'startsWith'
  | 'endsWith'
  | 'greaterThan'
  | 'lessThan'
  | 'greaterThanOrEqual'
  | 'lessThanOrEqual'
  | 'between'
  | 'isEmpty'
  | 'isNotEmpty';

export type F1GridFilter<T> = {
  field: keyof T;
  operator: F1GridFilterOperator;
  value?: unknown;
  value2?: unknown;
};

export type F1GridPinSide = 'left' | 'right';
```

`F1GridColumn`에는 필드를 추가하지 않는다. 고정/정렬/필터 상태는 `F1Grid`가 소유한다(컬럼 정의는 불변 유지).

## 3. 정렬 — `sorting/GridSort.ts`

- `toggleGridSort<T>(sorts, field, direction)`: 동일 field+direction이면 제거(해제), 동일 field 다른 direction이면 그 항목의 direction만 갱신(순번 유지), 없으면 배열 끝에 추가. 다중 컬럼 정렬이므로 다른 field의 기존 항목은 유지한다.
- `sortGridRows<T>(rows, sorts)`: `sorts` 배열 순서대로 안정 정렬(문자열은 `localeCompare`, 그 외는 `<`/`>` 비교, `null/undefined`는 항상 마지막).
- `getGridSortIndicator<T>(sorts, field)`: 해당 컬럼의 `{ direction, order }`(order는 1부터 시작하는 다중정렬 순번) 또는 `undefined` 반환. 헤더에 방향 아이콘 + 순번 배지로 표시한다.

## 4. 필터 — `filter/GridFilter.ts`

- `getGridFilterOperators(type: F1GridEditorType): F1GridFilterOperator[]`
  - text/select/autocomplete/code: `contains, equals, notEquals, startsWith, endsWith, isEmpty, isNotEmpty`
  - number/decimal/currency: `equals, notEquals, greaterThan, lessThan, greaterThanOrEqual, lessThanOrEqual, between, isEmpty, isNotEmpty`
  - date/datetime/time: number 그룹과 동일 연산자 집합(값은 날짜 문자열/timestamp 비교)
  - checkbox: `equals`만 제공(값은 boolean)
- `matchesGridFilter<T>(row, filter, columns)`: 연산자별 매칭 로직. 문자열 연산자는 대소문자 무시. `isEmpty`/`isNotEmpty`는 `value` 무시.
- `applyGridFilters<T>(rows, filters, columns)`: 필터 배열을 AND로 적용.

### 필터 UI

- 헤더 메뉴 `필터` 클릭 시 팝오버 오픈. 팝오버 구성: 연산자 Select + 값 입력(연산자에 따라 1~2개 입력 또는 미표시), 하단 `적용`/`초기화` 버튼.
- 값 입력 컴포넌트는 컬럼 타입에 따라 텍스트/숫자/날짜/체크박스(Yes/No/전체) 입력을 사용한다.
- 필터가 적용된 컬럼은 헤더에 필터 아이콘(강조 색상)으로 표시한다.

## 5. 컬럼 고정 — `columns/GridColumnPin.ts`

- `getPinnedGridColumns<T>(columns, pinnedFields: Map<string, F1GridPinSide>)`: 표시 컬럼을 `[왼쪽 고정...] [일반...] [오른쪽 고정...]` 순서로 재정렬(각 그룹 내 원래 상대 순서 유지).
- `getGridColumnPinOffsets<T>(columns, pinnedFields, checkboxWidth = 44)`: `{ leftOffsets: Record<string, number>; rightOffsets: Record<string, number> }` 반환. 왼쪽 고정 컬럼 오프셋은 `checkboxWidth`부터 누적, 오른쪽 고정 컬럼 오프셋은 우측 끝에서부터 누적.
- 체크박스 선택 컬럼은 항상 `left: 0` sticky로 고정 표시한다(별도 상태 불필요).
- `F1Grid`는 `pinnedFields: Map<string, F1GridPinSide>` 상태를 소유하며, 헤더 메뉴의 `왼쪽 고정`/`오른쪽 고정`/`고정 해제`로 갱신한다.
- `GridHeader`/`GridCell`은 해당 컬럼이 고정이면 `position: sticky`, `left`/`right: offset px`, `zIndex: 1`, `bgcolor: background.paper`(본문)/`action.hover`(헤더)를 적용해 스크롤 시 겹침 없이 고정 표시되게 한다.

## 6. 데이터 파이프라인 (`F1Grid.tsx`)

```text
data.rows (삭제 제외)
  -> applyGridFilters(rows, filterState, columns)
  -> sortGridRows(rows, sortState)
  = visibleRows

columns
  -> getVisibleGridColumns(columns, hiddenColumnFields)
  -> getPinnedGridColumns(columns, pinnedFields)
  = visibleColumns (렌더 순서)
```

- 서버사이드 쿼리 연동은 이번 범위 밖이며, 전량 클라이언트 데이터 기준으로 동작한다.
