# 20260828_009 F1-GRID 에디터 오토컴플리트 점검 및 날짜/시간 피커 사양

## 1. 목적

F1-GRID의 `autocomplete` 에디터가 모든 커밋 경로에서 일관되게 옵션 값을 저장하도록 점검/수정하고, `date`/`datetime`/`time` 에디터를 브라우저 기본 컨트롤 대신 MUI 달력/시간 선택 UI로 교체한다.

## 2. 범위

### 포함

- `autocomplete` 타입: `Enter`(옵션 일치) 외에 `Tab`/포커스 이동으로 커밋될 때도 입력 텍스트가 옵션 라벨과 일치하면 해당 옵션의 `value`를 저장
- `date` 타입: MUI `DatePicker` 적용, 값 포맷 `YYYY-MM-DD` 유지
- `datetime` 타입: MUI `DateTimePicker` 적용, 값 포맷 `YYYY-MM-DDTHH:mm` 유지
- `time` 타입: MUI `TimePicker` 적용, 값 포맷 `HH:mm` 유지
- 세 에디터 모두 기존 `CellEditor` 계약(`value: string`, `onChange(value: string)`, `onKeyDown`)을 유지

### 제외

- `F1GridColumn`, `F1GridRef` 등 공개 타입 계약 변경
- 서버 연동, 타임존 변환, 로케일 다국어 지원
- `select`, `code`, `currency`, `decimal`, `checkbox` 등 기존 다른 에디터 타입의 동작 변경

## 3. 상세 동작

### 3.1 Autocomplete 커밋 정규화

- 위치: `core/F1Grid.tsx`의 `commitEdit`
- 조건: `column.type === 'autocomplete' && column.options`
- 로직: `column.options`에서 `option.label === draftValue` 또는 `String(option.value) === draftValue`인 옵션을 찾아 존재하면 `option.value`를 커밋 값으로 사용하고, 없으면 `draftValue`(자유 입력 텍스트)를 그대로 사용
- 기존 `AutocompleteEditor`의 `Enter` 즉시 커밋(옵션 일치 시 `onSelectChange` 호출) 동작은 그대로 유지하여 중복되지 않게 한다.

### 3.2 Date/DateTime/Time MUI 피커 적용

- 패키지: `@mui/x-date-pickers`(신규), `dayjs`(신규, 어댑터용)
- 각 에디터는 자체 `LocalizationProvider dateAdapter={AdapterDayjs}`로 감싼다.
- `value` 문자열을 지정 포맷으로 `dayjs` 파싱(빈 문자열은 `null`), 변경 시 동일 포맷 문자열로 되돌려 `onChange` 호출
- `enableAccessibleFieldDOMStructure={false}`로 단일 `<input>` DOM 구조 유지(키보드 조작/테스트 쿼리 호환)
- `slotProps.textField`에 `onKeyDown`, `autoFocus`, `fullWidth`, 컴팩트 스타일(`variant="standard"`, 언더라인 제거, `bgcolor: background.paper`, `fontSize: inherit`) 적용
- 포맷:
  - `date`: `YYYY-MM-DD`
  - `datetime`: `YYYY-MM-DDTHH:mm`
  - `time`: `HH:mm`
