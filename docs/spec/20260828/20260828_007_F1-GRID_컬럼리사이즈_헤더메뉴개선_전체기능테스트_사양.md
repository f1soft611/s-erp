## 1. 컴포넌트 사양

### 1.1 `F1GridProps` 인터페이스 확장

```typescript
export type F1GridProps<T extends object> = {
  rows: T[];
  columns: F1GridColumn<T>[];
  rowKey: keyof T;
  ariaLabel?: string;
  columnLine?: boolean;
  rowHeight?: number;
  minRowHeight?: number;
  maxRowHeight?: number;
  resizableRows?: boolean;
  resizableColumns?: boolean; // 기본값: true
  minColumnWidth?: number; // 기본값: 50
  createRow?: () => T;
  createDuplicate?: (row: T) => T;
  onChangesChange?: (changes: F1GridChanges<T>) => void;
};
```

### 1.2 컬럼 너비 리사이즈 (Column Resizing)

- **핸들 엘리먼트**: 각 컬럼 헤더 셀의 우측 끝에 배치 (`position: absolute; right: 0; top: 0; bottom: 0; width: 6px; cursor: col-resize; zIndex: 3;`)
- **드래그 동작**:
  - `onMouseDown` 시 드래그 시작 X 좌표와 현재 컬럼 너비를 기록.
  - 전역 `window`에 `mousemove`와 `mouseup` 리스너를 등록하여 사용자가 마우스를 빠르게 움직이거나 그리드 바깥으로 나가도 매끄럽게 너비 갱신.
  - 새 너비 = `Math.max(minColumnWidth, startWidth + (currentX - startX))`
  - 마우스 클릭 종료 시 리스너 해제.
- **핀 컬럼 오프셋 계산**:
  - `columnWidths` 상태가 변경되면 `getPinnedGridColumns`와 `getGridColumnPinOffsets`에 실시간 전달되어 sticky 위치(`leftOffsets`, `rightOffsets`)가 자동으로 정확하게 재배치됨.

### 1.3 헤더 더보기 버튼 개선

- 헤더 셀 CSS 구조:
  ```tsx
  <Box
    role="columnheader"
    sx={{
      position: 'relative',
      p: 1,
      display: 'flex',
      alignItems: 'center',
      gap: 0.5,
      '& .f1-grid-col-menu-btn': {
        opacity: isMenuOpen ? 1 : 0,
        transition: 'opacity 0.15s ease-in-out',
        ml: 'auto',
      },
      '&:hover .f1-grid-col-menu-btn, &:focus-within .f1-grid-col-menu-btn': {
        opacity: 1,
      },
    }}
  >
  ```
- 더보기 버튼은 항상 `ml: 'auto'`로 우측 끝에 정렬되고, 마우스가 헤더 셀에 진입할 때만 나타남.

## 2. F1GridTestPage 사양

### 2.1 테스트 컬럼 데이터 모델 (`FullTestRow`)

- `id`: 행 식별자 (string)
- `itemCode`: 품목코드 (type: `code`, 팝업 픽커 연동)
- `itemName`: 품목명 (type: `text`, `mergeRows: true`, `wrapText: true`, `required: true`)
- `category`: 분류 (type: `select`, options: 원자재, 부자재, 완제품)
- `status`: 상태 (type: `autocomplete`, options: 대기, 진행중, 완료, 보류)
- `qty`: 수량 (type: `number`, `min: 1`, `required: true`)
- `price`: 단가 (type: `currency`, `min: 0`)
- `ratio`: 할인율/비율 (type: `decimal`, `min: 0`, `max: 100`)
- `useYn`: 사용여부 (type: `checkbox`, `headerCheckbox: true`)
- `regDate`: 등록일 (type: `date`)
- `deliveryAt`: 납기일시 (type: `datetime`)
- `workTime`: 작업시각 (type: `time`)

### 2.2 제어판 및 툴바

1. **행 조작 버튼군**:
   - `[+ 행 추가]`: `gridRef.current.addRow()` 호출
   - `[복제]`: `gridRef.current.duplicateSelectedRows()` 호출
   - `[삭제]`: `gridRef.current.deleteSelectedRows()` 호출
   - `[삭제 복구]`: `gridRef.current.restoreDeletedRows()` 호출
   - `[선택 해제]`: `gridRef.current.clearSelection()` 호출
2. **검증 및 변경 추적**:
   - `[검증 실행]`: `gridRef.current.validate()` 호출 및 성공/실패 메시지 표시
   - 변경 이력 요약 칩: 신규 N건 / 수정 N건 / 삭제 N건 실시간 뱃지 노출 (`onChangesChange` 연동)
3. **그리드 설정 토글**:
   - 컬럼 구분선 표시 토글 (`columnLine`)
   - 행 높이 조절 토글 (`resizableRows`)
   - 컬럼 리사이즈 토글 (`resizableColumns`)
