## 2. 명칭 변경 및 파일 제거 사양

- `ERPGrid` -> `F1Grid` (컴포넌트 이름 및 export 이름)
- `ERPGridProps` -> `F1GridProps`
- 레거시 호환용 임시 파일(`F1Grid.tsx`, `f1Grid.types.ts`, `f1Grid.state.ts`, `f1Grid.merge.ts`, `utils/f1Grid.utils.ts`) 전량 삭제
- 모든 소비처(`MenuManagementPanel.tsx`, `f1-grid.test.tsx` 등)의 import 경로를 `shared/components/f1-grid` (index.ts)로 전환 완료
