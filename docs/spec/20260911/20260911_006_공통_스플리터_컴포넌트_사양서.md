## 2. 기능 개요

`Splitter`는 두 개의 영역을 연결하는 공통 UI 컴포넌트로, 방향에 따라 좌우 또는 상하로 드래그하여 영역 크기를 조절할 수 있다.

기본 요구사항은 다음과 같다.

- `direction="horizontal"`이면 좌우 크기 조절
- `direction="vertical"`이면 상하 크기 조절
- `initialSize`로 초기 영역 크기 지정
- `minSize` / `maxSize`로 조절 범위 제한
- 사용자 접근성을 위해 `role="separator"`와 `aria-label` 제공
- 드래그 중 마우스/터치 포인터 이동을 따라 크기 반영

## 3. 컴포넌트 인터페이스

```tsx
<Splitter
  direction="horizontal"
  initialSize={320}
  minSize={200}
  maxSize={420}
  ariaLabel="공통코드 트리와 상세영역 분리기"
>
  <Box>left</Box>
  <Box>right</Box>
</Splitter>
```

### Props

- `direction: 'horizontal' | 'vertical'`
- `initialSize?: number`
- `minSize?: number`
- `maxSize?: number`
- `handleSize?: number`
- `className?: string`
- `ariaLabel?: string`
- `children: [ReactNode, ReactNode]`

## 4. 동작 사양

### 4.1 좌우 분리기

- 첫번째 자식 영역의 너비를 `initialSize`로 초기화한다.
- 첫번째 영역과 두번째 영역 사이에 고정 폭의 핸들을 렌더링한다.
- 드래그 시 마우스 X 위치를 기반으로 첫번째 영역의 너비를 계산한다.
- `minSize`와 `maxSize` 범위를 벗어나지 않도록 제한한다.

### 4.2 상하 분리기

- 첫번째 자식 영역의 높이를 `initialSize`로 초기화한다.
- 위/아래 영역을 나누는 핸들에서 Y 축 이동을 감지한다.
- 첫번째 영역의 높이를 조정하면서 두번째 영역은 나머지 공간을 채운다.

### 4.3 레이아웃 규칙

- 컨테이너는 `display: flex`를 사용하고, 방향에 따라 `flexDirection`을 조정한다.
- 분리기 핸들은 `userSelect: none`으로 텍스트 선택 방지
- 드래그 중 마우스 이동 이벤트를 전역에서 수신하여 부드럽게 반영
- 드래그 종료 시 이벤트 리스너를 해제

## 5. 사용자 경험 규칙

- 핸들에 마우스 커서를 올리면 `col-resize` 또는 `row-resize` 커서 표시
- 트리/그리드 화면에서 드래그가 즉시 반영되고, 전체 레이아웃이 깨지지 않아야 함
- 작은 화면에서도 영역이 너무 작아지지 않도록 최소 크기 보장
- 기존 화면의 검색/조작 영역이 분리기와 충돌하지 않아야 함

## 6. 공통코드 화면 적용 규칙

- `CommonCodeManagementPanel`의 좌측 트리와 우측 그리드 사이에 `Splitter`를 사용한다.
- 리사이즈 상태는 각 페이지 인스턴스에서 관리한다.
- 기존 `F1Tree`와 `F1Grid`의 행/선택/저장 동작은 그대로 유지한다.
- F1 관련 컨텍스트 메뉴는 분리기와 별개로 정상 동작한다.

## 7. 검증 기준

- `Splitter`를 사용해 좌우 분리기 생성 시 핸들이 보이고 드래그가 동작한다.
- `vertical` 방향을 사용하면 상하 분할이 동작한다.
- `minSize`/`maxSize` 제한이 지켜진다.
- 공통코드 페이지에서 트리와 그리드의 크기를 조절할 수 있다.
- 빌드 및 테스트가 정상 통과한다.

## 8. 비기능 요구사항

- 타입 안정성
- 접근성 도구 호환
- React 19 기반 코드 스타일 유지
- 처리 빠르게 수행
- 기존 MUI 스타일 체계와 충돌하지 않는 범위로 구현
