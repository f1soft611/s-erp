# 20261012_005 공지 피드 확장 본문 이미지 표시 수정 사양서

## 1. 목적

공지 피드에서 `더보기`로 본문을 펼쳤을 때 인증이 필요한 본문 이미지가 깨져 보이는 현상을 수정한다. 접힌 피드 썸네일과 이미지 상세 뷰어에서 확인되는 기존 동작은 유지한다.

## 2. 근거 및 조사 결과

- 사용자 재현 설명: 공지 피드 본문을 펼치면 본문 이미지가 깨져 보이며, 이미지 목록과 상세 모달에서는 보인다.
- `NoticeFeedList.tsx`의 접힌 썸네일은 `AuthenticatedNoticeImage`로 렌더링하고 `apiGetBlob`을 사용한다.
- 확장된 본문은 sanitized HTML을 렌더링하고, 컴포넌트 전역 효과가 `data-notice-embedded-image-source` 이미지를 찾아 blob URL을 직접 설정한다.
- 해당 확장 본문 경로를 검증하는 피드 통합 테스트는 확인되지 않았다.
- 실제 브라우저에서 게시글 81을 펼쳐 재현했다. 이미지 API는 HTTP 200을 반환하고 이미지도 일시적으로 로드되지만, 다른 피드 상태 변경 후 다시 렌더링되면 이미지 `src`가 제거된 deferred HTML이 다시 적용된다. hydration 효과 의존성은 변경되지 않아 다시 로드되지 않는다.
- 별도 브라우저 컨텍스트는 인증 페이지로 이동했지만, 기존 인증된 브라우저 세션으로 재현했다.

## 3. 사용자 동작 및 데이터 흐름

1. 사용자가 공지 피드에서 `더보기`를 선택한다.
2. 해당 공지의 sanitized HTML 본문이 확장 상태로 표시된다.
3. 보호된 notice embedded-image API 경로는 기존 방식대로 HTML 안에서 지연 이미지 source로 유지된다.
4. 확장 본문 컨테이너 안의 지연 이미지마다 `apiGetBlob`을 호출하고, 성공한 blob URL을 포함하는 HTML을 React 상태로 저장해 표시한다.
5. 피드가 다른 상태 변경으로 재렌더링되어도 React 상태의 hydrated HTML을 유지해 deferred HTML로 되돌아가지 않게 한다.
6. 인증 API 요청에 실패한 이미지가 하나 이상이면 해당 공지 본문에 아래 오류를 한 번 표시한다.
   - `본문 이미지를 불러오지 못했습니다.`
   - 접근성 역할: `role="alert"`
7. 공지를 접거나 다른 본문으로 교체하거나 컴포넌트가 해제되면 해당 확장 본문이 만든 모든 object URL을 폐기한다. 정리 이후 늦게 완료된 요청에서 생성된 URL도 표시하지 않고 폐기한다.

## 4. 표시 및 오류 기준

- 보호 이미지 요청에는 기존 `apiGetBlob`을 사용한다. 보호된 API를 `<img src>`가 직접 요청하지 않는다.
- `alt` 텍스트, 표, 문단, 인라인 스타일 및 비보호 이미지의 기존 HTML은 보존한다.
- 이미지 요청 일부만 실패한 경우 성공한 이미지는 계속 표시하고, 오류 안내는 공지별로 한 번만 표시한다.
- API 요청 실패를 빈 성공 값으로 간주하지 않는다. 실패 상태는 사용자에게 오류 안내로 표시한다.
- plain-text 본문은 기존 렌더링을 유지한다.

## 6. 검증 기준

### Vitest

1. 확장 피드의 보호 이미지가 `apiGetBlob`을 통해 요청된다.
2. 성공한 응답 blob이 확장 본문 `<img>`의 object URL로 설정된다.
3. 요청 실패 시 확장 공지에 `role="alert"` 오류가 표시된다.
4. 피드의 무관한 상태 변경 후에도 확장 본문 이미지 URL이 유지된다.
5. 축소 또는 교체 후 이전 확장 본문이 만든 object URL이 폐기된다.
6. 기존 embedded-image service, 접힌 미리보기, 뷰어, 표 서식 및 본문 렌더링 테스트가 통과한다.

### 브라우저

- 인증된 S-ERP 공지 화면에서 보호 본문 이미지가 포함된 공지를 펼쳐 이미지가 본문 안에 표시되는지 확인한다.
- 같은 공지를 접었을 때 기존 미리보기 이미지가 유지되고, 미리보기를 통한 상세 뷰어가 계속 동작하는지 확인한다.
- 결과 스크린샷을 `docs/result/20261012/notice-feed-expanded-images/screenshots/`에 보관한다.
