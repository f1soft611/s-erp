# S-ERP 로고 종합현황 이동 상세사양서

근거: [계획서](../../plan/20261028/20261028_006_brand-overview-link_계획서.md)

## 동작

- 대상은 로그인 후 왼쪽 모듈 레일 상단의 `S-ERP` 텍스트다.
- 링크 목적지는 기존 종합현황 `/groupware/overview`이며 React Router로 전체 새로고침 없이 이동한다.
- 링크의 접근 가능한 이름은 보이는 텍스트 `S-ERP`다. Tab으로 초점을 받고 Enter로 이동한다.
- 같은 모듈의 다른 메뉴와 다른 모듈 양쪽에서 이동한다. 종합현황에서 다시 눌러도 같은 화면을 유지한다.
- 기존 브랜드의 색상, 글자 크기, 굵기, 간격을 유지하며 링크 기본 밑줄을 제거한다. 브라우저 키보드 초점 표시를 제거하지 않는다.
- 기존 메뉴 조회권한과 유효 경로 검증을 우회하지 않는다. 권한 없는 메뉴를 생성하거나 별도 데이터 조회를 추가하지 않는다.

## 범위와 검증

- 프론트엔드 브랜드 링크 및 집중 회귀 테스트만 변경한다. 백엔드/API/DB 변경 및 MCP 조회는 해당하지 않는다.
- DOM 테스트에서 링크 클릭 후 경로 변경을 검증한다.
- 실제 브라우저에서 합성 응답으로 light/dark × 375/768/1280px 클릭 이동, 키보드 이동, 링크 표시와 가로 넘침을 확인하고 스크린샷을 남긴다.
