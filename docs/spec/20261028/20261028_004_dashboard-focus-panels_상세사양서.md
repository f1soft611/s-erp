# 포커스 패널 상세사양

근거: [계획서](../../plan/20261028/20261028_004_dashboard-focus-panels_계획서.md)

- A 시안 적용. 실제 기존 2열 업무/공지 및 추이/납기 배치 유지(미리보기의 비교용 3열 배치 적용하지 않음).
- 세 패널: 부드러운 아이콘 배경, 카드 내부 행 경계, 적절한 여백, hover/focus, 구분선 있는 하단 링크. 차트 패널은 기존 디자인 유지.
- 업무: 결재대기/보완요청을 채움형 배지로 구분, 제목과 상태만 표시. 하단 문서 업무 보기 이동 유지.
- 공지: 고정 공지는 배경/‘고정 공지’ 배지와 날짜 강조, 일반 공지는 제목 아래 날짜. 기존 날짜 값 표시 유지. 하단 공지 전체 보기.
- 납기: 월/일 구분 달력 타일, 오늘 납기 강조, 내일 · D-1, D-n. 차이는 응답 asOfDate와 deliveryDt의 UTC 자정 간 일수로 계산하여 브라우저 현재시각/DST에 영향받지 않는다. 출하 상태나 지연을 추정하지 않는다.
- 납기 전체 건수는 헤더, 표시 개수는 하단 안내. 전체 보기 및 행 상세 조회는 기존 기간/수주번호 이동 유지.
- 로딩은 같은 focus 헤더/행/하단 구조 및 달력 공간을 사용한다. 숫자나 합성 제목을 실제 값처럼 보여주지 않으며 비대화형 유지.
- 오류/빈 데이터/권한 숨김 유지. 밝은/다크 ×375/768/1280px 가로 넘침 없음.
- 백엔드/API/DB 변경 없음. DB MCP/마이그레이션 대상 아님.
