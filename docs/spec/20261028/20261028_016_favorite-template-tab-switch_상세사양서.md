## 기대 동작

1. 기안서 결재선 설정은 문서 코드 `001`의 즐겨찾기를 조회한다.
2. 설정 창에서 목록을 확인하고 취소하면 작성 화면의 참여자는 변경되지 않는다.
3. 업무연락 탭 전환 확인 후 자주 쓰는 참조자를 열면 문서 코드 `008`의 목록을 조회한다.
4. 이전 모달의 조회 결과, 선택값, 진행 상태가 새 참조자 설정에 남지 않는다.
5. 참조자 목록을 선택하면 임시 참조자만 바뀌고, 적용 버튼을 눌러야 작성 화면에 전달된다.
6. 업무연락에서 취소 후 기안서로 돌아가는 역방향도 같은 경계를 지킨다.

## 범위와 검증

- 프론트엔드 모달 조회/상태 흐름과 관련 회귀 테스트에 한정한다. 레이아웃, 템플릿 API/DB, F1-Grid 코어를 바꾸지 않는다.
- 정상 응답과 이전 조회 지연 조건에서 현재 문서 종류의 목록이 조회되는지 확인한다.
- 기존 설정 모달/작성 모달 회귀, TypeScript/Vite 빌드, 대상 린트 및 공백 검사를 수행한다.
- 375px, 768px, 1280px의 실제 브라우저 화면 및 참조자 목록을 결과 경로에 저장한다.
