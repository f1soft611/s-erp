# 20261028_014 문서작성 재상신 후 상세 댓글 갱신 상세 사양서

## 사용자 동작

1. 보완요청된 문서를 우측 상세에서 열면 기존처럼 문서 상세와 최신 댓글·시스템 이력을 조회한다.
2. `수정 후 재상신` 창을 통한 저장 및 결재신청이 완료되면 문서작성 페이지가 상세 갱신 신호를 보낸다.
3. 상세 패널은 같은 문서의 상세 정보뿐 아니라 최신 댓글·시스템 이력도 다시 조회해 재상신 이력을 표시한다.

## 갱신 규칙

- 최초 댓글 조회는 기존의 문서 ID/패널 열림 상태 effect가 담당한다.
- 상세 갱신 토큰이 바뀌었을 때 패널이 열려 있고 문서 ID가 유효하면 문서 상세 API와 기본 댓글 페이지 API를 각각 다시 호출한다.
- 패널이 닫혔거나 문서 ID가 없으면 갱신 조회를 하지 않는다.
- 댓글 응답은 기존 `loadComments()` 처리와 동일하게 댓글, 시스템 이력, 전체 수, 이전 댓글 커서를 갱신한다.
- 댓글 조회 실패 시 기존 댓글 조회 오류 상태를 사용하고, 문서 상세 재조회와 오류 처리는 서로 독립적으로 유지한다.

## 회귀 검증

- 최초 상세 진입 시 기존처럼 댓글 목록을 조회한다.
- 토큰 변경 후 같은 문서의 댓글 API가 다시 호출된다.
- 두 번째 응답의 재상신 시스템 이력이 우측 상세에 렌더링된다.
- 다른 문서, 닫힌 패널, 기존 댓글 페이지네이션 및 댓글 CRUD 동작은 변경하지 않는다.

## 비범위

- API, 데이터베이스, 댓글 정책 및 시스템 이력 생성 로직
- 목록/요약 갱신 또는 상세 패널 열림·닫힘 UX 변경
