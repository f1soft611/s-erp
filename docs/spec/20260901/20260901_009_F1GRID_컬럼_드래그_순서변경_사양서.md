# F1-GRID 컬럼 드래그 순서 변경 사양서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot

## 1. 개요

컬럼 헤더를 드래그해 다른 컬럼 위치로 이동시키면 그리드의 컬럼 표시 순서가 변경된다. 좌/우 고정 컬럼은 이동 대상/목표에서 제외된다. `storageKey`를 지정하면 변경된 순서가 `localStorage`에 영구 저장된다.

## 2. 타입 사양

```ts
// F1GridProps<T>
storageKey?: string;
```

## 3. 동작 사양

1. `F1Grid`는 `columnOrder: string[]` state를 가진다.
   - `storageKey`가 지정되고 `localStorage.getItem(storageKey)`에 유효한 JSON 배열이 있으면 해당 값으로 초기화한다.
   - 그렇지 않으면 `columns.map(c => String(c.field))` 순서로 초기화한다.
2. `columnOrder`가 변경될 때마다 `storageKey`가 있으면 `localStorage.setItem(storageKey, JSON.stringify(columnOrder))`로 저장한다.
3. 실제 렌더링에 사용하는 컬럼 배열은 `reorderGridColumns(columns, columnOrder)` → `getVisibleGridColumns` → `getPinnedGridColumns` 순서로 계산한다. `columnOrder`에 없는(신규 추가된) 컬럼은 정의 순서 그대로 뒤에 붙는다.
4. `GridHeader`의 각 헤더 셀은 pinned가 아닐 때만 `draggable`이며, 드래그 시작/드래그 오버/드롭 이벤트로 `onReorderColumn(sourceField, targetField)`를 호출한다.
5. pinned 컬럼은 드래그 소스로 지정할 수 없고, 드롭 대상으로도 무시된다(순서 변경 없음).
6. `moveGridColumnOrder(order, sourceField, targetField)`는 `order` 배열에서 `sourceField`를 제거한 뒤 `targetField`가 있던 위치에 삽입한 새 배열을 반환한다.

## 4. 검증 기준

- `reorderGridColumns`/`moveGridColumnOrder` 유틸 단위 테스트
- 헤더 드래그·드롭 시 컬럼 순서가 바뀌는 상호작용 테스트
- pinned 컬럼이 드래그 대상/목표에서 제외되는지 테스트
- `storageKey` 지정 시 `localStorage`에 순서가 저장/복원되는지 테스트
- `npm run test -- tests/f1-grid.test.tsx`, `npm run build` 통과
