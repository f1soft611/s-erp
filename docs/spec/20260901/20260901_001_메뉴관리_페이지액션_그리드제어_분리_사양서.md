# 20260901_001 메뉴관리 페이지 액션/그리드 제어 분리 사양서

## 1. 목적

메뉴관리 페이지에서 페이지별 업무 버튼과 F1Tree 제어 버튼의 책임을 분리해 권한 기반 액션 버튼 정책을 적용할 수 있는 화면 구조를 마련한다.

## 2. 화면 구조

메뉴관리 패널은 다음 구조를 가진다.

1. 패널 제목 영역
   - `메뉴 관리` 제목을 표시한다.
2. 서비스 액션 영역
   - `루트 메뉴 추가`
   - `하위 메뉴 추가`
   - `삭제`
   - `저장`
   - `새로고침`
3. 그리드 제어 영역
   - `전체 펼치기`
   - `전체 접기`
4. 그리드 영역
   - 기존 `F1Tree`를 표시한다.
   - 동적 권한 체크박스 열과 기존 편집 동작을 유지한다.

## 3. 동작 규칙

- 서비스 액션 버튼은 페이지 업무 흐름을 수행한다.
- 그리드 제어 버튼은 F1Tree 표시 상태만 제어한다.
- 선택 모듈이 없거나 저장 중이면 기존과 동일하게 버튼을 비활성화한다.
- 하위 메뉴 추가 버튼은 기존과 동일하게 선택 행이 없으면 비활성화한다.
- 기존 메뉴 저장 순서와 권한 저장 흐름은 변경하지 않는다.

## 4. 접근성 및 반응형

- 서비스 액션 영역은 `aria-label="메뉴 업무 액션"`으로 구분한다.
- 그리드 제어 영역은 `aria-label="메뉴 그리드 제어"`로 구분한다.
- 375px, 768px, 1280px에서 버튼 영역은 줄바꿈되며 서로 겹치지 않아야 한다.
- 페이지 전체 가로 스크롤을 유발하지 않고, 넓은 그리드 콘텐츠는 기존 내부 스크롤 정책을 따른다.

## 5. 검증 기준

- Vitest에서 두 액션 영역이 분리되어 렌더링되는지 확인한다.
- 기존 메뉴 추가, 삭제, 저장, 권한 저장 테스트가 통과해야 한다.
- 프론트엔드 빌드가 통과해야 한다.
