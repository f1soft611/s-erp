## 1. 컴포넌트 위치 및 Props

`frontend/src/shared/components/PageSearchArea.tsx`

```ts
type PageSearchAreaProps = {
  children: ReactNode; // 검색 조건 필드들(Select, TextField 등)
};
```

## 2. 마크업/스타일

- 컨테이너: `px:3, py:2, borderBottom:'1px solid rgba(148,163,184,0.18)'`
- 내부 배치: `display:flex, flexWrap:'wrap', alignItems:'center', gap:1`
- 헤더 컴포넌트와 달리 배경/블러 효과는 적용하지 않는다(검색 영역은 패널 바로 위에 위치하는 얇은 필터 바 역할).

## 3. 화면 배치 순서 (MenuManagementPage)

```
<PageHeader ... actionGroups={pageActionGroups} />   // children 제거
<PageMessageArea message={error} ... />
<PageSearchArea>
  <FormControl>...모듈 선택...</FormControl>
  <TextField ... 메뉴명/코드 검색 ... />
</PageSearchArea>
<MenuManagementPanel ... />
```

- 기존 모듈 선택/검색 필드의 props, 이벤트 핸들러, 스타일(width/minWidth/flex)은 그대로 유지한다.
- 다른 페이지는 검색 UI가 없으므로 변경하지 않는다.
