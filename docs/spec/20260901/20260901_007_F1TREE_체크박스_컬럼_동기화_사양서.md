# F1-GRID F1Tree treeCheckbox 체크박스 컬럼 동기화 사양서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot

## 1. 개요

`F1Tree`의 `treeCheckbox`(행 선택용 트리 체크박스)를 체크/해제하면 해당 행 및 하위 행의 `type: 'checkbox'` 데이터 컬럼 값을 함께 동기화한다.

## 2. 타입 사양

`F1GridColumn<T>`에 옵션 추가:

```ts
syncWithTreeCheckbox?: boolean; // 기본값 true
```

`F1GridRef<T>`에 메서드 추가:

```ts
setCellValue(rowId: F1GridRowId, field: keyof T, value: unknown): void;
```

- `isCellEditable` 여부와 무관하게 값을 강제로 반영하는 시스템 자동화 경로다.

## 3. 동작 사양

1. `F1Tree`의 `toggleTreeCheckbox(rowId, nextChecked)`가 호출되면 기존 `treeCheckedIds` 갱신과 함께, 대상 rowId 목록(`[rowId, ...하위 rowId]`)에 대해 다음을 수행한다.
   - `gridProps.columns` 중 `type === 'checkbox'` && `syncWithTreeCheckbox !== false`인 컬럼 목록을 계산
   - 각 대상 rowId × 대상 컬럼 조합에 대해 `gridRef.current.setCellValue(rowId, column.field, nextChecked)` 호출
2. 기존 셀 값과 무관하게 `nextChecked` 값으로 무조건 덮어쓴다(체크 시 `true`, 해제 시 `false`).
3. `syncWithTreeCheckbox: false`로 지정된 컬럼은 반영 대상에서 제외되어 사용자가 입력한 값이 그대로 유지된다.

## 4. 검증 기준

- `treeCheckbox` 체크/해제 시 `type: 'checkbox'` 컬럼 값이 함께 바뀌는지 확인하는 상호작용 테스트 추가
- `syncWithTreeCheckbox: false` 컬럼은 영향받지 않음을 확인하는 테스트 추가
- `npm run test -- tests/f1-tree.test.tsx`, `npm run build` 통과
