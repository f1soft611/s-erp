# F1-GRID 화면크기(displayScale) 연동 사양서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot

## 1. 개요

대시보드의 화면크기 설정(`displayScale`, `AppSettingsContext`)이 변경되면, 그리드의 기본/최소 행 높이가 비례해서 자동 조정된다. 사용자가 개별 행 높이를 수동 조정한 경우 그 값이 우선한다.

## 2. 동작 사양

1. `AppSettingsContext.tsx`에 `useOptionalDisplayScale(): number` 훅을 추가한다. `AppSettingsProvider`가 없는 트리에서 호출되면 `1`을 반환하고, 있으면 현재 `displayScale` 값을 반환한다.
2. `F1Grid`는 `useOptionalDisplayScale()`로 `displayScale`을 조회하고, 다음과 같이 계산한다.
   - `scaledRowHeight = rowHeight * displayScale`
   - `scaledMinRowHeight = minRowHeight * displayScale`
   - `scaledMaxRowHeight = maxRowHeight * displayScale`
   - 이후 기존과 동일하게 `clampGridRowHeight`로 정규화한다.
3. 개별 행 높이 조정 상태(`rowHeights` state)는 그대로 유지되며, `rowHeights[rowId]`가 있으면 해당 값을 사용하고 없으면 위에서 계산한 `defaultRowHeight`(스케일 반영값)를 사용하는 기존 로직을 그대로 따른다. 즉 displayScale은 "미조정 상태의 기본값"에만 영향을 준다.
4. `displayScale` 기본값은 `1`이므로 `AppSettingsProvider`로 감싸지 않은 환경(단위 테스트 등)에서는 기존 동작과 동일하다.

## 3. 검증 기준

- `useOptionalDisplayScale`이 Provider 없이 `1`을 반환하는지 테스트
- `displayScale`이 1이 아닐 때 `F1Grid`의 기본 행 높이가 비례 조정되는지 테스트(AppSettingsProvider로 감싼 렌더링)
- 수동으로 조정된 행 높이는 `displayScale` 변경과 무관하게 유지되는지 확인
- `npm run test -- tests/f1-grid.test.tsx`, `npm run build` 통과
