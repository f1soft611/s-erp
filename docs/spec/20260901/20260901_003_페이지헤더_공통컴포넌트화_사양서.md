# 페이지 헤더 공통 컴포넌트화 사양서

- 관련 계획서: [20260901*003*페이지헤더*공통컴포넌트화*계획서.md](../../plan/20260901/20260901_003_페이지헤더_공통컴포넌트화_계획서.md)

## 1. 컴포넌트 위치

`frontend/src/shared/components/PageHeader.tsx`

## 2. Props 정의

```ts
type PageHeaderProps = {
  /** 모듈/메뉴 계층을 순서대로 나열. 마지막 항목이 현재 메뉴(굵게 강조)로 표시됨 */
  breadcrumbItems: string[];
  /** 페이지 설명 문구 */
  description: string;
  /** 우측 기능 버튼 그룹 (미전달 시 우측 영역 렌더하지 않음) */
  actionGroups?: PermissionActionGroupDefinition[];
  /** 헤더 하단 추가 영역 (모듈 선택/검색 필터 등) */
  children?: ReactNode;
};
```

- `breadcrumbItems`는 항상 배열로 통일한다. 기존 "모듈명 + 현재메뉴명" 2단 구조 페이지는 호출부에서 `[selectedModule.name, currentMenuName]`으로 변환해서 전달한다.
- `MenuManagementPage`처럼 이미 `breadcrumbItems` prop을 받는 경우, 값이 없으면 기존 fallback(`[dashboardModule.name, currentMenuName]`)을 호출부에서 구성해 전달한다.

## 3. 마크업/스타일 규칙 (기존 스타일 그대로 이관)

- 외곽 컨테이너: `px:3, py:2, borderBottom:'1px solid rgba(148,163,184,0.18)'`, 배경 `isDark ? 'rgba(15,23,42,0.75)' : 'rgba(255,255,255,0.72)'`, `backdropFilter:'blur(12px)'`
- 좌/우 배치: `actionGroups`가 있으면 `display:flex, justifyContent:'space-between', flexWrap:'wrap', gap:2`로 좌측 브레드크럼 블록과 `PermissionGroupActionBar`를 나란히 배치. 없으면 좌측 블록만 렌더(기존 단순 페이지와 동일).
- 브레드크럼: `Typography variant="overline"`, 마지막 항목만 `color:'text.primary', fontWeight:800`, 나머지는 `color:'text.secondary'`, 구분자 `' > '` (2단 구조였던 페이지는 기존과 동일하게 `'/'` 구분자 유지 — 아래 4번 참고).
- 설명: `Typography variant="body2" color="text.secondary" sx={{ mt: 1 }}`
- `children`은 브레드크럼 블록과 액션 버튼을 포함한 상단 Row 아래에 `mt:2`로 렌더.

## 4. 브레드크럼 구분자 처리

- 기존 단순 페이지(모듈명/현재메뉴명 2단): 구분자 `/` 사용 중이었음. 공통 컴포넌트는 `breadcrumbItems` 배열 길이가 2이고 별도 옵션이 없을 때도 통일된 `>` 구분자를 사용해도 되지만, 팀 규칙상 화면 문구/동작 변경 최소화가 우선이므로 **구분자를 `>`로 통일**하지 않고 기존 MenuManagementPage 방식(`' > '`)으로 통일한다. (시각적으로 `/` → `>` 로 미세 변경되나 브레드크럼 구분자는 기능적 의미가 없는 표기 스타일이므로 공통화 목적상 통일 허용)
