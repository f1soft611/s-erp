# F1-GRID 컬럼 설정 로컬스토리지 확장 사양서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot

## 1. 개요

`storageKey`가 지정된 `F1Grid`는 컬럼 순서뿐 아니라 컬럼 너비, 숨김 컬럼 목록까지
하나의 JSON 객체로 `localStorage`에 저장하고 복원한다.

## 2. 저장 포맷

```ts
type F1GridColumnStorageState = {
  order?: string[]; // columns.map(c => String(c.field)) 기준 순서
  widths?: Record<string, number>; // field -> 픽셀 너비
  hidden?: string[]; // 숨김 처리된 field 목록
  pinned?: Record<string, 'left' | 'right'>; // field -> 고정 방향
};
```

`localStorage.getItem(storageKey)` 값은 위 타입의 JSON 직렬화 문자열이다.

## 3. 동작 사양

1. `parseGridColumnStorageState(raw)`는 `raw`가 없거나 JSON 파싱 실패, 또는 파싱 결과가
   객체가 아니면(예: 배열) `null`을 반환한다.
2. `F1Grid` 마운트 시 `storageKey`가 있으면 `parseGridColumnStorageState`로 저장 값을 읽어:
   - `order`가 있으면 `columnOrder` 초기값으로 사용, 없으면 `columns.map(c => String(c.field))`.
   - `widths`가 있으면 `columnWidths` 초기값으로 사용, 없으면 `{}`.
   - `hidden`이 있으면 `hiddenColumnFields` 초기값(`Set`)으로 사용, 없으면
     `columns.filter(c => c.hidden)` 기준 기본값.
   - `pinned`이 있으면 `pinnedFields` 초기값(`Map`)으로 사용, 없으면
     `columns.filter(c => c.pinned)` 기준 기본값.
3. `columnOrder`, `columnWidths`, `hiddenColumnFields`, `pinnedFields` 중 하나라도 변경되면
   `storageKey`가 있는 경우 네 값을 모두 모아
   `localStorage.setItem(storageKey, JSON.stringify({ order, widths, hidden, pinned }))`로 저장한다.
4. `storageKey`가 없으면 기존과 동일하게 컴포넌트 state로만 유지하고 저장하지 않는다.

## 4. 검증 기준

- `parseGridColumnStorageState` 단위 테스트(정상 JSON, 배열/손상 JSON에 대해 `null`).
- 컬럼 순서 변경 → 저장 → 재마운트 시 순서 복원 (기존 테스트 갱신).
- 컬럼 너비 변경 → 저장 → 재마운트 시 너비 복원.
- 컬럼 숨김 처리 → 저장 → 재마운트 시 숨김 상태 복원.
- 컬럼 고정(pin) 처리 → 저장 → 재마운트 시 고정 상태 복원.
- `npm run test -- tests/f1-grid.test.tsx`, `npm run build` 통과.
