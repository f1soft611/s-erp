# F1-GRID 컬럼 자동너비맞춤 사양서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot

## 1. 개요

컬럼 리사이즈 핸들을 더블클릭하면 헤더 제목과 현재 렌더링된 셀 값 중 가장 긴 내용을 기준으로 컬럼 너비를 자동 조정한다.

## 2. 타입 사양

`F1GridColumn<T>`에 옵션 추가:

```ts
maxWidth?: number;
```

- 미지정 시 상한 없음(내용 길이만큼 확장)
- 지정 시 자동 맞춤 결과가 `maxWidth`를 넘지 않음(수동 드래그 리사이즈는 기존과 동일하게 `maxWidth` 영향 없음)

## 3. 동작 사양

1. `GridHeader`의 리사이즈 핸들(`role="separator"`, `aria-label="{headerName} 컬럼 너비 조절"`)에 `onDoubleClick` 핸들러 추가.
2. 더블클릭 시 다음 순서로 목표 너비를 계산한다.
   - 헤더 제목(`column.headerName`) 텍스트 너비 측정
   - `visibleRows`(현재 정렬/필터 적용 후 렌더링 중인 행 전체, 가상 스크롤 미적용이므로 화면 표시 행과 동일) 각각의 표시값(`column.getValue?.(row) ?? row[column.field]`)을 문자열로 변환 후 텍스트 너비 측정
   - 위 값들의 최댓값에 셀 좌우 패딩만큼 여유값을 더함
3. 계산된 값을 `Math.max(minColumnWidth, Math.min(column.maxWidth ?? Infinity, measuredWidth))`로 clamp.
4. `onResizeColumn(column, nextWidth)`을 호출해 기존 컬럼 리사이즈와 동일한 상태 갱신 경로를 사용한다.
5. 텍스트 너비 측정은 Canvas 2D context의 `measureText`를 사용하는 유틸리티 함수(`utils/grid.utils.ts`)로 구현하고, 폰트 문자열은 그리드 셀의 기본 스타일(`font-size: 13px`, MUI 기본 폰트 패밀리)과 근사하게 고정값으로 설정한다.

## 4. 검증 기준

- 신규 유틸 함수 단위 테스트(측정값 clamp 동작) 추가
- `GridHeader` 더블클릭 시 `onResizeColumn` 호출 및 결과 너비 검증 테스트 추가
- `npm run test -- tests/f1-grid.test.tsx`, `npm run build` 통과
