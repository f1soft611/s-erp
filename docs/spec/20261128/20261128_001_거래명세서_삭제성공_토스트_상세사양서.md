# 거래명세서 삭제 성공 토스트 상세사양서

- 계획서: [20261128_001](../../plan/20261128/20261128_001_거래명세서_삭제성공_토스트_계획서.md)

## 동작

| 구분 | 기준 |
| --- | --- |
| 성공 | `deleteStatement` 성공 → 화면 초기화 → `showSuccess('거래명세서가 삭제되었습니다. 명세번호: ' + 삭제 전 명세번호)` → `onDeleted` |
| 명세번호 | 초기화(`reset`)가 `item`을 비우므로 삭제 요청 전에 `item?.statementNo`를 보관한다. 번호가 없으면 `거래명세서가 삭제되었습니다.`만 표시 |
| 실패 | 기존 `setError` 유지(메시지 영역, 수정 창이면 창 안). `showSuccess` 호출 없음 |
| 취소 | 확인창에서 취소하면 아무 표시 없음(기존 동작) |

## 테스트

- T1: 현황 → 상세 → 수정 창 → 삭제 → 확인 → 창 닫힘, 토스트 `거래명세서가 삭제되었습니다. 명세번호: TS-1`.
- T2: 삭제 API 실패 → 창 유지, 창 안에 오류 문구, 성공 문구 없음.
