# 20260827_005 MUI TreeView 메뉴 트리 전환 사양

## 1. 목적

대시보드 좌측 메뉴의 계층 표현을 MUI X `SimpleTreeView`로 표준화하고, 사용자에게 그룹 확장 상태와 현재 페이지 위치를 명확하게 제공한다.

## 2. 대상 화면과 컴포넌트

| 구분            | 위치                | 책임                                             |
| --------------- | ------------------- | ------------------------------------------------ |
| 메뉴 트리       | `DashboardMenuTree` | 재귀 노드 렌더링, 확장 상태, 리프 선택 전달      |
| 사이드바        | `DashboardSidebar`  | 모듈 레일과 메뉴 트리 조립                       |
| 대시보드 페이지 | `DashboardPage`     | URL 기반 선택 리프·조상 그룹 계산 및 리프 라우팅 |

## 3. 데이터 사양

기존 `MenuTreeNode`를 변경 없이 사용한다.

```ts
type MenuTreeNode = {
  id: string;
  name: string;
  pageKey?: string;
  children?: MenuTreeNode[];
};
```

- `children`가 하나 이상인 노드는 그룹이다.
- `pageKey`가 있는 자식 없는 노드는 페이지 이동 가능한 리프다.
- 노드 ID는 모듈 내부에서 고유해야 하며, `TreeItem.itemId`와 URL의 `menuId`에 사용한다.

## 4. 동작 사양

### 4.1 모듈 변경

1. 모듈 레일 항목을 선택한다.
2. 해당 모듈의 첫 번째 페이지 리프 경로로 이동한다.
3. 새 선택 리프와 그 조상 그룹을 트리에 표시하고 조상 그룹을 확장한다.

### 4.2 그룹 토글

1. 그룹 노드의 콘텐츠 또는 펼침 아이콘을 선택한다.
2. 해당 그룹의 하위 항목을 확장 또는 축소한다.
3. 현재 URL, 선택 리프, 본문 콘텐츠는 변경하지 않는다.

### 4.3 리프 메뉴 선택

1. 리프 노드를 선택한다.
2. `/dashboard/:moduleId/:menuId`로 이동한다.
3. 선택 리프는 강조 표시하고 그 조상 그룹은 확장 상태로 유지한다.

### 4.4 직접 URL 진입

유효한 모듈과 리프 메뉴 경로로 진입하면 해당 리프를 선택하고 모든 조상 그룹을 확장한다. 유효하지 않은 메뉴 ID는 현재 모듈의 첫 페이지 리프로 대체한다.

## 5. UI 사양

- 92px 모듈 레일, 메뉴 패널 헤더, 하단 사용자 정보 카드는 기존 구조를 유지한다.
- 그룹은 확장/축소 아이콘, 굵은 텍스트, 일반 리프보다 낮은 시각 밀도로 표시한다.
- 리프는 들여쓰기와 행 높이로 그룹 하위임을 드러낸다.
- 선택 리프는 기존 파란 계열의 배경, 좌측 강조선, 굵은 글꼴로 표시한다.
- hover와 selected 스타일은 밝은/다크 테마에서 식별 가능해야 한다.
- MUI TreeView가 제공하는 트리 역할 및 키보드 이동 접근성을 유지한다.

## 6. 오류 및 경계 조건

- 선택된 모듈에 트리 또는 페이지 리프가 없으면 기존 대시보드 기본 메뉴 fallback을 유지한다.
- 그룹 노드는 `pageKey`가 있더라도 이번 범위에서는 페이지 이동 대상이 아니다.
- 메뉴 데이터, API, DB 계약은 변경하지 않는다.

## 7. 검증 기준

- `@mui/x-tree-view`의 `SimpleTreeView`가 메뉴 패널에 렌더링된다.
- 그룹 토글 후 URL과 본문 제목이 변하지 않는다.
- 리프 선택 후 URL과 본문 콘텐츠가 기존 경로와 일치한다.
- 현재 URL 리프의 조상 그룹이 확장되고 선택 상태가 보인다.
- `tests/dashboard-sidebar.test.tsx`와 `npm run build`가 성공한다.
