# 20260916_001 공지 작성 모달 수정 사양서

## 1. 목적

공지 작성 모달의 시각적 톤과 첨부 문서 삽입 흐름을 정규화하여 사용자가 자연스럽게 공지 내용을 작성할 수 있도록 한다.

## 2. UI 요구사항

### 2.1 취소 버튼 스타일

- 공지 작성 모달의 취소 버튼은 F1-Grid FormModal과 같은 톤으로 적용한다.
- 기본 여백, radius, 텍스트 굵기, 배경 표현을 맞춘다.
- 버튼은 현재 화면과 너무 강하게 대비되지 않도록 한다.

### 2.2 툴바 배치

- 툴바 버튼은 참조 이미지를 기준으로 재배치한다.
- 기본 문단/형식 도구 순서를 유지하되, 사용자에게 익숙한 흐름으로 배치한다.
- 툴바 버튼은 실제 기능에 연결되도록 정리한다.

## 3. 첨부 동작 요구사항

### 3.1 업로드 위치 규칙

- 본문이 비어 있으면 첨부 섹션을 가장 상단에 추가한다.
- 본문이 존재하면 마지막 본문 뒤에 구분선과 첨부 섹션을 추가한다.
- 구분선은 시각적으로 첨부 영역과 본문을 분리한다.

### 3.2 단일/다중 업로드 규칙

- 파일 선택 시 업로드 순서를 유지한다.
- 여러 파일을 한 번에 선택한 경우에도 순서대로 문서에 추가된다.
- 파일은 텍스트 노드의 순서와 동일한 배열 순서로 문서에 반영한다.

### 3.3 첨부 표현

- 첨부 파일은 파일명 텍스트가 포함된 문서 노드로 표현한다.
- 본문과 구분된 상태로 화면에 노출된다.
- 기존 본문 텍스트는 유지한다.

## 4. 검증 기준

- 취소 버튼이 F1-Grid form modal과 동일한 톤으로 렌더링된다.
- 툴바 목록이 재배치되어 있다.
- 첨부 업로드 시 본문 빈 상태와 존재 상태가 각각 의도대로 동작한다.
- 다중 업로드 순서가 보존된다.
- 관련 테스트가 통과한다.

## 5. 비기능 요구사항

- 기존 에디터 동작 흐름을 손상시키지 않는다.
- 공지 작성 모달만 범위를 수정하고 다른 화면으로 영향이 전이되지 않는다.
