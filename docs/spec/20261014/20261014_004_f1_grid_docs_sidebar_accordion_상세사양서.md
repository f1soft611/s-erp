## 2. 메뉴 상태와 동작

### 일반 메뉴

- 선택 문서의 `group`을 유일한 펼침 그룹으로 삼는다. 별도 사용자 확장 상태를 저장하지 않는다.
- 초기 문서 기본값 `overview`는 `getting-started` 그룹에 포함되므로 첫 화면에서는 `시작하기`만 펼친다.
- 펼쳐진 그룹에 속한 문서 항목만 표시한다. 다른 그룹의 항목은 일반 메뉴 DOM/접근성 탐색에서 숨긴다.
- 그룹 제목은 버튼이며 `aria-expanded` 값은 해당 그룹이 선택 문서의 그룹일 때만 `true`다.
- 그룹 제목을 선택하면 그 그룹의 문서 배열에서 첫 항목을 선택한다. 선택된 문서가 바뀌므로 그룹은 해당 그룹 하나만 펼쳐진다. 현재 열린 그룹 제목을 눌러도 그 그룹의 첫 문서로 이동한다.
- 문서 항목 선택은 기존 `selectDocument` 흐름을 사용하고 선택 문서의 그룹을 자동으로 펼친다. 모바일에서는 메뉴를 기존과 같이 닫는다.

### 검색 메뉴

- 검색어가 비어 있지 않으면 기존 필터링 결과 렌더링을 유지한다. 필터된 문서가 하나라도 있는 각 그룹은 그룹 레이블과 결과 문서를 모두 노출하며, 아코디언으로 결과를 접지 않는다.
- API 이름/계약 검색 결과도 기존과 같이 별도 `API 항목` 영역에 모두 표시하고 클릭 시 해당 API 행으로 이동한다.
- 검색 결과 선택, 결과 없음 표시, 선택 문서 보정 로직, 검색어 보존 동작은 변경하지 않는다.

## 3. 접근성 및 반응형

- 그룹 버튼은 표시 레이블을 accessible name으로 사용하고 `aria-expanded`를 설정한다.
- 키보드로 표준 버튼 포커스/활성화가 가능해야 한다.
- 현재 문서 메뉴 항목의 활성 스타일, 검색 상태의 결과 스타일은 유지한다.
- 최소 1280px 데스크톱과 375px 모바일에서 메뉴를 사용할 수 있어야 한다. 페이지 전체 가로 overflow를 만들지 않는다.
- 그룹 제목 버튼의 높이·간격·줄바꿈은 기존 사이드바 너비와 라이트/다크 토큰을 따른다.

## 4. 수정 대상과 제외

- 수정 대상: `F1GridDocsPage.tsx`, `F1GridDocsPage.css`, `f1-grid-docs.test.tsx`, `F1-GRID.md`, 날짜별 결과 문서와 스크린샷.
- 제외: 그룹 데이터 및 문서 분류 변경, 검색 알고리즘/API 데이터 변경, 페이지 본문/목차, Playground, 라우트, F1-Grid 런타임, 백엔드 및 DB.

## 5. 검증 조건

1. 기본 `overview` 화면에서 `시작하기`만 `aria-expanded=true`이고 기본 메뉴에는 해당 그룹 문서만 표시된다.
2. 그룹 제목을 누르면 그 그룹 첫 문서 본문이 표시되고, 해당 그룹만 펼쳐지며 첫 문서가 활성 상태다.
3. 문서 항목을 선택하면 그 문서 그룹이 유일하게 펼쳐진다.
4. 검색 결과가 있는 여러 그룹의 매칭 문서가 모두 보이고 검색어에 맞는 API 결과도 기존대로 이동한다.
5. `npm run test -- tests/f1-grid-docs.test.tsx`와 `npm run build`가 성공한다.
6. 실제 브라우저 1280px/375px에서 그룹 제목 이동과 검색을 확인하고 페이지 전체 가로 overflow가 없는지 검증한다.
