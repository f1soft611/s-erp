# 20261014_001 공지 피드 이전 댓글 완료 시 버튼 숨김 상세 사양서

## 사용자 동작

- 이전 댓글이 남아 있으면 기존 이전 댓글 보기 버튼을 사용할 수 있다.
- 이전 댓글 조회가 완료되어 남은 댓글 수가 0이면 이전 댓글 보기 버튼과 문구를 숨긴다.
- 조회가 진행 중일 때는 기존 로딩 레이블과 비활성 상태를 유지한다.

## 표시 조건

`FeedCommentsSection`은 기존 `showPrevious` 조건을 기본으로 따른다. 단, `remainingPreviousCount`가 유한한 0 이상 숫자이고 그 값이 0인 경우에는 조회 중이 아닐 때 버튼을 숨긴다.

| 남은 댓글 수 | 조회 상태 | 이전 버튼 |
|---|---|---|
| 0 | 대기/완료 | 숨김 |
| 0 | 조회 중 | 로딩 문구로 표시 |
| 1 이상 | 대기/완료 | `이전 댓글 보기 (N)` 표시 |
| 미전달/유효하지 않음 | 대기/완료 | 기존 `이전 댓글 보기` 표시 여부와 문구 유지 |

## 호환성 및 제외 범위

- `showPrevious`의 기존 의미와 호출 계약을 유지한다.
- 댓글 카운트 산출, 페이지 조회, 커서/exhausted 상태, API 및 DB는 변경하지 않는다.
- 카운트를 알 수 없는 기존 화면을 추측으로 숨기지 않는다.
- 전자결재 등 공통 섹션의 모든 호출부에 0건 완료 규칙을 일관되게 적용한다.

## 회귀 검증

- 0건이고 이전 버튼 표시 조건이 true일 때 버튼이 렌더링되지 않는다.
- 양수 카운트 레이블과 숫자가 없는 기본 레이블이 유지된다.
- 로딩 중 기존 로딩 문구 및 disabled 동작이 유지된다.
- 공지사항 및 전자결재 이전 댓글 페이지네이션 회귀 테스트와 빌드가 통과한다.
