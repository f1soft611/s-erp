## 표시 계약

1. 적용 대상은 공통 `F1GridColumn.type: 'date'`다. 문서현황의 결재신청일과 최종 변경일도 별도 renderer 없이 적용된다.
2. `format`이 없으면 `yyyy-mm-dd`다. 빈 형식 문자열도 기본 형식으로 처리한다.
3. 지원 날짜 토큰: `yyyy`/`YYYY`(4자리 연도), `yy`/`YY`(2자리 연도), `mm`/`MM`(2자리 월), `m`/`M`(월), `dd`/`DD`(2자리 일), `d`/`D`(일). 대괄호로 감싼 문자열은 리터럴이다.
4. 예시: `yyyy/mm/dd` → `2026/10/20`, `dd.mm.yyyy` → `20.10.2026`, `yyyy년 m월 d일` → `2026년 10월 20일`.
5. ISO 날짜 및 timestamp 문자열은 날짜 부분을 검증해서 표시한다. 시간대 오프셋이 있어도 문자열에 명시된 날짜를 유지한다. 8자리 `yyyymmdd` 날짜와 유효한 `Date` 객체도 지원한다.
6. `null`, `undefined`, 빈 문자열은 빈 셀로 표시한다.
7. 잘못된 날짜는 임의 보정하거나 `Invalid Date`로 바꾸지 않고 기존 표시 규칙대로 원문을 유지한다. 데이터 검증 정책을 새로 추가하지 않는다.
8. 날짜 원본과 편집/검색 값은 변경하지 않는다. `datetime`, `time`, 숫자 컬럼의 기존 표시와 사용자 `renderCell` 우선순위를 유지한다.
9. 기존 공통 표시 함수 호출을 유지하여 셀, 자동 너비 계산, Excel 텍스트 출력에 같은 형식을 적용한다. 클립보드 원본값 정책은 바꾸지 않는다.

## 검증

- 기본/지정 형식, 대소문자 토큰, ISO timestamp 및 시간대 경계, 윤년/잘못된 날짜, 빈 값, 원본/편집값 보존.
- 문서현황 결재신청일/최종 변경일의 기본 날짜 표시.
- 기존 숫자 형식 및 datetime/time 표시 회귀 확인.
- TypeScript 및 Vite 빌드, 375/768/1280px 실제 브라우저 확인과 스크린샷.

## 제외 범위

백엔드, API 데이터 계약, DB, 날짜 검색/편집 형식 변경, datetime/time format 확장은 포함하지 않는다.
