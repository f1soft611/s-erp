# 20261001_002 공통 상세 검색 구분선 사양서

## 화면 동작

- `PageSearchArea` 상세 검색 오버레이에서 필드 그리드 바로 아래, 하단 액션 버튼 그룹 바로 위에 수평 구분선을 표시한다.
- 구분선은 오버레이 콘텐츠 전체 폭을 차지하며 MUI 테마의 divider 색상을 사용한다.
- 구분선 전후 간격은 기존 필드-액션 간격과 어울리게 유지한다.
- 초기화, 조회, 닫기 버튼의 순서, 우측 정렬, 동작 및 loading 비활성화는 변경하지 않는다.
- 상세 검색 오버레이가 닫혀 있을 때에는 구분선을 렌더링하지 않는다.

## 검증 기준

- 상세 오버레이가 열리면 `separator` 역할의 수평 구분선이 존재한다.
- 기존 상세 검색 상호작용 테스트와 프론트엔드 빌드 결과를 확인한다.
