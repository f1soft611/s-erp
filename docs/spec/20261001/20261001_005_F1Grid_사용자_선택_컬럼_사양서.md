# 20261001_005 F1-Grid 사용자 선택 컬럼 상세 사양서

## 1. 목적과 범위

F1-Grid에 사용자 전용 컬럼을 추가해 일반 그리드 셀 편집과 rowFormPlugin 모달에서 공용 사용자 선택 UI를 제공한다. 첫 적용은 `/co/workflow/form`의 검토자, 승인자, 담당자다. 승인 설계는 [설계 문서](../../superpowers/specs/2026-10-01-f1-grid-user-selector-design.md), 작업 범위는 [작업지시서](../../directions/20261001/20261001_005_F1Grid_사용자_선택_컬럼_작업지시서.md)를 기준으로 한다.

## 2. 공개 컬럼 계약

```ts
export type F1GridUserOption = {
  value: string | number;
  label: string;
  avatarUrl?: string | null;
  positionName?: string | null;
  departmentName?: string | null;
};
```

- `F1GridEditorType`에 `user`를 추가한다.
- `F1GridColumn.userOptions?: F1GridUserOption[]`에 선택 후보를 전달한다.
- `column.form?.multiple`이 true이면 다중, 아니면 단일 선택이다.
- `required`, `form.readOnly`, `editable`, 기존 `validate` 동작을 따른다.
- `onValueChange`는 ID 값만 받아 페이지 필드 patch를 만들며 사용자 표시 메타데이터를 행 데이터에 복사하지 않는다.
- 단일 선택 값은 `string | number | null`, 다중 선택 값은 `(string | number)[]`다. 기존 페이지가 숫자 단일 login ID와 문자열 다중 user ID를 사용하므로 원래 타입을 보존한다.
- 단일 해제 결과는 `null`, 다중 해제 결과는 `[]`다.

## 3. 사용자 선택 UI

- 선택기는 그리드 셀 편집과 `GridFormField`에서 동일 컴포넌트를 사용한다.
- 입력에서 이름, 직급, 부서를 검색한다. 검색 결과가 없을 때 빈 결과를 구분해 표시한다.
- 각 후보는 프로필 아바타, 이름, 직급, 부서를 표시한다. `avatarUrl`이 없거나 로드되지 않으면 이름 이니셜 아바타를 표시한다. 직급/부서가 비어 있으면 해당 보조 텍스트만 생략한다.
- 단일은 한 후보를 고르면 편집 완료 상태로 반영한다. 기존 선택을 지우는 명시적 해제 동작을 제공한다.
- 다중은 선택 후 목록을 닫지 않아 연속 선택할 수 있고, 선택된 값은 칩으로 보여 칩을 제거해 해제한다.
- 셀 표시 상태는 단일 선택 이름, 다중 선택 이름 요약을 표시한다. 컬럼 `renderCell`이 제공되면 기존의 화면별 요약을 우선한다.
- 팝업은 anchor/viewport 폭 안에서 표시하고 후보 목록 내부만 스크롤되게 한다. 375px 너비에서도 화면 밖으로 잘리지 않는다.
- read-only면 입력/삭제/선택을 차단한다. validation error는 기존 form helper text와 `aria-invalid` 흐름을 유지한다.

## 4. 편집값과 dirty 계약

- 단일 편집 초깃값은 현재 scalar ID, 다중 초깃값은 ID 배열이다.
- multi draft 배열은 선택 이벤트마다 업데이트한다. 최종 commit 시 각 ID를 `userOptions[].value`와 문자열 비교해 원래 옵션 값 타입으로 복원한다.
- 단일도 선택한 옵션의 원래 값 타입을 복원한다.
- `column.onValueChange` 결과 patch를 적용한다. 결과 ID와 기존 값이 같으면 행 상태/dirty cell을 변경하지 않는다.
- Escape/취소로 편집을 종료하면 draft만 버리고 행 데이터는 바꾸지 않는다.
- 행 폼 모달은 기존 `GridFormModel`의 editable/hidden/readOnly 필터를 따르고, 선택 확정 때만 `onPatch`를 호출한다.

## 5. 기안양식 사용자 API 계약

`GET /api/v1/co/workflow/forms/users`의 `result.resultList[]` 필드는 다음과 같다.

| 필드           | 타입             | 의미                                      |
| -------------- | ---------------- | ----------------------------------------- |
| `userId`       | number           | 담당자 저장값으로 사용할 사용자 ID        |
| `loginId`      | number           | 검토자/승인자 저장값으로 사용할 로그인 ID |
| `userNm`       | string           | 표시명                                    |
| `departmentNm` | string 또는 null | 부서명                                    |
| `profileImage` | string 또는 null | 로그인 계정 프로필 이미지 값              |
| `levelNm`      | string 또는 null | 활성 `LEVEL` 공통코드 항목명              |

- 인증 사용자의 `tenantId`를 사용하고 tenant 파라미터를 받지 않는다.
- 활성 `tb_user` 및 연결된 활성 `tb_login_account`만 반환한다.
- `tb_login_account.profile_image`를 선택한다. `tb_user.level_id`는 같은 tenant의 활성 `tb_common_code_item` 및 활성 `tb_common_code_group.group_code='LEVEL'`에 연결한다.
- 부서, 프로필, 직급은 left join/nullable 값으로 다루어 값 누락 때문에 사용자 자체가 누락되지 않는다.
- DDL/데이터 변경, 다른 endpoint, 저장 payload 변경은 없다.

## 6. 기안양식 매핑

- 검토자: `type: 'user'`, `userOptions[].value = loginId`, single, empty => null.
- 승인자: `type: 'user'`, `userOptions[].value = loginId`, single, empty => null.
- 담당자: `type: 'user'`, `userOptions[].value = userId`를 문자열로 정규화, `form.multiple = true`, 결과를 기존 `assigneeIds: string[]`로 변환.
- 표시 메타는 사용자 이름/직급/부서로 만든다. 담당자 셀의 기존 요약(`assigneeSummary`) 표현을 유지한다.
- `DraftFormGrid.onBeforeEdit`에서 담당자 필드만 막던 조건을 제거한다.
- 사용자 API 옵션 정규화는 null-safe이고 기존 ID 필드 계약을 유지한다.

## 7. 검증 및 완료 조건

- 단위/컴포넌트 테스트: 사용자 셀 단일·다중 선택, 원래 ID 타입 보존, 표시명, 미변경 dirty 없음, 취소/해제, 검색, 사진 대체 아바타, 직급/부서 누락.
- 폼 모달 테스트: 신규/수정의 scalar/array 복원, readOnly, required/error, 선택 칩 제거.
- 기안양식 테스트: API 응답의 추가 필드 정규화, 세 컬럼 타입/옵션, 담당자 편집 가능, 기존 payload ID 보존.
- Backend 테스트: controller JSON에 profileImage/levelNm 직렬화, 기존 인증 tenant forwarding 유지, MyBatis mapper SELECT statement 로드.
- 검증 명령은 작업지시서/계획서에 기재된 focused Vitest, frontend build, focused Maven tests, full Maven test를 사용한다.
- 브라우저 375/768/1280px에서 셀/폼 모달, 팝업 내부 스크롤 및 viewport clipping을 확인하고 `docs/result/20261001/f1-grid-user-selector/screenshots/`에 저장한다.
