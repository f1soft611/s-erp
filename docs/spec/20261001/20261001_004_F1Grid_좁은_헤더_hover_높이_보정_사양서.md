# F1-Grid 좁은 헤더 hover 높이 보정 사양서

## 요구 동작

- 좁은 컬럼에서 헤더 텍스트는 한 줄로 유지한다.
- 사용 가능한 폭보다 제목이 길면 제목 영역 안에서 말줄임표로 표시한다.
- hover/focus에 따라 컬럼 메뉴 버튼이 나타나는 현재 동작 및 배치를 유지한다.
- 메뉴 표시를 위한 우측 여백 변화가 헤더 제목의 줄바꿈이나 공용 헤더 행 높이 증가를 일으키지 않아야 한다.
- 헤더의 기존 `aria-label`은 생략되지 않은 전체 제목을 제공한다.

## 원인 및 제어 경로

`GridHeader.tsx`의 헤더 콘텐츠는 기본 상태에서 hover/focus보다 더 넓은 가용 너비를 갖고, hover/focus 때 메뉴 버튼을 위해 우측 여백이 추가된다. 헤더 행은 높이를 고정하지 않아 제목 줄바꿈이 발생하면 행 높이도 증가한다. 제목의 텍스트 노드만 한 줄 말줄임 처리하여 폭 변화가 세로 레이아웃에 영향을 주지 않도록 한다.

## 검증 기준

- Vitest에서 긴 헤더명의 표시 요소에 `white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`가 적용되고 columnheader 접근성 이름에 전체 제목이 남는지 검증한다.
- 실제 브라우저에서 좁은 헤더 hover 전후 헤더 행 높이가 동일하고 컬럼 메뉴 버튼을 열 수 있는지 확인한다.
- 기존 헤더 메뉴 테스트와 프론트엔드 빌드가 통과한다.

## 범위 제외

컬럼 너비, 헤더/행 높이 설정, 메뉴 표시 정책, 화면별 컬럼 정의와 API 계약은 변경하지 않는다.
