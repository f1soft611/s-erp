# 20261001_006 F1-Grid 저장 키 누락 보완 상세 사양서

## 범위

`frontend/src/pages` 및 `frontend/src/shared/components` 내 실제 JSX의 `F1Grid`/`F1Tree` 호출부만 대상이다. 그리드 컴포넌트의 라이브러리 내부 구현과 문서 코드 예제 문자열은 제외한다.

## 동작 계약

- `storageKey`는 브라우저 로컬 컬럼 레이아웃 저장소의 식별자이므로 실제 그리드 인스턴스마다 고유하고 안정적이어야 한다.
- 기존 키는 바꾸지 않는다. 신규 키는 페이지/기능과 그리드 목적을 식별하는 문자열을 사용한다.
- 공용 플레이그라운드에서 `kind`에 따라 컬럼 구성이 달라지는 인스턴스는 `kind`를 키에 포함해 설정이 서로 섞이지 않도록 한다.
- 저장 동작 자체, 기본 레이아웃, 데이터/행 상태는 변경하지 않는다.
- F1-Grid 문서에 키가 고유해야 하는 이유와 키 미지정 시 저장되지 않는 기존 동작을 명시한다.

## 검증 기준

- 소스 AST 검사가 `F1Grid` 및 `F1Tree` 호출부마다 `storageKey`가 있는지 확인한다.
- AST 검사에서 중복 키 값 또는 동일 키 표현식이 발견되지 않는다.
- 집중 Vitest와 프론트엔드 빌드가 성공한다.
