# Java 8 호환 개발 지침 상세사양

근거: [계획서](../../plan/20261102/20261102_010_Java8호환개발지침_계획서.md).

- 신규·수정 Java 운영 코드는 Java 8 문법과 표준 API 범위에서 작성한다.
- Java 9+ API와 문법을 사용하지 않는다. 예: `List.of`, `Set.of`, `Map.of`, `List.copyOf`, `String.isBlank`, `String.repeat`, `Stream.toList`, `var`, record, text block, switch expression.
- 컬렉션·문자열 처리는 Java 8 API 또는 기존 호환 라이브러리를 사용하며, 불변성·null·공백 처리 등 기존 의미를 보존한다.
- 의존성 추가·업데이트 시 Java 8 지원 여부를 확인한다. 호환성 확보를 이유로 JDK·배포 환경·컴파일 타깃을 임의 상향하지 않는다.
- 개발·테스트 도구용 Java 17+ 안내와 운영 코드의 Java 8 호환성은 구분한다.
- `source/target=1.8`만으로 최신 JDK API 사용을 검출할 수 없음을 명시한다. Java 변경 시 관련 Maven 테스트와 별도로 JDK 9+의 `javac --release 8` 또는 JDK 8 컴파일 등 API 호환 검증을 수행한다.
- 검증하지 못한 범위는 결과에 명시하고, 최신 JDK 테스트 통과만으로 Java 8 운영 호환성을 단정하지 않는다.
