# 검색 빈값 표시 상세사양서

근거: [계획서](../../plan/20261102/20261102_006_검색_빈값_표시_계획서.md).

- 상단 검색 폼만 적용한다. 결과 페이지 재검색 폼의 안내 메시지는 유지한다.
- 상단의 잘못된 길이 제출: error=true, aria-invalid=true, 빨간 테두리. helperText는 렌더링하지 않는다. URL 이동/API 요청 없음.
- 입력을 변경하면 기존처럼 error를 해제한다.
- 길이 검증 자체, 실제 조회 오류, `/search` 직접 진입 안내는 유지한다.
- 폼 외부 여백이 오류 문구 때문에 늘어나지 않게 한다.
- 기존 검색 UI 결과 문서에 후속 결과 및 각 너비 스크린샷을 보관한다.
