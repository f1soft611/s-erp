# 통합검색 전용 페이지 상세사양서

근거: [작업지시서](../../directions/20261102/20261102_005_통합검색_전용페이지_작업지시서.md), [계획서](../../plan/20261102/20261102_005_통합검색_전용페이지_계획서.md).

## 결정

상단 입력+전용 페이지를 채택한다. 모달 확대는 긴 결과 비교에 불리하고, 유형별 별도 페이지는 전체 결과의 맥락을 나누므로 채택하지 않는다. 첨부 화면의 정보 계층을 참고하되 기존 ERP 테마와 레이아웃을 유지한다.

004 사양의 API/권한/검색 범위는 그대로다. 화면과 상태 규칙 중 모달/닫기 초기화만 아래로 대체한다. 추가 서버·DB 변경이 없어 새로운 MCP 조회나 SQL 스크립트는 필요하지 않다.

## 진입 및 경로

- 로그인된 공통 `/search` 경로. 기존 ERP 헤더/사이드바를 유지하며 본문에 통합검색 결과 페이지를 렌더링한다.
- `/search?keyword={trim한 검색어}&type={ALL|MENU|DOCUMENT|NOTICE}&page={1부터 시작}`.
- 헤더 우측 상단에 항상 검색 입력과 검색 아이콘 버튼을 표시한다. 2~100자 검증 후 Enter/버튼으로 이동한다. 잘못된 검색어는 입력 필드에서 안내하며 이동하지 않는다.
- 검색 페이지에도 재검색 필드를 제공한다. 새 검색은 ALL/1페이지로 이동한다. 유형/더보기 이동은 해당 유형/1페이지, 페이지 이동은 현재 검색어·유형을 유지한다.
- query를 상태의 근거로 사용하여 직접 진입/새로고침/뒤로가기 시 검색어·유형·페이지를 복원한다. 잘못된 검색어/유형/페이지 URL은 조회하지 않고 안내한다. 최대 page=1001(offset=10000), ALL은 page=1만 허용한다.
- `/search/` 직접 진입도 동일하게 처리한다. 같은 검색어를 다시 제출하면 history state의 새 요청 키로 결과를 갱신한다. 유형/페이지 이동은 해당 요청 키를 유지해 전체 집계를 불필요하게 반복 조회하지 않는다.
- 공통 검색 페이지는 DB 메뉴가 아니며 별도 메뉴 등록을 요구하지 않는다. 다른 모듈의 기본 메뉴 이름으로 헤더가 표시되거나 최근 메뉴/즐겨찾기에 검색 경로가 잘못 기록되지 않게 한다.

## 결과 및 가독성

- 상단에 검색어와 전체 결과 건수를 표시한다. 전체/메뉴/문서/공지 탭에 각 집계 건수를 표시한다.
- 전체는 각 유형별 제목·건수·최대 5개 결과·더보기다. 개별 유형은 페이지당 10개와 이전/다음 및 현재 페이지를 제공한다.
- 전체 집계는 검색어가 바뀔 때 조회하고, 개별 페이지는 현재 유형/페이지로 조회한다. 기존 API를 사용해 개별 페이지에서도 다른 유형 건수를 유지한다.
- 결과 제목을 굵게, 메뉴 breadcrumb 또는 문서번호/기안자·공지 작성자를 보조 텍스트로 표시한다. 제목에서 검색어와 일치하는 텍스트를 대소문자 무시 강조한다. HTML 삽입은 하지 않는다.
- 원래 API의 내부 이동 경로만 사용한다. 외부 URL, 이중 slash, backslash, 제어문자 경로는 차단한다.
- 조회 중 이전 조건의 결과/건수를 숨긴다. 검색 전 안내, 잘못된 조건, 전체/유형별 빈 결과, 로딩, 오류/재시도를 구분한다. 실패를 0건 성공으로 표시하지 않는다.
- effect cleanup으로 이전 조건 및 unmount 이후 응답을 무효화한다.
- 검색어/제목/설명은 줄바꿈하며 넓이 고정을 피한다. 탭은 작은 화면에서 줄바꿈하고 헤더 검색 필드는 모바일에서도 직접 노출한다.
- 탭은 방향키/Home/End로 이동하며 현재 탭만 Tab 순서에 포함한다.

## 검증

필드 진입/검증, API 파라미터 유지, URL/뒤로가기 복원, 전체/유형별 집계, 더보기/페이지, 새 검색 초기화, 오류/재시도, 응답 경쟁, 내부 경로 차단, 375/768/1280px 실제 브라우저 가로 overflow 및 전체 앱 인증 경로 통합을 확인한다.

## 비범위

추천/인기 검색어, 정확도, 결과 내 재검색, 검색 기록, 추가 대상, 서버 검색엔진, API/SQL/스키마 변경은 포함하지 않는다. 공지 본문/날짜 등의 새 응답 필드는 만들지 않는다.
