# 쪽지 이모지 응답 오류 상세사양서

- 공통 `HtmlCharacterEscapes.getEscapeSequence`는 별도 escape가 없는 문자에 null을 반환해 Jackson의 기본 Unicode 처리를 사용한다. 기존 ASCII JSON escape 설정을 유지하며 HTML escape 정책을 새로 추가하지 않는다.
- 정상 supplementary character와 ZWJ/skin tone/한글/따옴표/개행이 UTF-8 JSON 왕복에서 보존되어야 한다.
- 쪽지 알림 summary는 기존처럼 497 UTF-16 units를 넘어가면 줄임표를 붙인다. 497 경계가 surrogate pair 사이면 앞쪽 경계를 한 칸 줄인다. 본문은 변경하지 않는다.
- DB/SQL/API 필드나 길이 계약은 변경하지 않는다. DB 행을 조회하거나 수정하지 않는다.
- UI 변경이 아닌 서버 응답 오류 수정이므로 프런트 스크린샷 대신 실제 converter 바이트 응답 회귀로 검증한다.
