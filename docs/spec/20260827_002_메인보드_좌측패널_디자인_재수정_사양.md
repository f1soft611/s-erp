# 20260827*002*메인보드*좌측패널*디자인*재수정*사양

## 1. 목적

메인보드 좌측 패널을 ERP형 시각 구조로 재정렬하여 사용자가 기능군과 세부 메뉴를 빠르게 이해할 수 있도록 한다.

## 2. 화면 요구사항

### 2.1 좌측 패널 구조

- 왼쪽에는 고정 폭의 모듈 아이콘 영역을 둔다.
- 오른쪽에는 모듈 선택 영역과 메뉴 트리 영역을 배치한다.
- 사용자 정보 영역은 하단에 유지한다.

### 2.2 모듈 영역

- 각 모듈은 아이콘과 텍스트를 함께 표시한다.
- 선택된 모듈은 강조 배경과 경계선을 갖는다.
- hover 상태는 약한 배경 변화로 구분한다.

### 2.3 메뉴 트리 영역

- 선택된 모듈의 그룹별 메뉴를 표시한다.
- 상위 메뉴는 강조 버튼, 하위 메뉴는 차등 색상으로 구분한다.
- 파일트리형 계층이 아닌 ERP 운영형 요약 구조로 정리한다.

## 3. 동작 요구사항

- 모듈 클릭 시 해당 모듈의 하위 메뉴가 즉시 갱신된다.
- 상위 메뉴 클릭 시 기본 하위 메뉴 선택이 자동 반영된다.
- 하위 메뉴 클릭 시 현재 선택 상태가 유지된다.

## 4. 검증 기준

- 페이지에 ERP SYSTEM 로고 텍스트가 표시된다.
- 모듈 선택 영역과 메뉴 트리 영역이 분리되어 보인다.
- 불필요한 Sales 항목이 노출되지 않는다.
- 브라우저에서 시각적으로 의도대로 보인다.

## 5. 비범위

- 서버 API 구조 변경
- 다른 페이지 전체 레이아웃 대수정
- 메뉴 데이터 구조 대대적 리팩터링
