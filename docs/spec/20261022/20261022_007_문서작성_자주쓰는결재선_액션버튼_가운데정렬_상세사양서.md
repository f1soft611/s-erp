## 2. 화면 및 동작

- 대상은 업무작성 결재선 설정 내 `자주 쓰는 결재선` 관리 Grid의 액션 열이다.
- 각 행의 `적용`/`삭제` 버튼을 하나의 그룹으로 유지하고 그 그룹을 액션 셀 가로 중앙에 배치한다.
- 버튼 그룹 컨테이너는 셀의 전체 폭을 사용하고 내부 콘텐츠를 중앙 정렬한다.
- MUI 버튼 기본 최소 너비를 해제하고 좌우 패딩을 줄여 두 버튼 그룹이 액션 열 안에 들어오게 한다.
- 액션 열 너비 110px, 우측 고정, 버튼 순서·높이·색상·기능은 유지한다.
- 행별 적용·삭제 처리 및 비활성화 로직은 변경하지 않는다.

## 3. 반응형 및 비범위

- 375px, 768px, 1280px에서 버튼이 잘리거나 페이지 전체 가로 넘침을 만들지 않는지 확인한다.
- 팝업 하단 버튼, 공통 F1-Grid 셀 동작, Grid 열 너비, API 및 데이터 구조는 변경하지 않는다.

## 4. 검증 기준

- 관리 Grid 행 액션 그룹의 중앙 정렬과 각 버튼의 컴팩트한 가로 크기를 컴포넌트 테스트로 확인한다.
- 기존 행별 적용/삭제 버튼과 관련 설정 다이얼로그 테스트가 통과한다.
- 실제 브라우저 화면에서 지정한 뷰포트를 확인하고 결과 보고서에 캡처를 포함한다.
- 프론트엔드 빌드와 `git diff --check`가 통과한다.
