# 공통 상세검색 날짜 입력 상세 사양서

## 근거 및 범위

- [작업지시서](../../directions/20261022/20261022_003_grid_search_date_input_work_instruction.md)
- [구현 계획](../../plan/20261022/20261022_003_grid_search_date_input_plan.md)
- 사용자 승인: 공통 상세검색 전체에 기존 날짜 입력 기능을 재사용한다.
- 적용 대상은 `PageSearchArea`의 `type: 'date'` 시작일·종료일이다.
- 업무 화면별 별도 날짜 필드, datetime/time, 백엔드와 DB는 변경하지 않는다.

## 입력 및 확정

기존 `DateEditor.normalizeDateInput`을 재사용한다.

| 입력 | 확정 결과 |
| --- | --- |
| `20261022` | `2026-10-22` |
| `261022` | `2026-10-22` |
| `1022` | 현재 연도 `10-22` |
| `22` | 현재 연도·월의 22일 |
| `10-22` | 현재 연도 `10-22` |
| `2026-10-22` | 동일 |
| 빈 문자열 | 빈 문자열, 해당 endpoint 제한 없음 |

- 축약 입력의 현재 연도·월은 기존 셀 편집기와 동일하게 브라우저 로컬 날짜를 사용한다.
- 이는 수동 축약 입력의 해석 기준이다. 기존 서버 기준 검색 기본값 계산은 변경하지 않는다.
- 입력 중에는 미완성 문자열을 허용한다. blur 또는 조회 버튼에서 유효 날짜를 ISO로 확정한다.
- 조회 버튼 처리는 blur 발생 여부에 의존하지 않고 전체 날짜를 다시 검증한다.
- 달력 선택은 즉시 ISO 문자열로 반영하고 달력을 닫는다.
- 검색 폼은 자동 포커스를 강제하지 않고 기존 outlined 스타일, 시작일·종료일 label과 접근성 이름을 유지한다.
- 검색용 입력에는 `YYYY-MM-DD` placeholder와 숫자 키보드를 제공한다.
- 각 날짜 입력에 160px 확보가 어려우면 시작일·종료일을 세로로 배치한다. 상위 검색 필드의 span 및 그룹 계약은 변경하지 않는다.

## 검증과 오류

- 윤년과 월별 일수를 포함하여 실제 존재하는 날짜만 허용한다.
- `20260230` 등 잘못된 입력은 원문을 보존하고 해당 필드에 날짜 형식 오류를 표시한다.
- 날짜 오류가 있으면 조회 callback을 호출하지 않고 상세검색을 닫지 않는다.
- 유효하게 수정하거나 삭제하면 오류를 해제한다.
- 시작일과 종료일의 순서에 대한 새로운 제한은 추가하지 않는다.
- 입력 오류를 빈 문자열로 바꾸어 제한 없는 검색을 실행하지 않는다.

## 데이터 흐름과 기존 동작 보존

- `PageSearchFieldValue` 및 업무 페이지의 `{ from, to }` 계약은 변경하지 않는다.
- 날짜 입력 중 callback은 기존처럼 입력 draft를 전달할 수 있다. 실제 조회 callback은 검증·정규화된 값만 받는다.
- 입력 완료 시 변경 callback에도 정규화된 값을 반영한다.
- 외부에서 전달된 기본값과 세션 복원 ISO 날짜는 그대로 표시한다.
- 초기화는 기존 defaultValues를 복원하고 입력 오류를 해제한다.
- 초기화만으로 자동 조회하지 않는 기존 공통 동작 및 선택적 reset callback을 유지한다.
- 기존 F1-Grid 셀 편집기의 기본 props, 스타일, 키보드 처리, 자동 포커스 및 날짜 정규화 계약을 유지한다.

## 검증 기준

- 시작·종료 독립 입력과 한쪽만 지정한 검색, 양쪽 삭제.
- 각 축약 입력 형식, ISO, 윤년 유효/무효 및 존재하지 않는 날짜.
- blur 없이 조회하는 경우에도 ISO만 전달.
- 오류 시 조회 차단 및 패널 유지, 수정·삭제·초기화 후 오류 해제.
- 달력 열기·선택, 기존 날짜 기본값과 외부 값 변경 반영.
- 셀 날짜 편집과 기존 공통 검색 회귀 테스트.
- 실제 브라우저 375px, 768px, 1280px에서 입력 및 달력 사용 가능, 입력/아이콘 겹침 없음.
- 관련 Vitest, TypeScript/Vite build, 수정 파일 진단, `git diff --check`.
