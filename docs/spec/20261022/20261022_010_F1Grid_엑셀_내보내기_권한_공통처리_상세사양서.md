# F1Grid 엑셀 내보내기 권한 공통 처리 상세 사양서

## 근거

- [작업지시서](../../directions/20261022/20261022_010_F1Grid_엑셀_내보내기_권한_공통처리_작업지시서.md)
- [계획서](../../plan/20261022/20261022_010_F1Grid_엑셀_내보내기_권한_공통처리_계획서.md)
- 사용자는 모든 엑셀 내보내기 화면에 동일한 엑셀 권한 기준을 적용하고, 권한이 없을 때 메뉴를 숨기는 방식을 승인했다.

## 권한 표시 계약

| 페이지 권한 | `canExportExcel` | 컨텍스트 메뉴 |
|---|---:|---|
| 엑셀 권한 있음 | `true` | 엑셀 내보내기 표시 및 기존 실행 허용 |
| 엑셀 권한 없음 | `false` | 엑셀 내보내기 미표시 |
| 권한 정보 없음 | `false` | 엑셀 내보내기 미표시 |

- 공통 F1Grid는 인증 컨텍스트를 직접 읽지 않는다. 페이지에서 결정한 권한을 `canExportExcel` prop으로 전달한다.
- 기존 `F1GridProps.canExportExcel?: boolean` 계약과 기본값 `false`를 유지한다.
- F1Tree 역시 F1Grid props의 권한 값을 받아 트리 컨텍스트 메뉴에 동일하게 적용한다.
- 서버 측 권한 검사, Excel 생성 방식, 나머지 컨텍스트 메뉴의 표시 조건은 이 변경의 대상이 아니다.

## 페이지별 데이터 전달

1. 문서현황: `selectedMenuPermissions?.excel ?? false`를 `DocumentStatusPage`에서 `DocumentStatusGrid`까지 전달한다.
2. 기안양식: `DraftFormManagementPage`가 전달한 기존 `pagePermissions.excel`을 `DraftFormGrid`에서 F1Grid로 전달한다.
3. 자료실 파일 트리: `ArchiveBoardPage`의 `selectedMenuPermissions?.excel ?? false`를 `ArchiveFileGrid`의 F1Tree로 전달한다.
4. 이미 페이지 권한에서 `canExportExcel`을 전달하는 거래처/자재/창고/메뉴/역할/모듈/공통코드 화면은 기존 구현을 유지한다.
5. 엑셀 내보내기를 명시적으로 비활성화한 화면 및 F1Grid 문서 데모는 그대로 둔다.

## 검증 시나리오

- 문서현황: 권한이 true면 엑셀 메뉴를 표시하고, false 또는 undefined면 표시하지 않는다.
- 기안양식: `canExportExcel=false`일 때 메뉴 항목을 렌더링하지 않고, true일 때 렌더링한다.
- 자료실: 엑셀 권한이 있는 사용자에게 메뉴를 표시하고, 없는 사용자에게 숨긴다. 자료실의 다른 우클릭 메뉴와 행위는 유지한다.
- 기존 엑셀 내보내기 테스트, 세 화면의 관련 테스트, 프론트엔드 빌드가 통과한다.
- 실제 브라우저 검증은 합성 데이터만 사용한다. 권한별 메뉴의 표시 여부를 확인하고 스크린샷은 날짜별 결과 폴더에 기록한다.

## 제외

- 사용자 권한을 위한 신규 상태 관리, context, hook 또는 공통 권한 API
- 백엔드, API, DB, 스키마 변경
- Excel workbook 내용, 파일명, 필터/정렬 및 다운로드 성능 변경
