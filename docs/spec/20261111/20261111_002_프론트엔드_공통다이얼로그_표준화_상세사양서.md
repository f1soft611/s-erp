## 공통 셸 계약

- 모든 일반 MUI 다이얼로그는 `CommonDialog`를 사용한다.
- `CommonDialog.tsx`만 MUI `Dialog`를 직접 렌더링하는 기반 구현으로 남긴다.
- 너비 옵션:

| 크기 | 최대 너비 | 주 사용 |
|---|---:|---|
| `xs` | 480px | 확인/삭제/간단 입력 |
| `sm` | 600px | 폼/선택기 |
| `md` | 820px | 넓은 폼/이력 |
| `lg` | 990px | 큰 편집/이미지 보기 |
| `xl` | 1200px | 기존 대형 이미지 보기 |

- `titleId`가 전달되면 제목과 다이얼로그의 `aria-labelledby`에 함께 적용하고, 없으면 고유 ID를 생성한다.
- 닫기 버튼의 접근성 이름은 `closeButtonLabel`로 지정할 수 있으며 기본값은 `닫기`이다.
- 호출자는 기존 닫기 가드를 `onClose`에서 유지한다. 확인 액션과 닫기 버튼의 활성 상태는 기존 조건을 따른다.

## 전환 대상

- 대시보드 즐겨찾기 폴더 생성/이름 변경
- F1-Grid 시간 선택 및 테스트 품목 선택
- 역할 관리 사용자 추가와 미저장 확인
- 시스템 정책 삭제/이력 및 정책 편집/미저장 확인
- 자료실 상위 코드 선택, 삭제 확인, 파일 편집
- 알림 읽음 항목 정리
- 문서 결재 취소/삭제, 참조자 추가, 문서 작성·설정 중 확인
- 이미지 뷰어

기존 다이얼로그의 제목, 설명, 데이터 선택/입력 콘텐츠, 버튼 라벨과 순서, 핸들러, 처리 중 비활성화, 오류 표시, 취소 및 닫기 조건은 유지한다. 공유 `UnsavedChangesConfirmDialog`는 기존 API를 유지하고 내부 렌더링만 `CommonDialog`로 전환한다.

## 비범위

- `Popover`, `Menu`, `Drawer`, 툴팁 및 인쇄용 포털
- MUI `Dialog`를 렌더링하는 `CommonDialog.tsx` 자체
- 업무 상태 전이, API 응답, 서버 및 데이터베이스

## 검증 기준

- 새 크기와 접근성 props를 공통 컴포넌트 테스트로 검증한다.
- 공유 미저장 확인창 테스트에서 continue/cancel 순서, 라벨, disabled, custom title ID 및 닫기 콜백을 확인한다.
- 기존 기능별 테스트에서 폼 저장, 삭제, 선택, 확인, 취소 및 에러 표시가 유지되는지 확인한다.
- `rg "<Dialog\\b" frontend/src` 결과가 `CommonDialog.tsx`만 반환한다.
- 전체 Vitest와 프론트엔드 빌드가 통과한다.
- 실제 브라우저에서 375px, 768px, 1280px 뷰포트의 대표 확인·폼·특수 콘텐츠를 확인하고 결과에 기록한다.
