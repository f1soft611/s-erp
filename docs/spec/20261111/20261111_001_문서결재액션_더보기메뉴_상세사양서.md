## 메뉴 동작

- 피드 및 상세 툴바에서 승인, 반려, 보완요청, 최종확인, 참조 확인, 상신 취소, 승인 취소 버튼을 직접 표시하지 않는다.
- `문서 더보기` 선택 시 현재 사용자 권한과 문서 상태에 따라 실행 가능한 결재 액션만 메뉴 첫 그룹에 표시한다.
- 첫 그룹 내 순서는 기존 툴바 순서를 유지한다: 승인, 반려, 보완요청, 최종확인, 참조 확인, 상신 취소, 승인 취소. 조건에 해당하지 않는 항목은 숨긴다.
- 결재 액션이 하나 이상이면 그 다음 공유·참조 그룹 앞에 구분선을 표시한다.
- 공유·참조 그룹은 문서 공유하기, 참조자 추가하기 순이며 참조자 추가는 기존 상태 조건을 따른다.
- 수정 또는 삭제 항목이 제공될 때 공유·참조 그룹과 수정·삭제 그룹 사이에 구분선을 표시한다. 수정 라벨은 기존처럼 문서 상태에 따라 문서 수정 또는 수정 후 재상신으로 구분한다.
- 선행 그룹과 후행 그룹 중 하나가 비어 있으면 해당 경계의 구분선을 생략한다.
- 메뉴 항목을 선택하면 메뉴를 닫고 기존 액션 함수를 호출한다.

## 동작 보존

- 결재 액션의 권한 및 상태 조건은 기존 `canProcess`, `canConfirmFinal`, `canConfirmReference`, `canCancelSubmission`, `canCancelApproval` 판정을 그대로 사용한다.
- `isActing` 상태에서 결재 액션 선택은 비활성화하며 기존 처리 중복 방지 동작을 유지한다.
- 승인 의견, 반려/보완요청 사유 팝업, 참조/최종 확인, 상신/승인 취소 확인 다이얼로그와 성공·오류·목록 갱신 흐름은 변경하지 않는다.
- 상태 배지, 문서 종류 배지, 상단 고정, 상세의 처리 의견 입력은 기존 위치와 동작을 유지한다.

## 검증

- 툴바에서 결재 액션 버튼이 없는지 확인한다.
- 메뉴 항목의 정렬, 조건별 구분선, 권한에 따른 항목 노출, 선택 후 메뉴 닫힘을 검증한다.
- 피드 및 상세에서 승인/반려/보완요청과 취소/확인 동작의 회귀 테스트를 실행한다.
- 프론트엔드 빌드 및 375px, 768px, 1280px 실제 브라우저 화면을 확인한다.
- 결과 문서에 변경 범위, 검증 결과 및 스크린샷 위치를 기록한다.
