- 기준 화면: 수주등록(`SalesOrderCreatePage`), 수주현황(`SalesOrderStatusPage`)

## 1. 메뉴

| 구분 | menu_code | menu_nm | menu_url | sort | 권한 |
| --- | --- | --- | --- | --- | --- |

| 화면 | `CO_WORK_STD_RECIPE` | 작업표준서 등록(레시피) | `/co/work-standard/work-standard-recipe` | 10 | READ, CREATE, UPDATE, DELETE |

## 2. 화면 구성 (데스크톱)

```
PageHeader(경로·설명 | 신규 · 저장 · 삭제)
PageSearchArea(통합검색 + 상세검색)            SearchResultMessage(조회 결과 n건)
┌ 작업표준서 목록 (lg 360px) ┐ ┌ 작업표준서 기본정보 + 등록/변경 이력 문구 [복사][버전 개정][샘플→양산 이관] ┐
│ 구분 칩: 전체/제품/반제품/샘플 │ │ 4열 입력 그리드 (16개 필드)                          │
│ F1Grid: 계정·품목명·버전·상태 │ │ Tabs: 배합비 n | 공정절차 | 포장 기준 | CCP·품질 기준 | 버전 이력 │
└───────────────────────┘ │ 배합비 툴바 + F1Grid + 합계                           │
                              └──────────────────────────────────────────┘
```

- 결과 메시지와 본문은 같은 세로 스크롤 영역에 두어 폭을 일치시키고, 메시지를 닫으면 본문 상단 여백을 복원한다. 좌우 패널 하단은 같은 높이로 맞춘다.

- `lg` 이상: 목록 360px + 상세 가변 2열. `lg` 미만: 목록 위, 상세 아래 1열. 페이지 전체 가로 스크롤 없음, 그리드는 내부 스크롤.

## 3. 검색

- 통합검색 placeholder: `품목코드/품목명/원료명 검색`, 엔터 또는 검색 버튼으로 적용.
- 상세검색 필드(select): 품목계정(제품/반제품/원료), 제품분류(생초콜릿/초콜릿/쿠키), 버전 상태(양산/샘플/폐기), 공정(용해/혼합가열/혼합믹서/성형). 모두 선택 사항.
- 목록 구분 칩(전체/제품/반제품/샘플)은 조회 결과 안에서 추가로 거른다. 샘플은 버전 상태 기준.
- 키워드는 품목코드·품목명·배합 원료명을 대소문자 무시 부분일치. 공정은 배합비 투입 공정 포함 여부.

## 4. 목록 F1Grid

- 컬럼: 계정(80) · 품목명(코드 포함 표시, flex) · 버전(60, 가운데) · 상태(72, 가운데, 칩).
- 읽기 전용, 체크박스·컨텍스트 메뉴 행 편집 없음, 행 선택 시 우측 상세 갱신. 최초 조회 시 첫 행 선택.

## 6. 배합비 탭

- 툴바: `원료 추가`(행 추가), `원료 선택`(선택 1행일 때 품목 picker), 투입량 기준 radio(`기준 생산량(n판)` / `1판 기준`), 안내 문구.
- F1Grid 컬럼 및 동작

| 컬럼 | field | type | 편집 | 계산 |

| 순서 | rowId | rownumber | | |

| 원료명/규격/단위 | | text | | |
