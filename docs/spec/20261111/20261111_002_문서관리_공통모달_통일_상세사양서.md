## 공통 표시 기준

- 문서관리의 일반 확인·입력 모달은 `CommonDialog`를 사용한다.
- `CommonDialog` 크기는 기존 모달의 목적과 너비를 유지한다.
  - `xs`: 최대 너비 480px, 일반 확인 모달
  - `sm`: 최대 너비 600px, 참조자 추가
  - `md`: 최대 너비 820px
  - `lg`: 최대 너비 990px
- 공통 닫기 버튼, Escape 및 바깥 영역 닫기는 각 모달의 기존 닫기 조건을 따른다. 작업 중인 경우 기존과 같이 닫기 동작을 막는다.

## 모달별 동작

| 모달 | 크기 | 내용/액션 | 보존 동작 |
|---|---:|---|---|
| 상단 고정/해제 확인 | xs | 고정 여부에 따른 제목·설명, `취소`와 `확인` | 처리 중 확인 비활성화, 확인 시 기존 pin 핸들러 |
| 문서 유형 변경 | xs | 기존 안내문, `취소`와 `이동` | 이동 확정/취소 콜백 및 초기화 동작 |
| 본문 교체 | xs | 기존 안내문, `취소`와 `교체` | 본문 교체 확정/취소 콜백 |
| 결재 템플릿 변경 폐기 | xs | 기존 안내문, `취소`와 `계속` | 폐기 확정/취소 콜백 |
| 결재 신청/승인 취소 | xs | 기존 상태별 제목·설명, 취소 실행/닫기 액션 | 처리 중 닫기 및 버튼 비활성화, 오류 메시지 |
| 문서 삭제 | xs | 기존 삭제 경고, 삭제/취소 액션 | 삭제 중 닫기 및 버튼 비활성화, 오류 메시지 |
| 참조자 추가 | sm | 사용자 다중 선택, 정보/오류 메시지, 추가/취소 액션 | 선택 변경, 제출 조건, 처리 중 닫기/비활성화 |

기존 `CommonDialog`를 사용하는 사유 입력, 작성/설정 본 모달은 변경하지 않는다. 이미지 뷰어와 팝오버는 특수 오버레이로 유지한다. 공유 `UnsavedChangesConfirmDialog` 및 다른 메뉴의 사용처는 수정하지 않는다.

## 검증 기준

- `CommonDialog` 테스트에서 새 `sm` 너비 600px 및 기존 크기 너비를 확인한다.
- 문서 작성·설정 테스트에서 각 확인창의 제목, 라벨, 닫기/취소/확정 흐름 및 처리 중 제한을 확인한다.
- 결재 취소/삭제와 참조자 추가에서 기존 오류·안내 메시지와 핸들러가 유지되는지 확인한다.
- 관련 Vitest와 `npm run build`를 실행한다.
- 375px, 768px, 1280px 브라우저에서 대표 확인 및 입력 모달을 확인하고 결과 문서에 화면을 기록한다.
