# 20261023_007 품목·거래처 저장 조용한 로딩 상세 사양

## 요구 동작

- 초기 목록 조회 및 사용자가 실행한 조회는 현재처럼 F1-Grid 전체 로딩을 표시한다.
- 저장 요청 및 저장 성공 후 목록 재조회 중에는 기존 Grid 행을 계속 표시하고 전체 로딩 오버레이를 표시하지 않는다.
- 저장 버튼은 기존 진행 아이콘과 비활성 상태를 유지한다. 저장 중 셀 편집 및 추가/저장 재실행 제한을 변경하지 않는다.
- 저장 완료 후 최신 목록 반영, 성공 알림, 저장 실패 메시지 및 저장 성공 후 재조회 실패 메시지는 현재 동작을 유지한다.
- API 요청, 응답, 데이터 변경은 없다.

## 구현 기준

- 거래처/품목 페이지의 Grid `loading` 입력은 관리 훅의 일반 조회 `loading` 상태만 사용한다.
- 관리 훅의 `saving` 상태는 페이지 액션 진행 아이콘 및 기존 편집/버튼 제어에만 계속 사용한다.
- 저장 도중 배치 API와 재조회 중 각각 Grid 오버레이가 나타나지 않는 페이지 수준 회귀 테스트를 둔다.

## 검증 기준

- 각 페이지에서 저장 요청이 보류된 동안 저장 진행 표시가 보이고 `f1-grid-loading-overlay`는 없으며 기존 행이 보인다.
- 저장 완료 및 목록 재조회가 끝난 뒤 저장 진행 표시는 사라지고 목록이 갱신된다.
- 최초 조회/명시적 조회의 Grid 로딩 동작과 저장 오류 표시를 보존한다.
- 거래처 및 품목 집중 테스트, 프론트엔드 빌드 및 브라우저 확인을 수행한다.
