# F1-Grid 편집 가능 헤더 상단 강조 사양서

> 최종 사양: 편집 가능 여부에 따른 헤더 강조선은 상단/하단 모두 표시하지 않는다. 다른 아이콘/배경/안내 문구를 추가하지 않는다. `data-editable-column` 판정 속성과 기존 그룹 divider, 고정/드롭 그림자, 셀 편집 테두리는 유지한다. 아래 상단 강조선 사양은 최초 구현 이력이며 이 최종 사양으로 대체한다.

## 표시 계약

- `data-editable-column="true"`인 헤더에만 테마 `primary.main`의 2px 상단 안쪽 그림자를 표시한다.
- CSS 표현은 `inset 0 2px 0 0 <primary.main>`이다. 실제 border를 추가하지 않으므로 헤더 높이/콘텐츠 배치에 추가 공간을 요구하지 않는다.
- 기존 하단 강조 border는 제거하고 일반 하단 경계 처리는 변경하지 않는다.
- 편집 가능 판정, editor plugin 조건, 행별 editable 조건은 그대로 유지한다.
- 그룹 헤더의 기존 상단 divider border는 유지한다. 강조선은 해당 컬럼 헤더 셀 안쪽에 표시한다.
- 고정 컬럼 좌우 그림자와 드롭 대상 그림자는 기존 값과 합성하여 유지한다.
- 정렬/필터/리사이즈/드롭 위치 표시의 DOM과 동작은 변경하지 않는다.

## 회귀 검증

- 편집 가능/읽기 전용 컬럼, 고정 컬럼, 그룹 헤더, 드롭 대상 상태의 computed style을 검증한다.
- 브라우저에서 실제 셀 편집 중에도 강조선이 헤더 상단에 있고 하단 강조는 없는지 확인한다.
- 375/768/1280px에서 페이지 가로 넘침 및 표시를 확인한다.
- 백엔드/DB 변경은 없으므로 DB MCP 확인과 SQL 생성은 대상이 아니다.
