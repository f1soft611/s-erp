# 20261023_008 기준정보·환경설정 조용한 저장 편집 잠금 상세사양서

## 목적 및 승인 범위

품목관리·거래처관리에서 확인한 저장 중 편집 차단 패턴을 기준정보와 환경설정의 나머지 관리 화면에도 적용한다. 2026-10-23 사용자는 기준정보·환경설정 메뉴만 대상으로 하고, 현재 대시보드 라우트에서 참조가 확인되지 않는 창고관리 화면도 포함하도록 승인했다.

적용 대상:

- 기준정보: 공통코드, 기안양식관리
- 환경설정: 권한관리, 메뉴관리, 모듈관리, 창고관리
- 품목관리·거래처관리: 직전 변경에서 같은 저장 중 잠금 패턴을 적용했으므로 회귀 기준으로 사용한다.

문서작성·공지·자료실 등 그룹웨어 화면, 프로필·보안 설정, F1-Grid 테스트/문서 화면은 범위에 포함하지 않는다.

## 동작 계약

1. 저장을 시작하면 저장 요청부터 저장 후 조용한 목록/패널 재조회 완료까지 저장 중 상태를 유지한다.
2. 저장 중 기존 목록은 그대로 표시한다. 조용한 재조회에 전체 Grid 로딩 오버레이를 표시하지 않는다.
3. 저장 중 추가, 중복, 삭제, 행/셀 편집, 행 폼 열기 및 폼 적용, 권한/메뉴 매핑 등 데이터 변경 조작을 차단한다.
4. 저장 중 검색·조회 또는 다른 역할/모듈/그룹으로 전환해 진행 중인 변경 대상이 바뀌는 조작을 차단한다.
5. 기존 저장 진행 표시와 저장 버튼 비활성화를 유지한다. 저장 중복 요청은 UI와 저장 경계 모두에서 차단한다.
6. 초기 진입 및 사용자가 직접 실행한 일반 조회의 기존 로딩 표현은 유지한다.
7. 저장 성공 후 갱신된 데이터가 표시되면 잠금을 해제한다. 저장 또는 조용한 재조회가 실패하면 기존 오류 전달 및 미저장 변경 보존 정책을 따르고, 저장 작업이 종료된 뒤 잠금을 해제한다.
8. 화면별 기존 권한, 삭제 정책, 검증, 알림, 변경 확인 대화상자 및 그리드 데이터 계약은 유지한다.

## 설계

- 각 페이지의 저장 상태를 해당 관리 패널까지 명시적 prop으로 전달하거나 이미 패널이 소유한 저장 상태를 이용한다.
- 각 패널은 저장 중임을 컬럼 편집 가능 여부, F1-Grid/F1-Tree 편집 게이트, 폼 플러그인, 추가·복제·삭제 메뉴, 보조 변경 대화상자에 반영한다.
- 페이지 액션은 저장 중 저장·조회·대상 전환을 비활성화한다.
- 공통 F1-Grid의 전역 동작이나 데이터/API 계약은 바꾸지 않는다. 해당 페이지에서 이미 동작하는 저장 중 잠금 구조는 유지한다.
- 저장 상태는 저장 API만이 아니라 조용한 재조회가 끝나거나 실패할 때까지 유지한다.

## 회귀 검증

- 각 적용 화면에서 저장 요청이 지연되는 동안 기존 행/그리드는 보이고 추가·편집·삭제·적용·조회/대상 전환이 불가능해야 한다.
- 저장 요청이 완료된 뒤 조용한 재조회가 지연되어도 동일한 잠금과 저장 진행 표시를 유지해야 한다.
- 저장 및 재조회 완료 후 잠금이 풀리고 정상적인 추가·편집 동작이 가능해야 한다.
- 저장 오류와 재조회 오류 경로에서 기존 dirty 데이터, 오류 메시지, 재시도 가능한 상태를 보존해야 한다.
- 기존 권한별 편집 가능 여부와 확인 대화상자 동작을 회귀 검증한다.
- 적용 대상별 집중 테스트, 프론트엔드 빌드, 가능한 경우 실제 브라우저 확인을 수행한다.
