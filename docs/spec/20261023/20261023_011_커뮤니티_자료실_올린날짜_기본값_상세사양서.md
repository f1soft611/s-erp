# 20261023_011 커뮤니티 자료실 올린 날짜 기본값/초기화 상세사양서

## 1. 날짜 기본값

자료실 상세검색의 `uploadedAt` 날짜 범위는 기존 공통 날짜 기본값 계약을 사용한다.

```ts
defaultValue: {
  from: { type: 'systemDate', offset: { years: -1 } },
  to: { type: 'systemDate' },
}
```

- 시스템 날짜는 `/api/v1/common/system-date`의 기존 client/resolver로 가져온다.
- 최근 1년은 달력 기준이며 양 끝 날짜를 포함한다.
- 계산은 브라우저 시계를 사용하지 않는다.
- 날짜 입력, 적용 검색 조건, 날짜 요약은 동일한 resolved 범위를 기준으로 한다.

## 2. 최초 조회와 오류

- 기본값이 해석되기 전에는 `/api/v1/groupware/boards/archive/files` 목록 조회를 보내지 않는다.
- 해석에 성공하면 시작일/종료일과 기본 파일 유형 `ALL`로 첫 조회를 진행한다.
- 시스템 날짜 조회에 실패하면 오류 메시지와 재시도 동작을 표시한다. 빈 날짜 조회 또는 브라우저 날짜 fallback은 허용하지 않는다.
- 재시도는 공통 resolver를 다시 실행하고 성공 후 첫 목록 조회를 시작한다.

## 3. 초기화

- 상세검색 초기화는 날짜 시작/종료를 resolved 기본 범위로 돌린다.
- 파일 유형은 기본값 `ALL`, 빠른 검색어는 빈 문자열로 설정한다.
- 현재 자료실 폴더는 유지한다.
- 화면 입력값과 목록 API에 적용되는 조건이 같아야 한다.
- 사용자가 날짜를 직접 비워서 검색하는 기존 열린 범위 동작과 날짜 순서 검증은 유지한다.
