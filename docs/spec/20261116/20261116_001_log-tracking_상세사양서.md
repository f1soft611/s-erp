# 공개 로그 추적 중단 상세 사양

계획: [20261116_001](../../plan/20261116/20261116_001_log-tracking_계획서.md)

## 설계

- 루트 `.gitignore`에서 `backend/logs/` 전체를 제외한다.
- 기존에 추적된 해당 경로의 파일은 Git 인덱스에서만 제거한다. 로컬 파일과 내용은 변경하지 않는다.
- 이력 재작성, 커밋 및 푸시는 하지 않는다. 기존 공개 커밋과 복제본의 로그는 이 작업으로 제거되지 않는다.

## 검증

- `git ls-files`로 해당 경로의 추적 파일이 없는지 확인한다.
- `git check-ignore`로 기존 로그와 신규 로그 예시가 제외되는지 확인한다.
- 작업 전후 대상 파일의 존재와 해시를 비교한다.
- 결과 문서에 검증 결과 및 기존 이력의 잔여 위험을 기록한다.
