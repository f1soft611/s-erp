# npm 취약점 호환 범위 개선 상세사양

## 의존성 계약

- Vite와 Vitest의 기존 주요 버전 8과 4를 유지한다.
- ExcelJS의 직접 버전과 사용 코드를 바꾸지 않는다. 강제 수정이나 전역 override는 적용하지 않는다.
- 전이 의존성은 기존 의존성 범위에서 갱신하며 잠금 파일에 결과를 고정한다.
- 공유 작업 공간의 `node_modules`, 운영 코드 및 DB는 변경하지 않는다.

## 검증

- 기준 audit의 전체 8건과 운영 의존성 3건에서 변경 후 건수를 비교한다. 취약점 데이터는 시점에 따라 달라질 수 있다.
- 격리된 잠금 파일 설치로 빌드와 lint, `f1-grid-excel-export.test.ts`, `item-partner-price-excel.test.ts`, `dashboard-data.test.tsx`를 실행한다.
- `uuid` 및 ExcelJS 잔여 항목이 있으면 강제 다운그레이드 없이 별도 검토 대상으로 보고한다.
- 이 작업은 화면 동작을 변경하지 않으므로 새 브라우저 검증을 주장하지 않는다.
