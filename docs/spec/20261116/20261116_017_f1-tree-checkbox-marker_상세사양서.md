## 표시 및 배치

- 기존과 동일하게 `depth > 0 && !hasChildren`인 행에만 `ㄴ` 마커를 표시한다.
- 마커는 해당 leaf 행의 빈 펼침 버튼 슬롯 안에 배치한다. 트리 체크박스가 꺼져 있으면 기존 수평 위치를 유지하고, 켜져 있으면 체크박스 뒤 슬롯에 표시한다.
- 체크박스, 펼침 버튼, 라벨의 순서와 위치 및 체크·펼침 동작은 유지한다.
- 트리 데이터, 사이드 트리, 백엔드는 변경하지 않는다.

## 회귀 검증

- `treeCheckbox`가 켜진 최하위 행에서 마커가 disclosure 슬롯 안에 표시되고 체크박스와 겹치지 않는지 확인한다.
- 기존 체크박스 선택, 부모·자식 전파, 루트·중간·최하위 마커 및 접기·펼치기 테스트를 유지한다.
- 375px, 768px, 1280px 브라우저 뷰포트에서 체크박스와 마커가 겹치지 않는지 확인한다.
