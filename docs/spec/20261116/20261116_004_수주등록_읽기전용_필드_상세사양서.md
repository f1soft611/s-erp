# 수주등록 읽기전용 필드 상세사양서

## 대상 및 표시 기준

수주등록과 동일 컴포넌트를 사용하는 수주현황 상세·수정 폼의 기본정보에 적용한다. 배경색은 현재 MUI 테마의 `action.disabledBackground`를 사용하고 기존 글자색, 기능 및 레이아웃은 유지한다.

| 필드 | 읽기전용 배경 조건 |
| --- | --- |
| 수주번호, 수주상태 | 항상 |
| 수주일자, 견적번호, 납기일자, 납품장소, 배송방법, 비고 | `isEditable`이 거짓일 때 |
| 거래처 | 선택 버튼을 사용할 수 없는 `isEditable` 거짓 상태 |

거래처 텍스트는 직접 입력을 막지만 선택 버튼을 사용할 수 있으면 배경을 변경하지 않는다. 저장 중, 로딩 중, 잠금, 권한 부족, 수주 상태 또는 출하수량에 따른 기존 `isEditable` 판정을 그대로 따른다. 그리드 및 다른 페이지의 동작은 변경하지 않는다.

## 검증

- 신규 편집 가능 상태에서 수주번호·수주상태만 색상을 적용하고 거래처 선택과 나머지 입력은 기존처럼 사용 가능해야 한다.
- 보기 또는 권한 제한 상태에서 모든 기본정보 필드를 같은 읽기전용 배경으로 표시하고 거래처 선택을 허용하지 않아야 한다.
- 등록 및 현황 공유 폼에서 기존 데이터·저장·검증 동작을 유지한다.
- 관련 회귀 테스트, 빌드, 린트 및 375px·768px·1280px 브라우저 확인을 수행한다.
