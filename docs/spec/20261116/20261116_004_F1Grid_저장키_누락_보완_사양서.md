# F1Grid 저장키 누락 보완 사양

[계획](../../plan/20261116/20261116_004_F1Grid_저장키_누락_보완_계획서.md)과 기존 저장키 사양을 따른다.

- 각 그리드에는 화면 용도별로 고유하고 재렌더링 및 재진입 시 변하지 않는 키를 지정한다.
- 분류 선택은 품목 또는 거래처와 선택 수준별로, 분류 설정은 품목 또는 거래처별로 구분한다. 선택한 부모 ID는 키에 넣지 않는다.
- 결재선/참조자 즐겨찾기는 모드별로 구분하며 생략된 기본 모드는 결재선이다.
- 출하계획 등록 폼과 현황 상세 폼은 같은 컬럼 컴포넌트를 사용하되 서로 다른 키를 전달한다. 보기와 수정은 현황 상세 키를 공유한다.
- 컬럼 저장·복원 및 초기화 동작은 기존 F1Grid 계약을 사용한다. 기존에 키가 지정된 화면은 변경하지 않는다.
- 누락 및 정적 중복 검사를 통과하고, 동적 분류 키와 공유 폼 키가 실제 로컬 저장소에 각각 기록되는지 확인한다.
