# 전체 읽기전용 폼 필드 상세사양서

## 표시 기준

- MUI 입력의 `readOnly` 또는 `disabled` 상태는 각 테마의 `action.disabledBackground`를 배경으로 표시한다.
- 선택 버튼으로 값을 변경할 수 있는 코드 및 마스터 선택 입력은 직접 입력이 읽기전용이어도 선택이 활성화되면 편집 가능 배경을 유지한다.
- 선택 버튼이 비활성화되면 해당 입력에 읽기전용 배경을 표시한다.
- F1-Grid 행 폼에서는 `form.readOnly`·`editable`의 기존 판정과 `form.disabled`를 그대로 적용하고, 텍스트·날짜·숫자·선택·자동완성·사용자·코드·체크박스·이미지 입력의 배경을 동일하게 표시한다.
- 공통 서식 편집기의 본문도 읽기전용 상태에서 동일한 배경을 표시한다.
- 밝은 테마 및 다크 테마의 각 비활성 배경 토큰을 사용한다. 선택 및 저장 동작, 그리드 셀 배경, 권한 정책은 변경하지 않는다.

## 검증

테마별 일반 입력, 마스터 선택기의 활성·비활성, 행 폼의 읽기전용·편집 가능·코드 선택 상태를 자동 테스트한다. 수주등록 회귀 테스트와 실제 브라우저 375px·768px·1280px 렌더링 및 F1-Grid 행 폼을 확인한다.
