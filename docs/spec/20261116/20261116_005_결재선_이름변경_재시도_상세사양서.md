# 결재선 이름 변경 재시도 상세 사양

[계획](../../plan/20261116/20261116_005_결재선_이름변경_재시도_계획서.md)과 기존 F1Grid 사양을 따른다.

- 복수 이름 저장 중 성공 행에는 서버 응답 이름을 반영한다.
- 실패 행은 사용자가 입력한 이름과 미저장 상태를 보존하고 오류를 표시한다.
- 부분 실패 후 재시도 시 실패한 변경만 서버로 전송한다.
- 실패 행을 포함한 목록을 닫거나 다른 작업을 실행할 때 기존 미저장 변경 확인을 유지한다.
- 기존 템플릿 API·서버 계약과 F1Grid 공통 동작을 변경하지 않는다.
