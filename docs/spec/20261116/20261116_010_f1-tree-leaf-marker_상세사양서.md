## 표시 기준

- `depth > 0`이고 projection의 `hasChildren`이 거짓인 행에만 기존 `ㄴ` 마커를 표시한다.
- 루트는 자식 유무와 관계없이 표시하지 않는다. 중간 노드는 접힌 상태에서도 표시하지 않는다.
- 자식 판단은 기존 전체 트리 인덱스의 실제 자식 관계를 사용한다. 펼침·접기, 선택, 체크박스 및 기존 최하위 위치는 유지한다.
- 사이드 트리와 백엔드는 변경하지 않는다.

## 검증

3단계 트리와 단독 루트에서 마커의 유무, 중간 노드 접기·펼치기를 검증한다. 최소 375, 768, 1280px 브라우저 뷰포트를 확인한다.
