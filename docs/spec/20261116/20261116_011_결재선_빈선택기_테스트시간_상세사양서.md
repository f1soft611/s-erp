# 결재선 빈 선택기 테스트 시간 상세사양

- 대상: `frontend/tests/document-write-page.test.tsx`의 `keeps the empty approval selector without an unavailable-user message`.
- 기준 동작: 후보 소진 후 빈 선택기는 유지하고 후보 없음 문구는 나타나지 않으며 선택값이 없을 때 추가 버튼은 비활성화한다.
- 범위: 대상 테스트만 제한을 15초로 지정한다. 전역 제한, 검증 조건, 픽스처와 운영 코드는 변경하지 않는다.
- 검증: 기본 제한에서 재현된 실패와 확대 제한에서의 통과를 확인하고 변경 후 대상 및 인접 결재선 테스트, lint, 빌드를 실행한다.
