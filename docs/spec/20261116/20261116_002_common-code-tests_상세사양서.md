# 공통코드 테스트 회귀 정리 상세 사양

계획: [20261116_002](../../plan/20261116/20261116_002_common-code-tests_계획서.md)

## 원인과 수정 범위

- 실제 화면 통합 테스트는 실제 `F1Tree`가 필요하지만 기존 테스트의 기본 설정은 목을 렌더링한다.
- 목 ref에 `setSelectedRowIds`가 없어 선택 복원 타이머가 예외를 발생시킨다.
- 목 컴포넌트는 조건부 Hook 호출로 lint를 위반한다.
- 실제 트리를 기본으로 사용하고, 삭제 차단 콜백을 직접 검증하는 테스트만 목을 사용한다. 목 ref는 실제 사용 계약을 지원하며 Hook 호출 순서를 유지한다.
- 테스트마다 공통코드 페이지 세션을 격리하고, 그룹 선택 테스트는 초기 상세 데이터가 표시된 뒤 선택한다. 이전 테스트의 선택 상태와 초기 로딩에 영향을 받지 않는다.
- 운영 코드와 사용자 화면 동작은 변경하지 않는다.

## 검증

- `vitest run tests/common-code-management-page.test.tsx --maxWorkers=1`로 전체 파일과 미처리 예외를 확인한다.
- 해당 테스트 파일의 oxlint 및 TypeScript 검사를 수행한다.
- 남는 실패는 기대값과 현재 구현을 비교해 원인을 기록하며 임의로 단언을 약화하지 않는다.
