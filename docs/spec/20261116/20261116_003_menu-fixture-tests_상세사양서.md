# 메뉴 기반 테스트 회귀 정리 상세 사양

계획: [20261116_003](../../plan/20261116/20261116_003_menu-fixture-tests_계획서.md)

## 원인과 범위

- 정적 `moduleDescriptors`는 빈 배열이다. 실제 메뉴는 사용자 메뉴 응답을 변환해 구성한다.
- 기존 두 테스트는 정적 `moduleItems`가 설정 모듈을 포함한다고 가정한다.
- 테스트용 권한이 있는 사용자 메뉴 응답을 `buildModuleDescriptors`와 `buildModuleItems`로 변환해 기존 아이콘·메뉴·화면 단언을 유지한다.
- 메뉴 페이지 연결은 실제 `DashboardContent`를 통해 확인한다. 운영 코드와 F1-Grid 기능은 변경하지 않는다.

## 검증

- 두 테스트 파일을 단일 워커로 실행하고 실패 원인을 확인한다.
- 변경 파일의 oxlint 및 전체 TypeScript 검사를 수행한다.
- 테스트 데이터의 시간 의존성과 현재 UI 계약이 다르면 관련 근거에 따라 단언을 갱신한다.
