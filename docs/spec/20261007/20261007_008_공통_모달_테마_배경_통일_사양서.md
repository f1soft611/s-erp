# 20261007_008 공통 모달 테마 배경 통일 사양서

## 1. 목적

공통 다이얼로그에서 테마별 배경색을 일관되게 적용한다. 라이트 테마는 흰색 표면을 사용하고 다크 테마에서는 읽을 수 있는 다크 표면을 명시적으로 정의한다.

- 작업지시서: [20261007_008 공통 모달 테마 배경 통일](../../directions/20261007/20261007_008_공통_모달_테마_배경_통일_작업지시서.md)
- 계획서: [20261007_008 공통 모달 테마 배경 통일](../../plan/20261007/20261007_008_공통_모달_테마_배경_통일_계획서.md)
- 설계: [공통 다이얼로그 테마 표면 설계](../../superpowers/specs/2026-10-07-document-composer-dark-theme-design.md)

## 2. 기본 배경 정책

`CommonDialog`가 `surfaceBackgroundColor`를 전달받지 않은 경우:

| 테마 | paper | header | body | footer |
|---|---|---|---|---|
| Light | `#ffffff` | `#ffffff` | `#ffffff` | `#ffffff` |
| Dark | `#1e293b` | `#1e293b` | `#1e293b` | `#1e293b` |

선택된 단일 표면색은 paper, header, body, footer의 각 MUI 영역 모두에 적용한다. body만 `background.default` 색으로 구분하지 않는다.

## 3. 명시적 사용자 지정

- 호출자가 `surfaceBackgroundColor`를 지정하면 해당 값은 라이트/다크 자동값보다 우선한다.
- 모달의 기존 레이아웃, 높이, 스크롤, 접근성 속성 및 액션 구성은 그대로 유지한다.
- 문서작성 모달은 `surfaceBackgroundColor`로 흰색을 지정하지 않고 공통 기본 색을 사용한다.
- 문서작성 제목 필드와 에디터 본문 표면은 자체 테마 색(`#1e293b`, `#0f172a` 등)과 기존 표시 동작을 유지한다.

## 4. 테스트 기준

### CommonDialog

- 테마별 기본 surface에서 paper/header/body/footer의 computed background color가 동일한지 검증한다.
- 라이트 기대값은 `rgb(255, 255, 255)`, 다크 기대값은 `rgb(30, 41, 59)`이다.
- 명시적 surface 색상을 제공하면 다크 테마에서도 그 색이 전체 영역에 우선 적용되는지 검증한다.
- 기존 접근성, 액션, 크기, 모바일 전체 화면 테스트를 보존한다.

### 문서작성 통합

- 다크 테마에서 문서작성 다이얼로그를 열면 paper/header/body/footer가 `rgb(30, 41, 59)`로 렌더링된다.
- 문서작성의 제목/본문 에디터 전용 표면이 공통 표면 변경으로 바뀌지 않는다.
- 기존 문서작성 화면 테스트 및 저장/입력 흐름이 유지된다.

## 5. 비범위

다이얼로그 레이아웃/기능, 기타 페이지의 편집기 배경, API, 백엔드/DB, 데이터 계약, 다른 컴포넌트의 색상은 변경하지 않는다.

## 6. 브라우저 검증

공유 브라우저를 이용해 문서작성 모달의 다크 모드를 확인한다. 모달 표면에 흰색 불일치가 없어야 하며 내부 에디터는 자체 배경을 유지해야 한다. 사용 중인 개발 서버는 재사용하고 종료하지 않는다.
