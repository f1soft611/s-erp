# 20261007_012 문서작성 합의 라벨 정렬 및 배경 제거 사양서

## 1. 목적 및 범위

문서작성 모달에서 합의 참여자가 표시될 때 `합의` 라벨의 세로 정렬을 합의자 목록 중앙에 맞추고 합의자 표시 배경색을 제거한다.

- 작업지시서: [20261007_012 합의 라벨 정렬 및 배경 제거](../../directions/20261007/20261007_012_문서작성_합의라벨_정렬_배경제거_작업지시서.md)
- 계획서: [20261007_012 합의 라벨 정렬 및 배경 제거](../../plan/20261007/20261007_012_문서작성_합의라벨_정렬_배경제거_계획서.md)
- 승인 설계: [문서작성 합의 행 라벨 정렬 및 배경 제거 설계](../../superpowers/specs/2026-10-07-document-composer-agreement-row-alignment-design.md)

## 2. 표시 기준

- 합의 참여자가 없으면 현재와 같이 합의 행을 렌더링하지 않는다.
- 합의 참여자가 있으면 기존 `labeledRowSx`를 사용하면서 합의 표시 행에만 `alignItems: 'center'`를 적용한다.
- `합의` 라벨의 상단 패딩을 제거한다. 라벨의 글자 상자가 추가 오프셋 없이 행의 세로 가운데에 놓여야 한다.
- 합의자 칩의 테마별 회색/슬레이트 `bgcolor`를 설정하지 않는다. 칩 배경의 계산 스타일은 투명해야 한다.
- 합의자 칩의 테두리 색상, 테두리, 둥근 모서리, 높이, 내부/외부 간격, 글자색은 기존 값을 유지한다.

## 3. 유지 동작 및 비범위

- 결재/합의 참여자 구분, 전역 순번, 이름 및 말줄임, title과 접근성 레이블, 삭제 버튼과 삭제 처리, 선택 후보 복원은 변경하지 않는다.
- 결재선 입력 행, 결재 행, 참조 행의 정렬과 색상은 변경하지 않는다.
- 합의 선택/삭제 흐름, 저장 구조, API, 백엔드, DB는 변경하지 않는다.
- 기존 사용자 변경인 `frontend/tests/document-write-page.test.tsx` 및 `docs/result/20261007/document-composer-approval-stage/` 안의 결과 문서/스크린샷은 수정하거나 덮어쓰지 않는다.

## 4. 자동 검증 기준

- `frontend/tests/document-approval-fields-theme.test.tsx`에서 라이트와 다크 합의자 칩의 계산 배경색이 `rgba(0, 0, 0, 0)`인지 확인한다.
- 라이트/다크 기존 칩 테두리 검증과 다크 텍스트 색 검증이 계속 통과한다.
- 합의 표시 행의 계산 `align-items`가 `center`이고 `합의` 라벨의 계산 상단 패딩이 `0`인지 확인한다.
- 테마 집중 테스트, 변경 컴포넌트/테스트 린트, `npm run build`가 통과한다.

## 5. 브라우저 검증 기준

375px, 768px, 1280px에서 합의 참여자가 있는 문서작성 화면을 확인한다. 라벨은 칩 목록의 세로 중앙에 놓이고, 합의자 칩은 배경색 없이 기존 테두리와 삭제 컨트롤을 유지해야 한다. 페이지 전체 가로 넘침이 없어야 한다. 스크린샷은 합성 사용자 이름과 민감하지 않은 본문만 사용하며 기존 결재선 스크린샷과 분리된 결과 폴더에 저장한다.
