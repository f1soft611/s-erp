# 20261007_011 문서작성 짧은 이름 말줄임 개선 사양서

## 표시 동작

### 결재자 이름

- 결재 슬롯 최소 너비는 88px로 한다.
- 이름 행은 순번 배지 20px, 2px 간격, 남은 너비의 이름 영역으로 구성한다.
- 삭제 X는 상단 직위/직함 행에 있으므로 이름 행에 삭제 버튼용 열을 배치하지 않는다.
- 결재자 이름에 임의 `3em` 최대 너비를 두지 않는다.
- 이름은 한 줄을 유지한다. 슬롯 안에 모두 들어가는 3~4글자 이름은 전체 표시하고, 더 긴 이름은 필요한 경우 말줄임 처리한다.
- 이름의 전체 문자열과 접근성 레이블은 기존 `title` 및 참여자 그룹 레이블로 유지한다.

### 합의자 이름

- 합의 칩 이름 최대 너비는 4em으로 한다.
- 3~4글자 이름은 전체 표시하고, 더 긴 이름은 기존처럼 한 줄 말줄임 처리한다.
- `title`, 합의자 그룹 접근성 이름, X 버튼의 접근성 이름은 전체 사용자 이름을 계속 포함한다.

## 반응형 기준

- 결재 슬롯 최소 너비가 증가해 좁은 화면에서 한 행에 배치되는 슬롯 수가 감소할 수 있다.
- 기존 반응형 그리드의 슬롯 배치/줄바꿈을 유지하며, 페이지 전체 가로 스크롤을 만들지 않는다.
- 순번 배지, 이름, 삭제 X가 겹치지 않아야 한다.

## 비범위

- 사용자명 데이터/API, 선택/삭제/순번 비즈니스 규칙을 변경하지 않는다.
- 긴 이름을 여러 줄로 변경하지 않는다.
- 백엔드, DB 및 스키마 변경은 없다.

## 검증 기준

- 문서작성 테스트에서 4글자 결재자·합의자 이름, 긴 이름의 말줄임 스타일, 전체 접근성 이름을 확인한다.
- 관련 Vitest 전체 파일, 변경 파일 lint, 프론트엔드 build를 통과한다.
- 375px, 768px, 1280px 실제 브라우저 렌더링에서 이름/배지/X 겹침과 페이지 전체 가로 넘침을 확인한다.
- 화면 내 개인정보를 흐림 처리한 반응형 스크린샷과 결과 문서를 갱신한다.
