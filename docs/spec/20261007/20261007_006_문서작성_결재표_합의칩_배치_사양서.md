# 20261007_006 문서작성 결재 표/합의 칩 배치 사양서

## 1. 목적 및 범위

문서작성 모달에서 결재자 선택/확정 입력과 확정 결재/합의 표시를 구분한다. 결재는 직위/도장/순번/이름의 열형 표로, 합의는 순번/이름/도장/X가 담긴 개별 칩으로 표시하고 좁은 폭에서는 둘 다 다음 줄로 이어간다.

- 작업지시서: [20261007_006 결재 표/합의 칩 배치](../../directions/20261007/20261007_006_문서작성_결재표_합의칩_배치_작업지시서.md)
- 계획서: [20261007_006 결재 표/합의 칩 배치](../../plan/20261007/20261007_006_문서작성_결재표_합의칩_배치_계획서.md)
- 승인 디자인: [Document Approval Display Layout](../../superpowers/specs/2026-10-07-document-approval-display-layout-design.md)
- 구현 계획: [Document Approval Display Layout Implementation Plan](../../superpowers/plans/2026-10-07-document-approval-display-layout.md)

## 2. 행 구조

1. **결재선**: 기존 다중 사용자 선택기, `결재 추가`, `합의 추가` 버튼을 표시한다. 확정 사용자는 이 행에 표시하지 않는다.
2. **결재**: 각 승인 사용자를 직위 셀, 도장 영역, 하단 순번/이름 셀, 개별 삭제(X)가 있는 표형 열로 표시한다. 열은 결재 순서대로 배치하고 가용 폭에 따라 다음 줄로 wrap한다.
3. **합의**: 각 합의 사용자마다 연회색 칩을 만든다. 칩에는 결재/합의가 섞인 전역 순번, 이름, 도장 자리, 해당 사용자만 삭제하는 X를 표시한다. 아바타와 구분 문구는 표시하지 않는다. 가용 폭에 따라 다음 줄로 wrap한다.
4. **참조**: 기존 참조 행, 선택기와 동작을 그대로 유지한다.

각 행은 일관된 왼쪽 라벨과 `min-width: 0`인 오른쪽 콘텐츠 영역을 사용한다. 비어 있는 결재/합의 행에는 참여자 셀/칩을 표시하지 않는다.

## 3. 순서 및 삭제

- 다중 결재 선택은 기존 선택 순서대로 개별 승인 항목이 된다.
- 합의 선택은 기존처럼 하나의 agreement stage에 그룹으로 저장되지만 화면에서는 사용자별 칩으로 펼친다.
- 결재와 합의 사용자를 기존 stage/user 순서대로 평탄화해 1부터 전역 번호를 부여한다. 순번은 결재선 다음 입력 필드의 번호에도 일관되게 반영한다.
- 결재 표 열 삭제는 해당 approval stage를 제거한다.
- 합의 칩 삭제는 해당 사용자만 agreement stage에서 제거한다. 마지막 사용자를 지우면 빈 agreement stage를 제거한다.
- 삭제한 사용자는 결재 후보로 복원하고 나머지 참여자의 전역 순번을 다시 계산한다.
- 참조 선택은 결재 상태와 독립적이며 변경하지 않는다.

## 4. 표시 및 접근성

- 네 라벨 `결재선`, `결재`, `합의`, `참조`가 화면 순서와 일치한다.
- 승인 열은 사용자 position/title, 도장 영역, 순번/이름과 참여자/순번을 구별하는 삭제 버튼을 표시한다.
- 합의 칩은 사용자 순번/이름/도장/X만 표시하고 삭제 버튼의 접근성 이름에 대상 참여자와 순번을 포함한다.
- 결재 표 그리드와 합의 칩 목록은 wrap하고 페이지 또는 모달 전체 가로 폭을 늘리지 않는다.

## 5. 변경하지 않을 사항

공통 에디터, 공통 사용자 선택기, 공통 다이얼로그, 라우팅, 데이터 계약, 저장/상신, 백엔드, 권한 및 데이터베이스를 변경하지 않는다.

## 6. 검증 기준

### 자동 테스트

- 네 행 라벨/순서, 결재 입력과 액션 배치, 기존 참조 필드를 확인한다.
- 결재자 여러 명의 직위/도장/순번/이름/개별 삭제와 기존 선택 순서를 확인한다.
- 합의자별 순번/이름/도장/X와 아바타/구분 미표시를 확인한다.
- 결재/합의 혼합 참여자 순번, 합의자 한 명 삭제 후 같은 그룹의 다른 인원 유지, 마지막 인원 삭제 시 그룹 제거, 후보 복원/재번호를 확인한다.
- 결재 표 열과 합의 칩의 wrap 스타일 및 페이지 가로 넘침 방지를 확인한다.
- 기존 참조 선택, 공통 사용자 선택기 및 로딩/오류 흐름이 통과하는지 확인한다.

### 브라우저

375px, 768px, 1280px에서 결재/합의 참여자를 추가하고, 결재선 입력 → 결재 표 → 합의 칩 → 참조 입력 순서, 표 열과 칩의 wrap 및 삭제 후 갱신을 확인한다. 화면 전체 가로 넘침이 없어야 한다. 결과 캡처에는 실제 사용자 식별정보나 문서 본문을 포함하지 않는다.
