# 20261007_003 F1-Grid 사용자 선택 필드 라벨 수직 정렬 사양서

## 동작 사양

- 대상은 `UserSelectEditor`의 outlined small TextField에서 비축소 상태로 표시되는 라벨이다.
- 비축소 라벨은 라벨 폰트 크기(0.82rem)와 실제 입력 높이에 맞춰 수직 중앙에 보이도록 한다.
- 포커스 또는 선택값으로 축소된 라벨의 notch 위치는 기존 MUI 동작을 유지한다.
- compact Grid cell 편집기는 standard variant이며 이번 보정 대상에서 제외한다.
- 팝업, 선택값, 칩 제거, 검색 및 키보드 동작은 변경하지 않는다.

## 검증

- 테스트에서 비축소 라벨의 transform이 중앙 정렬 보정값을 사용하는지 확인한다.
- focused/shrink 및 compact 경로의 기존 동작에 회귀가 없는지 테스트와 브라우저로 확인한다.
