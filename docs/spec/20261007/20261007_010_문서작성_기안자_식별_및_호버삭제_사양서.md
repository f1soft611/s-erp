# 20261007_010 문서작성 기안자 식별 및 호버 삭제 사양서

## 프로필 응답 계약

| 필드 | 의미 | 원천 | 변경 |
|---|---|---|---|
| `userId` | 로그인 코드 | `tb_login_account.login_code` | 기존 의미 유지 |
| `employeeId` | 내부 사용자 식별자 | `tb_user.user_id` | 현재 인증 사용자 값 추가 |

`employeeId`는 Java API 응답에서 `Long`, JSON 응답에서 숫자로 반환한다. 프론트엔드 타입은 API/테스트 경계에 대응해 `number | string`을 허용하고 비교 전에 `String(value).trim()`으로 정규화한다. 프로필 응답은 본인 조회 API이므로 사용자 목록 전체에 로그인 코드를 추가하지 않는다.

## 초기 결재자 및 후보 필터링

- 작성 모달을 열 때 이름과 `employeeId`가 유효한지 확인한다.
- 선택 후보에서 `String(option.value).trim() === String(profile.employeeId).trim()`인 항목을 찾아 고정 결재 1번으로 설정한다.
- 선택 후보에 일치 항목이 없으면 프로필 표시 정보로 항목을 구성하되 값은 `employeeId`로 설정한다. 일반 후보 옵션 목록에는 fallback 사용자를 추가하지 않는다.
- `employeeId`가 없거나 공백이면 기존 작성 정보 오류 영역에 명시적 오류를 표시하고 `login_code`를 내부 사용자 ID처럼 대체 사용하지 않는다.
- 결재/합의/참조 후보 제외는 정규화한 사용자 ID로 수행한다. 이름 기준으로 차단하지 않으며 동명이인의 서로 다른 ID는 후보에 남는다.
- 고정 기안자는 삭제할 수 없다.

## 삭제 동작

### 결재자

- 비고정 결재 카드의 직위/직함 행 우측에 X 아이콘 버튼을 둔다.
- 호버 가능한 장치에서는 기본 상태에서 숨기고 카드 호버 또는 카드 내부 키보드 포커스 시 표시한다.
- 버튼은 `결재 참여자 {순번} {이름} 삭제` 접근성 이름과 키보드 조작을 유지한다.
- 고정 기안자에는 버튼을 렌더링하지 않는다.

### 합의자

- 기존 삭제-outline 아이콘을 X 아이콘으로 변경한다.
- 호버 가능한 장치에서는 기본 비표시이며 합의 항목 호버 또는 키보드 포커스 시 표시한다.
- 버튼의 접근성 이름은 `합의 참여자 {순번} {이름} 삭제`를 유지한다.

### 터치 장치 및 상태 전이

- CSS `@media (hover: none)` 등 기존 MUI/CSS 패턴으로 두 유형의 X 버튼을 항상 표시한다.
- 결재 사용자 삭제 시 해당 결재 단계를 제거하고 이후 순번을 재계산한다.
- 합의 그룹에서 사용자를 한 명 제거하면 나머지 그룹 구성원과 순번은 유지한다. 마지막 구성원을 제거하면 빈 합의 단계를 제거한다.
- 삭제한 사용자는 결재/합의/참조 선택 후보 중 다른 역할로 사용 중이지 않은 곳에 복원한다.

## 비범위

- 기존 프로필 `userId`를 employee ID로 재정의하지 않는다.
- 사용자 후보 API에 `loginCode`를 추가하지 않는다.
- 사용자 이름을 기준으로 차단하지 않는다.
- 테이블/컬럼/FK/데이터 변경, DB 마이그레이션, 문서 제출 API 또는 결재 상태 처리를 추가하지 않는다.

## 테스트 및 검증

- 백엔드 컨트롤러 테스트에서 `userId=login_code`와 `employeeId=user_id`가 독립적으로 반환됨을 검증한다.
- 프론트엔드에서 프로필 login code가 선택 옵션과 일치하지 않아도 employee ID 후보를 고정 기안자로 사용하고, 해당 후보가 모든 역할 선택기에서 제외됨을 검증한다.
- 동명이인이지만 ID가 다른 사용자 선택을 허용한다.
- employee ID 누락 오류, 고정 기안자 삭제 불가, X 아이콘/위치/접근성 레이블, 데스크톱 hover/focus, 터치 항상 표시, 결재/합의 개별 삭제 및 후보 복원을 검증한다.
- 백엔드 컨트롤러 테스트, 관련 Vitest, 변경 파일 lint, frontend build와 375px·768px·1280px 실제 브라우저 검증을 수행한다.
