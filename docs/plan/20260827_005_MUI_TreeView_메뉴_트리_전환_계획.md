# MUI TreeView 메뉴 트리 전환 구현 계획

**목표:** 대시보드 좌측 메뉴를 MUI X `SimpleTreeView`로 전환하고, 그룹 토글과 리프 라우팅을 분리한다.

**구조:** `DashboardMenuTree`가 재귀 `MenuTreeNode` 렌더링과 확장 상태를 담당한다. `DashboardPage`는 현재 경로에 해당하는 리프 및 조상 그룹을 재귀적으로 계산하고, 리프 선택 시에만 라우팅한다.

**기술:** React 19, TypeScript, MUI Material 9, MUI X Tree View, React Router 7, Vitest, Testing Library

---

## 1. 의존성 및 테스트 기준 준비

대상 파일:

- 수정: `frontend/package.json`
- 수정: `frontend/tests/dashboard-sidebar.test.tsx`

1. `@mui/x-tree-view`를 MUI Material 9과 호환되는 버전으로 추가한다.
2. 다음 실패 테스트를 추가한다.

```tsx
it('toggles a menu group without navigating and navigates from a leaf menu', async () => {
  render(<App />);
  await loginAsAdmin();

  fireEvent.click(screen.getByRole('treeitem', { name: /업무관리/i }));
  expect(window.location.pathname).toBe('/dashboard/groupware/approval');
  expect(
    screen.queryByRole('treeitem', { name: /전자결재/i }),
  ).not.toBeInTheDocument();

  fireEvent.click(screen.getByRole('treeitem', { name: /업무관리/i }));
  fireEvent.click(screen.getByRole('treeitem', { name: /공지사항/i }));
  expect(window.location.pathname).toBe('/dashboard/groupware/notice');
});
```

3. WSL2에서 `npx vitest run tests/dashboard-sidebar.test.tsx`를 실행하여, TreeView 도입 전에는 기대한 트리 역할 또는 그룹 토글 동작이 없어 실패함을 확인한다.

## 2. 재귀 메뉴 탐색 정리

대상 파일:

- 수정: `frontend/src/pages/dashboard/DashboardPage.tsx`
- 테스트: `frontend/tests/dashboard-sidebar.test.tsx`

1. `MenuTreeNode[]`를 순회해 ID로 노드, 리프 메뉴, 조상 그룹 ID를 찾는 로컬 순수 함수를 만든다.
2. URL의 `menuId`가 현재 모듈의 리프일 때만 선택 메뉴로 인정한다.
3. `DashboardSidebar`에서 `onParentSelect`와 부모 선택 상태 전달을 제거한다.
4. 부모 클릭 핸들러와 첫 자식 메뉴 이동 로직을 제거하고, `handleMenuSelect`만 라우팅을 수행하도록 한다.
5. 직접 `/dashboard/groupware/notice`에 진입하면 `업무관리`이 자동으로 확장되고 `공지사항`이 선택되는 테스트를 추가한다.

## 3. MUI TreeView 메뉴 렌더링

대상 파일:

- 수정: `frontend/src/pages/dashboard/components/DashboardMenuTree.tsx`
- 수정: `frontend/src/pages/dashboard/components/DashboardSidebar.tsx`
- 테스트: `frontend/tests/dashboard-sidebar.test.tsx`

1. `DashboardMenuTree`에서 `SimpleTreeView`, `TreeItem`을 import한다.
2. 다음 책임의 재귀 렌더러를 구현한다.

```tsx
function renderMenuNode(node: MenuTreeNode): ReactNode {
  const hasChildren = Boolean(node.children?.length);
  return (
    <TreeItem
      key={node.id}
      itemId={node.id}
      label={node.name}
      onClick={hasChildren ? undefined : () => onMenuSelect(node.id)}
    >
      {node.children?.map(renderMenuNode)}
    </TreeItem>
  );
}
```

3. `expandedItems`와 `onExpandedItemsChange`로 그룹 확장 상태를 관리한다. 선택 리프의 조상과 새 모듈의 기본 리프 조상을 초기 확장한다.
4. `selectedItems={selectedMenuId}`를 사용해 리프 선택 상태를 연결한다.
5. 트리 그룹, 리프, 선택 리프, hover, 확장 아이콘의 스타일을 기존 밝은/다크 테마에 맞춘다.
6. `DashboardSidebar` props를 그룹 선택 콜백 없이 갱신한다.
