# 검색 영역 공통 컴포넌트 분리 계획서

- 관련 작업지시서: [20260901*004*검색영역*공통컴포넌트*분리\_작업지시서.md](../../directions/20260901/20260901_004_검색영역_공통컴포넌트_분리_작업지시서.md)

## 1. 현황

- 검색 UI(모듈 선택 + 메뉴명/코드 검색)는 [MenuManagementPage.tsx](../../../frontend/src/pages/settings/system/menus/MenuManagementPage.tsx)에만 존재하며, 기존에는 `PageHeader`의 `children`으로 헤더 내부에 렌더링되고 있었다.
- 나머지 페이지(RoleManagementPage, DocumentsPage, OverviewPage, F1GridTestPage, DashboardContent fallback)는 검색 UI가 없다.

## 2. 구현 단위

1. `src/shared/components/PageSearchArea.tsx` 신규 생성 — 헤더와 동일한 톤의 구분선을 가진 flex 컨테이너로 자식 요소(검색 필드들)를 감싼다.
2. `MenuManagementPage.tsx`에서 모듈 선택 `FormControl`/검색 `TextField`를 `PageHeader`의 `children`에서 꺼내 `PageSearchArea`로 이동.
3. 화면 순서를 `PageHeader → PageMessageArea → PageSearchArea → MenuManagementPanel`로 재배치.
4. 검색 UI가 없는 다른 페이지는 변경하지 않는다(불필요한 빈 검색 영역을 추가하지 않음).

## 3. 검증 계획

- `npm run build`
- `npm run test -- tests/menu-management-f1-grid.test.tsx`
