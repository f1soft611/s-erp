## 2. 구현 단위

1. `src/shared/components/PageHeader.tsx` 신규 생성
   - 좌측: 모듈명/현재메뉴명 또는 `breadcrumbItems` 배열 기반 브레드크럼 + description
   - 우측: `actionGroups`(옵션) 전달 시 `PermissionGroupActionBar` 렌더
   - `children`(옵션): 헤더 하단 필터/셀렉트 영역(MenuManagementPage 전용)
2. 위 6개 페이지의 중복 헤더 마크업을 `PageHeader` 사용으로 교체
3. 기존 props/동작(설명 문구, 액션 버튼, 필터) 변경 없이 그대로 유지

## 3. 검증 계획

- `npm run build` (TypeScript 컴파일 확인)
- 관련 기존 테스트 실행: `npm run test -- tests/menu-management-f1-grid.test.tsx`, `npm run test -- tests/dashboard-data.test.tsx`, `npm run test -- tests/f1-grid-test-page.test.tsx`
- 필요 시 로컬 브라우저 스크린샷으로 좌/우 레이아웃 확인
