# F1-GRID F1Tree treeCheckbox 체크박스 컬럼 동기화 계획서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot
- 작업 대상: `frontend/src/shared/components/f1-grid/tree/F1Tree.tsx`, `types/grid.types.ts`

## 구현 계획

### 1단계: 타입 옵션 추가

- `F1GridColumn`에 `syncWithTreeCheckbox?: boolean` 추가(문서화: 기본 `true`)

### 2단계: F1Tree 체크박스 동기화 로직

- `F1Tree`는 `gridProps.columns`를 통해 전체 컬럼 정의에 접근 가능하므로, `toggleTreeCheckbox` 호출 시 대상 rowId 목록(자기 자신 + 하위)에 대해 `type: 'checkbox'` && `syncWithTreeCheckbox !== false`인 각 컬럼 값을 `nextChecked`로 덮어쓰는 데이터 갱신을 함께 수행
- `F1Grid`가 내부에서 `rows` state(`data`)를 관리하므로, `F1Tree`에서 직접 데이터를 변경할 수 있는 경로가 필요 → `F1GridRef`가 노출하는 낮은 수준 API 대신, `F1Tree`가 `rows` prop 자체를 변환해 `F1Grid`로 넘기는 방식은 controlled 데이터 흐름을 깨므로, `F1Grid`에 `onExternalRowsPatch` 형태의 내부 콜백을 추가하기보다 `F1Grid`가 이미 관리하는 `data` state에 직접 반영할 수 있도록 `startEdit`/`commitEdit`와 별개로 `F1GridRef`에 `patchRow(rowId, patch)` 같은 메서드를 추가하는 대신, 가장 단순하게 `F1Tree`가 `gridRef.current`를 통해 각 대상 row의 체크박스 컬럼에 대해 `F1GridRef`의 기존 편집 경로(`startEdit`/커밋)를 쓰지 않고, `F1Grid`에 새 imperative 메서드 `setCellValue(rowId, field, value)`를 추가해 사용한다.
- `F1GridRef`에 `setCellValue(rowId: F1GridRowId, field: keyof T, value: unknown): void` 추가, `F1Grid` 내부에서 `updateGridRow`를 호출하는 방식으로 구현(검증/편집 가능 여부와 무관하게 시스템 자동 반영이므로 `isCellEditable` 체크는 하지 않음)
- `F1Tree`의 `toggleTreeCheckbox`에서 대상 rowId들에 대해 체크박스 컬럼 각각 `gridRef.current.setCellValue(id, column.field, nextChecked)` 호출
