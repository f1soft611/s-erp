# F1-GRID 컬럼 자동너비맞춤 계획서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot
- 작업 대상: `frontend/src/shared/components/f1-grid`

## 구현 계획

### 1단계: 너비 측정 유틸리티

- `utils/grid.utils.ts`에 텍스트 너비 측정 함수 추가 (Canvas `measureText` 기반, 폰트는 셀에서 사용하는 스타일과 동일하게 근사)
- 헤더 제목과 화면에 렌더링된 행들의 셀 표시값(`getValue` 우선, 없으면 `row[field]`)을 모두 측정해 최댓값 계산

### 2단계: `F1GridColumn`에 `maxWidth` 옵션 추가

- `types/grid.types.ts`에 `maxWidth?: number` 필드 추가
- 자동 맞춤 계산 결과를 `Math.max(minColumnWidth, Math.min(maxWidth ?? Infinity, measuredWidth))`로 clamp

### 3단계: 더블클릭 핸들러 연결

- `GridHeader.tsx` 리사이즈 핸들(`role="separator"`)에 `onDoubleClick` 추가
- 더블클릭 시 현재 `visibleRows` 중 실제 렌더링된 행 데이터를 기준으로 측정 함수 호출 후 `onResizeColumn` 호출
- `F1Grid.tsx`에서 `GridHeader`로 현재 표시 중인 rows를 전달(이미 `GridBody`에 넘기는 값 재사용)

### 4단계: 검증

- `npm run test -- tests/f1-grid.test.tsx`
- `npm run build`
