# 메뉴 기능권한/설명 연동 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메뉴관리에서 저장한 기능 권한, 메뉴명, 메뉴설명을 실제 페이지의 버튼과 헤더에 그대로 반영한다.

**Architecture:** `tb_menu.menu_dc`를 메뉴 관리 및 사용자 메뉴 API 계약에 추가한다. 대시보드는 선택 메뉴 노드의 경로로 페이지를 식별하고 그 노드의 이름, 설명, 기능 권한을 페이지 컴포넌트에 전달한다. 공통 액션은 READ/CREATE·UPDATE/DELETE/EXCEL을 조회/저장/삭제/엑셀에 매핑한다.

**Tech Stack:** PostgreSQL, Spring Boot/eGovFrame, MyBatis, React, TypeScript, MUI, Vitest
