# F1-GRID 컬럼 드래그 순서 변경 계획서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot
- 작업 대상: `frontend/src/shared/components/f1-grid`

## 구현 계획

### 1단계: 컬럼 순서 유틸리티

- `columns/GridColumnManagement.ts`에 `reorderGridColumns(columns, order)` 추가: `order`(field 문자열 배열) 기준으로 컬럼 배열을 재정렬하고, `order`에 없는 컬럼(신규 컬럼 등)은 뒤에 원래 순서대로 붙인다.
- `moveGridColumnOrder(order, sourceField, targetField)` 추가: 배열에서 `sourceField`를 제거 후 `targetField` 위치에 삽입한 새 배열 반환.

### 2단계: F1Grid 상태 및 localStorage 연동

- `F1GridProps`에 `storageKey?: string` 추가.
- `F1Grid`에 `columnOrder` state 추가. 초기값은 `storageKey`가 있고 `localStorage`에 저장된 값이 있으면 그 값을, 없으면 `columns.map(c => String(c.field))`.
- `columnOrder` 변경 시 `storageKey`가 있으면 `localStorage.setItem(storageKey, JSON.stringify(columnOrder))` 수행(부수효과 `useEffect`).
- `visibleColumns` 계산 전에 `reorderGridColumns(columns, columnOrder)`를 적용해 실제 렌더링 순서에 반영.

### 3단계: GridHeader 드래그 앤 드롭

- 헤더 셀에 `draggable` 속성 추가(고정 컬럼 제외: pinned 컬럼은 `draggable={false}`).
- `onDragStart`: 드래그 중인 컬럼 field를 `dataTransfer`에 저장.
- `onDragOver`: `preventDefault()`로 드롭 허용(단, 대상이 pinned 컬럼이면 무시).
- `onDrop`: 드래그 소스 field와 드롭 대상 field를 이용해 `onReorderColumn(sourceField, targetField)` 콜백 호출.
- `F1Grid`가 `onReorderColumn`을 받아 `moveGridColumnOrder`로 `columnOrder` state 갱신.

### 4단계: 검증

- `npm run test -- tests/f1-grid.test.tsx`
- `npm run build`
