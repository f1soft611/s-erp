# 20260901_001 메뉴관리 페이지 액션/그리드 제어 분리 계획서

## 1. 목표

메뉴관리 페이지에서 페이지 업무 액션과 F1Tree 제어 액션을 시각적, 구조적으로 분리한다.

## 2. 구현 범위

- `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx`
  - 카드 헤더를 제목, 서비스 액션 영역, 그리드 제어 영역으로 재구성한다.
  - 서비스 액션 영역에는 루트 메뉴 추가, 하위 메뉴 추가, 삭제, 저장, 새로고침을 둔다.
  - 그리드 제어 영역에는 전체 펼치기, 전체 접기를 둔다.
  - 접근 가능한 이름을 부여해 테스트와 스크린리더에서 영역을 구분할 수 있게 한다.
- `frontend/tests/menu-management-f1-grid.test.tsx`
  - 서비스 액션 영역과 그리드 제어 영역이 분리되어 렌더링되는지 검증한다.

## 3. 제외 범위

- 역할별 권한 부여 화면 구현
- 공통 F1Grid API 변경
- 백엔드 API 또는 DB 스키마 변경
- 다른 업무 페이지의 액션 영역 일괄 적용

## 4. 검증

- `cd frontend; npm run test -- tests/menu-management-f1-grid.test.tsx`
- `cd frontend; npm run build`
