# F1-GRID 화면크기(displayScale) 연동 계획서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot
- 작업 대상: `frontend/src/shared/context/AppSettingsContext.tsx`, `frontend/src/shared/components/f1-grid/core/F1Grid.tsx`

## 구현 계획

### 1단계: Provider 없이도 안전한 displayScale 조회 훅

- `AppSettingsContext.tsx`에 `useOptionalDisplayScale()` 훅 추가: `useContext(AppSettingsContext)`가 없으면(Provider 미장착) `1`을 반환, 있으면 `displayScale` 반환. 기존 `useAppSettings()`(Provider 필수, 없으면 throw)는 그대로 유지.

### 2단계: F1Grid에서 displayScale 반영

- `F1Grid`에서 `useOptionalDisplayScale()`로 `displayScale` 값을 얻는다.
- 기존 `defaultRowHeight`/`normalizedMinRowHeight`/`normalizedMaxRowHeight` 계산 전에 원본 `rowHeight`, `minRowHeight`, `maxRowHeight` prop 값에 `displayScale`을 곱한 뒤 clamp한다.
- 개별 행이 수동으로 조정된 경우(`rowHeights[rowId]`가 존재) 그 값을 그대로 사용하는 기존 로직은 변경하지 않는다(자동으로 우선순위 보장됨).

### 3단계: 검증

- `npm run test -- tests/f1-grid.test.tsx`
- `npm run build`
