# F1-GRID 컬럼 설정 로컬스토리지 확장 계획서

- 작성일: 2026-09-01
- 작성자: GitHub Copilot
- 작업 대상: `frontend/src/shared/components/f1-grid`

## 구현 계획

### 1단계: 저장 상태 유틸리티

- `columns/GridColumnManagement.ts`에 `F1GridColumnStorageState` 타입 추가:
  `{ order?: string[]; widths?: Record<string, number>; hidden?: string[] }`.
- `parseGridColumnStorageState(raw: string | null)` 추가: JSON 파싱 후 객체 형태가
  아니면 `null` 반환(기존 배열 전용 포맷과 호환하지 않는 신규 포맷).

### 2단계: F1Grid 상태 초기화/저장 통합

- `columnOrder`, `columnWidths`, `hiddenColumnFields` 각 state의 초기값을
  `storageKey`가 있으면 `parseGridColumnStorageState(localStorage.getItem(storageKey))`
  결과에서 각각 `order`/`widths`/`hidden`을 사용하도록 변경(없으면 기존 기본값 유지).
- 기존에 `columnOrder`만 저장하던 `useEffect`를 `columnOrder`, `columnWidths`,
  `hiddenColumnFields` 세 state를 모두 감시하는 단일 `useEffect`로 통합하고,
  `{ order, widths, hidden }` 형태로 `localStorage.setItem(storageKey, JSON.stringify(...))` 수행.

### 3단계: 검증

- 기존 컬럼 순서 저장/복원 테스트를 신규 저장 포맷에 맞게 수정.
- 컬럼 너비 변경 후 재마운트 시 복원되는지 테스트 추가.
- 컬럼 숨김 처리 후 재마운트 시 복원되는지 테스트 추가.
- `npm run test -- tests/f1-grid.test.tsx`, `npm run build`
