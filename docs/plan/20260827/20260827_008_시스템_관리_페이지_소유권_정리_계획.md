# 시스템 관리 페이지 소유권 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 환경설정 > 시스템 관리의 권한관리/메뉴관리 전용 코드를 각 페이지 폴더로 이동하고 dashboard 의존성을 제거한다.

**Architecture:** 각 관리 페이지 폴더가 타입, 정적 데이터, 상세 패널을 소유한다. `DashboardContent`는 페이지를 선택해 렌더링하고 `dashboardData`는 공통 메뉴/요약 콘텐츠만 제공한다.

**Tech Stack:** React 19, TypeScript, MUI, Vitest, Testing Library
