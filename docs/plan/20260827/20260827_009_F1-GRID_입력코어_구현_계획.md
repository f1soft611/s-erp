# F1-GRID 입력 코어 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메뉴관리 목록에서 사용할 수 있는 재사용형 `F1Grid` ERP 입력 코어를 구현한다.

**Architecture:** `shared/components/f1-grid`가 컬럼 렌더링, 선택, 포커스, 셀 편집, 행 상태를 소유한다. 메뉴관리 패널은 기존 정적 메뉴 데이터를 입력으로 전달하고 Grid ref의 명령만 툴바에 연결한다.

**Tech Stack:** React 19, TypeScript, MUI 9, Vitest, Testing Library

---

## File Structure

- Create: `frontend/src/shared/components/f1-grid/f1Grid.types.ts` - 제네릭 컬럼, 행 상태, 변경분, ref 타입
- Create: `frontend/src/shared/components/f1-grid/f1Grid.state.ts` - 행 추가, 수정, 삭제, 복원, 복제와 변경분 계산 순수 함수
- Create: `frontend/src/shared/components/f1-grid/F1Grid.tsx` - 키보드·선택·편집·ref를 조합하는 렌더링 컴포넌트
- Create: `frontend/tests/f1-grid.test.tsx` - 상태와 UI 동작의 테스트 선행 명세
- Modify: `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx` - 목록 Table을 F1Grid로 교체하고 툴바 연결
- Create: `frontend/tests/menu-management-f1-grid.test.tsx` - 메뉴관리 통합 검증
- Create: `docs/result/20260827/f1-grid-input-core/20260827_009_F1-GRID_입력코어_결과.md` - 변경 및 검증 결과
