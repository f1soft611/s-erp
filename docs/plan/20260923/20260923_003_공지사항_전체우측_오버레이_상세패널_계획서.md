# 20260923_003 공지사항 전체 우측 오버레이 상세 패널 계획서

## 1. 목표

기존 `ContentSplitLayout` 우측 컬럼에 표시하던 공지 상세를 페이지 전체 높이의 우측 Drawer 오버레이로 전환한다. 데스크톱에서는 `min(960px, 72vw)` 수준의 넓은 패널을 사용하고, 모바일에서는 전체 너비를 사용한다. 목록은 배경에 유지하고 상세 내부에 독립 스크롤을 제공한다.

## 2. 작업 범위

- 대상: 프론트엔드 공지사항 화면
- 화면: `/groupware/community/notice`
- 공통 UI: `PostDetailPanel`
- 상태 연결: `CommunityNoticePage`
- 기존 기능: `NoticeFeedList` 단일 게시글 재사용
- 백엔드/DB/API: 변경 없음

## 3. 구현 계획

### Step 1. 오버레이 패널 테스트 RED

- `frontend/tests/post-detail-panel.test.tsx`에 전체 높이·넓은 폭·닫기 계약을 추가한다.
- `frontend/tests/notice-page.test.tsx`에 선택 시 Drawer 열림, 닫기, 다른 게시글 교체 계약을 추가한다.
- 신규 계약이 구현 전 실패하는지 실행한다.

### Step 2. 공통 패널 프레임 조정

- `frontend/src/shared/components/feed/PostDetailPanel.tsx`
- 패널을 전체 높이(`100dvh`)로 확장하고 헤더를 고정한다.
- 콘텐츠 영역만 `overflow-y: auto`를 갖도록 한다.
- 데스크톱 Drawer가 폭을 제어하므로 패널 자체는 폭 100%를 사용한다.

### Step 3. 공지 페이지 Drawer 전환

- `frontend/src/pages/groupware/community/notice/CommunityNoticePage.tsx`
- 데스크톱에서도 선택 상세를 `Drawer anchor="right"`로 렌더링한다.
- `ContentSplitLayout`의 우측 선택 상세 분기를 제거하고 요약 패널만 유지하거나 목록 레이아웃을 단일 콘텐츠로 정리한다.
- Drawer 폭을 `min(960px, 72vw)`로 설정하고 모바일은 `100vw`로 설정한다.
- `onClose`, 백드롭, Escape 기본 동작을 연결한다.
- 목록 클릭 시 배경 목록을 유지하고 기존 `selectedNoticePanel`을 Drawer 내부에 재사용한다.

### Step 4. 대상 교체·스크롤·기능 회귀

- 다른 게시글 선택 시 Drawer는 닫히지 않고 같은 패널의 콘텐츠만 교체되는지 확인한다.
- 본문 HTML, 첨부, 댓글, 좋아요, 북마크, 작성자 메뉴가 기존과 동일하게 유지되는지 확인한다.
- 상세 조회 실패 시 기존 오류 처리와 닫기 동작을 유지한다.

### Step 5. 반응형 브라우저 검증

- 1280px: 넓은 우측 오버레이와 배경 목록 동시 표시
- 768px: 패널 폭·헤더·본문 스크롤 확인
- 375px: 전체 너비, 가로 스크롤 없음, 닫기 버튼 접근성 확인
- Playwright 스크린샷과 `scrollWidth`/주요 rect를 결과 문서에 기록한다.

### Step 6. 최종 검증·문서화

- 관련 Vitest
- `npm run build`
- 전체 `npm run test`
- 결과 문서와 원장 갱신
