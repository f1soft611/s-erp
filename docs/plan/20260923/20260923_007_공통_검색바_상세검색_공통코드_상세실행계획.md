# 20260923_007 공통 검색바 상세 검색 및 공통코드 상세 실행 계획

## Global Constraints

- 현재 브랜치에서 진행하며 별도 Worktree를 생성하지 않는다.
- 승인된 작업지시서와 상세 사양서 범위만 수정한다.
- `form.span`은 폼모달 전용으로 유지하고 검색 레이아웃에는 `search?.span`을 사용한다.
- `date` 검색은 `from`/`to` 범위 상태를 사용한다.
- 공통코드 그룹 조회는 항상 인증 사용자 tenant 조건을 유지한다.
- DB 스키마는 변경하지 않는다.
- 기존 사용자 변경과 무관한 파일을 되돌리지 않는다.
- 각 태스크 완료 후 좁은 검증을 실행한다. 저장소 정책상 커밋은 사용자가 요청한 경우에만 수행한다.

## 기준선

- 작업 위치: 현재 브랜치
- `frontend`: `npm run build` 성공
- `backend`: `mvn "-Dtest=CommonCodeApiControllerTest,CommonCodeBatchServiceImplTest,CommonCodeMapperJdbcTypeTest" test` 성공
