# 20260923_009 프로필 내 정보 관리·보안 설정 계획서

## 1. 목적

대시보드 프로필 팝오버의 `내 정보 관리`와 `보안 설정` 메뉴를 실제 독립 페이지로 연결한다. 인증된 사용자가 본인의 이메일·프로필 이미지·도장 이미지를 수정하고, 현재 비밀번호 검증을 거쳐 비밀번호를 변경할 수 있도록 프론트엔드와 백엔드 계약을 추가한다.

## 2. 확정 설계

- 내 정보 관리 경로: `/dashboard/profile`
- 보안 설정 경로: `/dashboard/security`
- 이미지 저장: 기존 `tb_login_account.profile_image`, `tb_login_account.stamp_image` TEXT 컬럼 재사용
- 이메일 저장: 기존 `tb_user.email_addr` 컬럼 갱신
- 이미지 제한: PNG/JPEG, 원본 1MB 이하, 최대 512x512, 저장 전 정규화
- 비밀번호 변경 성공 시 인증 토큰·세션을 폐기하고 `/login`으로 이동
- 신규 테이블·컬럼·FK·마이그레이션 없음

## 3. 영향 범위

### 프론트엔드

- `DashboardPage` 프로필 액션 라우팅
- 대시보드 라우팅/콘텐츠 분기 또는 기존 라우트 등록 패턴
- 프로필 페이지 컴포넌트, 보안 설정 페이지 컴포넌트
- 사용자 프로필 서비스와 타입
- 로그인 상태/토큰 정리 흐름
- Vitest 컴포넌트·서비스 테스트 및 Playwright 캡처 스크립트/결과 문서

### 백엔드

- 인증된 본인 프로필 조회·수정 API
- 비밀번호 변경 API
- 사용자 프로필 서비스/DAO/Mapper
- 이미지 Data URL 검증·정규화 유틸리티 또는 서비스 로직
- 현재 로그인 사용자 식별 및 토큰 무효화 정책
- API 단위/컨트롤러 테스트

### 데이터베이스

- 현재 스키마 변경 없음
- MCP 확인 근거: `tb_user.email_addr`, `tb_login_account.profile_image`, `tb_login_account.stamp_image`, `tb_login_account.password_changed_at` 존재
- 별도 SQL·롤백 파일 작성 대상 아님

## 4. 구현 단계

1. 기존 프로필·인증 타입과 API 호출 패턴을 확인하고 실패하는 서비스/컴포넌트 테스트를 추가한다.
2. 백엔드 본인 프로필 조회·수정 및 비밀번호 변경 계약을 구현한다.
3. 이미지 MIME·용량·픽셀 검증과 512x512 이내 정규화를 적용한다.
4. 프론트엔드 프로필/보안 페이지와 저장·오류·로딩 상태를 구현한다.
5. 프로필 팝오버 액션을 두 페이지 경로에 연결하고 저장 후 사용자 표시를 갱신한다.
6. 프론트 관련 테스트와 build, 백엔드 Maven 테스트를 실행한다.
7. 375px/768px/1280px 브라우저 검증과 캡처를 수행한다.
8. 실패가 있으면 원인을 기록하고 해당 범위만 수정한 뒤 동일 검증을 재실행한다.
9. 결과 문서와 작업 원장에 DB 영향 없음, 검증 명령, 캡처 경로, 리뷰 결과를 기록한다.

## 5. 검증 계획

### Frontend

- 프로필 메뉴의 두 경로 이동 테스트
- 프로필 입력·이미지 미리보기·삭제·저장 성공/실패 테스트
- 이미지 형식·용량 클라이언트 검증 테스트
- 비밀번호 필수값·확인값 불일치·성공 후 로그아웃 테스트
- `npm run test -- <관련 테스트>`
- `npm run build`

### Backend

- 본인 프로필 조회/수정과 타 사용자 대상 지정 차단 테스트
- 이메일·이미지 검증 및 DB 갱신 매퍼 테스트
- 현재 비밀번호 불일치·새 비밀번호 해시 갱신 테스트
- `mvn test`

### Browser

- 로그인 후 프로필 팝오버에서 두 메뉴 이동
- 375px, 768px, 1280px에서 폼 overflow·버튼 겹침·이미지 미리보기 확인
- 성공 저장 및 비밀번호 변경 후 로그인 화면 이동 확인

## 6. 제외 및 주의사항

- 이름·아이디·부서·직급 변경은 구현하지 않는다.
- 관리자용 타 사용자 수정 API를 만들지 않는다.
- 외부 객체 저장소나 신규 파일 테이블로 확장하지 않는다.
- 비밀번호 찾기·이메일 인증·다중 인증은 다루지 않는다.
- 기존 대시보드 메뉴 트리·세션 복원 동작은 필요한 라우팅 연결 외 변경하지 않는다.
