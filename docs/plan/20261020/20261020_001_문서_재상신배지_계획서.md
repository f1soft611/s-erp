# 문서 재상신 배지 계획서

기준: [작업지시서](../../directions/20261020/20261020_001_문서_재상신배지_작업지시서.md).

1. `frontend/tests/document-presentation.test.ts`에서 RESUBMITTED를 미지원 목록에서 제외하고 재상신/info/filled/PENDING 매핑 사례를 추가한다. 실패를 확인한다.
2. `frontend/src/pages/groupware/documents/write/data/documentPresentation.ts`의 이벤트 switch에서 기존 PENDING presentation을 재사용하고 명칭만 재상신으로 지정한다.
3. `frontend/tests/feed-components.test.tsx`에 재상신 배지 표시 사례를 추가하고 두 테스트 파일을 함께 실행한다.
4. 기존 공통 변환이 피드/상세에 적용되는지 확인한다. 진행 중인 상세 댓글 갱신 변경은 수정하지 않는다.
5. 빌드 및 합성 실제 컴포넌트 브라우저 검증으로 375px/768px/1280px에서 배지 텍스트, info 클래스, 8px 모서리와 가로 넘침을 확인한다.
6. `docs/result/20261020/document-resubmission-badge`에 결과와 스크린샷을 기록하고 기존 배지 사양을 갱신한다.
