# F1-Grid 날짜 검색 기본값 계획서

## 목표

날짜 상세검색 컬럼에 고정일 또는 서버 시스템 날짜 기준 기본값을 선언하고 첫 진입·초기화·문서현황 세션 복원에서 일관되게 적용한다.

## 범위

- 백엔드 공통 시스템 날짜 조회 API 추가
- F1-Grid 날짜 기본값 metadata 타입 및 상세검색 변환
- 프런트엔드 날짜 API 서비스, 달력 기준 resolver, 기본값 hook
- `PageSearchArea`의 기본값 표시/초기화와 선택적 reset callback
- 비동기 초기 기본값을 위한 세션 저장 지연
- 문서현황 적용 및 기존 문서현황/F1-Grid 문서 갱신
- 타깃 테스트, 프런트엔드 빌드, 브라우저 검증 및 결과 문서

DB 스키마 및 업무 데이터 API 계약 변경은 없다.

## 구현 순서

1. 작업지시서·계획서·상세사양서를 작성한다.
2. `GET /api/v1/common/system-date`를 `EgovDateUtil.getToday()`의 `yyyyMMdd` 값을 ISO 날짜로 정규화해 표준 `ResultVO` 응답으로 추가하고, 응답 형식과 인증을 컨트롤러 테스트로 검증한다.
3. `F1GridDateDefault` 및 `F1GridDateRangeDefault`를 추가하고 `search.defaultValue`를 `PageSearchField`까지 전달한다.
4. 서버 날짜 client와 fixed/systemDate resolver를 테스트 우선으로 구현한다. 서버 날짜는 ISO 형식과 실제 날짜인지 검증하고, 달력 연산 순서는 연도·월·일로 고정한다.
5. `usePageSearchDefaults`에서 loading/error/retry를 제공한다. API 실패는 오류로 노출하고 브라우저 날짜를 사용하지 않는다.
6. `PageSearchArea`에 resolved defaults와 선택적 `onDetailReset`을 연결한다. 기존에는 초기화가 검색을 실행하지 않으며 callback이 전달된 페이지에서만 초기화 검색을 적용한다.
7. `usePageSessionState`의 `persistWhen` 옵션으로 비동기 기본값이 준비될 때까지 임시 상태 저장을 막는다.
8. 문서현황의 `submittedAt` metadata에 최근 1개월 범위를 선언하고, 초기 조회/사용자 세션/초기화/재시도 흐름을 구현한다.
9. F1-GRID 문서와 결과 문서 및 반응형 스크린샷을 작성한다.
10. 계획의 타깃 검증 명령과 실제 브라우저 검증을 수행한다.

## 주요 파일

- Backend: `CommonSystemDateApiController.java`, 대응 JUnit 테스트
- Frontend shared: `grid.types.ts`, `searchFields.ts`, `systemDateService.ts`, `searchDefaults.ts`, `usePageSearchDefaults.ts`, `PageSearchArea.tsx`, `usePageSessionState.ts`
- Document status: `DocumentStatusGrid.tsx`, `DocumentStatusPage.tsx`
- Tests: F1-Grid metadata/resolver, system-date service, search-area, defaults hook, page-session-state, document-status-page tests
- Docs: 본 문서와 같은 날짜 폴더의 작업지시서·상세사양서, `frontend/src/pages/f1-grid-docs/F1-GRID.md`, 결과 문서 및 스크린샷

## 검증 및 완료 기준

- 고정/상대 날짜와 월말·윤년 경계 및 비정상 값 검증
- API 오류, 재시도, 초기 요청 차단, 세션 복원 우선순위, reset callback 검증
- `npm run build`, 관련 Vitest와 `mvn "-Dtest=CommonSystemDateApiControllerTest" test`
- 375px, 768px, 1280px 브라우저 확인 및 접근 제한 시 그 제한 기록
- 날짜 기본값을 사용하지 않는 검색 필드와 페이지의 기존 reset 동작을 보존한다.
