# 납품관리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** 수주 연계 및 직납품을 지원하는 납품등록·납품현황과 DB/메뉴 스크립트를 제공한다.

**Architecture:** 기존 수주등록의 eGovFrame Controller → Service → DAO → MyBatis 구조와 React 기능별 디렉터리를 따른다. 납품 헤더/상세를 분리하고 수주 참조는 선택 사항으로 관리한다. 연결 수주 헤더 잠금으로 잔량 검사와 출하수량 보정을 직렬화한다.

**Tech Stack:** Java 8 compatible Spring/eGovFrame, PostgreSQL, MyBatis, React/TypeScript, MUI, F1-Grid, Vitest, Maven, Playwright.
