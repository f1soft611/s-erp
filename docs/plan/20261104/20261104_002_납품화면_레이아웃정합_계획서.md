# 납품 화면 레이아웃 정합 계획서

1. 수주/납품 등록·현황과 상세/편집 컴포넌트를 직접 비교한다.
2. [사양서](../../spec/20261104/20261104_002_납품화면_레이아웃정합_상세사양서.md)를 기준으로 레이아웃 회귀 테스트를 먼저 추가하고 실패를 확인한다.
3. 납품등록 PageHeader 액션/기본정보/상세/합계를 수주 구조로 맞춘다. 별도 상단 액션바와 선택 행 삭제 버튼을 제거하고 우클릭 삭제는 유지한다.
4. 납품현황 검색/안내/그리드 배치를 맞추고, 수주와 같은 페이지 영역 상세패널 및 조회/수정 모달 하단 액션을 구현한다.
5. 집중 Vitest, build, 변경 파일 lint, 4173 실제 브라우저 375/768/1280px 비교를 수행한다.
6. `docs/result/20261104/sales-delivery-layout`에 전후 차이·원인·회귀항목과 스크린샷을 기록한다.

백엔드/SQL/공통 F1-Grid 자체 변경은 없다. 기존 납품 기능/권한/오류 시 입력 보존을 유지한다.
