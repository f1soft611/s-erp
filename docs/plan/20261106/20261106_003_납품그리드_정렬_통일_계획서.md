# 납품 그리드 정렬 통일 계획서

- 작업지시서: [20261106_003](../../directions/20261106/20261106_003_납품그리드_정렬_통일_작업지시서.md)

## 작업 단계

1. 납품등록 상세/계획선택과 납품현황 그리드의 현재 컬럼 정렬을 확인한다.
2. 기존 납품 화면 테스트에 코드·명칭 가운데, 텍스트 왼쪽, 숫자 오른쪽 정렬 검증을 추가한다.
3. 해당 컬럼 정의에 `align`을 명시해 F1-Grid 기본 정렬 추론에 의존하지 않도록 한다.
4. F1-Grid 사용 문서의 납품 화면 적용 기준과 결과서를 갱신한다.
5. 관련 Vitest, 프론트엔드 빌드, 브라우저 렌더링을 검증한다.

## 범위 제외

공통 F1-Grid 구현, 필드 순서/폭, 데이터 표시 형식, 메뉴 및 백엔드 계약은 변경하지 않는다.
