# 납품계획번호 채번 규칙 정렬 계획서

## 목표

납품계획번호 생성의 표시 형식과 유효성 검증을 수주·납품번호의 공통 규칙과 맞춘다.

## 기준 문서

- [작업지시서](../../directions/20261106/20261106_002_납품계획번호_채번규칙_정렬_작업지시서.md)
- 수주번호: `SO-YYYYMMDD-0001`
- 납품번호: `SD-YYYYMMDD-0001`

## 실행 단계

1. 납품계획 채번 테스트에서 30자 초과 번호를 저장 전에 거부하는 동작을 먼저 검증한다.
2. `SalesDeliveryPlanServiceImpl.generatePlanNo`에 공통 로케일 고정 포맷과 길이 검증을 적용한다.
3. 정상 번호 형식 및 초과 길이 테스트와 백엔드 테스트를 실행한다.
4. 구현 및 검증 결과를 결과 문서에 남긴다.

## 범위 제외

- 접두사 변경, 채번 날짜 기준 변경, sequence key 변경, DB 스키마 변경, 화면 변경은 하지 않는다.
