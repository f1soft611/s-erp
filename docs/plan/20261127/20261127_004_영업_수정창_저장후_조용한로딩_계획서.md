# 영업 수정 창 저장 후 조용한 로딩 계획서

- 작성일: 2026-11-27
- 작업지시서: [영업 수정 창 저장 후 조용한 로딩](../../directions/20261127/20261127_004_영업_수정창_저장후_조용한로딩_작업지시서.md)
- 기준 화면: 출하현황 `SalesDeliveryStatusPage.handleSaved`(`quietRefresh` 후 재조회)

## 구현 단위

1. 거래명세서현황 `useSalesStatementStatus`
   - `quietRefresh` 상태(조용히 처리할 refresh 번호)를 두고, 목록 요청 시작 시 그 번호면 `setLoading(true)`를 생략한다.
   - `saved`/`deleted`는 `refreshQuietly()`로 재조회한다. `search`·`retry`는 그대로 로딩을 표시한다.
2. 출하계획현황 `SalesDeliveryPlanStatusPage`
   - 수정 창 저장 중 상태를 `saving`으로 분리해 저장·취소 버튼, 그리드 편집, 닫기 잠금에 사용한다.
   - `runSearch(next, { quiet })`: quiet면 `loading`을 켜지 않는다. 저장 후 `runSearch(filters, { quiet: true })`.
3. 테스트(먼저 작성)
   - `sales-statement-page.test.tsx`: 수정 창 저장 후 재조회 대기 중 `거래명세서현황 목록` 그리드가 `aria-busy`가 아니고 행 유지.
   - `sales-delivery-plan-page.test.tsx`: 저장 대기 중·재조회 대기 중 `출하계획 현황 목록` 그리드가 `aria-busy`가 아님.
4. 로컬 브라우저 확인, 결과 문서 `docs/result/20261127/sales-editor-quiet-refresh`.
