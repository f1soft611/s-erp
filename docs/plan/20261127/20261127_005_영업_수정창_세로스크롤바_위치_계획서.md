# 영업 수정 창 세로 스크롤바 위치 계획서

- 작성일: 2026-11-27
- 작업지시서: [영업 수정 창 세로 스크롤바 위치](../../directions/20261127/20261127_005_영업_수정창_세로스크롤바_위치_작업지시서.md)

## 방식

스크롤 영역(등록 화면 영역)은 그대로 두고, 여백 위치만 옮긴다. 스크롤 대상을 `DialogContent`로 바꾸는 방식은 그리드 높이 채우기(`bodyMode="fill"`) 레이아웃이 달라질 위험이 있어 택하지 않는다.

1. `CommonDialog`에 `disableBodyGutters?: boolean` 추가. true면 `DialogContent`의 `px`·`py`를 0으로 한다. 같은 파일에 기존 본문 여백 값을 `COMMON_DIALOG_BODY_PADDING`(`px: { xs: 2, sm: 3 }`, `py: 2`)으로 export해 여백 값이 한 곳에서 관리되게 한다.
2. 등록 화면 4개(`QuotationCreatePage`, `SalesOrderCreatePage`, `SalesDeliveryCreatePage`, `SalesStatementCreatePage`)의 스크롤 영역: `embedded`이면 여백 0 대신 `COMMON_DIALOG_BODY_PADDING`을 쓴다. 비 embedded는 기존 `px/pt/pb: 2` 유지.
3. 수정 창 4개(`QuotationEditorDialog`, `SalesOrderEditorDialog`, `DeliveryEditorDialog`, `StatementEditorDialog`)와 출하계획현황 수정 창: `disableBodyGutters` 지정. 출하계획현황은 자체 스크롤 상자에 `COMMON_DIALOG_BODY_PADDING`을 둔다.
4. `frontend/AGENTS.md`의 "embedded 본문 패딩 0" 문구를 수정 창 기준으로 갱신한다.
5. 테스트(먼저 작성): 견적 수정 창에서 `DialogContent` 좌우 여백 0, 스크롤 영역(`견적 입력 내용`)이 `overflowY: auto`이면서 좌우 24px 여백을 가짐. 메뉴에서 연 견적 등록 화면은 기존 16px 유지.
6. 로컬 브라우저: 5개 수정 창에서 스크롤 영역 오른쪽 끝과 창 오른쪽 끝 좌표, 기본정보 패널 좌표를 변경 전후로 측정.

## 영향 범위

프론트엔드만. `CommonDialog`는 선택 옵션 추가라 기존 사용처 동작 변화 없음.
