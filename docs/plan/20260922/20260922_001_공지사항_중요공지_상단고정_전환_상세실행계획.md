# 20260922_001 공지사항 중요 공지 기능 상단 고정 전환 상세 실행 계획

## Global Constraints

- 현재 브랜치 `socra710`에서 진행하며 새 worktree는 생성하지 않는다.
- 기존 사용자 변경 파일은 되돌리거나 덮어쓰지 않는다.
- API 필드명은 `isPinned`, DB 컬럼명은 `is_pinned`로 통일한다.
- 공지 도메인의 모든 페이징 목록 API는 `ComDefaultVO` + `PaginationInfo` + 동일 조건 count 조회 + `ListResult<T>` 응답을 사용한다. 상세·단건 API는 제외한다.
- 작성/수정 모달에는 고정 입력을 추가하지 않는다.
- 일반 피드와 상단 고정 영역은 같은 목록 API를 별도 요청으로 호출한다.
- 일반 피드는 1기반 페이지, `size=20`을 사용하며 목록 끝에서 누적한다.
- 첨부 프로젝트의 공통 페이징 방식을 따라 검색 VO는 `ComDefaultVO`를 상속하고 `PaginationInfo`로 인덱스를 계산한다. 목록과 전체 건수는 `ListResult<T>`로 묶되 기존 `ResultVO` 외부 응답 래퍼는 유지한다.
- 각 태스크는 테스트 우선 RED → 최소 GREEN → REFACTOR 순서로 진행한다.
