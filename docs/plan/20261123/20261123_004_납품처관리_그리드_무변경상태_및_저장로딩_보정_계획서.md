# 납품처 관리 그리드 상태 및 저장 로딩 보정 계획서

기준: [작업지시서](../../directions/20261123/20261123_004_납품처관리_그리드_무변경상태_및_저장로딩_보정_작업지시서.md)

1. F1-Grid 텍스트 셀의 편집 확정 경로와 납품처 화면의 저장·조회 상태 처리를 확인한다.
2. 빈 텍스트 셀의 무변경 확정, 거래처 미선택 초기 그리드, 저장 후 수정값 유지·성공 토스트·목록 갱신을 재현하는 회귀 테스트를 추가한다.
3. nullable 원본 값이 비어 있는 텍스트 편집을 확정할 때 원본 null을 유지하고, 해당 필드가 dirty로 바뀌지 않게 한다.
4. 납품처 저장 성공 후 변경 행을 `acceptSavedRows`로 확정해 재조회 전 수정값을 유지하고 공통 성공 토스트를 표시한다. customer/destination 재조회는 기존 데이터를 유지하는 조용한 갱신으로 처리하고 실패는 메시지로 표시한다.
5. 거래처 선택 전에도 우측 F1Grid를 렌더링하며, 선택 전에는 행 등록·편집 기능을 비활성화한다.
6. F1-Grid 동작 문서를 갱신하고 납품처 결과 문서 및 화면 검증 자료를 작성한다.
7. 납품처 관리 테스트와 F1-Grid 테스트, TypeScript/Vite 빌드를 실행해 확인한다.
