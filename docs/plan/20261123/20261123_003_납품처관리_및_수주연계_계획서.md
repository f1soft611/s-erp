# 납품처 관리 및 수주 연계 계획서

기준: [작업지시서](../../directions/20261123/20261123_003_납품처관리_및_수주연계_작업지시서.md)

1. 기존 거래처 관리, 수주 등록·조회·수정, 메뉴 및 관련 DB 참조 관계를
   확인하고 사용자 승인 범위에 맞게 상세 계약을 정리한다.
2. 거래처별 납품처 마스터와 수주 필수 참조, 단일 테넌트 초기화,
   메뉴 seed의 SQL·이력·안전한 롤백을 설계한다. DB 직접 적용은 하지 않는다.
3. 납품처 관리 API와 화면, 등록 여부 표시 및 수주등록의 거래처·납품처·
   매출처 선택 흐름을 기존 공통 패턴에 맞춰 구현한다.
4. 관련 회귀 테스트, 빌드, Java 8 API 호환성과 375·768·1280px 실제
   브라우저 동작을 검증한다.
5. 결과와 스크린샷을 날짜별 결과 폴더에 기록한다.
