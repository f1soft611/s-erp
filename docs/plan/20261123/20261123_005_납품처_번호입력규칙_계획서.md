# 납품처 번호 입력 규칙 계획서

기준: [작업지시서](../../directions/20261123/20261123_005_납품처_번호입력규칙_작업지시서.md)

1. `frontend/tests/sales-destination-page.test.tsx`에 행 폼과 셀에서 자동 하이픈, 자리수 검증 및 빈 값 허용 회귀 테스트를 추가하고 기존 구현에서 실패를 확인한다.
2. `frontend/src/pages/sales/master/destination/data/salesDestinationColumns.tsx`의 `businessNo`에 `inputFormat: { type: 'digits', groupSizes: [3, 2], maxDigits: 10, validDigitCounts: [10] }`를 지정한다.
3. 같은 파일의 `mobileNo`, `telephoneNo`, `facsimileNo`에 `inputFormat: { type: 'korean-phone', maxDigits: 11 }`을 지정한다. 필수·중복 제약은 추가하지 않는다.
4. 납품처 화면 테스트와 공통 입력 형식 테스트, 빌드·lint를 실행하고 F1-Grid 문서와 결과를 기록한다.
