# 시스템 모서리 4px 통일 계획서

**목표:** 공통 테마 및 사각형 UI의 모서리 반경을 4px로 통일한다.

**방식:** MUI 공통 shape를 4로 바꾸고, 개별 사각형 지정과 부분 모서리도 4px로 정규화한다. 원형과 0px 접합은 보존한다.

**기술:** React, TypeScript, MUI, CSS, Vitest, Vite.

## 작업

1. [작업지시서](../../directions/20261123/20261123_004_시스템_모서리_4px_작업지시서.md)를 기준으로 상세 사양을 작성한다.
2. `frontend/tests/theme-radius.test.ts`와 기존 배지 테스트의 반경 기대값을 4px로 변경하고 관련 테스트가 현재 실패하는지 확인한다.
3. `frontend/src/theme/theme.ts`의 공통 반경을 4로 변경한다. `frontend/src`의 사각형 `6px`, 부분 모서리 `6px`, MUI `borderRadius: 1.5` 또는 `2`를 4px 또는 MUI 단위 `1`로 변경한다. 원형과 0은 변경하지 않는다.
4. 공통 다이얼로그, 달력, 그리드 입력 및 화면별 배지의 반경과 예외를 회귀 테스트한다. F1-Grid 관련 문서도 갱신한다.
5. 관련 Vitest, `npm run build`, `npm run lint`, 실제 브라우저 375/768/1280px 확인을 수행하고 결과 및 스크린샷을 기록한다.
