# 20261123_003 구매자재·수입검사 "행" 열 이름·정수 표시 계획서

기준: [작업지시서](../../directions/20261123/20261123_003_purchase-line-no-column_작업지시서.md)

1. **점검**: 구매자재(request·order·arrival·receipt)와 quality/inspect의 grid·상세 패널에서 헤더 "행"과 `lineNo`/`rownumber` 열을 전수 검색한다(검색 결과: 표 열 8곳, 상세 패널 머리글 5곳).
2. **열 정의 변경**: `lineNo` 열은 머리글 "순번", `decimalPlaces: 0`(열 옵션이 모듈 소수점 정책보다 우선). 등록 화면의 `rownumber` 열 "행"은 머리글만 "순번". 상세 패널(MUI 표) 머리글도 "순번".
3. **매입마감 구매처 요약**: 첫 열에 `rownumber` No 열 추가(오른쪽 입고 행 표의 No와 같은 모양).
4. **테스트·검증**: 열 정의 단위 테스트(머리글·소수점), 영향 있는 기존 테스트, `tsc`, 브라우저(소수점 정책이 있는 상태에서 정수 표시).

위험: 열 이름을 바꾸므로 기존 테스트가 "행"을 찾고 있으면 함께 갱신한다. 그리드 저장 키는 열이 늘거나 이름만 바뀌는 정도라 유지하되, 매입마감 구매처 요약은 열이 늘어 키 번호를 올린다.
