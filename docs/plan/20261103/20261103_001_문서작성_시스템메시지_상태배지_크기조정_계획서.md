# 문서작성 시스템 메시지 상태 배지 크기 조정 계획서

**Goal:** 시스템 이벤트 상태 배지의 글자 크기와 시각적 크기를 작성자 이름에 맞춰 축소한다.

**Architecture:** 공통 댓글 렌더러의 선택적 `systemEventBadge` Chip에만 밀도 스타일을 적용한다. 작성자와 같은 `caption` 글자 크기, 20px 높이, 6px 좌우 라벨 여백을 지정하고 이벤트 매핑, 팔레트, variant 및 일반 댓글은 그대로 둔다.

**Tech Stack:** React, TypeScript, MUI Chip, Vitest, Testing Library, Playwright.
