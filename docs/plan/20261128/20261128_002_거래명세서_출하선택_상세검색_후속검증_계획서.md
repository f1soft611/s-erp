## 2. 기준 화면

출하등록의 `수주 선택` 도움창(`SourceOrderPicker`). 창 크기·위치, 통합검색·상세검색 배치, 하단 `선택`/`닫기` 버튼을 비교한다.

## 3. 진행 순서

1. 커밋 diff로 프론트·백엔드 계약 정리 → 사양서 작성
2. Maven 의존성 classpath 생성 후 변경 Java 파일을 `--release 8`로 컴파일. 같은 방법으로 Java 9+ API(`List.of`)가 거부되는지 대조 확인
3. Playwright 스크립트(임시, 저장소 밖)로 1280·768·375px 확인
   - 도움창 열기 → 통합검색 Enter → 기본 조회 파라미터(출하일 한 달 전~오늘) 확인
   - 상세검색 열기 → 필드 6개 확인 → 출하번호 입력 후 검색 → 요청 파라미터·결과 확인
   - 1280px: 거래처 A 선택 시 거래처 B 행 선택 불가, `선택` 후 창 닫힘, 기준 화면 캡처, 현황 No 컬럼
   - 768·375px: `닫기`로 창 닫힘
4. 영업 프론트 테스트 실행, 결과 문서 작성

## 4. 위험

- 가짜 응답이라 서버 SQL 필터 결과는 확인하지 않는다. SQL은 기존 Mapper 테스트(`SalesStatementMapperTest`)가 근거다.
