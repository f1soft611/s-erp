# 출하등록 단가 편집 테스트 간헐 실패 계획서

- 작성일: 2026-11-28
- 작업지시서: [20261128_003](../../directions/20261128/20261128_003_출하등록_단가편집_테스트_간헐실패_작업지시서.md)

## 1. 가설

테스트는 헤더 출하번호(`SD-1`) 표시만 기다린 뒤 단가 셀을 텍스트 `100.000000`으로 바로 찾는다. 헤더(출하 조회)와 소수점 정책 조회는 서로 다른 비동기 요청이므로, 부하로 정책 적용이 늦으면 셀이 아직 정책 형식이 아니어서 `find`가 `undefined`를 돌려준다. 같은 파일의 다음 테스트(`uses shipment column overrides…`)는 정책 형식 셀을 `waitFor`로 기다려 이 문제가 없다.

## 2. 진행 순서

1. 이 테스트에서만 정책 응답을 300ms 지연시켜 실패를 결정적으로 재현
2. 정책이 적용된 셀을 `findByText`로 기다리도록 테스트 수정, 지연 상태에서 반복 통과 확인
3. 임시 지연 제거, 파일 전체·영업 테스트 전체 실행

## 3. 범위

- `frontend/tests/sales-delivery-page.test.tsx` 한 줄 수정. 운영 코드 변경 없음(정책 적용 전에는 편집·저장이 정책 대기 상태로 막혀 있는 기존 설계).
