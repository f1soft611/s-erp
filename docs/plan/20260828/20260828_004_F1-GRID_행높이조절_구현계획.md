# F1-GRID 행 높이 조절 구현 계획

## 목표

기본 긴 텍스트는 말줄임표로 표시하고, 행별 드래그 또는 키보드 조절 시 `wrapText` 컬럼을 줄바꿈 표시한다.

## 구현 범위

- `F1Grid`가 행 ID별 높이를 런타임 상태로 관리
- 기본/최소/최대 높이 옵션 제공
- 행 하단 resize 핸들의 포인터 및 ArrowUp/ArrowDown 조절
- `GridCell`의 말줄임표, 전체값 title, 높이 증가 시 줄바꿈
- 순수 높이 보정 유틸리티 및 Vitest 회귀 테스트
- F1-GRID 가이드와 결과 문서 갱신

## 검증

집중 테스트, 전체 Vitest, TypeScript/Vite build를 실행한다. 서버·DB·행 높이 영속화는 범위에서 제외한다.
