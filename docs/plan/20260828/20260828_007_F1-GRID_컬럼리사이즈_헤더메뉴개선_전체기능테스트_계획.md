# 계획서: F1-GRID 컬럼 리사이즈, 헤더 더보기 메뉴 개선 및 전 기능 종합 테스트

## 1. 구현 목표 및 범위

1. **컬럼 너비 리사이즈 (Column Resize)**:
   - `F1GridProps`에 `resizableColumns?: boolean` (기본값 true), `minColumnWidth?: number` (기본값 50) 추가.
   - `GridHeader.tsx`에 컬럼 리사이즈 핸들 추가 및 드래그 이벤트 연동.
   - 리사이즈된 컬럼 너비 상태(`columnWidths: Record<string, number>`)를 상위 `F1Grid`에서 관리하여 `GridHeader` 및 `GridBody` 그리드 템플릿과 핀 오프셋 계산에 즉시 동기화.
2. **헤더 더보기 버튼 마우스 호버 노출 및 우측 끝 정렬**:
   - 헤더 셀 레이아웃을 정비하여 라벨/정렬/필터는 좌측 및 중앙에, 더보기 버튼은 `margin-left: auto`로 우측 끝에 배치.
   - 평소 `opacity: 0` (포커스 또는 메뉴 오픈 시 `opacity: 1`), 헤더 셀 호버 시 `opacity: 1` 처리.
3. **F1GridTestPage 전 기능/옵션 종합 구축**:
   - 11개 전체 에디터 타입 컬럼 구성:
     1. `itemCode` (code - 팝업 픽커 연동)
     2. `itemName` (text - 행 병합 mergeRows, 줄바꿈 wrapText 지원)
     3. `category` (select - 드롭다운)
     4. `status` (autocomplete - 자동완성)
     5. `qty` (number - 최소 1 이상)
     6. `price` (currency - 통화 포맷)
     7. `ratio` (decimal - 소수점)
     8. `useYn` (checkbox - 헤더 전체선택 headerCheckbox 지원)
     9. `regDate` (date - 날짜)
     10. `deliveryAt` (datetime - 일시)
     11. `workTime` (time - 시각)
   - 툴바 액션: 행 추가, 행 삭제, 행 복제, 삭제 복구, 선택 해제, 유효성 검증, 변경 내역(`getChanges()`) 요약 뱃지.
   - 그리드 옵션 토글: 행 높이 조절 가능 여부, 컬럼 리사이즈 가능 여부, 컬럼 구분선 토글 등.
4. **검증 및 스크린샷 캡처**:
   - 단위 테스트 작성 및 통과 확인.
   - 브라우저 스크립트를 통한 실제 화면 및 동작 스크린샷 캡처 및 결과 보고서 작성.
