# 20260828_002 F1-GRID 폴더 구조 및 명칭 정리 계획서

## 1. 개요

F1-GRID 가이드 문서(`frontend/src/pages/f1-grid-docs/F1-GRID.md`) 기준에 맞춰 `frontend/src/shared/components/f1-grid` 컴포넌트의 디렉터리 구조를 정렬하고, `ERPGrid` 잔재 명칭을 `F1Grid`로 변경한다.

## 2. 세부 단계 계획

### 단계 1: 사양서 작성

- `docs/spec/20260828/20260828_002_F1-GRID_폴더구조_및_명칭정리_사양.md` 작성
- 이동 대상 파일 및 타입/함수 이름 변경 매핑 정의

### 단계 2: 모듈 이동 및 명칭 변경

- `core/ERPGrid.tsx` -> `core/F1Grid.tsx` (ERPGrid export를 F1Grid로 변경)
- `f1Grid.state.ts` -> `state/GridState.ts`
- `f1Grid.merge.ts` -> `merge/GridRowMerge.ts`
- `f1Grid.types.ts` & `types/grid.types.ts` -> `types/grid.types.ts`
- `utils/f1Grid.utils.ts` & `utils/grid.utils.ts` -> `utils/grid.utils.ts`
- `index.ts` 메인 모듈 엔트리 생성 (`F1Grid`, `F1GridProps` 및 주요 타입/함수 export)
- `F1Grid.tsx`는 기존 소비자 호환용 re-export 엔트리로 유지

### 단계 3: 내부 및 외부 참조 경로 수정

- `f1-grid` 내부 컴포넌트 import 경로 업데이트
- `MenuManagementPanel.tsx` 및 `f1-grid.test.tsx` import 경로 수정 및 `ERPGrid` 참조 제거

### 단계 4: 검증 및 결과 작성

- `npm run test` 실행
- `npm run build` 실행
- `docs/result/20260828/f1-grid-structure-cleanup/20260828_002_F1-GRID_폴더구조_및_명칭정리_결과.md` 결과 문서 작성
