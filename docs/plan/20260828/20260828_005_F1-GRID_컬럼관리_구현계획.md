# F1-GRID Column Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 헤더 메뉴의 컬럼 목록 서브메뉴에서 F1-GRID 컬럼을 숨기고 다시 표시한다.

**Architecture:** `GridColumnManagement.ts`에 표시 컬럼 계산과 마지막 컬럼 보호 규칙을 순수 함수로 둔다. `F1Grid`가 숨김 상태를 소유하고, 계산된 표시 컬럼을 Header와 Body에 전달한다. `GridHeader`는 헤더별 메뉴와 컬럼 목록 서브메뉴를 렌더링한다.

**Tech Stack:** React 19, TypeScript, MUI Menu/Checkbox, Vitest, Testing Library
