# F1-GRID Header Menu Sort/Filter/Pin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F1-GRID 컬럼 헤더 더보기 메뉴에 정렬(다중 컬럼)/필터(타입별 연산자)/컬럼 고정(sticky)을 추가하고, 헤더 구분선을 항상 표시한다.

**Architecture:** `sorting/GridSort.ts`, `filter/GridFilter.ts`, `columns/GridColumnPin.ts`에 순수 함수를 두고 `F1Grid`가 `sortState`/`filterState`/`pinnedFields` 상태를 소유한다. `GridHeader`가 메뉴 UI와 필터 팝오버를 렌더링하고, `GridHeader`/`GridCell`이 고정 컬럼 sticky 스타일을 적용한다.

**Tech Stack:** React 19, TypeScript, MUI Menu/Select/TextField, Vitest, Testing Library
