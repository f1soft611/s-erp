# F1-GRID Clipboard, Validation, and Editor Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the reusable F1 Grid with TSV clipboard operations, cell validation, ERP editor types, keyboard commands, and an interactive system-management test page.

**Architecture:** Keep `core/F1Grid.tsx` as the owner of focus, editing, internal row state, and the imperative ref. Add pure clipboard and validation modules that work only with typed rows and columns; core coordinates their inputs, applies returned row patches through `GridState`, and passes cell errors to the renderer. Editor modules remain presentation-focused and the test page owns its sample data and code-picker dialog.

**Tech Stack:** React 19, TypeScript, MUI 9, Vitest, Testing Library, Vite.

```ts
export type F1GridEditorType =
  | 'text'
  | 'number'
  | 'decimal'
  | 'currency'
  | 'date'
  | 'datetime'
  | 'time'
  | 'checkbox'
  | 'select'
  | 'autocomplete'
  | 'code';

export function parseGridTsv(value: string): string[][] {
  return value
    .replace(/\r\n/g, '\n')
    .replace(/\r/g, '\n')
    .split('\n')
    .filter((line, index, lines) => line !== '' || index < lines.length - 1)
    .map((line) => line.split('\t'));
}
```

Implement `toGridTsv` using the configured column order and `coerceClipboardValue` for `number`, `decimal`, `currency`, and `checkbox`; return `undefined` for invalid numeric values.
