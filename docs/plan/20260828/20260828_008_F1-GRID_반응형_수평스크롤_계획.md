# F1-GRID 반응형 수평 스크롤 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 좁은 화면에서 앱 셸은 가용 폭으로 축소되고, F1-GRID만 자체 수평 스크롤로 고정 컬럼 폭을 제공한다.

**구조:** `DashboardPage`의 중앙 flex item에 `minWidth: 0`을 추가하여 자식의 max-content 폭이 페이지 폭을 넓히지 않게 한다. `F1Grid` 루트는 최대 폭을 부모에 제한하고 수평 오버플로우를 담당하며, `GridHeader`와 `GridBody`의 현재 max-content 컬럼 레이아웃은 유지한다.

**기술:** React 19, TypeScript, MUI System `sx`, Vitest, Testing Library, Playwright 캡처 스크립트

---
