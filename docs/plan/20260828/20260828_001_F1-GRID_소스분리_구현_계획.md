# F1-GRID Source Separation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the F1-GRID implementation by responsibility while preserving the current public import and behavior.

**Architecture:** `core/ERPGrid.tsx` composes the grid and owns orchestration state. Header/body/row/cell/footer rendering is isolated from pure selection, keyboard, editing, type, and utility modules. `F1Grid.tsx` remains a compatibility export for existing consumers.

**Tech Stack:** React 19, TypeScript, MUI 9, Vitest, Testing Library
