# F1Grid 엑셀 내보내기 권한 공통 처리 계획서

## 목표

엑셀 내보내기 메뉴를 사용하는 모든 실제 업무 화면에서 메뉴 표시 여부가 해당 메뉴의 엑셀 권한과 일치하도록 한다.

## 설계

공통 `F1Grid`와 `F1Tree`의 `canExportExcel` 입력 및 기본값(false)은 변경하지 않는다. 페이지 권한을 이미 가진 화면은 이 값을 하위 그리드까지 전달하고, 테스트에서 허용·거부 두 경우를 검증한다. 이 방식은 기존 컴포넌트 계약을 유지하면서 권한 정보를 화면에서 그리드로 명시적으로 흐르게 한다.

## 변경 파일

- `frontend/src/pages/groupware/documents/status/DocumentStatusPage.tsx`
- `frontend/src/pages/groupware/documents/status/components/DocumentStatusGrid.tsx`
- `frontend/src/pages/co/workflow/form/components/DraftFormGrid.tsx`
- `frontend/src/pages/groupware/community/archive/ArchiveBoardPage.tsx`
- `frontend/src/pages/groupware/community/archive/components/ArchiveFileGrid.tsx`
- `frontend/tests/document-status-page.test.tsx`
- `frontend/tests/draft-form-management.test.tsx`
- `frontend/tests/archive-page.test.tsx`
- `docs/result/20261022/f1-grid-excel-permission/` 내 결과 문서 및 검증 스크린샷

## 작업 1: 실패하는 권한 회귀 테스트 작성

1. 문서현황 테스트에서 권한이 있는 경우(`selectedMenuPermissions.excel === true`)에는 메뉴가 보이고, 권한이 없거나 권한 정보가 없으면 메뉴가 보이지 않는다고 검증한다.
2. 기안양식 테스트에서 `DraftFormGrid`의 `canExportExcel`이 false일 때 메뉴가 숨겨지고 true일 때 보이는 동작을 검증한다.
3. 자료실 페이지 테스트의 권한 있는 fixture에 `excel: true`를 명시하고, `excel: false`일 때 트리 메뉴가 숨겨지는 테스트를 추가한다.
4. 구현 전에 다음 테스트를 실행하고 권한 전달 누락 때문에 실패하는지 확인한다.

```powershell
Set-Location frontend
npm run test -- tests\document-status-page.test.tsx tests\draft-form-management.test.tsx tests\archive-page.test.tsx
```

## 작업 2: 권한 값을 페이지에서 공통 그리드로 전달

1. `DocumentStatusPage`에서 `selectedMenuPermissions?.excel ?? false`를 `DocumentStatusGrid`에 전달한다.
2. `DocumentStatusGrid`에 `canExportExcel: boolean` prop을 추가하고 기존 `canExportExcel` 상수 대신 해당 prop을 F1Grid에 전달한다.
3. `DraftFormGrid`는 이미 `canExportExcel` prop을 받고 있으므로 `<F1Grid>`에 `canExportExcel={canExportExcel}`을 설정한다.
4. `ArchiveBoardPage`에서 `selectedMenuPermissions?.excel ?? false`를 `ArchiveFileGrid`에 전달한다.
5. `ArchiveFileGrid`에 `canExportExcel: boolean` prop을 추가하고 `F1Tree`에 전달한다.
6. 이미 권한 연동된 거래처·자재·창고·메뉴·역할·모듈·공통코드 화면, 명시적인 비노출 설정, 문서 페이지의 인터랙티브 샘플은 변경하지 않는다.

## 작업 3: 검증 및 결과 기록

1. 작업 1의 테스트를 다시 실행해 모든 권한 허용·거부 사례가 통과하는지 확인한다.
2. F1Grid 메뉴 표시 동작을 포함한 관련 테스트를 실행한다.
3. `npm run build`로 타입 검사와 프로덕션 빌드를 확인한다.
4. 자료실 및 문서현황에서 합성 데이터로 메뉴 숨김/표시를 브라우저에서 확인하고 스크린샷을 저장한다.
5. 결과 문서에 수정 원인, 수정 범위, 테스트/빌드 결과, 기존 실패 여부 및 스크린샷 경로를 기록한다.
6. `git diff --check`를 실행하며 사용자 요청이 없으므로 커밋은 생성하지 않는다.

## 제외 범위

- F1Grid가 인증/라우팅 컨텍스트에서 권한을 직접 조회하도록 변경
- 서버 API, 백엔드 권한 검증, DB/스키마 변경
- 엑셀 값 변환/파일 생성 동작 및 메뉴의 숨김 외 UX 변경
- 메뉴 권한이 없는 다른 기능의 동작 변경
