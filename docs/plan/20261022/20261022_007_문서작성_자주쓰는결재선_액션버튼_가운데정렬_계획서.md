## 영향 파일

- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalSettingsDialog.tsx`: 액션 버튼 그룹의 셀 폭과 가로 정렬 선언
- `frontend/tests/document-approval-settings-dialog.test.tsx`: 중앙 정렬 회귀 테스트
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`: 업무작성 결재선 템플릿 Grid의 renderCell 정렬 안내
- `docs/result/20261022/document-approval-favorite-action-alignment/`: 작업 결과 및 375px, 768px, 1280px 브라우저 캡처

## 구현 순서

1. 템플릿 관리 모달 행에서 `적용`/`삭제` 버튼의 기본 최소 너비 및 좌우 패딩과 그룹 컨테이너의 중앙 정렬을 검사하는 테스트를 추가한다.
2. 새 테스트를 단독 실행해 현재 기본 버튼 최소 너비/패딩이 그대로 남아 실패하는지 확인한다.
3. 해당 화면의 renderCell 내부 버튼만 최소 너비를 해제하고 좌우 패딩을 줄인다. 컨테이너는 전체 셀 폭으로 중앙 정렬한다. 버튼 열 정의, 공통 Grid, 액션 처리 로직은 변경하지 않는다.
4. 관련 테스트 및 프론트엔드 빌드를 실행한다.
5. F1-Grid 사용자 가이드에 업무 액션 셀 정렬 기준을 덧붙이고, 결과 보고서와 합성 데이터 기반 브라우저 캡처를 작성한다.
6. 375px, 768px, 1280px에서 버튼 잘림 및 페이지 가로 넘침 여부를 확인하고 `git diff --check`를 실행한다.

## 검증 명령

```powershell
cd frontend
npx vitest run --testTimeout=15000 tests/document-approval-settings-dialog.test.tsx -t "centers favorite row action buttons in the action column"
npx vitest run --testTimeout=15000 tests/document-approval-settings-dialog.test.tsx
npm run build
git diff --check
```

기준선 확인에서 33개 중 32개 테스트가 통과했으나 1개 이름 변경 재시도 테스트가 일시 실패했다. 이후 동일 파일 전체 재실행은 34개 모두 통과했다. 기존 공유 작업공간의 무관한 변경은 보존하고 본 작업의 파일만 수정한다.
