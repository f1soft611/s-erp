# 20261119_007 구매·품질 잔여 lint 정리 계획서

기준: [작업지시서](../../directions/20261119/20261119_007_purchase-quality-lint-effect_작업지시서.md)

1. 현황 훅 3종(가입고·발주·수입검사)의 검색 초기화 / 목록 / 상세를 입고현황 훅과 같은 방식으로 정리한다(9건).
2. 등록 화면 5건은 각 effect를 읽어 건별로 방식을 정한다. 상세 로드 시작 상태는 렌더 중 보정, 불러오기 후 폼 초기화는 이벤트/렌더 보정 중 상태 소유권에 맞는 쪽을 택한다.
3. 건별 검증: 해당 화면 기존 테스트, 신규 첫 commit 회귀 테스트, 린트 진단 소멸 확인.
4. 마무리: tsc·전체 린트·관련 테스트, 브라우저 3폭 확인, 결과 문서, Flow 공유.
