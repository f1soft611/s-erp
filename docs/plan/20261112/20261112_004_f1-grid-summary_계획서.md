# F1-Grid 집계 구현 계획

> 작업지시서: [20261112_004](../../directions/20261112/20261112_004_f1-grid-summary_작업지시서.md)

**목표:** 공통 집계 행을 지원하고 수주등록 상세 그리드에 적용한다.

**구조:** 필터된 활성 행에서 컬럼별 집계를 계산한다. 헤더와 같은 가로 스크롤 영역에 집계 행을 배치하고 기존 컬럼 트랙 및 고정 위치를 재사용한다.

**기술:** React, TypeScript, MUI, Vitest.

## 순서

1. 사양을 작성한 뒤 집계 표시·위치·갱신 회귀 테스트를 먼저 작성하여 실패를 확인한다.
2. 공통 타입과 집계 행을 구현하고 수주 상세의 수량 및 금액 합계를 설정한다.
3. 테스트, 빌드, lint와 브라우저 화면을 확인하고 기능 문서 및 결과를 작성한다.

## 파일

- `frontend/src/shared/components/f1-grid/types/grid.types.ts`: 옵션과 컬럼 타입.
- `frontend/src/shared/components/f1-grid/core/F1Grid.tsx`: 집계 행과 스크롤 연결.
- `frontend/src/pages/sales/order/create/components/SalesOrderDetailGrid.tsx`, `data/salesOrderDetail.ts`: 수주 상세 설정.
- `frontend/tests/f1-grid.test.tsx`: 동작 회귀 테스트.
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`: 공개 옵션 문서.
