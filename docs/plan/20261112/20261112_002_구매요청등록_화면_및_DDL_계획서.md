## 목표

구매자재 모듈의 첫 화면인 구매요청등록을 수주등록과 같은 구조로 만들고,
확정·발주 단계까지 이어 쓸 구매요청 헤더/상세 테이블을 확정한다.

## 실행 순서

1. **문서 정합성**: 작업지시서·계획서·상세사양서의 컬럼, 상태값, API 경로를
   맞춘다.
2. **SQL 정적 테스트 작성(실패 확인)**:
   `tools/tests/test_purchase_request_schema.cjs`에서 두 경로 사본 동일성,
   컬럼·PK·UNIQUE·FK·CHECK 존재를 검사한다.
3. **DB 스크립트 작성** (`20261112_002`):
   - `create_purchase_request_schema.sql`: 헤더/상세 DDL, 인덱스, 코멘트
   - `seed_purchase_request_menu.sql`: `MATERIALS` 모듈, `구매관리` 상위 메뉴,
     `구매요청등록` 메뉴, 메뉴 권한, 수주등록 역할 권한 복사 (테넌트 1)
   - `rollback_*.sql`: 데이터가 있으면 중단하는 롤백
   - `change_purchase_request_schema.md`: 변경 이력
   - `docs/database/db-schema.md` 누적 스키마 갱신
4. **백엔드 실패 테스트 작성**: Service 단위 테스트(채번, 상태별 수정·삭제
   거부, 상세 추가·수정·삭제 반영, 금액 합계), Controller 테스트, Mapper
   테넌트 범위 테스트.
5. **백엔드 구현**: `egovframework.let.materials.request.create`
   Controller / Service / ServiceImpl / DAO / VO와 Mapper XML.
6. **프론트 실패 테스트 작성**: 페이지 렌더링, 필수값 검증, 저장 요청 payload,
   저장 후 번호 표시, 확정 상태 읽기 전용, 서비스 API 호출.
7. **프론트 구현**: 페이지, 상세 그리드, 서비스, 타입. 공통 품목 선택기와
   공통코드 조회 서비스를 재사용한다.
8. **라우트 연결**: `AppRouter`에 `/materials/*`, `DashboardContent`에
   `materials` 모듈 `request-create` 분기를 추가한다.
8-1. **(2026-11-12 추가) 구매 가능 품목계정 제한**: 품목 선택기 조회 결과를
   원재료·부재료·소모품으로 거르고, 서버 저장 검증에서도 같은 계정만 허용한다.
   공통 품목 목록 API(`/api/v1/co/master/materials`)는 바꾸지 않는다.
9. **검증**: 프론트 집중 테스트·빌드, 백엔드 `mvn test`, SQL 정적 테스트,
   브라우저 375px/768px/1280px 확인.
10. **결과 문서**: `docs/result/20261112/purchase-request-create/`에 결과
    보고서, 스크린샷, 커밋 제목·본문 예시를 남긴다.

## 의존 관계

- 화면의 사용용도 선택은 `20261112_001` 공통코드가 DB에 등록돼 있어야
  실제 값이 보인다.
- 백엔드 구현은 DDL 확정 후, 프론트 저장 연결은 백엔드 API 계약 확정 후 진행한다.
- 브라우저 확인은 로컬 DB에 `20261112_001`, `20261112_002` 스크립트를
  적용한 환경이 필요하다. 적용 여부는 사용자가 결정한다.

## 제외 범위

- 구매요청현황 화면·목록 API, 구매요청확정 화면·확정 처리, 발주대기 마감
  처리, 수주 연계 생성, SQL 실제 DB 적용.

## 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 신규 모듈 추가로 대시보드 모듈 분기 누락 | 라우트/대시보드 분기 테스트를 함께 추가 |
| `tb_warehouse`에 `(warehouse_id, tenant_id)` 유니크가 없어 복합 FK 불가 | 단일 FK + 서비스에서 테넌트 일치 검증 |
| 확정 컬럼이 이번 화면에서 쓰이지 않아 누락 검증이 어려움 | SQL 정적 테스트로 컬럼 존재만 확인, 처리 로직은 확정 작업에서 검증 |
