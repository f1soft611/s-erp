# F1-Grid 집계 컬럼 경계선 정렬 계획

작업지시서: [20261112_005](../../directions/20261112/20261112_005_f1-grid-summary-lines_작업지시서.md)

## 구현 순서

1. 상세 사양을 작성하고 집계 셀과 헤더·본문의 테두리 방향을 비교하는 회귀 테스트의 실패를 확인한다.
2. `GridSummary.tsx`에 `columnLine`을 전달하고 기존 데이터 셀과 같은 왼쪽 경계 규칙을 적용한다.
3. 실제 수주등록 화면에서 각 셀 경계와 고정 열, 스크롤, 모바일 행 폼 열을 확인한다.
4. 관련 테스트, 빌드, lint와 기능·결과 문서를 갱신한다.
