# 매출마감 선택 마감 및 화면 개선 구현 계획

> **For agentic workers:** Follow this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. Do not execute SQL against a database or create a git commit.

**Goal:** Add selectable statement detail lines, atomic line-level closing, disable closed-row checkboxes, display closing-state badges, and keep both pages usable on small viewports.

**Architecture:** Track each source delivery detail on `tb_sales_statement_dt`; one statement can combine selected lines across multiple deliveries when they belong to the same customer. The picker excludes issued details and restricts a source selection to one customer. Store explicit closing timestamp/actor on `tb_sales_delivery_dt` so issuing a statement, including AUTO delivery registration, never marks a line closed by itself. Closing batches create statements only for selected lines without one, grouped by customer, then mark every selected line closed. Backfill active legacy statement links by delivery and line number without backfilling the closing fields.

**Tech Stack:** React, TypeScript, MUI, F1Grid, Vitest, Spring Boot/eGovFrame, MyBatis, PostgreSQL, Maven.
