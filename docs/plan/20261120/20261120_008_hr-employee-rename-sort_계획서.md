# 20261120_008 사원관리 명칭 변경·정렬 변경 계획서

2. 명칭: `tb_menu.HR_INFO_EMPLOYEE` 이름 변경 스크립트(`20261120_005`, 롤백·이력·db-schema), 코드 주석·테스트 입력 갱신. 과거 날짜 문서는 당시 이름의 기록이라 그대로 둔다.
3. 검증·결과 문서.
