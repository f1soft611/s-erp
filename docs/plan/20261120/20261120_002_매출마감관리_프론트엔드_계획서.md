# 매출마감관리 조회 API 및 프론트엔드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the 매출마감관리 read API and page with required 출하일 search, customer multi-selection, customer summary filtering, a detail-grid-only vertical scroll layout, and a safe tenant-scoped menu seed.

**Architecture:** Reuse `PageSearchArea`, F1Grid, CommonDialog, the existing customer master search service, and dashboard page dispatch. Add a tenant-scoped read API over existing delivery/order/customer/material/statement tables. An active statement marks a delivery closed; summary counts distinct delivery headers. Keep existing single-select picker callers unchanged. Add a tenant-explicit, rerunnable SQL menu seed and rollback without applying either to a live database; no schema change is needed.

**Tech Stack:** React 19, TypeScript, MUI, F1Grid, Vitest, Testing Library, Vite, Orca browser.
