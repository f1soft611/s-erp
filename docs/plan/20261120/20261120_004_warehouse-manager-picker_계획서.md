# 20261120_004 창고등록 담당자 선택에 사원 선택 도움창 연결 계획서

기준: [작업지시서](../../directions/20261120/20261120_004_warehouse-manager-picker_작업지시서.md)

## 구현 단위
1. **도움창 보강**: `EmployeePickerDialog`에 선택 속성 `onClear`(있을 때만 "선택 해제" 버튼)를 추가한다. 테스트 먼저.
2. **창고 화면**: `warehouseGridData.ts`의 담당자 칸을 `type: 'code'`로 바꾸고 `onOpenCodePicker`로 페이지의 도움창을 연다. 페이지(`WarehouseManagementPage`)가 도움창 상태를 갖고 선택 결과를 `applyPatch`로 적용한다.
3. **정리**: 더 이상 쓰지 않는 사용자 목록 조회(`fetchWarehouseUserOptions`, 타입, 훅 상태)를 프론트에서 제거한다. 백엔드 API는 그대로 둔다.
4. **검증·문서**: 단위 테스트, 실서버 브라우저 확인, 결과 문서.

## 위험과 대응
- `type: 'code'` 칸은 직접 입력·Delete로 값을 지울 수 없어서(거래처 분류와 같음) 담당자 해제가 불가능해질 수 있다 → 도움창에 "선택 해제"를 추가해 해결한다.
- 담당자 선택 시 담당부서가 같이 바뀌어야 한다 → 선택 결과의 부서 ID·부서명을 같은 패치에 넣는다. 부서가 없는 사원이면 부서도 비운다(기존 드롭다운과 동일).
- 도움창이 일반 사용자 권한으로 조회되어야 한다 → 사원 선택 도움창 API는 관리자 전용이 아니다.
- 담당자 칸 검색 조건은 숨김이므로 상세검색에는 영향이 없다.
