# 문서 결재 액션 더보기 메뉴 계획서

## 목표

문서작성 피드와 상세에서 결재 액션을 더보기 메뉴의 첫 그룹으로 이동하고 기존 동작 및 권한 조건을 유지한다.

## 근거 문서

- [작업지시서](../../directions/20261111/20261111_001_문서결재액션_더보기메뉴_작업지시서.md)
- [설계](../../superpowers/specs/2026-11-11-document-approval-actions-menu-design.md)

## 구현 범위

- `DocumentApprovalDetailFeed.tsx`: 기존 승인/반려/보완요청/확인/취소 액션을 권한별 메뉴 항목으로 전달하고, 툴바에서 결재 버튼 그룹을 제거한다.
- `DocumentActionsMenu.tsx`: 결재 액션을 맨 앞 그룹으로 렌더링하고, 결재/공유·참조/수정·삭제 그룹 사이 구분선을 조건부로 표시한다.
- 기존 문서작성/메뉴 테스트: 툴바 직접 노출 기대를 갱신하고, 메뉴 순서·권한·선택 동작 및 주요 결재 흐름을 검증한다.

## 실행 순서

1. 메뉴 항목의 타입과 렌더 순서에 대한 테스트를 먼저 추가/갱신하고 실패를 확인한다.
2. 메뉴 컴포넌트에 선택 가능한 결재 액션 목록을 추가한다.
3. 공유 컴포넌트의 기존 권한 조건과 처리 핸들러를 유지하면서 결재 액션을 전달한다.
4. 피드와 상세의 메뉴·처리 테스트를 실행한다.
5. 프론트엔드 빌드와 실제 브라우저 반응형 검증을 수행한다.
6. 결과 문서와 스크린샷을 작성한다.

## 검증 기준

- 결재 액션은 툴바의 버튼이 아니라 더보기 메뉴 항목으로만 나타난다.
- 결재 액션은 공유 메뉴보다 앞에 있고 구분선이 액션 그룹과 공유·참조 그룹, 수정·삭제 그룹을 분리한다.
- 액션 선택 뒤 메뉴가 닫히고 기존 핸들러 및 확인/사유 입력 흐름이 작동한다.
- 상태별/권한별 노출이 기존과 동일하다.
- 관련 Vitest, `npm run build`, 375px/768px/1280px 브라우저 검증이 통과한다.
