# 종합현황 전체 폭 및 스크롤 위치 보정 Implementation Plan

> **For agentic workers:** Follow this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 종합현황 본문이 앱 콘텐츠의 전체 가용 폭을 사용하게 하여 가운데 고정 폭과 그 옆의 불필요한 스크롤 여백을 없앤다.

**Architecture:** `OverviewPage`의 MUI Container에서 `xl` 최대 폭 제한만 해제한다. 기존 종합현황 전용 세로 스크롤, 페이지 헤더, 앱 셸과 다른 페이지 동작은 유지한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Testing Library, Playwright

## Task 1: 컨테이너 폭 회귀 테스트와 최소 수정

**Files:**
- Modify: `frontend/tests/overview-page.test.tsx`
- Modify: `frontend/src/pages/groupware/OverviewPage.tsx`

- [x] **Step 1: 실패할 폭 제한 테스트 추가**

`real-data overview` 테스트 그룹에 다음 기준을 추가한다.

```tsx
it('uses the full available width for the overview scroll area', async () => {
  mount();
  await screen.findByText('검증용 운영 공지');
  expect(screen.getByTestId('overview-scroll')).not.toHaveClass('MuiContainer-maxWidthXl');
});
```

- [x] **Step 2: 테스트가 현재 구현에서 실패하는지 확인**

Run from `frontend`: `npm run test -- tests/overview-page.test.tsx`

Expected: 새 테스트가 현재의 `MuiContainer-maxWidthXl` 때문에 실패한다.

- [x] **Step 3: OverviewPage Container 최대 폭 제한 해제**

`frontend/src/pages/groupware/OverviewPage.tsx`의 본문 Container에서 `maxWidth="xl"`을 `maxWidth={false}`로 변경한다. `overflowY`, `overflowX`, flex 제약 및 반응형 패딩은 유지한다.

## Task 2: 실제 브라우저 검증과 결과 기록

**Files:**
- Create: `docs/result/20261028/overview-full-width-scroll/20261028_007_종합현황_전체폭_스크롤_보정_결과.md`
- Create: `docs/result/20261028/overview-full-width-scroll/screenshots/`의 영문 소문자 파일명 스크린샷

- [x] **Step 1: 4173 브라우저 기준으로 화면 확인**

기존 4173 서버가 S-ERP인지 먼저 확인한다. S-ERP 서버면 재사용하고 종료하지 않는다. 서버가 없다면 `npm run dev -- --strictPort`로 시작한 뒤 테스트 종료 시 프로세스를 정리한다.

- [x] **Step 2: 축소 메뉴 상태 및 반응형 폭 검증**

브라우저에서 좌측 메뉴 패널을 접은 상태로 넓은 데스크톱 화면과 1280px, 768px, 375px를 확인한다. 종합현황 본문 Container가 가용 폭을 채우는지, `document.documentElement.scrollWidth === window.innerWidth`인지, 세로 스크롤이 페이지 내용의 오른쪽 경계에 유지되는지 확인한다. 넓은 데스크톱 및 최소 375/768/1280px 화면을 결과 폴더에 캡처한다.

- [x] **Step 3: 결과 문서 작성**

결과 문서에 재현 조건, root cause, 최소 수정, 테스트/빌드 및 브라우저 측정 결과를 적고 스크린샷에 상대 링크를 건다. 실제 브라우저 검증을 수행하지 못한 항목은 수행한 것처럼 기록하지 않는다.
