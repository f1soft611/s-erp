# 20261028_014 문서작성 재상신 후 상세 댓글 갱신 계획서

## 구현 범위

- 상세 갱신 토큰 변경 시 댓글과 시스템 이력도 최신화한다.
- 같은 문서의 상세 갱신 후 댓글 조회 여부를 통합 테스트로 고정한다.
- 결과와 브라우저 검증 근거를 기록한다.

## 실행 순서

1. 기존 상세 갱신 토큰 흐름과 댓글 조회 테스트를 확인한다.
2. 댓글 조회 응답에 신규 재상신 시스템 이력을 제공하고, 갱신 토큰 변경 후 표시되는 실패 테스트를 작성한다.
3. 해당 테스트가 댓글 재조회 누락으로 실패하는지 확인한다.
4. 상세 갱신 효과에서 기존 문서 상세 재조회와 함께 `loadComments()`를 호출한다.
5. 회귀 테스트와 관련 문서작성 테스트를 실행한다.
6. 프론트엔드 빌드와 사용 가능한 브라우저 확인을 수행하고, 결과 및 제한사항을 기록한다.

## 검증 기준

- 초기 진입 외에 상세 갱신 토큰이 변경되면 댓글 조회가 다시 일어난다.
- 갱신 응답의 재상신 이력이 우측 상세에 표시된다.
- 관련 Vitest와 production build가 통과한다.
- 브라우저 확인은 375px, 768px, 1280px 크기를 대상으로 하며, 캡처는 개인정보를 포함하지 않는다.

## 미변경 보장

- API 계약, 댓글 권한·정렬·페이지 크기, 페이지 및 요약 갱신은 변경하지 않는다.
- 사용자 댓글 및 시스템 이력의 표시/조회 오류 처리는 유지한다.
