# 20260831_007 공통 페이지 메시지 알림 구현 계획서

**목표:** 권한관리와 메뉴관리의 저장 성공은 앱 공통 토스트로, 조회 또는 저장 실패는 각 페이지 헤더 아래의 공통 오류 메시지 영역으로 안내한다.

**아키텍처:** `NotificationProvider`는 성공 토스트 한 건의 열림 상태와 메시지를 소유하고 `useNotification().showSuccess()`로 호출된다. 오류 상태는 페이지가 보유하고 재사용 가능한 `PageMessageArea`에 전달한다. 메뉴 관리 패널은 작업 결과를 상위 페이지 콜백으로 전달해 오류의 표시 위치와 성공 토스트 호출 책임을 페이지에 둔다.

**기술 스택:** React 19, TypeScript, MUI 9, Vitest, Testing Library

---

- [ ] **Step 1: 성공 토스트 한 건을 관리하는 Provider와 훅을 구현한다.**

```tsx
type NotificationContextValue = {
  showSuccess: (message: string) => void;
};

export function NotificationProvider({ children }: PropsWithChildren) {
  const [message, setMessage] = useState<string | null>(null);
  return (
    <NotificationContext.Provider value={{ showSuccess: setMessage }}>
      {children}
      <Snackbar open={Boolean(message)} onClose={() => setMessage(null)}>
        <Alert severity="success" onClose={() => setMessage(null)}>
          {message}
        </Alert>
      </Snackbar>
    </NotificationContext.Provider>
  );
}
```

- [ ] **Step 2: 오류 문자열이 있을 때만 닫기 가능한 오류 `Alert`를 렌더링하는 `PageMessageArea`를 구현하고, `App.tsx`에서 Provider를 라우터 바깥에 등록한다.**

```tsx
export function PageMessageArea({ message, onClose }: PageMessageAreaProps) {
  if (!message) return null;
  return (
    <Box sx={{ px: 3, pt: 2 }}>
      <Alert severity="error" onClose={onClose}>
        {message}
      </Alert>
    </Box>
  );
}
```
