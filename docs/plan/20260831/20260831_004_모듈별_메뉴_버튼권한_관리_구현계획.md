> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

```sql
CREATE TABLE IF NOT EXISTS tb_permission (
  permission_id BIGSERIAL PRIMARY KEY,
  permission_code VARCHAR(50) NOT NULL UNIQUE,
  permission_nm VARCHAR(100) NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  use_at CHAR(1) NOT NULL DEFAULT 'Y',
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS tb_menu_permission (
  menu_id BIGINT NOT NULL REFERENCES tb_menu(menu_id) ON DELETE CASCADE,
  permission_id BIGINT NOT NULL REFERENCES tb_permission(permission_id),
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
  PRIMARY KEY (menu_id, permission_id)
);

INSERT INTO tb_permission (permission_code, permission_nm, sort_order)
VALUES ('READ', '조회', 10), ('CREATE', '등록', 20), ('UPDATE', '수정', 30),
       ('DELETE', '삭제', 40), ('EXCEL', '엑셀', 50)
ON CONFLICT (permission_code) DO UPDATE
SET permission_nm = EXCLUDED.permission_nm, sort_order = EXCLUDED.sort_order, use_at = 'Y';
```

- [ ] **Step 3: 메뉴 목록의 permissionCodes 조회와 전체 교체 SQL을 구현한다.**

```sql
SELECT mn.menu_id, ..., COALESCE(permission_codes.permission_codes, ARRAY[]::varchar[]) AS permission_codes
FROM tb_menu mn
LEFT JOIN LATERAL (
  SELECT array_agg(p.permission_code ORDER BY p.sort_order, p.permission_id) AS permission_codes
  FROM tb_menu_permission mp
  JOIN tb_permission p ON p.permission_id = mp.permission_id AND p.use_at = 'Y'
  WHERE mp.menu_id = mn.menu_id
) permission_codes ON TRUE
WHERE mn.tenant_id = #{tenantId};
```

서비스는 대상 메뉴를 tenant 기준으로 조회하고 `countChildMenus`가 0인지 확인한다. 요청 코드의 중복을 제거한 뒤 활성 권한 코드 전체가 존재하는지 검증하고, 하나의 트랜잭션에서 기존 `tb_menu_permission` 행을 삭제한 뒤 요청 코드만 삽입한다. 메뉴 삭제에도 같은 트랜잭션에서 메뉴 권한 행을 명시적으로 먼저 삭제한다.

F1Grid column contract에 `getValue`와 `onValueChange`가 없다면, boolean 동적 필드를 별도 `permissions` 객체에 저장하도록 최소 범위로 확장하고 기존 checkbox 열의 의미를 보존한다. 그룹 노드는 편집 불가 checkbox로 표시한다. `하위 메뉴 추가`는 선택 노드가 없으면 disabled, 루트 메뉴 추가는 선택 모듈이 없으면 disabled 처리한다.
