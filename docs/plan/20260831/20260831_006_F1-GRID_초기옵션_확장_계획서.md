# 20260831_006 F1-GRID 초기 옵션 확장 계획서

## 1. 목표

`F1Grid`와 `F1Tree`를 사용하는 화면에서 최초 렌더링 시점에 컬럼 고정과 트리 전체 펼침을 옵션만으로 지정할 수 있게 한다.

## 2. 범위

- `F1GridColumn.pinned` 옵션 추가
- `F1Tree.defaultExpandAll` 옵션 추가
- 기존 헤더 메뉴의 수동 컬럼 고정/해제 동작 유지
- 기존 `F1Tree.defaultExpanded` 세부 지정 동작 유지
- F1 Grid 가이드와 테스트 페이지 예시 갱신

## 3. 구현 단위

1. `frontend/tests/f1-grid.test.tsx`에 컬럼 옵션 기반 초기 고정 테스트를 추가한다.
2. `frontend/tests/f1-tree.test.tsx`에 `defaultExpandAll` 기반 초기 전체 펼침 테스트를 추가한다.
3. `frontend/src/shared/components/f1-grid/types/grid.types.ts`에 공개 옵션 타입을 추가한다.
4. `F1Grid` 초기 `pinnedFields` 상태를 컬럼 옵션에서 구성한다.
5. `F1Tree` 초기 `expandedIds` 상태에서 `defaultExpandAll`을 우선 반영한다.
6. 테스트 페이지, 메뉴 관리 화면, `frontend/src/pages/f1-grid-docs/F1-GRID.md` 사용 예시를 갱신한다.

## 4. 검증

- `npm run test -- tests/f1-grid.test.tsx tests/f1-tree.test.tsx tests/f1-grid-test-page.test.tsx tests/menu-management-f1-grid.test.tsx`
- `npm run build`
