# F1Tree 메뉴 관리 CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F1Grid 공통 동작을 재사용하는 F1Tree를 구현하고, 메뉴 관리 화면에서 계층형 메뉴의 루트/하위 등록, 수정, 삭제 및 저장을 실제 메뉴 CRUD API에 연결한다.

**Architecture:** `F1Grid`는 행 상태, 선택, 셀 편집, 키보드, 검증을 계속 소유한다. `F1Tree`는 `F1Grid`의 행 투영과 트리 열 장식 확장 지점만 이용해 평면 행의 계층 순서, 펼침 상태, 깊이와 하위 노드 삭제 정책을 추가한다. 메뉴 화면은 API DTO를 트리 행으로 정규화하고 변경분을 POST/PUT/DELETE로 저장한 뒤 서버 목록을 다시 가져온다.

**Tech Stack:** React 19, TypeScript, MUI 9, Vitest, Testing Library, MSW, Vite

- [ ] **Step 4: F1Tree를 F1Grid 조합 컴포넌트로 구현한다.**

```tsx
export const F1Tree = forwardRef(function F1TreeInner<T extends object>(
  {
    parentKey,
    treeColumn,
    defaultExpanded = 'all',
    getRowOrder,
    onDeleteBlocked,
    ...gridProps
  }: F1TreeProps<T>,
  ref: ForwardedRef<F1TreeRef<T>>,
) {
  const gridRef = useRef<F1GridRef<T>>(null);
  const [expandedIds, setExpandedIds] = useState<Set<F1GridRowId>>(() =>
    resolveInitialExpandedIds(
      gridProps.rows,
      gridProps.rowKey,
      parentKey,
      defaultExpanded,
    ),
  );
  const projection = useCallback(
    (rows: T[]) =>
      buildTreeProjection(
        rows,
        gridProps.rowKey,
        parentKey,
        expandedIds,
        getRowOrder,
        treeColumn,
        setExpandedIds,
      ),
    [expandedIds, getRowOrder, gridProps.rowKey, parentKey, treeColumn],
  );

  useImperativeHandle(ref, () => ({
    ...gridRef.current!,
    addChildRow(parentId) {
      setExpandedIds((current) => new Set(current).add(parentId));
      gridRef.current?.addRow({ [parentKey]: parentId } as Partial<T>);
    },
    deleteSelectedRows() {
      /* block IDs with descendants, then delegate */
    },
    expandAll() {
      /* add every parent ID */
    },
    collapseAll() {
      setExpandedIds(new Set());
    },
  }));

  return (
    <F1Grid
      ref={gridRef}
      {...gridProps}
      rowProjection={projection}
      disableSorting
      disableFiltering
    />
  );
});
```

`F1TreeProps`에는 `parentKey`, `treeColumn`, `defaultExpanded`, `getRowOrder`, `onDeleteBlocked`를, `F1TreeRef`에는 `addChildRow`, `expandRow`, `collapseRow`, `expandAll`, `collapseAll`, `isExpanded`를 추가한다. `F1GridRef` 메서드는 `gridRef.current`을 안전하게 위임하고, 렌더 전에 ref 호출이 오면 빈 결과 또는 no-op으로 처리한다.
