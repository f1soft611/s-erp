# F1-Grid Editable Header Indicator Implementation Plan

## 최종 변경 계획

사용자 최종 결정에 따라 강조선을 제거한다. 테스트 기대를 먼저 변경하여 실패를 확인한 뒤 GridHeader의 편집 가능 inset 그림자만 제거하고 기존 고정/드롭 그림자 분기를 복원한다. 사용 문서/화면 안내를 동기화하고 선별 회귀 테스트, 빌드, 375/768/1280px 브라우저 및 편집 상태를 검증한다. 아래는 최초 상단 강조선 구현 이력이다.

**Goal:** 편집 가능 컬럼의 강조선을 헤더 상단 안쪽으로 옮겨 편집 셀 테두리와 분리한다.

**Architecture:** 공통 GridHeader의 하단 border 강조를 제거하고 기존 그림자와 상단 inset 그림자를 병합한다. 편집 가능 판정과 API는 변경하지 않는다.

**Tech Stack:** React, TypeScript, MUI sx, Vitest, Playwright.

## 구현 및 검증 순서

1. `frontend/tests/f1-grid.test.tsx`: 편집 가능 헤더의 상단 inset 그림자, 하단 강조 제거, 읽기 전용/고정/그룹/드롭 표시 보존을 검증한다. 변경 전 실패를 확인한다.
2. `frontend/src/shared/components/f1-grid/core/GridHeader.tsx`: 기존 `boxShadow`를 유지하면서 편집 가능 헤더에 `inset 0 2px 0 0 ${theme.palette.primary.main}`을 추가한다. 편집 여부에 따른 `borderBottom`과 `borderBottomColor`는 제거한다.
3. `frontend/src/pages/f1-grid-docs/F1-GRID.md`와 화면에 표시되는 편집 안내 및 `frontend/tests/f1-grid-docs.test.tsx`를 같은 설명으로 갱신한다.
4. `npm run test -- tests/f1-grid.test.tsx tests/f1-grid-docs.test.tsx tests/f1-grid-form-modal.test.tsx` 및 `npm run build`를 실행한다.
5. 기존 4173 서버가 S-ERP인지 확인하고 재사용하여 375/768/1280px에서 헤더 표시, 편집 셀, 가로 넘침을 확인한다. 결과와 스크린샷을 `docs/result/20261023/f1-grid-editable-header-top`에 저장한다.

## 범위

- 공통 헤더 스타일, 관련 회귀 테스트, 사용 안내와 결과 문서만 변경한다.
- 신규 옵션, 라이브러리, API, DB 변경은 없다.
