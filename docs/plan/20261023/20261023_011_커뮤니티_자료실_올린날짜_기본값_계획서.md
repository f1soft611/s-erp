# 20261023_011 커뮤니티 자료실 올린 날짜 기본값/초기화 계획서

## 목표

자료실 상세검색의 올린 날짜를 공통 시스템 날짜 기준 최근 1년으로 설정하고, 첫 조회와 초기화가 동일한 날짜 범위를 사용하도록 한다.

## 범위

- `PageSearchField.defaultValue`와 `usePageSearchDefaults`를 재사용해 `uploadedAt` 시작일은 서버 날짜 기준 1년 전, 종료일은 서버 날짜로 해석한다.
- 날짜 기본값 로딩이 성공하기 전에는 파일 목록을 조회하지 않고, 실패 시 재시도할 수 있는 오류를 표시한다.
- 초기화 시 최근 1년과 파일 유형 기본값을 재적용하고 검색어를 비우며 현재 폴더는 유지한다.
- 자료실 검색 조건 문서와 결과 문서/스크린샷을 갱신한다.
- 백엔드·API·DB는 변경하지 않는다.

## 구현 순서

1. 이 계획을 바탕으로 상세 사양서를 작성한다.
2. `frontend/tests/archive-page.test.tsx`에 서버 날짜 기준 첫 조회, 지연/실패/재시도, 초기화 회귀 테스트를 추가한다.
3. `ArchiveBoardPage.tsx`에 날짜 default metadata와 공통 기본값 hook을 연결한다.
4. `useArchiveList.ts`가 기본값 준비 전에는 요청을 보내지 않도록 하고 브라우저 시간 초기화를 제거한다.
5. 상세검색 초기화 시 기본 날짜를 필드와 실제 조회 필터에 반영하고 요약 표시도 resolver 결과를 기준으로 처리한다.
6. 기존 자료실 상세 사양 및 결과 문서와 375px·768px·1280px 스크린샷을 갱신한다.
7. 포커스 Vitest, 프런트엔드 빌드, 브라우저 동작 및 `git diff --check`를 검증한다.

## 검증 기준

- 고정 서버 날짜 `2024-02-29`에서 윤년 경계를 포함해 시작일 `2023-02-28`, 종료일 `2024-02-29`가 적용된다.
- 서버 날짜 기본값 요청이 대기 중이거나 실패한 동안 날짜 조건 없는 첫 파일 조회가 발생하지 않는다.
- 재시도 성공 후에만 최근 1년 조건으로 조회한다.
- 초기화는 기본 날짜 및 파일 유형을 복원하고 검색어를 비우며 현재 폴더를 유지한다.
- 서버 날짜와 브라우저 날짜가 다르더라도 기본값/요약/목록 조건은 서버 날짜에 일치한다.
