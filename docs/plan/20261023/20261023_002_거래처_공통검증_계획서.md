# 거래처 공통검증 구현 계획

**목표:** 거래처명·사업자번호의 필수 설정과 번호 자리수 검증을 F1-Grid로 통일하고 폼 적용·저장 오류를 상단에 표시한다.

**근거:** [사용자 승인 작업지시서](../../directions/20261023/20261023_002_거래처_공통검증_작업지시서.md) 및 [기존 작업지시서](../../directions/20261022/20261022_008_거래처_관리_페이지_작업지시서.md). 사용자가 사업자번호 필수화, 저장 훅 중복 검사 제거, 폼 적용·저장 모두 실제 오류 상단 표시를 승인했다.

**구조:** 기존 `validateGridRow`를 재사용한다. 선택적 `onValidationErrors` 콜백으로 행 ID·필드·메시지 배열을 전달하고 기존 `validate(): boolean` 계약은 유지한다. React/TypeScript/Vitest를 사용하며 API·DB는 변경하지 않는다.

## 검증 명령

`frontend`에서 `npm run test -- tests/customer-management-page.test.tsx tests/f1-grid-form-modal.test.tsx tests/f1-grid-input-format-validation.test.ts`를 실행한다. 수정 전 새 테스트 실패, 수정 후 전체 통과가 기대 결과다. 이후 `npm run build`가 성공해야 한다.
