# 20261023_007 품목·거래처 저장 조용한 로딩 계획

**목표:** 저장 및 저장 후 조용한 재조회 중 품목·거래처 Grid를 계속 노출하고, 저장 진행은 페이지 액션의 기존 진행 표시로 전달한다.

**원인:** 두 페이지 모두 `loading` prop에 초기/조회 `loading`과 저장 `saving`을 합쳐 전달한다. 저장 중 `saving`이 true인 동안 F1-Grid 전체 로딩 오버레이가 표시되어, 이미 구현된 조용한 재조회 동작이 가려진다.

**범위:** 프론트엔드 저장 UI와 회귀 테스트, F1-Grid 사용 문서 및 작업 결과만 변경한다. 저장 훅의 `saving`, 재조회 `quiet` 처리, 에러·알림·권한 동작은 유지한다.

## 실행 순서

- [x] 거래처·품목 페이지 테스트에 저장 진행 중 Grid 오버레이 미표시와 행 표시 유지를 재현하는 회귀 검증을 추가한다.
- [x] 집중 테스트를 실행해 기존 구현에서 실패하는지 확인했다. 두 테스트 모두 이전 코드에서 오버레이 검증에 실패했다.
- [x] 두 페이지에서 F1-Grid `loading`에 초기/일반 조회 `loading`만 전달한다.
- [x] 진행 표시 아이콘, 저장 중 액션 비활성화, 저장 결과/재조회 오류 동작을 유지한다.
- [x] 저장 회귀 테스트 2개와 거래처 테스트 18개를 통과시켰다. 거래처 전체 실행에는 기본 5초 제한을 넘는 기존 시나리오를 고려해 명령에서만 15초 제한을 사용했다.
- [x] 최종 통합 테스트에서 소비기한 변경 테스트 3개가 추가로 실패한 것을 확인했다. 해당 테스트/구현은 이 작업과 별개로 수정하지 않는다.
- [x] 프론트엔드 빌드를 실행했다. 다른 작업에서 함께 수정 중인 `MaterialGrid.tsx`의 `align` 타입 오류로 실패했으며 [결과 문서](../../result/20261023/item-customer-quiet-save/20261023_007_품목·거래처_저장_조용한로딩_결과.md)에 기록한다.
- [x] F1-GRID 사용 문서에 저장과 Grid 로딩 상태의 분리를 명시한다.
- [ ] 실제 브라우저에서 저장 중 Grid 노출 및 화면 크기별 표시를 확인하고 결과·스크린샷을 남긴다. 현재 공유 브라우저 페이지가 조작 도구에서 조회되지 않고 새 페이지는 로그인으로 이동해 검증을 보류했다.
