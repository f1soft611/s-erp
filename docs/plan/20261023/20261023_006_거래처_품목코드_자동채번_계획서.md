# 거래처·품목 코드 자동채번 Implementation Plan

> **For agentic workers:** Follow this plan task by task. Use checkbox steps and preserve unrelated worktree changes.

**Goal:** Make customer and material codes server-generated for new records and immutable for updates.

**Architecture:** Keep each existing eGov ID Generator and its six-digit behavior. Make the code columns list-only in F1-Grid, always generate codes in create services, and remove code assignments from update SQL so client-supplied values cannot change persisted codes.

**Tech Stack:** React, TypeScript, F1-Grid, Vitest, Java, Spring, MyBatis, PostgreSQL, JUnit, Mockito.

- Existing tenant scope, duplicate detection, generator errors, validation, permissions, and saved response behavior are preserved.
- Focused frontend/backend tests and frontend build pass; browser evidence and result documentation are saved.
- No DB migration, DDL, or data change is created or applied.
