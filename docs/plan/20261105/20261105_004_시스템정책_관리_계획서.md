# 시스템 정책 관리 Implementation Plan

**Goal:** 현재 테넌트의 플랫폼 관리자가 타입별 정책을 등록·설정하는 실제 저장 가능한 화면을 제공한다.

**Architecture:** 기존 테넌트 라우팅 데이터소스와 LoginVO를 사용한다. 정책은 JSON 타입값과 버전으로 저장하며 변경 이력을 같은 트랜잭션에 기록한다. 기존 납품 정책 두 개는 tb_tenant 컬럼을 적용값의 기준으로 유지하고 저장 어댑터로 연동하여 업무 서비스의 읽기 계약을 바꾸지 않는다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Java 8, Spring/MyBatis, PostgreSQL.

## 실행 단위

- [x] 백엔드: `backend/src/main/java/egovframework/let/system/policies` 아래 Controller, Service, DAO, VO를 생성한다. 플랫폼 전용 접근·타입값·버전 충돌·시스템 정책 보호 테스트를 먼저 실패시킨 뒤 구현한다.
- [x] DB: 두 스키마 경로의 `20261105_004_*` SQL/이력/롤백과 누적 스키마를 작성한다. 기존 납품 정책은 현재 값을 보존하는 seed를 사용한다. 메뉴 `/settings/system/policies`는 PLATFORM_ADMIN만 권한 부여한다.
- [x] 화면: `frontend/src/pages/settings/system/policies` 아래 정책 서비스·타입·값 입력기·편집 대화상자·페이지를 생성한다. `DashboardContent.tsx` 및 `dashboardData.tsx`에 연결한다.
