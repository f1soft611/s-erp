# 수주 선택 모달 레이아웃 계획서

1. 첨부 이미지의 검색폭/표 잘림을 재현하고 원인을 모달 검색 레이아웃 및 고정 열 폭으로 확인한다.
2. [상세사양서](../../spec/20261105/20261105_001_수주선택_모달레이아웃_상세사양서.md)를 기준으로 폼 검색 구조와 열 너비에 대한 회귀 테스트를 먼저 추가하고 기존 구현에서 실패시킨다.
3. `SourceOrderPicker`에서 페이지용 검색 컴포넌트 대신 전체폭의 모달용 검색 폼을 사용하고, Enter/버튼 검색을 유지한다.
4. 표 열 너비를 축소하되 수주번호 링크/선택 버튼을 읽기 쉬운 크기로 유지한다. 좁은 화면은 내부 그리드 스크롤로 처리한다.
5. 수주 선택 통합 테스트, build, 변경 파일 lint, 375/768/1030x668/1280px 브라우저 검증을 수행한다.
6. 결과 문서와 비교 스크린샷을 `docs/result/20261105/sales-delivery-source-picker`에 저장한다.

F1-Grid 공통 구현과 백엔드/SQL은 변경하지 않는다.
