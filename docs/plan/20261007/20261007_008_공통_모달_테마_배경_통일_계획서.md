# 20261007_008 공통 모달 테마 배경 통일 계획서

## 목표

공통 다이얼로그의 기본 표면을 라이트 모드에서 흰색, 다크 모드에서 `#1e293b`로 정의하고 paper/header/body/footer에서 일관되게 사용한다. 문서작성 모달의 흰색 강제를 제거하고 에디터 전용 색상과 명시적 표면 재정의는 보존한다.

## 변경 파일

- `frontend/src/shared/components/CommonDialog.tsx`: 기본 표면 토큰을 테마에 따라 계산하고 paper, header, body, footer에 일관되게 적용한다. `surfaceBackgroundColor`의 명시적 사용자 지정 우선순위는 유지한다.
- `frontend/src/pages/groupware/documents/write/components/DocumentComposerDialog.tsx`: 고정 흰색 `surfaceBackgroundColor` 전달을 제거한다. 제목/본문 에디터의 테마 전용 색상은 그대로 둔다.
- `frontend/tests/common-dialog.test.tsx`: 라이트/다크 기본 표면 테스트를 같은 단일 색상 기대값으로 갱신하고, 표면색 사용자 지정 회귀 테스트를 유지/보강한다.
- `frontend/tests/document-write-page.test.tsx`: 다크 테마로 문서작성 모달을 열어 공통 표면과 에디터 고유 표면색을 검증한다.
- 날짜별 작업지시서, 계획서, 사양서 및 결과 보고서를 유지한다. 브라우저 확인은 공유 4173 서버를 재사용하고 서버 종료를 시도하지 않는다.

## 실행 순서

1. 현재 테스트가 요구하는 라이트/다크 공통 모달 영역의 computed background를 확인한다.
2. 기존 다크 콘텐츠 `#0f172a`, 라이트 콘텐츠 기본 배경 테스트를 통일 표면 기대값으로 바꿔 실패를 확인한다.
3. `CommonDialog`에서 `surfaceBackgroundColor ?? (dark ? '#1e293b' : '#ffffff')`를 사용하고 같은 값을 paper/header/body/footer에 적용한다.
4. `DocumentComposerDialog`의 흰색 강제를 제거하고 문서작성 모달 통합 테스트를 추가한다.
5. 집중 테스트, 해당 파일 lint, 빌드를 수행한다.
6. 공유 브라우저에서 모달의 테마 적용을 검증하고 캡처 및 결과 문서를 작성한다.


다이얼로그의 크기/구조/동작, API, 데이터, 공지 작성 전용 스타일, 에디터 내부 표면색 및 기존 명시적 다이얼로그별 색상 지정은 변경하지 않는다.
