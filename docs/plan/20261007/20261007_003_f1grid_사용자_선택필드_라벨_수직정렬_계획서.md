# 20261007_003 F1-Grid 사용자 선택 필드 라벨 수직 정렬 계획서

## 목표

Outlined 사용자 선택 입력에서 기본 폰트보다 작은 라벨을 사용할 때 발생하는 비축소 라벨의 수직 위치 오차를 바로잡는다.

## 변경 및 검증

1. `UserSelectEditor`에서 라벨이 비축소 상태일 때의 현재 스타일을 테스트로 재현한다.
2. 비축소 라벨에 한정해 입력 높이 중앙에 맞는 수직 transform을 적용한다. 축소 라벨과 compact 편집기 스타일은 유지한다.
3. 단위 테스트, 프론트엔드 빌드 및 브라우저 렌더링으로 정렬과 회귀 여부를 확인한다.
4. F1-Grid 문서와 날짜별 결과 문서를 갱신한다.

## 제외

공통 MUI 테마, 다른 화면의 TextField, 사용자 선택 동작 및 필드 높이는 변경하지 않는다.
