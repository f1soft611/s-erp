# 20261007_011 문서작성 짧은 이름 말줄임 개선 계획서

## 목표

문서작성 결재선과 합의 칩에서 3~4글자 이름을 전체 표시하고 더 긴 이름은 말줄임 처리한다.

## 작업 단계

1. 표시 사양에 맞춰 기존 결재선 이름 표시 테스트를 4글자 이름 기준으로 확장하고, 현재 코드에서 실패하는 것을 확인한다.
2. 결재 슬롯 최소 너비를 88px로 늘리고, 결재자 이름 행의 불필요한 삭제 버튼 공간과 3em 제한을 제거한다.
3. 합의자 이름 최대 너비를 4em으로 늘린다.
4. 문서작성 테스트, 대상 파일 lint, 프론트엔드 build를 실행한다.
5. 브라우저에서 375px, 768px, 1280px 레이아웃/이름 노출/가로 넘침을 확인한다.
6. 개인정보를 흐림 처리한 스크린샷과 결과 문서를 갱신한다.

## 검증 명령

```powershell
cd frontend
npx vitest run tests/document-write-page.test.tsx -t "renders compact accessible badges" --testTimeout=15000
npx vitest run tests/document-write-page.test.tsx --testTimeout=15000
npm run lint -- src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx tests/document-write-page.test.tsx
npm run build
```

저장소 루트에서 `git diff --check`를 실행한다.

## 영향 범위

- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx`
- `frontend/tests/document-write-page.test.tsx`
- 본 작업지시서/사양서 및 기존 문서작성 결과 문서, 반응형 스크린샷

기존 사용자 선택, 결재 순번, 삭제 동작은 변경하지 않는다. API와 데이터베이스 변경은 없다.
