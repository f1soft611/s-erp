# 20261007_001 문서작성 결재선 및 에디터 사용성 개선 계획서

## 목표

승인 설계에 따라 문서작성 모달에서 선택한 결재자/참조자 후보를 숨기고, 여러 결재자를 선택 순서대로 단계화하며, 단계와 필드 공간을 줄인다. 본문 에디터를 내용 높이에 맞춰 확장하고 모달 콘텐츠가 세로 스크롤을 담당하도록 한다.

## 변경 파일과 책임

- `frontend/src/shared/components/f1-grid/editing/UserSelectEditor.tsx`: 기본 동작을 보존하는 opt-in `hideSelectedOptions`와 `preserveSelectionOrder` 지원.
- `frontend/src/pages/groupware/documents/write/hooks/useDocumentComposer.ts`: 선택 순서의 다중 결재를 한 사람당 하나의 단계로 추가하고 선택을 초기화; 기존 합의 그룹 추가 동작 유지.
- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx`: 선택된 사용자 미리보기 제거, 중복 결재 후보 숨김, 필드 우측 액션, 가로 결재 단계 스트립, 내부 가로 스크롤 적용.
- `frontend/src/pages/groupware/documents/write/components/DocumentComposerDialog.tsx`: 본문 자연 높이와 기존 CommonDialog 콘텐츠 영역 스크롤 적용.
- `frontend/tests/user-select-editor.test.tsx`: 선택 후보 필터와 선택 순서 동작을 독립 검증.
- `frontend/tests/document-write-page.test.tsx`: 문서작성 상호작용, 본문 overflow 책임, 기존 양식 동작 회귀 검증.

## 구현 순서

1. 선택 후보 숨김 및 선택 순서 보존을 `UserSelectEditor`의 opt-in 동작으로 테스트하고 구현한다.
2. 다중 결재자를 선택한 순서로 연속 단계 추가하고, 기존 합의 그룹 동작은 유지한다.
3. 결재선/참조선의 별도 선택자 요약을 제거하고, 후보 중복 방지와 우측 액션/가로 단계 레이아웃을 구현한다.
4. 본문 에디터 고정 최대 높이와 내부 세로 스크롤을 제거하고 모달 콘텐츠 스크롤로 통합한다.
5. 세부 동작 사양서를 기준으로 지정 테스트 및 빌드를 수행하고, 375px/768px/1280px 브라우저에서 확인한다.
6. 실제 확인 내용을 결과 보고서와 스크린샷에 기록한다.

## 검증 계획

- `cd frontend; npm run test -- tests/user-select-editor.test.tsx tests/document-write-page.test.tsx`
- `cd frontend; npm run build`
- 브라우저에서 선택 순서, 단계 가로 스크롤, 긴 본문 편집 시 모달 세로 스크롤을 확인한다.
- 브라우저 뷰포트 375px, 768px, 1280px의 목록/작성 모달 캡처를 `docs/result/20261007/document-write-approval-editor-usability/screenshots/`에 저장한다.
- 최종 `git diff --check` 및 변경 범위를 확인한다.

## 범위 제외

실제 저장, 상신, 결재 처리, 백엔드/DB, 결재선-참조선 간 사용자 중복 제한은 이번 작업에 포함하지 않는다. 공통 리치 텍스트 에디터와 공통 다이얼로그 구현은 수정하지 않는다.
