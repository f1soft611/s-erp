# 20261007_009 문서작성 다크 테마 합의 칩/에디터 배경 계획서

## 목표

다크 모드 합의 칩을 어두운 슬레이트 표면으로 맞추고, 에디터 캔버스는 라이트에서 흰색, 다크에서 모달 본문과 같은 `#1e293b`를 사용하며 각 테마에서 기본 글자/placeholder가 읽히도록 한다.

## 변경 파일

- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx`: 다크/라이트 테마를 읽어 합의 칩 표면과 경계색을 결정한다. 참여자 데이터 및 동작은 변경하지 않는다.
- `frontend/src/pages/groupware/documents/write/hooks/useDocumentComposer.ts`: 에디터 표면을 테마별로 라이트 `#ffffff`, 다크 `#1e293b`로 설정한다.
- `frontend/src/pages/groupware/documents/write/components/DocumentComposerDialog.tsx`: 에디터 기본 글자와 placeholder를 각 테마 표면에 맞게 조정한다.
- `frontend/tests/document-write-page.test.tsx`: 라이트/다크 에디터 표면과 기본 글자색을 검증하되 다른 작업자의 초기 결재자/테스트 변경은 보존한다.
- `frontend/tests/document-approval-fields-theme.test.tsx`: 합의 칩 라이트/다크 배경 및 테두리 회귀 검증을 추가한다.
- `docs/result/20261007/document-composer-dark-surfaces/`: 실행 결과와 개인정보 없는 캡처를 기록한다.

## 실행 순서

1. 기존 합의 칩이 `grey.100`/`grey.300`, 에디터 표면이 다크 `#0f172a`를 사용하는 현재 기준을 테스트로 재현한다.
2. 합의 칩에 다크 `#334155` 및 `divider`, 라이트 `grey.100` 및 기존 회색 경계를 설정한다.
3. 에디터 배경을 라이트 `#ffffff`, 다크 `#1e293b`로 하고 기본 입력 텍스트/placeholder는 theme primary/secondary 색을 사용한다.
4. 합의 선택 및 결재선 관련 기존 테스트를 포함한 집중 테스트와 lint/build를 실행한다.
5. 공유 브라우저에서 양 테마 및 375px/768px/1280px를 확인하고 개인정보가 없는 캡처를 남긴다.

