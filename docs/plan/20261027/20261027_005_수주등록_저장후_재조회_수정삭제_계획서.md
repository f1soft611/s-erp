## 1. DB 확인 (MCP 읽기 전용)

- `tb_sales_order_hd`: `use_at char NOT NULL default 'Y'`, `updated_by varchar`, `updated_at timestamp`, `status default '수주등록'`이 있다.
- `tb_sales_order_dt`: `use_at`/감사 컬럼이 없다. `UNIQUE(sales_order_id, line_no)`, `FK(sales_order_id, tenant_id) -> hd`가 있다.
- 마스터 코드/명 컬럼: `tb_customer_info.customer_code/customer_name`, `tb_material_info.material_code/material_name`.
- 결론: 스키마 변경 없음. 삭제는 헤더 `use_at='N'` 소프트 삭제로 처리한다.

## 2. 백엔드 작업 단위

| 순서 | 파일 | 내용 |
| --- | --- | --- |
| 1 | `EgovSalesOrderCreate_SQL_postgresql.xml` | `selectOrderHeader`, `selectOrderDetails`, `countShippedDetails`, `updateOrderHeader`, `deleteOrderDetails`, `softDeleteOrderHeader` 추가 (모두 tenant 조건) |
| 2 | `SalesOrderDAO` | 위 statement 호출 메서드 + Javadoc |
| 3 | `SalesOrderVO`/`SalesOrderDetailVO` | `customerCode/customerName`, `materialCode/materialName` 필드와 `@Schema` |
| 4 | `SalesOrderService`/`Impl` | `getOrder`, `updateOrder`, `deleteOrder`. 수정/삭제는 `status='수주등록'`이고 출하수량이 없을 때만 허용(409) |
| 5 | `SalesOrderApiController` | `GET/PUT/DELETE /api/v1/sales/orders/{salesOrderId}` + OpenAPI 어노테이션 |
