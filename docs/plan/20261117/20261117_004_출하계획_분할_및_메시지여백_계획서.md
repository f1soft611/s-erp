# 출하계획 분할 및 메시지 여백 계획서

**목표:** 미출하 기존 계획의 분할 저장을 복구하고 오류 여백을 수주등록과 일치시킨다.

**구조:** 출하계획 등록 화면에서 원본 조회 시점의 잔량과 불러온 현재 계획 상세를 결합해 수정 가능 수량을 계산한다. 신규 등록은 기존 잔량을 유지하고 서버 검증은 그대로 둔다.

**기술:** React, TypeScript, Vitest, MUI.

1. 작업지시서와 기존 품목별 계획·수주 오류 여백 사양을 확인한다.
2. AUTO 기존 계획 100을 50·50으로 나누어 저장하는 실패 테스트와 다른 계획이 차지한 수량을 초과하는 경우의 테스트를 작성한다.
3. 저장 가능 한도를 계산하고 출하수량이 있는 상세의 분할·삭제·셀 편집을 비활성화한다. 등록 화면의 오류 메시지를 수주등록 compact 여백에 맞춘다.
4. 관련 테스트, 빌드, lint와 가능한 브라우저 375/768/1280px 검증을 수행한다.
5. 결과와 스크린샷을 날짜별 결과 폴더에 남긴다. 커밋은 생성하지 않는다.
6. 추가 지적에 따라 오류 메시지와 기본정보 영역의 실제 좌우 경계 및 오류 전후 위치를 375/768/1280px 브라우저에서 검증하고 맞춘다.
7. 성공 직후 검증 오류가 발생해도 성공과 오류 알림이 동시에 남지 않는지 검사한다.
