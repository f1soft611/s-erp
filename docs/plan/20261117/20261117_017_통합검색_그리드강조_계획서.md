# 통합검색어 그리드 강조 계획서

- 작업번호: 20261117_017
- 근거: [작업지시서](../../directions/20261117/20261117_017_통합검색_그리드강조_작업지시서.md)

## 구현 단위
1. F1-Grid 공통: `highlightKeyword` prop, `highlightSearch` 컬럼 속성, `F1GridHighlightText`, 문자열 분할 유틸
2. 영업관리 현황 5개 화면 적용 (수주·견적·출하·출하계획·거래명세서)
3. 통합검색이 있는 나머지 F1-Grid 화면 적용 (자재·그룹웨어·기준정보·시스템설정 등)
4. 테스트, F1-GRID.md, 결과 문서

## 성능 방침
- 강조 컬럼이 없거나 검색어가 비면 Grid가 `undefined`를 내려 행·셀 memo를 그대로 유지한다.
- 일치 구간 탐색은 정규식 없이 `indexOf`를 사용하고, 강조 컬럼의 셀에만 적용한다.
- 컬럼 배열은 검색어에 의존하지 않는다. `renderCell`은 context의 검색어를 사용한다.
