# 영업관리 작성 기준일 서버날짜 통일 계획서

**Goal:** 영업관리 작성폼의 신규 기본일과 초기화 날짜를 서버 시스템 날짜로 통일한다.

**Architecture:** 기존 `getSystemDate()`를 재사용한다. 수주·출하·명세 폼은 서버날짜 조회가 완료되기 전 브라우저 날짜를 넣지 않으며, 오류 시 날짜 기본값을 적용하지 않고 기존 오류 표시 흐름을 사용한다. 견적의 기존 서버날짜 동작과 수정 데이터의 저장 날짜는 유지한다.

**Tech Stack:** React, TypeScript, Vitest.

- 제외: 견적작성(이미 서버날짜 사용), 현황 검색 기간(오늘 단일 날짜 기본값이 아님), 선택 원천 자료에서 가져오는 날짜.

- [x] 출하작성 테스트에서 서버날짜를 신규 기본값과 초기화 날짜로 사용하고, 기존 자료의 날짜를 덮어쓰지 않는지 검증한다.
- [x] 거래명세서 작성 테스트에서 서버날짜를 신규 기본값과 초기화 날짜로 사용하고, 기존 자료의 날짜를 덮어쓰지 않는지 검증한다.
