# 견적서 공통코드 Implementation Plan

**Goal:** 견적 기본정보와 단위의 신규 선택값을 활성 공통코드에서 가져온다.

**Architecture:** 기존 공통코드 서비스로 그룹과 항목을 조회하는 견적 전용 서비스를 추가한다. 작성·현황 보기/수정이 공유하는 작성 폼 및 기존 F1Grid select를 사용한다. 신규 API와 스키마 변경 없이 누락된 그룹만 seed한다.

**Tech Stack:** React, TypeScript, MUI, F1Grid, Vitest, Playwright, PostgreSQL.
