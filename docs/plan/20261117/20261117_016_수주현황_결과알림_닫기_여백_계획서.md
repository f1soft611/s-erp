# 수주현황 결과 알림 닫기 여백 보정 계획서

**Goal:** 조회 결과 알림을 닫아도 수주현황 그리드 위 기본 상단 간격을 유지한다.

**Root cause:** `SearchResultMessage`가 내부 상태로 Alert만 숨기지만 `SalesOrderStatusPage`의 `showSearchResultMessage`는 조회 성공 상태를 기준으로 계속 true다. 따라서 그리드 컨테이너의 `pt`가 0으로 남아 닫힌 알림의 바깥 여백도 사라진다.

## 실행 단계

- [x] 수주현황 페이지 테스트에서 결과 알림을 닫은 뒤 그리드 컨테이너가 기본 `pt: 1`(8px)을 유지하는지 검증하고 실패를 확인한다.
- [x] 공용 `SearchResultMessage`에 선택적인 dismiss 콜백을 추가하고 수주현황 부모 상태에 닫힘을 전달한다.
- [x] 수주현황의 결과 알림이 닫힌 경우에만 그리드 기본 상단 여백을 적용한다. 신규 조회 및 목록 재시도/갱신에서는 닫힘 상태를 초기화한다.
- [x] 결과 알림 표시 간격, 닫기 후 간격, 새 조회 시 재표시를 회귀 테스트한다.
- [x] 변경 영역 Vitest, frontend build, lint를 실행하고 결과 문서를 작성한다.
- [ ] 실제 브라우저 확인은 375/768/1280px에서 수행하고 접근이 막히면 결과 문서에 제한을 기록한다. **차단:** 로컬 앱이 `/login`으로 이동해 인증 후 화면 검증 및 스크린샷을 진행할 수 없다.
