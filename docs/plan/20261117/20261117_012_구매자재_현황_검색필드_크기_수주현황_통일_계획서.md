# 20261117_012 구매자재 현황 검색필드 크기 수주현황 기준 통일 계획서

기준: [작업지시서](../../directions/20261117/20261117_012_구매자재_현황_검색필드_크기_수주현황_통일_작업지시서.md)

## 구현 단위

| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | 검색 정의 테스트 | 여섯 화면의 `toPageSearchFields(columns)` 결과가 수주현황 기준 스팬·그룹·순서인지 확인하는 테스트 |
| 2 | 컬럼 정의 변경 | 화면별 검색 컬럼의 `search.span`, `group`, `order`만 변경 |
| 3 | 문서·검증 | 브라우저에서 수주현황과 같은 폭인지 측정, 결과 문서 |

## 결정과 이유
- **그룹으로 줄을 나눈다**: `PageSearchArea`는 연속한 같은 `group`을 한 줄로 묶는다. 수주현황과 같은 `텍스트`/`선택`/`부가날짜` 그룹명을 쓰면 줄 구성이 같아진다. 매입마감처리의 마감월·조회구분은 선택 줄, 발주번호는 텍스트 줄이다.
- **`PageSearchArea`는 바꾸지 않는다**: 폭은 `span`과 격자에서 정해지므로 컬럼 정의만 바꾼다. 빠른 날짜 단추 등 공통 동작은 그대로다.
- **검색 동작 불변**: 필드 이름·라벨·필수·기본값·옵션은 그대로 둔다. `order`가 바뀌어도 필드 순서만 바뀐다.

## 위험과 대응
- **기존 테스트가 필드 순서·스팬에 의존**: 현황 테스트에서 검색 필드 순서·그룹을 확인하는 곳이 있으면 갱신한다(검색해 보면 구매 화면 테스트에는 스팬 단정이 없음).
- **필드가 많은 화면**(입고현황 텍스트 5개, 수입검사현황 텍스트 6개): 5열 격자라 한 줄에 5개까지 들어가고 나머지는 다음 줄로 넘어간다. 수주현황 폭 기준이라 의도한 동작이다.
- **좁은 화면**: `PageSearchArea`가 이미 `xs`/`sm` 반응형으로 스팬을 줄이므로 375/768px에서 확인한다.

## 검증 계획
- 단위: 화면별 검색 필드의 `searchSpan`·`group`·`order`, 날짜 필드 필수·기본값 유지, 상태 필드 `required`/`allowEmpty` 유지.
- 브라우저: 수주현황의 `수주번호` 입력과 구매 화면 텍스트 입력의 폭 비교(오차 1px 이내), 날짜 입력 폭 비교, 줄 구성 스크린샷.
