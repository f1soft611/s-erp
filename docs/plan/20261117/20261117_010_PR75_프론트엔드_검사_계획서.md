# PR #75 프론트엔드 검사 실패 수정 계획서

## 목표

브랜치에서 추가한 AUTO 출하계획 테스트가 CI에서 안정적으로 그리드를 찾도록 비동기 렌더링 대기를 적용한다. 기존 실패는 범위에서 제외한다.

## 근거

- [작업지시서](../../directions/20261117/20261117_010_PR75_프론트엔드_검사_작업지시서.md)
- 출하계획 source-picker 종료는 MUI Dialog 전환을 거치므로, 계획번호가 갱신된 직후 그리드가 접근성 트리에 즉시 나타난다고 가정하지 않는다.

## 실행

- [x] 추가된 두 AUTO 테스트에서 그리드 역할이 접근 가능해질 때까지 `findByRole`로 대기하고, 실행시간이 긴 split 테스트에 개별 timeout을 설정한다.
- [x] 대상 테스트 파일을 CI와 같은 `--pool=threads --maxWorkers=2` 옵션과 PR lockfile 의존성으로 검증한다.
- [x] base 재현 실패 및 base에서 재현되지 않은 CI 실패를 결과 문서에 분리해 기록한다.
- [x] 실제 동작을 바꾸지 않는 테스트 안정화임을 결과 문서에 기록한다.
