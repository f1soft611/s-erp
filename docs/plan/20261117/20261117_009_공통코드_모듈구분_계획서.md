# 공통코드 모듈 구분 계획서

모듈은 별도 목록을 만들지 않고 시스템 모듈관리(`tb_module`) 데이터를 사용한다.

1. DB: `module_cd varchar(50) NULL` + `(tenant_id, module_cd)` 인덱스 (`docs/database/20261117/20261117_007_*`). 값은 `tb_module.module_code`.
2. 백엔드: Mapper(resultMap/조회 필터/insert/update/`countModuleByCode`), VO 3종 + 검색조건, Service 검증(tb_module 존재, 빈값=NULL), Controller `moduleCd`, 배치 저장 전달.
3. 프론트: `/api/v1/system/modules` 기반 모듈 옵션, 그룹 트리 `모듈` 컬럼, 상세검색 `모듈` 필터.
4. 검증: 매퍼 계약 테스트, 프론트 서비스·페이지 테스트, tsc.
