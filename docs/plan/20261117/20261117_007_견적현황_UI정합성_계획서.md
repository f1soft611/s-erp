# 견적현황 UI 정합성 Implementation Plan

**Goal:** 견적현황의 더보기·통합검색·상세 날짜 표시를 수주현황 공통 패턴과 일치시킨다.

**Architecture:** 기존 견적현황 컴포넌트와 검색 훅/서비스를 수정한다. 선택 검색어 keyword를 기존 조회 API에 추가하고 서버에서 날짜·테넌트 조건과 AND로 결합한다. 날짜는 공통 DateEditor에 disabled 상태를 직접 전달한다.

**Tech Stack:** React, MUI, F1Grid, TypeScript, Java 8 호환 Spring/MyBatis, Vitest, JUnit, Playwright.

1. `quotation-status-page.test.tsx`, `quotation-status-api.test.ts`, `quotation-create-page.test.tsx`에 더보기 아이콘·검색 제출/복원·날짜 MUI disabled 상태 회귀를 추가하고 실패를 확인한다.
2. `SalesQuotationStatusServiceImplTest`, `SalesQuotationMapperTest`에 keyword 정규화·바인딩·OR 범위 회귀를 추가하고 실패를 확인한다.
3. `QuotationActionsMenu`, `QuotationStatusSearchArea`, `useQuotationStatusSearch`, 상태 페이지·서비스·타입과 작성 폼의 두 날짜 disabled 전달만 수정한다.
4. `SalesQuotationStatusSearchVO`, `SalesQuotationStatusServiceImpl`, 현황 Mapper에 선택 keyword와 다섯 컬럼 OR 부분일치를 추가한다. 스키마와 기존 개별 검색 조건은 변경하지 않는다.
5. 견적 관련 Vitest/JUnit, 빌드, 변경 영역 lint 및 Java 8 API 호환 컴파일을 실행한다.
6. Playwright로 375/768/1280px 통합검색/더보기/상세보기 날짜 배경·입력 차단과 수정 모드를 확인한다.
7. `docs/result/20261117/quotation-status-consistency`에 결과 및 스크린샷을 저장한다. DB 직접 변경·커밋은 하지 않는다.

## 완료 확인

- 1~7 구현·검증 완료. 프론트엔드 23개, 백엔드 5개 테스트 통과.
- Java 8 API 호환 컴파일, 프론트 빌드, lint(기존 경고 유지), 375/768/1280px 실제 브라우저 확인 완료.
- 결과와 스크린샷 9개는 `docs/result/20261117/quotation-status-consistency`에 기록했다.
