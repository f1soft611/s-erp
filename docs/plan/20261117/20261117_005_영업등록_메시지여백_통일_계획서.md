# 영업 등록 화면 메시지 여백 통일 계획서

**목표:** 네 영업 등록 화면의 성공·오류 메시지를 수주등록과 동일하게 정렬한다.

**구조:** 수주등록의 입력 검증 오류와 성공 메시지의 본문 직계 Alert를 기준으로 한다. 오류 여부로 본문 패딩을 바꾸거나 메시지 전용 패딩을 추가하지 않는다. 수주의 서버 오류도 같은 배치로 통일하고 embedded 본문 0px 정책은 유지한다.

**기술:** React, TypeScript, MUI, Vitest, Playwright.

1. 수주등록과 대상 네 화면의 메시지 및 embedded 구성을 조사한다.
2. 실제 수주 신규 화면에서 품목 상세 미입력 오류를 발생시키고, 각 화면의 성공·오류와 좌우 경계 및 위아래 간격을 비교하는 실패 검사를 작성한다.
3. 메시지와 본문 래퍼를 기준 화면과 일치시키되 상태·API·권한은 유지한다.
4. 관련 테스트, lint, 빌드 및 375/768/1280px 브라우저 비교를 수행하고 결과를 기록한다.
