- [x] **Step 4: 기존 결재선 resultMap과 조회 SQL을 확장한다**

`approvalLine` resultMap에 `participant_profile_image` 및 `participant_stamp_image` 매핑을 추가한다. `selectApprovalLines`의 `tb_electronic_approval_line_info`에 `line` alias를 부여하고 기존 결재선 열, tenant/document 필터, `ORDER BY line.stage_order, line.participant_order`를 유지하면서 해당 쿼리의 컬럼 참조를 `line.`으로 한정한다. 아래 관계를 LEFT JOIN한다.

```sql
LEFT JOIN public.tb_user u
  ON u.tenant_id = line.tenant_id
 AND CAST(u.user_id AS varchar) = line.participant_user_id
LEFT JOIN public.tb_login_account la
  ON la.tenant_id = u.tenant_id
 AND la.login_id = u.login_id
```

`la.profile_image`는 프로필 응답에 사용한다. `participantStampImage`는 `participant_type = 'APPROVAL'`이고 `action_status IN ('APPROVED', 'REJECTED', 'RETURNED')`인 행에만 `la.stamp_image`를 반환하는 `CASE` projection으로 만든다. 나머지는 SQL `NULL`로 반환한다. 계정이 없더라도 LEFT JOIN으로 원 결재선 행이 유지되어야 한다.

- [x] **Step 5: 합의·참조 표시를 승인된 그룹 규칙으로 구현한다**

기존 `stageOrder`, `participantOrder` 정렬을 유지한다. 합의 항목을 `stageOrder`로 그룹화하고 테두리 카드 안에서 순번 원형 배지와 참여자 영역을 한 행에 배치한다. 참여자는 `participantOrder` 순으로 테두리 카드에 프로필/이름 1행과 부서/상태 배지 2행으로 표시하고, 가용 폭에 따라 가로 배치 후 자동 줄바꿈한다. 참조는 번호 없이 가로로 불필요하게 늘어나지 않는 테두리 카드에 프로필/이름 1행과 부서 2행을 표시하고 자동 줄바꿈한다. 모든 프로필 사진에서 누락·로드 실패 시 이름 첫 글자 Avatar fallback을 제공한다. 확대나 재구성 과정에서 승인 처리 핸들러, 합의 동시 처리 상태, 참조 처리 불가 동작을 변경하지 않는다.

정렬된 합의 목록에서 단계 그룹을 만든다. 그룹 내 배열은 기존 정렬 순서를 보존한다.

```tsx
const agreementStages = useMemo(() => {
  const stages = new Map<number, DocumentApprovalLine[]>();
  for (const line of approvalLineGroups.agreement) {
    const participants = stages.get(line.stageOrder) ?? [];
    participants.push(line);
    stages.set(line.stageOrder, participants);
  }
  return Array.from(stages, ([stageOrder, participants]) => ({
    stageOrder,
    participants,
  }));
}, [approvalLineGroups.agreement]);
```

합의 단계는 순번 배지와 참여자 카드 목록을 한 행에 두고, 카드 목록 자체는 가용 폭에 따라 줄바꿈한다. 각 카드에는 2행 이름/부서·상태와 Avatar fallback을 둔다. 각 합의/참조 Avatar는 이미지 URL을 `src`로, `participantName.slice(0, 1)`을 자식 fallback으로 사용한다.

```tsx

    >

        >
          <Avatar
            data-testid={`approval-line-agreement-avatar-${line.electronicApprovalLineId}`}
            src={line.participantProfileImage ?? undefined}
            alt={line.participantName}
          >
            {line.participantName.slice(0, 1)}
          </Avatar>
          <Box sx={{ minWidth: 0, flex: 1 }}>
            <Typography variant="body1" noWrap title={line.participantName}>

            </Typography>
            <Box sx={{ display: 'flex', alignItems: 'center', gap: 0.5 }}>

              <Box component="span" sx={{ borderRadius: 99, fontSize: '1rem' }}>

        </Box>
      ))}

```

참조 행도 번호 없는 테두리 카드로 표시하며 프로필·이름 첫 행, 부서 두 번째 행을 `body1`로 구성한다. 합의 및 참조 카드 목록은 가용 폭에 따라 줄바꿈한다. `participantOrder` 정렬을 보존하고 참조 항목이나 참조 그룹에는 stage 순번을 추가하지 않는다.
