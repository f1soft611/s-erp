# 20261014_001 공지 피드 이전 댓글 완료 시 버튼 숨김 계획서

## 목표

현재 남은 댓글 수가 0인데도 서버의 이전 페이지 플래그나 커서 때문에 공통 이전 댓글 버튼이 계속 표시되는 문제를 해결한다.

## 범위

| 파일 | 변경 목적 |
|---|---|
| `frontend/tests/feed-components.test.tsx` | 남은 댓글 수가 0일 때 버튼이 숨겨지는 실패 회귀 테스트 추가 |
| `frontend/src/shared/components/feed/FeedCommentsSection.tsx` | 유효한 남은 댓글 수가 0이면 이전 댓글 버튼을 숨김 |
| `docs/result/20261014/notice-previous-comments-exhausted/` | 수정 원인, 검증 결과 및 브라우저 확인 결과 기록 |

## 실행 순서

1. `showPrevious`가 true이고 `remainingPreviousCount`가 0일 때 버튼이 없어야 하는 테스트를 추가한다.
2. 공통 피드 테스트를 실행해 요구사항에 맞는 실패를 확인한다.
3. 공통 섹션에서 이전 댓글 버튼의 표시 조건에 남은 댓글 수를 반영한다. 조회 중에는 로딩 상태를 유지하며, 카운트가 없거나 유효하지 않으면 기존 동작을 보존한다.
4. 공통 피드 및 이전 댓글 관련 공지사항/전자결재 테스트를 실행한다.
5. `npm run build`와 `git diff --check`를 실행하고 브라우저에서 완료 상태를 확인해 결과를 기록한다.

## 검증 계획

- `npx vitest run tests/feed-components.test.tsx`
- 이전 댓글 관련 선택 테스트: `tests/notice-page-local-updates.test.tsx`, `tests/notice-page.test.tsx`, `tests/document-write-page.test.tsx`
- `npm run build`
- 브라우저에서 댓글을 전부 펼친 뒤 `이전 댓글 보기 (0)` 및 버튼이 남지 않는지 확인
