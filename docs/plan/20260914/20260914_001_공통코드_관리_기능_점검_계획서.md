## 2. 요구사항 분석 및 목적

공통코드 관리 화면은 `F1Tree`와 `F1Grid`를 결합한 관리 페이지로, 좌측 그룹 트리와 우측 상세코드 그리드의 연동이 핵심이다. 현재 기능이 비정상으로 보이는 지점을 확인하고, 실제 실패가 발생하는 동작별로 재현 조건을 정리한 뒤 수정 범위를 최소화하여 보완한다.

주요 확인 항목은 다음과 같다.

1. 화면 진입 시 그룹 목록과 상세코드 목록이 정상 조회되는가
2. 선택 그룹 변경 시 상세 목록이 올바르게 갱신되는가
3. 저장 액션이 dirty 상태를 정확히 반영하는가
4. 루트 추가, 행 추가, 행 삭제가 실제로 반영되고 저장까지 이어지는가
5. 저장 실패 혹은 재조회 후에도 화면 상태와 데이터 정합성이 유지되는가

## 3. 프론트엔드 작업 범위

### 3.1 화면 로딩 및 데이터 흐름

- 공통코드 그룹 목록 조회 로직 점검
- 선택 그룹 기준 상세코드 목록 조회 로직 점검
- 변경 사항이 화면 상태에 반영되는 구조 확인
- `selectedGroupId`/`groups`/`items` 흐름에서 누락되는 값 검증

### 3.2 액션별 동작 점검

- 조회 버튼/초기 로딩 동작
- 저장 버튼과 dirty 상태 계산
- 루트 추가 기능
- 행 추가 기능
- 행 삭제 기능
- 변경 후 자동 재조회/리렌더 처리

### 3.3 검증 방식

- 실제 브라우저로 화면 동작 확인
- 필요 시 Vitest로 관련 테스트 추가/수정
- 로직상 확인이 어려운 UI 동작은 Playwright 기반 스크립트 또는 사용자 시나리오 검증 수행
