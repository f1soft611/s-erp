# 수주번호 필드 크기 수정 계획

근거: [작업지시서](../../directions/20261110/20261110_002_order-number-field_작업지시서.md).

1. 수주번호의 개별 모바일 글꼴 지정과 같은 화면의 일반 입력란 스타일을 비교한다.
2. 기존 합성 데이터 브라우저 회귀에 수주번호·견적번호·수주상태의 실제 글꼴과 외곽 높이 비교를 추가하고 실패를 확인한다.
3. 수주번호의 개별 글꼴 재정의만 제거해 공통 TextField 스타일을 상속한다.
4. 브라우저 375/768/1280px, 수주 등록 테스트, 변경 파일 lint와 빌드를 확인한다.
5. 결과 문서와 기본정보 스크린샷을 `docs/result/20261110/order-number-field`에 남긴다.
