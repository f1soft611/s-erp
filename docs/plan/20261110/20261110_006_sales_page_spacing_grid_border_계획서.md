# 영업 페이지 여백 및 그리드 테두리 정합 계획서

1. 수주·출하·출하계획·거래명세서 등록/현황 페이지의 콘텐츠 외부 여백과 기존 예외를 확인한다.
2. 네 등록/현황 쌍의 콘텐츠 바깥 패딩을 비교하는 회귀 테스트를 먼저 추가한다. 기준값은 현황의 좌우 `xs 8px / sm 16px`, 위 8px, 아래 16px이다.
3. 출하계획현황 테스트에서 목록 F1Grid 주위에 별도 outlined Paper가 없고 기본 그리드 테두리만 유지되는지 확인한다.
4. 공통 메시지에 기본 동작을 유지하는 선택적 수평 패딩을 추가하고, 해당 옵션에 대한 실패 테스트를 먼저 작성한다.
5. 수주·출하·거래명세서의 현황 메시지는 그리드의 반응형 거터를 사용하고, 출하계획현황 메시지는 기존 콘텐츠 거터를 중복하지 않도록 수평 패딩을 제거한다.
6. 등록 페이지 콘텐츠 래퍼의 패딩을 현황 기준으로 변경하고 출하계획현황의 이중 테두리 래퍼를 테두리 없는 레이아웃 Box로 바꾼다.
7. 등록/현황 여백, 메시지 폭, 그리드 테두리 테스트와 프런트엔드 빌드 및 변경 파일 Oxlint를 실행한다.
8. 실제 브라우저에서 대응하는 등록/현황 화면을 375px, 768px, 1280px로 비교하고 스크린샷을 기록한다.
9. 변경 범위와 검증 결과를 `docs/result/20261110/sales-page-layout`에 작성한다.

## 범위 제한

- 등록 페이지의 동작 및 오류 간격 예외, 검색 필드/메시지, 상세 패널, API/데이터 계약, F1Grid 내부 구현은 수정하지 않는다.
- 백엔드 및 DB 변경은 없다.
