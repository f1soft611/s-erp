# 20261002_009 공통코드 중복 저장 오류 메시지 계획서

**상태:** 완료

**목표:** 공통코드 중복 저장 시 프론트가 실제로 읽는 최상위 `resultMessage`에 구체적인 검증 메시지를 반환한다.

**원인 가설:** `CommonCodeGroupApiController.badRequest`는 상세 오류를 `result.message`에 기록하면서 `ResultVoHelper`의 기본 overload를 사용한다. 이 overload는 최상위 `resultMessage`를 공통 입력 오류 문구로 고정한다.

## 변경 대상

- 수정: `backend/src/main/java/egovframework/let/co/master/commoncode/controller/CommonCodeGroupApiController.java`
- 테스트: `backend/src/test/java/egovframework/let/co/master/commoncode/controller/CommonCodeApiControllerTest.java`
- 문서: 본 작업지시서, 상세 사양서, 결과 보고서

## 작업 순서

1. [x] 배치 저장 API에서 중복 상세코드의 HTTP 400, 입력 오류 코드, 최상위 `resultMessage`를 검증하는 테스트를 추가한다.
2. [x] RED: 최상위 메시지가 일반 입력 오류 문구로 반환되는 것을 확인한다.
3. [x] `badRequest`가 메시지 overload를 사용해 최상위 메시지를 구체 검증 메시지로 설정하도록 수정한다.
4. [x] 공통코드 API/서비스 집중 테스트 11건을 실행한다.
5. [x] 결과 보고서를 작성한다.
