# 분류 설정 모달 공통 셸 적용 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기안양식관리 분류 설정과 F1-Grid 폼이 같은 공통 modal footer divider와 공통 셸을 사용하도록 한다.

**Architecture:** `CommonCodeItemHelpDialog`의 데이터/dirty-close 로직을 유지하고 MUI Dialog 외곽만 `CommonDialog`로 바꾼다. 셸에는 업무별 높이를 보존할 `paperHeight` 옵션을 추가한다. 본문 `DialogContent dividers`는 제거하고 footer divider는 `CommonDialog` 하나만 사용한다.

**Tech Stack:** React, TypeScript, MUI Dialog, Vitest, Testing Library, Playwright.

## Task 2: CommonDialog paperHeight 지원 및 분류 설정 이전

**Files:**

- Modify: `frontend/src/shared/components/CommonDialog.tsx`
- Modify: `frontend/src/shared/components/common-code/CommonCodeItemHelpDialog.tsx`
- Modify: `frontend/tests/common-dialog.test.tsx`

- [ ] **Step 1: 공통 `paperHeight` 실패 테스트 추가**
  - `bodyMode="fill"`과 `paperHeight="60vh"`를 함께 전달하면 paper height가 `60vh`가 되고 footer가 고정되는지 검증한다.
- [ ] **Step 2: 공통 모달 테스트 실행**
  - Run: `cd frontend; npm run test -- tests/common-dialog.test.tsx`
  - Expected: paper height assertion 실패.
- [ ] **Step 3: CommonDialog paperHeight 구현**
  - `paperHeight?: CSSProperties['height']`를 추가한다.
  - 지정 값은 일반 paper에 적용하고, 모바일 full-screen일 때는 MUI fullScreen 스타일을 우선한다.
  - 값이 생략되면 기존 `bodyMode`별 높이 동작을 그대로 유지한다.
- [ ] **Step 4: CommonCodeItemHelpDialog 공통 셸 이전**
  - `size="lg"`, `bodyMode="fill"`, `paperHeight="60vh"`, `fullScreenOnMobile`을 지정한다.
  - 제목은 `기안양식 분류 설정`, `onClose`는 기존 `requestClose`로 연결한다.
  - 기존 Stack/F1Grid와 error, saving, `handleSave`, dirty-close 로직은 그대로 유지한다.
  - 저장/취소 버튼은 `actions` 슬롯에 놓고 `DialogContent dividers` 및 별도 `DialogActions` border를 제거한다. Divider는 색상 prop 없이 기본 스타일을 사용한다.
- [ ] **Step 5: 관련 단위 테스트 실행**
  - Run: `cd frontend; npm run test -- tests/common-dialog.test.tsx tests/common-code-item-help-dialog.test.tsx tests/f1-grid-form-modal.test.tsx`
  - Expected: 공통 셸, 분류 설정 dirty-close/save, F1-Grid footer divider 테스트 통과.
