# 20261002_002 기안양식 백엔드 패턴 및 무결성 보완 계획서

**상태:** 사용자 요청에 따라 구현 진행

**목표:** 기안양식 API 문서화를 기존 S-ERP 패턴에 맞추고, 생성 payload의 null 담당자 목록과 동시 양식 코드 중복을 안전하게 처리한다.

**접근:** 외부 VO와 컨트롤러의 OpenAPI 메타데이터를 기준정보 API에 맞춘다. Service는 null 담당자 목록을 빈 목록으로 정규화한다. PostgreSQL partial unique index를 데이터 무결성의 최종 보장으로 두고, Mapper의 `ON CONFLICT ... DO NOTHING RETURNING`으로 경합 충돌을 트랜잭션 오류 없이 서비스의 입력 오류로 변환한다.
