# 20261002_005 기안양식 분류 안내 초기 노출 보완 계획서

## 목표

분류 옵션 상태 확인이 끝나기 전 안내 영역이 잘못 노출되지 않도록 한다.

## 수정 범위

- `frontend/src/pages/co/workflow/form/DraftFormManagementPage.tsx`
- `frontend/tests/draft-form-management.test.tsx`

## 실행 단계

1. 분류 옵션 요청이 보류 중인 동안 안내가 숨겨지는 회귀 테스트를 추가한다.
2. 옵션 로딩 완료 및 분류 없음 결과 이후에 안내되는지 검증한다.
3. 안내 조건에 옵션 로딩 완료 상태를 반영한다.
4. 관련 테스트와 프론트엔드 빌드를 실행하고 결과를 기록한다.

## 검증

- `cd frontend; npm run test -- tests/draft-form-management.test.tsx`
- `cd frontend; npm run build`
