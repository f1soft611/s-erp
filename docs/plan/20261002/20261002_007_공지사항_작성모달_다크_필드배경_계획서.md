# 20261002_007 공지사항 작성 모달 다크 필드 배경 계획서

> **For agentic workers:** 이 계획은 현재 작업 세션에서 순서대로 수행한다. 각 단계는 체크박스로 진행 상태를 기록한다.

**목표:** 다크 테마 공지 작성 모달의 구분·제목 입력면에만 한 단계 밝은 표면색을 적용한다.

**구현 방식:** `NoticeComposerDialog` 내부에 필드 전용 배경 토큰을 추가한다. 다크에서는 `#1e293b`, 라이트에서는 기존 `editorSurfaceBackground`를 사용하고, 두 `TextField`의 입력 루트에만 적용한다. 본문 편집기와 첨부 표면은 기존 토큰을 유지한다.

**기술 스택:** React, TypeScript, MUI, Vitest, Testing Library, Vite.

- `frontend/src/pages/groupware/community/notice/components/NoticeComposerDialog.tsx`: 구분·제목 입력 표면 전용 색상 적용
- `frontend/tests/notice-composer-dialog-theme.test.tsx`: 다크 입력면 및 라이트 회귀 검증

## Task 1: 테마 회귀 테스트 추가

**파일:** `frontend/tests/notice-composer-dialog-theme.test.tsx`

- [x] **Step 1: 다크 필드 배경 테스트 추가**

```tsx
it('uses the slate surface for category and title fields in dark mode', () => {
  render(
    <ThemeProvider theme={createAppTheme('dark')}>
      <NoticeComposerDialog
        open
        isDark
        onClose={() => undefined}
        noticeGubunOptions={[{ code: 'GENERAL', name: '일반' }]}
      />
    </ThemeProvider>,
  );

  const categoryInput = screen.getByRole('combobox', { name: /구분/ });
  const titleInput = screen.getByRole('textbox', { name: '제목' });

  expect(categoryInput.closest('.MuiInputBase-root')).toHaveStyle({
    backgroundColor: 'rgb(30, 41, 59)',
  });
  expect(titleInput.closest('.MuiInputBase-root')).toHaveStyle({
    backgroundColor: 'rgb(30, 41, 59)',
  });
});
```

- [x] **Step 2: 새 테스트를 실행해 배경색 기대값에서 실패하는지 확인**

  - 기대: 두 필드의 계산 배경색이 현재 `rgb(15, 23, 42)`이므로 새 기대값과 불일치한다.
