# 메뉴관리 조회조건 세션 보존 Implementation Plan

> **For agentic workers:** Use the repository's date-based planning workflow. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메뉴관리 화면의 모듈, 권한, 검색어를 로그인 세션 동안 복원한다.

**Architecture:** 페이지 전용 `MenuManagementPageSession` 계약과 기존 `usePageSessionState` 훅을 사용한다. 메뉴·권한 옵션 로드 완료 후 세션의 모듈/권한 ID를 현재 옵션과 대조해 선택하고, 두 값이 유효할 때만 메뉴 데이터를 조회한다. 메뉴 검색은 기존 클라이언트 필터 로직을 재사용한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Testing Library, sessionStorage.
