## 공통 컴포넌트 계약

`CommonDialog`는 다음 계약을 사용한다. `dialogProps`는 grid 이벤트 전파 차단 및 화면의 `data-*` 식별자를 전달하고, 제어 props는 셸이 소유한다.

```ts
import type { DialogProps } from '@mui/material/Dialog';
import type { ReactNode } from 'react';

type CommonDialogProps = {
  open: boolean;
  onClose: () => void;
  title: string;
  description?: string;
  children: ReactNode;
  footerStart?: ReactNode;
  actions?: ReactNode;
  size?: 'md' | 'lg';
  bodyMode?: 'content' | 'fill';
  fullScreenOnMobile?: boolean;
  dialogProps?: Omit<
    DialogProps,
    'open' | 'onClose' | 'children' | 'fullWidth' | 'maxWidth' | 'fullScreen'
  >;
};
```

기본 크기는 `md=820px`, `lg=960px`이며 모바일 전체 화면은 기본 비활성이다. `bodyMode` 기본값은 `content`; `fill`은 기존 공지 에디터처럼 모달 높이를 채워 본문을 확장해야 하는 경우 사용한다. `footerStart`와 `actions`가 모두 없을 때만 푸터를 생략한다.
