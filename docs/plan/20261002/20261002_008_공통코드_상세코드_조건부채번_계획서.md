# 공통코드 상세코드 조건부 자동 발번 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 상세코드가 비어 있을 때 그룹별 3자리 이상 숫자 `item_code`를 원자적으로 발급한다.

**Architecture:** `tb_id_sequence`와 별도 DAO/서비스로 재사용 가능한 조건형 카운터를 제공한다. 키는 발번 목적과 두 범위 키이며 `tenant_id`는 저장하지 않는다. 공통코드 상세 저장 서비스는 코드가 비었을 때 카운터를 사용하고, 숫자 코드를 수동 입력한 경우 카운터를 해당 값 이상으로 맞춘다.

**Tech Stack:** PostgreSQL, Spring, MyBatis, Java, React, TypeScript, Vitest.
