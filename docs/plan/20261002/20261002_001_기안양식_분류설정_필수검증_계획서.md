# 20261002_001 기안양식 분류 설정 필수 검증 계획서

## 목표

분류 설정 모달이 F1-Grid 필수 컬럼 검증을 저장 전에 실행하고, 저장 오류를 모달 안에서만 표시하게 한다.

## 수정 범위

- `frontend/src/shared/components/common-code/CommonCodeItemHelpDialog.tsx`
- `frontend/src/pages/co/workflow/form/DraftFormManagementPage.tsx`
- `frontend/tests/draft-form-management.test.tsx`
- 관련 날짜별 작업지시서, 계획서, 사양서 및 결과 문서

## 실행 단계

1. 테스트 우선: 빈 신규 행 저장 시 필수 안내가 모달에 표시되고 API를 호출하지 않는지 검증한다.
2. 테스트 우선: 저장 실패 시 메시지가 모달 내에만 표시되는지 페이지 통합 흐름으로 검증한다.
3. 모달 저장 핸들러에서 `gridRef.current.validate()` 실패 시 안내를 설정하고 저장을 중단한다.
4. 모달 전용 오류 처리로 정리하고 페이지에서 오류 전달 콜백을 제거한다.
5. 관련 단위 테스트, 프론트엔드 빌드, 브라우저 동작을 확인하고 결과 문서를 작성한다.

## 검증

- `cd frontend; npm run test -- tests/common-code-item-help-dialog.test.tsx`
- `cd frontend; npm run build`
- 브라우저에서 빈 분류 행 저장과 저장 실패 표시 위치를 확인한다.

## 제외

공통 F1-Grid 코어, 공통코드 API/백엔드 검증, 다른 화면의 오류 표시 동작은 수정하지 않는다.
