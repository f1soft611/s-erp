## 목표 및 구현 방식

공지사항의 기존 clipboard HTML 정규화 경로를 유지하면서, 표 행별 직계 셀만 처리하고 셀 크기·병합·줄바꿈·허용된 폰트 서식을 보존한다. 원본 `<colgroup>` 너비를 Tiptap `colwidth`로 전달하고 셀 최소 너비는 16px로 둬 Excel 열 크기를 정확히 반영한다. 이벤트 우선순위, 이미지 업로드, 저장/API에는 변경을 가하지 않는다.

## 파일 역할

- `frontend/src/pages/groupware/community/notice/utils/noticeClipboard.ts`: HTML table row/cell 추출과 셀 콘텐츠의 안전한 줄바꿈 보존
- `frontend/src/pages/groupware/community/notice/utils/noticeClipboard.ts`: Excel `<colgroup>` px/pt 너비를 병합/세로 병합 위치에 맞춰 Tiptap cell `colwidth`로 전달
- `frontend/src/pages/groupware/community/notice/components/NoticeComposerDialog.tsx`: Tiptap font style 확장과 표 셀 최소 너비 설정
- `frontend/package.json`, `frontend/package-lock.json`: Tiptap 공식 text-style 확장 의존성
- `frontend/tests/notice-clipboard.test.ts`: 정규화 유닛 회귀 테스트
- `frontend/tests/notice-composer-payload.test.ts`: 실제 Tiptap paste 경로의 구조/내용 검증
- `docs/result/20261002/notice-excel-paste-structure/`: 결과 보고서와 캡처

## Task 2: 최소 정규화 수정

**파일:** `frontend/src/pages/groupware/community/notice/utils/noticeClipboard.ts`

- [x] 행을 순회할 때 현재 표에 직접 속한 행만 선택한다.
- [x] 한 행에서 현재 행에 직접 속한 `td`/`th`만 선택한다. 중첩 표는 바깥 표의 셀 수/순서를 늘리지 않는다.
- [x] 셀 내부 텍스트를 `textContent`로 합치지 않고 `<br>` 및 문단 경계를 보존한다. 텍스트는 escape하고 안전하지 않은 태그/속성은 전달하지 않는다.
- [x] 셀 없는 Excel 행은 `<tr></tr>`로 보존하고, `rowspan`이 이미 덮는 열에 placeholder 셀을 추가하지 않는다.
- [x] 기존 빈 셀, `rowspan`, `colspan`, style allowlist, 이미지 정책을 유지한다.
- [x] Task 1 테스트를 실행해 통과시켰다.
- [x] 허용된 셀/인라인 글꼴 스타일을 CSS allowlist와 HTML serializer에 추가했다.
- [x] `@tiptap/extension-text-style`의 `TextStyle`, `FontFamily`, `FontSize`, `Color`를 편집기 스키마에 등록했다.
- [x] 표 `cellMinWidth`를 40px에서 16px로 조정했다.
- [x] Excel `<colgroup>` 열 너비를 절대 px 단위로 정규화하고 각 셀의 Tiptap `colwidth`로 변환한다. `rowspan`이 있는 행도 점유된 열을 건너뛰어 매핑한다.
- [x] 열 너비 유닛 테스트와 모달 DOM 테스트를 먼저 실패시킨 뒤 구현으로 통과시켰다.

## 계획 자체 점검

- 행/셀 위치, 병합, 줄바꿈 보존 요구사항은 Task 1~3에 연결되어 있다.

- UI/CSS 수정과 백엔드 변경은 포함하지 않는다.
