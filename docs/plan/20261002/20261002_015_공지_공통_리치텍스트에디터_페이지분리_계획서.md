# 공통 리치 텍스트 에디터 및 공지 페이지 분리 Implementation Plan

> **For agentic workers:** Implement each task in order with test-first validation. This repository does not authorize commits unless explicitly requested.

**Goal:** Extract a reusable rich-text editor for notices and drafting forms, and separate community notice page state, services, data, and types by responsibility without changing domain contracts.

**Architecture:** Put Tiptap schema, toolbar, clipboard normalization, image paste/resizing, and editor styles in a domain-neutral shared component. Keep notice and drafting-form upload, image restoration, cleanup, and save adapters in their existing domain dialogs/services. Keep the notice page as a composition layer backed by focused feature hooks and types.

**Tech Stack:** React 19, TypeScript, MUI, Tiptap, Vitest, Testing Library, Vite, Playwright/Chromium.
