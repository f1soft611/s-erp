# 문서 상세 액션 후 댓글 즉시 갱신 계획서

## 목표

문서 상세에서 결재 액션이 성공한 직후 서버에 기록된 시스템 메시지를 댓글
영역에 표시하고, 바뀐 문서 상태를 갱신하면서 상세를 열린 상태로 유지한다.

## 구현 방향

- 기존 `DocumentApprovalDetailFeed`의 상세/댓글 상태 및 오류 재시도 로직을
  재사용한다.
- 결재·반려·보완요청 및 두 취소 액션 성공 시 문서 상세 재조회와 최신 통합
  댓글 페이지 재조회를 실행한다.
- 서버에서 반환한 댓글/시스템 메시지와 페이지 메타데이터만 표시한다.
- 상세 액션 후에도 기존 상위 목록 갱신을 수행하고, 액션 실패 동작은 유지한다.

## 작업 단계

1. [구현 세부 계획](../../superpowers/plans/2026-10-16-document-approval-comment-refresh.md)의 TDD 순서로 결재 성공, 취소 성공, 댓글 재조회 실패 회귀 테스트를 추가한다.
2. 성공 핸들러에서 최신 댓글 페이지 및 상세를 갱신하고, 결재 처리 후 상세 닫기를 제거한다.
3. 집중 테스트, `document-write-page.test.tsx`, production build를 수행한다.
4. 지정된 세 뷰포트에서 안전한 브라우저 확인을 수행하고 결과 문서/스크린샷을 작성한다.

## 범위

- 프론트엔드 상세 컴포넌트 및 관련 회귀 테스트
- API, DB, 백엔드, 공지사항 댓글, 권한/상태 전이 정책은 변경하지 않는다.

## 완료 기준

- 액션 성공 후 시스템 메시지, 댓글 건수 및 페이지 정보가 서버의 최신 응답으로 갱신된다.
- 상세가 열린 채 상태 변경을 반영한다.
- 댓글 재조회 오류는 기존 재시도 UI에 표시되고 액션 성공과 혼동되지 않는다.
- 관련 Vitest/build 및 브라우저 확인 근거가 결과 문서에 기록된다.
