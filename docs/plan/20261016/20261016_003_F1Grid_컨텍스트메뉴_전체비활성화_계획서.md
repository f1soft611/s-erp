# F1-Grid 컨텍스트 메뉴 전체 비활성화 계획서

**목표:** `disableContextMenu` 옵션으로 F1Grid와 F1Tree의 바디 우클릭 메뉴를 끈다. 우클릭 대상 선택, 기본 브라우저 메뉴 차단, 헤더 메뉴, 기본 동작은 유지한다.

**구조:** 옵션을 공유 `F1GridProps`에 추가하고, 공통 F1Grid 이벤트 처리에서 메뉴 상태만 생략한다. 이미 열린 메뉴는 옵션 활성화 시 닫는다. API 레퍼런스, 문서 포털 Playground, 독립 F1-Grid 문서 및 회귀 테스트를 함께 갱신한다.

**기술:** React, TypeScript, MUI, Vitest, Testing Library, Vite.

## 실행 순서

1. [작업지시서](../../directions/20261016/20261016_003_F1Grid_컨텍스트메뉴_전체비활성화_작업지시서.md)와 [승인된 설계](../../superpowers/specs/2026-10-16-f1-grid-disable-context-menu-design.md)를 기준으로 [상세 사양서](../../spec/20261016/20261016_003_F1Grid_컨텍스트메뉴_전체비활성화_상세사양서.md)를 작성한다.
2. [F1-Grid context menu 테스트](../../../frontend/tests/f1-grid-context-menu.test.tsx)에 F1Grid/F1Tree의 메뉴 억제, 기본 브라우저 메뉴 억제, 대상 선택 보존 및 동적 비활성화 회귀 테스트를 추가하고 먼저 실행해 실패를 확인한다.
3. [공유 타입](../../../frontend/src/shared/components/f1-grid/types/grid.types.ts) 및 [F1Grid 구현](../../../frontend/src/shared/components/f1-grid/core/F1Grid.tsx)에 `disableContextMenu?: boolean`(기본 false)을 추가한다. 메뉴는 열지 않되 기존 우클릭 타겟 선택을 유지하고, 옵션이 켜지면 열려 있는 메뉴/재오픈 타이머를 정리한다.
4. API Reference, Docs Portal/Playground, 공개 API 테스트 allowlist 및 [F1-GRID.md](../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)를 같은 계약으로 갱신한다.
5. `cd frontend; npm run test -- tests/f1-grid-context-menu.test.tsx tests/f1-grid-docs.test.tsx` 및 `npm run build`를 실행한다.
6. `127.0.0.1:4173`에서 기본/비활성화 전환, 우클릭 선택, 메뉴 미표시, 헤더 메뉴 유지 여부를 확인하고 캡처를 포함해 [날짜별 결과 문서](../../result/20261016/f1-grid-disable-context-menu/)를 작성한다.
