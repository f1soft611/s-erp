# 문서작성 놓치지 마세요 패널 스타일 보완 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 문서작성 페이지 우측 `놓치지 마세요` 항목을 좌측 정렬하고 긴 제목이 카드 폭 안에서 읽히도록 중립적인 카드 스타일로 보완한다.

**Architecture:** 알림 UI를 담당하는 `ApprovalNoticePanel`에 한정해 MUI `Button` 정렬과 제목 폭/줄바꿈 스타일을 명시한다. 전용 단위 테스트에서 스타일 계약, 클릭 선택, 빈 상태를 검증하며 데이터와 페이지 조립은 변경하지 않는다.

**Tech Stack:** React, TypeScript, MUI, Vitest, React Testing Library, Vite

- [x] **Step 1: 실패할 테스트 작성**

```tsx
import { fireEvent, render, screen, within } from '@testing-library/react';
import '@testing-library/jest-dom/vitest';
import { describe, expect, it, vi } from 'vitest';
import { ApprovalNoticePanel } from '../src/pages/groupware/documents/write/components/ApprovalNoticePanel';
import type { DocumentWriteItem } from '../src/pages/groupware/documents/write/types/documentWrite.types';

const item: DocumentWriteItem = {
  id: 42,
  title: '긴제목g가공백없이이어지는경우에도카드너비안에서줄바꿈되어야합니다',
  kind: '기안서',
  status: '결재진행중',
  author: '작성자',
  date: '2026.10.16',
  summary: '',
};

describe('ApprovalNoticePanel', () => {
  it('좌측 정렬된 전체 너비 알림 항목에서 긴 제목을 카드 너비에 맞춘다', () => {
    render(<ApprovalNoticePanel items={[item]} onSelect={() => undefined} />);

    const button = screen.getByRole('button', { name: /결재 요청 도착/ });
    const title = within(button).getByText(item.title);

    expect(button).toHaveStyle({
      display: 'flex',
      flexDirection: 'column',
      alignItems: 'flex-start',
      justifyContent: 'flex-start',
      textAlign: 'left',
      width: '100%',
      borderWidth: '1px',
    });
    expect(title).toHaveStyle({
      width: '100%',
      overflowWrap: 'anywhere',
    });
  });

  it('알림을 선택하면 선택한 문서 ID를 전달한다', () => {
    const onSelect = vi.fn();
    render(<ApprovalNoticePanel items={[item]} onSelect={onSelect} />);

    fireEvent.click(screen.getByRole('button', { name: /결재 요청 도착/ }));

    expect(onSelect).toHaveBeenCalledWith(item.id);
  });

  it('최대 세 건까지만 표시한다', () => {
    const items = [0, 1, 2, 3].map((index) => ({
      ...item,
      id: item.id + index,
      title: `문서 ${index}`,
    }));

    render(<ApprovalNoticePanel items={items} onSelect={() => undefined} />);

    expect(screen.getAllByRole('button')).toHaveLength(3);
  });

  it('알림이 없으면 기존 안내 문구를 표시한다', () => {
    render(<ApprovalNoticePanel items={[]} onSelect={() => undefined} />);

    expect(screen.getByText('새로운 결재 알림이 없습니다.')).toBeInTheDocument();
  });
});
```

- [x] **Step 1: 버튼 레이아웃을 좌측 정렬 세로 flex로 변경**

현재 버튼 `sx`의 레이아웃을 다음 계약으로 조정한다. 배경과 테두리는 MUI theme 토큰을 사용하고 기존 `onClick`, 라벨, 항목 수 제한은 그대로 둔다.

```tsx
sx={{
  display: 'flex',
  flexDirection: 'column',
  alignItems: 'flex-start',
  justifyContent: 'flex-start',
  width: '100%',
  minWidth: 0,
  gap: 0.5,
  p: 1.5,
  border: '1px solid',
  borderColor: 'divider',
  borderRadius: 2,
  bgcolor: 'action.hover',
  color: 'text.primary',
  textAlign: 'left',
  textTransform: 'none',
}}
```

- [x] **Step 2: 제목 Typography의 너비와 줄바꿈을 고정**

```tsx
<Typography
  variant="caption"
  color="text.secondary"
  sx={{
    width: '100%',
    minWidth: 0,
    overflowWrap: 'anywhere',
    lineHeight: 1.5,
  }}
>
  {item.title}
</Typography>
```
