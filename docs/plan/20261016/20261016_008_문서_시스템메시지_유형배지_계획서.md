# 문서 시스템 메시지 유형 배지 구현 계획

**Goal:** 승인된 다섯 시스템 이벤트를 기존 상태 색상의 명칭 배지로 표시한다.

**Architecture:** 문서 표시 데이터에서 이벤트를 기존 상태 presentation에 매핑한다. 공통 댓글 모델에는 선택적 배지 presentation만 전달하여 공통 컴포넌트가 문서 이벤트 코드를 알지 않도록 한다.

**Tech Stack:** React, TypeScript, MUI Chip, Vitest, Testing Library, Playwright.

## 기준

- [작업지시서](../../directions/20261016/20261016_008_문서_시스템메시지_유형배지_작업지시서.md)

## 후속 수정 계획

1. `COMPLETED` 명칭/색상 매핑과 배지의 계산된 `border-radius: 8px` 회귀 테스트를 먼저 추가하고 실패를 확인한다.
2. 시스템 배지에 기존 문서 상태 배지의 `8px` 모서리를 적용한다. `COMPLETED`는 기존 완료 상태 presentation을 재사용하되 이벤트 명칭은 `완료`로 표시한다.
3. 공통 배지/매핑 테스트와 문서 피드/상세 관련 테스트, 빌드를 수행한다.
4. 합성 브라우저 검증에 완료 이벤트 및 계산된 모서리 값을 추가하고 세 뷰포트 스크린샷과 결과를 갱신한다.
