# 전자결재 빈 댓글 안내문구 제거 계획서

## 목표

댓글이 등록되지 않은 문서에서 빈 상태 안내문구만 제거하고 댓글 입력창 및 다른 상태 처리는 유지한다.

## 구현 방향

- [DocumentApprovalDetailFeed.tsx](../../../frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx)의 빈 상태 `Typography` 렌더링만 제거한다.
- [document-write-page.test.tsx](../../../frontend/tests/document-write-page.test.tsx)에 USER 댓글과 SYSTEM 메시지가 모두 없는 상세 화면에서 안내 문구가 없고 댓글 입력창이 표시되는 회귀 테스트를 추가한다.
- API, 서비스, 백엔드, DB는 변경하지 않는다.

## 작업 순서

1. 실패 테스트를 먼저 작성하고 지정한 Vitest 테스트로 테스트가 의도대로 실패하는지 확인한다.
2. 컴포넌트에서 빈 상태 문구만 제거한다.
3. 회귀 테스트와 변경 범위 테스트를 실행하고 프런트엔드 빌드를 수행한다.
4. 결과 보고서에 구현 및 테스트 결과를 기록한다.

## 검증 기준

- 빈 목록에서 `등록된 댓글이 없습니다.` 텍스트가 존재하지 않는다.
- 빈 목록에서도 `댓글 입력` 입력 요소가 보인다.
- USER/SYSTEM 항목, 로딩, 오류/재시도 동작은 관련 회귀 테스트 및 기존 테스트에서 보존된다.
- 브라우저에서 실제 빈 댓글 상태를 재현할 수 있으면 댓글 섹션을 확인하고 결과 기록에 재현 가능 여부를 명시한다.
