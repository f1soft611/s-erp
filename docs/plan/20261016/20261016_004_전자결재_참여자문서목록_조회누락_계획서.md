# 전자결재 참여자 문서목록 조회 누락 수정 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 결재 참여자의 문서 목록 및 요약 조회가 인증 사용자의 결재선 식별값을 사용하도록 보완한다.

**Architecture:** `DocumentApprovalServiceImpl.actorParams`가 tenant 및 기안자 정보와 함께 `participantUserId = LoginVO.uniqId`를 공통 DAO 파라미터에 포함한다. 목록/요약 SQL은 이미 이 키를 사용하므로 SQL과 프런트엔드 동작은 변경하지 않는다.

**Tech Stack:** Java 17, Spring Boot/eGovFrame, MyBatis, PostgreSQL metadata MCP, JUnit 5, Mockito.
