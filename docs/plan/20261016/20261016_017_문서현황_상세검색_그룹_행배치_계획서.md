# 문서현황 상세검색 그룹 행 배치 계획서

## 목표 및 접근

승인된 [상세 사양](../../spec/20261016/20261016_017_문서현황_상세검색_그룹_행배치_상세사양서.md)에 따라 공통 상세검색의 group별 행 배치와 문서현황 4행 메타데이터를 구현한다. `group`은 행 경계를, `span`은 각 행 안의 필드 너비를 지정하며 기존 span 동작과 값은 유지한다. 날짜 상단 중복 캡션만 제거하고 검색/API 필터 값은 변경하지 않는다.

## 구현 단계

1. `PageSearchArea`와 문서현황 컬럼 메타데이터 테스트를 먼저 추가하고 실패를 확인한다.
2. `PageSearchArea`에서 연속된 같은 group 필드를 새 행으로 묶는다. 모든 행에서 기존 five-column grid와 `searchSpan` 너비 동작을 보존한다.
3. 날짜 필드의 별도 제목만 제거하고 시작/종료일 입력 라벨과 접근성 이름을 유지한다.
4. 문서현황의 `submittedAt`, 결재상태/종류, 제목, 기안자/부서/참여자에 각각 group을 부여하고 기존 `span`을 보존한다.
5. F1-Grid 상세검색 문서를 갱신하고 타깃 테스트, 빌드, 세 가지 브라우저 너비 검증을 수행한다.
6. 결과와 화면 캡처(민감 데이터 미포함 시)를 기록하고 diff 무결성을 확인한다.

## 작업 상태

설계, span 적용 방식, 구현 계획을 승인받았다. 공통 그룹 행 배치와 문서현황 메타데이터를 구현했고, 타깃 테스트 17개와 프런트엔드 빌드가 통과했다. 브라우저 레이아웃 검증은 미인증 세션의 `/login` 리다이렉트와 통합 브라우저 CDP 시간 초과로 보류했다. 접근 가능한 인증 세션에서 375px, 768px, 1280px 검증이 필요하다. 근거는 [결과 문서](../../result/20261016/document-status-page-search-groups/result.md)에 기록했다.
