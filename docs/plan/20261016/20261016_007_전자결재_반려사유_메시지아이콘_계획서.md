# 전자결재 반려 사유 메시지 아이콘 구현 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 반려 승인선의 사유를 도장 아래에 표시하는 대신 메시지 아이콘과 앵커 팝오버로 확인하게 한다.

**Architecture:** 기존 `DocumentApprovalLine.actionComment`를 그대로 사용한다. `DocumentApprovalDetailFeed`의 승인 카드에서 `REJECTED` 및 유효한 사유에만 메시지 버튼을 표시하고, 버튼을 앵커로 하는 MUI 팝오버에 사유를 노출한다. API/타입/백엔드 및 다른 상태의 의견 표현은 변경하지 않는다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Testing Library, Vite.

**Files:**
- Modify: `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`

- [ ] `@mui/icons-material/MessageOutlined`와 MUI `Popover`를 기존 import 규칙대로 추가한다.
- [ ] 팝오버 선택 상태를 `{ anchorEl: HTMLElement; reason: string } | null`로 선언한다. 닫기 처리 시 상태를 `null`로 만든다.

- [ ] 기존 의견 Typography는 `REJECTED`일 때 렌더링하지 않고, `REJECTED` 외 상태는 기존 조건과 표시를 유지한다.

## 설계 반영 확인

- 선택된 위치는 반려 도장 오른쪽 위 겹침이며, 방식은 버튼을 누를 때 도장 옆 팝오버를 여는 것이다.
- 반려 사유는 기존 상세 `approvalLines[].actionComment`에서만 읽는다. 새로운 API, 상태, 저장 또는 DB 변경은 없다.
- 사유가 없는 반려 행은 아이콘을 숨기며, 반려 이외 상태의 기존 의견 텍스트는 보존한다.
