# 20260921_006 공지사항 상단 고정 및 공통 보기 전환 계획서

## 1. 목표

공지사항을 첫 적용 대상으로 하여 게시판·자료실·그룹웨어 업무 화면에서도 재사용할 수 있는 좌우 분할 콘텐츠 셸과 피드형·리스트형 공통 보기 기반을 구축한다. 좌측에는 상단 고정 개수·보기 선택·목록을 배치하고, 우측에는 공지 요약·최근 이슈를 sticky로 고정한다. 보기 모드 전환 시 좌측은 선택 모드 스켈레톤, 우측은 요약 스켈레톤을 표시한 뒤 목록을 재조회한다.

## 2. 작업 분류 및 범위

- 분류: `architectural`
- 대상: 프론트엔드
- 시작 화면: `/groupware/community/notice`
- 백엔드·DB: 변경 없음
- 후속 범위: 리스트 항목 클릭 후 우측 상세 현황 패널, 다른 도메인의 실제 API 연동

## 3. 작업 분해

### 3.1 공통 UI 계층

- `frontend/src/shared/components` 아래에 도메인 중립적인 좌우 콘텐츠 셸과 보기 모드 타입·표시 모델을 정의한다.
- 좌측 상단 도구, 피드형 목록, 리스트형 목록, 피드형 스켈레톤, 리스트형 스켈레톤, 우측 요약 스켈레톤을 책임별 파일로 분리한다.
- 셸은 좌측 목록 슬롯과 우측 요약 슬롯을 제공하고 우측 슬롯에 `position: sticky`를 적용한다.
- 공통 컴포넌트는 제네릭 데이터와 슬롯/render prop/콜백을 사용하고 공지사항 API 타입을 직접 import하지 않는다.
- 공통 컴포넌트는 API 호출, 권한 판단, 도메인별 상세·다운로드·댓글 비즈니스 로직을 소유하지 않는다.

### 3.2 공지사항 어댑터 및 페이지

- `NoticeFeedItem`을 공통 표시 모델로 변환하는 공지사항 어댑터를 둔다.
- 기존 피드형 공지 상호작용은 공지사항 조립 계층에서 유지한다.
- `CommunityNoticePage`는 보기 모드, 재조회, 로딩·오류 상태를 관리한다.
- 보기 모드 버튼 클릭 시 모드를 변경하고 기존 공지 목록 조회 경로를 재호출한다.
- 재조회 중에는 선택 모드에 맞는 전용 스켈레톤을 표시한다.
- 재조회 중에는 우측 요약·최근 이슈 전용 스켈레톤을 함께 표시한다.
- `highlight`/`isNotice === 'Y'`를 기반으로 상단 고정 대상을 계산한다.

### 3.3 리스트형 동작

- 첨부 이미지와 같은 문서형 단일 행을 표시한다.
- 행은 좌측 문서 아이콘, 제목과 사용자 아이콘, 아래 작성자·작성일시 메타정보로 구성한다.
- `isPinned` 항목은 연한 강조 배경과 강조 제목 색상으로 표시한다.
- 리스트 항목 클릭 후 우측 요약 패널을 상세 현황으로 바꾸는 기능은 구현하지 않는다.
- 리스트형에 피드형의 댓글·첨부·확장 UI를 복제하지 않는다.

### 3.4 문서 및 테스트

- 공통 컴포넌트의 표시 모델과 사용 계약을 문서화한다.
- 공지사항 어댑터, 모드 전환, 재조회, 모드별 스켈레톤, 상단 고정 표시 테스트를 추가한다.
- 결과 문서와 375px·768px·1280px 브라우저 스크린샷을 작성한다.

## 4. 영향 범위

- 기존 `frontend/src/shared/components/feed/FeedList.tsx`의 제네릭 목록 패턴을 재사용한다.
- 기존 `NoticeFeedList`의 피드 상호작용과 공지사항 API 계약은 유지한다.
- 목록 길이에 따른 세로 스크롤은 허용하되 우측 요약 영역은 sticky로 고정하고 내부 스크롤은 만들지 않는다.
- 공통 컴포넌트에 공지 전용 필드나 서비스 의존성을 넣지 않는다.
- 필터, 작성, 삭제, 댓글, 첨부, 조회수 정책은 변경하지 않는다.

## 5. 검증 계획

- Vitest: 공통 표시 모델 렌더링, 리스트 필드, 상단 고정 빈 상태, 모드 전환 재조회, 모드별 스켈레톤, 기존 피드 회귀.
- TypeScript/Vite: `cd frontend; npm run build`.
- 전체 프론트 테스트: `cd frontend; npm run test`.
- 브라우저: Playwright로 375px, 768px, 1280px에서 좌우 셸, 모드 전환·좌측 스켈레톤·우측 요약 스켈레톤, sticky 고정, 겹침·잘림·가로 스크롤을 확인한다.
- 백엔드/Maven/DB: 해당 없음.

## 6. 완료 조건

- 공지사항이 공통 좌우 셸, 피드·리스트 컴포넌트와 어댑터를 통해 렌더링된다.
- 피드형과 리스트형 소스·스켈레톤이 분리되어 있다.
- 우측 요약·최근 이슈가 셸의 sticky 슬롯으로 렌더링된다.
- 모드 전환마다 목록 재조회가 발생한다.
- 모드 전환 중 좌측 모드별 스켈레톤과 우측 요약 스켈레톤이 표시된다.
- 상단 고정 영역과 기본 피드형이 제공된다.
- 다른 도메인이 사용할 수 있는 제네릭 props/표시 모델 계약이 문서화되어 있다.
- 테스트·빌드·브라우저 검증과 결과 문서가 남아 있다.
