# 20260921_005 공지사항 제목·본문 조회수 진입 상세 실행 계획

## 공통 제약

- 현재 브랜치에서 진행하며 Worktree를 생성하지 않는다.
- `더보기`가 있으면 더보기 클릭만 조회 트리거로 허용한다.
- `더보기`가 없으면 제목·본문·이미지·첨부파일·댓글 클릭을 조회 트리거로 허용한다.
- 목록 로딩·메뉴·카드 여백은 조회 트리거에서 제외한다.
- 기존 이미지 뷰어·첨부파일·댓글 동작은 보존한다.
- 백엔드·DB와 기존 사용자별 조회수 정책은 변경하지 않는다.

## 실행 태스크

### Step 1: RED 회귀 테스트 추가

- 파일: `frontend/tests/notice-page.test.tsx`
- 작업: 더보기 유무에 따른 제목·본문 조회 콜백 조건과 이미지·첨부·댓글 상호작용 조건을 테스트한다.
- 검증: `npx vitest run tests/notice-page.test.tsx`
- 완료 조건: 구현 전 새 테스트가 클릭 핸들러 부재 또는 조건 불일치로 실패한다.

### Step 2: NoticeFeedList 이벤트 연결

- 파일: `frontend/src/pages/groupware/community/notice/components/NoticeFeedList.tsx`
- 작업: `hasMore` 조건을 계산하고, 더보기 없는 제목·본문에 키보드/클릭 진입을 연결한다. 더보기 없는 이미지·첨부·댓글 클릭에서 상세 콜백을 호출하되 기존 동작은 보존한다. 더보기 있는 공지의 비더보기 영역은 조회 콜백을 호출하지 않는다.
- 검증: `npx vitest run tests/notice-page.test.tsx`
- 완료 조건: 조건별 테스트가 통과하고 이미지·첨부·댓글 이벤트가 중복 호출되지 않는다.

### Step 3: CommunityNoticePage 콜백 안정화

- 파일: `frontend/src/pages/groupware/community/notice/CommunityNoticePage.tsx`
- 작업: 기존 상세 조회 콜백을 재사용하고, 필요한 경우 요청 중 공지 ID를 관리해 빠른 반복 클릭의 중복 API 요청을 막는다.
- 검증: `npx vitest run tests/notice-page.test.tsx tests/notice-page-local-updates.test.tsx`
- 완료 조건: 서버 응답 viewCount 병합과 기존 좋아요·북마크 상태 보존이 유지된다.

### Step 4: 프론트 최종 검증 및 결과 문서

- 파일: `docs/result/20260921/notice-view-entry/`
- 작업: 공지 집중 테스트, 빌드, diff 공백 검사를 실행하고 조건별 결과와 잔여 위험을 기록한다.
- 검증: `npx vitest run tests/notice-page.test.tsx tests/notice-page-local-updates.test.tsx`, `npm run build`, `git diff --check`
- 완료 조건: 집중 테스트와 빌드가 통과하거나 실패 원인이 결과 문서에 기록된다.
