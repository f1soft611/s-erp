# 20260921_006 공지사항 상단 고정 및 공통 보기 전환 상세 실행 계획

## Global Constraints

- 현재 브랜치에서 진행한다.
- 변경 범위는 프론트엔드와 관련 문서로 제한한다.
- 공통 컴포넌트는 공지사항 API 타입·서비스를 직접 import하지 않는다.
- 리스트형 상세 현황 우측 패널은 구현하지 않는다.
- 보기 모드 클릭은 선택 모드로 목록을 재조회하고, 모드별 스켈레톤을 표시한다.
- 기존 사용자 변경 파일은 되돌리지 않는다.
- 기준선 `npm run test`는 22개 파일 통과, 19개 파일 실패, 391개 테스트 통과, 151개 테스트 실패 상태였다. 기존 실패는 이번 변경의 성공 판정과 분리해 기록한다.

## Step 1: 공통 표시 모델과 모드 계약 정의

- 파일: `frontend/src/shared/components/view-mode/commonViewTypes.ts` 신규
- 작업: `feed`/`list` 모드, 도메인 중립 항목 모델, 고정 항목 모델, 모드 전환 콜백 타입을 정의한다.
- 검증: `cd frontend; npx tsc --noEmit -p tsconfig.app.json`
- 인터페이스: 이후 공통 피드·리스트·고정 영역 컴포넌트가 이 타입만 참조한다.
