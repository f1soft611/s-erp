# 20260921_004 공지사항 요약 실데이터 연동 계획서

## 1. 작업 목적

공지사항 페이지의 요약 영역에서 정적 샘플 통계와 하드코딩된 최근 이슈를 제거하고, 현재 공지사항 목록 API가 반환한 실제 게시글 데이터를 기준으로 요약 통계와 최근 이슈를 계산한다.

## 2. 승인 기준 문서

- 작업지시서: `docs/directions/20260921/20260921_004_공지사항_요약_실데이터_연동_작업지시서.md`
- 대상 화면: `/groupware/community/notice`
- 경로 분류: `bounded`
- 승인된 집계 범위: 현재 `fetchNoticePosts`가 반환한 목록

## 3. 설계 결정

- 요약 집계의 입력은 `CommunityNoticePage`의 `noticeItems`로 고정한다.
- 현재 API에 전체 건수 메타데이터가 없으므로 서버 전체 기준 집계 API는 추가하지 않는다.
- `전체 공지`는 현재 목록 길이, `이번 주`는 `createdAt` 기준 주간 건수, `중요 공지`는 `isNotice === 'Y'` 건수, `첨부 문서`는 첨부파일 배열 길이 합계로 계산한다.
- 최근 이슈 점수는 `viewCount + commentCount`이며, 내림차순으로 최대 3건을 표시한다.
- 점수가 같으면 최신 `createdAt`, 그것도 같으면 게시글 ID 내림차순으로 정렬한다.
- 숫자·날짜·첨부파일이 누락되거나 유효하지 않으면 집계에서 0 또는 제외 가능한 기본값으로 정규화한다.

  - `noticeItems` 기반 순수 집계 함수와 메모이즈된 요약 데이터·최근 이슈를 연결한다.
- `frontend/src/pages/groupware/community/notice/components/NoticeSummaryPanel.tsx`
  - 정적 문자열 배열을 제거한다.
  - 계산된 요약 통계와 최근 이슈 props를 렌더링한다.
  - 빈 상태와 조회수·댓글수·점수 표시를 제공한다.
- `frontend/src/pages/groupware/community/notice/data/noticeData.ts`
  - 더 이상 화면 경로에서 사용하지 않는 정적 요약 데이터 의존성을 정리한다.

  - 집계 함수 및 패널 렌더링 회귀 테스트를 추가한다.

### 백엔드 및 데이터베이스
