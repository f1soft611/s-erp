# 20260921_004 공지사항 요약 실데이터 연동 상세 실행 계획

## 실행 방식

- 현재 브랜치에서 진행
- Inline Execution 방식
- 프론트엔드 단일 기능이며 `CommunityNoticePage`와 `NoticeSummaryPanel` 사이 의존성이 있어 태스크를 순차 실행

## 공통 제약

- 승인된 작업지시서와 계획서·상세 사양서 범위만 구현한다.
- 백엔드, DB, API 계약은 수정하지 않는다.
- 조회수는 `NoticeFeedItem`의 별도 원본 필드로 유지하고 `meta` 문자열을 파싱하지 않는다.
- 각 태스크 완료 후 지정된 좁은 검증을 실행하고 결과를 원장에 기록한다.

## 태스크

### Step 1: 집계 계약 RED 테스트 작성

- 파일: `frontend/tests/notice-summary.test.ts`
- 작업: `deriveNoticeSummary`가 전체/이번 주/중요/첨부 통계와 조회수+댓글수 점수 정렬, 동점 처리, 최대 3개 제한, 빈 목록을 검증하는 실패 테스트를 작성한다.
- 검증: `npx vitest run tests/notice-summary.test.ts`
- 완료 조건: 구현 전 집계 함수 미존재 또는 기대 결과 불일치로 테스트가 의도대로 실패한다.

### Step 2: 집계 타입 및 순수 함수 GREEN 구현

- 파일: `frontend/src/pages/groupware/community/notice/data/noticeSummary.ts`
- 작업: `NoticeSummaryStat`, `NoticeRecentIssue` 및 목록 입력을 받아 요약 결과를 반환하는 순수 함수를 구현한다. 숫자·날짜·첨부파일을 정규화하고 주간 경계를 계산한다.
- 검증: `npx vitest run tests/notice-summary.test.ts`
- 완료 조건: Step 1 테스트가 통과한다.

### Step 3: 피드 데이터에 조회수와 생성일 원본 연결

- 파일: `frontend/src/pages/groupware/community/notice/data/noticeData.ts`, `frontend/src/pages/groupware/community/notice/CommunityNoticePage.tsx`
- 작업: `NoticeFeedItem`에 `viewCount`, `createdAt`을 추가하고 API 변환 결과에 원본 값을 저장한다. 정적 `summaryStats` 의존성을 제거한다.
- 검증: `npx vitest run tests/notice-summary.test.ts tests/notice-page-local-updates.test.tsx`
- 완료 조건: 실제 API 목록이 집계 함수에 필요한 필드를 제공한다.

### Step 4: 요약 패널을 계산 결과로 전환

- 파일: `frontend/src/pages/groupware/community/notice/components/NoticeSummaryPanel.tsx`, `frontend/src/pages/groupware/community/notice/CommunityNoticePage.tsx`
- 작업: 정적 최근 이슈를 제거하고 `stats`, `recentIssues` props를 렌더링한다. 빈 상태, 제목 줄바꿈, 조회·댓글·점수를 표시한다.
- 검증: `npx vitest run tests/notice-summary.test.ts tests/notice-page.test.tsx tests/notice-page-local-updates.test.tsx`
- 완료 조건: 화면이 API 목록 기반 요약과 최근 이슈를 표시한다.

### Step 5: 회귀 정리 및 빌드

- 파일: `frontend/tests/notice-summary.test.ts`, 관련 공지 테스트
- 작업: 패널 렌더링 및 필터 갱신 회귀 케이스를 보완하고 테스트와 타입을 정리한다.
- 검증: `npm run build`, `npx vitest run tests/notice-summary.test.ts tests/notice-page.test.tsx tests/notice-page-local-updates.test.tsx`
- 완료 조건: 관련 테스트와 프론트 빌드가 통과한다.
