# 20261015_019 문서 수정 이미지 리사이즈 미리보기 복원 계획서

## 목표 및 근거

기존 전자결재 본문 이미지를 수정 모달에서 리사이즈할 때 Blob 미리보기가 보호 API URL로 덮여 엑박이 되는 문제를 수정한다. 승인된 설계는 [이미지 리사이즈 미리보기 설계](../../superpowers/specs/2026-10-15-document-edit-image-resize-preview-design.md)에 기록했다.

## 변경 범위

- `frontend/src/pages/groupware/documents/write/hooks/useDocumentComposer.ts`: 이미지 로드 효과에서 원본 URL→Blob URL 매핑과 업데이트 후 미리보기 복원, 실패 소스 숨김, listener/URL 정리
- `frontend/tests/document-write-page.test.tsx`: 기존 보호 이미지 편집 테스트에 resize handle 이벤트와 Blob 표시 및 저장 결과 검증
- `docs/result/20261015/document-edit-image-resize-preview/`: 실제 검증 결과와 브라우저 접근 여부

## 실행 순서

1. 보호 이미지 통합 테스트에 에디터 resize 조작을 추가하고 변경 전 실패를 확인한다.
2. 이미지 로드 effect가 TipTap update 이벤트 후 렌더된 DOM에 Blob URL을 다시 적용하도록 한다.
3. 리사이즈 후 이미지 `src`, width/height, 저장 시 원래 API URL, Blob URL 미포함을 검증한다.
4. 기존 첨부 유지 테스트, build, Problems, `git diff --check`를 실행한다.
5. 브라우저 인증이 가능하면 직접 확인하고, 로그인으로 제한되면 결과에 기록한다.

## 검증 명령

`frontend`에서:

```powershell
npx vitest run tests/document-write-page.test.tsx -t "loads protected existing images|shows and preserves existing attachments" --testTimeout=20000
npm run build
git diff --check
```

## 제외 범위

- API/DB와 이미지 업로드 계약
- 신규 이미지 업로드 흐름과 문서 상세 화면
- 저장 모델의 URL이나 공용 이미지 크기 계산 로직 변경
