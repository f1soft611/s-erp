# 20261015_008 전자결재 상세 합의·참조 한 줄 배치 계획서

## 목표

전자결재 상세 결재선에서 합의·참조 제목과 참여자 목록을 각각 한 행으로 정렬하고, 제목 너비와 기본 행 높이를 동일하게 한다.

## 변경 범위

- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`: 합의/참조 각 영역을 동일한 제목 열 및 유동 콘텐츠 열을 가진 grid row로 배치한다.
- `frontend/tests/document-write-page.test.tsx`: 상세 결재선의 제목-목록 형제 관계, 동일한 너비/최소 높이 및 기존 승인 데이터 표시를 검증한다.
- `docs/spec/20261015/20261015_008_전자결재_상세_합의_참조_한줄배치_상세사양서.md`: 반응형 레이아웃 기준을 상세화한다.
- `docs/result/20261015/document-approval-agreement-reference-inline-layout/`: 테스트, 빌드, 375/768/1280px 브라우저 검증과 비식별 캡처를 기록한다.

## 실행 순서

1. 계획에서 합의한 반응형 배치, 64px 제목 열, 72px 기본 최소 높이 및 동작 비변경 기준을 상세 사양서에 기록한다.
2. 기존 상세 결재선 회귀 테스트에 한 행 DOM 구조 및 동일 grid geometry 검증을 추가하고 실패를 확인한다.
3. 상세 화면 합의/참조 영역만 동일 grid geometry로 구성한다.
4. 관련 상세 테스트와 프론트 빌드를 실행한다. 전체 문서작성 테스트는 기준 실행에서 확인한 기존 실패와 사용자가 지정한 집중 검증 범위를 결과에 구분해 기록한다.
5. 빌드가 가능하면 375px, 768px, 1280px 브라우저 폭에서 줄바꿈, 겹침 및 전체 가로 넘침을 확인한다. 빌드가 차단되면 브라우저 검증과 캡처 미수행 사실 및 원인을 기록한다.
6. 결과 문서에 코드 변경, 검증 결과, 알려진 차단 사항을 작성하고 개인정보가 없는 캡처가 가능할 때만 포함한다.

## 제외 범위

결재 카드, 결재선의 참가자 데이터/순서/상태, 합의 처리 규칙, API, 백엔드, DB는 수정하지 않는다.
