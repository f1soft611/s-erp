# 20261015_015 기안양식 본문 스크롤 공통화 계획서

## 목표

기안양식 문서 작성/수정 모달에서 에디터의 위·아래 구분선을 제거하고, 내부 에디터 스크롤 대신 공통 다이얼로그 본문 전체가 세로 스크롤하도록 변경한다.

## 근거 문서

- 작업지시서: [20261015_015 작업지시서](../../directions/20261015/20261015_015_기안양식_본문_스크롤_공통화_작업지시서.md)
- 승인 설계: [본문 스크롤 공통화 설계](../../superpowers/specs/2026-10-15-draft-form-template-body-scroll-design.md)
- 구현 계획 상세: [Draft form template body scroll implementation plan](../../superpowers/plans/2026-10-15-draft-form-template-body-scroll.md)

## 변경 범위

- `frontend/src/shared/components/rich-text-editor/richTextEditor.types.ts`: 기본 동작을 유지하는 선택형 스크롤 모드 타입을 추가한다.
- `frontend/src/shared/components/rich-text-editor/RichTextEditor.tsx`: 선택한 경우에만 에디터 콘텐츠가 높이에 제한되지 않고 컨테이너 스크롤을 허용하는 스타일을 적용한다.
- `frontend/src/pages/co/workflow/form/components/DraftFormTemplateDialog.tsx`: 컨테이너 스크롤 모드를 선택하고 에디터 위·아래 선을 제거한다.
- `frontend/tests/rich-text-editor.test.tsx`: 기본 모드와 컨테이너 모드의 스크롤 소유권을 검증한다.
- `frontend/tests/draft-form-template-dialog.test.tsx`: 모달 본문 스크롤, 고정 푸터 및 프레임 구분선 부재를 검증한다.
- 날짜별 상세 사양서와 결과 보고서를 작성한다.

## 실행 순서

1. 집중 테스트에 컨테이너 모드와 기안양식 다이얼로그의 새 스크롤 계약을 작성하고 기존 코드에서 실패하는지 확인한다.
2. RichTextEditor의 선택형 모드를 추가하되 기존 기본 내부 스크롤을 유지한다.
3. DraftFormTemplateDialog만 컨테이너 모드를 적용하고 위·아래 에디터 경계를 없앤다.
4. 집중 Vitest를 실행한다.
5. 375px, 768px, 1280px에서 고정 헤더/푸터와 전체 본문 스크롤을 브라우저로 확인한다.
6. `npm run build`를 실행하고 날짜별 상세 사양서 및 결과 문서에 검증 결과를 기록한다.

## 비범위

- `CommonDialog`의 구조나 헤더/푸터 구분선
- 문서 작성/공지사항 작성 및 다른 RichTextEditor 소비자의 스크롤 규칙
- 기안양식 편집·저장·업로드 기능, API, 백엔드 및 DB

## 검증 명령

`frontend` 폴더에서:

```powershell
npm run test -- tests/draft-form-template-dialog.test.tsx tests/rich-text-editor.test.tsx
npm run build
```

## 완료 기준

- 대상 모달에서 본문 전체의 세로 스크롤, 위·아래 선 제거, 고정 헤더/푸터가 검증된다.
- `RichTextEditor` 기본 모드의 내부 스크롤과 다른 화면 동작이 유지된다.
- 집중 테스트와 빌드가 통과하고 브라우저 확인 또는 미수행 사유가 결과 문서에 남는다.
