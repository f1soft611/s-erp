# 20261015_011 업무작성 자주 쓰는 결재선 F1-Grid 계획서

## 목표

템플릿 관리 화면을 F1-Grid로 바꾸고, 행별 적용/삭제와 결재선명 인라인 편집 및 수정 행 일괄 저장을 제공한다.

## 구현 순서

1. 기존 설정 다이얼로그 테스트에 F1-Grid 표시, 셀 편집, 일괄 저장, 부분 실패, 행별 불러오기/삭제, 미저장 변경 폐기 확인 테스트를 추가한다.
2. `DocumentApprovalSettingsDialog.tsx`에서 기존 선택/이름 변경 UI를 F1-Grid로 교체하고 기존 CRUD 서비스를 재사용한다.
3. 이름 검증과 부분 성공 재시도, 불러오기/삭제/닫기 전 미저장 편집 확인을 구현한다.
4. Grid가 중첩 모달 안에 있어도 같은 Grid 내 다른 셀 클릭으로 현재 편집을 commit하고 변경 집합 및 포커스가 갱신되는지 회귀 테스트로 검증한다.
5. F1-Grid 사용 문서, 날짜별 상세 사양, 결과 보고서 및 브라우저 캡처를 갱신한다.
6. 아래의 최소 검증을 수행하고 기존 공유 작업공간의 무관한 변경은 보존한다.

## 범위

- 프론트엔드 설정 다이얼로그, F1-Grid의 same-grid blur commit 처리 및 관련 테스트
- F1-Grid 공개 API 사용 문서와 날짜별 작업 문서
- 기존 템플릿 API 및 저장 데이터 계약은 변경하지 않는다.
- 기존 셀 범위 선택 동작과 백엔드/DB 계약은 변경하지 않는다.

## 검증
