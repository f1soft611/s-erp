# 20261015_002 문서 작성 결재선 순번 표시 통일 계획서

## 목표

문서 작성 모달과 문서 상세 결재선의 결재·합의 단계 순번을 24px 원형 테두리 배지로 통일하고, 작성 결재자 순번과 이름을 가운데 배치한다.

## 실행 순서

1. 작업지시서, 승인 설계 및 상세 사양서에 따라 표시 규칙을 고정한다.
2. `frontend/tests/document-write-page.test.tsx`의 작성·상세 결재선 회귀 테스트에 배지 크기, 테두리, 중앙 정렬 검증을 추가하고 기존 동작 기준이 통과하는지 확인한다.
3. `ApprovalSequenceBadge.tsx` 공통 컴포넌트를 추가한다.
4. `DocumentApprovalFields.tsx`에서 결재·합의 순번에 공통 배지를 사용하고 결재자 하단 순번/이름 묶음을 가운데 정렬한다.
5. `DocumentApprovalDetailFeed.tsx`에서 승인·합의 단계 순번에 공통 배지를 사용해 크기를 24px로 통일한다.
6. 대상 Vitest 파일과 프로덕션 빌드를 실행한다.
7. 실제 브라우저에서 1280px, 768px, 375px 폭으로 모달·상세 화면을 확인하고 결과 문서 및 개인정보 없는 스크린샷을 기록한다.

## 변경 대상

- `frontend/src/pages/groupware/documents/write/components/ApprovalSequenceBadge.tsx` (신규)
- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx`
- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`
- `frontend/tests/document-write-page.test.tsx`
- `docs/result/20261015/document-approval-sequence-badge/`

현재 worktree에 존재하는 상세 화면 및 테스트 파일 변경은 보존하고, 이번 순번 표현에 필요한 부분만 반영한다.

## 검증 명령

`frontend`에서 실행한다.

```powershell
npm run test -- tests/document-write-page.test.tsx
npm run build
```

## 완료 기준

- 상세 및 작성 화면의 결재·합의 배지 크기가 각각 24px 원형 테두리로 일치한다.
- 모든 순번 숫자가 배지 중앙에 정렬되고, 작성 결재자의 순번·이름이 한 묶음으로 가운데 배치된다.
- 순번 산정, 합의 단계 표현 방식, 참여자 제거, 상세 결재 상태 및 기존 화면 기능이 유지된다.
- 대상 테스트와 프론트엔드 빌드가 통과한다.
- 데스크톱·태블릿·모바일 브라우저 확인 및 결과 기록이 완료된다.
