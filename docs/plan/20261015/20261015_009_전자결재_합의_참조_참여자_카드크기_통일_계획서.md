# 전자결재 합의·참조 참여자 카드 크기 통일 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 상세 결재선의 합의·참조 참여자 카드를 참조 카드 크기 기준으로 통일하고 부서 정보가 없을 때 `부서없음`으로 표시한다.

**Architecture:** 기존 `DocumentApprovalDetailFeed`의 두 참여자 렌더링 경로를 유지하면서 폭, 고정 높이, 내부 여백, 아바타 치수와 두 줄 정보 레이아웃을 맞춘다. 기존 상세 화면 통합 테스트에서 스타일 및 빈 부서 표시를 검증하고, 날짜별 작업 문서와 결과 기록을 갱신한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Playwright/browser validation.

---

## 승인된 설계

상세 기준은 [합의·참조 카드 크기 통일 설계](../../superpowers/specs/2026-10-15-document-approval-participant-card-size-design.md)를 따른다. 합의·참조 모두 동일한 폭 규칙(`flex: 0 1 240px`, 최소 폭 `min(100%, 190px)`, 최대 폭 100%), `66px` 고정 외곽 높이 및 `36 × 36px` 아바타를 사용한다. 사용자 이름과 부서는 각각 한 줄씩 표시하며, 부서가 없거나 공백이면 `부서없음`으로 표시한다. 합의 상태 표시는 기존처럼 유지한다.

## Task 2: 합의·참조 카드 동일성 회귀 테스트 작성

**Files:**
- Modify: `frontend/tests/document-write-page.test.tsx`

- [ ] **Step 1: 기존 상세 결재선 테스트의 크기 assertion 갱신**

기존 `read-only system events` 테스트에서 합의 카드에 대한 `minHeight: '58px'` assertion을 제거하고, 합의와 참조 카드에 아래 공통 치수 규칙이 각각 적용되는지 검사한다.

```tsx
const participantCards = [
  screen.getByTestId('approval-line-agreement-participant-72'),
  screen.getByTestId('approval-line-reference-participant-73'),
];

for (const card of participantCards) {
  expect(card).toHaveStyle({
    flex: '0 1 240px',
    minWidth: 'min(100%, 190px)',
    maxWidth: '100%',
    height: '66px',
    boxSizing: 'border-box',
    padding: '8px',
  });
}
```

각 카드의 Avatar에서 `width: 36px`, `height: 36px`를 확인한다. 기존 참여자 목록 flex-wrap 및 상세 행 배치 assertion은 보존한다.

- [ ] **Step 2: 부서 fallback 회귀 assertion 추가**

기존 합의자 72(부서 없음), 합의자 77(공백 부서), 참조자 78(공백 부서) 데이터를 이용해 세 카드에 `부서없음`이 표시되는지 검사한다. 부서 표시는 각 카드의 `approval-line-agreement-department-<id>` 및 `approval-line-reference-department-<id>` test id를 사용하도록 사양과 구현을 맞춘다. 기존 빈 부서 문자열이 숨겨지는 assertion은 `부서없음` 표시 검증으로 교체한다.

- [ ] **Step 3: 변경 전 지정 테스트 실행**

Run from `frontend`:

```powershell
npx vitest run tests/document-write-page.test.tsx --testNamePattern="read-only system events" --testTimeout=15000
```

Expected: FAIL. 현재 합의 카드 치수와 참조 카드 치수가 다르고, 빈 부서에는 `부서없음` 표시가 없어 최소한 해당 신규 assertion이 실패한다.

## Task 3: 상세 결재선 합의·참조 카드 구현

**Files:**
- Modify: `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`

- [ ] **Step 1: 합의 카드의 공통 외곽 스타일 반영**

합의 참여자 카드 `sx`의 `flex`, `minWidth`, `maxWidth`를 참조 기준으로 맞춘다. 기존 `minHeight: 58`을 `height: 66`, `boxSizing: 'border-box'`로 바꾸고, 내부 여백은 참조 카드와 동일하게 `p: 1`로 유지한다.

- [ ] **Step 2: 합의 Avatar와 두 줄 정보 표시 반영**

합의 Avatar의 가로/세로를 `36`으로 맞춘다. 이름은 첫 줄에 남기고, 부서명과 기존 상태 배지를 둘째 줄에 렌더링한다. 부서 표시를 빈 값에서도 유지하며, 표시 텍스트는 `hasDepartmentName ? departmentName : '부서없음'`로 만든다. 둘째 줄에는 기존 합의 상태 배지가 함께 표시되도록 한다.

- [ ] **Step 3: 참조 카드도 고정 크기와 fallback 적용**

참조 참여자 카드에 `height: 66`, `boxSizing: 'border-box'`를 추가하고, 부서 Typography에 `approval-line-reference-department-<id>` test id를 일관되게 제공한다. 부서 텍스트는 누락/공백일 때 `부서없음`을 표시하며 항상 이름 아래 두 번째 줄을 렌더링한다. 참조 Avatar는 이미 `36 × 36px`이므로 유지한다.

- [ ] **Step 4: 지정 테스트 재실행**

Run from `frontend`:

```powershell

```

Expected: PASS. 대상 상세 결재선 테스트가 통과하고 다른 테스트는 제외된다.
