# 전자결재 공지사항형 피드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전자결재 문서 목록/피드 항목을 선택하면 공지사항과 같은 우측 상세 패널에서 문서 본문·이미지·첨부·시스템 이력·참여자 댓글을 보고 처리할 수 있도록 한다.

**Architecture:** 화면은 기존 `PageAreaOverlay`, `PostDetailPanel`, `ContentSplitLayout`, 공통 `FeedView`/`ListView`를 사용하며 문서 전용 카드와 상세 피드 컴포넌트를 둔다. USER 댓글/파일은 전자결재 컨트롤러/서비스의 전용 경로에서 처리해 문서 참여와 댓글 소유 관계를 검증한다. USER 댓글 페이지는 `comment_type='USER'`만 반환하며 기존 SYSTEM 타임라인은 유지한다. 댓글 파일의 `owner_type`은 `APPROVAL_COMMENT`로 분리하고, 일반 공통 파일 API에서도 이 owner type을 거부해 전용 권한 경로를 우회하지 못하게 한다. 문서 본문·시스템 이벤트·결재 상태는 기존 approval API 경계를 유지한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Java 17, Spring Boot/eGovFrame, MyBatis, PostgreSQL, JUnit 5, Mockito.

---

## 범위

- 목록 행 또는 피드 카드 선택 시 상세 모달 대신 오른쪽 `PageAreaOverlay` 패널을 연다. 닫기 버튼·바깥 클릭·Escape로 닫으며 목록, 필터, 보기 모드를 유지한다.
- 피드/리스트 전환을 보존하고 피드에서는 공지사항과 같은 카드형 문서 목록을 보여준다.
- 상세 피드에서 본문 이미지, 기존 승인 문서 첨부, 결재선 및 시스템 이력, 사용자 댓글·대댓글을 보여준다.
- 댓글 작성/수정/삭제, 댓글 파일 업로드/다운로드/삭제 및 댓글 이미지 표시를 참여자 권한 안에서 제공한다.
- 기존 순차 결재/합의/반려/보완요청/재상신 규칙을 보존한다. 공감·북마크·문서 고정, 게시글 수정/삭제는 추가하지 않는다.
- 사용자 댓글 저장은 `tb_common_comment`의 `USER` 행과 `owner_type='APPROVAL'`, `owner_id=electronicApprovalId`를 사용한다. 시스템 이벤트는 기존의 `SYSTEM` 행으로 구분하고 USER 댓글 페이지에서 제외한다.
- 댓글 첨부는 `tb_common_file`에서 `owner_type='APPROVAL_COMMENT'`, `owner_id=commentId`, `file_usage_type='ATTACHMENT'`를 사용한다. tenant·문서 참여·댓글과 approval 문서의 연계·댓글 작성자·파일 owner를 서버에서 검증한다.
- 일반 공통 댓글 API의 `APPROVAL` 차단은 유지하고, comment ID 기반 범용 수정/삭제도 approval-owned 행을 거부하게 한다. 공통 파일 API는 `APPROVAL`과 `APPROVAL_COMMENT`를 owner 지정 경로뿐 아니라 file ID 직접 조회/삭제에서도 차단하며 approval 전용 경로만 댓글 파일을 다룬다.
- PostgreSQL metadata 확인 결과 `tb_common_comment`는 USER의 `event_type IS NULL`을 허용하고 parent ID FK만 있으며, comment/file의 approval owner 관계 FK는 없다. `tb_common_file.file_usage_type`은 `ATTACHMENT`와 `EMBEDDED`만 허용한다. 코드에서 association을 반드시 검증하며 이 기능에 필요한 DB 변경은 없다.

## 완료 조건

- 목록과 피드 카드 모두 선택 시 모달 없이 공지사항 같은 오른쪽 상세 패널을 열며 닫기/바깥 클릭/Esc 동작이 된다.
- Feed mode가 공지사항형 카드 목록이고 list mode/필터/좌측 상태를 보존한다.
- 본문 이미지와 문서 첨부가 인증 참여자에게 표시/다운로드 된다.
- USER 댓글/대댓글과 댓글 첨부/이미지 기능이 참여자와 작성자 권한 안에서 제공되며 SYSTEM 이벤트는 read-only로 구분된다.
- 다른 tenant/비참여자/교차 문서 댓글·파일 ID의 조회·쓰기·다운로드가 서버에서 차단된다.
- 순차 결재/합의 및 action/재상신 권한이 기존대로 유지된다.
- 관련 Vitest/Maven 테스트와 frontend build 결과가 성공 또는 남은 blocker로 명시되고, 375/768/1280px 캡처 및 결과 보고서가 존재한다.
- PostgreSQL 확인 또는 대체 증거와 schema migration 여부를 결과에 기록한다.
