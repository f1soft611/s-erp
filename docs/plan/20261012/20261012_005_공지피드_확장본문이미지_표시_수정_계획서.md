# 공지 피드 확장 본문 이미지 표시 수정 계획서

> **For agentic workers:** Implementation is performed inline in this session. Follow the project task direction and detailed specification before changing code. Use TDD for the renderer regression.

**Goal:** Fix authenticated embedded images that appear broken when a notice feed body is expanded.

**Architecture:** Keep the existing sanitized HTML rendering and stable notice image API. Store the hydrated expanded HTML in React state so rerenders retain blob-backed image sources. Manage generated blob URLs with that content's lifecycle and show an accessible inline error when an image request fails.

**Tech Stack:** React, TypeScript, Vitest, Testing Library, Vite.

Test shape for the success path:

```tsx
it('loads a protected image inside an expanded notice body', async () => {
  const objectUrl = 'blob:expanded-notice-image';
  apiGetBlob.mockResolvedValue(new Blob(['image']));
  vi.stubGlobal(
    'URL',
    Object.assign(URL, {
      createObjectURL: vi.fn(() => objectUrl),
      revokeObjectURL: vi.fn(),
    }),
  );
  const item = {
    ...noticeFeed[0],
    body: '이미지를 포함한 공지 전체 내용',
    summary: '이미지를 포함한 공지',
    bodyHtml:
      '<p><img src="/api/v1/groupware/boards/notice/posts/42/embedded-images?objectKey=tenant%2F1%2Fimage.png" alt="본문 이미지"></p>',
  };

  render(
    createElement(NoticeFeedList, {
      items: [item],
      isDark: false,
      expandedNoticeId: item.id,
    }),
  );

  const body = screen.getByTestId(`notice-preview-${item.id}`);
  await waitFor(() =>
    expect(body.querySelector('img')).toHaveAttribute('src', objectUrl),
  );
  expect(apiGetBlob).toHaveBeenCalledWith(
    expect.stringContaining('/api/v1/groupware/boards/notice/posts/42/'),
  );
});
```
