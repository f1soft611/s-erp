## 상세 계획

1. [상세 사양서](../../spec/20261012/20261012_009_DB_MCP_에이전트_사용지침_명확화_상세사양서.md)와
   [승인된 설계](../../superpowers/specs/2026-10-12-db-mcp-agent-instructions-design.md),
   [실행 계획](../../superpowers/plans/2026-10-12-db-mcp-agent-instructions.md)을
   기준으로 변경 범위와 완료 조건을 확인한다.
2. 루트 [AGENTS.md](../../../AGENTS.md)에 DB 작업의 MCP 직접 호출 원칙을
   간결하게 추가하고 상세 전용 지침으로 연결한다.
3. DB MCP 전용 지침에 현행 workspace 서버명과 도구, 안전한 호출 순서,
   tenant 선택 조건, 도구 미노출·오류 대응을 기술한다.
4. 변경 문구를 루트 `.mcp.json` 및 MCP 설정 테스트와 대조한다. 설정과 기존
   사용자용 연결 사양서는 읽기만 한다.
5. 민감정보·잘못된 쓰기 허용·MCP 검증을 가장한 표현 여부와 링크를 확인하고,
   scoped `git diff --check`를 실행한다.
6. 변경과 검증 결과를 날짜별 결과 문서에 기록한다.

## 비범위

- `.mcp.json`, 서버 코드, 환경변수, 자격 증명 수정
- MCP 도구를 통한 DB 행 조회·변경
- 실제 VS Code UI에서 서버 시작·신뢰 및 새 Copilot 세션 조작
- 기존 사람용 PostgreSQL MCP 구성 사양서 수정
