## 상세 계획

1. [상세 사양서](../../spec/20261012/20261012_008_DB_MCP_연결문서_개정_사양서.md)와
   [설계 문서](../../superpowers/specs/2026-10-12-db-mcp-connection-documentation-design.md),
   [실행 계획](../../superpowers/plans/2026-10-12-db-mcp-connection-documentation.md)를
   기준으로 범위와 완료 조건을 확인한다.
2. 기존 PostgreSQL 읽기 전용 MCP 구성 사양서에서 구식 `.vscode/mcp.json`
   지침을 제거하고, 루트 `.mcp.json`에 연결하는 절차를 정리한다.
3. 로컬 `.env` 준비, Node 패키지 설치·빌드, VS Code 서버 시작·신뢰, 새
   Copilot 세션에서 도구 확인, 기본 문제 해결 절차를 문서화한다.
4. 연결값과 tenant 식별 정보가 문서에 노출되지 않았는지 검토하고, 실제 경로·
   명령을 설정 및 패키지 파일과 대조한다.
5. 문서 변경 결과를 날짜별 결과 경로에 기록하고 `git diff --check`와 변경
   범위를 확인한다.

## 비범위

- `.mcp.json` 및 MCP 서버 구현 수정
- DB 조회·변경 및 실제 접속 자격 증명 점검
- VS Code UI에서 서버를 시작하거나 신뢰하는 실제 세션 조작
- UI 변경 및 스크린샷 작성
