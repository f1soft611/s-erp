# 문서작성 저장 피드백 및 로딩 개선 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 문서작성 모달의 성공/오류 피드백과 초기·양식 로딩 표시를 S-ERP의 공통 알림 및 페이지 로딩 UX에 맞춘다.

**Architecture:** 문서 저장과 첨부 API 계약은 유지한다. `useDocumentComposer`는 성공 시 공통 `NotificationContext` 토스트를 발생시키고 저장/첨부 오류는 컴포저 상단 오류 상태에 보존한다. `DocumentComposerDialog`는 초기 조회나 양식 본문 조회 중 공통 헤더와 푸터를 유지하면서 탭 아래 전체 본문을 중앙 `CircularProgress`로 대체한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, React Testing Library, Vite.
