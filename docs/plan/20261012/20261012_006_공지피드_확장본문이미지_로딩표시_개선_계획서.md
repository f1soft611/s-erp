# 20261012_006 공지 피드 확장 본문 이미지 로딩 표시 개선 계획서

> **For agentic workers:** Execute inline after approval, following the failing-test-first steps. Keep the existing sanitized HTML renderer and authenticated image contract.

**Goal:** Prevent broken-image flashes after expanding a notice by showing a per-image loading placeholder until each protected image is fetched and decoded.

**Architecture:** Keep rich body HTML in the existing sanitized/deferred HTML flow. Replace deferred protected-image nodes with sized loading placeholders immediately when source markup declares dimensions, then hydrate each image independently through `apiGetBlob`. If markup has no dimensions, avoid a guessed-size placeholder while fetching; decode the blob to learn its intrinsic size, show an exact-size placeholder for at least one rendered frame, then replace it with the blob-backed image. Constrain the final image and placeholder to the content width while preserving aspect ratio, and keep existing failure and object URL cleanup behavior.

**Tech Stack:** React, TypeScript, MUI `Skeleton` visual conventions, Vitest, Testing Library, Vite.
