# F1-Grid 좁은 헤더 hover 높이 보정 계획서

- 작업지시서: [20261001*004_F1Grid*좁은*헤더\_hover*높이*보정*작업지시서.md](../../directions/20261001/20261001_004_F1Grid_좁은_헤더_hover_높이_보정_작업지시서.md)
- 승인 설계: [F1-Grid Header Hover Height Design](../../superpowers/specs/2026-10-01-f1-grid-header-hover-height-design.md)
- 상세 사양서: [20261001*004_F1Grid*좁은*헤더\_hover*높이*보정*사양서.md](../../spec/20261001/20261001_004_F1Grid_좁은_헤더_hover_높이_보정_사양서.md)

## 구현 단계

1. `frontend/tests/f1-grid.test.tsx`에 긴 헤더명의 한 줄 말줄임 스타일과 전체 접근성 이름을 검증하는 테스트를 먼저 추가한다.
2. `cd frontend; npx vitest run tests/f1-grid.test.tsx -t "truncates narrow header names"`로 구현 전 실패를 확인한다.
3. `frontend/src/shared/components/f1-grid/core/GridHeader.tsx`에서 헤더명만 `span`으로 감싸고 `minWidth: 0`, `overflow: hidden`, `textOverflow: ellipsis`, `whiteSpace: nowrap`을 적용한다. hover 메뉴 공간 확보 스타일과 메뉴 동작은 변경하지 않는다.
4. 동일 테스트를 다시 실행해 통과를 확인한다.
5. `frontend/src/pages/f1-grid-docs/F1-GRID.md`에 좁은 헤더 표시 규칙을 추가한다.
6. `cd frontend; npm run build` 및 실제 브라우저에서 hover 전후 헤더 높이와 메뉴 동작을 확인한다.
7. 결과 문서와 검증 스크린샷을 `docs/result/20261001/f1-grid-header-hover-height/`에 보관한다.

## 영향 범위

- `GridHeader`를 사용하는 공용 F1-Grid 헤더
- 헤더 제목이 좁은 컬럼에서 말줄임으로 표현되는 표시 방식만 변경

## 완료 조건

- 관련 회귀 테스트와 빌드가 통과한다.
- 브라우저 hover 전후 헤더 높이가 유지되고 메뉴 버튼이 동작한다.
- F1-Grid 문서 및 결과 기록이 코드 동작과 일치한다.
