# 20261001_002 공통 상세 검색 구분선 계획서

## 목적

상세 검색의 입력 영역과 액션 버튼 영역을 전체 폭 가로선으로 분리해 시각적 위계를 명확히 한다.

## 구현 순서

1. 상세 검색 테스트에 가로 separator 노출 검증을 추가하고 현재 구현에서 실패하는지 확인한다.
2. `PageSearchArea`에서 필드 그리드와 액션 영역 사이에 MUI `Divider`를 배치한다.
3. 상세 검색 컴포넌트 테스트와 프론트엔드 빌드를 검증한다.
4. 결과 문서에 변경 및 검증 상태를 기록한다.

## 영향 및 제외

- 영향 파일: `frontend/src/shared/components/PageSearchArea.tsx`, `frontend/tests/page-search-area-detail.test.tsx`
- 검색 로직, API, 반응형 그리드 정의, 버튼 순서와 정렬은 변경하지 않는다.
- DB 영향 없음.
