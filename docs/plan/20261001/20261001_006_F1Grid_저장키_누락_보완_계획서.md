# 20261001_006 F1-Grid 저장 키 누락 보완 계획서

## 목표

모든 실제 F1Grid/F1Tree 화면 인스턴스가 서로 다른 안정적인 `storageKey`를 사용하도록 하고, 이후 누락/중복을 회귀 테스트에서 감지한다.

## 구현 순서

1. TypeScript AST 기반 테스트로 화면 및 공용 컴포넌트 JSX의 키 누락/중복을 검사하고 현재 누락 상태를 확인한다.
2. 키가 없는 12개 렌더링 인스턴스에 용도별 고유 값을 지정한다. 기존 키는 보존하고 플레이그라운드 공용 그리드는 `kind`별 키를 사용한다.
3. F1-Grid 문서와 날짜별 작업 문서를 갱신하고 집중 테스트 및 빌드를 수행한다.

## 변경 대상

- 호출부: DraftFormGrid, F1GridPlayground, F1GridTestPage, ModuleManagementPanel, RoleManagementPanel, WarehouseManagementPanel, CommonCodeItemHelpDialog
- 회귀 테스트: `frontend/tests/f1-grid-storage-keys.test.ts`
- 문서: `frontend/src/pages/f1-grid-docs/F1-GRID.md`, `frontend/src/pages/f1-grid-docs/data/f1GridDocs.ts`

## 검증

- `npm --prefix frontend run test -- tests/f1-grid-storage-keys.test.ts`
- `npm --prefix frontend run build`
- TypeScript AST 회귀 테스트가 모든 JSX 호출부의 키 존재와 키 표현식 고유성을 검증한다.
