# 출하계획 메뉴와 레이아웃 계획서

1. 기존 출하·수주 화면의 페이지 헤더, 입력 영역, 검색과 그리드 구조를 계획 화면과 비교하고 재발 방지 규칙을 기록한다.
2. 메뉴 보정 SQL을 작성한다. 독립 계획 부모 아래 기존 자식은 ID와 권한을 유지해 출하관리 아래로 이동하고, 없는 자식은 기존 메뉴 등록 패턴으로 추가한다. 독립 부모에 다른 참조가 있으면 삭제하지 않고 중단한다.
3. 출하계획등록의 상세와 수주 선택을 기존 출하등록 패턴의 F1-Grid로 교체하고 분할·삭제와 AUTO/MANUAL 저장 동작을 유지한다.
4. 출하계획현황의 검색 영역과 목록을 출하현황의 PageSearchArea와 F1-Grid 패턴으로 정렬하고 기존 상세 편집을 유지한다.
5. 회귀 테스트, 빌드, SQL 계약 검사와 실제 브라우저 반응형 검증을 수행하고 결과, 스크린샷 및 복사 가능한 커밋 제목·본문을 기록한다.
