# 출하계획 분할 버튼 정렬 계획

- 기준: 등록과 현황 수정이 공유하는 `DeliveryPlanForm`의 분할 셀.
- 버튼 그룹을 셀 너비 중앙으로 정렬하고 아이콘 삭제 버튼의 불필요한 최소 너비를 줄인다.
- 분할 시 최신 활성 행에서 대상 바로 뒤에 행을 삽입하고 새 행의 계획수량 셀에 편집 포커스를 준다.
- 서버가 기존 행 번호는 유지하고 신규 행 번호를 뒤에 부여하므로, 조회한 행은 수주 상세별로 묶어 표시한다. 각 그룹과 그룹 내부의 최초 조회 순서는 보존한다.
- 기존 분할·삭제 회귀 테스트와 실제 브라우저 375/768/1280px 검증을 수행한다.
