# 출하계획 F1Grid 편집 계획

**목표:** 출하계획 등록과 현황 수정에서 수주·출하 화면의 네이티브 F1Grid 셀 편집을 사용한다.

**방식:** 공통 `DeliveryPlanForm`의 계획일·수량 컬럼을 그리드 `date`·`decimal` 편집기로 변경하고 변경 행을 부모 상태에 반영한다. 분할·삭제와 문서 전환 시 그리드 상태를 동기화하며 저장은 최신 행을 사용한다.

**기준 화면:** `SalesDeliveryCreatePage`와 `DeliveryEditorDialog`의 기본정보 필드 간격, 상세 도구영역 여백, 기본 F1Grid 행 높이와 내부 스크롤 배치를 등록·자세히보기·수정에 적용한다.

상세 패널은 `SalesOrderStatusDetailPanel`과 `DeliveryStatusDetailPanel`을 기준으로 정렬한다. 상세 조회에서 작성자명·사진·등록일을 테넌트 범위로 조회하고, 목록 조회에는 사진을 포함하지 않는다. 기존 스키마만 사용한다.

**검증:** 관련 Vitest로 셀 더블클릭·Enter·저장, 실패 복원, 분할·삭제, 읽기 전용과 권한을 확인하고 빌드·lint를 수행한다. 375/768/1280px 실제 브라우저에서 등록·현황 편집을 확인한다.
