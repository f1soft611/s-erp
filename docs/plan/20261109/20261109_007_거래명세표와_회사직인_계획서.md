# 거래명세표와 회사 직인 구현 계획

**목표:** 첨부 양식과 같은 2부 출력 및 회사 직인 관리 제공.

**구조:** 회사정보 API에 검증된 직인 이미지를 저장하고 명세서 생성 시 별도 스냅샷으로 복사한다. 스냅샷이 없는 명세서는 같은 테넌트의 현재 직인을 사용한다. 출력은 품목을 페이지별로 나누고 각 페이지에 같은 두 부를 상하 배치한다.

**기술:** React, TypeScript, Spring Boot Java 8, MyBatis, PostgreSQL.

1. `CompanyInfoVO`, 서비스, 회사 매퍼, 명세서 매퍼에 직인 필드를 추가하고 형식·크기·스냅샷 회귀 테스트를 작성한다.
2. `docs/database/20261109`와 `backend/DATABASE/20261109`에 직인 컬럼 변경·롤백·이력을 동일하게 추가한다.
3. `CompanyInfoPage`에서 기본정보·연락처·직인을 구분하고 파일 선택·미리보기·삭제 및 기존 권한·저장 흐름을 유지한다. 저장 성공 시 공통 성공 토스트를 표시한다.
4. `StatementPrint`와 CSS를 첨부 양식에 맞추고 A4 한 장에 동일 2부, 여러 페이지, 인쇄·직인 테스트를 추가한다.
5. 집중 테스트, 빌드, Java 8 호환, 반응형 브라우저 및 PDF 검증 후 결과와 스크린샷을 기록한다.
