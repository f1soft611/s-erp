# 출하계획 상세와 공통 도움창 개선 계획서

1. 수주등록의 거래처 선택 입력란, 출하현황 번호 링크·상세 패널·상세 대화상자 및 공통 도움창의 기존 동작을 확인한다.
2. 품목·거래처 API가 반환하는 필드를 타입과 MCP 메타데이터로 확인해 신규 백엔드 계약 없이 사용할 수 있는 항목을 정한다.
3. 회귀 테스트를 먼저 작성한 뒤 두 출하 선택 입력란을 돋보기 아이콘으로 변경한다.
4. 계획번호 링크, 출하현황과 같은 상세 패널·메뉴·대화상자 흐름을 구현하며 계획 데이터와 수정 권한을 보존한다.
5. 공통 도움창의 선택값에 부가정보를 보존하고 결과 항목에 표시한다. 선택, 검색, 빈값 및 다른 도움창 동작은 유지한다.
6. 프론트 테스트·빌드·린트와 375/768/1280px 브라우저 검증 후 결과서와 스크린샷을 작성한다.
