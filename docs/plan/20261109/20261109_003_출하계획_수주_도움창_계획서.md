# 출하계획·수주 도움창 개선 계획

**목표:** 두 도움창의 검색 및 번호 표시를 통일하고 행 단위 선택을 적용한다.

**방식:** 출하등록 `SourceOrderPicker` 검색 UI를 기준으로 출하계획등록 검색 UI를 맞춘다. 번호 클릭 시 기존 수주 그룹 전체 선택 로직은 유지하고, 각 F1Grid의 `selectionMode`를 `row`로 지정한다. 등록의 기본정보와 상세 F1Grid를 공통 폼으로 추출해 현황 대화상자에서 동일하게 사용한다.

**검증:** 관련 Vitest에서 검색 UI·번호 선택·행 강조 및 그룹 선택 회귀, 동일 폼·분할·저장 실패 보존을 확인하고 빌드와 변경 파일 lint를 수행한다. 합성 데이터로 375/768/1280px 브라우저 검증 및 스크린샷을 남긴다.
