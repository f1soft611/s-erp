# 20260826_001 모듈별 메뉴 레이아웃 개선 계획

## 1. 목적

ERP 메인 화면에서 좌측 모듈 네비게이션과 하위 메뉴 영역을 분리하여, 사용자에게 모듈 구조와 업무 흐름을 더 명확하게 전달한다.

## 2. 구현 범위

- 좌측 모듈 네비게이션 유지
- 선택된 모듈의 하위 메뉴를 별도 영역으로 노출
- 메인 영역의 시각적 밀도 개선
- 선택 상태와 hover/focus 상태 구분
- 모듈 전환 시 하위 메뉴와 메인 콘텐츠 갱신

## 3. 화면 구성 계획

1. 메인 레이아웃을 세 영역으로 분리
   - 좌측: 모듈 목록
   - 중간: 선택된 모듈의 메뉴 그룹
   - 우측: 메인 콘텐츠
2. 기본 진입 시 첫 모듈을 자동 선택
3. 모듈 클릭 시 다음 상태 갱신
   - selectedModuleId
   - selectedMenuId
   - currentMenu/pageKey
4. 메인 콘텐츠는 카드/요약/리스트 형태로 구성

## 4. 데이터 구조

- moduleItems 배열로 모듈과 하위 메뉴 관리
- 메뉴별 pageKey를 통해 콘텐츠 템플릿 매핑
- 선택 상태를 React state로 관리

## 5. 검증 계획

- 로그인 후 대시보드 진입 확인
- 모듈 선택 시 하위 메뉴 갱신 확인
- 메뉴 선택 시 메인 영역 변화 확인
- 브라우저에서 실제 화면 검증
- 결과 문서와 스크린샷 작성

## 6. 완료 조건

- 좌측 모듈 네비게이션이 유지된다.
- 선택된 모듈의 세부 메뉴가 별도 영역으로 표시된다.
- 메인 영역이 업무형 카드와 목록 구조로 보인다.
- 실제 브라우저에서 흐름이 정상 동작한다.
