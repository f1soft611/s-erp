## 요구사항 분석 및 목적

- 공통 `SelectEditor`가 Select 옵션 값 이름을 전역 MUI 아이콘으로 변환해 모든 F1-Grid Select에 표시하고 있다.
- 목적은 아이콘 표시를 컬럼의 명시적 렌더러로 전환해 일반 Select의 레이블 전용 표시를 복구하고, 모듈관리의 아이콘명 선택 UX는 보존하는 것이다.
- 아이콘 종류는 공통 컴포넌트의 하드코딩이 아니라 F1-Grid 호출자가 결정한다.

## 작업 범위 분해

### 프론트엔드

1. `grid.types.ts`
   - `F1GridColumn<T>`에 선택적 `selectOptionIcon?: (option: F1GridOption) => ReactNode` 계약을 추가한다.
2. `CellEditor.tsx` 및 `SelectEditor.tsx`
   - 컬럼의 `selectOptionIcon`을 Select 에디터로 전달한다.
   - 전역 MUI 아이콘 import/map과 기본 `Settings` fallback을 제거한다.
   - 렌더러가 반환한 아이콘이 존재할 때만 선택값/목록 항목의 아이콘 영역을 표시한다.
3. `ModuleManagementPanel.tsx`
   - 모듈 아이콘명 옵션 목록과 동일한 이름의 아이콘 렌더러를 정의하고 `iconName` 컬럼에만 지정한다.
   - 정의되지 않은 아이콘 이름은 `undefined`를 반환해 레이블만 표시한다.
4. `tests/f1-grid.test.tsx`
   - 아이콘 렌더러가 없는 Select의 레이블 전용 출력과 렌더러가 제공한 아이콘의 출력을 각각 검증한다.
5. `F1-GRID.md`
   - `selectOptionIcon`의 타입, 기본 비활성 정책, 사용 예시 및 모듈관리 적용 원칙을 문서화한다.

### 백엔드 및 DB

- 해당 없음. API 요청/응답, 데이터 모델, 데이터베이스 스키마를 변경하지 않는다.
- DB 스크립트: 해당 없음. 기존 스키마 영향 검토 완료.

## 기존 코드 및 아키텍처 영향

- `F1GridColumn`은 공통 공개 타입이므로 새 속성은 선택적으로 추가해 기존 컬럼 정의의 하위 호환성을 보장한다.
- `SelectEditor`는 편집 모드에서만 렌더링되며, 표시 모드의 셀 값 렌더링이나 다른 에디터 타입에는 영향을 주지 않는다.
- 모듈관리만 MUI 아이콘 컴포넌트에 의존하고, 공통 에디터는 아이콘 라이브러리를 알지 않는다.
- `Select`의 값 변환, `onChange`, 크기 및 여백 스타일은 유지한다.

## 검증 계획

1. RED: 아이콘 렌더러가 없는 Select에 아이콘 컨테이너가 없고 레이블만 표시되는 테스트를 추가해 실패를 확인한다.
2. GREEN: 렌더러 전달 및 조건부 렌더링 구현 후 동일 Vitest 파일을 실행한다.
3. 아이콘 렌더러가 제공한 식별 가능한 테스트 아이콘이 선택값과 목록에 표시되는지 검증한다.
4. `npm run build`로 TypeScript 공개 타입과 모듈관리 아이콘 렌더러의 컴파일을 확인한다.
5. Playwright로 모듈관리 화면을 UI 클릭으로 이동해 1280px 및 375px 뷰포트의 Select 편집 상태를 캡처한다.
6. 결과 문서 및 작업 원장에 명령 결과, DB 영향 없음, 캡처 경로와 리뷰 결과를 기록한다.
