# 20260918_008 공지사항 구분코드 및 행위자 감사정보 상세 실행 계획

## 공통 제약

- 작업 위치는 현재 브랜치다.
- 승인된 사양 범위만 수정한다.
- DB SQL은 `backend/DATABASE/20260918`와 `docs/database/20260918`를 동기화한다.
- Java 8 호환 문법과 기존 eGovFrame/MyBatis 패턴을 유지한다.
- 요청 payload의 작성자 값을 인증 사용자보다 우선하지 않는다.
- 태스크 완료마다 관련 좁은 검증을 실행하고 원장에 결과를 기록한다.

## 태스크

### Task 1: 게시글 DB 및 공지 백엔드 계약

- 파일: `backend/src/main/java/egovframework/let/groupware/community/notice/domain/model/NoticeBoardPostSaveRequestVO.java`, `NoticeBoardPostVO.java`, `NoticeBoardService.java`, `NoticeBoardServiceImpl.java`, `NoticeBoardApiController.java`, `backend/src/main/resources/egovframework/mapper/let/groupware/community/notice/NoticeBoard_SQL_postgresql.xml`
- 작업: `noticeGubunCode`, `lastModifiedByName` 계약을 추가하고 목록 필터를 전달한다. Controller의 `LoginVO.id/name`을 등록·수정·삭제 서비스에 전달하며 payload 작성자 값은 무시한다. Mapper의 조회/등록/수정/삭제 SQL을 신규 컬럼에 맞춘다.
- 검증: 공지 서비스/컨트롤러 단위 테스트와 Mapper XML 로딩 또는 `mvn "-Dtest=NoticeBoardServiceImplTest" test`
- 인터페이스: Task 3 프론트는 확정된 JSON 필드와 목록 query를 사용한다.

### Task 2: 공통 댓글/답글 행위자 감사정보

- 파일: `backend/src/main/java/egovframework/com/common/domain/model/CommonCommentVO.java`, `CommonCommentApiController.java`, `CommonCommentService.java`, `CommonCommentServiceImpl.java`, `backend/src/main/resources/egovframework/mapper/com/common/CommonComment_SQL_postgresql.xml`
- 작업: 등록·수정·삭제에서 인증 사용자 ID/name을 사용하고 최신 행위자 컬럼을 갱신한다. 기존 작성자 ID 기반 수정·삭제 권한 조건과 답글 검증을 보존한다.
- 검증: `backend/src/test/java/egovframework/com/common/service/CommonCommentServiceTest.java` 및 관련 Controller 테스트를 좁게 실행
- 인터페이스: Task 3의 댓글 표시 타입에 최신 행위자 필드를 제공한다.

### Task 3: 프론트 공통코드 및 공지 화면

- 파일: `frontend/src/pages/groupware/community/notice/services/noticeBoardService.ts`, `frontend/src/pages/groupware/community/notice/CommunityNoticePage.tsx`, `frontend/src/pages/groupware/community/notice/components/NoticeFeedList.tsx`, 공지 작성 모달 관련 파일
- 작업: `NOTICE_GUBUN` 그룹/상세코드를 조회하고 목록 필터, 카드 표시, 작성·수정 모달의 제목 위 선택 필드를 연결한다. 저장 payload에서 작성자 ID/name 의존을 제거하고 `noticeGubunCode`를 전송한다.
- 검증: 관련 공지 Vitest 단일 파일 실행 후 `npm run build`
- 인터페이스: Task 1의 API 필드와 공통코드 서비스의 `itemCode/itemNm`을 사용한다.

### Task 4: 회귀 테스트 및 문서 동기화

- 파일: 관련 `frontend/tests/*notice*`, `backend/src/test/**/*Notice*`, `backend/src/test/**/*Comment*`, `frontend/src/pages/f1-grid-docs/F1-GRID.md`는 변경 대상 아님, `docs/result/20260918/notice-gubun-actor-audit/*`
- 작업: 구분 필터/초기값, payload 작성자 변조 무시, 공지·댓글 행위자 저장, 권한 제한 회귀 케이스를 추가한다. F1-Grid 문서는 변경하지 않는다.
- 검증: `cd frontend; npm run test; npm run build`, `cd backend; mvn test`, UI 변경 시 Playwright 375/768/1280 캡처
- 인터페이스: 모든 구현 태스크 완료 후 수행한다.
