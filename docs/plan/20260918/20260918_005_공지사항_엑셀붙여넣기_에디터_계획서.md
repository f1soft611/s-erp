## 요구사항 분석

- 공지사항 작성 모달은 Tiptap 기반 에디터를 사용하므로, 브라우저에서 발생하는 기본 붙여넣기 동작을 제어하는 `onPaste` 훅이 핵심 구현 지점이다.
- Excel/Google Sheets 복사 내용은 보통 HTML 테이블 형식으로 클립보드에 담기며, 이 경우 에디터가 단순 텍스트 조합으로 읽어버리면 셀 단위 정보가 손실된다.
- 정교한 구현은 표 데이터의 의미를 유지하면서, 안전한 HTML/문자열 정규화와 fallback 전략을 함께 적용해야 한다.
- 외부 HTML은 에디터가 허용하는 구조로만 정리해야 한다. 그렇지 않으면 불필요한 스타일, 빈 줄, 비정상 태그가 남아 실제 본문이 깨진다.

## 작업 범위 분해 (프론트엔드 전용)

1. **붙여넣기 입력 이벤트 처리**
   - `NoticeComposerDialog`에서 브라우저 `paste` 이벤트를 감지해 `clipboardData`를 읽는다.
   - Excel/표 형식의 HTML 우선 처리와 일반 텍스트 fallback 로직을 분리한다.
   - 붙여넣기 시 editor 내용이 비정상적으로 사라지지 않도록 안전한 삽입 지점을 유지한다.

2. **표 형식 정규화 로직**
   - 복사된 HTML에서 `<table>`, `<tr>`, `<td>`, `colspan/rowspan` 데이터 등 표 구조를 안전하게 추출한다.
   - 셀 값을 줄바꿈/공백 정리 후, 에디터가 허용되는 paragraph/table 구조로 변환한다.
   - 표라기보다 일반 텍스트인 경우 plain text fallback으로 처리한다.

3. **안전한 HTML 처리**
   - 외부 태그, inline style, 스크립트 관련 요소를 제거한다.
   - 본문이 비어 있거나 출력이 비정상적인 경우 사용자 입력을 유지하면서 안전한 fallback을 적용한다.
   - Tiptap의 ProseMirror 구조와 충돌하지 않도록 기본 노드만 유지한다.

4. **회귀 검증 추가**
   - 일반 텍스트 붙여넣기와 표형식 붙여넣기 동작을 각각 검증하는 테스트를 추가한다.
   - 저장 직전/직후의 HTML 직렬화 결과가 정상인지 확인한다.
