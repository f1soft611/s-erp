# MinIO 설정 정합화 Implementation Plan

> **For agentic workers:** 설정 계약을 테스트로 고정한 뒤 최소 변경으로 구현하고 검증한다.

**Goal:** 백엔드 전체 MinIO 기본 설정을 제공된 속성 계약으로 통일한다.

**Architecture:** Spring profile properties를 기본 설정의 단일 기준으로 유지하고, 프로필 없이 생성될 수 있는 `MinioStorageConfig`의 중첩 fallback도 같은 값으로 맞춘다. 회귀 테스트는 dev/prod의 7개 속성과 Java fallback을 검증한다.

**Tech Stack:** Java 8 호환 소스, Spring `@Value`, JUnit 5, Maven
