# F1-Grid 병합 경계선 및 필터 위치 보정 계획서

## 작업 근거

- 작업지시서: [20260909*004_f1grid*머지*경계선*필터*위치*보정\_작업지시서.md](../../directions/20260909/20260909_004_f1grid_머지_경계선_필터_위치_보정_작업지시서.md)

## 구현 범위

1. `GridCell.tsx`에서 병합 시작 셀의 하단 보더를 병합 span의 경계선으로 렌더링한다.
2. `GridHeader.tsx`에서 컬럼 메뉴를 여는 헤더 버튼을 필터 메뉴의 안정적인 앵커로 보관한다.
3. `f1-grid.test.tsx`에 보더 및 앵커 회귀 테스트를 먼저 추가한다.
4. F1-Grid 개발 문서와 결과 문서에 동작 및 검증 결과를 기록한다.

## 검증 계획

- `npx vitest run tests/f1-grid.test.tsx -t "row merge|column filter"`
- `npm run build`
- F1 Grid 테스트 페이지에서 병합된 품목명/품목분류 셀의 하단선과 필터 메뉴 위치를 실제 브라우저로 확인한다.

## 영향 범위

- `mergeRows`를 사용하는 모든 공용 F1-Grid 화면
- 헤더의 컬럼 메뉴에서 필터를 사용하는 모든 공용 F1-Grid 화면
