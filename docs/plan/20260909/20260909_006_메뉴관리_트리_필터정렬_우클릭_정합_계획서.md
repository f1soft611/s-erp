# 메뉴 관리 트리 필터/정렬 우클릭 정합 계획서

## 작업 근거

- 작업지시서: [20260909_006_메뉴관리_트리_필터정렬_우클릭_정합_작업지시서.md](../../directions/20260909/20260909_006_메뉴관리_트리_필터정렬_우클릭_정합_작업지시서.md)

## 구현 순서

1. 메뉴 관리 `F1Tree`에서 우클릭 메뉴의 필터/정렬 해제 항목이 현재는 제공되지 않음을 확인하는 회귀 테스트를 작성한다.
2. 해당 테스트를 실행하여 `F1Tree`의 강제 `disableFiltering`, `disableSorting` 설정 때문에 실패하는지 확인한다.
3. `F1Tree`가 호출자의 필터/정렬 정책을 그대로 공용 `F1Grid`에 전달하도록 최소 변경한다.
4. 테스트를 다시 실행하고, 메뉴 관리 트리에 필터·정렬을 적용한 뒤 각 우클릭 해제가 상태를 초기화하는지 검증한다.
5. F1-Grid 문서 및 결과 문서에 지원 범위와 검증 근거를 기록한다.

## 검증 계획

- `npx vitest run tests/menu-management-f1-grid.test.tsx -t "clears tree filters|clears tree sorting"`
- `npm run build`
- 메뉴 관리 화면에서 필터와 정렬을 각각 적용하고 우클릭 해제 동작을 브라우저로 확인한다.

## 영향 범위

- `F1Tree`를 사용하는 화면은 필터·정렬을 비활성화하지 않은 경우 공용 `F1Grid`와 동일한 우클릭 해제 항목을 제공한다.
- 현재 메뉴 관리 화면은 별도 비활성화 옵션을 전달하지 않으므로 필터·정렬을 사용할 수 있다.
