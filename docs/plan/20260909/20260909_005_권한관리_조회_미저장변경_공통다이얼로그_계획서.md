# 모듈관리·권한관리 조회 미저장 변경 공통 다이얼로그 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 모듈관리와 권한관리 조회가 미저장 그리드 변경을 버리기 전에 기존 공통 확인 다이얼로그로 사용자 확인을 받는다.

**Architecture:** 각 페이지가 이미 보유한 `panelDirty` 상태를 조회 가드의 단일 판단 기준으로 사용한다. 공통 `UnsavedChangesConfirmDialog`는 각 페이지에 렌더링하고, 확인 후에만 기존 목록 조회 함수를 호출해 해당 그리드 키를 갱신한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, React Testing Library

### Task 2: 페이지 조회 가드 구현

**Files:**
- Modify: `frontend/src/pages/settings/system/modules/ModuleManagementPage.tsx`
- Modify: `frontend/src/pages/settings/system/roles/RoleManagementPage.tsx`

- [ ] **Step 1: 공통 다이얼로그와 열림 상태를 추가한다.**

```tsx
const [refreshConfirmOpen, setRefreshConfirmOpen] = useState(false);
```

- [ ] **Step 2: 조회 요청 함수를 추가한다.**

```tsx
const requestRefresh = useCallback(() => {
  if (panelDirty) {
    setRefreshConfirmOpen(true);
    return;
  }
  void loadItems({ showSkeleton: true });
}, [loadRoles, panelDirty]);
```

- [ ] **Step 3: 조회 액션을 요청 함수로 교체하고 공통 다이얼로그를 렌더링한다.**

```tsx
<UnsavedChangesConfirmDialog
  open={refreshConfirmOpen}
  title="저장하지 않은 변경사항"
  description="변경사항을 버리고 대상 목록을 다시 불러오시겠습니까?"
  onCancel={() => setRefreshConfirmOpen(false)}
  onContinue={() => {
    setRefreshConfirmOpen(false);
    void loadItems({ showSkeleton: true });
  }}
/>
```
