## 구현 단위

1. 백엔드 `selectApprovalLines`: 현재 부서명 조인 + 복사본 대체(테스트 선행)
2. 프론트 공통 순수 함수: 참조자를 부서별로 묶고 정렬·요약하는 함수(단위 테스트)
3. 작성 화면 `DocumentReferenceField`: 칩 제한(`+N명`), 선택 목록 다이얼로그(검색·부서별·삭제), 겹침 제거
4. 문서 상세 참조 영역: 요약 줄 + 접힘/펼침 부서별 목록
5. 브라우저 검증과 결과 문서

## 접근

- 근본 원인은 두 가지다: 저장된 복사본 의존(데이터), 고정 높이·전체 펼침(화면). 복사본 이관 대신 조회 시 조인을 택한다. 과거 문서도 즉시 고쳐지고 DB 변경이 없다.
- 입력은 기존 `UserSelectEditor`를 유지하되 `limitTags` 계열 옵션을 추가해 접는다. 다른 사용처 동작은 기본값으로 보존한다.

## 검증 계획

- 백엔드: 부서 지정/미지정/복사본만 있는 경우 단위 테스트
- 프론트: 그룹 함수, 칩 접힘, 다이얼로그 삭제, 상세 접힘/펼침 테스트(100명 데이터)
- `npm run build`, 관련 vitest, `mvn test`(대상 테스트), 실제 브라우저 스크린샷
