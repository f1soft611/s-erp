# 그룹웨어 공통 소수점 정책 적용 계획서

- 작업지시서: [20261126_007](../../directions/20261126/20261126_007_그룹웨어_공통_소수점_정책_적용_작업지시서.md)

## 조사 결과

- `GRID_DECIMAL_GROUPWARE` 정책(DB MCP 확인): number 0자리(사용자가 2자리에서 변경), decimal 2자리, currency 2자리, 모두 HALF_UP·FIXED.
- 그룹웨어 그리드에 `type: number/decimal/currency` 컬럼과 직접 소수점 옵션은 없다. 숫자 값은 두 가지다.
  - 자료실 게시글 목록 첨부 수(`attachmentCount`): 정수 개수, `renderCell`로 직접 출력.
  - 파일 크기(자료실 파일 목록, 문서 첨부 목록): 바이트를 B/KB/MB로 환산해 `toFixed(1)`로 표시.
- 그룹웨어 서버는 소수점 규칙으로 계산·저장하는 값이 없다. 서버 변경은 없다.

## 구현 단위

1. 계약 JSON에 `groupware.archivePost`(`attachmentCount`, 수량 `number`)와 `groupware.file`(`fileSize`, `decimal`)을 화면 전용 문서로 추가하고 골든 파일을 갱신한다.
2. 첨부 수 컬럼이 `decimalColumnOptions`로 계약과 정책을 따르게 한다(`renderCell` 대신 `getValue`).
3. 파일 크기 환산 표시를 공통 함수로 모아 환산한 숫자에 정책 규칙을 적용하고 `toFixed(1)`을 제거한다.
4. 가드 테스트 대상에 그룹웨어 폴더를 등록하고 서버 가드의 화면 전용 문서 허용 목록에 추가한다.
5. 사양서·결과 문서를 작성한다.

## 범위 밖

- 컬럼 예외(필요 시 계약 JSON으로 추가), 서버 변경, 단가·금액(그룹웨어에 없음).
