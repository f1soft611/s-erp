# 공통 소수점 계약 가드레일 계획서

- 작업지시서: [20261126_001](../../directions/20261126/20261126_001_공통_소수점_계약_가드레일_작업지시서.md)

## 구현 단위 (한 단위씩 실패 테스트 → 구현 → 커밋)

1. **영업 현황 조사**: 영업 컬럼 정의의 직접 소수점 설정과 고정 자릿수 위치를 전수 확인한다. 결과를 표로 기록한다.
2. **JSON 우선 보장**: 예외 컬럼을 넣은 테스트 계약으로 각 영업 화면 표시가 JSON 값을 따르는지 실패 테스트를 만들고, JSON을 거치지 않는 곳(명세서 총 합계 등)을 고친다.
3. **고정 대체값 제거**: 정책 미로드 시 고정 `places: 2`를 쓰지 않고 로딩 상태를 표시한다.
4. **계약 가드 테스트**: 스키마 검증, 골든 파일, 필드 대조(프론트·서버).
5. **직접 설정 차단 테스트**: 가드 대상 폴더 소스 스캔.
6. **공통 정책 문서화**: 신규 모듈 적용 체크리스트를 프론트·백엔드 AGENTS와 F1-GRID 문서에 추가한다.

## 범위 밖

- 정책관리 화면/DB에서 컬럼별 설정을 하는 기능
- 영업 외 모듈의 실제 적용 (이번에는 적용 방법과 가드만 마련)
- 배포 상태 확인용 해시 노출 API
