# 거래명세서 헤더 합계 소수점 계약 적용 계획서

- 작업지시서: [20261126_004](../../directions/20261126/20261126_004_명세서_헤더합계_소수점_계약_적용_작업지시서.md)

## 구현 단위

1. DB MCP로 `tb_sales_statement_hd`·`tb_sales_delivery_dt`의 `total_amt`가 `numeric`임을 확인한다(확인 완료, 스키마 변경 없음).
2. 명세서 서비스 테스트: 헤더 합계가 정책 규칙으로 반올림되는 실패 테스트를 먼저 만든다.
3. `lockDeliveryDetails`가 `totalAmt`를 반환하게 하고, 서비스가 그룹별 합계에 `deliveryTotal` 규칙을 적용해 `insertHeader`에 `totalAmt`로 넘긴다. SQL은 서브쿼리 합산 대신 이 값을 쓴다.
4. 서비스가 `SystemPolicyService`로 정책을 읽도록 생성자를 확장하고 관련 테스트를 갱신한다.
5. 사양서·결과 문서를 갱신한다.
