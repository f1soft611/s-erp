# 앱 진입 레이싱 로딩 화면 계획서

- 작업지시서: [20261126_002](../../directions/20261126/20261126_002_앱_진입_레이싱_로딩화면_작업지시서.md)

## 구현 단위

1. **스플래시 해제 로직**: `shared/bootSplash.ts`의 `dismissBootSplash()`를 실패 테스트로 먼저 만든다. 아직 보이지 않으면 즉시 제거, 보이면 페이드아웃 후 제거한다.
2. **준비 신호**: `BootSplashReady` 컴포넌트를 `AppRouter`의 `Suspense` 안, `Routes` 뒤에 둔다. lazy 페이지가 해결되어 같은 경계가 커밋될 때만 effect가 실행되므로, 실제 화면이 준비된 시점에 해제된다.
3. **정적 스플래시**: `index.html`에 `#boot-splash` 마크업과 인라인 CSS를 넣고, 저장된 테마를 읽는 작은 인라인 스크립트를 둔다.
4. **안전 해제**: `main.tsx`에서 15초 후 강제 해제 타이머를 건다.
5. **검증**: 단위 테스트, 빌드, 실제 브라우저에서 375/768/1280px 스크린샷.

## 범위 밖

- 페이지 내부 데이터 로딩 표시(`AppLoadingSpinner`, `PageLoadingSkeleton`)는 변경하지 않는다.
- 로그인 이후 화면 전환 중 로딩 표시.
- 진행바는 실제 진행률이 아닌 연출용 애니메이션이다.
