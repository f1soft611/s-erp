# 매출마감 공통 소수점 정책 적용 계획서

- 작업지시서: [20261126_003](../../directions/20261126/20261126_003_매출마감_공통_소수점_정책_적용_작업지시서.md)

## 판단

- 매출마감 서버(`RevenueClosingServiceImpl`)는 금액을 계산·저장하지 않는다. 출하 상세의 `delivery_qty`, `supply_amt`, `vat_amt`, `total_amt`를 읽어 보여 주고, 마감 처리와 거래명세서 발행만 한다.
- 따라서 새 계약 문서를 만들지 않고, 같은 값을 계산·저장하는 출하 계약(`sales.delivery`)의 해당 필드 설정을 읽기 전용 화면이 따른다. 새 문서를 만들면 서버가 쓰지 않는 계약 필드가 생겨 서버 가드가 실패한다.
- DB 변경은 없다.

## 구현 단위

1. 매출마감 컬럼을 출하 계약 필드에 연결하는 실패 테스트를 만든다.
2. 컬럼 정의를 `createRevenueClosingColumns()`로 분리하고 `decimalColumnOptions`로 연결한다.
3. 가드 테스트의 `sales.delivery` 대상 폴더에 매출마감을 등록한다.
4. 사양서의 표시 전용 컬럼 표와 결과 문서를 갱신한다.
