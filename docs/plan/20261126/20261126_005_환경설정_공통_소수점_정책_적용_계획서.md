# 환경설정 공통 소수점 정책 적용 계획서

- 작업지시서: [20261126_005](../../directions/20261126/20261126_005_환경설정_공통_소수점_정책_적용_작업지시서.md)

## 원인

- F1-Grid의 일반 모드는 정책(0자리)을 값 정규화에만 적용하고 `.`·`,` 키 입력은 막지 않았다. 편집 중 원문을 보여 주므로 `1.5`가 입력창에 보이고, 확정 때 소수 부분을 버려 `1`이 된다(정책의 반올림이 아니라 버림).
- 키 입력 차단은 정확한 소수 모드(`exactDecimal`) 컬럼에만 있었다(영업이 사용).
- 메뉴 관리 정렬만 `decimalPlaces: 0`을 컬럼에 직접 쓰고 있다.

## 구현 단위

1. 계약 JSON에 `settings.module`(`sortOrder`, `menuCount`), `settings.menu`(`order`), `settings.role`(`menuCount`)을 `type: number`로 추가한다. 정책(환경설정 number 0자리)을 따르며 컬럼 예외는 두지 않는다. 골든 파일을 갱신한다.
2. 가드 테스트 대상에 환경설정 폴더를 등록한다. 서버가 쓰지 않는 화면 전용 문서는 서버 가드의 허용 목록으로 둔다.
3. F1-Grid 공통 변경: 0자리일 때 `.`·`,` 키 입력 차단을 `exactDecimal`과 무관하게 적용한다(`NumberEditor`). 값은 숫자 그대로이므로 저장 변환은 필요 없다.
4. 환경설정 컬럼이 `decimalColumnOptions`로 계약과 정책을 따르게 하고 `decimalPlaces`를 제거한다.
5. 입력 차단 테스트(F1-Grid 공통, 모듈 관리 화면)를 만든다.
6. F1-Grid 문서와 사양서·결과 문서를 갱신한다.

## 범위 밖

- 서버의 정렬 순서 검증 변경(서버는 정수로 저장·집계만 한다), 계정 관리(숫자 컬럼 없음), 붙여넣기·행 폼 입력의 차단(기존 정규화 유지).
