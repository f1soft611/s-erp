## 구현 단위

1. `frontend/AGENTS.md` 36행의 여백 값을 16px 기준으로 바꾸고 기준 코드와 확정일을 적는다.
2. 적용 범위(본문, embedded 0, `CommonDialog` 제외)를 같은 문단에 적는다.
3. 영업 수주등록 코드와 문서 값이 일치하는지 대조한다.

영향 범위는 문서 한 곳이며 코드·API·DB 변경은 없다.
