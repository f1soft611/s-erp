# 협업공간 피드 공통 컴포넌트 적용 계획서

- 작성일: 2026-11-26
- 작업지시서: [20261126_009](../../directions/20261126/20261126_009_협업공간_피드_공통컴포넌트_적용_작업지시서.md)

## 구현 단위

1. 데이터: 타입(서식 본문·첨부 데이터·서식 댓글), 샘플, 서비스(댓글 수정·삭제·첨부, 빈 본문 판정) — 단위 테스트
2. 화면용 변환: 본문 HTML 정리(옛 일반 텍스트 호환), 본문 이미지 추출, 접힘/펼침 HTML, 댓글을 `FeedCommentItem`으로 변환, 첨부 미리보기 URL — 단위 테스트
3. 피드 카드: `WorkspaceFeedPost`(공통 컴포넌트 조합)와 `FeedList`, 카드 상세 다이얼로그
4. 글 작성창: `RichTextEditor` + `AttachmentList` 편집 모드
5. 페이지 연결: 댓글 수정·삭제·내려받기 핸들러, 권한 반영
6. 기존 자체 댓글·피드 카드 제거와 테스트 갱신
7. 브라우저 검증, 결과 문서

## 접근

- 문서작성 피드(`DocumentApprovalDetailFeed`)의 조합 순서를 그대로 따른다: FeedCard → FeedBodyContent → AttachmentList → Divider → FeedReactionBar → FeedCommentsSection(CommentThread).
- 파일은 백엔드가 없으므로 1MB 이하만 data URL로 저장해 미리보기·내려받기를 지원하고, 그보다 크면 파일명·크기만 저장한다.

## 검증 계획

- 단위: 서비스(댓글 수정·삭제 권한, 빈 본문), 변환 함수
- 화면: 피드 카드 구성, 더보기, 첨부 아이콘·이미지 미리보기, 공통 댓글 동작, 권한별 입력 가능 여부
- `tsc -b`, 협업공간 테스트, 실제 브라우저 375/768/1280px
