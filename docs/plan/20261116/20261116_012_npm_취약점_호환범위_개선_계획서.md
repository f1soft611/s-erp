# npm 취약점 호환 범위 개선 계획

**목표:** 주요 버전 변경 없이 수정 가능한 프론트엔드 npm 취약점을 줄인다.

**범위:** `frontend/package.json`, `frontend/package-lock.json` 및 이번 날짜별 문서. 공유 서버의 `node_modules`는 변경하지 않는다.

1. 기존 audit과 엑셀·대시보드 관련 테스트를 실행해 기준선을 기록한다.
2. `vite`를 `^8.3.8`, `vitest`를 `^4.1.12`로 지정하고 npm의 잠금 파일 전용 갱신으로 호환 가능한 `brace-expansion`, `source-map-js`, `undici`를 업데이트한다.
3. 저장소 스냅샷을 별도 임시 디렉터리에 복사하고 변경된 잠금 파일로 `npm ci`를 실행한다.
4. 격리된 설치에서 audit, 빌드, lint와 엑셀·대시보드 테스트를 실행한다. 기존 전체 테스트 실패 여부는 별도로 표시한다.
5. 잔여 취약점과 검증 한계를 결과 문서에 기록한다. ExcelJS 대체 및 주요 버전 변경은 하지 않는다.
