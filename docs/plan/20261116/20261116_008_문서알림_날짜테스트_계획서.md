# 문서 알림 날짜 테스트 계획

- 근거: [날짜 표시 작업지시서](../../directions/20261016/20261016_014_문서작성_날짜표시_우선순위_작업지시서.md), [상세 사양](../../spec/20261016/20261016_014_문서작성_날짜표시_우선순위_상세사양서.md).
- 기존 알림 카드 테스트의 날짜 픽스처를 공통 날짜 선택 결과와 원천 라벨 계약에 맞춘다.
- 상신일·수정일·작성일과 날짜 부재를 확인하고 기존 클릭·상태·레이아웃 검사를 유지한다.
- 관련 컴포넌트·날짜 선택·훅 테스트와 lint 및 빌드를 수행하고 결과를 기록한다.
