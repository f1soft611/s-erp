# 공개 로그 추적 중단 구현 계획

작업지시서: [20261116_001](../../directions/20261116/20261116_001_log-tracking_작업지시서.md)

**목표:** 로컬 로그를 보존하면서 Git 추적 및 신규 추가를 방지한다.

**방식:** 루트 무시 규칙을 추가하고 대상 경로만 인덱스에서 제거한다. 공유 이력은 유지한다.

## 구현 및 검증

1. 대상 경로의 추적 파일 목록과 각 파일의 SHA-256을 확인한다.
2. `.gitignore`에 `backend/logs/`를 추가하고 기존 개별 로그 규칙을 제거한다.
3. `git rm -r --cached -- backend/logs`로 대상만 추적 해제한다.
4. `git ls-files -- backend/logs`가 빈 결과인지 확인하고 `git check-ignore`로 기존·새 로그 경로를 확인한다.
5. 동일 파일의 SHA-256을 다시 비교하고 결과 문서에 실제 검증과 잔여 공개 이력 위험을 기록한다.
6. 커밋과 푸시는 하지 않는다.
