# F1Grid 저장키 누락 보완 계획

- 근거: [기존 작업지시서](../../directions/20261001/20261001_006_F1Grid_저장키_누락_보완_작업지시서.md), [기존 사양서](../../spec/20261001/20261001_006_F1Grid_저장키_누락_보완_사양서.md).
- 누락된 10개 호출부에 안정적인 키를 부여하고 기존 키는 변경하지 않는다.
- 분류 종류·선택 수준과 결재/참조 모드를 구분하고 공유 출하계획 폼은 등록과 현황 상세에서 서로 다른 키를 전달한다.
- 키 누락 검사 및 공유 화면의 저장 분리 회귀 테스트, 관련 화면 테스트, lint와 빌드를 수행한다.
- F1Grid 문서와 결과 문서에 동작 및 검증 범위를 기록한다.
