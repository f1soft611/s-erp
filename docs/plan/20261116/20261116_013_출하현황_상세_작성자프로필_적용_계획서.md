# 출하현황 상세 작성자 프로필 적용 계획서

- 근거: [작업지시서](../../directions/20261116/20261116_013_출하현황_상세_작성자프로필_적용_작업지시서.md), [거래명세서 상세 사양](../../spec/20261109/20261109_006_회사정보와_거래명세서_상세사양서.md).
- 기존 출하번호 클릭 흐름, 상세 조회 API 응답, `DeliveryStatusDetailPanel`의 작성자 영역을 추적한다. 기준 화면은 거래명세서 및 수주현황 상세의 `ProfileAvatar` 사용 방식으로 한다.
- 회귀 테스트에서 상세 조회 SQL의 사용자·프로필 조인과 API JSON 필드, 상세 패널의 작성자 표시를 확인한다.
- 기존 테넌트 범위 로그인 계정·사용자 조인을 적용하고 `createdByName`, `createdByProfileImage`, `createdAt` 응답을 화면에 연결한다. 프로필이 없으면 기존 fallback을 유지한다.
- 백엔드 매퍼/API 및 프론트엔드 상세 화면 테스트와 빌드를 수행한다. DB 변경은 하지 않는다.
- 결과 문서에 원인, 변경 범위, MCP 메타데이터 확인, 검증 결과 및 375px·768px·1280px 화면을 기록한다.
