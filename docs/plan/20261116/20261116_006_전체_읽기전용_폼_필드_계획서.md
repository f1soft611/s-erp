# 전체 읽기전용 폼 필드 Implementation Plan

**Goal:** 모든 화면의 읽기전용 폼 입력과 F1-Grid 행 폼을 동일한 테마 배경으로 구분한다.

**Architecture:** `frontend/src/theme/theme.ts`에서 MUI 입력의 읽기전용 및 비활성 배경을 정의한다. 선택으로 값을 바꿀 수 있는 코드·마스터 선택기는 실제 선택 가능 여부를 반영한다. F1-Grid 폼의 판정 및 기존 수주등록 배경과 호환한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Playwright.

1. `frontend/tests/readonly-form-fields.test.tsx`에 밝은·다크 테마, 일반 입력, 마스터 선택기 및 F1-Grid 폼의 실제 편집 가능 여부를 검증하는 테스트를 추가한다.
2. `cd frontend; npm run test -- tests/readonly-form-fields.test.tsx`로 기존 구현이 배경색 검증에서 실패하는지 확인한다.
3. `frontend/src/theme/theme.ts`와 `frontend/src/shared/components/master-picker/MasterPicker.tsx`에 최소한의 공통 스타일을 적용하고 필요한 F1-Grid 폼 예외를 처리한다.
4. `frontend/src/pages/f1-grid-docs/F1-GRID.md`에 행 폼의 읽기전용 표시 기준을 갱신한다.
5. 집중 테스트, `npm run build`, `npm run lint`와 기존 4173 서버를 사용하는 픽스처 기반 브라우저 확인을 실시하고 날짜별 결과 문서 및 스크린샷을 작성한다.
