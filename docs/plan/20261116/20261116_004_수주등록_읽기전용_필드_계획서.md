# 수주등록 읽기전용 필드 Implementation Plan

**Goal:** 수주 기본정보에서 변경할 수 없는 필드를 배경색으로 구분한다.

**Architecture:** 등록과 현황 상세가 공유하는 `SalesOrderCreatePage`의 기본정보 폼에만 스타일을 적용한다. 직접 입력은 읽기전용이지만 선택 가능한 거래처는 `isEditable` 기준으로 별도 판정한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Playwright.

## 작업

- [ ] `frontend/tests/sales-order-create-page.test.tsx`에 편집 가능 및 권한 없는 상태에서 각 입력의 실제 배경색과 거래처 선택 가능 여부를 확인하는 테스트를 추가한다.
- [ ] `cd frontend; npm run test -- tests/sales-order-create-page.test.tsx -t "읽기전용 배경"`을 실행해 기존 구현이 배경색 검증에서 실패하는지 확인한다.
- [ ] `frontend/src/pages/sales/order/create/SalesOrderCreatePage.tsx`의 기본정보 폼에 MUI `action.disabledBackground`를 사용해 항상 읽기전용 필드와 비활성 입력, 편집 불가능한 거래처에 적용한다. 거래처 선택 가능 상태에서는 적용하지 않는다.
- [ ] `cd frontend; npm run test -- tests/sales-order-create-page.test.tsx` 및 `npm run build`, `npm run lint`를 실행한다.
- [ ] 기존 서버 여부를 확인하고 포트 4173에서 등록·현황 공유 폼과 375px, 768px, 1280px 렌더링을 확인해 `docs/result/20261116/sales-order-readonly-fields/`에 결과 및 스크린샷을 보관한다. 직접 시작한 서버는 종료한다.
