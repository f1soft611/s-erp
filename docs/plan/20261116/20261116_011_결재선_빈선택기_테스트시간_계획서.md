# 결재선 빈 선택기 테스트 시간 계획

- 근거: `docs/directions/20261007/20261007_002_문서작성_결재선_입력필드_공간개선_작업지시서.md`의 빈 후보 안내 문구 제거 요구사항.
- 빈 결재선 후보 테스트의 기본 시간 제한 실패를 재현하고 더 긴 제한에서 기존 검증의 결과를 확인한다.
- 다수의 사용자 선택을 수행하는 해당 테스트에만 인접 테스트와 같은 15초 제한을 지정한다. 운영 동작과 테스트의 검증 내용은 변경하지 않는다.
- 해당 테스트와 인접 결재선 테스트, lint 및 빌드를 확인하고 결과를 기록한다.
