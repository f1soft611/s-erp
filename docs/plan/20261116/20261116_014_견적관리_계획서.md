# 견적관리 화면 추가 Implementation Plan

> **For agentic workers:** Follow this plan task by task. Keep the existing sales-order behavior compatible and verify each backend and frontend contract with focused tests.

**Goal:** Add quotation registration and status screens, support master-selected or manually entered quotation lines, and let sales orders optionally record a quotation number.

**Architecture:** Add tenant-scoped quotation header/detail storage and CRUD/search APIs following the sales-order layers. Build registration and status pages in the existing sales page registry, reuse the customer/material pickers and F1-Grid, and retain the existing optional `quotNo` field as the sales-order reference. Directly entered quotation item data is stored as a line snapshot; it never creates or updates a material master.

**Tech Stack:** React, TypeScript, MUI, F1-Grid, Spring Boot/eGovFrame, Java 8, MyBatis, PostgreSQL, Vitest, JUnit 5.
