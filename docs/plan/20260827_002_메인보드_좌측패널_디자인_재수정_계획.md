# 20260827*002*메인보드*좌측패널*디자인*재수정*계획

## 1. 작업 배경

사용자가 제공한 캡처 이미지를 기준으로 메인보드 좌측 패널을 ERP형 구조로 재설계한다. 기존 구조는 모듈 선택 영역과 메뉴 계층이 혼재되어 있어 시각적 계층과 사용성 측면에서 개선 여지가 있다.

## 2. 목표

- 좌측 패널을 모듈 영역과 메뉴 트리 영역으로 분리한다.
- 상단 고정 모듈 리스트와 하단 상세 메뉴를 구분해 ERP형 구조를 확보한다.
- 선택 상태와 hover 상태를 명확히 표현한다.
- 기존 React 대시보드 구조를 유지하면서 시각적인 UX를 캡처 기준에 맞춘다.

## 3. 구현 단위

1. 좌측 패널 레이아웃 분리
   - 좌측 아이콘 모듈 영역
   - 상세 메뉴 영역
   - 사용자 정보 영역
2. 모듈/메뉴 상태 관리 유지
   - selectedModuleId
   - selectedParentId
   - selectedMenuId
3. 스타일 정리
   - 배경색, border, spacing, font weight
   - active/hover/selected contrast 개선
4. 검증
   - 단일 테스트 실행
   - 브라우저 레이아웃 확인

## 4. 검증 기준

- ERP SYSTEM 문구와 좌측 모듈 구조가 보인다.
- 선택된 모듈과 메뉴가 시각적으로 구분된다.
- Sales 항목이 노출되지 않는다.
- 실제 브라우저에서 레이아웃이 의도대로 보인다.

## 5. 리스크

- Windows PowerShell에서 Vitest EMFILE 오류가 발생할 수 있으므로 Git Bash/WSL2로 검증한다.
- 하드코딩된 스타일 값이 기존 디자인과 충돌할 수 있어 범위를 기존 대시보드 레이아웃으로 한정한다.
