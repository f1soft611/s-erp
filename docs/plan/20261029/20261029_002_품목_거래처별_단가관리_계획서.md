> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add tenant-safe item/partner pricing maintenance with row-form editing and a validated Excel import preview, backed by an unapplied S-ERP-compatible PostgreSQL DDL draft.

**Architecture:** Add one price domain with tenant-scoped list, import-preflight, and transactional batch-save endpoints. The frontend follows existing co/master page patterns, stages only preflight-valid spreadsheet rows as new F1-Grid rows, and uses the existing page-level save flow for both manual and imported changes. The matching dated DB scripts remain documentation only and are never executed.

**Tech Stack:** React, TypeScript, Vite, MUI, F1-Grid, ExcelJS, Spring Boot/eGovFrame, MyBatis, PostgreSQL, Vitest, Maven.
