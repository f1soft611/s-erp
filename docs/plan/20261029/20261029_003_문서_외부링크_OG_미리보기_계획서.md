# 문서 외부 링크 OG 미리보기 계획서

## 목표

문서 본문·댓글의 외부 웹 URL에 Open Graph 미리보기를 제공하되, 기존 암호화된 시스템 문서 공유 링크와 카드/동작/API를 분리해 둘 다 정상 지원한다.

## 설계 요약

- 내부 문서 링크는 기존 토큰 해석, 접근권한 검사, 상세 패널 동작을 그대로 유지한다.
- 외부 URL은 인증된 `POST /api/v1/groupware/approvals/link-preview`에서 메타데이터만 조회한다. 본문에 응답 메타데이터를 저장하지 않으며 DB를 변경하지 않는다.
- 백엔드는 HTTP(S)와 기본 포트만 허용하고, DNS/IP 공인 주소 확인 및 연결 DNS 고정, 리다이렉트 재검증, 응답 크기/시간 제한을 적용한다.
- 프론트엔드는 내부 `문서` 카드와 외부 `웹 링크` OG 카드를 시각적으로 구분한다. 외부 클릭은 원문을 새 탭에서 열고 내부 상세 패널로 연결하지 않는다.
- 오류 시 원문 링크와 문서 저장/댓글 작성은 계속 사용할 수 있도록 미리보기만 일반 오류 상태로 처리한다.

## 구현 순서

1. [상세 실행 계획](../superpowers/plans/2026-10-29-document-url-og-preview.md) 기준으로 백엔드 검증 테스트를 먼저 작성한다.
2. 인증된 외부 링크 미리보기 API, URL 안전성 검증, DNS 고정 fetch, OG 파싱 및 응답 제한을 구현한다.
3. 링크 분류와 미리보기 API 클라이언트를 추가하고, 기존 미리보기 컴포넌트에 외부 웹 카드만 별도로 연결한다.
4. 내부 링크 호환성을 포함한 frontend/backend 테스트, 빌드, 린트, 브라우저 375/768/1280px 검증을 수행한다.
5. 결과 보고서와 반응형 스크린샷을 `docs/result/20261029/document-external-link-og`에 기록한다.

## 검증 및 데이터베이스

- 내부/외부 링크 분류, 중복 URL, 편집 후 오래된 응답, 인증 실패, SSRF 방어, 리다이렉트 및 응답 한계, OG 필드 파싱을 테스트한다.
- MCP `list_tables`를 확인했으며 새 DB 오브젝트나 기존 데이터 계약 변경은 없으므로 추가 DB 조회/변경은 불필요하다.
