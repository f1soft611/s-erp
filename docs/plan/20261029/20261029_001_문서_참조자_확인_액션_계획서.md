# 문서 참조자 확인 액션 계획서

## 목표

기안서·업무연락 참조자가 상세에서 확인을 수행하고, 미확인 문서를 종합현황과 문서작성 결재요약에서 결재와 별도로 확인할 수 있게 한다.

## 구현 범위

- 참조자별 `CONFIRMED` 상태를 저장하고 기존 공통 SYSTEM 이력 경로에 `REFERENCE_CONFIRMED` 이벤트를 원자적으로 추가한다.
- 참조자 권한과 문서 상태를 확인하는 확인 API를 추가하고 반복 요청은 성공 상태를 보존한다.
- 미확인 참조 문서의 조회 범위와 결재요약 응답을 추가한다.
- 종합현황과 문서작성 결재요약에 각각 독립된 대기 건수/목록을 표시하고 확인 완료 후 갱신한다.
- MCP 메타데이터에서 참조 action 필드 및 SYSTEM 이벤트 제약이 현재 확인 동작을 거부함을 확인했다. `20261029_001` 날짜별 migration/롤백을 양쪽 schema 경로에 추가하고 `db-schema.md`를 동기화한다. migration은 코드 작업 중 실제 DB에 적용하지 않는다.

## 검증

- 백엔드: 확인 서비스/컨트롤러/매퍼 테스트 및 관련 기존 전자결재 테스트
- 프론트엔드: `document-approval-service`, `document-write-page`, `overview-page`, `dashboard-overview-service` 관련 테스트와 `npm run build`
- 브라우저: 실제 `127.0.0.1:4173`에서 375px, 768px, 1280px 확인
- 결과: `docs/result/20261029/document-reference-confirmation/`에 결과 문서 및 스크린샷

구체 파일, 실패 테스트, 단계별 구현 및 실행 명령은 상세 구현 계획을 따른다.
