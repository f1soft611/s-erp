# 이전 댓글 상태 유지 및 카운트 계획서

## 구현 범위

- 공통 이전 댓글 버튼에 남은 댓글 수를 표현한다.
- 공지사항과 전자결재의 댓글 등록 이후 로드된 댓글/커서 유지 여부를 회귀 테스트로 고정한다.
- 전자결재의 댓글 등록을 로컬 전체 목록 업데이트 방식으로 바꿔 이전 페이지가 초기화되지 않게 한다.
- 결과 문서와 반응형 브라우저 캡처를 추가한다.

## 실행 순서

### 1. 공통 이전 댓글 카운트 표시

1. `FeedCommentsSection` 테스트에 카운트가 있을 때 `이전 댓글 보기 (N)` 레이블과 접근 가능한 이름이 표시되는 검증을 추가한다.
2. 카운트가 전달되지 않은 경우 기존 `이전 댓글 보기` 레이블을 유지하는 테스트를 추가/보존한다.
3. 테스트를 실행해 신규 카운트 테스트의 초기 실패를 확인한다.
4. `remainingPreviousCount?: number` prop을 추가하고 `null`/`undefined`일 때 숫자를 생략하여 공통 버튼을 구현한다.
5. 공통 피드 테스트를 재실행한다.

### 2. 공지사항 상태 유지와 카운트

1. 공지사항 통합 테스트에 이전 페이지를 로드한 뒤 새 댓글 및 답글을 등록하고 기존 댓글이 유지되는 시나리오를 추가한다.
2. 기존 `NoticeFeedList`의 로컬 댓글 병합 및 `loadedPreviousByNoticeId` 유지 동작을 테스트로 검증한다.
3. 남은 수를 `max(0, item.commentCount - countComments(itemComments))`로 계산하고 `FeedCommentsSection`에 전달한다. 계산 근거가 불충분하면 숫자를 전달하지 않는다.
4. 공지사항 관련 선택 테스트를 재실행한다.

### 3. 전자결재 목록 지속성

1. 전자결재 테스트에서 최신 댓글 3개와 이전 댓글 페이지를 준비하고, 이전 페이지를 불러온 뒤 새 댓글 등록 시나리오를 작성한다.
2. 댓글 등록 후 새 댓글/답글이 로드된 전체 댓글 목록에 나타나고 과거 댓글이 유지되며 첫 페이지 재조회가 일어나지 않는다는 실패를 확인한다.
3. 성공한 `createApprovalComment` 응답을 `commentRecords`에 추가하고 `commentCount`를 증가시킨다. 기존 `nextBeforeCommentId`와 `hasPreviousComments`는 건드리지 않는다.
4. 첨부 업로드 결과를 새 댓글 레코드에 포함하여 기존 등록 후 첨부 표시 동작을 유지한다. 저장/업로드 오류 알림은 유지하고, 서버에 이미 생성된 댓글이 있으면 기존 로드 목록을 보존한 채 반영한다.
5. 수정/삭제 후 목록 재조회가 이전 댓글 전체를 지우지 않는지 확인한다. 필요한 경우 변경된 댓글만 기존 기록에서 교체하거나 제거하는 방식으로 처리하고 페이지 커서는 유지한다.
6. 남은 수를 사용자 댓글 총수에서 `commentRecords.length`를 뺀 0 이상 값으로 전달한다. 시스템 이벤트는 이 계산에서 제외한다.
7. 전자결재의 이전 댓글 및 CRUD 선택 테스트를 실행한다.

### 4. 통합 검증 및 결과 기록

1. `npx vitest run tests/feed-components.test.tsx tests/notice-page-local-updates.test.tsx tests/notice-page.test.tsx tests/document-write-page.test.tsx`를 실행한다.
2. `npm run build`와 `git diff --check`를 실행한다.
3. 공유 브라우저에서 공지사항과 전자결재 상세를 열어 375px, 768px, 1280px에서 댓글 영역 및 버튼 카운트를 확인한다.
4. 텍스트/개인정보를 노출하지 않는 캡처를 `docs/result/20261013/previous-comments-persistence/screenshots`에 저장한다.
5. 검증 결과, 실패한 기존 기준선(있는 경우), 제한 사항을 결과 문서에 기록한다.

## 미변경 보장

- API 요청/응답 형식, 댓글 정렬, 페이지 크기 및 사용자 권한을 변경하지 않는다.
- 새 댓글 등록으로 이미 펼친 댓글 페이지를 접거나 초기화하지 않는다.
- 전체 댓글 수를 알 수 없으면 잘못된 숫자 대신 숫자 없는 기존 버튼 문구를 표시한다.
