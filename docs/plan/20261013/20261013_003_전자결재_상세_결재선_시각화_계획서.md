# 20261013_003 전자결재 상세 결재선 시각화 계획서

> **실행 안내:** 이 작업은 현재 세션에서 단계별로 구현하고 각 단계의 테스트 결과를 확인한다.

**목표:** 사용자가 공유한 참조 이미지처럼 상세 결재선을 하나의 컴팩트한 읽기 전용 패널로 개선한다.

**구성:** 전자결재 상세의 현재 데이터 정렬과 결재선 슬롯을 유지한다. 패널 헤더에 결재선과 기안 메타 정보를 함께 표시하고, 승인 상태를 원형 도장으로 표현하며 화살표로 승인 순서를 연결한다. 합의·참조는 패널 내부 구분선 아래 칩으로 표현하고 문서 액션/API/DB 계약은 그대로 둔다.

**기술:** React, TypeScript, MUI `sx`, Vitest, React Testing Library.

---

## 작업 3 — 결재선 표현 구현

- [ ] 상세 카드의 별도 작성자 아바타 줄을 제거하고 현재 더보기/핀/문서 상태 동작을 새 결재선 패널 헤더 오른쪽에 조립한다. 헤더 왼쪽에는 `결재선`과 `기안자 이름 · 작성일`을 한 줄로 배치한다.
- [ ] 승인 상태를 기존 슬롯 가운데의 원형 도장으로 표현하고 테마 상태색을 지정한다: `WAITING` 중립, `PENDING` primary, `APPROVED` success, `REJECTED` error, `RETURNED` warning.
- [ ] `PENDING` 도장/카드만 현재 단계로 강조하고 접근 가능한 텍스트 상태 라벨을 유지한다.
- [ ] 정렬된 승인 카드 사이에 화살표를 렌더링한다. 결재 카드 흐름은 내부 overflow 영역으로 한정하고 화면 전체에 가로 넘침이 없게 한다.
- [ ] 승인/합의/참조를 같은 옅은 배경 패널 안에 배치하고 승인 그룹과 하단 합의/참조 칩 사이에 내부 구분선을 둔다.
- [ ] 합의/참조 chip은 부서가 있으면 `합의 · {부서} {이름}`, `참조 · {부서} {이름}` 형식으로 표시하고 결재선 전체의 기존 외부 구분선, 읽기 전용 동작 및 실제 참여자만 렌더링하는 정책을 유지한다.
- [ ] 동일 집중 테스트를 다시 실행해 통과를 확인한다.
