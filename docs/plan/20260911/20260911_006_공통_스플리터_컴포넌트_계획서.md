## 2. 요구사항 분석 및 목적

공통코드 관리 페이지는 좌측 트리와 우측 그리드가 동일한 높이를 유지하면서 분할되어 표시된다. 현재는 고정 비율 레이아웃으로 구성되어 있어 사용자가 직접 좌우 폭을 조절할 수 없다.

이번 작업은 재사용 가능한 `Splitter` 공통 컴포넌트를 추가하여, 좌우 또는 상하 방향 모두에서 드래그 기반 분할을 지원하게 하는 것이 목적이다.

## 3. 작업 범위

### 3.1 공통 컴포넌트

- `frontend/src/shared/components/Splitter.tsx` 신규 생성
- 방향 지원: `horizontal` / `vertical`
- 드래그 기반 크기 조절
- 초기 크기, 최소/최대 크기, 접근성 라벨 지원
- 사용자 조작 상태와 크기 상태를 내부적으로 관리

### 3.2 공통코드 화면 적용

- `frontend/src/pages/co/master/common-code/components/CommonCodeManagementPanel.tsx`
- 좌측 트리와 우측 그리드 사이에 `Splitter`를 적용
- 기존 트리/그리드 동작 및 선택 로직 유지
- 기존 검색/저장/엑셀 동작과 충돌하지 않도록 레이아웃만 리사이즈

## 4. 기존 코드 영향 범위

- 공통코드 관리 페이지 레이아웃 구조 변경
- 공용 컴포넌트 추가로 다른 화면에서도 재사용 가능
- 다른 페이지는 본 작업 범위에서 직접 수정하지 않음
