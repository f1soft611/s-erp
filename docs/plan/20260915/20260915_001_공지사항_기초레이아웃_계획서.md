공지사항은 `GROUPWARE` 모듈 아래 `커뮤니티` 중메뉴의 첫 기능으로 구현한다. 사용자 관점에서는 기본 목록 화면이 중요하며, 상세 내용은 선택 시 확인 가능한 구조로 설계한다. 이 단계에서는 관리자 기능이나 백엔드 연결을 제외하고, 화면 레이아웃과 데이터 표현을 우선 검증한다.
