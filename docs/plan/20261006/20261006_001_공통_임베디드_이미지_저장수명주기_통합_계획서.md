# 공통 임베디드 이미지 저장 수명주기 통합 계획서

> **For agentic workers:** 작업별 체크리스트를 따라 진행하고 요청되지 않은 commit은 만들지 않는다.

**목표:** 공지사항과 기안양식 본문 이미지를 공통 임시 업로드/영구 승격/소유권/정리 서비스로 처리한다.

**구조:** 공통 backend service가 MIME/signature/size validation, tagged temp upload, temporary deletion, permanent copy, `tb_common_file` insert, rollback compensation을 소유한다. Notice와 Draft 도메인 adapter는 각자 authorization, owner identity, stable URL rewrite를 소유한다. Frontend는 공통 editor adapter를 유지하며 upload/save/close progress 계약만 두 dialog에서 동일하게 연결한다.

**기술:** Java 8 source-compatible Spring/eGovFrame, MyBatis, MinIO, PostgreSQL `tb_common_file`, React/TypeScript/Tiptap, Vitest.
