# 문서작성 기안서 탭 필드 재정의 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기안서 작성 모달에 현재 기안양식과 사용자 목록을 연동하고, 38px 메타 필드와 순차 결재/단일 합의 단계/참조 UX를 제공한다.

**Architecture:** 기존 기안양식관리 조회 서비스, 현재 사용자 프로필 서비스, F1-Grid `UserSelectEditor`, 공용 `CommonDialog`와 `RichTextEditor`를 재사용한다. 조회/편집 상태는 `useDocumentComposer`에서 관리하고, 선택된 사용자와 단계는 작은 `DocumentApprovalFields` 컴포넌트에서 표시한다. 저장과 실제 결재 처리는 계속 범위 밖이다.

**Tech Stack:** React 19, TypeScript, MUI, Tiptap, Vitest, Testing Library, Vite

```ts
const availableForms = forms.filter(
```

- [x] **Step 1: 승인/합의 단계 추가 함수를 테스트로 고정**

선택된 ID를 `F1GridUserOption.value`와 문자열 비교하여 옵션으로 정규화한다. `결재 추가`는 길이 1만, `합의 추가`는 길이 1 이상만 단계로 만든다. 단계는 배열 끝에 추가하고, 추가 성공 후 선택 ID를 비운다. 단계 삭제 후에는 화면 순서로 순번을 계산한다.

```ts
const selectedUsers = selectedApprovalUserIds
  .map((id) => userOptions.find((user) => String(user.value) === id))
  .filter((user): user is F1GridUserOption => Boolean(user));

const addApproval = () => {
  if (selectedUsers.length !== 1) return;
  setApprovalStages((current) => [
    ...current,
    { id: nextStageId.current++, kind: 'approval', users: selectedUsers },
  ]);
  setSelectedApprovalUserIds([]);
};
```

합의 함수는 같은 패턴으로 `selectedUsers.length === 0`이면 반환하고 `kind: 'agreement'` 단계 하나에 선택 사용자 전체를 넣는다.

- [x] **Step 2: 공통 사용자 입력과 수신자 정보 표시 컴포넌트 작성**

`DocumentApprovalFields`는 `UserSelectEditor`를 다중 모드로 하나만 렌더링하여 `결재 추가`·`합의 추가` 두 버튼과 공유한다. `결재 추가`는 선택 1명일 때만 활성화하고, `합의 추가`는 선택 1명 이상일 때 활성화한다. 각 단계에 아바타, 이름, 부서를 표시하고 결재/합의 단계에만 빈 도장 슬롯을 둔다. 참조자는 별도의 다중 `UserSelectEditor`와 선택 사용자 요약으로 렌더링한다.

```tsx
<UserSelectEditor
  value={selectedApprovalUserIds}
  options={userOptions}
  multiple
  label="결재선 사용자 선택"
  onChange={(value) =>
    setSelectedApprovalUserIds(Array.isArray(value) ? value.map(String) : [])
  }
/>
<Button disabled={selectedApprovalUserIds.length !== 1} onClick={onAddApproval}>
  결재 추가
</Button>
<Button disabled={selectedApprovalUserIds.length === 0} onClick={onAddAgreement}>
  합의 추가
</Button>
```
