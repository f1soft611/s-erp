# 20261006_003 기안양식 에디터 스크롤 정렬 계획서

> 작업지시서: [20261006_003 기안양식 에디터 스크롤 정렬 작업지시서](../../directions/20261006/20261006_003_기안양식_에디터_스크롤_정렬_작업지시서.md)  
> 설계: [기안양식 에디터 스크롤 정렬 설계](../../superpowers/specs/2026-10-06-draft-form-editor-scroll-design.md)

**목표:** 기안양식 본문 편집기의 스크롤바를 에디터 프레임 상단에 정렬하면서 본문 안쪽 여백을 유지한다.

**방식:** 스크롤 책임을 에디터 외부 Box에서 Tiptap `.ProseMirror` 본문으로 옮긴다. 외부 프레임은 overflow를 숨기고, 기존 본문 여백은 `.ProseMirror`에 적용한다. 공통 에디터 및 공지사항 모달은 변경하지 않는다.

**기술 스택:** React, TypeScript, MUI, Tiptap, Vitest, Testing Library.

## 대상 파일

- 수정: `frontend/src/pages/co/workflow/form/components/DraftFormTemplateDialog.tsx` — 에디터 외부 프레임과 본문 스크롤 스타일
- 수정: `frontend/tests/draft-form-template-dialog.test.tsx` — 스크롤 소유 요소와 안쪽 여백 회귀 검증
- 생성: `docs/spec/20261006/20261006_003_기안양식_에디터_스크롤_정렬_사양서.md` — 상세 동작 및 검증 기준
- 생성: `docs/result/20261006/draft-form-editor-scroll/result.md` 및 `screenshots/` — 검증 결과와 브라우저 캡처

## 작업 순서

### Task 1: 에디터 스크롤 소유자 회귀 테스트

- [ ] 테스트 파일 `frontend/tests/draft-form-template-dialog.test.tsx`에 회귀 테스트를 추가한다.

```tsx
it('scrolls the editor content from the top of its frame and keeps inner padding', async () => {
  renderDialog();

  const frame = screen.getByTestId('draft-form-template-editor');
  const editor = await screen.findByRole('textbox', { name: '본문' });

  expect(editor).toHaveClass('ProseMirror');
  expect(frame).toHaveStyle({ overflow: 'hidden' });
  expect(editor).toHaveStyle({
    overflowX: 'auto',
    overflowY: 'auto',
    padding: '16px',
  });
});
```

- [ ] 실패 확인: `npm --prefix frontend run test -- tests/draft-form-template-dialog.test.tsx` 실행. 새 테스트가 현 상태에서 외부 프레임의 `overflow: auto` 때문에 실패하는지 확인한다.

### Task 2: 스크롤과 여백을 본문에 배치

- [ ] `DraftFormTemplateDialog.tsx`의 `data-testid="draft-form-template-editor"` Box에서 `p: 2`를 제거하고 `overflow: 'auto'`를 `overflow: 'hidden'`으로 바꾼다. 기존 border, 배경색 및 크기 제약은 유지한다.
- [ ] 같은 컴포넌트의 `RichTextEditor.contentSx`에 `overflowX: 'auto'`, `overflowY: 'auto'`, `boxSizing: 'border-box'`, `px: 2`, `py: 2`를 적용한다. 기존 `minHeight: '100%'`와 placeholder 스타일을 유지한다.
- [ ] focused 테스트를 다시 실행해 스크롤 스타일 회귀 테스트와 기존 템플릿 저장/복원 테스트가 통과하는지 확인한다.
