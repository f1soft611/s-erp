# 공통 리치 텍스트 저장 수명주기 계획서

> 기준 설계: [Shared Rich Text Save Lifecycle](../../superpowers/specs/2026-10-06-shared-editor-save-lifecycle-design.md)

**목표:** Notice 기준의 본문 이미지 session/save lifecycle과 backend HTML/JSON owner rewrite를 Notice와 Draft가 공통 사용하게 한다.

**구조:** frontend shared hook은 editor body snapshot과 임시 업로드 session 정리를 담당하고 domain dialog는 API adapter 및 form state를 유지한다. backend common sanitizer와 processor는 Tiptap HTML/JSON 정규화, image reference/token/promotion/rewrite/retained-file logic을 담당하며 Notice/Draft service는 target authorization, domain stable URL resolver, 업무 row save를 유지한다.

**기술:** React, TypeScript, Tiptap, Vitest, Java 8-compatible Spring/eGovFrame, MyBatis, Jackson, Jsoup.

## 구현 계약

- `useRichTextEditorSaveLifecycle({ editor, uploadImage, deleteTemporaryImage, onImageUploadError })` returns wrapped `uploadImage`, `onOrphanedImageUpload`, `onUploadingChange`, `uploadingCount`, `getSnapshot()`, `cleanupTemporaryImages()`, and `completeSave()`.
- `getSnapshot()` returns `{ html, json, referencedImages, temporaryImages }`. `referencedImages` comes from current Tiptap image nodes; `temporaryImages` comes from every unexpired upload in this dialog session, even if removed from the body.
- Domain upload adapters return the shared `RichTextEditorImage` contract plus `fileName`. Delete adapters accept `{ uploadToken, fileName }`.
- `EmbeddedImageDocumentProcessor` accepts tenant ID, server-selected owner type/ID, HTML/JSON, referenced image metadata, full temporary session, uploaded-by identity, and a stable image URL resolver. Referenced details provide the preferred filename, while a new token can only be promoted when present in the full session; already owner-listed images can be retained without a current session token.
- `EmbeddedImageDocumentStorage` is the processor bridge. Notice uses `EmbeddedImageStorageService`; Draft implements the bridge through its form-checking adapter and fixes owner type to `DRAFTING_WORK_TEMPLATE`.
- `RichTextDocumentSanitizer` returns sanitized HTML and JSON using the common Tiptap/Notice text-style allowlist. Owner-specific stable URL checks remain in the processor.
