# 타 업무 본문 여백 통일 계획

**Goal:** 영업관리와 같은 16px 본문 여백 및 현황 알림 닫힘 여백을 나머지 업무 모듈에 적용한다.

**Architecture:** 공통관리(co), 생산(pr), 그룹웨어, 환경설정의 업무 페이지별 기존 본문과 메시지 래퍼를 수정한다. 구매자재, 품질, 인사 및 이미 적용된 영업관리 화면의 소스는 수정하지 않는다. 공통 메시지에는 기존 동작을 유지하는 선택적 16px 옵션만 추가한다.

**Tech Stack:** React, TypeScript, MUI, Vitest, Playwright.

## 단계
- [ ] 각 업무의 본문 래퍼와 메시지 배치를 확인하고 사양에 범위를 기록한다.
- [ ] 기존 컴포넌트의 16px 여백 및 알림 닫기 동작을 실패 테스트로 확인한다.
- [ ] 해당 업무 페이지 본문과 그리드·메시지 경계를 정렬한다.
- [ ] 관련 테스트, 빌드, lint, 실제 브라우저 375/768/1280px 검증을 수행한다.
- [ ] 작업 결과 및 스크린샷과 검증 제한을 기록한다.
