# 영업관리 본문 여백 통일 계획

**Goal:** 영업관리 페이지 본문 외곽 여백을 모든 화면 크기에서 16px로 통일하고 현황 알림을 닫은 뒤에도 상단 16px을 유지한다.

**Architecture:** 수주등록·수주현황을 기준으로 각 영업 페이지 본문 컨테이너를 정렬한다. embedded 등록 폼의 패딩은 유지한다. 결과 알림의 표시 여부에 따른 중복 여백을 피하고 닫은 후 기본 간격을 복구한다.

**Tech Stack:** React, TypeScript, MUI, Vitest.

## 단계
- [x] 기존 작업지시서와 페이지별 컨테이너 및 알림 배치를 확인한다.
- [x] 등록·현황 본문, 알림 닫기 동작의 회귀 테스트를 먼저 작성한다.
- [x] 영업관리 본문을 16px 기준으로 정렬하고 embedded 폼을 보존한다.
- [x] 납품처 관리 좌우 카드에 수주등록과 같은 outlined 테두리를 적용하고 회귀 테스트한다.
- [x] 등록 화면 기본정보·상세 제목·그리드·금액 영역의 카드 내부 좌우 여백을 16px로 맞춘다.
- [x] 관련 테스트, 빌드, lint와 영업관리 12개 화면 375/768/1280px 브라우저 검증을 수행한다.
- [x] 검증 제한 및 스크린샷을 결과 문서에 기록한다.
