# 양쪽 그리드 내부 여백 통일 계획

**Goal:** 공통코드 관리와 납품처 관리의 각 카드 내부 그리드 여백 및 제목 정렬을 통일한다.

**Architecture:** 두 페이지의 카드 콘텐츠에서 좌우·아래 패딩을 16px로 지정하고 제목의 별도 좌우 패딩을 제거한다. 공통 그리드, 분할기 및 데이터 동작은 수정하지 않는다.

**Tech Stack:** React, MUI, Vitest, Playwright.

## 실행
- [ ] 양쪽 화면의 각 그리드와 제목에 대한 16px 여백 회귀 테스트를 먼저 추가하고 실패를 확인한다.
- [ ] 두 화면의 카드 좌우·아래 패딩을 16px로 변경하고 제목과 그리드 좌우 경계를 맞춘다.
- [ ] 관련 테스트, 빌드, lint와 375/768/1280px 브라우저 검증을 수행한다.
- [ ] 결과 및 스크린샷을 `docs/result/20261124/dual-grid-inner-spacing`에 기록한다.
