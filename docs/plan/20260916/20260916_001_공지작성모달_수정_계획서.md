# 20260916_001 공지 작성 모달 수정 계획서

## 1. 작업 배경

공지 작성 모달은 기존 F1Editor 기반 문서 편집 영역을 사용하지만, 툴바와 첨부 동작이 사용자 기대와 다른 흐름으로 동작하고 있다. 특히 첨부 파일 삽입 위치와 버튼 스타일이 다른 화면 톤과 일관되지 않다.

## 2. 작업 범위 분해

### 2.1 스타일 정합화

- 대상: `NoticeComposerDialog.tsx`
- 작업 내용:
  - 취소 버튼 스타일을 F1-Grid form modal 기준으로 맞춘다.
  - 버튼 레이아웃, 여백, radius, 색상 톤을 정리한다.

### 2.2 툴바 구성 정리

- 대상: `NoticeComposerDialog.tsx`, `F1Editor.tsx`
- 작업 내용:
  - 버튼 순서를 참조 이미지 기준으로 재배치한다.
  - 실제 기능이 연결된 버튼을 유지하도록 정리한다.

### 2.3 첨부 삽입 로직 개선

- 대상: `F1Editor.tsx`
- 작업 내용:
  - 업로드 파일을 본문 끝에 단순 append하지 않고 본문 문맥에 맞춰 삽입한다.
  - 본문이 비어 있으면 최상단에 추가한다.
  - 본문이 있으면 구분선 뒤에 첨부 파일 섹션을 추가한다.
  - 다중 파일 업로드 시 파일 순서를 유지한다.

## 3. 영향 범위

- 프론트엔드 공통 에디터 컴포넌트
- 공지 작성 모달 전용 레이아웃
- 관련 Vitest 스냅샷/동작 검증

## 4. 검증 계획

- `cd frontend`
- `npm run test -- tests/notice-composer-dialog-theme.test.tsx`
- 필요 시 추가 리그레션 검증

## 5. 위험 요소

- 에디터 내 content node 구조를 잘못 변형하면 문서 전체 렌더링이 깨질 수 있다.
- 첨부 파일 추가 로직은 저장 시점에 재사용될 수 있으므로 node 배열의 순서를 보존해야 한다.
