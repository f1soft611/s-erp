# 20260916_001 공지 작성 모달 전면 재수정 계획서

## 1. 작업 개요

공지 작성 모달에서 제목, 본문, 첨부 영역이 하나의 연속된 입력 블록처럼 보이도록 재구성한다. 기존의 분리형 하단 툴바와 별도 첨부 섹션을 제거하고, Tiptap 에디터와 첨부파일 카드 목록을 공지사항 페이지 첨부 리스트 스타일에 맞게 통합한다.

핵심 목표는 다음과 같다.

- `NoticeComposerDialog`에서 `f1-editor` 제거
- Tiptap 기반 에디터 적용
- 제목/본문/첨부 영역을 하나의 연속된 입력 영역처럼 구조화
- 첨부 파일 목록을 공지사항 페이지 첨부 리스트 형태로 표현
- 불필요한 하단 툴바와 링크 버튼 조합 제거
- 관련 `f1-editor` 파일 정리

## 3. 요구사항 분석

### 3.1 현재 문제점

현재 모달은 제목, 본문, 첨부 영역이 분리되어 보이며, 하단의 맞춤형 툴바가 별도 영역으로 존재한다. 시각적으로는 본문이 제목에 비해 독립적으로 보이고, 첨부 리스트도 공지사항 페이지와 다른 스타일을 가진다.

필수 반영 사항은 아래와 같다.

- 제목, 본문, 첨부가 하나의 흐름으로 이어지는 레이아웃
- 첨부 목록이 공지사항 페이지의 첨부 카드와 유사하게 표시
- `f1-editor` 제거 후 Tiptap 적용
- 하단 툴바 제거, 기본 Tiptap 툴바 수준 유지
- 첨부 아이콘은 에디터와 자연스럽게 연결된 위치에 배치

### 3.2 기술적 선택지

대안 1: 기존 구조를 유지하고 CSS만 조정

- 장점: 변경 범위가 작다.
- 단점: 요구사항의 “한몸처럼” 표현과 첨부 리스트 통합 요구를 충족하지 못한다.

대안 2: 에디터 구조와 첨부 스타일을 일괄 재배치

- 장점: 요구사항과 일치하며 디자이너 의도에 맞는다.
- 단점: 레이아웃과 테마 보정이 필요하다.

권장안은 대안 2이며, 공지 작성 모달을 기본 입력 블록 단위로 재구성하는 방식으로 진행한다.
