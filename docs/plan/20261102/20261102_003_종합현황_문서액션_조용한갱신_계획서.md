# 20261102_003 종합현황 문서 액션 조용한 갱신 계획서

## 목표

종합현황에서 전자결재 문서를 열고 액션을 완료한 뒤, 종합현황과 상세를 기존 데이터가 보이는 상태로 조용히 재조회한다.

## 영향 범위

- `frontend/src/pages/dashboard/overview/hooks/useOverviewData.ts`: 일반 새로고침과 구분되는 조용한 summary 갱신 제공. 요청 중에는 마지막 성공 데이터를 계속 반환하며, 권한/월이 그대로면 수주 데이터를 불필요하게 재조회하지 않는다.
- `frontend/src/pages/groupware/OverviewPage.tsx`: 조용한 완료 콜백에서는 summary만 조용히 갱신하고 별도 상세 refresh token을 변경하지 않는다.
- `frontend/src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx`: 승인/반려/보완요청/참조확인/최종확인 성공 후 상위 갱신을 quiet로 호출하고 자체 상세 재조회도 quiet로 수행한다.
- `frontend/tests/overview-page.test.tsx`: 액션 뒤 summary 재조회가 대기 중인 동안 이전 현황과 상세가 유지되는 회귀 검증.
- `docs/result/20261102/overview-silent-document-actions/result.md`: 구현 원인, 변경, 검증 및 브라우저 확인 결과.

## 구현 순서

1. [x] summary 2차 조회를 지연시키는 테스트를 추가해 기존 로딩 전환을 재현한다.
2. [x] overview data hook에 quiet refresh 경로를 추가하고 기존 화면 데이터 보존을 검증한다.
3. [x] 종합현황 콜백이 quiet 옵션을 처리하도록 하고 quiet 액션에서 외부 상세 refresh token이 중복 발행되지 않게 한다.
4. [x] 결재 및 확인 액션 성공 후 quiet 옵션과 quiet detail reload를 사용한다. 버튼 pending 상태와 오류 처리는 유지한다.
5. [x] 관련 Vitest, 빌드, lint를 실행하고 결과 문서를 작성한다.
6. [ ] 실제 브라우저 검증은 로그인으로 리디렉션되어 수행하지 못했다. 인증 정보를 추측하거나 사용하지 않았으며 결과 문서에 제한을 기록했다.

## 검증

- `cd frontend; npm run test -- tests/overview-page.test.tsx`
- `cd frontend; npm run build`
- `cd frontend; npm run lint`
- 액션 회귀: `cd frontend; npx vitest run tests/document-write-page.test.tsx -t 'submits a detail approval directly|processes a detail REJECTED|processes a detail RETURNED|confirms the drafter final line|confirms only the authenticated employee reference|shows reference-confirmation failures|keeps an approval successful when refreshing comments fails'`
- 문서현황 회귀: `cd frontend; npx vitest run tests/document-status-page.test.tsx`
- 변경 파일 대상 lint: `cd frontend; npx oxlint src/pages/dashboard/overview/hooks/useOverviewData.ts src/pages/groupware/OverviewPage.tsx src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx tests/overview-page.test.tsx tests/document-write-page.test.tsx`
- `git diff --check`
- 실제 브라우저에서 종합현황과 상세가 조용히 유지되는지 확인하고 스크린샷을 `docs/result/20261102/overview-silent-document-actions/screenshots`에 저장한다.
