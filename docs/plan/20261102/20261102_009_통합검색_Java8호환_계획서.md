# 통합검색 Java 8 호환 수정 계획

근거: [작업지시서](../../directions/20261102/20261102_009_통합검색_Java8호환_작업지시서.md).

1. `UnifiedSearchServiceImpl`의 `List.of`/`String.isBlank` 사용과 운영 오류를 대조한다.
2. 검색·실시간 신규 패키지의 운영 소스를 `javac --release 8`로 검사하는 회귀를 추가하고 실패를 확인한다. 테스트 실행 JDK는 기존 개발 기준을 유지한다.
3. 검색 서비스의 컬렉션 생성은 Java 8 Collections/Arrays로, 공백 검증은 Spring `StringUtils.hasText`로 치환한다. Unicode 공백 처리와 유형 순서를 유지한다.
4. 검색 서비스·컨트롤러·호환성 회귀와 관련 실시간 테스트를 실행한다. API/SQL/DB 수정은 하지 않는다.
5. 결과에 최초 원인, 종료 DB 경고와의 구분, 로컬 검증 및 운영 미확인 범위와 재배포 절차를 기록한다. UI 변경이 없어 스크린샷은 해당하지 않는다.

상태: 1~5 완료. [실패 재현·수정·검증·재배포 안내](../../result/20261102/unified-search-java8/README.md).
