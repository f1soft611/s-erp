# 쪽지 이모지 응답 오류 수정 계획

근거: [작업지시서](../../directions/20261102/20261102_010_쪽지_이모지_응답오류_작업지시서.md).

1. 실제 MVC JSON converter로 emoji를 포함한 쪽지 목록의 UTF-8 응답 실패를 재현한다.
2. 공통 CharacterEscapes가 처리하지 않는 문자는 Jackson 기본 인코딩에 위임한다.
3. 쪽지 알림 요약의 UTF-16 상한은 유지하되 surrogate pair를 중간에서 자르지 않는다.
4. 대상 테스트, Java 8 API 호환 검사와 WAR 빌드를 수행하고 결과를 기록한다.

상태: 완료. [재현·원인·검증·배포 결과](../../result/20261102/message-emoji/README.md).
