# 기안자 최종확인 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 최종 승인/반려 문서를 기안자가 앱 내에서 최종 확인하게 하고, 확인 이력을 문서 최종 상태와 분리해 저장한다.

**Architecture:** 서버는 상신/재상신 트랜잭션에서 기안자의 내부 `FINAL_CONFIRMATION` 행을 일반 결재선 뒤에 생성한다. 최종 승인/반려 시 문서 상태를 즉시 `COMPLETED`/`REJECTED`로 확정하면서 확인 행만 활성화하고, 기안자의 확인은 행 상태와 SYSTEM 이벤트만 갱신한다. 참조확인 API와 화면 패턴은 참고하되 조회 범위·권한·참여 유형·이력 코드는 분리한다.

**Tech Stack:** Java 17, Spring Boot/eGovFrame, MyBatis, PostgreSQL, React, TypeScript, MUI, Vitest, JUnit 5.
