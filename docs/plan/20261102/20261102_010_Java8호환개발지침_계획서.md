# Java 8 호환 개발 지침 계획

근거: [작업지시서](../../directions/20261102/20261102_010_Java8호환개발지침_작업지시서.md).

1. 루트·백엔드 `AGENTS.md`, 팀 지침, 백엔드 README와 기존 Java 8 호환 사양을 확인한다.
2. 상세사양서에 문법·API·의존성·검증 기준 및 개발 JDK와의 구분을 정의한다.
3. 에이전트 진입 문서에 규칙을 추가하고 기존 Java 17+ 안내를 개발 도구 기준으로 명확히 한다.
4. 변경 차이와 문서 간 일관성을 확인하고 결과를 기록한다.

애플리케이션 코드, Maven 설정, 기존 개별 작업 문서는 수정하지 않는다.
