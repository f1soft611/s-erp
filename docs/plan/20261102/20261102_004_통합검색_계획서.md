# 통합검색 Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan inline, task-by-task. Preserve unrelated worktree changes.

**Goal:** 우측 상단 공통 모달에서 권한이 있는 메뉴·문서·공지를 검색하고 기존 화면을 연다.

**Architecture:** 서버 `UnifiedSearchService`가 권한 메뉴 트리, 기존 `DocumentApprovalStatusService` 및 `NoticeBoardDAO` 조회를 조합한다. 검색 전용 응답만 반환하여 문서/공지 본문·첨부·댓글 데이터를 클라이언트로 보내지 않는다. 프런트 `UnifiedSearch`가 모달/유형/페이지/응답 경쟁을 관리하고 API 서비스와 타입은 분리한다.

**Tech Stack:** Java 17, Spring Boot/eGovFrame, MyBatis, React/TypeScript, MUI CommonDialog, Vitest, Playwright.
