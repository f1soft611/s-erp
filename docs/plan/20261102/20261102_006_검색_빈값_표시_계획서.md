# 검색 빈값 표시 계획서

근거: [작업지시서](../../directions/20261102/20261102_006_검색_빈값_표시_작업지시서.md).

1. 기존 검색 테스트 파일에 상단 폼의 빈값·공백/1자 제출 시 문구 없음, 본문은 문구 유지, aria-invalid 유지, 이동 없음, 입력 후 해제 회귀를 추가하고 실패를 확인한다.
2. 공통 UnifiedSearch 폼의 error를 길이 오류 상태로 유지하고 header variant일 때 helperText만 숨긴다.
3. 검색 타깃 테스트/build/lint 및 375/768/1280px 브라우저에서 실제 빨간 테두리와 문구 부재를 확인한다.
4. 기존 결과 폴더에 빈값 스크린샷과 후속 결과를 기록한다. 백엔드/DB 변경은 없다.
