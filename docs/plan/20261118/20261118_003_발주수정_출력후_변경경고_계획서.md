# 20261118_003 출력된 발주서 변경 시 경고 계획서

기준: [작업지시서](../../directions/20261118/20261118_003_발주수정_출력후_변경경고_작업지시서.md)

## 구현 단위
| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | 테스트 | 출력된 발주 수정 창의 경고·확인창(취소/확인), 미출력 발주, 입고대기마감 저장에서 경고 없음 |
| 2 | 구현 | `PurchaseOrderCreatePage`에 경고 Alert와 저장 직전 `confirm` 추가 |
| 3 | 검증·문서 | 관련 테스트·tsc, 실제 서버·브라우저, 결과 문서 |

## 결정과 이유
- **화면에서만 처리**: 출력 표시는 서버에 이미 있고(`printAt`), 막지 않으므로 백엔드 변경이 필요 없다.
- **확인창은 저장 시점**: 수정 창을 열자마자 묻기보다 실제로 내용을 바꿔 저장할 때 묻는 편이 흐름을 덜 끊는다. 창 상단에는 계속 경고를 보여 미리 알 수 있게 한다.
- **공통 확인창 사용**: `useCommonConfirmDialog`(프로젝트 규칙).
