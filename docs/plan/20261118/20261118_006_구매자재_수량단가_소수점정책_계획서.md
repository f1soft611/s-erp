# 20261118_006 구매자재·품질 수량·단가 소수점 정책 적용 계획서

기준: [작업지시서](../../directions/20261118/20261118_006_구매자재_수량단가_소수점정책_작업지시서.md)

| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | 조사 | 서버 정책(`/api/v1/system/policies/grid-decimals`)과 F1Grid 우선순위 확인, 컬럼별 고정 자릿수 목록화 |
| 2 | 컬럼 정리 | 수량·단가 컬럼의 `decimalPlaces: 2` 제거, 현황 도우미를 수량·단가용(`quantityColumn`, 정책 따름)과 금액용(`amountColumn`, 2자리)으로 분리 |
| 3 | 검증 | 관련 단위 테스트·`tsc`, 실서버에서 현황 화면 3곳의 값이 정책(2자리)대로 보이는지 확인 |

## 결정과 이유
- **금액은 컬럼 고정 유지**: 정책 설명이 "수량·단가 기본 소수점 자릿수"이므로 범위를 넘지 않는다.
- **도우미 분리**: 현황 화면의 한 도우미가 수량·단가·금액을 함께 만들어 자릿수를 일괄 고정하던 구조라, 정책을 따르는 도우미를 별도로 두었다.
- 정책을 바꿨을 때의 화면 반영은 F1Grid의 기존 정책 적용 테스트가 보장하므로 정책 값을 임의로 바꿔 확인하지는 않는다.
