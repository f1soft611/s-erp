# 문서 공통 UI 테스트 복구 계획서

- [작업지시서](../../directions/20261118/20261118_001_repository-remediation_작업지시서.md)의 테스트 복구 단계다.
- 범위: 결재 툴바, 문서 링크 통합, 기안양식 본문 대화상자 테스트 3개 파일. 운영 UI·API·DB는 변경하지 않는다.

## 순서

- [x] 기존 실패와 최신 결재 액션 메뉴/내외부 링크 사양 및 실제 확인창 문구를 비교한다.
- [x] 승인 액션이 더보기 메뉴로 이동한 현행 툴바 슬롯 계약을 검증한다.
- [x] 링크 목적지를 외부 URL로 바꾼 뒤 내부 카드 제거와 외부 카드 생성을 함께 검증한다.
- [x] 누락된 멘션 사용자/외부 미리보기 fixture를 제공하되 클립보드 성공·실패 알림 횟수 단언은 유지한다.
- [x] 본문 변경 취소 확인창의 현재 `계속` 버튼을 사용하고 임시 이미지 삭제 단언을 보존한다.
- [x] 관련 테스트 전체와 최소 lint 결과를 기록한다.
