# 20261118_008 단가등록 품목 기준 트리 화면 계획서

기준: [작업지시서](../../directions/20261118/20261118_008_단가등록_품목기준트리화면_작업지시서.md), 선행 [20261118_007 사양서](../../spec/20261118/20261118_007_단가등록_이력부가세외화_상세사양서.md)

| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | 백엔드 조회 | `overview` API: 품목 + 매입/매출 기본단가 + 특별단가 건수, 특별단가 자식 행. 조건·건수 상한 |
| 2 | 프론트 모델 | 응답 → 트리 행 변환, 셀 변경 → `save-batch` 변경 집합(정정/신규) 변환 로직(단위 테스트 우선) |
| 3 | 프론트 화면 | 탭(품목 기준/단가 목록), `F1Tree` 화면, 자식 추가(거래처 선택), 적용일 기본값, 잠금 표시 |
| 4 | 엑셀 | 품목 기준 양식(현재 단가 포함) 다운로드, 업로드 미리보기·검증·반영 |
| 5 | 검증 | 단계 중에는 관련 단위 테스트와 `tsc`만, 실서버·브라우저·스크린샷은 마지막에 한 번 |

## 결정과 이유
- **DB 변경 없음**: 기본단가(거래처 NULL)와 특별단가는 007의 `tb_item_partner_price`를 그대로 쓴다.
- **저장은 기존 `save-batch` 재사용**: 겹침·자동 종료·과거 잠금 규칙이 이미 서버에 있어 중복 구현하지 않는다. 화면이 "이 셀 변경이 정정인지 신규 적용인지"만 판단해 변경 집합을 만든다.
- **조회 전용 신규 API**: 품목 전체를 펼치려면 단가 행이 없는 품목도 나와야 하므로 기존 목록 API로는 부족하다. 품목 건수가 크므로 상한을 두고 조건 검색을 안내한다.
- **한 행에 매입·매출**: 부모/자식 모두 한 행에 두 구분을 피벗해서 보여 주고, 저장 시 구분별 단가 행으로 나눈다.
- **단가 목록 탭 유지**: 007의 평면 그리드가 이력 조회와 특별단가 엑셀에 이미 맞아 재사용한다.
