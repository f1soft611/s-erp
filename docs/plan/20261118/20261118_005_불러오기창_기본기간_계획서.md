# 20261118_005 구매자재·품질 불러오기 창 기본 조회 기간 계획서

기준: [작업지시서](../../directions/20261118/20261118_005_불러오기창_기본기간_작업지시서.md)

| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | 백엔드 | 구매요청 후보(`/candidates`)·확정 목록에 `fromDt`/`toDt` 추가(요청일·확정일), 시작일>종료일은 400. 확정 품목 API는 이미 지원 |
| 2 | 공통 | `usePickerDateRange`(서버 날짜로 기본 기간, 준비 완료 전 조회 금지), `PickerDateRangeFields`(공통 달력 2개) |
| 3 | 창 6곳 | 기간 입력 추가/교체, 열릴 때 기본 기간이 준비된 뒤 첫 조회, 서비스 호출에 기간 전달 |
| 4 | 검증 | 훅·6개 창 단위 테스트, 백엔드 서비스 테스트, 큰 작업 종료 시 실서버·브라우저 한 번에 확인 |

## 결정과 이유
- **기본 기간이 준비된 뒤 조회**: 기간 없는 전체 조회가 먼저 나갔다가 다시 조회되는 깜빡임과 불필요한 호출을 막는다.
- **창 열릴 때 한 번만 채움**: 사용자가 바꾼 기간은 창을 닫았다 열어도 유지한다(같은 화면 사용 중).
- **상수 분리**: 업체별 기준은 정책 설계가 필요하므로 이번에는 한 곳의 상수로만 둔다.
