# 20261118_007 단가등록 이력·부가세·외화·기본단가 개선 계획서

기준: [작업지시서](../../directions/20261118/20261118_007_단가등록_이력부가세외화_작업지시서.md)

| 순서 | 단위 | 내용 |
| --- | --- | --- |
| 1 | DB | `tb_item_partner_price` 컬럼 추가·제약 변경, 기본단가용 부분 유니크 인덱스, 스크립트·롤백·변경 이력 |
| 2 | 백엔드 | 모델 필드, 저장 규칙(겹침·자동 종료·과거 잠금), 조회 필터(이력 포함), 엑셀 일괄 저장 반영 |
| 3 | 단가 조회 | `selectDefaultUnitPrice` 거래처 일치 → 기본단가 폴백, 외화 필드 반환 여부 결정 |
| 4 | 프론트 | 컬럼(부가세구분·포함·외화단가·통화), 거래처 비움=기본, 이력 포함 토글, 행 잠금 표시, 엑셀 양식 |
| 5 | 검증 | 단계 중에는 관련 단위 테스트와 `tsc`만, 실서버·브라우저 확인은 묶어서 마지막에 한 번 |

## 결정과 이유
- **한 테이블 유지**: 적용 기간 행이 이미 이력 구조이고 기존 단가 조회가 기간 기준이라 MES식 2테이블(현재/이력)을 두지 않는다.
- **기본단가=거래처 NULL 행**: 새 거래처가 생겨도 설정이 필요 없고, 이력·겹침 규칙을 같은 방식으로 재사용한다.
- **통화 의미 변경**: 기존 `KRW` 기본 필수 컬럼을 "외화단가의 통화"(선택)로 바꾸고 기존 `KRW` 값은 NULL로 정리한다.
- **공통코드 항목 값 미확인**: MCP 항목 조회가 실패했다. 구현 단계에서 `PURCHASE_TAX_TYPE`·`CURRENCY` 항목 코드를 Mapper/기존 발주 코드로 확인하고 결과 문서에 기록한다.
