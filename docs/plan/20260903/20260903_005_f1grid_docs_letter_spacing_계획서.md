# F1-Grid 문서 포털 자간 통일 계획서

## 1. 목적

F1-Grid 문서 포털의 메인 제목과 라벨 텍스트가 서로 다른 자간 값으로 보이며, 시각적 기준이 일관되지 않는다. 문서 화면의 전반적인 가독성과 디자인 정합성을 유지하기 위해 자간을 통일한다.

## 2. 작업 범위

### 프론트엔드

- `frontend/src/pages/f1-grid-docs/F1GridDocsPage.css`
- 필요 시 `frontend/tests/f1-grid-docs.test.tsx` 회귀 테스트 보강

### 제외 범위

- F1-Grid 문서 구조 재설계
- 라우팅 및 메뉴 접근 방식 변경
- 다른 페이지의 전역 스타일 수정

## 3. 구현 접근법

1. 현재 문서 페이지의 CSS를 점검해 `letter-spacing`이 일부 요소에만 적용되는 지점을 확인한다.
2. 제목/라벨/네비게이션 텍스트에 동일한 기준 자간 값을 적용한다.
3. 회귀 테스트를 추가해 문서 페이지의 대표 텍스트가 동일 자간 기준을 유지하는지 검증한다.

## 4. 검증 계획

- `cd frontend; npm run test -- --run tests/f1-grid-docs.test.tsx`
- 필요 시 `npm run build`로 프론트엔드 빌드 확인

## 5. 리스크 및 대응

- 자간 값 과다 적용 시 텍스트가 답답하게 보일 수 있으므로, 기존 여백과 가독성을 함께 유지하는 값으로 조정한다.
- 문서 페이지와 다른 스타일이 충돌하지 않도록 해당 CSS 범위만 수정한다.
