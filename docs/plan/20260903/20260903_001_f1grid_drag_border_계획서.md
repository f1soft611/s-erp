# 계획서

## 목표

F1-Grid 의 드래그 선택 오버레이가 실제 선택된 셀 영역을 벗어나 그려지는 문제를 수정한다.

## 작업 분해

1. F1Grid 범위 오버레이 계산 로직 확인
2. 오버레이 좌표 계산에서 경계 여분 값 제거 및 안쪽 정렬 반영
3. 회귀 테스트 추가
4. 관련 테스트 실행으로 검증

## 영향 범위

- 드래그 선택 표시에만 한정
- 복사 범위 오버레이와 드래그 범위 오버레이 모두 동일 규칙 적용

## 검증 계획

- `cd frontend && npm run test -- tests/f1-grid.test.tsx`
