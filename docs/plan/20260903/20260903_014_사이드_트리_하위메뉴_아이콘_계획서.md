## 요구사항 분석 및 목적

현재 사이드 트리와 F1-Tree는 부모-자식 계층을 펼침/접힘 상태로만 표현하고 있어, 하위 메뉴가 어떤 경로의 자식 노드인지 시각적으로 구분하기 어렵습니다. 사용자는 특히 여러 단계의 하위menu를 탐색할 때, 실제 계층 구조를 파악하는 데 어려움을 겪습니다.

이번 작업은 하위 메뉴에 계층 표시 마커를 추가해 트리 구조의 가독성을 높이는 것을 목표로 합니다. 표시 방식은 기존 트리 동작과 맞물려 동작해야 하며, 루트 메뉴와 자식 메뉴의 구분을 동시에 유지해야 합니다.

## 작업 범위 분해 (프론트엔드 전전용)

### A. 사이드 트리 시각화 보강

1. `frontend/src/pages/dashboard/components/DashboardMenuTree.tsx`의 `TreeItem` 렌더링 로직을 검토한다.
2. 하위 메뉴 노드에 계층 표시 아이콘 또는 마커를 추가한다.
3. `node.children`가 있는 노드와 하위 자식 노드의 레이블 간격을 보정한다.
4. 기존 선택 상태, 강조, 트리 expand/collapse 동작은 유지한다.

### B. F1-Tree 하위 메뉴 마커 보강

1. `frontend/src/shared/components/f1-grid/tree/F1Tree.tsx`의 셀 어드ornment 로직을 수정한다.
2. 자식 노드에 대해 `ㄴ` 계열의 하위메뉴 표시 마커를 추가한다.
3. depth 기반 좌측 들여쓰기를 유지하고, expand/collapse 아이콘과 마커가 자연스럽게 보이도록 정렬한다.
4. 트리 체크박스, 부모/자식 노드 상태 표시, row selection 로직은 유지한다.

### C. 레이아웃/접근성 유지

1. 아이콘/마커 추가로 인해 텍스트가 밀리거나 넓어지지 않도록 정렬을 보정한다.
2. `aria-label`과 기존 클릭 동작은 유지한다.
3. 모바일/데스크톱 환경에서 UI가 과도하게 깨지지 않는지 점검한다.

### D. 검증

1. 관련 UI 렌더링 또는 브라우저 스크린샷 검증을 수행한다.
2. 사이드 트리 와 F1-Tree의 expand/collapse 동작이 유지되는지 확인한다.
3. 변경 범위가 제한된 프론트엔드 파일에만 영향을 주는지 확인한다.

## 기존 코드/아키텍처 영향 범위

- 변경 범위는 프론트엔드의 트리 렌더링 컴포넌트 2개 파일로 제한한다.
- 트리 데이터 구조, 메뉴 권한/조회 API, 백엔드 스키마는 변경하지 않는다.
- F1Tree 내부 row projection, expand 상태 관리 로직은 그대로 유지한다.
- 다른 화면 레이아웃이나 공용 전역 테마는 수정하지 않는다.

## 검증 계획

- **빌드**: `cd frontend && npm run build`
- **테스트**: `cd frontend && npm run test -- tests/f1-grid-docs.test.tsx` 또는 관련 UI smoke test
- **브라우저 검증**: Dashboard 사이드 트리와 F1-Tree에서 하위 메뉴 마커 표시 여부 확인
- **회귀 검증**: expand/collapse, 선택 상태, 체크박스 동작 유지 확인
