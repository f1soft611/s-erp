# 계획서

## 목표

F1-Grid 셀 에디터 기본 동작과 폰트 상속 문제를 수정하여 편집 UX를 일관되게 정리한다.

## 작업 분해

1. 공통 에디터 입력 요소에서 `selectOnFocus` 동작을 추가하고 공용 옵션으로 전달한다.
2. 텍스트/숫자/자동완성/날짜/시간 에디터에 폰트 상속 스타일을 통일한다.
3. 회귀 테스트를 추가해 드래그 선택 및 에디터 입력 동작을 검증한다.
4. 관련 단일 테스트 파일을 실행해 결과를 확인한다.

## 영향 범위

- F1-Grid 공용 에디터 구성요소에만 한정
- 다른 화면 및 API와는 무관
