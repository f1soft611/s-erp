# 20261026_007 그룹웨어 문서현황·자료실 브로드크럼 경로 수정 계획서

## 목표

문서현황과 자료실 페이지가 상위 메뉴를 누락하지 않고 모듈 > 부모 메뉴 > 현재 페이지의 브로드크럼을 표시하도록 한다.

## 구현 단위

1. `frontend/tests/document-status-page.test.tsx`와 `frontend/tests/archive-page.test.tsx`에 승인된 전체 경로가 표시되는 회귀 테스트를 추가하고, 구현 전에 실패하는지 확인한다.
2. `DocumentStatusPage`의 경로를 `selectedModule.name`, `문서관리`, `currentMenuName`으로 구성한다.
3. `ArchiveBoardPage`의 경로를 `selectedModule.name`, `커뮤니티`, `currentMenuName`으로 구성한다.
4. 페이지별 타깃 테스트, 프런트엔드 빌드, 브라우저 화면 및 `git diff --check`를 검증한다.
5. 변경 원인과 검증 결과를 `docs/result/20261026/groupware-page-breadcrumbs/`에 기록한다.

## 변경 범위

| 파일 | 변경 |
|---|---|
| `frontend/src/pages/groupware/documents/status/DocumentStatusPage.tsx` | 문서현황 브로드크럼의 부모 메뉴 추가 |
| `frontend/src/pages/groupware/community/archive/ArchiveBoardPage.tsx` | 자료실 브로드크럼의 부모 메뉴 추가 |
| `frontend/tests/document-status-page.test.tsx` | 문서현황 전체 경로 회귀 테스트 |
| `frontend/tests/archive-page.test.tsx` | 자료실 전체 경로 회귀 테스트 |

## 검증 기준

- 문서현황은 `그룹웨어 > 문서관리 > 문서현황`, 자료실은 `그룹웨어 > 커뮤니티 > 자료실`을 표시한다.
- 기존 페이지 렌더링, 검색, 권한, 목록 기능에는 영향이 없다.
- DB, 백엔드, API, 공통 `PageHeader`는 수정하지 않는다.
