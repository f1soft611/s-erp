# 20261026_005 커뮤니티 자료실 그리드 전체 높이 계획서

## 목표

자료실 파일/폴더 그리드가 헤더, 검색, 안내 및 경로 아래 남은 세로 공간을 차지하도록 한다.

## 구현 계획

1. `frontend/tests/archive-page.test.tsx`에서 기존 자료실 회귀 테스트를 실행해 현재 기능 기준선을 확인한다.
2. `frontend/src/pages/groupware/community/archive/ArchiveBoardPage.tsx`의 마지막 그리드 영역에 세로 flex 레이아웃을 적용해 `ArchiveFileGrid`에 가용 높이가 전달되도록 한다. 날짜 기본값 및 조회 로딩 변경을 포함한 기존의 수정 내용은 유지한다.
3. `frontend`에서 자료실 페이지 테스트와 `npm run build`를 실행한다.
4. `127.0.0.1:4173`의 기존 S-ERP 개발 서버를 확인/재사용해 375px, 768px, 1280px 화면에서 그리드의 높이와 가로 넘침을 검증한다.
5. `docs/result/20261026/community-archive-grid-fill-height`에 원인, 수정 내용, 검증 결과와 가능한 스크린샷을 기록한다.

## 완료 기준

- 그리드가 자료실 페이지의 남은 세로 공간을 사용한다.
- 기존 검색, 폴더 탐색, 빈 결과, 로딩 및 오류 표시가 유지된다.
- 관련 테스트와 프런트엔드 빌드가 통과한다.
- 브라우저 검증 결과가 결과 문서에 남는다.

상세 단계는 [구현 계획](../../superpowers/plans/2026-10-26-community-archive-grid-fill-height.md)을 따른다.
