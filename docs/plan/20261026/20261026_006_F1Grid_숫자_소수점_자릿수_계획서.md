# F1-Grid 숫자 소수점 자릿수 계획서

## 목표

기존 `decimalPlaces` 컬럼 옵션을 유지하면서, 일반 숫자 및 소수 컬럼의 미지정 기본 표시를 최대 5자리의 선택 소수 표시로 변경한다.

## 범위 및 파일

- `frontend/src/shared/components/f1-grid/utils/grid.utils.ts`: 화면 숫자 표시의 기본 최대 소수 자릿수를 3에서 5로 변경한다. 기본 최소 소수 자릿수 0과 명시 `decimalPlaces`의 고정 표시 동작은 유지한다.
- `frontend/src/shared/components/f1-grid/export/GridExcelExport.ts`: 기본 숫자 엑셀 서식을 `#,##0.###`에서 `#,##0.#####`로 맞춘다. 명시 정밀도 및 통화 기본 서식은 보존한다.
- `frontend/tests/f1-grid-date-format.test.tsx`: 기본 정수/소수/반올림 및 명시 자릿수 표시 회귀 테스트를 추가한다.
- `frontend/tests/f1-grid-excel-export.test.ts`: 기본 숫자 엑셀 서식의 회귀 테스트를 추가한다.
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`, `frontend/src/pages/f1-grid-docs/data/f1GridApiReference.ts`, `frontend/src/pages/f1-grid-docs/data/f1GridDocs.ts`: 옵션 기본값과 예시 설명을 갱신한다.
- `docs/result/20261026/f1-grid-number-decimal-precision/`: 결과 문서 및 브라우저 스크린샷을 생성한다.

## 구현 절차

1. 화면 표시 테스트에 `number`/`decimal`의 기본 선택 소수점, 정수, 5자리 반올림, 명시 고정 자릿수 사례를 추가한다.
2. 해당 단일 테스트 파일을 실행하여 기본 최대값이 현재 3자리인 이유로 신규 기본값 사례가 실패하는 것을 확인한다.
3. `grid.utils.ts`의 두 기본 `maximumFractionDigits` 경로를 5로 변경하고, 화면 표시 테스트를 통과시킨다.
4. 엑셀 테스트에 미지정 숫자 컬럼을 추가하고 기본 `numFmt`가 `#,##0.#####`인지 검증한다.
5. 해당 테스트를 먼저 실행해 현재 `#,##0.###` 서식과의 차이로 실패하는 것을 확인한다.
6. `GridExcelExport.ts`의 미지정 숫자 기본 서식을 최대 5자리 선택 표시로 변경하고 테스트를 통과시킨다.
7. F1-Grid 문서의 기본 숫자 자릿수 설명을 최대 5자리로 변경하고, `decimalPlaces` 명시 시 고정 표시 및 통화 예외를 설명한다.
8. 브라우저에서 숫자 표시를 확인하고 영문 소문자/숫자/하이픈 경로 아래 결과 문서와 스크린샷을 저장한다.

## 검증

```powershell
cd frontend
npm run test -- tests/f1-grid-date-format.test.tsx tests/f1-grid-excel-export.test.ts
npm run build
```

- 기대 결과: 지정한 두 Vitest 파일 모두 통과하고 TypeScript/Vite 프로덕션 빌드가 성공한다.
- 브라우저에서 정수, 1자리 소수, 5자리 초과 소수, 명시 자릿수 및 통화 표시를 확인한다.
- 저장소에 이미 존재하는 다른 미커밋 변경은 수정하거나 스테이징하지 않는다.
