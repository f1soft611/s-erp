## 변경 대상

- `frontend/src/shared/components/master-picker/MasterPicker.tsx`:
  선택 필드와 버튼의 크기/표현을 통일한다.
- `frontend/src/shared/components/master-picker/MasterPickerDialog.tsx`:
  `CommonDialog` 적용, 검색 영역 및 결과 항목의 시각 표현을 정돈한다.
- `frontend/tests/master-picker.test.tsx`:
  40px 높이 및 공통 다이얼로그 사용과 기존 검색/선택 상태를 검증한다.
- 날짜별 결과 문서와 영문 슬러그 경로의 화면 캡처를 작성한다.

## 실행 절차

1. picker 테스트에서 컨트롤 높이와 공통 다이얼로그 렌더링을 확인한다.
2. 기존 검색·선택 로직은 유지하고 두 picker UI에 공통 디자인을 적용한다.
3. 관련 picker 및 수주등록 테스트와 프론트엔드 빌드를 실행한다.
4. 기존 S-ERP 브라우저 서버를 확인한 뒤 세 뷰포트에서 거래처/품목 도움창을
   열고 정렬, 잘림, 페이지 가로 overflow를 확인해 캡처한다.
5. 실제 확인 결과와 인증/테스트 환경을 결과 문서에 기록한다.

## 완료 기준

- picker 관련 회귀 테스트와 빌드가 통과한다.
- 375px, 768px, 1280px에서 도움창 및 입력 컨트롤이 잘리지 않고 표시된다.
- 결과 문서에 실제 브라우저 확인 내용 및 캡처 경로가 포함된다.
