## 변경 대상

- `frontend/src/pages/sales/order/create/SalesOrderCreatePage.tsx`: 기본정보
  그리드를 xs 1열, sm 2열, lg 4열로 맞춰 승인된 필드 순서를 데스크톱
  두 행으로 표시한다. 비고는 sm 이상에서 전체 행을 차지한다.
- `frontend/src/shared/components/master-picker/MasterPicker.tsx`: 거래처
  입력 옆 선택 버튼만 40px 높이로 맞춘다.
- `frontend/tests/master-picker.test.tsx`: picker 버튼의 높이 회귀 테스트를
  추가한다.
- `docs/spec/20261026/20261026_010_수주등록_레이아웃_개선_상세사양서.md` 및
  날짜별 결과 문서/스크린샷: 검증 계약과 결과를 기록한다.

## 실행 절차

1. picker 버튼의 40px 높이를 검증하는 실패 테스트를 먼저 추가하고 실행한다.
2. picker 버튼 높이와 수주 기본정보 그리드 breakpoint만 최소 수정한다.
3. picker, 수주등록 페이지, 스크롤 테스트를 실행한다.
4. 프론트엔드 빌드를 실행한다.
5. 실제 브라우저에서 375px, 768px, 1280px의 정렬 및 overflow를 확인하고
   결과 스크린샷을 저장한다.
6. 상세사양서와 결과 문서를 실제 확인 결과에 맞춰 갱신한다.

## 완료 기준

- 승인된 필드 행 순서와 picker 버튼 높이가 구현된다.
- 기존 수주등록 동작을 검증하는 집중 테스트와 빌드가 통과한다.
- 세 가지 뷰포트에서 브라우저 렌더링을 확인하고 결과 문서를 남긴다.
- 저장 API, 데이터 계약, 상세 그리드 동작에는 변경이 없다.
