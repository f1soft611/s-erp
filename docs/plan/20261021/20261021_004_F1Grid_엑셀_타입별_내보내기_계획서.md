# F1-Grid 엑셀 타입별 내보내기 구현 계획

## 목표

F1-Grid의 현재 ExcelJS 내보내기에서 컬럼 `type`에 맞는 Excel 셀 타입과 표시 서식을 적용한다.

- [설계 문서](../../superpowers/specs/2026-10-21-f1-grid-excel-export-types-design.md)

## 변경 대상

- `frontend/src/shared/components/f1-grid/export/GridExcelExport.ts`: 값 타입 변환, Excel number format 적용, 다운로드
- `frontend/src/shared/components/f1-grid/utils/grid.utils.ts`: date 표시 및 Excel 내보내기에서 공유할 안전한 날짜 파싱
- `frontend/tests/f1-grid-excel-export.test.ts`: 실제 `.xlsx`의 셀 타입/값/서식 회귀 테스트
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`: Excel 내보내기 계약 설명
- `docs/spec/20261021/20261021_004_F1Grid_엑셀_타입별_내보내기_상세사양서.md`: 상세 동작 및 검증 기준
- `docs/result/20261021/f1-grid-excel-export-types/`: 결과 보고서와 브라우저 스크린샷

## 구현 순서

1. ExcelJS로 생성된 파일을 캡처해 재로딩하는 실패 테스트를 추가한다.
2. 유틸리티에서 날짜 파싱/검증을 추출해 화면 표시와 export가 동일한 date-only 계약을 공유하게 한다.
3. exporter에 numeric/date/datetime/time/checkbox 타입 변환과 Excel number format을 추가한다. 다른 타입의 기존 표시 텍스트, 빈 셀 및 원문 fallback, visible rows/columns, 다운로드 흐름을 유지한다.
4. 상세 사양서와 F1-GRID 문서를 갱신하고, 실제 브라우저의 F1-Grid 내보내기 화면을 결과 스크린샷으로 남긴다.
5. 새 export 테스트, 기존 날짜/Grid 관련 테스트 및 `npm run build`를 실행하고 결과 문서를 기록한다.

## 검증

```powershell
cd frontend
npm run test -- tests/f1-grid-excel-export.test.ts
npm run test -- tests/f1-grid-date-format.test.tsx tests/f1-grid-docs.test.tsx
npm run build
```

테스트는 numeric/date/Boolean/text 셀 타입, 소수·통화·날짜 표시 서식, date-only timezone 경계, 빈 값 및 변환 불가 원문 보존을 실제 `.xlsx` 재로딩으로 확인한다. 백엔드와 DB 검증은 범위 밖이다.

## 기준 테스트 상태 (2026-10-21)

- `f1-grid-date-format.test.tsx`: 23개 통과.
- `f1-grid-docs.test.tsx`: 기준 테스트 실행에서 통과.
- 넓은 `f1-grid.test.tsx`: 단독 실행에서도 156개 중 46개 실패가 재현되었다. 현재 DOM role/레이아웃 동작과 일치하지 않는 테스트 기대 및 일부 깨진 한국어/통화 문자열이 확인되었다.
- `f1-grid-context-menu.test.tsx`: 31개 중 2개 실패가 재현되었다. `F1Tree`가 내부 Grid에 정렬/필터 비활성화를 전달하지만 해당 테스트는 트리에서 해당 메뉴를 기대한다.
