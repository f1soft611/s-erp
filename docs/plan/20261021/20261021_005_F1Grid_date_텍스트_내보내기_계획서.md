# F1-Grid date 텍스트 내보내기 계획서

## 목표

`type: 'date'` 컬럼은 Grid 표시 문자열로 출력하고, Excel 헤더·데이터 정렬을 Grid의 명시 설정과 기본값에 맞춘다.

## 파일별 책임

- `frontend/src/shared/components/f1-grid/export/GridExcelExport.ts`: date 값을 기존 Grid 표시 함수로 문자열화하고 헤더/본문 셀의 Grid 수평 정렬을 적용한다.
- `frontend/tests/f1-grid-excel-export.test.ts`: XLSX 재로딩 후 문자열 값, 빈/잘못된 날짜 fallback, 명시 및 기본 헤더/셀 정렬, 다른 typed 셀의 기존 타입을 확인한다.
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`: date export의 텍스트/정렬 계약을 설명한다.
- `docs/result/20261021/f1-grid-date-export-text/result.md`: 변경 및 검증 결과를 기존 Excel export 스크린샷과 함께 기록한다.

## 실행 순서

1. 테스트에서 기존 Date 값/날짜 number format 기대를 Grid 형식 문자열로 바꾸고 헤더와 본문의 명시/기본 정렬 및 빈 날짜 셀 사례를 추가한다.
2. export 테스트만 실행해 현재 구현이 Date 값과 Grid 정렬 부재로 실패하는지 확인한다.
3. exporter에서 date 타입 값을 `getCellDisplayValue` 결과로 저장하고 모든 헤더/데이터 셀에 Grid `headerAlign`/`align` 및 해당 기본 정렬을 설정한다. 빈 셀도 같은 열 정렬을 유지한다.
4. export 테스트를 재실행하고 date formatting 및 F1-GRID 문서 테스트를 함께 확인한다.
5. F1-GRID 문서와 결과 문서를 갱신한다.
6. 프론트엔드 빌드를 실행하고 diff/status를 확인한다. 작업 범위 밖 변경은 보존한다.
