# 문서 결재 액션 더보기 메뉴 작업 결과

## 작업 내용

- 문서관리 피드와 상세 툴바에서 승인·반려·보완요청 등 결재 액션을 직접 노출하지 않고, `문서 더보기` 메뉴의 첫 그룹으로 이동했습니다.
- 결재 액션 그룹 뒤와 수정·삭제 그룹 앞에 필요한 구분선을 표시하고, 비어 있는 그룹의 구분선은 생략합니다.
- 기존 권한 판정, 확인/사유 대화상자, 성공·오류 처리와 처리 의견 입력은 유지했습니다.
- 메뉴 순서와 피드·상세 처리 흐름을 회귀 테스트에 반영했습니다.

## 검증 결과

- `tests/document-link-sharing.test.tsx`: 19개 통과
- `tests/document-write-page.test.tsx`의 결재 메뉴 및 액션 관련 선택 테스트: 21개 통과
- `tests/document-write-page.test.tsx` 전체: 155개 중 114개 통과, 41개 실패. 실패에는 페이지네이션 응답을 기대하는 기존 테스트 픽스처 불일치와 상세·피드 콘텐츠 조회 실패가 포함됩니다. 메뉴·결재 액션 선택 테스트는 독립 실행 시 통과했습니다.
- `node tests/document-approval-actions-menu.browser.mjs`: 375px, 768px, 1280px에서 피드·상세 메뉴와 구분선 확인
- 프론트엔드 빌드: `npm run build` 통과
- 변경 파일 lint: 통과. `DocumentApprovalDetailFeed.tsx`의 기존 effect 상태 설정 경고 5건이 출력됩니다.
