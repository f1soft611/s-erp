# F1-Grid Excel 정수 표시 서식 보정 결과

## 반영 내용

- 원인: 기본 숫자 서식 `#,##0.#####`는 Excel에서 정수 값도 `4.`로 표시했다.
- 기본 `number`/`decimal` 컬럼은 숫자로 변환된 값이 정수일 때 `#,##0`, 소수값일 때 기존 `#,##0.#####`를 셀별로 적용한다.
- 명시 `decimalPlaces`와 통화 서식, 숫자값 및 다른 셀 타입은 변경하지 않았다.
- F1-GRID 문서의 일반 숫자/Excel 서식 계약을 갱신했다.

## 검증

| 검증 | 결과 |
|---|---|
| 실패 회귀 테스트 사전 실행 | 정수 숫자 문자열이 `#,##0.#####`를 받아야 할 `#,##0`와 달라 실패 |
| Excel export 및 F1-GRID 문서 테스트 | 31개 통과 |
| Excel COM 실제 서식 표시 | 정수 `4`는 `4`, 소수 `4.2`는 `4.2`로 표시 |
| 프론트엔드 빌드 | 통과 |
| 변경 TypeScript 파일 lint | 통과 |
| `git diff --check` | 통과 |

화면 레이아웃 변경이 없어 브라우저 스크린샷 대상이 아니다. 실제 Excel에서 정수·소수 형식 표시를 확인했다.

## 범위

공통 F1-Grid Excel exporter, 해당 테스트, F1-GRID 문서와 날짜별 작업/계획/사양/결과 문서만 변경했다. 백엔드/API/DB 및 기존 작업 트리 변경은 건드리지 않았다.
