# 문서작성 시스템 메시지 상태 배지 크기 조정 결과

## 변경 내용

- 문서작성 피드/상세에서 공통으로 사용하는 시스템 이벤트 배지의 글자 크기를 작성자 이름과 같은 `12px`로 줄였다.
- Chip 높이를 `20px`, 좌우 라벨 여백을 `6px`로 줄였다.
- 기존 색상, variant, `8px` 모서리, 이벤트 이름, 일반 댓글 및 공지사항 동작은 유지했다.
- 변경 파일: `frontend/src/shared/components/feed/TiptapCommentThread.tsx`, `frontend/tests/feed-components.test.tsx`.

## 원인 및 해결

- 기존 MUI small Chip의 기본 높이/라벨 글자 크기가 작성자 이름보다 커 댓글 헤더에서 상태 배지가 더 두드러졌다.
- 시스템 이벤트에만 적용되는 Chip 스타일로 크기를 축소해 다른 댓글과 공유 UI의 크기는 바꾸지 않았다.

## 검증

- 구현 전 크기 assertion 9개가 기존 Chip 높이 `24px`로 실패하는 것을 확인했다.
- `feed-components.test.tsx` 전체 47개 테스트 통과.
- `npm run build` 통과.
- 4173에서 기존 Vite 서버를 재사용해 합성 시스템 댓글을 실제 Chromium에서 확인했다. 375px, 768px, 1280px 모두 배지 높이 `20px`, 글자 크기와 작성자 글자 크기 `12px`, 좌우 패딩 `6px`, 모서리 `8px`, 가로 넘침 없음, 브라우저 오류 없음.
- 취소 배지의 기존 error 글자색과 outlined 테두리색도 유지됨을 확인했다.
- 실제 계정/테넌트 데이터는 사용하지 않았다. 기존 Vite 서버는 종료하지 않았다.
