# 현황 검색결과 안내 및 통합검색 강조 결과 보고서

## 변경 내용

- 문서현황과 수주현황에 성공한 조회의 0건 안내 및 결과 건수 안내를 공통 `SearchResultMessage`로 표시하도록 변경했다. 안내는 정보성 status 메시지로 X 닫기를 제공하며, 검색 조건 초기화 버튼은 제공하지 않는다.
- 메시지를 닫은 뒤 다음 조회가 성공하면 다시 나타나도록 조회 상태에 따라 컴포넌트를 마운트한다. 조회 전·로딩 중·오류 상태에는 표시하지 않는다.
- `PageMessageArea`의 기본 오류 여백은 유지하면서 결과 안내에만 compact 간격을 적용했다. wrapper 위쪽은 8px, 아래쪽은 0px로 하고 그리드의 기존 위쪽 8px과 합쳐 안내 아래도 8px이 되도록 했다.
- 통합검색 결과 설명에서도 기존 안전한 React `<mark>` 강조를 사용해 검색어 일치 텍스트를 강조한다.
- 합성 응답으로 두 현황 화면과 통합검색을 375px, 768px, 1280px에서 확인하고 스크린샷을 저장했다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| Vitest: 관련 6개 파일 | 통과, 123개 테스트 |
| `npm run build` | 통과 |
| `npm run lint` | 통과(종료 코드 0, 경고 출력됨) |
| `node .\tests\search-result-notice.browser.mjs` | 통과. 375px/768px/1280px에서 두 현황 화면의 안내 간격·닫기 후 재조회 및 통합검색 제목/설명 강조 확인 |
| `git diff --check` | 통과 |

브라우저 검증은 테스트용 합성 계정과 API 응답만 사용했으며 실제 사용자 데이터는 캡처하지 않았다.
