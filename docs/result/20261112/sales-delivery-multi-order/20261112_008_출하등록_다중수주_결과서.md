## 변경 내용

- 수주 도움창에 별도 체크박스 선택 열, 병합된 수주번호, 표시용 계획번호를 제공한다. 계획번호 클릭 대신 하단 `선택` 버튼으로 처리한다.
- 체크된 수주가 속한 모든 계획 상세를 출하 상세로 불러오며, 같은 거래처의 수주만 함께 등록할 수 있다.
- 헤더에는 첫 수주 ID를 대표값으로 저장하고 상세행마다 실제 수주 ID를 보존한다. 저장·수정·삭제 시 주문별 수량 누계를 조정하고, 현황 행별 수주번호도 상세 기준으로 조회한다.
- 상세-헤더 대표 수주 FK만 제거하는 `20261112_008` migration과 다중 수주 상세가 있으면 중단하는 rollback을 작성했다. 상세별 수주·계획 FK는 유지하며 DB에는 적용하지 않았다.

## 검증

- `frontend`: 출하 화면/API 테스트 28건 통과, `npm run build` 통과.
- `backend`: 서비스·매퍼·스키마 계약 테스트 32건 통과.
- Orca 브라우저에서 수주 선택 도움창을 375/768/1280px로 확인했다. 각 화면에서 문서 전체 가로 넘침은 없었고 375px에서는 전체 화면 도움창, 768/1280px에서는 화면 안에 맞는 대화상자로 표시됐다. 실제 조회 데이터가 없어 캡처에는 빈 결과가 표시된다.
- 기본 PostgreSQL MCP에서 출하 헤더/상세 컬럼과 외래키 메타데이터를 확인했다. 상세 `sales_order_id`, 제거 대상 `fk_sales_delivery_dt_hd_order`, 유지할 상세별 수주/계획 외래키를 확인했고 데이터 행은 조회하지 않았다.
