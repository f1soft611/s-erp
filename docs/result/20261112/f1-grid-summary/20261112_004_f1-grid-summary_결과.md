# F1-Grid 집계 작업 결과

## 변경

- `features`의 `summary`를 상단 또는 하단에 표시하고 컬럼별 `sum`, `average`, `min`, `max`를 지원한다.
- 수주등록 상세 그리드의 주문수량, 공급가, 부가세, 라인합계에 상단 합계를 적용했다. 수주현황의 공유 상세 폼에도 동일하게 적용된다.
- 삭제 행은 제외하고 현재 필터 결과를 집계한다. 서버 데이터 소스는 현재 로드된 행만 집계한다.
- DB/API 변경은 없다.
