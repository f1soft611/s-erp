# 20261112_009 출하계획 품목기준 연계 작업 결과

## 작업 결과

- 계획 원본은 수주상세 품목 행, 출하 원본은 출하계획상세 품목 행으로 선택한다.
- 출하 도움창은 체크된 `salesDeliveryPlanDetailId` 행만 전달한다. 같은 수주·계획의 미선택 형제 행은 자동 추가하지 않는다.
- 잔량이 0 이하인 계획상세는 출하 선택창에서 제외하며, 서로 다른 거래처 선택은 창을 유지하고 오류를 표시한다.
- 여러 계획의 품목을 한 출하로 선택할 수 있고, `DIRECT`, 부분 출하, WARN 확인·재시도 동작은 유지했다.
- 출하계획현황은 계획상세별 행으로 표시한다. 거래명세서 기능은 범위에서 제외했다.

상세 기준은 [승인 상세사양서](../../../spec/20261112/20261112_009_출하계획_품목기준_연계_상세사양서.md)와 [구현 체크리스트](../../../superpowers/plans/2026-11-12-sales-delivery-item-level-implementation.md)를 따른다.

## DB 및 마이그레이션

- DB MCP의 `list_tables`, `describe_table`, 제한된 `information_schema` 제약 메타데이터 조회 결과를 기준으로 계획 헤더/상세 관계를 확인했다. 업무 데이터 행은 조회하지 않았다.
- 전방·롤백 스크립트와 변경 이력은 [docs/database](../../../database/20261112/20261112_009_change_multi_order_sales_delivery_plan_schema.md) 및 `backend/DATABASE/20261112`에 쌍으로 관리한다.
- 이번 작업에서 DDL은 적용하지 않았다. 롤백은 다중수주 계획이 없고 단일 원 수주를 복구할 수 있는 경우에만 가능하다.
- 거래명세서 테이블·화면·데이터는 변경하지 않았다.
