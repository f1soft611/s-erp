# 구매요청현황 화면 작업 결과

## 작업 내용

- `구매관리 > 구매요청현황` 메뉴 seed를 작성했습니다(테넌트 1, READ/EXCEL, 역할 권한은 수주현황에서 복사).
- 백엔드 `egovframework.let.materials.request.status`: `GET /api/v1/materials/purchase-request-status`. 헤더+상세를 품목 행 단위로 펼쳐 조회하며, 테넌트·사용 중(`use_at = 'Y'`) 조건을 항상 붙입니다. 검색: 빠른 검색, 구매요청번호, 요청일, 요청자, 상태, 품목, 요청납기일, 사용용도.
- 프론트 `pages/materials/request/status`: 수주현황과 같은 구성입니다.
  - 검색 영역(검색 기본값: 요청일 최근 1개월)
  - 병합 F1-Grid
  - 구매요청번호 클릭 시 상세 패널
  - 더보기 메뉴의 자세히보기/수정 → 구매요청등록 화면을 띄우는 다이얼로그
- 상태는 한글 라벨로 표시하며 `CONFIRMED`(확정)는 수정 메뉴를 숨깁니다. 수정 메뉴는 구매요청등록 메뉴의 UPDATE 권한이 있을 때만 보입니다.
- 사양 대비 변경: 그리드 하단 합계는 F1-Grid에 합계 행 기능이 없어 두지 않았습니다(사양서 반영).

## 검증 결과

- 백엔드 새 테스트 4개 통과(검색 조건 정규화, 날짜 범위 검증, Mapper 테넌트·삭제 제외·정렬, Controller 인증).
- 프론트 새 테스트 3개 통과(검색값→API 파라미터, 목록·상세 패널·수정 메뉴, 확정 건 수정 숨김). `npm run build` 통과.
- 브라우저 `node tests/purchase-request.browser.mjs`: 375/768/1280px에서 목록 → 상세 패널 → 수정 다이얼로그 흐름 확인, 콘솔 오류 없음.
- 백엔드 전체 테스트 결과와 환경 참고 사항은 [구매요청등록 결과](../purchase-request-create/20261112_002_구매요청등록_화면_및_DDL_결과.md)를 참고하세요.
