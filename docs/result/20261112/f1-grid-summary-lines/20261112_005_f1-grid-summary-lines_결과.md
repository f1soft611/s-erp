# F1-Grid 집계 컬럼 경계선 정렬 결과

## 원인과 수정

- 집계 셀의 오른쪽 테두리와 헤더·본문 셀의 왼쪽 테두리가 다른 픽셀에 그려져 세로선이 어긋났다.
- 집계 셀이 본문과 같은 왼쪽 테두리, `columnLine` 설정 및 셀 여백을 사용하도록 수정했다. 모바일 행 폼 열에도 같은 경계를 적용했다.
- 수주 상세의 현재 하단 집계 설정은 유지했다.

## 검증

- 집계 행의 상단·하단과 `columnLine` 활성·비활성 회귀 테스트로 테두리 방향을 비교했다.
- Playwright 합성 데이터로 열 너비 변경 후 375/768/1280px에서 스크롤 전후 전체 컬럼의 헤더·집계·본문 위치와 테두리, 셀 여백을 비교했다. 모바일 행 폼 열도 확인했다.
- 프론트엔드 빌드와 변경 파일 lint를 확인했다.
- 화면: [375px](screenshots/sales-order-summary-375.png), [768px](screenshots/sales-order-summary-768.png), [1280px](screenshots/sales-order-summary-1280.png).
- DB/API 변경은 없다.
