# 수주·출하 흐름 데이터 초기화 작업 결과

## 결과

지정한 `tenant_id`에 한정해 수주, 출하계획, 출하등록 및 연결 거래명세서와 구매요청 문서를 초기화하는 PostgreSQL 스크립트를 작성했다. 구매확정은 삭제 대상 요청이 참조한 헤더 중 남은 구매요청 상세가 없는 경우에만 삭제한다.

운영자가 출력된 건수를 확인할 수 있도록 했으며 기본 마지막 명령은 `ROLLBACK`이다. 실제 데이터 초기화는 실행자가 사전 백업을 확인하고 마지막 명령을 명시적으로 `COMMIT`으로 바꾸어 수행해야 한다. 커밋 후 데이터 복원용 SQL은 없으며 백업 복원이 필요하다. PK와 문서번호 시퀀스는 유지한다.

## DB 근거와 안전 범위

- `s-erp-postgresql-readonly` MCP로 관련 테이블 목록, 헤더/상세 컬럼, FK 및 삭제 규칙을 확인했다. 업무 데이터 행이나 테넌트 개인정보는 조회하지 않았다.
- SQL은 주문 상세, 계획/출하 상세, 거래명세서 상세, 구매요청 문서 참조를 자식부터 처리하고 마지막에 수주 헤더를 삭제한다. 삭제는 모두 입력한 tenant 범위로 제한된다.
- 마스터, 타 테넌트 데이터, 무관한 구매요청·구매확정, PK/문서번호 시퀀스는 변경하지 않는다.
- 이 작업에서는 DB에 SQL을 적용하지 않았고, 스키마도 변경하지 않았다. UI 작업이 아니므로 스크린샷은 해당되지 않는다.
