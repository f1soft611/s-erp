# 수주현황 및 엑셀 집계 결과

- 수주현황 하단에 주문수량, 공급가, 부가세, 합계의 합계를 표시했다. 단가 등 다른 컬럼은 집계하지 않는다.
- F1-Grid 엑셀 내보내기에 화면과 같은 필터·표시 컬럼 및 현재 로드 행 기준 집계를 추가했다. 상단 집계는 헤더 아래, 하단 집계는 데이터 아래에 숫자와 숫자 서식으로 저장하며 수식은 사용하지 않는다.
- 백엔드 및 DB 변경은 없다.

## 검증

- 집계, 엑셀 내보내기, 수주현황 테스트: 28개 통과.
- 브라우저에서 375/768/1280px 화면, 필터 적용 후 집계 및 다운로드된 엑셀의 네 숫자 셀과 서식을 확인했다. 브라우저 데이터는 테스트 fixture다.
- 프론트엔드 빌드와 변경 파일 대상 lint 통과.
- 추가 컨텍스트 메뉴 테스트는 33개 중 3개 실패: 가상 행 삽입 스크롤 기대값 불일치, 트리 정렬 및 필터 메뉴 미노출. 트리의 정렬·필터 비활성화 설정은 기존 HEAD에도 존재한다. 스크롤 실패 원인은 별도 확인이 필요하다.
- 전체 lint는 기존 `tests/common-code-management-page.test.tsx:53`의 조건부 Hook 오류로 실패했다.
