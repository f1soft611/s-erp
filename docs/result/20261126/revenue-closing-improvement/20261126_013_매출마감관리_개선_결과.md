# 매출마감관리 개선 결과

## 요청
1. 출하번호·수주번호 클릭 시 우측 상세
2. 상세검색 거래처 도움창을 출하등록이 된 거래처만 조회하고, 거래처별 마감/미마감 건수 표시

## 변경
- 프론트: 그리드 출하번호/수주번호 링크(underline hover) → `RevenueClosingSourcePanels`가 출하 상세·수주 상세 패널(조회 전용, 자세히보기 포함)을 우측에 표시. 둘은 동시에 열리지 않음
- 프론트: 거래처 도움창 검색을 `searchRevenueClosingCustomers`로 교체(기존 전체 거래처 마스터 조회 제거). 도움창 항목에 기존 추가정보(사업자번호·대표자명)와 마감/전체 건수를 함께 표시(마스터 조회 실패 시 건수만 표시)
- 백엔드: `GET /api/v1/sales/revenue-closings/customers`(조회 권한 필요) 및 `selectCustomerOptions` 추가 — 현재 상세검색의 출하일 기간 내 사용 중인 출하(`use_at='Y'`)가 있는 거래처만, 코드/명 키워드 필터
- 도움창 항목 아래 새 줄에 `마감 마감건수/전체건수`(예: 마감 1/4)로 간단 표시. 마감건수는 녹색, 미마감이 남으면 전체건수는 주황색(공통 `progress` 옵션)
- 거래처 다중선택 도움창(MasterPickerDialog) 버튼 순서를 수주 선택 도움창과 같게 `적용`, `취소` 순으로 변경
- 백엔드: 상세 조회에 `salesOrderId` 추가(수주 상세 연결용). DB 스키마 변경 없음

## 정책 결정
- 거래처 도움창의 대상 기간은 상세검색의 출하일 입력값(미적용 초안 포함)을 따름. 기간이 유효하지 않으면 도움창에서 오류 표시

## 검증
- `npm run test -- tests/sales-revenue-closing-page tests/revenue-closing` 통과(링크→패널 신규, 거래처 도움창 테스트 갱신)
- `tsc --noEmit` 오류 없음, `mvn test -Dtest='RevenueClosing*Test'` 통과
- 미수행: DB MCP 조회, 브라우저 스크린샷
