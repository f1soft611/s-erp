# 출하등록/출하현황 개선 결과

## 요청 (영업관리 > 출하)
1. 출하 기본정보 배송방법을 공통코드(`SALES_DELIVERY_METHOD`) 선택으로 변경
2. 출하상세 그리드에서 `행` 컬럼 제거, `연결 수주번호` 컬럼 추가, 수주등록처럼 하단 summary 추가
3. 출하현황에서 연결 수주번호 클릭 시 페이지 이동 없이 우측에 수주 상세 패널 표시
4. 출하현황 그리드에 하단 summary 추가

## 변경
- 백엔드: `SalesDeliveryDetailVO.orderNo` 추가, `selectDeliveryDetails`에 `tb_sales_order_hd` LEFT JOIN (스키마 변경 없음, SQL 스크립트 불필요)
- 프론트 등록: 배송방법 select(수주 공통코드 훅 재사용), 상세 그리드 `행` 제거/`연결 수주번호` 추가/summary(수량·공급가·VAT·합계 sum)
- 프론트 현황: 연결 수주번호 링크 → 수주현황 상세 패널·자세히보기 재사용(조회 전용), 출하 상세와 동시에 열리지 않음, summary 추가, 상세 패널 배송방법은 공통코드 라벨 표시
- 현황 그리드의 `행` 컬럼은 요청 범위(출하상세=등록 화면)가 아니므로 유지
