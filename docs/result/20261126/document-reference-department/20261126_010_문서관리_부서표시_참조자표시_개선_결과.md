## 변경 내용

- 백엔드: `selectApprovalLines`, `selectApprovalLinesByOwnerIds`가 `tb_department`를 조인해 현재 부서명을 우선하고 저장된 복사본을 대체값으로 사용. DB 스키마 변경 없음.
- 작성 화면: 참조자 칩 3개 + `+N명`, `참조 N명 보기` 목록 다이얼로그(검색·부서별 묶음·개별/전체 삭제). `UserSelectEditor`에 `maxVisibleChips`, `onOverflowClick` 옵션 추가(기본값은 기존 동작).
- 문서 상세: 참조자 5명까지 표시, 초과 시 `전체 N명 보기`로 부서별 펼침(최대 높이 320px 스크롤). 별도 요약 줄은 사용자 지시로 제외.
