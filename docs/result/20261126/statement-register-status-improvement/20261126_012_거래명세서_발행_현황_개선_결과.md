# 거래명세서 발행/현황 개선 결과

## 요청
1. 출하번호 도움창을 다른 도움창(수주 선택)과 동일한 구조(PageSearchArea dialog)로 변경
2. 거래명세서 상세 NO 컬럼 제거, 하단 합계(공급가/부가세/총 합계) 및 grid summary 추가
3. 현황 명세번호 링크 밑줄 제거(hover만), 출하번호 클릭 시 우측 출하 상세, 현황 summary 추가

## 변경
- `StatementSourcePicker`: PageSearchArea(mode=dialog) + 빠른검색(Enter 조회), 래퍼/간격을 SourceOrderPicker와 통일
- `StatementDetailGrid`/컬럼: No 제거, 품목명 왼쪽 정렬, 수량·공급가·VAT·합계 summary, 페이지 하단 합계 3종(등록 시 선택된 행 기준)
- 현황: 명세번호·출하번호 링크 `underline="hover"`, 출하번호는 행별 원천 출하(`sourceDeliveryId`) 기준으로 출하 상세 패널(조회 전용, 자세히보기 포함) 표시, 명세 상세와 동시에 열리지 않음, summary, No 컬럼 제거, 거래처명·품목명 왼쪽 정렬
- 백엔드: `selectStatus`에 `sourceDeliveryId` 추가, `sourceDeliveryNo/Dt`를 행별 출하 기준으로 변경(스키마 변경 없음)
