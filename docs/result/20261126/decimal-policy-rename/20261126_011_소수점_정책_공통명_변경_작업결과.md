## 변경 내용

- `sales.common.SalesDecimalPolicy` → `egovframework.com.cmm.DecimalPolicy`(`git mv`로 이력 유지).
- `from()` 두 개 제거. 영업 호출부(수주·견적·출하·출하계획·명세서 서비스)는 `DecimalPolicy.forModule("SALES", …)`를 쓴다. `co.master` 두 서비스는 기존대로 `forModule("COMMON", …)`.
- 정책 단위 테스트 `SalesDecimalColumnPolicyTest` → `com.cmm.DecimalPolicyTest`. 가드 테스트와 PostgreSQL 통합 테스트는 새 이름으로 갱신.
- 현재 지침 `backend/AGENTS.md`, `frontend/src/pages/f1-grid-docs/F1-GRID.md`의 클래스명 갱신. 과거 날짜별 문서는 이력이라 그대로 둔다.
- 동작·API·DB·SQL·프론트 화면 변경 없음. DB 변경이 없어 MCP 확인과 스키마 이력은 해당 없음.
