# 결과서

## 변경 결과

- `.github/hooks/force-doc-workflow.js`의 `additionalContext`에 `SKILL_APPLICATION_POLICY`를 추가했다.
- 정책은 적용 가능한 스킬·워크플로우를 작업 전 확인하도록 하고, 현재 환경의 스킬 로더·명령·도구·문서를 사용하도록 정의한다.
- 특정 모델명과 특정 스킬 도구명을 요구하지 않아, 다른 모델 환경에서도 동일한 절차 원칙을 적용할 수 있다.
- 기존 `UserPromptSubmit` 이벤트명과 JSON 출력 구조는 유지했다.

## 검증

- `node --check .github/hooks/force-doc-workflow.js` 성공
- Node 런타임에서 훅 출력을 JSON으로 파싱해 `UserPromptSubmit`, `SKILL_APPLICATION_POLICY`, 모델 독립 정책 문구 포함 여부 확인 성공

## 스크린샷

- 본 작업은 브라우저 화면이 없는 Node.js 프롬프트 훅 변경으로, 캡처할 UI가 없어 스크린샷을 생성하지 않았다.
