## 2026-08-27 편집 회귀 수정

- 원인: `commitEdit()`가 편집 전후 값 비교 없이 항상 `updateGridRow()`를 호출했다. 따라서 값을 바꾸지 않고 Enter로 편집을 끝내도 기존 행이 `updated` 상태가 되어 수정 건수가 증가했다.
- 수정: 편집값을 컬럼 타입에 맞게 정규화한 뒤 원본 값과 `Object.is()`로 비교한다. 값이 실제로 달라질 때만 행 상태와 변경분을 갱신한다.
- UI: 기본 `TextField` 대신 셀 높이와 글꼴을 따르는 테두리 없는 `InputBase`를 사용해 편집 시 중첩된 입력 박스가 보이지 않게 했다.
- 회귀 테스트: 값 변경 없이 Enter로 편집을 완료하면 `insertedRows`, `updatedRows`, `deletedRows`가 모두 비어 있는지 검증한다.

## 2026-08-27 에디터 확장

- `editing` 모듈에 text, number, date, select 에디터와 타입별 에디터 선택 컴포넌트를 분리했다.
- `utils` 모듈에 select label 표시와 Boolean/함수형 `editable` 판정을 분리했다.
- `date`는 `YYYY-MM-DD` 값을 표시 및 저장하고 네이티브 날짜 입력을 사용한다.
- `select`는 화면 또는 서비스가 전달한 `options` 배열을 사용하며, 비편집 상태에는 label을 표시하고 행 데이터에는 value를 저장한다.
- `editable`은 Boolean 또는 `(row) => boolean`을 받는다. 조건이 false인 행은 text/date/select 편집과 checkbox 변경이 비활성화된다.

## 2026-08-27 행 병합 확장
