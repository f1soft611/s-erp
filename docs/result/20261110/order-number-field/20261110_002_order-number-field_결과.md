# 모바일 수주번호 필드 크기 통일 결과

근거: [작업지시서](../../../directions/20261110/20261110_002_order-number-field_작업지시서.md), [계획서](../../../plan/20261110/20261110_002_order-number-field_계획서.md), [사양서](../../../spec/20261110/20261110_002_order-number-field_상세사양서.md).

## 원인과 변경

- 수주번호에만 모바일 글꼴 `0.75rem`이 지정되어 있었다. 375px 브라우저에서 수주번호는 12px/외곽 높이 34.25px, 견적번호·수주상태는 16px/40px로 재현했다.
- 수주번호의 개별 글꼴 재정의 5줄을 제거했다. 다른 필드와 동일한 공통 TextField 글꼴·높이를 사용한다. 공통 폼을 쓰는 조회·수정에도 적용된다.
- 읽기 전용, 자동 채번 안내와 저장 로직은 유지했다. 백엔드·API·DB 및 F1-Grid 동작 변경 없음.

## 검증

- `node scripts\capture-mobile-sales-grid.mjs`: 수정 전 필드 크기 불일치로 실패, 수정 후 통과.
- 375/768/1280px에서 수주번호·견적번호·수주상태의 실제 글꼴 크기·font-family·외곽 높이 일치 및 수주번호 읽기 전용을 확인했다.
- 같은 브라우저 회귀의 합성 데이터 등록·저장 요청, 합계, 행 폼, 모듈 바·내부 스크롤 검증도 통과했다. 실제 서버 저장이나 실기기 검증은 아니다.
- 수주 등록 Vitest 21개 중 20개 통과. 삭제 후 버튼 비활성화 테스트 1개는 변경 전 HEAD `f3248ac2`의 별도 복사본에서도 같은 `:509` assertion으로 실패했다. 관련 없는 기존 실패로 유지했다.
- 변경 파일 oxlint 오류 없음(기존 effect 경고 1개). 프로덕션 빌드 통과.
