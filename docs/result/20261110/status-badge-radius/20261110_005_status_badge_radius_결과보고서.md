# 상태 배지 색상 및 모서리 통일 결과보고서

## 작업 결과

- 문서 결재상태·업무구분 및 공지구분 배지의 의미 색상과 표시 형태를 통일했다. 문서현황 결재상태도 공통 결재 표시 메타데이터를 사용하도록 연결했다.
- 프런트엔드 직각형 UI의 모서리 반경을 6px 기준으로 정규화하고, 원형 요소와 0px 경계는 유지했다.
- 검색 결과 안내 배경이 페이지 캔버스와 거의 같은 밝기로 표시되던 원인은 MUI 정보성 Alert의 기본 배경색이 앱 기본 배경색과 근접했기 때문이다. 정보 색상 투명도를 라이트 모드 16%, 다크 모드 24%로 조정해 배경 구분을 높였다.
- `PageMessageArea`의 오류 및 검색결과 메시지 다음에 오는 콘텐츠 `Box`에서 상단 중복 패딩을 공통 제거해 화면별 메시지 아래 간격 편차를 줄였다. 수주현황의 화면별 조건부 패딩 보정은 제거하고, 출하계획 현황의 메시지 그룹 간격도 공통 8px 단위로 맞췄다.

## 검증

- Vitest 집중 검증: 52개 테스트 통과 (`sales-order-status-page`, `search-result-message`, `document-status-page`).
- 추가 집중 검증: 39개 테스트 통과 (`theme-radius`, `notification` 포함).
- 프런트엔드 빌드: `npm --prefix frontend run build` 통과.
- 변경 파일 Oxlint 검사 통과.
- `git diff --check` 통과. `frontend/src/App.css`에 LF→CRLF 작업 트리 경고가 출력됐다.
- 메시지 여백 집중 테스트: `notification`, `sales-order-status-page`, `search-result-message`, `document-status-page` 58개 통과.
- 출하/명세 화면 회귀 테스트: 41개 통과, 1개 실패. 실패는 출하계획 상세 그리드 행 높이 기대값(32px)과 계산값(28.8px) 불일치이며 메시지 여백 변경과 무관한 상세 그리드 치수 검증이다.
- Chromium 375px, 768px, 1280px에서 확인: 수평 overflow 없음, 정보 배경 `rgba(100, 120, 166, 0.16)`, 배지와 카드 모서리 6px.

## 전체 테스트 스위트 참고

전체 테스트 스위트는 413개 테스트 파일 중 310개 통과, 103개 실패했으며 전체 2,177개 테스트 중 1,895개 통과, 282개 실패했다. 실패는 기존 문서작성·그리드·메뉴관리 등 여러 화면의 테스트에 분포되어 있다. 예를 들어 `ApprovalNoticePanel` 날짜 표시 테스트는 현재 컴포넌트의 `일자`/기안일 표시와 테스트가 기대하는 `상신일`/대시 표기가 불일치하며, 해당 동작은 이번 스타일 변경 범위에 포함되지 않는다. 전체 저장소 lint도 기존 이슈가 있으나 변경 파일의 Oxlint 검사는 통과했다.
