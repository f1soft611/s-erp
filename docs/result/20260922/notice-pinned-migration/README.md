# 공지사항 중요 공지 상단 고정 전환 결과

## 변경 내용

- 공지 상태 계약을 `isNotice`/`is_notice`에서 `isPinned`/`is_pinned`로 전환
- DB 컬럼 변경 SQL과 rollback을 `backend/DATABASE/20260922` 및 `docs/database/20260922`에 기록
- 공지 검색 VO가 `ComDefaultVO`를 상속하고 `PaginationInfo`로 페이지 인덱스를 계산하도록 구현
- `ListResult<T>`의 `resultList`/`resultCnt` 목록 응답 패턴 추가
- 일반 피드와 상단 고정 피드를 같은 목록 API의 별도 조회로 분리
- 일반 피드를 20건 단위 무한 스크롤로 누적
- 작성/수정 모달의 중요 공지 및 고정 체크박스 제거
- 게시글 더보기 메뉴에 상단 고정/해제 아이콘과 기존 수정 API 기반 토글 추가
- 상단 고정 클릭 시 확인창을 표시하고 전용 `/posts/{postId}/pin` API로 상태만 갱신
- 상단 고정 게시글도 일반 피드와 동일한 카드 배경·상태 색상을 사용하도록 강조 배경을 제거
- 중요 공지 요약·색상·필터를 상단 고정 의미로 전환

## 검증

- `backend`: `mvn test` 성공, 120개 통과, 2개 스킵
- `frontend`: `npm run build` 성공
- 핵심 프론트 테스트 4개 파일, 21개 테스트 통과
- 고정 전용 API 서비스 테스트 3개 통과
- 기존 `notice-page-local-updates.test.tsx` 통합 테스트는 배열형 단일 조회 mock과 새 일반/고정 별도 조회 계약이 맞지 않아 실패가 남아 있다. 이 실패는 테스트 double 갱신이 필요한 잔여 항목으로 분리했다.
- 브라우저 캡처: 개발 서버의 기존 실행 실패로 이번 작업에서는 수행하지 못함

## 잔여 위험

- 기존 페이지 통합 테스트 일부는 과거의 배열형 서비스 mock과 화면 상태 가정에 의존해 전체 회귀 기준으로 별도 정리가 필요하다.
- 개발 서버가 기존 실행 환경에서 시작되지 않아 375px·768px·1280px 실제 브라우저 검증은 미완료다.
