# 공지사항 이전 댓글 조회 후 신규 댓글 순서 수정 결과

## 재현 조건

1. 공지사항에서 `이전 댓글 보기`를 클릭한다.
2. 새 댓글을 작성한다.
3. 재조회 전 화면에서 이전 댓글과 새 댓글의 표시 순서를 확인한다.

이전 댓글을 불러온 뒤 신규 댓글을 작성하면 재조회 전에는 댓글 순서가 뒤섞이고, 전체 재조회 후 정상화되는 현상을 대상으로 한다.

## 원인

`NoticeFeedList`의 댓글 병합 함수가 서버 목록 변경 시 `incoming`을 항상 앞에 두고 기존 로컬 댓글을 뒤에 병합했다. 이전 댓글이 로컬 상태에 보존된 상황에서 신규 댓글이 서버 목록에 추가되면, 오래된 댓글과 최신 댓글의 표시 순서가 서버 정렬 순서와 달라질 수 있었다.

## 수정 내용

- `mergeCommentTrees`에 병합 우선 순서를 명시하는 인자를 추가했다.
- 이전 댓글 조회 결과는 기존 댓글보다 앞에 병합한다.
- 서버 목록 갱신 시에는 보존된 이전 댓글을 먼저 두고 새 서버 댓글을 뒤에 병합한다.
- 중복 댓글과 답글 병합 동작은 기존처럼 ID 기준으로 유지한다.
