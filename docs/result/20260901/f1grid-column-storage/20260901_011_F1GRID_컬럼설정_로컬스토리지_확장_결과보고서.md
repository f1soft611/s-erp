## 변경 사항

- `columns/GridColumnManagement.ts`: `F1GridColumnStorageState` 타입 및 `parseGridColumnStorageState` 유틸 추가(`order`/`widths`/`hidden`/`pinned`).
- `core/F1Grid.tsx`: `columnOrder`/`columnWidths`/`hiddenColumnFields`/`pinnedFields` 초기값을 `storageKey` 저장 값에서 복원하고,
  네 state 중 하나라도 변경되면 `{ order, widths, hidden, pinned }` 형태로 `localStorage`에 단일 저장하도록 통합.
- `tests/f1-grid.test.tsx`: 기존 컬럼 순서 저장 테스트를 신규 객체 포맷에 맞게 수정하고,
  컬럼 너비/숨김 목록/고정(pin) 상태 저장·복원 테스트를 추가.

## 검증 결과

- `npm run test -- tests/f1-grid.test.tsx`: 89개 전부 통과(이전에 무관하게 실패하던 오버플로우 테스트도 해결됨).
- `npm run test -- tests/menu-management-f1-grid.test.tsx`: 34개 전부 통과.
- `npm run build`: 통과.

## 참고

- 저장 포맷이 배열(`string[]`)에서 객체(`{ order, widths, hidden, pinned }`)로 변경되어, 기존에 저장된
  구 포맷 값은 `parseGridColumnStorageState`가 `null`로 처리하고 기본값으로 대체된다(하위 호환 불필요, 당일 확장).
