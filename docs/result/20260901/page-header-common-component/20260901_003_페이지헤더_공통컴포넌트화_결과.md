## 조사 결과

공통 헤더 컴포넌트가 없었고, 아래 6개 페이지가 "좌측 브레드크럼+설명 / 우측 액션 버튼" 헤더 마크업을 개별적으로 중복 구현하고 있었습니다.

- [RoleManagementPage.tsx](../../../../frontend/src/pages/settings/system/roles/RoleManagementPage.tsx)
- [DocumentsPage.tsx](../../../../frontend/src/pages/groupware/DocumentsPage.tsx)
- [OverviewPage.tsx](../../../../frontend/src/pages/groupware/OverviewPage.tsx)
- [DashboardContent.tsx](../../../../frontend/src/pages/dashboard/components/DashboardContent.tsx) (fallback 화면)
- [F1GridTestPage.tsx](../../../../frontend/src/pages/settings/system/f1-grid-test/F1GridTestPage.tsx)
- [MenuManagementPage.tsx](../../../../frontend/src/pages/settings/system/menus/MenuManagementPage.tsx) (좌측 브레드크럼+설명, 우측 액션 버튼, 하단 필터까지 포함한 복합 헤더)

## 변경 내용

1. `frontend/src/shared/components/PageHeader.tsx` 신규 생성
   - `breadcrumbItems`(배열), `description`, `actionGroups`(옵션), `children`(옵션, 하단 필터 영역) props 지원
   - 기존 각 페이지의 헤더 스타일(px/py, 테두리, 배경 blur, overline 브레드크럼, body2 설명)을 그대로 이관
   - `actionGroups` 전달 시 우측에 `PermissionGroupActionBar` 자동 렌더
2. 위 6개 페이지의 중복 헤더 마크업을 `PageHeader` 사용으로 교체
   - `MenuManagementPage`는 `actionGroups={pageActionGroups}`와 `children`(모듈 선택 + 검색 필터)을 전달
   - 나머지 페이지는 `breadcrumbItems={[selectedModule.name, currentMenuName]} description={content.description}`만 전달
3. 사용하지 않게 된 `useTheme`/`isDark`, `PermissionGroupActionBar` 직접 import 등 불필요 코드 정리

## 검증

- `npm run build` → 성공 (TypeScript 컴파일 + Vite 빌드 통과)
- 관련 테스트 실행: `npm run test -- tests/menu-management-f1-grid.test.tsx tests/dashboard-data.test.tsx tests/f1-grid-test-page.test.tsx tests/role-management-notification.test.tsx tests/dashboard-sidebar.test.tsx`
  - 결과: 52개 중 51개 통과, 1개 실패
  - 실패 테스트(`MenuManagementPage module selection > shows the full saved menu hierarchy in the page breadcrumb`)는 `git stash`로 이번 변경을 제외한 상태에서도 동일하게 실패하는 **기존 미해결 테스트**임을 확인함(이번 리팩터링과 무관, 텍스트가 여러 span에 나뉘어 있어 `findByText`가 결합 문자열을 찾지 못하는 기존 이슈). 이번 작업 범위(헤더 공통화)를 벗어나므로 별도 수정하지 않음.

## 영향 범위

- 프론트엔드 화면 6개의 헤더 렌더링 로직만 변경. 문구/버튼/필터 등 기존 동작은 유지됨(브레드크럼 구분자만 기존 MenuManagementPage 방식인 `>` 로 통일 — 표기 스타일 변경이며 기능적 차이 없음).
- 백엔드 변경 없음.
