# F1-GRID F1Tree treeCheckbox 체크박스 컬럼 동기화 결과

## 구현 내용

- `F1GridColumn`에 `syncWithTreeCheckbox?: boolean`(기본 `true`) 옵션 추가
- `F1GridRef`/`F1TreeRef`에 `setCellValue(rowId, field, value)` 메서드 추가, `F1Grid`가 `updateGridRow`로 즉시 데이터 반영(편집 가능 여부와 무관한 시스템 자동화 경로)
- `F1Tree.toggleTreeCheckbox`에서 트리 체크박스 상태 변경 시, 대상 행(자기 자신 + 하위) 중 `type: 'checkbox'` && `syncWithTreeCheckbox !== false`인 컬럼 값을 `setCellValue`로 무조건 덮어씀(양방향 동기화)
