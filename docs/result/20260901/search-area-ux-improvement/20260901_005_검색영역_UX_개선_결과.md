## 작업 내용

1. **검색어 state 연동 및 키보드 Enter 조회 트리거**:
   - `searchQuery` 상태를 추가하여 검색어 입력을 바인딩함.
   - 검색창에서 `Enter` 키 입력 시 `requestRefresh(selectedModuleId)` 조회가 실행되도록 이벤트 처리.
2. **Clear(초기화) 버튼 지원**:
   - 검색어가 입력되면 검색창 오른쪽(`endAdornment`)에 초기화 버튼(`IconButton` + `ClearIcon`)이 나타남.
   - 초기화 버튼 클릭 시 검색어가 빈 값으로 설정됨.
3. **레이아웃 순서 및 컴팩트 스타일 최적화**:
   - 레이아웃 순서: `PageHeader` → `PageSearchArea` → `PageMessageArea` → `MenuManagementPanel`
   - 검색 조건 영역에 은은한 카드형 배경과 아이콘 헤더 적용.
