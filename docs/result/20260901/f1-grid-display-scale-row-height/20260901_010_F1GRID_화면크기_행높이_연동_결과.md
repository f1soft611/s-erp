# F1-GRID 화면크기(displayScale) 연동 결과

## 구현 내용

- `AppSettingsContext.tsx`에 `useOptionalDisplayScale()` 훅 추가: `AppSettingsProvider`가 없으면 `1`을 반환(기존 `useAppSettings()`는 그대로 유지)
- `F1Grid`에서 `useOptionalDisplayScale()`로 `displayScale`을 조회해 `rowHeight`/`minRowHeight`/`maxRowHeight`에 곱한 뒤 clamp
- 개별 행 수동 조정 상태(`rowHeights`)는 그대로 유지되어, displayScale은 미조정 상태의 기본값에만 영향
- `MenuManagementPanel.tsx`의 `rownumber` 컬럼 정의에서 비어 있던 `field`를 `'id'`로 채워 타입 오류 해결(순번 컬럼은 표시값을 `rowIndex + 1`로 덮어쓰므로 실제 필드 값은 사용되지 않음)
