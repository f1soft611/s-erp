# 20260901_002 메뉴 기능권한/설명 연동 결과

## 구현 내용

- 공통 페이지 기능 버튼을 조회, 저장, 삭제, 엑셀 네 종류로 정리했다.
- CREATE와 UPDATE는 저장 버튼 권한으로 합치고 등록/수정 버튼을 제거했다.
- `/api/v1/menus/my`가 메뉴별 `permissionCodes`를 실제 페이지 권한으로 반환하도록 변경했다.
- `tb_menu.menu_dc` 스키마와 메뉴 관리 CRUD, 사용자 메뉴 트리의 설명 계약을 추가했다.
- 메뉴관리 그리드에 메뉴설명 편집 컬럼을 추가했다.
- 선택 메뉴의 저장된 메뉴명과 메뉴설명을 실제 페이지 제목과 설명에 반영했다.
- 페이지 식별을 변경 가능한 메뉴명이 아니라 경로에서 만든 `pageKey` 기준으로 변경했다.
- 선택 경로의 상위 메뉴 이름을 보존해 `환경설정 > 시스템 관리 > 메뉴관리`처럼 전체 계층을 표시했다.

## DB 적용 참고

현재 환경에는 `psql` 실행 파일이 없어 실행 DB에 마이그레이션을 직접 적용하지 못했다. 배포 또는 로컬 재실행 전에 `backend/DATABASE/20260901/20260901_001_add_menu_description.sql`을 대상 DB에 적용해야 한다. 적용 후 백엔드를 재시작하면 메뉴관리에서 저장한 설명이 `/api/v1/menus/my`를 거쳐 실제 페이지 헤더에 표시된다.
