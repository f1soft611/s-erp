# F1-GRID 컬럼 드래그 순서 변경 결과

## 구현 내용

- `columns/GridColumnManagement.ts`에 `reorderGridColumns`(순서 배열 기준 재정렬, 미포함 필드는 뒤에 유지), `moveGridColumnOrder`(드롭 대상 위치로 필드 이동) 유틸 추가
- `F1GridProps`에 `storageKey?: string` 추가
- `F1Grid`에 `columnOrder` state 추가: `storageKey` 지정 시 `localStorage`에서 초기값 복원, 변경 시 저장
- `visibleColumns` 계산에 `reorderGridColumns` 적용
- `GridHeader`의 헤더 셀에 `draggable`(고정 컬럼 제외), `onDragStart`/`onDragOver`/`onDrop` 추가, `onReorderColumn(sourceField, targetField)` 콜백으로 순서 변경 위임(드롭 대상 위치 앞으로 삽입)
