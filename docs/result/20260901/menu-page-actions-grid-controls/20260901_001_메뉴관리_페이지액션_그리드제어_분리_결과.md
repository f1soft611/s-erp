# 20260901_001 메뉴관리 페이지 액션/그리드 제어 분리 결과

## 1. 요약

메뉴관리 페이지에 페이지 업무 액션 영역과 F1Tree 그리드 제어 영역을 분리 적용했다.

- `루트 메뉴 추가`, `하위 메뉴 추가`, `삭제`, `저장`, `새로고침`은 `메뉴 업무 액션` toolbar에 배치했다.
- `전체 펼치기`, `전체 접기`는 `메뉴 그리드 제어` toolbar에 배치했다.
- F1Tree 체크박스 접근성 라벨은 유지하면서, 트리 셀의 접근 가능한 이름이 기존 표시 텍스트와 달라지지 않도록 보정했다.
- MUI v9 Checkbox 타입에 맞춰 F1Tree 체크박스 input 속성을 `slotProps.input`으로 정리했다.

## 2. 변경 사항

- `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx`
  - 메뉴관리 패널 헤더의 업무 액션 버튼과 그리드 제어 버튼을 별도 toolbar로 분리했다.
  - 좁은 화면에서 업무 버튼이 줄바꿈되도록 유지하고, 그리드 제어는 그리드 바로 위에 배치했다.
- `frontend/src/shared/components/f1-grid/tree/F1Tree.tsx`
  - MUI Checkbox `inputProps`를 `slotProps.input`으로 변경했다.
  - 기존 `Root 트리 선택` 형태의 접근성 라벨을 유지했다.
- `frontend/src/shared/components/f1-grid/core/GridCell.tsx`
  - 일반 셀의 `aria-label`을 표시값으로 고정해 adornment 라벨이 gridcell 이름에 섞이지 않게 했다.
- `frontend/tests/menu-management-f1-grid.test.tsx`
  - 메뉴 업무 액션과 메뉴 그리드 제어가 별도 toolbar로 렌더링되는지 검증을 추가했다.
- `frontend/scripts/capture-menu-page-actions-grid-controls.js`
  - 메뉴관리 페이지를 375px, 768px, 1280px에서 캡처하고 페이지 가로 overflow를 검사하는 Playwright 스크립트를 추가했다.

## 5. 영향 범위

- 프론트엔드 메뉴관리 페이지와 공통 F1Tree/GridCell 접근성 보정만 변경했다.
- 백엔드 API와 DB 스키마는 변경하지 않았다.
- 다른 업무 페이지의 액션 영역 적용은 후속 작업 범위로 남겼다.
