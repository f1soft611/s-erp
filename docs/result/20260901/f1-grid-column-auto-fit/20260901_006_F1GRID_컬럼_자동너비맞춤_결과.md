# F1-GRID 컬럼 자동너비맞춤 결과

## 구현 내용

- `F1GridColumn`에 `maxWidth?: number` 옵션 추가
- `utils/grid.utils.ts`에 Canvas `measureText` 기반 `getAutoFitColumnWidth` 유틸리티 추가 (헤더 제목 + 화면 렌더링 행의 표시값 중 최댓값, `minWidth`/`maxWidth` clamp)
- `GridHeader`의 컬럼 리사이즈 핸들(`role="separator"`)에 `onDoubleClick` 추가, 더블클릭 시 `getAutoFitColumnWidth` 결과로 `onResizeColumn` 호출
- `F1Grid`에서 `GridHeader`로 현재 렌더링 중인 `visibleRows`를 `rows` prop으로 전달

## 검증 결과

npm run test -- tests/f1-grid.test.tsx

jsdom 테스트 환경은 Canvas 2D context를 지원하지 않아 텍스트 측정 시 문자 수 기반 추정치로 폴백하며, 실제 브라우저에서는 `measureText`를 사용한다.
