# F1-Tree 최하위 마커 수정 결과

## 재현과 원인

루트 → 중간 노드 → 최하위 노드의 3단계 트리에서 중간 노드에도 `ㄴ` 마커가 나타났다. 기존 조건이 `depth > 0`만 확인했기 때문이다.

## 변경

루트가 아닌 행 중 실제 자식이 없는 행에만 마커를 표시한다. 접힌 중간 노드에도 마커가 표시되지 않으며 펼침·접기, 선택, 체크박스 및 최하위 마커 위치는 유지한다. 사이드 트리와 백엔드는 변경하지 않았다.

## 검증

- 변경 전 회귀 테스트에서 중간 노드의 마커가 존재해 실패함을 확인했다.
- `npm run test -- tests/f1-tree.test.tsx`: 28개 통과. 단독 루트, 중간 노드, 최하위 및 접기·펼치기 포함.
- `npm run build`: 통과.
- `npm run lint`: 종료 코드 0, 기존 경고 출력.
- 기존 4173 개발 서버의 F1-Grid 문서 트리 예제를 375, 768, 1280px에서 확인했다. 루트와 중간 노드에는 마커가 없고 최하위 행에는 마커가 표시된다. 페이지 전체 가로 스크롤 폭은 뷰포트 폭과 같고 그리드는 내부 스크롤을 사용한다.
- 스크린샷: [375px](screenshots/tree-375.png), [768px](screenshots/tree-768.png), [1280px](screenshots/tree-1280.png).
