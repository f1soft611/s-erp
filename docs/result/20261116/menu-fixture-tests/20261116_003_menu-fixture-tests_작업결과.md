# 메뉴 기반 테스트 회귀 정리 결과

## 재현과 원인

- 단일 워커 기준 F1-Grid 테스트 페이지 9건 모두와 대시보드 데이터 1건이 실패했다.
- 정적 모듈 목록이 빈 배열인데 테스트가 기존 설정 모듈을 직접 참조했다.
- 해당 픽스처를 복구한 뒤 필수 컬럼 표시와 표시 배율을 반영하지 않은 기대값 2건이 추가로 드러났다.

## 변경

- 테스트용 사용자 메뉴 응답을 실제 모듈 변환 경로로 처리한다.
- 메뉴 페이지 연결은 `DashboardContent`를 통해 검증한다.
- 필수 컬럼의 `*`, 기본 배율 0.9의 행 높이와 현재 연도 기준 날짜 단축 입력을 반영했다.
- 운영 코드와 F1-Grid 기능은 변경하지 않았다.

## 검증 및 잔여 사항

- 두 테스트 파일 12건 모두 단일 워커에서 통과했다.
- 변경 파일의 oxlint 및 전체 TypeScript 검사 통과.
- 전체 프론트엔드 테스트는 재실행하지 않았다. 다른 테스트 실패와 lint 경고는 별도 작업이다.
- UI 변경이 없어 스크린샷은 생성하지 않았다.

## 커밋 제목과 내용

```text
test: 메뉴 기반 그리드 테스트 픽스처 정리

- API 메뉴 변환 경로를 이용해 대시보드 및 그리드 테스트 픽스처 구성
- 필수 컬럼과 표시 배율에 맞게 테스트 기대값 갱신
```
