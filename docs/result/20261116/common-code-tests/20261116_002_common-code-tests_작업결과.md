# 공통코드 테스트 회귀 정리 결과

## 재현 및 원인

- 단일 워커에서 공통코드 테스트 30건 중 11건 실패, 미처리 예외 19건을 재현했다.
- 화면 테스트가 실제 트리 대신 목을 사용했다. 목에는 `setSelectedRowIds`가 없었고 Hook을 조건부로 호출했다.
- 테스트 간 페이지 세션 선택 상태가 남았고 일부 테스트는 초기 상세 데이터가 준비되기 전에 그룹을 선택했다.

## 변경

- 실제 트리를 기본으로 사용하고 삭제 차단 콜백 테스트만 목을 사용한다.
- 목 ref 계약과 Hook 호출을 수정하고 테스트마다 페이지 세션을 격리한다.
- 그룹 선택 전 초기 상세 데이터 표시를 기다린다. 운영 코드는 변경하지 않았다.

## 검증 및 잔여 사항

- 단일 워커 공통코드 테스트 30건 통과, 미처리 예외 없음. 기존 React `act` 경고는 출력된다.
- 전체 oxlint: 오류 0건, 경고 164건. 변경 테스트 파일의 oxlint 및 TypeScript 검사 통과.
- 전체 프론트엔드 테스트는 재실행하지 않았다. 다른 테스트 실패와 lint 경고는 별도 작업이다.
- UI 변경이 없어 스크린샷은 생성하지 않았다.
