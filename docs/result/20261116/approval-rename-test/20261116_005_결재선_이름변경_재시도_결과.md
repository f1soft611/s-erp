# 결재선 이름 변경 재시도 테스트 결과

## 원인 및 변경

부분 저장 오류는 표시됐지만 실패 이름은 그리드 재생성 후 별도 effect에서 복원된다. 테스트가 오류 메시지 직후 동기 조회해 복원 전 상태를 읽었다. 오류와 성공 행, 실패 행 보존, 저장 버튼 활성화, 실패 행만 재시도 및 서버 결과를 계속 검증하면서 복원과 재시도 완료를 기다리도록 수정했다. 운영 코드와 화면 동작은 변경하지 않았다.

## 검증

- 기존 테스트는 수정 전 실패, 수정 후 결재선 설정 테스트 41건 통과.
- 변경 파일 lint 오류 0건, 기존 미사용 변수 경고 1건. 기존 React `act` 경고가 출력됐다.
- 프론트엔드 빌드 및 타입 검사 통과.
- 화면 변경이 없어 이번 작업의 브라우저 테스트는 수행하지 않았다. [기존 작업의 모바일 화면](screenshots/historical-grid-375.png)은 과거 캡처이며 이번 검증 결과가 아니다.
