# npm 취약점 호환 범위 개선 결과

## 변경

- Vite `8.2.2 → 8.3.8`, Vitest `4.1.11 → 4.1.12`로 주요 버전을 유지해 갱신했다.
- 기존 범위 내 `brace-expansion`, `source-map-js`, `undici`와 관련 전이 의존성을 잠금 파일에서 갱신했다.
- ExcelJS의 직접 버전과 운영 코드, 공유 개발 서버의 `node_modules`는 변경하지 않았다.

## 검증

- 전체 audit은 높음 4건·보통 4건에서 높음 0건·보통 2건으로 감소했다. 운영 의존성 기준은 높음 1건·보통 2건에서 보통 2건이 됐다.
- 격리된 저장소 스냅샷에 `npm ci --ignore-scripts`를 실행했다. 빌드·타입 검사 성공, lint 오류 0건·기존 경고 164건, 엑셀 내보내기·업로드·대시보드·출하계획 API 테스트 18건 통과.
- 전체 테스트는 실행하지 않았다. 화면 변경은 없으며 브라우저 검증을 수행하지 않았다. [과거 엑셀 메뉴 캡처](screenshots/historical-excel-export.png)는 참고용이며 이번 검증 결과가 아니다.

## 잔여 사항

- ExcelJS와 그 전이 의존성 `uuid`에 보통 등급 audit 항목이 남는다. npm의 강제 수정은 ExcelJS를 이전 주요 버전으로 변경하므로 실행하지 않았다.
- 공유 개발 서버가 사용 중인 기존 `node_modules`는 이전 버전이다. 서버 사용이 끝난 뒤 변경된 잠금 파일로 의존성을 재설치해야 한다.

## 커밋 메시지

```text
chore: 호환 범위 내 npm 취약점 개선

Vite와 Vitest 및 취약한 전이 의존성을 갱신한다.
```
