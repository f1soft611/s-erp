# 수주등록 읽기전용 필드 작업결과

## 변경 내용

- 수주번호·수주상태에 테마 비활성 배경색을 적용했다.
- 권한·수주 상태·보기 모드 등으로 편집할 수 없는 기본정보 필드에도 동일한 배경을 적용했다.
- 직접 입력이 아닌 선택 방식인 거래처는 선택할 수 있을 때 편집 가능 배경을 유지한다.
- 수주현황의 공유 보기·수정 폼에도 같은 기준을 적용했다. 그리드와 저장 동작은 변경하지 않았다.

## 검증

- 수주등록 테스트 23개 통과. 추가한 두 테스트는 구현 전 배경색 불일치로 실패함을 확인했다.
- 프론트엔드 빌드 및 린트 종료 코드 0. 린트는 기존 경고를 출력한다.
- 기존 4173 서버를 재사용해 픽스처 응답으로 등록 화면 375px·768px·1280px과 수주현황 보기·수정 화면을 브라우저에서 확인했다. 등록 화면의 전체 가로 넘침과 브라우저 오류가 없음을 확인했다.
