# 문서 알림 날짜 테스트 결과

## 원인 및 변경

기존 테스트는 상신일만 표시하는 이전 사양을 기준으로 작성됐다. 이후 승인된 사양은 상신일 → 수정일 → 작성일 순으로 선택하고, 알림 카드에 선택한 날짜와 원천 라벨을 표시한다.

운영 코드를 변경하지 않고 카드 테스트 픽스처와 누락 날짜 기대값을 현재 사양에 맞췄다. 수정일·작성일 fallback과 날짜 부재도 검증한다.

## 검증

- 변경 전 알림 카드 테스트 2건 실패. 변경 후 카드·날짜 선택·훅 테스트 총 32건 통과.
- 변경 파일 lint 및 프론트엔드 빌드·타입 검사 통과.
- 전체 프론트엔드 테스트는 이번 작업에서 실행하지 않았다.
- 테스트만 변경해 이번 브라우저 검증은 수행하지 않았다. [과거 카드 캡처](screenshots/historical-notice-375.png)는 이전 사양의 참고 이미지이며 현재 날짜 부재 라벨이나 이번 검증 결과가 아니다.

## 커밋 메시지

test: 문서 알림 날짜 표시 테스트 정합화

날짜 우선순위와 원천 라벨에 맞게 테스트를 갱신한다.
