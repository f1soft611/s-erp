# 20261116_013 가입고현황 결과

기준: [작업지시서](../../../directions/20261116/20261116_013_가입고현황_화면_작업지시서.md), [계획서](../../../plan/20261116/20261116_013_가입고현황_화면_계획서.md), [사양서](../../../spec/20261116/20261116_013_가입고현황_화면_상세사양서.md)
공통 검증·DB 근거·환경·미확인 항목은 [가입고등록 결과](../material-arrival-create/20261116_012_가입고등록_결과.md)에 함께 기록했다.

## 구현 범위
- 백엔드: 목록(`GET /api/v1/materials/material-arrival-status`), 수정·취소(`/api/v1/materials/material-arrivals/{id}`)는 가입고등록과 같은 서비스에서 처리한다.
- 프론트: 가입고현황 목록(헤더 셀 병합, 가입고번호 링크) → 상세 패널 → 조회/수정 다이얼로그(가입고등록 화면을 `embedded`로 재사용).

## 기준 화면
발주현황(`materials/order/status`)의 페이지·컬럼·훅·상세 패널·에디터 다이얼로그 구조를 따랐다. 폼과 F1Grid는 가입고등록 화면의 실제 컴포넌트를 공유하며 차이는 숨김·읽기 전용뿐이다(조회 모드는 입력 전체 읽기 전용, 수정 모드는 구매처·발주 불러오기 숨김, 취소된 가입고는 조회만).

## 동작
- 검색: 가입고일 기간(필수, 기본 최근 1개월~오늘), 가입고번호, 구매처, 상태(정상/취소), 발주번호, 품목, 빠른 검색.
- 수정: 가입고일, 부가세구분·여부, 비고, 행의 수량·단가·세액·입고창고·제조일·소비기한·비고. 수량 상한은 서버가 계산한 "이 행을 제외한 발주 잔량"이다. 행 빼기 후 저장하면 행번호가 다시 매겨지고 모든 행을 뺄 수는 없다.
- 취소: 확인창 후 가입고 전체를 취소(`use_at='N'`, 이력 보존)하고 발주 잔량이 복원된다. 취소된 가입고는 수정·취소할 수 없다.
- 수정·취소 권한은 가입고등록 메뉴의 UPDATE 권한을 쓴다. 엑셀은 EXCEL 권한이 있을 때만 보인다.

## 후속 연동 (이번에는 검증하지 않음)
무검사 가입고는 입고가 생기면, 검사 대상은 수입검사가 진행되면 수정·취소가 막힌다. 입고·수입검사 테이블이 생기는 작업에서 `validateEditable`에 추가한다.
