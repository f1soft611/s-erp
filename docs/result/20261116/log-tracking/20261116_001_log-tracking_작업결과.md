# 공개 로그 추적 중단 결과

## 변경

- `backend/logs/`를 Git 무시 대상으로 지정했다.
- 기존 로그 65개를 인덱스에서 제거했다. 로컬 파일은 유지했다.
- UI 변경이 없어 스크린샷은 생성하지 않았다.

## 검증

- `git ls-files -- backend/logs`: 추적 파일 0개.
- 기존 로그와 신규 로그 예시 모두 `git check-ignore`로 제외 확인.
- 대상 65개 파일의 작업 전후 SHA-256 집계가 일치했다.

## 남은 위험

- 커밋과 푸시는 하지 않았다. 변경사항을 반영하기 전까지 원격 브랜치의 현재 파일은 그대로 공개된다.
- 기존 Git 이력 및 복제본에도 로그가 남는다. 민감정보 포함 여부를 조사하고 필요한 경우 담당자가 이력 정리와 노출 대응을 별도로 결정해야 한다.

## 커밋 제목과 내용

```text
chore: 백엔드 로그 추적 중단

- 백엔드 로그 디렉터리를 Git 무시 대상으로 지정
- 기존 로그를 로컬에서 보존하며 추적 해제
```
