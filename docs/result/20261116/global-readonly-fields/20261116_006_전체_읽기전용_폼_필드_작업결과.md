# 전체 읽기전용 폼 필드 작업결과

## 변경 내용

- 공통 MUI 입력의 읽기전용 및 비활성 배경을 각 테마의 `action.disabledBackground`로 통일했다.
- 마스터·코드 선택기는 선택이 가능하면 편집 가능 배경을 유지한다.
- F1-Grid 행 폼의 텍스트, 날짜, 숫자, 선택, 자동완성, 사용자, 코드, 체크박스 및 이미지 입력에도 동일한 기준을 적용했다.
- 공통 서식 편집기의 읽기전용 본문을 동일한 배경으로 표시하고 F1-Grid 문서를 갱신했다. 데이터, 저장, 권한 및 그리드 셀 동작은 변경하지 않았다.

## 검증

- 읽기전용 배경 신규 테스트를 구현 전 실패, 구현 후 통과로 확인했다.
- 공통 입력·선택기·F1-Grid·수주등록·에디터 관련 6개 테스트 파일, 122개 테스트 통과. 기존 F1-Grid 선택 테스트에서 MUI 값 범위 경고가 출력된다.
- 프론트엔드 빌드 및 린트 종료 코드 0. 린트는 기존 경고를 출력한다.
- 기존 4173 서버에서 픽스처 응답으로 품목 행 폼과 수주등록을 밝은·다크 테마로 확인했다. 행 폼은 375px·768px·1280px에서 화면 넘침이 없음을 확인했다.
- 스크린샷: [밝은 375](screenshots/form-light-375.png), [밝은 768](screenshots/form-light-768.png), [밝은 1280](screenshots/form-light-1280.png), [다크 375](screenshots/form-dark-375.png), [다크 768](screenshots/form-dark-768.png), [다크 1280](screenshots/form-dark-1280.png).
