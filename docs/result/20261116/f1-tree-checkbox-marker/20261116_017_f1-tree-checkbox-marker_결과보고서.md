# F1-Tree 체크박스·최하위 마커 겹침 수정 결과

## 재현과 원인

`treeCheckbox`를 켠 3단계 F1-Tree에서 최하위 행의 `ㄴ` 마커가 트리 체크박스와 겹쳤다. 마커가 행 깊이만으로 절대 배치되어 체크박스가 같은 영역을 차지하는 경우를 반영하지 못했다.

## 변경

최하위 마커를 행의 빈 32px 펼침 버튼 슬롯 안으로 이동했다. 트리 체크박스 뒤에 슬롯이 놓이므로 체크박스가 있을 때도 겹치지 않으며, 체크박스가 없을 때는 기존 마커 위치를 유지한다. 체크 선택, 부모·자식 전파, 펼침·접기, 트리 데이터는 변경하지 않았다.

## 검증

- 변경 전 회귀 테스트에서 disclosure 슬롯이 없어 실패함을 확인했다.
- `npm run test -- tests/f1-tree.test.tsx`: 29개 통과.
- `npm run build`: 통과.
- `npm run lint`: 종료 코드 0. 기존 프론트엔드 파일의 lint 경고가 출력됐다.
- `treeCheckbox`를 켠 3단계 트리를 브라우저에서 375px, 768px, 1280px로 확인했다. 각 너비에서 체크박스와 마커의 경계가 겹치지 않았고, 문서 너비가 뷰포트 너비와 같았다.
