# 결재선 빈 선택기 테스트 시간 결과

## 원인과 조치

빈 후보 상태까지 네 사용자를 순서대로 선택하는 테스트가 Vitest 기본 5초 제한을 초과했다. 단독 실행에서 동일한 제한 시간 초과를 재현했고, 전역 실행 인자로 제한을 15초로 늘리면 기존 검증이 통과했다. 인접한 복합 결재선 테스트와 동일하게 해당 테스트에만 15초 제한을 지정했다. 검증 조건과 운영 코드는 변경하지 않았다.

## 검증 및 한계

- 변경 후 대상과 인접 테스트 2건 통과, 변경 파일 lint 및 프론트엔드 빌드·타입 검사 통과.
- 전체 테스트는 단일 워커 실행 중 여러 실패와 `act` 경고가 관찰됐지만 장시간 실행되어 중단했으므로 최종 실패 건수는 확인하지 못했다.
- 화면 변경은 없으며 이번 브라우저 검증은 수행하지 않았다. [과거 결재선 캡처](screenshots/historical-approval-stage-375.png)는 이전 작업의 참고 이미지일 뿐 이번 테스트 검증 결과가 아니다.
