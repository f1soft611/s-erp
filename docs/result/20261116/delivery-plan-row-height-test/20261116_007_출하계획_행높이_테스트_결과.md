# 출하계획 행 높이 테스트 결과

## 원인 및 변경

그리드 기본 행 높이 32px에는 표시 배율이 적용된다. Provider가 없는 테스트 환경에서도 기본 배율이 0.9이므로 실제 높이는 28.8px인데, 기존 테스트는 배율 적용 전 32px을 기대했다.

운영 코드를 변경하지 않고 출하 상세와 출하계획 상세 그리드를 실제로 렌더링해 기본 배율 0.9와 명시 배율 1.2에서 행 높이와 그리드 행 트랙을 비교하도록 수정했다. 기본정보 필드 간격 검사도 유지했다.

## 검증

- 기존 행 높이 테스트는 수정 전 실패, 수정 후 출하계획 테스트 25건 통과.
- 변경 파일 lint 및 프론트엔드 빌드·타입 검사 통과.
- 화면 변경이 없어 이번 작업의 브라우저 테스트는 수행하지 않았다. [기존 작업의 가상 데이터 폼](screenshots/historical-form-1280.png)은 과거 캡처이며 이번 검증 결과가 아니다.
