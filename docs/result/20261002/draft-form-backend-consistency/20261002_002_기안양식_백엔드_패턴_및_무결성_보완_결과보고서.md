# 20261002_002 기안양식 백엔드 패턴 및 무결성 보완 결과

## 변경 내용

- `DraftingWorkApiController`에 API tag, 작업 요약, 응답 코드 및 인증 principal 숨김 메타데이터를 추가하고 입력 오류 응답 생성은 기존 공통코드 API와 같은 helper 흐름으로 정리했다.
- 기안양식 외부 요청/응답 VO에 클래스와 필드 `@Schema` 설명을 추가했다. 내부 검색 조건 VO는 API 요청 모델이 아니므로 변경하지 않았다.
- `codeIdGnrService` 주입에 `@Qualifier`를 적용해 실제 `EgovConfigAppIdGen` 빈을 명시했다.
- 생성 요청의 `assigneeIds`가 명시적으로 null이면 빈 목록으로 처리해 수정 경로와 동작을 일치시켰다.
- `(tenant_id, cata_type_code)`에 `delete_status IS DISTINCT FROM 'Y'` 조건의 부분 unique index를 추가하는 SQL 초안과 rollback을 작성했다. 선검사에서 중복이 있으면 migration은 예외로 중단된다.
- Mapper는 같은 conflict predicate의 `ON CONFLICT ... DO NOTHING RETURNING`을 사용한다. 경합으로 ID가 반환되지 않으면 기존 중복 코드 메시지로 400 응답을 반환한다.
- 10월 1일 기안양식 계획/사양/결과와 누적 DB 스키마에서 잘못 언급한 채번 서비스 이름을 실제 `codeIdGnrService` 설정으로 정정했다.

## 미실행 및 영향

- DDL 및 rollback은 기록만 했고 DB에 실행하지 않았다. 배포 전 적용 대상 DB에서 중복 선검사 후 승인된 절차로 실행해야 한다.
- UI/API 경로와 JSON 필드 구조는 바꾸지 않았다. UI 변경이 없어 브라우저 확인과 스크린샷은 대상이 아니다.
- 기존 Mapper의 `assignee_summary` 빈 표시 변경은 작업 시작 전부터 존재했으며 그대로 보존했다.
