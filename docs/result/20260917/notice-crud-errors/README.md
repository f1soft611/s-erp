# 공지사항 오류 수정 결과

## 작업 개요

공지사항의 댓글 작성 오류, 첨부파일 포함 저장 오류, 저장 후 목록 맨뒤 이동, 저장 후 제목 잔류 현상을 수정하고 브라우저에서 회귀 검증한다.

## 구현 내역

- 신규 공지 저장 후 서버 목록을 재조회해 서버 정렬 위치를 유지한다.
- 공지 작성 모달을 다시 열 때 제목과 첨부 draft를 기본값과 동기화한다.
- 댓글·답글 실패 시 기존 오류 메시지와 draft 보존 동작을 회귀 테스트로 고정했다.
- 첨부 업로드 실패 시 기존 부분 업로드 정리 동작을 회귀 기준으로 유지했다.

## 검증 결과

- 공지사항 관련 테스트: 3개 파일, 31개 통과
- 프론트 빌드: `cd frontend; npm run build` 성공
- 전체 테스트: 38개 파일 중 14개 실패, 120개 테스트 실패. 실패는 F1-Grid·메뉴 관리 등 무관 영역에 집중되었고 공지사항 관련 테스트는 통과했다.
- 브라우저: 로그인 후 UI 클릭으로 공지사항 접근, 작성 모달 입력 및 재개방 초기화 확인
- 캡처: [모바일](screenshots/notice-mobile.png), [태블릿](screenshots/notice-tablet.png), [데스크톱](screenshots/notice-desktop.png), [작성 모달](screenshots/notice-composer.png)
