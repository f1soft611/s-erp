# 거래명세서 출하 선택 도움창 상세검색 및 현황 No 컬럼 결과

## 변경 내용
- 거래명세서등록 `출하 선택` 도움창을 출하등록의 `수주 선택` 도움창과 같은 패턴으로 변경했습니다.
  - 상단: 통합검색 + 상세검색(출하현황과 동일 조건: 출하일(필수, 기본 한 달 전~오늘), 출하구분, 거래처, 품목, 출하번호)
  - 하단: `선택`, `닫기` 버튼 (기존 `선택 완료` 버튼명 변경)
  - 서로 다른 거래처 선택 제한은 유지했습니다.
  - 도움창은 열릴 때만 렌더링해 기준일 조회가 페이지 진입 시 중복 호출되지 않게 했습니다.
- 백엔드 `GET /api/v1/sales/statements/source-deliveries`에 선택 파라미터를 추가했습니다: `deliveryDtFrom`, `deliveryDtTo`, `deliveryType`, `customerKeyword`, `materialKeyword`, `deliveryNo`. 파라미터가 없으면 기존 동작과 같습니다. 품목 조건은 `EXISTS`로 처리해 출하 상세 ID 목록이 줄어들지 않습니다.
- 거래명세서 현황 그리드 맨 앞에 `No`(rownumber) 컬럼을 추가했습니다(출하현황과 동일 설정).
- DB 스키마 변경 없음. 확인한 테이블: `tb_sales_delivery_hd`, `tb_material_info` (읽기 전용 MCP `describe_table`).

## 검증
- 프론트: `sales-statement-page`, `sales-statement-exact-api`, `sales-page-network-failure` 테스트 31건 통과, `tsc --noEmit` 오류 없음.
- 백엔드: 거래명세서/출하/매출마감 관련 테스트 53건 통과(1건 기존 skip), 필터 SQL 매퍼 검증 추가.
