## 데이터 영향(확인 필요)

- 확인용 저장으로 개발 DB의 두 문서가 실제로 저장되었다.
  - `DP-20261125-0001`: 변경 없이 저장(`updated_at`만 갱신).
  - **`TS-20261125-0001`: 비고가 빈 문자열로 저장되었다.** 확인 스크립트의 "원복" 실행이 먼저 실행되어야 할 "변경" 실행의 실패 후에도 진행되면서 비고를 빈 값으로 채웠다. 이 문서는 그전까지 수정 이력이 없었고(`updated_at` NULL), 원래 비고 값은 DB·서버 로그(SQL만 기록, 조회 결과 미기록)로 확인할 수 없다. 명세일·상세 항목은 기존 값 그대로 전송되었다(서버 로그의 UPDATE 확인).
  - 필요한 조치: 원래 비고를 알고 있으면 화면에서 다시 입력한다.
