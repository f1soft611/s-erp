# 20261008_004 F1-Grid 행 삽입 결과 보고서

## 구현 결과

- 일반 F1Grid 행 컨텍스트 메뉴에 `위에 행 삽입`과 `아래에 행 삽입`을 추가했다.
- 삽입된 행은 우클릭 기준 행의 바로 앞/뒤에 반영되고, 선택·포커스·가상 스크롤을 갱신한다.
- 행 폼이 활성화된 경우 Apply가 성공한 후에만 기준 위치에 행을 삽입한다.
- 기존 `행 추가`/`F1GridRef.addRow()`의 끝 추가와 F1Tree의 계층 추가 동작은 유지했다.
- 정렬 또는 필터가 활성화되면 상대 삽입 메뉴를 비활성화하고, 사용자 설정은 변경하지 않는다.
- 상세 동작은 [F1-GRID.md](../../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)에 반영했다.

## 참고 사항

관련 테스트 파일 전체 실행에서 다음 세 테스트가 실패했다. 삽입 기능 전용 11개 테스트는 모두 통과했다.

1. `f1-grid-context-menu.test.tsx`의 트리 정렬/필터 메뉴 두 사례는 F1Tree에 정렬·필터를 비활성화하는 `disableSorting`/`disableFiltering` 설정이 적용되어 있어 기대한 메뉴 항목을 찾지 못했다.
2. `f1-grid-form-modal.test.tsx`의 모달 크기 사례는 테스트가 `maxWidth: 960px`, `maxHeight: 85vh`를 기대하지만 실제 다이얼로그 스타일이 일치하지 않았다. 행 삽입 구현 범위 밖의 모달 스타일이며 이번 작업에서는 수정하지 않았다.
