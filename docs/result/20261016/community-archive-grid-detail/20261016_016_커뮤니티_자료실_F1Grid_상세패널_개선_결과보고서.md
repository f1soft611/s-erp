# 20261016_016 커뮤니티 자료실 F1-Grid 상세 패널 개선 결과보고서

## 1. 작업 요약

커뮤니티 자료실의 목록/검색을 기안양식관리의 관리 화면 패턴으로 정리하고, 제목 선택 시 전체 높이 우측 패널에서 피드형 게시글 상세를 표시했다. 공지사항 화면, 백엔드 API, 데이터베이스는 변경하지 않았다.

## 2. 구현 내용

- 기본 검색 영역에는 제목·본문·작성자를 검색하는 통합검색 입력만 두고, 활성 분류는 `F1GridColumn.search` 기반 상세검색에서 적용한다.
- 기존 HTML 테이블/페이지네이션을 읽기 전용 F1-Grid 목록으로 교체했다. 제목 버튼으로만 상세를 열고, 분류/작성자/등록일/첨부 수를 표시한다.
- F1-Grid의 `offset`/`limit`을 기존 API `pageIndex`/`pageUnit`으로 변환하고 요청 `AbortSignal`을 서비스까지 전달한다. 서버 최신순을 유지하며 요청 실패는 오류 및 재시도로 표시한다.
- 상세는 작성자·작성일 메타, 분류 칩, 권한별 더보기 메뉴, 일반 텍스트 본문, 공통 `AttachmentList` 순서로 구성했다.
- 기존 작성/수정/삭제, 권한 판정, 삭제 확인, 업로드 및 다운로드 오류 처리는 유지했다.
- [F1-GRID.md](../../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)에 자료실의 상세검색 및 서버 페이지 연결 예제를 추가했다.
