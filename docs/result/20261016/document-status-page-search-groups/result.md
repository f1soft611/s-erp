# 문서현황 상세검색 그룹 행 배치 결과

## 변경 내용

- `search.group`이 연속된 필드들을 새 행으로 묶도록 공통 `PageSearchArea`를 변경했다. `search.span`은 그룹 행과 단독 필드 모두에서 너비 설정으로 유지된다.
- 문서현황 상세검색을 결재신청일, 결재상태/문서종류, 제목, 기안자/부서/결재 참여자의 4개 행으로 구성했다. 기존 span 값(4, 2, 2, 4)과 기본 span 1을 보존했다.
- 결재신청일 범위 위의 반복 캡션만 제거했다. 시작일/종료일 입력 라벨과 접근성 이름, 날짜 값 및 API 조회 조건은 유지된다.
- 회귀 테스트와 F1-Grid 상세검색 안내, 날짜별 작업지시서/계획/사양서를 갱신했다.
- 백엔드, API 계약, DB에는 변경이 없다.

## 검증

- `npm run test -- tests/page-search-area-detail.test.tsx tests/page-search-fields.test.ts tests/document-status-page.test.tsx tests/document-status-service.test.ts` — 4개 파일, 17개 테스트 통과.
- `npm run build` — TypeScript 검사와 Vite 프로덕션 빌드 성공. 기존 번들 청크 1 MB 초과 경고가 있었으며 이번 작업 범위 밖이다.
- `git diff --check` — 오류 없음. 기존 공유 작업트리의 무관한 수정은 보존했다.

## 브라우저 확인 및 개인정보 처리

- `http://127.0.0.1:4173/groupware/doc/read`에 HTTP 200 응답은 확인했다.
- 통합 브라우저 도구는 CDP 연결 시간 초과로 페이지를 읽지 못했다. 로컬 headless Playwright는 인증되지 않은 상태로 `/login`에 리다이렉트되어 문서현황 화면을 확인할 수 없었다. 로그인 자격 증명을 확인하거나 시도하지 않았다.
- 따라서 375px, 768px, 1280px에서 대상 화면의 그룹 렌더링과 가로 넘침 여부는 브라우저에서 검증되지 않았다. Playwright에서 측정된 viewport 결과는 로그인 화면 기준이므로 대상 화면 검증으로 간주하지 않는다.
- 상세검색 화면을 열지 못해 스크린샷은 생성하지 않았다. 문서 행이나 본문이 포함될 수 있는 화면 캡처도 생성하지 않았다.

## 후속 확인

인증된 S-ERP 브라우저 세션에서 상세검색을 열고 375px, 768px, 1280px 너비에서 4개 그룹의 순서/span, 날짜 입력 라벨, 페이지 가로 넘침을 확인한다. 문서 행/본문을 포함하지 않는 경우에만 스크린샷을 결과 폴더에 추가한다.
