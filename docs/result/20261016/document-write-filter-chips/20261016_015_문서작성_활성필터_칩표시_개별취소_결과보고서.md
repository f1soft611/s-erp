# 20261016_015 문서작성 활성 필터 칩 표시 및 개별 취소 결과보고서

## 작업 결과

문서작성 페이지의 `전체 조회` 버튼을 제거하고 현재 적용된 결재 범위, 업무구분, 알림 문서 조건을 각각 `#값` 칩으로 표시했습니다. 칩의 X는 해당 조건만 취소하며, 다른 조건과 현재 피드/리스트 보기 방식은 유지합니다.

- 결재 범위 라벨을 공통 표현 함수로 통합해 칩과 요약/상태 패널에서 동일하게 사용합니다.
- 알림 문서 제목은 요약 데이터에서 조회하며, 데이터가 없으면 `문서 {id}`로 표시합니다.
- 삭제 가능한 칩에 조건별 접근성 이름을 제공하고 MUI Chip 기본 키보드 삭제(Delete/Backspace)를 사용합니다. 중첩 버튼은 만들지 않습니다.
- API/backend/DB 변경은 없습니다.

## 검증

### 테스트

```text
npx vitest run tests\use-document-write-page.test.tsx tests\document-write-page.test.tsx --testNamePattern='active filter chips|scope filter chip|selected document kind|defaults to list mode and displays approval status and all document kinds|uses the view-specific skeleton while the document list is loading'
Test Files: 2 passed
Tests: 16 passed, 97 skipped
```

검증 항목: 기본 칩 없음, 각 결재 범위 라벨, 결재 범위/업무구분/문서 칩의 독립 해제 및 남은 조건의 재조회 인자, 문서 제목/fallback, 리스트 및 피드 모드 유지, 기본 리스트 및 loading skeleton 회귀.

구현 전 같은 신규 필터 칩 테스트를 먼저 실행해 기능 부재로 예상된 테스트 실패를 확인했습니다.

### 빌드, lint, diff

- `npm run build`: 최종 재검증에서 실패했습니다. 변경 범위 밖인 커뮤니티 보관 화면의 `ArchivePostTable` 모듈 누락과 `ArchiveBoardPage`/`ArchivePostDetail` 타입 오류가 보고됐습니다. 초기 구현 검증 시에는 빌드가 통과했지만, 현재 공유 작업트리 상태에서는 전체 빌드를 통과로 확인할 수 없습니다.
- 변경 TS/TSX 파일 `npx oxlint`: 오류 없이 종료. 기존 hook effect의 `react(set-state-in-effect)` 경고 2건이 남아 있습니다.
- `git diff --check`: 통과.

### 브라우저/반응형

인증된 `http://127.0.0.1:4173/groupware/doc/write`에서 필터를 적용하고 각 조건을 지운 뒤 확인했습니다.

| 뷰포트 | 문서 너비 / 클라이언트 너비 | 필터 영역 | 결과 |
| --- | --- | --- | --- |
| 375px | 375px / 375px | 115px × 63px, 칩 줄바꿈 | 가로 overflow 없음 |
| 768px | 768px / 768px | 206px × 28px | 가로 overflow 없음 |
| 1280px | 1280px / 1280px | 칩 너비 약 99px, 71px | 가로 overflow 없음 |

세 크기에서 scope 제거 후 kind 조건이 유지되는 것과 리스트 보기가 유지되는 것을 확인했습니다. 1280px에서는 키보드 Delete로 범위 칩을 지우고, X 아이콘으로 업무구분 칩을 지웠습니다. 브라우저 자동화의 포인터 클릭은 화면 오버레이에 간헐적으로 가로막혀 DOM click/keyboard 이벤트로 확인했으며, 실제 사용자 클릭 경로는 페이지 테스트의 X 아이콘 클릭 테스트로 검증했습니다.

저장한 캡처는 개인/테넌트 문서 행을 포함하지 않는 툴바 영역입니다. 모바일/태블릿 캡처는 브라우저 캡처 도구가 크롭 위치를 잘못 잡아 결과물에서 제외했습니다. 해당 뷰포트의 너비 및 줄바꿈 검증은 브라우저 DOM 측정으로 완료했습니다.

- 확인 종료 과정에서 이번 변경 범위 밖인 커뮤니티 보관 페이지 `ArchivePostTable.tsx`의 Vite HMR 404/reload 오류가 콘솔에 기록됐습니다. 문서작성 필터 작업에서는 해당 파일을 수정하지 않았습니다.
