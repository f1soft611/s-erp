# 20261016_012 문서작성 전체 조회 필터 초기화 결과보고서

## 변경 내용

- 결재 범위, 업무구분 또는 특정 문서 ID가 선택된 경우에만 상단 필터 영역에 `전체 조회` 버튼을 표시한다.
- 버튼은 범위 `ALL`, 업무구분 미선택, 특정 문서 ID 미선택으로 초기화한다.
- 피드/리스트 보기 방식은 유지하고 기존 목록/요약 조회 흐름을 재사용한다.
- 백엔드/API/DB 변경은 없다.

## 검증 결과

### 통과

- 훅 초기화/알림 날짜 집중 테스트: `npx vitest run tests/document-write-page.test.tsx tests/use-document-write-page.test.tsx --testNamePattern="returns the filtered|filter reset|maps only submittedAt"` — 7 passed.
- 피드/리스트 인접 회귀 테스트: `npx vitest run tests/document-write-page.test.tsx --testNamePattern="returns the filtered|defaults to list mode and displays approval status and all document kinds|uses the view-specific skeleton|renders every filtered document as a complete feed card"` — 5 passed.
- `npm run build` — TypeScript 및 Vite production build 통과. 1000KB 초과 번들 경고가 출력됨.
- `npx oxlint src/pages/groupware/documents/write/DocumentWritePage.tsx src/pages/groupware/documents/write/hooks/useDocumentWritePage.ts` — 종료 코드 0. 훅의 기존 effect 관련 `react(set-state-in-effect)` 경고 2건이 남아 있음.
- `git diff --check` — 통과.

### 기존 전체 페이지 테스트 기준

구현 전 집중 실행 기준에서 훅 테스트 3개는 통과했으나, 기존 문서작성 페이지 테스트 88개 중 31개가 댓글 표시, 승인/반려 처리, 상세 패널 및 Composer/첨부 동작 등 이번 필터 변경 범위 밖에서 실패했다. 전체 페이지 테스트는 약 6분 42초가 걸렸다. 이 기존 실패들은 수정하지 않았으며 이번 기능은 명명된 집중 테스트로 검증했다.

## 브라우저 확인

브라우저에서 `http://127.0.0.1:4173/groupware/doc/write` 접근을 시도했으나 로그인 경로(`/login`)로 이동했다. 인증된 문서작성 화면에서 필터를 직접 조작할 수 없어 375px, 768px, 1280px 렌더링 및 스크린샷은 확보하지 못했다. 결과물 폴더에는 브라우저 스크린샷이 없다.
