## 1. Java 8 호환 컴파일 (V1)

- 방법: `mvn dependency:build-classpath`로 classpath를 만든 뒤 JDK 19 `javac --release 8 -encoding UTF-8 -cp "target/classes;<deps>"`로 `SalesStatementApiController.java`, `SalesStatementServiceImpl.java` 컴파일(Lombok 어노테이션 처리 포함)
- 결과: **성공**(exit 0, class 5개 생성)
- 대조: 같은 방법으로 `java.util.List.of(1)`을 쓴 파일은 `cannot find symbol`로 거부되어, 검사가 Java 9+ API를 걸러냄을 확인
- 범위: 이 커밋의 운영 Java 2개. 테스트 코드는 대상 아님
