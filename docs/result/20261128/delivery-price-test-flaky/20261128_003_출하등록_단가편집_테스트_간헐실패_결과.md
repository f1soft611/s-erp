## 원인

테스트가 헤더 출하번호 표시만 기다리고 단가 셀을 바로 찾았다. 헤더 조회와 소수점 정책 조회는 따로 끝나므로, 여러 파일을 함께 실행해 정책 적용이 늦어지면 셀이 아직 `100.000000` 형식이 아니어서 대상 셀을 찾지 못했다(`dblclick` 대상 없음). 운영 코드 결함이 아니라 테스트의 기다림 누락이다.

## 변경

| 파일 | 내용 |
| --- | --- |
| `frontend/tests/sales-delivery-page.test.tsx` | 단가 셀을 `await within(row).findByText('100.000000', { exact: true })`로 기다린 뒤 더블클릭. 이유 주석 1줄 |

운영 코드·API·DB 변경 없음. 화면은 바뀌지 않아 스크린샷 없음.

## 검증

| ID | 결과 |

| T1 | 이 테스트에서만 정책 응답을 300ms 지연(임시) → 변경 전 `Error: Unable to fire a "dblclick" event - please provide a DOM element.` 로 실패(보고된 증상과 같음) |
