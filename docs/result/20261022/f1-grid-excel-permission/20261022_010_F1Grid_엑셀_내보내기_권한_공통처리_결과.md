엑셀 내보내기를 제공하는 화면은 각 화면의 엑셀 권한을 공통 `canExportExcel`에 전달한다. 권한이 없거나 권한 정보가 없으면 컨텍스트 메뉴 항목을 숨긴다.

## 원인 및 수정

공통 `F1Grid`는 이미 `canExportExcel`이 false일 때 엑셀 메뉴를 숨기며 기본값도 false였다. 문제는 일부 화면이 해당 권한 계약을 지키지 않아 발생했다.

| 화면 | 수정 |
|---|---|
| 문서현황 | `selectedMenuPermissions?.excel ?? false`를 `DocumentStatusPage`에서 `DocumentStatusGrid`까지 전달 |
| 기안양식 | 페이지에서 이미 전달하던 `pagePermissions.excel`을 `DraftFormGrid`에서 F1Grid까지 전달 |
| 자료실 파일 트리 | `selectedMenuPermissions?.excel ?? false`를 `ArchiveBoardPage`에서 `ArchiveFileGrid`와 F1Tree까지 전달 |

공통 그리드의 권한 API, 메뉴 UX, 엑셀 파일 생성, 백엔드/API/DB는 변경하지 않았다. 이미 페이지 권한과 연결된 거래처·자재·창고·메뉴·역할·모듈·공통코드 화면, 엑셀 기능을 끈 자료실 게시글 그리드, 문서 데모는 유지했다.

## 회귀 검증

구현 전에 문서현황·기안양식·자료실의 권한 거부 테스트 세 개가 모두 실패했고, 허용 테스트는 통과했다. 권한 전달 수정 후 신규 권한 허용/거부 회귀 테스트 4개가 통과했다.

| 검증 | 결과 |
|---|---|
| 권한 관련 세 파일 선택 실행 | 신규 권한 사례 포함 6개 통과 |
| 문서현황·기안양식·자료실 전체 테스트 | 59개 중 54개 통과, 기존 실패 5개 |
| `f1-grid-excel-export.test.ts` | 통과 |
| `f1-grid-context-menu.test.tsx` | 33개 중 31개 통과, 기존 F1Tree 테스트 2개 실패 |
| `npm run build` | 초기 실행은 성공했으나 최종 재실행은 실패. 관련 없는 기존 수정 파일 `frontend/src/shared/components/f1-grid/form/GridFormField.tsx:377`에서 `ChangeEvent<HTMLInputElement \| HTMLTextAreaElement>`가 `ChangeEvent<HTMLInputElement>` 인수 타입과 불일치 |
| `git diff --check` | 성공 |

### 기존 실패와 분리

수정 전 문서현황·기안양식·자료실 기준 실행은 55개 중 50개 통과, 5개 실패였다. 수정 후에는 테스트 4개가 추가되어 59개 중 54개 통과했고 같은 기존 실패 5개가 남았다. 실패는 `구분명` textbox를 찾지 못하는 기안양식 테스트 4건과 `행 삭제` 메뉴를 찾지 못하는 테스트 1건이다. 이번 변경 전부터 재현되어 있던 동작이며 범위 밖이므로 수정하지 않았다.

F1Grid 컨텍스트 메뉴 실행의 실패 2개는 `clears tree sorting from the shared context menu`, `clears tree filters from the shared context menu`다. 기존 F1Tree의 정렬/필터 비활성 동작과 테스트 기대 불일치로, 이전 [문서현황 우클릭 메뉴 결과](../../20261021/document-status-context-menu/20261021_010_document_status_context_menu_result.md)에도 기록된 범위 밖 실패다. 엑셀 내보내기 테스트는 통과했다.

빌드의 최신 재실행은 현재 작업공간에서 `GridFormField.tsx`의 `handleFormattedChange(event)` 인수 타입 오류로 중단됐다. 이 파일은 이번 권한 변경 범위가 아니며 기존 미커밋 수정 파일이므로 변경하거나 되돌리지 않았다. 첫 빌드 결과는 성공했지만 최신 결과를 기준으로 빌드 전체 통과로 처리하지 않는다.

## 브라우저 확인 및 스크린샷

공유 F1Grid 문서의 컨텍스트 메뉴 플레이그라운드를 로컬 브라우저에서 열고 합성 샘플 행에 우클릭해 `엑셀 내보내기` 항목이 표시되는 것을 확인했다. 스크린샷은 엑셀 권한이 허용된 공통 메뉴 예시다. 권한 거부/허용에 따른 실제 페이지 연결은 문서현황·기안양식·자료실 통합 컴포넌트 테스트에서 각각 검증했다. 실제 업무 데이터는 결과 이미지에 포함하지 않았다.
