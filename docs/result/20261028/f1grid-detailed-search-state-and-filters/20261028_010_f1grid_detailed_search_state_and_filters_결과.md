# F1-Grid 상세검색 상태 및 필터 결과

## 구현 내용

- 상세검색의 편집 중인 값과 실제 조회에 적용된 값을 분리하고, 적용된 조건을 접힌 버튼의 배지와 펼친 패널의 제거 칩으로 표시한다.
- 칩의 제거 동작은 해당 조건만 해제하며, 필수 조건은 유효한 상태로 유지되도록 처리한다.
- 품목·거래처·기안양식·자료실의 탭 세션에서 마지막 조회조건을 복원한다. 공통코드·수주현황·문서현황도 적용된 조건을 기준으로 조회 상태를 유지한다.
- 필수 검색 메타데이터와 검증을 추가했다. 수주현황은 수주일자 시작일·종료일을 모두 입력해야 조회할 수 있으며, 누락/오류 시 조회를 막고 상세검색에 오류를 표시한다.
- 상세검색 패널이 열린 동안 그리드 로딩 덮개보다 위에 표시되도록 레이어 순서를 조정했다.
- 공통 컴포넌트 동작과 검증 기준은 `frontend/src/pages/f1-grid-docs/F1-GRID.md`에 반영했다.

## 검증

- `npm run build`: 통과.
- 상세검색 및 관련 페이지 테스트 7개 파일: 170개 중 164개 통과. 실패 6개는 기안양식 테스트의 기존 레이블/삭제 메뉴 기대 5건과 수주현황 상세 버튼 기대 1건이다. 해당 실패는 이번 상세검색 변경을 검증하는 항목이 아니다.
- 공통코드 페이지 테스트: 30개 중 19개 통과, 11개 실패. 실패는 그룹 전환·트리/그리드 상호작용 관련 항목이며 이 테스트 파일에는 검색 세션 복원 검증 항목이 없다.
- `npm run lint`: 경고로 종료 코드 1, lint 오류는 없었다. 기존 hook/fast-refresh 경고가 출력됐다.
- 브라우저 레이아웃 확인: 375px / 768px / 1280px 모두 패널-로딩 덮개 겹침과 가로 넘침 여부를 확인했다.
