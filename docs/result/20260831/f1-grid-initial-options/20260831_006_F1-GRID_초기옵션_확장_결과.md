## 2. 구현 결과

- `F1GridColumn.pinned` 옵션을 추가해 컬럼 정의만으로 최초 좌/우 고정이 가능하게 했다.
- `F1Tree.defaultExpandAll` 옵션을 추가해 Tree Grid가 최초 렌더링 시 모든 부모 노드를 펼치도록 했다.
- 기존 컬럼 헤더 메뉴의 고정/해제 조작과 기존 `defaultExpanded` 옵션은 유지했다.
- F1 Grid 테스트 페이지의 품목코드 컬럼을 초기 왼쪽 고정 예시로 갱신했다.
- 메뉴 관리 화면은 기존 `defaultExpanded="all"` 대신 명시적인 `defaultExpandAll`을 사용하도록 갱신했다.
- `docs/guide/F1-GRID.md`에 두 옵션의 사용 예시를 추가했다.
- 비동기 조회처럼 빈 `rows`로 먼저 렌더링된 뒤 데이터가 들어오는 경우에도 `defaultExpandAll`이 부모 노드를 확장하도록 보완했다.
