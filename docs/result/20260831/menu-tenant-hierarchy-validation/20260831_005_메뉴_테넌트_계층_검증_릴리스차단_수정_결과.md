# 메뉴 테넌트 계층 검증 릴리스 차단 수정 결과

## 완료 범위

- 메뉴 생성 전에 요청 테넌트 소유 모듈인지 검증한다.
- 생성 및 수정에서 부모 메뉴가 요청 테넌트 소속이며 대상 모듈과 같은지 검증한다.
- 검증 실패 시 메뉴 insert/update를 실행하지 않고 API는 HTTP 400을 반환한다.
- DB 스키마와 MyBatis SQL은 변경하지 않았다.

## 화면 캡처

서버 서비스/API 검증만 변경한 작업으로 브라우저 화면 변경이 없어 스크린샷은 생성하지 않았다.
