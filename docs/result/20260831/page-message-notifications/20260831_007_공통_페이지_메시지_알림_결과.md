# 20260831_007 공통 페이지 메시지 알림 결과

## 1. 요약

권한관리와 메뉴관리 화면에 공통 성공 토스트와 공통 페이지 오류 메시지 영역을 적용했다.

- 저장이 정상 완료되면 우측 하단 공통 성공 토스트를 표시한다.
- 조회 또는 저장이 실패하면 해당 페이지 헤더 아래 공통 오류 메시지 영역을 표시한다.
- 오류 메시지는 닫을 수 있으며, 저장 실패한 권한 등록 다이얼로그는 닫혀 페이지 오류를 바로 확인할 수 있다.

## 2. 변경 사항

- `frontend/src/shared/context/NotificationContext.tsx`
  - `NotificationProvider`, `useNotification`, 4초 자동 닫힘 성공 토스트를 추가했다.
- `frontend/src/shared/components/PageMessageArea.tsx`
  - 닫기 가능한 공통 페이지 상단 오류 `Alert`를 추가했다.
- `frontend/src/App.tsx`
  - 전체 라우트에 공통 토스트 Provider를 등록했다.
- `frontend/src/pages/settings/system/roles/`
  - 역할 목록 조회의 목업 대체를 제거하고 조회/저장/재조회 오류를 페이지 상단에 표시한다.
  - 역할 저장과 재조회가 모두 성공했을 때 토스트를 표시한다.
- `frontend/src/pages/settings/system/menus/`
  - 패널의 저장/새로고침 결과를 페이지로 전달해 공통 오류 영역 및 성공 토스트와 연결했다.
  - 모바일에서 모듈 선택 컨트롤이 페이지 폭을 넘지 않도록 반응형 너비를 적용했다.
- `frontend/tests/notification.test.tsx`, `frontend/tests/role-management-notification.test.tsx`
  - 공통 알림과 권한관리 성공/실패 동작 테스트를 추가했다.
- `frontend/tests/menu-management-f1-grid.test.tsx`
  - 메뉴 저장 완료 콜백 테스트를 추가했다.
