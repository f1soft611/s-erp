# 20261014_001 공지 피드 이전 댓글 완료 시 버튼 숨김 결과

## 결과 요약

이전 댓글 조회 가능 플래그나 커서가 남아 있어도 전체 댓글 수와 현재 로드된 댓글 수가 같으면 이전 댓글 버튼을 숨기도록 수정했다. 모든 댓글이 로드된 뒤 `이전 댓글 보기 (0)` 문구가 남던 문제를 해결했다.

## 원인 및 수정

- 공지사항 피드는 이전 페이지 플래그/커서 상태로 `showPrevious`를 결정하고, 카운트는 별도로 계산하고 있었다. 둘 사이에 상태가 어긋나면 남은 댓글이 0이어도 공통 섹션이 버튼을 계속 렌더링했다.
- 공통 `FeedCommentsSection`에서 유한한 남은 댓글 수가 0이고 조회 중이 아닐 때 이전 댓글 버튼을 렌더링하지 않도록 했다.
- 조회가 진행 중일 때는 기존 로딩 문구를 유지한다. 카운트 미전달/유효하지 않은 경우의 기본 문구와 표시 동작, 양수 카운트 표시는 유지한다.
- 공지사항 회귀 테스트에 stale 이전 댓글 플래그가 있어도 총 댓글이 모두 표시되면 버튼을 숨기는 경우를 추가했다. 이전 댓글이 실제로 남은 기존 테스트 fixture는 총 댓글 수를 정확히 반영하도록 조정했다.

## 브라우저 확인 및 제한 사항

- 기존 S-ERP 개발 서버(`127.0.0.1:4173`)를 재사용했다.
- 공지사항 경로가 로그인 페이지로 리다이렉트되어 인증된 피드에서 직접 상호작용을 확인하지 못했다. 사용자 계정에 접근하거나 테스트 데이터를 변경하지 않았다.
- 로그인 화면만 확인 가능한 상황이라 무관한 화면 캡처는 만들지 않았다. 따라서 이번 결과에는 브라우저 스크린샷이 포함되지 않는다. 실제 브라우저 검증은 인증된 세션에서 추가 확인이 필요하다.
