## 수정 내용

시안과 실제 화면을 다시 대조한 결과, 합의 참여자가 세로 목록으로 쌓이고 참조 카드가 가용 폭 전체로 늘어나는 차이를 확인했다. 승인된 시안의 카드 구조에 맞춰 합의·참조 영역을 조정했다.

- 합의는 `stageOrder`마다 테두리 그룹을 만들고 단계 순번을 한 번만 표시한다. 참여자 카드는 프로필·이름 1행, 부서·상태 2행으로 구성하며 가로 공간이 부족하면 다음 줄로 감싼다.
- 참조는 순번 없이 프로필·이름 1행, 부서 2행의 고정 폭 카드로 표시하고, 가용 폭에 따라 줄바꿈한다.
- 기안자·기안일, 승인 도장 이미지와 상태 fallback 등 기존 결재선 상세 표시를 유지했다.
- 댓글, 첨부, 조회수, 권한 및 결재 처리 동작은 변경하지 않았다.
- 기존 사용자·계정 이미지 컬럼을 조회에 이용했으며 DB 스키마 및 migration 변경은 없다.

## 반응형 브라우저 확인

API 응답은 합성 문서·사용자·부서 정보로 대체해 확인했다. 캡처에 실제 사용자 정보나 실제 프로필·도장 이미지는 포함하지 않았다. 결재선 그룹의 `scrollWidth`와 `clientWidth`는 각 폭에서 일치했고 합의·참조 카드가 가용 폭에 맞춰 줄바꿈하는 것을 확인했다. 좁은 화면에서 순차 승인 카드 흐름의 기존 가로 스크롤은 유지된다.
