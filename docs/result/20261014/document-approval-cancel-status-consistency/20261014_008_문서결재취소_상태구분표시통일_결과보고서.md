# 20261014_008 문서 결재 취소 및 상태·구분 표시 통일 결과보고서

## 결과 요약

문서작성 기능에 기안자 상신 취소와 결재자 본인 승인 취소를 추가하고, 결재 상태 및 문서 구분 배지의 라벨·색상을 상세, 리스트, 피드에서 공통 표시 규칙으로 통일했다. 긴 본문을 접을 때 결재선도 함께 감추고, 더보기로 다시 표시하도록 했다.

기안자의 상신 취소는 본문, 첨부, 결재선 및 기존 이력을 보존한 채 문서를 `DRAFT`로 복귀시킨다. 결재자 승인 취소는 최종 완료 전 본인 승인선에 한해 허용하며, 뒤 단계에서 처리된 결재가 있으면 거부한다. 최종 승인으로 `COMPLETED`가 된 문서는 취소 대상에서 제외한다. 두 동작은 문서 상세에서 확인 후 실행한다.

상태 표시는 `임시저장`, `결재진행중`, `승인`, `반려`, `보완요청`으로, 구분 표시는 `기안`, `업무`, `지출`, `근태`로 통일했다. 상세에서도 상태와 문서 구분을 함께 표시한다.

## 주요 변경

- 백엔드 결재 취소 API, 트랜잭션 검증, 결재선 및 문서 상태 복구, 시스템 이벤트 기록을 추가했다.
- MyBatis 취소 조회/갱신 SQL과 서비스·컨트롤러·매퍼 테스트를 추가했다.
- `SUBMISSION_CANCELED`, `APPROVAL_CANCELED` 이벤트를 위한 전진/변경 이력/롤백 SQL 초안을 `docs/database`와 `backend/DATABASE`에 동일하게 작성했다.
- 프론트엔드 공통 결재 상태·문서 구분 표시 메타데이터를 추가하고 리스트, 피드, 상세 표시를 일치시켰다.
- 상세의 확인 대화상자, 오류 표시 및 성공 후 갱신을 연결하고, 긴 본문 접힘 상태와 결재선 표시를 연동했다.
- 기존 피드 quiet-refresh 동작은 유지했다.

## 브라우저 확인 및 스크린샷

기존 `http://127.0.0.1:4173` S-ERP 개발 서버를 재사용했다. 실제 API가 로그인 화면으로 이동해, 브라우저에서만 가상의 인증 상태와 합성 API 응답을 사용해 화면을 열었다. 실제 자격 증명이나 업무 데이터를 사용하지 않았다.

375px, 768px, 1280px로 화면을 설정해 확인했다. 리스트의 상태/구분 배지, 상세의 취소 버튼과 상태/구분 표시를 확인했고, 긴 본문에서 `접기` 시 결재선이 숨고 `더보기` 시 다시 나타나는 동작을 확인했다. 각 설정 너비에서 문서 스크롤 너비와 브라우저 콘텐츠 너비가 일치했다.

## 승인된 UI 보완 추가 결과

- 상태 배지의 임시저장 outlined 및 그 외 상태 filled 표시와 8px 반경을 리스트·피드·상세에 적용했다.
- 피드와 상세 툴바에 권한별 결재 동작, 상태, 문서구분, 구분선, 상단고정, 더보기 순서를 적용했다. 피드 승인/반려/보완요청과 필수 사유 입력, 임시저장 문서만 삭제 가능한 규칙을 반영했다.
- 피드 진입 시 사용자 사원 ID를 페이지에서 한 번 조회해 카드에 공유한다. 조회 실패 시 오류와 재시도를 제공하고, 성공 시 결재 버튼이 노출된다.
- 승인/반려/취소 버튼 강조색, 결재진행중 결재선 테두리 색상 및 기존 상세 취소 동작을 회귀 테스트로 확인했다.

전체 집중 실행에서 시간 초과된 테스트는 작성 모달의 승인선 편집/합의 사용자 선택 3건, 빈 승인 선택기 1건, 모호한 첨부 업로드 결과 1건이다. 격리 재실행에서는 다섯 테스트 모두 통과했다. 따라서 이 실행의 시간 초과는 집중 실행 중 테스트 런타임 지연으로 관찰되었으며, 해당 테스트를 통한 변경 회귀는 재현되지 않았다.

반응형 DOM 측정값은 다음과 같다. 피드/상세 toolbar는 `flex-wrap: wrap`이며 측정된 toolbar `scrollWidth`와 `clientWidth`가 같았다.

| Viewport | 문서작성 영역 (x, width) | 상세 패널 (x, width) | Toolbar (client/scroll width) |
|---:|---:|---:|---:|
| 375px | 92px, 283px | 92px, 283px | 219px / 219px |
| 768px | 92px, 676px | 215px, 553px | 231px / 231px |
| 1280px | 92px, 1188px | 358px, 922px | 231px / 231px |

이번 보완분의 새 화면 캡처는 아직 갱신하지 못했다. 기존 인증된 브라우저 페이지가 숨김 상태였고, CDP viewport 변경 후 DOM 레이아웃 측정은 갱신되었으나 스크린샷은 이전 compositor frame을 반환했다. 따라서 위 측정값은 브라우저 DOM에서 확인한 결과이며, 기존 `screenshots/` 파일은 이번 UI 보완의 시각 증거로 간주하지 않는다. 최신 툴바가 보이는 스크린샷 갱신은 브라우저 페이지를 표시 가능한 상태로 연 뒤 완료해야 한다.

## DB 변경 적용 상태

읽기 전용 PostgreSQL MCP에서 기존 `tb_common_comment` 이벤트 허용 목록 및 USER/SYSTEM 제약 조건을 확인한 근거를 기준으로 SQL 초안을 작성했다. 새 시스템 이벤트 두 종류를 추가하는 스크립트는 검토·배포용이며, 실제 데이터베이스에는 적용하지 않았다. 신규 테이블이나 컬럼은 없다. 롤백 스크립트는 취소 이벤트를 참조하는 SYSTEM 행이 남아 있으면 롤백을 거부한다.
