# 납품 그리드 정렬 통일 결과서

## 변경 내용

- 납품등록 상세 및 계획 선택 그리드에서 품목 코드·명칭을 가운데, 수량·단가·금액을 오른쪽으로 정렬했다.
- 납품현황 그리드에서 거래처/품목 코드·명칭과 문서번호·일자·구분을 가운데, 일반 텍스트를 왼쪽, 숫자를 오른쪽으로 정렬했다.
- 화면별 F1-Grid 컬럼 설정과 문서를 갱신했으며 공통 그리드 동작과 데이터 계약은 변경하지 않았다.

## 검증

- `npm run test -- tests/sales-delivery-page.test.tsx`: 16개 테스트 통과.
- `npx vitest run tests/f1-grid.test.tsx --testNamePattern="centers cell content when align is set to center"`: 통과.
- `npm run build`: 통과.
- Playwright 브라우저에서 정렬을 확인하고 375/768/1280px 납품등록·납품현황 화면의 가로 넘침이 없음을 확인했다. 합성 데이터만 사용했으며 화면별 캡처는 [screenshots](screenshots)에 저장했다.
- 변경 파일 lint는 오류 없이 완료했다. 기존 파일의 Fast Refresh 및 effect 관련 경고 2건이 출력되었다.
- 두 테스트 파일을 한 번에 실행한 경우 F1-Grid 기존 테스트 46건이 실패했다. 변경하지 않은 테스트의 한국어 문자열 접근성 이름 불일치가 보고되었고, 정렬 관련 F1-Grid 단일 회귀 테스트와 납품 페이지 테스트는 각각 통과했다.
