# 납품계획번호 채번 규칙 정렬 결과서

## 변경 내용

- 납품계획 채번은 문서 고유 접두사 `DP`를 유지하고 `DP-YYYYMMDD-0001` 날짜·순번 형식을 명확히 테스트한다.
- 계획번호 출력에 `Locale.ROOT`를 적용하고 30자 초과 결과를 헤더 저장 전에 거부한다. 수주·납품과 동일한 길이 제한 및 로케일 독립성을 보장한다.
- 채번 키, tenant/date 범위, 현재 날짜 기준, DB 스키마는 변경하지 않았다.

## 검증

- 납품계획·수주·납품 서비스 테스트 통과: `mvn -q "-Dtest=SalesDeliveryPlanServiceImplTest,SalesOrderServiceImplTest,SalesDeliveryServiceImplTest" test`
- 초과 길이 회귀 테스트는 수정 전 계획 헤더 저장 경로까지 진행되는 실패를 확인했으며, 수정 후에는 HTTP 500으로 거부되고 헤더 저장은 호출되지 않는다.
- 화면 동작 변경이 없어 브라우저 검증과 스크린샷은 대상이 아니다.
