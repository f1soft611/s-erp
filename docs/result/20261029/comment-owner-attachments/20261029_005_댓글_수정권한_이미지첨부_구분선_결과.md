# 댓글 수정 권한 및 이미지 첨부 구분선 결과

## 변경 내용

- 공통 댓글 UI가 `isEditable === true`인 댓글에만 더보기 메뉴를 표시하도록 수정했다. 전자결재 문서 adapter가 이미 판별한 작성자 정보를 이제 UI에서도 적용한다.
- 공지 댓글 adapter에서 로그인 사용자 ID와 댓글 작성자 ID가 일치할 때만 수정 가능하도록 제한했다. 작성자/로그인 정보가 없거나 삭제된 댓글은 편집할 수 없다.
- 댓글 편집 화면의 이미지 미리보기는 기존대로 유지하고, 미리보기와 파일명 사이에 구분선과 간격을 추가했다. hover 미리보기는 추가하지 않았다.

## 검증

- `feed-components.test.tsx`, `notice-comment-tree.test.ts`: 50개 테스트 통과
- 소유자 댓글 메뉴, 공지 작성자 판별, 첨부 미리보기 회귀 테스트: 4개 통과
- `npm run build`: 통과
- 변경 관련 파일 `oxlint`: 오류 없음. 기존 `TiptapCommentThread.tsx` 경고만 표시됨.
- Chromium 375px, 768px, 1280px: 타인 댓글 메뉴 미노출, 이미지 미리보기/구분선 표시, 가로 넘침 없음 확인
- 전체 `npm run lint`는 기존 변경 범위 밖인 `tests/common-code-management-page.test.tsx:53`의 Hook 규칙 오류로 실패했다. 확장 테스트 실행도 현재 작업 전부터 수정 중인 다른 영역에서 기존 실패가 확인되어, 관련 집중 테스트 결과와 구분했다.
