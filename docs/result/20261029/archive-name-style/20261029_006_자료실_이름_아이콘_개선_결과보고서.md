# 20261029_006 자료실 이름·아이콘 개선 결과보고서

## 변경 내용

- 자료실 폴더 이름은 기본 텍스트 색상과 굵은 글씨로 표시하며, 폴더 아이콘은 `text.secondary` 회색톤으로 표시한다.
- 파일 이름은 기본 텍스트 색상과 일반 굵기로 표시한다. 기존 이름 클릭 다운로드와 폴더 클릭 탐색 동작은 유지한다.
- PDF, 스프레드시트 등 파일 확장자 아이콘은 공지/문서 첨부에 사용하는 `getAttachmentIconMeta`의 아이콘과 전경/배경 색상을 재사용한다.
- F1-Grid 문서와 자료실 표시/상호작용 테스트를 갱신했다. API/DB 변경은 없다.
