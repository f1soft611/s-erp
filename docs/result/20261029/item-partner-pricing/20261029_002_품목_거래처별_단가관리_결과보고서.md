# 20261029_002 품목·거래처별 단가관리 결과보고서

## 구현 결과

- 기준정보에 품목·거래처별 단가관리 페이지를 추가하고 F1-Grid row form으로 단건 등록·수정하도록 구성했다.
- `.xlsx` 템플릿 다운로드, 행 미리보기·수정, 파일 및 서버 사전검증을 추가했다. 오류가 있으면 일부 행도 stage하지 않으며, 수기/엑셀 변경은 단일 batch-save로 저장한다.
- 테넌트 경계 및 업무키 중복 검증을 포함한 목록·사전검증·batch-save API와 mapper를 추가했다.
- 신규 `public.tb_item_partner_price` DDL, rollback, 변경 이력은 `docs/database/20261029`와 `backend/DATABASE/20261029`에 동일하게 보관했다. **DDL은 적용하지 않았다.**
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`에 row form과 업로드 stage/save 흐름을 기록했다.
