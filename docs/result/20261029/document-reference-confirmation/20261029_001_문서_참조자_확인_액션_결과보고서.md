# 문서 참조자 확인 액션 결과

## 구현 결과

- 기안서(`DRAFTING`) 및 발송된 업무연락(`BUSINESS_CONTACT`)의 참조자만 상세 화면에서 문서를 확인할 수 있도록 구현했다. 임시저장 문서와 미지원 문서 종류, 참조자가 아닌 사용자는 확인할 수 없다.
- 참조 확인 상태 저장과 `REFERENCE_CONFIRMED` SYSTEM 이력 기록은 하나의 트랜잭션으로 처리하며, 재요청 시 확인 이력을 중복 생성하지 않는다.
- 미확인 참조 문서를 결재 대기와 분리해 종합현황 및 문서작성 결재요약에 표시하고, 확인 후 목록과 요약을 갱신한다.
- 기존 DB 제약을 반영한 migration/rollback/change record를 `backend/DATABASE/20261029`와 `docs/database/20261029`에 함께 준비했다. DB에는 migration을 적용하지 않았다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| 백엔드 전자결재/종합현황 집중 테스트 7개 클래스 | 125건 통과 |
| 프론트엔드 참조 확인 관련 Vitest | 37건 통과, 164건 선택 제외 |
| 프론트엔드 TypeScript 및 Vite 프로덕션 빌드 | 통과 |
| 브라우저 375px / 768px / 1280px | Playwright로 상세 확인, SYSTEM 이력 노출, 확인 후 미확인 목록 제거 확인 |
| 페이지 가로 overflow | 세 viewport 모두 없음 |
| `git diff --check` | 통과 |
