# 20261029_003 문서 외부 링크 OG 미리보기 결과보고서

## 구현 결과

- 문서 본문, 기존 문서 본문, 댓글/답글의 외부 HTTP(S) 링크에 별도의 OG 미리보기를 제공한다.
- 기존 암호화된 시스템 문서 공유 링크는 권한 검사와 상세 패널 동작을 유지하고, 외부 링크는 `웹 링크` 카드로 분리해 새 탭에서 연다.
- 인증된 `POST /api/v1/groupware/approvals/link-preview`에서 메타데이터를 조회한다. URL/IP 검증, DNS 연결 고정, 리다이렉트 재검증, 제한된 응답 크기/시간, HTML 메타데이터 정규화를 적용한다.
- 본문/댓글 저장 형식과 DB 스키마는 변경하지 않았다. OG 데이터는 저장하지 않는다.

## 반응형 브라우저 확인

Chromium에서 시스템 문서 카드와 웹 링크 카드의 구분, 외부 링크의 새 탭 이동, 댓글 미리보기, 가로 overflow 여부를 확인했다. 375px, 768px, 1280px 모두 통과했다.

## DB 및 외부 네트워크 확인

읽기 전용 PostgreSQL MCP `list_tables`로 현재 테이블 계약을 확인했다. DB 변경은 없다. 브라우저 검증은 API와 외부 페이지 응답을 모킹했으며, 실제 외부 네트워크 fetch는 수행하지 않았다. 백엔드 DNS 고정 정책은 단위 테스트로 검증했다.
