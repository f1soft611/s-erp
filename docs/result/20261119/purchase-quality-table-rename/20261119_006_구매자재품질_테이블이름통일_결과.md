# 20261119_006 구매자재·품질 테이블/컬럼/소스 이름 통일 결과

관련: [작업지시서](../../../directions/20261119/20261119_006_purchase-quality-table-rename_작업지시서.md) · [계획서](../../../plan/20261119/20261119_006_purchase-quality-table-rename_계획서.md) · [사양서](../../../spec/20261119/20261119_006_purchase-quality-table-rename_상세사양서.md)

## 변경 내용
- 테이블: `tb_material_arrival_hd/dt` → `tb_purchase_arrival_hd/dt`, `tb_material_receipt_hd/dt` → `tb_purchase_receipt_hd/dt`, `tb_material_inspection_hd/dt` → `tb_quality_inspection_hd/dt`. 컬럼·인덱스·제약·시퀀스 이름도 같은 규칙으로 변경(스크립트 `20261119_001`, `docs/database/20261119`·`backend/DATABASE/20261119`).
- 백엔드 Mapper·Java 클래스/필드·파일명, 프론트 식별자·파일명·테스트를 같은 규칙으로 치환.
- API: `/materials/purchase-arrivals`, `/purchase-arrival-status`, `/purchase-receipts`, `/purchase-receipt-status`, `/quality/quality-inspections`, `/quality-inspection-status`.
- 유지: 채번 키 `MATERIAL_RECEIPT_NO`·`MATERIAL_INSPECTION_NO`, 번호 접두어, 메뉴 코드·URL, `tb_material_info`, 과거 날짜 문서·이력 SQL(스키마 이력 검증 테스트는 옛 이름 유지).

## DB 확인(MCP 읽기 전용)
- 적용 전·후 건수·합계 동일: arrival_hd 71 / 482,710.55, arrival_dt 72 / 482,710.55, receipt_hd 31 / 300,540.55, receipt_dt 51 / 300,540.55, inspection_hd 26, inspection_dt 42 / 수량합 228.00.
- 옛 이름 객체(관계·제약·컬럼) 0건, 새 이름 관계 42건(테이블 6·인덱스·시퀀스).

## 검증
- 백엔드 전체 1,342건 실패 0·오류 0·건너뜀 3. 프론트 `tsc` 통과, 린트 오류 0·경고 63(변동 없음), 관련 테스트 37개 파일 417건 통과.
- 실서버 연결 흐름(단가→요청→확정→발주→가입고→검사→입고→매입마감→해제) 새 API 경로로 통과. 마감 목록 통화 컬럼 확인 1건은 보류 항목(외화 마감 요구 시 추가).
- 브라우저: 가입고등록·현황, 입고등록·현황, 매입마감처리, 수입검사등록·현황 7개 화면이 API 오류·페이지 오류 없이 조회됨. 스크린샷 [screenshots](screenshots/).

## 영향·한계
- 화면 저장 키(storageKey, 세션 키)가 새 이름으로 바뀌어 저장된 컬럼 설정·검색 복원은 한 번 초기화된다.
- 롤백: `20261119_001_rollback_rename_purchase_quality_tables.sql`(코드도 이전 커밋으로 되돌릴 때만).
