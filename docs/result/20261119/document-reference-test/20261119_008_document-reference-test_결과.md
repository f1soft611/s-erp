# 문서 작성 참조자 테스트 안정화 결과

[상세사양](../../../spec/20261119/20261119_008_document-reference-test_상세사양서.md)에 따라 대상 테스트 한 건에서 대시보드 준비와 열기 클릭을 실제 문서 작성 다이얼로그 직접 렌더링으로 대체했다. 기존 준비 대기, 선택·격리 단언 및 5초 제한은 그대로 유지했다.

- 이전 exact-lock 전체 실행에서는 대상 테스트가 5초를 넘겼고, 변경 전 단독 실행은 3.46초였다.
- 같은 lock으로 변경된 테스트와 관련 사례를 집중 실행한 결과 4건 모두 통과했다. 대상 테스트는 1.07초였다. 실행 범위가 다르므로 소요 시간은 참고치이며, 변경 후 전체 스위트는 실행하지 않았다.
- 운영 코드, 구매 관련 파일, lint 설정 및 의존성은 변경하지 않았다. 화면 변경이 없어 스크린샷 대상이 아니다.

```text
test(documents): 참조자 격리 테스트 준비 축소

- 실제 문서 작성 다이얼로그를 직접 렌더링하고 기존 단언과 제한 시간 유지
```
