# 문서현황·자료실 브로드크럼 경로 수정 결과

## 원인 및 변경

두 화면의 `PageHeader`에 모듈명과 현재 메뉴명만 전달되어 상위 메뉴가 누락됐다. 문서현황은 `그룹웨어 > 문서관리 > 문서현황`, 자료실은 `그룹웨어 > 커뮤니티 > 자료실`을 전달하도록 수정했다. 페이지 기능 및 공통 헤더는 변경하지 않았다.

회귀 테스트는 수정 전 두 페이지 모두에서 기대하는 전체 경로를 찾지 못해 실패하는 것을 확인한 뒤 추가한 상위 메뉴명이 표시되는지 확인하도록 했다.

## 검증

- `npm run test -- tests/document-status-page.test.tsx tests/archive-page.test.tsx`: 두 테스트 파일, **44개 테스트 통과**.
- `npm run build`: TypeScript 검사와 Vite 빌드 통과. 큰 번들 크기 경고가 출력됐다.
- 브라우저에서 공통 `PageHeader`를 실제 렌더링하고 세 경로의 각 항목을 확인했다. 모바일 375px, 태블릿 768px, 데스크톱 1280px에서 두 경로를 캡처했으며 브라우저 런타임 오류는 없었다.
- 공유 앱 브라우저의 직접 페이지 경로는 로그인 화면 또는 로딩 상태에 머물러 전체 페이지를 인증된 상태로 확인하지 않았다. 캡처는 페이지별 브로드크럼을 동일하게 구성한 공유 헤더 컴포넌트의 렌더링 확인이며, 페이지 통합 테스트에서도 전체 경로를 검증했다.
