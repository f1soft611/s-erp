## 재현 조건 및 원인

자료실 첫 진입 시 분류 응답이 늦으면 그리드 밖에 분류 로딩 Alert가 나타났다. 응답 완료 시 Alert가 제거되면서 그리드 위치가 변했다. 기존 그리드 loading은 분류 조회를 포함하지 않았고, 날짜 기본값 초기화에도 별도 `불러오는 중` 요약이 표시되었다.

## 변경 사항

- [자료실 페이지](../../../../frontend/src/pages/groupware/community/archive/ArchiveBoardPage.tsx)에 날짜 기본값 초기화·분류·파일 목록을 합친 조회 로딩 상태를 연결했다.
- 조회 중에는 기존 F1Tree/F1-Grid 스피너만 사용한다. 분류 로딩 Alert 및 임시 날짜 로딩 문구를 제거했다.
- 분류 조회가 남아 있는 동안 빈 결과 Alert가 나타나지 않도록 했다.
- 날짜 기본값 오류로 종료된 상태에는 영구 스피너가 남지 않는다. 기존 오류·재시도 및 업로드/수정/삭제 진행 안내 코드는 유지했다.
- 공통 그리드, 백엔드, API/DB 계약은 수정하지 않았다. DB MCP 및 SQL 생성 대상이 아니다.

## 실제 브라우저 렌더링 검증

기존 `http://127.0.0.1:4173` 개발 서버를 재사용했다. 실제 자료실 컴포넌트·테마·F1Tree를 별도로 렌더링하고 API 클라이언트를 브라우저 안에서 합성 응답으로 대체했다. 실제 계정 로그인이나 실데이터 조회/변경은 수행하지 않았다. 전체 대시보드 셸 및 실제 백엔드 통합 검증은 포함하지 않는다.

통합 브라우저의 뷰포트 자동 조정 영향을 배제하기 위해 별도 headless Edge에서 고정 뷰포트로 재검증했다. 날짜 → 파일 → 분류 순으로 응답을 해제하면서 조회 중 배너가 없고 마지막 조회까지 스피너가 유지되는지 확인했다.

| 375×900 | 8 / 289.921875 | 359 / 320 | 변화 0px | 변화 0px | 변화 0px | 없음 |

빈 결과/오류/업로드 등 명시적 안내가 표시될 때의 기존 레이아웃 변화는 유지한다.
