# 20261026_011 수주등록 기본정보 필드 간격 개선 결과

## 변경 내용

- 기본정보 그리드의 가로 간격 16px은 유지하고 행 간격을 8px로 줄였다.
- MUI 입력 필드의 기본 상하 여백과 picker 자체 상단 오프셋을 이 그리드에 한해
  제거해 실제 입력 테두리 사이 간격이 8px이 되도록 했다.
- picker 입력/버튼은 같은 행의 다른 필드와 상단 정렬을 유지한다.
- 필드 순서, 값, 반응형 열 수, 버튼 높이 및 입력 동작은 변경하지 않았다.

## 자동 검증

`frontend`에서 실행한 집중 회귀 테스트:

```text
npm run test -- tests/sales-order-create-page.test.tsx tests/master-picker.test.tsx tests/sales-order-scroll.test.tsx
```

결과: 3개 파일, 10개 테스트 통과. 기본정보 그리드의 8px/16px gap과 picker
상단 여백을 검사하는 페이지 회귀 assertion을 포함한다.
`npm run build`의 TypeScript 검사와 Vite 프로덕션 빌드도 통과했다.

## 브라우저 검증

기존 `http://127.0.0.1:4173` S-ERP 개발 서버에서 Chromium으로 실제 수주등록
라우트를 확인했다. 일반 로컬 로그인 대신 격리된 브라우저 컨텍스트에만 임시
테스트 세션과 메뉴/모듈 API 응답을 설정했다. 실제 인증정보나 업무 데이터는
사용하지 않았다.

| 뷰포트 | 결과 |
| --- | --- |
| 375px | row gap 8px, column gap 16px. 문서/본문 폭 375px, 수평 overflow 없음. |
| 768px | row gap 8px, column gap 16px. 문서/본문 폭 768px, 수평 overflow 없음. |
| 1280px | row gap 8px, column gap 16px. 첫째/둘째 필드 행 세로 정렬, picker 상단 정렬 확인. 문서/본문 폭 1280px, 수평 overflow 없음. |

모든 뷰포트에서 페이지 오류는 없었다.
