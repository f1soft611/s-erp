# 문서작성 결재 표·합의 칩 배치 결과보고서

- 작업일: 2026-10-07
- 대상: 문서작성 결재선 표시
- 기준 사양: [결재 표 compact capacity 설계](../../../superpowers/specs/2026-10-07-document-approval-compact-capacity-design.md)

## 구현 결과

- 실제 결재 영역 너비를 기준으로 80px 최소 슬롯과 4px 간격을 적용하고, 첫 행에 빈 도장 슬롯을 채우며 초과 결재자는 다음 행에 표시합니다.
- `ResizeObserver`와 `window.resize` 이벤트로 슬롯 수를 갱신합니다.
- 참여자에게만 전역 순번 배지와 삭제 동작을 제공하고, 이름은 말줄임 표시합니다.
- 합의 참여자가 없으면 합의 행을 표시하지 않습니다. 기존 참조 행과 결재자 삭제·후보 복원 동작은 유지했습니다.

## 검증 결과

| 구분 | 결과 |
| --- | --- |
| 결재선 전체 페이지 테스트 | 28개 통과, 편집기 최소 높이 불일치 1개 실패 |
| 결재·합의·참조 회귀 테스트 | 13개 통과, 나머지 16개 제외 |
| 린트 | 변경 관련 4개 파일 통과 |
| 프로덕션 빌드 | `tsc -b` 및 Vite 빌드 통과 |
| 브라우저 레이아웃 | 375px, 768px, 1280px에서 각 2, 6, 10개 슬롯 |
| 가로 넘침 | 각 뷰포트에서 문서 페이지 너비가 뷰포트 너비와 일치 |
| 빈 합의선 | 세 뷰포트 모두 합의 행 미표시 |
| 캡처 | [1102px 결재/참조 영역 캡처](./screenshots/compact-approval-1102.png) |

### 실제 너비 측정

| 뷰포트 | 다이얼로그 너비 | 결재 영역 너비 | 결재 그리드 너비 | 슬롯 수 |
| ---: | ---: | ---: | ---: | ---: |
| 375px | 311px | 262px | 190px | 2 |
| 768px | 704px | 654px | 562px | 6 |
| 1280px | 990px | 940px | 848px | 10 |

통합 브라우저의 `setViewportSize`는 CSS 너비와 DOM 측정값은 변경하지만 `resize` 이벤트를 전달하지 않았고, 스크린샷 저장 전에는 브라우저 호스트의 기본 너비로 돌아갔습니다. 따라서 각 너비는 해당 뷰포트로 페이지를 다시 연 뒤 DOM에서 검증했으며, 잘못된 너비로 캡처되는 이미지는 제외하고 안정적으로 저장된 1102px 캡처만 첨부했습니다. 자동화 테스트에서는 실제 `window.resize` 이벤트에 따른 슬롯 갱신을 검증했습니다.

## 기존 테스트 실패

`lets the dialog content scroll while the editor surface grows naturally` 테스트는 편집기 최소 높이 `180px`을 기대하지만, 작업 범위 밖의 기존 `DocumentComposerDialog.tsx` 변경이 이를 `200px`로 지정하여 실패했습니다. 해당 변경은 보존했습니다. 이번 결재 슬롯 관련 테스트는 모두 통과했습니다.
