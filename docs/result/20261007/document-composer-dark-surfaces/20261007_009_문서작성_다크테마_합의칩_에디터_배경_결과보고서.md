# 20261007_009 문서작성 다크 테마 합의 칩/에디터 배경 결과

## 변경 내용

- 합의 칩은 라이트 테마에서 기존 `grey.100`/`grey.300` 외관을 유지하고, 다크 테마에서는 `#334155` 배경, 테마 divider 테두리, 밝은 본문색을 사용한다.
- 에디터 캔버스와 입력 가능 영역을 라이트/다크 모두 흰색으로 통일했다.
- 다크 테마 흰 캔버스에 맞춰 기본 본문색을 `#0f172a`, placeholder를 `#475569`로 적용했다.
- 첨부 파일 칩을 흰 에디터 표면에서 읽을 수 있도록 어두운 텍스트/삭제 아이콘과 옅은 회색 배경으로 처리했다.
- 합의 칩 사용자 선택·삭제, 결재선 저장 구조 및 기존 결재선 작업 변경은 유지했다.

## 검증

- TDD RED: 새 합의 칩 다크 테스트는 기존 `rgb(245, 245, 245)`가 기대 `rgb(51, 65, 85)`와 달라 실패했다. 에디터 통합 테스트는 기존 다크 에디터 배경 `rgb(15, 23, 42)`가 기대 흰색과 달라 실패했다.
- 테마 집중 테스트: `document-approval-fields-theme.test.tsx` 2개 및 다크 에디터 통합 1개 통과.
- 변경 파일 lint: 통과.
- `npm run build`: TypeScript 및 Vite 프로덕션 빌드 통과.
- 공유 브라우저 375px/768px/1280px 확인: 다크 모달 및 합의 칩 표면 `rgb(51, 65, 85)`, 에디터 `rgb(255, 255, 255)`, 본문 기본색 `rgb(15, 23, 42)`, placeholder `rgb(71, 85, 105)`였고 페이지 전체 가로 넘침은 없었다.
- 캡처 시 기안자/합의자 이름과 에디터 본문 콘텐츠를 숨겼다.

## 공유 워킹트리의 관련 테스트 실패

전체 `document-write-page.test.tsx`를 실행했을 때 결재선 동작 테스트 4건이 실패했다. 실패는 이번 색상 회귀 테스트와 별도로 현재 공유 워킹트리에 함께 있는 결재선 로직/테스트 변경 영역에서 발생했으며, 이번 작업에서 동작을 임의로 수정하지 않았다.

- `prevents the same user from being assigned to approval and reference`: 기대한 `결재선 3 사용자 선택` combobox를 찾지 못함.
- `adds selected approval users as ordered individual stages and removes them from candidates`: 5초 timeout.
- `removes only the selected agreement user and returns that user to candidates`: 5초 timeout.
- `numbers participants by stage and renumbers after a removable stage is deleted`: 5초 timeout.

새 테마 집중 테스트는 별도 재실행하여 모두 통과했고, 빌드 및 lint도 성공했다. `DocumentApprovalFields.tsx` 빌드 오류를 유발하던 미사용 `Divider` import와 미사용 `SealSlot`은 사용자 확인 후 제거했다.
