# 20261007_002 문서작성 결재선 입력 필드 공간 개선 결과보고서

> 대체됨: 이 보고서의 UI 설명, 측정값, 스크린샷은 이후 폐기된 읽기 전용 선택기 상자 레이아웃을 대상으로 한다. 카드형 레이아웃의 현재 결과는 [카드형 결과보고서](../document-write-approval-card-row/20261007_003_문서작성_결재선_카드형_레이아웃_결과보고서.md)를 참조한다. 이 문서의 과거 측정치는 새 UI 검증 근거로 사용하지 않는다.

## 1. 작업 요약

- 확정된 결재·합의 단계를 읽기 전용 사용자 선택 필드로 가로 배치하고, 마지막에 다음 활성 선택 필드를 이어 표시했다.
- 결재 선택은 사용자별 단계 순서를 보존하고, 합의 선택은 한 단계 안에 그룹으로 유지한다.
- 결재선 후보에서 확정 사용자를 제외하며, 단계를 삭제하면 후보로 복원한다.
- 참조 입력은 독립된 다중 선택 필드로 유지하고 중복 사용자 요약 목록은 표시하지 않는다.
- 공통 `UserSelectEditor`의 읽기 전용 칩은 개별 삭제를 차단하고, 편집 가능한 선택기의 기존 칩 삭제 동작은 보존했다.

### 브라우저 반응형 확인

문서 작성 모달에서 테스트용 제목과 18개 장문 문단을 입력해 확인했다. 화면 폭은 375px, 768px, 1280px이며 아래 측정치는 CSS 픽셀 기준이다.

| 뷰포트 폭 | 문서 폭 | 결재선 스트립 가시 폭 / 콘텐츠 폭 | 모달 본문 스크롤 높이 / 가시 높이 | 에디터 자연 높이 |
|---:|---:|---:|---:|---:|
| 375px | 375px | 262px / 727px | 5996px / 615px | 5380px |
| 768px | 768px | 639px / 727px | 2962px / 764px | 2444px |
| 1280px | 1280px | 593px / 727px | 2392px / 694px | 1954px |

- 세 화면 모두 문서 폭이 뷰포트 폭을 넘지 않았다.
- 결재선 스트립은 모든 폭에서 내부 가로 스크롤을 사용했다. 375px에서는 콘텐츠 727px을 262px 영역 안에서 이동할 수 있었다.
- 긴 본문에 맞춰 에디터가 자연스럽게 확장됐고, 모달 본문 영역이 자체 세로 스크롤을 사용했다.
- 375px에서 본문을 끝까지 스크롤한 상태에도 모달 제목 영역은 y=56px, 하단 액션 영역은 y=714px에 남아 접근 가능했다.
- 참조 사용자 요약 목록은 DOM에 없음을 확인했다.

## 3. 브라우저 데이터 제약

실행 환경에서 선택 가능한 사용자는 관리자 1명뿐이었다. 따라서 실제 브라우저에서는 사용자 1명을 결재 단계에 추가하고 다음 활성 입력이 이어지는 흐름을 확인했다. 다중 사용자의 결재 순서, 합의 그룹, 단계 삭제 후 후보 복원은 테스트 목 데이터로 검증했으며, 실제 브라우저에서 수행했다고 간주하지 않는다.
