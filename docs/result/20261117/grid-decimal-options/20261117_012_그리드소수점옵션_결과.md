# 그리드 소수점 옵션(0 표시/반올림) 결과

## 작업지시/계획/사양 요약
- 기존 `GRID_DECIMAL_{모듈}` 정책에 소수점 0 표시(FIXED/AUTO)와 반올림 방식(HALF_UP/UP/DOWN)을 추가하고, 수주현황에 우선 적용한다.
- 새 정책은 만들지 않고 `value_json`을 `{"places":2,"trailingZeros":"FIXED","rounding":"HALF_UP"}` 객체로 확장한다. 기존 숫자 값은 FIXED/HALF_UP으로 호환된다.
- 객체 값은 `GRID_DECIMAL_` 정책에만 허용하며 다른 NUMBER 정책은 기존대로 숫자만 허용(객체는 400).

## 변경
- 백엔드: `SystemPolicyServiceImpl` 검증/정규화, `getGridDecimals` 응답을 모듈별 `{places,trailingZeros,rounding}`로 변경.
- 프론트: F1-Grid 컬럼 옵션 `trailingZeros`/`rounding`, `roundGridNumber`, Excel 내보내기, 정책 관리 소수점 편집기(자릿수/0 표시/반올림), F1Grid 정책 병합(컬럼 > 정책 > 기본값).
- 영업관리 전체(수주/견적/출하/출하계획/거래명세서) 그리드 컬럼의 고정 `decimalPlaces`를 모두 제거해 정책을 따르게 함. 필요한 컬럼만 개발자가 `decimalPlaces`를 직접 지정. 테스트 기대값은 기본 포맷(`2.00`→`2`)으로 수정. 개발자 가이드: `20261117_012_정책개발자적용가이드.md`.
- 수주현황: 정책 자동 적용(금액 컬럼 포함).
- DB: `ck_system_policy_value_shape`가 NUMBER에 number만 허용해 저장 오류가 발생 → `20261117_010_alter_grid_decimal_value_shape.sql`로 `GRID_DECIMAL_*` 정책에 한해 객체 허용(롤백 스크립트/이력 문서 포함, `docs/database`와 `backend/DATABASE` 동일). **저장 전에 이 스크립트를 DB에 적용해야 한다.**
- 근거: 스키마 이력 `20261105_004_create_system_policy_schema.sql`(MCP 미조회).

## 동작/제약
- 반올림은 표시와 Excel 값에만 적용, 저장값/입력 편집기 불변.
- 정책은 세션 캐시이므로 변경 후 새로고침/재로그인 필요.
