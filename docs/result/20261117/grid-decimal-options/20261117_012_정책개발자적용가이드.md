# 정책 관리 신규 정책 및 개발자 적용 가이드

## 1. 새로 생긴 정책

| 정책 코드 | 유형 | 용도 | 비고 |
| --- | --- | --- | --- |
| `GRID_DECIMAL_{모듈코드}` (예: `GRID_DECIMAL_SALES`) | NUMBER(객체 값) | 모듈별 그리드 숫자 표시 규칙 | 모듈관리(`tb_module`) 사용 모듈마다 1건 (`20261117_009` 시드) |
| `STATEMENT_ISSUE_MODE` | SELECT(AUTO/MANUAL) | 출하등록 시 거래명세서 자동 발행 여부 | `20261117_008` |

`GRID_DECIMAL_*` 값 형식: `{ "places": 2, "trailingZeros": "FIXED|AUTO", "rounding": "HALF_UP|UP|DOWN" }`
- places: 소수점 자릿수(0~6), trailingZeros: FIXED=항상 `.00` 표시 / AUTO=있을 때만, rounding: 반올림/올림/내림
- 정책 관리 > 해당 정책의 소수점 편집기에서 한 번에 설정. 기존 숫자 값도 호환(FIXED, HALF_UP).
- DB 적용 필요: `20261117_009`(시드), `20261117_010`(값 형태 제약 확장).

## 2. 개발자가 할 일 (그리드 소수점)

**대부분 할 일 없음.** F1Grid가 자동 적용한다. 대시보드가 현재 모듈 코드를 제공(`GridDecimalModuleProvider`)하고, `type`이 `number`/`decimal`/`currency`인 컬럼에 정책값을 채운다.

1. 컬럼에 `decimalPlaces`를 **지정하지 않는다** → 정책 적용.
2. 특정 컬럼만 고정하려면 `decimal` 객체 하나로 지정한다: `decimal: { places: 0 }`, `decimal: { places: 3, trailingZeros: 'AUTO', rounding: 'DOWN' }`. 지정한 항목만 정책보다 우선하며 생략한 항목은 정책을 따른다. (기존 `decimalPlaces`/`trailingZeros`/`rounding` 개별 옵션도 호환되나 `decimal`이 우선)
3. 우선순위: **컬럼 `decimal` > 컬럼 개별 옵션 > 모듈 정책 > F1-Grid 기본값**(최대 5자리, 끝자리 0 제거). 항목별(자릿수/0 표시/반올림)로 각각 판단.
4. `toLocaleString`/`toFixed`로 직접 포맷하는 상세 패널·합계 문구 등 F1Grid 밖의 숫자는 자동 적용 대상이 아니다(필요 시 별도 처리).
5. 반올림은 표시와 Excel 내보내기 값에만 적용. 저장값·입력 편집기는 그대로.
6. 정책은 세션당 1회 캐시 → 정책 변경 후 새로고침/재로그인.
7. 모듈 밖(Provider 없는 화면, 팝업 단독 렌더 등)의 F1Grid는 정책을 조회하지 않고 기본값을 쓴다. 테스트에서도 기본 포맷(`2.00` 아님 `2`)이 나온다.

새 모듈 정책이 필요하면 모듈관리에 모듈을 추가하고 `GRID_DECIMAL_{모듈코드}` 정책을 시드/등록한다.

## 3. 거래명세서 정책
- 정책 관리의 `STATEMENT_ISSUE_MODE`: AUTO면 출하등록 시 출하 단위로 거래명세서 자동 발행, MANUAL이면 출하건을 묶어 직접 발행.
