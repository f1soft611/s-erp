# 수주현황 결과 알림 닫기 여백 보정 결과

## 원인 및 수정

- 원인: 결과 알림은 `SearchResultMessage` 내부 상태로 닫히지만, 수주현황 부모 화면은 알림이 계속 보인다고 판단해 그리드 상단 `pt`를 0으로 유지했다.
- 공용 결과 알림에 선택적인 닫힘 콜백을 추가해 수주현황이 닫힘 상태를 반영하도록 했다. 알림을 닫으면 그리드의 기본 상단 여백(`pt: 1`, 8px)을 유지한다.
- 신규 조회, 목록 재시도, 저장/삭제 후 목록 갱신 시 닫힘 상태를 초기화한다. 공용 메시지의 다른 사용 화면은 변경되지 않았다.
- 회귀 테스트는 수정 전에 실패하는 것을 확인했으며, 닫기 후 여백과 다음 조회 시 알림 재표시를 검증한다.
