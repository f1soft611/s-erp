## 2. 진행 중·미해결

- **출하계획 배포 호환성:** 현재 계약과 구버전 요청·응답이 호환되지 않는다. 운영 배포 버전, 외부 API 소비자, 캐시된 화면 및 대상 DB 스키마는 확인되지 않았고 전환·롤백은 실행하지 않았다.
- **프론트 전체 테스트:** 견적 작업 결과에 전체 테스트 실패가 기록되어 있다(31/194 파일, 실패 142개). 시간 초과와 기존 수주현황·테마 테스트가 포함된 것으로 기술되어 있으나 실패 원인별 분류와 기준선 확인은 남아 있다.
- **DB 반영:** 구매 발주, 견적, 전자결재 알림 및 공통코드 관련 스크립트는 준비되어 있으나 실제 적용 여부가 확인되지 않았다. 공통코드 Seed만으로 화면의 하드코딩 선택값이 제거되지는 않는다.
- **수주등록 읽기전용 배경 작업 문서:** 화면 코드와 테스트에는 적용이 확인되지만, `20261116_004` 계획서 체크리스트는 미완료 상태이며 대응 결과 문서는 확인되지 않았다. 구현 완료 여부와 브라우저 검증을 결과 문서로 닫아야 한다.
- **구매 발주 후속 기능:** 가입고 데이터와 발주 행 삭제·취소 제한의 연계, 전자결재, 재고량·품목 검사대상 연결이 남아 있다. 발주서 이메일·팩스 발송도 구현되지 않았다.
- **ExcelJS 취약점 대응:** 조사 결과만 기록되어 있다. 브라우저 배포 번들까지 수정되는 안전한 업그레이드 또는 대체 방식이 확정되지 않았다.
