## 2. 진행 중·미해결 사항

- **프론트엔드 전체 테스트/CI 실패:** 확인 가능한 최근 `main` CI 실행이 실패했다. 2026-11-17 조사 보고는 최근 `main` 실행 6건 실패, 로컬 18개 파일·86개 테스트 실패를 기록한다. 로그인 화면 lazy 로딩을 기다리지 않는 테스트 등 일부 원인은 확인됐지만 전체 실패 분류와 기준선 복구는 끝나지 않았다. [CI 조사](https://flow.team/l/QzIlt)
- **구매자재 후속 기능:** 가입고와 발주 행 삭제·취소 제한의 연계, 전자결재, 재고량·검사대상 연결이 남아 있다. 발주서 이메일/팩스 발송도 구현 완료 근거가 없다.
- **기타 미해결:** ExcelJS→uuid audit 항목의 브라우저 번들 대응안, 공통코드 조사에서 보류된 `plantId` 의미, 여러 출하를 묶는 거래명세서 직접 발행은 미결정/미구현이다.
- **Flow 상태:** 영업관리 서버 날짜 작업은 소스·결과 문서와 일치하도록 Flow 업무를 완료로 갱신했다. [Flow 업무](https://flow.team/l/QzqMr)
