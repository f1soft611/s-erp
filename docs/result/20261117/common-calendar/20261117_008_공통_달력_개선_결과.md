# 20261117_008 공통 달력 개선 결과

기준: [작업지시서](../../../directions/20261117/20261117_008_공통_달력_개선_작업지시서.md), [계획서](../../../plan/20261117/20261117_008_공통_달력_개선_계획서.md), [상세 사양서](../../../spec/20261117/20261117_008_공통_달력_개선_상세사양서.md)

## 결과 요약
날짜·월 달력을 한국어, 연·월 드롭다운, 주말 색, 오늘 표시가 있는 공통 달력으로 바꿨다. 기간(from~to) 검색은 시작일·종료일이 각각 단일 날짜 달력을 쓰고 자기 값만 바꾼다. 범위 선택 달력(`DateRangePanel`)은 만들어 두었으나 실서버 확인에서 시작·종료가 동시에 바뀌고 종료일 달력에 시작일이 선택으로 보이는 혼동이 있어(사용자 지적, 2026-11-17) 화면에 연결하지 않고 보류했다. 날짜 입력 규칙(직접 입력, 축약 입력, 정규화, `disabled`, 오류 표시)은 바꾸지 않았고 달력 팝업만 교체했다. DB·API 변경 없음.

## 변경
- 신규 [shared/components/calendar](../../../../frontend/src/shared/components/calendar/): `DatePanel`(날짜), `DateRangePanel`(기간), `MonthPanel`(월), `CalendarHeader`(화살표·연도·월 드롭다운), `DayGrid`(6주×7일 격자), `calendarUtils`(격자·범위 계산, dayjs 사용, 새 라이브러리 없음).
- [DateEditor](../../../../frontend/src/shared/components/f1-grid/editing/DateEditor.tsx): 기본 달력을 `DatePanel`로 교체하고 선택 prop `renderCalendar({ value, close })` 추가. `disabled`이면 팝업이 열리지 않는 기존 동작 유지.
- [MonthEditor](../../../../frontend/src/shared/components/f1-grid/editing/MonthEditor.tsx): `MonthPanel` 사용(매입마감처리 마감월).
- [PageSearchArea](../../../../frontend/src/shared/components/PageSearchArea.tsx): 변경 없음(기간 날짜 필드의 시작일·종료일은 각각 기본 `DatePanel`을 쓴다. 처음에 범위 달력을 연결했다가 되돌렸다).
- [DateTimeEditor](../../../../frontend/src/shared/components/f1-grid/editing/DateTimeEditor.tsx), [TimeEditor](../../../../frontend/src/shared/components/f1-grid/editing/TimeEditor.tsx): 모양은 그대로, 한국어 로케일만 적용.
- 같은 작업에서: 매입마감처리 마감월 기본값을 서버 날짜(입고일 종료일 기본값)의 월로 변경(브라우저 날짜 대체 없음), 구매처 요약의 건수 열을 정수로 표시(`decimal: { places: 0 }`, 소수점 정책 도입 후 `24.00`으로 보이던 문제), 구매자재 DB 번호가 영업 스크립트 번호와 겹치는 점을 변경이력 문서 006·007·008에 기록.
- 문서: [F1-GRID.md](../../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)에 "공통 달력" 섹션 추가, 월 검색 설명 갱신.

## 동작
- 날짜 달력: 이전/다음 달 화살표, 연도·월 드롭다운, 일~토(일 빨강, 토 파랑), 오늘 날짜 주황 점, 이전·다음 달 날짜는 흐리게(누르면 그 달로 이동), 하단 "오늘"·"삭제".
- 기간(from~to) 검색: 시작일·종료일 입력이 각각 단일 날짜 달력을 열고 자기 값만 바꾼다. 종료일 달력은 종료일을 선택으로 보여 준다. 범위 달력(`DateRangePanel`, 첫 클릭 하루 범위·두 번째 클릭 완성·호버 미리보기)은 컴포넌트와 단위 테스트만 있고 화면에는 연결하지 않았다(보류, 이후 보강).
- 월 달력: 연 화살표·연도 드롭다운, `1월`~`12월`, 선택 월 강조, 이번 달 점, 하단 "이번 달"·"삭제".

## 확인하지 못한 것
- 공지 작성의 팝업 종료일, 출하·명세서·견적 폼, F1Grid 날짜 셀 편집은 실제 브라우저로 따로 확인하지 못했다(같은 `DateEditor`를 쓰며 테스트와 영업 수주등록 확인으로 갈음). `DateTimeEditor`·`TimeEditor`의 한국어 표시도 화면으로는 보지 못했다.
- 전체 프론트 테스트의 기존 실패 파일은 이번 작업과 무관하게 남아 있다.
- 키보드 방향키로 날짜를 이동하는 기능은 만들지 않았다(Tab과 Enter/Space로 선택).

## 영업 담당자 전달 안내문
> 공통 `DateEditor`의 달력 팝업이 새 공통 컴포넌트(`shared/components/calendar`)로 바뀌었습니다. 한국어로 표시되고 연·월을 드롭다운으로 고를 수 있습니다. `DateEditor`의 props, 입력 규칙(직접·축약 입력, blur 정규화), `disabled` 동작은 그대로이고 영업 화면 코드는 수정하지 않았습니다. 팝업 내용을 바꾸고 싶으면 선택 prop `renderCalendar`를 쓰면 됩니다. 달력의 "오늘"은 이동·표시용 브라우저 날짜이며 서버 날짜 기본값 규칙과는 무관합니다.
