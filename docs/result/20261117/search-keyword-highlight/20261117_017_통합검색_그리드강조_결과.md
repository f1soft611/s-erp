# 통합검색어 그리드 강조 결과

## 커밋 제목/내용
- 제목: `feat(grid): 통합검색어 일치 글자 빨간색 강조 (highlightSearch)`
- 내용: F1-Grid에 `highlightKeyword` / 컬럼 `highlightSearch` / `F1GridHighlightText` 추가, 영업관리 현황 5종 및 통합검색이 있는 그리드 화면에 적용, 문서·테스트 갱신

## 공통
- `highlightKeyword`(조회에 적용된 검색어)와 컬럼 `highlightSearch`로 대소문자 무시 부분 일치 글자를 `error.main` 색으로 표시.
- 성능: 강조 컬럼이 없거나 검색어가 비면 값을 내리지 않아 memo 유지, 비강조 컬럼 셀은 `undefined`를 받아 재렌더 안 함, `indexOf` 사용(정규식 없음), 컬럼 배열은 검색어와 무관.

## 적용 화면 (실제 검색되는 컬럼만 지정)
- 영업: 수주현황, 견적현황, 출하현황, 출하계획현황, 거래명세서현황
- 구매/그룹웨어: 구매요청현황, 구매발주현황, 문서현황, 자료실(파일 트리)
- 기준정보: 창고, 품목-거래처 단가, 자재, 거래처, 공통코드(그룹)
- 설정/기타: 역할, 모듈, 기안양식, 작업표준 레시피
- 제외: 메뉴관리, 공정(F1Tree 구조, 그리드 아님)
