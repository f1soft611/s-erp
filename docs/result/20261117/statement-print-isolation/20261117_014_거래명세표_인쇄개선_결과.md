# 거래명세표 인쇄 영향 범위 및 공용 금액 변환 결과

- 작업번호: 20261117_014
- 근거 게시물: [Flow 게시물](https://flow.team/l/QzdDk)

## 결과

- 거래명세표는 `shared/utils/amountInKorean.ts`를 사용하고, 거래명세표 전용 데이터 파일의 중복 변환 함수를 제거했다.
- 인쇄 CSS의 전역 숨김/출력 규칙을 `body.statement-printing` 조건으로 제한했다. 인쇄 호출 중에만 클래스를 추가하며, 호출이 끝나면 제거하고 이미 외부에서 설정한 클래스는 유지한다.
- 브라우저 PDF 검증에서 화면 루트가 숨겨지고 거래명세표 인쇄 호스트만 표시되는 것을 확인했다. A4 PDF는 1페이지이며, 미리보기는 375/768/1280px에서 확인했다.
- 브라우저 테스트 mock에 서버 기준일 응답을 추가해 필수 명세일 검증을 통과한 뒤 저장·인쇄 흐름을 실행하도록 보완했다.
- 백엔드 및 DB 변경은 없다.
