# F1-Grid 상세검색 빠른 날짜 세팅 결과

## 변경 내용
- 상세검색에 필수 날짜 범위(기준일 고정)가 있을 때만 날짜 칸 옆에 빠른 날짜 버튼(오늘, 이번주, 이번달, 전월, 최근 30일)을 표시한다.
- 버튼 클릭 시 `GET /api/v1/common/system-date` 서버 날짜 기준으로 시작일·종료일을 채우며, 자동 조회는 하지 않는다. 조회 실패 시 브라우저 시계로 대체하지 않고 오류 문구를 표시한다.
- 영업관리 현황 날짜 필드(견적, 수주, 출하계획, 출하, 명세)는 `span` 2로 통일: 시작일·종료일 각 1칸 + 빠른 날짜 버튼.
- 견적서현황·수주현황 `search.span`을 4에서 2로 조정했다.
- 견적서현황·수주현황 상세검색 필드를 같은 속성끼리 행으로 묶었다: 기준일 → 텍스트(span 1) → 선택(span 1) → 부가 날짜(span 2).
- 변경 파일: `shared/components/PageSearchArea.tsx`, `shared/components/page-search/quickDates.ts`, `pages/sales/quotation/status/data/quotationStatusColumns.tsx`, `pages/f1-grid-docs/F1-GRID.md`, `tests/page-search-area-detail.test.tsx`
