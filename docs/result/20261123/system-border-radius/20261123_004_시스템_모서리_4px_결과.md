# 시스템 모서리 4px 통일 결과

## 변경

- MUI 공통 테마와 화면·공통 컴포넌트의 사각형 모서리를 4px로 변경했다.
- 연결된 입력과 막대의 0px 접합, 원형 요소 및 전체 화면 다이얼로그의 직각 경계를 유지했다.
- F1-Grid 문서와 관련 반경 테스트 기대값을 갱신했다. API와 DB 변경은 없다.

## 검증

- 변경 전 공통 테마 테스트에서 기존 6px로 인한 실패를 확인했다.
- `npm run build`, `npm run lint` 성공. 빌드의 청크 크기 및 lint 경고가 출력되었다.
- 공통 다이얼로그·달력·F1-Grid 폼 관련 테스트 96개 성공. 일부 기존 MUI 경고가 출력되었다.
- 공통 테마·배지·피드·공지 관련 테스트 성공. 공지 테스트에서 React `act` 경고가 출력되었다.
- 문서 작성 테스트 전체 실행은 최초 4개 실패, 단독 전체 재실행은 3개 시간 초과로 실패했다. 제한을 15초로 늘린 전체 재실행에서는 155개 통과, 글자 굵기 검사 1개가 실패했다. 반경 관련 2개와 각 실행에서 실패한 사례를 추려 단독 재실행했을 때는 모두 성공했지만 전체 스위트의 실패는 해결되지 않았다.
- 사용자 요청에 따라 추가 전체 실행은 중단하고 공통 테마·배지·다이얼로그·달력·F1-Grid 폼 131개와 문서 배지 2개를 대상으로 재검증해 모두 통과했다. 전체 테스트는 사용자가 별도로 진행한다.
- 실제 브라우저의 합성 F1-Grid 문서 화면에서 375/768/1280px 가로 넘침이 없고 각 뷰포트에서 4px 버튼 반경을 확인했다.
