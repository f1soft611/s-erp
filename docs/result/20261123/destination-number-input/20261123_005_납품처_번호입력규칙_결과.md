# 납품처 번호 입력 규칙 결과

- 거래처 관리에는 번호 형식이 이미 적용되어 있어 직전 작업 맥락에 따라 납품처 관리를 대상으로 해석했다.
- 사업자번호 및 이동전화·전화·팩스번호에 거래처 관리와 같은 공통 F1-Grid 입력 형식·자리수 검증을 적용했다. 기존 선택 입력과 중복 정책은 유지했다.
- 행 폼과 셀 입력 회귀 테스트에서 자동 하이픈, 사업자번호·전화번호 자리수 오류를 확인했다. 기존 빈 값 허용 테스트도 유지된다.
- 관련 4개 테스트 파일 70개 통과. 최초 병렬 실행에서 거래처 페이지의 기존 테스트 1개가 시간 초과했으나 재실행 시 통과했다.
- 프론트엔드 빌드 성공(기존 번들 크기 경고), 수정 파일 lint 성공.
- 가상 인증 및 가상 API를 사용한 실제 브라우저 폼 입력 확인: [375px](screenshots/destination-375.png), [768px](screenshots/destination-768.png), [1280px](screenshots/destination-1280.png). 실제 서버 연동 검증은 아니다.
