# 납품처 관리 그리드 상태 및 저장 로딩 보정 결과

## 변경 내용

- 원본 값이 `null` 또는 `undefined`인 기본 텍스트 셀을 빈 값으로 확정해도 원본을 유지하여 우측 그리드가 dirty로 바뀌지 않게 했다.
- 저장 성공 시 공통 성공 토스트를 표시한다. 저장 후 거래처·납품처 재조회 중 기존 행을 유지하고 그리드 로딩 오버레이를 띄우지 않으며, 저장 버튼 진행 표시와 오류 메시지도 유지한다.
- 저장 직후 변경 행을 그리드에 확정해 재조회 응답 전 수정값이 이전 값으로 깜박이며 되돌아가는 현상을 방지한다. 재조회 완료 시 서버 응답값으로 갱신한다.
- 거래처를 선택하지 않은 초기 화면에도 우측 납품처 그리드를 표시한다. 거래처 선택 전 추가·편집은 비활성화한다.
- 기존 사용자 미커밋 변경은 보존했다. 빌드에서 확인된 거래처 No 컬럼의 잘못된 rownumber 필드(`salesDestinationId`)는 `DestinationCustomer`의 실제 키인 `customerId`로 맞췄다.

## 원인 및 회귀 검증

- 텍스트 셀 편집기는 nullish 값을 빈 문자열로 보여 주고, 편집 확정 시 `''`를 반환해 실제 값 변경이 없어도 원본 null과 다르게 dirty 상태를 만들 수 있었다. 빈 텍스트 편집 확정에서 nullish 원본을 보존하도록 수정했다.
- 저장 성공 때 그리드를 재마운트하면 부모가 보유한 재조회 전 행으로 초기화되어, 이미 저장한 편집값이 재조회 응답 전 잠시 이전 값으로 보였다. 변경 행을 `acceptSavedRows`로 확정하고 재마운트를 제거해 현재 값을 유지한다.
- 회귀 테스트는 nullable 텍스트 `null`/`undefined`, 납품처의 빈 사업자번호 셀 무변경 확정, 거래처 미선택 초기 그리드 표시, 저장 성공 토스트, 저장·재조회 중 저장값 및 그리드 유지와 저장 버튼 진행 상태를 확인한다.
