# 결과 문서

## 작업명

메뉴관리 검색조건 개선(스켈레톤 + 필수선택), 새로고침 시 메뉴없음 UX 개선, NotFound 페이지 추가

## 변경 내용

### 1) 메뉴 관리 페이지의 조건 기반 조회/저장 제한

- 모듈과 권한이 모두 선택되어야만 메뉴 목록 조회가 실행되도록 조건을 추가했습니다.
- 조건 미충족 시 안내 문구를 노출하고, 메뉴 트리 영역이 비활성화된 상태로 유지됩니다.
- 저장 액션은 선택 조건이 불완전할 때 자동으로 비활성화되도록 막아 두었습니다.

### 2) 대시보드 로딩 상태 UX 개선

- 메뉴 데이터 로딩 중에는 스피너를 노출하도록 변경했습니다.
- 실제로 접근 가능한 메뉴가 없을 때만 "접근 가능한 메뉴가 없습니다" 문구를 보여주도록 조건을 분리했습니다.

### 3) NotFound 페이지 추가

- 정의되지 않은 경로에서 인증 상태와 무관하게 전용 404 페이지가 보이도록 라우트를 수정했습니다.
- 돌아가기 버튼은 기존 인증 상태 기반 이동 로직을 유지하면서 별도 페이지로 연결합니다.
