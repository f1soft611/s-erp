## 1. 구현 범위

### DB
- 신규 `tb_item_default_supplier`(품목당 매입 기본 거래처 1건, 유일키 `(tenant_id, material_id)`), `tb_item_partner_price.order_type` 추가.
- 기존 데이터 이관: 매입 단가를 가진 거래처가 한 곳뿐인 품목만 기본 거래처로 지정(5건, `created_by = 'migration'`).
- 스크립트: `docs/database/20261120/20261120_006_*`(생성·변경이력·롤백), `backend/DATABASE` 동일 복사, `db-schema.md` 갱신. 사용자가 적용했다.

### 백엔드
- `ItemPriceLookupService`(공통 단가 조회): 단가·기본 거래처 테이블은 이 서비스만 읽는다. 선택 규칙은 기본 거래처 단가 → 공통단가 → 빈칸, 기준일 유효·시작일 최신·가격 ID 최신.
- `ItemDefaultSupplierService`: 지정·해제·자동 정리(매입 단가가 없어진 품목).
- 단가 저장(`save-batch`): `orderType`, `defaultSupplier`(true 지정 / false 해제 요청 / 생략 변경 없음), 응답 `clearedDefaultMaterialIds`. 기본 거래처 표시만 바뀐 저장은 단가 행을 갱신하지 않는다. 엑셀 검증(발주구분·기본거래처)과 조회 필터 `NO_DEFAULT_SUPPLIER` 추가.
- 구매요청확정: `request-details`가 미확정 행에 기본 거래처·단가·발주구분을 채운다(`baseDt` 선택, 기본 서버 오늘). `unit-price` 응답에 `orderType` 추가. 확정 모듈의 자체 단가 쿼리는 삭제하고 공통 서비스를 호출한다.

### 프론트엔드
- 단가등록: "공통단가" 용어 변경, 품목 기준 부모 행 "매입 기본 거래처", 자식 행 "기본 거래처" 체크박스(같은 품목의 다른 행 자동 해제)·"발주구분", 거래처 기준·이력 조회·행 폼 열 추가, 검색 "매입 기본 거래처 미지정", 엑셀 선택 열 `발주구분`·`기본거래처`(12열 양식도 읽음), 서버 자동 해제 안내 메시지. 그리드 `storageKey` v 번호 상향.
- 행 폼(수정·등록) 배치 통일: 품목 기준·거래처 기준 폼 모두 맨 위 그룹에 거래처 정보를 비활성(읽기 전용)으로 보여 주고(기존에는 수정 시 거래처 칸이 폼에서 숨겨졌다), 그 오른쪽에 "기본 거래처" 체크박스를 둔다. 체크박스는 거래처가 있는 매입 단가에서만 보이고 단가가 있어야 체크할 수 있다. 품목(부모) 행 폼에는 품목 정보만 읽기 전용으로 보인다. 같은 품목의 다른 거래처 행 체크 해제는 폼 적용(변경 반영) 뒤에 처리해, 폼을 취소하면 기존 기본 거래처 표시가 유지된다.
- 구매요청확정: 요청 불러오기로 채워진 구매처·단가·통화·부가세·외화단가·발주구분을 행에 반영하고 금액을 계산한다. 구매처를 바꾸면 응답에 발주구분이 있을 때만 덮어쓴다.

## 2. 사양과 다른 점 · 미구현
- 확정 화면의 단가 기준일은 확정일이 아니라 서버 오늘 날짜다(요청 불러오는 시점에 확정일이 비워졌다가 서버 날짜로 채워지므로 같은 값). `baseDt`는 프론트에서 보내지 않는다.
- 거래처 기준 탭 "기본" 열 머리글 툴팁(안내 문구)은 만들지 않았다.
- 거래처 기준 탭은 거래처 하나만 보여 주므로 같은 품목의 다른 거래처 체크를 화면에서 해제하는 처리는 없고, 서버가 품목당 하나를 보장한다. 단가 이력 조회 탭의 폼은 조회 전용이라 확인하지 않았다. 거래처 기준 탭의 등록 폼(단가 추가)도 따로 확인하지 않았다.
- 품목 기준 엑셀(`itemPriceOverviewExcel`)에는 발주구분·기본 거래처 열을 추가하지 않았다(사양 범위 밖). 거래처별 단가 엑셀 업로드에만 추가했다.

## 3. DB MCP 확인 근거 (읽기 전용 `s-erp-postgresql-readonly`)
- `tb_item_default_supplier` 5건, `order_type` 입력된 단가 0건, 공통코드 `PURCHASE_ORDER_TYPE` 항목 10건.
- 공통 단가 조회 SQL(`selectDefaultSupplierPrices`와 같은 LATERAL 쿼리)을 실제 DB에 읽기 전용으로 실행: 기본 거래처가 있는 품목은 거래처·단가가 채워지고, 유효 단가가 없는 품목(품목 6)은 거래처만 나온다.
- 공통코드 테이블 컬럼(`common_code_group_id`, `group_id`, `item_code`, `item_nm`)이 SQL과 일치함을 확인.
