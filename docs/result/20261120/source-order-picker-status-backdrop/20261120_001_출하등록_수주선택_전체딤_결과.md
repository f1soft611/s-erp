# 출하등록 수주 선택 상세검색 전체 딤 결과

## 작업 내용

- 기존 딤 레이어가 `SourceOrderPicker` 본문 영역에만 있어 모달 제목과 하단 액션은 현황의 전체 화면 딤과 다르게 보였다.
- 상세검색이 열릴 때 `CommonDialog.overlay`로 같은 `rgba(15, 23, 42, 0.12)` 레이어를 모달 전체에 적용했다. 상세검색 영역은 딤 위에 선명하게 두고, 바깥 앱 화면의 기존 모달 backdrop은 변경하지 않았다.
- 통합검색 입력의 outlined 배경을 현황 페이지처럼 `background.paper`로 지정해, 투명 입력 배경을 통해 전체 딤이 비치지 않게 했다.
- 그리드 `inert` 동작은 유지했다.
- 사양 및 F1-Grid 대상 선택 다이얼로그 검색 패턴 문서를 갱신했다.

## 검증

- 회귀 테스트는 기존 본문 내부 레이어에서 실패하고 `CommonDialog` 직접 자식 레이어 적용 후 통과했다.
- 통합검색 입력의 불투명한 배경을 검증하는 회귀 테스트는 기존 투명 배경에서 실패하고 `background.paper` 적용 후 통과했다.
- 출하 화면 테스트 32개 통과
- 프론트엔드 빌드 통과 (기존 대형 번들 경고)
- 변경 파일 Oxlint 통과
- 브라우저에서 375px, 768px, 1280px 확인: 제목·그리드·하단 액션이 같은 딤 색상으로 덮이고 상세검색 패널은 선명하게 유지된다.
