# 20261120_007 사원 선택 도움창 다중 선택·크기 고정 결과

기준: [작업지시서](../../../directions/20261120/20261120_007_hr-employee-picker-multiple_작업지시서.md), [계획서](../../../plan/20261120/20261120_007_hr-employee-picker-multiple_계획서.md), [상세사양서](../../../spec/20261120/20261120_007_hr-employee-picker-multiple_상세사양서.md)

## 1. 변경 내용
- **크기 고정**: 사원이 없을 때 나오던 "조회된 사원이 없습니다." 안내 영역을 없애고(표의 "데이터가 없습니다"만 사용) 오른쪽 영역 높이를 고정했다. 같은 자리에 나올 수 있는 메시지는 조회 오류뿐이며 오류가 나도 표 영역만 줄어든다.
- **다중 선택 옵션**: `selectionMode="multiple"` + `onApply(options[])`, `selected`(초기 선택), `maxSelect`(최대 인원). 체크 열로 고르고 푸터 "선택 N명 / 취소 / 적용(N명)", 안내 줄에 "현재 목록 전체 선택·선택 해제". 부서·검색을 바꿔도 선택 유지, 더블클릭은 적용하지 않음, 0명 적용 가능, 한도 초과는 안내 줄에서 알림. 기본(단일) 동작은 그대로(창고 담당자 변경 없음).
- 서버·DB 변경 없음. 다중 선택을 쓰는 화면은 아직 없다(첫 사용처가 생기면 연결).

## 2. 검증
| 항목 | 결과 |
|---|---|
| 프론트 테스트 | 도움창 20(다중 6 신규 포함: 체크 순서대로 적용·더블클릭 미적용·부서 이동 후 유지·초기 선택/전체 선택/0명·최대 인원·다시 열면 초기화) + 담당자 선택 7 통과, `tsc` 오류 없음 |
| 실서버(창고 담당자 선택, 1280px) | 전체 인원과 사원 없는 부서(영업팀 외부)의 도움창 크기 모두 990×585로 동일, 표 빈 문구 1개·별도 안내 없음 |
| 미확인 | 다중 선택 화면은 사용처가 없어 브라우저로 확인하지 못했다(테스트로만 검증) |

## 3. 복사용 커밋 메시지
제목: `feat(picker): 사원 선택 도움창 다중 선택 옵션 추가, 빈 목록 안내 제거로 창 크기 고정`

내용:
- selectionMode 'multiple'(onApply·selected·maxSelect), 부서·검색 이동 시 선택 유지
- 빈 목록 별도 안내 영역 제거, 오른쪽 영역 높이 고정
