# 20261120_004 창고등록 담당자 선택에 사원 선택 도움창 연결 결과

기준: [작업지시서](../../../directions/20261120/20261120_004_warehouse-manager-picker_작업지시서.md), [계획서](../../../plan/20261120/20261120_004_warehouse-manager-picker_계획서.md), [상세사양서](../../../spec/20261120/20261120_004_warehouse-manager-picker_상세사양서.md)

## 1. 변경 내용
- 창고관리의 **담당자 칸을 드롭다운에서 선택 버튼(돋보기) + 사원 선택 도움창**으로 바꿨다(F1Grid `type: 'code'` + `onOpenCodePicker`, 거래처 분류 선택과 같은 방식). 표 셀과 창고 등록·수정 행 폼 모두 같은 도움창을 연다.
- 사원을 더블클릭하면 **담당자와 담당부서가 같은 행에 함께** 적용된다(`toManagerPatch`). 부서가 없는 사원이면 담당부서를 비운다.
- **선택 해제**: 사원 선택 도움창에 선택 속성 `onClear`를 추가했다. 주면 도움창 왼쪽 아래에 "선택 해제" 버튼이 나타나고 누르면 담당자·담당부서를 비운다(`code` 칸은 직접 지울 수 없어서 필요했다). 주지 않으면 버튼은 없다.
- 직접 값을 바꾸는 것은 "사원 선택으로 담당자를 선택해 주세요." 오류로 막는다.
- 더 이상 쓰지 않는 사용자 목록 조회(`GET /api/v1/co/master/warehouses/users`)를 프론트에서 제거했다(화면 로드 시 호출 0회 확인). **백엔드 API와 저장 계약은 그대로**다.

## 2. 검증
| 항목 | 결과 |
|---|---|
| 프론트 테스트 | 사원 선택 도움창 14건(선택 해제 3건 추가), 창고 담당자 칸·패치 7건, 창고 페이지 초기 오류 포함 관련 파일 통과. `tsc`·lint 오류/경고 없음, `f1-grid-storage-keys` 통과. 변경 전에 새 테스트 실패(red) 확인 |
| 실서버·브라우저 | 8건 통과: 화면 로드 시 사용자 목록 호출 0회, 도움창에 선택 해제 버튼, 선택하면 담당자 채움, 저장 후 서버에 담당자(관리자)·담당부서(임원) 기록, 재조회 후 수정 폼에 담당자 표시, 선택 해제 시 비움, 해제 후 저장하면 서버에서도 null, 페이지 오류 없음 |
| 백엔드 | 변경 없음 |

## 3. 확인한 사항(변경 아님)
- 창고 등록·수정 행 폼에는 **담당부서 칸이 원래 보이지 않는다**(읽기 전용 칸은 표에만 있음). 부서는 선택 시 자동으로 채워져 저장되고 표의 담당부서 열에 보인다. 이번 작업에서 바꾸지 않았다.
- 점검용 창고(`점검창고*` 3건)는 실서버 점검 후 불용 처리했다. 창고 삭제 기능은 없다.
