# 20261120_006 창고 미사용(사용여부) 관리 결과

기준: [작업지시서](../../../directions/20261120/20261120_006_warehouse-unused_작업지시서.md), [계획서](../../../plan/20261120/20261120_006_warehouse-unused_계획서.md), [상세사양서](../../../spec/20261120/20261120_006_warehouse-unused_상세사양서.md)

## 1. 변경 내용
- **개념 정리**: 불용창고(`disuse_at`)는 불용재고·불용자재를 보관·처분하는 창고, **미사용**(`use_at`, 신규)은 창고를 쓰지 않는 상태다. 삭제가 아니라 상태만 바꾼다.
- **DB**: `tb_warehouse.use_at CHAR(1) NOT NULL DEFAULT 'Y'` + Y/N 제약([20261120_003](../../../database/20261120/20261120_003_add_warehouse_use_at.sql)), 점검 창고 3건을 불용창고 해제·미사용으로 정리([20261120_004](../../../database/20261120/20261120_004_fix_inspection_warehouses.sql)). 롤백·변경 이력·`db-schema.md` 갱신. **작성만 했고 적용 전**.
- **서버**: 조회 `useAt` 조건, 저장(기본 Y, Y/N 검증), 삭제불가 창고는 미사용 불가("삭제불가 창고는 미사용으로 변경할 수 없습니다."), 삭제 안내 "미사용으로 변경해 주세요.", 구매 확정의 창고 확인에 `use_at='Y'` 추가.
- **화면**: 사용 체크 열(행 폼 운영설정 첫 칸), 상세검색 "사용"(사용 기본/미사용/전체), 기본 조회는 사용 중인 창고만, 미사용 행 흐리게, 구매 확정 창고 선택 목록에서 미사용 제외. 그리드 저장 키 `co-master-warehouse-grid-v2`(열이 바뀌어 사용자별 저장된 열 설정은 초기화된다).
