## 재현 원인과 조치

### 병합 마지막 행 경계선

병합 셀은 시작 행의 DOM 노드가 여러 행을 span하지만, 기존 코드는 시작 행 자체가 그리드 마지막 행일 때만 하단 보더를 적용했다. `GridCell.tsx`에 `getGridCellBottomBorder`를 추가해 병합 시작 셀에도 하단 보더를 적용했다. 병합 내부의 숨겨진 셀은 기존처럼 보더를 그리지 않는다.

### 컬럼 필터 위치

기존 구현은 부모 컬럼 메뉴의 `필터` 항목을 필터 메뉴 앵커로 저장했다. 부모 메뉴가 닫히면 해당 항목도 제거되므로 MUI가 필터 메뉴를 잘못된 좌표에 표시할 수 있었다. `GridHeader.tsx`는 이제 컬럼 메뉴를 연 헤더 버튼을 별도로 보관하고, 필터 메뉴를 열 때 그 지속되는 버튼을 앵커로 사용한다.

## 검증

```text
npx vitest run tests/f1-grid.test.tsx -t "row merge|column filter"
```

- 결과: 4 passed, 123 skipped, 0 failed
- 추가 회귀 테스트:
  - 병합 span 시작 셀의 하단 경계선 계산
  - 필터 메뉴의 헤더 메뉴 버튼 앵커 유지

```text
npm run build
```

- 결과: TypeScript 컴파일 및 Vite 프로덕션 빌드 성공
- 기존 경고: 동적 import 청크와 500 kB 초과 청크 경고는 이번 변경과 무관하다.

```text

```

- 결과: 7 test files passed, 12 failed; 218 tests passed, 84 failed
- 이번 변경의 대상 회귀 테스트는 별도 명령에서 4 passed, 0 failed를 확인했다.
