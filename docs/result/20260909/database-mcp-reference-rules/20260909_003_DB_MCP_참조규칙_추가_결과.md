# DB MCP 참조 규칙 추가 결과

## 변경 파일

- `AGENTS.md`
- `.github/instructions/database-mcp.instructions.md`

## 적용 규칙

- DB 관련 작업은 구현 전에 `s-erp-postgresql-readonly` MCP로 현재 데이터베이스 계약을 확인한다.
- 조회는 `list_tables`, `describe_table` 순서로 수행하고, 메타데이터만으로 계약을 확인할 수 없는 경우에만 `query_readonly`를 사용한다.
- `query_readonly`는 읽기 전용 단일 문장으로 실행하며, `maxRows`는 100 이하로 제한한다. 집계 조회 또는 민감하지 않은 컬럼의 명시적 선택을 우선한다.
- MCP는 현재 상태를 확인하는 읽기 전용 증거일 뿐이다. 날짜별 마이그레이션 SQL, 변경 이력, 롤백 스크립트 절차는 계속 필수로 유지한다.
- MCP를 사용할 수 없으면 결과 문서에 실패 사유와 스키마 이력, Mapper XML, 도메인 코드 기반의 대체 확인 근거를 기록한다.
- 자격 증명, 접속 문자열, 개인정보, 계정, 인증, 테넌트 또는 기타 민감한 행 데이터는 코드, 테스트, 문서, 결과물, 채팅을 포함한 어떤 산출물에도 기록하지 않는다.
