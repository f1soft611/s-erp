# 공지사항 요약 실데이터 연동 결과

## 작업 개요

공지사항 요약 영역의 정적 샘플 통계와 하드코딩된 최근 이슈를 제거하고, 현재 공지 목록의 실제 조회수·댓글수·작성일·중요공지·첨부파일 데이터를 기반으로 표시하도록 연결했다.

## 주요 변경

- `noticeSummary.ts`에 현재 목록 기반 요약 통계와 최근 이슈 점수 계산을 추가했다.
- `NoticeFeedItem`에 `viewCount`, `createdAt` 원본을 연결했다.
- `NoticeSummaryPanel`을 계산된 통계와 최근 이슈 props 기반으로 전환했다.
- 최근 이슈는 `조회수 + 댓글수` 내림차순, 동점 시 작성일·게시글 ID 순으로 최대 3개 표시한다.
- 빈 목록에서는 모든 통계를 0으로 표시하고 `최근 이슈가 없습니다.`를 표시한다.
- 백엔드·DB·API 계약은 변경하지 않았다.

## 검증 결과

- `npx vitest run tests/notice-summary.test.ts`: 통과, 2 tests
- `npm run build`: 통과
- 브라우저: 개발 서버 `http://127.0.0.1:4174/`에서 로그인 후 UI 클릭으로 공지사항 진입 확인
- 실제 렌더링 확인: 공지 요약의 전체 공지·이번 주·중요 공지·첨부 문서와 조회수+댓글수 점수순 최근 이슈 표시 확인
- 가로 오버플로: 375px, 768px, 1280px 검사 결과 모두 `overflow: false`

## 기존 실패 및 범위 판정

- `tests/notice-page.test.tsx`의 제목·본문 클릭 진입 테스트가 기존 피드 동작 계약 불일치로 실패했다.
- `tests/notice-page-local-updates.test.tsx`는 중복 텍스트 및 기존 요소 탐색 계약 등 18건이 실패했다.
- 위 실패들은 이번 요약 집계·패널 변경과 무관한 `NoticeFeedList` 동작 및 테스트 상태이며, 승인 범위 밖 수정은 하지 않았다.
