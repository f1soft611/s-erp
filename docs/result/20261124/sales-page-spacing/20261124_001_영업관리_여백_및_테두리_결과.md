# 영업관리 여백 및 테두리 결과

## 변경
- 영업관리 등록·현황·납품처·매출마감 본문 외곽을 모든 화면 크기에서 16px로 통일했다. embedded 등록 폼의 외곽 0은 유지했다.
- 현황 결과 알림의 좌우 및 상하 간격을 정렬하고 닫은 후 그리드 위 16px을 유지한다. 견적현황은 알림이 닫혀도 부모 조건이 참으로 남아 있던 문제를 인접 메시지 기준으로 수정했다.
- 납품처의 거래처·납품처 카드에 수주등록과 동일한 outlined 테두리를 적용했다.
- 수주·견적·출하·출하계획·거래명세서 등록의 상세 그리드와 카드 내용의 좌우 간격을 16px로 맞췄다.

## 검증
- 핵심 Vitest 13건, 추가 현황 닫기 2건 통과. `npm run build`, 변경 영역 `oxlint` 통과(기존 React effect 경고 및 빌드 청크 크기 경고 있음).
- 실제 브라우저 테스트 `node tests\sales-page-spacing.browser.mjs`: 모의 API 데이터로 영업관리 12개 페이지의 375/768/1280px 렌더링을 확인했다. 등록 본문과 그리드, 현황 안내 닫힘, 납품처 양쪽 카드 테두리 및 페이지 가로 오버플로를 확인했다. 출하계획을 제외한 현황은 각 크기에서 알림 표시와 재조회도 확인했다.
- 실제 인증된 데이터는 확인하지 못했다. 스크린샷은 `screenshots`에 저장했다. 모의 공통코드가 일부 없어 등록 화면에 안내가 나타날 수 있다.
- 최종 관련 Vitest 188건 묶음에서는 183건 통과, 수주등록 저장·수정 테스트 5건이 시간 초과됐다. 다른 브라우저 검증을 종료한 뒤 해당 5건을 단독으로 재실행해 모두 통과했다. 앞선 수주현황 상세 실패 6건도 최종 묶음에서는 통과했다.
