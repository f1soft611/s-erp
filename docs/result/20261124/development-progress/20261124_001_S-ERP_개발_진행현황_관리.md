## 2. 다음 진행내역

긴급 작업은 확인되지 않았다. 우선순위는 남은 실환경 검증과 이전 보고서의 미확인 백로그를 기준으로 정했다.

1. **[우선순위: 높음] 단가등록 저장·권한 및 구매요청확정 흐름 실환경 검증**
   - 목적: 결과 문서에서 미수행으로 기록된 단가 저장·거래구분별 권한·구매요청확정 실제 화면 흐름을 안전한 테스트 계정으로 확인한다.
   - 예상 결과: API·화면·권한 경계의 실환경 검증 근거를 추가한다.
   - 선행 조건: 테스트 계정, 비운영 데이터 또는 데이터 복구가 보장되는 검증 환경.

2. **[우선순위: 보통] 구매자재 후속 범위 재확인**
   - 목적: 2026-11-17 진행현황에서 남은 것으로 기록한 가입고·발주 삭제/취소 제한, 전자결재, 재고·검사 연계, 발주서 이메일/팩스 발송의 현재 상태와 요구사항을 재확인한다.
   - 예상 결과: 완료된 항목은 닫고, 남은 요구사항만 작업지시서로 구체화한다.
   - 선행 조건: 관련 최신 요구사항·데이터 계약 확인. 확인 전 구현 범위를 추정하지 않는다.

3. **[우선순위: 보통] 구매 확정·수주 현황 브라우저 확인**
   - 목적: 실제 데이터가 없어 결과 문서에서 확인하지 못한 구매 확정 요청 선택 창과 수주 현황 상세 다이얼로그를 점검한다.
   - 예상 결과: 화면에서 순번·필드 배치가 기대와 맞는지 기록한다.
   - 선행 조건: 안전한 테스트 데이터와 재현 가능한 브라우저 환경.

4. **[우선순위: 낮음] 이전 보고서의 보류 항목 재평가**
   - 목적: `plantId` 의미와 ExcelJS/uuid 의존성 권고의 결정 상태를 확인한다.
   - 예상 결과: 새 근거가 없으면 보류 상태를 유지하고, 새 근거가 있으면 별도 조사 작업으로 분리한다.
   - 선행 조건: 실제 사용처·공식 패치 여부에 대한 근거. ExcelJS/uuid 권고는 공식 수정 경로가 확인될 때까지 강제 override하지 않는다.
