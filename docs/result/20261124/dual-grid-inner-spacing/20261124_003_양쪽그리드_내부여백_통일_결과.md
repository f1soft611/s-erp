# 양쪽 그리드 내부 여백 통일 결과

## 작업 내용
- 공통코드 관리와 납품처 관리의 각 좌우 카드에서 그리드의 좌우·아래 여백을 8px에서 16px로 변경했다.
- 제목의 추가 좌우 여백을 제거해 제목과 그리드의 좌우 경계를 맞췄다. 기존 외곽 여백, 납품처 카드 테두리, 분할 및 그리드 높이 설정은 유지했다.
- 모바일도 요청된 16px을 유지한다. 좁은 화면에서는 그리드 내부 가로 스크롤이 필요할 수 있다.

## 검증
- 두 화면의 패널 회귀 테스트가 기존 8px에서 실패하고 수정 후 통과했다.
- 두 화면의 관련 테스트 56건, `npm run build`, `npm run lint`가 통과했다. 기존 테스트의 React act 경고, 빌드 번들 크기 경고 및 lint 경고가 출력되었다.
- 실제 브라우저에서 테스트용 빈 데이터로 375/768/1280px의 네 패널 여백·제목 정렬·그리드 높이·페이지 가로 넘침을 확인했다. [스크린샷](screenshots).
- 기존 그리드 자체, API 및 데이터 계약은 변경하지 않았다.
