# 20261012_005 전자결재 상세 패널 공지사항 UI 정합성 결과보고서

## 작업 결과

- 전자결재 상세 패널 제목을 `문서 상세`로 고정하고 문서 ID 보조 표시를 추가했다.
- 읽기 전용 결재선, 작성자/작성일, 문서 제목·본문·본문 이미지 미리보기, 첨부, 좋아요/북마크 UI를 공지사항 피드 구조로 배치했다.
- 본문 내 이미지 위치에는 번호/대체 텍스트 참조를 남기고 실제 이미지는 미리보기 목록에서 한 번만 표시한다. 본문 이미지 노출은 직접 확인했고 본문/목록에 중복 이미지가 없다.
- USER 댓글과 SYSTEM 이벤트를 한 시간순 타임라인에 합쳤다. SYSTEM 행은 메뉴와 답글을 제공하지 않는다.
- 기안자 여부를 상세 응답의 `isDrafter`로 전달하고 프런트엔드에서 boolean을 검증한다.
- 본인 임시저장 및 허용된 결재대기 문서의 수정/삭제 메뉴를 제공한다. 삭제는 확인 후 호출하며 실패 시 다이얼로그 안에 오류를 표시한다.
- 백엔드 DELETE API는 문서 잠금, 소유자/상태/결재선 검증 후 논리 삭제와 `DELETED` SYSTEM 이벤트를 같은 transaction으로 처리한다.
- 목록, 요약, 알림, 상세, 참여자 접근, 잠금 및 임시저장 조회/수정에서 논리 삭제 문서를 제외한다.
- 운영 DB에 migration을 적용하지 않았다. 배포 전에 `20261012_002` migration을 적용해야 한다.
