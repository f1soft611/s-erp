# 20260828_005 F1-GRID 컬럼 관리 결과

## 구현 내용

- F1-GRID 각 헤더에 컬럼 메뉴 버튼을 추가했다.
- 헤더 메뉴의 `컬럼 목록`에서 전체 컬럼을 체크박스로 확인할 수 있다.
- 체크 해제 시 해당 컬럼을 즉시 숨기고, 다시 체크하면 복원한다.
- 마지막으로 표시된 컬럼은 숨기지 못하도록 체크박스를 비활성화했다.
- 숨김 상태는 현재 F1Grid 인스턴스에만 유지한다.
- 별도의 `컬럼 관리` 버튼은 추가하지 않았다.
- 숨김 컬럼을 제외한 표시 컬럼 기준으로 본문, 병합, 키보드 이동, 편집 인덱스를 계산한다.
