# F1-GRID 행 높이 조절 결과

## 구현 내용

- 행 ID별 높이 상태와 기본/최소/최대 높이 옵션 추가
- 행 하단 resize 핸들의 포인터 드래그 및 ArrowUp/ArrowDown 지원
- 기본 긴 텍스트 말줄임, 전체값 title 제공
- `wrapText` 컬럼의 높이 증가 시 줄바꿈 지원
- F1-GRID 테스트 페이지에 긴 품목명 샘플과 행 높이 조절 옵션 연결
- 행 높이 보정 유틸리티 및 상호작용 테스트 추가
- F1-GRID 가이드 문서 갱신
