# 20260828_003 F1-GRID 클립보드, 검증 및 에디터 확장 결과

## 구현 내용

- `clipboard/GridClipboard.ts`에 Excel 호환 TSV 파싱, 행/컬럼 순서 직렬화, 숫자/체크박스 값 정규화를 추가했다.
- `Ctrl+V`는 현재 포커스 셀을 시작점으로 TSV를 반영한다. 기존 행은 `updated`, 표시 범위를 넘는 행은 `createRow`로 생성해 `inserted` 상태로 관리한다.
- `Ctrl+C`는 선택 행 전체를 TSV로 복사하며, 선택 행이 없으면 현재 포커스 셀 값을 복사한다.
- `validation/GridValidation.ts`에 `required`, `min`, `max`, 사용자 정의 `validate` 규칙을 추가했다.
- `grid.validate()`는 삭제 행을 제외한 전체 행을 검사하고, 오류 셀은 error 색상과 메시지 `title` 툴팁을 표시한다.
- `autocomplete`, `code`, `currency`, `decimal`, `datetime`, `time` 에디터 타입을 추가했다.
- 코드 picker는 동기 `Partial<T>` 반환과 비동기 `applyPatch` 콜백을 모두 지원한다. 테스트 화면의 picker는 `itemCode`와 `itemName`을 함께 반영한다.
- `Insert`, `Delete`, `Backspace`, `Ctrl+D`, `Home`, `End` 키보드 동작을 추가했다. 행 선택 시 Delete/Backspace는 행 삭제를 우선하며, 선택이 없으면 현재 편집 가능 셀 값을 비운다.
- 셀 편집 시작 시 포커스 관리 effect가 editor 포커스를 셀 컨테이너로 덮어쓰던 문제를 수정했다. 편집 중에는 현재 셀 내부 editor에 포커스를 유지한다.
- 환경설정 > 시스템 관리 > `F1 Grid 테스트` 메뉴와 샘플 품목 Grid, 검증 명령, 코드 선택 다이얼로그를 추가했다.
