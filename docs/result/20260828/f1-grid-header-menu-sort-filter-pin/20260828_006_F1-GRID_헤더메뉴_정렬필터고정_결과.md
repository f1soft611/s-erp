# 20260828_006 F1-GRID 헤더메뉴 정렬/필터/고정 결과

## 구현 내용

- F1-GRID 헤더 셀에 `columnLine` 값과 무관하게 항상 세로 구분선(`borderRight`)을 표시했다.
- 컬럼 더보기 메뉴에 `오름차순 정렬`/`내림차순 정렬`을 추가했다. 다중 컬럼 정렬을 지원하며, 같은 컬럼에서 이미 선택된 방향을 다시 클릭하면 정렬이 해제된다. 헤더에는 방향 아이콘과 다중 정렬 순번을 표시한다.
- 컬럼 더보기 메뉴에 `필터`를 추가했다. 컬럼 타입별 연산자(문자열: contains 등, 숫자/날짜: 등호·범위, checkbox: Yes/No)를 제공하는 팝오버에서 값을 입력해 적용/초기화할 수 있으며, 필터가 적용된 컬럼은 헤더에 필터 아이콘으로 표시한다.
- 컬럼 더보기 메뉴에 `왼쪽 고정`/`오른쪽 고정`/`고정 해제`를 추가했다. 고정된 컬럼은 표시 순서상 좌/우측으로 재배치되고, 가로 스크롤 시 `position: sticky`로 화면에 고정 표시된다. 행 선택 체크박스 컬럼은 항상 왼쪽에 고정 표시된다.
- 정렬·필터는 클라이언트에 로드된 데이터 기준으로 동작하며, 서버사이드 쿼리 연동은 이번 범위에서 제외했다.
- 컬럼 고정 재정렬로 인해 컬럼 인덱스 기반 키보드 탐색/편집/복사·붙여넣기 로직을 표시 컬럼(`visibleColumns`) 기준으로 정합화했다.
