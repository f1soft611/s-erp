# 20260828_001 F1-GRID 소스 분리 결과

## 구현 내용

- 기존 `F1Grid.tsx`의 실제 orchestration 구현을 `core/ERPGrid.tsx`로 이동했다.
- 기존 import 호환을 위해 `F1Grid.tsx`는 `ERPGrid`를 `F1Grid` 이름으로 re-export한다.
- `GridHeader`, `GridBody`, `GridRow`, `GridCell`을 실제 렌더링 경로에 연결했다.
- 기존 editing 모듈을 유지하고 `types`, `selection`, `keyboard`, `utils` 책임을 별도 모듈로 분리했다.
- 실제 DOM 셀 focus를 활성 셀 상태와 동기화했다.
- Tab/Shift+Tab은 편집 가능한 셀을 기준으로 다음 위치를 계산한다.
- 외부 `rows` 변경은 pending change가 없을 때만 내부 baseline으로 재기반화한다.
- 신규/복제 행 ID가 기존 ID와 충돌하면 Grid 상태를 변경하지 않는다.
- 메뉴관리 새 메뉴, 삭제, 복제 및 변경 건수 통합 테스트를 추가했다.

## 현재 구조

```text
frontend/src/shared/components/f1-grid/
  core/
    ERPGrid.tsx
    GridHeader.tsx
    GridBody.tsx
    GridRow.tsx
    GridCell.tsx
  editing/
  selection/GridSelection.ts
  keyboard/GridKeyboard.ts
  types/grid.types.ts
  utils/grid.utils.ts
```

`GridFooter`는 현재 Grid가 footer UI를 소유하지 않고 메뉴관리 화면의 변경 요약이 page layer에 있기 때문에 추가하지 않았다. footer가 Grid 공통 기능으로 확정되는 후속 요구사항에서 별도 컴포넌트로 도입한다.

## 제외 범위

저장 API, validation, dirty dialog, clipboard, sorting, filtering, aggregation, pagination, virtualization, Excel export는 API와 화면 요구사항 확정 후 별도 작업으로 남겼다.
