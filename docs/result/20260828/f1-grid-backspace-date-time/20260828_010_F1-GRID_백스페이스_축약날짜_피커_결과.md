# 20260828_010 F1-GRID 백스페이스 및 날짜/시간 피커 결과

## 변경 사항

- F1Grid 전역 키보드 처리에서 `Backspace`를 제거했다. 편집 중 Backspace가 행 삭제나 셀 초기화를 호출하지 않는다.
- DateEditor에 `DD`, `MMDD`, `YYMMDD`, `YYYYMMDD` 숫자 입력 정규화를 추가했다.
  - `01` -> 현재 연월의 01일
  - `0701` -> 현재 연도의 07월 01일
  - `250604` -> 2025-06-04
  - `20260801` -> 2026-08-01
- 잘못된 날짜는 자동 보정하지 않도록 검증했다.
- 설치된 MUI X 버전과 맞지 않는 피커 prop을 제거해 TypeScript 빌드를 정상화했다.
- 시간 피커 버튼 클릭 회귀 테스트를 추가했다.
- autocomplete 관련 코드는 이번 작업에서 변경하지 않았다.

## 검증 결과

- `npm run test -- tests/f1-grid.test.tsx`: 64개 통과
- `npm run test`: 9개 테스트 파일, 92개 테스트 통과
- `npm run build`: TypeScript 및 Vite 빌드 성공
- 빌드에는 기존 번들 크기 경고만 남음
