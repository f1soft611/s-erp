## 2. 점검 결과 및 변경 사항

### 2.1 autocomplete 타입 작동상태 점검

- 기존 동작: `Enter` 키로 옵션 라벨과 정확히 일치하는 값을 입력하면 `AutocompleteEditor`가 `onSelectChange`를 호출해 옵션의 실제 `value`를 저장했다.
- **발견한 문제**: `Tab` 키로 셀을 이동하며 커밋하거나 포커스를 이동해 커밋하는 경우에는 이 매칭 로직을 거치지 않고 `core/F1Grid.tsx`의 `commitEdit`이 입력 텍스트(라벨)를 그대로 저장했다. 즉 옵션이 `{ value: 'done', label: '완료' }`일 때 `Tab`으로 커밋하면 `status` 필드에 `'완료'`(라벨)가 저장되고 `'done'`(값)이 저장되지 않는 불일치가 있었다.
- **수정**: `commitEdit`에서 `column.type === 'autocomplete'`이고 `column.options`가 있는 경우, 입력값이 옵션의 `label` 또는 `String(value)`와 일치하면 해당 옵션의 `value`로 정규화해 저장하도록 수정했다. 일치하는 옵션이 없으면 자유 입력 텍스트를 그대로 저장한다(자유 입력 허용 유지).
- 회귀 테스트 추가: `Tab`으로 커밋 시 옵션 값이 저장되는지 확인하는 테스트를 추가했다.

### 2.2 date/datetime/time 에디터 MUI 피커 적용

- 기존: `input type="date"` / `"datetime-local"` / `"time"` 브라우저 기본 컨트롤 사용
- 변경: `@mui/x-date-pickers`(신규 의존성, `dayjs` 어댑터 포함)의 `DatePicker`, `DateTimePicker`, `TimePicker`로 교체
  - `date`: 포맷 `YYYY-MM-DD`
  - `datetime`: 포맷 `YYYY-MM-DD[T]HH:mm` (`T`는 리터럴로 이스케이프해 일(day) 섹션이 올바르게 파싱/표시되도록 함)
  - `time`: 포맷 `HH:mm`
- `enableAccessibleFieldDOMStructure={false}`로 설정해 기존 커밋/키보드 흐름(`onKeyDown` 전달)과 셀 렌더링 스타일(`background.paper`, `fontSize: inherit`)을 유지했다.
- 값 문자열 계약(`value: string` / `onChange(value: string)`)은 변경하지 않아 `F1GridColumn`, 클립보드, 검증 로직 등 기존 공개 계약에 영향이 없다.
