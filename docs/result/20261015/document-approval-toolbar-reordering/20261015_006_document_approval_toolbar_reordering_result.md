# 문서 결재 툴바 재배치 결과

## 적용 내용

- 문서 피드/상세에서 사용하는 결재 툴바 레이아웃을 문서 기능 전용 컴포넌트로 분리했습니다.
- 승인 액션, 결재상태, 구분선, 상단고정, 더보기, 문서구분 순서를 유지하도록 구성했습니다.
- 기존 결재 권한 및 액션 처리 로직은 상세 피드 컴포넌트에 두고, 툴바 컴포넌트는 배치와 간격만 담당합니다.
- 결재선 접힘/표시, 진행 중 문서 삭제 제한 및 승인/취소 동작의 실제 브라우저 확인은 백엔드 API에 연결되지 않아 완료하지 못했습니다.

## 검증 결과

| 항목 | 결과 |
|---|---|
| `npx vitest run tests/document-approval-toolbar.test.tsx` | 통과: 2 tests |
| Frontend Problems 검사 | 툴바 및 통합 컴포넌트 오류 없음 |
| `npm run build` | 통과. 기존 큰 번들 경고 출력 (index JS 1,052.87 kB) |
| `git diff --check` | 통과 |
| 실제 문서 상세 화면 | 미확인: 상세 요청 실패 후 인증 화면으로 이동 |
| `mvn spring-boot:run` | 실행 불가: 8080 포트를 이미 사용 중인 프로세스가 있어 백엔드가 시작되지 않음. 기존 프로세스는 중단하지 않음 |

초기 확인에서 문서 상세 API는 `ERR_CONNECTION_REFUSED`였고, 이후 로컬 `http://localhost:8080/`은 HTTP 200 및 `S-ERP 시스템` 제목을 반환했습니다. 다만 포트 소유 프로세스는 현재 작업에서 실행한 백엔드가 아니며, 브라우저 인증 갱신이 실패해 로그인 화면으로 이동했습니다. 스크린샷은 문서작성 목록 페이지의 뷰포트 확인 자료이며, 결재 툴바 상세 화면의 시각 검증 자료는 아닙니다.

## 후속 확인

백엔드가 실행 가능한 상태에서 문서 상세를 다시 열어 결재 액션, 상태/구분 표시, 더보기 메뉴, 본문 접힘 시 결재선 노출을 확인해야 합니다.
