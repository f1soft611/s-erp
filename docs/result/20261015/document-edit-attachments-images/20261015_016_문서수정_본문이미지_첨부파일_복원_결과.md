# 20261015_016 문서 수정 본문 이미지·첨부파일 복원 결과

## 적용 내용

- 문서 수정 및 보완 후 재상신 시 상세 응답의 기존 첨부파일을 편집 모달에 표시한다.
- 기존 첨부파일은 저장 중 재업로드하지 않는다. 사용자가 제거한 파일만 기존 문서 첨부 삭제 API를 사용한다.
- 수정 모달은 현재 문서의 임베디드 이미지 API를 통해 이미지 Blob을 조회하고 Object URL로 미리보기한다. 원본 저장 HTML/JSON은 서버 이미지 URL을 유지하며 Blob URL은 저장하지 않는다.
- 이미지 조회 실패 시 깨진 이미지 링크를 남기지 않고 모달 오류 영역에 알린다. 임시 Object URL은 정리한다.
- 신규 첨부 업로드/재시도, 신규 문서 작성 및 상세 본문 이미지 처리 흐름은 유지했다.

## 원인

수정 모달은 `initialDocument.contentsHtml`만 편집기에 주입하고 `initialDocument.attachments`를 첨부 상태로 초기화하지 않았다. 상세 화면은 인증 API를 통해 임베디드 이미지 Blob을 로드하지만 편집기는 보호된 이미지 URL을 그대로 `<img>`에 표시해 인증이 적용되지 않았다.
