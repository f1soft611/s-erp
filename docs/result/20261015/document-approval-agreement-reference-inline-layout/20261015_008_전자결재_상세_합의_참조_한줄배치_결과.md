## 수정 내용

- 상세 합의·참조 그룹을 `64px minmax(0, 1fr)` 두 열 grid로 바꿔 각 제목을 참여자 목록 왼쪽 같은 행에 배치했다.
- 두 행의 최소 높이를 `72px`로 통일했다. 참여자 수가 늘거나 좁은 화면에서는 기존 참여자 콘텐츠 영역이 확장/줄바꿈하도록 유지했다.
- 합의 단계, 순번, 참여자, 상태와 참조 정보 및 승인 처리 동작은 변경하지 않았다.
- 문서작성 편집 결재선, API, 백엔드, DB는 변경하지 않았다.

## 미완료 검증 및 제한

실제 브라우저에서의 반응형 확인과 스크린샷은 요청에 따라 수행하지 않았다. 전체 테스트 기준 실행에서 확인된 기존 실패는 이번 UI 변경 범위에 포함하지 않았다. 초기 빌드 오류는 마지막 재실행에서 재현되지 않았으며, 별도 서비스/타입 파일은 수정하지 않았다. 현재 작업트리에는 다른 툴바 작업의 변경도 함께 존재하며, 해당 변경은 이 작업에서 수정하지 않았다.
