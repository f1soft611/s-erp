# 문서 작성·상세 결재선 순번 표시 통일 작업 결과

## 변경 사항

- 결재선 화면에서 함께 사용하는 `ApprovalSequenceBadge`를 추가했다.
- 작성 모달의 결재·합의 순번을 상세 화면과 같은 24px 원형 테두리 배지로 변경했다.
- 작성 모달 결재자 하단에서 순번과 이름을 가운데 정렬했다.
- 상세 화면의 승인 순번과 합의 단계 순번을 공통 24px 배지로 통일했다.
- 순번 값, 합의 단계별 그룹, 참여자 표시 및 결재 흐름은 유지했다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| 변경 전 전체 `document-write-page.test.tsx` 기준 실행 | 82개 중 71개 통과, 11개 타임아웃으로 실패. 약 287초 소요 |
| 순번 관련 집중 회귀 테스트 | 통과: 결재 모달, 합의 단계 순번, 상세 결재선, 합의 칩 등 4개 테스트 |
| 프론트엔드 빌드 | 통과 |
| Oxlint 대상 파일 실행 | 종료 코드 0, 오류 없음. 기존 컴포넌트 및 테스트 코드의 경고가 출력됨 |
| 작성 모달 브라우저 확인 | 1280px, 768px, 375px에서 결재·합의 배지 모두 24×24px 원형이며 숫자가 중앙 정렬됨. 결재자 순번·이름 행도 가운데 정렬되고 가로 넘침 없음 |
| 상세 결재선 브라우저 확인 | 1280px, 768px, 375px에서 승인 순번 배지 24×24px, 원형, 중앙 정렬이며 가로 넘침 없음. 확인 가능한 진행 중 문서에는 합의 단계가 없어 상세 합의 배지의 실제 데이터 화면은 확인하지 못했으나, 집중 회귀 테스트에서 합의 단계 순번을 검증함 |

전체 테스트 기준 실행에서 발생한 시간 초과는 본 변경과 관련된 집중 회귀 테스트 및 빌드 성공 여부와 별도로 기록했다. 브라우저에서는 작성 모달과 상세 결재선을 세 화면 폭에서 확인했다.

## 실행 명령

```powershell
npx vitest run tests/document-write-page.test.tsx --testNamePattern='adds the signed-in user|renders read-only system events|renders each selected agreement user|shares one sequence across an agreement stage'
npm run build
npx oxlint src/pages/groupware/documents/write/components/ApprovalSequenceBadge.tsx src/pages/groupware/documents/write/components/DocumentApprovalFields.tsx src/pages/groupware/documents/write/components/DocumentApprovalDetailFeed.tsx tests/document-write-page.test.tsx
```
