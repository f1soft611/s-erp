# 문서 공통 UI 테스트 복구 결과

- [계획서](../../../plan/20261118/20261118_007_document-component-tests_계획서.md), [상세사양서](../../../spec/20261118/20261118_007_document-component-tests_상세사양서.md).
- 툴바 테스트가 더보기 메뉴로 이동한 승인 액션의 과거 slot을 전달했다. 현재 상태·문서구분·구분선·고정·더보기 순서, 간격과 버튼 수를 검증한다.
- 링크 목적지를 외부 URL로 바꾸면 외부 미리보기가 남아야 하므로 전체 컨테이너 제거 기대가 잘못됐다. 기존 내부 카드 제거와 새 외부 카드의 목적지를 함께 검증한다. 원문 표시 텍스트 보존 단언도 유지했다.
- 클립보드 사례의 추가 오류는 `멘션 사용자 목록을 불러오지 못했습니다.`였다. 누락된 멘션 사용자 fixture를 제공해 공유 성공/실패 각각 정확히 1회, 반대 종류 0회 단언을 보존했다. 외부 미리보기는 합성 응답으로 격리했다.
- 기안양식 본문 변경 취소 확인의 현재 `계속` 버튼을 사용하며 임시 이미지 삭제 요청과 닫힘을 계속 확인한다.
