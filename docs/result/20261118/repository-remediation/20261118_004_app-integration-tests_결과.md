# 앱 통합 테스트 복구 결과

## 범위와 원인

- [작업지시서](../../../directions/20261118/20261118_001_repository-remediation_작업지시서.md), [계획서](../../../plan/20261118/20261118_004_app-integration-tests_계획서.md), [상세사양서](../../../spec/20261118/20261118_004_app-integration-tests_상세사양서.md).
- 로그인·사이드바·종합현황·최초 오류 테스트 4개 파일의 현행 문구, 명시적인 권한/메뉴 fixture, lazy 준비 및 데이터 조회 대기를 복구했다. 공통 setup과 시간 제한은 변경하지 않았다.
- 사이드바는 관련 없는 공지 로그인 팝업을 기존 로그인 테스트와 같은 방식으로 분리했다. 역할·메뉴 화면 검증은 인증 세션의 직접 진입 두 사례로 나누고, 기존 탐색·프로필·최근 메뉴·권한 단언을 보존했다.
- 메뉴 그리드는 조회 성공 시 `reloadToken`으로 재마운트된다. 이전 loading 그리드 내부에서 기다리지 않고 실제 행을 기다린 후 현재 그리드를 다시 취득한다.
- 수주현황 최초 오류 사례는 공통코드·서버 날짜 선행 조회를 성공시켜 실제 목록 요청 실패의 본문 대체와 헤더 보존을 검증한다.

## 입증된 로그아웃 결함

유효한 version 1 메뉴관리 세션을 저장한 회귀 테스트에서 로그아웃 후 세션이 남는 실패를 먼저 확인했다. `DashboardPage.handleLogout`은 공통코드 세션만 제거하고 있었다.

기존 키 상수 옆에 메뉴관리 세션 키를 선언하고 같은 logout 처리에서 제거하는 두 줄만 추가했다. 인증 API, 권한, 다른 페이지의 세션 수명, 백엔드와 DB는 변경하지 않았다. 키·기존 정리 helper·호출 순서와 유효한 회귀 fixture를 diff로 재검토했다.

## 검증

공유 설치는 교체하지 않았다. 전용 검증 worktree의 잠금 설치(Vitest 4.1.12 / Vite 8.3.8)와 `22bd60b8` 프론트 소스 오버레이에 이번 복구 변경을 반영했다. 이번 소유 파일 10개의 공유 작업 공간/검증 worktree hash 일치를 확인한 뒤 실행했다. 별도 작업의 미커밋 운영 변경은 포함하지 않는다.

| 검증 | 결과 |
|---|---|
| 사이드바 | 21 통과 |
| 로그인 | 10 통과 |
| 종합현황 | 20 통과 |
| 최초 오류 화면 | 14 통과 |
| 위 4개 + 메뉴관리 2개 + 공통 계약 4개 파일 동시 집중 검사 | 10개 파일, 159개 모두 통과 |
| `npm run typecheck` | 종료 코드 0 |
| `npm run lint` | 종료 코드 0, 오류 0 / 경고 206 |
| `npm run build` | 종료 코드 0, 큰 청크 경고 유지 |

경고 수는 최신 고정 소스 전체의 결과다. 최초 기준의 183개와 소스 기준이 다르므로 증가분을 이번 변경의 신규 경고라고 단정하지 않는다. 전체 프론트 테스트 통과나 최신 백엔드 재검사를 의미하지 않는다.

## 실제 브라우저

격리 프로필과 합성 API/인증 응답으로 실제 프로필 메뉴의 로그아웃을 확인했다. 세 폭 모두 합성 실행 표식이 유지되고 메뉴 세션과 인증이 제거되며 로그인 화면으로 돌아왔다. 문서 너비가 viewport 너비와 같아 가로 넘침도 없었다.

| 폭 | 메뉴 세션 제거 | 인증 제거 | 문서 너비 | 스크린샷 |

스크린샷의 개발용 안내 영역은 비식별 처리했다. 비식별 전 임시 이미지 3개, 임시 HTML, 생성한 브라우저 탭/프로필은 제거했다. 공유 서버는 종료하지 않았다.

## 남은 순서와 복사용 커밋 문구

테스트 복구 전체 단계는 진행 중이다. 남은 공지 댓글·전자결재·권한·그리드 실패를 해결하기 전 빠른 날짜 경합, 의존성 업데이트, PR/CI 단계로 넘어가지 않는다.

```text
fix(session): 로그아웃 시 메뉴관리 조회조건 정리

- 유효한 메뉴 세션 잔존 회귀 수정
- 앱 통합 테스트를 현재 메뉴·로그인·오류 화면 계약에 맞춤
```

커밋·푸시·병합은 하지 않았다.
