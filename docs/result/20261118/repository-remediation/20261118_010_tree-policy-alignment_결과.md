# 트리 정책 테스트 정합 결과

## 결과

- 최신 [20261014 공통 Grid 사양 §6](../../../spec/20261014/20261014_002_f1_grid_docs_overhaul_사양서.md)과 [20261021 Tree 사양](../../../spec/20261021/20261021_001_커뮤니티_자료실_업로드_F1Tree_상세사양서.md)에 맞춰 구형 정렬·필터 해제 테스트 두 개를 정정했다.
- 기본 props와 명시적 false props에서 헤더 정렬·필터 및 본문 해제 항목이 없고, 부모 Zulu → 자식 Beta → Alpha의 계층·형제 정렬이 보존됨을 검증한다.
- 일반 F1Grid 정렬·필터 적용/해제 회귀는 그대로 유지한다. F1Tree/F1Grid 운영 코드는 변경하지 않았다.

## 원인 정정

- 이전 전체 실행의 두 실패는 메뉴를 찾지 못한 실제 실패다. 당시 결과는 보존한다.
- 사양 006은 9월 9일 사양만 근거로 운영 회귀라고 판단했으나, 더 최신인 10월 문서가 계층 보호를 위한 비활성화를 명시했다. 운영 기능 추가 대신 테스트를 최신 계약에 맞추는 것이 올바르다.
- 단순 강제 속성 제거가 계층을 깨뜨린다는 이전 실험도 유효하므로 해당 운영 변경은 계속 적용하지 않는다.

## 검증

- 소유 exact-lock 검증 worktree에서 context-menu 33개, tree 29개, tree-projection 1개: **63/63 통과**, 제외 없음.
- 로그: 세션 산출물 `tree-policy-alignment.log`.
- root와 검증 worktree의 F1Tree/F1Grid hash 일치를 확인했다.
- 새 테스트에서 메뉴가 열린 동안 MUI가 배경 Grid를 접근성 트리에서 숨기는 점을 반영해, 메뉴를 닫은 후 최종 행 순서를 확인한다.
- 운영·UI 변경이 없는 테스트/문서 전용 단계이므로 신규 스크린샷은 해당 없음이다.
- 전체 프론트엔드 검증 완료를 의미하지 않는다. 다음 단계는 문서작성 시간 초과의 원인 확인이다.
