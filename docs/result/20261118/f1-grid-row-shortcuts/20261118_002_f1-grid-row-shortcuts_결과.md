# F1-Grid 행 단축키 수정 결과

품목관리는 우클릭 행 삭제를 끄지만, 셀 선택 후 `Delete`를 누르면 공통 F1-Grid가 해당 설정을 확인하지 않고 행을 삭제했다. 공통 키 처리에서 `Delete`, `Insert`, `Ctrl+D`를 각각 행 삭제·추가·복제 설정과 연결했다. 행 삭제가 차단된 경우 셀 값도 바뀌지 않으며 선택 행이 없는 편집 가능한 셀이나 이미지 셀의 값 지우기는 유지한다. 품목관리 화면 설정과 서버 권한은 변경하지 않았다.

- 수정 전 회귀 테스트에서 세 단축키가 비활성 설정을 무시하는 것을 재현했다. 수정 후 F1-Grid 및 이미지 회귀 테스트 205개가 통과했다.
- TypeScript 검사 통과. 변경 파일 lint 오류 0건, 기존 React 훅 경고 11건.
- 기존 개발 서버(`127.0.0.1:4173`)에서 공통 그리드를 테스트 데이터로 렌더링해 세 단축키의 허용·차단을 확인했다. 인증된 품목관리 화면에서 별도로 실행한 것은 아니다.
- `Delete` 차단 화면: [375px](screenshots/delete-disabled-375.png) · [768px](screenshots/delete-disabled-768.png) · [1280px](screenshots/delete-disabled-1280.png)

커밋 제목: `fix(f1-grid): 행 단축키에 기능별 허용 설정 적용`

커밋 내용: `Delete`, `Insert`, `Ctrl+D`가 기존 행 동작 설정을 따르게 하고 회귀 테스트와 문서를 갱신한다.
