# 20261013_001 공지사항·전자결재 피드 UI 공통화 결과

## 결과 요약

- 전자결재 상세 피드를 공지사항 공통 상세 패널 계약에 맞춰 표시하고, 카드 경계와 본문 접기/더보기 동작을 확인했습니다.
- 본문에 저장된 embedded image는 인증 Blob으로 불러와 썸네일로 표시하고, 선택 시 이미지 뷰어를 엽니다.
- 삭제된 댓글의 `writerId: null`을 유효한 목록 응답으로 처리해 댓글 및 이전 댓글 페이지 정보를 계속 표시하도록 보완했습니다.
- DB/API 스키마 변경은 없습니다.

## 수정 사항

- 전자결재 상세 본문 접기/더보기, 본문 이미지 썸네일/뷰어와 상세 카드 테두리를 추가했습니다.
- 댓글 응답 타입과 검증을 맞춰 삭제된 댓글의 nullable 작성자 ID를 허용했습니다.
- 삭제 댓글이 포함된 댓글 목록, 상세 UI, 이미지 미리보기 및 댓글 등록/재조회 회귀 테스트를 보강했습니다.

## 검증 결과

- `npx vitest run tests/document-approval-service.test.ts tests/document-write-page.test.tsx`: 73/73 통과.
- `npm run build`: TypeScript 검사 및 Vite production build 통과.
- 변경 파일 진단: 오류 없음.
- 브라우저에서 전자결재 상세 카드, 본문 `더보기`, 이미지 미리보기, 댓글 thread 및 입력란을 확인했습니다.
- 375px, 768px, 1280px에서 문서 가로 넘침이 없고 카드 경계 스타일이 적용됨을 확인했습니다.
- 테스트 환경에서 댓글을 등록해 목록에 반영되는 것을 확인한 뒤 해당 확인용 댓글을 삭제했습니다. 기존 `UI regression verification 20261013` 및 `전자결재 댓글 저장 확인 20261013 1033` 확인 댓글도 찾아 삭제했습니다.
- 실제 화면에서 `이전 댓글 보기`는 해당 문서에 이전 페이지가 없어서 표시되지 않았습니다. `hasPrevious: true` 응답의 버튼 노출 및 이전 페이지 prepend 동작은 회귀 테스트에서 확인했습니다.
