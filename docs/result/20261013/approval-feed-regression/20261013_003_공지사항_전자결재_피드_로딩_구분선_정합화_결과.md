# 공지사항·전자결재 피드 로딩 및 구분선 정합화 결과

## 작업 내용

- 공지사항 피드에서 첨부가 있을 때만 첨부와 반응 영역 사이 구분선을 유지하고, 첨부가 없을 때의 본문-반응 구분선과 반응-댓글 구분선을 제거했다.
- 전자결재 상세에서 본문 직후와 반응-댓글 사이 구분선을 제거했다. 결재선 및 첨부-반응 구분선은 유지했다.
- 문서 목록 로딩을 현재 보기 모드에 맞는 공지사항 공용 `ListViewSkeleton` / `FeedViewSkeleton`으로 변경했다.
- 상세 진입 시 본문이 펼쳐지는 동작을 유지하면서, embedded image 테스트가 실제 본문 이미지와 접힘 시 미리보기 동작을 함께 검증하도록 조정했다.
- API, 권한, 결재 흐름, 댓글 데이터 및 DB 계약은 변경하지 않았다.

## 검증

| 검증 | 결과 |
|---|---|
| 선택 separator·view-mode skeleton·상세 본문 회귀 테스트 | 통과: 6/6 |
| embedded image 상세 동작 단독 테스트 | 통과: 1/1 |
| 대상 3개 테스트 파일 통합 실행 | 115개 중 109개 통과, 6개 실패 |
| `npm run build` | 통과: TypeScript 및 Vite production build |
| `git diff --check` | 통과 |
| 브라우저 가로 폭 확인 | 375px, 768px, 1280px에서 document/body 폭이 viewport와 같음; 상세 패널의 scrollWidth와 clientWidth도 일치 |

통합 테스트 실패 중 1건은 상세 본문 기본 펼침 변경 후 이전의 접힘 상태만 기대하던 embedded image 테스트였다. 기대값을 현재 UX에 맞게 수정했으며, 해당 테스트는 단독 재실행에서 통과했다. 나머지 5건은 공지사항 초기 skeleton 기준선 실패 1건과 전자결재 테스트 timeout 4건이다. 초기 skeleton 실패는 이번 작업 전에도 확인된 기준선 실패이며, 전체 테스트 파일은 수정 후 다시 통합 실행하지 않았으므로 전체 통과로 간주하지 않는다.

테스트 실행 중 일부 기존 notice comment 테스트에서 React `act(...)` 경고가 출력됐다. 이번 변경의 회귀 실패로 보지는 않았으며, 관련 없는 테스트/동작은 수정하지 않았다.

## 전자결재 반응 영역 간격 추가 정합화

- 첨부 목록, 첨부/반응 구분선, 반응바, 댓글 섹션을 `approval-feed-footer`로 묶어 외부 `Stack spacing={2}`가 하위 요소 사이에 추가 간격을 삽입하지 않도록 했다.
- 첨부/반응 구분선은 공지사항과 동일하게 `my: 1.5`(상·하 12px)를 유지했다. 반응바와 댓글 섹션 사이의 구분선은 추가하지 않았다.
- 회귀 테스트에서 반응바와 댓글 섹션이 footer의 직접 자식이고 자체 `marginTop`이 0인지 확인한다. 기존 상세 구분선 개수도 함께 검증한다.
- 브라우저에서 375px, 768px, 1280px로 확인했다. 각 크기에서 document 폭은 viewport와 같았고, 상세 패널의 `scrollWidth`와 `clientWidth`도 일치했다. 구분선 여백은 상·하 12px, 반응바와 댓글 섹션의 자체 위쪽 여백은 0px로 확인했다. 댓글 내부 시작 위치는 공지사항과 동일하게 반응바 아래 16px 간격이다.

| Viewport | Document width | Detail panel client / scroll width | 캡처 |
|---|---:|---:|---|
| 375px | 375px | 281 / 281 | [reaction-spacing-375.png](./screenshots/reaction-spacing-375.png) |
| 768px | 768px | 551 / 551 | [reaction-spacing-768.png](./screenshots/reaction-spacing-768.png) |
| 1280px | 1280px | 898 / 898 | [reaction-spacing-1280.png](./screenshots/reaction-spacing-1280.png) |

대상 footer 간격 회귀 테스트와 production build가 통과했다. 전체 테스트 기준선 이슈는 위 검증 결과에서 설명한 기존 notice skeleton 실패 및 전자결재 timeout과 구분해 유지했다.
