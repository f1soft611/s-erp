# 20261013_001 공지사항·전자결재 피드 UI 공통화 결과보고서

## 작업 개요

공지사항을 기준으로 전자결재 피드 카드와 상세 패널의 공통 표시 UI를 재사용하도록 정리했다. API 호출, 권한, 댓글 cursor, 문서별 업무 로직은 각 기능에 유지했다.

## 반영 내용

- `FeedCard`를 추가해 공지사항·전자결재 좌측 카드의 공통 표현을 조립한다.
- `FeedReactionBar`, `FeedCommentsSection`을 추가해 반응/댓글 수, 이전 댓글, 댓글 thread 영역의 배치를 공유한다.
- 공지사항과 전자결재 상세에서 기존 첨부·댓글 컴포넌트와 공통 섹션을 함께 사용한다.
- 전자결재 상세 상단에는 읽기 전용 결재·합의·참조 참여자와 기안 정보를 둔다. 빈 결재선 placeholder는 표시하지 않는다.
- 전자결재 SYSTEM 이벤트에는 `시스템` 배지를 표시하고 기존 읽기 전용 동작을 유지한다.
- API 및 DB 계약은 변경하지 않았다.

### 테스트 실패 상세

- 공지사항 `keeps the initial skeleton loading state without showing a preloaded notice list`: 기대한 `notice-feed-skeleton` 요소를 찾지 못함. 이 실패는 구현 전 기준선에서도 확인된 항목이다.
- 전자결재 문서작성 테스트의 5초 timeout 4건: `retains and wraps the fourth approval in a three-column grid`, `keeps the empty approval selector without an unavailable-user message`, `marks an ambiguous upload as unknown and does not retry it automatically`, `shows a success toast when an ambiguous attachment is confirmed`. 별도 재실행에서는 뒤의 세 테스트가 통과했고 첫 테스트 timeout은 재현됐다. 대상 테스트 전체 완료 상태는 통과로 간주하지 않는다.

## 잔여 사항

- 대상 회귀 테스트에서 위에 명시한 timeout 및 기준선 실패가 남아 있어, 전체 테스트 통과를 주장하지 않는다.
- lint는 성공 종료했으나 저장소 전체 경고 109건이 출력됐다. 이번 작업과 무관한 경고는 범위에 포함해 수정하지 않았다.
- 브라우저에서 확인한 viewport는 가로 넘침이 없었다. 캡처는 데이터 비식별을 위해 텍스트/이미지를 숨긴 상태로 보관한다.
