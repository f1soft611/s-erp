# 출하계획 상세와 공통 도움창 결과

## 변경 내용

- 출하등록의 계획 선택과 출하계획등록의 수주 선택을 입력 필드 안의 돋보기로 변경했다. 기존 권한과 저장 상태에 따른 제한은 유지한다.
- 출하계획현황에서 계획번호를 눌러 출하현황과 같은 상세 패널과 더보기 메뉴를 연다. 상세보기와 수정은 공통 대화상자에서 제공하며 계획일·계획수량을 수정할 수 있다. 저장 실패 시 입력값은 유지한다.
- 이 작업 당시 계획 편집 대화상자는 등록 화면을 별도로 구현해 분할 행 추가·삭제를 제공하지 않았다. 이후 [공통 폼 개선](../shipment-picker-shared-form/20261109_003_출하계획_수주_도움창_결과서.md)에서 등록 화면과 폼을 공유하고 분할 편집을 제공한다.
- 공통 품목 도움창에 품목규격, 품목규격2, 단위, 품목모델명을, 거래처 도움창에 사업자번호와 대표자명을 표시한다. 값이 없는 정보는 생략한다.

## DB 확인

- 읽기 전용 `s-erp-postgresql-readonly` MCP의 테이블 메타데이터로 품목과 거래처의 관련 컬럼을 확인했다. 업무 데이터 행은 조회하지 않았다.
- 기존 API 응답 필드를 사용하며 백엔드, API 계약 및 DB 스키마 변경은 없다.

## 검증

- 관련 Vitest 4개 파일: 42개 통과. 번호 클릭, 권한, 조회 실패, 저장 실패 시 값 보존, AUTO/MANUAL 및 도움창 정보·선택을 확인했다.
- 프론트엔드 빌드 통과. 변경 파일 lint는 오류 없이 종료했으며 기존 출하등록 effect 관련 경고 1건이 있다.
- 기존 S-ERP 개발 서버를 재사용해 합성 데이터로 375, 768, 1280px에서 패널·상세보기·수정·품목/거래처 도움창·선택 아이콘을 확인했다. 문서 전체 가로 넘침과 브라우저 런타임 오류는 없었다.
- 상세보기·수정의 넓은 그리드는 모바일에서 그리드 내부 가로 스크롤을 사용한다.
