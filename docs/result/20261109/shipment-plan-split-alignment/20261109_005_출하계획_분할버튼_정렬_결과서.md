# 출하계획 분할 버튼 정렬 결과

분할 셀에서 삭제 버튼의 기본 최소 너비가 커 두 버튼 사이가 벌어졌다. 버튼 그룹을 셀 가운데로 정렬하고 삭제 버튼의 불필요한 너비를 줄였다.

분할 시 새 행을 선택한 행 바로 아래에 넣고 수량 셀을 즉시 편집한다. 서버는 수정 시 신규 행을 마지막 행 번호로 저장하므로, 다시 열 때 같은 수주 상세의 분할 행을 함께 표시한다. 기존 수량은 자동 배분하지 않고 신규 수량 0과 빈 계획일, 삭제 및 서버 검증을 유지한다. 등록과 현황 수정에 공통 적용된다.

375/768/1280px Chromium에서 합성 데이터로 버튼 한 개와 두 개의 중앙 위치, 여러 품목 가운데 분할 행 위치, 편집 포커스 및 분할·삭제를 확인했다.
