# 20261023_011 커뮤니티 자료실 올린 날짜 기본값/초기화 결과

## 변경 사항

- 자료실 `올린 날짜` 기본 범위를 공통 시스템 날짜 기준 달력상 최근 1년으로 적용했다.
- 서버 날짜 기본값이 준비되기 전에는 자료 목록을 조회하지 않으며, 날짜 조회 실패 시 오류와 재시도 동작을 표시한다.
- 상세검색 초기화는 최근 1년 날짜와 `전체` 파일 유형을 다시 적용하고 빠른 검색어를 비우며 현재 폴더를 유지한다.
- 날짜 요약은 브라우저 날짜가 아니라 적용된 검색 범위와 서버 날짜 기본값을 비교한다.
- 백엔드, API 계약 및 DB는 변경하지 않았다.

## 검증

- `frontend`에서 `npm run test -- tests/archive-page.test.tsx tests/archive-board-service.test.ts`
  - 결과: 2개 테스트 파일, 25개 테스트 모두 통과.
  - 초기 날짜/요청 필터, 기본값 대기 중 조회 차단, 실패 후 재시도, 초기화 동작과 목록 hook의 조회 gate를 확인했다.
- `frontend`에서 `npm run build`
  - 결과: TypeScript 검사 및 Vite 빌드 통과.
  - 참고: 번들 크기 경고가 출력되었으나 빌드는 성공했다.
- 저장소 루트에서 `git diff --check`
  - 결과: 통과.

## 브라우저 검증 제한

브라우저 자동화 세션이 자료실 대신 로그인 화면으로 이동했고, 로그인 화면을 통해 인증된 자료실에 접근하지 못했다. 사용자 결정에 따라 이 제한을 기록하고, 375px·768px·1280px 화면 확인과 스크린샷은 수행하지 않았다. 따라서 실제 브라우저 레이아웃과 화면 동작은 검증되지 않았다.
