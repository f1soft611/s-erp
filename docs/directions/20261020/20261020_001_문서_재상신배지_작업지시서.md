# 문서 재상신 시스템 메시지 배지 작업지시서

- 재현: `문서가 재상신되었습니다.` 메시지에 배지 대신 안내 아이콘이 표시된다.
- `RESUBMITTED` 이벤트를 `재상신` 배지로 표시한다.
- 결재신청과 같은 기존 PENDING의 info/filled를 재사용하고 8px 모서리와 읽기 전용 동작을 유지한다.
- 본문, 시각, 작성자, 정렬, 페이지, 취소 배지 및 API/DB 계약은 변경하지 않는다.
- 계획서 → 상세 사양서 → 실패 테스트 → 구현 → 관련 테스트/빌드/375·768·1280px 브라우저 검증 → 결과 및 스크린샷 기록 순서로 수행한다.
