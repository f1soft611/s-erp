# F1-Grid date format 작업지시서

## 요구사항 및 승인

- 문서현황을 포함한 공통 F1-Grid의 `type: 'date'` 컬럼에서 `format`으로 표시 형식을 지정한다.
- 미지정 시 기본 표시 형식은 `yyyy-mm-dd`다.
- 2026-10-20 사용자 승인: 페이지별 `renderCell` 우회가 아닌 공통 date 컬럼에 적용한다.
- 기존 문서현황 컬럼의 미커밋 변경을 보존한다.

## 범위 및 완료 기준

- 표시 유틸리티와 컬럼 타입, 관련 테스트 및 F1-Grid 사용 문서를 수정한다.
- 날짜 원본, 편집/검색 값, 숫자 포맷 및 datetime/time 동작은 유지한다.
- 기본/사용자 지정 표시, 빈 값, 잘못된 날짜, 원본 보존을 검증한다.
- 공통 표시 함수를 사용하는 셀, 자동 너비, Excel 출력의 일관성을 확인한다.
- 프런트엔드 관련 테스트·빌드 및 375/768/1280px 브라우저 렌더링을 검증한다.
- 백엔드/API/DB 변경은 없다.
