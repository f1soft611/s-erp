# 댓글 이미지 미리보기 순서 및 테마별 확대 뷰어 작업지시서

## 사용자 요구

- 댓글과 답글의 이미지 미리보기 영역을 첨부파일 목록보다 먼저 표시한다.
- 이미지 클릭 시 확대 뷰어가 밝은 테마와 다크 테마에서 모두 원본 색상과 명암을 유지하도록 수정한다.
- 확대 이미지가 잘리거나 비율이 변형되지 않도록 한다.

## 승인된 설계

- 댓글 표시 순서는 본문 → 이미지 미리보기 → 첨부파일 목록이다.
- 이미지 미리보기와 파일 목록은 각자의 기존 첨부 순서를 유지한다.
- 공유 `ImageViewerDialog`는 이미지 자체에 색상 필터를 적용하지 않는다.
- 투명 이미지의 배경 영향을 확인할 수 있도록 중립 체크무늬 캔버스를 사용한다.
- 대화상자 표면과 텍스트는 현재 앱 테마를 따른다. 이미지 원본 비율을 유지하며 뷰포트 안에 맞춘다.
- 공유 뷰어 변경은 문서/공지 댓글 및 피드 본문 이미지에 동일하게 적용한다.

## 작업 절차

1. 상세 사양서와 계획서를 확인한다.
2. 댓글 미리보기 순서 및 공유 이미지 뷰어 회귀 테스트를 먼저 작성하고, 변경 전 실패를 확인한다.
3. 공통 댓글 UI 순서와 공유 이미지 뷰어 표시만 수정한다. 인증, Blob URL, 데이터 계약은 변경하지 않는다.
4. 관련 테스트와 프론트엔드 빌드를 실행한다.
5. 합성 데이터로 375px, 768px, 1280px에서 밝은 테마와 다크 테마를 실제 브라우저로 확인한다.
6. 재현 조건, 해결 내용, 검증 결과와 스크린샷을 날짜별 결과 폴더에 기록한다.

## 범위 제외

- 이미지 데이터 자체 변환/재인코딩, 색상 자동 보정, CSS 필터 적용
- 댓글/첨부 업로드·삭제·다운로드, 페이지네이션, 권한, API 및 DB 변경
- 미리보기 데이터 조회 및 object URL 생성·정리 흐름 변경

## 완료 조건

- 댓글 및 답글에서 이미지 미리보기 영역이 파일 첨부 목록보다 먼저 나온다.
- 이미지와 파일 항목 각각 기존 등록 순서를 유지한다.
- 밝은/다크 테마 모두에서 이미지의 색상 및 명암이 CSS 필터로 바뀌지 않고 투명 영역이 식별된다.
- 확대 이미지는 원본 비율로 전체가 표시되며 375/768/1280px에서 가로 overflow가 없다.
- 관련 테스트, 빌드, 브라우저 검증과 결과 문서/스크린샷을 완료한다.
