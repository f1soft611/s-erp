# 문서·공지 댓글 다크 테마 수정 작업지시서

## 요구 및 승인

- 사용자 제보: 문서·공지 작성 페이지의 첨부파일, 댓글 및 답글 영역이 다크 테마와 맞지 않는다.
- 사용자 승인: 공통 댓글에서 현재 테마를 자동 적용하는 방식으로 수정한다.
- 기존 배치, 이미지 원본 색상, 댓글 저장·수정·답글·다운로드 동작은 유지한다.

## 절차 및 완료 조건

1. [계획서](../../plan/20261020/20261020_012_comment-dark-theme_계획서.md), 상세 사양서를 작성한다.
2. 테마 값 생략 시의 다크 모드 실패 테스트를 먼저 확인한다.
3. 공통 댓글에서 테마를 결정하고 모든 하위 댓글 UI에 전달한다.
4. 명시적 테마 값 호환성, 라이트 테마, 기존 관련 테스트 및 빌드를 검증한다.
5. 합성 데이터로 375/768/1280px 브라우저 검증과 스크린샷을 결과 폴더에 기록한다.

백엔드, API, DB, 이미지 뷰어 및 무관한 기존 변경은 수정하지 않는다.
