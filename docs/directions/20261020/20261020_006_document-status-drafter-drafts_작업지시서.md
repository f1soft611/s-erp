# 20261020_006 문서현황 기안자 역할 및 임시저장 표시 작업지시서

## 목적

문서현황에서 기안자가 `결재` 역할로 표시되는 문제를 바로잡고, 임시저장 문서를 기안자 본인에게 결재신청일 기간 기준으로 조회 가능하게 한다.

## 승인된 요구사항

- 현재 로그인 사용자가 문서의 기안자이면 `내 결재 역할`은 결재선의 `APPROVAL` 값보다 우선하여 `기안`으로 표시한다.
- 상세검색의 역할 선택에도 `기안`을 제공하며, 해당 검색은 현재 로그인 사용자가 기안한 문서만 반환한다.
- 임시저장 문서에는 `submitted_at`이 없으므로, 문서현황 결재신청일 기간 검색 시 임시저장 문서는 `created_at`을 기준으로 검색한다.
- 임시저장 문서는 기존 tenant 및 접근권한 조건을 유지하고, 기안자 본인 문서만 조회한다.
- 결재신청된 문서는 기존대로 `submitted_at`을 기간 검색에 사용한다.
- DB 스키마 및 결재선 상세 동작은 변경하지 않는다.

## 범위

- 프런트엔드 역할 옵션, 타입 및 회귀 테스트
- 백엔드 문서현황 목록/건수 쿼리, 역할 검증 및 회귀 테스트
- F1-Grid 문서와 날짜별 계획/상세사양/결과 문서 갱신

## 완료 기준

- 기안자는 결재선에 참여하더라도 문서현황 역할에 `기안`으로 표시된다.
- 역할 `기안`으로 검색하면 인증된 본인이 기안한 문서만 반환된다.
- 임시저장 문서는 선택한 결재신청일 시작/종료 기간 안에서 `created_at` 기준으로 조회된다.
- 타인의 임시저장은 목록과 건수에서 노출되지 않는다.
- 관련 프런트엔드 및 백엔드 회귀 테스트가 통과하고 결과 문서에 검증 결과를 기록한다.
