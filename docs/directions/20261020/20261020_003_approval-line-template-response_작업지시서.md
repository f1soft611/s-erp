# 자주 쓰는 결재선 저장 응답 오류 작업지시서

## 요청과 승인 범위

- 문서작성에서 자주 쓰는 결재선 저장 시 `자주 쓰는 결재선 저장 응답을 확인할 수 없습니다.`가 표시되는 원인을 확인한다.
- 사용자 승인: 서버 응답을 유지하고 프론트엔드 날짜 타입·응답 검증과 회귀 테스트를 수정한다.
- 기존 [기능 작업지시서](../20261015/20261015_002_업무작성_자주쓰는결재선_작업지시서.md)의 소유권, 문서 코드, 결재선 적용/취소 동작은 유지한다.

## 절차 및 완료 기준

1. 계획서와 상세 사양서를 작성한다.
2. 저장 응답의 `updatedAt: null` 및 조회 응답의 숫자형 날짜로 실패 테스트를 작성한다.
3. 공통 요약 검증과 타입만 수정하고 잘못된 응답 거부는 유지한다.
4. 관련 테스트, 프론트엔드 빌드, 모의 API 브라우저 저장 흐름을 검증한다.
5. 결과 문서와 스크린샷을 기록한다. 실제 서버 저장 검증과 모의 검증을 구분한다.

DB/백엔드 변경과 기존 작업 중인 파일의 변경은 제외한다.
