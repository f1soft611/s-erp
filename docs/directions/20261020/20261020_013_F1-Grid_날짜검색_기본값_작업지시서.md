# F1-Grid 날짜 검색 기본값 작업지시서

## 사용자 요구 및 승인

- F1-Grid 날짜 상세검색 컬럼에 기본값을 선언할 수 있어야 한다.
- 기본값은 고정 연·월·일 또는 서버 시스템 날짜 기준 상대 연·월·일로 지정한다.
- 기간의 시작일과 종료일은 각각 독립적으로 설정할 수 있으며 한쪽만 지정할 수 있다.
- 기본값은 첫 진입과 검색조건 초기화에 적용한다. 지정하지 않은 날짜 필드는 기존처럼 비운다.
- 오늘 날짜는 백엔드에서 제공한다. 프런트엔드 시계로 대체하지 않는다.
- 상대 월 계산은 달력 기준으로 하며, 대상 월에 같은 일자가 없으면 해당 월의 말일로 보정한다. 윤년을 포함한 유효 날짜를 처리한다.
- 문서현황의 결재신청일 최근 1개월 기본 범위를 페이지의 브라우저 날짜 계산에서 컬럼 metadata 선언으로 옮긴다.
- 사용자가 저장한 문서현황 검색 조건은 metadata 기본값보다 우선해 복원하고, 초기화하면 metadata 기본값을 다시 적용하고 저장한다.

## 승인된 설계

- 날짜 컬럼의 `search.defaultValue`에 `from` 및 `to`의 날짜 기본값 표현식을 선언한다.
- 고정 날짜 표현은 `{ type: 'fixed', year, month, day }`, 시스템 날짜 표현은 `{ type: 'systemDate', offset? }` 형식을 사용한다.
- 백엔드 `GET /api/v1/common/system-date`가 기존 `EgovDateUtil`을 사용해 ISO `yyyy-MM-dd` 날짜를 표준 응답의 `result.today`로 반환한다.
- 프런트엔드 공통 resolver가 시스템 날짜 API를 필요한 경우에만 호출하고, 연도 → 월 → 일 순서의 달력 연산을 수행한다.
- `PageSearchArea`는 이미 해석된 기본값을 표시 및 초기화에 사용한다. 초기화는 기존 공통 동작처럼 자동 조회하지 않으며, 필요 페이지는 선택적 초기화 callback으로 조회를 적용한다.
- 문서현황은 서버 날짜 기본값의 해석이 완료되기 전에 기본값이 빠진 첫 목록 조회를 보내지 않는다. API 실패 시 오류를 표시하고 재시도를 제공하며 브라우저 날짜로 fallback하지 않는다.
- 비동기 기본값이 로드되기 전에 세션 저장이 임시 빈 상태로 덮어쓰지 않도록 세션 persistence를 조건부로 지연한다.
- DB 테이블, 데이터 조회, 스키마 및 migration 변경은 없다.

## 작업 순서 및 완료 기준

1. 이 지시서에 따라 날짜별 계획서와 상세 사양서를 작성한다.
2. 백엔드 시스템 날짜 API 계약 테스트를 작성하고 API를 구현한다.
3. F1-Grid 및 상세검색 metadata 타입, 전달 변환, 날짜 API client, 날짜 resolver와 경계값 테스트를 구현한다.
4. 공통 검색 영역이 해석된 기본값으로 초기화 및 초기화 동작을 지원하도록 하고, 선택적 초기화 callback을 테스트한다.
5. 기본값 loading/error/retry hook과 세션 persistence 지연을 구현하고 테스트한다.
6. 문서현황 결재신청일에 metadata 기본값을 선언하고, 첫 조회·초기화·세션 복원에 동일하게 적용한다.
7. F1-Grid 문서, 결과 문서 및 스크린샷을 갱신한다.
8. 관련 Vitest, 프런트엔드 빌드, Maven 대상 테스트, `git diff --check`를 실행한다.
9. 실제 브라우저에서 375px, 768px, 1280px 화면의 초기 날짜·초기화 동작을 확인한다. 접근할 수 없는 경우 제한 사항을 결과 문서에 명시한다.

## 완료 조건

- 날짜 기본값 metadata가 상세검색 필드까지 타입 안전하게 전달된다.
- 고정일, 오늘, 상대 연·월·일, 부분 범위, 월말 보정, 윤년 및 잘못된 설정이 테스트된다.
- 서버 날짜 API 오류가 숨겨지지 않고, 잘못된 날짜 또는 브라우저 시계로 fallback하지 않는다.
- 문서현황의 첫 기본 조회에 서버 날짜 기준 최근 1개월 범위가 적용되고, 미적용/초기화/세션 복원 동작이 구분되어 검증된다.
- 기존 상세검색 초기화 동작이 선택적 page callback이 없는 페이지에서 바뀌지 않는다.
- 관련 문서와 실제 검증 결과가 기록된다.
