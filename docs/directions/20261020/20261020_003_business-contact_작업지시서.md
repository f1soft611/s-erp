# 업무연락 작성 및 탭 전환 보호 작업지시서

## 승인 요구사항

- 문서작성 모달의 기안일, 기안자, 구분, 기안양식을 공통화하여 기안서와 업무연락에서 재사용한다.
- 업무연락에는 결재/합의/결재선 설정 없이 참조자 다중 선택만 제공한다.
- 업무연락은 참조자에게 발송하면 완료되며 수신자의 승인/확인을 요구하지 않는다.
- 다른 탭 선택 시 수정 여부와 관계없이 항상 확인하고, 취소 시 모든 상태를 보존한다. (2026-10-20 추가 지시)
- 탭 이동 시 결재/합의/추가 대기 선택/참조자를 초기화한다. 기안서는 기안자 기본 단계만 복구한다.
- 제목과 본문은 유지하며 탭 이동으로 양식 본문을 다시 적용하지 않는다.

## 구현 경계

- 기존 저장/상신 API와 본문/첨부/댓글/조회 권한을 재사용한다.
- 업무연락은 임시저장 시 참조자 없이 저장 가능하고 발송 시 1명 이상 필요하다.
- 공통 구분/양식 선택과 첨부도 탭 이동 시 유지한다. 수정 감지는 탭 전환 조건으로 사용하지 않는다.
- 발송은 시스템 내 문서 공유이며 메일/푸시, 열람확인, 발송취소는 추가하지 않는다.
- 기존 미커밋 변경을 보존하고 현재 작업 폴더에서 진행한다.
- DB 메타데이터를 직접 확인하고 기존 상태/이벤트로 처리 가능한지 검증한다.

## 완료 기준

프론트엔드 회귀 테스트/빌드, 백엔드 관련 테스트, 375/768/1280px 브라우저 검증과 결과 문서/스크린샷을 남긴다. 기존 기안서 결재 동작을 유지한다.
