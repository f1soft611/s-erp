# 20261020_009 커뮤니티 자료실 검색/파일목록 개선 작업지시서

## 1. 목적

자료실을 폴더와 파일이 구분되는 파일형 목록으로 개선하고, 통합검색 및 상세검색으로 최근 업로드 파일을 쉽게 찾을 수 있도록 한다. 기존 자료실 테이블과 `WF_ARCHIVE_CATEGORY` 공통코드 분류를 유지한다.

## 2. 요구사항

1. 루트 화면에는 폴더 섹션과 파일 섹션을 순서대로 표시한다. 폴더 선택 시 해당 폴더로 이동하고 상위 자료실로 돌아갈 수 있어야 한다. 폴더는 1단계만 지원한다.
2. 파일 목록은 이름, 소유자, 올린 날짜, 크기, 작업 항목을 제공하고 문서작성 파일 목록과 유사한 반응형 행 스타일을 사용한다.
3. 생성 권한이 있는 tenant 관리자는 우측 상단에서 `파일 업로드` 및 `새 폴더` 작업을 사용할 수 있다. 파일 업로드는 파일 선택 직후 시작하며 별도 정보 입력을 요구하지 않는다.
4. `새 폴더`는 `WF_ARCHIVE_CATEGORY` 공통코드 도움창을 재사용한다. 분류 관리 권한이 있는 tenant 관리자는 비활성 분류를 다시 활성화할 수 있어야 한다.
5. 통합검색은 현재 위치의 파일명/소유자를 대상으로 한다. 루트의 폴더는 검색어로 이름을 필터링하되 날짜/파일 유형 조건으로 숨기지 않는다.
6. 상세검색은 올린 날짜와 유형(전체, 문서, 스프레드시트, 프레젠테이션, PDF, 이미지, 비디오, 압축)을 제공한다. 최초 진입은 최근 1년을 적용하고, 날짜 양쪽을 비우면 전체 기간으로 검색할 수 있다.
7. 페이지 번호나 더 불러오기 없이 검색 조건에 맞는 전체 파일 결과를 한 번에 표시한다. 서버에서 검색/날짜/유형/현재 위치 조건을 적용하고 최신 업로드 순으로 반환한다.
8. 활성 폴더 파일은 권한에 따라 이름/폴더 변경, 삭제, 다운로드를 제공한다. 비활성 폴더 파일은 다운로드만 허용한다. 새 폴더 분류 재활성화는 공통코드 도움창에서 권한에 따라 수행한다.
9. 기존 데이터베이스 테이블/컬럼을 변경하지 않는다. 파일 유형은 파일 MIME 형식, 필요 시 확장자 기준으로 분류한다.

## 3. 작업 순서

1. [승인 설계](../../superpowers/specs/2026-10-20-community-archive-search-layout-design.md), [기존 파일/폴더 상세사양서](../../spec/20261020/20261020_006_커뮤니티_자료실_파일폴더_그리드_상세사양서.md), 그리고 본 작업에 대응하는 계획/상세사양을 확인한다.
2. 백엔드 목록 API 호출자와 DB 컬럼 계약을 확인한다. 구현 전 PostgreSQL 읽기 전용 MCP에서 테이블 목록 및 `tb_common_file`, `tb_board_post` 메타데이터를 확인하고 실제 행은 조회하지 않는다.
3. 백엔드 테스트 우선으로 날짜/유형/키워드 검색과 전체 결과 반환을 구현한다. 기존 tenant/게시판/파일 소유 범위를 유지한다.
4. 프론트 서비스/훅/화면을 순서대로 변경하고, 권한과 오류 상태를 검증한다.
5. F1-Grid 문서와 결과 문서를 갱신하고 375px, 768px, 1280px 브라우저 확인 및 스크린샷을 남긴다.

## 4. 완료 조건

- 새 검색 API 요청은 keyword, folderCode, uploadedFrom, uploadedTo, fileType을 지원하고 pagination 파라미터 없이 전체 필터 결과를 반환한다.
- 최근 1년 기본 조건, 양방향 열린 날짜 범위, 8개 파일 유형, root/폴더 탐색, 비활성 폴더 열람/재활성화 흐름이 동작한다.
- 생성/수정/삭제 권한이 버튼과 행 작업에 일관되게 적용되고 업로드/목록 오류가 명시된다.
- 대상 백엔드 테스트, 프론트 Vitest, 프론트 빌드가 통과한다.
- 지정된 세 뷰포트에서 가로 넘침 없이 확인하고 스크린샷 및 검증 결과를 기록한다.
- DB MCP 확인 근거 또는 호출 불가 사유와 대체 확인 근거를 결과 문서에 기록한다.

## 5. 범위 제외

중첩 폴더, 즐겨찾기, 파일 미리보기, 일괄 다운로드, 신규 DB 테이블/컬럼, 다른 커뮤니티 화면 변경은 포함하지 않는다.
