# 20260828_001 F1-GRID 소스 분리 작업지시서

## 목적

기존 `shared/components/f1-grid/F1Grid.tsx`에 집중된 렌더링, 편집, 선택, 키보드, 타입 책임을 기능별 모듈로 분리한다.

## 범위

- `core`: ERPGrid 공개 컴포넌트와 헤더/본문/행/셀/footer 렌더링
- `editing`: CellEditor와 text/number/date/select editor
- `selection`: 선택 계산 및 Ctrl/Shift/전체 선택
- `keyboard`: 포커스 이동과 키보드 액션 계산
- `types`: 공개 타입 계약
- `utils`: row key, 표시값, 편집 가능 여부, merge 계산
- 기존 `F1Grid` import 호환 유지
- 실제 DOM 포커스, 편집 가능 셀 Tab 이동, rows 동기화, ID 중복 방지
- 선택/키보드 및 메뉴관리 CRUD 통합 테스트 보강

## 제외

저장 API, validation, dirty dialog, clipboard, sorting, filtering, aggregation, pagination, export는 별도 요구사항과 API 계약 확정 후 진행한다.

## 완료 기준

- 기존 F1-GRID 집중 테스트와 전체 프론트 테스트 통과
- `npm run build` 통과
- 기존 소비자의 import 경로가 유지됨
- 분리된 각 모듈이 단일 책임을 가짐
- 결과 문서에 변경 범위와 제외 범위를 기록함
