## 1. 작업 개요

F1-GRID의 실무 편의성을 높이기 위해 다음 3가지 핵심 요구사항을 구현한다.

1. **컬럼 너비 리사이즈 (Column Resize)**: 마우스 드래그를 통해 컬럼의 너비를 자유롭게 조절하고, 최소 너비(기본 50px)를 보장하며, Pinned 컬럼(Left/Right)과 동적 연동되도록 지원.
2. **헤더 더보기 메뉴 마우스 오버 활성화 및 우측 끝 정렬**: 마우스 호버 시에만 더보기 버튼이 활성화(호버 전 숨김/투명, 호버 시 노출)되고, 헤더 셀 내 우측 끝(`margin-left: auto`)에 정렬.
3. **F1GridTestPage 전체 옵션 및 기능 종합 테스트 구성**: F1-GRID의 모든 에디터 타입, 행 작업, 컬럼 옵션, 유효성 검증, 상태 관리, 핀 고정, 정렬, 필터, 리사이즈를 테스트 페이지에 통합하고 브라우저 기반 스크린샷 검증 수행.

## 2. 세부 작업 항목

### 2.1 F1-GRID 코어 및 헤더 개선

- `F1GridColumn` 및 `F1GridProps`에 컬럼 리사이즈 관련 속성 지원 (`resizableColumns`, `minColumnWidth` 등).
- `GridHeader.tsx`에 컬럼 리사이즈 핸들(`onMouseDown` 기반 드래그 조절) 추가.
- `GridHeader.tsx`의 더보기(`MoreVertIcon`) 버튼을 우측 끝 정렬(`margin-left: auto`) 및 마우스 호버 시 활성화(`opacity: 0` -> `:hover { opacity: 1 }`, 메뉴 열림 시 유지) 처리.
- `F1Grid.tsx`에서 각 컬럼의 조절된 너비 상태(`columnWidths`) 관리 및 그리드 템플릿/핀 오프셋 계산에 반영.

### 2.2 F1GridTestPage 전체 기능/옵션 통합

- **에디터 타입 전수 반영**: text, number, decimal, currency, checkbox, date, datetime, time, select, autocomplete, code.
- **컬럼 옵션 전수 반영**: width, editable, required, min, max, validate, onOpenCodePicker, align, headerAlign, wrapText, mergeRows, headerCheckbox, hidden.
- **그리드 Props/Ref 전수 제어**: rowHeight, minRowHeight, maxRowHeight, resizableRows, resizableColumns, columnLine, addRow, deleteSelectedRows, restoreDeletedRows, duplicateSelectedRows, clearSelection, validate, getChanges.
- **실시간 통계 및 제어판 UI**: 변경 이력(신규/수정/삭제 건수), 선택 건수, 검증 결과, 그리드 설정 토글 UI 제공.

### 2.3 단위 테스트 및 브라우저 E2E 캡처

- Vitest 단위 테스트 추가/갱신 (`frontend/tests/f1-grid.test.tsx`, `f1-grid-test-page.test.tsx`).
- 실제 브라우저(Playwright/Node 스크립트)를 통해 F1-GRID 테스트 페이지에서 컬럼 리사이즈, 헤더 호버 메뉴, 핀 고정, 정렬, 필터, 전체 에디터 동작 검증 및 스크린샷 캡처 (`docs/result/20260828/f1-grid-column-resize-all-options-test/screenshots`).

## 3. 완료 기준

1. 컬럼 헤더 우측 경계선을 마우스 드래그하여 컬럼 너비를 부드럽게 조절할 수 있어야 함.
2. 헤더의 더보기 버튼이 평소에는 숨겨져 있다가 헤더에 마우스를 올리면 우측 끝에 나타나야 함.
3. `F1GridTestPage`에서 F1-GRID의 모든 컬럼 타입, 속성, 액션이 동작하고 조작 가능해야 함.
4. 모든 프론트엔드 테스트 통과 및 브라우저 스크린샷이 첨부된 결과 보고서 작성 완료.
