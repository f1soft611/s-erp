# 작업지시서: F1-GRID 반응형 수평 스크롤

- 문서 번호: 20260828_008
- 일자: 2026-08-28
- 대상: 대시보드 앱 셸(`frontend/src/pages/dashboard`), F1-GRID 공통 컴포넌트(`frontend/src/shared/components/f1-grid`)

---

## 1. 작업 개요

좁은 화면에서 F1-GRID의 고정 컬럼 너비 때문에 브라우저 문서 전체에 가로 스크롤이 생기는 문제를 개선한다. 중앙 콘텐츠 영역은 좌측 사이드바 이후의 남은 너비로 축소되어야 하며, 컬럼 합계 폭이 가용 폭을 넘을 경우 F1-GRID 내부 하단 수평 스크롤로 전체 컬럼을 확인할 수 있어야 한다.

## 2. 작업 항목

1. 대시보드의 중앙 콘텐츠 flex item이 축소될 수 있도록 최소 너비를 0으로 설정한다.
2. 좁은 중앙 콘텐츠 폭에서 앱 바 제어 영역이 줄바꿈되도록 반응형 레이아웃을 적용한다.
3. F1-GRID 루트가 부모 너비를 넘지 않도록 축소 및 최대 너비 제약을 설정한다.
4. F1-GRID의 헤더와 본문은 현재 컬럼 폭을 유지하고, 초과 폭은 F1-GRID 루트의 가로 스크롤로 표시한다.
5. 좁은 부모 폭에서의 스크롤 소유 및 축소 규칙을 단위 테스트로 검증한다.
6. 실제 브라우저의 좁은 뷰포트에서 문서 가로 오버플로우가 없고 F1-GRID에 가로 스크롤이 표시되는지 캡처로 검증한다.

## 3. 완료 기준

1. 좁은 뷰포트에서 브라우저 문서 전체 하단에 가로 스크롤이 생기지 않는다.
2. 중앙 콘텐츠는 사이드바를 침범하지 않고 가용 폭으로 축소된다.
3. F1-GRID의 컬럼 합계 폭이 가용 폭보다 클 때 F1-GRID 내부에서만 수평 스크롤할 수 있다.
4. 관련 Vitest와 TypeScript/Vite 빌드가 통과한다.
