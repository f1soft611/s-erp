## 작업 범위

1. F1-GRID `autocomplete` 타입 에디터의 값 커밋 동작을 점검하고, Enter 외의 커밋 경로(Tab, 포커스 이동)에서도 옵션 값이 올바르게 저장되도록 수정한다.
2. F1-GRID `date`, `datetime`, `time` 타입 에디터를 브라우저 기본 달력/시간 입력(`input type="date/datetime-local/time"`) 대신 MUI(`@mui/x-date-pickers`) 달력/시간 선택 UI로 교체한다.

## 작업 순서

1. 문서 확인 (본 문서, 계획서, 사양서)
