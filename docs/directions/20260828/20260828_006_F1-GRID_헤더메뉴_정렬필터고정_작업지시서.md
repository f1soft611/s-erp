# 20260828_006 F1-GRID 헤더 메뉴 정렬/필터/고정 작업지시서

## 1. 목적

F1-GRID 컬럼 헤더의 `더보기` 메뉴에 정렬(오름차순/내림차순), 필터, 컬럼 고정(왼쪽/오른쪽/해제) 기능을 추가하고, 헤더 컬럼 간 구분선을 항상 표시한다.

## 2. 작업 범위

- 헤더 셀에 `columnLine` 옵션과 무관하게 항상 표시되는 세로 구분선 추가
- 컬럼 더보기 메뉴에 다음 항목 추가
  - 오름차순 정렬 / 내림차순 정렬 (다중 컬럼 정렬 지원, 클라이언트 데이터 기준)
  - 컬럼 목록 (기존 유지)
  - 필터 (컬럼 타입별 연산자 + 값 입력 팝오버)
  - 왼쪽 고정 / 오른쪽 고정 / 고정 해제 (가로 스크롤 시 sticky 고정 표시)
- 신규 모듈: `sorting/GridSort.ts`, `filter/GridFilter.ts`, `columns/GridColumnPin.ts`
- `F1Grid.tsx`, `GridHeader.tsx`, `GridBody.tsx`, `GridRow.tsx`, `GridCell.tsx` 반영

## 3. 완료 조건

- 정렬/필터/고정 메뉴 동작이 F1-GRID.md 13/14/15장 사양과 일치
- 서버사이드 조회 연동은 이번 범위에서 제외 (클라이언트 데이터 기준)
- `npm run test`, `npm run build` 통과
- 결과 문서 작성 (`docs/result/20260828/f1-grid-header-menu-sort-filter-pin/`)
