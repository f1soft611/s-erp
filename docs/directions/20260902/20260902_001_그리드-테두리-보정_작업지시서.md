# 작업지시서

## 요청

- F1Grid의 활성 셀/편집 셀 테두리를 원래 의도대로 2px solid로 복구한다.
- 드래그 선택 범위는 평면 상태를 유지하며 선택 영역 border가 다시 생기지 않도록 한다.

## 범위

- 프론트엔드: `frontend/src/shared/components/f1-grid/core/GridCell.tsx`
- 검증: `frontend/tests/f1-grid.test.tsx`

## 완료 기준

- 활성 셀 및 편집 상태에 2px 테두리가 보인다.
- 드래그 선택 시 선택 셀 border는 생기지 않는다.
- 관련 Vitest 회귀 테스트가 통과한다.
