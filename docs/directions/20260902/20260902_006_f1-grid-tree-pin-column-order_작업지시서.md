# 작업지시서: F1 Grid/F1 Tree 핀 고정 컬럼 정렬 보정

- 작성일: 2026-09-02
- 요청자: 사용자 채팅 요청
- 관련 영역: `frontend/src/shared/components/f1-grid`

## 요청

- F1 Grid 테스트 페이지에서 컬럼을 핀 고정하면 컬럼 정렬이 어긋나는 문제를 수정한다.
- 메뉴관리 페이지별 보정 없이 F1Grid와 F1Tree 공통 동작으로 처리한다.

## 완료 기준

- `flex` 컬럼을 포함해 둘 이상의 컬럼을 같은 방향으로 고정해도 헤더와 본문 셀이 같은 위치에 정렬된다.
- `flex` 컬럼이 있어도 헤더와 본문은 하나의 공통 픽셀 단위 컬럼 트랙을 사용한다.
- 좌측 및 우측 고정 컬럼은 각각 고정 영역의 선두 및 후미에 배치된다.
- F1Tree는 내부 F1Grid 공통 로직을 통해 같은 동작을 보장한다.
- F1 Grid 및 F1 Tree 회귀 테스트와 프론트엔드 빌드가 통과한다.
