# 납품처 관리 및 수주 연계 작업지시서

근거: 2026-11-23 사용자 요청 및 설계 승인.

## 작업 범위

- 영업관리 > 기준정보 > 납품처 관리 메뉴와 메뉴 seed를 추가한다.
- 거래처별 납품처 등록 여부와 납품처 목록을 표시하고 등록·수정·삭제한다.
- 납품처 항목은 납품처코드, 납품처명, 사업자번호, 납품처주소, 담당자,
  이동전화번호, 전화번호, 팩스번호, 비고다. 납품처코드는 자동 발급한다.
- 수주등록의 기존 납품장소를 납품처 선택으로 대체한다. 거래처 선택을
  선행하고 해당 거래처의 납품처만 선택한다. 매출처는 기존 거래처
  도움창으로 선택한다. 납품처와 매출처는 필수다.
- 거래처·납품처·매출처는 같은 행에 배치하되 좁은 화면에서는 반응형으로
  줄바꿈한다.
- 기존 수주 변환 대신 명시한 단일 테넌트의 수주·출하계획·출하·
  거래명세서·매출마감 관련 데이터를 초기화하는 SQL을 작성한다.
  실제 DB에는 실행하지 않고 기준정보는 보존한다.
- 수주에서 참조하는 납품처는 삭제하지 못하게 한다.

## 절차 및 완료 조건

1. 계획서와 상세사양서를 작성하고 검토받는다.
2. 읽기 전용 DB MCP와 기존 구현으로 테이블, 참조 관계, 메뉴 및 API
   계약을 확인한다.
3. 회귀 테스트를 우선 작성하고 프론트엔드·백엔드와 메뉴 seed를 구현한다.
4. DB 변경·초기화 및 롤백 스크립트와 이력을 규칙에 따라 관리한다.
5. 대상 테스트, 빌드, Java 8 호환성, 실제 브라우저 반응형 검증을 수행한다.
6. 결과 문서와 스크린샷을 남기고 사용자의 기존 변경을 보존한다.
