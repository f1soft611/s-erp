# 시스템 모서리 4px 통일 작업지시서

## 요구사항

- 프런트엔드의 사각형 UI 모서리 반경을 6px에서 4px로 통일한다.
- 공통 MUI 테마와 화면별로 명시한 사각형 반경을 함께 적용한다. 부분적으로 접합되는 경계의 0px은 유지한다.
- 원형 아바타·아이콘 등 원형 요소와 의도적으로 각진 0px 경계는 유지한다.
- 기존 화면 동작, 색상, API 및 DB 계약은 변경하지 않는다.
- 이 요구사항은 [기존 6px 기준](../20261110/20261110_005_status_badge_radius_작업지시서.md)의 모서리 값에 우선한다.

## 작업 순서 및 완료 기준

1. 이 작업지시서를 바탕으로 계획서와 상세 사양서를 작성한다.
2. 공통 테마 및 명시적 반경과 예외를 확인하고 관련 회귀 테스트를 먼저 수정한다.
3. 사각형 반경을 4px로 정규화하고 원형 및 0px 경계를 유지한다.
4. 관련 테스트, 빌드, 변경 영역 lint 및 375px/768px/1280px 브라우저 렌더링을 확인한다.
5. 결과 문서와 합성 데이터 스크린샷을 `docs/result/20261123/system-border-radius/`에 보관한다.
