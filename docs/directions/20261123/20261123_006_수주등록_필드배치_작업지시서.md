# 수주등록 필드 배치 작업지시서

## 요청

- 첫 행: 수주번호, 수주일자, 납기일자, 수주상태.
- 둘째 행: 거래처, 납품처, 매출처. 세 필드의 너비는 수주번호와 같다.
- 셋째 행: 견적번호, 배송방법. 넷째 행: 비고.
- 사용자 요청의 납품일자는 기존 수주 기본정보의 납기일자 필드를 뜻하며, 필드 명칭과 업무 동작은 유지한다.
- 좁은 화면은 기존 반응형 열 수를 유지하고 순서대로 줄바꿈한다.
- 수주 등록과 공유되는 현황 상세의 기존 동작을 유지한다.

## 완료 조건

입력 순서와 데스크톱 필드 너비를 확인하고, 기존 입력·저장 동작 및 375/768/1280px 브라우저 레이아웃을 검증한다. 결과 문서와 스크린샷을 남긴다.
