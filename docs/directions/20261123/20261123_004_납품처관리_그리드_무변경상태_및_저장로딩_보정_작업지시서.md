# 납품처 관리 그리드 상태 및 저장 로딩 보정 작업지시서

근거: 2026-11-23 사용자 요청.

## 작업 범위

- 납품처 관리 우측 그리드에서 빈 문자열로 보이는 `null` 값을 편집 후 그대로 확정해도 변경 행으로 표시되지 않게 한다.
- 저장 후 재조회 중에는 그리드 전체 로딩 표시로 기존 내용을 가리지 않고 기존 저장 버튼 진행 표시를 사용한다.
- 저장 성공은 공통 성공 토스트로 알리고, 저장·재조회 실패는 기존 오류 메시지 영역을 사용한다.
- 거래처를 선택하기 전에도 우측 납품처 그리드가 초기 화면에 표시되게 한다. 거래처 선택 전에는 추가·편집을 허용하지 않는다.
- 현재 작업 트리의 미커밋 사용자 변경을 보존한다.

## 절차 및 완료 조건

1. 기존 납품처 관리 문서와 F1-Grid 편집·변경 추적 구현을 확인한다.
2. 무변경 셀 확정, 저장 중 조용한 갱신, 초기 우측 그리드 표시의 회귀 테스트를 작성한다.
3. 변경 영향 범위를 납품처 관리 화면과 F1-Grid 텍스트 값 확정 동작으로 제한한다.
4. 납품처 저장 성공 시 변경 행을 그리드에 확정해 현재 수정값을 유지하고 공통 성공 토스트를 표시한다. 기존 목록을 유지하며 비차단 방식으로 고객·납품처 목록을 갱신하고, 오류는 기존 메시지 영역에 표시한다.
5. 대상 테스트, 프론트엔드 빌드 및 화면 렌더링을 확인하고 결과 문서를 남긴다.
