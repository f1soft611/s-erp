# 20261123_003 구매자재·수입검사 그리드 "행" 열 이름·정수 표시 / 매입마감 구매처 No 열 작업지시서

## 배경
구매자재와 품질관리(수입검사) 화면의 표에는 품목 행 순서를 보여 주는 `lineNo` 열이 "행"이라는 이름으로 있고, 이 열이 숫자(`number`) 열이라 정책 관리의 모듈 소수점 정책(예: 2자리)이 적용되어 `1.00`처럼 소수로 보인다. 또 매입마감처리의 왼쪽 "구매처별 요약" 표에는 No 열이 없다.

## 결정 (사용자 요청, 2026-11-23)
- 표의 "행" 항목 이름을 **"순번"** 으로 바꾼다.
- 순번은 **정수**로 보이게 한다(소수점 없음).
- 구매자재 전 화면과 **품질관리 > 수입검사**를 점검해 같은 열이 있으면 모두 반영한다.
- 매입마감처리 왼쪽 그리드(구매처별 요약)에 **No 열**을 추가한다.

## 범위·완료 조건
- 포함: 구매요청(등록·현황·상세)·구매 확정·발주 현황·가입고 현황·입고 현황·수입검사 현황의 "행" 열(표와 상세 패널 머리글), 구매 확정의 요청 선택 창, 매입마감 구매처 요약 No 열, 테스트·문서.
- 제외: 서버·DB(변경 없음), 수량·금액 열의 소수점 정책, 영업 화면.
- 완료: 위 화면에서 "행" 머리글이 모두 "순번"이고 `1`, `2`처럼 정수로 보인다. 매입마감 왼쪽 표가 No 열로 시작한다. 관련 테스트·`tsc`·`f1-grid-storage-keys` 통과, 브라우저 확인.
