# 20261113_003 발주서 출력 작업지시서

## 작업 목적

발주를 구매처에 보낼 수 있도록 **발주서 출력물**을 만든다. 출력 방식과 규칙은 영업관리 > 출하관리 > 거래명세서현황(`StatementPrint`)을 따르고, 양식은 사용자가 제공한 `발주서.PDF` 기본 양식을 따른다. MES는 참고일 뿐이다.

## 영업(거래명세서) 규칙 검토 결과와 적용

| 영업 규칙 | 발주서 적용 |
| --- | --- |
| 상세 패널 더보기에 `자세히보기`/`수정`/`출력`. 출력은 "미리보기" 다이얼로그에서 `인쇄`(브라우저 인쇄) | 동일. 발주 상세 패널 더보기에 `출력` 추가 |
| 수정 다이얼로그 하단에도 `출력`, 저장하지 않은 변경이 있으면 비활성 | 동일 |
| 저장 시 회사·거래처 정보를 명세서에 **복사(스냅샷)**해 이후 마스터가 바뀌어도 출력값 불변. 스냅샷이 없는 기존 건은 현재 정보로 출력 | 동일(사용자 확정). 발주 저장 시 회사·구매처·발주자 정보를 발주 헤더에 복사한다. 기존 발주는 현재 정보로 출력 |
| 금액은 저장값을 그대로 쓰고 출력 시 재계산하지 않음. 합계는 전체 기준이며 페이지마다 같은 합계 | 동일 |
| 합계가 정수면 한글 금액 + 숫자, 소수면 숫자만 | 동일 |
| 미리보기 용지 가운데 정렬, 좁은 화면은 축소·자르지 않고 가로 스크롤 | 동일 |
| 품목이 많으면 줄 수를 계산해 페이지 분할 | 동일(한 페이지 24줄) |
| 인쇄는 전용 숨김 영역만 인쇄하는 `@media print` CSS | 동일(발주서 전용 클래스) |

### 영업과 다른 점(양식 차이)
- 한 장에 **한 부**를 인쇄한다(영업은 두 부 상하 배치).
- 납기일은 헤더가 아니라 **품목 행마다** 표시한다(사용자 확정).
- 부가세 표기는 부가세구분·포함 여부에 따라 `VAT포함` / `VAT별도` / `영세` / `면세`로 쓴다.

## 확정 업무 규칙 (2026-11-13 사용자 확정)

1. 발주 시점의 회사·구매처·발주자 정보를 발주에 보관한다(스냅샷). 마스터가 바뀌어도 과거 발주서 출력은 같다.
2. 납기일은 행마다 표시한다.
3. **취소된 발주는 출력할 수 없다**(메뉴·버튼 숨김 또는 비활성, 서버도 409).
4. 출력상태: 미리보기의 `인쇄` 버튼을 누르면 "출력했다"로 기록한다(`print_at='Y'`, 출력 일시·출력자). 발주현황 목록에 출력상태 컬럼을 표시한다.
5. 한글 금액 변환 함수는 **공통 위치**(`shared/utils`)에 새로 만들고 발주서가 참조한다. 영업 파일은 이번 작업에서 수정하지 않는다(다른 담당자가 작업 중). 영업 담당자가 나중에 공통 함수를 참조하도록 바꿀 수 있게 결과 문서에 전달 내용을 남긴다.

## 범위

- DB: 발주 헤더에 회사·구매처·발주자 스냅샷 컬럼과 출력 일시·출력자 컬럼 추가(`20261113_006`, 사용자가 직접 실행).
- 백엔드: 발주 저장 시 스냅샷 복사, 출력 데이터 조회 API(`GET /purchase-orders/{id}/print`), 출력 기록 API(`POST /purchase-orders/{id}/print-mark`), 현황 목록 출력상태.
- 프론트: 공통 한글 금액 함수, 발주서 미리보기·인쇄 컴포넌트, 상세 패널 `출력` 메뉴, 수정 다이얼로그 `출력` 버튼, 목록 출력상태 컬럼.

## 제외 범위
전자결재 버튼, 이메일·팩스 발송, 발주서 양식 편집기, 영업 거래명세서 코드 수정, 가입고 연동.

## 구현 절차
1. 계획서, 상세사양서
2. DB 스크립트(`20261113_006`) 두 경로 사본, `db-schema.md`
3. 백엔드 실패 테스트 → 구현
4. 프론트 실패 테스트 → 구현
5. 검증: 집중 테스트, 빌드, JDK 8 컴파일, 브라우저(미리보기 375/768/1280px, 다중 페이지)
6. 사용자 SQL 실행 후 MCP 확인, 결과 문서 `docs/result/20261113/purchase-order-print`

## 완료 조건
- 정상 발주를 `출력`하면 PDF 양식과 같은 구성의 미리보기가 열리고 `인쇄`가 동작한다.
- 취소된 발주는 출력할 수 없다.
- `인쇄`를 누르면 발주현황 목록의 출력상태가 `출력`으로 바뀐다.
- 마스터(회사·구매처·발주자) 정보를 바꿔도 과거 발주서 출력은 그대로다. 기존 발주는 현재 정보로 출력된다.
