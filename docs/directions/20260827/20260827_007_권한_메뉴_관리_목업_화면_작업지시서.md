# 작업지시서: 권한관리/메뉴관리 목업 화면 구성

## 목적

환경설정 > 시스템 관리 하위의 권한관리와 메뉴관리 메뉴를 실제 ERP 화면처럼 구성한다.

- 권한관리: 역할 목록, 권한 매핑, 접근 권한 편집 UI
- 메뉴관리: 메뉴 트리/목록, 기본 속성 편집, 사용 여부 및 정렬 관리 UI
- 해당 화면은 샘플 데이터 기반의 목업이지만, 실제 운영 환경에서의 관리 흐름을 반영한다.

## 범위

### 포함

- 환경설정 > 시스템 관리 > 권한관리 디자인 추가
- 환경설정 > 시스템 관리 > 메뉴관리 디자인 추가
- 샘플 데이터 기반의 역할/메뉴 관리 양식 구성
- 선택된 역할 또는 메뉴에 대한 상세 편집 화면
- 실제 ERP 운영 화면처럼 필드/표/체크박스/버튼 배치

### 제외

- 백엔드 API 연동
- DB 스키마 생성 또는 영속화
- 실제 사용자 인증/인가 엔진 반영
- 다국어/테마별 상세 로직 확장

## 요구사항

1. 좌측 메뉴에서 환경설정 > 시스템 관리 > 권한관리, 메뉴관리 항목이 표시된다.
2. 권한관리 화면은 역할 목록과 권한 상세 편집 영역을 함께 제공한다.
3. 권한관리 화면은 샘플 데이터로 최소 3개 이상의 역할을 표시한다.
4. 각 역할은 접근 권한(read/create/update/delete)과 메뉴 접근 범위가 보인다.
5. 메뉴관리 화면은 메뉴 목록과 상세 편집 영역을 제공한다.
6. 메뉴관리 화면은 상위/하위 메뉴, 사용 여부, 정렬 순서, 설명 정보가 샘플 데이터로 표기된다.
7. 화면은 실제 ERP에서 자주 쓰는 테이블/폼/체크박스 레이아웃으로 구성한다.
8. 현재 페이지 선택 상태와 본문 타이틀은 기존 대시보드 구조와 일치해야 한다.

## 작업 순서

1. 문서 확인
2. 계획서 작성
3. 상세 사양서 작성
4. 화면 컴포넌트 구성
5. 샘플 데이터 추가
6. 테스트 및 빌드 검증
7. 결과 문서 정리

## 검증 기준

- `npm run build` 성공
- `npm run test` 성공
- 권한관리 화면이 렌더링된다.
- 메뉴관리 화면이 렌더링된다.
- 샘플 데이터가 테이블 및 상세 패널에 표시된다.
