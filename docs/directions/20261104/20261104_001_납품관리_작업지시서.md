# 납품등록·납품현황 작업지시서

## 사용자 요구

- 영업관리 > 납품관리 아래 납품등록, 납품현황을 추가한다.
- 수주등록과 동일한 화면·저장·조회 패턴을 따른다.
- 기존 수주에서 납품하거나 수주 없이 거래처와 품목을 선택하여 직납품한다.
- S-ERP 패턴의 테이블 및 메뉴등록 스크립트를 제공한다.

## 작업 순서

1. 기존 수주 문서·코드 및 읽기 전용 DB MCP 계약 확인.
2. [계획서](../../plan/20261104/20261104_001_납품관리_계획서.md) 작성.
3. [상세사양서](../../spec/20261104/20261104_001_납품관리_상세사양서.md) 작성.
4. 납품 API·화면·메뉴 연결·SQL 구현.
5. 집중 테스트, 빌드, Java 8 호환성, 실제 브라우저 반응형 검증.
6. 결과 문서와 스크린샷 기록 및 양쪽 스키마 디렉터리 동기화.

## 범위와 완료 조건

- 단일 수주별 부분납품 및 직납품, 저장/조회/수정/논리삭제, 납품일 필수 현황 검색.
- 수주 잔량 초과·타 테넌트 참조·중복 수주상세를 차단하고 출하수량을 원자적으로 보정.
- 재고수불, 세금계산서, 회계전표, 반품, 다중 수주 합산은 제외.
- SQL은 작성만 하며 실제 DB에 적용하지 않는다. 운영 데이터·자격 증명을 사용하지 않는다.
- 기존 수주 화면의 표시 패턴을 재사용하며 F1-Grid 자체 동작은 수정하지 않는다.
