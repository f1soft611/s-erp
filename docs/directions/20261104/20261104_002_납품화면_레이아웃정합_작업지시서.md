# 납품 화면 레이아웃 정합 작업지시서

- 사용자 지시: 수주등록=납품등록, 수주현황=납품현황의 레이아웃 구조와 버튼 기본 위치를 맞춘다.
- 기준: 현재 수주등록/현황 컴포넌트의 실제 배치. 새로운 디자인을 만들지 않는다.
- 등록: PageHeader 액션, 기본정보 제목/4열, 전체폭 비고, 상세 Paper 우측 도구, 하단 합계 카드.
- 현황: 빠른검색 입력, 안내 메시지, 목록 여백/No/병합, 번호 클릭 상세패널, 더보기→조회/수정, 모달 하단 저장/삭제.
- 납품 전용 구분/수주 선택은 기존 기본정보/상세 도구 구조에 배치한다. API·DB·수량 계약은 변경하지 않는다.
- 작업지시서→계획서→사양서→구현→실제 브라우저 비교/스크린샷/결과서 순서로 진행한다.
