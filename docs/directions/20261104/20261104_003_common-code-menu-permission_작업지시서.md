# 공통코드 메뉴별 기능 권한 적용 작업지시서

- 요청: 권한그룹에 공통코드 쓰기 권한이 있어도 발생하는 “인가된 사용자가 아닙니다” 오류를 수정한다.
- 기존 근거: [공통코드 관리 작업지시서](../20260911/20260911_003_공통코드_관리_화면_API_작업지시서.md), [메뉴 기능권한 작업지시서](../20260901/20260901_002_메뉴_기능권한_설명_연동_작업지시서.md).
- 공통코드 변경 API에서 관리자 역할 검사를 제거하고, 로그인 사용자 권한그룹의 공통코드 메뉴별 기능 권한만으로 인가한다.
- 저장은 화면과 동일하게 CREATE 또는 UPDATE, 삭제는 DELETE를 사용한다. 일괄 저장에 삭제 행이 있으면 DELETE도 필요하다.
- 인증 및 테넌트 분리, 데이터 유효성 검사, 공용 코드 조회, 다른 메뉴의 정책은 유지한다.
- 완료 기준: 일반 사용자 저장 성공, 권한 없는 사용자 및 관리자 거부, 다른 메뉴 권한의 오용 차단, 일괄 삭제 권한 검증, 회귀 테스트 및 Java 8 호환성 확인, 결과 기록.
- DB 스키마/데이터 변경과 화면 변경은 없다.

## 재확인 지시

- 실제 DB의 일반사용자 그룹 쓰기 권한은 존재하지만 기존 문서의 `cmncodes`와 현재 메뉴의 `common-code` 경로 차이로 거부되는 문제를 함께 수정한다.
- 프론트엔드가 지원하는 두 페이지 키를 서버에서도 동일하게 지원하고, 다른 메뉴 권한은 인정하지 않는다.
