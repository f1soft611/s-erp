# 문서 작성·상세 결재선 순번 표시 통일 작업지시서

## 작업 목적

문서 작성 모달의 결재자·합의 단계 순번을 문서 상세 결재선과 같은 원형 테두리 배지로 표시하고, 두 화면의 배지 크기와 숫자 중앙 정렬을 일치시킨다. 사용자가 승인한 기준 크기는 24px이다.

## 작업 범위

- 문서 상세의 승인 순번과 합의 단계 순번을 24px 원형 테두리 배지로 통일한다.
- 문서 작성 모달의 결재자·합의자 순번도 동일한 공통 배지를 사용한다.
- 작성 모달 결재자 하단의 순번과 이름 묶음을 상세 화면처럼 가운데 정렬한다.
- 배지 스타일을 공통 컴포넌트로 관리해 양쪽 화면에서 동일하게 사용한다.
- 순번 산정, 단계 및 참여자 구조, 결재 동작, API, 데이터 저장은 변경하지 않는다.

## 기준 문서

- [승인된 순번 표시 통일 설계](../../superpowers/specs/2026-10-15-document-approval-sequence-badge-design.md)

## 완료 조건

1. 상세 화면과 작성 모달에서 결재 및 합의 순번 배지 크기가 모두 24px이다.
2. 배지는 원형 테두리 스타일이며 숫자가 수평·수직 중앙에 표시된다.
3. 작성 모달 결재자의 순번·이름 조합이 중앙 정렬된다.
4. 기존 단계 번호, 참여자 구성, 사용자 조작과 결재 흐름은 변하지 않는다.
5. 관련 문서 작성/상세 회귀 테스트와 프론트엔드 빌드가 통과한다.
6. 375px, 768px, 1280px 브라우저에서 표시를 확인하고 결과 문서와 스크린샷을 남긴다.

## 작업 절차

1. [계획서](../../plan/20261015/20261015_002_문서작성_결재선_순번_표시_통일_계획서.md)와 [상세 사양서](../../spec/20261015/20261015_002_문서작성_결재선_순번_표시_통일_상세사양서.md)를 확인한다.
2. 결재선 순번 배지를 공통 컴포넌트로 정리하고 상세 화면과 작성 모달에서 재사용한다.
3. 관련 회귀 테스트, 빌드, 실제 브라우저 반응형 화면을 검증한다.
4. [결과 문서](../../result/20261015/document-approval-sequence-badge/)에 검증 결과와 개인정보가 없는 스크린샷을 기록한다.
