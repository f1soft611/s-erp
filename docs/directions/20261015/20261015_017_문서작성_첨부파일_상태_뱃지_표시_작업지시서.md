# 20261015_017 문서작성 첨부파일 상태 뱃지 표시 작업지시서

## 목적

문서 수정 모달에서 파일 상태를 첨부 박스 아래 문장으로 표시하지 않고, 사용자가 제공한 이미지와 같이 파일명과 삭제 버튼 사이에 짧은 상태 뱃지로 표시한다.

## 승인된 표시 규칙

- 행 순서: 파일 아이콘, 파일명, 상태 뱃지, 삭제 버튼
- `uploaded`: 초록 `완료`
- `pending`: 중립 `대기`
- `failed`: 빨강 `실패`
- `unknown`: 황색 `확인 필요`
- 기존 박스 아래 상태 텍스트는 제거한다.
- 실패 재시도 및 업로드 상태 확인 기능은 유지한다.
- 파일명은 가변 영역에서 줄어들고, 뱃지와 아이콘 버튼은 줄어들지 않도록 한다.

## 범위

- 프론트엔드 문서작성 첨부 행 및 그에 필요한 공용 첨부 행 확장
- 상태 뱃지/아래 상태 텍스트 부재 및 재시도/확인 동작 회귀 테스트
- 날짜별 계획/사양/결과 문서
- DB/API 변경 없음

## 절차 및 완료 기준

1. 상세 계획과 사양에 맞춰 실패 회귀 테스트를 먼저 추가한다.
2. 공용 `AttachmentList`가 선택적으로 행 끝 장식을 그릴 수 있도록 최소 확장하고 문서작성 화면에서 상태 뱃지를 전달한다.
3. 별도 상태 텍스트를 제거하되 실패 재시도/상태 확인 액션은 행에 유지한다.
4. 집중 테스트, 빌드, Problems, diff 확인을 마친다.
5. 실제 브라우저가 인증 화면으로 제한되면 그 사유를 결과 문서에 기록한다.
