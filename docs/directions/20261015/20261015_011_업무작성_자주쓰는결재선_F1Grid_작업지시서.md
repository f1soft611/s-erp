# 20261015_011 업무작성 자주 쓰는 결재선 F1-Grid 작업지시서

## 작업 목적

업무작성 모달의 `자주 쓰는 결재선 불러오기` 관리 화면을 F1-Grid로 구성한다. 결재선명은 그리드 셀에서 직접 수정하고, 우측 행 액션에서 해당 결재선을 적용하거나 삭제하며, 하단 `저장`에서 수정한 이름들을 서버에 저장한다.

## 승인된 동작

- 각 템플릿 행에 `결재선명` 및 우측 `액션`을 표시한다.
- `액션`에서 행별 `적용`을 제공한다. 버튼을 누르면 해당 결재선이 결재선 설정 모달의 임시 상태에 반영되고, 작성 화면은 기존 설정 창의 `적용`을 눌렀을 때 갱신한다.
- 이름 변경은 F1-Grid의 인라인 편집으로 수행한다. 하단 `저장`은 수정된 모든 행의 이름을 기존 이름 변경 API로 저장한다.
- 기존 삭제 확인 흐름은 행별 삭제로 유지한다. 별도 결재선 템플릿 신규 저장 흐름도 유지한다.
- 이름 수정이 저장되지 않은 상태에서 적용·삭제·관리 창 닫기를 요청하면 폐기 확인을 표시한다. 취소 시 그리드의 수정 상태를 유지한다.
- 기존 이름 길이/중복 검증, 사용자 오류 표시, 불러오기 실패 시 임시 결재선 보존을 유지한다.
- 결재선명 셀을 편집한 뒤 같은 그리드의 다른 셀 또는 모달 액션을 클릭하면 기존 편집이 commit되어 변경이 dirty 집합에 반영되어야 한다. 중첩 모달 안에서도 이 동작을 유지하고, 셀을 클릭한 경우 클릭한 셀만 선택 포커스로 남긴다.

## 작업 절차

1. 승인 설계를 바탕으로 날짜별 계획서와 상세 사양서를 정리한다.
2. 설정 모달의 관련 테스트를 먼저 추가·수정하고, 실패를 확인한다.
3. F1-Grid 이름 인라인 편집, 행별 적용/삭제, 수정 이름 일괄 저장, 미저장 수정 폐기 확인을 구현한다. 같은 Grid 안에서 다른 셀로 포커스가 이동할 때 편집을 commit하고 변경을 추적하도록 한다. 백엔드/API/DB는 변경하지 않는다.
4. F1-Grid 사용 문서와 결과 문서를 갱신한다.
5. 관련 Vitest, 프론트엔드 빌드, `git diff --check`를 수행한다.
6. 브라우저에서 375px, 768px, 1280px 화면을 확인하고 화면 캡처를 결과 문서 경로에 기록한다.

## 완료 기준

- 템플릿 목록이 F1-Grid로 표시되고 각 행의 불러오기 및 삭제가 정확한 템플릿 ID를 사용한다.
- 결재선명 셀 편집 후 다른 셀을 클릭하면 기존 편집 상태가 사라지고, 변경이 dirty로 추적되며 새 셀만 포커스된다.
- 여러 이름 변경이 하단 저장으로 반영되고 미변경 시 저장이 비활성화된다.
- 이름 공백/길이/중복 및 서버 오류가 명시되고 성공으로 오인되지 않는다.
- 부분 저장 실패 시 성공 항목과 실패 항목을 구분하며 실패 항목은 재시도할 수 있다.
- 미저장 편집에 대한 불러오기/삭제/닫기 확인 취소는 편집 상태를 보존한다.
- 기존 기안자 고정 및 결재선 설정 적용/취소 경계를 유지한다.
- 프론트엔드 테스트/빌드와 반응형 브라우저 확인을 수행하고 날짜별 결과 문서/캡처를 남긴다.
