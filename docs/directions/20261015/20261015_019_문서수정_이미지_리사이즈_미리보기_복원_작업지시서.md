# 20261015_019 문서 수정 이미지 리사이즈 미리보기 복원 작업지시서

## 목적

문서 수정 모달에 표시된 기존 본문 이미지의 크기를 조절해도 인증된 Blob 미리보기가 유지되도록 한다.

## 확인된 원인

수정 모달은 보호된 전자결재 이미지 URL을 인증된 Blob으로 조회하지만, Blob URL은 ProseMirror 문서 모델이 아닌 현재 이미지 DOM에만 설정한다. 이미지 리사이즈는 TipTap 이미지 노드의 크기 속성을 갱신해 DOM을 다시 그리므로, 모델에 남아 있던 보호 API URL이 이미지 `src`로 돌아오고 인증 없는 이미지 요청이 깨진다.

## 요구사항

1. 기존 이미지의 인증 Blob 미리보기는 에디터가 이미지 크기 속성을 갱신한 후에도 유지한다.
2. 기존 ProseMirror 이미지 `src`, API 요청, 메타데이터 계약은 변경하지 않는다.
3. 저장 결과에는 원래 전자결재 이미지 URL 및 사용자가 조정한 크기를 보존하고 Blob URL을 포함하지 않는다.
4. Blob 로드 실패 시 깨진 이미지를 다시 표시하지 않으며 기존 사용자 오류 알림을 유지한다.
5. 에디터 업데이트 리스너를 정리하고 생성한 Blob URL을 기존 수명주기에 맞게 해제한다.

## 작업 절차

1. 기존 보호 이미지 테스트에 리사이즈 핸들 조작 및 저장 결과 검증을 추가하고 실패를 확인한다.
2. 이미지 로드 효과에서 원본 URL과 Blob URL 연결을 유지하고 에디터 업데이트 후 표시 DOM에 재적용한다.
3. 이미지 미리보기, 저장 HTML/JSON, 크기 속성, 오류 및 URL 정리 회귀를 검증한다.
4. 날짜별 계획/사양/결과를 갱신하고 build, Problems, diff를 점검한다.

## 비범위

- 신규 이미지 업로드나 문서 상세 이미지 표시 변경
- 리사이즈 계산 방식, 백엔드/API 계약, DB 변경
- ProseMirror 저장 모델에 임시 Blob URL 기록
