# F1-Grid 상세검색 연동 가이드 개편 작업지시서

## 배경

기존 `필터와 정렬` 문서의 상세검색 설명은 긴 문단과 부분 코드 예제로 구성되어 있어 처음 연동하는 개발자가 컬럼 설정부터 실제 목록 조회까지 따라가기 어렵다. 승인된 A안인 단계별 레시피 구조로 다시 구성하고, 실제 기안양식 관리 화면의 검색 계약을 끝까지 보여준다.

## 작업 범위

- 포털 문서의 읽기 순서를 전체 흐름, 컬럼 선택, 필드 변환, `PageSearchArea` 연결, 페이지 조회조건 변환, 기안양식 전체 예제, 일반 날짜 예제, 빠른 참조 순으로 바꾼다.
- 실제 기안양식 상세검색의 분류(`categoryItemId`), 등록주기(`regTermId`), 사용여부(`useAt`)와 별도 키워드 검색을 정확히 설명한다.
- `F1GridColumn.search` API 검색과 문서 데이터 계약 테스트를 유지하고, 지속 문서와 날짜별 결과 문서를 갱신한다.
- 데스크톱과 375px 모바일 화면을 확인하고 결과 스크린샷을 남긴다.

## 제외 범위

- Grid, `PageSearchArea`, 검색 변환 함수, 실제 업무 화면, API/서버의 런타임 동작 변경
- 현재 기안양식 화면에 날짜 검색 추가 또는 확인되지 않은 서버 파라미터 지정
- 신규 메뉴, 전용 문서 렌더러, 별도 스타일 시스템 추가
- 백엔드 및 데이터베이스 변경

## 완료 조건

1. 가이드가 각 단계를 짧은 설명과 코드 예제로 구분한다.
2. 전체 예제가 현재 기안양식의 필드, 옵션, 값 변환, 기본 키워드, 편집 보호 흐름과 일치한다.
3. 날짜 범위 예제가 현재 기안양식 검색과 분리되고 서버 계약을 추측하지 않는다.
4. 새 문서 계약 테스트와 기존 `F1GridColumn.search` API 검색 테스트가 통과한다.
5. 프론트엔드 빌드, 포털 브라우저 검색, 1280px/768px/375px 반응형 확인을 완료한다.
6. [작업 계획서](../../plan/20261015/20261015_001_f1_grid_detail_search_guide_redesign_계획서.md), [상세 사양서](../../spec/20261015/20261015_001_f1_grid_detail_search_guide_redesign_상세사양서.md), 최종 결과 문서와 스크린샷을 작성한다.
