# 작업지시서

## 제목

F1-Grid 컨텍스트 메뉴에서 필터/정렬 해제 항목이 숨겨질 때 구분선 중복 수정

## 배경

`F1Grid.tsx`는 필터 해제/정렬 해제 메뉴 항목 앞과 설정 복원 항목 앞의 구분선을 항상 렌더링한다. `disableFiltering`과 `disableSorting`이 모두 활성화되어 두 항목이 숨겨지면 빈 메뉴 그룹을 감싸던 구분선이 연속으로 나타난다.

## 요구사항

- 두 해제 항목이 모두 숨겨질 때 필터/정렬 그룹 앞의 구분선을 렌더링하지 않는다.
- 설정 복원 항목 앞 구분선은 유지하여 바로 앞 메뉴 그룹과 구분한다.
- 필터 해제 또는 정렬 해제 중 하나라도 표시될 때는 기존 그룹 구분선을 유지한다.
- 기존 항목 노출 조건, 메뉴 순서, 활성/비활성 상태 및 나머지 구분선은 변경하지 않는다.

## 변경 및 검증 절차

1. `frontend/tests/f1-grid-context-menu.test.tsx`에 두 항목이 숨겨질 때 중복 구분선이 없는 테스트를 추가하고, 일부 항목이 보일 때 기존 구분선이 유지되는지도 검증한다.
2. 해당 테스트를 먼저 실행해 현재 동작에서 실패하는지 확인한다.
3. `frontend/src/shared/components/f1-grid/core/F1Grid.tsx`에서 두 항목 중 하나라도 노출될 때만 해당 그룹 앞 구분선을 렌더링한다.
4. 회귀 테스트와 `frontend/src/pages/f1-grid-docs/F1-GRID.md`를 갱신한다.
5. 관련 Vitest 테스트와 프론트엔드 빌드를 실행한다.
6. 브라우저에서 메뉴를 확인하고 캡처를 결과 폴더에 기록한다.

## 범위 제외

- 다른 컨텍스트 메뉴 구분선의 정규화 또는 재배치
- 필터/정렬 기능이나 항목 동작 변경
- F1-Grid의 기타 UI/상태 관리 변경

## 완료 기준

- 두 해제 항목이 모두 숨겨졌을 때 설정 복원 앞에 단일 구분선만 표시된다.
- 해제 항목 중 하나라도 표시되면 기존 구분선과 항목 순서가 유지된다.
- 집중 테스트와 빌드가 통과하며, F1-Grid 문서와 날짜별 결과 문서/화면 캡처가 포함된다.
