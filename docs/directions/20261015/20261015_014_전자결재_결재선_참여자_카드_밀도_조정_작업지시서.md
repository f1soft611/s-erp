# 20261015_014 전자결재 결재선 참여자 카드 밀도 조정 작업지시서

## 작업 분류

- 대상: 프론트엔드 전자결재 문서 상세 결재선
- 화면: 결재, 합의, 참조 참여자 카드
- 승인 설계: [참여자 카드 밀도 조정 설계](../../superpowers/specs/2026-10-15-document-approval-participant-card-density-design.md)
- DB/API 변경: 없음

## 작업 목적

합의·참조 참여자 카드가 한 줄에 남는 콘텐츠 폭을 균등하게 채우고 카드 높이를 줄인다. 결재·합의·참조 모든 카드의 사용자명 글자 크기를 낮추고, 합의·참조의 두 줄 사용자 정보와 상태 표시가 줄어든 카드 안에 유지되도록 한다.

## 요구사항

1. 합의·참조 카드에 `flex: 1 1 240px`, 최소 너비 `min(100%, 190px)`, 최대 너비 100%를 적용하고 콘텐츠 열에서 기존처럼 줄바꿈한다.
2. 합의·참조 카드의 높이를 `56px`, `box-sizing: border-box`로 한다.
3. 합의·참조 카드의 아바타를 `32 × 32px`, 내부 padding을 가로 8px·세로 6px로 한다.
4. 결재·합의·참조 참여자 이름을 모두 14px로 표시한다. 결재 카드의 폭, 높이, 아바타, 상태/순번 배치는 유지한다.
5. 합의·참조 부서명 및 합의 상태 배지를 14px/18px line-height로 표시하며 기존 둘째 줄 배치를 유지한다.
6. `부서없음` 표시, 결재순서/합의 단계/참여자 순서/상태 및 프로필 이미지 fallback을 유지한다.
7. 페이지 전체 가로 넘침이나 텍스트 겹침 없이 작은 뷰포트에서 콘텐츠 열 내부 줄바꿈을 보존한다.
