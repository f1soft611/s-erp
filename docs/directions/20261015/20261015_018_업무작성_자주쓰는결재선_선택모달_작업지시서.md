# 작업지시서

## 제목

업무작성 결재선 설정에서 자주 쓰는 결재선 선택 및 저장 버튼 위치 변경

## 목적

결재선 설정 창에서 등록된 자주 쓰는 결재선을 select로 바로 적용할 수 있게 하고, 기존 F1-Grid 관리 화면은 `설정` 버튼을 통해 유지한다. 자주 쓰는 결재선 저장 시작 버튼은 설정 창 footer 왼쪽에 배치한다.

## 승인된 요구사항

- `자주 쓰는 결재선` 제목 아래에 템플릿 select와 `설정` 버튼을 한 줄로 표시한다.
- 결재선 설정 창을 열 때 현재 문서 종류의 템플릿 요약 목록을 조회한다.
- select에서 결재선을 고르면 기존 상세 조회를 실행하고 성공한 경우 결재선 설정 창의 임시 결재선/참조자에 즉시 반영한다. 작성 화면에는 기존 `적용` 버튼을 눌렀을 때 반영한다.
- `설정`은 기존 자주 쓰는 결재선 F1-Grid 관리 모달을 연다. 관리 모달 종료 후 목록을 갱신한다.
- `자주 쓰는 결재선 저장` 시작 버튼은 본문에서 제거하고 `CommonDialog` footer 왼쪽에 둔다. 기존 이름 입력 저장 모달은 유지하며 저장 성공 시 새 항목을 목록에 추가하고 선택 상태로 표시한다.
- 상세 조회 실패 시 현재 임시 결재선/참조자는 유지하고 오류를 표시하며 선택한 항목은 select에 남긴다.
- 목록 조회 및 목록 갱신 실패는 빈 목록처럼 보이지 않게 오류와 재시도 수단을 제공한다.
- 기존 관리 Grid, API/DB 계약, 결재선 설정의 적용/취소 경계를 변경하지 않는다.

## 작업 및 완료 기준

1. 날짜별 계획 및 상세 사양을 이 작업지시서와 승인된 설계 문서를 근거로 작성한다.
2. 설정 다이얼로그 테스트에 자동 목록 조회, 템플릿 즉시 적용, 오류 시 임시 데이터 유지, 설정 모달 이후 갱신, footer 저장 위치 및 생성 후 선택 테스트를 먼저 추가하고 실패를 확인한다.
3. 기존 템플릿 API 및 `CommonDialog.footerStart`를 재사용해 UI와 상태 흐름을 구현한다.
4. 기존 관리 모달의 행별 적용/삭제, 이름 수정/저장, 오류/확인 흐름이 유지되는지 회귀 검증한다.
5. 결과 보고서에 변경/검증/브라우저 확인을 기록하고 반응형 화면 캡처를 갱신한다.

완료 조건은 선택 즉시 임시 결재선이 갱신되고, 작성 화면은 명시적 적용 전까지 유지되며, 저장 진입 버튼이 footer 왼쪽에서 기존 저장 모달을 여는 것이다. 관련 테스트, 빌드, 문제 진단 및 `git diff --check` 결과를 기록한다.
