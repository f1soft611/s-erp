# 20261015_006 전자결재 상세 합의·참조 한 줄 배치 작업지시서

## 작업 분류

- 대상: 프론트엔드 상세 결재선 레이아웃
- 화면: 전자결재 문서 상세의 합의·참조 영역
- 기준 설계: [합의·참조 한 줄 배치 설계](../../superpowers/specs/2026-10-15-document-approval-agreement-reference-inline-layout-design.md)
- DB/API 변경: 없음

## 작업 목적

전자결재 상세 화면에서 합의·참조 제목이 참여자 결재선과 별도 줄에 표시되는 여백을 줄이고, 두 영역의 제목과 기본 높이를 일관되게 맞춘다.

## 요구사항

1. 합의 및 참조 제목을 각 참여자 목록 왼쪽에 배치해 제목과 목록이 한 행에서 시작되도록 한다.
2. 두 영역의 제목 열 너비와 행의 기본 높이를 동일하게 한다.
3. 기존 참여자 카드의 정보, 순서, 상태 표시와 합의 단계 번호를 유지한다.
4. 좁은 화면에서는 제목을 유지하고 참여자 목록만 가용 폭에 따라 줄바꿈한다. 페이지 전체 가로 넘침은 만들지 않는다.
5. 결재 처리 동작, 데이터/API, 승인 카드 레이아웃은 변경하지 않는다.

## 작업 순서

1. [계획서](../../plan/20261015/20261015_008_전자결재_상세_합의_참조_한줄배치_계획서.md)에 변경 파일과 테스트 기준을 정리한다.
2. [상세 사양서](../../spec/20261015/20261015_008_전자결재_상세_합의_참조_한줄배치_상세사양서.md)에 데스크톱 및 좁은 화면의 배치 기준을 고정한다.
3. 상세 결재선의 합의·참조 표시만 수정하고 관련 회귀 테스트를 추가 또는 갱신한다.
4. 관련 테스트와 프론트엔드 빌드를 수행하고 375px, 768px, 1280px 브라우저 폭에서 확인한다.
5. [결과 폴더](../../result/20261015/document-approval-agreement-reference-inline-layout/)에 결과 문서와 개인정보가 포함되지 않은 화면 캡처를 기록한다.

## 완료 기준

- 데스크톱에서 합의·참조 제목과 해당 참여자 영역이 각각 같은 행에 놓인다.
- 합의와 참조의 제목 열 너비 및 기본 행 높이가 일치한다.
- 좁은 화면에서도 제목이 유지되고 참여자 카드만 줄바꿈하며 페이지 전체 가로 넘침이 없다.
- 기존 결재선 데이터와 승인·합의 처리 동작이 보존된다.
- 관련 테스트, 빌드, 실제 브라우저 확인 및 결과 문서/캡처가 완료된다.
