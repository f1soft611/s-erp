# 20261015_010 문서작성 상세 패널 모바일 너비 수정 작업지시서

## 작업 목적

375px 화면에서 문서 상세 패널이 문서작성 페이지 영역 밖으로 잘리는 현상을 수정한다. 상세 패널은 공통 헤더 아래 페이지 영역에 계속 한정한다.

## 요구사항

1. 문서작성 페이지 루트가 내부 콘텐츠의 최소 너비 때문에 상위 콘텐츠 영역보다 넓어지지 않아야 한다.
2. 상세 패널은 계속 문서작성 페이지 루트의 위치·너비를 기준으로 우측에 배치한다.
3. 앱 셸, 공통 오버레이 컴포넌트, 공지 페이지, 결재 권한·API·상태 동작은 변경하지 않는다.
4. 375px, 768px, 1280px에서 페이지 전체 가로 넘침이 없고 상세 패널이 페이지 영역에 맞는지 확인한다. 인증된 브라우저 접근이 불가하면 미확인 사실과 원인을 기록한다.

## 작업 절차

1. [승인 설계](../../superpowers/specs/2026-10-15-document-write-responsive-width-design.md), [계획서](../../plan/20261015/20261015_010_document_write_responsive_width_plan.md), [상세사양서](../../spec/20261015/20261015_010_document_write_responsive_width_spec.md)를 따른다.
2. `document-write-page.test.tsx`의 페이지 루트 회귀 검증을 먼저 추가하고, 구현 전에 해당 테스트가 실패하는지 확인한다.
3. `DocumentWritePage` 루트에만 `minWidth: 0`을 추가한다. 다른 flex 경계나 오버레이 정책은 수정하지 않는다.
4. 집중 테스트, 빌드, Problems 및 diff 검사를 실행한다.
5. 가능한 경우 실제 브라우저에서 375px, 768px, 1280px을 검증하고 결과 문서를 작성한다.

## 비범위

- 대시보드 공통 레이아웃, 사이드바, `DashboardContent` 전역 수정
- `PageAreaOverlay`의 위치·폭·닫기 동작 변경
- 공지사항 및 기타 페이지의 반응형 수정
- API, 백엔드, DB, 결재 권한 및 비즈니스 상태 변경
- 기존 작업공간 변경 정리 또는 되돌리기

## 완료 기준

- 문서작성 페이지 루트에 `min-width: 0`이 적용된다.
- 대상 회귀 테스트가 수정 전 실패하고 수정 후 통과한다.
- 관련 검증 결과와 브라우저 접근 제한이 결과 문서에 남는다.
