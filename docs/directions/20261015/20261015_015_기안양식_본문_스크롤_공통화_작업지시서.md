# 20261015_015 기안양식 본문 스크롤 공통화 작업지시서

## 작업 분류

- 대상: 프론트엔드 기안양식관리
- 화면: 문서 양식 작성/수정 모달
- 승인 설계: [기안양식 본문 스크롤 공통화 설계](../../superpowers/specs/2026-10-15-draft-form-template-body-scroll-design.md)
- DB/API 변경: 없음

## 작업 목적

문서 양식 편집 모달이 문서 작성 및 공지사항 작성 모달과 동일한 공통 다이얼로그 셸을 사용하도록 일관성을 유지하면서, 에디터 주변의 위·아래 구분선을 제거하고 모달 본문 전체에서 스크롤되도록 한다.

## 요구사항

1. 기존 `CommonDialog` 공통 셸을 유지한다. 별도 모달을 새로 만들거나 공통 셸의 다른 화면 동작을 변경하지 않는다.
2. 문서 양식 에디터 프레임의 위·아래 구분선을 제거한다. 공통 셸의 헤더·푸터 구분선은 유지한다.
3. 모달 제목 영역과 푸터의 툴바/저장/취소 액션은 고정하고, 양식 편집 본문 전체가 세로 스크롤되도록 한다.
4. 다른 RichTextEditor 사용 화면의 스크롤 동작을 바꾸지 않는다.
5. 본문 편집, 서식, 붙여넣기, 이미지 업로드, 저장, 취소 및 미저장 변경 확인 동작을 보존한다.

## 작업 절차

1. [승인 설계](../../superpowers/specs/2026-10-15-draft-form-template-body-scroll-design.md), 상세 계획서 및 상세사양서를 기준으로 변경 범위를 확정한다.
2. [기안양식 본문 모달 테스트](../../../frontend/tests/draft-form-template-dialog.test.tsx)에 테두리 및 스크롤 소유 영역 검증을 반영한다.
3. `DraftFormTemplateDialog` 및 필요 시 공유 rich-text editor의 해당 사용 옵션만 조정한다.
4. 집중 테스트, 프론트엔드 빌드 및 Problems를 확인한다.
5. 브라우저에서 375px, 768px, 1280px 화면의 전체 본문 스크롤과 고정 헤더/푸터를 확인한다.
6. [결과 폴더](../../result/20261015/draft-form-template-body-scroll/)에 변경 및 검증 결과와 가능한 스크린샷을 기록한다.

## 비범위

- 공통 `CommonDialog`의 다른 소비 화면 변경
- 공지사항 또는 문서 작성 모달의 개별 편집기 동작 변경
- API, 데이터 계약, 백엔드 및 DB 변경
- 양식 편집기 기능 또는 저장/업로드 동작 변경

## 완료 기준

- 에디터 프레임에 위·아래 구분선이 없고, 내부 중첩 스크롤 없이 모달 본문 전체가 스크롤된다.
- 제목 영역 및 푸터 액션이 고정되고, 다른 rich-text editor 소비 화면의 스크롤은 유지된다.
- 기존 편집/저장/취소 관련 집중 테스트와 프론트엔드 빌드가 통과한다.
- 브라우저 확인 또는 미수행 사유, 결과 문서 및 스크린샷 여부가 결과 폴더에 기록된다.
