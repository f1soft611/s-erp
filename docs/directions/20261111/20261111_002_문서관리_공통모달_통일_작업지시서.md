# 문서관리 공통 모달 통일 작업지시서

## 목적

문서관리에서 사용하는 일반 확인·입력 모달을 `CommonDialog`로 통일해 공통 테마, 헤더, 액션 영역 및 반응형 스타일을 적용한다.

## 요구사항

- 문서관리 화면 안에서 직접 MUI `Dialog`를 사용하는 일반 모달을 `CommonDialog`로 전환한다.
- 상단 고정/해제 확인과 문서 작성·설정 중 확인에 사용하는 `UnsavedChangesConfirmDialog` 호출도 `CommonDialog` 기반으로 통일한다.
- 기존 제목, 안내 문구, 입력 요소, 액션 라벨, 처리 중 비활성화, 닫기 조건 및 제출 동작을 유지한다.
- 참조자 추가 모달의 기존 너비와 사용성을 유지할 수 있도록 공통 크기 옵션을 보완한다.
- 이미지 뷰어와 팝오버처럼 일반 확인·입력 모달이 아닌 특수 UI는 변경하지 않는다.
- 공유 확인 컴포넌트 구현과 문서관리 외 화면에는 영향을 주지 않는다.

## 작업 순서

1. 문서관리 모달의 사용처와 기존 동작을 확인한다.
2. 공통 크기 옵션 및 모달 전환에 대한 회귀 테스트를 먼저 작성한다.
3. 문서관리의 일반 확인·입력 모달을 `CommonDialog`로 전환한다.
4. 기존 액션 흐름, 비활성화 및 닫기 동작을 검증한다.
5. 관련 테스트와 빌드를 수행하고 375px/768px/1280px 브라우저 화면을 확인한다.
6. 결과 문서와 비식별 화면을 `docs/result/20261111/document-management-common-dialogs/`에 기록한다.

## 제외 범위

- 문서관리 이외의 화면 및 공유 `UnsavedChangesConfirmDialog` 구현
- 이미지 뷰어, 팝오버 등 특수 목적 UI
- 문서 업무 로직, API, 백엔드 및 DB 변경

## 완료 기준

- 문서관리의 일반 확인·입력 모달이 `CommonDialog`를 사용한다.
- 참조자 추가 모달이 기존 너비에 가까운 공통 크기를 사용한다.
- 버튼 동작, 닫기 조건, 오류/안내 메시지 및 입력 흐름이 유지된다.
- 관련 회귀 테스트, 빌드, 브라우저 반응형 확인이 완료되고 결과 문서 및 화면 기록이 남는다.
