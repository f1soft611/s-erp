# 작업표준서 등록(레시피) 화면 레이아웃 작업지시서

## 목적

기준정보 모듈에 `작업표준서 관리 > 작업표준서 등록(레시피)` 메뉴를 추가하고, 제공된 레이아웃 샘플을 기준으로 화면 레이아웃을 구성한다.

## 요구사항 (요청 원문 요약)

- 경로: 기준정보 > 작업표준서 관리 > 작업표준서 등록(레시피) 에 메뉴를 추가한다.
- 구조는 현재 iPlusMES(S-ERP) 프론트엔드 구조(`pages/<도메인>/<기능>`, `PageHeader`, `PageSearchArea`, `F1Grid`)를 따른다.
- 검색은 통합검색(키워드)만 상단에 두고, 나머지 조건(품목계정·제품분류·버전 상태·공정)은 상세검색으로 제공한다.
- 작업표준서 기본정보 영역은 수주등록의 기본정보 영역과 유사한 구성(Paper + 4열 입력 그리드)으로 만든다.
- 하단 탭은 F1-Grid로 구현하며 F1-Grid 공통 컴포넌트는 수정하지 않는다.
- 우선 배합비 탭까지 화면 레이아웃을 구성한다. 나머지 탭은 탭 머리만 노출한다.
- 백엔드는 아직 구현하지 않는다. 화면은 예시 데이터로 동작한다.

## 기준 화면

- 수주등록: `frontend/src/pages/sales/order/create/SalesOrderCreatePage.tsx` (헤더 액션, 기본정보 Paper, 상세 F1Grid 툴바)
- 수주현황: `frontend/src/pages/sales/order/status/SalesOrderStatusPage.tsx` (통합검색 + 상세검색 `PageSearchArea`, 결과 건수)
- 레이아웃 샘플: 사용자 제공 이미지(좌측 작업표준서 목록, 우측 기본정보 + 하단 탭)

## 완료 기준

- 메뉴 seed 적용 시 기준정보 모듈에 작업표준서 관리 > 작업표준서 등록(레시피)가 노출되고 화면이 열린다.
- 통합검색 + 상세검색, 작업표준서 목록, 기본정보, 배합비 탭 F1Grid가 샘플 레이아웃과 같은 구조로 표시된다.
- F1-Grid 공통 코드는 변경하지 않는다.
- 테스트·빌드 통과 및 결과 문서/스크린샷이 남는다.
