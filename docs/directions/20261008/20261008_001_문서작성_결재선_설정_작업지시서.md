# 20261008_001 문서작성 결재선 설정 작업지시서

## 작업 목적

문서작성 모달의 `합의 추가` 옆에 `결재선 설정`을 추가한다. 현재 작성 중인 결재선과 참조선을 별도 설정 창에서 편집하고 적용하며, 결재선 순서 변경과 결재/합의/참조 참여자 변경을 지원한다.

## 승인 요구사항

- 설정 창을 열면 현재 작성 중인 결재 단계와 참조자를 불러온다.
- 창의 편집 상태는 임시 상태로 유지한다. `적용`을 눌렀을 때만 작성 상태에 함께 반영하고, 취소/닫기 시 변경을 폐기한다.
- 고정 기안자는 이동/수정/삭제할 수 없다.
- 결재 및 합의 단계는 단계 단위로 드래그하거나 위/아래 버튼으로 이동한다. 합의자 그룹은 한 단계로 취급한다.
- 결재자와 합의자를 추가/삭제하고 참조자를 별도 선택기로 추가/삭제한다. 기존 문서작성 결재/참조 사용자 중복 제한과 한 단계 사용자 구조를 유지한다.
- 즐겨찾기 저장 및 불러오기 버튼은 표시하되, 테이블/API 및 명명 규칙 결정 전까지 비활성화하고 사유를 안내한다. 로컬 저장이나 서버/DB API는 만들지 않는다.
- 기존 `CommonDialog`, `UserSelectEditor`, `DocumentApprovalStage` 데이터 구조를 재사용한다.

## 작업 절차

1. 결재선 설정 창의 독립 테스트를 먼저 작성하고 실패를 확인한다.
2. 편집 창의 복사/재정렬/참여자 편집/즐겨찾기 비활성 상태를 구현한다.
3. 문서작성 화면의 결재선 설정 버튼과 임시 편집 상태의 적용/취소 흐름을 연결한다.
4. 적용 뒤 다음 결재 단계 추가 시 ID가 중복되지 않는지 검증한다.
5. 관련 Vitest, 프론트엔드 빌드 및 375px/768px/1280px 브라우저 화면을 확인한다.
6. 결과 보고서와 화면 캡처를 날짜별 결과 폴더에 기록한다.

## 완료 기준

- 설정 버튼에서 작성 중 결재선/참조자를 확인하고 변경할 수 있다.
- 드래그 및 위/아래 이동으로 고정 기안자 뒤의 단계를 재정렬할 수 있다.
- 적용 시 결재선과 참조자가 함께 반영되고, 취소/닫기 시 작성 화면 원본이 유지된다.
- 즐겨찾기 저장/불러오기는 비활성화 사유를 표시하며 저장 성공을 가장하지 않는다.
- 테스트, 빌드, 세 화면 폭 브라우저 확인 및 결과 문서/스크린샷을 완료한다.

## 범위 제외

- 즐겨찾기 저장 테이블/마이그레이션, API 및 사용자별 영속 저장
- 결재/합의 역할 전환, 기안자 단계 변경
- 실제 문서 저장, 상신, 승인
- 백엔드/DB 변경
