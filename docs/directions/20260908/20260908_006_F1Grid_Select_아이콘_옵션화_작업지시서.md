# 작업지시서

## 제목

F1-Grid Select 아이콘 렌더링 옵션화 및 모듈관리 전용 적용

## 작업 분류

- 경로: `bounded`
- 사유: F1-Grid 공통 Select 에디터의 표시 동작만 명시적 컬럼 옵션으로 전환하고, 기존 모듈관리 아이콘명 컬럼에만 해당 옵션을 적용한다. API, 데이터베이스, 라우팅 변경은 포함하지 않는다.

## 배경

- 현재 `SelectEditor.tsx`는 모든 `type: 'select'` 컬럼의 선택값과 옵션 항목에 아이콘을 렌더링한다.
- 아이콘 이름으로 해석하지 못하는 값도 기본 `Settings` 아이콘으로 대체되어, 일반 Select 컬럼에도 의도하지 않은 아이콘이 표시된다.
- 모듈관리의 `iconName` 컬럼은 아이콘을 선택하고 확인해야 하므로 현재와 같이 아이콘을 표시해야 한다.

## 목표

1. 일반 F1-Grid Select 컬럼은 아이콘 없이 레이블만 표시한다.
2. 컬럼이 명시적인 옵션을 설정한 경우에만 선택값과 드롭다운 옵션에 아이콘을 표시한다.
3. 아이콘 종류는 F1-Grid 사용자가 컬럼 옵션을 통해 설정한다.
4. 모듈관리의 `iconName` Select 컬럼은 기존 아이콘 미리보기 동작을 유지한다.

## 요구사항

### 1. 공통 컬럼 계약

- `F1GridColumn`에 Select 옵션의 아이콘을 렌더링하기 위한 선택적 콜백 `selectOptionIcon`을 추가한다.
- 콜백은 선택 옵션(`F1GridOption`)을 받아 아이콘 `ReactNode` 또는 빈 값을 반환할 수 있어야 한다.
- 옵션이 없거나 콜백이 아이콘을 반환하지 않으면 아이콘 영역을 렌더링하지 않는다.

### 2. SelectEditor 동작

- `SelectEditor`는 컬럼에서 전달받은 `selectOptionIcon`이 있을 때만 선택값 및 목록 옵션에 아이콘을 표시한다.
- 기존의 전역 값-아이콘 하드코딩 매핑과 미등록 값의 기본 `Settings` 아이콘 대체 동작을 제거한다.
- 아이콘 표시 여부와 무관하게 현재 값 선택, 레이블 표시, 변경 이벤트 및 셀 크기 스타일은 유지한다.

### 3. 모듈관리 적용

- `ModuleManagementPanel`의 `iconName` 컬럼에서만 프로젝트의 기존 모듈 아이콘 목록에 맞춘 렌더러를 설정한다.
- 모듈관리에서 아이콘이 설정되지 않았거나 알 수 없는 아이콘명인 경우에는 아이콘 없이 레이블만 표시한다.
- 다른 모든 `type: 'select'` 컬럼은 새 옵션을 설정하지 않아 일반 Select로 동작한다.

### 4. 문서 및 검증

- F1-Grid 문서에 `selectOptionIcon`의 기본 비활성 동작, 사용 예시 및 모듈관리 적용 기준을 반영한다.
- 공통 Select 렌더링과 모듈관리 컬럼 설정을 검증하는 Vitest를 추가 또는 보완한다.
- UI 변경 결과는 데스크톱과 모바일 브라우저에서 캡처하여 결과 문서에 보관한다.
- DB 스크립트: 해당 없음. 기존 스키마 영향 검토 완료.

## 완료 기준

- `selectOptionIcon`이 없는 F1-Grid Select는 선택값과 드롭다운 항목에 아이콘을 표시하지 않는다.
- `selectOptionIcon`이 있는 컬럼은 콜백이 반환한 아이콘을 표시한다.
- 모듈관리 `iconName` 컬럼은 아이콘과 레이블을 함께 표시한다.
- 미등록 아이콘명에 `Settings` 등 임의 기본 아이콘이 표시되지 않는다.
- 관련 테스트, 프론트엔드 빌드 및 데스크톱·모바일 브라우저 캡처 결과가 결과 문서에 기록된다.
