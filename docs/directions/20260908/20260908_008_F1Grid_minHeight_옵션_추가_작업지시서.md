# 작업지시서

## 제목

F1-Grid 부모 높이 연동 및 내부 스크롤 보장

## 작업 분류

- 경로: `bounded`
- 대상: 프론트엔드 공용 F1-Grid 및 관련 문서·테스트
- 사유: 기존 `height`/`maxHeight`와 대칭되는 최소 높이 제어가 필요하며, 공용 그리드 계약에 한정된 작은 API 확장이다.

## 배경

- 현재 `F1GridProps`에는 `height`와 `maxHeight`가 있으나 `minHeight`가 없다.
- F1-Grid 컨테이너는 내부적으로 `minHeight: 0`을 고정 적용하므로, 부모 flex 레이아웃 또는 로딩 스켈레톤이 요구하는 최소 표시 높이를 인스턴스별로 지정할 수 없다.
- 메뉴 관리 화면처럼 `height="100%"`를 사용하는 화면에서 부모 높이 변화에 맞춰 그리드가 줄어들고, 초과 행은 그리드 본문 안에서 스크롤되어야 한다.

## 목표

1. `F1GridProps`와 `F1TreeProps`에서 사용할 수 있는 선택적 `minHeight` 옵션을 제공한다.
2. 숫자 값은 기존 `height`/`maxHeight`와 동일하게 px로 해석하고, 문자열은 CSS 길이 값으로 전달한다.
3. `height="100%"` 사용 시 부모 flex 영역의 높이와 `minHeight: 0` 조건을 통해 브라우저 높이 축소를 반영한다.
4. 행이 부모 높이를 초과하면 페이지가 아닌 F1-Grid 본문에서 세로 스크롤한다.
5. 옵션 미지정 시 기존 동작을 유지한다.
6. F1-Grid 문서와 회귀 테스트에 공개 계약 및 동작을 반영한다.

## 요구사항

### 1. 공용 Props 계약

- `minHeight?: number | string`을 `F1GridProps`에 추가한다.
- `F1TreeProps`는 `F1GridProps`를 상속하는 기존 구조를 통해 동일 옵션을 노출한다.
- `minHeight={0}`도 유효한 값으로 처리하고, 숫자 값은 `${value}px`로 변환한다.

### 2. 컨테이너 적용

- F1-Grid 최상위 컨테이너의 `minHeight` 스타일에 옵션을 연결한다.
- 옵션을 지정하지 않은 경우 기존의 `minHeight: 0` 동작을 유지한다.
- `height="100%"` 호출부의 부모 및 상위 flex 컨테이너는 `minHeight: 0`과 남은 공간을 차지하는 `flex: 1`을 가져야 한다.
- 브라우저 높이가 줄어들면 그리드 루트 높이도 함께 줄고, 본문 `overflowY: auto`로 초과 행을 스크롤한다.
- 기존 `height`, `maxHeight`, flex 내부 스크롤, 로딩 스켈레톤 동작을 변경하지 않는다.

### 3. 문서·테스트

- `frontend/src/pages/f1-grid-docs/F1-GRID.md`의 Props/API 설명에 `minHeight` 타입·단위·기본 동작을 추가한다.
- 공용 F1-Grid 테스트에 숫자 및 문자열 값이 컨테이너 스타일에 적용되는지, 미지정 시 기존 값이 유지되는지 회귀 사례를 추가한다.
- F1-Grid 변경 결과 문서에 변경 전·후, 검증 명령, 브라우저 확인 결과를 기록한다.

## 제외 범위

- 메뉴 관리 화면에 임의의 고정 높이를 적용하는 작업
- `height`/`maxHeight`의 의미 또는 우선순위 변경
- 행 높이 옵션(`minRowHeight`)의 동작 변경
- F1-Grid 외 화면의 레이아웃 리팩터링
- 백엔드·API·DB 변경

## 설계 대안

### 권장안: F1-Grid 공용 `minHeight` Props 추가

기존 `height`/`maxHeight`와 동일한 값 변환 패턴으로 최상위 컨테이너에 적용한다. `F1Tree`가 별도 변환 없이 같은 계약을 상속하므로 API가 일관되고, 호출부가 필요한 화면에서만 최소 높이를 지정할 수 있다.

### 대안: 호출부 래퍼의 CSS로 최소 높이 지정

메뉴 화면의 래퍼에만 `minHeight`를 지정할 수 있지만, 공용 그리드가 이미 `minHeight: 0`을 설정하므로 인스턴스 계약이 불명확해지고 다른 화면에서 같은 요구가 반복될 때 중복 스타일이 생긴다.

## 검증 조건

1. `F1GridProps`에 `minHeight`가 노출되고 `F1Tree`에서도 타입 오류 없이 사용할 수 있다.
2. 숫자와 문자열 `minHeight`가 최상위 grid 컨테이너에 각각 올바른 CSS 값으로 적용된다.
3. `minHeight` 미지정 시 기존 `minHeight: 0` 동작이 유지된다.
4. 관련 F1-Grid Vitest 테스트와 프론트엔드 빌드가 통과한다.
5. 최소 375px, 768px, 1280px 브라우저 뷰포트에서 레이아웃 겹침·가로 스크롤 이상이 없는지 확인하고 결과 문서에 기록한다.
