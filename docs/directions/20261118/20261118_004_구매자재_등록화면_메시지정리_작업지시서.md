# 20261118_004 구매자재 등록화면 상단 메시지 정리 작업지시서

## 배경
수정 창(등록 화면 공용)에서 값을 바꾸거나 다시 시도해도 이전 경고·오류·성공 메시지가 계속 남아 위에 쌓인다. 오른쪽 X로만 지워진다(2026-11-18 사용자 제보). 구매요청, 구매요청확정, 발주, 가입고, 입고, 수입검사 등록 화면이 같은 구조다.

## 원인
검증 메시지 목록, 성공 안내, 오류, (발주는) 경고가 각각 따로 저장되고, 각 처리 지점이 그중 일부만 지운다. 예) 값을 고치면 검증 메시지만 지워지고 오류·성공·경고는 남는다. 발주의 저장 후 경고는 X를 누르거나 신규로 초기화할 때까지 남는다.

## 정책 (사용자 승인)
- 사용자가 값을 고치거나 새 동작(저장·불러오기·행 추가·삭제·선택)을 하면 **일시 메시지(검증·오류·경고·성공)를 모두 비우고** 그 동작의 결과만 보여준다.
- 상태 안내(취소된 문서, 확정과 다른 행, 출력됨, 잠금 안내 등)는 상태에서 계산되는 안내이므로 계속 표시한다.
- 동작 결과로 새로 생기는 메시지는 비운 뒤에 설정하므로 사라지지 않는다.

## 범위
- 포함: 위 여섯 등록 화면(수정 창 포함)의 일시 메시지 처리 통일, 공통 훅 추가, 테스트, 문서.
- 제외: 영업·그룹웨어 등 다른 화면, 메시지 디자인·여백 변경, 백엔드 변경.

## 완료 조건
- 여섯 화면에서 값 수정·동작 시 이전 일시 메시지가 사라지고 새 결과만 남는다. 상태 안내는 유지된다.
- 저장 성공 직후의 성공 메시지는 그리드 재구성 때문에 사라지지 않는다. 관련 테스트·빌드가 통과한다.
