# 20261118_007 단가등록 이력·부가세·외화·기본단가 개선 작업지시서

## 배경
단가등록(`co/master/item-partner-prices`)은 품목·거래처·구분(매입/매출)별 단가를 한 줄로 관리하는 뼈대만 있다. MES 구매단가(WCO315)는 부가세구분·부가세포함·외화단가·통화·적용일·이력을 관리했다. 현업은 특별 거래처만 단가를 따로 지정하고 나머지 거래처는 같은 단가를 쓰므로, 모든 거래처에 단가를 등록하게 하면 안 된다(2026-11-18 사용자 결정).

## 정책 (사용자 승인)
- 매입·매출을 한 화면에서 계속 관리한다(`trade_type`). 단가 노출 권한 분리는 후속.
- 추가 항목: 부가세구분(공통코드 `PURCHASE_TAX_TYPE`), 부가세포함 여부(Y/N), 외화단가(선택), 통화(공통코드 `CURRENCY`, 외화단가의 통화). 환율은 단가 화면에서 관리하지 않는다.
- 제외: 외주가공 단가, 기본 거래처 체크, 발주구분, 단가단위. 단위는 품목 마스터 단위를 보여 주기만 한다.
- 기본단가: 거래처가 비어 있는 행을 "품목 기본단가"로 쓴다. 단가 조회는 품목+거래처 → 품목 기본단가 순으로 찾는다. 품목+거래처 단가를 필수로 하지 않는다.
- 이력: 적용 기간 행 자체가 이력이다. 새 적용일 등록 시 직전 행 종료일을 자동으로 닫고, 기간 겹침은 저장을 막는다.
- 조회: 기본은 현재 적용 중·예정 단가만, "이력 포함"을 선택하면 종료된 과거 행도 표시한다.
- 수정 제한(프론트·백엔드 모두): 과거 행(종료일이 오늘 이전)은 수정·삭제 불가, 현재 적용 중 행은 정정 가능하되 적용일 변경 불가, 예정 행은 자유. 기준일은 서버 날짜.

## 범위
- 포함: 프론트 단가등록 화면·엑셀 가져오기, 백엔드 `let/co/master/itempartnerprice`, 구매확정 단가 조회 쿼리(`selectDefaultUnitPrice`)의 기본단가 폴백, DB 변경 스크립트.
- 제외: 영업 파일(이 테이블을 쓰는 영업 코드 없음을 확인함), 환율 연동, 권한 분리, 발주 단가 재계산.

## 완료 조건
- 부가세구분·포함·외화단가·통화가 저장·조회된다. 거래처 없는 기본단가를 등록할 수 있고 단가 조회가 폴백한다.
- 겹침·과거 행 수정은 서버에서 막힌다. 신규 적용일 등록 시 직전 행이 자동 종료된다.
- 관련 테스트 통과, DB 스크립트·롤백·변경 이력·`db-schema.md` 갱신.
