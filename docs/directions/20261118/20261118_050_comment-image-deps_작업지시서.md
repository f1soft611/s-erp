# 공지 댓글 이미지 조회 의존성 작업지시서

- 근거: 잔여 lint 순차 처리 요청과 NoticeFeedList 댓글 이미지 effect의 배열 누락 진단 1건.
- [댓글 이미지 기존 사양](../../spec/20261029/20261029_005_댓글_수정권한_이미지첨부_구분선_상세사양서.md)과 기존 미리보기·뷰어·다운로드·오류·URL 정리 동작을 유지한다.
- 기존 effect의 실제 재실행 키는 notice ID와 `[noticeId, commentId, attachmentId][]`의 JSON 문자열이다. 이미지 ID가 같고 댓글 표시 정보나 테마만 달라졌을 때 재다운로드하지 않는다.
- 배열 참조를 dependency에 추가하면 기존 재요청 조건이 넓어진다. 대신 내부에서 생성한 기존 JSON 키를 effect 안에서 같은 순서의 요청 ID로 복원하여 실제로 선언된 값만 읽는다. 외부 데이터용 파서나 광범위한 타입 변환은 추가하지 않는다.
- 계획 → 사양 → 기존 이미지 회귀 확장/기준선·대상 lint RED → 최소 구현/동일 회귀·정적 비교 → 실제 격리 피드/결과 → 별도 커밋·푸시 순서다.
- 서버 댓글 합치기/이전 댓글 커서, 본문 이미지 lifecycle, 공개 props·UI·API/DB 계약은 이번 범위가 아니다.
