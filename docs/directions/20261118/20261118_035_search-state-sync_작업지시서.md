## 목적

잔여 lint 순차 해소를 계속한다. 034 `e2b93480` 이후 113개 중 PageSearchArea의 draft prop 동기화와 제거 대기 칩 정리 effect-state 2개를 처리한다. F1-GRID 문서의 상세검색 초안/적용조건/칩/서버 빠른 날짜 계약과 기존 요청 경합 회귀를 기준으로 한다.

1. 계획·사양을 먼저 작성한다.
2. 외부 값의 첫 commit과 제거 대기 안내의 첫 commit을 재현하고, 중단된 transition render가 현재 빠른 날짜 요청을 무효화하지 않는 회귀를 추가한다.

5. 기존 경합/검색/업무 회귀, typecheck/build, lint 113→111·다른 진단 동일 및 source 일치를 확인한다.
