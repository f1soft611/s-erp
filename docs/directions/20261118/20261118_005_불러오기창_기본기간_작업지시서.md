# 20261118_005 구매자재·품질 불러오기 창 기본 조회 기간 작업지시서

## 배경
구매자재·품질의 불러오기 창 중 가입고(발주 품목), 입고(수입검사 합격분), 수입검사(가입고) 창은 날짜 조건이 있지만 비어 있고 브라우저 기본 날짜 입력을 쓴다. 먼저 만든 구매요청 선택, 구매요청확정 선택, 확정 품목 선택 창에는 날짜 조건이 없다(2026-11-18 사용자 요청: 모든 불러오기 창에 날짜 조건을 두고 기본 한 달로 채운다. 기준은 업체마다 다를 수 있다).

## 정책
- 불러오기 창 6곳(구매요청 선택, 구매요청확정 선택, 확정 품목 선택, 발주 품목 선택, 수입검사 합격분 선택, 검사 대기 가입고 선택)에 기간(시작·종료) 조건을 두고, 처음 열 때 서버 날짜 기준 종료일=오늘, 시작일=한 달 전으로 채워 조회한다.
- 조회 기준일: 구매요청=요청일, 확정=확정일, 확정 품목=확정일, 발주 품목=발주일, 수입검사 합격분=검사일, 가입고=가입고일.
- 서버 날짜를 못 가져오면 브라우저 날짜로 대체하지 않고 기간 없이 조회한다. 기간을 지우면 전체 조회, 시작일이 종료일보다 늦으면 조회하지 않고 안내한다.
- 기본 기간(1개월)은 한 곳(`PICKER_DEFAULT_RANGE_MONTHS`)에서 정의해, 업체별 정책으로 바꿀 때 한 곳만 고치게 한다.
- 날짜 입력은 공통 달력(`FormDateField`)을 쓴다.

## 범위
- 포함: 공통 훅·컴포넌트, 위 6개 창, 구매요청 후보·확정 목록 API의 기간 조건(요청일·확정일), 테스트, 문서.
- 제외: 업체별 정책 저장(기본값 상수만 분리), 창 외 다른 현황 화면, DB 변경(없음).
