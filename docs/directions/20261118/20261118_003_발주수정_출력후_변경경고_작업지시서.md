# 20261118_003 출력된 발주서 변경 시 경고 작업지시서

## 배경
발주서를 출력한 뒤 내용을 바꿔도 아무 안내가 없다. 막지는 않되 출력본과 내용이 달라진다는 경고를 띄워 달라는 요청(2026-11-18, 사용자 승인: 경고만 하고 출력 표시는 그대로 둔다).

## 정책
- 출력 표시(`print_at = 'Y'`)가 있는 발주를 수정할 때 수정 창 상단에 경고(warning)를 보이고, 저장 직전에 확인창을 띄운다. 확인하면 그대로 저장한다(차단 없음).
- 출력 표시는 바꾸지 않는다(수정해도 '출력' 상태가 유지된다).
- 입고대기마감 저장은 발주서 내용을 바꾸지 않으므로 경고·확인을 하지 않는다. 출력하지 않은 발주도 동작이 같다.

## 범위
- 포함: 발주 등록·수정 화면(발주현황 수정 창 공통)의 경고 문구와 저장 확인창, 테스트, 문서.
- 제외: 백엔드 변경 없음, 출력 상태 자동 초기화, 다른 문서(구매요청·입고 등)의 출력 경고.

## 완료 조건
- 출력된 발주를 수정하면 경고가 보이고 저장 시 확인창이 뜨며, 취소하면 저장하지 않고 확인하면 저장한다.
- 미출력 발주와 입고대기마감 저장에서는 경고와 확인창이 없다. 관련 테스트가 통과한다.
