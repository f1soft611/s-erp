# 20261118_006 구매자재·품질 수량·단가 소수점 정책 적용 작업지시서

## 배경
소수점 자릿수는 정책 관리(`GRID_DECIMAL_{모듈코드}`)에서 모듈별로 관리하도록 되어 있고, 구매자재(MATERIALS)·품질(QUALITY)은 2자리·항상 표시·반올림으로 등록되어 있다. F1Grid는 `decimalPlaces`가 없는 수량·단가 컬럼에 정책을 자동으로 채운다(우선순위: 컬럼 `decimal` 객체 > 컬럼 개별 옵션 > 정책 > 그리드 기본). 그런데 구매자재·품질 컬럼 정의에는 `decimalPlaces: 2`가 직접 박혀 있어 정책을 바꿔도 반영되지 않았다(2026-11-18 사용자 요청: 정책 등록 후 한꺼번에 정리, 금액은 유지).

## 정책 (사용자 승인)
- 수량·단가 컬럼에서 고정 `decimalPlaces`를 제거해 정책 관리의 모듈 정책이 적용되게 한다.
- 금액(공급가·세액·합계·금액)은 컬럼에서 2자리로 계속 고정한다(정책 설명 범위가 수량·단가).
- 건수(`decimal: { places: 0 }`)와 비율(`passRate` 1자리)처럼 의도적으로 고정한 컬럼은 그대로 둔다.

## 범위
- 포함: `pages/materials`, `pages/quality`의 등록·현황·불러오기·입고마감 컬럼 정의(수량·단가).
- 제외: 영업·기타 모듈, 정책 관리 화면, 금액 컬럼, 백엔드·DB 변경(없음).

## 완료 조건
- 수량·단가 컬럼에 고정 자릿수가 없고, 정책 값(현재 2자리 항상 표시)대로 표시된다. 금액·건수·비율은 기존과 같다. 관련 테스트가 통과한다.
