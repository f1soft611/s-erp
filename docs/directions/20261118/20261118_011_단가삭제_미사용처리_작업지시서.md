# 20261118_011 단가 삭제·미사용 처리 작업지시서

## 배경
단가등록(20261118_007~009)은 물리 삭제를 허용하지 않고 사용여부로만 비활성화하도록 만들었는데, 품목 기준 탭에는 사용여부 컨트롤이 없어 기본단가(거래처 비움)는 어느 화면에서도 비활성화할 수 없고, 잘못 등록한 단가를 정정·삭제하는 경로가 불완전하다(2026-11-18 사용자 지적). 사용자 결정: **B안 — 미사용 처리 + 오등록 정정용 물리 삭제**.

## 정책 (사용자 승인)
- **정정**(값 오입력): 같은 적용일로 값을 수정한다. 이력은 새로 생기지 않는다(기존 규칙).
- **미사용 처리**: 더 이상 쓰지 않는 단가를 `use_at = 'N'`으로 둔다. 기록은 남는다.
- **삭제**(오등록 정정용): 적용 중·예정 단가만 물리 삭제할 수 있다. 종료된 과거 단가는 삭제·수정 모두 불가.
  - 삭제한 행 때문에 자동 종료됐던 직전 단가는 구간을 이어받도록 종료일을 다시 연다(직전 행의 종료일을 삭제 행의 종료일로 되돌린다).
- 적용 중인 단가를 잘못 등록한 경우(거래처 오류 등)는 삭제 후 올바르게 재등록한다. 예정 단가의 거래처·품목 변경도 삭제 후 재등록으로 안내한다(서버는 예정 행의 키 수정을 계속 허용).
- 구매확정·발주는 단가를 복사해 저장하고 단가 행을 참조하지 않으므로, 단가를 지워도 이미 만든 문서는 바뀌지 않는다.
- 권한: 삭제·미사용 처리는 단가 저장과 같은 권한(테넌트 관리자 + 수정 권한, 삭제는 삭제 권한)이 있을 때만 화면에 보인다.

## 범위
- 포함: 서버 삭제 규칙·API(기존 `save-batch`의 삭제 행 지원), 품목 기준 탭의 "단가 삭제" 동작(삭제/미사용 선택, 매입·매출 선택), 거래처 기준 탭의 행 삭제와 사용여부 미사용, 테스트와 실서버·브라우저 확인.
- 제외: 정정 이력 감사 로그(누가·언제·무엇을 바꿨는지), 과거 이력 수정·삭제, 영업 파일.

## 완료 조건
- 품목 기준 탭에서 기본단가·특별단가를 선택해 삭제 또는 미사용 처리할 수 있고, 과거 단가는 막힌다.
- 거래처 기준 탭에서 행을 삭제하거나 사용여부를 미사용으로 바꿀 수 있다.
- 삭제 시 직전 단가의 종료일이 다시 열린다.
- 관련 테스트 통과, 결과 문서와 스크린샷.
