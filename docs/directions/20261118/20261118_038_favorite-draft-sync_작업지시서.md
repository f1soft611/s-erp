# 즐겨찾기 편집 초안 동기화 작업지시서

- 근거: 저장소 잔여 lint 순차 처리 요청과 [기존 즐겨찾기 사양](../../spec/20261102/20261102_002_메뉴_즐겨찾기_상세사양서.md).
- 범위: `MenuFavoriteEditDialog`의 동기식 prop 복사 effect 한 개만 정리한다. 다른 대시보드 훅이나 파일 편집창은 포함하지 않는다.
- 이름/폴더/오류는 기존 다섯 dependency가 변경되고 열려 있을 때만 초기화한다. 첫 열린 mount도 저장된 표시명/폴더부터 commit한다.
- 기존 CommonDialog, JSX, trim/검증, 읽기 전용 URL, 더보기/완료/제거, 중복 요청 방지와 비동기 오류 동작을 유지한다.
- 순서: 계획 → 상세 사양 → 실패 회귀 → 최소 구현 → 관련 테스트/정적 검사 → 실제 3폭/이벤트 → 결과/이미지 → 별도 커밋·비강제 푸시.
- API/서비스/타입/권한/DB/의존성은 변경하지 않는다. lint 우회나 불필요한 remount를 사용하지 않는다.
