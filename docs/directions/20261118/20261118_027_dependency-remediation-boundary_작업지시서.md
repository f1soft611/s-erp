# 잔여 의존성 실제 수정 경로 확인 작업지시서

- 사용자 “나머지도 해결해줘” 요청에 따라 기존 권고 두 건의 실제 적용 가능한 수정 경로를 재확인한다.
- registry latest만 반복하지 않고 공식 prerelease, 권고가 참조하는 upstream PR, 실제 브라우저 진입점을 확인한다.
- 의존 버전 숫자만 바꿔 audit 경고를 숨기지 않는다. 특히 미리 빌드된 vendor bundle까지 같은 수정이 반영되는지 구별한다.
- 기존 화면·Excel 입출력과 도구 계약을 보존할 근거가 없는 미병합 PR/fork/major override를 임의 적용하지 않는다.
- 이 단위는 지시서 → 계획 027 → 사양 027 → 근거에 따른 적용 가능/차단 판정 → 결과 기록 순서다. frontend export 정리 026의 소스 소유 범위는 건드리지 않는다.
