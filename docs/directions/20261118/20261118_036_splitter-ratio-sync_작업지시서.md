# Splitter 비율 상태 동기화 작업지시

## 근거와 범위

잔여 lint를 기존 화면 기능을 보존하며 순차 해결한다는 사용자 지시를 따른다. [기존 분리기 지시](../20260911/20260911_005_공통코드_관리_트리그리드_분리기_작업지시서.md)와 [공통 사양](../../spec/20260911/20260911_006_공통_스플리터_컴포넌트_사양서.md)의 드래그·최소/최대·반응형 계약을 유지한다.

Splitter의 leftFlex/rightFlex prop 복사 effect 1개만 제거한다. 비율은 드래그가 수정하는 local state이므로 단순 prop 파생값으로 대체하지 않는다. 같은 prop 재렌더는 드래그 결과를 유지하며 어느 한 flex prop이 변경되면 두 prop 중 숫자로 전달된 쪽을 모두 기존처럼 동기화한다.

JSX·스타일·props·픽셀 크기·드래그 계산·리스너·모바일 판정·저장 콜백을 변경하지 않는다. F1Grid/F1Tree 자체 기능, 업무 화면, 서비스/API/DB는 대상이 아니다.

## 완료 기준

계획→사양→첫 commit RED→최소 구현→관련 회귀/typecheck/build/lint→실제 375/768/1280px→결과/별도 커밋·푸시 순서를 지킨다. React effect dependency의 Object.is 비교, 특히 NaN 반복과 0/-0 변경을 보존한다. 정상 숫자 prop 변경 및 0/-0 변경의 첫 commit 회귀가 수정 전 실패해야 한다. 최종 lint는 111→110, 다른 진단은 동일해야 한다.
