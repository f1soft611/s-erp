# 영업 현황 목록 요청 시작 작업지시서

- 잔여 lint 순차 해결 요청의 다음 단위다. [수주 상세/목록 원 사양](../../spec/20261027/20261027_010_수주현황_상세패널_및_상태저장_상세사양서.md)의 조용한 갱신과 [견적 정합성 지시서](../20261117/20261117_007_견적현황_UI정합성_작업지시서.md)의 기존 조회 흐름을 보존한다.
- 수주/견적 현황 목록 훅의 동일 요청 시작 패턴만 수정한다. filters/retryRequest 변경 첫 commit부터 기존 로딩·결과 알림·오류 초기화·initialLoad 시작 상태를 일치시킨다.
- quiet 갱신은 기존 목록/그리드 로딩을 유지하며, 다음 조건 변경은 일반 로딩이다. filters=null이면 요청하지 않고, 이때 쌓인 quiet token의 기존 처리도 보존한다.
- ref를 render로 옮기지 않는다. quiet 판정용 마지막 실제 시작 version을 local state로 관리하고 API/서비스/화면·권한·검색·세션·응답 취소는 변경하지 않는다.
- 계획/사양 → 실제 훅 commit RED → 최소 구현 → 관련 회귀/정적/3폭 native → 결과/스크린샷 → 정확한 066 CI 성공 후 별도 커밋/푸시 순서다.
