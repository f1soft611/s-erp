# 20261118_002 발주 수정 시 가입고 행 잠금 작업지시서

## 배경
- 발주를 수정할 때 가입고가 진행된 행도 수량·단가·납기·창고가 그대로 바뀌어 저장됐다(수량을 가입고량 아래로 줄이는 것만 막았다). 뒷단계(가입고)가 진행 중이면 앞단계(발주) 수정을 막아야 한다는 요청(2026-11-18).
- 점검: 구매요청(확정되면 수정·삭제 불가), 구매확정(발주되면 취소 불가), 가입고(입고·검사 행 잠금), 수입검사(입고된 합격분 제한), 입고(매입마감 행 수정·취소 불가)는 이미 적용되어 있고 발주만 빠져 있었다.

## 정책 (사용자 승인: 가입고 선례를 따르는 행 단위 잠금)
- 가입고가 있는 행: 수량·단가·납기·창고·검사대상·세액(금액)을 바꿀 수 없고 삭제할 수 없다. 행 비고는 수정 가능.
- 가입고가 하나라도 있으면 헤더의 발주일·부가세구분·부가세 포함 여부를 바꿀 수 없다(잠긴 행 금액에 영향). 비고는 수정 가능.
- 가입고가 없는 행은 지금처럼 수정·삭제할 수 있다. 입고대기마감은 별도 기능이라 그대로 가능하다. 발주 취소 불가 규칙(가입고가 있으면 취소 불가)도 그대로다.
- 가입고수량은 유효 가입고 합계에서 유효 수입검사 불합격 수량 합계를 뺀 값(가입고 대상 조회와 같은 정의)이다. 가입고를 취소하면 수량이 0이 되어 잠금이 풀린다.

## 범위
- 포함: 발주 수정 API 검증(409), 발주 상세 응답에 행별 `arrivedQty` 추가, 발주 등록·수정 화면의 행·헤더 잠금과 안내, 테스트, 문서.
- 제외: DB 변경(없음), 입고대기마감 변경, 다른 단계 규칙 변경, 출력 경고(별도 작업 003), 메시지 정리(별도 작업 004).

## 완료 조건
- 가입고가 있는 행을 바꾸거나 빼는 저장은 서버가 409로 거부하고, 화면은 해당 행·헤더를 수정하지 못하게 하며 이유를 안내한다.
- 가입고가 없는 발주·행은 기존대로 수정된다. 관련 테스트와 전체 백엔드 테스트가 통과한다.
