# 20261118_001 발주현황 가입고수량·입고잔량 컬럼 및 입고대기마감 검색 작업지시서

## 배경
- 입고대기마감(발주 상세 행의 `receipt_close_at`)은 이미 구현되어 있다. 마감하면 가입고 대상 조회와 가입고 저장에서 제외된다(`MaterialArrivalCreate` mapper `receipt_close_at = 'N'`, `MaterialArrivalServiceImpl` 검증).
- 그러나 발주현황에서 "가입고가 얼마나 됐고 입고 잔량이 얼마인지"를 볼 수 없고, 마감 여부로 조회할 수도 없어서 마감 대상을 고르기 어렵다(2026-11-18 사용자 요청).
- 한 번에 여러 건을 처리하는 일괄 마감은 이번 범위가 아니다. 개선 요청이 오면 별도 작업으로 설계한다(사용자 결정).

## 작업 목표
1. 발주현황 그리드에 `가입고수량`, `입고잔량` 컬럼을 추가한다.
2. 발주현황 상세검색에 `입고대기마감`(전체/미마감/마감) 조건을 추가한다.

## 기준
- 기준 화면: 발주현황(현재), 가입고 대상 조회(수량 계산 기준 `arrivedQtySubquery`).
- 가입고수량 = 유효한 가입고 합계 − 유효한 수입검사 불합격 수량 합계(가입고 대상 조회의 `arrived_qty`와 같은 값). 불합격 수량은 다시 가입고할 수 있으므로 뺀다.
- 입고잔량 = 발주수량 − 가입고수량, 0 미만이면 0.

## 범위
- 포함: 발주현황 mapper·VO·검색 VO·서비스, 프론트 발주현황 컬럼·검색·타입, 테스트, 문서.
- 제외: 일괄 마감, 마감 저장 로직 변경, 가입고·입고 화면, DB 스키마 변경(없음), 공용 검색 영역 컴포넌트(별도 작업).

## 완료 조건
- 발주현황에 두 컬럼이 표시되고 값이 가입고 대상 조회와 일치한다.
- `입고대기마감` 조건으로 미마감/마감 행만 조회된다. 비우면 전체.
- 기존 상태 3종·검색·상세·마감 동작이 바뀌지 않고 관련 테스트가 통과한다. 결과 문서와 스크린샷을 남긴다.
