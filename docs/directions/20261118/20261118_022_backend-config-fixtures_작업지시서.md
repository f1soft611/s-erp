# 백엔드 비공개 설정 의존 테스트 분리 작업지시서

- 사용자 후속 요청: 프론트 전체 CI 완료 뒤 남은 항목을 순차 진행한다.
- 먼저 기존 backend 오류 두 개를 정리하고, 그다음 잔여 npm advisory를 재평가한다.
- MinioStorageConfigTest와 SecurityConfigTest가 ignored 배포 profile을 직접 읽는 의존을 제거한다. 비공개 설정·실제 자격 증명은 열람·복사·생성·출력하지 않는다.
- 운영 설정·기본값·보안 정책·API·DB를 바꾸지 않는다. 테스트 제외·예외 무시·실패 단언 삭제로 통과시키지 않는다.
- 순서는 이 작업지시서 → 계획 022 → 상세사양 022 → 기존 오류 재현 → 최소 수정 → 전체 backend 검증 → 결과·작업별 커밋/push다.
- 실제 배포 profile의 값 일치 여부는 저장소 단위 테스트에서 확인할 수 없는 배포 검증으로 명시한다.
- 결과는 기존 repository-remediation 결과 폴더에 보관한다. UI 변경이 없어 신규 스크린샷 대상이 아니다.
