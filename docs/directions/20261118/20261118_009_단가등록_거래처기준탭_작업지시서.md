# 20261118_009 단가등록 거래처 기준 탭 작업지시서

## 배경
단가등록의 "품목 기준" 탭(20261118_008)은 품목을 기준으로 기본단가와 특별단가를 입력한다. 영업·구매 담당은 "이 거래처에 어떤 품목의 단가가 정해져 있나"를 거래처 기준으로 조회하고 입력하는 경우도 많고, MES에서도 거래처 기준 화면(판매단가 거래처별)이 따로 있었다(2026-11-18 사용자 요청: 거래처 기준 조회·입력을 함께 제공). 또한 이력 조회 탭이 조회 전용이 되면서 사라진 **거래처가 지정된 특별단가의 엑셀 일괄 등록**도 이 탭에서 다시 제공한다.

## 정책 (사용자 승인)
- 탭 추가: **품목 기준** · **거래처 기준**(이번 작업) · **단가 이력 조회**(조회 전용).
- 거래처 기준 탭은 **좌측 거래처 목록 + 우측 선택 거래처의 특별단가(품목별)** 구조다. 같은 테이블(`tb_item_partner_price`)을 보므로 한쪽에서 입력하면 다른 쪽에도 바로 반영된다. DB 변경은 없다.
- 거래처 목록에는 거래처별 **등록 건수**(적용 중·예정 단가가 있는 품목·구분 수)를 보여 주고 "단가 등록 여부(전체/등록/미등록)"로 거를 수 있다.
- 우측은 선택 거래처의 단가를 **한 행 = 품목 + 거래구분(매입/매출)** 으로 편집한다. 입력·정정·새 기간 규칙(적용일 기본값 오늘, 값만 바꾸면 정정, 더 늦은 적용일이면 새 기간, 과거 단가 수정 불가, 겹침 방지, 직전 단가 자동 종료)은 007·008과 같다. 입력은 셀 직접 입력과 맨 오른쪽 "상세" 아이콘의 행 폼을 모두 지원한다.
- 엑셀 일괄 등록: 거래처코드를 포함한 007의 양식(거래구분·품목코드·거래처코드·원화단가·부가세구분·부가세포함·외화단가·통화·적용시작일·적용종료일·최소주문수량·사용여부)을 이 탭에서 제공한다. 신규 단가만 추가하고(기존 키는 오류) 검증을 통과해야 전체가 반영되며, 반영 시 확인 후 바로 저장한다.
- 입력·저장·엑셀은 테넌트 관리자 + 생성/수정 권한이 있을 때만, 조회는 조회 권한으로 한다(007·008과 동일).

## 범위
- 포함: 거래처 목록 조회 API, 거래처별 단가 조회(기존 목록 API에 거래처 조건 추가), 거래처 기준 탭 화면(마스터-디테일), 저장(기존 `save-batch` 재사용), 엑셀 일괄 등록 연결.
- 제외: 단가 노출 권한 분리, 환율 연동, 영업 파일, 기준정보 모듈 소수점 정책 연결(후속).

## 완료 조건
- 거래처를 선택하면 그 거래처의 특별단가(품목·구분별)가 보이고 셀·상세 폼으로 추가·정정·새 기간 등록이 된다.
- 거래처 목록의 등록 건수와 등록 여부 필터가 동작한다.
- 엑셀 양식 다운로드→작성→업로드→검증→반영이 동작한다.
- 관련 테스트 통과, 결과 문서와 스크린샷 작성.
