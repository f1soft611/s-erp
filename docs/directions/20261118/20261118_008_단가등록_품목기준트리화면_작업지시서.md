# 20261118_008 단가등록 품목 기준 트리 화면 작업지시서

## 배경
단가등록(`co/master/item-partner-prices`)은 행을 추가해 품목을 고르고 입력하는 방식(20261118_007)이라 품목이 많으면 입력이 불편하고, 단가가 없는 품목을 화면에서 알 수 없다. 타 시스템의 품목별 단가 화면처럼 품목을 모두 펼쳐 놓고 단가를 바로 입력하는 방식을 도입하되, 특별 거래처 단가는 품목 아래 하위 행으로 표현한다(2026-11-18 사용자 결정).

## 정책 (사용자 승인)
- **품목 기준 화면**: 품목 마스터의 품목을 모두 목록으로 보여 주고, 부모 행 = 품목 + 기본단가(거래처 비움), 자식 행 = 그 품목의 거래처 특별단가. 기본단가가 없는 품목에도 특별단가를 달 수 있다.
- 한 행에 매입·매출 단가를 나란히 둔다. 단가가 바뀌면 적용일(기본 오늘, 수정 가능)로 저장하며, 기존 007 규칙(기간 겹침 거부, 직전 단가 자동 종료, 과거 단가 수정 차단)을 따른다.
- 자식 행은 기본 접힘이며 부모 행에 "특별 N건"을 표시한다.
- 화면은 탭으로 구성한다: **품목 기준**(이번 작업) · **단가 목록**(007에서 만든 평면 그리드, 이력·엑셀) · **거래처 기준**(별도 작업 009).
- 기본단가 엑셀은 현재 단가가 채워진 전체 품목 양식을 내려받아 올리는 방식으로 한다(품목코드 키). 특별단가 엑셀은 007의 "단가 목록" 탭을 그대로 쓴다.
- 부가세구분·부가세포함·외화단가·통화는 007 규칙과 같다.

## 범위
- 포함: 조회 API(품목+기본단가+특별단가), 품목 기준 트리 화면, 저장(기존 `save-batch` 재사용), 기본단가 엑셀 양식·업로드, 탭 구성.
- 제외: 거래처 기준 탭(009), 단가 노출 권한 분리, 환율 연동, 영업 파일.

## 완료 조건
- 품목이 모두 나열되고 매입·매출 기본단가를 셀에서 바로 입력·저장할 수 있다. 특별단가를 품목 아래에서 추가·수정할 수 있다.
- 단가 변경은 적용일 규칙대로 저장되고 과거 단가는 수정되지 않는다.
- 기본단가 엑셀 양식(현재 단가 포함) 다운로드→수정→업로드가 동작한다.
- 관련 테스트 통과, 결과 문서와 스크린샷 작성.
