# 문서 상세 액션 후 댓글 즉시 갱신 작업지시서

## 목적

문서 상세에서 결재, 반려, 보완요청, 결재신청 취소 또는 승인 취소를 수행한
뒤 액션으로 기록된 시스템 메시지가 댓글 영역에 즉시 나타나도록 한다.

## 승인 요구사항

- 각 액션 성공 시 상세를 닫지 않고 열린 상태로 유지한다.
- 성공 후 기존 통합 댓글 API에서 최신 댓글 페이지를 다시 조회한다. 댓글과
  시스템 메시지, 전체 건수 및 이전 페이지 정보는 서버 응답으로 갱신한다.
- 이전 페이지를 펼쳐 둔 상태에서 액션을 실행해도 최신 페이지로 이동해 새
  시스템 메시지를 보여 준다.
- 액션 성공 후 문서 상세 데이터와 상위 목록도 갱신한다.
- 댓글 재조회 실패는 액션 성공을 실패로 바꾸지 않는다. 기존 댓글 오류/재시도
  표시를 사용한다.
- 액션 실패 시 기존 오류 동작을 유지하고 댓글 성공 갱신을 수행하지 않는다.

## 작업 절차

1. 승인된 설계에 따라 날짜별 계획서와 상세 사양서를 작성한다.
2. 문서작성 상세와 통합 댓글 페이지의 기존 구현 및 테스트 패턴을 유지한다.
3. 액션 성공 뒤 댓글 재조회 및 상세 유지에 대한 실패 회귀 테스트를 추가한다.
4. 결재 계열 성공 시 상세를 닫지 않고, 상세 데이터 및 최신 통합 댓글 페이지를
   갱신한다.
5. 상신 취소와 승인 취소 성공 시에도 상세 데이터와 최신 통합 댓글 페이지를
   갱신한다.
6. 액션 실패 및 댓글 조회 실패의 오류 표시와 재시도 동작을 검증한다.
7. 관련 Vitest, 프론트엔드 production build, 375px/768px/1280px 실제 브라우저
   동작을 확인한다.
8. 결과 문서와 개인정보 없는 스크린샷을 `docs/result/20261016/document-approval-comment-refresh/`에 기록한다.

## 완료 기준

- 모든 문서 상세 액션 성공 직후 서버가 기록한 시스템 메시지가 댓글에 표시된다.
- 결재 계열 액션 성공 후 상세가 계속 열려 있고 바뀐 문서 상태를 반영한다.
- 최신 페이지 재조회 후 댓글 목록, 시스템 메시지, 총 건수, 이전 페이지 상태가
  함께 갱신된다.
- 댓글 재조회 실패 시 댓글 오류/재시도가 나타나며 액션 성공 알림은 유지된다.
- 액션 실패 시 기존 오류 표시가 유지되며 목록/댓글을 성공 데이터로 덮지 않는다.
- 관련 테스트와 빌드가 통과하고 세 가지 뷰포트의 결과 문서/스크린샷이 있다.

## 범위 제외

- 백엔드/API/DB 스키마 및 결재 상태 전이 변경
- 공지사항 댓글 동작 변경
- 액션 권한, 확인 대화상자, 메시지 문구 변경
- 댓글 페이지 크기, 정렬, 권한 및 저장 동작 변경
