# 20261016_016 커뮤니티 자료실 F1-Grid 및 상세 패널 개선 작업지시서

## 목적

`/groupware/community/archive` 페이지를 기안양식관리의 검색/그리드 패턴과 공지·업무 상세 피드 UI에 맞춘다. 공지사항 페이지는 변경하지 않는다.

## 승인된 요구사항

1. 페이지 구조를 `PageHeader → PageSearchArea → PageMessageArea → F1-Grid`로 정리한다.
2. 검색은 통합검색 한 개만 기본 영역에 둔다. 기존 제목·본문·작성자 통합 검색 동작은 유지한다.
3. 현재 API가 지원하는 분류 조건만 F1-Grid 컬럼 메타데이터 기반 상세검색에 제공한다. 작성자/날짜 별도 검색을 위한 API 확장은 하지 않는다.
4. 현재 HTML 표와 별도 페이지네이션을 F1-Grid로 교체하고, 기존 서버 조회/최신순/총건수/로딩/오류 동작을 유지한다. 분류 또는 통합검색 조건 변경 시 조회를 처음부터 다시 시작한다.
5. 제목을 선택하면 목록을 배경에 유지하고 전체 높이 우측 상세 오버레이를 연다.
6. 상세 UI는 상단 정보/액션 → 제목 및 일반 텍스트 본문 → 첨부파일 목록 순서로 구성한다. 상단에 작성자/일자 정보, 분류 칩, 더보기 메뉴를 표시하며 더보기 메뉴로 권한이 허용된 수정·삭제를 제공한다.
7. 본문은 HTML 에디터를 사용하지 않고 줄바꿈을 보존하는 일반 텍스트로 표시한다. 첨부파일은 공통 `AttachmentList` 보기 형식과 개별 다운로드 동작을 사용한다.
8. 기존 작성/수정 다이얼로그, API 계약, 첨부파일 소유권, 테넌트 격리, 서버 권한 검증 및 삭제 확인 흐름을 유지한다.

## 구현 기준

- 설계: [자료실 F1-Grid 및 상세 패턴 설계](../../superpowers/specs/2026-10-16-community-archive-f1-grid-detail-redesign-design.md)
- 패턴 참조: `DraftFormManagementPage`, `PageSearchArea`, `F1Grid` dataSource, `PostDetailPanel`, `PageAreaOverlay`, `FeedCard`, `AttachmentList`
- 문서 결재 전용 상세 컴포넌트는 직접 재사용하지 않는다.
- 변경 영역은 프론트엔드 자료실 페이지, 관련 그리드/상세 컴포넌트와 테스트 및 날짜별 문서로 제한한다.
- 백엔드, 데이터베이스, API, 공지사항 화면, 공통 F1-Grid 구현은 변경하지 않는다.

## 검증 및 완료 기준

- 관련 프론트엔드 테스트에서 검색/상세검색, F1-Grid 목록 및 서버 페이지 요청, 제목 선택, 권한별 더보기, 일반 텍스트 본문, 첨부 목록과 다운로드를 검증한다.
- 프론트엔드 빌드와 `git diff --check`가 통과한다.
- 브라우저에서 375px, 768px, 1280px 화면의 그리드 넘침, 오버레이 크기/스크롤, 첨부 행 가독성을 확인한다.
- 결과와 캡처를 `docs/result/20261016/community-archive-grid-detail/`에 기록한다.
- 기존 자료 등록/수정/삭제/업로드 및 API 계약이 유지된다.
