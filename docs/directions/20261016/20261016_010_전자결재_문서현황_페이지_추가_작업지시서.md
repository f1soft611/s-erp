# 20261016_010 전자결재 문서현황 페이지 추가 작업지시서

## 목적

`/groupware/doc/read`에 과거 전자결재 문서를 검색하고 확인할 수 있는 문서현황 페이지를 추가한다. 기안양식관리와 같은 `PageHeader → PageSearchArea → F1-Grid` 구성을 사용하고, F1-Grid 컬럼의 검색 메타데이터를 상세검색 항목과 연결한다.

## 승인된 요구사항

- 화면은 기존 기안양식관리와 같은 검색영역 및 F1-Grid 중심의 단일 페이지로 구성한다. 상태 요약 카드와 상태별 좌측 메뉴는 추가하지 않는다.
- 기본 조회 범위는 인증 사용자가 기안했거나 결재선에 참여한 문서이며, 기존 tenant 및 권한 범위를 유지한다.
- 최초 조회는 결재신청일(`submittedAt`) 기준 최근 1개월이며, 사용자가 기간을 변경하여 과거문서를 검색할 수 있어야 한다.
- 기본 상태 조건은 전체 상태이며, 상세검색에서 문서종류와 결재상태를 좁힐 수 있어야 한다.
- 기본 컬럼: 행번호, 문서번호, 제목, 문서종류, 결재상태, 결재신청일, 기안자, 기안부서, 결재 참여자, 결재 진행, 최종 변경일.
- 기본 빠른검색은 문서번호, 제목, 기안자를 대상으로 한다. 상세검색은 컬럼의 `search` 메타데이터로 생성한다.
- 행 선택 시 문서현황 화면 안에서 읽기 전용 상세 패널을 연다. 문서작성/수정 및 결재 처리 동작은 제공하지 않는다.
- 본문에 표시되는 기안일은 이번 목록 컬럼 및 검색조건에서 제외한다. 목록 기본 날짜 기준은 결재신청일이다.
- API는 상세검색 조건과 서버 조회용 정렬/범위 정보를 받아 서버에서 필터링한다. 전체 문서 본문을 브라우저로 내려 클라이언트에서만 검색하지 않는다.

## 구현 범위

1. `/groupware/doc/read`가 사용하는 `documents` 메뉴 페이지를 기존 일반 문서 요약 화면에서 문서현황 F1-Grid 페이지로 연결한다.
2. F1-Grid 컬럼과 `PageSearchArea` 검색 필드를 정의하고, `submittedAt` 기본 기간 및 사용자가 바꾼 조건을 목록 조회에 적용한다.
3. 전자결재 문서목록 API에 빠른검색, 상세검색, 서버 정렬 및 F1-Grid 데이터 조회에 필요한 전체 건수 계약을 추가한다.
4. 기존 문서/참여자 조회의 tenant 및 사용자 식별 조건을 유지하고, 문서 상세는 기존 상세 조회 계약과 읽기 전용 UI로 제공한다.
5. F1-Grid 문서, 테스트, 브라우저 확인 및 결과 문서를 갱신한다.

## DB 및 계약 확인

2026-10-16 읽기 전용 `s-erp-postgresql-readonly` MCP에서 `tb_electronic_approval_main`과 `tb_electronic_approval_line_info`의 컬럼 메타데이터를 확인했다. 목록에 필요한 `submitted_at`, `drafter_department_name`, 결재 참여자/상태/단계 정보가 기존 테이블에 있다. 새 DB 컬럼이나 테이블은 계획하지 않는다. 문서 행 데이터는 조회하거나 결과 문서에 기록하지 않았다.

현행 `/api/v1/groupware/approvals/documents`는 상세검색/페이지 조회 조건이 없으므로, 구현 전에 Mapper 및 서비스 계약과 위 MCP 메타데이터를 다시 확인한다. 기존 컬럼만으로 목록 응답을 만들 수 없는 변경이 확인되면 임의로 진행하지 말고 별도 DB 변경 스크립트 절차를 추가한다.

## 제외 범위

- F1-Grid 코어의 검색/컬럼 기능 변경
- 본문 기안일 추출·저장·검색
- 문서 생성, 편집, 삭제, 상신 및 결재 처리
- 요약 카드, 피드 보기 또는 별도 상태 탐색 메뉴
- DB 스키마 변경

## 완료 기준

- `/groupware/doc/read`에서 승인된 문서현황 화면이 표시되고, 기본 조회는 최근 1개월의 결재신청일 및 현재 사용자의 관련 문서 범위를 따른다.
- 컬럼별 상세검색이 F1-Grid 검색 메타데이터에서 생성되고 서버 목록 조회 결과에 반영된다.
- 정렬/조회 범위, 빈 결과, 로딩, 오류 및 재시도 상태가 명시적으로 동작한다.
- 선택한 행의 상세 내용을 읽기 전용으로 볼 수 있고 타 사용자의 문서나 다른 tenant 문서가 노출되지 않는다.
- 프런트엔드/백엔드 관련 테스트, 프런트엔드 빌드 및 375px·768px·1280px 실제 브라우저 검증을 완료한다.
- F1-Grid 문서와 `docs/result/20261016/document-status-page/` 결과 보고서 및 스크린샷을 갱신한다.
