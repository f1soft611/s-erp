# 문서현황 상세검색 그룹 행 배치 작업지시서

## 목적

문서현황 상세검색의 `search.group` 메타데이터를 실제 행 배치에 반영하고, 결재신청일 범위 위에 반복 표시되는 제목을 제거한다.

## 승인된 요구사항

- 사용자가 선택한 A안대로 `search.group`을 상세검색 행 구분으로 사용한다.
- 그룹이 같은 필드는 한 행에 놓고, 다음 그룹은 새 행에서 시작한다. 그룹 이름은 화면 제목으로 표시하지 않는다.
- `search.span` 기능은 제거하지 않는다. 그룹은 행 경계를 정하고 span은 각 그룹 행 안에서 필드 너비를 정하며, 생략 시 기본 span 1을 사용한다.
- 문서현황 상세검색은 다음 순서의 4행으로 구성한다.
  1. 결재신청일 시작일, 결재신청일 종료일
  2. 결재상태, 문서종류
  3. 제목
  4. 기안자, 기안부서, 결재 참여자
- 문서현황의 기존 span 너비 설정을 유지한다. 그룹이 있는 필드와 없는 필드 모두 `search.span`으로 너비를 지정할 수 있어야 한다.
- 결재신청일 범위 위의 별도 제목만 제거한다. 입력에 표시되는 시작일/종료일 라벨과 접근성 이름은 유지한다.
- 좁은 화면은 그룹 내부 필드를 반응형으로 접어 페이지 가로 넘침을 만들지 않는다.
- 검색 필드 값, 날짜 `{ from, to }`, 필터/API 계약 및 검색 동작은 변경하지 않는다.
- F1-Grid 관련 동작 문서와 날짜별 계획/사양/결과 문서를 함께 갱신한다.

## 구현 범위

- 공통 `PageSearchArea`에서 연속된 같은 group의 필드를 새로운 행으로 묶고, 모든 행에서 span 너비 설정을 유지한다.
- 그룹 행 내부는 기존 반응형 5열 grid를 사용한다. 그룹이 없는 필드도 기존 바깥 grid에서 `searchSpan`을 사용한다.
- 문서현황 Grid 컬럼 메타데이터에 4개 행 그룹을 지정하고 기존 span 값(4, 2, 2, 4)을 보존한다.
- 그룹 행 구성, grouped/ungrouped span, 날짜 제목 제거 및 접근성 입력 라벨에 대한 회귀 테스트를 추가한다.
- F1-Grid 문서와 날짜별 상세 사양/계획/결과를 갱신한다.

## 완료 기준

- 데스크톱 상세검색이 승인된 4행과 필드 순서로 표시된다.
- 375px, 768px, 1280px에서 그룹 내부 요소와 페이지 레이아웃이 잘리거나 가로 넘치지 않는다.
- 날짜 범위 위의 별도 제목은 보이지 않으며 시작일/종료일 라벨로 두 입력을 식별할 수 있다.
- 검색 조건 적용, 초기화, API 쿼리 파라미터가 기존 동작을 유지한다.
- 관련 테스트와 프런트엔드 빌드가 통과하고 결과 문서가 기록된다.
