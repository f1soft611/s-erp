# 작업지시서

## 제목

업무작성 자주 쓰는 결재선 선택 상자와 설정 버튼 수직 정렬 수정

## 목적

결재선 설정 창에서 `자주 쓰는 결재선` 선택 상자와 `설정` 버튼의 세로 위치를 중앙 정렬해 사용자가 첨부 화면에서 확인한 어긋남을 해소한다.

## 승인된 요구사항

- 선택 상자와 `설정` 버튼의 세로 중심을 맞춘다.
- 두 컨트롤의 너비, 높이, 간격, 동작, 로딩 및 오류 처리는 변경하지 않는다.
- 공통 다이얼로그/F1-Grid 및 다른 화면의 스타일은 변경하지 않는다.

## 작업 및 완료 기준

1. 기존 선택 모달 사양과 컴포넌트 행 스타일을 확인한다.
2. 설정 창 테스트에 선택 상자/설정 버튼 행의 중앙 정렬 검증을 추가하고 실패를 확인한다.
3. 해당 행의 정렬만 중앙 정렬로 변경한다.
4. 관련 테스트와 프론트엔드 빌드를 실행하고 diff를 확인한다.
5. 가능한 경우 브라우저에서 화면을 검증하고, 인증 화면 접근이 불가능하면 결과 문서에 한계를 명시한다.
