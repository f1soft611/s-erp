# 작업지시서

## 제목

전자결재 참여자 문서목록 조회 누락 수정

## 목적

결재자로 로그인한 사용자의 관련 문서가 문서작성 화면에 표시되지 않고 결재 요약의 처리 대기 건수도 0으로 조회될 수 있는 원인을 수정한다.

## 승인 요구사항

- 문서 목록과 요약 조회에 인증 사용자의 결재선 식별값(`LoginVO.uniqId`)을 전달한다.
- 기존 기안자 식별(`LoginVO.id`), tenant 범위 및 권한 검증을 유지한다.
- 기본 `ALL` 목록은 현재 사용자가 기안자 또는 결재선 참여자인 관련 문서를 표시한다.
- `MY_PENDING` 및 처리 대기 요약은 현재 사용자의 `PENDING` 결재선을 기준으로 계산한다.
- API 응답 계약, DB 스키마, 프런트엔드 표시 구조는 변경하지 않는다.

## 작업 및 완료 기준

1. 관련 작업지시서·계획서·상세 사양서를 확인하고 결함 재현 조건을 고정한다.
2. 서비스 단위 테스트를 먼저 추가해 목록/요약 DAO에 `participantUserId`가 전달되지 않는 현재 동작을 확인한다.
3. 공통 조회 파라미터에 `LoginVO.uniqId` 기반의 `participantUserId`를 추가한다.
4. 관련 백엔드 테스트와 빌드를 실행하고 기존 회귀 테스트가 유지되는지 확인한다.
5. 결과 보고서에 원인, 변경, 검증 결과 및 DB MCP 메타데이터 확인을 기록한다.

## 제외 범위

- DB 스키마·데이터 변경 및 마이그레이션
- API 경로/응답 계약 변경
- 문서작성 화면의 레이아웃 또는 필터 UX 변경
- 다른 계정·tenant의 문서 데이터 조회
