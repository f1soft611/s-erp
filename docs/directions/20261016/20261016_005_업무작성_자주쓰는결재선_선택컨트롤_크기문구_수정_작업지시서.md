# 작업지시서

## 제목

업무작성 자주 쓰는 결재선 선택 컨트롤 크기 및 기본 문구 수정

## 목적

결재선 설정 창의 자주 쓰는 결재선 select와 `설정` 버튼을 결재자/합의자 및 참조 선택기와 같은 시각적 패턴으로 표시하고 미선택 안내 문구를 명확히 한다.

## 승인된 요구사항

- 자주 쓰는 결재선 select의 외곽 높이는 사용자 선택기와 같은 38px로 맞춘다.
- select는 `UserSelectEditor`와 같이 `margin="none"`을 사용하여 기본 수직 여백이 행 높이를 늘리지 않도록 한다.
- 같은 행의 `설정` 버튼은 행 stretch 정렬을 통해 select와 동일한 38px 높이로 표시한다. 버튼 variant는 기존 medium을 유지한다.
- 미선택 문구는 `UserSelectEditor`의 입력 라벨과 같은 0.82rem, 굵기 600 스타일을 사용한다. 선택된 결재선명 스타일은 변경하지 않는다.
- 미선택 문구의 색상도 `UserSelectEditor`의 입력 라벨과 같게 `text.secondary`를 사용한다. 본문 기본색을 상속해 더 진하게 보이는 차이를 없앤다.
- 미선택 기본 문구는 `자주 쓰는 결재선 선택`으로 표시한다.
- select 접근성 이름, 선택 동작, 로딩/오류 상태는 유지한다.
- 공통 컴포넌트, 다른 화면, `결재 추가`/`합의 추가` 버튼 크기는 변경하지 않는다.

## 작업 및 완료 기준

1. 승인 설계 문서와 관련 설정 창 코드/테스트를 확인한다.
2. 기본 문구·타이포그래피, margin, select 높이, 같은 행의 stretch 정렬 검증을 테스트에 반영한다.
3. 자주 쓰는 결재선 select의 기본 margin을 제거하고, 행 stretch 정렬 및 사용자 선택기 라벨 타이포그래피를 적용한다.
4. 설정 창 회귀 테스트, 프론트엔드 빌드, 파일 진단, diff 검사를 실행한다.
5. 브라우저에서 실제 업무작성 설정 창을 확인할 수 있으면 검증하고, 접근할 수 없으면 결과 문서에 제한을 기록한다.
