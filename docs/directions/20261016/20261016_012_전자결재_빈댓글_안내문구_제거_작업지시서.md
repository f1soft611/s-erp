# 전자결재 빈 댓글 안내문구 제거 작업지시서

## 목적

문서작성 화면의 댓글이 없을 때 `등록된 댓글이 없습니다.` 문구를 표시하지 않는다.

## 승인된 동작

- USER 댓글과 SYSTEM 메시지가 모두 없는 경우 빈 상태 문구만 표시하지 않는다.
- 댓글 입력창은 계속 표시한다.
- 로딩 표시, 오류/재시도, 이전 페이지 제어 및 댓글 렌더링 동작은 유지한다.
- 변경 범위는 문서작성 전자결재 상세 댓글 영역으로 제한한다.

## 작업 절차

1. 계획서와 상세 사양서를 작성한다.
2. 빈 댓글 상황에서 안내 문구가 없고 댓글 입력창이 남는지 확인하는 실패 회귀 테스트를 추가한다.
3. 실패를 확인한 다음 빈 상태 문구만 제거한다.
4. 관련 테스트, 프런트엔드 빌드, 변경 범위의 브라우저 확인을 수행한다.
5. 결과 문서에 수정 내용과 실제 검증 결과를 기록한다.

## 완료 기준

- USER 댓글 및 SYSTEM 메시지가 없을 때 `등록된 댓글이 없습니다.`가 표시되지 않는다.
- 댓글 입력창은 빈 상태에서도 계속 사용할 수 있다.
- 로딩·오류/재시도·이전 페이지·댓글 및 시스템 메시지 표시 동작은 유지된다.
- 관련 테스트와 빌드 결과가 기록된다.

## 제외 범위

- API, 백엔드, DB, 댓글 페이지 데이터 계약 변경
- 댓글 작성/수정/삭제 및 권한 정책 변경
- 다른 댓글 화면 또는 알림 UI 변경
