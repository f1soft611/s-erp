# 문서작성 타인 임시저장 조회 제외 작업지시서

## 승인 요구사항

- 사용자 요청: 문서작성 피드·리스트에 다른 기안자의 임시저장이 표시되지 않도록 한다.
- 추가 확인: 본인 문서는 임시저장 포함 유지하고, 타인 문서는 본인이 결재선에 참여하는 상신된 문서만 조회한다.
- 상신 취소 후 `DRAFT`로 복귀한 문서도 타인에게 표시하지 않는다.
- 진행/완료/반려/보완요청 문서의 기존 참여자 조회는 유지한다.
- 목록, 페이징 건수, 요약, 알림, 상세 및 문서 참여 권한 검사를 동일 기준으로 맞춘다.

## 순서 및 완료 기준

1. 계획서와 상세 사양서를 작성한다.
2. PostgreSQL 읽기 전용 MCP로 관련 테이블 메타데이터를 확인한다.
3. Mapper 회귀 테스트를 먼저 실패시키고 공통 조회 조건을 수정한다.
4. 관련 백엔드 테스트 및 가상 데이터 기반 SQL 검증을 수행한다.
5. 결과와 검증 한계를 기록한다. 실사용 데이터나 인증정보를 결과물에 남기지 않는다.

DB 스키마·데이터, API 응답 형식, UI 레이아웃 및 다른 미커밋 작업은 변경하지 않는다.
