# 문서작성 알림 카드 문서 정보 보강 작업지시서

## 사용자 요청 및 승인

- 알림 카드에 기안자, 상신일, 결재상태, 업무구분을 표시한다.
- 상단 알림 유형/상태 배지, 본문 제목, 하단 라벨형 정보 구성을 승인했다.
- [승인 설계](../../superpowers/specs/2026-10-16-document-approval-notice-metadata-design.md)를 기준으로 현재 작업 폴더에서 직접 구현한다.

## 절차 및 완료 기준

1. 계획서 → 상세 사양서 → 실패 테스트 → 구현 순서를 따른다.
2. 기존 알림 API의 값을 재사용하고 상신일과 작성일/수정일을 구분한다.
3. 알림 카드의 기존 선택/최대 3건/빈 상태 동작을 보존한다.
4. 관련 단위 테스트, 빌드, 375/768/1280px 브라우저 검증을 수행하고 결과 및 캡처를 기록한다.
5. backend/DB 변경은 하지 않는다. 기존 미커밋 변경을 보존한다.
