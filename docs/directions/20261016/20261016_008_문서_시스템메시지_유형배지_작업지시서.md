# 문서 시스템 메시지 유형 배지 작업지시서

## 승인 요구사항

- 후속 수정: 시스템 메시지 배지 모서리를 기존 문서 상태 배지와 같은 `8px`로 통일한다.
- 후속 수정: 최종 결재 `COMPLETED` 이벤트는 개별 승인과 구분하여 `완료` 배지로 표시하고 기존 success/filled 색상을 재사용한다.

- 시스템 메시지의 안내 아이콘을 `eventType`에 따른 명칭 배지로 교체한다.
- `DRAFT_SAVED`는 임시저장, `SUBMITTED`는 결재신청, `REJECTED`는 반려, `APPROVED`는 승인, `RETURNED`는 보완요청으로 표시한다.
- 기존 문서 상태 색상 정의를 재사용한다. 새로운 색상값을 정의하지 않는다.
- 그 외 이벤트는 기존 안내 아이콘을 유지한다.
- 메시지 본문, 작성자, 시각, 정렬, 페이지 처리, 읽기 전용 동작은 유지한다.
- 문서 피드와 상세 패널에 동일하게 적용한다. 일반 댓글과 공지사항 동작은 변경하지 않는다.

## 작업 순서와 완료 기준

1. 날짜별 계획서와 상세 사양서를 작성한다.
2. 유형 매핑, 배지 표시, 알 수 없는 이벤트 및 일반 댓글 회귀 테스트를 먼저 추가한다.
3. 프런트엔드 표시 계층만 수정한다. API와 DB 계약은 변경하지 않는다.
4. 관련 Vitest 테스트, 프런트엔드 빌드 및 375px/768px/1280px 브라우저 검증을 수행한다.
5. 결과 문서와 합성 데이터 기반 스크린샷을 기록한다.

기존 작업 중인 통합 댓글 페이지와 반려 사유 표시 변경은 보존한다.
