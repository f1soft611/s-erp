# 문서 상세 결재 버튼 및 사유 줄바꿈 작업지시서

## 요청 및 승인

- 상세 화면의 반려 기능을 복구하고 승인·보완요청·상신 취소·승인 취소를 점검한다.
- 반려·보완 사유를 시스템 댓글에서 입력한 줄바꿈대로 표시한다.
- 사용자 승인: 상세 화면도 피드와 동일한 사유 입력 팝업을 사용한다.
- 추가 요청 및 승인: 반려·보완요청 사유 입력에 기존 `CommonDialog`를 `size="xs"`로 사용한다. 공통 닫기 버튼을 포함하고 처리 중 닫기를 차단한다.

## 작업 순서 및 완료 기준

1. [계획서](../../plan/20261016/20261016_013_문서상세_결재버튼_사유줄바꿈_계획서.md)와 상세 사양을 작성한다.
2. 상세 반려·보완요청 팝업, 필수 사유, 여러 줄 전송, 실패 후 재시도를 테스트한다.
3. 기존 피드 팝업을 재사용하고 시스템 댓글의 일반 텍스트 줄바꿈을 보존한다.
4. 관련 테스트와 빌드, 375/768/1280px 브라우저 검증을 수행한다.
5. 결과와 비식별 화면을 결과 폴더에 기록한다.

## 제외 범위

백엔드/API/DB 계약·권한·상태 전이 변경 및 작업 시작 전에 존재한 변경은 제외한다.
