# 작업지시서

## 제목

F1-Grid 컨텍스트 메뉴 전체 비활성화 옵션 추가

## 배경

현재 F1-Grid는 바디 영역을 우클릭하면 자체 컨텍스트 메뉴를 연다. 행 추가/복사/삭제 등 개별 항목 노출 옵션은 있지만, F1Grid와 F1Tree에서 메뉴 전체를 끄는 옵션은 없다.

## 요구사항

- `disableContextMenu?: boolean` 옵션을 추가한다. 기본값은 `false`로 하여 기존 동작을 유지한다.
- 옵션은 일반 F1Grid 및 F1Tree 바디의 우클릭 컨텍스트 메뉴 전체에 적용한다.
- 활성화 시 그리드 메뉴와 브라우저 기본 우클릭 메뉴를 모두 표시하지 않는다.
- 우클릭 대상 셀/행 선택은 기존처럼 유지한다.
- 이미 메뉴가 열린 상태에서 옵션이 활성화되면 열린 메뉴를 닫는다.
- 헤더의 정렬/필터/고정/숨김 메뉴 동작은 변경하지 않는다.

## 변경 및 검증 절차

1. `frontend/tests/f1-grid-context-menu.test.tsx`에 F1Grid/F1Tree의 메뉴 비노출, 우클릭 선택 유지, 기본 동작 유지, 열려 있는 메뉴 닫힘을 검증하는 회귀 테스트를 추가한다.
2. 관련 테스트를 먼저 실행하여 새 요구사항의 실패를 확인한다.
3. `frontend/src/shared/components/f1-grid/types/grid.types.ts`와 `frontend/src/shared/components/f1-grid/core/F1Grid.tsx`에서 옵션 계약과 동작을 구현한다. F1Tree는 공유 props를 상속하도록 유지한다.
4. F1-Grid API Reference, Playground 문서, `F1-GRID.md`를 갱신한다.
5. 관련 Vitest 테스트와 프론트엔드 빌드를 실행한다.
6. 브라우저에서 기본/비활성화 동작을 확인하고 캡처를 결과 폴더에 기록한다.

## 범위 제외

- 컨텍스트 메뉴 항목별 노출/활성 정책 변경
- 헤더 메뉴의 정렬/필터/고정/숨김 동작 변경
- 브라우저 기본 우클릭 메뉴를 표시하는 별도 모드 추가

## 완료 기준

- `disableContextMenu` 기본값(false)에서 기존 메뉴 및 선택 동작이 유지된다.
- `disableContextMenu={true}`이면 F1Grid와 F1Tree 바디 우클릭 시 앱 메뉴와 브라우저 메뉴가 나타나지 않으며, 대상 셀/행 선택은 유지된다.
- 열린 메뉴가 옵션 활성화 시 닫히고, 헤더 메뉴 동작은 유지된다.
- 관련 테스트와 빌드가 통과하며 F1-Grid 문서와 날짜별 결과 문서/화면 캡처가 포함된다.
