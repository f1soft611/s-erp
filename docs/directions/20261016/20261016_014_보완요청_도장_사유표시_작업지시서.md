# 반려·보완 사유 및 보완요청 도장 표시 작업지시서

- 시스템 댓글의 처리 문구와 `사유:` 사이를 줄바꿈한다. 사유 내부 개행은 보존한다.
- 보완요청 도장은 가운데 정렬된 `보완` / `요청` 두 줄로 표시한다.
- 보완 사유는 도장 아래에서 제거하고 반려와 같은 메시지 아이콘/팝오버로 확인한다.
- 사용자 승인: 기존 저장 데이터까지 화면에서 보정하고 백엔드·저장 형식은 변경하지 않는다.
- [계획서](../../plan/20261016/20261016_014_보완요청_도장_사유표시_계획서.md) → 상세 사양 → 테스트 실패 확인 → 구현 → 브라우저 검증/결과 기록 순으로 수행한다.
- 카드 크기, 상태 색상, 개인 도장 이미지 및 반려 외 승인 의견은 유지한다.
