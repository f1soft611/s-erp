# 문서현황 조회 버튼 작업지시서

## 요청 및 승인

문서현황 상단 우측에 조회 권한이 있을 때 조회 버튼을 표시한다. 다른 관리 페이지의 공통 액션 패턴을 따른다. 사용자가 현재 입력한 검색조건으로 조회하는 방식을 승인했다.

## 범위 및 순서

1. 이 지시서에 따라 계획서와 상세사양서를 작성한다.
2. 현재 메뉴 권한을 문서현황 페이지에 전달하고 공통 PageHeader 액션을 사용한다.
3. 권한 유무, 기본값 로딩, 검색조건 적용 및 동일 조건 재조회를 테스트한다.
4. 관련 테스트와 빌드, 375/768/1280px 브라우저 검증 및 스크린샷을 기록한다.

기존 미커밋 문서현황 분리 작업을 보존한다. 자동조회, 검색바, 상세검색, API, 백엔드, DB 및 공통 그리드는 변경하지 않는다.
