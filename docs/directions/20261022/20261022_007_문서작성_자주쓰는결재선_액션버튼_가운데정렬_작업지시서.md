# 작업지시서

## 제목

문서작성 자주 쓰는 결재선 팝업 행 액션 버튼 가운데 정렬

## 목적

자주 쓰는 결재선 관리 팝업의 각 행에서 `적용`/`삭제` 버튼 그룹을 액션 열 중앙에 배치해 열 끝에 치우쳐 보이지 않게 한다.

## 승인된 요구사항

- 행별 `적용`/`삭제` 버튼 그룹을 액션 셀의 가로 중앙에 정렬한다.
- 액션 열 너비 110px 및 우측 고정 위치는 유지한다.
- 기본 최소 너비와 좌우 패딩을 줄여 버튼 두 개가 셀 안에 함께 보이게 한다. 버튼 높이, 순서, 색상, 기능은 유지한다.
- 팝업 하단 `저장`/`닫기` 버튼과 공통 F1-Grid 동작은 변경하지 않는다.
- 좁은 화면에서도 버튼이 잘리거나 페이지 전체 가로 넘침을 만들지 않는다.

## 작업 및 완료 기준

1. 승인 설계와 기존 자주 쓰는 결재선 관리 Grid 구현/테스트를 확인한다.
2. 행 액션 버튼의 최소 너비/좌우 패딩과 컨테이너 중앙 정렬을 검사하는 회귀 테스트를 먼저 작성해 실패를 확인한다.
3. 해당 관리 팝업의 행 액션 버튼에만 컴팩트한 가로 크기를 적용하고 그룹을 중앙 정렬한다.
4. F1-Grid 사용자 가이드와 결과 보고서에 화면 동작 및 검증 결과를 반영한다.
5. 설정 다이얼로그 테스트, 프론트엔드 빌드, `git diff --check`를 실행하고 375px, 768px, 1280px 브라우저 화면을 확인한다.
