# 로그인 공지 팝업 작업지시서

- 승인: 2026-10-22 사용자 대화 및 화면 시안.
- 공지 작성/수정 배치: 구분 → 로그인 시 팝업·팝업 종료일(같은 행) → 제목 → 내용. 모바일에서는 설정 행을 세로 배치한다.
- 상단 필드는 업무작성의 outlined 라벨/테두리 스타일을 따른다. 상단 고정과 로그인 팝업 여부는 독립적이다.
- 팝업 설정 시 종료일은 필수이며 종료일 당일까지 유효하다.
- 로그인 후 유효 공지를 최신순으로 한 건씩 공통 모달에 표시한다. 메뉴 이동/토큰 갱신/새로고침은 새 로그인이 아니다.
- 후속 UI 지시: 진행 표시(`1 / 1` 등)는 본문이 아닌 상단 '로그인 공지' 타이틀 바로 아래에 표시한다.
- 후속 UI 지시: 작성자·작성일시도 상단 '로그인 공지' 타이틀 아래에 진행 표시와 함께 표시하며 본문에는 중복하지 않는다.
- 최종 승인 디자인: 제목 오른쪽에 연한 파란 진행 배지, 제목 아래에 아이콘·라벨로 구분한 작성자/작성일시. 모바일 작성일시는 별도 줄에 표시한다.
- 확인/닫기는 다음 공지로 진행한다. 체크하지 않으면 다음 로그인 때 다시 보인다.
- '오늘 하루 이 공지 보지 않기'는 현재 공지만 사용자별 서버 저장하며 한국 날짜의 자정에 해제한다.
- 조회수는 실제 표시하는 공지만 기존 사용자별 최초 1회 정책을 재사용한다. 대기열 조회/미표시 공지는 집계하지 않는다.
- 오류는 명시하고 재시도 가능하게 하되 로그인 자체를 막지 않는다.
- 계획 → 사양 → 테스트/구현 → 검증/결과 순서. DB MCP 메타데이터를 확인하고 SQL/롤백/이력을 양쪽 스키마 폴더에 보관한다.
- DB 변경 실행과 서버 재시작은 이 작업에서 자동 수행하지 않는다.
