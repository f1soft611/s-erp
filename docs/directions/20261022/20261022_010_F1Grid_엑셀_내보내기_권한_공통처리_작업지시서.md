# F1Grid 엑셀 내보내기 권한 공통 처리 작업지시서

## 요청 및 승인

- 문서현황 우클릭 메뉴에서 엑셀 권한이 없는데도 엑셀 내보내기가 활성화되는 문제를 수정한다.
- 사용자는 엑셀 내보내기를 제공하는 모든 화면이 동일한 엑셀 권한 기준을 적용하도록 승인했다.
- 엑셀 권한이 없으면 컨텍스트 메뉴에서 엑셀 내보내기 항목을 숨긴다.

## 조사 결과

- 공통 F1Grid는 `canExportExcel`이 `true`일 때만 엑셀 내보내기 메뉴를 표시하며 기본값은 `false`다.
- 문서현황과 기안양식 그리드는 권한이 아닌 상수 `true`를 전달한다. 기안양식 페이지는 이미 `pagePermissions.excel`을 계산해 하위 그리드에 전달하지만 그리드가 이를 사용하지 않는다.
- 자료실 파일 트리는 페이지 권한을 받으면서도 그리드에 엑셀 권한을 전달하지 않고 `true`로 고정한다.
- 나머지 확인된 업무 화면(현재 거래처·자재·창고·메뉴·역할·모듈·공통코드)은 `pageActionPermissions.excel`, `pagePermissions.excel` 또는 `selectedMenuPermissions.excel`을 전달하거나 엑셀 메뉴를 명시적으로 끄고 있다.

## 작업 범위 및 완료 기준

1. 기존 공통 `F1GridProps.canExportExcel` 표시 계약을 유지한다.
2. 문서현황, 기안양식, 자료실 파일 트리에서 해당 페이지의 엑셀 권한을 그리드까지 전달한다.
3. 권한이 없는 경우 메뉴 항목이 DOM에 표시되지 않고, 권한이 있는 경우 기존처럼 표시되는 회귀 테스트를 추가하거나 갱신한다.
4. 관련 Vitest와 프론트엔드 빌드를 실행한다.
5. 작업 결과 문서와 검증 스크린샷을 `docs/result/20261022/f1-grid-excel-permission/`에 보관한다.
6. 백엔드, API, DB, Excel 내보내기 변환 및 공통 F1Grid의 메뉴 UX는 변경하지 않는다.
