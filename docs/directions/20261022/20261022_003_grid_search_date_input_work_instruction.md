# 공통 상세검색 날짜 입력 개선 작업지시서

## 요구 및 승인

- F1-Grid 셀 날짜 편집기의 숫자 축약 입력과 달력 선택을 공통 상세검색 시작일·종료일에서도 사용한다.
- 사용자 승인 범위는 특정 화면이 아닌 공통 상세검색 전체다.
- 기존 검색 기본값, 초기화, 검색조건 복원 및 `{ from, to }` 문자열 계약을 유지한다.

## 작업 순서

1. 날짜별 계획서와 상세 사양서를 작성하고 검토한다.
2. 기존 날짜 편집기의 입력·정규화·달력 동작을 재사용하되 셀 편집 전용 포커스와 스타일을 검색 폼에 강제하지 않는다.
3. 공통 상세검색에 적용하고 잘못된 날짜를 명시적으로 표시하며 조회를 차단한다.
4. 관련 회귀 테스트, 빌드 및 실제 브라우저 검증을 수행한다.
5. F1-Grid 문서와 날짜별 결과 문서, 스크린샷을 갱신한다.

## 완료 기준

- `YYYYMMDD`, `YYMMDD`, `MMDD`, `DD`, `M-D`, ISO 날짜 입력과 달력 선택을 지원한다.
- 날짜 입력 완료 시 유효한 값만 ISO 날짜로 확정한다. 빈 값은 제한 없는 검색을 의미한다.
- 존재하지 않는 날짜는 빈 값으로 조용히 대체하거나 조회에 전달하지 않는다.
- 시작일·종료일 각각 독립적으로 입력·수정·삭제한다.
- 그리드 셀 편집, 날짜 기본값, 초기화, 복원 동작이 유지된다.
- 375px, 768px, 1280px에서 실제 브라우저로 입력과 달력 표시를 확인한다.
- 백엔드, DB, 업무별 검색 API 및 날짜 기본값 정책은 변경하지 않는다.
