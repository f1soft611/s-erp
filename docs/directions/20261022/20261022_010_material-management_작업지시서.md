# 20261022_010 품목관리 작업지시서

## 사용자 요청 및 승인

- `/co/master/materials`에 거래처 페이지와 같은 품목관리 화면을 추가한다.
- 지정 MCP `s-erp-postgresql-readonly-tenant-1110011111`의 `public.tb_material_info`를 기준으로 한다.
- 2026-10-22 사용자 승인: 품목코드는 직접 입력 가능하며, 미입력 시 기존 eGov IDS를 이용해 6자리 자동채번한다.
- 품목 전용 Controller → Service/Impl → DAO → Mapper 및 별도 배치 서비스 구조를 사용한다.
- 기본/상세 검색, F1-Grid 목록, 행 폼 등록/수정, 단일 트랜잭션 일괄저장을 제공한다.
- 삭제/복원과 임의의 사용여부 컬럼 추가는 제외한다. 삭제되지 않은 품목만 조회/수정한다.

## DB 확인

지정 MCP에서 `list_tables`, `describe_table`로 `tb_material_info`, `ids`, 공통코드 그룹/항목 구조를 확인했다. 품목의 컬럼 타입·길이·주석 및 제약은 PostgreSQL 카탈로그를 제한 조회했다. 업무 행, 계정, 인증정보 및 IDS 카운터 행은 조회하지 않았다.

## 완료 조건

- 후속 누락 보완: `tb_material_info`가 없는 환경용 생성 SQL을 추가한다. 지정 tenant MCP의 37개 컬럼/기본값/주석/PK/FK/unique/CHECK 및 인덱스를 반영한다. 기존 테이블이 있으면 생성 SQL은 실행하지 않고 채번 초기화만 수행한다. 생성 SQL → 채번 초기화 순서를 명시하고, 신규 테이블의 빈 테이블 전용 롤백은 기존 no-op 채번 롤백과 분리한다.

- 후속 컴파일 오류 수정: Maven의 Java 8 source/target에 맞춰 품목 서비스와 테스트에서 Java 9 이상 컬렉션 팩토리 및 문자열 반복 API를 사용하지 않는다. 실제 Java 8 API 기준 컴파일 회귀 검증을 추가한다.

- 기존 품목 테이블 구조와 기존 거래처/공통 그리드 변경사항을 보존한다.
- 품목명, 품목계정코드, 코드 중복, 필드 길이, 숫자와 소비기한 제약을 검증한다.
- 인증 테넌트 격리, 관리자 및 메뉴 권한, 명시적 오류와 미저장 변경 확인을 제공한다.
- 품목유형/보관방법/소비기한 기준은 명시된 공통코드와 연계한다.
- IDS 초기화/변경이력/안전한 롤백을 두 스키마 폴더에 동일하게 보관한다. 읽기 전용 MCP로 적용하지 않는다.
- 계획서 → 상세사양서 → 테스트/구현 → 검증/결과 문서 순서를 지킨다.
- 프론트 집중 테스트·빌드, 백엔드 집중 테스트, 375/768/1280px 브라우저 확인과 스크린샷을 남긴다.
