# F1-Grid 개발자 문서 포털 전면 개편 작업지시서

## 배경

F1-Grid 문서 포털은 기능 설명, 옵션 참조, 예제, 실행형 Playground를 제공하지만 메뉴 구조와 기능/API 연결이 개발자의 빠른 탐색에 최적화되어 있지 않다. 사용자가 F1-Grid의 지원 옵션과 동작 범위를 전체적으로 확인하기도 어렵다.

## 목표

- 문서 포털의 메뉴를 기능 중심으로 재구성한다.
- 실제 사용자 공개 API와 지원 기능을 빠짐없이 문서화한다.
- 옵션, 기능 설명, 복사 가능한 예제, 실행형 Playground 간 연결을 명확히 한다.
- 한국어 중심의 안내와 개발자가 사용하는 정확한 API 식별자를 함께 제공한다.
- 데스크톱, 태블릿, 모바일과 라이트/다크 테마에서 문서를 읽고 탐색할 수 있도록 개선한다.

## 확정 요구사항

### 정보 구조

기능 중심으로 `시작하기`, `그리드와 데이터`, `편집과 검증`, `선택·클립보드·행 작업`, `필터와 정렬`, `컬럼·레이아웃·행 높이`, `대용량 데이터`, `트리 그리드`, `행 병합`, `플러그인과 확장`, `API 참조`, `테스트`를 구성한다.

### 완전성

- `F1GridProps`, `F1TreeProps`, `F1GridColumn`, `F1GridRef`, `F1TreeRef`를 포함한 사용자 공개 API 전체를 다룬다.
- 공개 타입, 데이터 소스, 편집기 및 행 폼 플러그인, 콜백, 기본값, 제약과 동작을 구현 및 테스트와 대조한다.
- 각 옵션의 이름, 타입/시그니처, 해당하는 기본값, 설명/제약 및 사용 예 또는 관련 링크를 제공한다.
- 행 선택 체크박스, checkbox 컬럼 편집, 트리 체크박스의 차이를 구분한다.
- 저수준 내부 유틸리티를 사용자 공개 API인 것처럼 문서화하지 않는다.

### 화면과 사용성

- 데스크톱에서는 좌측 그룹 메뉴, 본문, 우측 섹션 목차를 제공한다.
- 좁은 화면에서는 메뉴 및 목차를 접어 본문과 예제가 가로로 넘치지 않게 한다.
- 문서 제목, 섹션 제목, API 식별자와 설명을 검색할 수 있게 한다.
- 기능 설명, 옵션 상세, 복사 가능한 코드, 기존 기능별 Playground를 함께 제공한다.
- `/f1-grid-docs` 및 대시보드 내 진입, 라이트/다크 테마, 코드 복사 동작을 유지한다.
- Playground는 기존의 로컬 샘플 데이터 방식으로 유지하며, 사용자 임의 코드 실행이나 백엔드 연결을 추가하지 않는다.

## 구현 범위

- `frontend/src/pages/f1-grid-docs` 포털 컴포넌트, 문서 데이터, 스타일 및 관련 테스트
- API 완전성에 필요한 F1-Grid 문서와 Playground의 직접 관련 내용
- 날짜별 상세 사양서, 작업 결과 문서와 브라우저 스크린샷

## 제외 범위

- F1-Grid 런타임/엔진의 동작 변경
- 백엔드, API 서버 및 데이터베이스 변경
- 브라우저에서의 임의 코드 실행
- 무관한 전역 레이아웃 또는 스타일 리팩터링

## 완료 기준

- 공개 사용 API의 항목과 지원 기능이 구현 타입/동작/테스트를 기준으로 모두 문서화된다.
- 검색, 그룹 메뉴, 섹션 링크, 코드 복사와 기능별 Playground가 작동한다.
- 관련 테스트와 프론트엔드 빌드가 통과한다.
- 실제 브라우저에서 375px, 768px, 1280px와 라이트/다크 테마를 확인한다.
- 결과 문서와 데스크톱/모바일 스크린샷을 `docs/result/20261014/f1-grid-docs-overhaul`에 보관한다.
