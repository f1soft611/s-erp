# 20261014_001 공지 피드 이전 댓글 완료 시 버튼 숨김 작업지시서

## 작업 목적

공지사항 피드에서 이전 댓글을 모두 불러온 뒤 남은 댓글 수가 0이면 `이전 댓글 보기 (0)` 버튼이 남지 않도록 한다. 모든 댓글이 화면에 표시된 상태에서는 이전 댓글 보기 문구를 숨긴다.

## 대상 및 범위

- 공통 컴포넌트: `frontend/src/shared/components/feed/FeedCommentsSection.tsx`
- 회귀 테스트: `frontend/tests/feed-components.test.tsx`
- 공지사항에서 기존 남은 댓글 계산 및 페이지네이션 동작이 유지되는지 관련 테스트로 확인한다.
- 이 컴포넌트를 사용하는 전자결재 피드에도 동일한 완료 상태 표시 규칙을 적용한다.

## 요구사항

1. 이전 댓글 버튼 표시 가능 상태여도 유효한 남은 댓글 수가 0이면 버튼과 문구를 표시하지 않는다.
2. 이전 댓글 조회 중에는 기존 로딩 문구와 진행 상태를 유지한다.
3. 남은 댓글 수가 양수이면 기존 `이전 댓글 보기 (N)` 레이블을 유지한다.
4. 남은 댓글 수를 알 수 없으면 기존 `이전 댓글 보기` 레이블과 표시 조건을 유지한다.
5. 댓글 조회 API, 커서, 댓글 수 계산, 오류 알림은 변경하지 않는다.

## 완료 기준

- 남은 댓글 수가 0인 공통 컴포넌트 회귀 테스트가 통과한다.
- 기존 카운트, 로딩, 조회 액션 테스트가 유지된다.
- 관련 공지사항/전자결재 테스트와 프론트엔드 빌드가 통과한다.
- 실제 브라우저에서 공지사항의 0건 완료 상태를 확인하고 결과 문서에 기록한다.
