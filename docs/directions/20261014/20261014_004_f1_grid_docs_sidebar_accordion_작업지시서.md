# F1-Grid 문서 사이드 메뉴 아코디언 작업지시서

## 배경

문서 포털의 기능별 메뉴 그룹이 모두 펼쳐져 있어 사이드 메뉴가 길고 현재 문서 위치를 빠르게 찾기 어렵다.

## 목표

- 문서 사이드 메뉴를 단일 열린 그룹 아코디언으로 바꾼다.
- 현재 선택 문서의 그룹만 펼쳐 현재 위치를 명확히 한다.
- 그룹 제목을 선택하면 해당 그룹 첫 문서로 이동시켜 메뉴와 본문 선택 상태를 일치시킨다.
- 검색 중에는 필터된 문서와 API 결과를 기존처럼 그룹별로 모두 노출한다.

## 범위와 제약

- 변경 범위: F1-Grid 문서 포털 메뉴 컴포넌트, 메뉴 스타일, 관련 테스트 및 직접 관련 문서/결과물.
- 기능 그룹, 문서 순서, 검색 의미, API 참조, Playground, 본문, 목차와 라우트는 유지한다.
- 그룹 제목은 실제 버튼으로 제공하고 `aria-expanded` 상태를 노출한다.
- 검색 중에는 메뉴 그룹을 접지 않고 검색 결과가 있는 그룹과 항목을 모두 보여준다.
- 모바일과 데스크톱에서 같은 그룹 전환 규칙을 제공한다.
- F1-Grid 런타임, 백엔드, 데이터베이스는 변경하지 않는다.

## 완료 기준

- 초기 문서, 그룹 문서 선택, 그룹 제목 선택 시 선택 문서와 펼쳐진 그룹이 항상 일치한다.
- 접힌 그룹의 문서 항목은 기본 메뉴에서 노출되지 않는다.
- 검색 중 일치 문서 및 API 결과가 누락되지 않고 기존 이동 동작이 유지된다.
- 관련 Vitest와 프론트엔드 빌드가 통과한다.
- 데스크톱 및 모바일 실제 브라우저에서 그룹 전환/검색을 확인하고 결과 문서와 스크린샷을 저장한다.
