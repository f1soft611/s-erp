# 거래명세표와 회사 직인 작업지시서

- 사용자의 최종 요청에 따라 제공된 PDF처럼 같은 거래명세서 두 부를 A4 한 장의 상하에 배치한다. 공급자, 거래처, 품목, 금액, 합계와 직인을 표시한다.
- 회사정보 관리 화면을 재구성하고 회사 직인 이미지를 첨부·교체·삭제할 수 있게 한다.
- 회사정보 세로 스크롤바는 가운데 입력 폼이 아닌 화면 오른쪽 끝에 배치한다.
- 회사정보 입력 필드 사이의 불필요하게 넓은 세로 여백을 줄인다.
- 회사정보 저장 성공 시 토스트 메시지를 표시한다.
- 인쇄 미리보기에서 출력물을 가운데 정렬한다.
- 직인을 등록하기 전에 발행된 명세서도 현재 회사 직인을 출력한다. 저장된 직인 스냅샷이 있는 명세서는 해당 스냅샷을 우선한다.
- 신규 발행 시 직인을 함께 저장하고 저장된 직인이 있는 명세서는 이후 회사 직인 변경의 영향을 받지 않게 한다.
- 기존 권한과 테넌트 경계를 유지하고 이미지 형식과 크기를 서버에서 검증한다.
- PDF의 실제 회사·거래처 정보는 구현이나 테스트 데이터에 복사하지 않는다.
