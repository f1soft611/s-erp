# 출하계획 메뉴와 레이아웃 작업지시서

- 기존 독립 출하계획 메뉴를 정리하고 출하관리 아래 출하계획등록과 출하계획현황을 배치한다.
- 기존 메뉴 ID와 권한을 가능한 한 보존하고, 기존 메뉴가 없는 경우에도 추가할 수 있는 안전한 SQL과 롤백을 제공한다. DB에 직접 적용하지 않는다.
- 출하계획등록과 출하계획현황을 각각 출하등록과 출하현황의 화면 구조, 버튼 위치, 검색 영역과 그리드 패턴에 맞춘다. 기존 계획 편집과 권한 동작은 유지한다.
- 에이전트가 기존 동종 화면의 레이아웃을 무시하고 새로 구성하지 않도록 프론트엔드 지침에 비교 및 검증 기준을 기록한다.
- 테스트, 실제 브라우저의 375/768/1280px 확인과 결과 문서를 작성한다.
- 결과 문서에 실제 작업 내용을 반영한 복사 가능한 커밋 제목과 본문을 기록한다.
