# 출하계획 F1Grid 편집 작업지시서

- 출하계획등록과 출하계획현황 상세 수정의 계획일·계획수량을 수주·출하 상세와 같은 F1Grid 기본 셀 편집 방식으로 제공한다.
- 기존 등록·현황의 공통 폼, 분할, 저장 검증, 권한, AUTO/MANUAL 및 저장 실패 시 값 보존을 유지한다.
- 수주·출하 등록 및 자세히보기·수정 화면과 그리드 행 높이, 기본정보 필드 간격, 상세 영역 여백과 대화상자 내부 배치를 일치시킨다.
- 출하계획현황 상세 패널은 수주현황과 같은 작성자 이름·프로필 사진·등록일을 표시하고, 요약·정보·품목 영역의 배치를 동종 화면과 맞춘다.
- 셀 편집 확정, 저장, 분할, 취소 및 읽기 전용 동작을 실제 브라우저에서 확인하고 관련 F1Grid 문서와 결과를 기록한다.
