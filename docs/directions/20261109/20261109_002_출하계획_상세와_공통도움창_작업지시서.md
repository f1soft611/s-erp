# 출하계획 상세와 공통 도움창 개선 작업지시서

- 출하등록의 계획 선택과 출하계획등록의 수주 선택을 수주등록 거래처 필드와 같은 입력란 내부 돋보기로 제공한다.
- 출하계획현황은 계획번호 클릭으로 상세를 열고 출하현황 상세 패널, 더보기 메뉴 및 상세보기·수정 대화상자 패턴을 따른다. 계획 편집과 권한을 유지한다.
- 공통 품목 도움창에 품목규격, 품목규격2, 단위, 모델명 등 기존 항목을, 거래처 도움창에 사업자번호와 대표자명 등 기존 항목을 보여준다.
- 기존 API 데이터 계약과 테넌트 범위를 그대로 유지하고 없는 값을 임의로 만들지 않는다.
- 반응형 화면, 기존 선택·계획 편집 회귀, 결과서와 복사 가능한 짧은 커밋 문구를 확인한다.
