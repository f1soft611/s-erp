# 출하계획·수주 도움창 개선 작업지시서

- 출하계획등록의 수주 도움창 검색 필드와 버튼 크기를 출하등록의 출하계획 선택 도움창에 맞춘다.
- 두 도움창의 번호 셀에는 번호만 표시하고 기존 선택 동작은 유지한다.
- 두 목록에 F1Grid 행 선택 모드를 적용한다.
- 출하계획현황 상세보기·수정 폼을 출하계획등록과 동일한 폼 및 F1Grid로 공유하고, 편집 기능과 저장 동작을 맞춘다.
- 에이전트가 현황의 상세·수정 화면을 등록 화면과 별도로 재구현하지 않도록 재발 방지 규칙을 기록한다.
- 반응형 브라우저 검증과 결과서 및 짧은 커밋 문구를 남긴다.
