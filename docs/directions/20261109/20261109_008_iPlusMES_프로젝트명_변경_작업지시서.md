# iPlusMES 프로젝트명 변경 작업지시서

## 요청

기존 프로젝트 제품명 `S-ERP`를 `iPlusMES`로 변경한다.

## 작업 범위

- 현재 애플리케이션의 로그인·대시보드·오류 화면, 브라우저 제목, 푸시 알림, 기본 HTML 화면의 제품명 표시를 변경한다.
- 사용자가 현재 참고하는 프로젝트 안내 문서와 실행 가이드의 제품명 표기를 변경한다.
- 제품명을 기대하는 테스트와 접근성 텍스트를 새 이름에 맞춘다.
- 세션 저장소 키, 인증·이벤트 식별자, 아티팩트 이름, MCP 서버 ID, 저장소 경로처럼 실행 호환성에 영향을 주는 내부 식별자는 유지한다.
- 과거 작업지시서·계획서·사양서·결과 기록은 당시 이력으로 보존한다.

## 작업 절차

1. 저장소에 이미 존재하는 미커밋 변경을 보존하면서 대상 파일과 브랜드 표기를 구분한다.
2. 계획서와 상세 사양서에 변경 범위 및 제외 항목을 기록한다.
3. 현재 애플리케이션과 운영 안내서의 제품명만 `iPlusMES`로 변경한다.
4. 관련 테스트, 프론트엔드 빌드, 테스트 및 브라우저 화면을 확인한다.
5. 의도적으로 남긴 `S-ERP` 문자열을 분류하고 결과 문서에 기록한다.

## 완료 조건

- 현재 사용자에게 노출되는 제품명과 활성 프로젝트 안내가 `iPlusMES`로 표시된다.
- 기술 식별자 및 과거 기록은 불필요하게 변경되지 않는다.
- 관련 검증이 통과하고 결과 문서와 스크린샷이 저장된다.
- 데이터베이스 구조와 API 계약은 변경되지 않는다.
