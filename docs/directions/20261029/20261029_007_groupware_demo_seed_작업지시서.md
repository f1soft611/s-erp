# 업무·그룹웨어 데모 데이터 SQL 작업지시서

## 요청과 범위

- 사용자 요청: 실제 업무처럼 보이는 업무·그룹웨어 데이터와 댓글을 넣을 수 있는 스크립트 작성.
- 기존 데이터를 바꾸거나 삭제하지 않는 추가형을 기본으로 한다. 연결 DB에는 적용하지 않는다.
- 공지사항 8건, 전자결재 12건, 일반 댓글·대댓글, 문서 상태에 맞는 결재선·시스템 이벤트를 생성한다.
- 기존 테넌트와 활성 사용자 3명을 실행 인자로 명시한다. 계정/권한/비밀번호는 만들거나 변경하지 않는다.
- 자료실은 실제 오브젝트 저장소에 파일이 있어야 화면에 표시되므로 가짜 파일 메타데이터와 빈 게시글은 생성하지 않는다.
- 수주/품목/거래처, 기안양식 마스터 변경은 별도 작업이며 이번 범위에서 제외한다.

## 순서와 완료 기준

1. 이 지시서를 바탕으로 계획서, 상세사양서를 순서대로 작성한다.
2. 기본 읽기 전용 DB MCP의 테이블·컬럼·제약과 Mapper/Service를 확인한다.
3. 신규 시드, 롤백, 변경 이력을 양쪽 날짜별 DB 폴더에 동일하게 보관한다.
4. 격리 PostgreSQL 엔진에서 정상 삽입, 반복 실행, 테넌트 경계, 잘못된 입력, 롤백 보호를 검증한다.
5. 결과 보고서에 실행법, 검증 범위, 실DB 미적용 사실을 기록한다. UI 변경과 실DB 쓰기가 없으므로 화면 스크린샷은 해당 없음으로 명시한다.
