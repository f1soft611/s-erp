# 댓글 수정 권한 및 이미지 첨부 구분선 작업지시서

## 사용자 요구

- 문서와 공지의 댓글 더보기 메뉴에서 본인이 작성하지 않은 댓글의 수정/삭제 동작을 제공하지 않는다.
- 댓글 수정 화면의 이미지 첨부 미리보기는 기존처럼 표시한다. 이미지 미리보기와 파일명 사이에 구분선과 여백을 추가한다.

## 범위와 원칙

- 공통 댓글 UI는 댓글 작성자 여부를 나타내는 `isEditable` 값에 따라 더보기 메뉴를 표시한다.
- 공지 댓글 adapter는 로그인 사용자와 댓글 작성자 ID가 일치할 때만 `isEditable`을 허용한다. ID가 없거나 로그인 정보가 없으면 편집 불가로 처리한다.
- 전자결재 문서의 작성자 판별, 서버 API 권한 및 기존 이미지 미리보기 동작은 유지한다.
- 변경 범위는 프론트엔드와 관련 문서/테스트로 제한한다. API, DB, 첨부파일 저장 계약은 변경하지 않는다.

## 실행 순서와 완료 기준

1. 기존 댓글 소유자 판별 및 첨부 미리보기 렌더링을 확인한다.
2. 타인 댓글 메뉴 미노출, 공지 작성자 비교, 이미지 미리보기 유지와 구분선을 검증하는 회귀 테스트를 먼저 추가한다.
3. 공통 댓글 UI에서 `isEditable`이 true인 댓글만 수정/삭제 메뉴를 표시한다.
4. 공지 댓글 adapter에 현재 로그인 사용자 기준의 편집 가능 여부를 설정한다.
5. 첨부 이미지 미리보기와 파일명 사이에 세로 구분선과 간격을 추가한다.
6. 집중 프론트엔드 테스트, build, lint를 실행하고 변경 결과를 문서화한다.

## 제외 범위

- 이미지 미리보기 제거 또는 hover 방식으로의 변경
- 댓글 편집/삭제 서버 권한 정책 및 API 변경
- DB 스키마 변경
