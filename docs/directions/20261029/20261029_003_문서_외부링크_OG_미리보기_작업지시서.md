# 문서 본문·댓글 외부 링크 OG 미리보기 작업지시서

## 사용자 요구

- 문서 작성 본문, 기존 문서 본문, 댓글/답글 본문에 외부 웹 링크를 넣으면 OG 미리보기를 제공한다.
- 기존 `문서 공유하기`의 암호화된 내부 문서 링크 미리보기와 외부 URL 미리보기는 서로 구분되어야 하며 둘 다 정상 동작해야 한다.

## 범위와 원칙

- 기존 내부 링크의 토큰 발급, 권한 확인, 상세 패널 열기 동작을 변경하지 않는다.
- 외부 URL만 별도 웹 링크 카드로 처리한다. 본문에 저장하는 값은 기존 HTML/URL 그대로이며 OG 메타데이터는 저장하지 않는다.
- 외부 메타데이터 조회는 인증된 백엔드 API를 통해 수행하며, DB/스키마는 변경하지 않는다.
- 임의 URL 요청에 따른 SSRF를 방지한다. HTTP(S)만 허용하고, 사용자 정보·비표준 포트·비공개/예약 IP·검증되지 않은 리다이렉트 대상은 거부한다. DNS 결과를 연결에 고정하고, 연결 시간·응답 바이트·리다이렉트 횟수를 제한한다.
- 메타데이터는 HTML에서 OG 제목/설명/이미지와 문서 제목을 파싱해 길이를 제한한 안전한 텍스트로 반환한다. HTML/스크립트는 실행하거나 반환하지 않는다.
- URL의 전체 값을 로그에 남기지 않는다. 네트워크 오류·잘못된 페이지는 원문 링크 기능을 유지하고 미리보기만 일반 오류 상태로 처리한다.

## 필수 순서와 완료 기준

1. 본 작업지시서를 확인하고 계획서와 상세 사양서를 작성한다.
2. 링크 분류, 안전한 외부 메타데이터 조회, 카드 표시/오류, 내부 공유 링크 회귀 테스트를 먼저 작성한다.
3. 백엔드 조회 정책과 컨트롤러를 추가하고 frontend 서비스/카드에 연결한다.
4. 본문·댓글·답글의 작성/조회/수정에 내부/외부 링크를 분리해 표시한다.
5. 관련 테스트와 빌드/린트를 수행하고 실제 브라우저에서 375/768/1280px 레이아웃을 확인한다.
6. 결과 문서와 필요한 스크린샷을 `docs/result/20261029/document-external-link-og`에 기록한다.

기존 작업 중인 변경은 보존한다. 이번 작업에서 DB 변경, 문서 공유 링크 형식 변경, 외부 OG 서비스 위탁은 하지 않는다.
