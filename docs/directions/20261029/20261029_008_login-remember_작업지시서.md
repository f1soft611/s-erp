# 로그인 저장 작업지시서

## 요청과 범위

- 사용자 요청: 로그인에 로그인 저장을 추가하여 회사코드와 사용자 아이디를 저장한다.
- 기존 화면의 회사코드 표기는 `업체코드`, 사용자 아이디 표기는 `사용자 ID`로 유지한다.
- 비밀번호 아래에 기본 해제된 `로그인 저장` 체크박스를 추가한다.
- 선택 후 로그인 성공 시 현재 브라우저에 업체코드와 사용자 ID만 저장한다.
- 재방문 시 저장된 두 입력값과 선택 상태를 복원한다. 비밀번호는 복원하거나 저장하지 않는다.
- 선택 해제 시 저장값을 즉시 삭제한다. 로그인 실패나 필수 입력 오류에서는 저장값을 갱신하지 않는다.
- 인증 세션, 자동 로그인, API, 백엔드, DB는 변경하지 않는다.

## 완료 기준

- 계획 → 상세 사양 → 실패 테스트 → 구현 → 검증 → 결과 문서 순서로 진행한다.
- 저장/복원/해제/실패/저장소 오류에 대한 집중 테스트를 통과한다.
- 기존 로그인 테스트, lint와 build를 확인한다.
- 4173 포트에서 실제 브라우저로 375/768/1280px 및 라이트/다크 테마를 확인하고 스크린샷을 보관한다.
