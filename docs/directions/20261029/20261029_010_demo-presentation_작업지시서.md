# 데모 승인·시스템 이력 보정

- 요청: 데모 승인에는 승인 의견 없이 도장만 표시하고 시스템 이력에 노출된 HTML/시드 마커를 제거한다.
- 기존 업무 기능과 일반 댓글/답글/반려·보완 사유는 유지한다.
- 신규 시드의 원인을 수정하고 이미 적용한 데모용 증분 보정·복원 SQL을 제공한다. 연결 DB에는 적용하지 않는다.
- 명시한 테넌트의 시드 마커가 있는 문서, 원본과 일치하는 합성 의견/시스템 이력만 변경한다. 사용자 변경은 보존하거나 중단한다.
- 계획 → 사양 → 실패 테스트 → 구현 → 격리 DB 검증 → 결과 기록 순서를 따른다.
