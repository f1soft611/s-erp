# 20261029_006 커뮤니티 자료실 파일·폴더 이름 색상 개선 작업지시서

## 목적

자료실에서 파란색으로 표시되는 이름을 기본 텍스트 색상으로 바꾸고, 폴더 이름은 검정색 굵은 글씨로 표시한다. 확장자별 파일 아이콘은 문서·공지 첨부 목록과 같은 색상 규칙을 사용한다.

## 승인 범위 및 동작

- 파일 이름은 기본 텍스트 색상, 일반 굵기로 표시한다. 클릭 시 기존 다운로드 기능을 유지한다.
- 폴더 이름은 기본 텍스트 색상, 굵은 글씨로 표시한다. 클릭 시 기존 폴더 진입 기능을 유지한다.
- 폴더 아이콘은 활성/비활성 상태와 무관하게 회색톤(`text.secondary`)을 사용한다. 비활성 표시와 사용중지 chip은 유지한다.
- 확장자 아이콘은 공유 `getAttachmentIconMeta`의 아이콘과 전경/배경 색상을 사용한다.
- 폴더 상태 아이콘, 사용중지 표시, 파일 작업 버튼, 검색/API 및 권한 동작은 변경하지 않는다.
- 백엔드, DB, API 계약은 변경하지 않는다.

## 작업 절차

1. 최신 자료실 사양 및 기존 첨부 아이콘 구현을 확인한다.
2. 자료실 페이지 테스트에 이름 색상·굵기, 아이콘 색상, 기존 클릭 동작 검증을 추가한다.
3. 자료실 F1Tree 렌더러만 최소 변경한다.
4. 대상 테스트/lint 및 375px, 768px, 1280px 브라우저 확인을 수행한다.
5. F1-Grid 문서와 결과 문서/스크린샷을 갱신한다.

## 완료 조건

- 이름은 파란색이 아니며 폴더명만 굵게 표시된다.
- 폴더 클릭은 기존 folder filter 조회를 수행하고 파일명 클릭은 기존 다운로드를 수행한다.
- 확장자 아이콘의 모양과 색상은 공지/문서 첨부 아이콘 헬퍼 규칙을 따른다.
- 대상 테스트와 lint가 통과하고 세 뷰포트 스크린샷을 결과 경로에 보관한다.
