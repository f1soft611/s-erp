# 20261120_004 창고등록 담당자 선택에 사원 선택 도움창 연결 작업지시서

## 배경
창고관리([20261105_001](../../spec/20261105/20261105_001_warehouse_screen_spec.md))의 담당자는 사용자 목록 드롭다운(`type: 'user'`)으로 고르고 담당부서가 같이 채워진다. 사원 선택 도움창([20261120_003](../../result/20261120/hr-employee-picker/20261120_003_사원선택_도움창_결과.md))을 만들었으므로 이 화면의 담당자 선택을 도움창으로 바꾼다.

## 결정 (사용자 요청, 2026-11-20)
- 창고등록의 **담당자 선택에 사원 선택 도움창을 연결**한다. 사원을 고르면 담당자와 함께 **담당부서까지 같이 설정**된다(기존 동작 유지).
- 표 셀과 창고 등록·수정 행 폼 모두에서 선택 버튼(돋보기)으로 같은 도움창을 연다(F1Grid `type: 'code'` + `onOpenCodePicker`, 거래처관리 분류 선택과 같은 방식).

## 범위
- 포함: 창고 담당자 칸을 도움창 방식으로 변경, 담당자 지정을 **해제**할 수 있는 방법(도움창의 "선택 해제" 버튼, 도움창에 선택 속성 추가), 드롭다운용 사용자 목록 조회 제거, 테스트·문서.
- 제외: 백엔드(저장 계약인 `managerUserId`·`departmentId` 그대로, `GET /warehouses/user-options`는 남겨 둠), F1Grid 자체, 다른 화면.

## 완료 조건
- 담당자 칸의 선택 버튼(표·행 폼)으로 도움창이 열리고, 사원을 더블클릭하면 담당자명·담당부서가 채워진 뒤 저장된다.
- 담당자를 지정하지 않거나 해제한 창고도 저장된다. 직접 입력으로는 담당자를 바꿀 수 없다.
- 관련 테스트·`tsc`·`f1-grid-storage-keys` 통과, 실서버·브라우저에서 선택→저장→재조회 확인.
