# 20261120_006 창고 미사용(사용여부) 관리 작업지시서

## 배경
창고의 **불용창고**(`disuse_at`)는 더 이상 쓰지 않는 창고가 아니라, 판매·사용하지 않는 **불용재고·불용자재·불용물품을 보관·정리·처분하기 위해 운영하는 창고**다([20261105_001](../../spec/20261105/20261105_001_warehouse_screen_spec.md)). 그런데 화면은 창고를 삭제할 수 없고 "불용창고로 변경"하라고 안내해 왔고, 점검용으로 만든 창고 3건도 불용창고로 눌러 두었다. 쓰지 않는 창고를 정리할 **별도의 미사용 상태**(실제 삭제가 아니라 상태만 변경)가 필요하다.

## 결정 (사용자 요청, 2026-11-20)
- 불용창고와 **미사용은 다른 개념**이다. 미사용 창고는 지우지 않고 사용여부만 바꾼다(soft delete, 이력·연결 전표 유지).
- 새 컬럼 `tb_warehouse.use_at`(Y=사용, N=미사용, 기본 Y)을 추가한다.

## 범위
- 포함: DB 컬럼·스크립트(롤백 포함), 서버(조회 조건·저장·검증·안내 문구), 창고 화면(사용여부 열·조회조건·미사용 행 표시), 창고를 고르는 다른 화면의 선택 목록에서 미사용 제외, 점검 창고 3건 정리, 테스트·문서.
- 제외: 재고가 남은 창고의 미사용 제한(재고 설계 담당자 확정 후), 불용창고 기능 자체 변경.

## 완료 조건
- 창고 화면에서 사용여부를 바꿔 저장하면 미사용이 되고, 기본 조회에는 사용 중인 창고만 나오며 상세검색 "사용여부"(사용/미사용/전체)로 바꿀 수 있다.
- 삭제 시도 안내가 "미사용으로 변경해 주세요"로 바뀌고, 미사용 창고는 구매 확정 등 창고 선택 목록에 나오지 않는다. 이미 저장된 전표의 창고명 표시는 그대로다.
- 관련 백엔드·프론트 테스트, `tsc`, `f1-grid-storage-keys` 통과, 실서버·브라우저 확인, DB 스크립트(적용 전 상태로 사용자 적용 요청)·db-schema.md·결과 문서 작성.
