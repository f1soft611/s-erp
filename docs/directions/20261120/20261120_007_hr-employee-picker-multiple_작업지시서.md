# 20261120_007 사원 선택 도움창 다중 선택 옵션 작업지시서

## 배경
사원 선택 도움창([20261120_003](../../spec/20261120/20261120_003_hr-employee-picker_상세사양서.md))은 한 명만 고른다. 참석자·공유 대상처럼 **여러 사원을 골라 한 번에 적용**하는 화면이 있어 옵션으로 다중 선택을 지원한다. 도움창 크기 고정(빈 목록 안내 제거)은 같은 날 반영했다.

## 결정 (사용자 요청, 2026-11-20)
- 단일/다중을 옵션(`selectionMode`)으로 두고 기본은 지금처럼 단일. 다중은 체크박스로 고르고 "N명 적용"으로 확정한다. 다중에서는 더블클릭으로 바로 적용하지 않는다.
- 부서·검색어를 바꿔도 선택은 유지한다. 받는 값은 단일과 같은 형태의 배열이다. 초기 선택값과 최대 인원 제한 옵션을 둔다.

## 범위·완료 조건
- 포함: 도움창 컴포넌트·타입, 테스트, 문서. 제외: 다중 선택을 쓰는 화면(아직 없음), 서버(변경 없음).
- 단일 사용(창고 담당자)은 동작이 변하지 않는다. 다중은 선택 유지·초기값·최대 인원·적용/취소가 테스트로 검증된다. 관련 테스트·`tsc`·`f1-grid-storage-keys` 통과.
