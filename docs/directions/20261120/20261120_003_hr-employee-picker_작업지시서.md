# 20261120_003 사원 선택 도움창 작업지시서

## 배경
인사 공용 선택 도움창 2종 중 ① 부서 선택 도움창은 1단계에서 만들었고([20261119_008](../../result/20261119/hr-department/20261119_008_인사관리_부서관리_결과.md)), ② **부서 조회 → 사원 선택 도움창**은 사원등록(2-1) 이후에 만들기로 했다. 구 MES의 "임직원조회" 도움창(좌측 부서 트리, 우측 사원 목록)을 참고한다.

## 결정 (사용자, 2026-11-20)
- 좌측에 회사 > 부서 트리, 우측에 사원 목록. 부서를 클릭하면 **그 부서 소속 사원만**(하위 부서 사원은 제외) 나오고, 최상단 **회사를 클릭하면 전체 인원**이 나온다.
- 우측 목록 항목은 **사원 이미지, 부서명, 직위, 사번, 사원명**. 통합검색을 둔다.
- 사원 행을 **더블클릭**하면 그 사원이 선택되고 창이 닫힌다.
- 호출한 쪽에 전달하는 데이터는 **부서 ID, 부서명, 사원 ID, 직위 코드, 직위명, 사번, 사원명**이다. 사원을 고르면 부서까지 같이 설정하는 경우(창고등록의 담당자 선택 등)가 많아 부서 정보를 함께 준다. 항목은 나중에 늘 수 있다.
- 일반 사용자도 쓰는 화면(창고 담당자 등)에서 호출하므로 관리자 전용이 아니어야 하고, 개인정보(연락처·주민번호·주소 등)는 내려주지 않는다.
- 이번에는 도움창과 서버 API까지만 만들고 기존 화면에는 연결하지 않는다(부서 선택 도움창과 같은 방식).

## 기본 규칙 (사용자가 별도 지정하지 않아 기존 기준을 따름)
- 퇴직자는 제외하고 휴직자는 포함한다(부서관리 소속 사원 조회와 같은 기준).
- 부서가 지정되지 않은 사원은 회사를 클릭했을 때만 나온다.
- 통합검색은 사원명·사번·직위·부서명에 적용하며 현재 선택한 트리 항목 안에서 찾는다.

## 완료 조건
- 부서 클릭 시 소속 사원, 회사 클릭 시 전체 재직 인원이 나오고 통합검색이 동작한다.
- 더블클릭 시 위 7개 값이 전달되고 창이 닫힌다. 일반 사용자 권한으로도 조회된다.
- 응답에 연락처·주민번호·주소가 없다. 백엔드 `mvn test`, 프론트 관련 테스트·`tsc`·`f1-grid-storage-keys`, 375/768/1280px 브라우저 확인, DB MCP 확인 근거 기록.
