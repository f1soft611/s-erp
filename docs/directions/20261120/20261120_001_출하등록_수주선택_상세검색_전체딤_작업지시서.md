# 출하등록 수주 선택 상세검색 전체 딤 작업지시서

## 목적

수주 선택 모달에서 상세검색을 열 때, 딤 오버레이 범위와 색상을 출하현황 상세검색과 동일하게 맞춘다.

## 작업 범위

- 상세검색 폼은 선명하게 유지한다.
- 수주 선택 모달의 제목, 본문, 하단 액션 영역 전체를 `PageSearchArea`의 현황 화면 backdrop과 같은 `rgba(15, 23, 42, 0.12)`로 딤 처리한다.
- 모달 바깥 화면에는 상세검색 때문에 새 딤을 추가하지 않는다. 기존 CommonDialog backdrop은 유지한다.
- 상세검색이 열린 동안 그리드 `inert` 동작을 유지한다.
- 기능 동작 문서, 테스트, 반응형 스크린샷을 갱신한다.

## 완료 조건

- 회귀 테스트가 기존 본문 한정 딤 구현에서 실패하고 전체 모달 딤 구현에서 통과한다.
- 상세검색 패널만 선명하며 제목·그리드·하단 액션 영역은 동일 색상으로 덮인다.
- 375px, 768px, 1280px 브라우저 확인과 대상 테스트, 빌드, lint를 완료한다.
