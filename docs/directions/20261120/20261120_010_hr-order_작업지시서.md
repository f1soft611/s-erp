# 20261120_010 인사명령(인사관리 3단계) 작업지시서

## 배경
인사관리는 1단계 부서관리, 2단계 사원관리(등록·계정)까지 끝났다. 3단계로 사원의 부서이동·승진·휴직·퇴직 같은 **인사명령을 처리하고 이력을 남기는 화면**을 만든다. 기준은 MES 인사명령처리(WHR902_VW)·인사명령코드 등록(WHR901_VW)이며, 저장 로직은 MES 프로시저(`SP_WHR902_02_IUD` 등)에서 확인했다.

## MES 동작 요약 (SP 확인 결과)
- 명령코드 마스터(TIN535): 명령항목, 변경항목(사원 마스터 컬럼명), 입력형태, 참조 테이블. 21종.
- 저장(`SP_WHR902_02_IUD`): 명령 내역(TIN536) INSERT → 사원 마스터(TIN114)의 해당 컬럼 즉시 UPDATE → 변경된 사원 한 행 전체를 이력(TIN125)에 스냅샷 INSERT. 신규 등록 시 "ERP신규등록·입사" 두 행 자동 생성.
- 내역 삭제(`SP_WHR902_03_IUD`)는 삭제 표시만 하고 사원 정보는 되돌리지 않는다. 명령 전 값은 화면이 채워 보낸다.
- 화면은 사원마다 행을 만들고 행마다 명령항목·명령 후 값을 도움창으로 고르는 방식이라 복잡하다.

## 결정 (사용자 확인, 2026-11-20)
- **즉시 처리**(예약 반영은 후속). 명령일은 오늘 포함 과거만 입력할 수 있다.
- **사원관리에서 직접 수정해도 이력을 자동으로 남긴다.** 인사명령 처리도 같은 사원 서비스를 거쳐 한 곳에서 기록한다.
- 명령 유형은 **현재 구현된 사원 항목 기준**으로 시작하고 점차 추가한다.
- 정정은 삭제·취소 없이 **반대 명령**으로 한다. 이력은 수정·삭제하지 않는다.
- MES의 사원 전체 스냅샷(TIN125)은 만들지 않는다(변경항목별 명령 전/후 값으로 추적).
- 화면은 **명령 입력 줄 + 다중 사원 선택 + 적용 전 확인표 + 발령 처리 버튼**이고, **처리 내역은 탭으로 나눠** 보여 준다.

## 범위
- 포함: 이력 테이블(헤더·상세)·메뉴 DB 스크립트, 서버(유형 목록·발령 처리·이력 조회·직접 수정/신규 등록 자동 이력), 인사명령 화면(처리 탭·처리 내역 탭), 테스트, 문서.
- 제외: 예약 발령, 명령코드 마스터 관리 화면, 사업장·파견·직무·호봉 등 우리 사원에 없는 항목, 이력 취소·삭제, 기존 사원의 과거 이력 소급 생성.

## 완료 조건
- 인사정보 > 인사명령 메뉴에서 사원을 여러 명 골라 부서이동·승진·승급·근무형태변경·휴직·복직·퇴직을 한 번에 처리하고, 사원 정보가 바뀌며 처리 내역 탭에서 명령 전/후 값이 조회된다.
- 사원관리에서 부서·직위 등을 수정하거나 사원을 신규 등록해도 이력이 자동으로 남는다.
- 백엔드·프론트 테스트, `tsc`, `f1-grid-storage-keys` 통과, DB 스크립트·`db-schema.md`·결과 문서·스크린샷 작성, 실서버 확인.
