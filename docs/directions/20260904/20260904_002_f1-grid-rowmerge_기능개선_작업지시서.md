# 작업지시서

## 제목

F1-Grid Row Merge 범위 규칙 개선

## 작업 분류

- 경로: `bounded`
- 사유: 공통 F1-Grid의 row merge 계산 로직을 개선하고, 기존 화면 예제와 테스트를 통해 동작을 검증한다. 새로운 화면 구조나 API를 도입하지 않고 기존 그리드 동작만 보완한다.

## 배경

F1-Grid는 `mergeRows`를 사용해 연속된 같은 값을 하나의 시각적 그룹으로 표시한다. 현재 구현은 단순히 인접 행에서 동일 값 여부만 비교하기 때문에, 상위 컬럼의 병합 영역과 하위 컬럼의 병합 영역이 서로 겹치거나 이전 그룹 경계를 무시하는 문제가 발생한다. 특히 품목명과 품목분류처럼 상하위 의미를 가진 컬럼이 함께 병합되면 값이 동일해도 서로 다른 상위 그룹 사이에서는 병합이 이어져 버린다.

## 목표

1. 같은 컬럼의 병합은 이전 컬럼의 merge 범위를 기반으로 제한한다.
2. 이전 컬럼이 서로 다른 merge 그룹에 속하면 동일한 값이어도 하위 컬럼은 병합하지 않는다.
3. 하위 컬럼의 merge span이 상위 merge 영역을 넘어서는 일이 없도록 한다.
4. F1-Grid 테스트와 데모 페이지의 행 병합 예시를 함께 검증하고 결과 문서에 회귀 케이스를 남긴다.

## 요구사항

- `mergeRows` 컬럼은 직전 merge 대상 컬럼의 merge 범위를 기준으로 계산한다.
- 동일한 값이라도 이전 컬럼의 merge 그룹이 다르면 자기 컬럼 merge를 하지 않는다.
- merge group은 상위 그룹의 경계를 벗어나지 않아야 한다.
- 행 병합은 값이 연속적이더라도 상위 그룹 기준으로 분리되어야 한다.
- 기존 비merge 컬럼과 다른 일반 동작은 그대로 유지한다.

## 제외 범위

- F1-Grid 설계 전체 재설계
- 서버 API 변경
- 다른 화면별 비즈니스 로직 변경

## 완료 기준

- 품목명 그룹이 분리된 경우 품목분류 값이 같아도 merge span이 이어지지 않는다.
- 하위 컬럼의 merge span이 상위 merge 범위를 침범하지 않는다.
- 관련 Vitest 케이스가 통과하고 결과 문서에 재현/해결 내용이 남는다.
