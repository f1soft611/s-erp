# 공통 소수점 계약 가드레일 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [영업 소수점 후속 검증 결과](../../result/20261125/sales-decimal-verification/20261125_001_영업소수점_후속검증_작업결과.md)

## 요청

1. 소수점은 정책이 필수로 적용되고, 계약 JSON(`decimal-column-contract.json`)에 컬럼 설정이 있으면 그 설정이 우선해 프론트와 서버가 같은 값으로 계산·저장한다.
2. JSON 변경을 놓치지 않도록 막는다.
3. JSON에 없는 컬럼에 화면 코드로 직접 소수점을 설정하거나 고정값을 쓰는 것을 막는다. 소수점은 JSON에서만 정한다.
4. 이 규칙을 영업 외 다른 모듈에도 적용할 수 있게 공통 정책으로 만들고, 다른 개발자가 놓치지 않게 한다.

## 완료 기준

- 계약 JSON의 값 오류가 빌드·테스트 단계에서 실패한다.
- 컬럼별 최종 규칙이 골든 파일과 달라지면 테스트가 실패해 변경이 diff로 드러난다.
- 계약의 필드와 서버·화면이 쓰는 필드가 어긋나면 테스트가 실패한다.
- 가드 대상 폴더에서 소수점 직접 설정이나 고정 자릿수가 발견되면 테스트가 실패한다.
- 정책이 로드되기 전에는 고정 대체값 대신 로딩 상태를 표시한다.
- 신규 모듈 적용 절차가 프론트·백엔드 가이드에 문서화된다.
