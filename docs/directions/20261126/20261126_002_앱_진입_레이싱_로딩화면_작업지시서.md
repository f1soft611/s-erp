# 앱 진입 레이싱 로딩 화면 작업지시서

- 작성일: 2026-11-26
- 디자인 확정본: 대화에서 승인한 컴팩트 미리보기 (F1Soft 레이싱카 스플래시)

## 요청

1. 새로고침하면 앱이 뜨기 전까지 빈 흰 화면이 보인다. 이 화면 가운데에 로딩 표시를 넣는다.
2. 로딩 표시는 에프원소프트 상징인 F1 레이싱카가 빠르게 달리는 모션으로 만든다.
3. 화면 전체는 단색 배경으로 채우고, 내용(로고·레이싱카·진행바·문구)은 가운데에 작게 둔다.
4. 로딩이 빨리 끝나면(300ms 이내) 스플래시가 보이지 않아야 한다.

## 완료 기준

- 새로고침 직후 JS 번들이 로드되기 전에도 스플래시가 표시된다(`index.html`에 정적으로 포함).
- 라우트 화면(lazy 페이지)이 실제로 그려진 뒤에 스플래시가 사라진다. 사라질 때 짧게 페이드아웃한다.
- 300ms 안에 앱이 준비되면 스플래시가 눈에 보이지 않는다.
- 저장된 앱 테마(`erp-theme`)가 dark면 스플래시도 어두운 배경으로 표시한다.
- `prefers-reduced-motion`에서는 애니메이션이 멈춘다.
- 어떤 이유로 앱이 준비 신호를 보내지 못해도 스플래시가 화면을 영구히 덮지 않는다(안전 해제).
- 375/768/1280px에서 가로 스크롤과 겹침이 없다.
