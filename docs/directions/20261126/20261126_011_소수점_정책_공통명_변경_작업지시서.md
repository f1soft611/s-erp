# 소수점 정책 공통명 변경 작업지시서

- 작성일: 2026-11-26
- 근거: Flow 글 `[의논] 구매자재 적용 전 확인 요청`(postId 88794036)에 대한 답변. 구매자재가 서버 소수점 정책을 쓰려면 영업 전용 이름인 `SalesDecimalPolicy`를 공통명으로 바꿔 먼저 main에 반영해야 한다.

## 요청

`egovframework.let.sales.common.SalesDecimalPolicy`를 모듈 중립 이름 `egovframework.com.cmm.DecimalPolicy`로 바꾼다. 동작은 바꾸지 않는다.

## 완료 기준

- `SalesDecimalPolicy` 클래스가 소스에 남아 있지 않고 모든 호출부가 `DecimalPolicy`를 쓴다.
- 영업 호출부는 `DecimalPolicy.forModule("SALES", …)`로 영업 정책 키를 명시한다. 기본값이 `SALES`인 `from()`은 없앤다.
- 정책 값·검증·오류 메시지·API·DB는 변경 전과 같다.
- 기존 서버 테스트가 통과하고 Java 8 호환 컴파일을 확인한다.
- 가드 테스트 검사 경로(`purchase` 추가)는 이번 범위가 아니며 구매 쪽에서 진행한다.
- 현재 지침(`backend/AGENTS.md`, `F1-GRID.md`)이 새 이름을 가리킨다. 과거 날짜별 문서는 당시 이력이므로 고치지 않는다.
