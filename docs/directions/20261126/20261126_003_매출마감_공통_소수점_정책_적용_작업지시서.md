# 매출마감 공통 소수점 정책 적용 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [공통 소수점 계약 가드레일](20261126_001_공통_소수점_계약_가드레일_작업지시서.md)

## 요청

매출마감 화면(`sales/revenue/closing`)도 영업의 다른 화면과 같이 공통 소수점 정책과 계약 JSON을 따르게 하고, 가드 테스트에 포함해 마무리한다.

## 완료 기준

- 매출마감의 수량·매출금액·부가세·합계가 화면에 직접 쓴 타입·소수점 설정이 아니라 계약 JSON(정책 + 컬럼 예외)으로 표시된다.
- 계약 컬럼에 예외를 넣으면 매출마감 화면에도 반영된다.
- 가드 테스트가 매출마감 폴더의 직접 설정을 막는다.
- 서버 변경이 필요한지 근거와 함께 판단해 기록한다.
