# 그룹웨어 공통 소수점 정책 적용 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [기준정보 공통 소수점 정책 적용](20261126_006_기준정보_공통_소수점_정책_적용_작업지시서.md)

## 요청

그룹웨어(`GROUPWARE`) 모듈도 공통 소수점 정책을 따르게 한다. 그룹웨어에는 단가·금액 컬럼이 없고, 컬럼 예외도 두지 않는다.

## 완료 기준

- 그룹웨어의 숫자 값(첨부 수, 파일 크기)이 계약 JSON과 정책으로 결정되고, 화면에 직접 쓴 자릿수(`toFixed`)가 없다.
- 가드 테스트가 그룹웨어 화면 폴더를 검사한다.
- 서버 변경 필요 여부를 근거와 함께 기록한다.
