# 기준정보 공통 소수점 정책 적용 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [환경설정 공통 소수점 정책 적용](20261126_005_환경설정_공통_소수점_정책_적용_작업지시서.md)

## 요청

기준정보(`COMMON`) 모듈도 우선 정책을 그대로 따르게 한다. 컬럼 예외는 두지 않고, 나중에 필요할 때 계약 JSON으로 추가한다. 숫자 컬럼은 수량, 단가, 금액 기준으로 분류하고, 서버도 같은 규칙으로 검증·저장한다.

## 완료 기준

- 기준정보 숫자 컬럼의 타입이 수량(`number`)·단가(`decimal`)·금액(`currency`) 기준으로 계약 JSON에 정의되고, 화면에 직접 쓴 소수점 옵션이 없다.
- 서버가 단가·최소주문수량·안전재고·중량·소비기한 숫자를 `COMMON` 정책의 자릿수로 검증하고 정책 값으로 저장한다.
- 가드 테스트가 기준정보 화면 폴더와 서버 사용 필드를 검사한다.
- 작업표준(레시피)은 이번 범위에 포함하는지 여부를 결과 문서에 기록한다.
