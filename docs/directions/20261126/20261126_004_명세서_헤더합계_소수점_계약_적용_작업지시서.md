# 거래명세서 헤더 합계 소수점 계약 적용 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [매출마감 공통 소수점 정책 적용](20261126_003_매출마감_공통_소수점_정책_적용_작업지시서.md)

## 요청

거래명세서 발행 저장도 출하와 같은 소수점 규칙으로 계산·저장한다. 현재 명세서 헤더 합계는 서버 SQL이 출하 상세 `total_amt`를 단순 합산해 저장해서, 출하 합계(`deliveryTotal`)에 예외를 넣으면 출하 헤더 합계와 달라질 수 있다.

## 완료 기준

- 명세서 헤더 합계가 출하 헤더 합계와 같은 규칙(`sales.delivery.deliveryTotal`: 정책 + 컬럼 예외)으로 계산되어 저장된다.
- 명세서 상세 행은 출하 상세 값을 그대로 복사하는 기존 동작을 유지한다.
- 정책 조회 실패나 규칙 오류 시 명세서가 저장되지 않는다.
- 스키마 변경은 없다.
