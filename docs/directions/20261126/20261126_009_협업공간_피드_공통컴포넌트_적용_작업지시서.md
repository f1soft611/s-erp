# 협업공간 피드 공통 컴포넌트 적용 작업지시서

- 작성일: 2026-11-26
- 선행: [20261126_008 협업공간 프론트엔드](20261126_008_협업공간_프론트엔드_작업지시서.md)

## 요청 배경

- 사용자 지시(2026-11-26): "피드 리스트 퀄리티를 문서작성 피드 리스트와 동일한 패턴으로 보여줘. 첨부파일도, 이미지도, 댓글도 마찬가지."
- 현재 협업공간 피드는 자체 제작한 카드·댓글(일반 텍스트)이라 문서작성 피드(`DocumentApprovalDetailFeed`)와 모양과 기능이 다르다.
- 기준 화면: 문서작성 피드 리스트(`documents/write`). 이 화면은 공통 피드 컴포넌트(`shared/components/feed`)를 조합한다.

## 추가 지시 (2026-11-26, 같은 작업 중 사용자 확인)

- 화면 구조는 문서작성 화면(목록 영역)을 그대로 옮긴다: 헤더 우측 상단의 작업 버튼, 좌측 보기 전환 툴바와 목록, 우측 요약 패널, 행 클릭 시 우측 상세 패널.
- 보기 방식은 칸반(신규), 피드, 리스트, 첨부(파일형)로 한다.
- 새 글 버튼은 헤더 우측 상단으로 올리고(문서작성의 `문서 작성` 버튼과 같은 위치), 같은 레이아웃 컴포넌트(`ContentSplitLayout`, `PinnedViewToolbar`, `FeedView`, `ListView`, `FileView`, `PageAreaOverlay`)를 쓴다.
- 칸반 카드를 눌러도 리스트·피드와 같이 우측 상세 패널이 열린다.
- 우측 요약 패널은 제거하고, 우측 패널 맨 위에 개발용 사용자 전환, 그 아래에 내 협업방 목록과 방 만들기를 둔다.
- `글 N건`의 필터(내가 쓴 글·검색)는 문서작성의 필터 아이콘을 눌렀을 때 나오게 하고, 컬럼 설정 버튼은 우측 보기 버튼의 왼쪽에 둔다.

- 칸반 컬럼 색상: 방 설정에서 컬럼마다 색을 지정하고, 사용자는 컬럼 설정에서 자기 화면의 색만 따로 바꿀 수 있다. 색 선택은 문서작성(서식 에디터)의 글자색 팔레트(기본 색상, 견본 12색, 최근 색상)를 따른다.
- 우측 상세 패널은 피드와 완전히 같은 카드로 그린다(아바타·작성자·날짜·상태 배지·제목·본문·첨부·반응·댓글).

## 작업 범위

- 협업공간 피드 보기와 카드 상세를 `FeedCard`, `FeedBodyContent`(더보기·본문 이미지 미리보기), `AttachmentList`(파일 아이콘·이미지 미리보기·내려받기), `FeedReactionBar`, `FeedCommentsSection`, 공통 `CommentThread`(서식 댓글·파일 첨부·수정·삭제), `ImageViewerDialog`로 교체한다.
- 글 작성창의 본문을 공지·문서작성과 같은 서식 에디터(`RichTextEditor`, 이미지 삽입 포함)로 바꾸고, 첨부 목록을 `AttachmentList`(편집 모드)로 보여준다.
- 데이터 계약안 변경: 글 본문은 서식(HTML), 첨부에 미리보기·내려받기용 데이터(작은 파일만), 댓글은 서식 본문·첨부·삭제 표시·수정.

## 제외 범위

- 칸반 카드 모양, 방 설정, 권한 그룹, 메뉴 seed
- 백엔드 API·DB, 실제 파일 저장소, 멘션, 링크 미리보기, 좋아요·북마크의 저장(문서작성 피드와 같이 화면 상태만)

## 완료 기준

1. 피드 보기의 카드 구성(아바타·작성자·메타·상태 배지·제목·본문 더보기·첨부·반응 줄·댓글)이 문서작성 피드와 같은 공통 컴포넌트로 그려진다.
2. 본문 이미지가 접힘 상태에서는 미리보기 줄로, 펼치면 본문 안에 보이고, 클릭하면 이미지 뷰어가 열린다.
3. 첨부 파일은 종류별 아이콘으로 보이고 이미지 첨부는 미리보기가 보이며, 내려받기를 지원하지 않는 파일은 안내를 보여준다.
4. 댓글은 공통 댓글(서식, 파일 첨부, 답글, 본인 댓글 수정·삭제)로 동작하고, 읽기 전용·메뉴 권한 없는 사용자는 입력할 수 없다.
5. 칸반 카드를 열었을 때의 상세도 같은 본문·첨부·댓글 구성이다.
6. 375/768/1280px에서 가로 스크롤과 겹침이 없다. 테스트·타입 검사·브라우저 검증과 결과 문서.
