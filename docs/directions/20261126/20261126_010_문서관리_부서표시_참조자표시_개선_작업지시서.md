# 문서관리 부서 표시·참조자 표시 개선 작업지시서

- 작성일: 2026-11-26

## 요청 배경

- 사용자 지시(2026-11-26): 사용자별로 부서가 설정되어 있는데 문서관리에서 부서가 표시되지 않는다. 점검 필요.
- 문서 작성 시 참조자를 여러 명 선택하면 칩이 본문 영역과 겹친다. 참조자를 100명 넣어도 문제없어야 하며, 전부 펼쳐 표시하는 것도 문제가 있다.
- 문서 상세의 참조자 표현도 같은 기준으로 검토한다.
- 후속 확인: 사용자가 "요약 표시 + 목록 다이얼로그 + 부서별 묶음" 방향에 동의했다.

## 점검 결과 (DB MCP `s-erp-postgresql-readonly` 확인)

- `tb_user.department_id` → `tb_department` 조인으로 부서명은 정상 조회된다(테넌트 1: 39/39명).
- `tb_electronic_approval_line_info.participant_department_name`은 결재선 저장 시점의 복사본이며 현재 144건이 모두 비어 있다(사용자 부서를 나중에 지정한 것으로 추정).
- `selectApprovalLines`(문서 상세)는 복사본만 읽어 `부서없음`으로 표시한다.
- 작성 화면 참조자 칩(`UserSelectEditor`)은 이름만 그리고 부서는 드롭다운 옵션에만 표시한다.
- 참조 입력 영역은 `height: 40px` 고정이라 칩이 여러 줄이면 본문과 겹친다.

## 작업 범위

1. 백엔드: 결재선 조회(`selectApprovalLines`)에서 `tb_department`를 조인해 현재 부서명을 우선하고, 없으면 저장된 복사본을 사용한다. DB 변경 없음.
2. 작성 화면: 참조자 칩 줄 수를 제한하고 `+N명`으로 접는다. 선택 목록 다이얼로그(검색, 부서별 묶음, 개별 삭제)를 제공한다. 고정 높이로 인한 겹침을 없앤다.
3. 문서 상세: 참조자를 요약(`참조 N명`)과 접힘/펼침 부서별 묶음 목록으로 표시하고, 100명에서도 화면이 길어지지 않게 한다.

## 제외 범위

- 부서 단위 일괄 추가 기능(사용자 요구 확정 전, 별도 작업).
- 저장된 복사본 컬럼의 이관·삭제.
- 결재/합의 단계 표시 변경.

## 완료 기준

- 부서가 지정된 사용자의 참조·결재 표시에 부서명이 나온다.
- 참조자 100명 선택 시 작성 화면 겹침이 없고 입력창 높이가 유지된다.
- 상세에서 참조자 100명이 요약으로 접혀 있고 펼치면 부서별로 확인된다.
- 관련 테스트와 `tsc -b`, 백엔드 테스트 통과, 375/768/1280px 브라우저 검증.
