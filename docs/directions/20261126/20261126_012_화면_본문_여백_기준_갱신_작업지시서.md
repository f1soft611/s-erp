# 화면 본문 여백 기준 갱신 작업지시서

- 작성일: 2026-11-26
- 근거: Flow 글 `[의논] 구매자재 적용 전 확인 요청`(postId 88794036) 2항. 영업 수주등록 코드는 본문 여백이 16px인데 `frontend/AGENTS.md`는 `xs:1 / sm:2`, 상단 1, 하단 2로 남아 있었다.

## 요청

16px(MUI spacing 2)를 최종 기준으로 확정하고 `frontend/AGENTS.md`를 갱신한다.

## 완료 기준

- AGENTS.md가 모든 폭에서 좌우·상단·하단 `2`를 기준으로 적는다.
- 적용 범위를 등록·현황 화면 본문으로 하고 embedded는 0 유지, 선택창·상세 대화상자(`CommonDialog` 자체 패딩)는 제외로 명시한다.
- 코드 변경은 없다. 구매·품질·인사 화면 적용은 모듈별 별도 작업으로 한다.
