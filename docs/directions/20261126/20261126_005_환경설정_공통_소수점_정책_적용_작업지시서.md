# 환경설정 공통 소수점 정책 적용 작업지시서

- 작성일: 2026-11-26
- 선행 작업: [공통 소수점 계약 가드레일](20261126_001_공통_소수점_계약_가드레일_작업지시서.md)

## 요청

환경설정(모듈·메뉴·역할 관리)의 숫자 컬럼(정렬 순서, 메뉴 수 등, 순번 제외)에서 컬럼에 직접 쓴 소수점 옵션을 모두 제거하고 정책을 따르게 한다. 환경설정 정책의 number는 0자리인데 정렬 입력에 소수점이 입력되는 문제를 해결한다.

## 완료 기준

- 환경설정 숫자 컬럼의 타입과 소수점 규칙이 계약 JSON과 정책으로 결정되고, 화면에 직접 쓴 소수점 옵션이 없다.
- 정수 정책(0자리)에서 정렬 순서 입력에 소수점(`.`, `,`)이 입력되지 않는다.
- 값이 문자열로 확정되어도 저장 요청에는 숫자로 전달된다.
- 가드 테스트가 환경설정 화면 폴더를 검사한다.
