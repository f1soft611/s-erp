# 20261007_006 문서작성 결재 표/합의 칩 배치 작업지시서

## 목적

문서작성 모달의 승인 결재선 표시를 승인된 컴팩트 용량 설계에 맞춘다. 결재 입력, 결재 그리드, 필요 시 합의 칩, 참조 입력을 순서대로 표시하고 실제 모달 콘텐츠 너비에 맞춰 빈 결재 슬롯과 줄바꿈을 제공한다.

## 승인된 요구사항

- 첫 `결재선` 행에는 다중 사용자 선택 필드와 `결재 추가`, `합의 추가` 버튼을 배치한다.
- 행 순서는 `결재선`, `결재`, 합의 참여자가 한 명 이상일 때만 `합의`, `참조`로 한다.
- `결재` 그리드는 실제 모달 콘텐츠 너비에 맞춰 빈 슬롯까지 미리 채운다. 슬롯 최소 너비는 80px, 간격은 4px이다. 그리드를 `ResizeObserver`로 관찰하고 첫 행 수용량을 `max(1, floor((contentWidth + 4) / 84))`로 계산한다. 확정 결재자가 수용량을 넘으면 뒤의 결재자는 다음 행으로 감싼다.
- 빈 결재 슬롯에는 눈에 덜 띄는 도장 영역만 표시하고 순번 배지나 삭제 동작은 표시하지 않는다.
- 확정 결재 슬롯은 직위/직함과 도장 영역을 유지하고, 이어서 작고 부드러운 파란색 원형 전역 순번 배지, 한글 약 3자 기준으로 말줄임되는 이름, 해당 사용자별 삭제 동작을 표시한다. 보조 기술과 title/tooltip을 통해 전체 이름을 제공하고, 삭제 액션의 접근성 이름은 대상 사용자와 순번을 식별한다.
- 합의 행은 참여자가 없으면 렌더링하지 않는다. 참여자가 있으면 한 명당 연회색 컴팩트 칩을 표시하며, 동일한 전역 원형 배지, 약 3자 기준 말줄임 이름, 도장 자리, 개별 삭제를 포함한다. 삭제 액션은 대상 사용자와 순번을 식별하며, 아바타나 단계 종류 문구는 표시하지 않는다.
- 결재와 합의 참여자는 기존 단계/사용자 순서에 따른 하나의 전역 순번을 공유한다. 개별 삭제 후 순번을 다시 계산하고 후보를 복원한다. 합의 마지막 인원 삭제 시 빈 합의 단계를 제거한다.
- 기존 `참조` 행과 참조 선택 동작은 그대로 유지한다.
- 공유 에디터, 선택기, 다이얼로그, API, 라우트, 백엔드 및 DB는 범위에서 제외한다.

## 작업 절차

1. 승인된 컴팩트 용량 설계 및 날짜별 계획서/상세 사양서를 확인한다.
2. 결재 그리드 수용량/빈 슬롯 및 합의 행 조건부 표시 회귀 테스트를 작성한다.
3. 실제 콘텐츠 너비를 관찰하는 결재 그리드, 빈 슬롯과 확정 결재 참여자 표시를 구현한다.
4. 합의 칩, 전역 순번, 개별 삭제, 후보 복원 및 마지막 합의 단계 정리를 구현한다.
5. 집중 테스트, 린트, 프론트엔드 빌드 및 375px/768px/1280px 브라우저 검증을 수행한다.
6. 캡처와 결과 기록이 필요한 경우 실제 사용자 식별정보나 문서 본문 없이 합성 이름만 사용한다.

## 완료 기준

- 행 순서는 `결재선 → 결재 → (합의 참여자가 있을 때만) 합의 → 참조`이다.
- 그리드 콘텐츠 너비를 관찰해 첫 행 수용량을 공식으로 계산하고, 최소 80px 슬롯/4px 간격 및 빈 슬롯 채우기를 적용한다. 수용량을 넘는 결재자는 다음 행으로 감싼다.
- 빈 슬롯은 도장 영역만 포함한다. 채워진 결재 및 합의 항목은 전역 배지/말줄임 이름/개별 삭제를 갖고 전체 이름은 접근 가능하며 title/tooltip에서 확인할 수 있다.
- 마지막 합의자 삭제 시 합의 단계가 제거되고, 삭제한 사용자는 후보로 복원되며 나머지 전역 번호는 재계산된다.
- 참조 선택은 그대로 유지된다. 375px/768px/1280px에서 브라우저 검증을 하고, 개인정보 없는 합성 이름만 캡처에 사용한다.
