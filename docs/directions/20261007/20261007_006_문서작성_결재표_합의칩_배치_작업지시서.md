# 20261007_006 문서작성 결재 표/합의 칩 배치 작업지시서

## 목적

문서작성 모달에서 결재 입력 행과 확정 결재/합의 표시를 분리하고, 결재는 표형 그리드, 합의는 사용자별 칩으로 표현한다.

## 승인된 요구사항

- 첫 `결재선` 행에는 다중 사용자 선택 필드와 `결재 추가`, `합의 추가` 버튼을 배치한다.
- 별도 `결재` 행은 확정된 결재자 각각을 표형 열로 표시한다. 각 열은 직위, 도장 영역, 순번/이름, 개별 삭제(X)를 포함한다.
- 별도 `합의` 행은 확정된 합의자 각각을 연회색 칩으로 표시한다. 각 칩은 전체 결재 순번, 이름, 도장 자리, 개별 삭제(X)를 포함하며 아바타와 구분 문구는 표시하지 않는다.
- 결재 표의 열과 합의 칩은 가로 공간이 부족하면 다음 줄로 wrap하며 전체 페이지의 가로 넘침을 만들지 않는다.
- 기존 `참조` 행과 참조 선택 동작은 그대로 유지한다.
- 다중 선택 순서, 결재/합의 그룹 데이터, 후보 제외/복원 및 기존 선택 동작을 유지한다. 합의 칩 개별 삭제는 해당 사용자만 합의 그룹에서 제거하며 마지막 사용자를 지우면 해당 빈 그룹을 제거한다.
- 결재 및 합의 사용자를 하나의 전역 순서로 번호 매겨 삭제 후 순번을 다시 계산한다.

## 작업 절차

1. 승인된 표시 레이아웃 설계에 맞춰 날짜별 계획서 및 상세 사양서를 기록한다.
2. 테스트에서 4행 구조, 결재 표, 합의 개별 칩/삭제, 전역 순번과 wrap 동작을 먼저 검증한다.
3. `DocumentApprovalFields`의 확정 표시 행을 결재 표형 그리드와 합의 wrap 칩으로 구현한다.
4. 합의자 개별 삭제 시 hook 상태와 후보 복원 동작을 갱신한다.
5. 집중 테스트, 린트, 프론트엔드 빌드 및 375/768/1280px 브라우저 검증을 수행한다.
6. 민감한 사용자 정보를 포함하지 않는 화면 캡처와 관찰 결과를 날짜별 결과 문서에 기록한다.

## 완료 기준

- 화면에 `결재선 → 결재 → 합의 → 참조` 라벨 행이 표시되고 확정 참여자는 입력 행과 분리된다.
- 각 결재자는 직위/도장/순번·이름과 삭제 동작이 있는 표 열에 표시된다.
- 각 합의자는 전역 순번/이름/도장/X만 있는 개별 회색 칩에 표시된다.
- 결재 표와 합의 칩은 좁은 너비에서 다음 줄로 wrap한다.
- 합의자 하나를 삭제해도 같은 합의 그룹의 다른 참여자는 유지되며, 마지막 참여자 제거 시 그룹이 제거된다. 후보와 전역 순번은 올바르게 갱신된다.
- 기존 참조 선택이 유지되고, 375px/768px/1280px에서 문서 전체 가로 넘침이 없다.
