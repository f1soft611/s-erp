# 20261007_002 문서작성 결재선 입력 필드 공간 개선 작업지시서

## 목적

문서작성 모달에서 결재선과 참조선을 정렬된 두 행으로 배치하고, 확정된 결재·합의 단계는 사용자 정보와 도장 및 삭제 동작이 하나로 묶인 간결한 항목으로 표시한다.

## 승인된 요구사항

- `결재선` 라벨은 왼쪽에 두고, 오른쪽 영역에는 확정 단계 항목과 마지막 사용자 선택 입력을 같은 행으로 순서대로 배치한다.
- 각 결재 항목은 `순번 + 프로필 이미지 + 이름/부서 + 도장 자리 + 삭제(X)`를 하나의 카드로 표시한다. 확정 사용자를 읽기 전용 선택기나 칩으로 표시하지 않는다.
- 확정 카드와 사용자 선택 필드, `결재 추가`/`합의 추가` 버튼의 높이를 같게 맞춘다. 카드 안의 프로필과 도장은 해당 높이를 넘지 않는다.
- `결재 추가`는 선택된 각 사용자를 선택 순서대로 개별 결재 단계 카드로 추가한다.
- `합의 추가`는 선택된 모든 사용자를 하나의 합의 단계 카드에 함께 표시한다.
- 마지막 입력에서만 사용자를 선택하고, `결재 추가` 또는 `합의 추가` 버튼으로 확정한다. 입력값이 비어 있으면 두 버튼은 비활성이다.
- 카드의 삭제(X)는 해당 결재 또는 합의 단계 전체를 제거한다. 제거 후 남은 단계의 순번을 갱신하고 제거된 사용자는 선택 후보로 돌려준다.
- 확정 단계에 등록된 사용자는 활성 결재선 입력 후보에서 제외한다.
- `참조` 라벨은 결재선 바로 아래 행의 왼쪽에 두고, 오른쪽에는 별도의 다중 선택 입력 하나를 배치한다. 선택된 참조자는 입력 안에 표시하며 결재선과 중복을 제한하지 않는다.
- 결재선의 오른쪽 콘텐츠 영역만 필요 시 가로 스크롤하여 좁은 화면에서 페이지 전체 가로 넘침을 방지한다. 라벨은 계속 보인다.
- 결재선/참조선 후보가 비어 있을 때 `선택 가능한 사용자가 없습니다.` 안내 문구를 표시하지 않는다.
- 문서작성 모달을 열면 본문 에디터가 앞선 입력 아래 남은 높이를 채우고 최소 180px을 유지한다. 긴 본문은 에디터를 확장시키며 모달 본문이 세로 스크롤한다.
- 양식의 첫/마지막 본문 블록 바깥 여백을 정리해 에디터의 위·아래 내부 공백을 동일하게 유지한다.
- 문서작성 모달만 공통 다이얼로그의 선택적 표면 배경을 흰색으로 지정한다. 다른 공통 다이얼로그는 기본 테마를 유지한다.
- 공통 `UserSelectEditor`, `RichTextEditor`, `CommonDialog`를 재사용한다. API, 저장/상신, 백엔드, DB 동작은 추가하지 않는다.

## 작업 순서

1. 상세 사양서와 계획서를 기준으로 두 행의 라벨/입력 배치와 카드형 결재선의 회귀 테스트를 먼저 추가한다.
2. 선택 확정 시 카드의 사용자 정보, 프로필, 순번, 도장, 역할, 그룹 표시 및 단계 전체 삭제/순번 갱신을 검증한다.
3. 결재선 라벨 오른쪽에 카드 목록, 마지막 다중 선택 입력 및 `결재 추가`/`합의 추가` 버튼을 배치한다.
4. 참조선을 바로 아래 행으로 옮기고 다중 선택 동작과 모달 본문 스크롤을 유지한다.
5. 지정 테스트, lint, 빌드를 실행하고 375px/768px/1280px 브라우저에서 레이아웃, 카드/필드/버튼 높이, 흰 배경, 내부 가로 스크롤, 에디터 남은 높이 채우기와 양식 상·하단 공백을 확인한다.
6. 이전 선택기 상자 설계/계획/결과 문서를 대체 상태로 표시하고 날짜별 결과 보고서와 새 브라우저 캡처를 작성한다.

## 완료 기준

- 확정 결재·합의 단계는 순번, 프로필 이미지, 사용자 이름과 부서, 도장 자리 및 단계 전체 삭제 버튼이 있는 카드로 표시된다.
- 다중 선택한 결재자는 순서대로 개별 카드가 되고 합의자는 하나의 단계 카드에 함께 표시된다.
- 활성 입력의 다중 선택값에만 `결재 추가`/`합의 추가`가 적용되고 확정 후 다음 빈 입력이 이어진다.
- 단계 전체 삭제 후 순번이 다시 매겨지고 그 사용자는 활성 결재 후보에 복원된다.
- `참조` 입력은 결재선 바로 아래 별도 행의 다중 선택 필드이며, 별도 요약 목록을 표시하지 않는다.
- 좁은 화면에서도 결재선 콘텐츠만 내부 가로 스크롤되고 문서 전체는 가로로 넘치지 않는다.
- 후보가 없을 때 안내 문구가 나오지 않고 문서작성 모달 표면만 흰색이며, 카드/필드/버튼 높이가 일치한다.
- 모달을 열면 에디터가 남은 높이를 채우고, 장문 양식은 에디터 및 모달 본문을 확장/스크롤하며 에디터 상·하단 공백은 동일하다.
- 기존 RichTextEditor 기본 동작, 모달 세로 스크롤, 오류/로딩 및 문서작성 회귀 동작을 보존한다. 본문 남은 높이/가장자리 여백 변경은 문서작성 모달에만 적용한다.
