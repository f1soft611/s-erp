# 20261007_011 문서작성 짧은 이름 말줄임 개선 작업지시서

## 목적

문서작성 모달 결재선에서 결재자와 합의자의 이름이 3~4글자인 경우 말줄임표 없이 전체 표시한다.

## 승인된 요구사항

1. 결재자와 합의자 이름 모두 3~4글자는 전체 표시한다.
2. 4글자를 초과하는 이름은 현재 한 줄 레이아웃을 유지하고, 공간이 부족하면 말줄임 처리한다.
3. 결재자 카드의 삭제 X는 상단 직위/직함 행에 있으므로 이름 행에 삭제 버튼 공간을 예약하지 않는다.
4. 결재 슬롯 최소 너비를 88px로 조정해 순번 배지 옆 이름 영역에 4글자 너비를 확보한다.
5. 합의 칩 이름의 최대 너비는 4em으로 한다.
6. 좁은 화면에서는 한 행에 배치되는 결재 슬롯 수가 줄어들 수 있지만, 페이지 전체 가로 넘침은 발생하지 않아야 한다.
7. 전체 이름은 기존 title 및 접근성 레이블로 계속 제공한다.

## 변경 범위

- 프론트엔드 결재선 표시 컴포넌트와 해당 문서작성 회귀 테스트
- 날짜별 계획/사양 및 기존 결과 문서
- 375px, 768px, 1280px 개인정보 보호 스크린샷

백엔드, API, DB 스키마 변경은 없다.

## 완료 기준

- 결재자와 합의자의 3~4글자 이름이 말줄임되지 않는다.
- 더 긴 이름은 기존과 같이 한 줄 말줄임 처리된다.
- 호버 삭제 X, 순번 배지, 이름 영역이 겹치지 않는다.
- 375px, 768px, 1280px 화면에서 페이지 전체 가로 넘침이 없다.
- 관련 테스트, lint, build와 결과 문서/스크린샷이 갱신된다.
