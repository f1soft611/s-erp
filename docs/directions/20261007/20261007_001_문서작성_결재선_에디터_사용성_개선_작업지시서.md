# 20261007_001 문서작성 결재선 및 에디터 사용성 개선 작업지시서

## 작업 목적

문서작성 모달의 결재선·참조 선택 과정을 간결하게 하고, 선택 항목의 순서와 공간 사용을 개선한다. 본문이 길어질 때 에디터 내부가 아닌 모달 콘텐츠 영역에서 스크롤할 수 있도록 한다.

## 승인된 요구사항

- 기존 F1-Grid `UserSelectEditor`를 재사용한다. 선택 후보 숨김 및 선택 순서 보존 기능은 기본 동작을 바꾸지 않는 opt-in 속성으로 제공한다.
- 결재선과 참조선에서 이미 선택된 사용자는 드롭다운 후보에서 즉시 숨기고 선택기 내부의 칩으로 표시한다. 필드 아래에 동일 사용자의 별도 미리보기 목록은 표시하지 않는다.
- 이미 결재 또는 합의 단계로 추가된 사람은 결재선 후보에서 숨긴다. 참조선과 결재선 사이에 중복 금지 규칙은 새로 추가하지 않는다.
- 선택한 여러 사용자를 `결재 추가`하면 선택 순서를 따라 사용자별 독립 결재 단계를 연속 추가하고 결재선 선택값을 비운다.
- `합의 추가`는 기존 사양대로 선택한 사용자를 하나의 합의 단계로 묶어 추가하고 선택값을 비운다.
- 결재선 입력 우측에 `결재 추가`, `합의 추가` 액션을 둔다.
- 추가된 결재/합의 단계는 번호와 `>` 방향 표시를 가진 가로 목록으로 표시한다. 좁은 화면에서는 단계 목록 내부에서 가로 스크롤하여 페이지 전체 가로 넘침을 방지한다.
- 본문 에디터 내용 영역은 입력한 내용에 따라 세로로 확장하고 에디터 내부의 고정 높이/세로 스크롤을 제거한다. 모달의 기존 콘텐츠 스크롤로 양식 필드와 본문 전체를 탐색한다.
- 공통 `RichTextEditor`, `CommonDialog`를 유지하고 저장·상신 및 실제 결재 처리는 추가하지 않는다.

## 작업 절차

1. 승인 설계를 기준으로 날짜별 계획서와 상세 사양서를 작성한다.
2. 사용자 선택 후보 숨김, 선택 순서에 따른 다중 결재 추가, 합의 단계 유지, 참조 미리보기 제거를 검증하는 회귀 테스트를 작성하거나 갱신한다.
3. `UserSelectEditor`의 선택적 후보 숨김 및 순서 보존 동작을 구현하고 기본값으로 기존 소비자 동작을 보존한다.
4. 문서작성 결재선/참조 입력 배치와 가로 단계 목록을 반영한다.
5. 본문 에디터의 고정 높이 및 내부 세로 스크롤을 제거하고 모달 콘텐츠 스크롤로 통합한다.
6. 지정 테스트, 프론트엔드 빌드 및 실제 브라우저 375px/768px/1280px 확인을 수행한다.
7. 결과 보고서와 실제 화면 캡처를 날짜별 결과 폴더에 기록한다.

## 완료 기준

- 선택한 결재자·참조자가 각 필드 아래 별도 미리보기로 중복 표시되지 않는다.
- 선택한 사람은 선택 후보 목록에서 숨겨진다. 결재에 추가된 사람은 결재선 후보에 다시 나타나지 않는다.
- 여러 결재자를 추가하면 사용자가 선택한 순서대로 사용자별 단계가 만들어진다.
- 여러 합의자는 현재 계약처럼 하나의 합의 단계에 유지된다.
- 추가 액션은 사용자 선택기 우측에 있고 단계 목록은 가로 흐름과 좁은 화면 내부 스크롤을 제공한다.
- 에디터는 본문 높이에 따라 확장되며 긴 콘텐츠는 모달 콘텐츠 영역에서 스크롤된다.
- 기존 공통 에디터/모달 및 저장 비활성 동작이 유지되고, 자동 검증과 세 뷰포트 브라우저 검증 및 결과 문서가 완료된다.
