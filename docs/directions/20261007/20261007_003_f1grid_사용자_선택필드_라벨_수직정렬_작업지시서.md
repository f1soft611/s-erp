# 20261007_003 F1-Grid 사용자 선택 필드 라벨 수직 정렬 작업지시서

## 목적

F1-Grid 공통 사용자 선택 필드의 비활성 라벨이 입력 테두리의 수직 중앙보다 위에 보이는 현상을 보정한다.

## 범위 및 완료 기준

- `UserSelectEditor`의 비축소(outlined small field) 라벨만 입력 높이 중앙에 정렬한다.
- 포커스/값 존재로 축소된 라벨, compact Grid cell 편집기, 칩/선택/검색 동작은 변경하지 않는다.
- 회귀 테스트와 F1-Grid 문서, 날짜별 결과 문서를 갱신한다.
- 테스트 및 프론트엔드 빌드를 실행하고 브라우저에서 확인한다.
