# 20261007_008 공통 모달 테마 배경 통일 작업지시서

## 목적

공통 다이얼로그의 표면 배경을 라이트/다크 테마에 맞게 일관되게 적용한다. 라이트 테마의 기본 배경은 흰색으로 유지하고, 다크 테마는 읽기 쉬운 어두운 배경을 명확히 정의한다.

## 승인 요구사항

- `CommonDialog`의 기본 paper/header/body/footer 배경은 라이트 테마에서 흰색(`#ffffff`)을 사용한다.
- 다크 테마 기본 배경은 슬레이트(`#1e293b`)로 정의하고 모든 공통 다이얼로그 영역에 같은 배경을 적용한다.
- 문서작성 모달은 흰색 표면색을 고정하지 않고 공통 테마 배경을 사용한다.
- 의도적인 `surfaceBackgroundColor` 사용자 지정과 에디터 내부 배경은 유지한다.
- 모달 크기, 레이아웃, 입력 동작 및 다른 기능은 변경하지 않는다.

## 작업 절차

1. 공통 다이얼로그 및 문서작성 화면의 기존 테마 테스트를 확인한다.
2. 라이트/다크에서 공통 다이얼로그 모든 영역의 기본 배경색 테스트를 작성하고 기존 구현에서 실패함을 확인한다.
3. 공통 기본 표면색과 각 영역 배경을 통일하고 문서작성의 흰색 고정값을 제거한다.
4. 공통 다이얼로그, 문서작성 통합 테스트와 프론트엔드 빌드를 실행한다.
5. 공유 브라우저의 다크 테마에서 문서작성 모달을 확인하고 라이트/다크 표시를 기록한다.

## 완료 기준

1. 라이트 기본 모달의 paper/header/body/footer 배경이 모두 흰색이다.
2. 다크 기본 모달의 paper/header/body/footer 배경이 모두 `#1e293b`이다.
3. 문서작성 다크 모달에 흰색 전체 표면이 나타나지 않고 에디터 전용 배경은 유지된다.
4. 사용자 지정 표면색 동작 및 기존 공통 다이얼로그 테스트가 유지된다.
5. 집중 테스트와 프론트엔드 빌드가 통과한다.
