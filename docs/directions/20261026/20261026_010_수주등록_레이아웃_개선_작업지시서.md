# 20261026_010 수주등록 레이아웃 개선 작업지시서

## 작업 목적

기존 `/sales/order/create` 수주등록 화면에서 수주 기본정보 입력 필드의
배치와 거래처 선택 버튼 정렬을 개선해 입력 흐름을 더 일관되게 한다.

## 확정 범위

- 기존 한 장의 `수주 기본정보` 카드를 유지한다.
- 데스크톱에서는 수주번호, 수주일자, 거래처, 견적번호를 첫 행에 배치한다.
- 납기일자, 납품장소, 배송방법, 수주상태를 다음 행에 배치한다.
- 거래처 입력/선택 컨트롤을 같은 행의 입력 필드와 세로 정렬한다.
- 비고 필드는 카드 전체 너비를 사용한다.
- 거래처 선택 버튼의 높이를 인접 입력 필드와 맞춘다.
- 좁은 화면에서 읽기 전용 수주번호 안내 문구가 필드 안에서 잘리지 않도록
  글자 크기를 반응형으로 조정한다. 실제 값은 유지한다.
- 기존 필드, 값, 입력 흐름, 저장 비활성 상태, 상세 그리드 동작은 변경하지 않는다.
- 375px, 768px, 1280px 실제 브라우저 화면에서 레이아웃을 확인하고 결과
  문서와 스크린샷을 갱신한다.

## 제외 범위

- 수주 저장/조회 API, DB 또는 업무 동작 변경
- 신규 필드, 필드 제거, 입력 검증 추가
- 상세 F1-Grid 동작 변경
- 공통 picker의 다른 화면 사용처 변경

## 완료 조건

- 입력 필드가 지정된 순서와 행에 정렬된다.
- 거래처 선택 버튼이 입력 필드 높이와 일치한다.
- 375px에서 읽기 전용 수주번호 안내 문구가 전부 표시된다.
- 375px, 768px, 1280px에서 페이지 가로 넘침, 겹침, 잘림이 없다.
- 기존 수주등록 테스트 및 프론트엔드 빌드가 통과한다.
- 날짜별 계획/상세 사양/결과 문서가 갱신되고 실제 브라우저 스크린샷이
  포함된다.
