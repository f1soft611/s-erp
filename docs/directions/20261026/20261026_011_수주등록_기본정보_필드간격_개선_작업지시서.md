# 20261026_011 수주등록 기본정보 필드 간격 개선 작업지시서

## 작업 목적

수주등록 기본정보 화면의 필드 행 사이 세로 여백을 줄여 한눈에 더 조밀하게
보이도록 한다.

## 확정 범위

- 기본정보 그리드의 가로 열 간격과 카드/필드 구조는 유지한다.
- 기본정보 필드의 행 간격만 기존 16px에서 8px로 줄인다.
- MUI 기본 입력 필드의 상하 여백을 이 그리드에서만 제거하고, 거래처 picker의
  상단 오프셋도 제거해 실제 필드 가장자리 간격을 8px로 맞춘다.
- 필드 순서, 반응형 열 수, picker 정렬/버튼 크기, 입력 동작은 변경하지 않는다.
- 375px, 768px, 1280px 브라우저 뷰포트에서 레이아웃을 확인하고 결과를 기록한다.

## 제외 범위

- 필드 간 가로 간격 변경
- 기본정보 카드 내부 패딩 또는 제목 간격 변경
- 공통 컴포넌트 및 다른 페이지 레이아웃 변경
- 업무 동작, API, 데이터 계약 변경

## 완료 조건

- 기본정보 필드 가장자리 간 세로 간격은 8px, 가로 열 간격은 기존 16px이다.
- 거래처 picker 입력과 버튼이 같은 행의 필드와 상단 정렬된다.
- 기존 필드/행 배치 및 picker 정렬이 유지된다.
- 관련 회귀 테스트와 프론트엔드 빌드가 통과한다.
- 세 뷰포트에서 잘림이나 수평 overflow가 없고 결과 문서/스크린샷이 저장된다.
