# 20261026_005 커뮤니티 자료실 그리드 전체 높이 작업지시서

## 요청 및 승인

- 자료실 화면의 파일/폴더 그리드가 헤더, 검색 및 경로 아래 남은 세로 공간을 채우도록 한다.
- 헤더, 검색, 경로, 로딩/오류/빈 결과 표시와 파일 동작은 유지한다.
- 기존 flex 흐름을 그리드 영역까지 연결하고 뷰포트 고정 높이는 사용하지 않는다.

## 범위 및 완료 기준

- `ArchiveBoardPage`의 그리드 호스트 레이아웃만 필요한 범위에서 조정한다.
- 현재 워크트리에 있는 자료실 로딩 변경을 보존하고 API, 공통 그리드, 백엔드는 수정하지 않는다.
- 자료실 회귀 테스트와 프런트엔드 빌드가 통과한다.
- 375px, 768px, 1280px 너비의 브라우저에서 그리드가 잔여 높이를 채우고 의도하지 않은 페이지 가로 스크롤이 없는지 확인한다.
- 변경 원인, 해결 및 브라우저 검증 결과를 결과 문서와 스크린샷으로 남긴다.

## 절차

1. 계획서와 상세사양서에서 승인된 flex 레이아웃 접근을 확인한다.
2. 기존 자료실 회귀 테스트와 빌드를 확인한다.
3. 그리드 호스트를 세로 flex 컨테이너로 구성하고 기존 로딩 상태 변경을 보존한다.
4. 회귀 테스트, 빌드 및 브라우저 뷰포트 검증을 수행한다.
5. `docs/result/20261026/community-archive-grid-fill-height`에 결과와 스크린샷을 기록한다.
