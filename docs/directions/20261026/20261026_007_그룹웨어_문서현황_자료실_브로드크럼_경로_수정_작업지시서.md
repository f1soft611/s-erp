# 20261026_007 그룹웨어 문서현황·자료실 브로드크럼 경로 수정 작업지시서

## 요청

문서현황 페이지와 자료실 페이지의 페이지 상단 브로드크럼 경로가 2단계로 표시되는 문제를 확인하고, 메뉴 계층에 맞춰 3단계 경로를 표시한다.

## 승인된 경로

- 문서현황: `그룹웨어 > 문서관리 > 문서현황`
- 자료실: `그룹웨어 > 커뮤니티 > 자료실`

각 경로의 첫 항목은 모듈, 두 번째는 부모 메뉴, 마지막은 현재 페이지다. 페이지 헤더의 설명 및 권한 동작은 유지한다.

## 원인 확인 및 범위

- 두 페이지 모두 `PageHeader`에 모듈명과 현재 메뉴명만 전달하고 있다.
- 공지사항은 `그룹웨어 > 커뮤니티 > 공지사항`, 문서작성은 `그룹웨어 > 문서관리 > 문서작성`을 전달하는 기존 패턴을 참고한다.
- 문서현황 및 자료실 페이지의 브로드크럼 구성과 관련 테스트만 변경한다. 라우팅, 메뉴 데이터, 페이지 기능, 공통 헤더는 변경하지 않는다.

## 완료 기준

- 두 페이지에서 각 승인 경로의 세 단계가 모두 표시된다.
- 페이지별 회귀 테스트와 프런트엔드 빌드가 통과한다.
- 두 페이지의 브라우저 렌더링 결과를 확인하고 결과 문서에 기록한다.
