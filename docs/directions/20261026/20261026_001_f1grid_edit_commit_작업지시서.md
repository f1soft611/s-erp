# F1-Grid 편집 확정 렌더 격리 작업지시서

## 요청과 근거

- 사용자가 셀 편집 후 끊김을 보고했으며, 조사 후 개선 진행을 승인했다.
- 합성 100행 × 2열 브라우저에서 값 변경 후 Enter 확정 시 비수정 99행의 본문까지 실행됐다.
- 다른 행의 표시 renderer는 기존 memo로 보호되지만 행별 셀 계산은 반복된다.
- 사전 5회 React Profiler actualDuration: 96.3, 93.4, 86.4, 77.7, 58.7ms. 개발 환경 참고값이며 운영 성능 보장값이 아니다.

## 범위와 완료 조건

- 공용 일반 행의 편집 확정 시 변경 행과 표시 영향이 있는 행만 본문을 실행한다.
- 병합 열은 전체 목록과 병합 정보 변경에 대한 기존 갱신을 보존한다.
- dirty 표시, 마지막 행, 정렬/필터, Enter/Tab, 취소 및 최신 이벤트 계약을 유지한다.
- 실패하는 성능 회귀 테스트를 먼저 확인하고 관련 테스트, 빌드, 실제 브라우저 전후 측정을 수행한다.
- 계획서 → 상세 사양서 → 구현 → 결과 문서 및 375/768/1280px 스크린샷 순서를 따른다.
- 백엔드/API/DB 및 화면의 공개 옵션 변경은 없다. 합성 데이터만 편집하며 업무 데이터는 저장하지 않는다.
