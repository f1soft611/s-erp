# 자료실 초기 로딩 레이아웃 안정화 작업지시서

## 요청 및 승인

- 자료실 첫 진입 시 로딩 안내가 나타났다 사라지면서 레이아웃이 움직이지 않도록 한다.
- 날짜 기본값, 분류, 파일 목록 조회 중에는 기존 F1-Grid 스피너만 표시한다.
- 오류 및 재시도, 업로드/수정/삭제 진행 안내는 유지한다. 사용자가 이 범위를 승인했다.

## 범위 및 완료 기준

- 자료실 페이지와 회귀 테스트만 수정한다. 공통 그리드, API, DB 계약은 변경하지 않는다.
- 계획서 → 상세사양서 → 실패 테스트 → 구현 → 검증 → 결과 문서 순으로 진행한다.
- 지연된 초기 날짜/분류/파일 응답 각각에서 스피너가 유지되고 로딩 안내 배너가 없어야 한다.
- 로딩 중에는 빈 결과 배너도 표시하지 않는다. 조회 완료 후 빈 결과 및 실패 안내는 유지한다.
- 관련 Vitest, 프론트엔드 빌드, 375/768/1280px 브라우저 확인 및 스크린샷을 남긴다.
- 기존 작업 중인 F1-Grid 공통 파일 및 다른 문서를 변경하거나 커밋하지 않는다.
