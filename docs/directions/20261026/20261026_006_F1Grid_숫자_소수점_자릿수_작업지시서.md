# F1-Grid 숫자 소수점 자릿수 작업지시서

## 목적

F1-Grid 숫자 컬럼에서 기존 `decimalPlaces` 옵션으로 표시 자릿수를 지정할 수 있도록 하고, 지정하지 않은 숫자/소수 컬럼은 소수점 이하 최대 5자리까지 표시한다.

## 요구사항

- 기존 `F1GridColumn.decimalPlaces`를 재사용하며 새로운 숫자 포맷 옵션은 추가하지 않는다.
- `number` 및 `decimal` 컬럼에서 `decimalPlaces` 미지정 시 최소 0자리, 최대 5자리로 표시한다.
- 기본 표시에서 불필요한 끝자리 0을 숨기며, 소수부가 없으면 소수점을 표시하지 않는다.
- `decimalPlaces`를 지정하면 기존처럼 지정 자릿수를 고정 표시한다.
- `format: 'currency'`의 기본 소수점 0자리 동작과 명시 자릿수 동작을 보존한다.
- 엑셀 내보내기의 기본 숫자 서식도 화면과 동일한 최대 5자리 선택 표시를 적용한다.
- 편집기 입력 제한 및 원본 데이터 저장 동작은 변경하지 않는다.

## 작업 순서

1. 계획서와 상세 사양서를 확인한다.
2. 숫자 화면 표시와 엑셀 표시의 회귀 테스트를 먼저 추가하고 실패를 확인한다.
3. 기존 표시 포맷터와 엑셀 서식 생성 로직을 최소 수정한다.
4. F1-Grid API 문서를 갱신하고 날짜별 결과 문서 및 브라우저 스크린샷을 정리한다.
5. 포커스 테스트, 프론트엔드 빌드, 브라우저 표시를 검증한다.

## 완료 조건

- 정수는 소수점 없이 표시된다.
- `1.2`는 `1.2`, `1.234567`은 `1.23457`로 기본 표시된다.
- 명시된 `decimalPlaces`는 기존처럼 고정 자릿수를 표시한다.
- 통화 기본 0자리 표시가 유지된다.
- 화면과 엑셀의 기본 숫자 표시가 일치한다.
- 관련 테스트와 프론트엔드 빌드가 통과하고 결과 문서 및 스크린샷이 저장된다.
