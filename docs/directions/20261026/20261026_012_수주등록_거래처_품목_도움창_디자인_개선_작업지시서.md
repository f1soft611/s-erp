# 20261026_012 수주등록 거래처·품목 도움창 디자인 개선 작업지시서

## 작업 목적

수주등록 거래처/품목 도움창을 공통 도움폼으로 통일하고 입력 필드와
버튼의 높이를 맞춰 사용성과 시각적 완성도를 높인다.

## 확정 범위

- 기존 `MasterPicker`의 거래처 및 품목 선택 흐름을 유지한다.
- 검색 입력 필드와 검색 버튼, 선택 표시 필드와 선택 버튼의 높이를
  각각 40px로 통일한다.
- 도움창은 기존 `CommonDialog` 공통 컴포넌트를 적용한다.
- 검색 중, 결과 없음, 오류, 결과 선택의 기존 동작을 보존한다.
- 375px, 768px, 1280px 실제 브라우저 화면을 확인하고 캡처한다.

## 제외 범위

- 검색 API, 검색 조건, 선택 데이터 타입 및 마스터 데이터 계약 변경
- 수주등록의 다른 필드/레이아웃 변경
- 로그인/권한/라우팅 변경

## 완료 조건

- 거래처와 품목이 동일한 공통 도움창 레이아웃을 사용한다.
- 대응하는 필드와 버튼 높이가 40px로 일치한다.
- 검색/선택 및 오류 표시 회귀 테스트와 프론트엔드 빌드가 통과한다.
- 세 뷰포트의 실제 브라우저 렌더링과 스크린샷이 결과 문서에 기록된다.
