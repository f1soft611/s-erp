# 최근 사용 메뉴 PC 유지 작업지시서

## 요구사항

- 사용자 요청: 좌측 최근 사용 메뉴 5건을 초기화하지 않고 해당 PC에서 계속 이어서 사용한다.
- 기존 [세션 유지 작업지시서](../20260923/20260923_002_최근사용메뉴_세션유지_작업지시서.md)의 세션 종료 시 삭제 정책을 이번 작업에서 변경한다.
- 같은 PC의 같은 브라우저 프로필·서비스 주소에서 새로고침, 탭/브라우저 종료 후 재접속, 로그아웃 후 재로그인해도 유지한다.
- 현재 세션에 남아 있는 기록은 영구 저장소로 이관한다.
- 최신순, 중복 제거, 최대 5건, 클릭 이동 및 시간 표시를 유지한다.
- 페이지 조회 상태·인증·즐겨찾기·백엔드·DB는 변경하지 않는다.
- 브라우저 저장소 직접 삭제, 시크릿 모드 종료, 다른 PC/브라우저/서비스 주소까지 보존하는 것은 제외한다.

## 실행 및 완료 기준

계획서 → 상세 사양서 → 실패 테스트 → 최소 구현 → 테스트·빌드·린트 → 실제 브라우저 확인 및 결과/스크린샷 작성 순서로 수행한다. 사용자 직접 수정 요청 및 자동 진행 모드에 따라 추가 승인 대기 없이 이 범위를 수행한다.
