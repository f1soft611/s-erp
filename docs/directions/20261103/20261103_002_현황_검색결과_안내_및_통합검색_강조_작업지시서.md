# 현황 검색결과 안내 및 통합검색 일치어 강조 작업지시서

## 작업 목적

문서현황과 수주현황의 검색 결과 안내 영역을 더 촘촘하고 일관되게 표시하고, 결과 수와 닫기 동작을 제공한다. 통합검색에서는 결과 제목뿐 아니라 보조 설명에서도 검색어와 일치하는 문자열을 강조한다.

## 승인 범위 및 동작

- 문서현황 및 수주현황의 성공한 검색 결과가 0건이면 기존 안내 문구를 유지하되 검색조건 초기화 버튼은 제공하지 않는다.
- 정상 조회 결과가 있으면 `조회 결과 총 N건입니다.` 형태로 건수를 알린다. 문서현황은 `totalRowCount`, 수주현황은 현재 검색 결과 목록 건수를 사용한다.
- 결과 안내는 둘 다 정보성 status 메시지로 표시하며 Alert의 X로 닫을 수 있다. 검색조건 변경 또는 재조회가 완료되면 새로운 결과 안내를 다시 표시한다.
- 두 현황 화면의 결과 안내에 동일한 공통 컴포넌트를 사용한다. Alert와 위 검색 영역 및 아래 그리드 사이 간격은 각각 8px로 맞춘다. 아래 그리드 컨테이너의 기존 `pt: 1`을 고려해 결과 안내 wrapper는 위 `pt: 1`, 아래 `pb: 0`을 적용한다. 공통 오류 메시지의 여백/닫기/재시도 동작은 변경하지 않는다.
- 최초 조회 전, 재조회 중, 조회 오류 및 검색 기본값 오류에는 결과 안내를 표시하지 않는다.
- 통합검색 결과에서 기존 제목 강조를 유지하고 보조 설명의 검색어 일치 텍스트도 대소문자를 구분하지 않고 안전한 `<mark>` 요소로 강조한다. API, 검색 범위, 데이터 계약은 변경하지 않는다.

## 작업 순서 및 완료 기준

1. 날짜별 계획서와 상세 사양서를 작성한다.
2. 공통 결과 안내, 각 현황 페이지의 0건/양수 건수/닫기/새 조회 표시 및 통합검색 설명 강조 테스트를 작성한다.
3. 공유 UI와 화면 표시 계층만 변경한다.
4. 관련 Vitest, 프런트엔드 빌드, 린트 및 375px/768px/1280px 브라우저 확인을 수행한다.
5. 합성 데이터 스크린샷과 검증 결과를 `docs/result/20261103/search-result-notice-highlighting/`에 기록한다.

## 범위 제외

- 서버/API/DB 검색 동작 및 응답 스키마
- 검색 결과 본문/첨부 내용 전체 탐색
- 결과 안내가 아닌 일반 오류/경고 메시지 스타일 변경
- 기존 통합검색 제목 강조의 제거 또는 검색어 매칭 규칙 변경
