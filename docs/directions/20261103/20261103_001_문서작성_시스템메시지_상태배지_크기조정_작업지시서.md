# 문서작성 시스템 메시지 상태 배지 크기 조정 작업지시서

## 작업 목적

문서작성 피드 및 상세의 댓글에 표시되는 시스템 메시지 상태 배지를 작성자 이름과 같은 글자 크기로 줄이고, 배지의 높이와 여백을 축소해 댓글 헤더의 시각적 비중을 낮춘다.

## 승인 요구사항

- 문서작성 피드와 상세에서 사용하는 시스템 메시지 상태 배지의 글자 크기를 작성자 이름과 같은 `caption` 크기로 표시한다.
- 기존 작은 Chip보다 배지 높이와 좌우 여백을 줄인다.
- 기존 배지 색상, variant, `8px` 모서리, 문구, 시스템 메시지 본문/작성자/시간은 변경하지 않는다.
- 일반 댓글 및 공지사항의 Chip과 다른 동작은 변경하지 않는다.

## 변경 범위

- 공통 댓글 렌더러의 선택적 시스템 이벤트 배지 스타일
- 공통 피드 컴포넌트의 배지 크기 회귀 테스트
- 날짜별 계획서, 상세 사양서, 결과 문서 및 합성 데이터 스크린샷

## 작업 순서 및 완료 기준

1. 작업지시서 기반 계획서와 상세 사양서를 작성한다.
2. 시스템 배지 글자 크기/높이 축소를 검증하는 테스트를 추가한다.
3. 시스템 이벤트 Chip에만 작성자 `caption` 크기와 축소된 크기를 적용한다.
4. 관련 Vitest, 프런트엔드 빌드 및 375px/768px/1280px 브라우저 검증을 수행한다.
5. 결과 보고서와 합성 데이터 스크린샷을 `docs/result/20261103/document-system-badge-density/`에 기록한다.

## 범위 제외

- 이벤트 매핑, 색상, variant, 문서 상태 및 시스템 메시지 본문 변경
- 일반 댓글/공지사항 스타일 변경
- API, 백엔드, DB 변경
