# 즐겨찾기 폴더·메뉴 구분 작업지시서

## 요청과 기준

- 사용자 요청: 즐겨찾기 모음 리스트에서 폴더와 메뉴가 잘 구별되도록 개선한다.
- 기존 기준: [메뉴 즐겨찾기 상세사양서](../../spec/20261102/20261102_002_메뉴_즐겨찾기_상세사양서.md).

## 범위와 완료 조건

- 즐겨찾기 트리의 폴더와 메뉴에 서로 다른 아이콘과 시각적 스타일을 적용한다.
- 후속 요청: "폴더에 컬러 넣지마.." — 폴더 컬러 아이콘과 배경/테두리 강조를 제거한다.
- 최종 후속 요청: 폴더 아이콘은 기존 상속 색상을 사용하고 폴더 이름 굵은 표시를 제거한다. 아이콘의 모양과 `폴더` 표시로 구분한다.
- 폴더·메뉴 글자색은 기존 일반 메뉴와 동일하게 light `#475569`, dark `#dbeafe`를 사용한다. 폴더 아이콘은 해당 행 색상을 상속한다.
- 최신 요청: 기존 메뉴와 헤더 높이/크기/여백을 동일하게 맞추고 즐겨찾기 별 아이콘, 제목, 새 폴더 버튼은 유지한다. 폴더는 색상을 그대로 두고 속이 채워지지 않은 윤곽선 아이콘으로 변경한다.
- 루트 메뉴와 폴더 안 메뉴에 같은 메뉴 스타일을 적용한다. 빈 폴더도 구분한다.
- 폴더 펼침, 메뉴 이동, 더보기와 우클릭 작업, 저장 및 권한 계약은 변경하지 않는다.
- 작업지시서 → 계획서 → 상세사양서 → 구현 → 검증 및 결과 문서 순서로 진행한다.
- 관련 Vitest, build, 변경 파일 lint와 실제 브라우저 375/768/1280px 검증을 수행하고 결과 및 스크린샷을 보관한다.
- 백엔드, DB 및 F1-Grid는 변경하지 않는다. 커밋하지 않는다.
