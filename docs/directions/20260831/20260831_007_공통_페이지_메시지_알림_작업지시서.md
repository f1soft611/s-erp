# 20260831_007 공통 페이지 메시지 알림 작업지시서

## 1. 요청

권한관리와 메뉴관리 페이지에서 저장 성공과 처리 실패를 일관된 방식으로 사용자에게 알린다.

- 정상적인 저장 완료는 공통 토스트 알림으로 표시한다.
- 비정상적인 조회 또는 저장 실패는 해당 페이지 상단의 공통 메시지 영역에 표시한다.

## 2. 범위

### 포함

- 앱 루트에서 표시되는 공통 성공 토스트 알림
- 권한관리와 메뉴관리 페이지 헤더 아래에 사용하는 공통 오류 메시지 영역
- 두 페이지의 조회/저장 실패 메시지 연동
- 두 페이지의 저장 성공 토스트 연동
- 관련 Vitest, 프론트엔드 빌드, 브라우저 반응형 확인
- 계획서, 사양서, 결과 문서 및 스크린샷 작성

### 제외

- 로그인 및 그 외 페이지의 알림 처리 변경
- 백엔드 API, 응답 계약, DB 스키마 변경
- 경고, 정보, 다중 토스트 큐 등 성공/오류 외 알림 유형 추가

## 3. 완료 기준

- 권한관리 또는 메뉴관리에서 저장에 성공하면 공통 성공 토스트가 표시된다.
- 권한관리 또는 메뉴관리에서 조회 또는 저장에 실패하면 해당 페이지 상단 공통 메시지 영역에 오류가 표시된다.
- 오류 메시지는 닫을 수 있고, 닫은 뒤 레이아웃 공간을 차지하지 않는다.
- 성공 토스트는 자동으로 사라지고 수동으로도 닫을 수 있다.
- 기존 관리 화면의 저장, 재조회, 미저장 변경 확인 흐름을 유지한다.
- 관련 테스트와 `npm run build`가 통과한다.
