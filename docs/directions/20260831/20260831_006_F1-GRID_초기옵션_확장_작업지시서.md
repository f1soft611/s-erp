# 20260831_006 F1-GRID 초기옵션 확장 작업지시서

## 요청

- `F1Grid` 컬럼 옵션에서 최초 렌더링 시 컬럼을 미리 핀 고정할 수 있게 한다.
- `F1Tree` 옵션에서 최초 렌더링 시 모든 트리 노드를 펼칠 수 있게 한다.

## 완료 기준

- 컬럼 정의에 `pinned: 'left' | 'right'`를 지정하면 초기 렌더링부터 해당 컬럼이 고정된다.
- `F1Tree`에 `defaultExpandAll`을 지정하면 초기 렌더링부터 모든 부모 노드가 펼쳐진다.
- 기존 헤더 메뉴의 컬럼 고정/해제와 기존 `defaultExpanded` 동작은 유지된다.
- F1 Grid 가이드와 테스트 페이지 또는 실제 사용 화면에 사용 예시를 반영한다.
- 관련 Vitest와 프론트엔드 빌드를 통과한다.
