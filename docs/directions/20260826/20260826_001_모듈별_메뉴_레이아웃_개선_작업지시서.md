# 20260826*001*모듈별*메뉴*레이아웃*개선*작업지시서

## 1. 작업 개요

현재 ERP 메인 화면은 좌측 모듈 목록만 존재하고, 중앙 콘텐츠 영역이 상대적으로 넓게 보이지 않거나 메인 기능 노출이 부족한 구조로 구성되어 있다. 사용자가 보이는 정보량이 적고, 각 모듈별로 제공되는 기능을 한눈에 파악하기 어렵다.

본 작업은 이를 개선하여, 모듈 선택 시 해당 모듈의 하위 메뉴를 별도 레이아웃으로 전개하고, 메인 영역의 가시성을 높이는 구조를 구현하는 것을 목표로 한다.

핵심 의도는 다음과 같다.

- 메인 화면에서 중앙 영역의 정보 밀도를 높인다.
- 좌측 모듈과 하위 메뉴를 별도 구조로 분리해 인지 부담을 줄인다.
- 모듈별 메뉴를 선택적으로 펼쳐 보여주어 ERP처럼 업무 흐름을 이해하도록 한다.
- 메인 콘텐츠가 빈 공간이 아니라 실제 업무 화면의 중심 역할을 하도록 구성한다.

---

## 2. 작업 목적

이번 작업의 목적은 다음 항목을 반영한 화면 구조를 구축하는 것이다.

- 현재 구조에서 메인 영역이 과도하게 비어 보이는 문제를 개선한다.
- 모듈별 메뉴를 다른 레이아웃으로 전개하여 사용자가 선택한 모듈의 기능 범위를 바로 확인할 수 있게 한다.
- 좌측 메뉴와 중앙/메인 영역의 시각적 우선순위를 재배치한다.
- 실제 ERP 운영 구조에 가까운 화면 구성을 구현한다.

---

## 3. 문제점

현재 메인 구조는 다음과 같은 한계를 가진다.

1. 좌측 네비게이션과 메인 영역 간 정보 균형이 어색하다.
2. 중앙에 보이는 정보량이 적어 화면이 단조롭게 느껴진다.
3. 모듈별 기능 분류가 충분히 드러나지 않아 업무 흐름을 이해하기 어렵다.
4. 하위 메뉴가 단순 배열 수준에 머무르거나, 모듈 전환 시 전체 구조가 충분히 전환되지 않는다.

이로 인해 ERP 화면이 아닌 단순한 사이드바형 리스트 구조로 인식될 수 있다.

---

## 4. 요구사항

### 4.1 화면 레이아웃 요구사항

메인 화면은 다음과 같은 구조로 재설계한다.

- 좌측: ERP 모듈 네비게이션
- 중간 또는 하단: 선택된 모듈의 세부 메뉴 전개 영역
- 우측 또는 메인 영역: 실제 페이지/콘텐츠 영역

즉, 모듈 네비게이션과 하위메뉴를 분리한 구조를 적용한다.

### 4.2 모듈별 메뉴 전개 요구사항

- 모듈을 선택하면 해당 모듈의 하위 메뉴를 별도 영역으로 보여준다.
- 하위 메뉴는 단순 텍스트 나열이 아니라, 해당 모듈에 맞는 기능 그룹으로 전개되어야 한다.
- 메뉴 선택 시, 메인 영역이 바뀌는 형태로 페이지 전환 효과를 보여준다.
- 선택된 모듈과 현재 선택된 메뉴는 시각적으로 명확히 구분되어야 한다.

### 4.3 메인 영역 개선 요구사항

- 메인 영역은 중앙에 보이는 기능 정보가 더 많아야 한다.
- 가독성을 위해 카드, 목록, 요약 정보, 버튼, 상태 영역을 적절히 배치한다.
- 사용자에게는 현재 선택된 모듈의 업무 내용이 한눈에 보여야 한다.
- 좌측 네비게이션이 전체 화면을 압도하지 않도록 적절한 너비와 간격을 유지한다.

### 4.4 동작 요구사항

- 기본 진입 시 첫 번째 모듈이 기본 선택 상태로 보인다.
- 다른 모듈 선택 시 하위 메뉴 영역이 즉시 갱신된다.
- 메뉴 클릭 시 메인 콘텐츠 영역이 변경된다.
- 현재 선택 상태와 hover/focus 상태가 구분되어야 한다.
- 화면 전환은 실제 ERP 화면처럼 자연스럽게 동작해야 한다.

## 5. 구현 방향

### 5.1 레이아웃 방향

기존 형태를 유지하되, 다음 구조를 우선 적용한다.

```text
┌──────────────────────────────────────────────────────┐
│ ERP 시스템                                           │
├──────────────┬────────────────────┬──────────────────┤
│ 모듈 목록     │ 모듈별 메뉴 전개     │ 메인 콘텐츠        │
│ 그룹웨어      │ 전자결재            │ 업무 요약/목록      │
│ 영업관리      │ 고객관리            │ 카드/테이블        │
│ 구매관리      │ 구매관리            │ 상세/검색/버튼      │
│ 생산관리      │ 생산계획            │ 상태 정보          │
│ 재무관리      │ 회계관리            │ ...               │
│ 인사관리      │ 인사관리            │ ...               │
│ 환경설정      │ 시스템관리          │ ...               │
└──────────────┴────────────────────┴──────────────────┘
```

이 구조는 기존 단일 목록형 사이드바를 보완하여, 모듈과 메뉴를 분리해서 사용자에게 ERP 업무 구조를 더 명확하게 전달한다.

### 5.2 데이터 구조 방향

메뉴 구조는 다음과 같은 형태로 관리하는 것을 권장한다.

```ts
interface ModuleItem {
  id: string;
  name: string;
  icon?: string;
  menus: MenuItem[];
}

interface MenuItem {
  id: string;
  name: string;
  pageKey: string;
}
```

이를 통해 다음을 구현할 수 있다.

- 모듈별 하위 메뉴 전개
- 현재 선택 모듈 추적
- 현재 선택 메뉴 추적
- 해당 메뉴에 대응하는 메인 콘텐츠 렌더링
