# 고정 컬럼의 병합 수주번호 클릭 작업지시서

## 요청

수주현황에서 row merge 된 수주번호는 기존 수정으로 클릭 가능하지만, 컬럼을 고정하면 다시 클릭되지 않는다. 고정 후에도 같은 상세 보기 동작을 유지한다.

## 범위와 완료 조건

- F1-Grid 고정 병합 셀의 사용자 정의 콘텐츠 클릭을 수정한다.
- 왼쪽/오른쪽 고정, 고정 해제, 가로 스크롤을 확인한다.
- 병합 영역의 빈 공간을 클릭했을 때 실제 상세 행 선택을 유지한다.
- 합성 데이터만 사용하는 실제 Chromium 회귀 테스트와 375/768/1280px 스크린샷을 남긴다.
- 프론트엔드만 변경하며 API/DB 계약은 변경하지 않는다.
