# F1-Grid 고정 컬럼 스크롤 자연스러움 개선 작업지시서

## 요청

컬럼 고정 후 스크롤할 때 헤더 선과 컬럼 경계가 늦게 조정되는 듯한 움직임을 줄여 더 빠르고 자연스럽게 표시한다.

## 현재 구조

- 본문과 헤더가 별도의 가로 스크롤 영역이며 본문 `scrollLeft`를 헤더로 동기화한다.
- 본문은 스크롤/viewport 정보를 requestAnimationFrame으로 모아 그리드 상태에 반영한다.
- `position: sticky`가 고정 열 위치를 유지하며, 스크롤 위치는 열 가상화 계산에도 사용된다.

## 작업 범위

- 네이티브 본문 스크롤과 즉시 헤더 동기화 및 기존 sticky 고정은 유지한다.
- 비가상화 그리드는 수평 스크롤만으로 viewport React 상태를 갱신하지 않는다.
- 열 가상화 그리드는 실제 가상 열 집합이 바뀌는 경우에만 수평 위치 상태를 갱신한다.
- 세로 행 가상화, viewport 크기, 세로 스크롤바 gutter, 헤더/본문 끝단 정렬은 보존한다.
- F1-GRID 기능 문서, 회귀 테스트, 결과 문서를 함께 갱신한다.

## 제외

- 헤더/본문 컨테이너 통합, sticky 레이아웃 전면 재설계, 별도 스크롤 애니메이션
- 고정 열 스타일/UX 변경, API/백엔드/DB 변경

## 완료 조건

- 일반 가로 스크롤에서 React 재렌더에 따른 선/헤더 지연을 줄인다.
- 가상 열 집합이 바뀔 때 필요한 열을 빠짐없이 렌더하고 고정/보호 열은 유지한다.
- 헤더와 본문이 스크롤 끝에서도 정렬되고 좌/우 고정 열이 흔들리지 않는다.
- 관련 회귀 테스트, 프론트엔드 빌드/lint, 실제 브라우저 확인을 수행하고 결과 문서에 증거를 남긴다.

## 영향 범위

- 프론트엔드 F1-Grid와 테스트/기능 문서에 한정한다.
- DB 스크립트와 백엔드 계약 변경은 없다.
