# F1-Grid 행 단위 선택 옵션 작업지시서

## 요구사항

현황 화면에서는 셀 단위 대신 행 전체에 선택 표시가 필요하다. F1-Grid 공통 옵션으로 제공하고 기존 편집 화면의 셀 선택은 유지한다.

## 작업 범위와 순서

1. 기존 행 선택 상태, 셀 범위 선택, 키보드, 병합/고정 열 및 현황 화면을 확인한다.
2. 계획서와 상세 사양서에 기본값과 행 선택의 동작을 정의한다.
3. 회귀 테스트를 먼저 추가하고 실패를 확인한 뒤 공통 옵션을 구현한다.
4. 수주현황·문서현황에 적용한다. 기존 체크박스, 읽기 전용/편집, 엑셀 권한, 우클릭 옵션은 유지한다.
5. F1-Grid 사용 문서/API와 결과 문서, 375/768/1280px 브라우저 스크린샷을 갱신한다.

페이지별 임시 CSS보다 공통 선택 모드를 사용한다. 단순 표시 전용 옵션보다 실제 선택·복사 계약도 행 단위로 일치시킨다. 기본값은 기존 셀 모드이며, 조회 화면에만 명시적으로 행 모드를 켠다. 백엔드/DB/API 계약과 무관하며 커밋/푸시는 요청 범위가 아니다. 병행 중인 수주현황 컬럼·스크롤 변경을 보존한다.
