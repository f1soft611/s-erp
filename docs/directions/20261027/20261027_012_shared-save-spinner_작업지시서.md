# 저장 버튼 소형 스피너 공통화 작업지시서

사용자 요구: 페이지와 모달에서 저장 중 문구와 함께 작은 로딩 스피너를 공통으로 제공한다.

1. 기존 저장 상태/공통 페이지 액션/모달 버튼과 기존 저장 진행 문서를 확인한다.
2. 계획·사양을 작성한 뒤 공통 저장 버튼과 페이지 액션 연결을 테스트 우선 구현한다.
3. 현재 저장 중 표시가 있거나 저장 상태로 버튼을 잠그는 페이지·모달에 공통 버튼을 연결한다.
4. 기존 문구, 권한, 검증, 비동기 저장/후속 재조회, 오류/닫기/편집 잠금은 유지한다.
5. 관련 회귀, 빌드/린트, 실제 브라우저 375/768/1280px와 결과/스크린샷을 남긴다.

백엔드/DB/API 계약과 조회용 전체 로딩은 변경하지 않는다. 동기적인 F1-Grid 행 폼의 로컬 적용은 서버 저장이 아니므로 범위 밖이다. 병행 변경을 보존하고 커밋/푸시하지 않는다.
