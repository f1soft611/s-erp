# F1-Grid 셀 범위 초기화 및 드래그 성능 작업지시서

## 요청

- 조회를 시작하면 기존 셀 드래그/범위 선택 표시가 남지 않게 한다.
- 행 데이터가 많아도 셀 드래그 중 포인터 반응이 느려지지 않도록 한다.
- 행 선택, 복사, 일반 마우스업, 그리드 가상화 동작은 보존한다.

## 범위 및 완료 기준

- F1Grid의 로딩 전환과 셀 범위 선택 생명주기, 포인터 위치에서 셀을 찾는 경로, 선택 오버레이 위치 계산을 확인한다.
- 실패 회귀 테스트를 먼저 작성한 뒤 최소 구현한다.
- 조회 시작 시 셀 범위, 복사 범위 및 진행 중 드래그 상태를 지우며 행 선택 상태는 유지한다.
- 드래그 중 전체 행 수에 비례해 반복되는 선형 ID 검색을 제거한다.
- 기존 범위 표시 좌표, 가상화 및 드래그 경계 이동 동작은 보존한다.
- F1-GRID 문서, 결과 문서, 375/768/1280px 브라우저 검증을 포함한다.
- 백엔드/API/DB 및 업무 데이터 변경은 없다.
