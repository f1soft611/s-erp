# 문서현황 문서번호 상세 진입 작업지시서

## 요구사항

문서현황에서 수주현황과 동일하게 문서번호를 클릭할 때만 상세를 연다. 기존 행 선택에 의한 상세 진입 요구사항은 이번 요청으로 대체한다.

## 범위와 완료 기준

- 문서번호를 수주번호와 같은 버튼형 링크로 표시한다.
- 일반 셀 클릭, 행 선택, 키보드 행 이동, 우클릭은 상세를 열지 않는다.
- 링크의 키보드 활성화, 닫은 뒤 같은 문서 다시 열기, 기존 상세 편집·갱신을 보존한다.
- 기존 미커밋 행 선택·체크박스 숨김·고정 열 변경을 보존한다.
- 계획서 → 사양서 → 회귀 테스트 → 구현 → 브라우저 검증 → 결과 문서 순서로 진행한다.
- 백엔드/DB/API 변경과 커밋/푸시는 범위가 아니다.
