# 20261027_010 수주현황 상세 패널 및 상태 저장 작업지시서

## 요청 원문

- 수주현황 페이지 상태 저장 추가해서 조회조건 유지
- 수주번호 클릭 시 오른쪽 상세 패널 열림
- 오른쪽 상세 패널은 문서현황의 상세 패널과 동일한 구조, 메인/디테일을 간단하게 표시
- 상세 패널 더보기에서 자기가 작성한 건은 `수정` → 수주등록 화면을 재사용해 수정
- 더보기의 `자세히보기` → 수주등록 화면을 읽기 전용으로 재사용

## 작업 범위

1. 수주현황(`/sales/order/status`)
   - 빠른검색어/상세검색 값을 페이지 세션 상태(`usePageSessionState`)로 저장·복원
   - 수주번호 셀을 링크 버튼으로 표시, 클릭 시 `PageAreaOverlay + PostDetailPanel` 상세 패널
   - 패널: 작성자/등록일, 상태 Chip, 더보기 메뉴, 헤더 요약, 상세 품목 목록
   - 더보기: `자세히보기`(항상), `수정`(작성자 본인 + 수주등록 수정 권한 + 수정 가능 상태)
2. 수주등록 화면 재사용
   - `SalesOrderCreatePage`에 `salesOrderId`, `mode('create'|'edit'|'view')`, `onSaved`, `onDeleted` 지원
   - 다이얼로그(`CommonDialog`)에서 읽기 전용/수정 모드로 렌더링
3. 백엔드 수주 단건 조회 계약 확장
   - `createdBy`, `createdByName`, `createdAt`, `writer` 필드 추가(DB 변경 없음)

## 완료 조건

- 계획서/사양서/결과 문서(스크린샷 포함)
- 프론트 테스트·빌드·oxlint, 백엔드 `SalesOrder*` 테스트 통과
- DB MCP 확인 근거 기록
