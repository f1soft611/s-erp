# F1-Grid select 편집 취소 작업지시서

## 요청

- `select` 컬럼 편집 중 목록을 연 상태에서 다른 셀을 클릭해도 셀 범위 드래그가 시작되지 않게 한다.
- 다른 셀 클릭 시 진행 중인 `select` 편집을 취소하고 기존 값을 유지한다.
- 목록의 정상 옵션 선택 및 다른 에디터의 기존 동작은 보존한다.

## 작업 범위

- F1-Grid의 선택 에디터와 셀 드래그 시작/종료 이벤트 흐름을 조사한다.
- 실패하는 회귀 테스트를 먼저 추가하고 최소 범위로 수정한다.
- 기능 문서와 결과 문서를 함께 갱신한다.
- 합성 데이터만 사용해 실제 브라우저에서 동작을 확인한다.
- 백엔드/API/DB 및 업무 데이터는 변경하지 않는다.

## 완료 기준

- 선택 목록을 연 뒤 포인터가 다른 셀로 이동해도 선택 범위가 드래그되지 않는다.
- 다른 셀 클릭 시 에디터가 종료되고 기존 값과 변경 상태가 보존된다.
- 옵션 선택, 다른 에디터 및 일반 셀 드래그가 기존대로 동작한다.
- 관련 회귀 테스트, 빌드/lint 및 브라우저 검증 결과를 기록한다.
