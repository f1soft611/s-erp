# F1-Grid 선택 에디터 외부 클릭 종료 작업지시서

## 요청

- 코드 선택 컬럼에서 선택하지 않고 다른 셀 또는 다른 영역을 클릭해도 셀 편집을 종료한다.
- 선택하지 않았으면 기존 값과 행 변경 상태를 유지한다.
- 코드 선택 버튼 및 코드/공통코드 선택 목록의 정상 선택 동작은 보존한다.

## 범위와 완료 기준

- 공통 F1-Grid의 `code` 및 코드 옵션을 표시하는 `select` 에디터 종료 흐름을 조사한다.
- 계획서 → 상세 사양서 → 실패 회귀 테스트 → 최소 구현 → 검증 및 결과 기록 순서를 지킨다.
- 목록을 열지 않은 외부 클릭, 목록을 연 뒤 선택 없는 닫기, 정상 선택을 검증한다.
- 4173의 S-ERP 서버에서 합성 데이터만 사용해 375/768/1280px 브라우저 검증과 스크린샷을 남긴다.
- 백엔드/API/DB 및 업무 데이터 변경은 없다.
