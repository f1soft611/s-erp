# F1-Grid Excel 정수 표시 서식 보정 작업지시서

## 요구사항

- F1-Grid Excel 내보내기의 `number`/`decimal` 컬럼에서 실제 값이 정수이면 소수점 구분자(`.`)를 표시하지 않는다.
- 기본 최대 5자리 선택 소수점 서식은 실제 소수부가 있는 값에서 유지한다.
- `decimalPlaces`를 지정한 경우의 고정 자릿수와 currency의 기존 표시 계약을 유지한다.

## 작업 순서

1. 기존 숫자 서식 코드와 ExcelJS 회귀 테스트를 확인한다.
2. 실제 `.xlsx` 기준 정수 값 및 정수 숫자 문자열의 현재 서식 결과를 테스트로 재현한다.
3. 값별 숫자 서식을 적용해 정수 값에만 정수 형식을 지정한다.
4. F1-GRID 문서와 날짜별 결과 문서를 갱신한다.
5. 대상 테스트, 프론트엔드 빌드 및 실제 Excel 표시를 검증한다.

## 완료 기준

- 정수 Number 및 정수 숫자 문자열은 `#,##0` 형식이고 표시 결과에 소수점이 없다.
- 소수 값을 가진 기본 숫자는 최대 5자리 선택 표시를 유지한다.
- 명시 `decimalPlaces`, currency, 문자열 및 기타 typed export의 기존 동작을 유지한다.
- 관련 회귀 테스트와 프론트엔드 빌드가 통과한다.
- 범위는 프론트엔드 F1-Grid와 문서에 한정하고 기존 작업 트리 변경을 보존한다.
