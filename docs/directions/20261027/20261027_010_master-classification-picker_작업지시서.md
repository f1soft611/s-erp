# 품목·거래처 분류 선택 및 마스터 저장

- 사용자 요청: 품목관리/거래처관리 컬럼에서 코드 선택 버튼으로 설정된 분류를 선택하고 기존 저장 버튼으로 저장한다.
- 기존 CommonDialog와 읽기 전용 F1Tree 선택창을 사용한다. 분류 설정 CRUD 팝업은 변경하지 않는다.
- 품목은 품목분류 경로 컬럼과 `itemClsId`, 거래처는 대분류/소분류 컬럼과 `businessKind1/2`를 연결한다.
- 미분류/선택 해제 허용, 품목 임의 단계 허용, 거래처 소분류 선택 시 대분류 자동 지정, 대분류 변경 시 소분류 초기화.
- 서버에서 tenant/활성/부모·레벨을 검증한다. 기존 미사용 분류는 유지할 수 있지만 새 지정은 거부한다.
- 기존 마스터 CRUD 권한과 저장·감사·batch transaction을 유지한다. DDL 실행 및 권한 리팩터링은 하지 않는다.
- 순서: 작업지시서 → 계획서 → 상세사양서 → 실패 테스트 → 구현 → 회귀·브라우저 확인 및 결과/스크린샷.

## 17:01 후속 요청

- 품목 및 거래처 대분류/소분류 선택창의 하단 `선택 해제` 버튼을 제거한다.
- 하단 버튼은 왼쪽부터 `선택`, `취소` 순서로 배치한다. 선택 조건, 취소/X, 저장 API는 유지한다.
