# F1-Grid 다중 행 선택 옵션 작업지시서

사용자 요구: 다중 선택도 공통 옵션으로 제공하고 기본값은 비활성화한다.

1. 기존 행 선택 옵션/checkbox/초기 선택/ref/키보드 경로를 확인한다.
2. 계획서와 상세 사양서를 작성한다.
3. 기본 단일 선택과 명시적 다중 선택의 회귀 테스트를 먼저 작성한다.
4. 공통 `multiSelect` 옵션을 구현하고 기존 다중 선택 예제/테스트는 명시적으로 활성화한다.
5. 공통 Grid 문서/API를 갱신하고 테스트·빌드·린트 및 실제 브라우저 375/768/1280px 결과를 남긴다.

옵션은 행 선택 개수를 제어한다. 기존 셀 드래그 범위, 데이터 checkbox 값 편집, 트리 내부 checkbox 전파는 변경하지 않는다. 현황 화면을 포함해 옵션을 생략한 화면은 단일 행 선택을 사용하며 임의로 다중 선택을 다시 켜지 않는다. 백엔드/DB/API 변경과 커밋/푸시는 없다. 병행 변경을 보존한다.
