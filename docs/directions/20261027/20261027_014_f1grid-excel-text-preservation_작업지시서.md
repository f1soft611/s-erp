# F1-Grid Excel 텍스트 셀 선행 0 보존 작업지시서

## 요구사항

- F1-Grid에서 `type: 'text'` 또는 텍스트 표시값으로 내보낸 숫자형 문자열(예: `000004`)을 Excel에서 편집 후에도 같은 문자열로 유지한다.
- 수주현황의 품목코드와 일반 문자열 컬럼에 적용한다.
- 숫자·날짜 등 실제 typed 값의 Excel 셀 타입과 표시 서식은 변경하지 않는다.

## 작업 순서

1. 기존 Excel exporter와 실제 `.xlsx` 회귀 테스트를 확인한다.
2. 실패 테스트로 문자열 데이터 셀의 Excel 텍스트 서식 누락을 재현한다.
3. 텍스트 셀에 Excel 텍스트 표시 형식을 적용하고, 문자열 값 및 기존 내보내기 계약을 유지한다.
4. F1-GRID 문서와 결과 문서를 갱신한다.
5. 대상 테스트와 빌드를 검증하고 결과를 기록한다.

## 범위 및 완료 기준

- 범위: 공통 F1-Grid Excel export, 회귀 테스트, F1-GRID 문서, 날짜별 작업/계획/사양/결과 문서.
- `.xlsx`를 재로딩해 `000004`가 문자열이며 텍스트 셀 서식(`@`)을 갖는지 검증한다.
- 기존 숫자 및 날짜 typed 값 테스트와 프론트엔드 빌드가 통과한다.
- 백엔드, API, 데이터베이스, 수주현황 표시 동작은 변경하지 않는다.
- 기존 작업 트리 변경을 보존하고 커밋하지 않는다.
