# 수주등록 저장 후 재조회/수정/삭제 및 신규 버튼 작업지시서

## 1. 배경

수주등록 화면은 저장 후 입력을 잠그고 수주번호만 안내한다. 사용자는 방금 저장한 수주를 바로 고치거나 삭제할 수 없고, 새 수주를 입력하려면 화면을 다시 열어야 한다.

## 2. 요청 사항 (사용자 요청 원문 요약)

1. 수주 저장 시 저장된 수주를 다시 불러와 상단(헤더)과 하단(상세 그리드)에 재세팅한다.
2. 재세팅된 수주를 수정하거나 삭제할 수 있어야 한다.
3. 우측 상단에 `신규` 버튼을 추가한다. 저장 권한(쓰기: create 또는 update)이 있을 때만 표시한다.
4. `신규` 클릭 시 상단과 하단을 초기화한다.

## 3. 제약

- 백엔드 API는 기존 eGovFrame 패턴(`egovframework.let.sales.order.create` 패키지, controller/service/service.impl/domain.model/domain.repository, `@Operation`/`@ApiResponses`/`@Schema`, Javadoc)을 그대로 유지한다.
- 테이블은 사용자가 생성/관리한다. DDL을 만들지 않는다.
- 테넌트 범위를 모든 조회/수정/삭제에 적용한다.

## 4. 완료 조건

- 저장 직후 헤더/상세가 서버 조회 결과로 재세팅되고 수주번호가 표시된다.
- 재세팅된 수주를 수정 저장(PUT)하거나 삭제(DELETE)할 수 있다.
- `신규` 버튼은 쓰기 권한이 있을 때만 보이고, 클릭 시 상단/하단이 초기화된다.
- 백엔드/프론트 테스트, 빌드, 화면 캡처 결과를 결과 문서에 남긴다.
