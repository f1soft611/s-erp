# 20261027_007 수주등록 버튼 정리 및 수주현황 작업지시서

## 요청 원문

- 우측 상세 행 추가 버튼 → 품목 선택 버튼 옆으로 이동, 선택 행 삭제 버튼은 제거
- 마우스 오른쪽 메뉴 행 복사 활성화
- 수주현황 페이지 추가: `http://127.0.0.1:4173/sales/order/status`
  - F1-Grid 컬럼 사용, 상세검색 제공
  - 컬럼은 메인정보(헤더) + 상세정보를 합쳐서 표시

## 작업 범위

1. 수주등록(`/sales/order/create`)
   - 상단 액션바에서 `상세 행 추가`, `선택 행 삭제` 제거
   - 수주 상세 그리드 헤더의 `품목 선택` 옆에 `상세 행 추가` 버튼 배치(저장 권한 보유 시 표시)
   - 그리드 우클릭 메뉴의 `행 복사` 활성화(행 삭제는 우클릭 메뉴로 유지)
2. 수주현황(`/sales/order/status`)
   - 백엔드: 전자정부 시스템 패키지 패턴(`egovframework.let.sales.order.status`) 조회 API
   - 프론트: `frontend/src/pages/sales/order/status` 페이지, F1-Grid 읽기 전용 목록, PageSearchArea 빠른/상세검색

## 완료 조건

- 계획서/사양서/결과 문서(스크린샷 포함) 작성
- 프론트 테스트·빌드·oxlint, 백엔드 테스트 통과
- DB 변경 없음(기존 `tb_sales_order_hd`/`tb_sales_order_dt` 조회만), MCP 확인 근거 기록
- 메뉴(`/sales/order/status`)는 메뉴관리에서 사용자가 등록
