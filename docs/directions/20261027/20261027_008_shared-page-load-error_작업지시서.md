# 최초 조회 실패 공통 화면 작업지시서

## 승인 요구사항

공지사항처럼 최초 필수 조회 실패 시 본문 레이아웃 대신 오류 안내와 재시도를 표시한다. 상단 헤더/탐색은 유지한다. 무응답과 서버 응답 오류를 구분한다. 저장·재조회·일부 영역 실패 때는 기존 화면과 작성 내용을 유지한다. 인증/권한 오류는 네트워크 오류로 표시하지 않는다.

## 순서 및 완료 조건

1. 현존 페이지별 필수 초기 조회와 독립적인 부가 조회를 구분한다.
2. 날짜별 계획서와 상세 사양서를 작성한다.
3. 최초 성공 여부를 명시적으로 관리하는 공통 상태와 오류 UI를 테스트 우선으로 구현한다.
4. 데이터 기반 페이지의 초기 조회에 연결한다. 저장 요청이나 모든 API에 대한 전역 화면 차단은 금지한다.
5. 합성 데이터로 무응답/서버 오류/빈 응답/재시도 성공/기존 데이터 유지 시나리오를 검증한다.
6. 실제 브라우저 375/768/1280px 결과와 스크린샷을 결과 폴더에 남긴다.

API 경로·응답 필드·백엔드·DB는 변경하지 않는다. 진행 중인 다른 작업은 보존하고 요청되지 않은 커밋은 생성하지 않는다.
