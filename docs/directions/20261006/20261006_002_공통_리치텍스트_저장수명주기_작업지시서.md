# 20261006_002 공통 리치 텍스트 저장 수명주기 작업지시서

## 작업 목적

공지사항에서 검증된 본문 이미지 저장 흐름을 공통 에디터 저장 lifecycle과 backend 본문 processor로 정리한다. Notice와 기안양식은 공통 처리를 그대로 사용하고, 향후 consumer는 API adapter와 owner/URL 계약만 연결한다.

## 승인된 설계

- frontend shared hook은 임시 이미지 전체 session, editor HTML/JSON 및 참조 이미지 snapshot, upload 상태, orphan/cancel/success 정리를 소유한다.
- shared clipboard normalizer는 표가 아닌 HTML paste에서도 안전한 font-family/font-size 서식을 inline span으로 보존한다. `<font face/size>` legacy attrs와 block style을 지원한다. Excel table은 행/열 및 병합 구조가 맞고 cell non-whitespace text가 일치할 때 `text/plain` TSV의 줄바꿈/공백을 해당 HTML cell 내용에 반영하며, HTML의 merge attrs와 cell-level styles는 유지한다. 구조나 문자가 일치하지 않으면 HTML에서 안전하게 fallback해 문자를 버리지 않는다. plain-text fallback도 탭과 공백을 유지하고 CRLF만 LF로 정규화한다. 저장 JSON은 재오픈할 때 줄바꿈을 수정하지 않는다. CSS `font` shorthand와 class 기반 `<col>` width를 Tiptap 속성으로 변환한다. `colspan` 셀은 전체 span 구간이 비어 있는지 검사해 기존 `rowspan` 영역과 겹치지 않는 열 위치에 배치한다. backend HTML/JSON sanitizer는 안전한 cell font-family/font-size를 저장 시 보존한다.
- Notice/Draft dialog는 도메인별 업로드/삭제 API adapter, 검증 메시지, 폼 상태, 저장 DTO mapping, close/dirty-confirmation 정책을 유지한다.
- backend shared `EmbeddedImageDocumentProcessor`는 JSON/HTML 참조 수집, null-safe token 처리, session/owner 검증, promotion, stable URL rewrite, retained file ID 계산을 소유한다.
- processor는 현재 본문 image metadata와 full temporary session을 분리 입력으로 받는다. 상세 metadata의 filename/file details는 우선 사용할 수 있지만, 새 token 승격 권한은 full session membership 검증을 통과해야 한다.
- backend shared `RichTextDocumentSanitizer`는 Notice와 Draft가 함께 쓰는 HTML/JSON allowlist sanitizer를 소유한다. 공통 Tiptap schema와 기존 Notice text/table style 지원을 기준으로 하며, server-side에서 두 도메인 모두에 적용한다.
- 공통 sanitizer는 `textStyle`의 color/font family/font size, link/underline, 표 구조/허용 스타일, 제한된 이미지 크기를 보존하고 active content/event/CSS/script protocol은 제거한다. Owner별 이미지 stable URL 검증은 sanitizer의 중복 policy가 아니라 processor가 resolver/소유 metadata로 수행한다.
- 도메인 service는 권한/대상 유효성, 고정 owner type/ID, stable URL resolver, 업무 테이블 저장, 기존 owner-save completion을 유지한다. Notice/Draft 전용 editor sanitizer는 제거한다.
- Notice contract (`NOTICE/postId`), Draft contract (`DRAFTING_WORK_TEMPLATE/formId`), 기존 API/DB schema/ordinary attachments를 변경하지 않는다.

- 이 문서, dated plan/spec, design 및 result 동기화

## 완료 기준

- Notice와 Draft가 같은 hook/processor로 임시 이미지 session과 본문 이미지 영구화를 처리한다.
- null/missing token은 token 문자열로 처리하지 않으며, 미귀속/타 owner 이미지 접근은 계속 거절한다.
- 두 도메인의 URL, owner ID/type, API request/response, row save behavior가 유지되며 같은 HTML/JSON sanitizer 정책을 적용한다.
- 관련 frontend/backend focused tests, frontend build, backend full tests, `git diff --check`가 통과한다.
- 브라우저 runtime 적용 여부와 검증 한계를 결과 문서에 분명히 기록한다.
