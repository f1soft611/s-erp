# 시스템 정책 관리 작업지시서

- 중앙에서 구성한 화면·정책을 기존 테넌트 DB 복제·배포 구조로 제공한다. 테넌트 선택·계정 생성·프로비저닝 기능은 추가하지 않는다.
- 현재 로그인한 테넌트에서 플랫폼 관리자만 정책을 추가·조회·수정·삭제한다. 테넌트 관리자에게 자동 허용하지 않는다.
- 정책 코드·이름·분류·설명·값 타입과 값을 쉽게 설정한다. 사용 여부, 숫자, 단일 선택, 문자열, 날짜, 사용자 목록을 지원한다.
- 기존 납품계획 운영 방식과 초과납품 정책을 화면에서 변경할 수 있도록 연결하되 기존 값을 보존한다.
- 실제 DB 적용은 하지 않는다. 필요한 DDL·메뉴·권한 스크립트와 조건부 롤백을 제공한다.
- 문서 → 실패 테스트 → 구현 → 최소 검증·반응형 브라우저 → 결과서 순서로 진행한다.
