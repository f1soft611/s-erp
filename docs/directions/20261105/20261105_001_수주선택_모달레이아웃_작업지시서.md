# 수주 선택 모달 레이아웃 작업지시서

- 사용자 보고: 납품등록에서 수주 선택 모달의 검색/표가 깨져 보인다.
- 첨부 화면과 코드 비교 결과, 페이지용 `PageSearchArea`는 검색 입력 너비를 360px로 제한하며 별도 버튼을 flex 배치한다. 모달에는 같은 제한이 불필요해 검색줄 중간에 빈 공간이 크게 생긴다.
- 그리드 열 너비 합계가 최대 1080px이며 CommonDialog lg의 내부 폭(약 940px)보다 커, 데스크톱에서도 마지막 잔량 열 일부가 가려지고 불필요한 가로 스크롤이 생긴다.
- 모달 전용 검색줄은 사용 가능한 폭을 채우게 하고, 표 열 너비를 줄여 1030px 이상 화면에서는 모두 보이게 한다. 소형 화면에서는 그리드 내부 가로 스크롤만 허용한다.
- 수주 선택, 검색 요청/Enter, 한 수주의 전체 잔량 품목 선택 동작과 기존 Dialog 크기/공통 컴포넌트는 유지한다.
- 진행 순서: 작업지시서→계획서→사양서→회귀 테스트 실패 확인→최소 UI 수정→실제 브라우저 비교 및 결과 문서/스크린샷.
