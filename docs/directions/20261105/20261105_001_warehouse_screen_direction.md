# 20261105_001 창고등록 화면 작업지시서

## 배경

`tb_warehouse` 테이블이 실무 구조(창고코드/창고명/창고구분 등)로 재생성되었다 ([[20261105_001_create_warehouse_schema.sql]] 참고). 기존 `settings/system/warehouses` 화면은 테스트용으로 메뉴에 등록되지 않은 상태였으므로, `co/master/customers` 화면 패턴을 기준으로 실무용 창고등록 화면을 새로 만든다.

## 지시 사항 (사용자 원문 요약)

- 화면 경로: `co/master/warehouse` (단일 화면, `tb_warehouse` 단일 테이블 기준)
- 기존 `settings/system/warehouses` 관련 화면/코드는 전부 삭제한다 (메뉴 미등록 상태라 영향 없음).
- 작업 순서: **화면부터 구현 → 이후 메뉴/권한 설정**은 별도 작업으로 진행한다. 이번 작업 범위는 화면(프론트) + 데이터 저장(백엔드) 구현까지다.

## 화면 컬럼 순서 및 입력 방식

| 순서 | 필드 | 컬럼 | 입력 방식 |
|---|---|---|---|
| 1 | 창고코드 | warehouse_code | 사용자 직접 입력 가능. 빈칸으로 두면 `001` 형식(3자리, 0패딩)으로 자동 순번 생성 |
| 2 | 창고명 | warehouse_name | 사용자 입력 |
| 3 | 창고구분 | warehouse_type | 공통코드 `WAREHOUSE_TYPE` 콤보박스 |
| 4 | 삭제불가 | delete_lock_at | 체크박스 |
| 5 | 불용창고 | disuse_at | 체크박스 |
| 6 | 현재고표시 | stock_qty_disp_at | 체크박스 |
| 7 | 수불처리 | stock_io_at | 체크박스 |
| 8 | 안전재고미달알림 | safety_stock_alert_at | 체크박스 |
| 9 | 재고현황기본조회 | stock_default_at | 체크박스 (사용자 지시 원문에 `stock_default_at`가 안전재고미달알림/재고현황기본조회 두 항목 모두에 쓰였으나, DB 컬럼은 `safety_stock_alert_at`(안전재고미달알림), `stock_default_at`(재고현황기본조회)로 이미 분리되어 있어 DB 컬럼 기준으로 정정함) |
| 10 | 사업장 | plant_id | 콤보박스, 현재는 `0:사내 / 1:외부` 고정값만 (추후 별도 테이블 참조로 교체 예정) |
| 11 | 담당자 | manager_user_id | 사원 선택 — 문서관리>문서작성(기안양식) 화면의 사원 선택 기능과 동일한 방식(사원 이미지 + 이름 표시). 선택 시 해당 사원의 부서를 `department_id`에 자동 반영 |
| 12 | 담당부서 | department_id | 담당자 선택 시 자동 설정, 현재는 직접 수정 불가 |
| 13 | 전화번호 | tel_no | 사용자 입력 |
| 14 | 팩스번호 | fax_no | 사용자 입력 |
| 15 | 주소 | address | 사용자 입력 |
| 16 | 비고 | remark | 사용자 입력 |

## 완료 기준

- `co/master/warehouse` 경로로 화면 접근 시 창고 목록 조회/등록/수정이 가능하다 (삭제는 거래처 화면과 동일하게 미지원, 필요 시 불용창고 체크로 대체).
- 창고코드 자동 순번, 사원선택 연동, 공통코드 콤보가 명세대로 동작한다.
- 기존 `settings/system/warehouses` 소스가 제거된다.
- 메뉴/권한 등록은 이번 작업 범위에서 제외하고 다음 작업으로 넘긴다.
