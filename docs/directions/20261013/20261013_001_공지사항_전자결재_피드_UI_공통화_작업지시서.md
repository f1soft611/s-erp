# 20261013_001 공지사항·전자결재 피드 UI 공통화 작업지시서

## 목적

공지사항을 기준으로 좌측 피드 카드와 우측 상세 패널의 공통 UI를 컴포넌트화하고 공지사항과 전자결재가 조립해 사용하도록 한다. 기능별 API, 데이터 로딩, 권한 및 업무 동작은 각 기능에 유지한다.

## 기준

- [승인된 설계](../../superpowers/specs/2026-10-13-notice-approval-feed-commonization-design.md)
- [구현 계획](../../plan/20261013/20261013_001_공지사항_전자결재_피드_UI_공통화_계획서.md)
- [상세 사양](../../spec/20261013/20261013_001_공지사항_전자결재_피드_UI_공통화_상세사양서.md)
- 좌측 카드 스타일 및 댓글 UX는 기존 공지사항 피드를 기준으로 한다.
- 전자결재 결재선 참고 화면과 댓글 영역 참고 화면은 사용자 첨부 이미지 1, 2를 기준으로 한다.

## 요구사항

1. `FeedView`를 사용하는 좌측 피드에서 공지사항과 전자결재가 공통 피드 카드 표시 컴포넌트를 사용한다.
2. 공지사항의 현재 카드 모양과 핀/첨부/본문 확장/좋아요/북마크/댓글 동작을 유지한다.
3. 우측 패널은 공통 헤더/닫기/스크롤 구조를 사용하고, 첨부·반응·이전 댓글·댓글 영역을 공통 섹션으로 조립한다.
4. 공지사항과 전자결재 모두 공통 패널과 하단 섹션을 사용한다. 데이터/API/권한은 각 기능에서 공급한다.
5. 전자결재 상세는 상단에 기안자/기안일 메타정보와 읽기 전용 결재선을 둔다. 결재·합의·참조의 실제 참여자만 표시하며 문서 제목/본문/이미지 다음에는 공통 하단 영역을 배치한다.
6. 시스템 이력은 댓글 타임라인에 통합하고 `시스템` 배지를 표시한다. 시스템 항목은 읽기 전용으로 답글·수정·삭제 조작을 제공하지 않는다.
7. 화면 구성 변경으로 공지사항의 댓글 페이지네이션, 첨부 다운로드, USER 댓글 CRUD, 전자결재의 결재/문서 동작을 깨뜨리지 않는다.
8. 최소 375px, 768px, 1280px에서 브라우저 렌더링과 가로 넘침을 확인하고 결과 문서 및 스크린샷을 저장한다.
9. 전자결재 상세에도 공지사항과 같은 본문 접기/더보기, 본문 이미지 미리보기, 카드 테두리를 적용한다.
10. 삭제 처리로 작성자 ID가 비식별화된 댓글을 포함해도 댓글 목록과 이전 댓글 페이지네이션이 정상 표시되고, 등록한 댓글이 새로고침 후에도 thread에 나타난다.
11. 본문 표시/접기/펼치기/이미지 미리보기 UI는 `FeedBodyContent` 공통 컴포넌트로 공지사항과 전자결재가 함께 사용한다. 도메인별 HTML 정리, 이미지 조회, 상태와 이미지 뷰어 연결은 기존 기능 영역에서 소유한다.
12. 전자결재 상세 결재 참여자 슬롯은 문서작성 모달의 32px/64px/32px 3행 레이아웃과 일치시키며, 결재·합의·참조 결재선 블록 마지막에 구분선을 둔다.
13. 전자결재 댓글은 최신 3개를 초기 표시하고, 이전 댓글은 기존 커서로 페이지를 이어서 조회한다. 이미지가 있는 본문은 확장 시 실제 인증 이미지를 본문 흐름에 표시하고, 접힌 상태에서는 제목 없는 미리보기만 표시한다. `[본문 이미지 ...]` 텍스트나 별도의 `본문 이미지` 제목은 표시하지 않는다.

## 범위 및 비범위

- 프런트엔드 공통 UI 컴포넌트와 공지사항/전자결재 소비자, 관련 테스트·문서만 변경한다.
- 백엔드/API/DB 변경, 반응 데이터 영속화, 결재 상태 전이는 범위에서 제외한다.
- 공통 컴포넌트는 기능 API, 인증, 업무 권한 결정을 포함하지 않는다.

## 완료 조건

- 좌측 카드와 우측 상세 패널의 공통 배치/스타일이 공지사항 기준으로 두 기능에 동일하게 적용된다.
- 기능별 고유 정보는 공통 컴포넌트의 slot/props로 조립되며, 각 도메인 서비스와 권한 로직은 유지된다.
- SYSTEM 댓글에 시스템 배지가 보이고 USER 댓글 동작은 기존과 동일하다.
- 공지사항과 전자결재 본문이 공통 표시 컴포넌트 및 동일한 본문/이미지 동작을 사용한다.
- 전자결재 결재선이 작성 모달 레이아웃과 정렬되고, 3개 최신 댓글 뒤에 이전 댓글 보기가 제공된다.
- 관련 Vitest, 프로덕션 빌드, 브라우저 반응형 검증이 완료된다.
- 결과보고서와 375px/768px/1280px 스크린샷이 `docs/result/20261013/notice-approval-feed-commonization`에 저장된다.
