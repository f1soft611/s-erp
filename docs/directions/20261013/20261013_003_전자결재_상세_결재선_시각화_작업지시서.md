# 20261013_003 전자결재 상세 결재선 시각화 작업지시서

## 목적

전자결재 상세 본문 위의 읽기 전용 결재선을 사용자가 공유한 화면과 같은 정돈된 결재 패널로 표현한다. 공유 이미지가 시각 기준이며, 앞서 선택한 A안은 카드 흐름의 방향만 보완한다.

- 시각 방향: 사용자가 공유한 결재선 이미지(옅은 배경의 둥근 패널, 한 줄 헤더, 원형 상태 도장, 합의/참조 칩)

## 작업 요구사항

1. 결재선, 기안자명, 기안일을 패널 상단 한 줄에 배치한다. 기존 문서 더보기/고정/결재상태 기능은 같은 헤더 오른쪽에 유지하며 별도 작성자 아바타 줄은 중복 표시하지 않는다.
2. 승인 카드와 합의/참조 표시를 하나의 옅은 배경·둥근 테두리 패널에 넣고, 실제 결재선 참여자 데이터만 렌더링한다.
3. 승인 참여자는 `stageOrder`, `participantOrder` 순으로 배치하고 카드 사이 화살표로 순서를 표시한다. 기존 작성 화면과 같은 `32px/64px/32px` 세 행 슬롯 구조는 유지한다.
4. 가운데 슬롯은 상태 텍스트를 원형 도장처럼 표시한다. `WAITING`, `PENDING`, `APPROVED`, `REJECTED`, `RETURNED`를 의미 색상과 기존 라벨로 구분하고 `PENDING`을 현재 처리자로 강조한다.
5. 승인 참여자의 부서, 이름, 처리 의견, 순번은 유지한다. 좁은 패널은 결재 카드 흐름만 내부 가로 스크롤하며 문서 전체 가로 넘침을 만들지 않는다.
6. 승인 카드 그룹과 합의/참조 칩 사이에 내부 구분선을 둔다. 합의 및 참조는 이미지처럼 `합의 · 부서 이름`, `참조 · 부서 이름` 형식으로 표시한다.
7. 결재선 패널 아래의 기존 구분선, 읽기 전용 동작, API/DB 계약은 유지한다. 결재 처리·수정·선택 동작은 추가하지 않는다.
8. 기존 미커밋 변경은 보존하고 이 작업과 직접 관련된 UI·테스트·문서만 수정한다.

## 완료 조건

- 공유한 이미지처럼 패널 외곽, 헤더, 원형 상태 도장, 승인 순서 연결, 합의·참조 칩이 구성된다.
- 상태별 표현과 현재 `PENDING` 단계 강조가 상세 패널에서 확인된다.
- 상태별 회귀 테스트가 실제 결재 데이터로 통과하고 결재선에 조작 버튼이 없다.
- 합의/참조와 기존 문서 상세, 댓글, 첨부 동작은 변경되지 않는다.
- 프론트엔드 집중 테스트와 프로덕션 빌드가 통과한다.
- 375px, 768px, 1280px 렌더링 및 가로 넘침을 실제 브라우저에서 확인하고 결과 문서와 캡처를 저장한다.
