# 20260921_002 공지사항 작성 모달 제목 강조 및 이미지 노드 리사이즈 작업지시서

## 작업 분류

- 경로: `bounded`
- 대상: 프론트엔드
- 관련 화면: `/groupware/community/notice`

## 작업 목적

공지사항 작성 모달의 제목 입력 텍스트를 피드 제목과 같은 굵기로 표시하고, 본문 이미지가 선택된 노드 영역에서 직접 크기 조절되도록 편집 동작을 보완한다.

## 요구사항

1. 작성·수정 모달의 제목 입력 텍스트는 피드 제목과 동일한 굵기 수준(`fontWeight: 700`)으로 표시한다.
2. 본문 이미지를 클릭하면 Tiptap 이미지 노드 선택 영역과 테두리가 표시된다.
3. 선택된 이미지 노드의 네 모서리와 네 변에 리사이즈 영역을 표시한다.
4. 모서리 드래그는 이미지 비율을 유지하며 너비와 높이를 함께 조절한다.
5. 변 드래그는 해당 축의 크기만 조절한다.
6. 이미지 크기 변경값은 Tiptap 이미지 노드의 `width`·`height` 속성에 반영되어 저장·재조회 시 유지된다.
7. 이미지 너비는 기존 제한 범위인 120~1200px 안에서 조절한다.
8. 별도의 우측 고정 핸들 버튼은 제거하고, 노드 경계 기반 리사이즈 UI로 통일한다.
9. 이미지 업로드, 본문 이미지 URL 재작성, 이미지 클릭 미리보기, 첨부파일 동작은 유지한다.

## 현재 코드 기준 원인 가설

- 현재 구현은 이미지 선택 여부에 따라 문서 바깥에 고정된 우측 핸들 버튼을 생성하므로, 사용자가 기대하는 이미지 노드 영역 기반 조절 UI와 동작이 다르다.
- 리사이즈 포인터 이동은 이미지의 `width`만 갱신하므로 모서리 조절, 세로 크기 저장, 비율 유지 요구를 충족하지 못한다.
- 제목 입력 컴포넌트에는 피드 제목과 동일한 굵기 스타일이 명시되지 않았다.

## 권장 설계

- `NoticeComposerDialog`의 기존 이미지 선택·Tiptap 명령 흐름을 유지한다.
- 선택된 이미지 DOM의 경계에 오버레이 리사이즈 영역 8개를 배치한다.
- 오버레이는 선택 이미지의 위치와 크기를 추적하고, 창 크기·스크롤·에디터 업데이트에 맞춰 재배치한다.
- 포인터 방향에 따라 모서리는 원본 비율을 유지하고 변은 단일 축만 변경한다.
- 변경된 크기는 `updateAttributes('image', { width, height })`로 문서 노드에 저장한다.
- 제목 입력에는 `fontWeight: 700`을 적용한다.

## 완료 기준

- 제목 입력 텍스트가 피드의 제목 텍스트와 같은 굵기로 표시된다.
- 이미지를 클릭하면 노드 선택 테두리와 조절 영역이 나타난다.

- 기존 이미지 업로드·미리보기·본문 저장 동작이 회귀하지 않는다.
