# 20260921_005 공지사항 제목·본문 조회수 진입 작업지시서

## 작업 분류

- 경로: `bounded`
- 대상: 프론트엔드
- 관련 화면: `/groupware/community/notice`
- 연계 API: `GET /api/v1/groupware/boards/notice/posts/{postId}`

## 작업 목적

공지사항 본문이 짧아 `더보기` 버튼이 렌더링되지 않는 경우에도 사용자가 제목·본문·이미지·첨부파일·댓글 영역을 클릭하면 상세 조회 API가 호출되고, 기존 서버 정책에 따라 사용자별 최초 1회만 조회수가 증가하도록 한다.

## 현재 문제

- 긴 공지는 `더보기` 클릭이 상세 조회 API 진입점으로 동작한다.
- 제목과 내용이 짧거나 비어 있는 공지는 `더보기` 버튼이 없어 상세 조회 API가 호출되지 않는다.
- 결과적으로 사용자가 공지를 실제로 확인해도 조회수가 증가하지 않는다.

## 요구사항

1. `더보기` 버튼이 있는 공지는 `더보기` 클릭에서만 상세 조회 API를 호출한다.
2. `더보기` 버튼이 있는 공지의 제목·본문·이미지·첨부파일·댓글 클릭은 조회수 증가를 호출하지 않는다.
3. `더보기` 버튼이 없는 공지의 제목·본문·이미지·첨부파일·댓글 클릭은 상세 조회 API를 호출한다.
4. 이미지 뷰어, 첨부파일 다운로드, 댓글 동작은 조회 API 호출과 별개로 기존 동작을 유지한다.
5. 목록 API 호출이나 화면 렌더링만으로 조회수를 자동 증가시키지 않는다.
6. 서버 응답의 `viewCount`를 기준으로 피드 메타를 갱신한다.
7. 같은 사용자의 반복 클릭은 서버의 조회 이력 유니크 정책에 따라 추가 증가하지 않는다.
8. 조회 API가 실패해도 기존 피드·이미지·첨부파일·댓글 동작은 유지하고 오류 메시지만 표시한다.
9. 메뉴 클릭은 조회수 증가 트리거에서 제외한다.
10. 기존 좋아요·북마크·수정·삭제 동작은 유지한다.

## 접근 방식 비교

### 대안 A: 목록 로딩 시 내용 없는 공지 자동 증가

- 장점: 구현이 단순하다.
- 단점: 사용자가 공지를 읽지 않아도 증가하며 목록 조회와 상세 열람의 의미가 섞인다.
- 판정: 사용자가 실제로 확인한 시점을 보장하지 못하므로 채택하지 않는다.

### 대안 B: 제목·본문 클릭을 상세 조회 진입점으로 추가

- 장점: 현재 `더보기`와 동일한 상세 조회 계약을 재사용하고, 실제 사용자 의도를 기준으로 증가시킨다.
- 단점: 클릭 가능한 영역의 접근성·버튼 전파를 함께 점검해야 한다.
- 판정: 기존 구조와 조회수 정책에 가장 부합하므로 채택한다.

### 대안 C: 공지 내부의 의미 있는 상호작용도 상세 조회 진입점으로 추가

- 장점: 이미지·첨부파일·댓글을 통해 공지를 실제로 확인하는 경우에도 열람을 기록할 수 있다.
- 단점: 각 하위 클릭 동작을 유지하면서 동일 공지의 중복 상세 요청을 차단해야 한다.
- 판정: `더보기`가 없는 공지에만 적용해 실제 열람 진입점을 보완하는 방식으로 채택한다.

## 구현 범위

- `NoticeFeedList`에서 `더보기`가 없는 공지의 제목·본문·이미지·첨부파일·댓글 클릭 이벤트를 기존 상세 조회 콜백과 연결한다.
- `CommunityNoticePage`의 기존 상세 조회·피드 갱신 콜백을 재사용한다.
- 클릭 가능한 제목·본문에 키보드 접근성 및 공지별 중복 요청 방지 상태를 적용한다.
- 하위 동작의 원래 이벤트와 조회 이벤트를 함께 처리하되, 메뉴 클릭은 제외한다.
- 관련 Vitest 회귀 테스트와 프론트 빌드를 실행한다.
- 결과 문서에 재현 조건과 검증 결과를 기록한다.

## 제외 범위

- 백엔드 조회수 정책·DB 구조 변경
- 목록 조회 시 자동 조회수 증가
- 조회수 중복 정책 변경
- 제목·본문 외 카드 여백 전체 클릭 처리
- 첨부파일·이미지·댓글의 기존 동작 변경

## 완료 기준

- 내용 없는 공지의 제목 클릭 시 상세 조회 API가 호출된다.
- 내용 없는 공지의 본문 클릭 시 상세 조회 API가 호출된다.
- `더보기`가 없는 공지에서 이미지 뷰어·첨부파일·댓글 동작과 상세 조회 API가 함께 동작한다.
- `더보기`가 있는 공지에서 제목·본문·이미지·첨부파일·댓글 클릭만으로는 조회수가 증가하지 않는다.
- 서버 응답의 조회수가 피드에 반영된다.
- 기존 `더보기` 공지와 관련 인터랙션이 회귀하지 않는다.
- 관련 테스트와 빌드 결과가 결과 문서에 기록된다.
