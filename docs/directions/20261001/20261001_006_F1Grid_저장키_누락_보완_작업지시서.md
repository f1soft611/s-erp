# 20261001_006 F1-Grid 저장 키 누락 보완 작업지시서

## 작업 요청

실제 렌더링되는 모든 `F1Grid`와 `F1Tree` 사용처에 중복되지 않는 `storageKey`를 지정한다.

## 기준

- 기존 `storageKey` 값은 유지한다.
- 업무 화면, 보조 다이얼로그, 설정/문서 플레이그라운드의 JSX 인스턴스에 각각 안정적인 키를 부여한다.
- 하나의 플레이그라운드 구현이 `kind`별 컬럼을 표시하면 종류를 키에 포함한다.
- 문서의 코드 예제 문자열과 F1Grid/F1Tree 내부 구현은 호출 인스턴스가 아니므로 제외한다.
- 공개 F1-Grid 문서에 키의 고유성 및 미지정 시 저장하지 않는 동작을 설명한다.

## 완료 기준

- `frontend/src`의 화면 및 공용 컴포넌트에서 사용하는 모든 F1Grid/F1Tree에 키가 지정되어 있다.
- 실제 키 값이 중복되지 않는다.
- 누락 및 중복을 잡는 자동 회귀 테스트, 프론트엔드 빌드가 통과한다.
- 구현 내용과 검증 결과를 결과 문서에 기록한다.
