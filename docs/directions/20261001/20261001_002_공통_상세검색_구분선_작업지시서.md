# 20261001_002 공통 상세 검색 구분선 작업지시서

## 작업 목적

`PageSearchArea` 상세 검색 오버레이에서 검색 필드와 하단 우측 액션 버튼 사이를 전체 폭 가로 구분선으로 시각적으로 분리한다.

## 범위

- 프론트엔드 공통 컴포넌트 `PageSearchArea`
- 구분선은 MUI `Divider`로 표시하고 기존 필드, 버튼 정렬 및 이벤트 동작을 유지한다.
- 회귀 테스트에서 상세 검색 오버레이 내 가로 separator 노출을 확인한다.
- 백엔드/API/검색 상태 동작은 변경하지 않는다.

## 완료 기준

- 상세 검색 오버레이에서 필드와 하단 액션 사이에 전체 폭 구분선이 표시된다.
- 기존 초기화/조회/닫기 동작은 변경되지 않는다.
- 관련 테스트와 프론트엔드 빌드가 통과한다.
- 변경 내용과 검증 결과를 `docs/result/20261001/common-search-divider/`에 기록한다.
