# 20261001_003 전자결재 기안양식관리 화면 보정 작업지시서

## 작업 분류

- 경로: bounded
- 대상: S-ERP 프론트엔드 기안양식관리 및 공통코드 분류 도움창
- 기준 화면: 모듈관리 페이지의 그리드 상단 간격
- 관련 선행 작업: [20261001_001 전자결재 기안양식관리](./20261001_001_전자결재_기안양식관리_작업지시서.md)

## 배경

기안양식관리와 분류 설정 화면을 사용하면서 그리드 편집, 저장 피드백, 컬럼 표시 및 상단 간격의 보정이 필요하다. 기존 기안양식 사양서의 저장 계약과 분류 데이터 구조는 유지한다.

## 작업 목적 및 요구사항

1. 분류 ID의 저장 컬럼을 `drafting_work_category_group_id`로 변경하거나 `category_item_id`를 제거하지 않는다. 현행 `category_item_id` 및 `WF_FORM_CATEGORY` 공통코드 계약과 DB 스키마를 유지한다.
2. 기안양식 분류 설정 모달은 그리드가 사용 가능한 콘텐츠 영역을 채우고, 행이 많을 때 스크롤은 모달 내부 그리드 영역에서 발생해야 한다.
3. 분류 설정은 별도 폼 모달 없이 F1-Grid의 행 추가 및 셀 편집으로 수행한다. 추가 행과 기존 저장 행의 수정 모두 dirty로 추적되어 하단 저장 동작에 반영되어야 한다. 수정하지 않은 저장 행은 dirty로 처리하지 않는다.
4. 분류 저장 중에는 그리드 전체를 가리는 과도한 로딩 표시 대신 조용하고 비차단적인 저장 상태를 표시한다. 오류는 기존 오류 표시 흐름을 유지한다.
5. 기안양식 그리드의 select 컬럼은 저장된 항목을 수정 없이 열었다 닫아도 dirty가 되지 않아야 한다. 편집 중 선택한 값은 ID로 저장하되, 일반 표시 상태에서는 대응하는 이름(label)을 표시한다.
6. 검토자와 승인자를 지정하지 않은 경우 선택값은 `선택 안 함`으로 표시하고 null 값 계약을 유지한다.
7. 기안양식관리 그리드 상단 여백을 모듈관리 페이지의 기준 간격과 일치시킨다.
8. 그리드에 저장되지 않은 변경이 있을 때 조회 또는 상세검색으로 현재 행이 교체되려 하면 기존 관리 페이지와 동일한 `UnsavedChangesConfirmDialog` 확인을 표시한다. 취소는 편집값을 유지하고, 계속은 변경을 버린 뒤 요청한 조회를 수행한다.
9. 분류 설정 모달도 변경사항이 있는 상태에서 닫기 또는 취소를 누르면 동일한 확인을 표시한다. 취소는 모달과 변경사항을 유지하고, 계속은 변경사항을 버리고 모달을 닫는다.

## 범위

- 기안양식 분류 도움창의 그리드 레이아웃, 행 추가/편집, 변경 추적, 저장 중 표시를 보정한다.
- 기안양식 그리드 select 편집/표시 및 dirty 추적을 보정한다.
- dirty 상태에서 조회/상세검색 또는 분류 모달 닫기로 변경사항이 유실될 수 있는 경우 공통 확인 다이얼로그를 적용한다.
- 검토자/승인자 미선택 표시와 기안양식 그리드 상단 간격을 보정한다.
- 관련 프론트엔드 회귀 테스트, F1-Grid 사용자 문서 및 작업 결과 문서를 갱신한다.
- UI 변경에 대해 최소 375px, 768px, 1280px 브라우저 화면을 확인하고 스크린샷을 결과 폴더에 보관한다.

## 제외 범위

- `category_item_id`, `drafting_work_category_group_id`, `tb_drafting_work_category_group`의 DB/API 계약 변경
- PostgreSQL 스키마 또는 데이터 변경, 백엔드 API/서비스 수정
- 공통코드 분류 모델 변경이나 새로운 분류 관리 정책
- F1-Grid 코어의 범용 동작 변경. 코어 변경이 필요하면 별도 범위 승인을 먼저 요청한다.
- 기안양식관리와 무관한 화면 또는 기존 테스트 실패 수정

## 완료 기준

- 분류 설정 모달에서 그리드가 남은 콘텐츠 영역을 채우며, 긴 목록은 모달 내부에서 스크롤된다.
- 별도 행 폼 모달 없이 행 추가와 셀 편집으로 추가/수정이 가능하며, 추가 및 실제 수정만 dirty로 표시된다.
- 저장 진행 표시는 조용하고 비차단적이며, 실패 시 오류 메시지를 확인할 수 있다.
- 저장된 기안양식 select 값은 미변경 편집 시 dirty가 되지 않고, 표시 상태는 이름을 보여주며 저장값은 기존 ID 계약을 유지한다.
- 검토자/승인자 미선택은 `선택 안 함`으로 보이고 null로 저장된다.
- 그리드 상단 여백은 모듈관리 기준과 일치한다.
- dirty 상태에서 조회/상세검색을 요청하면 변경사항 확인이 표시되고, 취소/계속 각각 편집 유지/폐기 후 조회가 정확히 동작한다.
- 분류 모달의 닫기/취소도 dirty 상태에서 확인을 거치며 취소 시 편집내용이 유지된다.
- 관련 테스트와 프론트엔드 빌드 결과가 기록되고, 375/768/1280px 브라우저 확인 및 스크린샷이 결과 문서에 포함된다.
- F1-Grid 동작 문서와 `docs/result/20261001/drafting-work-form-management/`의 진행 원장/결과 문서에 변경과 검증 결과가 반영된다.

## 승인 상태

- 상태: 변경 요구사항 반영 후 사용자 재승인 대기
- 기존 작업지시서는 승인되었으나 dirty 변경 확인 동작이 추가되어 범위 재승인이 필요하다. 재승인 후 계획서와 상세 사양서를 갱신해 다시 제시한다. 갱신된 두 문서의 별도 승인을 받기 전에는 구현, 테스트, 빌드 및 브라우저 검증을 시작하지 않는다.
