# 20261001_005 F1-Grid 사용자 선택 컬럼 작업지시서

## 작업 분류

- 경로: bounded
- 대상: F1-Grid 공용 컬럼, 기안양식관리 프론트엔드, 기안양식 사용자 옵션 API, 관련 문서
- 기준 설계: [F1-Grid 사용자 선택 컬럼 설계](../../superpowers/specs/2026-10-01-f1-grid-user-selector-design.md)
- 첫 적용 메뉴: 기준정보 > 전자결재관리 > 기안양식관리 (`/co/workflow/form`)

## 배경 및 목적

ERP 화면의 담당자 선택을 위해 F1-Grid에 전용 `user` 컬럼 타입을 추가한다. 단일/다중 선택을 지원하고, 이미지 참고처럼 검색 가능한 사용자 목록에 사진·이름·직급·부서를 표시한다. 그리드 셀 편집과 F1-Grid 행 폼 모달은 같은 사용자 선택 UI를 사용한다.

## 확정 요구사항

1. `F1GridEditorType`에 `user` 타입을 추가하고 사용자 옵션용 `F1GridUserOption` 및 `F1GridColumn.userOptions`를 제공한다.
2. 선택 모드는 `column.form?.multiple`로 결정하며 기본은 단일이다. 단일은 ID 또는 `null`, 다중은 ID 배열 또는 빈 배열로 값을 유지한다.
3. 옵션은 `value`, `label`과 선택적 `avatarUrl`, `positionName`, `departmentName`을 가진다. 표시 메타데이터는 저장값에 포함하지 않는다.
4. 셀 편집과 행 폼 모달에서 같은 컴포넌트를 쓰고, 검색 가능한 사용자 행·아바타·선택 칩·목록 스크롤을 제공한다.
5. 사용자 값 커밋은 `userOptions`의 원래 ID 타입을 보존하고 동일 선택은 dirty로 만들지 않는다.
6. 기안양식의 검토자/승인자는 기존 `loginId` 숫자 단일 값 및 미선택 `null`, 담당자는 기존 `userId` 문자열 배열 계약을 유지한다.
7. `/api/v1/co/workflow/forms/users`에 `profileImage`, `levelNm`을 추가한다. 기존 테넌트 및 활성 사용자/로그인 계정 필터를 유지한다.
8. `levelNm`은 같은 tenant의 활성 `LEVEL` 공통코드 항목에서 가져오고, 사진 또는 직급이 없어도 사용자를 반환한다.
9. DB 스키마, 저장 payload, 권한, 다른 화면의 동작은 변경하지 않는다.
10. F1-Grid 문서, 날짜별 작업 문서, 결과 문서 및 375/768/1280px 브라우저 스크린샷을 갱신한다.

## 구현 범위

- F1-Grid 타입, 셀 편집값/커밋, 셀 표시, 편집기, `GridFormField` 및 행 폼 모달 통합
- 기안양식 사용자 옵션 VO/Mapper/API 응답 및 프론트 타입/정규화
- 검토자·승인자·담당자 컬럼을 새 `user` 타입으로 전환하고 담당자 셀 편집 활성화
- 테스트, F1-Grid 문서, 기안양식 사용자 선택 작업 결과 문서

## 제외 범위

- 테이블/컬럼/FK/공통코드 데이터 변경 및 SQL 마이그레이션
- 기안양식 저장 필드나 기존 ID 타입의 변경
- 일반 사용자 검색 API 또는 서버 페이지네이션
- 첫 적용 외 다른 화면의 전환

## 완료 기준

- 단일/다중 선택 값이 셀 편집과 행 폼 모달에서 동일 계약으로 동작한다.
- 사진·직급·부서가 보이며 정보가 비어도 선택 UI가 안전하게 동작한다.
- 기존 ID 값 타입, null/배열 값, dirty 판정 및 tenant 보안 경계가 보존된다.
- 관련 프론트/백엔드 테스트, 빌드, 브라우저 검증이 완료되고 결과/스크린샷이 저장된다.
