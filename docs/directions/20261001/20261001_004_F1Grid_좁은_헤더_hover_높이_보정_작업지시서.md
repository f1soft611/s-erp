# F1-Grid 좁은 헤더 hover 높이 보정 작업지시서

## 배경

좁은 F1-Grid 컬럼 헤더에 마우스를 올리면 컬럼 메뉴가 나타나고 헤더 콘텐츠의 우측 여백이 늘어난다. 이때 헤더명이 여러 줄로 줄바꿈되며 공용 헤더 행 높이가 커질 수 있다.

## 목표

1. 좁은 헤더에서도 헤더명이 한 줄을 유지하고 공간이 부족하면 말줄임표로 표시한다.
2. 기존 컬럼 메뉴의 hover/focus 노출, 위치, 동작은 유지한다.
3. 전체 헤더명 접근성 라벨과 F1-Grid 문서 및 회귀 검증을 유지한다.

## 범위

- 대상: 공용 `GridHeader`, `f1-grid.test.tsx`, F1-Grid 문서
- 제외: 컬럼 너비/행 높이 정책 변경, 화면별 설정, 메뉴 기능 변경, 백엔드/API

## 완료 기준

- 좁은 헤더명이 한 줄 말줄임으로 표시되고 hover로 헤더 행 높이가 증가하지 않는다.
- 접근성 라벨에는 전체 헤더명이 유지되고 컬럼 메뉴가 계속 동작한다.
- 관련 Vitest, 프론트엔드 빌드, 실제 브라우저 hover 검증을 수행하고 결과를 기록한다.
