# 영업관리 폼 공통 날짜 입력 작업지시서

- 요청: 영업관리 모든 페이지의 폼 날짜 입력을 기존 공통 날짜 입력기로 통일한다.
- 기존 `DateEditor`의 outlined 변형을 재사용한다. 견적작성일·제출일, 수주일자·납기일자, 출하일자, 명세일이 대상이며, 거래명세서의 원천 출하일자는 비활성 공통 날짜 필드로 표시한다.
- 등록 폼을 재사용하는 현황 상세·수정에도 동일하게 적용한다. 이미 공통 입력기를 사용하는 검색조건과 F1Grid 셀은 변경하지 않는다.
- 필수/선택, 기본 날짜, 권한, 로딩·저장 중 비활성화, 기존 데이터 계약을 유지한다.
- 축약 날짜는 blur 및 저장 시 정규화한다. 존재하지 않는 날짜는 원문과 오류를 표시하고 저장을 차단한다.
- 작업지시서 → 계획서 → 상세사양서 → 테스트·구현 → 브라우저 검증·결과 순서로 진행한다.
- 별도 진행 중인 견적 레이아웃·품목 입력 변경을 덮어쓰지 않는다. 커밋은 생성하지 않는다.
