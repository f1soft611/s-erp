# 수주현황 컬럼 조정 작업지시서

근거: [회의 안건 설계안](../../superpowers/specs/2026-11-17-meeting-backlog-design.md) 3항

- 수주현황 그리드에서 수주상태(헤더 `status`) 컬럼을 숨긴다. 상세검색의 수주상태 조건은 유지한다.
- 행상태(`lineStatus`) 컬럼을 앞쪽(견적번호 다음, 기존 수주상태 위치)으로 옮기고 헤더명을 "업무상태"로 변경한다.
- 상세검색의 행상태 조건 라벨도 "업무상태"로 맞춘다. 조회 API·필드명·데이터 계약은 변경하지 않는다.
- 상세 패널의 행 표 헤더 등 다른 화면 문구는 이번 범위에서 변경하지 않는다.
- 프론트엔드만 수정하며 DB 변경·커밋은 하지 않는다.
- 계획서 → 상세사양서 → 실패 테스트 → 최소 구현 → 검증 → 결과 순서로 진행한다.
