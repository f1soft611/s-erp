# 영업 등록 화면 메시지 여백 통일 작업지시서

- 수주등록을 실제 기준 화면으로 사용한다.
- 기준 오류는 첨부 화면의 입력 검증 오류(품목 상세 미입력)다. 서버 오류만 비교하지 말고, 모든 상단 오류를 이 입력 검증 오류의 본문 직계 Alert 배치로 통일한다.
- 견적서작성, 출하등록, 출하계획등록, 거래명세서등록의 상단 성공·오류 메시지 좌우 및 위아래 여백을 수주등록과 동일하게 맞춘다.
- 각 화면의 기존 데이터, 저장, 권한, 대화상자 및 embedded 동작은 변경하지 않는다.
- 375/768/1280px에서 실제 수주등록과 각 화면의 성공·오류 배치를 비교하고 결과를 기록한다.
- 새 화면에서도 누락하지 않도록 메시지 종류와 무관한 여백 통일 및 실제 검증 기준을 `frontend/AGENTS.md`에 추가한다.
