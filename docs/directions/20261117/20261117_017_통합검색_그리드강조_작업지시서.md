# 통합검색어 그리드 강조 작업지시서

- 작업번호: 20261117_017
- 구분: 공통 기능 (F1-Grid)

## 요구사항
1. 현황 화면의 통합검색어와 일치하는 글자를 그리드 셀에서 빨간색으로 표시한다.
2. 강조 대상은 컬럼 속성(`highlightSearch`)으로 지정한다.
3. 영업관리 현황(수주·견적·출하·출하계획·거래명세서)에 먼저 적용한 뒤, 통합검색이 있는 나머지 F1-Grid 화면에 적용한다.
4. 그리드 렌더 성능을 저하시키지 않는다.

## 완료 조건
- 조회에 적용된 검색어와 일치하는 부분 글자만 빨간색으로 표시된다. 입력 중인 값은 반영하지 않는다.
- 대소문자를 구분하지 않고, 서버가 실제로 검색하는 컬럼에만 속성을 지정한다.
- 검색어가 없거나 `highlightSearch` 컬럼이 없으면 기존 렌더 경로와 동일하다.
- 관련 테스트, 타입 검사, F1-GRID.md·결과 문서가 갱신된다.
