# 공통코드 모듈 구분 작업지시서

- 근거: [회의 백로그 설계](../../superpowers/specs/2026-11-17-meeting-backlog-design.md) 항목 2
- 요구: 공통코드 그룹에 모듈 카테고리(공통/영업/생산/구매/품질)를 추가하고 목록에서 모듈별로 필터할 수 있게 한다.
- 범위: `tb_common_code_group.module_cd` 추가, 백엔드 조회/저장/배치저장 반영, 프론트 그룹 트리 컬럼·상세검색 필터.
- 제외: 상세코드, 다른 업무 화면의 공통코드 조회.
- 완료 조건: 기존 그룹은 COMMON, 모듈 필터 조회 가능, 잘못된 값은 서버에서 거부, 테스트 통과, DB 스크립트·이력 작성.
