# 견적현황 UI 정합성 작업지시서

- 견적현황 상세의 더보기 버튼을 수주현황과 동일한 아이콘·메뉴 표현으로 맞춘다.
- 견적현황에 통합검색 필드를 추가하고 견적번호·거래처·품목 검색이 실제 조회에 반영되게 한다.
- 상세보기 견적작성일·견적제출일에 공통 읽기전용 색상을 적용하고 입력·달력 편집을 차단한다.
- 기존 공통코드 연동, 날짜 필수 범위, 상세검색, 권한, 세션 복원 및 작성/수정 흐름은 보존한다.
- 계획서 → 상세사양서 → 실패 테스트 → 최소 구현 → 브라우저/회귀 확인 → 결과 및 스크린샷 순서로 진행한다.
- DB 스키마나 데이터 변경 및 커밋은 하지 않는다.
