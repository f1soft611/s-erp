# 그리드 소수점 관리 작업지시서

- 작업번호: 20261117_010
- 요구: 화면별 소수점 설정(1단계), 정책 관리의 모듈별 소수점 설정(2단계)

## 범위
1. 화면별: `F1GridColumn.decimalPlaces`(기존 지원) 유지.
2. 모듈별: 정책 관리에 `GRID_DECIMAL_{모듈코드}` NUMBER 정책을 등록하면 해당 모듈 화면의 기본 소수점으로 적용.
3. 모듈은 모듈관리(`tb_module.module_code`)의 코드를 사용한다.
4. 1차 적용 화면: 수주현황(SALES) 수량·단가·출하수량. 나머지 화면은 동일 훅으로 순차 확대.

## 완료 조건
- 정책 없음/조회 실패 시 기존 동작(2자리) 유지.
- 일반 사용자도 읽을 수 있는 테넌트 범위 조회 API 제공(관리자 전용 API 노출 금지).
- 백엔드/프런트 테스트, tsc 통과. F1-GRID.md 갱신.
