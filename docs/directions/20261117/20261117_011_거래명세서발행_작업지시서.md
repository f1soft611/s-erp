# 거래명세서 발행 작업지시서

- 작업번호: 20261117_011
- 요구: 거래명세서등록 → 거래명세서발행, 정책 관리에 자동/직접 발행 정책 추가, 자동이면 출하등록 시 자동 발행.

## 범위
1. 메뉴명 변경(`tb_menu` id 41).
2. 정책 `STATEMENT_ISSUE_MODE`(AUTO/MANUAL, 기본 MANUAL) 테넌트별 시드.
3. AUTO: 출하등록과 같은 트랜잭션에서 출하 1건당 명세서 1건 발행(출하 묶음 단위와 동일). 실패 시 출하도 롤백.
4. MANUAL: 기존 직접 발행 화면 사용(여러 출하 묶음 발행은 후속 과제).

## 완료 조건
백엔드 테스트 통과, DB 스크립트·롤백·이력 문서 작성.
