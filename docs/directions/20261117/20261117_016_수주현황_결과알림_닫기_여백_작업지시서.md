# 수주현황 결과 알림 닫기 여백 보정 작업지시서

근거: 사용자 제공 화면 및 재현 설명 (2026-11-17)

- 수주현황에서 조회 결과 알림의 닫기를 누른 뒤에도 그리드 위 기본 간격을 유지한다.
- 결과 알림이 보일 때 기존 간격은 바꾸지 않고, 다시 조회하면 결과 알림 표시와 간격이 정상적으로 복원되어야 한다.
- 공용 결과 알림의 다른 사용 화면과 조회·그리드 동작은 변경하지 않는다.
- 작업 순서: 계획서 → 상세사양서 → 실패 회귀 테스트 → 최소 수정 → 관련 테스트/빌드/lint → 결과 기록.
- 기존 미커밋 수정은 보존하고 커밋하지 않는다.
