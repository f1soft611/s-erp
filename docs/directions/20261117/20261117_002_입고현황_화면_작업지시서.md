# 20261117_002 입고현황 화면 작업지시서

## 작업 목적

등록된 입고(MI)를 조회하고, 상세를 보고, 값을 수정하거나 행을 빼거나 입고 전체를 취소하는 입고현황 화면을 만든다.
구조는 가입고현황(`20261116_013`)과 같다: 현황 목록 → 번호 링크 → 상세 패널 → 조회/수정 다이얼로그(입고등록 화면 `embedded`).
MES 입고현황(`WMA331_VW`, `SP_WMA331_01_LIST`)은 검토용으로만 참고한다.

## 확정 범위

### 화면 흐름
- 메뉴 `입고관리 > 입고현황`(입고등록 바로 다음). 권한은 READ, EXCEL.
- 검색(빠른 검색 + 상세검색) → 품목 행 단위 F1Grid(같은 입고는 헤더 셀 병합) → 입고번호 클릭 시 상세 패널 → 조회/수정 다이얼로그.
- 수정 가능 조건: 입고 상태가 정상이고 입고등록 메뉴의 UPDATE 권한이 있을 때.

### 취소건 조회 규칙 (2026-11-17 사용자 확정, 모든 현황 공통)
- 상태 검색 조건은 **정상(기본) / 취소 / 전체(취소 포함)** 세 가지이며 기본값은 정상이다. 취소건은 기본 조회에서 제외된다.
- 필수 조건이 아니므로 사용자가 취소·전체로 바꿔 조회할 수 있다.
- 이미 만든 현황 화면(구매요청·발주·가입고)은 입고 작업 종료 후 별도 작업으로 같은 규칙으로 맞춘다.

### 수정·행 삭제·취소
- 수정 가능: 입고일, 부가세구분·여부, 비고, 행의 수량·단가·세액·창고·제조일·소비기한·비고. 구매처·가입고 연결·품목은 바꾸지 않는다.
- 행 삭제: 수정 다이얼로그에서 체크 후 [선택 행 빼기] 후 저장. 모든 행을 뺄 수는 없고 모두 빼려면 입고 취소를 쓴다.
- 입고 취소: 입고 전체를 취소(`use_at='N'`, 이력 보존). 취소된 입고는 조회만 된다.
- 무검사 행의 수정은 가입고에 같이 반영되고, 취소·행 삭제는 연결된 가입고 행도 삭제한다(`20261117_001` 참고). 취소·행 삭제 전에 결과를 확인창에 안내한다.
- 수량이 발주 잔량을 넘으면 저장 전 확인창(예/아니오)을 띄운다.

### 입고 ↔ 가입고 연결 표시
- 목록과 상세에 가입고번호를 보여 준다. 가입고번호 링크로 가입고현황 상세로 이동할 수 있다.

## 제외 범위
- 출력, 입고등록으로 이동 버튼(수정은 다이얼로그에서 처리), 매입마감 표시, 재고·LOT 값 연결, 일괄 적용.

## 구현 절차
1. 계획서, 상세사양서
2. 메뉴 SQL(입고현황) 두 경로 사본
3. 백엔드 실패 테스트 → 구현(목록)
4. 프론트 실패 테스트 → 구현(현황 화면, 등록 화면 view/edit 모드)
5. 검증: 집중 테스트, 빌드, JDK 8 컴파일, 브라우저
6. 사용자 SQL 실행 후 MCP 확인, 결과 문서 `docs/result/20261117/material-receipt-status`

## 완료 조건
- 기본 조회는 정상 입고만 나오고, 상태를 취소·전체로 바꾸면 그에 맞게 조회된다.
- 번호를 눌러 상세를 보고 수정 다이얼로그에서 값 수정과 행 삭제가 저장된다.
- 입고 취소 후 연결된 가입고가 안내한 대로 정리된다. 취소된 입고는 수정·취소할 수 없다.
