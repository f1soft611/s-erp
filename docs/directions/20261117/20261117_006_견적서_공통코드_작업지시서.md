# 견적서 공통코드 작업지시서

- 사용자 요청: Incoterms·결제조건·화폐단위의 기존 공통코드 존재 여부를 확인하고, 누락분 seed를 제공한다.
- 견적 기본정보의 세 필드와 상세 그리드 단위를 공통코드 select로 변경한다.
- DB MCP로 현재 계약을 확인하고 기존 CURRENCY, ITEM_UNIT은 재사용한다.
- 작업 순서: 계획서 → 상세사양서 → 실패 테스트 → 구현 → 회귀·브라우저 검증 → 결과 문서.
- 기존 API 문자열, 선택 항목의 선택사항 정책, 저장·계산·권한과 과거 값을 보존한다.
- seed는 대상 테넌트를 명시하여 별도 적용하며 이 작업에서 DB에 쓰지 않는다.
