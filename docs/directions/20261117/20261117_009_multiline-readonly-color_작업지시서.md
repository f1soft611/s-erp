# 견적 비고 읽기전용 색상 오적용 작업지시서

- 견적작성에서 편집 가능한 비고가 읽기전용 회색으로 표시되는 문제를 수정한다.
- MUI multiline 내부의 높이 측정용 숨김 readonly textarea와 사용자가 실제 읽기전용인 입력을 구분한다.
- 공통 테마에서 원인을 수정하되 실제 disabled·readonly 및 선택 가능 마스터 입력의 기존 색상 정책은 유지한다.
- 계획서 → 상세사양서 → 실패 회귀 테스트 → 최소 수정 → 실제 브라우저 검증 → 결과 문서 순서로 진행한다.
- 사용자 중단 요청에 따라 커밋·푸시는 보류한다.
