# 영업관리 작성 기준일 서버날짜 통일 작업지시서

- 요청: 영업관리 작성화면에서 오늘 날짜를 기본값으로 사용하는 날짜 필드는 공통 시스템 날짜 API의 서버날짜로 초기화한다.
- 대상 폼: 견적작성, 수주작성, 출하작성, 거래명세서 작성. 견적은 이미 서버날짜를 사용하므로 회귀 확인만 한다.
- 새 작성 및 작성화면 초기화 시 서버날짜를 조회한다. 기존 자료 조회·수정 시 저장된 날짜를 유지하고, 원천 데이터에서 전달되는 날짜는 변경하지 않는다.
- 서버날짜 조회 실패 시 브라우저 날짜로 대체하지 않고 오류를 표시하며 재시도할 수 있도록 한다.
- 현황 검색의 기간 기본값은 오늘 날짜 단일값이 아니라 별도 정책이므로 이 작업 범위에서 제외한다.
- 기존 API·DB 계약, 입력 검증, 권한, 화면 동작을 유지한다.
- 작업지시서 → 계획서 → 상세사양서 → 테스트·구현 → 결과 문서화 순으로 진행한다.
- Flow 기본 프로젝트 `3005724`에 작업을 기록한다. 커밋은 생성하지 않는다.
