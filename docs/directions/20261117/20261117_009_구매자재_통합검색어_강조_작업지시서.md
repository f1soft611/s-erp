# 20261117_009 구매자재 현황 통합검색어 강조 적용 작업지시서

## 작업 목적

F1-Grid 공통 기능 "통합검색어 강조"(`highlightKeyword`/`highlightSearch`, 브랜치 socra710 커밋 `c9ded558`)가 구매모듈을 제외하고 반영되어, 구매 담당자가 적용해 달라는 요청이 Flow 글 [구매 그리드 통합검색어 강조 적용 안내](https://flow.team/l/QzH2C)(88354809)로 올라왔다(대표님 요청 기능). 글에 적힌 구매요청현황·구매발주현황 두 화면뿐 아니라 **구매자재 모듈에서 만든 현황 화면 전체**에 같은 방식으로 적용한다(2026-11-17 사용자 확정).

## 적용 대상

| 화면 | 통합검색어(서버 키워드 SQL)가 검색하는 컬럼 | 강조 컬럼 |
| --- | --- | --- |
| 구매요청현황 | 요청번호, 품목코드, 품목명, 요청자 | `requestNo`(링크), `materialCode`, `materialName`, `requesterName` |
| 구매발주현황 | 발주번호, 구매처명, 품목코드, 품목명, 발주담당자 | `orderNo`(링크), `supplierName`, `materialCode`, `materialName`, `ordererName` |
| 가입고현황 | 가입고번호, 구매처명, 품목코드, 품목명, 담당자 | `arrivalNo`(링크), `supplierName`, `materialCode`, `materialName`, `receiverName` |
| 입고현황 | 입고번호, 구매처명, 품목코드, 품목명, 담당자 | `receiptNo`(링크), `supplierName`, `materialCode`, `materialName`, `receiverName` |
| 자재수입검사현황 | 검사번호, 가입고번호, 구매처명, 품목코드, 품목명, 검사자 | `inspectionNo`(링크), `arrivalNo`(링크), `supplierName`, `materialCode`, `materialName`, `inspectorName` |
| 매입마감처리(입고 행) | 품목코드, 품목명 | `materialCode`, `materialName` |

- 서버가 실제로 검색하는 컬럼에만 `highlightSearch: true`를 지정한다(위 표는 매퍼 SQL에서 확인).
- 매입마감처리의 구매처 요약 그리드는 키워드로 구매처명을 검색하지 않으므로 강조하지 않는다.

## 제외·범위

- 서버 키워드 SQL, 검색 조건, 컬럼 구성은 바꾸지 않는다. 프론트 전달·컬럼 지정만 한다. DB·백엔드 변경 없음.
- 불러오기 창(선택기) 그리드는 현황 화면이 아니므로 이번 범위가 아니다.

## 선행 조건

- `origin/main`의 통합검색어 강조(PR #79)와 빠른 날짜 세팅(PR #80)을 병합했다(충돌은 `F1-GRID.md`만, 두 섹션 모두 유지).

## 구현 절차
1. 계획서, 상세 사양서(번호 `20261117_009`)
2. 현황 화면별 실패 테스트(검색 실행 후 일치 글자가 강조되는지) → 구현
3. 검증: 집중 테스트, `tsc`, 빌드, 실제 브라우저(1920/1280/768/375px)
4. 결과 문서 `docs/result/20261117/purchase-search-highlight`

## 완료 조건
- 위 여섯 화면에서 검색 실행 후 적용된 통합검색어와 일치하는 글자가 지정 컬럼 셀에서 빨간색으로 보인다. 입력 중인 값은 강조되지 않는다.
- 링크 컬럼(요청번호·발주번호·가입고번호·입고번호·검사번호)도 일치 글자가 강조되고 링크 동작은 그대로다.
- 검색어가 없으면 기존 렌더와 같다. 기존 구매 화면 테스트가 통과한다.
