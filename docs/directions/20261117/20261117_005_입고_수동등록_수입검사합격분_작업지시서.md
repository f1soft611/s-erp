# 20261117_005 입고 수동 등록(수입검사 합격분 불러오기) 작업지시서

## 작업 목적

수입검사(QI)를 마친 **합격분을 입고(MI)로 등록**한다. 입고등록 화면의 `수입검사 불러오기` 창(지금은 틀만 있음)을 실제 후보 조회와 저장에 연결하고, 합격분이 입고에 연결된 뒤의 **수입검사 수정·취소 제한**을 함께 구현한다.
무검사 품목은 가입고 저장 시 입고가 자동 생성되므로(`20261117_001`) 이번 작업의 대상이 아니다. MES 입고등록의 검사합격분 불러오기(`SP_WMA321_02_LIST`의 `GD_QTY > INPUT_QTY`)는 규칙 검토용으로만 참고하고, 화면 구조는 기존 입고등록·가입고등록 패턴을 따른다.
**필요한 것만 담은 간소한 뼈대**를 유지한다(재고·LOT·매입마감은 제외).

## 업무 흐름 (2026-11-16·17 사용자 확정)

발주(PO) → 가입고(MP) → [검사 대상] 수입검사(QI) → **입고(MI) 수동 등록(이번 작업)**. 무검사는 가입고 저장 시 입고 자동 생성(완료).

## 업무 규칙

### 입고 대상(불러오기 후보)
- 후보 = **정상 수입검사**(헤더 `use_at='Y'`)의 행 중 **입고 가능량 > 0**인 행. 입고 가능량 = 합격량 − 그 검사 행에 연결된 유효 입고(헤더 `use_at='Y'`)의 입고수량 합.
- 연결된 가입고 행이 살아 있고 가입고가 정상인 행만 후보로 한다(취소된 가입고의 검사는 후보에서 제외).
- 불합격량은 입고 대상이 아니다.

### 입고 등록
- 입고 1건 = 구매처 1곳·통화 1종. 불러오기에서 **첫 번째로 체크한 행의 구매처로 고정**하고(가입고 불러오기와 같은 칩 UX), 다른 구매처 행은 선택에서 제외한다. 통화가 다른 행은 한 입고에 담을 수 없다. 서로 다른 검사·가입고의 같은 구매처 행은 한 입고에 묶을 수 있다.
- 부가세 설정(구분·포함 여부)은 첫 행의 발주 설정을 기본값으로 하고 입고등록 화면에서 바꿀 수 있다(입고 전체 1설정, 발주·가입고와 같은 계산).
- 행 기본값: 입고수량 = 입고 가능량, 입고단가·입고창고·제조일·소비기한은 연결된 가입고 행의 값. 모두 입고등록 화면에서 수정할 수 있다. 입고일 기본 오늘, 담당자는 로그인 사용자.
- **입고수량은 그 검사 행의 입고 가능량을 넘을 수 없다**(합격분보다 많이 입고할 수 없다). 발주 잔량 초과 확인창 규칙(무검사 입고)과 다르다.
- 같은 검사 행을 한 입고에 두 번 담을 수 없다. 같은 검사 행을 여러 입고에 나눠 입고할 수 있다(분할 입고).
- 입고번호 `MI-YYYYMMDD-NNNN`(기존 번호 키 재사용). 검사번호를 입고 행에 복사해 저장하고 입고등록·입고현황에 보여 준다.

### 입고 수정·취소(검사 합격분 입고)
- 수정: 입고일·부가세 설정·비고, 행의 입고수량(상한 = 그 검사 행의 입고 가능량 + 이 입고의 기존 수량)·입고단가·세액·창고·제조일·소비기한·비고, 행 빼기(모든 행을 뺄 수는 없음, 취소 사용). **연결된 가입고와 검사에는 반영하지 않는다**(검사 대상 가입고 행은 검사에 의해 잠겨 있다).
- 취소 = 입고 헤더 `use_at='N'`(이력 보존). 가입고·검사는 그대로 두고 합격분의 입고 가능량만 복구되어 다시 입고할 수 있다.

### 수입검사 수정·취소 제한(이번 작업에서 구현)
- 합격분이 **유효 입고에 연결된 검사 행**이 있으면: 검사 취소 불가(해당 입고번호 안내), 그 행 빼기 불가, 합격량을 이미 입고된 수량 아래로 낮출 수 없다. 불합격량·비고·검사일 등 나머지는 수정할 수 있다(단 검사량 ≤ 검사 대기량 규칙은 그대로).
- 입고를 취소하면 제한이 풀린다. 막힌 경우 어느 입고에서 처리해야 하는지 입고번호를 안내한다.

### 사용자 안내와 편의
- 입고등록 화면 위쪽에 "입고 가능한 수입검사 합격분 N건" 안내(조회 조건과 무관한 전체 건수).
- 검사 화면에서 막힌 행·취소 버튼에 이유와 입고번호를 보여 준다.
- 입고 등록 후 "입고를 등록했습니다. 입고번호: MI-…"를 알린다.

## 범위

### 포함
- DB: `tb_material_receipt_dt`에 수입검사 행 연결 컬럼 추가(`material_inspection_detail_id` FK `ON DELETE SET NULL`, `inspection_no` 복사본), 인덱스, 롤백, 변경이력, `db-schema.md`(스크립트는 사용자가 실행).
- 백엔드: 합격분 후보 조회, 입고 수동 등록(POST), 입고 수정·조회에 입고 가능량 상한·검사번호 반영, 수입검사 서비스의 수정·취소 제한과 입고번호 안내.
- 프론트: 입고등록 화면 create 모드 활성화(불러오기 창 실제 연결, 구매처 고정, 저장), 입고 행·현황에 검사번호 표시, 수입검사 화면의 제한 안내.
- 테스트, 결과 문서(스크린샷 포함).

### 제외(별도 작업)
- 재고·LOT 연결, 매입마감, 입고 가능량 마감(분할 입고 종결), 샘플·특채 검사.
- 기존 현황 화면(구매요청·발주·가입고)의 상태 조회 3종 정비.

## 완료 조건
- 불러오기 창에 입고 가능량이 남은 정상 검사 행만 나오고, 입고하면 후보에서 빠지거나 입고 가능량이 줄어든다.
- 같은 구매처의 여러 검사 행을 한 입고(`MI-…`)로 등록할 수 있고, 입고수량이 입고 가능량을 넘으면 거부된다.
- 입고를 취소하면 입고 가능량이 복구되어 다시 입고할 수 있다.
- 입고된 합격분이 있는 수입검사는 취소·행 빼기·합격량 축소가 거부되고 입고번호가 안내된다. 입고를 취소하면 다시 가능하다.
- 입고 행과 입고현황에 검사번호가 보인다.
