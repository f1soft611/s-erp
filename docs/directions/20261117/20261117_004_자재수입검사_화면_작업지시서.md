# 20261117_004 자재수입검사 등록·현황 화면 작업지시서

## 작업 목적

가입고(MP) 다음 단계인 **자재 수입검사(QI) 등록과 현황**을 만든다. 검사 대상 가입고 행을 **불러와서** 검사량(합격량·불합격량)을 기록하고, 이후 입고(MI)의 합격분 불러오기가 이 결과를 쓴다. 여러 가입고 행을 한 번에 불러와 처리하면 **같은 검사번호로 묶인다**.
품질관리는 구매자재와 별개의 **새 모듈**로 만든다. 메뉴는 `품질관리 > 수입검사 > 자재수입검사등록 / 자재수입검사현황`이다.
기존 MES 수입검사(`WQC302_VW`, `TQC205/TQC206`, `SP_WQC302_*`)는 업무 규칙 검토용으로만 참고하고, 화면 구조는 s-erp 기존 패턴(가입고·입고 등록/현황)을 따른다. MES 일반 수입검사 화면(스크린샷 1·2)의 구성 요소(검사 대상 목록, 실적 요약, 기등록 내역)는 불러오기 창과 현황 화면으로 흡수하고, 식품 전용 검사 화면(스크린샷 3·4)의 항목은 담지 않는다.
**필요한 것만 담은 간소한 뼈대**를 만들고, 실무에서 필요해지면 그 위에 추가한다.

## 업무 흐름 (2026-11-16·17 사용자 확정)

발주(PO) → 가입고(MP) → [무검사] 입고(MI) 자동 생성 / [검사 대상] **수입검사(QI)** → 입고(MI)

## 업무 규칙

### 검사 대상과 번호
- 검사 대상 = 유효한 가입고 행 중 `inspect_at='Y'`인 행. 검사 대기량 = 가입고량 − 유효 검사의 (합격량+불합격량) 합.
- 가입고 한 행을 **여러 번 나눠 검사**할 수 있다(부분 검사). 검사 대기량이 0이면 대기 목록에서 빠진다.
- 검사 1건 = 헤더(검사일·검사자·비고) + 행(가입고 행 참조, 합격량, 불합격량, 행 비고). 여러 가입고 행을 한 검사에 담을 수 있고 이때 검사번호는 하나다. 번호는 `QI-YYYYMMDD-NNNN`이며 가입고(MP)·입고(MI) 번호 생성 방식과 같다.
- 첫 버전의 검사방법은 **전수검사만** 있다(별도 입력 항목 없음). 샘플·시료량·연속합격, 특채조건·부적합 처리, 검사항목별 결과, 부적합 사진은 이번에 관리하지 않는다.

### 수량
- 검사량 = 합격량 + 불합격량. 입력은 합격량과 불합격량이고 검사량은 자동 계산한다.
- 검사량이 검사 대기량을 넘으면 저장하지 않는다(실물이 가입고된 수량을 넘을 수 없다).
- 불합격량은 가입고 수량을 바꾸지 않는다. 발주 잔량은 조회 시 `발주량 − 유효 가입고 합 + 유효 불합격 합`으로 계산한다(2026-11-16 확정, 가입고 데이터는 불변).
- 입고 가능량(합격량 − 입고량)은 입고 수동 등록 단계에서 사용한다. 이번 작업에서는 합격량·불합격량을 기록하고 조회하는 데까지만 만든다.

### 수정·취소와 가입고 잠금
- 검사를 등록하면 그 가입고 행은 가입고에서 **수정·삭제할 수 없다**(행 단위 잠금). 가입고 헤더(가입고일·부가세 설정) 수정과 가입고 취소도 막고, 막힌 경우 검사번호를 안내한다.
- 검사 수정: 검사일·검사자·비고, 행의 합격량·불합격량·행 비고, 행 빼기. 검사 대기량 범위 안에서만 허용한다. 가입고 행(대상 품목)을 바꾸거나 새 행을 추가할 수는 없다(새 대상은 새 검사로 등록).
- **검사 취소** = 검사 헤더 `use_at='N'`(이력 보존). 취소하면 가입고 잠금과 검사 대기량이 복구된다. 행 빼기는 물리 삭제 후 행번호 재정렬이고, 모든 행을 뺄 수는 없다(취소 사용).
- 합격분이 입고(MI)에 연결된 뒤의 수정·취소 제한은 입고 수동 등록 단계에서 추가한다(이번에는 연결 데이터가 없어 취소는 항상 가능하다).

### 화면 구성
- **자재수입검사등록**(`inspect-create`): 헤더(검사일, 검사자, 비고) + 검사 행 그리드. [가입고 불러오기] 창이 MES의 "검사 대상 목록" 역할을 한다. 창에서 검색(가입고일 기간·구매처·품목)하고 여러 건을 체크해 가져온다. 등록 화면 위쪽에 "검사 대기 N건" 안내를 둔다. 가져온 행에 합격량·불합격량·행 비고를 입력한다(검사량 자동). 가입고량·기검사량·검사 대기량을 함께 보여 준다.
- **자재수입검사현황**(`inspect-status`): 입고현황과 같은 패턴(조회 → 검사번호 링크 → 상세 패널 → 조회/수정 다이얼로그). 상태 조회 3종(정상 기본/취소/전체). MES의 "기등록 내역"과 "검사 실적 요약"은 상세 패널이 담당한다.
- 상세 배치와 컬럼은 상세 사양서에서 확정한다.

### 사용자 안내와 편의
- 가입고 화면의 잠긴 행에 "수입검사 QI-…에서 처리해 주세요"를 안내하고, 가입고현황 상세에 검사번호를 보여 준다.
- 검사 대기량을 초과한 입력은 저장 전에 행 단위로 알려 준다.
- 검사 취소·행 빼기 확인창에 "취소하면 가입고 수정·삭제가 다시 가능해집니다"를 안내한다.

### 취소건 조회 규칙
- 검사현황은 상태 3종(정상 기본/취소/전체)을 제공한다.

## 범위

### 포함
- DB: **품질관리 모듈**(`QUALITY`, 경로 `/quality`), 메뉴 그룹 `수입검사`, 화면 `자재수입검사등록`·`자재수입검사현황`, 검사 헤더/상세 테이블, 롤백, 변경이력, `db-schema.md`(스크립트는 사용자가 실행).
- 백엔드: `egovframework.let.quality.inspect` 아래 검사 대기 후보 조회, 검사 단건 조회·등록·수정·취소, 검사현황 목록, 가입고 잠금과 발주 잔량 계산 반영.
- 프론트: `frontend/src/pages/quality/inspect` 아래 등록·현황 화면, 대시보드 라우팅(품질관리 모듈), 가입고 화면의 잠금 안내.
- 테스트, 결과 문서(스크린샷 포함).

### 제외(별도 작업)
- 입고 수동 등록 저장·수입검사 합격분 불러오기 연결(수입검사 다음 단계로 바로 이어서 진행), 샘플·특채·부적합 처리·검사항목별 결과·사진, 재고·LOT 연결.
- 기존 현황 화면의 취소건 기본 조회 규칙 정비.

## 완료 조건
- 불러오기 창에 `inspect_at='Y'`인 가입고 행만 나오고, 검사 대기량이 0인 행은 빠진다.
- 여러 가입고 행을 불러와 저장하면 `QI-YYYYMMDD-NNNN` 하나로 묶이고, 검사량이 검사 대기량을 넘으면 거부된다.
- 검사가 있는 가입고 행은 가입고에서 수정·삭제가 거부되고 검사번호가 안내된다. 검사를 취소하면 다시 수정할 수 있다.
- 불합격량이 발주 잔량에 더해져 조회된다.
- 사이드바에 품질관리 > 수입검사 > 자재수입검사등록·현황 메뉴가 나타난다. 현황은 기본으로 정상건만 조회하고 취소·전체를 선택할 수 있다.
