# PR #75 프론트엔드 검사 실패 수정 작업지시서

## 목적

PR #75의 실패한 프론트엔드 테스트를 조사하고, 브랜치에서 추가한 테스트 중 CI에서 재현된 실패만 최소 수정한다.

## 범위

- CI 로그와 PR base/head의 테스트 결과를 비교한다.
- 새 AUTO 출하계획 테스트가 출하계획 상세 그리드를 조회하기 전에 선택 다이얼로그의 종료 전환을 기다리도록 한다.
- 기존 base에서도 실패한 테스트와 원인이 확인되지 않은 테스트는 수정하지 않고 사용자에게 진행 여부를 확인한다.
- 제품 동작, API, 데이터 계약은 변경하지 않는다.

## 완료 조건

1. 실패 원인을 브랜치 변경과 base 재현 결과에 따라 분류한다.
2. 확인된 출하계획 테스트 실패만 수정하고 동일 파일을 CI와 같은 Vitest 옵션으로 검증한다.
3. 관련 없는 실패와 미확인 실패를 결과 문서에 구분해 기록한다.
