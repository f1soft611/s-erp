# 20260901_002 메뉴 기능권한/설명 연동 작업지시서

## 요청

메뉴관리에서 저장한 메뉴별 기능 권한, 메뉴명, 메뉴설명을 실제 페이지에 그대로 반영한다.

## 범위

- 공통 페이지 기능 버튼은 `조회`, `저장`, `삭제`, `엑셀` 네 종류만 사용한다.
- `CREATE`, `UPDATE` 권한은 별도 등록/수정 버튼으로 표시하지 않고 `저장` 버튼 권한으로 합친다.
- 현재 로그인 사용자의 메뉴별 권한에 따라 실제 페이지 버튼을 표시한다.
- 메뉴관리에 `메뉴설명` 편집 컬럼을 추가한다.
- 메뉴명과 메뉴설명을 DB에 저장하고 사용자 메뉴 API와 실제 페이지 헤더에 그대로 반영한다.

## 완료 기준

- 메뉴관리 권한이 읽기/쓰기/삭제이면 실제 메뉴관리 페이지에는 조회/저장/삭제만 표시된다.
- 엑셀 권한이 없으면 엑셀 버튼은 표시되지 않는다.
- 등록/수정 버튼은 표시되지 않는다.
- 메뉴관리에서 저장한 메뉴명과 메뉴설명이 재조회 후 유지된다.
- 실제 페이지의 제목과 설명이 저장된 메뉴명/메뉴설명과 일치한다.
- 관련 프론트엔드/백엔드 테스트와 빌드가 통과한다.
