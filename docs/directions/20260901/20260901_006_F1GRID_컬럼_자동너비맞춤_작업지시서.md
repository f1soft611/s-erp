# F1-GRID 컬럼 더블클릭 자동 너비 맞춤 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid`)

## 작업 요청 사항

컬럼 리사이즈 핸들을 더블클릭하면 해당 컬럼의 셀 내용(및 헤더 제목) 길이에 맞춰 너비가 자동으로 조정되도록 한다.

## 완료 기준

- 컬럼 헤더의 리사이즈 핸들을 더블클릭하면 현재 화면에 렌더링된 행들의 셀 값과 헤더 제목 중 가장 긴 값 기준으로 컬럼 너비가 자동 조정된다.
- 컬럼별 `maxWidth` 옵션이 있으면 자동 맞춤 결과가 해당 값을 넘지 않는다.
- 기존 `minColumnWidth` 하한은 그대로 유지된다.
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
