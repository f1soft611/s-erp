# F1-GRID rownumber 컬럼 타입 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid`)

## 작업 요청 사항

`rownumber` 컬럼 타입을 추가하여 행 추가 시 자동으로 순번이 채번(표시)되도록 한다.

## 완료 기준

- `F1GridColumn.type = 'rownumber'`로 지정한 컬럼은 항상 현재 행의 표시 순서 기준(정렬/필터/삭제와 무관하게 화면상 위치) 1부터 시작하는 순번을 보여준다.
- 해당 컬럼 값은 실제 row 데이터에 저장되지 않으며, 항상 읽기 전용이다(`editable` 설정을 지정해도 무시).
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
