# 20260901_001 메뉴관리 페이지 액션/그리드 제어 분리 작업지시서

## 요청

메뉴관리 페이지에서 상단 영역, 액션 버튼 영역, 그리드 영역을 분리한다.

## 범위

- 메뉴관리 페이지에 우선 적용한다.
- 페이지 업무 버튼은 우측 상단 액션 영역에 모은다.
- F1Tree/F1Grid 내부 제어 버튼은 그리드 제어 영역으로 분리한다.
- 공통 F1Grid 자체에는 페이지별 업무 버튼을 추가하지 않는다.

## 완료 기준

- 메뉴관리 패널에서 신규, 하위 추가, 삭제, 저장, 새로고침 버튼이 서비스 액션 영역에 표시된다.
- 전체 펼치기, 전체 접기 버튼은 그리드 제어 영역에 표시된다.
- 좁은 화면에서 액션 버튼과 그리드 제어 버튼이 겹치지 않고 줄바꿈된다.
- 기존 메뉴 추가, 삭제, 저장, 권한 저장 동작은 유지된다.
- 관련 Vitest와 프론트엔드 빌드를 통과한다.
