# F1-GRID 화면크기(displayScale) 연동 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid`, `shared/context/AppSettingsContext.tsx`)

## 작업 요청 사항

ERP 시스템은 행 padding이 크면 많은 데이터를 볼 수 없어 사용자가 행 높이를 조정한다. 대시보드의 "화면크기 설정"(`displayScale`)을 변경할 때 그리드 행 높이가 자연스럽게 함께 조정되도록 영향도를 검토하고 반영한다.

## 완료 기준

- 대시보드에서 화면크기(`displayScale`)를 변경하면, 사용자가 개별적으로 조정하지 않은 그리드 행의 기본/최소 행 높이가 화면크기 비율만큼 자동으로 조정된다.
- 사용자가 특정 행의 높이를 수동으로 조정한 이력이 있으면 그 값이 화면크기 변경보다 우선 유지된다.
- `displayScale`을 제공하는 `AppSettingsProvider` 없이 `F1Grid`를 렌더링해도(단위 테스트 등) 기존과 동일하게 동작한다(기본값 1로 처리).
- 기존 행 높이 조절 UX(드래그 핸들, ArrowUp/Down)는 그대로 유지된다.
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
