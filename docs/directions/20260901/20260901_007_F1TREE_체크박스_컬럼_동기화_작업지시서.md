# F1-GRID F1Tree treeCheckbox 체크박스 컬럼 동기화 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid/tree`, `shared/components/f1-grid/types`)

## 작업 요청 사항

`F1Tree`의 `treeCheckbox`를 체크할 경우 해당 로우의 `type: 'checkbox'` 데이터 컬럼들이 자동으로 체크되도록 구현한다. 컬럼 옵션으로 자동 체크를 끌 수 있는 옵션을 추가하며, 기본값은 자동 체크(on)로 한다.

## 완료 기준

- `treeCheckbox`를 체크하면 해당 행(및 하위 행)의 `type: 'checkbox'` 컬럼 값이 자동으로 `true`가 된다.
- `treeCheckbox`를 해제하면 자동으로 켜졌던 체크박스 컬럼 값도 함께 `false`가 된다(양방향 동기화).
- `F1GridColumn`에 `syncWithTreeCheckbox?: boolean` 옵션을 추가하고, `false`로 설정한 컬럼은 자동 반영 대상에서 제외된다. 기본값은 `true`.
- 기존 값과 무관하게 `treeCheckbox` 상태에 따라 무조건 덮어쓴다.
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
