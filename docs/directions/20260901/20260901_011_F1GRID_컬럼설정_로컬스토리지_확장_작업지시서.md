# F1-GRID 컬럼 설정 로컬스토리지 확장 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid`)

## 작업 요청 사항

기존 `storageKey`는 컬럼 순서(order)만 `localStorage`에 저장했다. 이를 확장해서
컬럼 순서 외에 컬럼 너비(size)와 컬럼 표시/숨김 목록까지 함께 저장하고,
다음 렌더링(재방문) 시 그대로 복원되도록 한다.

## 완료 기준

- `storageKey`가 지정된 그리드는 컬럼 순서, 컬럼 너비, 숨김 컬럼 목록을 하나의 저장 값으로
  `localStorage`에 저장한다.
- 페이지 재방문/리마운트 시 저장된 순서/너비/숨김 상태가 그대로 복원된다.
- `storageKey`가 없으면 기존처럼 세션 내 state로만 유지한다(저장 안 함).
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
