# F1-GRID 컬럼 드래그 순서 변경 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend (`shared/components/f1-grid`)

## 작업 요청 사항

컬럼 헤더를 드래그하여 컬럼 표시 순서를 변경할 수 있는 기능을 추가한다.

## 완료 기준

- 컬럼 헤더를 드래그해서 다른 컬럼 위치에 놓으면 컬럼 순서가 변경된다.
- 좌/우 고정(pinned) 컬럼은 드래그 대상/목표 위치에서 제외된다(고정 컬럼끼리도 순서 변경 불가).
- `F1GridProps`에 `storageKey?: string`를 추가하고, 값이 있으면 변경된 컬럼 순서를 `localStorage`에 저장하고 다음 렌더링 시 복원한다. 값이 없으면 기존처럼 세션 내 state로만 유지한다.
- 프론트엔드 빌드 및 관련 Vitest 테스트가 모두 통과한다.
