# 페이지 헤더 공통 컴포넌트화 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend

## 배경

각 화면(대시보드 하위 페이지들)의 상단 영역이 "좌측 브레드크럼 + 페이지 설명"과 "우측 기능 버튼"으로 구성되어 있으나, 페이지마다 동일한 마크업/스타일이 개별적으로 중복 구현되어 있음.

## 작업 요청 사항

1. 페이지별 헤더가 공통 컴포넌트로 구현되어 있는지 확인
2. 공통화되어 있지 않다면 다음을 공통 컴포넌트로 분리
   - 좌측: 브레드크럼(모듈/메뉴 경로) 및 페이지 설명(description) 영역
   - 우측: 기능 버튼(PermissionGroupActionBar 등) 영역

## 완료 기준

- `src/shared/components`에 공통 헤더 컴포넌트가 추가된다.
- 기존에 헤더를 개별 구현하던 페이지들이 공통 컴포넌트를 사용하도록 교체된다.
- 브레드크럼 표시 로직(단일 모듈/메뉴명 vs `breadcrumbItems` 배열)과 우측 액션 버튼(`PermissionGroupActionBar`) 표시 여부는 페이지별 요구사항을 그대로 유지한다.
- 기존 화면 동작(문구, 버튼, 필터)에 변화가 없어야 한다(리팩터링 목적).
- 프론트엔드 빌드 및 관련 테스트가 통과한다.
