# 검색 영역 공통 컴포넌트 분리 작업지시서

- 작성일: 2026-09-01
- 요청자: 사용자 채팅 요청
- 관련 영역: frontend

## 작업 요청 사항

1. 페이지별 검색 영역을 분리하여 공통 컴포넌트로 구성
2. 화면 레이아웃 순서: 헤더 → 에러 메시지 영역 → 검색 영역 → 메인 패널
3. 메뉴관리 페이지는 현재 헤더 안에 있는 모듈 선택/검색 필드를 새 검색 영역으로 이동

## 완료 기준

- `src/shared/components`에 검색 영역 공통 컴포넌트가 추가된다.
- 메뉴관리 페이지의 모듈 선택 + 메뉴명/코드 검색 필드가 헤더에서 분리되어 검색 영역으로 이동한다.
- 화면 순서가 헤더 → 에러 메시지 → 검색 영역 → 패널 순으로 구성된다.
- 검색 기능이 없는 다른 페이지는 기존 동작을 그대로 유지한다(임의로 검색 영역을 추가하지 않는다).
- 빌드 및 관련 테스트가 통과한다.
