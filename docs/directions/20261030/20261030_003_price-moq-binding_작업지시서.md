# 품목·거래처별 단가 저장 MOQ 숫자 바인딩 오류 수정

## 사용자 요청

단가 저장 INSERT에서 최소주문수량 `moq`의 PostgreSQL numeric 컬럼에 character varying 표현식이 전달되는 오류를 수정한다. 앞선 단가 도움창 수정은 유지한다.

## 기준 및 범위

- [기존 단가 상세사양](../../spec/20261029/20261029_002_품목_거래처별_단가관리_상세사양서.md): MOQ는 선택값이며 비어 있으면 SQL NULL, 0은 숫자 0으로 저장한다.
- 읽기 전용 DB MCP로 현재 테이블/컬럼 계약을 확인한다. 업무 데이터와 자격 증명은 조회하지 않는다.
- INSERT와 UPDATE의 `moq` 바인딩을 수정한다. 전역 MyBatis 설정, API, 업무 검증, 스키마는 변경하지 않는다.
- 실제 MyBatis 매퍼와 파라미터 핸들러를 거친 JDBC NULL/BigDecimal 바인딩을 테스트한다.
- 계획서/상세사양서 → 실패 테스트 → 최소 수정 → 검증 → 결과 문서 순서로 진행한다.
- DB 스키마 변경이 없으면 SQL/롤백 스크립트는 생성하지 않는다.
