# 수주등록 기본정보 거래처 돋보기 도움폼 작업지시서

## 요청

품목·거래처별 단가 등록 폼처럼 수주등록 페이지의 기본정보 거래처 필드도
필드 안 돋보기 아이콘을 눌러 거래처 도움폼을 열도록 변경한다. 필드 옆에
별도의 선택 버튼은 두지 않는다.

## 범위와 기준

- 기존 `CustomerPicker`와 거래처 검색 `MasterPickerDialog` 흐름을 재사용한다.
- 수주등록 기본정보의 거래처 선택 트리거만 별도 버튼에서 입력 필드 끝의
  돋보기 아이콘으로 변경한다.
- 거래처 코드·명 표시, 필수 검증, 오류/안내 텍스트, 비활성 상태, 검색
  서비스, 선택 후 저장 데이터는 유지한다.
- 기본 `MasterPicker` 사용 동작은 변경하지 않고, 수주등록 거래처에서만
  아이콘 트리거를 활성화한다.
- 백엔드, API/데이터 계약, F1-Grid 및 기타 거래처 필드는 변경하지 않는다.

## 작업 및 검증

1. 구현 계획 및 상세 사양을 작성한다.
2. 수주등록 화면에서 돋보기 아이콘으로 기존 도움폼을 열고 거래처를 선택하는
   회귀 테스트를 먼저 추가한다.
3. 공통 피커에 선택적 아이콘 트리거를 적용하고 수주등록 거래처에만 사용한다.
4. 수주등록/공통 피커 테스트와 프론트엔드 빌드를 수행한다.
5. 375px, 768px, 1280px 브라우저에서 필드 정렬 및 도움폼 동작을 확인하고,
   결과 문서와 스크린샷을 `docs/result/20261030/sales-order-customer-picker/`
   에 기록한다.

## 완료 조건

- 수주 기본정보 거래처 필드에는 별도 텍스트 선택 버튼이 없다.
- 필드 안 돋보기 아이콘으로 기존 거래처 검색 도움폼을 열고 선택할 수 있다.
- 미선택/선택값, 필수 오류, 저장 흐름, 비활성 상태가 기존과 동일하게
  동작한다.
- 대상 테스트, 프론트엔드 빌드 및 3개 뷰포트 실제 브라우저 확인이 완료된다.
