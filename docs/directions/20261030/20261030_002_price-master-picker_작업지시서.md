# 단가등록 품목·거래처 도움창 목록 혼용 수정

## 요청 및 기준

- 사용자 보고: 단가등록에서 품목 도움창을 연 뒤 거래처 도움창을 열면 품목 리스트가 표시된다.
- 기존 기준: [단가관리 작업지시서](../20261029/20261029_002_품목_거래처별_단가관리_작업지시서.md)의 품목·거래처 선택 흐름을 유지한다.
- 품목과 거래처는 각자의 검색 결과만 표시하고 각자의 ID/코드/명에 반영해야 한다.

## 범위와 완료 조건

1. 기존 변경사항을 보존하고 단가 화면의 도움창 수명과 검색 상태를 추적한다.
2. 계획서와 상세사양서를 작성한 뒤 실패하는 회귀 테스트를 먼저 실행한다.
3. 단가 화면에서 도움창 상태를 분리한다. 공통 검색 서비스, API, DB, 다른 화면 동작은 변경하지 않는다.
4. 양방향 전환, 닫았다 다시 열기, 이전 비동기 응답, 선택값 반영을 검증한다.
5. 관련 테스트, lint/build 및 375/768/1280px 브라우저 확인을 수행한다.
6. F1-Grid 사용 문서와 결과 보고서를 갱신하고 합성 데이터 스크린샷을 보관한다.
