# 참조 확인 후 문서현황 조회 장애 작업지시서

- 요청: 특정 사용자의 문서현황이 조회되지 않는 문제를 조사하고 복구한다.
- 기존 근거: [참조 확인 작업지시서](../20261029/20261029_001_문서_참조자_확인_액션_작업지시서.md)의 확인 후 일반 목록 접근 유지 요구사항.
- 원인: 문서현황의 처리상태 허용 목록에서 정상 참조 확인 상태 `CONFIRMED`가 누락되어 전체 응답 검증이 실패한다.
- 범위: 문서현황 응답 검증·상태 표시·검색 타입과 서버 검색 허용 상태를 기존 계약에 맞춘다. 계정, 권한, 데이터, SQL, 스키마는 변경하지 않는다.
- 순서: 계획 → 상세 사양 → 실패 회귀 테스트 → 최소 수정 → 검증 및 결과.
- 완료 기준: 확인 완료 문서가 섞인 목록이 정상 표시되고 확인 상태 검색이 가능하며, 알 수 없는 상태는 계속 거부한다. 관련 테스트와 빌드, 합성 데이터 브라우저 검증 및 스크린샷을 남긴다.
