# 20260911_005 공통코드 관리 트리/그리드 분리기 작업지시서

## 1. 작업 분류

- 분류: `bounded`
- 대상: 프론트엔드
- 사유: 공통코드 관리 페이지의 좌측 트리와 우측 상세 그리드 레이아웃을 조정하는 UI 개선으로, 현재 구현 범위는 화면 구조와 사용자 조작 경험에 국한된다.

## 2. 배경

공통코드 관리 화면은 좌측의 그룹 트리와 우측의 상세 코드 그리드를 함께 표시한다. 현재는 고정 비율의 `gridTemplateColumns`로 구성되어 있어, 사용자가 트리 영역과 그리드 영역의 너비를 직접 조절하기 어렵다.

사용자는 트리 경계를 드래그하여 좌우 영역의 비율을 조정하고 싶어 하며, 좁은 화면에서 특히 가독성과 작업 편의성이 떨어진다. 기능 추가보다는 기존 화면 구조를 유지하면서 사용자가 직접 분할 비율을 조정할 수 있도록 하는 개선이 필요하다.

## 3. 목표

1. 공통코드 관리 화면의 좌측 트리와 우측 상세 그리드 사이에 분리기(splitter)를 추가한다.
2. 사용자가 분리기를 드래그하여 트리 영역과 그리드 영역의 너비를 조절할 수 있게 한다.
3. 기존 선택/조회/저장/엑셀 동작은 유지하고, 레이아웃 조정이 화면 전반 구조를 방해하지 않도록 한다.
4. 작은 화면에서도 분리기와 콘텐츠가 정상적으로 동작한다.

## 4. 확정 범위

### 4.1 화면 구성

- `frontend/src/pages/co/master/common-code/components/CommonCodeManagementPanel.tsx` 구조 수정
- 좌측 `F1Tree` 영역과 우측 `F1Grid` 영역 사이에 수평 드래그 분리기 추가
- 기본 영역 비율 유지: 트리 영역과 그리드 영역이 적절한 초기 비율로 렌더링됨
- 분리기 상태를 로컬 컴포넌트 state 또는 사용자 액션 기반으로 관리

### 4.2 동작 요구사항

- 마우스 드래그로 트리 영역과 그리드 영역 사이 폭을 조정 가능
- 최소/최대 너비 범위를 지정하여 레이아웃이 과도하게 찌그러지지 않게 함
- 분리기를 통해 조정한 결과가 화면 재렌더 시에도 안정적으로 유지되도록 함
- Tree/Grid는 기존 F1Grid/F1Tree 동작을 유지하면서 영역 크기만 유동적으로 조정

### 4.3 반응형 처리

- 브라우저의 웹/태블릿/데스크톱 크기에 따라 분리기와 레이아웃이 정상 동작
- 좁은 화면에서는 트리/그리드 영역이 적절히 줄어들고, 분리기로 조정 가능
- 수평 스크롤/가로 압축이 발생하지 않도록 기존 UI 요소와 충돌하지 않아야 함

## 5. 제외 범위

- 백엔드 API 구조 변경
- 공통코드 데이터 모델 변경
- F1Tree/F1Grid 기능 자체의 행사 로직 변경
- 트리 노드 추가/삭제 기능 또는 상세코드 행 추가/삭제 전용 버튼 추가
- 다른 관리 화면에 동일한 분리기 컴포넌트 공통화

## 6. 완료 기준

- 공통코드 관리 페이지에서 트리와 그리드 사이에 드래그 가능한 분리기가 노출된다.
- 사용자가 분리기를 드래그할 때 좌우 영역 비율이 동적으로 변경된다.
- 기존 트리 선택, 상세코드 조회, 저장, 엑셀 내보내기 기능은 동일하게 동작한다.
- 분리기 조정은 화면 영역을 벗어나지 않는 범위에서 동작한다.
- 브라우저 기준으로 실제 화면 상에서 레이아웃이 정상적으로 보인다.
- 관련 프론트엔드 빌드 및 테스트가 문제없이 통과한다.

## 7. 검증 방법

- `cd frontend && npm run build`
- `cd frontend && npm run test -- --run` 또는 관련 단일 테스트 확인
- 필요 시 브라우저에서 공통코드 관리 화면을 직접 열어 분리기 드래그 동작 검증
- 결과 문서 및 스크린샷을 저장한다.
