# 20260923_004 페이지영역 우측 오버레이 상세 패널 작업지시서

## 작업 분류

- 경로: `bounded`
- 대상: 프론트엔드
- 관련 화면: 공지사항 상세 패널
- 선행 작업: `20260923_003_공지사항_전체우측_오버레이_상세패널`

## 작업 목적

현재 우측 상세 Drawer가 앱 전체를 기준으로 열릴 수 있어 공통 상단 헤더의 테마·알림·로그아웃 영역까지 덮을 수 있다. 상세 패널의 기준 영역을 공통 헤더 아래의 페이지 콘텐츠 영역으로 제한해, 헤더와 로그아웃은 항상 노출하고 해당 페이지의 목록·본문 영역만 상세 패널이 덮도록 조정한다.

## 요구사항

1. 상세 패널은 공통 상단 헤더와 로그아웃 영역을 덮지 않는다.
2. 상세 패널은 `DashboardPage`의 `AppBar` 아래 `DashboardContent` 영역 안에서만 표시한다.
3. 페이지 콘텐츠 영역의 전체 높이를 사용하고, 해당 영역의 오른쪽을 넓게 덮는다.
4. 상세 패널이 열려도 상단 헤더의 로그아웃·알림·테마 버튼은 계속 접근 가능하다.
5. 기존 Drawer의 넓은 폭, 독립 스크롤, X·백드롭·Escape 닫기, 게시글 전체 기능은 유지한다.
6. 목록은 페이지 콘텐츠 영역의 배경에 유지하고, 헤더는 패널 뒤로 가려지지 않는다.
7. 375px, 768px, 1280px에서 페이지 영역 밖으로 패널이 넘치거나 가로 스크롤이 생기지 않는다.

## 권장 접근 방식

`Drawer`를 `body` 포털에 둔 현재 구조 대신 페이지 콘텐츠 래퍼 내부에 오버레이 레이어를 렌더링한다. `DashboardPage`의 `contentRef`가 가리키는 헤더 포함 셸과 `DashboardContent`가 실제 페이지 영역을 구분하므로, 상세 패널은 `CommunityNoticePage` 내부의 `position: absolute` 오버레이 또는 공통 페이지 오버레이 호스트를 사용해 `DashboardContent` 영역만 덮는다. 공통 헤더를 포함한 상위 셸에는 z-index를 올리지 않는다.

## 구현 범위

- 공통 상세 패널 표시 프레임에 페이지 영역 기준 오버레이 모드를 추가한다.
- 공지사항 상세 호스트를 페이지 콘텐츠의 `position: relative` 영역에 두고, 패널을 `inset: 0 0 0 auto`로 배치한다.
- 기존 Drawer가 제공하던 백드롭·Escape·스크롤 동작을 유지하거나 동등하게 구현한다.
- 공지사항 외 화면 적용은 이번 작업에서 하지 않되, 공통 패널 API는 재사용 가능하게 유지한다.
- 실제 브라우저에서 헤더 로그아웃 노출과 패널 경계를 검증한다.

## 제외 범위

- 공통 헤더 디자인 및 로그아웃 기능 변경
- 게시판·자료실·그룹웨어 실제 화면 확장
- 게시글 API·DB·권한 변경
- 패널 내부 게시글 기능 변경

## 완료 기준

- 패널이 열려도 상단 공통 헤더와 로그아웃 버튼이 보인다.
- 패널은 헤더 아래 페이지 콘텐츠 영역만 덮는다.
- 콘텐츠 영역에서 넓은 우측 패널·독립 스크롤·닫기 동작이 유지된다.
- 반응형 뷰포트에서 영역 이탈과 가로 스크롤이 없다.
- 관련 테스트·빌드·브라우저 캡처가 결과 문서에 남는다.
