# 20260923_008 최근사용 메뉴 일시 표시 작업지시서

## 작업 분류

- 대상: 프론트엔드
- 관련 화면: 대시보드 좌측 사이드바, 최근 사용 메뉴 리스트, `DashboardMenuTree.tsx`, `DashboardPage.tsx`
- 목적: 최근 사용 메뉴 목록에 마지막 방문 시점을 사용자 친화적으로 표시하여, “몇 초 전 / 몇 분 전 / 몇 시간 전 / 몇 일 전” 형태로 빠르게 확인할 수 있도록 개선한다.
- 범위: 최근 사용 메뉴 아이템의 텍스트 표현, 시간 포맷 함수, 표시 기준, UI 간격 정리
- 제외 대상: 서버 저장 구조 변경, 전체 페이지 상태 복원, 상단 탭 추가, 최근 메뉴 기능 자체의 신규 저장 로직 대규모 변경

## 현재 문제

- 현재 사이드바 하단의 최근 사용 메뉴는 항목명과 경로만 노출되며, 마지막 방문 시점이 표시되지 않는다.
- 사용자가 어떤 메뉴를 가장 최근에 열었는지 직관적으로 파악하기 어렵다.
- 시간 정보가 있더라도 절대 시각으로만 표시되거나 UI에 무관하게 노출되어, 빠른 판단을 방해한다.
- 최근 메뉴 목록은 유지되고 있지만, 사용자 입장에서는 “언제 방문했는지”를 확인할 수 없어 가시성이 낮다.

## 요구사항

1. 최근 사용 메뉴 목록 각 항목에 마지막 방문 시점을 표시한다.
2. 표시 형식은 사용자 친화적으로 다음과 같이 보인다: “몇 초 전”, “몇 분 전”, “몇 시간 전”, “몇 일 전”, 필요 시 “몇 주 전”까지 확장 가능하다.
3. 표시 형식은 상대 시간 기반으로 계산한다.
4. 같은 항목을 다시 방문하면 최근 사용 시점이 갱신되고, 표시 시각도 최신 기준으로 다시 계산된다.
5. 최근 사용 리스트는 기존 UI 구성 유지하며, 메뉴 텍스트와 시간 텍스트가 자연스럽게 배열되도록 정리한다.
6. 불필요한 과도한 너비를 차지하지 않도록 텍스트 줄바꿈과 정렬을 적절히 제어한다.
7. 세션 종료 시 기록은 사라지며, 기존 최근 사용 기능과 충돌하지 않는다.
8. 실제 시간 계산은 클라이언트에서 동기적으로 처리하되, 로직은 재사용 가능한 형태로 구성한다.
9. 시간 표시는 최근 사용 메뉴가 비어있지 않을 때만 노출한다.
10. 모바일 및 데스크톱에서 모두 읽기 쉽게 보이도록 간격과 타이포그래피를 조정한다.

## 접근 방식 비교

### 대안 A: 절대 시각 표시

- 장점: 정확한 시각을 알 수 있다.
- 단점: 사용자 입장에서는 “몇 분 전인지”를 즉시 판단하기 어렵고, 사이드바 공간이 복잡해진다.
- 판정: 상대 시간 기반 UI가 더 적합하다.

### 대안 B: 상대 시간 표시 (권장)

- 장점: 최근성 확인이 빠르고 사이드바 공간을 효율적으로 활용할 수 있다.
- 장점: 현재 페이지의 최근 메뉴 히스토리 UX와 자연스럽게 연결된다.
- 단점: 오래된 항목은 “몇 주 전” 같은 표현이 다소 추상적일 수 있다.
- 판정: 요구사항에 가장 부합하며, 기존 최근 사용 기능과 함께 사용하기 좋다.

### 대안 C: 목록 우측에 타임스탬프 전체를 절대 형식으로 강제

- 장점: 정확하다.
- 단점: UI가 지저분하고 사용자가 빠르게 선택하려는 최근 메뉴 기능과 어울리지 않는다.
- 판정: 채택하지 않는다.

## 구현 범위

- `DashboardMenuTree` 최근 사용 메뉴 항목의 표시 레이아웃을 조정한다.
- `visitedAt` 값을 활용해 상대 시간을 생성하는 공통 함수 또는 로컬 유틸을 추가한다.
- 표시 형식은 “몇 초 전”, “몇 분 전”, “몇 시간 전”, “몇 일 전” 순으로 계산한다.
- 시간이 오래된 항목은 적절한 단위로 축약 표시한다.
- 기존 최근 사용 메뉴 정렬 로직과 세션 저장 로직은 그대로 유지한다.
- 사용자에게 보이는 복수 행 텍스트가 너무 길어지지 않도록 `Typography`/`Box` 간 정렬과 줄바꿈을 조정한다.

## 제외 범위

- 최근 메뉴 데이터를 서버로 영구 저장
- 새로운 상단 탭형 네비게이션 도입
- 메뉴별 즐겨찾기/핀 기능 추가
- 타임스탬프를 서버 DB로 관리하는 구조 변경

## 완료 기준

- 상대 시간 형식이 사용자에게 익숙하고 이해하기 쉽다.
- 메뉴명과 시간 표시가 자연스럽게 정렬된다.
- 최근 방문이 갱신될 때 시간 표기도 함께 갱신된다.
- 기존 최근 사용 기능, 메뉴 선택 로직, 세션 유지 동작을 유지한다.
- 관련 빌드/테스트 검증이 수행된다.
