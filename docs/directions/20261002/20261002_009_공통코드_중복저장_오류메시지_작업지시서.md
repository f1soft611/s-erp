# 20261002_009 공통코드 중복 저장 오류 메시지 작업지시서

## 작업 목적

공통코드 그룹 또는 상세코드 저장 시 중복 코드의 구체적인 검증 메시지가 화면에 표시되도록 API 오류 응답의 `resultMessage`를 수정한다.

## 원인

공통코드 서비스는 중복 그룹 코드에 `이미 사용 중인 그룹 코드입니다.`, 중복 상세코드에 `이미 사용 중인 상세 코드입니다.`를 던진다. 컨트롤러는 해당 메시지를 응답 `result.message`에 넣지만, 공통 프론트 API 클라이언트는 최상위 `resultMessage`를 오류 메시지로 사용한다. `resultMessage`가 항상 `입력값 무결성 오류 입니다.`로 설정되어 구체 메시지가 가려진다.

## 작업 범위

- 공통코드 API의 입력 오류 응답에 예외의 구체 메시지를 `resultMessage`로 설정한다.
- 기존 HTTP 400, 응답 코드, `result.message` 필드 및 메시지 문구는 유지한다.
- 컨트롤러 테스트에서 중복 상세코드 응답의 최상위 `resultMessage`를 검증한다.
- 문서와 결과 보고서를 날짜별 디렉터리에 기록한다.

## 완료 기준

- 중복 그룹/상세코드 저장 응답의 `resultMessage`가 중복 메시지 그대로 반환된다.
- 입력 오류는 계속 HTTP 400 및 기존 `INPUT_CHECK_ERROR` 코드를 반환한다.
- 공통코드 API 컨트롤러 테스트가 통과한다.
- DB 스키마 변경은 없다.
