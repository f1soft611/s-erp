# 20261002_001 기안양식 분류 설정 필수 검증 작업지시서

## 작업 목적

기안양식관리의 분류 설정 모달에서 빈 행을 저장할 때 서버 입력값 무결성 오류가 발생하는 문제를 해결한다. F1-Grid가 제공하는 필수 컬럼 검증을 저장 전에 실행하고, 모달 저장 오류가 메인 양식 그리드 영역에 표시되지 않도록 한다.

## 확인된 원인

- 분류 설정 모달의 `itemCode`, `itemNm` 컬럼에 `required: true`가 선언되어 있다.
- 모달 저장 핸들러가 F1-Grid `validate()`를 호출하지 않아 빈 값을 API에 전달한다.
- 저장 실패 처리에서 오류를 모달 내부 상태와 부모 `onError`에 함께 전달한다.
- 기안양식 메인 그리드는 저장 전에 `gridRef.current.validate()`를 호출한다.

## 범위

- 대상: `CommonCodeItemHelpDialog` 및 관련 프론트엔드 테스트/문서
- 필수값이 비어 있으면 F1-Grid 오류 표시와 모달 안내를 유지하고 저장 API를 호출하지 않는다.
- 서버 저장 오류는 분류 설정 모달 안에서만 표시한다.
- API, 데이터 계약, F1-Grid 공통 코어는 변경하지 않는다.

## 완료 기준

- 필수 분류 값을 입력하지 않고 저장하면 API 요청이 없고 모달에 필수 입력 안내가 표시된다.
- 분류 저장 실패 메시지는 모달 내부에만 표시되고 메인 화면 오류 영역에 전달되지 않는다.
- 기존 분류 추가/수정 저장 테스트와 프론트엔드 빌드가 통과한다.
- 결과 문서와 브라우저 검증 증거를 `docs/result/20261002/draft-form-category-required-validation/`에 남긴다.
