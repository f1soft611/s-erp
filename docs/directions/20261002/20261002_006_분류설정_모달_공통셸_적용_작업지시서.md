# 20261002_006 분류 설정 모달 공통 셸 적용 작업지시서

## 목적

기안양식관리의 분류 설정 모달을 `CommonDialog`로 이전해 헤더·본문·푸터 레이아웃을 통일하고, F1-Grid 행 폼과 하단 구분선 규칙을 일치시킨다.

## 작업 범위

- `CommonCodeItemHelpDialog`의 독립 MUI Dialog를 공통 셸로 이전한다.
- 제목, 닫기, 본문 스크롤, footer 저장/취소 액션의 공통 규칙을 적용한다.
- `DialogContent dividers`와 footer custom border를 제거하고 색상 지정 없는 기본 MUI `Divider` 한 개를 사용한다.
- 미저장 변경 확인, 저장·검증, F1-Grid 인라인 편집 흐름을 유지한다.
- 분류 설정과 F1-Grid 행 폼 footer divider의 스타일 회귀를 테스트한다.

## 제외 범위

- 분류 조회/저장 API와 데이터 계약 변경
- 미저장 변경 확인 대화상자의 공통 셸 이전
- F1-Grid 행 폼 필드와 편집 동작 변경

## 완료 기준

1. 분류 설정 모달이 `CommonDialog` 헤더/본문/푸터를 사용한다.
2. 하단 divider가 본문 `dividers`와 중복되지 않고 F1-Grid 행 폼과 같은 기본 MUI 구분선을 사용하며 별도 색상값을 지정하지 않는다.
3. 읽기 전용, 분류 추가/수정/저장, 실패 표시, dirty close 확인 흐름이 유지된다.
4. 관련 Vitest, 프론트엔드 빌드 및 브라우저 확인이 통과하고 결과 문서에 스크린샷을 남긴다.
