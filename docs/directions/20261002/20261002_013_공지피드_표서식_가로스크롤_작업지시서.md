# 20261002_013 공지 피드 표 서식 및 가로 스크롤 작업지시서

## 목적

공지 작성기에서 설정한 안전한 글꼴/크기 서식을 공지 저장 후에도 유지하고, 공지 피드에서 넓은 표가 피드 카드 폭을 늘리지 않도록 표 내부 가로 스크롤을 제공한다.

## 확인된 현재 동작

- 작성기 표 wrapper에는 `overflow-x: auto`가 적용된다.
- 공지 저장과 피드 표시에서 공통 `sanitizeHtml`을 사용하며, `span`과 font-family/font-size 등의 텍스트 서식을 제거한다.
- sanitizer는 작성기의 `div.tableWrapper`도 제거하므로 피드에서 기존 wrapper 스크롤 스타일이 항상 작동하지 않는다.

## 승인 요구사항

1. 피드의 일반 텍스트 및 표 셀 글꼴, 크기, 굵게/기울임 등 안전한 텍스트 서식을 작성기와 동일하게 유지한다.
2. notice 전용 sanitizer를 사용하고 공통 sanitizer 기본 동작 및 댓글 처리에는 영향을 주지 않는다.
3. 공지 저장 시 허용된 텍스트 서식은 기존 HTML body 필드에 보존한다. API 필드, JSON 계약, DB 스키마는 변경하지 않는다.
4. 피드 표시 시 wrapper가 없는 각 표를 `.tableWrapper`로 감싸며, wrapper에만 수평 스크롤을 적용한다. wrapper는 저장하지 않는다.
5. 접힘/펼침 피드 본문 모두 적용하고, 피드 카드 너비 및 기존 미리보기/상호작용 동작을 유지한다.

## 범위

- notice 본문 sanitizer 호출과 피드 렌더링, 관련 프론트 테스트 및 결과 문서/스크린샷.
- 백엔드/API/DB, 첨부 이미지 및 댓글 sanitizer는 제외한다.

## 완료 조건

- 안전한 폰트/크기 스타일은 보존되고 unsafe markup/style은 제거된다.
- 피드 표는 중복 wrapper 없이 감싸지며 넓은 표만 wrapper 안에서 가로 스크롤된다.
- 접힘/펼침 렌더 테스트, focused notice 테스트, 프론트 빌드, 데스크톱/375px 브라우저 확인이 통과한다.
- 결과 문서와 스크린샷을 `docs/result/20261002/notice-feed-table-rendering/`에 기록한다.
