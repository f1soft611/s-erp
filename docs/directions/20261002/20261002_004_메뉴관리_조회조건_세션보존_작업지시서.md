# 20261002_004 메뉴관리 조회조건 세션 보존 작업지시서

## 목적

메뉴관리 화면을 나갔다가 다시 진입해도 로그인 세션 동안 마지막으로 사용한 모듈, 권한, 검색어를 복원한다. 공통코드 관리와 동일하게 페이지별 `sessionStorage` 기반 상태 보존 패턴을 사용한다.

## 작업 범위

- 메뉴관리의 선택 모듈 ID, 선택 권한 ID, 검색어를 페이지 상태로 저장한다.
- 화면 재진입 시 모듈/권한 목록을 준비한 뒤 저장값을 검증하고 복원한다.
- 저장된 모듈과 권한이 모두 유효하면 해당 조건으로 메뉴 목록을 조회한다.
- 페이지 상태는 공통 `usePageSessionState` 훅을 사용하고, 페이지 전용 key 및 버전 검증을 둔다.
- 메뉴관리 관련 테스트와 프론트엔드 빌드로 복원 및 기존 기능을 검증한다.

## 제외 범위

- 선택된 트리 행, 펼침 상태, 그리드의 미저장 편집 내용 복원
- `localStorage`, 서버 저장, 계정 간 상태 공유
- 메뉴관리 조회/저장 API 계약 및 검색 동작 변경
- F1-Grid 또는 F1Tree 공통 상태 저장 기능 추가

## 완료 기준

1. 같은 브라우저 탭 세션 안에서 메뉴관리 재진입 시 유효한 모듈·권한·검색어가 복원된다.
2. 복원된 모듈과 권한이 있으면 그 조건의 메뉴 목록을 다시 조회한다.
3. 누락·구버전·잘못된 형식 또는 존재하지 않는 모듈/권한 값은 안전한 기본값으로 처리한다.
4. 미저장 그리드 편집 내용과 선택 행은 저장하지 않는다.
5. 메뉴관리 관련 테스트 및 프론트엔드 빌드가 통과한다.
6. 구현·검증 결과를 날짜별 결과 문서에 기록한다.

## 승인된 설계

저장 항목은 `selectedModuleId`, `selectedRoleId`, `searchQuery` 세 가지로 제한한다. 상세 설계는 [메뉴관리 조회조건 세션 보존 설계](../../superpowers/specs/2026-10-02-menu-management-session-state-design.md)를 기준으로 한다.
