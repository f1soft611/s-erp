# 20261002_005 기안양식 분류 안내 초기 노출 보완 작업지시서

## 작업 목적

기안양식관리 페이지에 진입할 때 분류 옵션 조회가 끝나기 전에 빈 분류 안내가 노출되는 현상을 방지한다.

## 범위

- 옵션 로딩이 끝나기 전에는 분류 안내를 표시하지 않는다.
- 옵션 로딩 완료 후 분류 항목이 없을 때만 기존 안내를 표시한다.
- 조회, 분류 편집, 양식 그리드 동작은 변경하지 않는다.

## 완료 기준

- 분류 옵션 요청이 대기 중일 때 안내가 보이지 않는다.
- 요청이 완료되고 분류 항목이 없으면 안내가 보인다.
- 관련 테스트 및 프론트엔드 빌드가 통과한다.
- 결과 문서에 검증 내용을 기록한다.
