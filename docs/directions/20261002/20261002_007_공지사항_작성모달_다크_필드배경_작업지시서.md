# 20261002_007 공지사항 작성 모달 다크 필드 배경 작업지시서

## 목적

공지 작성 모달의 다크 테마에서 구분과 제목 입력면을 본문 편집 영역과 은은하게 구분한다.

## 승인 요구사항

- 다크 테마의 구분·제목 입력 배경을 `#1e293b`로 적용한다.
- 라이트 테마 입력 배경은 기존 흰색을 유지한다.
- 본문 편집기 및 첨부 영역 배경, 모달 구조, 저장 동작은 변경하지 않는다.
- 기존 공지 모달 작업 변경을 보존하고 이번 색상 변경만 추가한다.

## 예상 변경 범위

- `frontend/tests/notice-composer-dialog-theme.test.tsx`

## 완료 기준

1. 다크 테마에서 구분·제목 입력면이 `#1e293b`로 렌더링된다.
2. 라이트 테마 입력면은 흰색이고 본문 편집 영역은 기존 배경을 유지한다.
3. 관련 테마 테스트와 프론트엔드 빌드가 통과한다.
4. 375px, 768px, 1280px 다크 모드 브라우저 표시를 확인하고 결과 문서에 캡처를 포함한다.

- 제목·구분 이외 편집면의 배경이나 테두리 변경
