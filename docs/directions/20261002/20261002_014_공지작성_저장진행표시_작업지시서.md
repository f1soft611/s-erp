# 20261002_014 공지 작성 저장 진행 표시 작업지시서

## 목적

공지 작성 모달에서 본문이 길어 저장 요청이 오래 걸릴 때 저장 중임을 명확히 보여주고, 중복 제출을 방지한다.

## 요구사항

1. 유효한 저장 요청 중 저장 버튼에 16px 진행 spinner와 `저장 중…` 문구를 표시한다.
2. 저장 중 저장 버튼을 비활성화해 중복 제출을 막고 취소/닫기도 방지한다.
3. 구분 필수 검증 실패에는 저장 spinner를 표시하지 않는다.
4. 요청 성공/실패 모두 진행 상태를 해제한다. 기존 성공/실패 및 저장 데이터 동작은 유지한다.
5. API 계약, 서버 저장 방식, 본문 인코딩은 변경하지 않는다.

## 범위 및 완료 조건

- 대상: 공지 작성 모달 저장 상태, focused Vitest 테스트, 프론트 문서/결과.
- 지연된 `onSubmit` 중 spinner 표시, 버튼 비활성, 한 번만 호출됨을 테스트한다.
- 성공과 실패 이후 spinner가 제거되고 버튼 문구가 `저장`으로 복구되는지 검증한다.
- focused 공지 테스트와 `npm --prefix frontend run build`를 통과한다.
- 결과 기록은 `docs/result/20261002/notice-composer-save-progress/`에 남긴다.

## 제외 범위

- 백엔드/API/DB 성능 변경
- 공통 버튼 컴포넌트 추상화
- 기안양식 및 다른 모달의 저장 동작 변경
