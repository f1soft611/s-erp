# 20261002_003 공통 모달 셸 통일 작업지시서

## 목적

그룹웨어 공지 작성과 F1-Grid 행 폼에서 사용하는 모달의 헤더·본문·푸터 구조를 공통화하고, 필요한 모달이 푸터 왼쪽 보조 콘텐츠를 전달할 수 있게 한다.

## 작업 범위

- 공통 모달 셸을 추가해 제목/설명/닫기, 본문 스크롤, 푸터 레이아웃을 일관되게 제공한다.
- 푸터 왼쪽에 선택형 `footerStart` 슬롯을 제공한다. 공지 작성의 편집·첨부 툴바와 F1-Grid 폼의 안내문을 이 슬롯으로 전달한다.
- 그룹웨어 공지 작성 모달과 F1-Grid 행 폼 모달을 단계적으로 공통 셸로 이전한다. 기안양식관리의 행 폼은 F1-Grid 경로를 통해 적용한다.
- 기존 모바일 동작, 테마, 접근성, 저장·취소·검증 동작을 보존한다.
- F1-Grid 사용 문서와 결과 문서를 갱신하고 375px, 768px, 1280px 브라우저 검증 스크린샷을 남긴다.

## 제외 범위

- 확인/경고 대화상자, 이미지 뷰어 등 특수 목적 모달의 일괄 이전
- 업무별 본문 편집기·폼·데이터 흐름 및 API 계약 변경
- 모든 MUI `Dialog`의 일괄 교체

## 완료 기준

1. 공통 셸이 헤더·본문·푸터의 기본 레이아웃과 본문 전용 스크롤을 제공한다.
2. `footerStart`가 있는 공지 작성에서 툴바와 우측 액션이 겹치지 않고, 슬롯이 없는 모달은 우측 액션을 일관되게 정렬한다.
3. F1-Grid 행 폼과 기안양식관리 생성/수정 흐름, 공지 작성 동작, 라이트/다크 테마, 모바일 표시가 유지된다.
4. 관련 Vitest와 프론트엔드 빌드가 통과하며, F1-GRID 문서와 날짜별 결과 문서 및 브라우저 스크린샷이 포함된다.
