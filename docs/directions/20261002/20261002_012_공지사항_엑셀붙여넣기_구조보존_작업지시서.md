# 20261002_012 공지사항 Excel 붙여넣기 구조 보존 작업지시서

## 작업 목적

공지사항 작성 모달에서 Excel/Spreadsheet 표를 붙여넣을 때 행·열 배치, 셀 크기, 글꼴 서식과 셀 내부 줄바꿈이 최대한 유지되도록 정규화한다. 원본보다 좁은 Excel 열이 에디터 기본 최소 너비로 과도하게 커지지 않게 조정하며, 넓은 표의 편집기 내부 가로 스크롤은 유지한다.

## 확인한 현재 동작과 원인 가설

- 공통 `frontend/src/shared/components/rich-text-editor/clipboard.ts`는 표의 각 행에서 `querySelectorAll('th, td')`를 사용해 하위 셀까지 수집하고, 셀 내용은 `textContent`와 공백 축약으로 평탄화한다.
- 이 구현은 셀 내부 `<br>`/문단 경계를 없애며, 중첩 표가 포함되면 하위 표 셀이 바깥 행의 셀처럼 다시 수집될 수 있다.
- 표를 재구성할 때 원본 `<colgroup>`을 버려 Excel의 열별 폭이 Tiptap `colwidth`로 전달되지 않는다. 병합 셀의 전체 폭 스타일만 남아 브라우저가 열 너비를 다시 추정한다.
- 편집기 표는 `max-content` 폭과 내부 `overflow-x: auto`를 사용하므로 표 폭/스크롤 UI는 유지하되 원본 열 너비 전달을 보완한다.

## 승인 범위 및 요구사항

1. Excel HTML의 표 행·셀 구조, 빈 셀, `rowspan`, `colspan`, 셀/행 크기와 `<colgroup>`의 열별 너비를 유지한다.
2. 셀 내부의 `<br>` 및 문단 경계를 보존해 여러 줄 텍스트를 한 줄로 합치지 않는다.
3. 각 행은 자신에게 속한 셀만 구조화하고 중첩 표의 셀이 바깥 표의 열 수에 중복 반영되지 않게 한다.
4. 허용 목록의 글꼴 크기/가족, 색상, 굵게/기울임 및 기존 셀 배경/테두리/정렬을 보존한다. 임의 CSS 전체를 보존하지 않는다.
5. 표 HTML이 없는 경우 기존 일반 텍스트 붙여넣기와 plain-text fallback을 유지한다.
6. 이미지 붙여넣기 우선순위, 업로드, 저장/API 동작은 변경하지 않는다.
7. Tiptap 표의 기본 셀 최소 너비는 16px로 조정한다. Excel의 더 큰 명시 너비는 유지하고, 기존 툴바 표는 텍스트/사용자 크기 조정으로 확장 가능하게 한다.
8. Excel `<colgroup>`의 안전한 px/pt 등 절대 열 너비를 병합 범위와 `rowspan` 위치에 맞춘 Tiptap `colwidth`로 변환한다. 이 폭이 제공되면 열 너비를 기준으로 렌더링하고 중복된 병합 셀 전체 폭으로 다시 늘리지 않는다.

## 완료 조건

1. 단위 테스트가 셀 내부 줄바꿈, 병합 셀, 빈 셀, 글꼴 스타일 및 중첩 셀 탐색 경계를 검증한다.
2. 모달의 실제 붙여넣기 경로에서 복잡한 표의 셀 텍스트, 크기/폰트 서식과 행·열 구조가 유지된다.
3. 기존 공지 Excel/일반 텍스트/이미지 붙여넣기 테스트와 프론트엔드 빌드가 통과한다.
4. Chromium에서 여러 행의 표를 붙여넣고 본문이 옆 셀에 합쳐지지 않는지, 넓은 표는 편집기 안에서 가로 스크롤되는지 확인한다.
5. 검증 명령, 브라우저 확인, 스크린샷을 결과 문서에 기록한다.

## 적용 경계

- 공통 clipboard normalizer와 editor schema/style은 공지 및 기안양식 양쪽에서 사용한다. 기안양식 본문 편집기 적용은 [20261002_015 공통 에디터 및 공지 페이지 분리 작업지시서](20261002_015_공지_공통_리치텍스트에디터_페이지분리_작업지시서.md)에서 관리한다.
