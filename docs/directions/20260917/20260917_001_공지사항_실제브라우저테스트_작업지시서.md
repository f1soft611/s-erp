# 20260917_001 공지사항 실제 브라우저 테스트 작업지시서

## 작업 목적

공지사항 페이지(http://127.0.0.1:4173/groupware/community/notice)에서 실제 브라우저를 통해 CRUD 동작과 첨부파일/댓글 기능이 정상 동작하는지 검증한다. 현재 확인된 댓글 작성 오류, 첨부파일 포함 저장 오류, 저장 후 목록 맨뒤 이동, 저장 후 제목 입력값 잔류 현상을 재현하고 원인을 수정한 뒤 최종 동작을 재검증한다.

## 대상 페이지

- `http://127.0.0.1:4173/groupware/community/notice`
- 관련 화면 컴포넌트: `frontend/src/pages/groupware/community/notice/**`
- 관련 공통 서비스/유틸: `frontend/src/shared/services/**`, `commonContentApi`

## 검증 항목

1. 공지사항 저장, 수정, 삭제 테스트
2. 공지사항 첨부파일 포함 저장, 수정, 삭제 테스트
3. 댓글 저장, 수정, 삭제 테스트
4. 답글 저장, 수정, 삭제 테스트
5. 댓글 작성 실패 시 오류 메시지와 작성 상태가 일관되게 유지되는지 확인
6. 첨부파일 포함 공지 저장 실패 시 게시글·첨부파일 상태가 부분 성공으로 남지 않는지 확인
7. 공지 저장 성공 후 서버 정렬 기준에 맞는 위치에 표시되는지 확인
8. 공지 저장 성공 후 작성 모달의 제목·본문·첨부파일이 초기화되는지 확인
9. 브라우저 동작상 오류/예외 발견 시 즉시 수정 및 재검증

## 수정 범위

- 공지사항 작성/편집 모달의 저장·수정 로직
- 첨부파일 업로드/다운로드/삭제 흐름
- 공지사항 목록 재조회 및 상세/수정 상태 갱신, 저장 후 정렬 위치 보정
- 저장 성공 후 작성 모달 입력값 초기화
- 댓글 및 답글 작성/수정/삭제 로직
- 댓글 작성 실패 시 로컬 댓글 트리 및 입력 상태 처리
- 관련 UI 상태, 에러 메시지, 재렌더링 문제 수정

## 제외 범위

- 다른 그룹웨어 페이지 전면 리팩터링
- 백엔드 신규 API 설계
- DB 스키마 변경
- 무관한 기능의 대규모 리팩터링
- 공지사항의 새로운 업무 규칙이나 권한 정책 추가

## 완료 기준

- 실제 브라우저에서 공지사항 저장/수정/삭제이 정상 동작한다.
- 첨부파일 포함 공지사항 저장/수정/삭제가 정상 동작한다.
- 댓글과 답글 저장/수정/삭제가 정상 동작한다.
- 댓글 저장 실패 시 사용자에게 오류가 표시되고 실패한 댓글이 로컬 목록에 추가되지 않는다.
- 첨부파일 포함 저장 실패 시 성공 메시지가 표시되지 않으며, 재시도 가능한 상태가 유지된다.
- 공지 저장 성공 후 목록이 서버 정렬 기준으로 표시되고 새 공지가 임의로 맨뒤에 추가되지 않는다.
- 공지 저장 성공 후 작성 모달을 다시 열면 제목, 본문, 첨부파일이 비어 있다.
- 오류가 발생하면 원인 파악 후 수정하고 재검증까지 완료한다.
- 브라우저 검증 결과와 수정 내역을 결과 문서에 정리한다.

## 검증 실행 방식

- 브라우저는 로컬 Vite 개발 서버에 접속해 실제 사용자 시나리오로 실행한다.
- 저장/수정/삭제는 실제 페이지 동작을 기준으로 검증한다.
- 필요한 경우 개발자 도구 로그, 네트워크 확인, UI 상태 확인을 병행한다.

## 문서 관리

- 구현 전 작업지시서를 작성하고 사용자 승인 확인
- 계획서와 상세 사양서 작성 후 구현 진행
- 구현 후 결과 문서와 브라우저 스크린샷 기록
