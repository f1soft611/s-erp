# 20260917_001 공지사항 실제 브라우저 테스트 작업지시서

## 작업 목적

공지사항 페이지(http://127.0.0.1:4173/groupware/community/notice)에서 실제 브라우저를 통해 CRUD 동작과 첨부파일/댓글 기능이 정상 동작하는지 검증한다. 오류가 발견되면 즉시 원인 분석 후 수정하고, 수정 결과를 재검증하여 최종적으로 동작이 안정적으로 확인되도록 한다.

## 대상 페이지

- `http://127.0.0.1:4173/groupware/community/notice`
- 관련 화면 컴포넌트: `frontend/src/pages/groupware/community/notice/**`
- 관련 공통 서비스/유틸: `frontend/src/shared/services/**`, `commonContentApi`

## 검증 항목

1. 공지사항 저장, 수정, 삭제 테스트
2. 공지사항 첨부파일 포함 저장, 수정, 삭제 테스트
3. 댓글 저장, 수정, 삭제 테스트
4. 답글 저장, 수정, 삭제 테스트
5. 브라우저 동작상 오류/예외 발견 시 즉시 수정 및 재검증

## 수정 범위

- 공지사항 작성/편집 모달의 저장·수정 로직
- 첨부파일 업로드/다운로드/삭제 흐름
- 공지사항 목록 재조회 및 상세/수정 상태 갱신
- 댓글 및 답글 작성/수정/삭제 로직
- 관련 UI 상태, 에러 메시지, 재렌더링 문제 수정

## 제외 범위

- 다른 그룹웨어 페이지 전면 리팩터링
- 백엔드 신규 API 설계
- DB 스키마 변경
- 무관한 기능의 대규모 리팩터링

## 완료 기준

- 실제 브라우저에서 공지사항 저장/수정/삭제이 정상 동작한다.
- 첨부파일 포함 공지사항 저장/수정/삭제가 정상 동작한다.
- 댓글과 답글 저장/수정/삭제가 정상 동작한다.
- 오류가 발생하면 원인 파악 후 수정하고 재검증까지 완료한다.
- 브라우저 검증 결과와 수정 내역을 결과 문서에 정리한다.

## 검증 실행 방식

- 브라우저는 로컬 Vite 개발 서버에 접속해 실제 사용자 시나리오로 실행한다.
- 저장/수정/삭제는 실제 페이지 동작을 기준으로 검증한다.
- 필요한 경우 개발자 도구 로그, 네트워크 확인, UI 상태 확인을 병행한다.

## 문서 관리

- 구현 전 작업지시서를 작성하고 사용자 승인 확인
- 계획서와 상세 사양서 작성 후 구현 진행
- 구현 후 결과 문서와 브라우저 스크린샷 기록
