# 작업지시서

## 작업명

DB MCP 참조 규칙 추가

## 목적

데이터베이스 관련 작업지시를 수행하는 AI 에이전트가 구현 전에 S-ERP 읽기 전용 MCP 서버로 현재 데이터베이스 계약을 확인하도록 한다.

## 작업 내용

- 루트 작업 절차와 완료 기준에 DB MCP 참조 조건 및 대체 절차를 추가한다.
- 백엔드 Java, MyBatis XML, SQL, 데이터베이스 문서 작업에 적용되는 전용 지침을 추가한다.
- 읽기 전용 MCP 사용 범위와 민감정보 기록 금지 규칙을 명시한다.

## 완료 기준

- DB 관련 작업의 MCP 확인 시점과 도구 사용 순서가 명확하다.
- MCP 연결 실패 시 근거 기록 및 대체 확인 절차가 명확하다.
- 기존 스키마 이력과 SQL 롤백 관리 규칙이 유지된다.
