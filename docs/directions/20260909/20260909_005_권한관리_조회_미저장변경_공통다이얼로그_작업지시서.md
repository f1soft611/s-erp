# 작업지시서

## 제목

모듈관리·권한관리 조회 시 미저장 변경사항 공통 확인 다이얼로그 적용

## 작업 분류

- 경로: `bounded`
- 사유: 모듈관리와 권한관리 페이지의 조회 버튼이 그리드 변경 상태를 확인하지 않고 목록을 즉시 다시 불러온다. 메뉴관리와 동일한 공통 확인 다이얼로그 흐름으로 정렬한다.

## 목표

1. 모듈관리와 권한관리 그리드에 미저장 변경사항이 있을 때 조회 버튼이 공통 `UnsavedChangesConfirmDialog`를 표시한다.
2. 취소하면 변경사항과 현재 목록을 유지하고 재조회 API를 호출하지 않는다.
3. 계속하면 변경사항을 버리고 역할 목록을 다시 불러온다.
4. 변경사항이 없을 때 조회 동작은 기존처럼 즉시 실행한다.

## 범위

- 대상: `frontend/src/pages/settings/system/modules/ModuleManagementPage.tsx`, `frontend/src/pages/settings/system/roles/RoleManagementPage.tsx`, 관련 Vitest, 작업 결과 문서
- 공통 UI: 기존 `frontend/src/shared/components/UnsavedChangesConfirmDialog.tsx`를 재사용한다.
- 제외: 메뉴관리 동작 변경, 역할 저장/API 계약 변경, 백엔드 및 DB 변경

## 완료 기준

- 조회 버튼이 미저장 변경 상태에서 제목 `저장하지 않은 변경사항`의 공통 다이얼로그를 연다.
- 안내 문구는 대상 목록에 맞춰 `변경사항을 버리고 모듈 목록을 다시 불러오시겠습니까?` 또는 `변경사항을 버리고 권한 목록을 다시 불러오시겠습니까?`이다.
- 취소와 계속의 API 호출 및 그리드 상태가 각각 요구사항대로 동작한다.
- 관련 Vitest, 프론트엔드 빌드 및 실제 브라우저 확인 결과를 결과 문서에 기록한다.
