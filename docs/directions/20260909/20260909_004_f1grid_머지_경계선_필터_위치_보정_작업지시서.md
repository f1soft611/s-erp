# F1-Grid 병합 경계선 및 필터 위치 보정 작업지시서

## 배경

F1-Grid 테스트 화면에서 병합된 셀의 마지막 행 경계선이 표시되지 않는다. 또한 컬럼 메뉴에서 필터를 선택하면 필터 창이 선택한 헤더와 다른 위치에 표시된다.

## 목표

1. `mergeRows` 셀의 병합 범위 하단에 행 경계선을 표시한다.
2. 컬럼 필터 창을 선택한 컬럼 헤더 메뉴 버튼 아래에 표시한다.
3. 공용 F1-Grid 회귀 테스트와 문서를 함께 갱신한다.

## 범위

- 대상: 공용 F1-Grid의 `GridCell`, `GridHeader`, 관련 Vitest 및 F1-Grid 문서
- 제외: 백엔드 API, 데이터베이스, 화면별 데이터 계약 변경

## 완료 기준

- 병합 시작 셀이 병합 범위 마지막 행의 하단 경계선을 표시한다.
- 필터 창이 제거되는 메뉴 항목이 아니라 선택 컬럼의 헤더 메뉴 버튼에 앵커링된다.
- 관련 Vitest와 실제 브라우저 검증을 수행하고 결과 문서에 기록한다.
