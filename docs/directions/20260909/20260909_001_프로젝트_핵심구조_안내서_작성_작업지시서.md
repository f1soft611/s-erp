# 작업지시서

## 작업명

S-ERP 프로젝트 핵심 구조 안내서 작성

## 목적

현재 프로젝트의 주요 영역과 작업 흐름을 한 개의 짧은 Markdown 안내서로 제공한다.

## 작업 내용

- `docs/guide/project-structure.md`에 프론트엔드, 백엔드, 문서, 데이터베이스 이력의 역할과 주요 경로를 정리한다.
- 실행 및 검증 명령과 문서 기반 작업 순서를 기록한다.
- 기존 코드와 설정은 변경하지 않는다.

## 완료 기준

- 안내서가 핵심 경로와 역할을 포함한다.
- 안내서의 경로와 명령이 현재 프로젝트 구조와 일치한다.
- 계획서, 사양서, 결과 문서에 작업 이력이 남는다.
