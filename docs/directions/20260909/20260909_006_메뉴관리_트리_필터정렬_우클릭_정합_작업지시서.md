# 메뉴 관리 트리 필터/정렬 우클릭 정합 작업지시서

## 배경

메뉴 관리 화면은 `F1Tree`를 사용하며, 모듈 관리와 권한 관리의 `F1Grid`와 달리 우클릭 메뉴에서 필터와 정렬을 해제하는 동작이 일관되지 않다.

## 목표

1. 메뉴 관리 트리에서도 필터와 정렬 기능을 사용할 수 있게 한다.
2. 우클릭 메뉴의 `필터 해제`, `정렬 해제`가 모듈 관리 및 권한 관리와 동일하게 공용 상태를 초기화하게 한다.
3. 메뉴 관리 회귀 테스트와 F1-Grid 문서를 갱신한다.

## 범위

- 대상: 공용 `F1Tree`, 메뉴 관리 F1-Grid 회귀 테스트, F1-Grid 문서, 결과 문서
- 제외: 메뉴 API, 백엔드, 데이터베이스, 트리의 펼침/접기 및 행 추가 정책 변경

## 완료 기준

- 메뉴 관리 트리 우클릭 메뉴에 활성 상태에 따른 `필터 해제`, `정렬 해제`가 표시된다.
- 각 메뉴 항목을 누르면 해당 상태만 초기화되고, 행 데이터와 트리 구조는 유지된다.
- 관련 Vitest, 프론트엔드 빌드, 실제 브라우저 동작을 검증한다.
