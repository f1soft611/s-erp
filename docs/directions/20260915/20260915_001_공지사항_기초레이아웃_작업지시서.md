# 20260915_001 공지사항 기초 레이아웃 작업지시서

## 1. 목적

그룹웨어 하위 커뮤니티 구조에서 첫 기능으로 공지사항을 구현한다. 우선 사용자 관점에서 가장 자연스러운 공지 목록 화면과 상세 화면의 레이아웃을 설계하고, 이 구조를 기준으로 이후 코드와 API를 구현한다.

## 2. 기본 구조

- 모듈: `GROUPWARE`
- 중메뉴: `커뮤니티`
- 하위 메뉴: `공지사항`
- 경로: `/groupware/community/notice`
- 게시판 유형: `NOTICE`

## 3. 사용자 요구사항 정리

1. 공지사항은 커뮤니티 하위의 첫 화면으로 노출된다.
2. `커뮤니티`는 중메뉴이고, 실제 공지사항은 그 아래 세부 기능이다.
3. 목록형 화면이 기본이며, 상세 내용은 선택 시 확인할 수 있어야 한다.
4. 관리자/운영자 관점의 등록/수정/삭제 기능은 이후 단계에서 확장한다.
5. 초기에 UI는 목록 중심, 상세는 분리된 패널 또는 페이지로 구성한다.

## 4. 설계 방향

### 4-1. 메인 레이아웃

- 상단 영역: 페이지 타이틀, 검색, 새 공지 작성 버튼
- 중간 영역: 필터/정렬 툴바
- 본문 영역: 공지 목록 테이블 또는 F1-Grid 기반 리스트
- 상세 영역: 선택된 공지의 본문, 첨부파일, 이전/다음 공지 이동

### 4-2. 목록 구성

| 컬럼   | 내용                |
| ------ | ------------------- |
| 중요   | 상단 고정 공지 표시 |
| 제목   | 공지 제목           |
| 작성자 | 등록자 이름         |
| 작성일 | yyyy-mm-dd 형태     |
| 조회수 | 읽기 수             |
| 상태   | 공지/일반/숨김 여부 |

### 4-3. 상세 구성

- 상단: 제목
- 메타정보: 작성자, 작성일, 조회수
- 본문: 에디터 기반 텍스트 또는 정적 HTML 렌더링
- 하단: 첨부파일 목록, 이전/다음 글, 목록 돌아가기

### 4-4. 반응형 동작

- 데스크톱: 목록 + 상세 분할 레이아웃
- 태블릿: 목록 위주, 상세는 하단 확장 또는 모달 방식
- 모바일: 카드형 리스트, 세부 내용은 별도 페이지로 전환

## 5. 범위
