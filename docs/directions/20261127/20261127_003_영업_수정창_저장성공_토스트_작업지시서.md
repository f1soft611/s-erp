# 영업 저장 성공 토스트 작업지시서

- 작성일: 2026-11-27
- 근거: [영업 소수점 배포 전 확인 결과](../../result/20261127/sales-decimal-predeploy/20261127_002_영업소수점_배포전_확인_결과.md) "확인 필요". 현황 화면의 수정 창은 저장이 끝나면 바로 닫혀, 창 안의 성공 문구가 함께 사라지고 사용자에게 성공 피드백이 없다(루트 `AGENTS.md` 작업 시작 전 체크리스트 12번).
- 사용자 지시(2026-11-27)
  1. "이거 보완해야 겠다. 토스트 메시지를 보여주면 될 거 같아"
  2. "기존 규칙대로 정상 메시지는 토스트로 하고 실패시에는 메시지영역에 나오게 하는거지?" → 범위 선택: **영업 전체 + 규칙 문서화**

## 요청

영업관리 화면의 처리 성공 문구를 공통 토스트로 통일하고, 실패 문구는 메시지 영역에 유지한다. 이 규칙을 `frontend/AGENTS.md`에 문서화한다.

## 범위

- 성공 문구를 화면 안 `Alert`로 표시하던 영업 화면 7개: 견적등록, 수주등록, 출하등록, 거래명세서등록(`useSalesStatementCreate`), 출하계획등록, 출하계획현황, 매출마감. 견적·수주·출하·거래명세서 등록 화면은 현황 화면의 수정 창에도 쓰이므로 수정 창도 함께 적용된다.
- 제외: 구매자재·품질 등 다른 모듈(같은 구조, 담당 모듈이 다름), 성공 문구가 원래 없는 동작(거래명세서 삭제)에 새 문구 추가.
- 별도 작업: 수정 창 저장 후 목록 조용한 로딩(사용자 후속 피드백, [20261127_004](20261127_004_영업_수정창_저장후_조용한로딩_작업지시서.md)).

## 완료 기준

1. 위 화면에서 저장·수정·삭제·마감 성공 시 기존 문구가 공통 토스트로 표시되고, 화면 안 성공 `Alert`은 표시되지 않는다.
2. 수정 창에서 저장·삭제 성공 시 창이 닫혀도 토스트가 남는다.
3. 실패는 기존처럼 화면 또는 수정 창 안 메시지 영역에 표시되고 토스트는 뜨지 않으며, 수정 창은 닫히지 않는다.
4. `frontend/AGENTS.md`에 성공=토스트, 실패=메시지 영역 규칙이 있다.
5. 실패하는 테스트를 먼저 추가하고 구현 후 통과를 확인한다. 기존 성공 문구 테스트는 토스트 기준으로 갱신한다.
6. 로컬 브라우저에서 실제 저장 후 토스트 스크린샷을 남긴다.
