# 영업 수정 창 세로 스크롤바 위치 작업지시서

- 작성일: 2026-11-27
- 근거: 사용자 피드백(2026-11-27) "모달창 수정 모달창 확인해보니깐 세로 스크롤 생길때 화면 끝에 생기는게 좋은거 아냐?", "응 다음 작업해주면되"

## 현황

견적·수주·출하·거래명세서·출하계획 수정 창은 `CommonDialog` 본문(`DialogContent`)이 좌우 24px·상하 16px 여백을 갖고, 실제 세로 스크롤은 그 안의 등록 화면 영역(`overflowY: auto`)에서 일어난다. 그래서 스크롤바가 창 오른쪽 끝이 아니라 본문 여백 안쪽(창 끝에서 약 24px 안)에 생긴다.

## 요청

수정 창의 세로 스크롤바가 창 오른쪽 끝에 붙도록 한다. 내용의 위치·여백·폭은 바꾸지 않는다.

## 범위

- `CommonDialog`에 본문 여백을 끄는 선택 옵션 추가(기본값은 현재와 동일, 다른 대화상자 영향 없음)
- 영업 수정 창 5개: 견적·수주·출하·거래명세서·출하계획

## 완료 기준

1. 5개 수정 창에서 스크롤 영역의 오른쪽 끝이 창(Paper) 오른쪽 끝과 같다(스크롤바가 창 끝에 생김).
2. 내용(기본정보 패널 등)의 좌우 위치와 상단 위치가 변경 전과 같다.
3. 메뉴에서 연 등록 화면의 여백은 바뀌지 않는다.
4. 실패하는 테스트를 먼저 추가하고 구현 후 통과를 확인한다.
5. 로컬 브라우저 스크린샷과 위치 측정값을 남긴다.
