# 20260918_005 공지사항 엑셀 붙여넣기 에디터 개선 작업지시서

## 작업 목적

공지사항 작성 에디터에서 Excel/Spreadsheet 복사 내용을 붙여넣을 때, 값이 누락되거나 구조가 깨지지 않고 실제로 사용하는 업무 형태에 맞게 정교하게 반영한다. 이 기능은 ERP에서 공지사항/업무 문서 작성 시 가장 중요한 입력 경로 중 하나로, 붙여넣기 동작이 빠르고 정확해야 한다.

## 대상 페이지 및 범위

- 대상 화면: 공지사항 작성/수정 모달
- 핵심 파일:
  - `frontend/src/pages/groupware/community/notice/components/NoticeComposerDialog.tsx`
  - 필요 시 `frontend/src/pages/groupware/community/notice/components/noticeContentStyles.ts`
  - 필요 시 공지사항 관련 테스트 파일 및 결과 문서
- 범위는 공지사항 에디터의 붙여넣기 입력 로직 및 시각적 결과에 국한한다.

## 요구사항

1. Excel/Spreadsheet 복사 붙여넣기
   - Excel, Google Sheets, 기타 표 형식 복사 내용을 에디터에 붙여넣을 때 셀값이 누락되지 않아야 한다.
   - 표의 행/열 구조가 최대한 유지되어야 한다.
   - 붙여넣기 직후에 단순 텍스트 결합으로 무너지는 문제를 방지한다.
   - 셀 값이 줄바꿈, 공백, 탭, 숫자 포맷, 날짜/시간 값, 빈 칸을 포함하더라도 의미가 보존되어야 한다.

2. 입력 방식 및 우선순위
   - 붙여넣기 이벤트는 `clipboardData`의 HTML/텍스트를 우선적으로 해석한다.
   - Excel의 표 형식 HTML은 행/열 구조로 변환하고, 일반 텍스트 복사는 텍스트로만 삽입한다.
   - 가능한 경우 표를 HTML `<table>` 기반 구조로 안전하게 변환하고, 그렇지 않은 경우에는 paragraph/line break 조합으로 fallback한다.
   - 외부 포맷에서 들어오는 스타일, 중첩 태그, 빈 셀, 줄바꿈, 고정 폭 텍스트를 비정상적으로 그대로 반영하지 않는다.

3. 안전성 및 정합성
   - 사용자의 붙여넣기 내용은 반드시 sanitization/normalization을 거친다.
   - 악성 HTML, 비정상 태그, 인라인 스타일이 과도하게 섞인 값은 제거하거나 안전한 구조로 변환한다.
   - 에디터가 기존 문서 포맷과 충돌하지 않도록, 본문 시맨틱을 유지하면서 붙여넣기만 안전하게 처리한다.
   - 붙여넣기 이후 에디터 본문이 비정상적으로 비어 버리거나, HTML이 깨지거나, 많은 빈 줄이 생기는 상황을 방지한다.

4. 사용자 경험
   - 붙여넣기 이후 즉시 정상적으로 보이고, 사용자가 추가 수정이 가능해야 한다.
   - 복사한 표가 많아도, 붙여넣기 완료 직후 텍스트/테이블이 자연스럽게 보인다.
   - 붙여넣기가 실패했을 때는 plain text fallback이 보장되어야 한다.
   - 기존 텍스트 입력, 서식 도구, 첨부파일 기능과 충돌하지 않아야 한다.

5. 검증 기준
   - 실제 브라우저에서 Excel 또는 표 형식 데이터 복사 후 붙여넣기 테스트를 수행한다.
   - 행/열 값의 누락, 합치기, 중복, 의도치 않은 공백 변환이 발생하지 않아야 한다.
   - 붙여넣기 후 저장 시 에디터 HTML이 정상적으로 직렬화된다.
   - 일반 텍스트 붙여넣기와 표 형식 붙여넣기가 서로 충돌하지 않는다.

## 권장 설계

- 권장안: `onPaste` 이벤트에서 `clipboardData`를 먼저 읽고, Excel 전용 HTML을 하나의 안전한 변환 단계로 정규화한 뒤 에디터에 삽입한다.
- 변환 로직은 에디터 본문 조작과 분리하여, `clipboard` 처리를 별도 함수로 두고 필요한 경우 테스트 가능한 순수 함수 형태로 구성한다.
- 표 형식 데이터는 `table` 구성을 유지하고, 비표형 데이터는 일반 텍스트 또는 paragraph 구조로 fallback한다.
- 외부 HTML은 DOMParser 또는 안전한 HTML 정규화 방식을 사용하고, 에디터가 허용하는 노드만 유지한다.
