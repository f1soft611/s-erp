# 20260918_009 공지사항 구분명·강조색상·모달여백 작업지시서

## 작업 목적

공지사항 작성 모달에서 중요 공지 여부를 직접 선택할 수 있게 하고, 피드에는 실제 `NOTICE_GUBUN` 구분명을 표시하며, 중요 공지만 강조 색상을 적용한다. 작성 모달의 상단 및 필드 간 여백도 통일한다.

## 요구사항

1. 공지사항 작성/수정 모달의 구분 선택지에는 전체 항목을 표시하지 않는다.
   - 전체 항목은 목록 필터에서만 사용한다.
   - 작성/수정 모달은 사용 중인 `NOTICE_GUBUN` 상세코드만 표시한다.
2. 공지사항 작성/수정 모달에 `중요 공지` 체크박스를 추가한다.
   - 체크됨: `isNotice = 'Y'`
   - 체크 해제: `isNotice = 'N'`
   - 수정 시 기존 `isNotice` 값을 체크 상태로 복원한다.
3. 공지사항 피드의 구분 라벨은 `isNotice`와 무관하게 실제 선택된 `NOTICE_GUBUN.itemNm`을 표시한다.
   - 코드명 조회가 불가능한 기존 데이터는 저장된 코드값을 대체 표시한다.
4. 중요 공지 필터를 목록 필터의 가장 앞에 별도 표시한다.
   - `NOTICE_GUBUN` 공통코드에 중요 공지 항목이 없어도 표시한다.
   - 중요 공지 필터는 `isNotice = 'Y'` 기준으로 동작한다.
5. `isNotice = 'Y'`인 게시글만 기존 중요 공지 강조 색상을 사용한다.
   - 구분명 표시와 중요 공지 여부를 혼합해 임의로 다른 명칭을 만들지 않는다.
6. 공지 작성 모달의 상단 여백을 모달 내부 하단 여백과 통일한다.
7. 구분, 중요 공지 체크박스, 제목, 본문 사이의 수직 여백을 동일한 기준으로 통일한다.
8. 모바일 375px, 태블릿 768px, 데스크톱 1280px에서 필드가 겹치거나 잘리지 않아야 한다.

## 권장 구현 방향

- `NOTICE_GUBUN` 상세코드를 코드→명칭 Map으로 구성한다.
- `toNoticeFeedItem`에 코드와 명칭을 주입하거나 페이지 매핑 단계에서 명칭을 결합한다.
- 중요 색상 여부는 `isNotice === 'Y'`일 때만 true로 계산한다.
- 중요 공지 필터는 공통코드 옵션과 별도의 고정 필터 옵션으로 구성한다.
- 작성 모달은 공통코드 옵션 배열을 그대로 사용하되 전체 항목을 추가하지 않는다.
- 모달 콘텐츠의 공통 `gap` 또는 동일한 `marginBlock` 기준으로 구분·제목·본문을 배치한다.
