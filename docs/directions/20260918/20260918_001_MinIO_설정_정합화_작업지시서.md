# 20260918_001 MinIO 설정 정합화 작업지시서

## 작업 목적

백엔드의 MinIO 연결 설정이 실행 프로필, Java fallback, 테스트, 배포 가이드마다 서로 다른 값을 사용하는 문제를 해소하고 제공된 설정 계약으로 통일한다.

## 요구사항

1. 개발 및 운영 프로필의 MinIO 설정을 동일한 속성 계약으로 맞춘다.
2. 기본 provider는 `minio`, bucket은 `document-attachments`, endpoint는 제공된 원격 MinIO 주소를 사용한다.
3. access key와 secret key는 기존 환경변수 이름을 유지하며 제공된 fallback 값으로 맞춘다.
4. region은 `us-east-1`, presign 만료시간은 600초 고정값으로 통일한다.
5. `MinioStorageConfig`의 중첩 fallback도 프로필 설정과 일치시킨다.
6. 설정 회귀 테스트와 Windows 배포 가이드를 같은 계약으로 갱신한다.

## 제외 범위

- MinIO 서버 설치 또는 버킷 생성
- DB 스키마 및 첨부파일 API 변경
- 파일 저장·조회·삭제 비즈니스 로직 변경

## 완료 기준

- dev/prod 프로필과 Java fallback이 동일한 MinIO 설정을 사용한다.
- 설정 회귀 테스트가 모든 관련 기본값을 검증하고 통과한다.
- Windows 배포 가이드의 예시가 새 endpoint와 환경변수 계약을 설명한다.
- Maven 집중 테스트가 통과한다.
