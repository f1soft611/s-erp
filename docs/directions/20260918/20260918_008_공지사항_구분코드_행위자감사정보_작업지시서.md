# 20260918_008 공지사항 구분코드 및 행위자 감사정보 작업지시서

## 작업 목적

공지사항의 구분을 `NOTICE_GUBUN` 공통코드로 관리하고, 공지사항 및 댓글/답글의 저장 행위자가 요청 본문이 아니라 백엔드 인증 사용자 정보로 기록되도록 보완한다.

## 요구사항

1. 공지사항 목록 상단 필터에서 `NOTICE_GUBUN` 그룹의 사용 중인 상세코드를 조회하여 코드명으로 표시한다.
2. 공지사항 작성 및 수정 시 제목 위에서 `NOTICE_GUBUN` 상세코드를 선택할 수 있게 한다.
3. 공지사항 게시글 테이블에 구분 코드 저장 컬럼을 추가한다.
   - 컬럼명: `notice_gubun_code`
   - 저장값: 공통코드 상세 항목의 `item_code`
   - 표시값: 공통코드 상세 항목의 `item_nm`
4. 공지사항 등록 시 작성자 ID/이름은 요청 payload를 신뢰하지 않고 `LoginVO`의 로그인 사용자 정보로 저장한다.
5. 공지사항 수정·삭제 시 최신 행위자 ID/이름을 백엔드 로그인 사용자 정보로 저장한다.
6. 댓글 및 답글 등록 시 작성자 ID/이름은 `LoginVO` 정보로 저장한다.
7. 댓글 및 답글 수정·삭제 시 최신 행위자 ID/이름을 백엔드 로그인 사용자 정보로 저장한다.
8. 기존 권한 검사, 테넌트 분리, 댓글/답글 대상 검증은 유지한다.

## 감사정보 보존 범위

- 전체 변경 이력 테이블은 추가하지 않는다.
- 최신 행위자 정보만 게시글 및 댓글/답글에 보존한다.
- 등록 작성자 정보와 최신 수정·삭제 행위자 정보를 구분할 수 있도록 기존 컬럼과 신규 감사 컬럼의 의미를 명확히 한다.
