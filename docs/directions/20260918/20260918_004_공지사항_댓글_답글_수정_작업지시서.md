# 20260918_004 공지사항 댓글/답글 수정 UX 개선 작업지시서

## 작업 목적

공지사항 댓글 및 답글의 수정 버튼을 눌렀을 때, 기존의 이름/날짜/내용/답글 영역이 아래에 추가되는 방식이 아니라 해당 영역 자체를 수정 입력 영역으로 교체되도록 UX를 개선한다.

## 증상 재현

- 댓글 또는 답글의 더보기 메뉴에서 "수정"을 선택한다.
- 기존 본문 아래에 수정 입력 박스가 추가로 렌더링되어, 이름/날짜/내용/답글 영역이 그대로 남아 있다.
- 수정 UI가 기존 댓글 레이아웃 흐름을 방해하며, 사용자에게 두 개의 서로 다른 상태가 동시에 보인다.

## 요구사항

1. 댓글/답글 수정 시 수정 입력창은 기존 본문 영역을 대체한다.
2. 수정 영역이 열리면, 이름, 날짜, 내용, 답글 버튼 영역이 보이지 않거나 해당 영역과 교체되도록 처리한다.
3. 수정 취소 시 원래 상태의 이름/날짜/내용/답글 영역이 다시 표시된다.
4. 댓글 작성/답글 작성 기능과 기존 서버 저장 로직은 그대로 유지한다.
5. 수정 UX 변경에 필요한 공용 컴포넌트와 테스트만 수정 범위로 제한한다.

- 답글 수정 시에도 동일한 동작이 적용된다.
- 취소 동작으로 원래 UI가 복구된다.
