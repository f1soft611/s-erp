# 20260918 공지사항 초기조회 스켈레톤 및 오류 상태 개선 작업지시서

## 작업 목적

공지사항 초기 진입 시 스켈레톤이 고정 시간 후 사라지는 문제를 해결하고, 실제 API 조회가 끝난 시점에 결과 상태를 표시한다.

## 증상 재현

- 공지사항 화면에 진입한다.
- 공지사항 목록 API 응답이 1.5초보다 늦으면 스켈레톤이 먼저 사라진다.
- API 조회 실패 시 스켈레톤이 사라진 뒤 오류 콘텐츠가 표시되지 않는다.

## 요구사항

1. 초기 공지사항 목록 스켈레톤은 `setTimeout`이 아니라 `fetchNoticePosts` API 조회 완료 시 제거한다.
2. API 조회 성공 시 스켈레톤을 제거하고 조회된 목록 또는 기존 빈 상태를 표시한다.
3. API 조회 실패 시에도 API 처리가 끝난 뒤 스켈레톤을 제거한다.
4. API 조회 실패 시 오류 문구 대신 화면 중앙에 재조회 아이콘 버튼을 표시한다.
5. 재조회 아이콘 버튼을 누르면 공지사항 목록 API를 다시 호출하고, 재조회 중에는 초기 조회와 동일한 스켈레톤을 표시한다.
6. 공지사항 생성/수정 후의 silent refresh 동작과 기존 목록 변환 로직은 유지한다.

## 완료 기준

- 초기 진입 시 고정 `setTimeout` 없이 실제 목록 API 응답까지 스켈레톤이 유지된다.
- API 성공 시 목록 또는 빈 상태가 표시된다.
- API 실패 시 스켈레톤이 제거되고 오류 문구 없는 중앙 재조회 버튼이 표시된다.
- 재조회 버튼 클릭 시 목록 API가 다시 호출된다.
- 초기 조회 성공/실패와 재조회 동작에 대한 관련 Vitest 케이스가 통과한다.
- 프론트엔드 빌드가 통과한다.
