# 20260918_002 MinIO 공지첨부 업로드 오류 작업지시서

## 작업 목적

공지사항에서 파일 업로드를 포함해 저장할 때 `MinIO 업로드 중 오류가 발생했습니다.` 500 오류가 발생하는 문제를 조사하고, 운영 MinIO 권한 계약에 맞게 업로드 흐름을 보정한다.

## 증상

- 공지사항 첨부 파일 업로드 시 서버가 500 응답을 반환한다.
- 사용자에게 보이는 예외 메시지는 `MinIO 업로드 중 오류가 발생했습니다.`로 고정되어 실제 원인이 드러나지 않는다.

## 요구사항

1. MinIO 업로드 실패 시 원인 예외를 서버 로그와 예외 체인에 보존한다.
2. 기본 업로드 흐름에서 매 요청마다 버킷 조회/생성 권한을 요구하지 않도록 한다.
3. 버킷 자동 생성이 필요한 환경은 별도 설정으로 opt-in 할 수 있게 한다.
4. MinIO SDK 버전 중복 선언으로 의도한 클라이언트 버전이 덮어써지지 않도록 정리한다.
5. `SignatureDoesNotMatch` 발생 시 실제 런타임 설정과 의존성 버전을 확인할 수 있게 검증 기준을 보강한다.
6. 기존 공지사항 첨부 API 응답 메시지와 HTTP 상태 계약은 유지한다.
7. 설정, 테스트, 배포 문서를 같은 정책으로 갱신한다.

## 제외 범위

- MinIO 서버 설치 및 운영 버킷 생성 작업
- DB 스키마 변경
- 공지사항 화면 UI 변경
- 첨부파일 API 경로 또는 응답 구조 변경

## 완료 기준

- 공통 파일 서비스가 원인 예외를 보존한다.
- MinIO 저장 서비스가 기본값에서 `putObject` 전에 `bucketExists`를 호출하지 않는다.
- `storage.autoCreateBucket` 설정 기본값이 `false`로 명시된다.
- MinIO Java client는 지원 버전으로 한 번만 선언된다.
- 관련 Maven 집중 테스트가 통과한다.
