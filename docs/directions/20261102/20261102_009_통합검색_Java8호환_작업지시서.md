# 통합검색 Java 8 운영 배포 오류 수정

- 근거: 사용자 제공 운영 시작 로그의 `UnifiedSearchServiceImpl.<clinit>:34` 및 `NoSuchMethodError: java.util.List.of`. 운영 JVM은 Java 8이다.
- 통합검색의 Java 9+ 컬렉션 생성 API와 Java 11 문자열 API를 Java 8 호환 코드로 교체한다.
- 검색 결과 순서, 공백 판정, 권한, API/DB 계약을 변경하지 않는다. 운영 JVM이나 배포 서버 설정을 임의 변경하지 않는다.
- 계획서 → 상세사양서 → 실패 회귀 → 구현 → 대상 검증 → 결과 문서 순서로 진행한다.
- 완료 기준: Java 8 표준 API 기준 컴파일 회귀와 기존 검색 테스트 통과. 운영 재배포 확인과 로컬 검증을 구분한다.
