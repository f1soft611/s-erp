# 알림·쪽지 실시간 갱신 작업지시서

근거: [후속 순서](20261102_007_공통기능_후속확장_작업지시서.md). SSE 변경 신호 + REST 재조회 제안 후 사용자가 자율 구현을 지시했다.

1단계만 구현한다. 새 알림/쪽지, 읽음/보관/대화 숨김 후 배지와 열린 목록/현재 대화를 갱신한다. 입력·과거 대화·스크롤을 보존한다. 저장 성공 이후에만 신호를 발행하며 tenant/user별로 격리한다. 연결 인증/재연결/정리와 장애 복구를 포함한다.

단일 JVM 내 즉시 신호와 30초 주기 재동기화로 구성한다. 다중 JVM 간 즉시 전달은 이번 범위가 아니며 주기 재동기화로 수렴한다. 웹 푸시/업무 이벤트 추가/검색 확대는 후속 단계로 유지한다. SQL/스키마는 변경하지 않는다.
