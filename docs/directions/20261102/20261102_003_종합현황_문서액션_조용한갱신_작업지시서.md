# 20261102_003 종합현황 문서 액션 조용한 갱신 작업지시서

## 목적

종합현황에서 문서 상세를 바로 열고 결재 또는 확인한 뒤, 화면 전체 로딩이나 상세 재로딩 표시 없이 기존 화면을 유지하면서 데이터를 갱신한다.

## 현재 동작

- 종합현황의 결재/확인 문서 항목은 기존 전자결재 상세 오버레이를 바로 연다.
- 결재/확인 성공 뒤 종합현황 summary와 문서 상세를 일반 재조회해 로딩 표시가 다시 나타난다.
- 상세 액션 버튼은 처리 중 비활성화되어 중복 처리를 막는다.

## 요구사항

- 문서 상세 오버레이의 즉시 열기 동작을 유지한다.
- 승인, 반려, 보완요청, 참조확인, 최종확인 요청 중 기존처럼 처리 중 버튼을 비활성화한다.
- 액션 성공 후 종합현황 summary와 열린 상세/시스템 이력을 조용히 갱신한다. 기존 콘텐츠를 유지하고 페이지 전체 skeleton 및 상세 재로딩 overlay를 표시하지 않는다.
- 갱신 실패는 기존 오류 영역으로 명시한다. 이전 성공 상태로 위장하거나 오류를 무시하지 않는다.
- 성공/실패 알림, 서버 권한 검증, 기존 액션 흐름을 유지한다.
- DB/API 계약 변경은 하지 않는다.

## 완료 조건

- 종합현황에서 문서 상세가 즉시 열리고, 액션 처리 중 버튼 비활성화가 유지된다.
- 성공 뒤 현황 및 상세 내용이 갱신되는 동안 화면 콘텐츠와 상세가 유지된다.
- 갱신 오류는 기존 오류 UI에서 확인할 수 있다.
- 관련 회귀 테스트와 프런트엔드 빌드가 통과한다.
- 결과 문서에 재현 조건, 원인, 해결, 검증 결과를 기록한다.
