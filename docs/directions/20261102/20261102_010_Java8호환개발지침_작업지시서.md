# Java 8 호환 개발 지침 문서화

- 근거: 사용자 요청 “자바 개발시 Java 8 호환성에 맞게 개발하게 문서에 기록해서 에이전트가 확인할 수 있게 해줘”.
- 공통·백엔드 에이전트 지침과 개발 환경 안내에 Java 8 호환 개발 기준을 명시한다.
- 개발 도구용 JDK와 운영 코드의 Java 8 호환성 기준을 구분하고, Java 9+ 문법·표준 API·비호환 의존성 사용을 방지한다.
- 계획서 → 상세사양서 → 지침 반영 → 결과 문서 순서로 진행한다.
- 코드·빌드 설정·DB는 변경하지 않는다. 문서 전용 작업이므로 UI 스크린샷은 해당하지 않는다.
