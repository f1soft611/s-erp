# 통합검색 전용 페이지 작업지시서

- 요청일: 2026-11-02.
- 근거: 사용자 첨부 참고 화면 및 “우측 상단 검색 필드를 바로 제공하고 검색이 통합 검색페이지로 이동되어 구분별로 조회되어 사용자가 쉽고 가독성 있게 보길원해”. 변경안 제시 후 사용자가 계획을 멈추고 자율 구현을 지시했다.
- 기존 검색 아이콘/모달 대신 헤더에 검색 입력창을 직접 노출한다. Enter/검색 버튼으로 전용 페이지로 이동한다.
- 기존 ERP 헤더·사이드바 안에서 메뉴/문서/공지 결과를 구분해 제공한다. 전체/유형별 건수, 더보기, 페이지 이동, 검색어 강조를 제공한다.
- 검색어/유형/페이지는 URL에 보존하여 새로고침·뒤로가기를 지원한다.
- 기존 검색 API·권한·검색 대상·데이터 계약은 유지한다. 백엔드/SQL/DB 변경은 없다.
- 추천 검색어, 정확도, 결과 내 재검색, 신규 검색 대상은 추가하지 않는다.
- 날짜별 계획·사양을 먼저 작성하고 구현 후 타깃 테스트/build/lint 및 375/768/1280px 브라우저 검증·스크린샷·결과 문서를 남긴다.
