# 통합검색 작업지시서

- 요청/승인일: 2026-11-02
- 근거: 사용자 “네 통합검색쪽 진행해주세요”, 메뉴·전자결재 문서·공지사항 1차 통합검색 설계에 대한 “승인”.
- 우측 상단 검색 아이콘에서 공통 모달을 열고 전체/메뉴/문서/공지 결과를 제공한다.
- 메뉴 이름·경로, 문서 제목·문서번호·기안자, 공지 제목·본문·작성자를 검색한다.
- 기존 인증/테넌트/메뉴 READ 권한과 문서 관련자 조회 규칙을 재사용한다. 권한 없는 결과/건수는 노출하지 않는다.
- 결과는 기존 메뉴/문서/공지 상세 화면으로 이동한다. 검색 동작 자체는 화면을 이동시키지 않는다.
- 서버 통합 API로 결과를 모으고 이후 업무 검색을 확장할 수 있게 유형별 처리 경계를 둔다.
- trim 후 2자 이상 검색, 유형별 제한/페이지 조회, 로딩/빈 결과/오류/재시도, 이전 응답 무효화를 제공한다.
- 첨부파일 내용·댓글·쪽지·검색 이력 저장·별도 검색엔진·웹 푸시는 제외한다.
- 완료 기준: 권한/범위/이동/검색 경쟁 회귀 테스트, 프런트 빌드·lint, 백엔드 타깃 테스트, 375/768/1280px 브라우저 확인과 결과 문서/스크린샷.
- 실제 DB 변경/DDL 적용은 하지 않는다.
