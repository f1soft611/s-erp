# 20261116_012 가입고등록 화면 작업지시서

## 작업 목적

발주(PO) 다음 단계인 **가입고(MP) 등록 화면**을 만든다.
발주 행의 잔량을 불러와 구매처별로 가입고(물건이 도착해 일단 받아둔 기록)를 등록한다.
기존 MES 가입고등록(`WMA301_REMAKE_VW`, `TMA203/204`, `SP_WMA301_*`)은 업무 규칙 검토용으로만 참고하고, 화면 구조는 s-erp 기존 패턴(발주등록/발주현황)을 따른다.

## 업무 흐름 (2026-11-16 사용자 확정)

발주(PO) → **가입고(MP)** → [검사 대상] 수입검사(QI) → 입고(MI) / [무검사] 가입고 시 입고(MI) 자동 등록

이번 작업은 가입고 단계만 만든다. 입고·수입검사는 후속 작업이며, 가입고 테이블은 그 연동을 받을 수 있게 설계한다.

## 업무 규칙

### 가입고 구성
- 가입고 1건 = 구매처 1곳. 발주 행(`tb_purchase_order_dt`) 단위로 담는다.
- 발주 불러오기: 여러 발주서의 행을 함께 고를 수 있으나 **같은 구매처만** 가능하다(발주등록의 확정 불러오기와 같은 칩 고정 방식).
- 후보 조건: 유효한 발주(헤더 `use_at='Y'`), 행의 입고대기마감 `receipt_close_at='N'`, 잔량 > 0.
- 잔량 = 발주수량 − 유효한 가입고 행 수량 합. 가입고 행이 빠지거나 가입고가 취소되면 잔량이 자동 복원된다.
  (수입검사가 생기면 불합격 수량을 잔량에 더한다. 가입고 수량 자체는 늘리지 않는다.)
- 가입고 수량은 발주 잔량을 초과할 수 있다. 초과 시 저장 전에 확인창(예/아니오)을 띄운다(2026-11-17 변경, 기존: 차단).
- 가입고단가는 **필수 입력**이며 0을 허용한다. 발주단가가 기본값이며 수정할 수 있다.
- 부가세는 발주등록의 규칙을 따른다: 부가세구분(과세/영세/면세)·부가세여부(포함/미포함)를 가입고 헤더에서 정하고, 행의 공급가·세액·합계를 같은 계산식으로 저장·관리한다.
- 입고창고는 발주 행의 창고가 기본값이며 수정할 수 있다. LOCATION은 관리하지 않는다.
- 제조일, 소비기한(MES의 유효기한)을 행에 입력한다. LOT번호는 컬럼만 확보하고 비워둔다(재고 로직 완성 후 연결).
- 검사대상 여부는 발주 행의 `inspect_at`을 가입고 행에 복사해 저장한다(이후 분기 기준).
- 제외: 실가입고량, LOCATION, SCM 확정, 수주 연계 정보, 첨부.

### 수정·삭제 잠금 (적용 단계 구분)
- 이번 작업: 가입고 취소와 행 빼기는 가입고현황(`20261116_013`)에서 처리한다. 잠금 조건(입고 생성, 수입검사 진행)을 검사할 대상 테이블이 아직 없어 이번에는 검증하지 않는다.
- 후속 규칙(사양서에 기록, 해당 작업에서 구현):
  - 검사 대상: 수입검사를 진행하기 전까지만 가입고 수정·삭제 가능. 입고를 삭제하면 입고만 삭제되고 수입검사 결과로 재등록한다.
  - 무검사: 입고가 자동 등록되면 가입고는 수정·삭제 불가, 수정·삭제는 입고에서만 처리하고 입고 수정 시 가입고 수량도 함께 반영, 입고 삭제 시 가입고도 함께 삭제한다.

### 발주 연동 (이번 작업에 포함)
발주현황 사양(`20261113_002` 2.5)에서 "가입고 작업에서 추가한다"고 남긴 검증을 이번에 추가한다.
- 발주 행 삭제·발주 취소: 유효한 가입고 행이 있으면 409.
- 발주 행 수량을 가입고 합계보다 작게 수정: 409. 가입고가 있는 행의 검사대상(`inspect_at`) 변경: 409.

## 범위

- 프론트: 가입고등록 화면, 발주 불러오기 창.
- 테스트, 결과 문서(스크린샷 포함).

### 제외(별도 작업)

## 완료 조건
- 같은 구매처의 발주 행을 불러와 가입고가 저장되고 `MP-YYYYMMDD-NNNN` 번호가 발급된다.
- 잔량을 초과한 수량은 확인창에서 '확인'을 눌러야 저장되고 '취소'면 저장되지 않는다. 단가 없는 행은 저장되지 않는다.
- 가입고 후 발주 후보 잔량이 줄고, 입고대기마감 행은 후보에서 빠진다.
- 가입고가 있는 발주 행은 발주현황에서 삭제·취소·수량 축소가 거부된다.
