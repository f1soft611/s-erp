# 모듈별 선택값 조사 및 공통코드 Seed 작업지시서

- 요청: 모듈별 페이지의 하드코딩된 select/type 데이터를 조사하고 공통코드에 추가할 항목과 Seed 스크립트를 작성한다.
- 기준: 기존 공통코드 관리 사양(20260911_003), 품목 공통코드 사양(20261023_004), 작업표준서 사양(20261111_003), 현재 페이지 및 서버 계약.
- 순서: 조사 → 계획서 → 상세사양서 → Seed/롤백 → 격리 PostgreSQL 검증 → 결과 문서.
- 범위: 실제 업무 선택값, 기존 공통코드 재사용, 고정 상태/검색 조건/동적 마스터/시제품 화면의 구분.
- 제외: 화면/API 변경, 운영 DB 실행, 테넌트 일괄 적용, 기존 코드값 변경, 임의 상태 추가, 커밋.
- 산출물: 날짜별 계획·사양, 모듈별 조사표, 기본/선택 Seed, 롤백, 재현 가능한 검증 SQL, 양쪽 DB 폴더의 동일한 변경 이력.
- 완료 기준: 원본 값·라벨·순서와 출처 명시, 대상 테넌트 필수 지정, 기존 데이터 보존, 재실행 중복 방지, 다른 테넌트 불변, 롤백 검증.
- UI 변경이 없으므로 브라우저 스크린샷 대신 SQL 실행 결과를 기록한다.
