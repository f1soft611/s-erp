# 20261116_013 가입고현황 화면 작업지시서

## 작업 목적

등록한 가입고(MP)를 조회하고, 상세를 보고, 값을 수정하거나 행을 빼거나 가입고 전체를 취소하는 가입고현황 화면을 만든다.
구조는 발주현황(`20261113_002`)과 같다: 현황 목록 → 번호 링크 → 상세 패널 → 조회/수정 다이얼로그(가입고등록 화면 `embedded`).

## 확정 범위

### 화면 흐름
- 메뉴 `입고관리 > 가입고현황`(가입고등록 바로 다음). 권한은 READ, EXCEL.
- 검색(빠른 검색 + 상세검색) → 품목 행 단위 F1Grid(같은 가입고는 헤더 셀 병합) → 가입고번호 클릭 시 상세 패널 → 조회/수정 다이얼로그.
- 수정 가능 조건: 가입고 상태가 정상이고 가입고등록 메뉴의 UPDATE 권한이 있을 때.

### 수정과 행 삭제
- 수정 가능: 가입고일, 부가세구분·부가세여부, 비고, 행의 수량·단가·세액·입고창고·제조일·소비기한·비고.
- 구매처, 발주 행 연결, 품목은 바꾸지 않는다. 새 행 추가는 없다(필요하면 새 가입고 등록).
- 행 삭제: 수정 다이얼로그에서 체크 후 [선택 행 빼기] 후 저장. 모든 행을 뺄 수는 없고, 모두 빼려면 가입고 취소를 쓴다. 행이 빠지면 발주 잔량이 자동 복원된다.
- 수정 후 수량은 발주 잔량(이 행 제외)을 초과할 수 없다.

### 가입고 취소
- 가입고 전체를 취소한다(`use_at='N'`, 이력 보존). 취소된 가입고는 조회만 된다.
- 취소하면 발주 잔량이 복원되어 다시 불러올 수 있다.

### 후속 연동 (이번에는 검증하지 않음)
- 무검사 가입고는 입고가 생기면 수정·취소 불가(입고에서만 처리), 검사 대상은 수입검사 진행 후 수정·취소 불가. 대상 테이블이 생기는 입고·수입검사 작업에서 검증을 추가한다.

## 제외 범위
- 입고 연동·잠금, 수입검사 연동, 출력, 재고·LOT 값 연결, 일괄 적용.

## 구현 절차
1. 계획서, 상세사양서
2. 메뉴 SQL(가입고현황) 두 경로 사본
3. 백엔드 실패 테스트 → 구현(목록, 수정, 취소)
4. 프론트 실패 테스트 → 구현(현황 화면, 등록 화면 view/edit 모드)
5. 검증: 집중 테스트, 빌드, JDK 8 컴파일, 브라우저
6. 사용자 SQL 실행 후 MCP 확인, 결과 문서 `docs/result/20261116/material-arrival-status`

## 완료 조건
- 검색 조건으로 가입고 목록이 조회되고 번호를 눌러 상세를 볼 수 있다.
- 수정 다이얼로그에서 값 수정과 행 삭제가 저장되고 목록과 헤더 금액이 갱신된다.
- 가입고 취소 후 발주 잔량이 복원된다.
- 취소된 가입고는 수정·취소할 수 없다.
