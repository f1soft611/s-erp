# 출하현황 상세 작성자 프로필 적용 작업지시서

## 목적 및 범위

- 출하현황에서 출하번호를 클릭해 여는 상세 패널에 작성자 이름, 사용자 프로필 이미지, 등록일을 표시한다.
- 상세 API 응답의 기존 작성자 ID를 유지하고, 테넌트 범위의 사용자·로그인 계정 정보로 이름과 프로필 이미지를 보강한다.
- 프로필 데이터가 없을 때는 기존 작성자 ID 및 아바타 대체 표시를 유지한다.
- 출하 등록·수정, 권한, 검색, 목록 및 DB 스키마는 변경하지 않는다.

## 구현 및 검증

1. 이 작업지시서에 따라 날짜별 계획서와 상세사양서를 작성한다.
2. 상세 API 매퍼와 화면에 대해 작성자 프로필 데이터가 제공·표시되는지 회귀 테스트를 먼저 추가하고 실패를 확인한다.
3. 거래명세서 상세의 작성자 이름·프로필 조회 패턴을 따라 출하 상세 응답과 패널을 보완한다.
4. 관련 백엔드·프론트엔드 테스트와 빌드를 수행한다.
5. 출하현황 상세를 375px, 768px, 1280px 브라우저에서 확인하고 결과 문서와 스크린샷을 기록한다.
