# npm 취약점 호환 범위 개선 작업지시서

## 목적과 범위

- 프론트엔드 `npm audit`에서 확인된 취약점 중 기존 주요 버전과 호환되는 수정본을 우선 적용한다.
- Vite와 Vitest는 기존 주요 버전을 유지하고, 호환되는 전이 의존성을 갱신한다.
- ExcelJS 강제 다운그레이드나 대체는 범위에서 제외하고 잔여 취약점을 명시한다.
- 실행 중인 공유 개발 서버를 방해하지 않도록 기존 `node_modules`를 변경하지 않는다.

## 완료 기준

- 변경 전후 취약점 수와 잔여 항목을 기록한다.
- 별도 격리 디렉터리에서 잠금 파일 기반 설치 후 빌드, lint와 관련 테스트를 확인한다.
- 실제 브라우저 화면 및 운영 코드를 변경하지 않고 계획·사양·결과를 기록한다.
