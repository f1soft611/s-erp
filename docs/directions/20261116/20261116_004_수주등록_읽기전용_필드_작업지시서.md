# 수주등록 읽기전용 필드 표시 작업지시서

## 목적 및 범위

- 수주등록 기본정보 폼에서 실제로 값을 변경할 수 없는 필드의 배경을 테마의 비활성 배경색으로 구분한다.
- 수주번호와 수주상태는 항상 읽기전용으로 표시한다.
- 수주일자, 거래처, 견적번호, 납기일자, 납품장소, 배송방법, 비고는 기존 권한·상태에 따라 편집이 불가능할 때에만 읽기전용 배경을 표시한다.
- 거래처 입력칸은 직접 입력이 불가능하더라도 선택 버튼을 사용할 수 있으면 편집 가능 항목으로 취급한다.
- 수주등록 컴포넌트를 공유하는 수주현황의 보기·수정 폼에도 동일한 표시를 적용한다. 다른 페이지나 공통 테마의 전역 동작은 변경하지 않는다.
- 그리드, 저장·검증·권한 및 데이터 계약은 변경하지 않는다.

## 구현 및 검증

1. 이 작업지시서에 따라 날짜별 계획서와 상세사양서를 작성한다.
2. 편집 가능 상태와 읽기전용 상태, 거래처 선택 가능 여부를 구분하는 집중 회귀 테스트를 추가한다.
3. 기존 폼 동작을 유지하면서 수주등록 화면에 국한해 배경색을 적용한다.
4. 관련 테스트와 빌드를 수행하고 375px, 768px, 1280px 브라우저 화면 및 수주현황의 공유 폼을 확인한다.
5. 결과 문서와 스크린샷을 날짜별 결과 폴더에 기록한다.
