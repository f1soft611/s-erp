# 전체 읽기전용 폼 필드 표시 작업지시서

## 목적

수주등록에 적용한 읽기전용 배경을 전체 화면의 폼 필드와 F1-Grid 행 폼 모달에도 동일하게 적용한다.

## 범위

- MUI 텍스트·숫자·날짜·선택·자동완성 등 공통 입력의 읽기전용 또는 비활성 상태에 현재 테마의 `action.disabledBackground`를 적용한다.
- 텍스트 직접 입력은 막혀도 활성 선택 버튼으로 값을 변경할 수 있는 필드는 편집 가능 배경을 유지한다. 선택이 비활성화되면 읽기전용 배경을 표시한다.
- F1-Grid 행 폼의 `form.readOnly`, `editable`, `form.disabled` 판정을 그대로 사용하며 폼의 편집 동작을 변경하지 않는다.
- 그리드 셀 자체, API, 데이터 및 권한 계약은 변경하지 않는다.
- 밝은 테마와 다크 테마를 모두 지원한다.

## 절차 및 완료 조건

계획서와 상세사양서를 순서대로 작성한 후 실패 테스트, 최소 구현, 집중 테스트·빌드·린트와 375px·768px·1280px 브라우저 확인을 수행한다. 결과 문서와 개인정보 없는 스크린샷을 저장하고 F1-Grid 문서도 갱신한다.
