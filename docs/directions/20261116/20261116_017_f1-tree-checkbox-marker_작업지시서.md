# F1-Tree 체크박스와 최하위 마커 겹침 수정

- 사용자 요청: F1-Tree 최하위 하위메뉴 마커가 체크박스가 있을 때 겹치는 현상을 수정한다.
- 기존 기능 사양: [F1-Tree 최하위 마커](../../spec/20261116/20261116_010_f1-tree-leaf-marker_상세사양서.md).
- F1-Tree에서만 수정한다. 트리 데이터, 체크 선택, 펼침·접기, 라벨 위치와 사이드 트리는 변경하지 않는다.
- 마커는 루트가 아닌 실제 최하위 행에만 표시하고, 체크박스가 있을 때 겹치지 않도록 빈 펼침 버튼 슬롯 안에 둔다.
- 회귀 테스트와 F1-Grid 문서·작업 결과를 갱신한다.
