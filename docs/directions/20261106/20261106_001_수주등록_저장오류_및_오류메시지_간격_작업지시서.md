# 수주등록 저장 오류 및 오류 메시지 간격 작업지시서

## 1. 배경

수주등록 저장이 실패한다는 보고가 있으며, 화면 상단 오류 메시지 영역의 위·아래 여백도 같지 않다는 피드백이 있다. 제공된 stack trace는 AUTO 납품계획 생성 후 조회가 `null`이 되어 예외를 던지는 정확한 지점을 나타낸다.

## 2. 요청 사항

1. 수주 저장 실패 경로를 확인하고, 확인된 원인만 수정한다. 원인 증거가 부족하면 정상 저장처럼 처리하거나 오류를 숨기지 않는다.
2. 수주등록 화면 상단 오류 메시지 영역의 위·아래 실제 공백을 같게 한다.

## 3. 제약

- 기존 수주 저장과 AUTO 납품계획 생성을 묶는 트랜잭션 및 데이터 무결성을 유지한다.
- DB 스키마 변경은 범위에 포함하지 않는다.
- 오류 메시지 간격 변경은 수주등록 화면에 국한한다.
- 자동 납품계획 저장 성공 여부를 확인하기 위한 불필요한 생성 직후 재조회에 의존하지 않는다. 사용자 직접 계획 생성 경로의 응답 계약 및 조회 검증은 유지한다.
- 실제 predicate/join 불일치는 tenant DB 메타데이터가 없어 미확인으로 기록한다.

## 4. 완료 조건

- 저장 경로를 확인하고, 자동 계획의 불필요한 재조회 의존을 제거하며 회귀 테스트를 통과시킨다.
- actual DB predicate/join 불일치 여부는 확인 가능한 메타데이터 한계를 결과 문서에 기록한다.
- 수주등록 오류 메시지 위·아래 공백을 일치시키고 테스트 및 브라우저 확인을 기록한다.
