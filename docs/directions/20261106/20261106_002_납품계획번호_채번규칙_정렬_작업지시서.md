# 납품계획번호 채번 규칙 정렬 작업지시서

## 사용자 요구

- 납품계획번호도 수주번호·납품번호와 같은 날짜 및 순번 형식으로 생성한다.
- 문서 종류를 구분하는 접두사와 기존 납품계획 기능은 유지한다.

## 확정 범위

- 형식은 `DP-YYYYMMDD-0001`로 한다. `SO`(수주), `SD`(납품)와 같이 업무 문서별 접두사는 유지하고 날짜 8자리와 최소 네 자리 순번 규칙을 맞춘다.
- 채번 키는 `SALES_DELIVERY_PLAN_NO`, 범위 키는 tenant ID와 생성일을 유지한다.
- 다른 번호 체계, 계획 날짜, 데이터베이스 스키마는 변경하지 않는다.

## 작업 및 완료 기준

1. 수주·납품 채번과 같은 `Locale.ROOT` 포맷 및 최대 30자 검증을 적용한다.
2. 정상 형식과 길이 초과에 대한 서비스 테스트를 추가한다.
3. 납품계획 서비스 테스트 및 백엔드 검증을 실행하고 결과를 기록한다.
