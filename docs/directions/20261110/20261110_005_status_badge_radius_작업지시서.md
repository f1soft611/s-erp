# 상태 배지 색상 및 프로젝트 모서리 통일 작업지시서

## 작업 목적

첨부 예시를 기준으로 문서 결재 상태, 업무 구분, 공지 구분 배지의 색상 톤과 모서리를 통일하고, 프런트엔드 전체의 직각형 UI 모서리 반경을 공통 기준으로 정리한다.

## 요구사항

- 승인·발송완료는 초록, 반려는 빨강, 임시저장은 차분한 중립색, 결재 진행은 파랑, 보완요청은 주황 계열로 표시한다.
- 문서 업무 구분은 기안 파랑, 업무 초록, 지출 주황, 근태 보라의 의미 색상을 유지한다. 공지 구분은 코드별 기존 색상 구분과 라이트/다크 대비를 유지한다.
- 문서 업무 구분과 공지 구분 배지는 첨부 예시처럼 outlined 스타일로 표시한다.
- 문서 작성, 문서 현황/피드/상세, 결재 알림, 공지 피드/상세에서 동일한 상태·구분 메타데이터를 사용한다.
- 검색 결과 안내와 페이지 오류 메시지는 모든 화면에서 위·아래 여백을 동일하게 유지하고, 메시지 배경은 페이지 배경과 구별되는 정보 색상을 사용한다.
- 배지와 프로젝트 UI의 직각형 모서리는 6px로 통일한다. 원형 아바타/아이콘, 명시적으로 각진 경계(0px)는 형태를 보존한다.
- 상태 코드, 라벨, 업무 흐름, API 및 DB 계약은 변경하지 않는다.

## 작업 순서

1. 이 작업지시서를 바탕으로 계획서와 상세 사양서를 작성한다.
2. 상태 프레젠테이션과 테마의 회귀 테스트를 먼저 추가하고 실패를 확인한다.
3. 문서 상태 및 업무 구분 색상 메타데이터를 정리하고 문서·공지 배지에 공통 6px 반경을 적용한다.
4. 프런트엔드 전체의 직각형 모서리 반경을 공통 6px로 정규화한다. 원형 요소와 0px 경계는 유지한다.
5. 관련 Vitest, 빌드, 375px/768px/1280px 브라우저 확인을 수행한다.
6. 결과 보고서와 합성 데이터 스크린샷을 `docs/result/20261110/status-badge-radius/`에 보관한다.

## 완료 기준

- 문서 상태 및 문서/공지 구분 배지가 화면 위치와 관계없이 같은 의미 색상과 6px 반경을 사용한다.
- 직각형 UI 모서리가 프런트엔드 전반에서 6px로 정규화되고 원형/각진 경계는 보존된다.
- 기존 라벨, 다크/라이트 테마 대비, API/DB 계약 및 화면 동작에 회귀가 없다.
- 집중 테스트, 빌드, 반응형 브라우저 검증 및 결과 문서가 완료된다.
