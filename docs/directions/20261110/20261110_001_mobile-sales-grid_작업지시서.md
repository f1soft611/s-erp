# 모바일 영업 등록 및 모듈 바 작업지시서

## 요청

- 수주등록, 출하계획등록, 출하등록을 모바일에서 사용할 수 있게 한다.
- 수주 하단 금액 합계와 F1-Grid 내부 가로 스크롤이 잘리지 않게 한다.
- 작은 화면의 F1-Grid 행 추가는 별도 옵션 없이 기존 행 폼으로 동작한다.
- 모바일 모듈 바는 좌측 대신 상단의 간결한 가로형 목록으로 배치한다.
- 모바일 페이지 경로 옆에 충분한 공간이 있을 때 조회 등 액션 버튼이 불필요하게 다음 줄로 내려가지 않게 한다.
- 출하계획 상세와 거래명세서 상세 패널의 그리드 아래 여백을 좌우와 같은 8px로 맞춘다.

## 범위와 완료 기준

- 기준 화면은 기존 수주등록·출하등록·출하계획 공통 폼이다. 기본정보, 도구 버튼, 상세 그리드와 합계의 기존 순서를 유지한다.
- 데스크톱의 좌측 모듈 바와 기본 인라인 편집을 유지한다.
- 기존 API, 권한, 수량·금액 계산, AUTO/MANUAL 출하계획 정책을 변경하지 않는다. 백엔드·DB 변경은 없다.
- 문서 → 실패 회귀 테스트 → 최소 구현 → 검증 → 결과·스크린샷 순으로 진행한다.
- 375px, 768px, 1280px 브라우저에서 전체 가로 넘침, 그리드 내부 스크롤, 하단 합계, 행 폼 적용·취소, 모듈·메뉴 전환을 확인한다.
- 사용자의 명시적 요청 없이 커밋하지 않는다.
