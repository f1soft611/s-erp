# iPlusMES 모바일 PWA 설치 지원

## 목적

모바일 브라우저에서 iPlusMES를 홈 화면에 설치해 독립 실행할 수 있도록 PWA 설치 메타데이터와 사용자 안내를 추가한다.

## 범위

- `frontend`에 web app manifest, 앱 아이콘, 모바일 웹 앱 메타데이터를 추가한다.
- 설치되지 않은 사용자가 지원 브라우저를 이용할 때 앱 내부에 닫을 수 있는 설치 안내를 표시한다.
- 지원 브라우저는 사용자 클릭으로 native 설치 프롬프트를 연다. iOS에서는 홈 화면 추가 안내를 표시한다.
- 설치 완료와 standalone 실행에서는 안내를 표시하지 않는다. 미설치 사용자가 안내를 닫으면 7일 후 다시 표시한다.
- 설치 안내는 로그인 화면이나 메인 이외 경로에서는 표시하지 않는다. 로그인 후 메인 경로(`/groupware/overview`)에서만 설치 상태를 확인해 표시한다.
- OS 푸시로 설치를 권유하지 않으며, 기존 Web Push 서비스 워커와 알림 권한 흐름을 변경하지 않는다.
- 오프라인 캐시, backend, API, DB 변경은 제외한다.

## 필수 순서

1. 이 작업지시서에 따라 계획서와 상세 사양서를 작성한다.
2. manifest, 앱 진입 HTML, 앱 공통 레이어 및 Web Push Service Worker 경계를 확인한다.
3. 설치 이벤트/설치 상태/안내 닫기 및 7일 후 재노출 동작의 실패 테스트를 먼저 작성한다.
4. 최소 frontend 변경으로 설치 메타데이터와 안내를 구현한다.
5. frontend 테스트, build, lint와 실제 브라우저 375px/768px/1280px 검증을 수행한다.
6. 결과 문서와 영문 파일명 스크린샷을 `docs/result/20261110/pwa-mobile-install/`에 보관한다.

## 완료 조건

- 지원 브라우저에서 manifest와 앱 아이콘을 통해 설치가 가능하고, 설치 동작은 사용자 클릭에 의해서만 시작된다.
- 미설치 브라우저의 안내는 앱 내부 UI이며 OS 알림 권한을 요청하지 않는다.
- iOS 안내는 Add to Home Screen 절차를 설명하며, 설치된 standalone 실행에서는 보이지 않는다.
- 미설치 사용자가 안내를 닫거나 브라우저 설치 프롬프트를 거절하면 7일 동안 숨기고, 7일 경과 후 다시 안내한다.
- 로그인 화면과 메인 이외 경로에서 숨기며, 인증된 메인 경로(`/groupware/overview`)에서만 표시한다. 로그인 전에 발생한 브라우저 설치 이벤트는 보존해 로그인 후 표시할 수 있어야 한다.
- 기존 `/sw.js`의 Web Push 동작, 로그인 및 API 계약에 변화가 없다.
- 검증 및 결과 문서에 모바일/태블릿/데스크톱 화면 확인과 지원 제한을 기록한다.
