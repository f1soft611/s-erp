# 영업 페이지 여백 및 출하계획현황 그리드 테두리 정합 작업지시서

## 요청

- 영업관리 등록 화면의 콘텐츠 바깥 여백을 현황 화면의 기존 여백과 동일하게 맞춘다.
- 출하계획현황 그리드의 테두리를 다른 F1Grid와 같은 단일 테두리로 정리한다.
- 현황 검색결과/오류 메시지의 가로 폭을 그리드 콘텐츠 경계와 맞춘다.

## 범위와 기준

- 수주, 출하, 출하계획, 거래명세서의 등록/현황 쌍을 비교한다.
- 현황 본문 기준은 좌우 `xs 8px / sm 16px`, 위 8px, 아래 16px이다.
- 수주, 출하, 출하계획, 거래명세서의 등록 콘텐츠 바깥 여백을 이 현황 기준으로 정렬한다.
- 기존 등록 화면의 embedded 레이아웃과 수주 저장 오류 간격 예외는 보존한다.
- 공통 메시지의 기본 가로 여백은 유지하고, 영업 현황 메시지에만 그리드 정렬 옵션을 적용한다.
- 검색 영역, 상세/편집 패널, 메시지 간격, API, 데이터 및 그리드 동작은 변경하지 않는다.
- 출하계획현황의 외부 Paper 테두리만 제거하고 F1Grid 기본 테두리를 유지한다.

## 완료 조건

1. 네 등록 화면의 본문이 대응하는 현황 화면과 같은 반응형 바깥 여백을 사용한다.
2. 출하계획현황 그리드는 F1Grid 기본 테두리 하나만 표시한다.
3. 메시지 상자의 좌우 경계가 같은 화면 그리드 경계와 일치한다.
4. 회귀 테스트, 빌드, 변경 파일 lint가 통과한다.
5. 375px, 768px, 1280px 브라우저 비교와 결과 스크린샷을 기록한다.
6. 작업 결과를 날짜별 결과 문서에 남긴다. 사용자가 요청하지 않은 커밋은 만들지 않는다.
