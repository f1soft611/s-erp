# 화면 크기 기본값을 작게로 변경

## 목적

화면 크기 설정을 아직 저장하지 않은 사용자의 기본 화면 크기를 현재 `보통`에서 `작게`로 변경한다.

## 범위

- 화면 크기 설정의 기본 배율을 기존 `1`에서 `0.9`로 변경한다.
- localStorage에 저장된 화면 크기는 기존처럼 복원하고 유지한다.
- 화면 크기 메뉴와 다른 설정 동작은 변경하지 않는다.

## 완료 조건

- 저장된 화면 크기가 없는 경우 앱의 초기 화면 크기가 `작게(0.9)`로 표시·적용된다.
- 저장된 화면 크기가 있으면 저장값이 계속 우선 적용된다.
- 화면 크기 설정 회귀 테스트와 프론트엔드 빌드가 통과한다.
- 결과 문서를 `docs/result/20261110/screen-scale-small-default/`에 작성한다.
