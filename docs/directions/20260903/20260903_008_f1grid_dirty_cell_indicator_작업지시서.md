# 작업지시서

## 제목

F1-Grid 셀 dirty 표시 기능 구현

## 배경

F1-Grid는 셀 수정 여부를 추적하는 dirty 상태를 이미 내부적으로 관리하고 있으나, 사용자에게 수정된 셀임을 명확히 보여주는 표시가 일관되지 않거나 누락된 상태이다. 특히 편집 후 다른 셀과 구분되어야 하는 상황에서 수정된 값에 대한 시각적 인지가 약하다.

첨부 이미지는 수정된 셀에 대해 상단 좌측에 작은 빨간 표시를 부여하는 표현을 기대하는 예시이다. 이 표시는 선택/편집 상태와 혼동되지 않도록 단순하고 명확하게 표시해야 한다.

## 요구사항

- F1-Grid 셀의 dirty 상태를 사용자에게 시각적으로 표시한다.
- 수정된 셀은 다른 일반 셀과 구분되도록 작은 표시(예: 빨간 점/모서리 마크)를 노출한다.
- 표시가 편집 중인 셀, 선택된 셀, 범위 선택 표시와 충돌하지 않아야 한다.
- 기존 셀 선택/편집/drag 동작은 유지한다.
- 관련 테스트를 추가하거나 기존 테스트를 보완하여 dirty 표시 회귀를 검증한다.

- 프론트엔드: `frontend/src/shared/components/f1-grid/core/GridCell.tsx`
- 프론트엔드: `frontend/src/shared/components/f1-grid/core/GridRow.tsx`

## 제외 범위

- F1-Grid의 전반적인 레이아웃/테마 대대적 리팩터링
- 메뉴 관리 기능 로직 전체 개편
- 비관련 화면의 UI 변경

## 완료 기준

- dirty 상태가 있는 셀에 시각적 표시가 정상적으로 보인다.
- 수정 직후와 재렌더링 이후에도 표시가 유지된다.
- 기존 F1-Grid 선택/편집 동작과 테스트가 무너지지 않는다.
- 관련 테스트 실행 결과가 정상이어야 한다.
