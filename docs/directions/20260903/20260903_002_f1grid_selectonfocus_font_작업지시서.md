# 작업지시서

## 제목

F1-Grid 셀 에디터 기본 선택/폰트 상속 개선

## 배경

F1-Grid 편집 상태에서 셀 입력값이 포커스 시 자동으로 선택되지 않고, 날짜/시간 에디터가 그리드 기본 폰트 크기를 상속하지 않아 텍스트가 커 보이는 문제가 발생한다.

## 요구사항

- 셀 컬럼 타입의 기본 동작으로 `selectOnFocus`를 활성화한다.
- 선택 상태는 에디터 진입 직후 값 전체가 드래그된 상태로 보이도록 한다.
- date, time, datetime 타입 에디터는 셀의 폰트 크기를 상속해 표시한다.
- 기존 그리드 동작과 축약된 셀 레이아웃은 유지한다.

## 변경 범위

- 프론트엔드: `frontend/src/shared/components/f1-grid/**`
- 테스트: `frontend/tests/f1-grid.test.tsx`

## 완료 기준

- F1-Grid 에디터가 포커스 시 기존 값 전체가 선택된다.
- 날짜/시간 에디터가 그리드 폰트 크기를 상속한다.
- 관련 테스트가 통과한다.
