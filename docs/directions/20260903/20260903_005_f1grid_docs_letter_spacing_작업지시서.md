# F1-Grid 문서 포털 글자 간격 통일 작업지시서

## 배경

현재 F1-Grid 문서 포털의 대문자 라벨/네비게이션 문구와 메인 제목 사이에 letter spacing 값이 일관되지 않다. 일부 요소는 `0.12em`을 사용하고, 메인 섹션 제목은 기본 간격을 유지해 시각적 균형이 깨진다.

## 목표

- `frontend/src/pages/f1-grid-docs/F1GridDocsPage.css`에서 문서 페이지 전반의 자간(letter spacing)을 일관되게 정리한다.
- 섹션 제목, 문서 네비게이션 라벨, 페이지 헤더와 본문 텍스트가 같은 기준으로 보이도록 유지한다.
- 다른 F1-Grid 문서 화면 동작 및 기존 테스트에 영향을 주지 않는다.

## 확정 요구사항

- F1-Grid 문서 페이지의 주요 제목과 라벨 간격을 하나의 기준값으로 통일한다.
- 기존 문서 포털의 레이아웃, 사이드바, 버튼 동작, 뷰포트 반응형 동작은 유지한다.
- 변경 범위는 해당 페이지의 CSS 및 필요 시 관련 테스트로 제한한다.
- F1-Grid 문서 포털의 시각적 일관성을 확인하는 회귀 테스트를 추가한다.

## 제외 범위

- 백엔드 API 및 데이터베이스 변경
- 다른 화면의 전역 테마 변경
- 문서 포털 구조 개편이나 라우팅 변경
- 불필요한 리팩터링 및 타 페이지 스타일 손질

## 완료 기준

- F1-Grid 문서 포털에서 제목/라벨/네비게이션의 자간이 일관되게 표시된다.
- 관련 테스트가 통과한다.
- 변경 사항이 디자인 요구사항과 일치한다.
