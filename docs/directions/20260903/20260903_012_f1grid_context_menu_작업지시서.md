# 작업지시서

## 제목

F1-Grid 우클릭 컨텍스트 메뉴 플러그인 신규 구현 및 F1-Grid Docs 페이지 반영

## 배경

`docs/guide/F1-GRID.md`의 "25. Grid Context Menu"는 아직 미구현 상태로 남아 있다. 이번 작업은 F1-Grid에 추가된 플러그인 형태의 우클릭 메뉴 기능을 구현하고, `f1-grid-docs` 페이지에서 실제 동작과 문서 설명이 함께 반영되도록 정리한다. 현재 메뉴관리 화면(`MenuManagementPanel.tsx`)은 그리드 바깥의 툴바 버튼으로 `루트 메뉴 추가`, `하위 메뉴 추가`를 제공하고 있는데, 이 버튼들을 그리드 내부의 우클릭 컨텍스트 메뉴로 대체하여 F1-Grid/F1-Tree 공통 UX를 정립하고자 한다.

## 요구사항

### 1. 컨텍스트 메뉴 플러그인 (F1-Grid 코어 공통)

- F1-Grid 바디(헤더 제외, 행/셀 영역) 우클릭 시 커서 위치에 컨텍스트 메뉴를 표시한다. 헤더 영역 우클릭은 기존 헤더 메뉴(정렬/필터/고정/숨김) 동작을 그대로 유지하고 이번 신규 메뉴 대상에서 제외한다.
- 기본 메뉴 항목과 구분선 구성(위에서 아래 순서):
  1. 엑셀 내보내기
  2. 컬럼 길이 자동 조정
  3. ────────────
  4. (F1Tree인 경우만) 루트 추가
  5. 행 추가
  6. 행 복사
  7. 행 삭제
  8. ────────────
  9. 필터 해제
  10. 정렬 해제
  11. ────────────
  12. 설정을 기본값으로 복원
- `그룹 해제`는 F1-Grid에 Grouping 기능이 없으므로 이번 범위에서 제외한다.

### 2. 각 메뉴 동작 정의

- **엑셀 내보내기**: 실제 `.xlsx` 파일로 내보낸다. 라이브러리 신규 도입(예: `xlsx`)이 필요하며, 화면에 표시 중인 컬럼/행(필터·정렬 반영된 활성 행) 기준으로 내보낸다. 부모 화면이 `canExportExcel`(가칭) boolean prop을 F1Grid/F1Tree에 전달하지 않거나 `false`로 전달하면 메뉴 항목 자체를 표시하지 않는다(숨김 처리, disabled 아님).
- **컬럼 길이 자동 조정**: 기존 `getAutoFitColumnWidth` 유틸을 활용해 전체 컬럼 폭을 데이터 기준 자동 조정한다.
- **루트 추가** (F1Tree 전용): 우클릭 위치와 무관하게 최상위 루트 행을 추가한다. 기존 `addRow()` 동작과 동일하다.
- **행 추가**: 우클릭한 행이 있으면 해당 행의 하위(자식)로 신규 행을 추가한다(F1Tree 기준, 기존 `addChildRow` 동작). 우클릭한 행이 없으면(빈 영역 우클릭) 최상위에 행을 추가한다. 일반 F1Grid(트리 아님)는 항상 신규 행을 추가한다(`addRow()`와 동일).
- **행 복사**: 우클릭한 행(또는 현재 선택된 행)을 복제한다. 기존 `duplicateSelectedRows()` 동작을 재사용한다.
- **행 삭제**: 우클릭한 행(또는 현재 선택된 행)을 삭제 처리한다. 기존 `deleteSelectedRows()` 동작을 재사용하며, 트리에서 하위 행이 있는 노드 삭제 차단 규칙(`onDeleteBlocked`)을 그대로 따른다.
- **필터 해제**: 현재 적용된 모든 컬럼 필터를 초기화한다.
- **정렬 해제**: 현재 적용된 정렬 상태를 초기화한다.
- **설정을 기본값으로 복원**: 사용자가 로컬 스토리지(`storageKey`)에 저장한 컬럼 순서/폭/숨김/고정 상태를 초기화하고 컬럼 정의 기본값으로 되돌린다.

### 3. 메뉴관리 화면(F1Tree) 정리

- `MenuManagementPanel.tsx`의 `루트 메뉴 추가`, `하위 메뉴 추가` 버튼(툴바)을 제거한다.
- 해당 기능은 신규 컨텍스트 메뉴의 `루트 추가`, `행 추가`로 대체된다.
- 기존 `펼치기`/`접기` 아이콘 버튼 등 컨텍스트 메뉴와 무관한 그리드 제어 툴바는 유지한다.

### 4. 문서/테스트

- `docs/guide/F1-GRID.md`의 "25. Grid Context Menu" 섹션을 실제 구현 내용에 맞춰 갱신하고 미구현 표시를 제거한다.
- `f1-grid-docs` 페이지에 새 플러그인 우클릭 메뉴 기능의 사용법, 예시, 검증 결과를 반영하고, 구현된 사용 흐름과 문서 설명을 일치시킨다.
- F1-Grid 관련 기능 변경이므로 `docs/result/20260903/<work-slug>/`에 결과 문서와 스크린샷을 남긴다.
- 컨텍스트 메뉴 표시/항목 활성화 조건/각 액션 동작에 대한 회귀 테스트를 프론트엔드 테스트(`frontend/tests/`)에 추가한다.
- 메뉴관리 화면 버튼 제거로 인해 깨지는 기존 테스트(`frontend/tests/menu-management-f1-grid.test.tsx` 등)를 신규 컨텍스트 메뉴 흐름 기준으로 갱신한다.

## 변경 범위

- 프론트엔드: `frontend/src/shared/components/f1-grid/**` (컨텍스트 메뉴 신규 컴포넌트/유틸, `F1Grid.tsx`, `F1Tree.tsx`, `grid.types.ts`, `index.ts` 등)
- 프론트엔드: `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx`
- 프론트엔드: `frontend/package.json` (엑셀 내보내기 라이브러리 의존성 추가)
- 테스트: `frontend/tests/**` (신규 컨텍스트 메뉴 테스트, 기존 메뉴관리 테스트 갱신)
- 문서: `docs/guide/F1-GRID.md`, `docs/result/20260903/<work-slug>/`

## 제외 범위

- Grid Toolbar(`F1GridToolbar`, 문서 24번 항목) 신규 구현
- Grouping(그룹 해제 등) 기능 구현
- 백엔드 API/DB 변경
- 메뉴관리 화면 외 다른 F1Grid/F1Tree 사용 화면의 기능 변경(컨텍스트 메뉴는 공통 플러그인으로 만들되, 다른 화면에 신규로 끼워 넣는 작업은 이번 범위에서 제외)

## 완료 기준

- F1-Grid 바디 영역 우클릭 시 지정된 순서/구분선의 컨텍스트 메뉴가 표시된다.
- F1Tree에서만 `루트 추가` 항목이 노출되고, 일반 F1Grid에는 노출되지 않는다.
- `canExportExcel`이 없거나 `false`인 화면에서는 `엑셀 내보내기` 메뉴가 보이지 않는다.
- 각 메뉴 항목 클릭 시 정의된 동작(엑셀 내보내기 `.xlsx`, 컬럼 자동 조정, 루트/행 추가, 행 복사/삭제, 필터/정렬 해제, 설정 기본값 복원)이 정상 수행된다.
- 메뉴관리 화면의 `루트 메뉴 추가`/`하위 메뉴 추가` 버튼이 제거되고, 동일 기능이 컨텍스트 메뉴로 대체되어 정상 동작한다.
- `docs/guide/F1-GRID.md` 문서가 갱신되고, `docs/result/20260903/<work-slug>/`에 결과 문서/스크린샷이 포함된다.
- 관련 프론트엔드 테스트가 통과한다(`npm run test`).
