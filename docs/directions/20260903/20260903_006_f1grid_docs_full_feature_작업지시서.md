# F1-Grid 문서 포털 전체 기능/옵션/플러그인 상세화 작업지시서

## 배경

현재 F1-Grid 문서 포털은 기본 문서 구조와 일부 예제만 보유하고 있다. 기능별 설명, 옵션, 플러그인, 샘플 데이터, 트리 구조 예제 등이 부족하여 개발자가 실제로 어떤 기능을 사용할 수 있는지 전체적으로 파악하기 어렵다.

## 목표

- F1-Grid 문서 포털에 기능 전체 목록, 옵션 정의, 플러그인, 동작 예시를 상세히 반영한다.
- 각 문서 페이지에서 실제로 사용할 수 있는 기본 옵션/상태/이벤트/플러그인 구성을 설명한다.
- Tree Grid는 실제 트리 구조 샘플 데이터로 렌더링되도록 문서 예제와 Playground를 함께 구성한다.
- `frontend/src/pages/f1-grid-docs/F1-GRID.md`와 포털 문서가 서로 상충하지 않도록 설명과 예시를 정리한다.

## 확정 요구사항

- F1-Grid 관련 문서 포털에 기능 리스트를 모두 포함한다.
- 각 기능마다 설명, 옵션, props, 플러그인, 사용 예시를 함께 제시한다.
- UI/UX 문서뿐 아니라 실행 가능한 Playground 예제를 포함한다.
- 선택/클립보드, 편집, 트리, 고정 컬럼, 필터/정렬, 행 높이, 병합, 플러그인 동작을 모두 문서에 반영한다.
- Tree Grid는 계층형 샘플 데이터를 사용해 실제 트리 구조가 보이도록 한다.
- 옵션과 기능 항목은 현재 구현 범위와 일치하도록 정리한다.
- 문서 예제는 실제 F1-Grid API와 동일한 데이터 구조를 사용한다.

- 각 예제와 Playground가 현재 F1-Grid 구현과 일치한다.
- F1-Grid 문서 관련 테스트와 빌드가 통과한다.
- 결과 문서와 스크린샷을 작성한다.
