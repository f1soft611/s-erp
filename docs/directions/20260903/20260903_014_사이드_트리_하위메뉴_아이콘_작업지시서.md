# 작업지시서

## 제목

사이드 트리 및 F1-Tree 하위메뉴 아이콘 표시 보강

## 배경

현재 사이드 트리와 F1-Tree는 계층 구조를 이해할 수 있는 펼침/접힘 상태만 제공하고 있으나, 하위 메뉴 경로를 시각적으로 구분하는 표시가 부족합니다. 사용자는 특히 하위메뉴가 여러 단계로 이어지는 경우, 각 메뉴가 어느 단계의 자식 노드인지 파악하기 어렵습니다.

요구사항은 하위메뉴에 대해 `ㄴ` 형태의 계층 표기처럼 보이는 추가 아이콘/마커를 표시해, 트리 구조를 직관적으로 확인할 수 있도록 하는 것입니다.

## 요구사항

- 사이드 트리의 하위메뉴 항목에 계층 구조를 표현하는 아이콘/마커를 추가한다.
- F1-Tree 역시 같은 방식으로 하위 메뉴 계층을 시각적으로 표시한다.
- 기존 펼침/접힘 아이콘과 동작은 유지한다.
- 하위 메뉴 표시가 반응형 레이아웃과 트리 구조에 어긋나지 않도록 정렬을 조정한다.
- 루트/부모/자식 노드의 구분이 한눈에 보이도록 시각 스타일을 유지한다.
- 관련 회귀 테스트 또는 UI 검증을 수행한다.

## 변경 범위

- 프론트엔드: `frontend/src/pages/dashboard/components/DashboardMenuTree.tsx`
- 프론트엔드: `frontend/src/shared/components/f1-grid/tree/F1Tree.tsx`
- 필요 시: 하위 메뉴 표시용 스타일/레이아웃 관련 보조 코드
- 테스트: `frontend/tests` 또는 관련 UI 검증 스크립트

## 제외 범위

- 다른 화면의 레이아웃 전면 리팩터링
- F1-Grid 기능 전반 재설계
- 백엔드 API 구조 변경
- 트리 데이터 로직의 비즈니스 로직 변경
- 접근 권한/메뉴 생성 로직 변경

## 완료 기준

- 사이드 트리에서 자식 노드가 `ㄴ` 계열의 하위메뉴 마커로 구분된다.
- F1-Tree에서도 동일하게 하위메뉴 아이콘/마커가 표시된다.
- 기존 확장/축소 동작과 선택 상태는 정상 유지된다.
- 레이아웃이 정렬되고, 지나치게 넓어지거나 겹치지 않는다.
- 관련 테스트 또는 검증 로그가 정상적으로 확인된다.
