# 작업지시서

## 제목

메뉴 관리 제목줄 우측에 전체 펼치기/접기 아이콘 배치

## 배경

현재 `MenuManagementPanel.tsx`의 전체 펼치기/접기 버튼은 메뉴 관리 카드 하단의 툴바 영역에 배치되어 있어, 메뉴 관리 제목 행과 시각적으로 분리되어 있다. 요구사항은 이 아이콘들을 `메뉴 관리` title 라인 우측에 배치해, 제목과 제어 액션이 같은 행에 묶여 보이도록 정리하는 것이다.

## 요구사항

- 메뉴 관리 타이틀 라인 우측에 `전체 펼치기`, `전체 접기` 아이콘 버튼을 배치한다.
- 버튼은 메뉴 관리 제목과 같은 행에 위치하고, 우측 정렬 기준으로 배치한다.
- `selectedModule` 미선택 또는 `saving` 상태에서는 기존 비활성화 동작을 유지한다.
- 버튼의 동작(트리 확장/축소)은 기존 그대로 유지한다.
- 아이콘과 타이틀의 간격, 정렬, 반응형 레이아웃이 유지되도록 조정한다.
- 관련 회귀 테스트 또는 UI 검증을 수행한다.

## 변경 범위

- 프론트엔드: `frontend/src/pages/settings/system/menus/components/MenuManagementPanel.tsx`
- 필요 시: 관련 스타일 또는 레이아웃 조정 코드
- 테스트: `frontend/tests/menu-management-f1-grid.test.tsx` 또는 관련 UI 테스트

## 제외 범위

- 메뉴 관리 외 다른 화면 구조 변경
- F1-Grid 기능 전반 재설계
- 백엔드 API 구조 변경
- 다른 버튼/툴바 레이아웃 전면 리팩터링

## 완료 기준

- `메뉴 관리` 타이틀 라인 우측에 전체 펼치기/접기 버튼이 표시된다.
- 버튼 클릭 시 기존 확장/축소 동작이 정상 동작한다.
- 비활성화 조건이 유지된다.
- 화면 레이아웃과 간격이 자연스럽게 정렬된다.
- 관련 테스트 또는 검증 로그가 정상적으로 확인된다.
