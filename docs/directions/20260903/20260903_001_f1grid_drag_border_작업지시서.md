# 작업지시서

## 제목

F1-Grid 셀 드래그 선택 보더 범위 정교화

## 배경

F1-Grid의 셀 범위 드래그 선택 시 오버레이 보더가 선택 영역을 벗어나서 그려지는 문제가 발생한다. 특히 셀 높이를 넘어가는 형태로 보더가 표시되어 UI가 어색하게 보인다.

## 요구사항

- 드래그 선택 보더는 선택 범위의 실제 외곽선을 따라 그려져야 한다.
- 선택 영역의 세로/가로 경계를 넘어서 보더가 확장되지 않아야 한다.
- 기존 선택 동작 및 복사/드래그 범위 표시 동작은 유지한다.
- 관련 테스트를 통해 회귀가 없는지 검증한다.

## 변경 범위

- 프론트엔드: `frontend/src/shared/components/f1-grid/core/F1Grid.tsx`
- 테스트: `frontend/tests/f1-grid.test.tsx`

## 완료 기준

- 드래그 오버레이가 선택 영역 안쪽에만 그려진다.
- focused 테스트를 통과한다.
- `npm run test -- tests/f1-grid.test.tsx` 실행 결과가 정상이어야 한다.
