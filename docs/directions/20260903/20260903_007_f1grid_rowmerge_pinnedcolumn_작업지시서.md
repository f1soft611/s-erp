# F1-Grid rowMerge 핀 고정 컬럼 적용 이슈 작업지시서

## 배경

현재 F1-Grid의 `mergeRows` 기능은 일반 컬럼에서 연속된 동일 값의 셀을 병합하는 동작이 동작하지만, 핀 고정(pinned / sticky) 컬럼에서는 병합이 적용되지 않거나 셀 레이아웃이 어긋나는 것으로 보인다.

핵심 문제는 보이는 데이터는 정상이나, 고정 컬럼이 `position: sticky` 로 렌더링되는 구조와 병합 계산 로직이 결합될 때, 셀의 병합 상태와 실제 그리드 위치가 일치하지 않는 지점에서 발생할 가능성이 높다.

## 목표

- F1-Grid의 `mergeRows` 기능이 고정 컬럼에서도 동일한 기준으로 동작하도록 수정한다.
- 고정 컬럼과 일반 컬럼이 함께 있는 경우에도 병합 범위 계산과 렌더링이 일관되게 유지되도록 한다.
- 병합 동작이 정상적으로 보이는지 확인할 수 있는 테스트와 문서 기준을 함께 정리한다.

## 확정 요구사항

- `mergeRows: true` 또는 `mergeRows: 'custom'` 기반 병합이 pinned left/right 컬럼에서도 적용된다.
- 병합 시작 셀과 병합된 셀의 경계/배경/테두리가 고정 컬럼 상태에서 자연스럽게 표현된다.
- 이미 병합된 상태에서 셀 포커스, 선택, 편집 상태가 비정상적으로 깨지지 않는다.
- 일반 컬럼과 핀 고정 컬럼이 혼합된 그리드에서도 row merge 로직이 동일하게 계산된다.
- 테스트는 실제 렌더링 경로에서 병합 상태가 유지되는지 검증한다.

## 범위

- `frontend/src/shared/components/f1-grid/**` 내부 병합 로직 수정
- 고정 컬럼 offset 및 grid cell 렌더링 관련 계산 확인
- 필요한 경우 `GridBody`, `GridRow`, `GridCell`, `GridRowMerge` 관련 로직 수정보완
- F1-Grid 관련 테스트 추가/수정
- 필요 시 문서 및 결과 문서 정리

## 제외 범위

- 백엔드 DB 변경
- 다른 화면의 기능 변경
- 비관련 레이아웃 리팩터링
- F1-Grid 외 다른 컴포넌트 대규모 정리
- 문서 포털 자체 구조 변경 이외의 범위

## 완료 기준

- 핀 고정 컬럼이 포함된 그리드에서 `mergeRows`가 정상 작동한다.
- 병합 시작 셀과 이어지는 셀의 렌더링이 일관되게 보인다.
- 관련 테스트가 통과한다.
- 결과 문서와 필요한 스크린샷을 작성한다.

## 검증 기준

- 일반 컬럼과 고정 컬럼이 섞인 샘플 데이터 시나리오에서 row merge 동작 확인
- 왼쪽/오른쪽 핀 고정 컬럼 각각에서 연속 동일 값이 병합되는지 확인
- 병합 영역 내 선택/포커스/편집이 깨지지 않는지 확인
- Vitest 실행 로그 및 브라우저 검증 스크린샷 확보
