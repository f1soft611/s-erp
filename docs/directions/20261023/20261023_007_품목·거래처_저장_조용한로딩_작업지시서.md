# 20261023_007 품목·거래처 저장 조용한 로딩 작업지시서

## 사용자 요청

품목관리와 거래처관리에서 저장할 때 목록 Grid를 전체 로딩 오버레이로 가리지 않고, 다른 관리 화면처럼 저장 진행 표시만 조용히 보여준다.

## 범위 및 완료 조건

- 품목관리·거래처관리 저장 중에도 기존 목록을 계속 표시한다.
- 저장 버튼의 진행 표시와 저장 중 편집/중복 저장 방지는 유지한다.
- 초기 조회와 사용자가 실행한 조회의 Grid 로딩 표시는 유지한다.
- 저장 후 목록 재조회 실패 메시지, 저장 성공 알림, 변경 상태 처리는 기존 동작을 보존한다.
- API·백엔드·DB 계약은 변경하지 않는다.
- 실패 회귀 테스트 → 최소 수정 → 집중 테스트·빌드 → 브라우저 확인 순으로 검증한다.
