# 20261023_008 기준정보·환경설정 조용한 저장 편집 잠금 작업지시서

## 사용자 요청

품목관리·거래처관리와 같은 조용한 저장 동작을 기준정보·환경설정의 나머지 관리 화면에도 적용한다. 저장 요청부터 저장 후 조용한 재조회가 끝날 때까지 기존 행을 표시하고, 추가·편집·삭제·조회·대상 전환을 막는다.

## 적용 범위

- 기준정보: 공통코드, 기안양식관리
- 환경설정: 권한관리, 메뉴관리, 모듈관리, 창고관리
- 품목관리·거래처관리와 공통 F1-Grid의 전역 동작은 회귀 기준으로만 사용하며 이번 코드 변경 범위에 포함하지 않는다.
- 그룹웨어 화면, 프로필·보안 설정, F1-Grid 테스트·문서 화면의 기능은 변경하지 않는다.

## 구현 절차

1. 승인된 [상세 사양서](../../spec/20261023/20261023_008_기준정보·환경설정_조용한저장_편집잠금_상세사양서.md)를 기준으로 기준정보와 환경설정 계획을 각각 작성한다.
2. 각 화면의 회귀 테스트에서 저장 요청과 저장 후 조용한 재조회가 지연되는 구간을 재현한다.
3. 저장 진행 표시와 기존 목록 표시를 유지하면서 화면별 편집·추가·삭제·조회·대상 전환을 막는다.
4. 저장/재조회 성공 및 실패 시 잠금 해제, dirty 데이터, 기존 오류·알림·권한 동작을 검증한다.
5. 관련 사용 문서와 날짜별 결과 문서를 갱신한다. 가능한 경우 실제 브라우저에서 화면을 확인하고 영문 소문자·숫자·하이픈 경로에 스크린샷을 저장한다.

## 완료 조건

- 6개 관리 화면에서 저장 요청과 조용한 재조회 중 기존 목록이 유지되고 전체 Grid 로딩 오버레이가 표시되지 않는다.
- 저장 중 추가·중복·삭제·행/셀 편집·행 폼 및 적용·권한/메뉴 매핑·조회·대상 전환이 차단된다.
- 초기 진입 및 사용자 직접 조회의 로딩 표시, 기존 저장 진행 표시, 권한·검증·오류·알림 동작은 유지된다.
- 적용 대상의 집중 테스트와 프론트엔드 빌드를 실행하고 결과를 기록한다. 기존 환경 실패는 원인과 범위를 구분해 결과 문서에 기록한다.
