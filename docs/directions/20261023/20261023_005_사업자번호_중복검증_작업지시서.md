# 사업자번호 중복 검증 작업지시서

2026-10-23 사용자 승인: 거래처 사업자번호도 같은 테넌트의 사용/미사용 전체에서 중복 금지한다. 하이픈·공백과 무관하게 숫자만 비교하고 수정 자기 행은 제외한다. 프론트 공통 옵션과 백엔드 검증을 모두 적용하고 동시 저장 방어 SQL도 작성하되 실제 DB에는 적용하지 않는다.

## 범위와 순서

1. [기존 거래처명 중복 사양](../../spec/20261023/20261023_003_거래처명_공통중복검증_상세사양서.md)을 바탕으로 계획·상세 사양을 작성한다.
2. 기존 `validation.unique`를 숫자 비교로 확장하고 필수/자리수 검증·오류 표시를 유지한다.
3. 서비스·Mapper에서 tenant 범위/자기 행 제외 조건으로 검사하고 DB 인덱스 충돌을 사업자번호 오류로 전달한다.
4. 기존 데이터 자동 수정 없이 날짜별 SQL/이력/롤백 사본을 두 DB 문서 폴더에 동일하게 보관한다.
5. 회귀 테스트 선행, 빌드, 실제 브라우저 375/768/1280px와 결과·스크린샷을 기록한다.
