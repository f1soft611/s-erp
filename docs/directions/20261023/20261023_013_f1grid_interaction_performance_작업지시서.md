# F1-Grid 선택·편집·저장 반응 성능 작업지시서

## 요청 및 재현

- 품목·거래처 샘플 각 100건 반영 후 셀 선택, 편집, 저장이 느리다는 사용자 보고를 근거로 한다.
- 이전 대용량 스크롤 개선과 구분해 100행에서 상호작용 렌더 비용을 확인한다.
- 합성 품목 100행을 실제 브라우저에서 측정한 결과 셀 선택 시 표시 셀 렌더 1,602회, 편집값 변경 시 비편집 표시 셀 렌더 1,099회를 확인했다.

## 범위 및 완료 조건

- 공용 셀의 불필요한 렌더를 줄이되 키보드, 범위 선택, 고정열, 편집·검증 계약은 유지한다.
- 품목·거래처 저장 완료 후 이전 목록으로 그리드를 먼저 재생성하는 중복 작업을 제거한다.
- 저장 API/DB 계약, 권한, 서버 처리 방식은 바꾸지 않는다. 운영 데이터 저장 테스트는 하지 않는다.
- 회귀 테스트와 빌드, 합성 데이터의 브라우저 전후 측정, 375/768/1280px 스크린샷을 결과에 남긴다.
- 서버 API 지연은 실제로 측정하지 않았다면 개선했다고 주장하지 않는다.
