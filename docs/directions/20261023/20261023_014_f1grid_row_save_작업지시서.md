# F1-Grid 행별 저장 확정 작업지시서

- 근거: 사용자 승인(2026-10-23). 거래처·품목부터 저장 후 전체 재조회 없이 서버의 최종 행을 반영한다.
- 공용 F1-Grid API로 저장 행만 정상 상태로 전환한다. 다른 수정 행은 보존한다.
- 신규행은 요청에 있는 임시 업무 ID와 실제 ID의 명시적 응답 매핑으로 연결한다. 응답 순서로 연결하지 않는다.
- 검색 조건에서 벗어나도 저장 행은 유지하며 다음 사용자 조회 때 조건을 적용한다.
- 저장 중 진행 표시·편집 잠금·중복 저장 방지는 유지한다. 최초/명시적 조회의 로딩은 유지하고 저장 후 quiet reload는 제거한다.
- 다른 화면과 현재 작업과 무관한 변경은 수정하지 않는다. 실제 업무 데이터 저장은 검증에 사용하지 않는다.
- 완료 조건: 공통 상태/ID 전환, 양 화면 저장 통합, 오류/회귀 테스트, 빌드, 합성 브라우저 검증 및 결과 문서.
