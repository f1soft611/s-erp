# 거래처 공통검증 작업지시서

## 사용자 지시 및 승인

2026-10-23 거래처관리의 사업자번호 필수 표시·폼 필수 검사 누락을 수정한다. 저장 훅에서 별도 필수 검사하지 않고 F1-Grid로 공통화한다. 번호 자리수 설정도 공통 검증을 사용하며 폼 적용·최종 저장 모두 실제 오류를 상단 메시지영역에 전달한다. 기존 빨간 오류 표시를 유지한다.

## 범위와 완료 조건

- 거래처명·사업자번호는 컬럼 `required` 설정을 단일 근거로 사용한다.
- 기존 `inputFormat` 자리수 검사를 재사용하고 저장 훅의 거래처명 중복 필수 검사를 제거한다.
- 공통 오류 전달은 선택적 콜백으로 추가하고 기존 boolean 검증 API와 다른 화면 동작은 보존한다.
- API·백엔드·DB 변경 없이 프론트엔드만 수정한다.
- 실패 회귀 테스트 → 구현 → 집중 테스트·빌드 → 375/768/1280px 브라우저 확인 순서로 검증한다.
