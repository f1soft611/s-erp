# 거래처명 공통 중복 검증 작업지시서

## 사용자 승인

2026-10-23 거래처명 중복 검사를 F1-Grid 컬럼 validation 옵션으로 공통화한다. 프론트 공통 검증과 백엔드 최종 검증을 모두 추가한다. 같은 테넌트의 사용/미사용 행을 포함하고 앞뒤 공백 제거 후 동일 이름을 중복으로 판단한다. 수정 중 자기 행은 제외한다.

## 범위

- 공통 `validation: { unique: true }` 옵션을 추가한다. 기존 `required`, 자리수, `validate` 및 오류 전달 계약을 유지한다.
- 폼 적용과 최종 저장에서 상단 메시지, 빨간 테두리, 적용/저장 차단을 동일하게 사용한다.
- 프론트는 로드된 전체 활성 행(그리드 필터로 숨긴 행 포함)과 신규/수정 행 사이를 검사한다. 서버 검색으로 로드되지 않은 행은 백엔드가 검사한다.
- 백엔드는 tenant 범위·자기 행 제외 조건으로 이름을 조회하고 동시 저장은 유니크 인덱스로 최종 방어한다.
- 기존 데이터는 자동 수정/삭제하지 않는다. 인덱스는 기존 중복이 있으면 적용 실패하므로 승인된 데이터 정리 후 재실행한다.
- 날짜별 SQL/변경 이력/롤백은 두 스키마 디렉터리에 동일하게 기록한다. 읽기 전용 MCP로 실행하지 않는다.
- 테스트 선행, 빌드, 실제 브라우저 375/768/1280px, F1-Grid 문서와 결과·스크린샷을 포함한다.
