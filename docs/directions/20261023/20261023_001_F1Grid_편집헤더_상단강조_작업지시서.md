# F1-Grid 편집 가능 헤더 상단 강조 작업지시서

## 요구사항

> 최종 사용자 결정(2026-10-23): 상단 강조선도 시각적으로 복잡하므로 헤더의 편집 가능 강조선을 제거한다. 아이콘/배경/안내 문구는 추가하지 않으며 셀 편집 테두리와 기존 고정/드롭 표시는 유지한다. 아래는 최초 요청 이력이다.

- 사용자 요청: 헤더 하단 강조선이 셀 편집 테두리와 겹치므로 상단으로 이동한다.
- 사용자 선택: 실제 border 대신 상단 안쪽 `inset box-shadow`를 사용한다.
- 기존 강조 색상 `primary.main`, 두께 2px, 편집 가능 판정은 유지한다.
- 일반/그룹 헤더 구분선, 고정 컬럼 그림자, 드래그 드롭 표시를 보존한다.

## 완료 조건

1. 계획서 → 상세 사양서 → 테스트 → 구현 순으로 진행한다.
2. 회귀 테스트, 빌드, 375/768/1280px 브라우저 검증을 수행한다.
3. F1-Grid 사용 문서와 결과 문서를 갱신하고 스크린샷을 남긴다.
4. 백엔드/API/DB는 변경하지 않는다.
