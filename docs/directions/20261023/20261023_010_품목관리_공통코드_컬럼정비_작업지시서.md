# 20261023_010 품목관리 공통코드·컬럼 정비 작업지시서

## 승인된 요구사항

- 품목계정코드 → 품목코드 → 품목명 순서로 업무 컬럼을 배치하고 왼쪽 고정한다. 기존 No 컬럼은 유지한다.
- 품목계정코드는 `ITEM_TYPE`, 단위는 사용자가 등록한 `ITEM_UNIT` 공통코드를 사용한다.
- 품목유형(`MATERIAL_TYPE`), 보관방법(`STORE_METHOD`), 소비기한기준(`EXPIRY_STATUS`)도 공통코드 select로 제공한다.
- 품목분류는 목록, 등록/수정 폼, 상세검색에서 제외한다. DB/API 필드와 기존 저장값은 보존한다.
- 품목코드, 품목유형, 보관방법, 소비기한기준은 가운데 정렬하고 안전재고는 오른쪽 정렬한다.
- 기존 권한, 자동채번, 배치 저장, 소비기한 숫자 검증과 오류 표시를 유지한다.

## 작업 순서와 완료 조건

1. [계획서](../../plan/20261023/20261023_010_품목관리_공통코드_컬럼정비_계획서.md)를 작성한다.
2. 계획을 기반으로 [상세사양서](../../spec/20261023/20261023_010_품목관리_공통코드_컬럼정비_상세사양서.md)를 작성한다.
3. 실패 테스트 확인 후 품목관리 설정과 기존 옵션 Mapper만 변경한다.
4. 집중 테스트, 빌드와 375/768/1280px 실제 브라우저 동작을 검증한다.
5. F1-Grid 사용 문서와 결과 문서·스크린샷을 갱신한다.

DB 스키마·데이터 변경은 하지 않는다. 기본 읽기 전용 MCP의 테이블 목록, 공통코드 그룹·상세 컬럼, 제한된 그룹 코드/명칭 조회로 다섯 그룹의 존재를 확인했다. tenant 업무 행과 인증 정보는 조회·기록하지 않는다.
