# 20261028_007 종합현황 전체 폭 및 스크롤 위치 보정 작업지시서

## 요청 배경

종합현황에서 좌측 메뉴 패널을 접어도 본문이 화면 폭을 충분히 사용하지 않고 가운데에 제한된 폭으로 표시된다. 본문 오른쪽에 불필요한 여백이 남으며, 세로 스크롤 막대도 가운데 정렬된 본문 컨테이너 끝에 나타난다.

## 작업 범위

1. 종합현황 본문이 좌측 메뉴 패널 상태와 관계없이 앱 콘텐츠의 가용 폭을 사용하도록 한다.
2. 종합현황 내부의 세로 이동은 유지하되, 좁게 제한된 가운데 컨테이너 옆에 스크롤 막대와 빈 여백이 생기는 현상을 제거한다.
3. 공통 앱 셸, 다른 페이지의 폭/스크롤 동작, 대시보드 데이터 동작은 변경하지 않는다.
4. 375px, 768px, 1280px 및 넓은 데스크톱 화면에서 가로 넘침과 폭 배치를 확인한다.

## 완료 조건

- 종합현황 콘텐츠 컨테이너에 `xl` 최대 폭 제한이 없다.
- 좌측 메뉴가 접힌 넓은 화면에서 대시보드가 남은 앱 콘텐츠 폭을 채운다.
- 세로 스크롤은 유지되고, 콘텐츠 오른쪽의 불필요한 빈 영역 때문에 스크롤이 내부에 따로 떠 보이지 않는다.
- 최소 375px, 768px, 1280px에서 가로 넘침이 없다.
- 프론트엔드 회귀 테스트, 빌드 및 실제 브라우저 화면을 확인하고 결과 문서와 스크린샷을 남긴다.
