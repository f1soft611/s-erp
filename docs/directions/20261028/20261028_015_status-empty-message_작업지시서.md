# 현황 빈 조회 결과 공통 메시지 작업지시서

## 승인된 요구사항

- 문서현황(업무현황)의 그리드 하단 빈 결과 안내를 검색조건 아래 공통 메시지 영역으로 이동한다.
- 수주현황에도 같은 안내를 적용한다. 모든 페이지에 자동 적용하지 않는다.
- 정상 조회가 완료되고 결과가 0건일 때만 정보성 안내와 `검색 조건 초기화` 버튼을 표시한다.
- 최초 조회 전, 재조회 중, 조회 오류 및 검색 기본값 오류에는 빈 결과 안내를 숨긴다.
- 문구는 `조회 결과가 없습니다. 조회 기간을 넓히거나 상세검색 조건을 초기화해 주세요.`를 사용한다.
- 기존 초기화 콜백을 사용하여 필수 기준일과 기본 검색 기간을 보존한다.
- 기존 오류 메시지, 닫기, 조회, 그리드와 API 계약은 변경하지 않는다.

## 완료 조건

1. 계획서와 상세사양서를 작성한 뒤 실패 테스트부터 추가한다.
2. 공통 메시지 영역을 재사용하고 두 현황 화면에서 명시적으로 사용한다.
3. 관련 테스트, 빌드, 린트 및 375/768/1280px 브라우저 검증을 수행한다.
4. 결과와 픽스처 기반 스크린샷을 날짜별 결과 폴더에 보관한다.
