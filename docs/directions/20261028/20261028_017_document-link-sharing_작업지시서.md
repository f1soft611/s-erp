# 문서 링크 공유 작업지시서

> 후속 사용자 피드백은 [018 작업지시서](20261028_018_document-sharing-corrections_작업지시서.md)에 반영했다. 백엔드 변경 제외 조건은 최초 구현에 한하며 후속 암호화 API 및 피드 변환 수정에는 적용하지 않는다.

## 사용자 요구

- 문서작성 피드 및 문서 상세의 더보기에 `문서 공유하기`를 추가한다.
- 클릭하면 해당 문서 링크를 클립보드에 복사한다.
- 문서 본문 또는 댓글에 붙여넣은 내부 문서 링크는 OG 형태의 미리보기를 제공한다.
- 미리보기 클릭 시 우측 상세 패널을 연다. 기존 접근 권한이 있는 사용자만 조회할 수 있다.

## 작업 순서와 완료 기준

1. 기존 조회 권한과 URL 경로를 확인하고 계획서, 상세 사양서를 작성한다.
2. 링크 파싱, 복사, 미리보기, 상세 열기 회귀 테스트를 먼저 작성한다.
3. 기존 목록 API의 문서 ID 필터로 제목·요약을 조회하며 공개 OG/API나 권한 부여 기능은 만들지 않는다.
4. 본문·댓글의 작성/조회/수정/답글에 미리보기를 제공한다.
5. 테스트, 빌드, 린트, 375/768/1280px 브라우저 검증 후 결과와 스크린샷을 기록한다.

기존 작업 중인 테스트와 문서는 보존한다. 백엔드 및 DB 스키마는 변경하지 않는다.
