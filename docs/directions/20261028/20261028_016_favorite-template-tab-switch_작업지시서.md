# 문서작성 탭 전환 후 즐겨찾기 목록 조회 오류 작업지시서

## 요구사항

- 기안서에서 자주 쓰는 결재선 목록을 확인하고 취소한 뒤 업무연락으로 이동하면 자주 쓰는 참조자 목록이 조회되지 않는 오류를 재현하고 수정한다.
- 각 설정 창은 현재 문서 종류의 목록을 조회해야 한다. 이전 창의 목록, 선택 및 진행 상태가 다음 창에 영향을 주면 안 된다.
- 기존 적용/취소 경계와 템플릿 CRUD/API/DB 계약을 유지한다.

## 완료 기준

1. 기존 업무연락 참조자 작업지시서와 사양서를 기준으로 계획과 상세 사양을 작성한다.
2. 실제 취소/탭 이동/재진입 순서를 회귀 테스트로 확인하고 실패 원인을 찾는다.
3. 확인된 원인만 최소 수정하고 관련 테스트, 빌드, 린트를 실행한다.
4. 실제 브라우저 375px, 768px, 1280px 확인 및 결과/스크린샷을 남긴다.
