# 20261028_002 ERP 종합현황 실데이터 대시보드 작업지시서

## 승인 근거

사용자가 현재 구현을 검토한 제안 중 `내 결재 업무 + 최근 공지 + 권한별 수주 요약`을 우선 진행하도록 승인했다. 밝은/다크 테마 모두 완성도 있는 디자인을 요구했다.

## 범위와 순서

1. 본 지시서 → 날짜별 계획서 → 상세사양서 순서로 작성한다.
2. 기존 로그인/모듈/메뉴 구조와 다른 진행 중 변경을 유지한다.
3. 현재 종합현황의 고정 카드/샘플을 실제 조회 API로 교체한다.
4. 개인 결재·공지와 수주 집계는 독립적으로 조회/실패 처리한다.
5. 수주는 헤더 건수와 상세 공급가액을 분리 집계한다. 매출·미출하·재고 지표는 만들지 않는다.
6. 사용자 메뉴 조회권한과 인증 테넌트를 서버에서 적용한다.
7. 375/768/1280px, 밝은/다크 테마를 브라우저에서 확인하고 합성 데이터 스크린샷을 결과 폴더에 보관한다.

## 완료 조건

- 실제 API로 결재 업무·공지·수주 조회, 로딩/빈 결과/부분 오류/재시도가 동작한다.
- 수주 기간과 카드의 상세 조회 조건이 일치한다.
- 권한 없는 모듈의 데이터는 내려주지 않으며 UI에서도 숨긴다.
- 날짜·집계 정의와 출하 미반영 범위를 화면에 표시한다.
- 프론트엔드 집중 테스트/빌드/린트, 백엔드 집중 테스트, 브라우저 검증을 수행한다.
- 스키마 변경 없이 기존 테이블을 조회한다. DB 변경이 발생하면 별도 승인 범위 및 날짜별 SQL/롤백 관리가 필요하다.
