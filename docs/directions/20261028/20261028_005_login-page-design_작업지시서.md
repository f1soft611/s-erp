# 20261028_005 로그인 페이지 디자인 개선 작업지시서

## 1. 작업 개요

기존 S-ERP 로그인 화면을 깔끔하고 읽기 쉬운 카드형 디자인으로 정돈한다. 인증 흐름과 입력 항목은 그대로 유지하며, 라이트/다크 테마와 모바일·태블릿·데스크톱 화면에서 안정적으로 표시한다.

## 2. 작업 목적

- 기존 중앙 로그인 카드의 타이포그래피, 간격, 배경 및 표면 대비를 개선한다.
- 375px, 768px, 1280px 화면에서 요소 겹침, 잘림, 가로 넘침을 방지한다.
- 화면 높이가 짧을 때도 로그인 카드 전체를 세로 스크롤로 사용할 수 있게 한다.

## 3. 변경 범위

- 프론트엔드 로그인 화면과 로그인 폼 관련 스타일 및 집중 테스트
- 설계/계획/상세사양 및 결과 문서, 브라우저 스크린샷
- 백엔드, API 계약, 세션 저장 방식, 입력 필드, 검증 규칙, 로그인 이후 이동은 변경하지 않는다.

## 4. 구현 기준

1. 브랜드 색상과 현재 앱 테마를 따르는 단일 카드 레이아웃을 유지한다.
2. 차분한 중립 배경, 얇은 카드 경계, 절제된 그림자 및 명확한 제목/설명 위계를 적용한다.
3. 세 입력 필드와 제출 버튼의 간격/높이를 통일하고 포커스·오류 대비를 유지한다.
4. 세션 안내, 인증 오류, 개발 환경 테스트 계정 안내, 비밀번호 표시, 제출 중 상태 및 저작권 표시 동작을 유지한다.
5. 라이트/다크 테마의 텍스트 대비와 키보드 접근성을 확인한다.
6. 짧은 화면에서도 폼 전체가 잘리지 않도록 로그인 레이아웃의 세로 스크롤을 허용한다.
7. 사용자가 확인한 추가 가독성 개선을 적용한다: 필드명을 입력 위에 고정하고 입력 글씨를 18px로 키우며, 기본 필드 margin을 제거해 여백을 정돈한다.
8. 개발 환경 계정 안내는 기존 노출 조건과 텍스트를 유지하되, 입력/제출보다 덜 강조되는 보조 영역으로 낮춘다.

## 5. 검증 및 완료 기준

- 로그인 관련 Vitest와 프론트엔드 빌드가 통과한다.
- S-ERP 개발 서버를 `127.0.0.1:4173`에서 실행해 라이트/다크 테마의 375px, 768px, 1280px 브라우저 렌더링을 확인한다.
- 필드, 유효성 오류, 인증 오류, 비밀번호 표시, 로그인 성공 후 이동이 기존과 동일하다.
- 세 필드의 고정 라벨은 각 입력과 접근성 트리에서 연결되고, 입력 글씨는 18px이며 높이는 약 56px이다.
- 뷰포트 가로 넘침이 없고 저작권/개발 안내를 포함한 폼 전체를 사용할 수 있다.
- 결과 문서와 영문 소문자/숫자/하이픈 경로의 스크린샷을 `docs/result/20261028/login-page-design/`에 보관한다.
