# 20261028_008 종합현황 개인 결재 카드 필터 작업지시서

## 요청 배경

종합현황의 `내가 처리할 결재`, `내 임시저장`, `내 보완 필요` 카드가 모두 동일한 문서 업무 화면을 전체 목록으로 연다. 카드의 지표와 이동 결과가 일치하도록 카드별 결재 범위를 적용한다.

## 작업 범위

1. 세 카드 클릭 시 각각 `MY_PENDING`, `DRAFT`, `REVISION_REQUESTED` scope를 전달한다.
2. 작성 권한 경로에서는 기존 문서 업무 화면의 scope 필터를 적용한다.
3. 조회 전용 경로에서도 기존 결재 검색 API의 scope 조회를 사용하고 필터 상태 및 해제 수단을 표시한다.
4. URL의 유효하지 않은 scope는 적용하지 않으며 기본 전체 조회를 유지한다.
5. 백엔드 계약과 권한 검증을 변경하지 않는다.

## 완료 조건

- 카드별 URL에 올바른 `dashboardScope`가 포함된다.
- 작성/조회 전용 경로 모두 요청 결과가 해당 scope로 제한된다.
- 새로고침/직접 링크에서 필터가 적용되며 필터를 해제할 수 있다.
- 관련 회귀 테스트, 빌드, 브라우저 확인을 마치고 결과 문서와 스크린샷을 남긴다.
