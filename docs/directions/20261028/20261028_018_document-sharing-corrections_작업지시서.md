# 문서 공유 후속 수정 작업지시서

## 사용자 피드백

1. 공유 URL에서 문서 ID를 노출하지 않도록 암호화한다.
2. 편집 중 링크를 변경하면 이전 미리보기가 남지 않아야 한다.
3. 링크 상세는 전체 화면을 덮는 Drawer가 아니라 기존 페이지 영역 우측 상세 패널과 동일하게 연다.
4. 피드형의 `고정 문서 피드 응답을 확인할 수 없습니다.` 오류를 해결한다.

## 작업 순서

계획서 → 상세 사양서 → 실패 회귀 테스트 → 최소 구현 → 테스트/빌드/실제 브라우저 → 결과 및 스크린샷.

암호화는 서버가 수행하고 기존 문서 조회 권한을 유지한다. 단순 Base64 인코딩이나 프론트엔드 내 비밀키는 사용하지 않는다. 기존 평문 공유 링크는 호환하되 새 복사 링크는 암호화한다. DB 변경은 하지 않는다. 동시 진행 중인 문서번호 작업은 보존하고 피드 변환 누락만 수정한다.
