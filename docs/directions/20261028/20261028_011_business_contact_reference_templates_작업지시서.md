# 업무연락 자주 쓰는 참조자 작업지시서

## 배경

문서작성 모달의 업무연락에는 참조자만 지정할 수 있지만, 자주 쓰는 참조자 구성을 저장하고 다시 적용할 진입점은 없다. 기안서가 사용하는 결재선 설정 창과 템플릿 CRUD를 재사용하되, 업무연락에서는 결재/합의 편집 UI를 노출하지 않는다.

## 승인 요구사항

- 업무연락 참조 입력 옆에 `자주 쓰는 참조자` 버튼을 제공한다.
- 버튼은 기존 결재선 설정 모달을 참조자 전용 모드로 연다. 제목과 저장/관리 용어도 참조자로 구분한다.
- 참조자 모드에서 참조자를 선택하고, 자주 쓰는 참조자를 저장/적용/이름 변경/삭제할 수 있다. 결재/합의 단계 입력과 편집은 숨긴다.
- 모달에서 변경한 임시 참조자만 `적용`으로 작성 화면에 전달한다. 취소/닫기는 작성 화면 상태를 보존한다.
- 기존 사용자별 템플릿 API 및 업무연락 문서 코드 `008`을 사용한다. 서버/API/DB 변경은 없다.
- `008`에 저장된 템플릿에 결재/합의 참여자가 있으면 전체 템플릿 적용을 거부하고 오류를 명시한다. 참조자만 부분적으로 추출하거나 변환하지 않는다.
- 기안서 모달의 기존 표시, 템플릿 동작, 적용/취소 흐름을 유지한다.
- 결재선 사용자 선택과 참조자 선택 필드 높이를 참조 필드 기준 40px로 통일하고, 각 필드 옆 액션 버튼도 같은 높이로 맞춘다.
- 375px, 768px, 1280px 브라우저에서 입력/버튼/모달의 겹침, 잘림, 페이지 가로 넘침을 확인한다.

## 작업 절차

1. 승인된 설계, 상세사양서, 계획서를 확인한다.
2. 참조 필드 진입 및 참조자 전용 모드/템플릿 동작의 실패 테스트를 먼저 작성하고 실패 원인을 확인한다.
3. 기존 모달을 명시적인 참조자 모드로 확장하고 사용자 선택/템플릿을 기존 임시 상태 경계에 연결한다.
4. 결재/합의가 섞인 기존 템플릿의 원자적 거부와 상태 보존을 검증한다.
5. 관련 회귀 테스트, 빌드, 브라우저 반응형 검증을 수행한다.
6. 결과 문서와 영문 경로의 스크린샷을 남긴다.

## 완료 조건

- 업무연락 참조 필드 옆 버튼으로 참조자 전용 모달을 열 수 있다.
- 참조자 모드에는 결재/합의 UI가 없고 기존 템플릿 API로 참조자만 저장/조회/적용/관리한다.
- 저장된 참조자 순서가 보존되고 적용 전에는 작성 화면에 변경이 반영되지 않는다.
- 취소/닫기 시 원래 참조자 목록이 유지된다.
- 결재/합의가 섞인 템플릿은 일부 적용 없이 명시적 오류를 표시한다.
- 기안서 결재선 설정 회귀가 없고, 관련 프론트 테스트/빌드/375·768·1280px 브라우저 검증과 결과 스크린샷이 포함된다.
- 결재선/참조자 입력 및 액션 버튼 높이가 모두 40px이며 같은 기준선으로 표시된다.
