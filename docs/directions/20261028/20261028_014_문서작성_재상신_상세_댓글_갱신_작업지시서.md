# 20261028_014 문서작성 재상신 후 상세 댓글 갱신 작업지시서

## 목적

보완요청 문서를 기안자가 수정 후 재상신한 뒤에도 우측 상세 패널의 댓글·시스템 이력이 최신 상태로 표시되도록 한다.

## 재현 경로

1. 문서작성에서 보완요청된 문서를 선택해 우측 상세를 연다.
2. `문서 더보기`에서 `수정 후 재상신`을 선택한다.
3. 수정창에서 `결재신청`을 실행한다.
4. 우측 상세의 시스템 댓글에 재상신 이력이 추가되지 않고 이전 이력만 보이는지 확인한다.

## 조사 결과

- 재상신 성공 시 작성 훅은 작성창을 닫고, 페이지는 `detailRefreshToken`을 증가시킨다.
- 상세 피드는 이 토큰 변경으로 문서 상세 API만 다시 호출한다.
- 댓글·시스템 이력 조회는 문서 ID와 패널 열림 상태에만 연결되어 있어, 같은 문서의 재상신으로는 다시 조회되지 않는다.

## 작업 지시

1. 상세 갱신 토큰이 바뀌면 문서 상세와 댓글·시스템 이력을 함께 다시 조회한다.
2. 기존 댓글 조회 오류 처리와 초기 조회 동작을 유지한다.
3. 토큰 갱신으로 댓글·시스템 이력이 다시 로드되는 회귀 테스트를 먼저 추가하고, 실패를 확인한 후 최소 수정한다.
4. 문서 상세 UI 동작과 테스트 결과를 결과 문서에 기록한다.

## 완료 조건

- 재상신 후 열린 우측 상세에서 재상신 시스템 이력이 표시된다.
- 최초 상세 진입 시 댓글 조회와 기존 댓글 기능이 유지된다.
- 관련 회귀 테스트와 프론트엔드 빌드가 통과한다.

## 범위 제외

- 백엔드/API/DB 변경
- 댓글 정책, 페이지 크기, 댓글 정렬 변경
- 목록 및 요약 갱신 동작 변경
