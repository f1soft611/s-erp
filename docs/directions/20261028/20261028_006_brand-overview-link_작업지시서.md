# S-ERP 로고 종합현황 이동 작업지시서

- 요청: 왼쪽 상단 S-ERP 클릭 시 종합현황으로 이동한다.
- 기존 [종합현황 사양](../../spec/20261028/20261028_002_erp-dashboard_상세사양서.md)의 `/groupware/overview` 경로를 재사용한다.
- 로고 외형, 모듈 선택, 메뉴 권한, API와 DB 계약은 변경하지 않는다.
- 계획서 → 상세사양서 → 회귀 테스트 → 구현 → 브라우저 확인 및 결과 기록 순서로 진행한다.
- 완료 기준: 다른 메뉴에서 로고 클릭 및 키보드 활성화로 종합현황 이동, 종합현황에서 재클릭 가능, 375/768/1280px 확인 및 스크린샷 보관.
