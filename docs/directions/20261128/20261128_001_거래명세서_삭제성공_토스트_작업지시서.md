## 배경

20261127_003에서 영업 화면의 저장·삭제 성공을 토스트로 통일했으나, 거래명세서 삭제는 원래 성공 문구가 없어 남겨 두었다. 사용자가 추가를 결정했다(2026-11-28).

## 요구사항

1. 거래명세서 삭제가 성공하면 `거래명세서가 삭제되었습니다. 명세번호: <번호>` 토스트를 표시한다(견적·수주와 같은 형식).
2. 현황의 수정 창에서 삭제해 창이 닫혀도 토스트가 보여야 한다.
3. 삭제 실패는 기존처럼 화면(수정 창이면 창 안) 메시지 영역에 표시하고 토스트는 띄우지 않는다.

## 완료 기준

- 자동화 테스트: 수정 창 삭제 성공 시 창이 닫히고 토스트 문구 표시, 실패 시 창 안 오류·토스트 없음.
- 관련 테스트·타입 검사·빌드·린트 통과, 결과 문서 작성.
