# F1-Grid 대용량 데이터 처리 및 50k/100k 샘플 문서화 작업지시서

## 배경

F1-Grid는 ERP 업무에서 대량 데이터 조회, 정렬, 필터, 편집, 선택, 엑셀 중심 업무를 지원하는 공용 그리드로 확장되어야 한다. 현재 문서와 예시는 소규모 샘플 중심으로 구성되어 있어, 50,000건과 100,000건 규모의 대용량 데이터에서도 그리드가 안정적으로 렌더링되고 사용자 입력/정렬/필터 동작을 유지하는지 명확히 정의할 필요가 있다.

대용량 데이터 처리 기능은 단순히 “더 큰 행 수를 지원한다”에 그치지 않고, 렌더링 성능, 메모리 사용량, 스크롤 응답성, dirty 상태 유지, 필수값 검증, 윈도우 기반 렌더링과 같은 실제 ERP 작업 흐름을 함께 고려해야 한다. 또한 문서 포털인 `f1-grid-docs`에 실사용용 샘플 데이터와 성능 시나리오를 함께 추가해 개발자와 사용자가 동일한 기준으로 검증할 수 있어야 한다.

## 경로 분류

- 분류: `bounded`
- 사유: F1-Grid 공용 컴포넌트와 문서 포털 범위에 국한되며, 요구사항이 모듈 단위로 명확하게 정의되고 구현 범위를 제한할 수 있다.

## 목표

1. F1-Grid의 대용량 데이터 처리 범위를 정의한다.
2. 50,000건과 100,000건 샘플 데이터 생성 구조를 설계한다.
3. `f1-grid-docs`에 대용량 데이터 동작 기준, 성능 기대치, 샘플 사용 예시를 반영한다.
4. 일반 데이터와 대용량 데이터의 동작 차이를 문서로 명확히 정리해 회귀 검증 기준을 준수한다.

## 확정 요구사항

### 1. 대용량 데이터 처리 기능 범위

- F1-Grid는 대용량 데이터 셋을 기존 구조와 크게 달라지지 않게 처리할 수 있어야 한다.
- 대용량 데이터에서는 메모리 부담을 줄이기 위해 렌더링/가상화 처리 방식을 정의하고, 행 수가 늘어나도 스크롤, 키보드 이동, 선택, 정렬 동작이 유지되도록 한다.
- 셀 편집, dirty 표시, 체크박스 선택, 필터/정렬 조건 적용, 폼 모달 연동 흐름이 50k/100k 데이터에서도 동일한 로직을 따라야 한다.
- 사용자 입장에서는 “대용량 데이터”가 특별한 별도 화면이 아니라, 기존 F1-Grid 사용법을 그대로 유지하면서 더 큰 데이터 집합을 다룰 수 있어야 한다.

### 2. 50,000건 / 100,000건 샘플 데이터 생성

- 대용량 데이터 샘플은 실제 ERP 업무에 가까운 값(품목코드, 거래처, 부서, 상태, 금액, 일자, 담당자, 권한 등)을 포함하도록 구성한다.
- 50,000건 샘플과 100,000건 샘플을 각각 생성할 수 있는 구조를 정의한다.
- 샘플 데이터는 반복 실행 가능하며, 로컬 개발/문서 예시에서 바로 재사용 가능한 형태로 제공한다.
- 샘플 데이터는 행 수 증가에 따라 필터/정렬/페이지네이션/selection 동작을 검증할 수 있는 기준 데이터셋으로 설계한다.

### 3. 문서 포털 업데이트

- `frontend/src/pages/f1-grid-docs/F1-GRID.md` 및 관련 문서 섹션에 대용량 데이터 처리 문맥을 추가한다.
- 문서에는 다음 내용을 포함한다.
  - 대용량 데이터 정의 및 목표
  - 50k/100k 샘플 데이터 구조 설명
  - 기대 동작(스크롤, 선택, 필터, 정렬, 편집 시나리오)
  - 성능 주의사항 및 기준치
  - 회귀 검증 방법 및 예시
- 문서에 샘플 코드 또는 구조 예시가 포함되어야 한다.

### 4. 검증 기준

- 소규모 샘플과 대용량 샘플 모두에서 기본 동작이 동일해야 한다.
- 50k/100k 데이터셋을 기준으로 다음 항목을 검증한다.
  - 데이터 로드/표시 시간
  - 스크롤 반응성
  - 키보드 이동
  - 필터/정렬 적용
  - 체크박스/selection 상태 유지
  - dirty 상태 및 편집 동작
- 기능 추가 전후의 동작을 문서와 테스트 시나리오로 비교할 수 있어야 한다.

## 구현 범위

- F1-Grid 대용량 데이터 처리 관련 공용 로직 설계
- 50,000건/100,000건 샘플 데이터 생성용 mock/fixture 구조 설계
- 문서 포털(`f1-grid-docs`)의 설명 및 샘플 예시 갱신
- 대용량 검증용 시나리오 정리 및 회귀 기준 문서화

## 제외 범위

- 백엔드 DB 구조 변경
- 다른 ERP 화면의 전역 리팩터링
- F1-Grid와 무관한 화면 기능 추가
- 외부 Grid 라이브러리 도입
- 대용량 데이터 처리와 무관한 UI/스타일 개편

## DB 영향

- DB 스크립트: 해당 없음
- 영향 검토: 프론트엔드 공용 컴포넌트와 사용자 문서만 수정하며, API/DB 스키마는 변경하지 않는다.

## 검증 기준

- 대용량 샘플 데이터 50k/100k 생성이 문서 예시와 테스트 구조에 반영된다.
- F1-Grid 대용량 처리 명세가 문서와 구현 계획에 일치한다.
- 기본 데이터셋과 대용량 데이터셋 모두에서 핵심 UX 시나리오가 유지된다.
- `f1-grid-docs` 문서와 실제 구현/테스트 수용 기준이 일치한다.

## 완료 기준

- `f1-grid-docs`가 대용량 데이터 사용 사례와 시나리오를 포함한다.
- 다음 단계인 계획서와 상세 사양서 작성이 이 작업지시서를 기준으로 이어질 수 있다.
