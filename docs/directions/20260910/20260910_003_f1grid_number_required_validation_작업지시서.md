# F1-Grid 컬럼 숫자/필수값 검증 개선 작업지시서

## 배경

F1-Grid 공용 그리드에서 숫자 컬럼과 필수값 검증은 생성/수정/폼 모달 입력 흐름 전반에서 일관되게 동작해야 한다. 현재는 `decimalPlaces: 0` 또는 소수점 입력 범위가 제어되지 않고, `required` 컬럼의 저장/폼모달 검증이 일관적이지 않아 사용자가 입력 누락을 쉽게 발견하지 못한다.

## 경로 분류

- 분류: `bounded`
- 사유: 공용 F1-Grid 컴포넌트와 문서 경계 내에서 동작 개선과 검증을 수행하며, 특정 화면에 얽매이지 않고 공용 로직 변경 범위가 명확하다.

## 목표

1. 숫자 컬럼 옵션에서 `decimalPlaces: 0`일 때 소수점 입력을 차단하고, 소수점 자릿수 제한이 1 이상일 때 1자리까지만 입력되도록 정규화한다.
2. 폼 모달 플러그인에서 `editable: true`인 컬럼만 기본 입력 필드로 세팅한다.
3. 컬럼 `required` 옵션이 지정된 경우 저장 시 필드 누락을 즉시 감지할 수 있도록 UX를 개선한다.
4. 저장 시 누락 필드는 자동 포커스 이동과 강조 표시를 제공한다.
5. 폼모달에서도 `required` 표시와 동일한 필수값 검증 로직을 적용한다.

## 확정 요구사항

### 1. 숫자 컬럼 소수점 제한

- `column.type`이 `number` 또는 `decimal`이고 `decimalPlaces`가 `0`이면 소수점 입력 및 소수점 값이 저장되지 않도록 처리한다.
- 소수 입력이 허용되는 경우 `decimalPlaces` 값에 맞춰 최대 자리수만 적용한다.
- 예를 들어 `decimalPlaces: 1`이면 입력 값은 `1.2`까지 허용하고, `1.23`처럼 초과 자리는 잘라내거나 차단한다.
- 소수점 문자 자체가 입력되지 않거나, 입력 후 표시 값이 소수점이 사라지는 버그가 없도록 정합성을 유지한다.
- 그리드 셀 편집, 폼 모달 입력, 저장 전 검증이 모두 동일한 규칙을 따른다.

### 2. 폼모달 기본 필드 세팅 범위

- 폼 모달 플러그인에서 기본 세팅할 필드는 `editable: true`인 컬럼만 대상으로 한다.
- `editable: false` 또는 조건부 `editable` 함수가 false인 컬럼은 기본 폼 필드에 포함하지 않는다.
- `hidden`, `readOnly`, `checkbox`, `rownumber` 등 비입력 필드는 기본 폼 필드에서 제외한다.
- 기존 동작과 충돌하지 않도록, 특정 플러그인 또는 화면에서 명시적으로 필드를 추가하는 경우는 별도 로직으로 유지한다.

### 3. 필수값 UX 개선

- 컬럼 옵션에 `required: true`가 지정된 경우 저장 시 필수값 누락을 즉시 검사한다.
- 누락 값이 있으면 저장을 막고 해당 셀에 자동 포커스 이동을 수행한다.
- 누락된 필드는 시각적으로 강조되어 사용자가 즉시 수정 위치를 확인할 수 있어야 한다.
- 로직은 그리드 저장 흐름과 폼 모달 적용 흐름 모두에서 동일하게 동작한다.

### 4. 폼 모달의 필수 표시 및 검증

- 폼 모달에 렌더되는 필드 중 `required`가 설정된 항목에는 필수 표시가 노출된다.
- 폼 모달의 적용 시에도 동일한 필수 체크 로직을 실행한다.
- 누락된 필드는 해당 입력 컴포넌트에 에러 메시지와 포커스를 적용한다.
- `required` 필드가 비어 있으면 `적용`을 막고, 해당 셀/필드의 에러 상태를 유지한다.

## 구현 범위

- 공용 F1-Grid 숫자 편집 및 검증 로직
- F1-Grid 폼 모달 기본 필드 세팅 규칙
- 그리드/폼모달 공통 필수값 검증 및 포커스 이동
- 필요한 UI 강조 스타일 및 접근성 속성
- F1-Grid 테스트 보강 및 문서 갱신

## 제외 범위

- 백엔드 API 및 데이터베이스 구조 변경
- 다른 업무 화면의 전역 스타일 리팩터링
- F1-Grid와 무관한 기능 추가
- 사용자가 이미 지정한 별도 범위를 벗어난 리팩터링

## DB 영향

- DB 스크립트: 해당 없음
- 영향 검토: 프론트엔드 공용 컴포넌트와 사용자 문서만 변경하며 API/DB 스키마는 변경하지 않는다.

## 검증 기준

- 숫자 컬럼의 `decimalPlaces: 0` 및 `decimalPlaces: 1` 입력 동작을 Vitest로 검증한다.
- 폼 모달 기본 필드 세팅이 `editable: true` 컬럼만 포함하는지 확인한다.
- `required` 컬럼 누락 시 저장이 막히고 자동 포커스 이동이 되는지 검증한다.
- 폼모달에서도 필수 표시와 필수 체크가 정상 동작하는지 검증한다.
- 관련 F1-Grid 테스트와 전체 프론트엔드 빌드를 실행해 회귀 여부를 확인한다.

## 완료 기준

- 숫자 소수점 입력 정규화가 일관되게 동작한다.
- 폼 모달 기본 필드 세팅이 `editable: true` 컬럼 기준으로 제한된다.
- `required` 저장 및 폼 적용 검증이 유지된다.
- 사용자 문서와 결과 문서가 구현 내용과 일치한다.
