# F1-Grid 집계 작업지시서

## 요청

- `features: [{ ftype: 'summary', dock: 'top' }]`과 컬럼의 `summaryType`으로 합계, 평균, 최솟값, 최댓값을 그리드 상단 또는 하단에 표시한다.
- 수주등록의 하단 상세 그리드에 먼저 적용한다.
- 참조: `WSA322_VW.js`의 수주 상세 합계 설정.

## 범위와 완료 조건

- 공통 그리드 기능, 수주 상세 적용, 회귀 테스트 및 F1-Grid 문서를 함께 변경한다.
- 기존 화면, 편집, 정렬, 필터, 고정 컬럼, 가상화와 가로 스크롤을 보존한다.
- 프론트엔드 검증 및 결과 문서와 스크린샷을 남긴다. 백엔드와 DB 변경은 없다.
