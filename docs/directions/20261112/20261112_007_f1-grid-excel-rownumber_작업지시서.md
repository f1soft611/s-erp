# F1-Grid 엑셀 행번호 작업지시서

- 사용자 요청: 엑셀 내보내기에서 `type: 'rownumber'`를 화면 그대로 출력한다.
- 기존 행번호 사양: [작업지시서](../20260901/20260901_008_F1GRID_ROWNUMBER_컬럼타입_작업지시서.md)와 [사양서](../../spec/20260901/20260901_008_F1GRID_ROWNUMBER_컬럼타입_사양서.md).
- 완료 기준: 화면 표시 순서와 같은 1부터의 행번호를 엑셀 숫자 셀에 기록하고, 필터·정렬 및 집계 행에서도 일관되게 확인한다.
