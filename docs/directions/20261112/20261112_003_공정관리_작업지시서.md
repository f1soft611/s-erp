# 공정관리 작업지시서

- 생산관리 > 기준정보 > 공정관리 메뉴를 추가하고 공정그룹과 공정을 한 화면에서 관리한다.
- 기존 F1Tree로 공정그룹과 공정의 계층을 표현한다.
- F1Grid에 이미지 컬럼을 추가하고 공정 이미지를 관리한다.
- 프론트엔드, 백엔드와 DB 변경 이력을 기존 패턴에 맞춰 구현한다.
- 참고: 레거시 WPR104_VW(공정그룹), WPR101_VW(공정); 기존 창고관리 및 F1Tree.
- 초기에는 기본 DB MCP가 노출되지 않아 스키마 이력과 Mapper를 참조했다. 이후 도구가 제공되어 현재 공정 테이블·메뉴 계약을 읽기 전용으로 확인했다.
- 화면이 열리지 않는 문제를 조사하고 생산관리 메뉴 경로가 기존 인증 및 대시보드 라우팅을 통과하도록 수정한다.
- 공정관리 검색 입력이 아이콘과 어긋나는 문제를 기존 창고관리·작업표준서 검색 패턴에 맞춰 수정한다.
- 우클릭 메뉴의 루트 추가·행 추가를 공정그룹 추가·공정 추가로 제공하고 권한과 선택한 그룹 관계를 지킨다.
- 공정 이미지는 약 60×60 크기와 빈 이미지 표시를 사용하고, 셀의 선택·삭제 버튼 대신 이미지 클릭과 Delete 키를 지원한다. 공정 속성 체크박스는 중앙 정렬한다.
- 공정관리의 코드 컬럼을 숨기고, 확장자와 실제 형식이 다른 PNG/JPEG 이미지도 실제 형식으로 검증·저장할 수 있게 수정한다.
- F1Tree에서 하위 행의 이름 앞에 ㄴ 형태의 계층 표시를 추가한다.
- 공정그룹 행의 이미지 영역은 비우고 하위 연결 표시가 이름에 가깝게 보이도록 조정한다.
- 공정관리 화면을 기존 기준정보 화면 패턴에 맞춰 컴포넌트·훅·서비스·타입·데이터 책임으로 분리하고 프론트엔드 지침을 보완한다.
- 백엔드도 기존 기준정보와 같은 컨트롤러·서비스 인터페이스/구현·도메인 모델/저장소 구조로 정리하고 지침을 보완한다. 기존 스키마와 API 계약은 유지한다.
