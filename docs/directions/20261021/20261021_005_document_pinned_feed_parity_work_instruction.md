# 문서작성 상단 고정 표시 정합성 작업지시서

## 사용자 요구 및 승인

- 피드형에서도 리스트형처럼 별도 조회한 상단 고정 문서를 상단 영역에 표시한다.
- 상단 고정 목록 안의 직접 해제 버튼을 제거한다.
- 공지사항처럼 피드 카드와 리스트 상세의 고정된 핀은 primary 색상을 사용한다.
- 기존 고정/해제 확인창, 실패 알림, 별도 조회, 필터, 페이지네이션은 유지한다.
- 추가 요청: 피드/리스트 본문은 일반 목록 API의 조회 순서를 유지하고 고정 문서도 제외하지 않는다. 고정 문서를 본문 선두로 이동하거나 별도 고정 조회 결과를 본문에 삽입하지 않는다.

## 절차 및 범위

1. 계획서와 상세 사양서를 작성한다.
2. 표시 누락, 직접 해제 제거, 핀 색상의 회귀 테스트를 작성하고 실패를 확인한다.
3. 문서작성 페이지, 상세 피드 컴포넌트, 일반/고정 목록을 구성하는 훅을 수정한다.
4. 관련 테스트, 프론트엔드 빌드, 375/768/1280px 브라우저 검증을 수행한다.
5. 결과와 스크린샷을 기록한다.

백엔드/API 계약/DB 변경은 없다. 이번 지시는 이전 004 작업의 고정 패널 해제 버튼 유지 조건을 대체한다.
