# 20261021_002 커뮤니티 자료실 F1Tree 컨텍스트 메뉴 개선 작업지시서

## 1. 목적

자료실 F1Tree의 마우스 오른쪽 메뉴에서 사용하지 않는 `루트 추가`를 제거하고 `엑셀 내보내기`를 제공한다.

## 2. 범위 및 요구사항

1. `ArchiveFileGrid`에서 자료실 트리에만 `allowAddRootInContextMenu={false}`를 적용한다.
2. `canExportExcel`을 활성화해 기존 공통 Excel exporter를 사용한다. 내보내기 대상은 현재 트리 행과 표시 중인 컬럼이다.
3. 행 추가, 행 삭제, 행 복제 비활성 설정과 공통 F1Grid/F1Tree 메뉴 항목 동작은 변경하지 않는다. 공유 컴포넌트는 실제 표시되는 메뉴 그룹 사이에만 구분선을 렌더링한다.
4. 표시할 행 작업 메뉴가 하나도 없는 경우 해당 메뉴 그룹의 구분선을 출력하지 않는다. 정렬/필터 메뉴도 숨겨진 자료실에서는 일반 메뉴와 기본 설정 복원 사이에 구분선을 하나만 표시한다.
5. 자료실 F1-Grid 문서와 결과 문서를 갱신한다.

## 3. 완료 조건

- 자료실 트리 우클릭 메뉴에 `루트 추가`가 없고 `엑셀 내보내기`가 표시된다.
- 엑셀 내보내기 메뉴 선택이 기존 exporter 다운로드 경로를 실행한다.
- 추가 작업 메뉴가 모두 없고 정렬/필터 메뉴도 숨겨지면 컨텍스트 메뉴에 중복 구분선이 생기지 않고 구분선 하나만 표시된다.
- 공통 트리 메뉴 및 다른 화면은 영향받지 않는다.
- 자료실 관련 테스트와 프론트엔드 빌드가 통과하고, 결과 문서가 갱신된다.
