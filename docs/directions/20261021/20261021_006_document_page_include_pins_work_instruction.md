# 문서작성 일반 페이지 고정 문서 포함 작업지시서

## 사용자 요구

상단 고정 영역은 별도로 유지한다. 일반 리스트/피드도 고정 문서를 포함해 조회하며 원래 순서를 유지하고 고정 상태는 핀으로 표시한다. 일반 목록에서 고정 문서가 빠지면 안 된다.

## 확인된 원인과 범위

- 앞선 005 작업에서 프론트엔드 제외/재정렬은 제거했지만 서버의 `relatedWriteDocumentFilters`에 개인 고정 문서 `NOT EXISTS` 조건이 남았다.
- 이 조건은 일반 페이지 및 전체 건수에 함께 적용된다. 피드도 같은 페이지 조회를 사용한다.
- 서버의 고정 제외 조건만 제거하고 tenant, 삭제 여부, 읽기 권한, 업무구분, 문서 ID, scope, 정렬, LIMIT/OFFSET을 유지한다.
- 별도 고정 조회 및 고정 저장/해제, DB 스키마는 변경하지 않는다.

## 절차

1. DB MCP 테이블/컬럼 메타데이터를 확인한다.
2. 계획서 → 상세 사양서 → 매퍼 실패 회귀 테스트 → 구현 순서로 진행한다.
3. 일반 목록/전체 건수 SQL의 고정 제외 제거를 검증하고 관련 서비스/컨트롤러 테스트를 실행한다.
4. 결과에 실제 서버 반영 여부와 재시작 필요성을 명시한다.
