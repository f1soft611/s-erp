# 문서현황 우클릭 메뉴 수정 작업지시서

## 요청 및 승인

- 문서현황에서 우클릭 메뉴가 동작해야 하며, 우클릭으로 상세를 열지 않는다.
- 행 추가·위/아래 삽입·행 복사·행 삭제는 허용하지 않는다.
- 사용자는 사용 불가 메뉴를 회색 표시하는 대신 **숨김**으로 승인했다.
- 왼쪽 클릭 및 체크박스 선택의 기존 상세 열기 동작과 다른 화면의 그리드 동작은 유지한다.

## 범위 및 완료 기준

- 문서현황과 F1Grid의 우클릭 행 선택 정책만 수정한다.
- 컬럼 길이 자동 조정, 정렬 해제, 설정 복원은 사용 가능하게 한다.
- 사용자의 추가 요청에 따라 엑셀 내보내기 메뉴도 표시하고 실행할 수 있게 한다. 필터 비활성 정책은 유지한다.
- 실패하는 회귀 테스트를 먼저 확인하고 관련 테스트·빌드·실제 브라우저로 검증한다.
- 결과 문서와 합성 데이터 스크린샷을 남긴다. 백엔드/API/DB 계약은 변경하지 않는다.
