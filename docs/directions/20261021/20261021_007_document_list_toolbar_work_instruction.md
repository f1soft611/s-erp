# 문서 리스트 도구막대 정합성 작업지시서

## 승인 요구

- 리스트형도 결재상태 → 문서구분 → 세로 구분선 → 상단 고정 핀 → 더보기 순서로 표시한다.
- 더보기는 기존과 동일하게 작성자의 수정/삭제 가능한 문서에만 표시한다.
- 구분선을 핀과 세로 중앙 정렬하며 피드/상세도 동일 기준을 사용한다.
- 조회/정렬/페이징/고정 확인/권한 정책은 유지한다.

## 범위와 절차

1. 계획서와 상세 사양서를 작성한다.
2. 목록 작성자 여부, 도구막대 배치/정렬, 메뉴 권한 및 수정/삭제 동작의 실패 테스트를 작성한다.
3. 목록 응답에 현재 인증 사용자 기준 작성자 여부를 추가하고, 기존 상세 메뉴를 리스트와 재사용한다.
4. 공통 ListView에는 선택형 도구막대 슬롯만 추가해 다른 소비자를 유지한다.
5. 대상 테스트/빌드/브라우저 검증과 결과 문서를 작성한다.

DB MCP에서 확인한 기존 문서의 drafter_id를 사용하며 스키마 변경은 없다. 기존 006 작업의 미커밋 SQL 수정은 보존한다.
