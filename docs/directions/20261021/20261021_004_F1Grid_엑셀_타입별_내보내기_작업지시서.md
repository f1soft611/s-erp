## 요구사항

- F1-Grid에서 `.xlsx`로 내보낼 때 컬럼 `type`에 맞는 Excel 셀 값을 생성한다.
- `number`, `decimal`, `currency`는 숫자 셀, `date`/`datetime`/`time`은 날짜·시간 셀, `checkbox`는 Boolean 셀로 내보낸다.
- select, user, code 등 나머지 타입은 현재의 화면 표시 텍스트를 유지한다.
- 숫자 자릿수, 통화 표시, 지원되는 date `format`은 Excel 표시 서식에 반영하되 값의 Excel 셀 타입은 유지한다.
- 빈 값은 빈 셀로 내보내고, 유효하지 않은 비어 있지 않은 typed 값은 원문 텍스트로 보존한다.
- date-only 문자열은 날짜 부분을 유지해 시간대 변환으로 날짜가 바뀌지 않게 한다.

## 범위

- 공통 F1-Grid Excel exporter, 필요한 날짜 변환 공통 유틸리티, 관련 테스트 및 F1-Grid 문서를 수정한다.
- 현재의 내보내기 메뉴, 파일명, 화면에 보이는 행/컬럼 범위와 다운로드 흐름은 유지한다.
- 백엔드, API 계약, 데이터베이스 및 다른 화면 동작은 변경하지 않는다.

## 완료 기준

- 실제 `.xlsx`를 읽어 numeric/date/Boolean/text 셀 값과 number format을 검증한다.
- 빈 값과 변환 불가 값 보존, 날짜 마스크 및 시간대 경계 사례를 검증한다.
- export·date format·F1-GRID 문서 테스트와 `npm run build`가 통과한다. 작업 전부터 재현되는 넓은 Grid/context-menu 테스트 실패는 결과 문서에 기준 상태로 기록하고 이번 범위에서 수정하지 않는다.
- [F1-GRID.md](../../../frontend/src/pages/f1-grid-docs/F1-GRID.md)와 날짜별 결과 문서를 갱신하고 결과 스크린샷을 저장한다.
- 기존 작업 트리 변경을 보존한다.
