# 20261119_009 인사관리 2-1단계 사원등록 작업지시서

## 배경
인사관리 모듈 2단계(인사정보관리)를 둘로 나눈다. 이 문서는 2-1(사원등록)이다. 2-2(계정 관리 화면, 비밀번호 초기화, 로그인 허용/미허용, 사진 변경 정책)는 후속 작업이다. 참고: 구 MES 화면 `WHR101_VW`(임직원 등록), 인사마스터 `TIN114`, 이력 `TIN125`, 저장 프로시저 `SP_WEB_F_IN_101_01_LIST/IUD`. 1단계 결과: [20261119_008](../../result/20261119/hr-department/20261119_008_인사관리_부서관리_결과.md).

## 결정 (사용자 승인, 2026-11-19)
- 사원 정보는 기존 `tb_user`를 확장한다(별도 인사마스터 테이블을 새로 만들지 않는다). 메뉴는 `HR_INFO`(인사정보) 그룹 아래 "사원등록"(`HR_INFO_EMPLOYEE`, `/hr/info/employee-manage`).
- 급여 관련과 아래 항목은 제외한다: 급여지급군·급여형태·지급은행·계좌·근무상태·메신저사용·회사·사업장·생산숙련도·외주업장명·공제대상부양가족·소득세적용율·거주구분·장애인·고용보험적용여부, 그리고 기본근태적용·연차적용입사일자·닉네임·한자이름 등 MES 부가 항목. 하위 팝업 8종(첨부·가족·학력·경력·외국어·자격·병역·여권/비자)은 "인사부가정보"로 나중에 확장한다.
- 신규 항목: 휴직일자(`suspend_dt`), 복직일자(`back_dt`). 마스터에는 최신 값만 두고, 여러 번의 휴직 이력은 3단계 인사명령 이력에서 본다.
- 공통코드: 성별(남/여), 내/외국인, 근무형태(정규/외주), 생일 음력/양력, 직위(`POSITION`: 회장, 대표이사, 상무이사, 이사, 부장, 차장, 과장, 대리, 주임, 사원), 국가(`COUNTRY`: ISO 3166-1 249개국, **코드는 3자리(alpha-3, 예 KOR)**, 2자리(KR)는 설명 칸에 함께 둔다. 기존 KR·JP는 KOR·JPN으로 변경한다. 거래처 `country_code`는 전부 비어 있어 영향이 없다).
- 직급은 기존 `LEVEL`, 직위는 신규 `POSITION`. 부서는 부서 선택 도움창(회사 선택 불가)을 쓴다.
- 사번: 직접 입력 또는 입사년월 `YYMM` + 순번 2자리 = 6자리 자동(입사일 기준, 순번이 99를 넘으면 3자리로 확장). 유일성은 서버와 DB 제약으로 검사하고 **등록 후 수정할 수 없다**.
- 주민등록번호: 서버에서 AES-GCM으로 암호화해 저장하고 화면에는 마스킹해 보여 준다. 중복 등록은 HMAC 해시로 막는다.
- 실사용자 구분(`real_user_at`): 시스템 사용 여부. 실사용자로 선택하면 로그인 아이디와 초기 비밀번호를 받아 계정(`tb_login_account`)까지 같이 발급한다(`DEFAULT_USER` 역할 부여, 초기 비밀번호는 최초 로그인 시 변경 대상). 실사용자가 아니면 계정 없이 사원만 등록한다(현장직).
- 사진: 사원 마스터(`tb_user`)가 원본이고, 계정이 있으면 `tb_login_account.profile_image`에도 같이 기록한다(기존 결재·공지 등 아바타 소비처는 수정하지 않는다). 관리자만 등록할지 본인도 등록할지의 정책 제어와 내 정보 관리 연동은 2-2에서 한다.
- 사원 삭제 기능은 없다(결재·알림·구매 등 FK 다수). 퇴사일을 입력해 퇴직 처리한다.

## 범위
- 포함: DB 스크립트(`tb_user` 확장, 공통코드·국가 시드, 사원등록 메뉴), 백엔드 `let/hr/employee`와 `ResidentNumberCipher`, 부서 소속 사원 조회에 재직/퇴직 구분 반영(1단계 후속), 프론트 `pages/hr/employee`, 부서관리 소속 사원 목록의 사번·직위·재직/퇴직 필터, 테스트, 결과 문서·스크린샷.
- 제외: 계정 관리 화면과 비밀번호 초기화·허용/미허용(2-2), 내 정보 관리 사진 정책(2-2), 인사명령·이력(3단계), 인사부가정보 팝업, 우편번호 검색 연동, 주민등록번호 전체 보기, 퇴사 시 계정 자동 비허용(2-2에서 결정).
