# 20261119_008 인사관리 1단계 부서관리 작업지시서

## 배경
인사관리 모듈을 신설한다. 전체는 3단계(1 부서관리 → 2 인사정보관리 → 3 인사명령처리)이며 단계마다 별도 작업지시서·계획서·사양서·PR 단위로 진행한다. 이 문서는 1단계(부서관리)만 다룬다. 구 MES 부서 등록 화면(좌측 폴더형 트리, 우클릭 메뉴, 부서생성 팝업, 우측 소속 사원 목록)을 참고하되 s-erp 공통 컴포넌트로 구현한다.

## 결정 (사용자 승인, 2026-11-19)
- 부서 트리는 공통 `F1Tree`로 구현하고, 폴더 아이콘(열림·닫힘·하위 없음)을 위해 `F1Tree`에 선택 옵션 `treeNodeIcon`을 추가한다. 옵션을 주지 않으면 기존 화면 동작은 그대로이다.
- 부서는 삭제하지 않는다. 하위 부서나 소속 사원이 있으면 사용안함 처리도 차단하고 안내한다. 사용안함 부서는 기본 트리에서 숨기고 조회 옵션으로 본다.
- `tb_department`를 확장한다: `manager_user_id`(부서장), `department_dc`(설명), 감사컬럼(`created_by`, `updated_by`). `department_code`는 두지 않는다(`tb_user.department_id`로 참조, 동명 구분은 같은 상위 아래 부서명 유일 제약).
- 모듈 `HR`(인사관리), 메뉴 그룹 `HR_INFO`(`/hr/info`), 화면 메뉴 `HR_INFO_DEPARTMENT`(`/hr/info/department-manage`). 사원·인사명령 메뉴는 각 단계에서 만든다(빈 그룹을 먼저 만들지 않는다).
- 소스 폴더와 신규 테이블 접두어는 `hr`. 부서·사원은 기존 `tb_department`, `tb_user`를 확장하므로 이름을 바꾸지 않는다.
- 우클릭 메뉴: 하위 부서 추가 / 편집 / 사용안함(복원). 부서 입력은 공통 `CommonDialog` 팝업.
- 우측 소속 사원 목록은 현재 `tb_user` 컬럼(성명·직급·아이디 등)만 보여 준다. 재직/퇴직 필터는 2단계에서 `join_dt`/`retire_dt`가 생긴 뒤 켠다.

## 범위
- 포함: DB 스크립트(컬럼·제약·모듈/메뉴/권한 시드, 롤백, 이력 md, `db-schema.md`), 백엔드 `let/hr/department`, 프론트 `pages/hr/department`, `F1Tree.treeNodeIcon`과 `F1-GRID.md`, 테스트, 결과 문서·스크린샷, AGENTS.md 테이블 이름 규칙 한 줄(이미 수정됨) 동봉.
- 제외: 사원 등록·수정(2단계), 인사명령(3단계), 부서 삭제 기능, 영업·타 담당자 파일, 기존 `tb_department` 소비 화면(창고 등) 변경.
