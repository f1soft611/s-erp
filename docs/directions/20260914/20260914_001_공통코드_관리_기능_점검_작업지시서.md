# 20260914_001 공통코드 관리 기능 점검 작업지시서

## 작업 목적

공통코드 관리 페이지에서 다음 기능이 정상 동작하는지 확인하고, 불량 지점을 재현/원인 분석/수정까지 수행한다.

- 조회
- 저장
- 루트 추가
- 행 추가
- 행 삭제

이번 작업은 화면 동작의 정상 여부를 확인하고 필요한 범위만 수정하는 것을 목표로 한다. 기능이 의도대로 동작하지 않는 구간을 확인하고, 실패 원인이 명확하면 최소 수정으로 보완한다.

## 작업 범위

- 프론트엔드: `frontend/src/pages/co/master/common-code/**`
- 관련 서비스/타입/배열 상태 처리
- 필요 시 F1Grid/F1Tree 공통 컴포넌트와 상호작용 검증
- 브라우저 기반 실제 동작 확인 및 재현 절차 정리

## 제외 범위

- 공통코드와 무관한 다른 메뉴/모듈의 로직 수정
- 대규모 리팩터링 또는 구조 변경
- 백엔드 스키마/DB 설계 변경이 아닌 경우에는 별도 DB 변경 작업을 미리 추가하지 않음
- 공통코드 기능과 관련 없는 공용 컴포넌트 대규모 정리

## 확인 항목

1. 페이지 진입 시 공통코드 그룹/상세 목록 조회가 정상 동작하는지
2. 선택 그룹 변경 시 상세 목록이 재조회되고 올바른 데이터가 노출되는지
3. 수정 내용이 dirty 상태로 반영되고 저장 API 흐름이 정상 동작하는지
4. 루트 추가 동작이 새 그룹 생성과 화면 반영까지 이어지는지
5. 행 추가 동작이 새 상세코드 생성과 화면 반영까지 이어지는지
6. 행 삭제 동작이 선택한 상세코드 제거와 저장 플로우까지 정상 동작하는지
7. 저장 실패/재조회 시 기존 변경값이 안전하게 처리되는지
8. 최소 검증 범위로 브라우저에서 실제 화면 동작 확인

## 기대 산출물

- 작업지시서 기준 범위의 점검 결과
- 실패 재현 조건 및 원인 파악
- 필요한 경우 수정 후 재검증 결과
- 결과 문서(`docs/result/YYYYMMDD/...`)와 필요 시 스크린샷

## 승인 기준

- 작업지시서 범위와 목표가 맞다는 확인을 받은 뒤에 계획서와 상세 사양서를 작성한다.
- 기능 점검 및 수정은 이 작업지시서 범위 안에서만 수행한다.

## 금지 사항

- 문서 없이 코드 수정 시작 금지
- 작업 범위를 벗어난 기능 추가 금지
- 실제 브라우저 검증 없이 성공 결론 내리지 않기
- 관련 기능을 테스트하지 않고 화면만 보고 완료로 간주하지 않기
