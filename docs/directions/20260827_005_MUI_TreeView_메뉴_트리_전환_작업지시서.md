# 20260827_005 MUI TreeView 메뉴 트리 전환 작업지시서

## 1. 작업 개요

대시보드 좌측 메뉴 패널의 `List` 기반 2단계 렌더링을 MUI X `SimpleTreeView` 기반 트리로 전환한다. 기존 모듈 레일과 하단 사용자 정보 영역은 유지하며, 선택 모듈의 메뉴 데이터만 트리로 표시한다.

## 2. 작업 목적

- 표준 트리 컴포넌트의 확장/축소 및 키보드 접근성 모델을 적용한다.
- 메뉴 데이터의 재귀형 `children` 구조를 그대로 렌더링한다.
- 그룹 메뉴와 페이지 이동 메뉴의 역할을 분리한다.

## 3. 확정 동작

- 모듈 선택 시 해당 모듈의 첫 페이지 메뉴로 이동하고, 그 조상 그룹을 펼친다.
- 자식 메뉴가 있는 그룹을 선택하면 확장/축소만 수행하며 URL과 현재 페이지를 변경하지 않는다.
- `pageKey`를 가진 리프 메뉴를 선택하면 기존 `/dashboard/:moduleId/:menuId` 경로로 이동한다.
- 현재 경로의 리프 메뉴는 선택 상태로 표시되고, 그 조상 그룹은 펼쳐진 상태로 표시한다.
- 기본, hover, 선택, 확장 상태는 기존 ERP형 밝은/다크 테마 톤과 구분되어야 한다.

## 4. 구현 범위

### Frontend

- `@mui/x-tree-view` 의존성 추가
- `DashboardMenuTree`를 `SimpleTreeView`와 재귀 `TreeItem` 렌더러로 교체
- `DashboardPage`의 메뉴 탐색을 재귀형 데이터 구조에 맞게 정리
- 그룹 클릭 시 첫 자식으로 이동하던 기존 라우팅 제거
- 좌측 사이드바 테스트에 그룹 토글과 리프 라우팅 검증 추가

### 비범위

- 백엔드 API, DB 스키마 및 메뉴 API 계약 변경
- 모듈 레일 및 하단 사용자 정보 카드의 구조 변경
- 메뉴 데이터의 신규 생성 또는 화면 범위를 벗어난 대시보드 리팩터링

## 5. 완료 조건

- 선택 모듈의 메뉴가 MUI `SimpleTreeView`로 렌더링된다.
- 그룹 클릭은 URL을 변경하지 않고 하위 메뉴를 토글한다.
- 리프 메뉴 클릭은 기존 페이지 이동과 선택 표시를 유지한다.
- 모듈 변경 및 직접 URL 진입 시 현재 리프의 조상 그룹이 펼쳐진다.
- Vitest 대상 테스트와 프론트엔드 빌드가 성공한다.
- 결과 문서와 브라우저 스크린샷을 `docs/result`에 남긴다.

## 6. 영향 범위 및 DB 점검

- 영향 범위: `frontend` 대시보드 좌측 사이드바와 관련 테스트
- DB 변경: 없음
- SQL 스크립트 및 스키마 이력: 불필요
