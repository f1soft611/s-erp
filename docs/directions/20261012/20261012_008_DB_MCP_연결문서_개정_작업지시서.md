# 작업지시서

## 작업명

PostgreSQL 읽기 전용 MCP 연결 안내 개정

## 목적

기존 MCP 구성 사양서의 오래된 `.vscode/mcp.json` 안내를 현행 루트
`.mcp.json` 및 VS Code Copilot 세션 연결 절차에 맞게 갱신한다.

## 작업 범위

- 기존 구성 사양서의 로컬 환경 준비, 설치·빌드, MCP 시작·신뢰, 새 세션
  도구 확인 절차를 다시 작성한다.
- 기본 DB MCP 서버와 선택적 tenant 서버를 구분해 설명한다.
- 비밀번호, 접속 문자열, DB 접속 주소, 계정 또는 tenant 식별 정보를 문서에
  복사하지 않는다.
- 이미 변경 중인 루트 `.mcp.json`과 MCP 서버 코드는 수정하지 않는다.
- 결과 문서에 변경 및 검증 내역을 기록한다.

## 완료 기준

- 연결 절차가 루트 `.mcp.json`의 stdio 등록과 일치한다.
- 개발자가 로컬 `.env` 준비부터 새 Copilot 세션에서 도구 확인까지 따라 할 수
  있다.
- 명령과 경로가 저장소의 MCP 패키지 구성과 일치한다.
- 문서에 자격 증명 또는 민감한 접속값이 포함되지 않는다.
- `git diff --check`가 통과하고 무관한 변경 파일을 수정하지 않는다.
