# 작업지시서

## 작업명

DB MCP 에이전트 사용 지침 명확화

## 목적

에이전트가 데이터베이스 관련 작업에서 사람용 연결 안내에 그치지 않고,
workspace에 등록된 PostgreSQL 읽기 전용 MCP 도구를 직접 호출하도록 공통
규칙과 DB 전용 지침을 명확히 한다.

## 작업 범위

- `AGENTS.md`에서 DB 작업 시 MCP 직접 호출 의무와 상세 지침 위치를 안내한다.
- `.github/instructions/database-mcp.instructions.md`에서 서버 선택, 도구
  호출 순서, 읽기 제한, tenant 선택, 도구 미노출·실패 시 대응을 구체화한다.
- 연결할 수 없는 경우 MCP 확인을 완료한 것처럼 말하지 않고, VS Code에서
  서버 시작·신뢰 및 새 세션 생성이 필요한 점을 안내한다.
- 연결 자격 증명, `.mcp.json`, MCP 코드, 기존 사용자용 연결 사양서는 변경하지
  않는다.
- 날짜별 결과 문서를 추가한다.

## 완료 기준

- 기본 MCP 서버 도구를 DB 관련 작업에서 직접 호출해야 함이 명시되어 있다.
- 테이블 목록, 관련 테이블 정의, 필요한 경우의 제한 쿼리 순서가 명확하다.
- tenant 서버는 요청 맥락상 해당 DB가 필요한 때만 선택한다.
- 도구 미노출 또는 연결 실패가 발생하면 사실을 보고하고 허용된 저장소 자료를
  대체 근거로 사용한다.
- 자격 증명 노출 또는 데이터 쓰기 지침이 없다.
- 변경 범위의 `git diff --check`가 통과한다.
