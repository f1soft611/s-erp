# DB MCP 세션 도구 검색 오류 수정 작업지시서

## 작업 목적

로컬 VS Code Copilot 세션이 S-ERP 읽기 전용 PostgreSQL MCP 도구를 발견하지 못하는 문제를 바로잡는다.

## 조사 결과

- 루트 `.mcp.json`은 Copilot portable workspace 설정 위치와 `mcpServers` 구조를 사용한다.
- 두 서버 항목의 전송 유형은 VS Code stdio MCP 문서에서 요구하는 `stdio`가 아닌 `local`로 지정되어 있다.
- 두 항목에 VS Code 설정 스키마에 없는 `tools` 속성이 포함되어 있다.
- MCP 서버 실행 파일은 존재하며 stdio 초기화 후 `list_tables`, `describe_table`, `query_readonly`를 제공한다.
- 해당 VS Code 세션의 과거 MCP 시작 오류 로그는 확보되지 않아 설정 불일치와 서버 실행 확인을 근거로 수정한다.

## 작업 범위

- `.mcp.json`의 두 PostgreSQL 서버 항목에서 `type`을 `stdio`로 변경한다.
- 두 항목에서 지원되지 않는 `tools` 속성을 제거한다.
- 기존 서버명, 명령/인수, tenant 전용 데이터베이스명 덮어쓰기는 유지한다.
- 설정 구조 회귀 테스트를 추가한다.
- 작업 전후 결과를 날짜별 문서에 기록한다.

## 제한 사항

- MCP 서버 코드와 읽기 전용 SQL 정책은 수정하지 않는다.
- 로컬 `.env`, 자격 증명, 원격 데이터베이스 데이터는 조회하거나 변경하지 않는다.
- `.mcp.json`에 비밀번호나 연결 문자열을 추가하지 않는다.
- 다른 기존 작업 변경사항은 수정하거나 커밋에 포함하지 않는다.

## 완료 기준

1. primary 및 tenant MCP 항목이 표준 stdio 형식으로 등록되어야 한다.
2. 회귀 테스트가 잘못된 전송 유형 또는 미지원 속성을 검출해야 한다.
3. 설정 JSON 파싱, 관련 테스트, MCP stdio 도구 목록 확인이 통과해야 한다.
4. VS Code에서 서버를 신뢰하고 시작한 뒤 새 로컬 세션에 도구가 제공되는 확인 절차를 결과 문서에 남긴다.
