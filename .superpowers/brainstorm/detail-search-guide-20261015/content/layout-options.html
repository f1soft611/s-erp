상세검색 가이드, 어떤 설명 순서가 가장 이해하기 쉬울까요?

실제 페이지에 붙여 볼 수 있는 전체 흐름 예제를 공통으로 포함하고, 설명을 읽는 순서만 다르게 구성했습니다.

A

따라 하기: 단계별 레시피 추천

먼저 “무엇을 만들지” 보여주고, 컬럼 설정 → 상세검색 필드 만들기 → 화면 연결 → 검색 결과 조회 순서로 안내합니다.

상세검색 연동하기
1. 검색할 항목 정하기컬럼에 label / type / options 설정
2. 검색 필드 만들기toPageSearchFields(columns)
3. 검색 영역에 연결하기detailFields + values + callbacks
4. 실제 조회하기페이지가 값을 API 조건으로 변환
columns → detailFields → PageSearchArea → query → API

완성된 한 화면 예제와 필드별 결과값, 흔한 실수를 단계 뒤에 둡니다.

B

예제 먼저: 전체 코드 해설

완성 코드 한 덩어리를 처음에 보여주고, 코드 줄을 따라가며 각 부분의 역할을 설명합니다.

한 번에 보는 예제
const columns = [...]
const detailFields = ...
<PageSearchArea ... />
// 조회 조건 만들고 API 호출
① columns검색 폼에 노출할 필드 지정
② detailFieldsGrid 컬럼 정의를 폼 정의로 변환
③ callbacks입력값 보관과 검색 실행

전체 그림이 빨리 보이지만 초보자에게 코드가 먼저 길게 느껴질 수 있습니다.

C

찾아보기: 설정표와 짧은 샘플

설정 속성을 표로 먼저 훑고, 날짜·select·숨김 필드 샘플을 필요한 부분만 골라 읽습니다.

속성별 빠른 참고
설정역할예시search.label표시 이름상태type: date기간 입력{ from, to }
선택 필드type: select + options
숨길 필드search.hidden: true

참조용으로 빠르지만 전체 연결 순서를 독자가 직접 조합해야 합니다.
