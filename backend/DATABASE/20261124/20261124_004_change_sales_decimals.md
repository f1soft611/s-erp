# 영업 숫자 자릿수 확장

- 날짜: 2026-11-24
- 대상: 수주·견적·출하·출하계획·거래명세서의 헤더 및 상세 숫자 컬럼
- 변경: 기존 `numeric(15,2)` 컬럼 27개를 `numeric(19,6)`으로 확장해 정수부 13자리를 유지한다.
- 영향: 테이블에 배타 잠금을 획득하며 ALTER TABLE에서 테이블 재작성과 잠금 대기가 발생할 수 있다. 적용 전 백업 및 점검 시간을 확보한다.
- 전제: 대상 컬럼이 모두 `numeric(15,2)`여야 하며 그렇지 않으면 전체 트랜잭션을 중단한다.
- 롤백: 전 대상 테이블을 잠근 후 소수 셋째 자리 이상, 정수부 범위 초과 또는 NaN이 있으면 축소하지 않고 전체 중단한다. 데이터 손실 허용 여부를 별도 결정하기 전에는 값을 임의로 반올림하지 않는다.
- 근거: 기본 읽기 전용 PostgreSQL MCP의 `list_tables`, `describe_table` 및 `information_schema.columns` 메타데이터 조회. 데이터 행은 조회하지 않았다.
- 적용 상태: 사용자가 실제 DB에 적용했으며 읽기 전용 MCP에서 대상 27개 컬럼이 `numeric(19,6)`인 것을 확인했다. 에이전트는 공유 DB에 SQL을 적용하지 않았다. 영업 계산·입력·저장 작업은 미완료다.
