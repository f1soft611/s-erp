# 20261002_003 조건형 ID 발번 테이블 추가

- 날짜: 2026-10-02
- 변경 내용: 조건별 숫자 발번을 위한 `tb_id_sequence` 테이블을 추가하고 공통코드 상세의 기존 숫자형 코드를 그룹별 카운터에 반영한다.
- 적용 대상 테이블: `tb_id_sequence`, `tb_common_code_item` (읽기만 수행)
- 영향 범위: 상세코드 저장 시 코드가 비어 있으면 그룹별 숫자 `item_code` 발급. 기존 직접 입력 및 공통코드 테이블 구조는 유지한다.
- 테넌트 범위: 카운터 테이블에는 `tenant_id`를 두지 않는다. 기존 그룹 ID를 범위 키로 사용하며 공통코드 테이블/API의 테넌트 필터는 유지한다.
- 기존 데이터 처리: 숫자 전용 코드 중 BIGINT 범위 값의 그룹별 최댓값을 `last_issued_value`에 시드한다. 3자리 초과 코드도 변경하거나 자르지 않는다.
- 롤백 여부: 가능. 롤백 스크립트에서 `tb_id_sequence`를 삭제한다. 공통코드 행은 변경하지 않는다.
- 검증: PostgreSQL 읽기 전용 조회에서 그룹 24의 최댓값 999, 그룹 27의 최댓값 2를 확인했으며, 마이그레이션은 각각의 다음 자동 발급을 1000, 003으로 시작시킨다.

## 적용 순서

1. 기존 `tb_common_code_item`의 숫자 코드를 읽어 카운터를 초기화한다.
2. 애플리케이션 mapper 및 저장 서비스를 배포한다.

이 작업 번호의 SQL/이력/롤백 파일은 `docs/database` 및 `backend/DATABASE`의 `20261002` 폴더에 동일하게 보관한다.
