# 수주부터 매출마감까지 초기화 스크립트

- 작성일: 2026-11-23. 스키마 변경 없음, 실제 DB 미적용.
- 대상: 실행자가 지정한 단일 테넌트의 수주·출하계획·출하·거래명세서.
  매출마감 정보는 출하 상세의 마감 필드에 저장되므로 해당 행과 함께 삭제된다.
- 거래처·품목 등 기준정보, 다른 테넌트와 구매 데이터, 번호 시퀀스는 보존한다.
  구매요청이 대상 수주를 참조하면 구매 데이터를 삭제하지 않고 중단한다.
- 스크립트는 대상 테이블 전체의 쓰기를 잠그므로 실행 중 다른 테넌트의
  해당 테이블 쓰기도 대기할 수 있다. 확인된 건수 출력 후 기본
  `ROLLBACK`한다. 실행 전 백업하고 실행자가 범위·건수를 확인한 경우에만
  마지막 명령을 `COMMIT`으로 바꾼다. 커밋 후에는 백업으로 복원해야 한다.
- 기본 PostgreSQL MCP의 관련 테이블 및 외래 키 메타데이터와
  `20261120_002_sales_statement_detail_source_and_revenue_closing.sql`을
  근거로 작성했으며 업무 데이터 행은 조회하지 않았다.
