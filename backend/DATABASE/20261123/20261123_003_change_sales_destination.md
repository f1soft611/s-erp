# 납품처 마스터 및 수주 참조 변경

- 작성일: 2026-11-23. 작성 중인 DDL이며 실제 DB에는 적용하지 않았다.
- 영향: `tb_sales_destination` 신설, `tb_sales_order_hd`에 납품처 및 매출처
  참조 열과 테넌트 범위 외래 키 추가. 기존 납품장소 열은 유지한다.
- 기존 주문 변환은 하지 않는다. 다른 테넌트의 기존 주문을 보존하기 위해
  신규 열은 nullable이며 신규·수정 시 필수 검증은 API가 담당한다.
- 롤백 스크립트는 납품처나 신규 참조가 있으면 중단한다. 데이터가 생긴 후
  롤백은 백업 복원이 필요하다.
- 기본 PostgreSQL MCP에서 거래처와 수주 테이블 및 제약 메타데이터를
  확인했다. 업무 데이터 행은 조회하지 않았다.
