# 공정관리 스키마 변경

- 날짜: 2026-11-12
- 대상: `tb_process_group`, `tb_process`, `tb_module`, `tb_menu`, `tb_menu_permission`
- 내용: 테넌트별 공정그룹과 공정 및 이미지·속성 저장, 생산관리 공정관리 메뉴 정의.
- 영향: 공정은 동일 테넌트의 공정그룹만 참조한다. 공정이 남은 그룹은 삭제할 수 없다.
- 스키마: `20261112_003_create_process_management.sql`. 기존 테이블이 있으면 중단하므로 계약과 소유권을 먼저 확인해야 한다.
- 메뉴: `20261112_003_seed_process_management_menu.sql`. 승인된 대상 테넌트를 지정해야 하며 역할 권한은 별도 부여한다.
- 롤백: 데이터가 있으면 `20261112_003_rollback_process_management.sql`은 중단한다. 메뉴는 소유권 확인 후 `20261112_003_rollback_process_management_menu.sql`로 해당 테넌트의 메뉴만 비활성화한다. 기존 모듈·상위 메뉴·권한은 유지한다.
- 읽기 전용 MCP에서 두 공정 테이블의 컬럼과 복합 외래키 및 생산관리 모듈·공정관리 메뉴의 존재를 확인했다. 다른 환경이나 테넌트에 적용되었는지는 확인하지 않았다. 이 작업에서 DB 쓰기나 스크립트 적용을 수행하지 않았다.
