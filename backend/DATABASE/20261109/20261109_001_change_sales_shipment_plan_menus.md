# 출하계획 메뉴 계층 보정 이력

- 날짜: 2026-11-09
- 대상: 승인된 대상 DB의 `tb_menu`, `tb_menu_permission`, `tb_role_menu_permission`
- 영향: 기존 계획 메뉴 ID와 역할 권한을 유지해 출하관리 아래로 이동하고, 참조가 없는 독립 계획 상위 메뉴만 삭제한다. 누락된 계획 메뉴는 신규 등록하고 수주 메뉴 권한을 복사한다.
- 사전 조건: 대상 DB 백업 후 SQL의 `v_tenant_id`를 승인된 값으로 지정한다. 메뉴가 충돌하거나 독립 상위 메뉴에 다른 참조가 있으면 트랜잭션 전체가 중단된다.
- 롤백: 신규·기존 메뉴의 과거 상태가 서로 다를 수 있어 자동 역변경은 차단한다. 적용 전 검증된 메뉴·권한 백업으로 DBA가 복원한다. 별도 롤백 SQL은 실수로 실행하지 못하도록 중단한다.
- 스키마 변경 없음. 실제 DB 적용은 수행하지 않았다.
